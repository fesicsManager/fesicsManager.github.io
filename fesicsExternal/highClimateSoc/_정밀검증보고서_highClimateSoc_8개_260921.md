## 최우선 수정 항목

### 1. 02화 — 캡이 실제로 지켜지지 않음 (중대)

`calc()`는 목표 감축량 `Q`로 균형 가격을 구한 뒤, 느슨한 캡에서는 가격을 임의로 40% 낮추고(`price *= 0.4`), 시장 안정 장치에서는 가격을 최소 15로 올린다. 이후 바뀐 가격으로 기업별 감축량을 다시 계산하므로 `totalQ`가 목표 `Q`와 달라진다.

- 결과: “캡이 있는 한 총량은 반드시 줄어든다”는 본문과 시뮬레이션 결과가 충돌한다.
- 시장 안정 장치가 감축 목표와 무관하게 초과 감축을 만들 수도 있다.
- 권장 수정: 캡앤트레이드 기본 모형에서는 `sum(q_i) = Q`를 항상 만족시키고, 과잉 할당은 캡 자체 또는 유통 배출권 수량을 바꾸는 별도 시나리오로 구현한다. 가격 하한이 적용될 경우 초과 감축·정부 매입·경매 미판매 중 어떤 메커니즘인지 명시한다.

### 2. 08화 — 설명의 “약 30회차”와 계산식이 불일치 (중대)

본문은 초기 3%, 설득력 보통, 지속 참여 조건에서 약 30회차에 25% 임계점에 도달한다고 설명한다. 그러나 코드의 증가식은 `p(1-p) × 0.2 × 3 × 1 - 0.03p`이므로 초기 구간에서 매 회차 약 50% 이상 상대 증가하여 대략 5~6회차에 임계점을 넘는다.

- 결과: 학습자가 본문 예측과 실제 그래프 사이에서 상반된 결과를 본다.
- 권장 수정: 코드 계수를 재보정해 30회차 근처가 되게 하거나, 설명을 실제 계산 결과에 맞춘다. `×3`이 “주변 3명”을 뜻한다면 중복 접촉과 이미 참여한 사람을 포함하는 확률 모형을 명시적으로 구현하는 편이 안전하다.
- 추가 주의: 3.5% 비폭력 운동 연구와 약 25% 사회규범 실험은 서로 다른 연구 맥락이다. 하나의 연속된 임계점 법칙처럼 읽히지 않도록 구분하고 출처를 표시하는 것이 필요하다.

### 3. 01화 — 설명의 국가별 누적 배출 비율이 코드 데이터와 불일치 (중대)

본문은 “8개국 누적 배출 합에서 미국 25%, 중국 15%, 독일 6%, 인도 3%”라고 적었지만 코드 데이터 합계는 873.2(십억 t)이며 계산값은 대략 미국 48.1%, 중국 29.8%, 독일 10.9%, 인도 6.9%이다.

- 결과: 원리 설명과 실제 결과표가 크게 다르다.
- 권장 수정: 문장을 코드 계산값에 맞춰 고치거나, 25%·15%가 세계 누적 배출 비중을 뜻한다면 “8개국 합에서”를 삭제하고 동일 기준·연도·가스 범위의 출처를 붙인다.

## 파일별 상세 검증

### 01_emission_vulnerability_lab_ClimateSoc_Ep01.html — 수정 필요

- 실행 구조: 정상. 구문 오류·중복 ID 없음.
- 계산 구조: 피어슨 상관계수 계산과 선택 기준별 몫 합계는 코드상 일관됨.
- 오류: 본문 국가별 누적 비율과 코드 데이터가 불일치.
- 표현 보완: `BASIS`의 “1인당 배출”을 부담 몫 계산 시 `1인당 배출 × 인구`로 변환하므로 실제 계산 기준은 “현재 총배출”이다. 버튼과 설명을 “현재 총배출(1인당×인구)”로 바꾸는 것이 정확하다.
- 통계 주의: 8개국만 임의 선택한 상관계수이므로 세계 전체의 인과관계처럼 일반화하지 않도록 표본 제한을 결과 영역에도 표시할 것.

### 02_emission_trading_cap_lab_ClimateSoc_Ep02.html — 수정 필요

- 실행 구조: 정상.
- 중대 오류: 가격을 사후 조정한 뒤 총감축량을 재계산하여 캡 목표가 깨짐.
- 개념 보완: 무상 할당 비율은 단기 균형가격을 직접 낮추는 변수가 아니라 배분·비용 귀착에 주로 영향을 준다. 현재 코드에서는 가격과 감축에는 영향을 주지 않고 기업 지불액만 바꾸므로, 이 사실을 UI에 명시하면 교육적으로 더 정확하다.

### 04_climate_migration_lab_ClimateSoc_Ep04.html — 보완 권장

- `left`는 누적 이주자/초기 인구 비율인데 변수명이 “남음”처럼 읽힐 수 있다. 표시 의미를 명확히 할 것.

### 06_city_density_emission_lab_ClimateSoc_Ep06.html — 보완 권장

- 실행 구조와 수단 분담 합계는 입력 범위 내에서 정상.
- 교통 배출식의 단위 환산(`km/일 × 365 × kg/km ÷ 1000 = t/년`)은 맞음.
- 애틀랜타 6 t, 바르셀로나 1 t, 면적 25배 문구는 경계·연도·교통 배출 정의에 크게 좌우되므로 출처와 기준을 명시할 것.
- 밀도에 따라 자동차 분담률을 자동으로 10%/20% 감산하면서 사용자가 별도로 대중교통 분담률을 정한다. 밀도 효과와 수단 분담 효과가 중복 반영될 수 있으므로 “보행·자전거 자동 증가” 가정을 UI에 표시할 것.
- 열섬 계산은 설명상 교육용 지수이므로 실제 ℃ 예측값처럼 보이지 않게 “모형 온도 상승”으로 명명 권장.

### 07_food_carbon_plate_lab_ClimateSoc_Ep07.html — 정상(표현 보완 권장)

- 생선의 농지 계수는 육상 농지와 직접 비교하기 어려우므로 “토지 사용 환산값” 또는 데이터 한계를 표시할 것.

### 08_social_tipping_35_lab_ClimateSoc_Ep08.html — 수정 필요

- 실행 구조 정상.
- 중대 오류: 본문의 약 30회차 설명과 코드 결과 불일치.
- 모형은 25%를 넘는 즉시 매 회차 잔여 인구의 15%가 추가 동참하도록 설계되어 급격한 전환을 미리 보장한다. 25% 결과를 검증하는 실험이 아니라 25%를 규칙으로 넣은 시뮬레이션임을 명확히 써야 한다.

## 검증 범위의 한계

소스 정적 검사와 계산·표시 상호 대조까지 수행했다. 현재 검증 환경에는 실행 가능한 Chromium 바이너리가 없어 실제 브라우저 클릭 자동화와 화면 캡처 기반 시각 QA는 수행하지 못했다. 따라서 최종 배포 전 Chrome/Edge에서 각 파일의 실행 버튼, 탭 전환, 4회 이상 기록, 데이터 검증 차트, 360 px 모바일 폭을 한 번씩 확인하는 것이 필요하다.
