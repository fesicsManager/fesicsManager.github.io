타원 초점 실험실 — a² − b²

장축과 단축을 바꿔 가며 초점의 위치를 재고, a²−b² 와 a²+b² 중 무엇과 맞는지 확인합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 타원은 c² = a² − b² — 피타고라스와 부호가 반대

타원 위의 점에서 두 초점까지 거리의 합이 2a 예요. 단축의 끝점에서 이 조건을 쓰면 b² + c² = a², 곧 c² = a² − b² 가 나옵니다. a²+b² 로 계산하면 초점이 타원 밖으로 나가 버립니다.

⚙️ 왜 그럴까

  • 단축 끝점에서 두 초점까지 거리가 각각 a 이고, 직각삼각형을 이룹니다.
  • a > b 이므로 c² = a² − b² > 0 이고 c < a — 초점은 타원 안에 있습니다.
  • a = b 면 c = 0 으로 원이 됩니다.

🧮 이 실험의 계산 방법

a, b를 바꿔 초점의 위치를 계산하고 실제 거리의 합이 2a 인지 확인

· “초점은 피타고라스처럼 a²+b² 로 구한다” → 타원은 빼기입니다.
