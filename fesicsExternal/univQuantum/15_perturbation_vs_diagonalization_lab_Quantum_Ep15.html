정확히 못 풀 때 조금씩 고친다

정확히 풀리는 해밀토니안에 작은 교란을 더합니다. 무한 우물의 왼쪽 절반에만 턱 V₀를 깔거나, 조화 진동자의 용수철을 ε만큼 세게 만들어 보세요. 1차·2차 섭동 보정과 행렬 수치 대각화(고유함수 N개 기저)를 나란히 비교합니다. 뭉치는 "가운데에 몰려 있으니 거의 0"이라고 했어요.

📖 물리 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 비축퇴 섭동 이론

Ĥ = Ĥ⁰ + λĤ′를 λ로 전개하면

Eₙ⁽¹⁾ = ⟨n⁰|Ĥ′|n⁰⟩, Eₙ⁽²⁾ = Σ_(m≠n) |⟨m⁰|Ĥ′|n⁰⟩|² / (Eₙ⁰ − Eₘ⁰)

1차 보정은 교란을 비섭동 상태로 평균한 것(가중 평균)이고, 바닥 상태의 2차 보정은 분모가 모두 음수라 항상 내려갑니다. 축퇴가 있으면 이 공식이 깨져요.

🧮 무한 우물 + 왼쪽 절반 턱

  • Eₙ⁽¹⁾ = V₀/2 (모든 n) — |ψₙ|²가 x = a/2에 대칭이라 정확히 절반이 턱 위
  • H′₂₁ = 4V₀/(3π) = 0.4244V₀, H′₃₁ = 0, H′₄₁ = −0.1698V₀, H′₆₁ = 0.1091V₀ (짝수 m만 남음)
  • E₁⁽²⁾ = −0.0625V₀²/E₁ (m = 2 항이 96 %), E₂⁽²⁾ = +0.0469V₀²/E₁ — 준위 반발
  • V₀ = 0.1E₁: 2차까지 0.04938E₁ / V₀ = 0.5E₁: 2차까지 0.23438, 수치 0.23445

🌀 조화 진동자 + (ε/2)mω²x²

정확해 ω → ω√(1+ε) → E/E⁰ = √(1+ε). 1차 1 + ε/2, 2차 1 + ε/2 − ε²/8 — √(1+ε)의 테일러 급수 그대로입니다. ε = 0.01 · 0.1 · 0.5 → 정확 1.004988 · 1.048809 · 1.224745.

수치 대각화는 비섭동 고유함수 N개로 Ĥ 행렬을 만들어 야코비 회전으로 대각화합니다. N을 늘리면 정확값으로 수렴해요.

📌 실험 모형과 실제의 차이
· 섭동 급수가 아예 발산하는 경우(점근 급수)도 많습니다. 변분법은 섭동이 작지 않아도 쓸 수 있는 보완 도구예요.
· "수렴값"은 N = 60 기저 대각화 결과입니다(넷째 자리 이내로 수렴).

위: 퍼텐셜(회색)과 섭동된 상태의 확률 밀도(파랑), 섭동 전(점선). 아래 막대: 에너지 변화 — 1차, 2차까지, 수치 대각화.
