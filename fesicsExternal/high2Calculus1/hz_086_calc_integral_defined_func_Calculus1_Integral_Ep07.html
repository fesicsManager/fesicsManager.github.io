적분 변수 실험실 — t 는 사라진다

위끝을 x 로 둔 적분함수를 만들어 x 를 움직이며 값을 재고, 미분하면 f(x) 가 되는지 확인합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — ∫ₐˣ f(t)dt 에서 t 는 계산되며 사라지고, 결과는 x 의 함수

적분 변수 t 는 더해 나가는 과정에서 쓰이고 결과에는 남지 않아요. 위끝 x 만 남아 F(x) 가 x 의 함수가 됩니다. 그리고 이 F 를 미분하면 F′(x) = f(x) — 미적분의 기본정리입니다.

⚙️ 왜 그럴까

  • t는 “더미 변수”라 u로 바꿔 써도 결과가 같습니다.
  • F(x+h) − F(x) 는 폭 h 인 얇은 띠의 넓이 ≈ f(x)·h.
  • 양변을 h로 나눠 h→0 하면 F′(x) = f(x).

🧮 이 실험의 계산 방법

위끝 x 를 움직이며 넓이를 재어 F(x) 를 만들고, 수치 미분으로 f(x) 와 비교

📌 자주 하는 오해
· “적분 변수와 바깥 변수는 같다” → t 는 사라지고 x 만 남습니다.
