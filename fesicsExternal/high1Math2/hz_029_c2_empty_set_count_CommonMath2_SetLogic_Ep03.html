빈 상자 실험실 — {0} 과 ∅

∅, {0}, {∅} 의 원소 개수를 세고, 부분집합의 개수 2ⁿ을 직접 나열해 확인합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — ∅ 은 원소가 0개, {0}과 {∅}은 원소가 1개 — 빈 상자와 “빈 상자가 든 상자”는 다르다

∅ 은 아무것도 없는 모임이라 n(∅) = 0이에요. {0}은 0이라는 원소가 하나 든 집합이라 n = 1, {∅}도 ∅ 이라는 원소가 하나 든 집합이라 n = 1입니다. 원소가 n개면 부분집합은 2ⁿ개, 자기 자신을 뺀 진부분집합은 2ⁿ − 1개입니다.

⚙️ 왜 그럴까

  • 각 원소마다 “넣는다/안 넣는다” 두 가지 → 2×2×… = 2ⁿ.
  • ∅의 부분집합은 ∅ 하나뿐 — 2⁰ = 1.
  • 특정 원소를 반드시 포함하는 부분집합은 2ⁿ⁻¹개입니다.

🧮 이 실험의 계산 방법

집합을 골라 부분집합을 모두 나열해 세고, 2ⁿ 및 진부분집합 개수와 대조

📌 자주 하는 오해
· “{0}과 ∅ 은 같다” → {0}은 원소가 하나 있는 집합입니다.
