실험 02 · 경사면으로 마찰계수 μ 측정하기

미끄러지기 직전의 임계각으로 정지마찰계수를, 미끄러지는 시간으로 운동마찰계수를 구합니다. 두 값이 왜 다른지, 그리고 측정이 타당한지 기울기로 검증합니다.
※ 재료별 마찰계수는 건조한 표면·상온 조건의 시뮬레이션 기준값이에요. 실제 마찰계수는 표면 거칠기·오염·온도·윤활·속도에 따라 크게 달라 보편적인 '문헌값'이 아니에요. μₖ의 불확도는 회귀 기울기·절편의 공분산까지 포함해 계산해요.

📖 과학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 경사면으로 정지·운동 마찰계수 재기

경사각 θ의 빗면 위 물체에는 중력의 빗면 성분 mg·sinθ와 수직 항력 N = mg·cosθ가 작용해요. 정지 마찰: 물체가 미끄러지기 직전(임계각 θ_s)에는 최대 정지 마찰력 μ_s N = mg·sinθ_s → μ_s = tanθ_s — 질량과 무관하게 각도만으로 정해져요. 운동 마찰: 미끄러지는 동안 가속도 a = g(sinθ − μ_k cosθ)이므로 여러 각도에서 a를 재고 a/cosθ = g·tanθ − gμ_k로 선형화하면 기울기 A = g, 절편 B = −gμ_k → μ_k = −B/A. 기울기가 g와 맞는지가 측정 타당성의 검사예요. 보통 μ_k < μ_s예요(움직이기 시작하면 표면 사이 결합이 끊어져 마찰이 줄어듦).

⚙️ 계산해 보기

  • 나무–나무(건조): θ_s ≈ 26.6° → μ_s = 0.50. 각도 읽기 오차 ±0.5° → δμ_s = sec²θ·δθ = 1.25 × 0.0087 = ±0.011.
  • 운동: 0.8 m 미끄러지는 시간 t로 a = 2L/t². 30°에서 μ_k = 0.30이면 a = 9.8(0.5 − 0.26) = 2.36 m/s², t = 0.82 s.
  • 회귀: 기울기 A ≈ 9.8 ± σ_A, 절편 B ≈ −2.94 ± σ_B → μ_k = 0.30. A가 9.8에서 크게 벗어나면 시간 측정이나 모형에 문제.
  • μ_k 불확도: A와 B는 같은 자료에서 나와 상관되어 있으므로 공분산 항 −2cov(A,B)/(AB)을 포함해야 정확해요.

🧮 이 실험의 계산 방법

μ_s = tan θ_s, a = 2L/t², 회귀 y = a/cosθ vs x = tanθ → A, B, σ_A, σ_B, cov; μ_k = −B/A, (δμ/μ)² = (σ_B/B)² + (σ_A/A)² − 2cov/(AB)

📌 실험 모형과 실제의 차이
· 재료별 계수는 건조한 깨끗한 표면·상온의 시뮬레이션 기준값이에요. 실제 마찰계수는 표면 거칠기·오염·습도·온도·윤활·속도에 따라 크게 달라 같은 '나무–나무'도 0.25~0.5로 보고돼요. 보편적 문헌값이 아니라 조건이 붙은 값으로 봐야 해요.
· 쿨롱 마찰 모형(마찰력 ∝ N, 속력 무관)은 근사예요. 실제로는 속력·접촉 시간에 따라 조금 변하고, 물체가 구르거나 기울면 식이 달라져요.

두 방식, 두 개의 식

임계각: mg sinθₛ = μₛ mg cosθₛ → μₛ = tan θₛ
등가속: a = g(sinθ − μₖ cosθ) → a/cosθ = g·tanθ − g·μₖ (y = Ax + B)

두 번째 식은 a/cosθ 를 세로축, tanθ 를 가로축에 놓으면 직선입니다. 기울기 A는 g여야 하고(실험이 타당한지 스스로 검사하는 값), 절편 B = −gμₖ 에서 운동마찰계수가 나옵니다. 한 번의 맞춤으로 미지수 하나를 구하고 이미 아는 값 하나를 검산하는 구조입니다.
