12주차 · 얇은 렌즈의 상 위치와 배율

초점 거리가 다른 볼록·오목 렌즈 앞에 높이 3 cm 물체를 놓고, 물체 거리 so를 바꿔 상의 위치 si와 배율을 잽니다. 물체가 초점 안쪽으로 들어가면 상이 어떻게 될지 예측하고, 1/si–1/so 그래프로 렌즈 공식을 확인하세요.
※ 상 위치 측정값에 약 ±1% 모의 오차를 넣었습니다. 두께를 무시한 얇은 렌즈·근축 광선 모형이에요. 부호: 실상 si > 0, 허상 si < 0.

📖 과학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 얇은 렌즈 공식

1/so + 1/si = 1/f, 배율 m = −si/so (m < 0이면 도립)

  • 볼록 렌즈(f > 0): so > 2f 축소 실상 · f < so < 2f 확대 실상 · so < f 확대 정립 허상(돋보기)
  • 오목 렌즈(f < 0): 언제나 축소 정립 허상
  • 그래프: 1/si = −1·(1/so) + 1/f → 기울기 −1, y절편 1/f

🪞 반사와 굴절

렌즈는 굴절(스넬 법칙 n₁sinθ₁ = n₂sinθ₂)로, 구면 거울은 반사로 같은 공식(1/so + 1/si = 1/f, f = R/2)을 따릅니다. 렌즈 제작자 공식 1/f = (n−1)(1/R₁ − 1/R₂).

📌 실험 모형과 실제의 차이
· 실제 렌즈는 구면 수차(가장자리 광선이 더 짧은 곳에 모임)와 색수차(파장마다 n이 다름)가 있습니다.
· 허상은 스크린에 맺히지 않아 실제로는 시차법 등으로 위치를 찾아요.

🌍 생활 속에서

  • 카메라·눈(수정체), 돋보기, 근시 안경(오목), 원시 안경(볼록), 현미경과 망원경(렌즈 두 개의 조합)

가로·세로 축척이 다릅니다. 빨강은 축에 나란한 광선, 파랑은 렌즈 중심을 지나는 광선이고, 점선은 허상을 만드는 연장선이에요.
