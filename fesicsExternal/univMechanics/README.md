## 검증해 둔 값
- 최속강하선: 해석해와 5자리 일치. 수평접선 원호는 로그 발산함을 확인
- 이중진자: 이론 주기 2.62239 / 1.08623 s ↔ 수치 2.62241 / 1.08643 s. λ ≈ 1.2/s (120°)
- 용수철 진자: 교환 폭이 2:1 에서 최대 34.2%, 1.6:1 은 9.7%, 3:1 은 5.5%
- 대칭: 두 입자계는 px·py·Lz 모두 1e-14, 중력장은 py 가 64, 중심력장은 px 가 0.91 변함
- 정준변환: 회전·스케일·밀기·시간발전 모두 {Q,P}=1.00000000, 「둘 다 늘이기」만 λ²
- 유효 퍼텐셜: 회귀점에서 V_eff = E 오차 1e-16
- 산란: 유한 출발거리 오차가 1/X0 로 감소 (X0=20→600 에서 0.72°→0.024°)
- 관성 타원체: 주축에서 ∠(ω,L)=0, 정육면체는 모든 방향에서 0
- 아령: |ω×L| = m r² ω² sin2α 오차 1e-16, 45°에서 최대
- 중간축: 최소·최대축 40초 뒤집힘 0회, 중간축 6회. L²·2T 오차 1e-12
- 팽이: 스핀이 클수록 Mgl/p_ψ 근사가 좋아짐. 균일 세차에서 θ 고정
- 정규모드: ω₁=√(k/m) 이 k′ 와 무관하게 일정. 정규좌표 분리 편차 1.7e-16
