정규모드와 분자 진동

좌표를 잘 고르면 얽혀 있던 운동이 독립적인 진동자 여러 개로 풀립니다.

① 두 질량, 세 용수철

벽 — 용수철 — 질량 — 용수철 — 질량 — 용수철 — 벽. 자유도 2이므로 모드가 2개입니다.

1.00 k
ω₁ (나란히)— ω₂ (마주 보고)— ω₂/ω₁— 모드 1 진폭비(1, 1) 모드 2 진폭비(1, −1)
모드 1에서는 두 질량이 나란히 움직여 가운데 용수철이 전혀 늘어나지 않습니다. 그래서 진동수가 $\sqrt{k/m}$ 로, 가운데 용수철이 없는 것과 같습니다. $k'$ 를 0으로 줄여 보세요 — 모드 2의 진동수만 내려옵니다.

「정규좌표 보기」를 누르면 $Q_1 = (x_1+x_2)/\sqrt2$, $Q_2 = (x_1-x_2)/\sqrt2$ 를 함께 그립니다. $x_1, x_2$ 가 복잡하게 흔들려도 $Q_1, Q_2$ 는 각각 깨끗한 사인파입니다.

③ 단순 모형은 어디까지 맞는가

원자를 공, 결합을 용수철로 놓고 두 신축 모드의 진동수 비를 계산해 봅니다.

13% 어긋납니다. 결합이 단순한 용수철이 아니고, 두 결합 사이에 상호작용이 있기 때문입니다. 정확한 값을 원하면 양자화학 계산이 필요합니다.

그런데 모드가 몇 개이고 어떤 모양인지는 오늘 배운 고전역학만으로 완전히 결정됩니다. 대칭성이 정하는 것과 세부 계산이 정하는 것은 다릅니다. 앞의 것이 훨씬 튼튼합니다.

지구가 내보내는 열복사가 600~700 cm⁻¹ 부근에 상당량 있습니다. CO₂ 의 굽힘 모드가 바로 그 자리입니다. 반면 질소와 산소는 원자 두 개가 같아서 어떻게 진동해도 쌍극자가 생기지 않습니다. 대기의 99%인데 온실기체가 아닌 이유입니다.

🔑 핵심 원리 — 정규모드와 분자 진동

여러 질량이 용수철로 이어진 계의 작은 진동은 연립 미분방정식 M·ẍ = −K·x로 쓰여요. x = A·e^(iωt)를 넣으면 고윳값 문제 (K − ω²M)A = 0이 되고, 그 해가 정규모드: 모든 질량이 같은 진동수·같은 위상으로 움직이는 특별한 패턴이에요. 자유도가 n이면 모드가 n개이고, 어떤 복잡한 운동도 모드의 중첩이에요. 각 모드의 진폭을 새 좌표(정규좌표 Q_k)로 잡으면 결합이 풀려 각 Q_k가 독립 조화 진동자처럼 깨끗한 사인파로 움직여요.

⚙️ 두 계 살펴보기

  • 벽–k–m–k–m–k–벽: 대칭 모드(두 질량 같은 방향, 가운데 용수철 안 늘어남) ω₁ = √(k/m), 반대칭 모드 ω₂ = √(3k/m). Q₁ = (x₁ + x₂)/√2, Q₂ = (x₁ − x₂)/√2. 한쪽만 당겨 놓으면 두 모드가 반반 섞여 맥놀이(에너지 왕복)가 보여요.
  • 선형 3원자 분자(CO₂형): 자유도 9 − 병진 3 − 회전 2 = 진동 모드 4개: 대칭 신축(적외선 비활성, 라만 활성), 비대칭 신축, 굽힘 2개(축퇴). 병진·회전 모드는 ω = 0(영모드).
  • 모드 진동수 비는 질량비·힘 상수로 정해져요: CO₂ 실제 값 1 333(대칭), 2 349(비대칭), 667 cm⁻¹(굽힘).
  • 모드 벡터는 M-직교: A_iᵀ M A_j = 0 (i ≠ j).

🧮 이 실험의 계산 방법

질량 행렬 M, 강성 행렬 K 구성 → 일반화 고윳값 문제 수치 해(야코비/QR) → ω_k, A_k; 시간 발전 x(t) = Σ c_k A_k cos(ω_k t + δ_k), Q_k = A_kᵀ M x

📌 실험 모형과 실제의 차이
· 작은 진동(조화 근사)이에요. 진폭이 크면 비조화항이 모드를 결합시켜 에너지가 모드 사이로 새고(페르미 공명), 진동수도 진폭에 따라 변해요.
· 실제 분자 진동은 양자화되어 있고(에너지 준위 ℏω(n + ½)), 적외선·라만 활성 여부는 쌍극자 모멘트·편극률 변화로 정해져요. 여기서는 고전 역학 모형만 다뤄요.

🌍 생활 속에서

  • 적외선 분광법으로 분자를 식별하는 것(지문 영역)이 정규모드 진동수 측정이에요. CO₂의 굽힘·비대칭 신축 모드가 적외선을 흡수해 온실 효과를 일으켜요.
  • 건물·다리의 고유 진동 모드 분석(모달 해석)은 지진·바람 공명을 피하는 설계의 기본이에요.
