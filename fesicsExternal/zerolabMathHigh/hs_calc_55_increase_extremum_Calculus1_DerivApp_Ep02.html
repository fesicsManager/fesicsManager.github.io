f′의 부호와 증가·감소 — f′ = 0 이면 항상 극값일까

도함수의 부호가 바뀌는 지점을 찾아, 그곳이 실제로 극값인지 기록합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 극값은 f′의 부호가 바뀌는 곳, f′ = 0만으로는 부족해요

f′ > 0이면 증가, f′ < 0이면 감소예요. 극댓값은 증가 → 감소(f′가 + → −), 극솟값은 감소 → 증가로 바뀌는 지점이에요. f′(a) = 0이어도 부호가 안 바뀌면(x³의 x = 0) 극값이 아니에요. 반대로 f′가 없는 뾰족점(|x|의 0)에서도 극값일 수 있어요.

⚙️ 왜 그럴까

  • f = x³ − 3x: f′ = 3(x − 1)(x + 1). x = −1에서 + → −: 극대 2. x = 1에서 − → +: 극소 −2.
  • f = x³: f′ = 3x² ≥ 0, x = 0에서 부호 유지 → 극값 아님(변곡점).
  • f″로도 판정: f′(a) = 0, f″(a) < 0이면 극대.

🧮 이 실험의 계산 방법

f′ 부호 변화 지점 탐색 → 실제 극값 여부 기록

📌 자주 하는 오해
· "f′ = 0이면 극값" → 아니에요. 함수가 a에서 미분 가능하고 a가 정의역의 내부점이면 극값일 때 f′(a) = 0이지만(페르마 정리), 그 역은 성립하지 않아요. 또한 |x|의 x = 0처럼 미분 불가능한 점에서는 f′(a) = 0이 아니어도 극값일 수 있으므로, 조건 없이 "f′ = 0은 극값의 필요조건"이라고 말할 수는 없어요.
