합집합의 원소 개수 — 왜 한 번 빼주는가

벤다이어그램에 원소를 놓고 합집합을 직접 세어, 단순한 덧셈과 어디서 차이가 나는지 기록합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — n(A ∪ B) = n(A) + n(B) − n(A ∩ B): 겹친 부분을 두 번 셌으니 한 번 빼요

n(A) + n(B)는 교집합 원소를 두 번 세므로 한 번 빼 줘야 합집합 개수가 돼요. 서로소(A ∩ B = ∅)면 그냥 더해요. 세 집합은 n(A) + n(B) + n(C) − n(A∩B) − n(B∩C) − n(C∩A) + n(A∩B∩C) — 세 번 겹친 곳은 3번 더하고 3번 빼서 0이 되니 다시 더해요(포함배제).

⚙️ 왜 그럴까

  • A = {1, 2, 3, 4}, B = {3, 4, 5}: 4 + 3 − 2 = 5 = |{1, 2, 3, 4, 5}| ✓.
  • n(A ∩ B)는 최대 min(n(A), n(B)), 그래서 n(A ∪ B)는 최소 max(n(A), n(B)).
  • 여집합: n(Aᶜ ∩ Bᶜ) = n(U) − n(A ∪ B).

🧮 이 실험의 계산 방법

벤다이어그램에 원소 배치 → 직접 센 합집합과 n(A) + n(B) 차이 기록

📌 자주 하는 오해
· "합집합 = 더하기" → 겹치면 초과 계산이에요.
