곱의 미분 — f′g′ 이 아닌 이유

두 함수를 곱한 뒤 미분한 값을, f′g + fg′ 와 f′g′ 각각과 비교해 기록합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — (fg)′ = f′g + fg′, f′g′이 아니에요

곱의 변화량은 f가 변한 몫 + g가 변한 몫이에요. 가로 f, 세로 g인 직사각형에서 f가 Δf, g가 Δg 늘면 넓이 증가는 Δf·g + f·Δg + Δf·Δg이고, 마지막 항은 2차 소량이라 극한에서 사라져요. 그래서 f′g + fg′. f′g′은 사라지는 그 모퉁이 조각에 해당해 답이 아니에요.

⚙️ 왜 그럴까

  • f = x², g = x³: (x⁵)′ = 5x⁴. f′g + fg′ = 2x·x³ + x²·3x² = 5x⁴ ✓. f′g′ = 6x³ ✗.
  • 몫의 법칙 (f/g)′ = (f′g − fg′)/g²도 같은 원리.
  • 세 함수: (fgh)′ = f′gh + fg′h + fgh′.

🧮 이 실험의 계산 방법

fg를 전개해 미분 → f′g + fg′, f′g′과 각각 비교

· "미분은 곱과 순서를 바꿔도 된다" → 합·상수배만 그래요.
