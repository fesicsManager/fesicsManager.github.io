(a + b)³ — 정육면체를 잘라 항의 정체 확인하기

한 변이 a + b인 정육면체를 8조각으로 잘라 각 조각의 부피를 기록하고, 전개식의 각 항이 어느 조각인지 맞춰봅니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — (a + b)³ = a³ + 3a²b + 3ab² + b³: 정육면체 8조각

한 변이 a + b인 정육면체를 각 방향으로 a, b로 자르면 a³ 1개, a²b 3개, ab² 3개, b³ 1개 총 8조각이에요. 세 방향 각각에서 a 또는 b를 고르는 2³ = 8가지 조합이고, a를 2번 b를 1번 고르는 방법이 3가지라 3a²b예요. 계수 1, 3, 3, 1은 파스칼 삼각형 3번째 줄이에요.

⚙️ 왜 그럴까

  • (a + b)(a + b)(a + b): 각 괄호에서 하나씩 골라 곱한 것을 모두 더함.
  • (a − b)³ = a³ − 3a²b + 3ab² − b³.
  • a³ + b³ = (a + b)³ − 3ab(a + b) — 유용한 변형.

🧮 이 실험의 계산 방법

8조각 부피 기록 → 전개식 각 항과 대응

📌 자주 하는 오해
· "(a + b)³ = a³ + b³" → 모서리·면 조각 6개가 빠져요.
