n제곱근 — 실수 범위에서 몇 개나 있나

y = xⁿ 과 y = a 의 교점을 세어, n의 홀짝과 a의 부호에 따라 실근이 몇 개인지 기록합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 실수인 n제곱근의 개수는 n의 홀짝과 a의 부호가 정해요

a의 n제곱근은 xⁿ = a의 해이고, 실수 범위에서는 y = xⁿ과 y = a의 교점 개수예요. n이 홀수면 xⁿ은 증가함수라 어떤 a에도 교점이 정확히 1개(ⁿ√a 하나). n이 짝수면 xⁿ ≥ 0이고 좌우 대칭이라 a > 0이면 ±ⁿ√a 2개, a = 0이면 1개, a < 0이면 0개예요. 복소수까지 넓히면 항상 n개예요.

⚙️ 왜 그럴까

  • x³ = −8 → x = −2 하나. x⁴ = 16 → x = ±2. x² = −4 → 실근 없음.
  • 기호 ⁿ√a는 n이 짝수일 때 양의 것 하나만 가리켜요. "16의 네제곱근"은 ±2, "⁴√16"은 2.
  • n 홀수: ⁿ√(−a) = −ⁿ√a.

🧮 이 실험의 계산 방법

y = xⁿ과 y = a 교점 수 세기 → n 홀짝 × a 부호 표로 정리

📌 자주 하는 오해
· "n제곱근은 항상 n개" → 실수 범위에서는 0, 1, 2개뿐이에요.

🌍 생활 속에서

  • 부피에서 한 변 길이(세제곱근)는 항상 하나, 넓이에서 변(제곱근)은 양수만 뜻이 있어요.
