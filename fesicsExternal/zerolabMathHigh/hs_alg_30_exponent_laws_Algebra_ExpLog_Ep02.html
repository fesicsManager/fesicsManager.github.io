지수의 확장 — 0, 음수, 분수 지수는 왜 그렇게 정했나

지수법칙이 그대로 유지되는지 확인합니다. m, n에 음수와 분수를 넣어 좌변과 우변을 비교해 기록합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — a⁰ = 1, a⁻ⁿ = 1/aⁿ, a^(1/n) = ⁿ√a는 지수법칙을 유지하기 위한 정의

지수를 0·음수·분수로 넓힐 때 새 규칙을 만든 게 아니라, aᵐ·aⁿ = aᵐ⁺ⁿ, (aᵐ)ⁿ = aᵐⁿ이 그대로 성립하도록 값을 정한 거예요. aⁿ·a⁰ = aⁿ⁺⁰ = aⁿ이려면 a⁰ = 1, aⁿ·a⁻ⁿ = a⁰ = 1이려면 a⁻ⁿ = 1/aⁿ, (a^(1/n))ⁿ = a¹ = a이려면 a^(1/n) = ⁿ√a여야 해요. 이렇게 정하면 m, n에 무엇을 넣어도 좌변과 우변이 일치해요.

⚙️ 확인

  • 2³ · 2⁻¹ = 8 × ½ = 4 = 2². (8^(1/3))² = 2² = 4 = 8^(2/3).
  • 2², 2¹, 2⁰, 2⁻¹: 4, 2, 1, ½ — 절반씩 줄어드는 흐름이 자연스럽게 이어져요.
  • 밑 a > 0이어야 분수 지수가 잘 정의돼요((−8)^(1/3)은 주의).

🧮 이 실험의 계산 방법

m, n에 음수·분수 대입 → aᵐ·aⁿ vs aᵐ⁺ⁿ, (aᵐ)ⁿ vs aᵐⁿ 수치 비교

📌 자주 하는 오해
· "a⁰ = 0" → 1이에요. "a⁻² 는 음수" → 1/a²으로 양수예요.

🌍 생활 속에서

  • 반감기(2^(−t/T)), 연 5 % 이자를 월 단위로(1.05^(1/12)) 나누는 계산이 확장된 지수예요.
