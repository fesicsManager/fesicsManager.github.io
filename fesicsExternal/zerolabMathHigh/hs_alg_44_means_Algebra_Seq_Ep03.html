등차중항과 등비중항 — 가운데를 정하는 두 가지 방법

두 수 a와 c 사이에 들어갈 수를 “차가 같게” 와 “비가 같게” 두 방식으로 구해 비교합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 등차중항 (a + c)/2, 등비중항 ±√(ac)

a와 c 사이에 수 b를 넣을 때 차가 같게 하면 b − a = c − b → b = (a + c)/2(산술평균), 비가 같게 하면 b/a = c/b → b² = ac → b = ±√(ac)(기하평균). 양수 a, c에서 등차중항 ≥ 등비중항이고 a = c일 때만 같아요(산술–기하 평균 부등식).

⚙️ 왜 그럴까

  • 2와 8: 등차중항 5, 등비중항 4(2, 4, 8).
  • (a + c)/2 − √(ac) = (√a − √c)²/2 ≥ 0.
  • 등비중항은 a, c가 같은 부호일 때만 실수예요.

🧮 이 실험의 계산 방법

두 방식으로 b 계산 → 차이 비교, a = c일 때 일치 확인
