유리함수의 평행이동 — x − p 인데 왜 오른쪽으로 가는가

y = k/x 를 옮겨 y = k/(x − p) + q 를 만들고, 점근선의 위치를 식과 비교해 기록합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — y = k/(x − p) + q의 점근선은 x = p, y = q

y = k/x의 점근선 x = 0, y = 0이 (p, q)만큼 함께 이동해요. x − p인데 오른쪽으로 가는 이유는 x = p일 때 분모가 0이 되어 그래프가 터지는 자리(세로 점근선)가 되기 때문이에요. y = (ax + b)/(cx + d)는 나눗셈으로 이 꼴로 고칠 수 있고, 점근선은 x = −d/c, y = a/c예요.

⚙️ 왜 그럴까

  • y = 2/(x − 1) + 3: 점근선 x = 1, y = 3. 두 점근선 교점 (1, 3)이 대칭 중심.
  • y = (3x + 1)/(x − 1) = 3 + 4/(x − 1): 점근선 x = 1, y = 3.
  • k > 0이면 1·3사분면 방향, k < 0이면 2·4사분면 방향.

🧮 이 실험의 계산 방법

p, q 변경 → 점근선 위치 측정, 식과 비교
