0/0 꼴 — 대입이 막힐 때 값을 찾는 법

분모와 분자가 함께 0이 되는 식에서, 양쪽에서 다가가며 값이 어디로 모이는지 기록합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 0/0은 "값이 없다"가 아니라 "이대로는 알 수 없다"

분모·분자가 함께 0이 되면 대입이 막히지만, 극한은 그 점 주변을 보는 것이므로 인수분해·유리화로 공통 인수를 약분한 뒤 대입하면 값이 나와요. (x² − 4)/(x − 2)는 x → 2에서 (x + 2) → 4. 0/0 꼴은 식마다 값이 달라서(0, 1, ∞ 모두 가능) '부정형'이라 불러요.

⚙️ 왜 그럴까

  • (√(x + 1) − 1)/x, x → 0: 유리화 → 1/(√(x + 1) + 1) → ½.
  • sin x / x → 1, (1 − cos x)/x → 0, x/x² → ∞: 모두 0/0 꼴이지만 답이 달라요.
  • ∞/∞, ∞ − ∞, 0·∞도 부정형.

🧮 이 실험의 계산 방법

양쪽에서 다가가며 값 기록 → 약분한 식에 대입한 값과 비교

📌 자주 하는 오해
· "0/0 = 1" 또는 "= 0" → 정해진 값이 없어요. 반드시 식을 변형해요.

🌍 생활 속에서

  • 순간 속도(Δs/Δt에서 Δt → 0)가 바로 0/0 꼴의 극한 — 미분의 출발점이에요.
