삼차식 실험실 — 근과 계수의 관계는 이어질까?

세 근으로 삼차식을 만들어 전개하고, 근의 합·곱과 계수를 대조한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 삼차방정식의 근과 계수의 관계

세 근 α, β, γ를 가진 삼차식 (x − α)(x − β)(x − γ)를 전개하면 x³ − (α+β+γ)x² + (αβ+βγ+γα)x − αβγ예요. 따라서 x³ + bx² + cx + d = 0에서 세 근의 합 = −b, 두 개씩 곱의 합 = c, 세 근의 곱 = −d예요. 이차방정식의 관계(합 −b/a, 곱 c/a)가 차수를 올려도 같은 규칙으로 이어져요(비에트 정리).

⚙️ 왜 그럴까

  • x² 계수: 세 인수에서 x를 두 개 고르고 근 하나를 −부호로 고른 항의 합 → −(α+β+γ).
  • x 계수: x 하나, 근 두 개 → +(αβ+βγ+γα). 상수항: 근 셋 → −αβγ.
  • 근 1, 2, 3: x³ − 6x² + 11x − 6. 합 6, 두 개씩 곱 합 11, 곱 6.

🧮 이 실험의 계산 방법

세 근으로 전개해 계수 b, c, d를 얻고 −b, c, −d와 대조

📌 자주 하는 오해
· "부호를 헷갈림" → 홀수 개 근을 곱한 항(x², 상수)은 음수, 짝수 개는 양수. 최고차 계수가 a면 모두 a로 나눠요.

🌍 생활 속에서

  • 근을 직접 구하지 않고 근의 합·곱 같은 대칭식 값을 구할 때, 제어공학의 특성방정식 분석에 쓰여요.
