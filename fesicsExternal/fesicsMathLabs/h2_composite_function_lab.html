합성함수 실험실 — 넣는 순서를 바꾸면?

두 일차함수를 서로 다른 순서로 합성해 식과 값을 비교한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 합성함수는 순서에 따라 달라요: f∘g ≠ g∘f

(f∘g)(x) = f(g(x))는 g를 먼저 통과시킨 뒤 f에 넣는 것이고, (g∘f)(x)는 그 반대예요. f(x) = ax + b, g(x) = cx + d면 f∘g = acx + (ad + b), g∘f = acx + (bc + d)로 x의 계수는 같지만 상수항이 달라요. f∘g = g∘f가 되는 것은 ad + b = bc + d인 특별한 경우뿐이에요.

⚙️ 왜 그럴까

  • f: 2배, g: +3. f(g(x)) = 2(x + 3) = 2x + 6, g(f(x)) = 2x + 3. '3 더하고 2배'와 '2배 하고 3 더하기'는 달라요.
  • 합성 기호는 오른쪽 함수부터 적용해요(f∘g에서 g가 먼저).
  • 정의역·치역이 맞아야 합성이 가능해요: g의 치역이 f의 정의역 안에 있어야 해요.

🧮 이 실험의 계산 방법

f∘g = a(cx + d) + b, g∘f = c(ax + b) + d; 식과 특정 x에서의 값 비교

📌 자주 하는 오해
· "f∘g는 f 먼저" → 안쪽(오른쪽)부터예요.
· "합성 = 곱셈" → f(x)·g(x)와는 전혀 달라요.

🌍 생활 속에서

  • 할인 후 세금 vs 세금 후 할인, 환율 변환 뒤 수수료 계산 순서가 합성 순서예요.
