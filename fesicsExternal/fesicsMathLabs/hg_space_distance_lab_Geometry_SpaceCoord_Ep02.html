공간 거리 실험실 — 좌표를 그냥 더하면 될까?

평면 위 그림자까지의 거리와 높이로 피타고라스를 두 번 써서 공간 거리를 구한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 공간 거리는 피타고라스를 두 번 쓴 √(x² + y² + z²)

원점에서 P(x, y, z)까지의 거리는 좌표를 그냥 더한 값이 아니에요. 먼저 xy평면 위 그림자까지 √(x² + y²), 그것과 높이 z로 다시 직각삼각형을 만들면 √(x² + y² + z²)예요. x + y + z가 맞는 건 두 좌표가 0일 때(축 위)뿐이에요.

⚙️ 왜 그럴까

  • P(3, 4, 12): 그림자 5, 거리 √(25 + 144) = 13. x + y + z = 19(틀림).
  • 두 점 사이 거리는 좌표 차의 제곱합의 제곱근.
  • 구의 방정식 x² + y² + z² = r²이 바로 '원점에서 거리 r'이에요.

🧮 이 실험의 계산 방법

그림자 길이 → √(그림자² + z²); x + y + z와 비교

📌 자주 하는 오해
· "좌표를 더하면 거리" → 축을 따라 걷는 '택시 거리'는 되지만 직선 거리는 아니에요.

🌍 생활 속에서

  • GPS 3차원 위치, 항공기 사이 거리, 3D 게임의 충돌 판정이 이 공식이에요.
