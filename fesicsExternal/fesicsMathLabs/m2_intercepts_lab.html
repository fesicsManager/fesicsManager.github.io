절편 실험실 — x절편은 b ÷ a일까?

그래프가 두 축과 만나는 점을 찾아 대입으로 검산하고, 부호를 바꾸지 않은 값과 비교한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — y절편은 x = 0의 y값 b, x절편은 y = 0을 풀어 −b/a

y = ax + b에서 y축과 만나는 점은 (0, b), x축과 만나는 점은 0 = ax + b를 풀어 x = −b/a, 즉 (−b/a, 0)이에요. 부호를 빠뜨린 b/a는 b = 0일 때만 우연히 맞아요. 절편은 '축과 만나는 점의 좌표 하나'라는 것을 기억하세요. a = 0이면 수평선이라 x절편이 없어요(b ≠ 0).

⚙️ 왜 그럴까

  • y = 2x + 6: y절편 6, x절편 −3. 검산 2(−3) + 6 = 0 ✓. b/a = 3이면 2·3 + 6 = 12 ≠ 0.
  • x절편의 부호: a, b가 같은 부호면 음수, 다르면 양수.
  • 두 절편을 알면 직선을 바로 그릴 수 있어요.

🧮 이 실험의 계산 방법

y = 0 대입해 x 구하기 → 원식에 대입해 검산, b/a와 비교

📌 자주 하는 오해
· "x절편은 b/a" → 이항하면 부호가 바뀌어요. 항상 대입 검산.

🌍 생활 속에서

  • 손익분기점(이익 = 0이 되는 판매량), 연료가 바닥나는 시각이 x절편이에요.
