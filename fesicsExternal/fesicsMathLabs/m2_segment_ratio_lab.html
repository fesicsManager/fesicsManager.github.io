평행선 실험실 — 어떤 비가 서로 같을까?

삼각형에 밑변과 평행한 선을 긋고 여러 선분의 비를 재어, 서로 같은 비와 다른 비를 구별한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — DE ∥ BC이면 AD : AB = AE : AC = DE : BC, AD : DB = AE : EC

삼각형 밑변 BC에 평행한 선 DE를 그으면 △ADE ∽ △ABC라 전체 변에 대한 비가 같아요(AD : AB = DE : BC). 조각끼리의 비 AD : DB = AE : EC도 성립해요. 하지만 AD : DB와 DE : BC는 다른 비예요. DE가 정확히 중간이면 AD : DB = 1 : 1인데 DE : BC = 1 : 2예요. DE를 구할 때는 잘린 조각의 비가 아니라 AB 전체에 대한 비를 써야 해요.

⚙️ 왜 그럴까

  • AD = 2, DB = 3(AB = 5), BC = 10: DE = 10 × 2/5 = 4. AD : DB = 2 : 3으로 계산하면 6.7(틀림).
  • 닮음비는 대응하는 '변 전체'의 비예요.
  • 역도 성립: AD : AB = AE : AC이면 DE ∥ BC.

🧮 이 실험의 계산 방법

평행선 위치별 각 선분 길이 측정 → 세 가지 비 비교

📌 자주 하는 오해
· "AD : DB = DE : BC" → 잘린 조각 비를 그대로 쓰면 틀려요.

🌍 생활 속에서

  • 그림자로 나무 높이 재기, 지도 축척, 사진 확대·축소가 닮음비 계산이에요.
