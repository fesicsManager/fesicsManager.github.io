# 수학 인터랙티브 실험 모음 (201종)

초등 3학년부터 미적분Ⅱ까지, 교육과정 전 범위의 개념 실험 HTML 파일입니다.

## 여는 방법

`index.html` 을 브라우저로 엽니다. 검색과 과정별 필터로 원하는 실험을 찾아
카드를 누르면 해당 실험이 열립니다.

모든 파일이 **같은 폴더**에 있어야 링크가 동작합니다. 각 실험 파일은
단독으로 열어도 정상 작동합니다(외부 라이브러리·네트워크 불필요).

## 실험의 공통 구조

1. **자유 탐구** — 슬라이더로 조건을 바꾸고 실행 버튼으로 관찰합니다.
2. **기록하기** — 관찰 결과가 표에 한 줄씩 쌓입니다.
3. **데이터 확인** — 기록이 4개 이상 모이면 탭이 열립니다.
   학생 자신의 기록만으로 통계를 내고 결론을 씁니다.

설계 원칙:

- 화면에 나오는 값은 전부 **실제 계산 결과**입니다. 미리 정해 둔 수치나
  꾸며 낸 상수를 쓰지 않았습니다. 좌표기하, 수치미분, 수치적분, 전수 열거로
  그때그때 구합니다.
- 학생이 아직 **반례를 만나지 않았으면 결론이 열리지 않습니다.**
  "더 해 보자"가 뜨면서 어떤 조건을 시험해야 하는지 안내합니다.
- 각 실험은 하나의 **오개념**을 겨냥합니다. 맞는 방법과 틀리기 쉬운 방법을
  나란히 계산해 보여 주고, 언제 우연히 같아지는지도 함께 기록합니다.
- 난수를 쓰는 실험(동전, 구슬, 표본평균, 신뢰구간, 이상값)은 매번 결과가
  달라집니다. 나머지는 같은 조건이면 같은 값이 나옵니다.

## generators 폴더

각 실험을 만든 파이썬 스크립트입니다. `gen_math_labs.py` 안의 공통 엔진
템플릿에 실험별 `LAB` 객체를 끼워 넣어 HTML을 생성합니다. 실험을 고치거나
새로 추가할 때 참고하시면 됩니다. `gen_index.py` 는 `index.html` 을 다시
만듭니다.
