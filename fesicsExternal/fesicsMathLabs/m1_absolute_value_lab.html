절댓값 실험실 — |a − b| 는 무엇을 나타낼까?

수직선에서 두 점 사이 거리를 재고, |a|−|b| 와 비교한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — |a − b|는 수직선에서 두 점 사이의 거리예요

절댓값은 '부호를 떼는 것'이 아니라 0에서 떨어진 거리예요. 그래서 |a − b|는 항상 두 점 a, b 사이의 거리이고 음수가 될 수 없어요. 부호가 같으면 두 절댓값의 차, 다르면 두 절댓값의 합과 같아요. |a| − |b|는 이와 다른 값이고 음수가 되기도 해요. a가 음수면 |a| = −a(예: |−3| = −(−3) = 3)예요.

⚙️ 왜 그럴까

  • a = 5, b = −3: |5 − (−3)| = 8 = 5 + 3(부호 다름). a = 5, b = 2: |5 − 2| = 3 = 5 − 2(부호 같음).
  • |a| − |b| = 5 − 3 = 2 ≠ 8.
  • |a − b| = |b − a| — 거리는 방향이 없어요.

🧮 이 실험의 계산 방법

수직선 두 점 사이 거리 측정 → |a − b|, |a| − |b|, |a| + |b|와 비교

📌 자주 하는 오해
· "|a| = a (부호만 떼면 됨)" → a가 음수면 |a| = −a. 문자에서는 부호를 알아야 해요.

🌍 생활 속에서

  • 온도 차, 오차의 크기, 두 지점 거리처럼 '얼마나 떨어졌나'는 모두 절댓값이에요.
