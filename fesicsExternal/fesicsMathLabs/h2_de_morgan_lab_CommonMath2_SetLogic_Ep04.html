집합 실험실 — 여집합을 씌우면 ∪는 어떻게 될까?

1부터 12까지에서 두 집합을 만들어 여집합 연산 결과를 원소 단위로 대조한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 드모르간 법칙: 여집합을 취하면 ∪와 ∩이 바뀌어요

(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ, (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ. "A 또는 B에 속하지 않는다"는 "A에 속하지 않고 그리고 B에도 속하지 않는다"와 같은 말이기 때문이에요. 기호만 그대로 두고 여집합을 씌우면((A ∪ B)ᶜ = Aᶜ ∪ Bᶜ) 틀려요.

⚙️ 원소로 확인

  • U = {1…12}, A = 2의 배수, B = 3의 배수. A ∪ B = {2,3,4,6,8,9,10,12}, 여집합 {1,5,7,11}. Aᶜ ∩ Bᶜ = 홀수 ∩ 3의 배수 아님 = {1,5,7,11} ✓.
  • Aᶜ ∪ Bᶜ = {1,3,5,7,9,11} ∪ {1,2,4,5,7,8,10,11}은 훨씬 커서 다름.
  • 벤 다이어그램에서 (A ∪ B)ᶜ는 두 원 바깥 = 두 여집합의 겹치는 부분.

🧮 이 실험의 계산 방법

각 원소가 A, B에 속하는지 판정 → 양변 집합을 원소 단위로 비교

📌 자주 하는 오해
· "부정은 기호 그대로 분배" → 부정은 ∪↔∩, '모든'↔'어떤'을 바꿔요.

🌍 생활 속에서

  • 검색 조건 "NOT (A OR B)" = "NOT A AND NOT B", 프로그래밍 조건문·회로 설계(NAND/NOR)에 드모르간 법칙을 써요.
