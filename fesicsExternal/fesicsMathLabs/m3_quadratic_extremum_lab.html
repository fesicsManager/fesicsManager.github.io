최댓값 실험실 — c가 최솟값일까?

y = ax²+bx+c의 그래프에서 가장 낮은(높은) 점을 직접 찾아 −b/2a, c와 비교한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 최댓값·최솟값은 x = −b/2a에서, 그 값은 c가 아니에요

y = ax² + bx + c의 꼭짓점 x좌표는 −b/2a이고 최솟값(a > 0) 또는 최댓값(a < 0)은 그 x를 대입한 값이에요. c는 x = 0일 때의 값, 즉 y절편일 뿐이고, b = 0일 때만 꼭짓점과 겹쳐요. 완전제곱으로 고치면 y = a(x + b/2a)² + (c − b²/4a)라 최적값 = c − b²/4a예요.

⚙️ 왜 그럴까

  • y = x² − 4x + 7: x = 2에서 최솟값 3 (c = 7이 아님).
  • a > 0 아래로 볼록 → 최솟값, a < 0 위로 볼록 → 최댓값.
  • 꼭짓점은 두 근의 정중앙(대칭축).

🧮 이 실험의 계산 방법

그래프에서 가장 낮은(높은) 점 탐색 → x = −b/2a, y와 c 비교

📌 자주 하는 오해
· "상수항 c가 최솟값" → 그래프가 x = 0에서 꼭짓점일 때만.

🌍 생활 속에서

  • 던진 공의 최고 높이, 이익이 최대가 되는 가격, 울타리로 만드는 최대 넓이가 이차함수 최적화예요.
