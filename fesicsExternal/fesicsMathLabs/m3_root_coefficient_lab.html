근과 계수 실험실 — 근을 구하지 않고 합을 알 수 있을까?

이차방정식의 두 근을 실제로 구해 합과 곱을 계산하고, −b/a·c/a와 대조한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 두 근의 합 = −b/a, 곱 = c/a (근과 계수의 관계)

ax² + bx + c = 0의 두 근 α, β에 대해 a(x − α)(x − β) = ax² − a(α + β)x + aαβ이므로 계수를 비교하면 α + β = −b/a, αβ = c/a예요. 근을 구하지 않고도 합·곱을 알 수 있고, 거꾸로 합·곱을 알면 x² − (합)x + (곱) = 0으로 방정식을 만들 수 있어요. a ≠ 1일 때도 성립해요.

⚙️ 왜 그럴까

  • 2x² − 6x + 4 = 0: 근 1, 2. 합 3 = 6/2, 곱 2 = 4/2 ✓.
  • 근의 공식으로 더하면 ±√ 부분이 사라져 −2b/2a = −b/a.
  • α² + β² = (α + β)² − 2αβ처럼 대칭식을 계수로 계산할 수 있어요.

🧮 이 실험의 계산 방법

두 근 계산 → 합·곱, −b/a·c/a와 비교

📌 자주 하는 오해
· "합은 −b, 곱은 c" → a로 나눠야 해요. a = 1일 때만 그대로.

🌍 생활 속에서

  • "합이 10, 곱이 21인 두 수"를 바로 x² − 10x + 21 = 0으로 만드는 것, 회로·진동 해석에서 근의 합·곱으로 특성을 읽는 것.
