## A급 — 즉시 수정 권고

### `hp_conditional_probability_lab_ProbStat_CondProb_Ep01.html`

**문제 1: 두 조건부확률이 같아지는 조건을 지나치게 제한함**

현재 설명은 `P(A|B)`와 `P(B|A)`가 같아지는 경우를 “A인 수와 B인 수가 같을 때뿐”이라고 단정한다. 그러나 `P(A∩B)=0`이면 `P(A)>0`, `P(B)>0`인 범위에서 두 조건부확률은 모두 0이므로, A와 B의 전체 수가 달라도 서로 같다.

- 현재 취지: `P(A|B)=P(A∩B)/P(B)`, `P(B|A)=P(A∩B)/P(A)`
- 정확한 조건: 분모가 정의되는 범위에서 `P(A∩B)=0`이거나 `P(A)=P(B)`이면 두 값이 같다.
- 권장 문구: **“P(A)>0, P(B)>0일 때 두 값은 A∩B가 공집합이거나 P(A)=P(B)인 경우에 같다.”**

이 표현은 원리 설명과 실험 결론 문자열 양쪽에 동일하게 반영해야 한다.

**문제 2: 곱셈정리를 ‘언제나 성립’이라고 표현함**

결론에 `P(A∩B)=P(A)·P(B|A)는 언제나 성립했다`라고 되어 있으나, `P(B|A)`는 `P(A)>0`일 때만 정의된다.

- 권장 문구: **“P(A)>0일 때 P(A∩B)=P(A)·P(B|A)가 성립한다.”**

## B급 — 공통 품질 개선 권고

### Canvas 고해상도(DPR) 대응

실험 HTML 201개 모두 Canvas를 사용하며 화면 크기 변화에 따른 재계산 코드는 확인됐다. 그러나 `window.devicePixelRatio`를 반영해 내부 버퍼 해상도를 조정하는 처리는 확인되지 않았다. 일반 모니터에서는 동작하지만 Retina·고밀도 모바일·브라우저 확대 환경에서는 선과 글자가 흐려질 수 있다.

권장 공통 처리:

```js
const dpr = window.devicePixelRatio || 1;
const rect = canvas.getBoundingClientRect();
canvas.width = Math.round(rect.width * dpr);
canvas.height = Math.round(rect.height * dpr);
ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
```

기존 좌표계와 충돌하지 않도록 Canvas 초기화 함수에서 한 번만 적용하고, resize 시 동일하게 재설정해야 한다.
