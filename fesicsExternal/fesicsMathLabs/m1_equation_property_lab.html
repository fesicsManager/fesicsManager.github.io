참·거짓 실험실 — 늘 참일까, 가끔 참일까?

식을 고르고 x 에 여러 수를 넣어, 어떤 x 에서도 참인 식과 한 값에서만 참인 식을 가려낸다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 늘 참인 식과 가끔 참인 식은 달라요

문자가 들어간 등식에는 두 가지가 있어요. 2(x+3) = 2x+6 처럼 x 에 어떤 수를 넣어도 참인 식을 항등식, 3x+1 = 10 처럼 딱 한 값에서만 참인 식을 방정식이라 해요. 방정식을 참으로 만드는 그 값이 해예요. 식만 보고는 알기 어려우니 x 에 여러 수를 넣어 보면 가려져요. 또 등식을 고칠 때 양변에 똑같이 하면 참·거짓이 바뀌지 않아요 — 저울 양쪽에 같은 무게를 올리는 것과 같아요.

⚙️ 왜 그럴까

  • 2(x+3) 을 풀면 2x+6 — 모양만 다른 같은 식이라 어떤 x 에서도 참이에요.
  • 3x+1 = 10 은 x = 3 일 때만 양변이 10 으로 같아요. 다른 수를 넣으면 거짓.
  • 한 번 참이었다고 늘 참은 아니에요. x 를 3가지 이상 넣어 봐야 가릴 수 있어요.
  • 8 = 8 에서 양변 +3 → 11 = 11 ✓. 왼쪽만 +3 → 11 ≠ 8 — 참이 거짓이 돼요.

🧮 이 실험의 계산 방법

식 고르기 → x 넣어 양변 값 재기 → 참·거짓 판정 → 같은 식에 x 를 여러 가지로 넣어 '늘 참'인지 가리기

📌 자주 하는 오해
· "x 에 한 수를 넣어 참이면 늘 참" → 방정식도 해에서는 참이에요. 여러 x 를 넣어 봐야 해요.
· "이항은 새로운 규칙" → 양변에서 같은 수를 빼는 것을 줄여 쓴 것뿐이에요.

🌍 생활 속에서

  • 저울로 물건 무게 재기, 요리 비율 늘리기(양쪽 재료 모두 2배)가 등식의 성질이에요.
