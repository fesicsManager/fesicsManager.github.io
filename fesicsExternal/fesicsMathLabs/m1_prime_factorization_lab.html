소인수분해 실험실 — 약수의 개수를 세지 않고 구할 수 있을까?

수를 소수로 나누어 소인수분해하고, (지수+1)의 곱과 실제로 센 약수의 개수를 비교한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 약수의 개수 = (지수 + 1)들의 곱

수를 소인수분해하면 약수는 각 소인수를 0개부터 지수 개까지 골라 곱해 만든 것이에요. 고르는 방법의 수가 곧 약수의 개수라 (a + 1)(b + 1)…(a, b는 지수)예요. 72 = 2³ × 3²의 약수는 (3 + 1)(2 + 1) = 12개. 아주 큰 수도 하나씩 세지 않고 개수를 알 수 있어요.

⚙️ 왜 그럴까

  • 2는 0~3개(4가지), 3은 0~2개(3가지) → 4 × 3 = 12가지 조합 = 약수 12개.
  • 소수는 p¹이라 약수 2개(1과 자신). 제곱수는 약수 개수가 홀수예요.
  • 약수의 합도 (1 + 2 + 4 + 8)(1 + 3 + 9)로 구할 수 있어요.

🧮 이 실험의 계산 방법

소수로 나누어 소인수분해 → Π(지수 + 1); 실제로 약수를 세어 대조

📌 자주 하는 오해
· "지수를 곱하면 약수 개수" → +1을 잊으면 0개 고르는 경우가 빠져요.

🌍 생활 속에서

  • 암호(RSA)는 큰 수의 소인수분해가 어렵다는 점을 이용하고, 톱니바퀴·타일 설계에 약수가 쓰여요.
