□ 구하기 실험실 — □는 = 뒤의 수일까?

구슬 한 묶음을 가려 □를 만들고, 전체에서 빼서 구한 값이 실제 가린 수와 같은지 확인한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 덧셈식의 □는 뺄셈으로 거꾸로 구해요

7 + □ = 16에서 □는 = 뒤의 16이 아니에요. 전체 16개 중 보이는 7개를 빼면 가려진 수가 나오니 □ = 16 − 7 = 9예요. 덧셈과 뺄셈은 서로 거꾸로 하는 관계라, 모르는 수를 구할 때는 반대 계산을 해요.

⚙️ 왜 그럴까

  • 구슬 두 묶음을 합쳐 16개인데 한 묶음이 7개면 다른 묶음은 16에서 7을 뺀 9개.
  • = 뒤의 수를 그대로 쓴 답이 우연히 맞는 건 보이는 수가 0일 때뿐이에요.
  • □ − 5 = 8이면 □ = 8 + 5(뺄셈의 반대는 덧셈).

🧮 이 실험의 계산 방법

a + □ = c → □ = c − a, 검산: a + (c − a) = c

📌 자주 하는 오해
· "□는 = 다음 수" → 등호를 '답'으로 읽은 실수예요. □는 양쪽이 같아지게 하는 수예요.

🌍 생활 속에서

  • "3 000원 내고 거스름돈 1 200원 받았다면 물건값은?" 3 000 − 1 200으로 구해요.
  • 중학교 방정식 x + 7 = 16도 똑같이 풀어요.
