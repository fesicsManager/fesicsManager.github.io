사분면 실험실 — 어느 사분면을 지나지 않을까?

기울기와 y절편의 부호를 바꿔 가며 직선이 지나는 사분면을 기록한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 직선이 지나는 사분면은 기울기와 y절편의 부호가 정해요

y = ax + b(a ≠ 0)는 세 사분면을 지나고 한 곳을 지나지 않아요. b의 부호가 y축 어디서 출발하는지, a의 부호가 오른쪽으로 오르는지 내리는지를 정해요. a > 0, b > 0 → 1·2·3, a > 0, b < 0 → 1·3·4, a < 0, b > 0 → 1·2·4, a < 0, b < 0 → 2·3·4. 크기는 상관없어요.

⚙️ 왜 그럴까

  • 외우지 말고: y절편 위치 + 방향으로 그려 보면 바로 보여요.
  • b = 0이면 원점을 지나 두 사분면만(1·3 또는 2·4).
  • 지나지 않는 사분면: a, b 같은 부호면 4(양)/1(음), 다른 부호면 2 또는 3.

🧮 이 실험의 계산 방법

부호 조합별 직선 그리기 → 지나는 사분면 기록, 같은 조합끼리 결과 일치 확인

📌 자주 하는 오해
· "기울기가 가파르면 사분면이 달라진다" → 부호만 중요해요.

🌍 생활 속에서

  • 이익(y)–판매량(x) 그래프에서 초기 비용(b < 0)과 마진(a > 0)의 부호로 그래프 위치를 읽어요.
