근의 공식 실험실 — 공식은 어디서 왔는가

완전제곱으로 고치는 여섯 단계를 하나씩 올려 가며, 근의 공식이 만들어지는 과정을 직접 따라간다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 공식은 완전제곱으로 고친 결과예요

근의 공식은 외우는 주문이 아니라 ax² + bx + c = 0 을 완전제곱으로 고치는 과정을 문자로 한 번 해 둔 것이에요. ② 양변을 a 로 나누고, ③ 상수를 오른쪽으로 옮기고, ④ 양변에 (b/2a)² 을 더하고, ⑤ 왼쪽을 (x + b/2a)² 으로 묶으면 (x + b/2a)² = (b² − 4ac)/4a² 가 되고, ⑥ 제곱근을 구해 x 를 남기면 x = (−b ± √(b² − 4ac)) / 2a 예요. 쓰인 것은 등식의 성질뿐이라 단계마다 해가 그대로예요. 그래서 계수만 넣으면 어떤 이차방정식이든 풀려요. D < 0 이면 ⑤에서 제곱근을 구할 수 없어 실근이 없어요.

⚙️ 왜 그럴까

  • 2x² − 5x + 1 : ② x² − 2.5x + 0.5 = 0 → ③ x² − 2.5x = −0.5 → ④ 양변에 1.5625 → ⑤ (x − 1.25)² = 1.0625 → ⑥ x = (5 ± √17)/4.
  • ④에서 더하는 (b/2a)² 은 ② 에서 나눈 뒤의 계수 b/a 의 절반을 제곱한 것이에요. 나누기를 잊으면 틀려요.
  • 단계마다 해를 넣어 보면 양변이 늘 같아요 — 등식의 성질만 썼기 때문이에요.

🧮 이 실험의 계산 방법

계수를 정하고 단계를 ①→⑥ 으로 올리며 그 단계의 식을 내놓기 → 해를 넣어 양변이 같은지 확인 → 마지막에 공식과 견주기

📌 자주 하는 오해
· "공식은 그냥 외우는 것" → 완전제곱으로 고친 과정의 결과예요. 직접 따라가 보면 보여요.
· "인수분해가 안 되면 근이 없다" → 무리수 근이 있어요. 공식으로 구해요.

🌍 생활 속에서

  • 발사체 착지 시각, 황금비(x² − x − 1 = 0), 대출 이자율 역산에 근의 공식이 쓰여요.
