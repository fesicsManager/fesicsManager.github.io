부등식 해 실험실 — 경계는 같은데 방향은 왜 다를까?

−10부터 10까지 하나씩 대입해 만족하는 수를 찾고, a의 부호와 해의 방향을 대조한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — ax + b > 0의 경계는 x = −b/a로 같지만, 해의 방향은 a의 부호가 정해요

a > 0이면 x > −b/a, a < 0이면 x < −b/a예요. 경계값은 같은데 방향이 반대인 이유는 a로 나눌 때 a가 음수면 부등호가 뒤집히기 때문이에요. a = 0이면 b > 0일 때 모든 수가 해, 아니면 해가 없어요. −10~10을 하나씩 넣어 보면 규칙이 그대로 보여요.

⚙️ 왜 그럴까

  • 2x − 6 > 0 → x > 3. −2x + 6 > 0 → −2x > −6 → x < 3.
  • 그래프로: y = ax + b가 x축 위에 있는 구간. a > 0이면 경계 오른쪽, a < 0이면 왼쪽.
  • a가 음수면 양변에 −1을 곱해 a를 양수로 만든 뒤 푸는 방법도 있어요(이때 부등호 뒤집기).

🧮 이 실험의 계산 방법

x = −10…10 대입해 만족하는 정수 찾기 → a 부호별 해의 방향 기록

📌 자주 하는 오해
· "경계값이 같으면 답도 같다" → 방향까지가 답이에요.
