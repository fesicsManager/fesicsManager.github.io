극값 실험실 — 기울기가 0이면 극값일까?

f′(x) = 0 인 점을 찾아 그 앞뒤 값을 비교하며 극값인지 아닌지 판정한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — f′(a) = 0은 극값의 필요조건일 뿐이에요

극값에서는 접선이 수평(f′ = 0)이지만, f′ = 0이라고 항상 극값은 아니에요. f(x) = x³은 f′(0) = 0인데 기울기가 잠깐 0이 되었다가 다시 같은 방향(증가)으로 올라가 극값이 아니에요. 극값이려면 그 점 앞뒤에서 f′의 부호가 바뀌어야 해요(+ → − 극대, − → + 극소).

⚙️ f(x) = x³ + ax로 확인

  • a < 0: f′ = 3x² + a = 0인 두 점 x = ±√(−a/3)에서 부호가 바뀜 → 극대·극소.
  • a = 0: f′ = 3x² ≥ 0, x = 0에서 0이지만 양쪽 다 양수 → 극값 아님(변곡점).
  • a > 0: f′ > 0 항상 → 극값 없음, 단조 증가.

🧮 이 실험의 계산 방법

f′(x) = 0의 근을 구하고 근의 좌우에서 f′ 부호(또는 f 값 비교) 확인

📌 자주 하는 오해
· "f′ = 0 풀면 극값 끝" → 증감표로 부호 변화를 확인해야 해요. 이계도함수 판정(f″ ≠ 0)도 쓸 수 있어요.

🌍 생활 속에서

  • 이익 최대·비용 최소 문제에서 f′ = 0인 점이 정말 최대인지 확인하지 않으면 잘못된 결정을 해요.
