연립방정식 실험실 — 해는 항상 하나일까?

두 번째 식의 계수를 바꿔 두 직선을 그리고, 해가 1개·없음·무수히 많음이 되는 조건을 찾는다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 해의 개수는 두 직선의 위치 관계: 1개·없음·무수히 많음

2x + y = 4와 ax + by = c에서 x·y 계수의 비가 다르면 두 직선이 한 점에서 만나 해 1개, 계수비는 같은데 상수비가 다르면 평행이라 해 없음, 상수까지 비례하면 같은 직선이라 해가 무수히 많아요. 계수만 보고 그래프를 그리기 전에 알 수 있어요.

⚙️ 왜 그럴까

  • 4x + 2y = 8: 2x + y = 4의 2배 → 같은 직선 → 무수히.
  • 4x + 2y = 9: 기울기 같고 절편 다름 → 평행 → 없음.
  • x − y = 1: 기울기 다름 → 교점 하나.

🧮 이 실험의 계산 방법

a/2 = b/1 인지, = c/4 인지로 판정 → 그래프의 교점 수와 대조

📌 자주 하는 오해
· "해가 없으면 문제가 틀렸다" → 조건이 모순인 것(평행)일 뿐이에요.

🌍 생활 속에서

  • 두 요금제가 같아지는 사용량(교점), 절대 같아지지 않는 경우(평행)가 이 판정이에요.
