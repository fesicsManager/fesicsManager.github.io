이차부등식 실험실 — 해는 두 근 사이일까 바깥일까?

a의 부호와 부등호 방향을 조합해 가며 그래프에서 조건을 만족하는 구간을 기록한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 이차부등식의 해는 그래프가 x축 위/아래에 있는 구간이에요

ax² + bx + c > 0의 해는 y = ax² + bx + c의 그래프가 x축보다 위에 있는 x의 범위예요. a > 0(아래로 볼록)이면 두 근 바깥, a < 0(위로 볼록)이면 두 근 사이가 답이에요. 부등호 방향을 바꾸면 반대가 돼요. 판별식이 0 이하면 해가 모든 실수, 한 점을 뺀 모든 실수, 한 점, 없음 중 하나예요.

⚙️ 네 가지 조합 (D > 0, 근 α < β)

  • a > 0, > 0: x < α 또는 x > β. a > 0, < 0: α < x < β.
  • a < 0, > 0: α < x < β. a < 0, < 0: x < α 또는 x > β.
  • a < 0이면 양변에 −1을 곱해 a > 0으로 바꾸고 부등호를 뒤집어 푸는 것이 안전해요.
  • D < 0, a > 0: 그래프가 항상 x축 위 → > 0의 해는 모든 실수, < 0의 해는 없음.

🧮 이 실험의 계산 방법

근 α, β를 구하고 각 구간에서 함숫값 부호 확인 → 조건을 만족하는 구간 표시

📌 자주 하는 오해
· "> 0이면 무조건 바깥" → a의 부호를 먼저 봐야 해요.
· 두 근이 같은 경우(D = 0)에는 x ≠ α 같은 답이 나와요.

🌍 생활 속에서

  • 이익이 양수가 되는 판매량 범위, 공이 특정 높이보다 위에 있는 시간 구간 계산이 이차부등식이에요.
