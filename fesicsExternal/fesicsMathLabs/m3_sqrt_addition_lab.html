제곱근 덧셈 실험실 — √2 + √3 은 √5 일까?

두 항을 길이로 이어 붙여 실제 합을 재고, 계수끼리 더한 값·근호 안끼리 더한 값과 비교한다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 근호 안이 같을 때만 계수끼리 더해요: 2√3 + 3√3 = 5√3

√3을 하나의 '덩어리'로 보면 2√3 + 3√3은 2a + 3a = 5a와 같은 동류항 계산이에요. 근호 안이 다르면(√2 + √3) 하나로 합쳐지지 않고 그대로 두어야 해요. 근호 안끼리 더하는 것(√2 + √3 = √5?)은 한 번도 맞지 않아요: 1.414 + 1.732 = 3.146 ≠ 2.236. 근호 안을 간단히 하면(√12 = 2√3) 동류항이 드러나기도 해요.

⚙️ 왜 그럴까

  • 길이로: √3 막대 2개 + 3개 = 5개. √2 막대와 √3 막대는 단위가 달라 개수로 못 합쳐요.
  • √8 + √2 = 2√2 + √2 = 3√2 — 먼저 간단히.
  • 곱셈은 근호 안끼리 곱해도 돼요(√2 × √3 = √6).

🧮 이 실험의 계산 방법

두 항 길이 이어 붙여 실측 → 계수 합, 근호 안 합과 비교

📌 자주 하는 오해
· "√a + √b = √(a + b)" → 제곱하면 a + b + 2√(ab)로 2√(ab)만큼 더 커요.

🌍 생활 속에서

  • 정사각형 대각선 여러 개 이어 붙이기(n√2), 벡터 크기 합산에서 단위 맞추기.
