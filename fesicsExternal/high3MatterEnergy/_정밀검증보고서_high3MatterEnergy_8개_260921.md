## 파일별 결과

### 01_reaction_enthalpy_lab_MatterEnergy_Ep08.html — B

- `q = -ΔH·n`, `ΔT = q/(m·c + Ccal)`, `ΔHexp = -q/n`의 부호와 단위 환산은 일관된다.
- NaOH, NH₄NO₃, CaCl₂의 질량→몰수 변환도 정상이다.
- **B-01: 중화 실험의 질량 모델과 UI 설명이 불일치한다.** 화면에서는 `물의 양`을 선택하지만 계산에서는 `W + n·36.46 + n·40`을 용액 질량으로 사용한다. 이는 HCl과 NaOH의 순물질 질량을 더한 근사이며, 실제 수용액 농도·부피·용매 질량이 정의되지 않아 사용자가 선택한 `물의 양`이 무엇을 뜻하는지 불명확하다.
- 권장 수정: 중화 항목에서는 `산·염기 용액의 총질량`을 직접 입력하게 하거나, 예를 들어 `1.0 M HCl/NaOH 용액 각 50 mL`처럼 농도와 부피를 명시해 용액 질량을 계산한다.

### 02_hess_law_lab_MatterEnergy_Ep09.html — 통과

- NaOH 경로는 `−44.5 + (−56.1) = −100.6 kJ/mol`로 직접 경로와 일치한다.
- 탄소 연소 경로는 `D − E = −393.5 − (−283.0) = −110.5 kJ/mol` 관계가 성립한다.
- 반응식·부호·경로 합산 설명과 기록 비교 로직이 일치한다.

### 03_gibbs_energy_lab_MatterEnergy_Ep10.html — B

- `ΔG = ΔH − TΔS`에서 ΔS를 J/(mol·K)→kJ/(mol·K)로 나누는 처리는 정상이다.
- 네 가지 부호 조합에 따른 온도 의존성 분류도 정상이다.
- **B-02: 200–1200 K 전 구간에서 ΔH와 ΔS를 상수로 두는 근사 및 상변화 제한이 표시되지 않는다.** 특히 `얼음이 녹음`, `물이 끓음`은 해당 압력의 상전이 온도 부근에서 의미가 큰 반응인데 전 온도 범위에 같은 표준값을 적용한다. 결과가 엄밀한 실제값처럼 보일 수 있다.
- 권장 수정: 화면에 `ΔH·ΔS를 온도와 무관한 상수로 둔 교육용 근사`를 표시하고, 상전이 예시는 1 atm 평형 온도와의 관계를 함께 안내한다.

### 04_ideal_gas_law_lab_MatterEnergy_Ep01.html — 통과

- 이상 기체식의 L→m³ 변환, 반데르발스 상수의 SI 사용, 압축 인자 `Z = PV/nRT` 계산이 일관된다.
- 모든 입력 조합에서 `V − nb > 0`이며 분모 특이점이 발생하지 않는다.
- 압력 반올림(100 Pa 단위)과 그래프용 kPa 변환도 일관된다.

### 05_intermolecular_force_lab_MatterEnergy_Ep03.html — B

- 1 atm 기준 상태 판정과 녹는점·끓는점 데이터는 대체로 정상이다.
- **B-03: 정상 끓는점보다 높은 온도에서도 클라우지우스–클라페이롱 외삽값을 그대로 `증기압`으로 제시한다.** 예를 들어 1 atm에서 이미 기체인 조건에도 포화 증기압 수치가 나타날 수 있어, 현재 압력과 포화 증기압을 혼동할 가능성이 있다.
- 권장 수정: `포화 증기압(외삽)`으로 명칭을 바꾸고, 정상 끓는점 이상에서는 `1 atm에서는 기체이며 값은 포화 곡선의 외삽`이라는 안내를 표시한다.

### 06_phase_diagram_lab_MatterEnergy_Ep03.html — A

- 삼중점·임계점 자료와 kPa/atm 변환 자체는 일관된다.
- **A-01: 승화 곡선의 표시와 상태 판정이 서로 다르다.** 캔버스는 삼중점 아래에서 `curveP × 0.55`를 승화 곡선으로 그리지만, `state()`는 `curveP` 원값을 경계로 사용한다. 따라서 같은 온도·압력에서 그림이 가리키는 영역과 출력 상태가 달라질 수 있다.
- **A-02: 경계와 삼중점의 공존 상태가 판정되지 않는다.** 삼중점 좌표에서도 현재 조건문은 액체로 반환하며, 고체–액체·액체–기체·고체–기체 경계 위에서도 단일 상만 반환한다.
- 추가 문제: 융해 곡선은 실측/클라페이롱 모델이 아니라 임의의 로그 기울기(`−0.0075`, `0.03`)로 생성되므로 고압에서 정량적 오차가 크다.
- 필수 수정: 승화·증기압·융해 경계를 각각 하나의 공통 함수로 정의해 그리기와 판정에서 같은 값을 사용한다. 경계 허용오차를 두어 `두 상 공존`, 삼중점에서는 `세 상 공존`을 반환한다.

### 07_solution_concentration_lab_MatterEnergy_Ep07.html — C

- 질량 백분율, 몰 농도, 몰랄 농도의 계산식과 단위는 정상이다.
- 밀도를 사용해 `용액 질량/밀도 = 용액 부피`를 구하는 처리도 정상이다.
- **C-01: `입자 몰랄 농도(ip)`를 내부에서 계산하지만 결과 표의 핵심 출력에는 충분히 설명되지 않는다.** 전해질의 i를 이상적 정수로 사용한다는 가정도 화면에 명시하는 편이 좋다.
- 권장 수정: `i×m(이상 완전 해리 가정)`을 결과에 표시하거나 사용하지 않는 내부 필드는 제거한다.

### 08_colligative_property_lab_MatterEnergy_Ep06-07.html — A

- 끓는점 오름 `ΔTb=iKbm`과 어는점 내림 `ΔTf=iKfm`은 현재 이상 용액 모형 안에서 정상이다.
- **A-03: 삼투압 식에 몰랄 농도 m을 그대로 넣었다.** 코드는 `π = i·m·R·T`이지만 삼투압 식은 `π = i·M·R·T`로 몰 농도 M(mol/L)를 사용해야 한다. 현재는 용액 부피/밀도 정보가 없어 정확한 M을 계산할 수 없으며, 고농도·다중 이온 조건에서 오차가 커진다.
- **A-04: 설명 문구에도 `π = imRT`라고 적혀 있어 차원과 개념이 잘못 전달된다.**
- 필수 수정안 1: 삼투압 탭의 입력을 몰 농도 M으로 분리한다.
- 필수 수정안 2: 묽은 수용액에서 `M≈m`을 쓰려면 화면에 근사 조건을 명시하고, 변수 표기 역시 `π≈imRT`로 바꾼다. 권장안은 입력을 M으로 분리하는 것이다.
- 참고: NaCl=2, CaCl₂=3은 완전 해리 이상값이다. 실제 용액에서는 농도에 따라 유효 반트호프 인자가 달라질 수 있음을 안내하면 더 정확하다.

### units.json — 정상

- JSON 문법과 8개 HTML 파일 목록 대응을 확인했다.
- 실제 폴더의 HTML 8개와 검증 대상 수가 일치한다.

## 수정 우선순위

1. `08_colligative_property...`: 삼투압 농도 변수를 몰 농도 M으로 수정.
2. `06_phase_diagram...`: 그리기와 상태 판정에 동일한 경계 함수 사용, 공존/삼중점 판정 추가.
3. `01_reaction_enthalpy...`: 중화 용액 질량·농도 조건 명시.
4. `03_gibbs_energy...`, `05_intermolecular_force...`: 근사·외삽 조건 표시.
5. `07_solution_concentration...`: i 가정과 입자 몰랄 농도 표시 보완.

## 결론

8개 파일 모두 기본 구문과 주요 UI 흐름은 정상이나, `06`과 `08`은 학생에게 잘못된 상태 또는 계산값을 제시할 수 있어 배포 전 필수 수정이 필요하다. 나머지 파일은 계산식 자체가 대체로 일관되며, 모델의 가정과 입력 정의를 보강하면 교육용으로 사용할 수 있다.
