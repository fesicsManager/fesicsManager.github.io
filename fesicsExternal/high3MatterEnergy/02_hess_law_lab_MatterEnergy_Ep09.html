헤스 법칙

이번에는 같은 처음과 끝 상태를 서로 다른 경로로 가면서 엔탈피 변화를 재어, 경로가 달라도 합이 같다는 것을 확인합니다.

📖 과학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 헤스 법칙: 경로가 달라도 총 반응열은 같다

엔탈피는 상태 함수라 처음과 나중 상태만 정하면 값이 정해지고, 중간에 어떤 경로를 거쳤는지는 상관없어요. 그래서 한 반응을 여러 단계로 나누면 각 단계 반응열의 합 = 전체 반응열이에요(헤스, 1840). 이를 이용하면 직접 재기 어려운 반응(탄소의 불완전 연소처럼 CO와 CO₂가 함께 생기는 반응)의 ΔH를 잴 수 있는 반응들을 더하고 빼서 구할 수 있어요.

⚙️ 두 경로 확인

  • NaOH 경로: 고체 NaOH → 수용액(−44.5) + 수용액 중화(−56.1) = −100.6 kJ/mol. 고체를 산에 바로 녹인 값(−100.6)과 같아요.
  • 탄소 연소: C + O₂ → CO₂ (−393.5), CO + ½O₂ → CO₂ (−283.0). 구하려는 C + ½O₂ → CO = (D) − (E) = −393.5 − (−283.0) = −110.5 kJ/mol.
  • 식을 거꾸로 쓰면 ΔH 부호가 바뀌고, 계수를 n배 하면 ΔH도 n배예요.
  • 에너지 준위 도식: 각 단계 화살표를 이어 붙이면 출발점과 도착점의 높이 차 = 전체 ΔH.

🧮 이 실험의 계산 방법

ΔH_전체 = Σ ΔH_단계 (식의 덧셈·뺄셈·배수에 맞춰 부호·배율 조정), 표준 반응 엔탈피(25 ℃) 자료값 사용

📌 실험 모형과 실제의 차이
· 여기서는 표준 자료값이라 정확히 맞지만, 실제 열량계 실험에서는 각 단계 측정에 열 손실·농도 차이 오차가 있어 합이 1~5 % 어긋나요. 그 차이가 헤스 법칙의 위반이 아니라 실험 오차임을 확인하는 것이 실제 실험의 목표예요.
· 모든 단계가 같은 온도·압력·농도 조건이어야 더할 수 있어요. 조건이 다르면 값을 보정해야 해요.

🌍 생활 속에서

  • 표준 생성 엔탈피 표(ΔH_f°)는 헤스 법칙 덕분에 어떤 반응의 ΔH든 '생성물 − 반응물'로 계산하게 해 줘요.
  • 연료의 발열량, 폭약의 에너지, 생체 대사 에너지 계산이 모두 헤스 법칙에 기대요.

그림은 에너지 준위 도식입니다. 아래로 내려가는 화살표가 발열, 위로 올라가는 화살표가 흡열입니다.
