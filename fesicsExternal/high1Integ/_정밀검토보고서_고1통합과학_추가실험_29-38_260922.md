## 29. 표준 화석과 지층 연대

**판정: 보완 권장**

### 확인 결과

- 여러 화석의 생존 연대가 겹치는 구간을 `가장 늦은 시작 연대 ~ 가장 이른 끝 연대`로 구하는 계산 논리는 맞습니다.
- Ma에서 오래된 쪽 숫자가 더 크므로 구간 폭을 `시작 − 끝`으로 구한 것도 맞습니다.
- 화석 조합이 많고 생존 기간이 짧을수록 지층 연대를 더 좁게 추정한다는 핵심 개념도 적절합니다.

### 보완 사항

- “같은 표준 화석이 나오면 같은 시기에 쌓였다”는 문장은 너무 강합니다. 실제로는 화석의 생존 기간 안에서 **비슷한 시기에 형성되었을 가능성이 크다**고 해석해야 하며, 재퇴적 가능성도 있습니다.
- 제시된 화석 연대 범위가 교육용 단순 자료라면 화면에 “학습용 모형 자료”라고 명시하는 편이 안전합니다.

### 권장 문구

> 같은 표준 화석이 발견된 지층은 그 화석이 살았던 기간과 겹치는 시기에 형성되었을 가능성이 큽니다. 다만 화석이 다른 곳에서 다시 퇴적된 경우 등은 별도로 살펴야 합니다.

### 수정안

## 31. 작물 다양성과 병해

**판정: 수정 필요**

### 확인 결과

- 같은 품종끼리 이웃할 확률이 낮아질수록 병의 연속 전파가 어려워진다는 방향은 적절합니다.
- 감염되지 않은 칸의 비율을 단순한 ‘남은 수확량’ 지표로 쓰는 것은 학습용 모형으로 사용할 수 있습니다.

### 수정 사항

- 품종 1을 “가장 널리 심는 품종”이라고 설명하지만, 실제 격자에서는 선택한 모든 품종이 거의 같은 확률로 배치됩니다.
- 품종 수가 늘 때마다 새 품종에 35% 확률로 저항성을 주므로, 결과가 **공간적 다양성 효과**인지 **저항성 품종 포함 효과**인지 분리되지 않습니다.
- “품종을 1→2로 늘릴 때 효과가 가장 크다”는 검증 문구는 난수 결과가 그렇게 나오지 않아도 항상 표시됩니다.

### 수정안

- 품종 1의 비중을 실제로 높이거나 “병원체가 잘 감염하는 기준 품종”으로 표현을 바꿉니다.
- 다양성만 비교하려면 모든 품종의 저항성을 동일하게 고정합니다. 저항성 효과를 함께 다룰 경우에는 별도 변수로 분리합니다.
- 검증 결론은 사용자가 기록한 평균값을 계산한 뒤 실제 관측 결과에 따라 생성하도록 바꿉니다.

## 32. 금속 반응성과 산화·환원

**판정: 긴급 수정**

### 확인 결과

- Mg > Zn > Fe > Cu > Ag의 상대적 반응성 순서와, 더 반응성이 큰 금속이 이온을 환원시키는 판단은 적절합니다.
- 전자 몰수를 이용해 석출 금속의 질량을 구하는 내부 계산도 원자가를 반영하고 있습니다.

### 긴급 수정 사항

- 화면 반응식은 계수를 생략해 원자·전하가 보존되지 않습니다. 예를 들어 현재 방식은 `Mg + Ag⁺ → Mg²⁺ + Ag`처럼 보이지만 올바른 식은 다음과 같습니다.

  `Mg + 2Ag⁺ → Mg²⁺ + 2Ag`

- 계산은 전자 수를 반영하면서 표시 반응식은 반영하지 않아, 학생이 계산과 반응식을 서로 다른 규칙으로 받아들일 수 있습니다.
- 금속 조각이 전부 반응한다고 계산하지만 용액 속 금속 이온의 양·농도가 없습니다. 따라서 “금속 이온이 충분히 많이 들어 있다”는 가정이 반드시 필요합니다.

### 수정안

- 각 금속과 이온의 산화수를 이용해 반응식 계수를 자동으로 맞춥니다.
- 입력부 또는 원리 설명에 “용액 속 금속 이온은 금속 조각을 모두 반응시키기에 충분하다”는 조건을 추가합니다.

## 33. 철 제련과 환원

**판정: 긴급 수정**

### 확인 결과

- Fe₂O₃, Fe₃O₄, FeO(OH)의 몰 질량과 철 질량비 계산은 대체로 맞습니다.
- 화면에 제시한 탄소 직접 환원식은 생성물을 CO로 둘 때 원자 수가 맞습니다.

### 긴급 수정 사항

- 반응식은 CO를 생성하지만 계산 결과는 제거된 산소 1몰마다 44 g을 곱해 “배출 이산화탄소”로 표시합니다.
- 이 계산은 환원 때 생긴 CO가 이후 공기 중 산소와 반응해 전부 CO₂가 된다는 **최종 CO₂ 환산량**으로는 해석할 수 있지만, 현재 화면에는 그 과정과 가정이 없습니다.
- 실제 고로에서는 CO가 주요 환원제라는 점도 현재의 ‘탄소가 광석을 직접 환원’하는 단순 모형과 구분할 필요가 있습니다.

### 수정안

- 현재 계산을 유지한다면 결과명을 “최종 CO₂ 환산량”으로 바꾸고 `CO + 1/2 O₂ → CO₂` 과정을 설명합니다.
- 또는 생성물을 CO로 유지해 CO 질량을 계산합니다. 어느 쪽이든 반응식, 탄소 소비량, 배출물 표시를 한 체계로 통일해야 합니다.

## 34. 표면적·부피와 열 손실

**판정: 보완 권장**

### 확인 결과

- 구의 `S/V = 3/r`, 밀도를 1000 kg/m³로 둔 질량, 대류 열전달식 `Q = hA(T몸−T공기)` 계산이 일관됩니다.
- 외부 온도 40 °C에서 Q가 음수가 되고 “열이 들어온다”고 표시하는 부호 처리도 적절합니다.
- 귀 면적을 추가 방열 면적으로 포함한 단순화도 교육용 비교 모형으로 이해할 수 있습니다.

### 보완 사항

- 알렌·베르그만 규칙은 모든 생물에 기계적으로 적용되는 법칙이 아니라 생태·계통·행동·털·혈류 등 여러 요인의 영향을 받는 경향입니다.
- “큰 귀는 더운 곳에서 밤에 유리”라는 표현은 낮에도 혈류 조절과 주변 조건에 따라 방열에 기여할 수 있으므로, 굳이 밤으로 한정하지 않는 편이 낫습니다.

### 권장 문구

> 이 모형은 몸을 구로 보고 털, 혈류, 증발, 행동을 제외한 단순 비교입니다. 알렌·베르그만 규칙은 여러 생물에서 관찰되는 경향이며 예외가 있습니다.

## 35. 무역풍과 엘니뇨

**판정: 수정 필요**

### 확인 결과

- 무역풍 약화 → 동태평양 수온 상승 → 용승 약화 → 생산성·어획 감소라는 인과 흐름은 적절합니다.
- 바다가 즉시 변하지 않고 수개월에 걸쳐 평형에 접근하도록 만든 지수형 반응도 교육용 모형으로 이해할 수 있습니다.

### 수정 사항

- 단일 시점의 동태평양 수온 편차가 ±0.5 °C를 넘으면 바로 엘니뇨·라니냐로 판정합니다. 그러나 ONI는 Niño 3.4 해역의 3개월 이동평균을 사용하며, 공식적인 사건 판정에는 지속 조건도 필요합니다.
- 무역풍이 100%보다 강할 때 수치로 계산한 구름 중심은 140 °E보다 서쪽으로 이동하지만, 그림은 140 °E에 고정됩니다. 결과 수치와 시각화가 서로 다릅니다.
- 어획량과 강수 위치는 매우 단순한 경험식이므로 실제 예측값처럼 보이지 않게 해야 합니다.

### 수정안

- “ONI” 대신 “단순화한 동태평양 수온 편차 지수”라고 부르거나 3개월 평균·지속 조건을 구현합니다.
- `rainLon` 계산과 그림의 위치 제한을 같은 식으로 통일합니다.
- 어획량·강수 위치에 “개념 비교용 가상 지표” 표시를 추가합니다.

## 36. 핵융합·질량 결손과 별의 수명

**판정: 긴급 수정**

### 확인 결과

- `L ∝ M^3.5`, `질량 결손 = L/c²`, 수소 소모량을 질량 결손/0.007로 구하는 계산은 내부적으로 일관됩니다.
- 태양 질량의 10%를 쓸 수 있다고 둔 수명이 약 100억 년으로 나오는 것도 적절합니다.

### 긴급 수정 사항

- 초당 질량 결손의 톤 표시가 잘못되었습니다. 태양은 약 `4.28×10⁹ kg/s = 4.28×10⁶ t/s = 428만 t/s`인데, 현재 코드는 약 `4만 t/s`로 표시합니다. 약 100배 작은 값입니다.
- 원인은 톤으로 바꾼 뒤 다시 10⁶으로 나누고 “만 t/s”를 붙인 것입니다. ‘만 톤’ 단위라면 10⁴로 나눠야 합니다.
- “1 g이 서울 시민 하루 전기 정도”라는 비교는 기준 연도·범위·전력 사용량이 없고 값도 불안정하므로 삭제하거나 출처를 붙이는 편이 좋습니다.
- `L ∝ M^3.5`는 전 질량 범위에 정확히 적용되는 법칙이 아니라 주계열성의 근사 관계라는 안내가 필요합니다.

### 코드 수정 방향

```js
// dmT는 t/s
['초당 질량 결손(톤)', Math.round(r.dmT / 1e4).toLocaleString() + ' 만 t/s']
```

## 37. 발전소 효율

**판정: 수정 필요**

### 확인 결과

- 카르노 한계 `1 − Tc/Th`를 이용해 실제 효율과 비교하는 구조는 적절합니다.
- 설비용량, 이용률, 시간, 생애주기 배출계수를 이용한 연간 발전량·CO₂ 계산도 단위상 일관됩니다.

### 수정 사항

- 도입부가 석탄·천연가스·원자력·지열 발전을 모두 “물을 끓여 증기로 터빈을 돌린다”고 묶습니다.
- 천연가스 복합화력은 연소가스로 가스터빈을 먼저 돌리고, 배열로 증기를 만들어 증기터빈을 추가로 돌리는 방식입니다.
- 지열도 증기 직접 이용, 플래시, 바이너리 방식 등 구성이 다양합니다.

### 수정안

> 여러 발전 방식은 열을 이용해 터빈을 돌리지만, 에너지 전달 과정은 서로 다릅니다. 석탄·원자력은 주로 증기터빈을, 천연가스 복합화력은 가스터빈과 증기터빈을 함께 사용합니다.

- 배출계수는 지역·기술·연료에 따라 달라지는 대표값임을 명시합니다.

## 38. AI 학습 자료 편향

**판정: 수정 필요**

### 확인 결과

- 밝기와 귀 모양이라는 두 특성으로 간단한 분류기를 학습시키고 집단별 정확도를 비교하는 구성은 교육적으로 좋습니다.
- 전체 정확도만으로는 특정 집단의 낮은 성능을 놓칠 수 있다는 핵심 메시지도 적절합니다.

### 수정 사항

- 실행할 때마다 시험 자료까지 새 난수로 만듭니다. 서로 다른 학습 조건을 비교할 때 시험 문제 자체가 달라져 결과 차이가 학습 조건 때문인지 난수 때문인지 구분하기 어렵습니다.
- 귀 특성이 고양이와 개를 거의 완벽하게 나누도록 생성되어 있으므로, 충분히 학습하면 편향된 자료에서도 귀 특성을 이용해 높은 정확도에 도달할 수 있습니다.
- 따라서 “편향된 자료에서는 아무리 늘려도 공정한 자료만큼 오르지 않는다”는 문구는 현재 모형이 보장하지 않습니다.
- “자료 수를 늘리면 정확도가 오른다” 역시 난수·학습률·반복 횟수에 따라 항상 성립하지 않습니다.

### 수정안

- 비교 실험 전체에서 동일한 고정 시험 세트와 난수 시드를 사용합니다.
- 검증 문구를 실제 기록의 평균과 추세를 계산해 조건부로 생성합니다.
- 편향 효과를 확실히 보여 주려면 귀 특성도 일부 겹치게 만들어 밝기라는 가짜 상관관계가 성능에 실제 영향을 주도록 설계합니다.
- 결론은 “자료 수만 늘려서는 대표성 부족이 자동으로 해결되지 않을 수 있다”처럼 확률적·조건부 표현으로 바꿉니다.

## 공통 품질 점검

- 29~38번 HTML의 JavaScript 문법 검사를 통과했습니다.
- 중복된 HTML `id`는 발견되지 않았습니다.
- 다만 문법 통과는 과학적 타당성이나 실행 결과의 정확성을 보장하지 않으므로 위 항목은 별도 수정이 필요합니다.

## 최종 권고

배포 전 최소 수정 범위는 **32, 33, 36번의 계산·표시 오류**와 **30, 31, 35, 37, 38번의 단정적 또는 부정확한 설명**입니다. 29번과 34번은 핵심 계산을 유지하되 모형의 한계와 예외를 한두 문장으로 밝혀 주면 수업 자료로 쓰기 더 안전합니다.
