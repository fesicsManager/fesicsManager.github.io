## 공통 기능 오류 — 10개 파일 모두 해당

### [중요] 같은 조건을 반복 기록하면 회귀분석이 `NaN`이 될 수 있음

- 위치: 공통 함수 `linregress(pts)`
- 원인: 동일한 슬라이더 값만 4회 이상 기록하면 `n*sxx-sx*sx = 0`이 되어 기울기 계산에서 0으로 나눈다.
- 증상: 데이터 확인 탭의 추세선 또는 예측값이 `NaN`으로 표시되거나 그래프가 정상적으로 그려지지 않는다.
- 재현: 슬라이더를 움직이지 않고 같은 값에서 측정·기록을 4회 반복한 뒤 `데이터 확인` 탭을 연다.
- 수정안:
  1. 같은 x값의 중복 기록을 막고 “다른 조건으로 측정하세요” 안내를 표시하거나,
  2. 서로 다른 x값이 2개 이상인지 확인한 뒤 회귀분석을 실행하고,
  3. 분모가 0이면 회귀 대신 “서로 다른 조건이 필요합니다”를 표시한다.

권장 방어 코드:

```js
const denom = n * sxx - sx * sx;
if (Math.abs(denom) < 1e-12) return null;
```

`renderVerify()`에서도 `null`을 확인해 분석을 중단하고 안내문을 보여야 한다.

- 계산: `반응 후 질량 = 반응 전 질량 + 측정 오차(±0.02 g)`로 모형 설명과 일치.
- 축: 0~200 g으로 슬라이더 범위를 수용.
- 정답: 밀폐계에서 질량 보존 설명과 일치.
- 참고: 오차가 교육용 임의 난수임을 화면에서 더 분명히 표시하면 좋지만 오류는 아니다.

### 02_open_container_lab.html — 정상

- 반응식 `CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂` 균형 정상.
- 계산 `CO₂ 질량 = CaCO₃ × 44/100` 정상(염산 충분, 완전 반응 가정 명시).
- 예측 허용범위와 그래프 축도 계산 범위를 수용.

### 03_iron_rust_lab.html — 표현 수정 권장

- 교육용 직선 모형 `0.15 g/일`임을 명시해 과학적 오해를 줄인 점은 적절함.
- 맞춤법 오류: `바닷가 자동차가 빨리 녹슮` → `바닷가 자동차가 빨리 녹슴` 또는 `바닷가에서는 자동차가 빨리 녹슨다`.
- 녹을 `Fe₂O₃·nH₂O`로 단순화했지만 교육용 설명으로 허용 가능하며 실제 녹이 혼합물임을 덧붙이면 더 정확함.

### 04_definite_proportions_lab.html — 정상

- 중학교 근사 원자량 Cu=64, O=16을 사용한 `Cu:O = 4:1`, `CuO = Cu×1.25` 계산 정상.
- `Cu₂O`가 생길 수 있다는 예외도 명시되어 있음.
- 표의 계산 `x/(y-x)`는 구리:산소 질량비를 올바르게 구함.

### 05_limiting_reactant_lab.html — 정상(공통 회귀 오류 제외)

- 산소 4 g, 구리:산소 4:1 가정에서 구리 최대 반응량 16 g, CuO 최대 20 g 계산 정상.
- `min(16, 구리 질량)×1.25` 모델 정상.
- 미반응 구리 계산도 모델과 일치.

### 06_water_electrolysis_lab.html — 표현 수정 권장

- 반응식 `2H₂O → 2H₂ + O₂`, 동일 온도·압력에서 부피비 2:1, 질량비 1:8은 정상.
- 수정 권장 문장: `이것이 일정 성분비 법칙이 기체 부피로 나타난 모습`은 엄밀하지 않다. 일정 성분비 법칙은 화합물의 **질량 조성**에 관한 법칙이고, 기체 부피비 2:1은 반응식 계수와 아보가드로 법칙으로 설명하는 편이 정확하다.
- 권장 문장: `반응식의 계수비와 아보가드로 법칙에 따라 같은 온도·압력에서 수소와 산소의 부피비가 2:1이 된다.`

### 07_exothermic_lab.html — 표현 수정 권장

- `4Fe + 3O₂ → 2Fe₂O₃`와 발열 반응 설명은 정상.
- `1 g당 0.6 ℃`가 교육용 모형값임을 반복 명시해 적절함.
- 수정 권장: 손난로의 활성탄 역할을 `산소 저장`으로 단정하면 부정확할 수 있다. 활성탄은 산소를 흡착하고 열·수분 분포와 반응 진행을 돕는 보조재라는 표현이 안전하다.
- 권장 문장: `활성탄은 산소를 흡착하고 열과 수분이 고르게 퍼지도록 도와 반응을 원활하게 한다.`

### 08_endothermic_lab.html — 정상

- `25.7 kJ/mol ÷ 80 g/mol ≈ 321 J/g` 정상.
- 물 200 g만 고려한 `ΔT ≈ −321/(200×4.18) = −0.384 ℃/g` 정상.
- 용액·비커 열용량, 주변 열 유입, 용해도 한계를 명시해 교육용 모형의 한계를 잘 설명함.

### 09_combustion_energy_lab.html — 즉시 수정 권장

- JavaScript 계산은 정상: `ΔT = 열량(kJ)×1000/(물 질량×비열)`.
- 화면의 계산식은 단위 환산이 빠져 있음:
  - 현재: `ΔT = 열량 ÷ (10 000 g × 4.18 J/g·℃)`
  - 수정: `ΔT(℃) = 열량(kJ) × 1000 ÷ (10 000 g × 4.18 J/g·℃)`
- 현재 문장 그대로 계산하면 1 g 연료에서 0.00103 ℃가 되어, 바로 앞의 “약 1.03 ℃ 상승”과 1000배 모순된다.
- `열량(kJ)=43×연료(g)` 계산과 그래프 모델 자체는 정상.

### 10_reaction_rules_lab.html — 정상

- `Fe₂O₃`: 철 112, 산소 48, 생성물 160 → 철:산소=7:3, 생성물/철=160/112≈1.43 계산 정상.
- 질량비 하나만으로 물질을 확정할 수 없다는 제한 설명도 적절함.
- 그래프·예측식과 화면 설명 일치.
