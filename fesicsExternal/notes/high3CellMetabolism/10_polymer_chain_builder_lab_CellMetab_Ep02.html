핵산과 단백질 — 단위체의 순서가 정보다

실험에서 DNA(이중 가닥)·RNA·단백질을 고르고 단위체 수 n을 2~40개로 바꿔 사슬을 이으며 결합 수·빠져나간 물 분자 수·서열 가짓수·분자량을 기록했습니다. 단백질 10개는 결합 9개에 서열 약 10¹³가지, 20개는 약 10²⁶가지였고, 같은 길이의 핵산은 10⁶가지에 그쳤습니다. 탈수 축합, 핵산과 단백질의 구조, 단위체 종류 수가 만드는 다양성을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 중합체 종류(DNA 이중 가닥·RNA·단백질)를 고르고 단위체 수 n(2~40개)과 GC 비율(DNA만)을 정한 뒤 사슬 잇기를 누르면 결합 수·물 분자 수·log₁₀(가짓수)·분자량이 자동으로 기록됩니다. 세 종류를 여러 n으로 4개 이상 기록하면 데이터 검증 탭에서 n과 log₁₀(가짓수)의 기울기를 log₁₀4, log₁₀20과 비교합니다.

결합이 하나 생길 때마다 물이 한 분자 빠져나가므로 결합 수 = 물 분자 수 = n − 1(한 가닥)이고, DNA는 두 가닥이라 2(n − 1)입니다. n이 2배가 되면 log₁₀(가짓수)도 2배, 즉 가짓수는 제곱이 됩니다. 단위체가 20종인 단백질은 n 하나당 log₁₀20 ≈ 1.30씩, 4종인 핵산은 log₁₀4 ≈ 0.60씩 늘어 단백질이 훨씬 다양한 구조를 만들 수 있습니다.

개념 정리

1. 단위체의 "순서"가 정보다

  • 핵산: 뉴클레오타이드(인산 + 5탄당 + 염기)가 인산 다이에스터 결합으로 이어집니다. DNA는 두 가닥이 A–T(수소 결합 2개), G–C(3개)로 상보적으로 결합한 이중 나선이에요.
  • 단백질: 아미노산 20종이 펩타이드 결합으로 이어진 폴리펩타이드가 접혀 입체 구조를 이룹니다. 구조가 곧 기능(효소·항체·수송)을 정합니다.

결합 수 = 물 분자 수 = n − 1 (한 가닥), 서열 가짓수 = 4ⁿ (핵산), 20ⁿ (단백질) → log₁₀(가짓수) = n × log₁₀4 ≈ 0.602n

2. 실험 모형과 실제의 차이

· 실제 세포에서는 효소(DNA 중합 효소, 리보솜)가 ATP 등 에너지를 써서 결합을 만듭니다.

· 모든 서열이 실제 기능을 하는 것은 아니며, 단백질은 올바르게 접혀야 기능합니다.

결합 수 = 물 분자 수 = n − 1 (한 가닥)  ·  서열 가짓수 = 4ⁿ (핵산), 20ⁿ (단백질)  ·  log₁₀(가짓수) = n × log₁₀(단위체 종류 수)

평균 분자량: DNA 염기쌍 약 650, RNA 뉴클레오타이드 약 330, 아미노산 약 110 g/mol · 수소 결합 A–T 2개, G–C 3개

예제

아미노산 300개로 이루어진 단백질 한 가닥을 만들 때 생기는 펩타이드 결합 수와, 이 단백질을 암호화하는 mRNA의 코돈 수(종결 코돈 포함)는?

펩타이드 결합 = 300 − 1 = 299개(물 299분자). 아미노산 하나에 코돈 하나, 끝에 종결 코돈 하나가 더 붙으므로 300 + 1 = 301개(염기 903개). 결합 299개, 코돈 301개

실험에서 DNA 20염기쌍, GC 비율 50 %로 사슬을 이었다. 염기쌍 사이의 수소 결합 수와 대략적인 분자량은?

수소 결합 ≈ n × (2 + GC 비율) = 20 × 2.5 = 50개(G–C 10쌍 × 3 + A–T 10쌍 × 2). 분자량 ≈ 20 × 650 = 13,000 g/mol. 수소 결합 약 50개, 분자량 약 13,000 g/mol
