고등 공통국어 ③ · 웹툰 3화 「좋은 문장을 모으면 좋은 글인가」

통일성과 응집성 — 문장의 가치는 놓인 자리에서 정해진다

‘학교 앞 횡단보도 신호 시간을 늘리자’는 건의문의 문장은 하나도 고치지 않고 배치와 연결만 바꾼 네 판을 연구원 20명에게 읽혀, 요청을 정확히 요약할 사람 수를 예측해 실제와 비교했습니다. 흐름대로 이어 쓴 가 판은 18명이었지만 순서만 섞은 나 판은 8명, 연결 표현을 지운 다 판은 12명, 무관한 문장 하나를 넣은 라 판은 13명이었습니다. 통일성·응집성·전개 흐름과 고쳐 쓰기의 순서를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 건의문 판(가 흐름대로 · 나 순서 뒤섞음 · 다 연결 표현 지움 · 라 무관한 문장 추가)을 고르고, 요청을 정확히 요약할 사람 수(20명 중)를 예측한 뒤 이 판을 읽히기를 누르면 문장 역할 칩의 배치, 연결 표현 수, 무관 문장 수, 제자리 문장 수, 요약 정확 수와 평균 읽기 시간이 나옵니다. 기록이 4개 이상 쌓이면 결과 비교 탭에서 판별 요약 수와 나의 예측을 볼 수 있어요. (요약 수와 읽기 시간은 대본 속 가상 조사입니다)

표 1. 건의문 판에 따른 요약 정확 수와 읽기 시간 (실험 예시)
판연결 표현무관 문장요약 정확읽기 시간나의 예측
가5개0개18/20약 50초18명
나5개0개8/20약 80초15명
다0개0개12/20약 65초10명
라5개1개13/20약 60초17명

네 판의 문장은 모두 같았습니다. 그런데 순서만 섞은 나 판(제자리 문장 0개)은 요약 정확이 18명에서 8명으로 줄고 읽기 시간은 약 50초에서 약 80초로 늘었어요. 연결 표현 5개를 지운 다 판은 독자가 문장 사이의 관계를 스스로 추측해야 해서 12명, 급식 문장 하나가 끼어든 라 판은 13명이었습니다. 글이 하나의 견해로 읽히게 만드는 것은 문장 하나하나의 질보다 문장 사이의 관계 — 통일성·응집성·전개 흐름입니다.

개념 정리

1. 벽돌·설계도·시멘트

  • 통일성: 모든 문장이 하나의 중심 생각을 향한다. 주제와 무관한 문장은 정보가 아니라 소음이에요.
  • 응집성: 문장과 문단이 순서·연결 표현·지시어로 단단히 이어진다. ‘하지만’은 방향이 꺾인다는 신호, ‘이처럼’은 앞을 묶는다는 신호예요.
  • 전개 흐름: 견해를 밝히는 글은 문제 → 원인 → 해결 방안 → 예상 반론과 답 → 다시 요청의 흐름이 독자가 따라갈 길이 됩니다.

2. 고쳐 쓰기의 순서 — 큰 것부터

① 중심 생각을 한 문장으로 써 보고 모든 문단이 그것을 돕는지 확인 → ② 문단 순서가 독자가 따라갈 길인지 확인 → ③ 문장 다듬기는 맨 마지막. 문장부터 고치면 문단을 통째로 뺄 때 고친 것이 다 날아가요.

사회적 쟁점을 다루는 글이라면 반론을 다루는 문단을 꼭 넣으세요. 독자는 ‘반대편도 생각했구나’ 하고 주장을 더 믿게 됩니다.

3. 실험 모형과 실제의 차이

· 요약 수와 읽기 시간은 대본 속 제로 랩의 가상 조사값이고, 건의문 문장은 실험용으로 만든 예시입니다.

· 연결 표현 수, 무관 문장 수, 제자리 문장 수는 각 판의 문장 배치에서 실제로 센 값이에요.

통일성(하나의 중심 생각) + 응집성(순서·연결 표현·지시어) + 전개 흐름(문제→원인→방안→반론과 답→요청) → 하나의 견해로 읽히는 글
뭉치

“문장마다 하나하나 다 공들였어. 좋은 문장 여섯 개면 좋은 글 여섯 배지!”

닥터 이안

“잘 썼으면 급식 건의문에 쓰면 된다. 문장의 가치는 놓인 자리에서 정해진다.”

웹툰 3화 #4 · 네 판 독자 실험

예제

가 판에 급식 문장 하나를 넣은 라 판에서 요청을 정확히 요약한 사람은 몇 명 줄었고, 어떤 성질이 깨졌나?

가 판 18명 − 라 판 13명 = 5명 줄었습니다. 주제와 무관한 문장이 중심 생각에서 벗어나 소음이 되었어요. 5명 감소 — 통일성

다 판은 가 판과 같은 순서에서 연결 표현만 지웠다. 화면에 나오는 연결 표현 수와 요약 정확 수, 읽기 시간을 가 판과 비교하라.

연결 표현은 5개 → 0개, 요약 정확은 18명 → 12명(6명 감소), 읽기 시간은 약 50초 → 약 65초(약 15초 증가)입니다. 독자가 문장 사이의 관계를 스스로 추측해야 했어요. 응집성이 약해져 6명 감소·약 15초 증가
