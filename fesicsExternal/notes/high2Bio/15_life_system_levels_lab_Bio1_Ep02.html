생명 시스템의 구성 단계 — 모일수록 새로운 기능이 생긴다

실험에서 고라니와 해바라기의 여러 부분(세포부터 숲·밭 전체까지)을 골라 어느 구성 단계인지 먼저 예측하고, 정답 단계와 대략적인 크기, 그 단계의 특징을 확인했습니다. 같은 칸에 있어도 심장은 기관, 표피 조직계는 조직계였고, 순환계는 기관계, 잎은 기관이었습니다. 동물과 식물의 구성 단계 차이와 개체군·군집·생태계의 구분 기준을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 생물(동물 고라니 · 식물 해바라기), 항목(8가지), 나의 예측 단계를 고르고 단계 확인하기를 누르면 사다리에 정답 단계·대략 크기·그 단계의 특징이 표시됩니다. 결과는 자동으로 기록되며, 4개 이상 기록하면 데이터 검증 탭에서 단계별 정답률과 동물·식물 비교가 나옵니다.

동물은 기관 위에 기관계가 있고, 식물은 조직과 기관 사이에 조직계가 있어 같은 칸이어도 단계가 다릅니다. 개체 위에서는 종이 하나인가 여럿인가로 개체군과 군집을, 비생물적 요인을 포함하는가로 군집과 생태계를 가릅니다.

개념 정리

1. 단계가 올라갈수록 새로운 성질이 생긴다

동물: 세포 → 조직 → 기관 → 기관계 → 개체. 식물: 세포 → 조직 → 조직계 → 기관 → 개체. 개체 위로는 개체군(같은 종의 무리) → 군집(여러 종의 개체군) → 생태계(군집 + 빛·물·흙 같은 비생물적 요인)입니다.

  • 근육 세포 하나는 수축만 하지만, 심장(기관)은 피를 밀어내고 순환계(기관계)는 온몸에 물질을 나릅니다.
  • 식물의 조직계는 표피 조직계·관다발 조직계·기본 조직계 세 가지이고, 여러 조직이 모여 이루어집니다.
  • 개체군과 군집을 가르는 기준은 종이 하나인가 여럿인가, 군집과 생태계를 가르는 기준은 비생물적 요인을 포함하는가입니다.

2. 실험 모형과 실제의 차이

· 크기는 대표값이며 생물·지역에 따라 몇 배씩 다릅니다.

· 실제 생태계의 경계는 뚜렷하지 않아, 연구 목적에 따라 범위를 정합니다.

동물: 세포 → 조직 → 기관 → 기관계 → 개체  ·  식물: 세포 → 조직 → 조직계 → 기관 → 개체  ·  개체 → 개체군(한 종) → 군집(여러 종) → 생태계(군집 + 비생물적 요인)

식물의 조직계: 표피 조직계 · 관다발 조직계 · 기본 조직계 · 크기는 자릿수만 맞춘 대략값

예제

실험에서 ‘심장 · 표피 조직계’는 같은 칸에 있다. 두 항목의 단계가 다른 까닭은?

심장은 여러 조직(근육·결합·신경 조직)이 모여 피를 밀어내는 특정 기능을 하는 기관입니다. 표피 조직계는 식물에서 여러 조직이 모인 기능 단위로, 조직과 기관 사이의 조직계입니다. 동물에는 조직계가 없고 식물에는 기관계가 없어 같은 칸이어도 단계가 어긋납니다.

연못에서 ㉠ 붕어 전체, ㉡ 붕어·수초·플랑크톤 전체, ㉢ ㉡ + 물·햇빛·바닥 진흙은 각각 어느 단계인가?

㉠ 한 종의 무리 → 개체군, ㉡ 여러 종의 개체군 → 군집, ㉢ 군집 + 비생물적 요인 → 생태계.
