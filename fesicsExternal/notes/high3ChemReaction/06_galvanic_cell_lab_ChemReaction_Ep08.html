화학 전지와 표준 환원 전위 — E°_전지 = E°_환원 − E°_산화

실험에서 Zn·Cu·Ag·H₂ 등 두 반쪽 전지를 골라 표준 전지 전위를 구하고 이온 농도(0.01~1.0 M)를 바꿔 네른스트 식으로 전압을 계산했습니다. Zn/Cu는 1.10 V, Zn/Ag는 1.56 V(전자 수를 2로 맞춤)였고, 환원 쪽 이온을 묽히면 전압이 내려갔으며 E°는 반응식을 2배 해도 그대로였습니다. 화학 전지의 원리, 표준 환원 전위, 네른스트 식을 정리합니다.

개념 정리

1. 화학 전지의 원리와 표준 환원 전위 (웹툰 7~8화)

1800년 볼타 전지(아연·구리·소금물 천) → 다니엘 전지 → 납축전지 → 건전지 → 1991년 리튬 이온 전지. 모든 실용 전지의 공통 구조: 산화 전극((−)극, 전자를 내놓음), 환원 전극((+)극), 전해질(이온 통로), 분리막 — 전자는 바깥 도선으로, 이온은 안쪽으로. 예측 게임(레몬에 구리판 두 장) — 제로 ‘켜진다’, 뭉치 ‘안 켜진다’: 산화되려는 경향이 다른 두 물질이 있어야 전자가 흐릅니다. 다니엘 전지: Zn → Zn²⁺ + 2e⁻(산화, −극), Cu²⁺ + 2e⁻ → Cu(환원, +극). 아연판을 CuSO₄에 그냥 넣으면 같은 반응이 열로 흩어지지만 산화·환원을 떼어 놓고 전자를 도선으로 지나가게 하면 전기 에너지. 염다리를 빼면 전하가 쌓여 곧 멈춥니다. 표준 환원 전위 E°: 표준 수소 전극(0 V) 기준, 25 ℃·1 M — 클수록 환원되기 쉽고(센 산화제) 작을수록 산화되기 쉬움(센 환원제). E°_전지 = E°(환원 전극) − E°(산화 전극): 예측 게임 — 뭉치 ‘−0.76 + 0.34 = 0.42 V’, 제로 ‘0.34 − (−0.76) = 1.10 V’. 구리–은: 0.80 − 0.34 = 0.46 V — 다니엘 전지에서 환원 전극이던 구리가 은과 짝이면 산화 전극(상대적 세기). 전지 전위가 양수면 자발적, 음수면 전기를 넣어야(9화 전기 분해). 전지 두 개를 직렬로 이으면 2.2 V.

산화 전극(−) 환원 전극(+) E° = E°환원 − E°산화

E°가 작은 쪽이 산화 전극(−극)이 되어 전자를 도선으로 내보냅니다. Zn–Cu는 0.34 − (−0.76) = 1.10 V, Cu–Ag로 바꾸면 구리가 이번엔 산화 전극(0.46 V)이 됩니다. 같은 금속 두 개면 0 V, 염다리를 빼면 이온 통로가 끊겨 전자도 멈춥니다. (25 ℃, 1 M 표준 상태)

2. 전자 수 맞추기와 네른스트 식

Zn/Ag: 반쪽 반응 전자 수 2와 1 → 최소공배수 2: Zn + 2Ag⁺ → Zn²⁺ + 2Ag, n = 2, Q = [Zn²⁺]/[Ag⁺]², E° = 0.80 − (−0.76) = 1.56 V. 농도가 표준이 아니면 네른스트 식 E = E° − (RT/nF)·lnQ: Ag⁺ 0.01 M → Q = 10⁴ → E = 1.56 − 0.01285 × 9.21 = 1.44 V(전자 수를 1로 잘못 쓰면 1.32 V, [Ag⁺]를 제곱하지 않으면 1.50 V). Zn/Cu, Cu²⁺ 0.01 M: Q = 100 → 1.10 − 0.01285 × 4.6 = 1.04 V. ΔG = −nFE로 반응의 자유 에너지와 연결(다니엘 −212 kJ/mol). 건전지(Zn/MnO₂ 1.5 V), 납축전지(2 V × 6), 리튬 이온 전지(약 3.7 V)의 전압은 모두 전극 재료의 환원 전위 차이에서 나오고, 배의 선체에 아연 덩어리를 붙이는 희생 양극법은 아연이 먼저 산화되어 철을 보호하는 화학 전지 원리입니다.

농도가 바뀌면 전압은? — 네른스트 식과 방전

n Q E ΔG = −nFE

환원 쪽 이온(Cu²⁺·Ag⁺)을 묽히면 전압이 내려가고, 산화 쪽 Zn²⁺를 묽히면 올라갑니다. Cu²⁺ 0.01 M → 1.04 V, Zn²⁺ 0.01 M → 1.16 V, Ag⁺ 0.01 M → 1.44 V(n = 2, Q = [Zn²⁺] ÷ [Ag⁺]²). ‘방전시키기’를 누르면 반응이 진행돼 Q가 커지며 전압이 천천히 떨어집니다. (25 ℃, RT/F = 0.0257 V, 두 용액 부피 같음)

3. 모형과 실제, 생활 속에서

활동도 대신 농도를 쓰고 액간 전위(염다리 접촉 전위)·전극 과전압·내부 저항을 무시했습니다. 실제 전압계 값은 계산보다 수십 mV 낮고 전류를 흘리면 더 떨어집니다. 표준 환원 전위는 25 ℃·1 M·1 atm 기준이라 온도가 바뀌면 E°와 RT/nF가 함께 변하고, 리튬처럼 물과 반응하는 금속은 수용액 전지로 구현할 수 없습니다. 좋은 전지의 조건: 두 전극의 경향 차이(전압), 전해질의 이온 이동(전류), 가볍고·많이 저장·여러 번 충전·안전.

E°_전지 = E°_환원 − E°_산화  ·  n = lcm(n₁, n₂), Q = [산화 쪽 이온]^(n/n₁) ÷ [환원 쪽 이온]^(n/n₂)  ·  E = E° − (RT ÷ nF)·lnQ  ·  ΔG = −nFE

예제

Mg²⁺/Mg(−2.37 V)와 Ag⁺/Ag(+0.80 V)로 전지를 만들면 전압과 반응식, 전자 수는? 반응식을 2배 하면 E°는?

Mg가 산화 전극. E° = 0.80 − (−2.37) = 3.17 V. Mg + 2Ag⁺ → Mg²⁺ + 2Ag, n = 2. 2배 해도 E°는 3.17 V 그대로(세기 성질), ΔG는 −612 → −1 224 kJ로 2배.

다니엘 전지에서 Zn²⁺ 1 M, Cu²⁺를 10⁻⁴ M로 하면 전압은? 전압이 0이 되는 Cu²⁺ 농도는?

Q = 1/10⁻⁴ = 10⁴ → E = 1.10 − 0.01285 × 9.21 = 0.98 V. E = 0 ⇔ lnQ = 1.10/0.01285 = 85.6 → Q = 10³⁷ → [Cu²⁺] = 10⁻³⁷ M — 사실상 Cu²⁺가 다 소모될 때까지 전지가 작동합니다.
