산화수와 산화·환원 반응 — 전자의 장부 맞추기

실험에서 Zn + Cu²⁺, 2Mg + O₂, 4Fe + 3O₂, CH₄ 연소, H₂O₂ 분해, 광합성 등의 반응식에 산화수를 매겨 변화한 원소를 찾고 이동한 전자 수를 세었으며, 실제로 섞어 보며 확인했습니다. 산화 전자 수와 환원 전자 수가 항상 같았고, H₂O₂는 한 물질에서 산화·환원이 함께 일어났으며, 산소가 끼지 않는 반응도 전자 이동으로 설명되었습니다. 산화수 규칙, 반쪽 반응식, 산화제·환원제의 상대성을 정리합니다.

산화 전자 수와 환원 전자 수가 같습니다 — 전자는 생기거나 없어지지 않습니다. 산화수가 오르는 원소가 있는 물질이 환원제(자신은 산화됨), 내리는 쪽이 산화제.

개념 정리

1. 산화수로 산화·환원 찾기 (웹툰 6화)

산화는 전자를 잃는 것(산화수 증가), 환원은 얻는 것(산화수 감소)이고 둘은 항상 동시에. 산소가 안 끼는 반응(Zn + Cu²⁺)이나 공유 결합 물질의 연소(CH₄)에서도 전자 이동을 셀 수 있게 만든 장부가 산화수. 예측 게임 — MnO₄⁻ 속 망가니즈의 산화수는? 뭉치 ‘이온 전하 −1이니 +1’, 제로 ‘산소 4개 −8, 전체 −1이려면 +7’. 반쪽 반응식으로 맞추기: 환원 MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O(+7 → +2), 산화 Fe²⁺ → Fe³⁺ + e⁻(×5) → 합 MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O — 전자가 반응식에서 사라지도록 잃은 수와 얻은 수를 같게. 상대를 산화시키고 자신은 환원되는 물질이 산화제, 상대를 환원시키고 자신은 산화되는 물질이 환원제. 과산화 수소는 I⁻는 산화시키고 MnO₄⁻에게는 산화됩니다 — 1화의 물이 산도 염기도 되듯 산화제·환원제는 상대적 세기로 결정됩니다.

2. 반응별 분석과 생활 속 산화·환원

Zn + Cu²⁺: Zn 0 → +2(산화, 환원제), Cu +2 → 0(환원), 2e. 2Mg + O₂: Mg 2개 × 2e = 4e. 4Fe + 3O₂: 4 × 3 = 12e. CH₄ + 2O₂: C −4 → +4(8e 산화), O 4개 × 2 = 8e 환원 — 연소는 탄소의 산화. 2H₂O₂ → 2H₂O + O₂: O −1 → −2(환원)와 −1 → 0(산화)이 같은 물질에서 — 불균등화(자체 산화·환원). 광합성: C +4 → 0(환원, 24e), O −2 → 0(산화) — 빛에너지로 CO₂를 환원해 포도당에 에너지를 저장하고, 세포 호흡은 그 반대(10화). 전지·연료 전지·부식·연소·호흡·표백·소독(차아염소산)이 모두 산화·환원이며, 비타민 C·폴리페놀 같은 항산화제는 자신이 먼저 산화되어 다른 분자를 보호하는 환원제입니다.

3. 모형과 실제, 생활 속에서

산화수는 전자를 전기 음성도가 큰 원자에 전부 배정한 형식적 장부라 실제 전하 분포와 다릅니다(CH₄의 C가 실제로 −4 전하를 갖지는 않음). 그래도 전자 이동을 세는 데는 정확합니다. Fe₃O₄처럼 평균 산화수가 분수(+8/3)인 경우는 실제로 +2와 +3이 섞인 것이고, 유기 화합물에서는 결합마다 따로 세는 방법을 씁니다. 산화·환원에서 옮겨 가는 전자를 도선으로 흐르게 하면 화학 전지(06 실험실)입니다.

산화수 배정 → 변화한 원소 → 이동 전자 = |Δ산화수| × 원자 수(계수 반영)  ·  Σ 산화 전자 = Σ 환원 전자  ·  반쪽 반응식: 전자 수 최소공배수로 맞춰 더함

예제

Cr₂O₇²⁻ + Fe²⁺ → Cr³⁺ + Fe³⁺(산성)의 반쪽 반응식을 맞춰 완성하면?

Cr: +6 → +3, 2개 → 6e 환원: Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O. Fe: +2 → +3, ×6. 합: Cr₂O₇²⁻ + 6Fe²⁺ + 14H⁺ → 2Cr³⁺ + 6Fe³⁺ + 7H₂O. 다이크로뮴산 이온(주황)이 Cr³⁺(초록)로 — 음주 측정기의 옛 원리.

Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O에서 산화·환원된 원소와 이 반응의 특징은?

Cl 0 → −1(환원)과 0 → +1(산화)이 같은 Cl₂에서 — 불균등화. 차아염소산 이온(ClO⁻)이 표백·소독의 산화제입니다. H₂O₂ 분해와 같은 유형.
