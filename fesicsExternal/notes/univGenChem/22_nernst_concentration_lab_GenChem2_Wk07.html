네른스트 식 — 전압은 log Q에 따라 직선으로 떨어진다

실험에서 다니엘 전지와 구리 농도 전지의 양쪽 이온 농도(10⁻⁴~1 M)와 온도(273~350 K)를 바꿔 전압 E를 기록했습니다. 298 K 다니엘 전지는 log Q가 0 → +4로 커지자 1.100 → 0.982 V로 log Q 1당 29.6 mV씩 떨어졌고, E° = 0인 농도 전지도 농도 차 100배에서 0.059 V를 냈습니다. 네른스트 식, 방전과 평형, 농도 전지와 온도 효과를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 전지(다니엘·농도 전지)와 온도를 버튼으로, 왼쪽(산화 전극 쪽)·오른쪽(환원 전극 쪽) 이온 농도를 슬라이더(10⁻⁴~1 M)로 정하고 전압 측정을 누르면 log Q와 E가 기록됩니다. 298 K에서 log Q가 다른 기록을 4개 이상 모으면 데이터 검증 탭에서 E 대 log Q 직선의 기울기·절편과 온도별 기울기 비교가 열립니다.

298 K에서 E는 log Q에 대해 기울기 −0.05916/n = −29.6 mV(n = 2)인 직선이고 절편이 E°입니다. 방전으로 [Zn²⁺]가 늘고 [Cu²⁺]가 줄면 Q가 커져 전압이 떨어지고, Q = K가 되면 E = 0인 ‘다 쓴 전지’가 됩니다. 농도 전지는 E° = 0이라 묽은 쪽이 산화 전극일 때만 양의 전압이 나오고, 온도가 오르면 기울기 2.303RT/nF가 커집니다(350 K에서 34.7 mV).

개념 정리

1. ΔG = ΔG° + RT ln Q 를 전압으로

ΔG = −nFE 를 대입하면 E = E° − (RT/nF) ln Q, 25 °C에서 E = E° − (0.05916/n) log Q.

  • 다니엘 전지: Zn + Cu²⁺ → Zn²⁺ + Cu, Q = [Zn²⁺]/[Cu²⁺], n = 2
  • 방전 → [Zn²⁺]↑, [Cu²⁺]↓ → Q↑ → E↓. 평형(Q = K)에서 E = 0 — "다 쓴 전지"
  • 농도 전지: 같은 전극, 농도만 다름. E° = 0이고 묽은 쪽이 산화 전극
  • pH 미터는 막 양쪽 H⁺ 농도 차가 만드는 농도 전지입니다(pH 1 차이 ≈ 59 mV).

2. 실험 모형과 실제의 차이

· 실제로는 활동도 계수 때문에 진한 용액에서 직선에서 벗어납니다.

· 온도를 바꿀 때 E°의 온도 의존성은 무시했습니다(기울기 효과만 봄).

3. 생활 속에서 · 이어지는 개념

  • 리튬 이온 전지의 잔량 표시는 전압-충전 상태 곡선을 이용하고, 금속 배관의 농담 전지 부식은 산소·이온 농도 차에서 생깁니다.
E = E° − (RT/nF) ln Q  ·  25 °C: E = E° − (0.05916/n) log Q  ·  다니엘 Q = [Zn²⁺]/[Cu²⁺]  ·  평형: E = 0, log K = nE°/0.05916

2.303RT/F = 59.16 mV (298 K) · n = 2 → 29.58 mV · 273 K 27.1, 350 K 34.7 mV · F = 96 485 C/mol

예제

다니엘 전지가 방전되어 [Zn²⁺] = 1.9 M, [Cu²⁺] = 0.10 M가 되었다. 25 °C의 전압은?

Q = 1.9 ÷ 0.10 = 19, log Q = 1.28. E = 1.10 − 0.02958 × 1.28 = 1.10 − 0.038 = 1.06 V. 농도가 크게 변해도 log라 전압은 조금만 떨어집니다 — 건전지 전압이 끝 무렵에야 급히 떨어지는 까닭입니다.

다니엘 전지의 전압이 0이 되는 Q(= K)는?

0 = 1.10 − 0.02958 log K → log K = 1.10 ÷ 0.02958 = 37.2, K ≈ 10³⁷. Cu²⁺가 사실상 모두 소모되어야 전지가 멈춥니다(6주차 실험의 log K 37.2와 같음).
