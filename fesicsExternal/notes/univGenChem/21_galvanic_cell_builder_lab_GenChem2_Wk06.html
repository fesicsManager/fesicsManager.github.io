대학 일반화학 실험 2 · 6주차 · 갈바니 전지

갈바니 전지 — E°, ΔG°, K를 한 줄로 잇는다

실험에서 Mg·Zn·Fe·Ni·Pb·Cu·Ag 가운데 두 금속을 골라 표준 상태 전지를 만들고 산화 전극, E°cell, 이동 전자 수 n, ΔG° = −nFE°, log K를 기록했습니다. Zn-Cu는 1.10 V·ΔG° −212 kJ·K ≈ 10³⁷, Mg-Ag는 3.17 V·K ≈ 10¹⁰⁷이었고, 금속을 좌우로 바꿔 놓아도 환원 전위가 낮은 쪽이 언제나 (−)극이 되었습니다. 전지 표기, 표준 환원 전위, 세 양의 관계를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 왼쪽 반쪽 전지와 오른쪽 반쪽 전지의 금속을 버튼으로 고르고 전지 연결하기를 누르면 전지 표기, 전체 반응, E°cell, n, ΔG°, log K가 기록됩니다(같은 금속 두 개는 계산되지 않음). 금속 짝을 바꿔 4개 이상 기록하면 데이터 검증 탭에서 ΔG° 대 nE°(기울기 −F)와 log K 대 nE°(기울기 16.90 V⁻¹) 분석이 열립니다.

E°cell = E°(환원) − E°(산화)이므로 표준 환원 전위 차가 클수록 전압이 큽니다. Ag가 들어간 짝은 반응식이 Zn + 2Ag⁺ → Zn²⁺ + 2Ag처럼 Ag 쪽 계수가 2가 되지만 E°(Ag) 0.80 V는 그대로입니다(세기 성질). 이 실험의 금속 이온은 Ag⁺ 말고 모두 2가라 모든 짝에서 n = 2이고, ΔG°와 log K는 모두 nE°에 비례합니다.

개념 정리

1. 환원 전위가 높은 쪽이 전자를 가져간다

E°cell = E°환원 전극 − E°산화 전극. 환원 전위가 더 큰 금속 이온이 환원되고(+극), 작은 쪽 금속이 산화됩니다(−극).

  • 반쪽 반응의 계수를 곱해도 E°는 바뀌지 않습니다(세기 성질). 전자 수 n만 맞춥니다.
  • 전지 표기: Zn(s) | Zn²⁺(1 M) ‖ Cu²⁺(1 M) | Cu(s)

2. 세 양의 삼각형

ΔG° = −nFE° (F = 96 485 C/mol), ΔG° = −RT ln K → 25 °C에서 log K = nE°/0.05916 V

3. 실험 모형과 실제의 차이

· 실제 전지는 내부 저항·과전압 때문에 전류가 흐를 때 전압이 E°보다 낮아집니다.

· Mg처럼 반응성이 큰 금속은 물과도 반응하므로 실제 전지에서는 표준 전위 그대로 쓰기 어렵습니다.

4. 생활 속에서 · 이어지는 개념

  • 레몬 전지(Zn·Cu 전극)는 레몬즙이 전해질 역할을 하는 갈바니 전지입니다. 전압이 1 V 안팎인 까닭이 E° 차이에 있어요.
E°cell = E°환원 전극 − E°산화 전극  ·  ΔG° = −nFE°  ·  ΔG° = −RT ln K  ·  log K = nE°/0.05916 V (25 °C)

F = 96 485 C/mol · 1 V × 1 C = 1 J · Zn²⁺/Zn −0.76, Cu²⁺/Cu +0.34, Ag⁺/Ag +0.80 V (SHE 기준)

🔬 실험 피드백

“같은 금속 두 개로는 표준 상태에서 전위차가 0입니다. 서로 다른 금속을 고르세요.”

실험 결과 칸 · 같은 금속을 양쪽에 골랐을 때

예제

Ni | Ni²⁺(1 M) ‖ Ag⁺(1 M) | Ag 전지의 E°cell, ΔG°, log K를 구하라.

E° = 0.80 − (−0.25) = 1.05 V. 반응 Ni + 2Ag⁺ → Ni²⁺ + 2Ag, n = 2. ΔG° = −2 × 96 485 × 1.05 = −2.03 × 10⁵ J = −203 kJ. log K = 2 × 1.05 ÷ 0.05916 = 35.5.

Zn과 Cu를 써서 1.10 V보다 큰 전압을 얻고 싶다. 표 1의 금속으로 무엇을 바꾸면 좋은가?

산화 전극을 환원 전위가 더 낮은 금속으로, 환원 전극을 더 높은 쪽으로 바꿉니다. Zn 대신 Mg를 쓰면 2.71 V, Cu 대신 Ag를 쓰면 1.56 V, 둘 다 바꾸면 Mg-Ag 3.17 V입니다. 다만 Mg는 물과도 반응해 실제 전지에서 그대로 쓰기 어렵습니다.
