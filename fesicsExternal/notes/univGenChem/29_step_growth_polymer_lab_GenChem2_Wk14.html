축합 중합 — 99 % 반응해도 사슬은 겨우 100단위

실험에서 나일론-6,6, PET, 폴리글라이신의 축합 중합에서 반응한 작용기 비율 p(0.900~0.999)와 단량체 몰비 r(1.000·0.990·0.950)을 바꿔 평균 중합도 X̄ₙ와 수평균 분자량 Mₙ을 기록했습니다. 나일론-6,6은 r = 1에서 p = 0.90일 때 X̄ₙ 10(1150 g/mol), 0.99일 때 100, 0.999일 때 1000이었지만, r = 0.99면 p = 0.999에서도 166에 그쳤습니다. 카로더스 식, 전환율과 몰비의 중요성, 연쇄 중합과의 차이를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 중합체와 단량체 몰비 r을 버튼으로, 반응한 작용기 비율 p(0.900~0.999)를 슬라이더로 정하고 중합 진행을 누르면 1/(1 − p), X̄ₙ, Mₙ이 기록됩니다. r = 1.000에서 p를 0.90·0.95·0.99·0.999처럼 바꿔 4개 이상 기록하고 r도 바꿔 보면 데이터 검증 탭에서 X̄ₙ 대 1/(1 − p) 그래프(r = 1이면 기울기 1)와 분자량 비교 막대가 열립니다.

개념 정리

1. 단계 성장 중합의 카로더스 식

작용기가 반응할 때마다 물(H₂O) 한 분자가 빠지며 결합이 생깁니다. 반응한 비율이 p이면 남은 분자 수는 처음의 (1 − p)배이므로

X̄ₙ = 1/(1 − p) (두 단량체가 정확히 1 : 1일 때), 몰비 r(< 1)이면 X̄ₙ = (1 + r)/(1 + r − 2rp)

  • p = 0.90 → X̄ₙ = 10, p = 0.99 → 100, p = 0.999 → 1000. 높은 전환율이 필수
  • r = 0.99면 p가 1이어도 X̄ₙ ≤ (1 + r)/(1 − r) ≈ 199 — 단량체 순도와 계량이 중요
  • 첨가 중합(폴리에틸렌 등)은 사슬 끝에서 단량체가 계속 붙는 연쇄 성장이라 초기부터 긴 사슬이 생깁니다.
  • 단백질의 펩타이드 결합, 핵산의 인산다이에스터 결합도 물이 빠지는 축합 결합입니다.

2. 실험 모형과 실제의 차이

· 실제 반응에는 고리 형성, 부반응, 평형(물 제거 필요)이 있어 계산보다 짧은 사슬이 생기곤 합니다.

· 생체에서 단백질은 리보솜이 서열대로 합성하므로 이런 무작위 축합이 아닙니다(여기서는 결합 종류만 비교).

3. 생활 속에서 · 이어지는 개념

  • 나일론 스타킹, 음료수 병(PET), 비단(단백질 섬유)은 모두 축합 결합으로 이어진 사슬입니다.
X̄ₙ = 1/(1 − p) (r = 1)  ·  X̄ₙ = (1 + r)/(1 + r − 2rp)  ·  p → 1: X̄ₙ → (1 + r)/(1 − r)  ·  Mₙ ≈ X̄ₙ·M₀ + 18

M₀(구조 단위 평균): 나일론-6,6 113.16 · PET 96.08 · 폴리글라이신 57.05 g/mol · 18 = 사슬 양 끝의 H와 OH(물 한 분자)

예제

나일론-6,6(r = 1)의 Mₙ을 20 000 g/mol 이상으로 만들려면 p가 얼마 이상이어야 하나?

X̄ₙ ≥ (20 000 − 18) ÷ 113.16 = 176.6 → 1 − p ≤ 1/176.6 = 0.00566 → p ≥ 0.9943. 작용기의 99.4 % 이상이 반응해야 합니다. 그래서 공업에서는 다이아민과 아디프산을 먼저 ‘나일론 염’으로 만들어 1 : 1을 정확히 맞춥니다.

몰비 r = 0.990일 때 나일론-6,6이 이를 수 있는 최대 X̄ₙ와 Mₙ은?

X̄ₙ(최대) = (1 + 0.990) ÷ (1 − 0.990) = 1.99 ÷ 0.01 = 199, Mₙ ≈ 199 × 113.16 + 18 ≈ 22 500 g/mol. 단량체를 1 % 잘못 계량하면 반응을 아무리 오래 해도 이 이상 길어지지 않습니다.
