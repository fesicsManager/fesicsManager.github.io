배위 화합물 — 배위수가 모양을, 모양이 이성질체 수를 정한다

실험에서 착화합물 여섯 가지를 골라 입체 이성질체 수를 먼저 예측한 뒤 구조를 펼쳐 산화수, 배위수, 기하 구조, cis/trans·fac/mer, 거울상 이성질체를 기록했습니다. 같은 MA₂B₂라도 평면사각형 [Pt(NH₃)₂Cl₂]는 2개, 사면체 [Zn(NH₃)₂Cl₂]는 1개였고, [Co(en)₂Cl₂]⁺는 trans 1개와 서로 거울상인 cis 2개로 모두 3개였습니다. 산화수 계산, 명명법, 기하·광학 이성질체를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 착화합물 여섯 가지 중 하나와 나의 예측(입체 이성질체 1~4개, 거울상 포함)을 버튼으로 고르고 구조 펼쳐 보기를 누르면 이성질체 그림과 함께 산화수·구조·실제 개수·정답 여부가 기록됩니다. 착화합물을 바꿔 4개 이상 기록하면 데이터 검증 탭에서 예측 정답률 막대와 구조별 이성질체 수 요약표가 열립니다.

표 1. 착화합물의 구조와 입체 이성질체 (실험 결과)
착화합물금속 산화수배위수 · 구조기하 이성질체광학 이성질체입체 총수
[Co(NH₃)₄Cl₂]⁺+36 · 팔면체cis, trans없음2
[Co(NH₃)₃Cl₃]+36 · 팔면체fac, mer없음2
[Pt(NH₃)₂Cl₂]+24 · 평면사각형cis, trans없음2
[Zn(NH₃)₂Cl₂]+24 · 사면체한 가지뿐없음1
[Co(en)₃]³⁺+36 · 팔면체한 가지뿐있음 (Δ/Λ 한 쌍)2
[Co(en)₂Cl₂]⁺+36 · 팔면체cis, transcis만 거울상 한 쌍3

사면체는 네 자리가 모두 서로 이웃(109.5°)이라 기하 이성질체가 없고, 평면사각형과 팔면체는 이웃 자리(90°, cis)와 마주 보는 자리(180°, trans)가 구별됩니다. MA₃B₃ 팔면체는 세 B가 한 면에 모이면 fac, 자오선에 늘어서면 mer입니다. 두자리 리간드 en이 셋 또는 cis로 둘 붙으면 대칭면이 사라져 거울상과 겹치지 않는 광학 이성질체가 생깁니다(trans-[Co(en)₂Cl₂]⁺는 대칭면이 있어 없음).

개념 정리

1. 배위수가 모양을, 모양이 이성질체를 정한다

  • 배위수 4: 사면체(모든 자리가 서로 이웃 → 기하 이성질체 없음) 또는 평면사각(d⁸ 금속, Pt²⁺ 등 → cis/trans)
  • 배위수 6: 팔면체 — MA₄B₂는 cis/trans, MA₃B₃는 fac/mer
  • 광학 이성질체: 거울상과 겹치지 않는 구조(대칭면이 없음). [Co(en)₃]³⁺의 Δ/Λ, cis-[Co(en)₂Cl₂]⁺

2. 명명 규칙 요약

리간드를 알파벳(한글 표기에서는 원어 기준) 순으로 먼저, 개수 접두사(다이·트라이·테트라, 두자리 리간드는 비스·트리스), 금속 뒤 괄호 안에 로마 숫자 산화수.

3. 산화수 계산

금속 산화수 + Σ(리간드 전하) = 착이온 전하 — NH₃, en은 0, Cl⁻는 −1.

4. 실험 모형과 실제의 차이

· 그림은 입체를 평면에 옮긴 개략도입니다. 앞·뒤 자리는 비스듬히 그렸어요.

· 구조 이성질체(결합 이성질, 배위권 이성질)는 이 실험에서 다루지 않습니다.

5. 생활 속에서 · 이어지는 개념

  • 항암제 cisplatin은 cis-[Pt(NH₃)₂Cl₂]만 효과가 있고 trans 이성질체는 효과가 거의 없습니다. 모양이 약효를 가릅니다.
금속 산화수 + Σ(리간드 전하) = 착이온 전하  ·  배위수 4: 사면체·평면사각형  ·  배위수 6: 팔면체  ·  MA₄B₂ → cis/trans · MA₃B₃ → fac/mer

리간드 전하: NH₃ 0 · en(에틸렌다이아민, 두자리) 0 · Cl⁻ −1 · CN⁻ −1 · 입체 총수 = 기하 이성질체 + 추가 거울상 수

예제

K₃[Fe(CN)₆]의 중심 금속 산화수, 배위수, 이름은?

착이온 전하는 K⁺ 3개를 맞추는 −3. x + 6(−1) = −3 → x = +3. 배위수 6(팔면체). 이름: 헥사사이아노철(III)산 포타슘(음이온 착물은 금속 이름 뒤에 ‘산’을 붙이고 양이온 이름을 뒤에 씀).

[Co(NH₃)₅Cl]²⁺는 입체 이성질체가 몇 개인가?

산화수: x + 0 − 1 = +2 → +3. MA₅B 팔면체에서 B는 어느 꼭짓점에 놓아도 회전하면 같은 구조이므로 기하 이성질체 1개, 대칭면이 있어 광학 이성질체도 없습니다 → 1개.
