분자 궤도함수 — 결합 차수와 산소의 상자성

실험에서 H₂~Ne₂와 그 ±1 이온을 골라 분자 궤도함수에 전자를 채우고 결합 차수·홀전자 수·자성을 구해 실측 결합 길이·에너지와 비교했습니다. N₂(결합 차수 3)는 110 pm·945 kJ/mol로 가장 짧고 강했고, O₂⁺ 2.5 → O₂ 2.0 → O₂⁻ 1.5로 갈수록 결합이 112 → 121 → 135 pm로 길어졌습니다. 루이스 구조는 O₂를 반자성으로 예측하지만 MO는 π*의 홀전자 2개로 상자성을 맞혔습니다. 결합 차수, 2주기의 두 가지 MO 순서, 자성을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 원소(H₂~Ne₂)와 전하(+1·중성·−1)를 고르고 전자 채우기를 누르면 결합성/반결합성 전자 수·결합 차수·홀전자 수·MO와 루이스 자성·실측 길이와 에너지가 나오고 자동 기록됩니다. 자리가 모자라는 He₂⁻·Ne₂⁻는 계산되지 않습니다. N₂·O₂·F₂와 O₂⁺·O₂⁻처럼 결합 차수가 다른 종을 4개 이상(권장 5개) 기록하면 데이터 검증 탭에서 결합 차수–길이·에너지 그래프와 자성 비교 표가 열립니다.

결합 차수가 클수록 결합이 짧고 강해집니다(F₂ 1.0·142 pm → O₂ 2.0·121 pm → N₂ 3.0·110 pm). N₂에서는 결합성 σ2p 전자가 빠져 N₂⁺가 약해지고(945 → 841 kJ/mol), O₂에서는 반결합성 π* 전자가 빠져 O₂⁺가 강해집니다(498 → 643 kJ/mol). 전자 수가 짝수인 O₂를 루이스 구조는 반자성으로 보지만, MO는 π*2p 두 오비탈에 홀전자 1개씩을 두어 상자성을 맞힙니다.

개념 정리

1. 원자 궤도함수가 섞여 분자 궤도함수가 된다

두 원자 궤도함수가 겹치면 에너지가 낮은 결합성과 높은 반결합성(*) 분자 궤도함수가 하나씩 생깁니다. 전자는 쌓음 원리·파울리 원리·훈트 규칙에 따라 채워집니다.

결합 차수 = (결합성 전자 수 − 반결합성 전자 수) / 2

2. 2주기의 두 가지 순서

  • Li₂ ~ N₂: 2s–2p 섞임 때문에 π2p가 σ2p보다 낮음
  • O₂ ~ Ne₂: σ2p가 π2p보다 낮음

3. 두 이론의 사용법

  • 원자가 결합(VB) 이론: 혼성 오비탈과 국소 결합 — 분자 모양과 루이스 구조에 편리
  • 분자 궤도함수(MO) 이론: 전자가 분자 전체에 퍼짐 — 자성, 이온의 결합 세기, 들뜬 상태를 설명
  • O₂의 루이스 구조(O=O)는 모든 전자가 짝지어져 반자성을 예측하지만, 액체 산소는 자석에 끌립니다(상자성). MO는 π*에 홀전자 2개를 예측합니다.

4. 실험 모형과 실제의 차이

· 결합 차수 0인 He₂, Be₂, Ne₂는 화학 결합 대신 아주 약한 반 데르 발스 인력만 있습니다.

· 결합 길이는 결합 차수만으로 정해지지 않고 원자 크기에도 달라집니다.

5. 생활 속에서 · 이어지는 개념

  • 슈퍼옥사이드(O₂⁻)·과산화물(O₂²⁻) 이온의 결합이 O₂보다 길고 약한 것은 π*에 전자가 더 들어가기 때문입니다.
결합 차수 = (결합성 전자 수 − 반결합성 전자 수) ÷ 2  ·  홀전자 ≥ 1 → 상자성, 0 → 반자성

Li₂~N₂: σ2s < σ*2s < π2p < σ2p < π*2p < σ*2p · O₂~Ne₂: σ2p < π2p · N₂ 3.0 (110 pm, 945 kJ/mol) · O₂ 2.0 (121 pm, 498) · F₂ 1.0 (142 pm, 159)

예제

C₂⁻(원자가 전자 9개, Li₂~N₂ 순서)의 결합 차수와 자성은?

σ2s² σ*2s² π2p⁴ σ2p¹ → 결합성 7, 반결합성 2 → 결합 차수 (7 − 2) ÷ 2 = 2.5. σ2p에 홀전자 1개 → 상자성.

B₂(원자가 전자 6개)는 실험적으로 상자성이다. 이것이 Li₂~N₂에서 π2p가 σ2p보다 낮다는 증거가 되는 까닭은?

π2p가 낮으면 σ2s² σ*2s² 다음 두 전자가 π2p 두 오비탈에 하나씩 들어가(훈트 규칙) 홀전자 2개 → 상자성, 결합 차수 1입니다. 만약 σ2p가 더 낮다면 두 전자가 σ2p에 짝지어 들어가 반자성이 되어야 하므로, 상자성은 2s–2p 섞임으로 순서가 바뀐다는 증거입니다.
