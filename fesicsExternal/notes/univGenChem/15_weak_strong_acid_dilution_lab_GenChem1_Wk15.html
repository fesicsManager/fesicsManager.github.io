대학 일반화학 실험 1 · 15주차 · 산–염기 평형

강산과 약산의 희석 — 묽힐수록 약산은 더 많이 이온화한다

실험에서 산 5종(HCl·HF·HCOOH·CH₃COOH·HCN)과 농도(10⁻¹~10⁻⁸ M)를 바꿔 물의 자동 이온화까지 포함한 정확한 pH와 이온화도 α를 구하고 간단 공식과 비교했습니다. 10배 묽힐 때 HCl의 pH는 1씩, 아세트산은 약 0.5씩 올랐고(2.875 → 3.382), 아세트산의 α는 0.1 M 1.33 %에서 10⁻⁴ M 34.37 %로 커졌습니다. 10⁻⁸ M 염산은 간단 공식의 8이 아니라 6.978이었습니다. 산의 세기, 오스트발트 희석 법칙, 물의 자동 이온화를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 산과 농도 C(10⁻¹~10⁻⁸ M)를 고르고 녹이고 pH 재기를 누르면 정확한 [H₃O⁺], pH(물 이온화 포함), 간단 공식 pH와 차이, 이온화도 α가 나오고 자동 기록됩니다. 같은 산으로 농도를 3가지 이상, 강산(HCl)과 약산 하나를 비교하고 10⁻⁸ M도 넣어 4개 이상 기록하면 데이터 검증 탭에서 pH–log C 그래프와 기울기가 열립니다.

강산은 log C가 1 줄 때 pH가 1 오르지만 약산은 약 0.5만 오릅니다([H₃O⁺] ≈ √(K_aC)). 묽힐수록 약산의 α는 커지고(오스트발트 희석 법칙), 10⁻⁴ M 아세트산에서는 α가 34 %나 되어 √(K_aC) 공식이 0.09만큼 어긋납니다. 아주 묽으면 물의 자동 이온화가 이겨 pH는 7에 다가가되 7을 넘지 않습니다.

개념 정리

1. 브뢴스테드–로리 산과 물의 자동 이온화

산은 H⁺를 주는 물질입니다. 물은 스스로 2H₂O ⇌ H₃O⁺ + OH⁻, Kw = 1.0×10⁻¹⁴ 만큼 이온화합니다. pH = −log[H₃O⁺]

2. 산 세기의 구조적 근거

  • 할로젠화 수소: H–X 결합이 약할수록 강산 → HF(약산) ≪ HCl < HBr < HI
  • 옥소산·카복실산: 짝염기 음전하가 잘 퍼질수록(공명·전기 음성도) 강산 → 폼산이 아세트산보다 약 10배 강함

3. 정확한 계산 (전하 균형)

[H₃O⁺] = [A⁻] + [OH⁻], [A⁻] = C·Ka/(Ka + [H₃O⁺]), [OH⁻] = Kw/[H₃O⁺] — 이 식을 수치로 풉니다.

  • 강산은 거의 다 이온화(α ≈ 1), 약산은 C가 클 때 α가 작고 묽힐수록 α가 커집니다(오스트발트 희석 법칙).
  • 10배 묽히면 강산 pH는 1, 약산 pH는 약 0.5만큼 오릅니다.
  • 아주 묽으면 물의 이온화가 이겨서 산의 pH는 7에 다가가지만 7을 넘지 않습니다.

4. 실험 모형과 실제의 차이

· 진한 용액(약 0.1 M 이상)에서는 이온 사이 상호 작용 때문에 실제 pH 측정값이 계산과 조금 다릅니다.

· 10⁻⁷ M 이하 용액은 공기 중 CO₂가 녹아 실제로 만들기 어렵습니다.

5. 생활 속에서 · 이어지는 개념

  • 식초(아세트산 약 0.8 M)는 pH가 약 2.4로, 같은 농도의 염산(pH 약 0.1)보다 훨씬 순합니다.
pH = −log[H₃O⁺]  ·  강산 [H₃O⁺] ≈ C  ·  약산 [H₃O⁺] ≈ √(K_a C)  ·  정확: [H₃O⁺] = C·K_a ÷ (K_a + [H₃O⁺]) + K_w ÷ [H₃O⁺]  ·  α = [A⁻] ÷ C

K_w = 1.0×10⁻¹⁴ (25 ℃) · K_a: HF 6.8×10⁻⁴, HCOOH 1.8×10⁻⁴, CH₃COOH 1.8×10⁻⁵, HCN 4.9×10⁻¹⁰ · 0.1 M CH₃COOH pH 2.875, α 1.33 %

🔬 실험 피드백

“간단 공식 pH 8.000 — 이 농도에서는 간단 공식이 틀림(+1.02)”

실험 결과 · 10⁻⁸ M 염산을 골랐을 때

예제

0.10 M 폼산(K_a = 1.8×10⁻⁴)의 pH와 α를 간단 공식으로 구하고 정확값(pH 2.382, α 4.15 %)과 비교하라.

[H₃O⁺] ≈ √(1.8×10⁻⁴ × 0.10) = 4.24×10⁻³ M → pH = 2.372, α ≈ 4.24×10⁻³ ÷ 0.10 = 4.2 %. α가 5 % 아래라 C − x ≈ C 근사가 잘 맞아 정확값과 0.01밖에 차이 나지 않습니다.

10⁻⁸ M HCl의 [H₃O⁺]와 pH를 전하 균형으로 구하라.

[H₃O⁺] = C + K_w/[H₃O⁺] → h² − 10⁻⁸h − 10⁻¹⁴ = 0 → h = (10⁻⁸ + √(10⁻¹⁶ + 4×10⁻¹⁴)) ÷ 2 = 1.05×10⁻⁷ M, pH = 6.978. 산을 넣었는데 pH 8(염기성)이 될 수는 없습니다.
