비교하는 말 — 손뼉 칸 수로 -er과 more를 골라요

형용사를 골라 -er 붙이기, more 붙이기, 특별한 모양 중 하나로 비교하는 말을 만들고, 손뼉 칸 수와 ○△✕ 판정을 기록했습니다. 1칸 단어와 -y로 끝나는 2칸 단어는 -er, 3칸 이상 단어는 more가 ○였고, good·bad는 better·worse라는 특별한 모양이었습니다. 단어 길이로 비교하는 말을 고르는 규칙과 예외를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 형용사 15개(tall, fast, small, long, big, hot, happy, easy, beautiful, interesting, delicious, expensive, smart, good, bad) 중 하나와 만드는 방법(-er 붙이기 / more 붙이기 / 특별한 모양)을 고르고 비교하는 말 만들기를 누르면 칸 수, 만든 말, 판정(○ 알맞음 · △ 가끔 씀 · ✕ 틀림)이 기록됩니다. 1칸, 2칸, 3칸 이상 단어와 good·bad를 골고루 해서 4개 이상 기록하면 결과 비교 탭이 열립니다.

표 1. 형용사의 칸 수와 비교하는 말 판정 (실험 예시, 초등 교과서 수준의 기본 규칙)
형용사칸 수만든 말판정
tall1칸taller○
big1칸bigger○
happy2칸happier○
beautiful3칸beautifuler✕
beautiful3칸more beautiful○
good1칸better○

짧은 단어(1칸, -y로 끝나는 2칸)는 -er, 3칸 이상 긴 단어는 앞에 more를 붙여야 ○였어요. 긴 단어에 -er까지 붙이면 beautifuler처럼 혀가 꼬이기 때문이에요. big → bigger는 끝 자음을 한 번 더, happy → happier는 y를 i로 바꿨어요. good → better, bad → worse는 규칙을 따르지 않는 예외라 따로 익혀요.

개념 정리

1. 단어 길이를 재고 고른다

칸 수단어비교하는 말
1칸tall, fast, small, longtaller, faster, smaller, longer
1칸 (짧은 모음 + 자음 끝)big, hotbigger, hotter (끝 자음 한 번 더)
2칸 (-y로 끝남)happy, easyhappier, easier (y → i)
3칸 이상beautiful, interesting, delicious, expensivemore beautiful, more interesting …

짧으면 -er, 3칸 이상으로 길면 앞에 more

긴 단어에 -er까지 붙이면 너무 길어지니까 앞에 more를 따로 둬요.

움직여 보기

칸을 세고 -er이냐 more냐 고르기

칸 수: 결과:

단어를 고르고 '한 단계씩 보기'를 눌러 보세요. 칸을 세고(①) 규칙을 골라(②) 비교하는 말을 만들어요(③). 주황 글자는 바뀌거나 더해진 철자, 보라 글자는 붙인 -er이나 more예요. good·bad는 규칙에 안 맞는 단어라 따로 익혀요.

2. 규칙에 안 맞는 단어

good → better, bad → worse. 자주 쓰는 단어일수록 예외가 많아요. 규칙으로 대부분을 해결하고 예외 몇 개만 따로 익혀요.

3. 실험 모형과 실제의 차이

· 2칸 단어 중 -y로 끝나지 않는 것(예: careful)은 more를 써요.

· happy처럼 -er이 기본인 단어도 more happy라고 쓰는 사람이 가끔 있어요. 그래서 △로 표시했어요.

1칸 → 형용사 + er (big → bigger, 끝 자음 한 번 더) · -y로 끝나는 2칸 → y를 i로 + er · 3칸 이상 → more + 형용사 · good → better, bad → worse
