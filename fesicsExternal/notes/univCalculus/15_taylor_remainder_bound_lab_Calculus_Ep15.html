대학 미적분학 · 웹툰 15화 「항을 많이 쓸수록 근삿값은 정확해진다?」

테일러 근사와 라그랑주 나머지 — 오차는 한계로 보증하고 Rₙ → 0을 확인한다

a = 0 중심의 n차 테일러 다항식으로 함수값을 근사해 실제 오차와 라그랑주 공식이 보장하는 한계를 함께 기록했습니다. eˣ의 x = 1에서 n = 4, 8, 9일 때 실제 오차는 9.95×10⁻³ → 3.03×10⁻⁷로 늘 한계 3/(n + 1)! 이하였고, n = 9에서 처음으로 한계가 10⁻⁶ 아래로 내려갔습니다. e^(−1/x²)는 테일러 다항식이 0이라 x = 0.5에서 오차 0.0183이 그대로 남았습니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 함수(eˣ, sin x, cos x, √(1 + x), e^(−1/x²)), x(0.01~3), 차수 n(1~12)을 정하고 근사하기를 누르면 원래 함수와 n차 테일러 다항식, x에서의 실제 오차 막대와 오차 한계 띠가 그려지고 Tₙ(x)·실제 오차·보장된 한계가 기록표에 쌓입니다. eˣ를 x = 1에서 n = 4, 6, 8, 9로 기록하고 sin x(n = 5)를 x = 0.5, 1, 2, 3에서도 기록해 4개 이상 모으면 결과 비교 탭에서 실제 오차와 한계를 로그 눈금으로 비교할 수 있습니다.

라그랑주 공식은 c가 어디인지 몰라도 |f⁽ⁿ⁺¹⁾| ≤ M만으로 |Rₙ| ≤ M|x|ⁿ⁺¹/(n + 1)!을 줍니다. 기록한 모든 경우에 실제 오차는 한계 이하였고, e의 계산에서 n = 8은 한계 8.27×10⁻⁶이 10⁻⁶을 넘어 보장에 실패, n = 9에서 비로소 보장됩니다. sin x의 5차 근사는 x가 1에서 3으로 커지자 오차가 2×10⁻⁴에서 0.38로 커져, 근사에는 ‘중심 근처에서’라는 조건이 붙습니다. e^(−1/x²)는 0에서 모든 도함수가 0이라 Tₙ = 0이고 Rₙ = f(x)가 0으로 가지 않습니다.

개념 정리

1. 라그랑주 나머지

f(x) = Tₙ(x) + Rₙ(x), Rₙ(x) = f⁽ⁿ⁺¹⁾(c)/(n + 1)! · xⁿ⁺¹ (c는 0과 x 사이)

|f⁽ⁿ⁺¹⁾| ≤ M이면 |Rₙ| ≤ M·|x|ⁿ⁺¹/(n + 1)! — n = 0이면 5화의 평균값 정리입니다.

  • e = Σ1/k! + Rₙ, e < 3을 쓰면 |Rₙ| ≤ 3/(n + 1)!. 10⁻⁶ 미만을 보장하려면 (n + 1)! > 3×10⁶ → 10! = 3628800 → n = 9.
  • sin의 짝수 차 항, cos의 홀수 차 항은 0이라 Tₙ이 한 차수 위 다항식과 같고, 한계가 한 단계 더 작아집니다.
  • √(1 + x) ≈ 1 + x/2의 오차는 |f″| ≤ ¼에서 ≤ x²/8. f″ < 0이라 나머지가 음수, 근삿값이 참값보다 큽니다.
  • e^(−1/x²)(f(0) = 0)는 0에서 모든 도함수가 0이라 테일러 급수가 0입니다. 급수는 어디서나 수렴하지만 함수와 0에서만 같아요.

2. 실험 모형과 실제의 차이

· 한계는 “최악의 경우” 보증서입니다. 실제 오차는 항상 한계 이하이고, 거의 꽉 찰 때도 넉넉할 때도 있어요.

· eˣ의 한계는 c가 0과 x 사이라 e^c < eˣ < 3ˣ로 잡았습니다(x > 0).

3. 생활 속에서 · 이어지는 개념

  • 진자의 sin θ ≈ θ(오차 ≤ θ³/6), 상대론 운동 에너지의 첫 항 ½mv²처럼 물리 근사는 대부분 테일러 1~2차입니다. 계산기는 sin 3을 sin(π − 3)으로 바꿔 0 근처로 끌어와 계산해요.
f(x) = Tₙ(x) + Rₙ(x), Rₙ(x) = f⁽ⁿ⁺¹⁾(c)/(n + 1)! · xⁿ⁺¹ (c는 0과 x 사이) · |f⁽ⁿ⁺¹⁾| ≤ M ⇒ |Rₙ| ≤ M|x|ⁿ⁺¹/(n + 1)!

웹툰 15화 #4 · 라그랑주 오차 한계표

예제

cos 0.2 ≈ 1 − 0.2²/2의 오차 한계를 라그랑주 공식으로 구하시오. (cos x의 3차 항은 0)

3차 항이 0이므로 T₂ = T₃이고, 나머지를 R₃으로 볼 수 있습니다. |cos⁽⁴⁾| ≤ 1이므로 |R₃| ≤ 0.2⁴/4! = 0.0016/24 ≈ 6.67×10⁻⁵입니다. 실제 cos 0.2 = 0.9800666이라 오차 6.66×10⁻⁵로 한계 이내예요. 오차 한계 약 6.67×10⁻⁵

√1.02 ≈ 1 + 0.02/2 = 1.01의 오차 한계를 구하고, 근삿값이 참값보다 큰지 작은지 판단하시오.

f(x) = √(1 + x)이면 f″(x) = −¼(1 + x)^(−3/2)이고 [0, 0.02]에서 |f″| ≤ ¼이므로 |R₁| ≤ ¼·0.02²/2 = 5×10⁻⁵입니다. f″ < 0이라 나머지가 음수이므로 1.01은 참값보다 큽니다. 실제 √1.02 ≈ 1.0099505, 오차 4.95×10⁻⁵입니다. 오차 ≤ 5×10⁻⁵, 근삿값 1.01이 참값보다 크다
