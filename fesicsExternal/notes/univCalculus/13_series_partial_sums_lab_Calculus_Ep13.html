대학 미적분학 · 웹툰 13화 「더하는 항이 0으로 가면 급수는 수렴한다?」

급수의 수렴 — 항이 0으로 가는 것은 필요조건일 뿐이다

급수를 골라 N = 10ᵏ항까지 실제로 더한 부분합 S_N을 기록했습니다. 조화급수는 N = 10, 10³, 10⁶에서 2.929, 7.485, 14.393으로 ln N + 0.5772를 따라 느리지만 끝없이 커졌고, Σ1/n²은 1.6439로, 교대 조화급수는 0.692647로 모였으며, 같은 항을 재배열한 급수는 0.3477로 절반 값에 다가갔습니다. 급수 수렴의 정의와 판정법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 급수(Σ1/n, Σ1/√n, Σn/(n + 1), Σ(−1)ⁿ⁺¹/n, Σ1/n², 재배열 1 − ½ − ¼ + ⅓ − ⅙ − ⅛ + …, Σ1/(n² + n))와 더할 항의 수 N = 10ᵏ(k = 1~6)을 정하고 N항까지 더하기를 누르면 log₁₀ N에 따른 부분합 그래프가 그려지고 S_N과 판정이 기록표에 쌓입니다. 조화급수를 k = 1, 2, 3, 6으로 기록하고 Σ1/n², 교대 조화급수, 재배열도 기록해 4개 이상 모으면 결과 비교 탭에서 S_N과 ln N의 관계, 부분합 표를 볼 수 있습니다.

표 1. N항까지의 부분합 (실험 예시)
급수NS_N판정
Σ1/n10¹2.928968발산
Σ1/n10³7.485471발산
Σ1/n10⁶14.392727발산

조화급수의 항 1/n은 0으로 가지만 부분합은 S_N ≈ ln N + 0.5772로 느리게 무한히 커집니다. 적분 판정으로 Σ1/n과 ∫₁^∞ 1/x dx가 함께 발산하기 때문이에요. 교대 조화급수의 S₁₀₀₀ = 0.692647은 ln 2 ≈ 0.693147과 약 0.0005 차이로, 교대급수 오차 한계 1/1001 이하입니다. 같은 항을 양수 하나·음수 둘 순서로 더한 재배열은 ½ ln 2 ≈ 0.3466 쪽으로 가서, 조건부 수렴 급수는 더하는 순서가 합을 바꾼다는 리만의 재배열 정리를 보여 줍니다.

개념 정리

1. 급수의 합은 부분합 수열의 극한

Σaₙ = S ⇔ lim S_N = S, S_N = a₁ + a₂ + … + a_N

  • 발산 판정: aₙ ↛ 0이면 발산. “aₙ → 0”은 필요조건일 뿐 충분조건이 아닙니다(조화급수).
  • 적분 판정: aₙ = f(n), f가 양수·감소·연속이면 Σaₙ과 ∫₁^∞ f는 함께 수렴·발산. 그래서 Σ1/n은 ∫1/x처럼 발산, p-급수 Σ1/nᵖ는 p > 1일 때만 수렴.
  • 교대급수 판정: bₙ ≥ 0이 감소하며 0으로 가면 Σ(−1)ⁿ⁺¹bₙ은 수렴, 오차 ≤ b_(N+1).
  • 조건부 수렴: 교대 조화급수는 절댓값을 씌우면 발산합니다. 리만의 재배열 정리에 따르면 항의 순서만 바꿔 어떤 값으로도 수렴하게 만들 수 있어요.

2. 이 실험의 계산 방법

항을 컴퓨터로 차례대로 더합니다(최대 10⁶항). Σ1/n²의 꼬리는 적분 판정으로 S_N + 1/(N + 1)과 S_N + 1/N 사이에 가둘 수 있어요.

3. 실험 모형과 실제의 차이

· 10⁶항까지 더해도 수렴·발산은 증명되지 않습니다. 조화급수는 10⁶항에서도 14.39에 불과하지만 끝없이 커져요.

· 수렴한다는 것과 계산에 쓸 만하다는 것은 다릅니다. 4(1 − ⅓ + ⅕ − …) = π는 1000항이어도 3.1406입니다.

4. 생활 속에서 · 이어지는 개념

  • 푸리에 급수, 확률의 기댓값 Σn·pₙ, 광학 다중 반사가 모두 급수입니다. 계산 순서를 바꾸는 알고리즘을 쓰려면 절대 수렴부터 확인해요.
Σaₙ = S ⇔ lim(N→∞) S_N = S (S_N = a₁ + a₂ + ⋯ + a_N) · aₙ ↛ 0 ⇒ 발산 (역은 성립하지 않음)

예제

Σ(n = 1 ~ ∞) 1/(n² + n)의 수렴 여부를 판정하고 합을 구하시오.

1/(n² + n) ≤ 1/n²이고 Σ1/n²이 수렴하므로 비교 판정으로 수렴합니다. 부분분수로 1/n − 1/(n + 1)이라 S_N = 1 − 1/(N + 1) → 1입니다. 실험의 S₁₀₀₀ = 0.999001도 1 − 1/1001과 같아요. 수렴, 합 1

Σ1/n²을 N = 10항에서 끊고 적분 판정으로 꼬리를 보정할 때 참값의 범위를 구하시오. (S₁₀ ≈ 1.549768)

나머지 Σ(n > 10) 1/n²은 ∫₁₁^∞ dx/x² = 1/11과 ∫₁₀^∞ dx/x² = 1/10 사이에 있습니다. 따라서 1.549768 + 0.090909 = 1.640677과 1.549768 + 0.1 = 1.649768 사이이고, π²/6 ≈ 1.644934가 그 안에 있습니다. 1.640677 ≤ π²/6 ≤ 1.649768
