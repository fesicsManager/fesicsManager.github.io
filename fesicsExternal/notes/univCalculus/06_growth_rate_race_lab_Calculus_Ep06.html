대학 미적분학 · 웹툰 6화 「0/0이면 일단 로피탈?」

로피탈 정리와 증가율 — 누가 결국 이기는지는 말하지만 언제인지는 말하지 않는다

두 함수를 골라 x = 10³ ~ 10²⁰에서 값을 자연로그로 바꿔 비교하고 앞선 쪽을 기록했습니다. x^0.1은 x = 10¹⁵까지 ln x에 졌다가 10¹⁶에서야 39.8 대 36.8로 앞섰고, (x + sin x)/x는 1로 모이는데 로피탈 식 1 + cos x는 0.16, 1.86, 0.0006으로 흔들렸습니다. 로피탈 정리의 가정과 한 방향성, 로그 < 거듭제곱 < 지수의 증가율 순서를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 비교할 두 함수(x^0.1 대 ln x, x 대 100 ln x, x¹⁰ 대 eˣ, (x + sin x)/x 대 로피탈 식 (1 + cos x)/1)와 x(10 ~ 10²⁰)를 고르고 비교하기를 누르면 log₁₀ x에 따른 log₁₀(비율) 그래프에 역전 지점이 표시되고 두 값과 앞선 쪽이 기록표에 쌓입니다. x^0.1 대 ln x를 x = 10³, 10¹⁰, 10¹⁵, 10¹⁶, 10²⁰에서 기록하고 (x + sin x)/x도 두세 번 기록해 4개 이상 모으면 결과 비교 탭에서 증가율 비교표를 볼 수 있습니다.

로피탈 정리로 lim ln x / x^0.1 = lim 10/x^0.1 = 0이므로 x^0.1이 결국 이기지만, 두 번째 역전은 x ≈ 3.43×10¹⁵에서야 일어납니다. (x + sin x)/x = 1 + (sin x)/x는 |sin x/x| ≤ 1/x 덕분에 1에 모이는데, 위아래를 미분한 (1 + cos x)/1은 0과 2 사이를 오갑니다. 로피탈은 f′/g′의 극한이 있을 때만 f/g의 극한을 알려 주는 한 방향 정리라서, 이 경우에는 아무 말도 하지 않습니다.

개념 정리

1. 로피탈은 한 방향 정리

lim f = lim g = 0 (또는 ±∞), 근처에서 g′ ≠ 0, lim f′/g′ = L이 존재 ⇒ lim f/g = L

“f′/g′의 극한이 있으면 f/g의 극한도 같다”는 뜻이지, 거꾸로가 아닙니다. (x + sin x)/x의 로피탈 식 (1 + cos x)/1은 진동하지만, 원래 식은 1 + (sin x)/x → 1입니다.

2. 증가율 순서: 로그 < 거듭제곱 < 지수

lim ln x / x^0.1 = lim (1/x)/(0.1·x^−0.9) = lim 10/x^0.1 = 0. 그래서 x^0.1이 결국 이기지만, 역전은 x ≈ 3.43×10¹⁵에서야 일어납니다.

3. 이 실험의 계산 방법

큰 수가 넘치지 않도록 모든 값을 자연로그로 바꿔 비교합니다. 예: ln(x¹⁰) = 10 ln x, ln(eˣ) = x. 역전 지점은 ln(왼쪽) − ln(오른쪽) = 0을 이분법으로 풀었습니다.

4. 실험 모형과 실제의 차이

· 극한은 “결국”만 말합니다. 알고리즘 복잡도에서도 실제 입력 크기에서 상수와 지수를 함께 봐야 해요.

· 1^∞, 0⁰, ∞⁰, ∞ − ∞, 0·∞는 모양만 보고 값을 정할 수 없는 부정형이라, 로그나 통분으로 0/0, ∞/∞ 꼴로 바꾼 뒤에 로피탈을 씁니다.

lim f = lim g = 0 (또는 ±∞), 근처에서 g′ ≠ 0, lim f′/g′ = L 존재 ⇒ lim f/g = L

닥터 이안

“로피탈은 ‘f′/g′의 극한이 있으면 f/g의 극한도 같다’는 한 방향 정리다. 뭉치는 반대로 썼다.”

웹툰 6화 #2 · 로피탈 정리 판서

예제

lim(x→0⁺) x ln x를 구하시오. 어떤 꼴로 바꿔야 로피탈을 쓸 수 있는가?

0·(−∞) 꼴이므로 ln x / (1/x)로 바꾸면 −∞/∞ 꼴이 됩니다. 위아래를 미분하면 (1/x)/(−1/x²) = −x → 0이므로 극한은 0입니다. 로그가 0으로 가는 x를 이기지 못한다는 증가율 비교의 결과예요.

lim(x→∞) (1 + 1/x)^x를 로그와 로피탈로 구하시오.

로그를 씌우면 x·ln(1 + 1/x) = ln(1 + 1/x)/(1/x)로 0/0 꼴입니다. 위아래를 미분하면 [(−1/x²)/(1 + 1/x)]/(−1/x²) = 1/(1 + 1/x) → 1이므로 원래 극한은 e¹ = e ≈ 2.718282입니다. x = 1000에서도 2.716924로 아직 다가가는 중이에요.
