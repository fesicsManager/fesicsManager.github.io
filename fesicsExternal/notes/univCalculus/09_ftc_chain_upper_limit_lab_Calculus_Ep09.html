대학 미적분학 · 웹툰 9화 「적분하고 미분하면 원래대로, 끝?」

미적분학의 기본정리 — 위끝이 g(x)이면 f(g(x))·g′(x)

F(x) = ∫₁^g(x) √(1 + t³) dt를 심프슨 공식으로 수치 적분하고 중앙 차분으로 미분해 정리의 값, 뭉치의 값과 비교했습니다. 위끝 x², x = 1에서 수치 미분은 2.8284271로 √2 × 2 = 2√2와 일치했고, 뭉치의 √(1 + x³) = 1.4142136은 정확히 절반이었습니다. FTC 1·2의 진술과 조건, 위끝이 함수일 때의 연쇄법칙을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 적분의 위끝 g(x)(x · x² · x³), 미분할 점 x(0.5~1.5), 차분 간격 h(0.1 · 0.01 · 0.001 · 0.00001)를 정하고 수치로 미분하기를 누르면 x − h에서 x + h로 늘어나는 넓이 띠가 그려지고 수치 미분, 정리 √(1 + g(x)³)·g′(x), 뭉치 √(1 + x³)이 기록표에 쌓입니다. 위끝 x²로 x = 1에서 기록하고 위끝과 x를 바꿔 세 번 이상 더 기록하면 결과 비교 탭에서 수치 미분이 어느 공식과 맞는지 볼 수 있습니다.

위끝이 x²이면 x가 조금 변할 때 띠의 폭은 g′(x)배로 늘어나고 높이는 f(g(x))이므로 F′(x) = √(1 + x⁶)·2x입니다. h = 10⁻⁵에서 수치 미분이 정리 값과 소수 일곱째 자리까지 같았고, h = 0.1에서는 2.8673으로 차분 오차가 보입니다. 뭉치의 √(1 + x³)는 위끝이 x일 때만 맞고, x = 1에서 위끝 x²이면 절반, x³이면 3분의 1입니다. 위끝 x², x = 0.5처럼 g′(x) < 1인 곳에서는 뭉치 값이 오히려 더 큽니다.

개념 정리

1. 넓이를 쌓는 함수의 변화율은 높이

FTC 1: f가 연속, F(x) = ∫ₐˣ f(t) dt ⇒ F′(x) = f(x)

FTC 2: f가 적분 가능, G′ = f ⇒ ∫ₐᵇ f(x) dx = G(b) − G(a)

위끝이 g(x)이면: d/dx ∫ₐ^g(x) f(t) dt = f(g(x))·g′(x) — FTC 1과 연쇄법칙(4화).

그래서 F(x) = ∫₁^(x²) √(1 + t³) dt이면 F′(1) = √(1 + 1)·2 = 2√2 ≈ 2.828427이고, 뭉치의 √2는 정확히 절반입니다.

2. 이 실험의 계산 방법

F(x + h) − F(x − h) = ∫ from g(x − h) to g(x + h) √(1 + t³) dt를 심프슨 공식(200등분)으로 계산해 2h로 나눕니다.

3. 실험 모형과 실제의 차이

· FTC 1에는 “f가 그 점에서 연속”이 필요합니다. f(t) = −1 (t < 0), 1 (t ≥ 0)이면 ∫₀ˣ f = |x|라 0에서 미분이 안 돼요.

· e^(−t²), sin t/t처럼 역도함수가 초등함수로 안 나오는 경우가 많고, FTC 1은 이런 “적분으로 정의된 새 함수”를 만듭니다(정규분포 누적분포 함수, 오차함수 erf).

4. 생활 속에서 · 이어지는 개념

  • 탱크 유량 q(t)를 적분하면 저장량, 저장량을 미분하면 유량. 힘을 위치로 적분하면 일(일-에너지 정리)도 같은 구조입니다.

예제

F(x) = ∫₀ˣ (t² − 4) dt (x ≥ 0)가 최소가 되는 x와 최솟값을 구하시오.

FTC 1로 F′(x) = x² − 4이고, x = 2에서 부호가 −에서 +로 바뀌므로 최소입니다. F(2) = [t³/3 − 4t]₀² = 8/3 − 8 = −16/3입니다. x = 2에서 최솟값 −16/3

G(x) = ∫ₓ^(x²) e^(−t²) dt의 G′(1)을 구하시오.

G(x) = ∫₀^(x²) e^(−t²) dt − ∫₀ˣ e^(−t²) dt로 나누면 G′(x) = e^(−x⁴)·2x − e^(−x²)입니다. x = 1이면 2e⁻¹ − e⁻¹ = e⁻¹이므로 G′(1) = e⁻¹ ≈ 0.3679입니다. 역도함수가 식으로 없어도 도함수는 구할 수 있어요.
