멱급수의 수렴반경 — 실수에서 매끄러워도 가장 가까운 특이점에서 멈춘다

멱급수의 부분합을 원래 함수와 비교하며 x와 마지막 첨자 N을 바꿔 기록했습니다. 1/(1 + x²)의 급수는 x = 0.5에서 N = 2, 8, 16일 때 0.8125, 0.8000031, 0.80000000005로 0.8에 붙었지만, x = 1.5에서는 3.8125, 455.04, 298689.5로 함숫값 0.3077에서 멀어졌습니다. 수렴반경의 계산, 끝점 판정, 복소 특이점이 반경을 정하는 이유를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 함수와 멱급수(1/(1 + x²) = Σ(−x²)ᵏ, −ln(1 − x) = Σxⁿ/n, arctan x, eˣ), x(−2~2), 부분합의 마지막 첨자 N(2 · 4 · 8 · 10 · 16)을 정하고 부분합 계산하기를 누르면 원래 함수와 부분합 곡선, 수렴반경 띠가 그려지고 부분합·함숫값·차이가 기록표에 쌓입니다. 1/(1 + x²)을 x = 0.5와 x = 1.5에서 N = 2, 8, 16으로 기록해 4개 이상 모으면 결과 비교 탭에서 N에 따른 오차와 끝점·반경 ∞의 예를 볼 수 있습니다.

1/(1 + x²) = Σ(−x²)ᵏ는 공비 −x²인 등비급수라 |x| < 1에서만 수렴합니다. x = 0.5에서는 |공비| = 0.25라 N이 1 늘 때마다 오차가 0.25배로 줄고, x = 1.5에서는 |공비| = 2.25라 부분합이 폭발합니다. 함수는 실수 어디서나 매끄럽지만 1 + x² = 0의 근 ±i가 원점에서 거리 1에 있어서, 복소평면에서 가장 가까운 특이점이 수렴반경을 정합니다.

개념 정리

1. 수렴반경은 가장 가까운 특이점이 정한다

Σ cₙ(x − a)ⁿ, R = lim |cₙ / cₙ₊₁| (극한이 있을 때)

  • |x − a| < R: 절대 수렴 · |x − a| > R: 발산 · |x − a| = R(끝점): 따로 판정.
  • 1/(1 + x²) = Σ(−x²)ᵏ는 공비 −x²인 등비급수라 |x| < 1에서만 수렴합니다. 실수축에는 문제가 없어 보여도 1 + x² = 0의 근 ±i가 원점에서 거리 1이에요.
  • Σxⁿ/n = −ln(1 − x)는 R = 1, x = 1에서 조화급수(발산), x = −1에서 교대 조화급수(수렴) → 수렴 구간 [−1, 1).
  • eˣ = Σxⁿ/n!은 R = ∞이지만 x가 크면 항이 많이 필요합니다.

2. 이 실험의 계산 방법

부분합을 직접 더하고 원래 함수값과의 차이를 계산합니다. 반경 안 등비급수의 오차는 N이 1 늘 때마다 |공비|배씩 줄어요.

3. 실험 모형과 실제의 차이

· 끝점에서의 값은 아벨 정리가 보장합니다. 수렴하기만 하면 그 값은 안쪽에서 다가간 함수의 극한과 같아요.

· 계수 비가 정의되지 않으면 근 판정 R = 1/limsup |cₙ|^(1/n)을 씁니다.

4. 생활 속에서 · 이어지는 개념

  • 상수계수가 아닌 미분방정식(조화 진동자, 베셀 함수, 르장드르 다항식)은 해를 멱급수로 놓고 계수를 하나씩 구합니다. 수렴반경은 해가 어디까지 믿을 만한지 알려 줍니다.
Σ cₙ(x − a)ⁿ, R = lim |cₙ / cₙ₊₁| · |x − a| < R이면 절대 수렴, |x − a| > R이면 발산, |x − a| = R이면 따로 판정

웹툰 14화 #4 · 멱급수 부분합 표

예제

Σ(n = 1 ~ ∞) xⁿ/(n·3ⁿ)의 수렴반경과 수렴 구간을 구하시오.

|cₙ/cₙ₊₁| = (n + 1)·3ⁿ⁺¹/(n·3ⁿ) = 3(n + 1)/n → 3이므로 R = 3입니다. 끝점 x = 3이면 Σ1/n으로 발산, x = −3이면 Σ(−1)ⁿ/n으로 교대급수 판정에 의해 수렴합니다. R = 3, 수렴 구간 [−3, 3)

1/(1 − x) = Σxⁿ을 항별 미분해 Σnxⁿ의 합을 구하고, Σn/2ⁿ의 값을 구하시오.

|x| < 1에서 항별 미분하면 Σnxⁿ⁻¹ = 1/(1 − x)²이고, x를 곱하면 Σnxⁿ = x/(1 − x)²입니다. x = ½은 반경 안이므로 대입할 수 있고, Σn/2ⁿ = (½)/(¼) = 2입니다.
