대학 미적분학 · 웹툰 7화 「최댓값은 도함수가 0인 곳에서 나온다?」

닫힌 구간 방법 — 임계점은 후보일 뿐, 최댓값은 비교로 정한다

다섯 함수에서 ‘f′ = 0 + 이계도함수 판정’(뭉치 방식)과 ‘후보를 모두 비교’(닫힌 구간 방법)로 최댓값·최솟값을 찾아 기록했습니다. x³ − 3x의 [−3, 3]에서 뭉치 방식은 극대 2와 극소 −2를 냈지만 참은 끝점의 18과 −18이었고, |x − 1| + x에서는 아무것도 찾지 못했습니다. 극값과 최대·최소의 차이, 끝점과 미분 불가능한 점을 후보에 넣는 이유를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 함수와 정의역(x³ − 3x [−3, 3], 상자 V(x) = x(30 − 2x)² [0, 15], |x − 1| + x [−1, 3], 거리² D(x) = x² + (x² − 3)² [−2, 2], 밭 둘레 P(x) = 2x + 200/x (0, ∞))과 찾는 방법(뭉치 방식 · 닫힌 구간 방법)을 고르고 최댓값 찾기를 누르면 후보점과 그 방법이 고른 답이 그려지고 최댓값·최솟값과 참과의 일치 여부가 기록표에 쌓입니다. x³ − 3x를 두 방법으로 모두 기록하고 |x − 1| + x와 상자 V도 기록해 4개 이상 모으면 결과 비교 탭에서 방법별 정답률을 볼 수 있습니다.

표 1. 두 방법으로 찾은 최댓값·최솟값 (실험 예시)
함수방법최댓값최솟값참과 같음
x³−3x뭉치2−2아니오
x³−3x닫힌 구간18−18예
상자 V뭉치2000못 찾음아니오
상자 V닫힌 구간20000예
|x−1|+x뭉치못 찾음못 찾음아니오
|x−1|+x닫힌 구간51예

x³ − 3x의 후보는 끝점 −3, 3과 임계점 ±1이고 값은 −18, 18, 2, −2입니다. 뭉치 방식은 극대 2와 극소 −2를 최대·최소로 착각했습니다. 상자 V는 끝점 값이 0이라 내부 임계점 x = 5의 2000이 최대가 되었지만, 이것도 비교해 봐야 아는 결과입니다. |x − 1| + x는 (−1, 1)에서 평평하고 x = 1에서 꺾여 이계도함수 판정이 아무것도 고르지 못했으므로, 미분 불가능한 점과 끝점까지 후보에 넣고 값을 비교해야 합니다.

개념 정리

1. 임계점은 후보일 뿐, 판정은 비교로

[a, b]에서 연속인 f의 최댓값 = max{ f(임계점), f(미분 불가능한 점), f(a), f(b) }

  • 2화의 최대최소 정리가 최댓값이 “있다”를 보장하고, 페르마 정리가 “내부라면 임계점”으로 좁혀 줍니다.
  • 끝점은 페르마 정리의 대상이 아니라 따로 비교해야 합니다. x³ − 3x의 극대 2는 [−3, 3]의 최댓값 18(x = 3)이 아니에요.
  • 열린 구간이면 끝점 대신 끝 쪽 극한을 봅니다. 둘레 P(x) = 2x + 200/x는 양 끝에서 무한히 커지므로 x = 10이 최소입니다.
  • 이계도함수 판정은 f″ = 0이면 아무것도 말하지 않습니다(x⁴, −x⁴, x³).

2. 이 실험의 계산 방법

각 함수의 f′ = 0인 점, 미분 불가능한 점, 끝점을 미리 구해 함숫값을 계산하고 크기를 비교합니다.

3. 실험 모형과 실제의 차이

· 실제 공학 최적화는 변수가 수백 개이고 제약 조건이 붙습니다. 그건 다변수 미적분의 라그랑주 승수법으로 이어져요.

4. 생활 속에서 · 이어지는 개념

  • 상자 부피 최대화, 울타리 길이 최소화, 빛이 가장 짧은 시간 경로를 택한다는 페르마의 원리(스넬의 법칙)가 모두 이 방법입니다.

웹툰 7화 #4 · 포물선까지 최단 거리

예제

점 (0, 3)에서 포물선 y = x²까지의 최단 거리를 구하시오. (거리의 제곱 D(x) = x² + (x² − 3)²)

D′(x) = 2x + 4x(x² − 3) = 2x(2x² − 5) = 0에서 x = 0 또는 x = ±√10/2입니다. D(0) = 9, D(±√10/2) = 5/2 + 1/4 = 11/4이고, |x| → ∞이면 D → ∞이므로 최솟값은 11/4입니다. 최단 거리 √11/2 ≈ 1.6583 (x = ±√10/2) — 꼭짓점 쪽 x = 0은 오히려 극대예요.

넓이 100 m²인 직사각형 밭의 둘레 P(x) = 2x + 200/x (x > 0)의 최솟값을 구하시오.

P′(x) = 2 − 200/x² = 0에서 x = 10, P(10) = 40입니다. 정의역이 열린 구간이라 끝점 대신 끝 쪽 극한을 보면 x → 0⁺과 x → ∞에서 모두 P → ∞이므로 x = 10이 최소입니다. 가로 10 m일 때 최소 둘레 40 m
