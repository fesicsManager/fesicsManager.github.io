대학 미적분학 · 웹툰 4화 「역함수의 미분계수는 1/f′(x)?」

역함수 정리 — (f⁻¹)′(b)는 b = f(a)인 a에서 1/f′(a)

f(x) = x³ + x + 1의 역함수 g를 식 없이 수치로 풀어 (g(b + Δ) − g(b))/Δ를 계산하고, 정리의 1/f′(a)와 뭉치의 1/f′(b)를 비교했습니다. b = 3에서 Δ를 0.1 → 0.0001로 줄이면 수치 미분이 0.2454 → 0.249995로 1/f′(1) = 0.25에 다가갔고 1/f′(3) = 1/28 ≈ 0.0357과는 멀었습니다. 역함수 정리와 연쇄법칙에서 ‘어느 점에서’ 계산하는지를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 역함수를 미분할 점 b(3 · 1 · 11 · −1)와 차분 간격 Δ(0.1 · 0.01 · 0.001 · 0.0001)를 고르고 수치로 미분하기를 누르면 x³ + x + 1 = b + Δ를 뉴턴법으로 풀어 수치 미분값을 내고, 정리 1/f′(a)와 뭉치 1/f′(b)를 함께 기록표에 쌓습니다. b = 3에서 Δ를 0.1, 0.01, 0.001로 바꿔 기록하고 다른 b도 한 번 이상 기록해 4개 이상 모으면 결과 비교 탭에서 어느 공식과 맞는지, Δ에 따라 오차가 어떻게 줄어드는지 볼 수 있습니다.

개념 정리

1. 공식에는 “어느 점에서”가 붙어 있다

역함수 정리: f가 a 근처에서 C¹, f′(a) ≠ 0, b = f(a) ⇒ (f⁻¹)′(b) = 1/f′(a)

연쇄법칙: (F∘g)′(x) = F′(g(x))·g′(x) — 바깥 함수의 미분은 안쪽 값 g(x)에서 합니다.

f(x) = x³ + x + 1이면 f′(x) = 3x² + 1 > 0이라 역함수가 있고, f(1) = 3이므로 g(3) = 1, g′(3) = 1/f′(1) = 1/4입니다. 뭉치의 1/f′(3) = 1/28은 x 자리에 y 값을 넣은 실수예요.

2. 이 실험의 계산 방법

뉴턴법으로 x³ + x + 1 = y를 풀어 g(y)를 구하고 (g(b + Δ) − g(b))/Δ를 계산합니다. 앞쪽 차분이라 오차는 대략 Δ에 비례해 줄어요.

3. 실험 모형과 실제의 차이

· 수치 차분은 Δ가 너무 작으면 반올림 오차가 커집니다. 여기 고른 Δ(10⁻⁴ 이상)에서는 문제가 없어요.

· f′(a) = 0인 점(예: x³의 원점)에서는 역함수 기울기가 수직이 되어 정리를 쓸 수 없습니다.

4. 생활 속에서 · 이어지는 개념

  • arcsin, arctan, ln의 도함수가 모두 역함수 정리에서 나옵니다. 관련 변화율(풍선 부피 dV/dt = dV/dr · dr/dt)도 연쇄법칙이에요.

웹툰 4화 #4 · 역함수 수치 미분

예제

q(x) = (x² + 1)³의 x = 1에서의 미분계수를 연쇄법칙으로 구하고, 바깥 함수를 안쪽 값 대신 x에서 미분한 실수의 값과 비교하시오.

바깥 F(u) = u³, 안쪽 g(x) = x² + 1이므로 q′(1) = F′(g(1))·g′(1) = 3·2²·2 = 24입니다. 안쪽 값 대신 x를 넣으면 F′(1)·g′(1) = 3·1·2 = 6이 나와 틀립니다. 수치 중앙 차분도 24.000000이에요. q′(1) = 24 (실수는 6)

곡선 x³ + y³ = 6xy 위의 점 (3, 3)에서 접선의 기울기를 음함수 미분으로 구하시오.

27 + 27 = 54 = 6·3·3이므로 점이 곡선 위에 있습니다. 양변을 x로 미분하면 3x² + 3y²y′ = 6y + 6xy′, 정리하면 y′ = (6y − 3x²)/(3y² − 6x)입니다. (3, 3)을 넣으면 (18 − 27)/(27 − 18) = −1입니다.
