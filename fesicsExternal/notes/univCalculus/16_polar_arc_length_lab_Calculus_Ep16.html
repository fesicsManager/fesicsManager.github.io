대학 미적분학 · 웹툰 16화 「극좌표 넓이는 ∫ r dθ, 한 바퀴 돌면 끝?」

호의 길이와 극좌표 넓이 — 내접 다각형의 극한과 ½∫r²dθ

곡선 위에 점을 찍어 선분으로 이은 내접 다각형의 길이를 선분 4 ~ 256개로 늘려 가며 참 길이와 비교하고, 극곡선의 넓이 ½∫r²dθ도 기록했습니다. 심장형 r = 1 + cos θ는 6.4721 → 7.9995로 8에 다가가 뭉치의 2π ≈ 6.28보다 훨씬 길었고, 원 r = 2cos θ를 0~2π로 돌리면 넓이가 π가 아닌 2π로 두 번 칠해졌습니다. 길이·넓이 공식과 ‘한 번 그리는 범위’를 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 곡선(심장형 r = 1 + cos θ, 원 r = 2cos θ, 사이클로이드, 타원 x = 2cos t·y = sin t, x = t²·y = t³), 다각형의 선분 수(점은 선분 수 + 1개)(4 · 8 · 16 · 64 · 256), 극곡선의 θ 범위(곡선을 한 번 그리는 범위 · 0 ~ 2π 한 바퀴 전부)를 고르고 다각형으로 재기를 누르면 곡선과 내접 다각형, 극곡선의 부채꼴 넓이가 그려지고 다각형 길이·참 길이·넓이가 기록표에 쌓입니다. 심장형을 선분 4, 16, 64, 256개로 기록하고 원 r = 2cos θ를 두 범위로 기록해 4개 이상 모으면 결과 비교 탭에서 다각형 길이의 오차와 다른 곡선들을 볼 수 있습니다.

내접 다각형의 선분은 곡선의 현이라 다각형 길이는 언제나 참 길이보다 짧고, 선분을 늘리면 √(r² + r′²) = 2|cos(θ/2)|를 적분한 8로 다가갑니다. 넓이는 부채꼴 조각 ½r²Δθ의 합이라 ½∫₀^2π (1 + cos θ)² dθ = 3π/2 ≈ 4.7124이고, 단위가 길이인 ∫r dθ는 넓이가 될 수 없습니다. 원 r = 2cos θ는 θ ∈ [0, π]에서 이미 한 번 다 그려지므로, 0~2π로 돌리면 길이 4π·넓이 2π로 두 번 센 값이 나옵니다.

개념 정리

1. 길이는 내접 다각형 길이의 극한

L = ∫ √(x′² + y′²) dt = ∫ √(r² + r′²) dθ, 극좌표 넓이 A = ½∫ r² dθ

  • 극좌표의 작은 조각은 직사각형이 아니라 부채꼴이라 넓이가 ½r²Δθ입니다. ∫r dθ는 단위가 길이라 넓이가 될 수 없어요.
  • 심장형 r = 1 + cos θ: r² + r′² = 2 + 2cos θ = 4cos²(θ/2) → L = ∫₀^2π 2|cos(θ/2)| dθ = 8. 절댓값 때문에 앞 절반의 2배로 계산.
  • 원 r = 2cos θ는 0 ≤ θ ≤ π에서 이미 한 번 다 그려집니다(π/2 < θ < 3π/2에서 r < 0이라 반대편에 찍힘). 0~2π로 계산하면 넓이 2π — 두 번 칠한 값.
  • 사이클로이드 한 아치의 길이 8, 아래 넓이 3π. 타원 x = 2cos t, y = sin t의 둘레는 초등함수로 안 풀려 수치로 약 9.6884.

2. 이 실험의 계산 방법

매개변수 구간을 n등분한 점을 이은 다각형 길이 Σ|Pᵢ − Pᵢ₋₁|, 참 길이는 속력 √(x′² + y′²)를 심프슨 공식으로 적분합니다. 다각형 길이의 오차는 대략 1/n²에 비례해 줄어요.

3. 실험 모형과 실제의 차이

· “한 바퀴 2π”가 아니라 “곡선을 정확히 한 번 그리는 범위”를 먼저 찾아야 합니다.

· 길이가 끝점 사이 직선 거리보다 짧게 나오면 계산이 틀린 것입니다(검산 기준).

예제

매개곡선 x = t², y = t³ (0 ≤ t ≤ 1)의 길이를 구하시오.

x′ = 2t, y′ = 3t²이므로 속력은 √(4t² + 9t⁴) = t√(4 + 9t²) (t ≥ 0)입니다. u = 4 + 9t², du = 18t dt로 치환하면 L = (1/18)∫₄¹³ √u du = (1/27)[u^(3/2)]₄¹³ = (13√13 − 8)/27입니다. 약 1.4397로, 끝점 사이 직선 거리 √2 ≈ 1.4142보다 조금 길어 합리적이에요.

사이클로이드 x = t − sin t, y = 1 − cos t의 한 아치(0 ≤ t ≤ 2π) 길이와 아치 아래 넓이를 구하시오.

x′² + y′² = (1 − cos t)² + sin²t = 2 − 2cos t = 4sin²(t/2)이므로 L = ∫₀^2π 2sin(t/2) dt = [−4cos(t/2)]₀^2π = 8입니다. 넓이는 ∫₀^2π y·x′ dt = ∫₀^2π (1 − cos t)² dt = 2π + π = 3π입니다. 길이 8, 넓이 3π ≈ 9.4248 — 바퀴 넓이 π의 정확히 3배예요.
