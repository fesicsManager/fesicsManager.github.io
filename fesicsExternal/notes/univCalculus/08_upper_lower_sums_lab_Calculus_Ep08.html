대학 미적분학 · 웹툰 8화 「적분은 넓이 공식 아닌가」

리만 적분 — 상합과 하합의 차가 0으로 가야 적분이 존재한다

구간을 n등분해 상합 Uₙ, 하합 Lₙ, 중점 합을 계산했습니다. x²의 [0, 1]은 n = 4, 10, 100에서 Uₙ − Lₙ이 0.25, 0.1, 0.01로 1/n씩 줄었고, 계단 함수도 0.1로 줄었지만 디리클레 함수는 n과 상관없이 1로 고정됐습니다. 적분 가능성의 정의, 근사 오차가 줄어드는 속도, 부호 있는 넓이를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 함수와 구간(x² [0, 1], x [0, 2], 계단 함수 [0, 1], 디리클레 함수 [0, 1], x³ [−1, 1])과 등분 수 n(1~100)을 정하고 직사각형 쌓기를 누르면 상합·하합 직사각형과 조각의 중점이 그려지고 Lₙ, Uₙ, Uₙ − Lₙ, 중점 합이 기록표에 쌓입니다. x²를 n = 4, 10, 100으로 기록하고 계단 함수와 디리클레 함수도 한 번씩 기록해 4개 이상 모으면 결과 비교 탭에서 오차가 줄어드는 속도와 함수별 Uₙ − Lₙ을 볼 수 있습니다.

증가함수 x²에서는 조각마다 오른쪽 끝이 최대, 왼쪽 끝이 최소라 차이가 서로 지워지고 Uₙ − Lₙ = (f(1) − f(0))/n = 1/n만 남습니다. 그래서 U₁₀ − L₁₀ = 0.1이고, 뭉치가 말한 0.385는 상합 자체입니다. 중점 합의 오차는 1/3 − Mₙ = 1/(12n²)로 끝점 합보다 훨씬 빨리 줄어, n = 4의 중점 합 0.328125가 n = 100의 하합과 비슷하게 정확합니다. 디리클레 함수는 모든 조각에 유리수와 무리수가 있어 Uₙ − Lₙ = 1로 고정되므로 리만 적분이 정의되지 않습니다.

개념 정리

1. 적분은 직사각형 합의 극한으로 정의한다

Lₙ ≤ ∫f dx ≤ Uₙ, 유계인 f가 적분 가능 ⇔ lim (Uₙ − Lₙ) = 0

  • 증가함수 x²의 [0, 1]: Uₙ − Lₙ = (f(1) − f(0))/n = 1/n. 그래서 U₁₀ − L₁₀ = 0.1.
  • 계단 함수: 상합과 하합이 다른 조각은 ½이 들어 있는 조각 하나뿐 → Uₙ − Lₙ ≤ 1/n → 0, 적분값 ½.
  • 디리클레 함수(유리수 1, 무리수 0): 모든 조각에서 최대 1, 최소 0 → Uₙ − Lₙ = 1로 고정. 리만 적분 불가.

2. 이 실험의 계산 방법

증가함수는 조각의 오른쪽 끝이 최대, 왼쪽 끝이 최소입니다. 중점 합 Mₙ은 조각 가운데 높이를 씁니다. x²에서 오차는 정확히 1/3 − Mₙ = 1/(12n²), 일반적으로 오차 한계 (b − a)³·max|f″|/(24n²).

3. 실험 모형과 실제의 차이

· 컴퓨터는 무리수를 정확히 표현하지 못하므로 디리클레 함수는 “각 조각에 유리수·무리수가 모두 있다”는 사실로 계산합니다(조각의 끝점·중점은 유리수라 값 1).

· 정적분은 부호 있는 넓이입니다. ∫₋₁¹x³dx = 0이지만 그래프와 x축 사이 넓이는 ½이에요.

4. 생활 속에서 · 이어지는 개념

  • 공학 데이터는 식이 아니라 측정값 표로 옵니다. 가속도 센서 값을 시간 간격마다 더해 속도를 얻는 것이 바로 리만 합이에요.
Lₙ ≤ ∫ₐᵇ f(x) dx ≤ Uₙ, 유계인 f가 적분 가능 ⇔ lim(n→∞) (Uₙ − Lₙ) = 0

웹툰 8화 #1 · 디리클레 함수 앞에서

예제

f(x) = x, [0, 2]를 n등분한 우측 끝점 리만 합 Rₙ을 n의 식으로 구하고 n → ∞일 때의 극한을 구하시오.

조각의 폭은 2/n, k번째 높이는 2k/n이므로 Rₙ = Σ(2k/n)(2/n) = (4/n²)·n(n + 1)/2 = 2(n + 1)/n입니다. n = 10이면 2.2로 실험의 상합과 같고, Rₙ = 2(n + 1)/n → 2로 삼각형 넓이 ½·2·2 = 2와 일치합니다.

x²의 [0, 1]에서 중점 합의 오차를 10⁻⁴ 미만으로 하려면 n을 최소 얼마로 해야 하는가? (오차 = 1/(12n²))

1/(12n²) < 10⁻⁴ ⇔ n² > 10⁴/12 ≈ 833.3 ⇔ n > 28.87이므로 n = 29입니다(n = 28이면 1.06×10⁻⁴). 같은 정확도를 Uₙ − Lₙ = 1/n으로 얻으려면 n > 10⁴이 필요하니, 높이를 어디서 잡느냐가 계산량을 크게 바꿉니다.
