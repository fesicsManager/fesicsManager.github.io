미분가능성 — 연속이어도 차분몫의 극한이 없으면 미분할 수 없다

x = 0에서 연속인 다섯 함수의 오른쪽·왼쪽 차분몫을 h = 0.1, 0.01, 0.001로 줄이며 기록했습니다. |x|는 +1과 −1로 갈렸고 x·sin(1/x)는 ±0.544, ±0.506, ±0.827로 흔들렸지만, x²·sin(1/x)는 −0.0544, −0.00506, 0.000827로 |h| 이하로 눌려 0으로 갔습니다. 미분계수의 정의와 미분 가능·연속·도함수 연속의 관계를 정리합니다.

x²·sin(1/x)의 차분몫은 h·sin(1/h)라서 부호는 흔들려도 크기가 |h| 이하로 눌려 0으로 갑니다(조임 정리). 그래서 g′(0) = 0이 존재합니다. 반면 x·sin(1/x)의 차분몫 sin(1/h)는 −1과 1 사이를 계속 오가고, |x|는 오른쪽 +1, 왼쪽 −1로 갈려 둘 다 미분 불가능합니다. 다섯 함수 모두 0에서 연속이므로 연속은 미분 가능의 필요조건일 뿐입니다.

개념 정리

1. 미분계수는 차분몫의 극한

f′(a) = lim(h→0) [f(a + h) − f(a)] / h (이 극한이 존재할 때만)

  • 미분 가능 ⇒ 연속: f(a + h) − f(a) = (차분몫)·h → f′(a)·0 = 0.
  • 연속 ⇏ 미분 가능: |x|는 좌 −1, 우 +1. x·sin(1/x)의 차분몫은 sin(1/h)로 계속 진동.
  • 미분 가능 ⇏ 도함수 연속: x²·sin(1/x)의 차분몫 h·sin(1/h)는 |h| 이하로 눌려 0으로(조임 정리). 그런데 x ≠ 0에서 g′(x) = 2x·sin(1/x) − cos(1/x)는 0 근처에서 진동합니다.

h를 줄이면 보는 창도 함께 확대됩니다. x²는 곧 직선처럼 보이고 두 차분몫이 2로 모이지만, |x|는 아무리 확대해도 꺾인 채 +1과 −1로 갈립니다. x²·sin(1/x)는 끝없이 흔들려도 |h·sin(1/h)| ≤ |h|라 0으로 눌립니다(조임 정리).

2. 이 실험의 계산 방법

h = 0.1, 0.01, 0.001, 0.0001에서 오른쪽 (f(h) − f(0))/h와 왼쪽 (f(−h) − f(0))/(−h)를 그대로 계산합니다. “도함수 공식에 0을 넣을 수 없다”는 것은 극한과 함숫값을 혼동한 거예요.

3. 실험 모형과 실제의 차이

· 유한한 h 몇 개로는 극한을 증명할 수 없습니다. 표는 증명의 방향(|h·sin(1/h)| ≤ |h|)을 보여 줄 뿐이에요.

· u(x) = x + 2x²·sin(1/x)는 u′(0) = 1 > 0인데도 x = 1/(2kπ)에서 u′ = −1이라 0 근처에서 증가함수가 아닙니다.

예제

f(x) = x|x|는 x = 0에서 미분 가능한가? 가능하면 f′(0)을 구하시오.

(f(h) − f(0))/h = h|h|/h = |h|이고, h → 0⁺과 h → 0⁻ 모두에서 0으로 갑니다. 실험에서도 h = 0.01일 때 좌우 차분몫이 모두 0.0100이었어요. 미분 가능하고 f′(0) = 0입니다. |x|는 뾰족하지만 x를 곱하면 뾰족함이 펴집니다.

u(x) = x + 2x²·sin(1/x) (u(0) = 0)에 대해 u′(0)을 정의로 구하고, x = 1/(2π)에서 u′(x)의 값을 구하시오.

차분몫은 1 + 2h·sin(1/h)이고 |2h·sin(1/h)| ≤ 2|h| → 0이므로 u′(0) = 1입니다. x ≠ 0에서 u′(x) = 1 + 4x·sin(1/x) − 2cos(1/x)이고, x = 1/(2π)이면 sin 2π = 0, cos 2π = 1이라 u′ = 1 − 2 = −1입니다. u′(0) = 1, u′(1/(2π)) = −1 — 0에서 기울기가 양수여도 0 근처에서 증가함수가 아닙니다.
