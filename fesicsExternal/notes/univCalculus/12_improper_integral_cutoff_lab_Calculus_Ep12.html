대학 미적분학 · 웹툰 12화 「양수 함수를 적분했더니 −2?」

이상적분 — 잘라서 적분한 뒤 극한을 본다

무한 구간은 R = 10ᵏ까지, 터지는 점 근처는 ε = 10⁻ᵏ까지 잘라 적분하고 k를 키우며 값을 기록했습니다. ∫₁ᴿ 1/x dx는 4.6 → 13.8로 k마다 ln 10씩 끝없이 커졌고 ∫₁ᴿ x^(−3/2) dx는 1.8 → 1.998로 2에 모였으며, 뭉치가 −2라고 한 ∫₋₁¹ 1/x² dx는 k = 2에서 이미 198로 발산했습니다. 이상적분의 정의, p-적분 판정, 비교 판정을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 이상적분(① ∫₁^∞ 1/x, ② ∫₁^∞ x^(−3/2), ③ ∫₀¹ 1/x², ④ ∫₋₁¹ 1/x², ∫₀¹ 1/√x, ∫₀¹ ln x, ∫₁^∞ e^(−x²))과 자르는 위치 k(1~6, R = 10ᵏ 또는 ε = 10⁻ᵏ)를 정하고 잘라서 적분하기를 누르면 자른 범위의 넓이와 k = 1~6의 값 막대가 그려지고 잘라 낸 값과 수렴·발산 판정이 기록표에 쌓입니다. ①~④를 각각 k = 2와 k = 6으로 기록하고 나머지도 한두 번 기록해 4개 이상 모으면 결과 비교 탭에서 k에 따른 값의 변화를 볼 수 있습니다.

∫₁ᴿ 1/x dx = ln R은 R = 10⁶에서도 13.816에 불과하지만 k가 1 늘 때마다 ln 10 ≈ 2.303씩 일정하게 끝없이 커지므로 발산입니다. 반면 p = 3/2 > 1인 ②는 2 − 2/√R → 2로 수렴합니다. ④는 x = 0에서 터지므로 둘로 나눠 양쪽이 모두 수렴해야 하는데, 한쪽인 ∫₀¹ 1/x² dx부터 1/ε − 1로 발산합니다. 그래서 FTC로 얻은 −2는 의미 없는 값입니다. ln x는 0 근처에서 −∞로 가지만 −1 − ε ln ε + ε → −1로 넓이가 유한합니다.

개념 정리

1. 이상적분은 극한으로 새로 정의한다

∫₁^∞ f dx = lim(R→∞) ∫₁ᴿ f dx, ∫₀¹ f dx = lim(ε→0⁺) ∫_ε¹ f dx

  • p-적분(무한 구간): ∫₁^∞ 1/xᵖ dx는 p > 1일 때만 수렴, 값 1/(p − 1).
  • p-적분(0 근처): ∫₀¹ 1/xᵖ dx는 p < 1일 때만 수렴, 값 1/(1 − p).
  • 비교 판정: 0 ≤ f ≤ g이고 ∫g 수렴 ⇒ ∫f 수렴. x ≥ 1에서 e^(−x²) ≤ e^(−x)이고 ∫₁^∞ e^(−x) dx = e⁻¹.
  • 가운데서 터지면 그 점에서 둘로 나눠 양쪽 모두 수렴해야 수렴. 1/x²은 x = 0에서 터지므로 FTC를 쓸 수 없고, 뭉치의 −2는 의미 없는 값입니다.

2. 이 실험의 계산 방법

∫₁ᴿ 1/x = ln R, ∫₁ᴿ x^(−3/2) = 2 − 2/√R, ∫_ε¹ 1/x² = 1/ε − 1, ∫_ε¹ 1/√x = 2 − 2√ε, ∫_ε¹ ln x = −1 − ε ln ε + ε. e^(−x²)는 심프슨 공식으로 수치 적분합니다.

3. 실험 모형과 실제의 차이

· k = 6까지 본 값으로는 수렴을 증명할 수 없습니다. ln R은 R = 10⁶에서도 14가 안 되지만 R = e¹⁰⁰이면 100이에요. 느린 것과 유한한 것은 다릅니다.

· ∫₋∞^∞ x dx를 대칭으로 잘라 0을 얻는 것은 “코시 주요값”이라는 다른 개념입니다.

4. 생활 속에서 · 이어지는 개념

  • 지구 탈출 속도는 중력이 한 일 ∫ᴿ^∞ GMm/r² dr = GMm/R가 유한해서 존재합니다. 확률밀도함수의 전체 적분이 1이라는 조건도 이상적분이에요.
∫₁^∞ f dx = lim(R→∞) ∫₁ᴿ f dx · ∫₁^∞ 1/xᵖ dx는 p > 1일 때만 수렴(값 1/(p − 1)), ∫₀¹ 1/xᵖ dx는 p < 1일 때만 수렴(값 1/(1 − p))

예제

∫₀^∞ x·e^(−x) dx가 수렴함을 보이고 값을 구하시오.

부분적분으로 ∫₀ᴿ x·e^(−x) dx = [−x·e^(−x)]₀ᴿ + ∫₀ᴿ e^(−x) dx = −R·e^(−R) + 1 − e^(−R)입니다. R → ∞이면 R·e^(−R) → 0(지수가 거듭제곱을 이김), e^(−R) → 0이므로 수렴하고 값은 1입니다.

∫₁^∞ e^(−x²) dx가 수렴함을 비교 판정으로 보이고 값의 상한을 구하시오.

x ≥ 1이면 x² ≥ x이므로 0 < e^(−x²) ≤ e^(−x)이고, ∫₁^∞ e^(−x) dx = e⁻¹ ≈ 0.3679로 수렴합니다. 비교 판정으로 수렴하고 값은 0.3679 이하입니다. 실험에서 k = 6으로 수치 적분한 실제 값은 약 0.1394였어요.
