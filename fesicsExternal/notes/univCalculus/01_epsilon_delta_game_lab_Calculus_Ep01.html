대학 미적분학 · 웹툰 1화 「극한값은 그냥 대입한 값 아닌가」

극한의 ε-δ 정의 — 어떤 ε가 와도 이기는 δ가 있어야 극한이다

x² → 4에서 상대가 내민 ε = 0.01에 대해 δ를 0.01, 0.005, 0.0025, 0.002로 바꿔 가며 최악의 오차 δ(4 + δ)를 기록했습니다. 0.0025는 경계 δ* ≈ 0.0024984보다 아주 조금 커서 실패하고 0.002는 성공했으며, f(2)를 10으로 바꿔도 판정은 그대로였습니다. 극한의 ε-δ 정의, 안전한 δ를 고르는 법, 극한이 없음을 보이는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 함수와 주장하는 극한(x² → 4, f(2) = 10으로 바꾼 x², 2x + 1 → 7, sin(1/x) → 0), 상대가 내민 ε(0.5 · 0.1 · 0.01 · 0.001), 내가 고른 δ(0.01 ~ 0.001 또는 안전 공식)를 고르고 δ로 도전하기를 누르면 띠 안의 x를 하나씩 확인해 최악의 오차와 성공·실패를 판정하고 기록표에 자동으로 쌓습니다. x²에서 ε = 0.01로 두고 δ를 차례로 바꿔 4개 이상 기록하면 결과 비교 탭에서 δ별 최악 오차 표와 증폭률 그래프를 볼 수 있습니다.

x²의 오차는 |x − 2|·|x + 2| < δ(4 + δ)로 묶이므로 δ = 0.0025는 0.01000625가 되어 ε를 0.00000625만큼 넘어 실패합니다. 경계는 δ² + 4δ − 0.01 = 0의 양수 근 δ* = √4.01 − 2 ≈ 0.0024984이고, δ ≤ δ*이면 어떤 δ든 성공입니다. f(2) = 10으로 바꾼 함수도 결과가 같은 것은 정의의 0 < |x − a| 조건이 x = a 자체를 빼기 때문입니다. sin(1/x)는 어떤 δ 안에도 값이 1인 점이 있어 ε = 0.5를 이길 수 없습니다.

개념 정리

1. “한없이 가까워진다”를 게임으로

lim f(x) = L ⇔ 모든 ε > 0에 대해 어떤 δ > 0이 있어서 0 < |x − a| < δ 이면 |f(x) − L| < ε

상대가 ε를 고르고 내가 δ를 고릅니다. 어떤 ε가 와도 이길 수 있으면 극한이 L입니다. 0 < |x − a| 조건 때문에 x = a에서의 값 f(a)는 극한과 상관이 없어요. 그래서 f(2)를 10으로 바꿔도 극한은 그대로 4입니다.

2. 이 실험의 계산 방법

  • x²: |x² − 4| = |x − 2|·|x + 2|. δ 안에서 최악은 오른쪽 끝, 상한은 δ(4 + δ). 경계는 δ* = √(4 + ε) − 2.
  • 2x + 1: |2x + 1 − 7| = 2|x − 3|, 상한 2δ → δ = ε/2면 언제나 이깁니다.
  • 안전 공식: δ ≤ 1로 먼저 묶으면 |x + 2| < 5이므로 δ = min(1, ε/5).
  • sin(1/x): 어떤 δ 안에도 sin(1/x) = 1인 점과 −1인 점이 있어서, ε = 0.5를 내밀면 어떤 L도 이길 수 없습니다.

3. 실험 모형과 실제의 차이

· 최악의 오차는 구간 안에서 실제로 닿지는 않는 상한(sup)입니다. 여기서는 이 상한이 ε보다 작으면 성공으로 봅니다.

· 증명에서는 δ를 하나만 찾으면 됩니다. 가장 큰 δ를 찾을 필요는 없어요(0.001도 성공).

4. 생활 속에서 · 이어지는 개념

  • 공차 설계가 곧 ε-δ입니다. “출력 오차를 0.01 이하로 하려면 입력을 얼마나 정밀하게 가공해야 하나?”를 계산하는 일이에요.
lim(x→a) f(x) = L ⇔ ∀ε > 0 ∃δ > 0 : 0 < |x − a| < δ ⇒ |f(x) − L| < ε
뭉치 · 제로

“④! x + 2가 대충 4니까 ε/4 = 0.0025. 딱 맞잖아!” “③이요. ‘대충 4’가 아니라 x + 2의 최댓값을 써야 안전해요.”

웹툰 1화 #4 · 최악의 오차 계산

예제

lim(x→3)(2x + 1) = 7을 ε-δ로 증명하려고 한다. 임의의 ε > 0에 대해 쓸 수 있는 δ를 ε의 식으로 구하고, ε = 0.01일 때의 δ를 쓰시오.

|(2x + 1) − 7| = 2|x − 3|이므로 0 < |x − 3| < δ이면 오차는 2δ보다 작습니다. δ = ε/2로 잡으면 2|x − 3| < 2·(ε/2) = ε가 되어 어떤 ε에도 이깁니다. ε = 0.01이면 δ = ε/2 = 0.005이고, 기울기 2가 곧 오차의 증폭률입니다.

lim(x→2) x² = 4에서 ε = 0.001이 주어졌다. 안전 공식 δ = min(1, ε/5)으로 고른 δ와 그때의 최악 오차 δ(4 + δ)를 구하고 성공 여부를 판정하시오.

δ = min(1, 0.001/5) = 0.0002입니다. 최악 오차는 0.0002 × 4.0002 = 0.00080004로 0.001보다 작습니다. δ ≤ 1이면 |x + 2| < 5이므로 오차가 5δ = ε보다 작다는 것이 공식의 근거예요. δ = 0.0002, 최악 오차 0.00080004 < 0.001 → 성공
