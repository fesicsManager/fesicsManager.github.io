중간값 정리와 최대최소 정리 — 닫힌 구간과 연속이 함께 있어야 한다

네 함수의 구간을 2ⁿ칸 격자로 나눠 가장 큰 값을 찾고, n을 늘렸을 때 그 값이 그대로인지 기록했습니다. 닫힌 구간에서 연속인 x²은 4로 고정됐지만 (0, 1)의 x는 0.9375 → 0.99976처럼 1에 다가가기만 했고, 1/x는 끝없이 커졌습니다. 이분법으로 x³ − x − 1 = 0의 근을 가두며 두 정리의 조건과 반복 횟수 계산을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 함수와 구간(① x² [−1, 2], ② 1/x (0, 1], ③ x (0, 1), ④ tan x [0, π/2), ⑤ 이분법 x³ − x − 1 = 0)과 단계 수 n(1~20, 격자 2ⁿ칸 또는 이분법 n회)을 정하고 탐색하기를 누르면 찾은 가장 큰 값과 한 단계 더 촘촘한 격자의 값(⑤는 구간 길이와 남은 구간)이 기록표에 쌓입니다. ①~④를 n = 4와 n = 12로, ⑤를 n을 바꿔 두세 번 기록해 4개 이상 모으면 결과 비교 탭에서 최댓값 판정 표와 이분법의 기울기를 볼 수 있습니다.

개념 정리

1. 두 정리 모두 “닫힌 구간 + 연속”

  • 중간값 정리: f가 [a, b]에서 연속이면 f(a)와 f(b) 사이의 모든 값을 어딘가에서 갖는다.
  • 최대최소 정리: f가 [a, b]에서 연속이면 최댓값과 최솟값을 반드시 갖는다.

1/x는 x = 0에서 정의되지 않아 [−1, 1]에서 연속이 아니므로 1/x = 0인 점이 없어도 정리와 모순이 아닙니다. (0, 1)의 x는 1에 다가가지만 1이 구간 밖이라 최댓값이 없어요.

2. 이 실험의 계산 방법

격자점 xₖ = a + k(b − a)/2ⁿ 중 구간에 들어가는 점만 계산하고, 한 단계 더 촘촘한 격자(n + 1)의 값과 비교합니다.

이분법: 중점 m의 부호로 반쪽을 고름, n회 후 구간 길이 = 1/2ⁿ — 오차 10⁻⁶을 보장하려면 1/2ⁿ < 10⁻⁶, n ≥ 20.

3. 실험 모형과 실제의 차이

· 격자 탐색은 “최댓값이 없음”을 증명하지 못하고 보여 줄 뿐입니다. 증명은 상한(1)이 구간 밖이라는 논리로 합니다.

· 중간값 정리의 진짜 근거는 실수의 완비성입니다. 유리수만 있는 세계에서는 x² − 2 = 0의 근(√2)이 “구멍”이라 정리가 깨져요.

웹툰 2화 #4 · 이분법 반복표

예제

방정식 x⁵ + x − 1 = 0이 (0, 1)에서 근을 정확히 하나 가짐을 보이시오.

g(x) = x⁵ + x − 1은 다항식이라 연속이고 g(0) = −1 < 0, g(1) = 1 > 0이므로 중간값 정리로 근이 존재합니다. g′(x) = 5x⁴ + 1 > 0이라 g는 증가함수이므로 근은 하나뿐입니다. (0, 1)에 근이 정확히 하나(약 0.7549)

구간 [1, 2]에서 이분법을 쓸 때 근의 오차를 10⁻³ 미만으로 보장하려면 최소 몇 번 반복해야 하는가?

n회 후 구간 길이는 1/2ⁿ이고, 근과 구간 안의 어느 점의 차이도 이 길이보다 작습니다. 1/2ⁿ < 10⁻³ ⇔ 2ⁿ > 1000이고 2⁹ = 512, 2¹⁰ = 1024이므로 10번입니다. 반복 횟수를 계산 전에 미리 알 수 있다는 것이 이분법의 장점이에요.
