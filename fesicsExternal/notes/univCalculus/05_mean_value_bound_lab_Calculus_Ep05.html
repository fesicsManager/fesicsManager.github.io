평균값 정리 — f′의 범위가 f(b) − f(a)의 범위를 정한다

f(0) = 1인 여러 모양의 함수를 그려 f(2)와 상한 1 + 2M을 비교했습니다. M = 3에서 직선은 상한 7을 정확히 달성했고, 완만해지는 곡선과 가팔라지는 곡선은 4에 그쳤으며, 중간에 솟는 봉우리는 10으로 상한을 넘었지만 f′의 최댓값이 M을 넘어 조건을 어긴 함수였습니다. 평균값 정리의 가정과, c를 몰라도 범위를 얻는 쓰임을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 f(0) = 1인 함수의 모양(직선, 처음 가파르고 점점 완만, 천천히 출발해 점점 가파름, 중간에 확 솟는 봉우리, x = 1에서 꺾인 산)과 도함수의 상한 M(1~4)을 정하고 함수 그려 보기를 누르면 할선, 할선과 평행한 접선(평균값 정리의 c), f′ > M인 구간이 그려지고 f(2)·상한·조건 충족 여부·c가 기록표에 쌓입니다. 직선을 M = 1, 2, 3으로, 다른 모양들을 M = 3으로 기록해 4개 이상 모으면 결과 비교 탭에서 f(2)와 상한 1 + 2M을 비교할 수 있습니다.

f′ ≤ M을 지킨 모양은 모두 f(2) ≤ 1 + 2M이었고, 직선 f = 1 + Mx가 상한을 정확히 달성합니다. 봉우리는 f(2) = 10으로 상한 7을 넘었지만 f′의 최댓값이 3 + 0.75π ≈ 5.36이라 가정 f′ ≤ 3을 어긴 함수입니다. 꺾인 산은 x = 1에서 미분 불가능해 할선 기울기 0과 같은 접선(c)이 없습니다. 정리의 힘은 c의 위치가 아니라 f′의 범위만으로 f의 범위를 주는 데 있습니다.

개념 정리

1. 정리의 힘은 결론의 쓰임에 있다

f가 [a, b]에서 연속, (a, b)에서 미분 가능 ⇒ f′(c) = (f(b) − f(a))/(b − a)인 c ∈ (a, b)가 있다

c가 어디인지 몰라도 f′의 범위만 알면 f의 범위가 나옵니다.

m ≤ f′(x) ≤ M ⇒ m(b − a) ≤ f(b) − f(a) ≤ M(b − a)

그래서 f(0) = 1, f′ ≤ 3이면 f(2) ≤ 1 + 3·2 = 7이고, f(x) = 3x + 1이 그 값을 실제로 달성합니다.

2. 이 실험의 계산 방법

  • 각 모양의 f′을 0~2에서 촘촘히 계산해 최댓값이 M 이하인지 확인합니다.
  • f′(c) = 할선 기울기인 c를 구간 안에서 수치로 찾습니다(부호가 바뀌는 곳을 이분법으로).
  • |x|처럼 꺾인 함수는 가정 “미분 가능”이 깨져 할선과 평행한 접선이 없습니다.

3. 실험 모형과 실제의 차이

· 여기 함수 모양은 정리를 보여 주려고 고른 예입니다. 정리는 모양과 상관없이 모든 함수에 성립합니다.

· 벡터값 함수에서는 그대로 성립하지 않습니다(원운동은 변위 0인데 속도가 한 번도 0이 아님).

4. 생활 속에서 · 이어지는 개념

  • 구간 단속: 10 km를 5분에 지났다면 평균 120 km/h이고, 어느 순간 계기판이 정확히 120을 가리켰습니다. 측정 오차 분석에서 출력 오차의 상한을 |f′|의 최댓값으로 잡는 것도 같은 정리예요.

웹툰 5화 #4 · √101을 범위로 가두기

예제

평균값 정리로 √101의 범위를 구하시오. (f(x) = √x, 구간 [100, 101])

√101 − √100 = 1/(2√c)·1인 c ∈ (100, 101)이 있습니다. 10 < √c < 10.5이므로 1/21 < 1/(2√c) < 1/20, 즉 0.047619 < √101 − 10 < 0.05입니다. 10.0476 < √101 < 10.05 (실제 10.049876)

모든 x > 0에 대해 ln(1 + x) < x임을 평균값 정리로 보이고, x = 0.5에서 두 값을 비교하시오.

f(t) = ln(1 + t)를 [0, x]에 적용하면 ln(1 + x) − 0 = x/(1 + c)인 c ∈ (0, x)가 있습니다. c > 0이라 1/(1 + c) < 1이므로 ln(1 + x) < x입니다. x = 0.5이면 ln 1.5 ≈ 0.4055 < 0.5입니다.
