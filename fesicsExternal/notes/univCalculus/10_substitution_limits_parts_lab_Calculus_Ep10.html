치환적분과 부분적분 — 구간도 함께 옮기고 경계항을 빠뜨리지 않는다

네 정적분을 흔한 실수, 올바른 계산, 중점 1000등분 수치 적분으로 계산해 비교했습니다. ∫₀² x·e^(x²) dx는 구간을 그대로 둔 실수가 3.1945, 올바른 값과 수치 값이 26.7991·26.7990이었고, ∫₀^π x·sin x dx는 경계항을 빠뜨리면 0, 올바르게는 π였습니다. 두 기법이 어떤 미분 공식의 역인지와 정적분에서의 주의점을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 정적분(∫₀² x·e^(x²) dx, ∫₀¹ x/√(1 + x²) dx, ∫₀^π x·sin x dx, ∫₁^e ln x dx)과 계산 방법(흔한 실수 · 올바른 계산 · 수치 적분)을 고르고 세 방법으로 계산을 누르면 x의 세계와 u의 세계(부분적분이면 경계항·남은 적분 막대)가 그려지고 값·올바른 값·차이가 기록표에 쌓입니다. ∫₀² x·e^(x²) dx를 세 방법으로 모두 기록하고 부분적분 하나도 실수·올바른 계산으로 기록해 4개 이상 모으면 결과 비교 탭에서 방법별 값과 부분적분 점화식을 볼 수 있습니다.

u = x²로 치환하면 x가 0 → 2로 갈 때 u는 0 → 4로 움직이므로 ½∫₀⁴ eᵘ du = (e⁴ − 1)/2 ≈ 26.7991이고, 구간을 0 → 2로 둔 값 3.1945는 8배 넘게 작습니다. 수치 적분 26.7990이 올바른 값을 확인해 줍니다. 부분적분에서는 ∫₀^π x·sin x dx의 남은 적분 ∫₀^π cos x dx가 0이라 경계항 [−x·cos x]₀^π = π가 답 전체이고, ∫₁^e ln x dx도 경계항 e를 빼먹으면 −(e − 1) ≈ −1.7183이라는 엉뚱한 값이 나옵니다.

개념 정리

1. 미분 공식을 거꾸로 읽은 것

치환: ∫ₐᵇ f(g(x))·g′(x) dx = ∫ from g(a) to g(b) f(u) du (연쇄법칙 + FTC)

부분적분: ∫ₐᵇ u dv = [uv]ₐᵇ − ∫ₐᵇ v du (곱의 미분 + FTC)

치환은 “x의 세계”에서 “u의 세계”로 옮겨 가는 것입니다. 식만 옮기고 구간을 남겨 두면 두 세계가 섞여요. ∫₀² x·e^(x²) dx에서 u = x²이면 u의 구간은 0² = 0부터 2² = 4까지입니다.

2. 이 실험의 계산 방법

  • 올바른 값: (e⁴ − 1)/2, √2 − 1, π, 1.
  • 수치 적분: 중점 규칙 1000등분 Σ f(중점)·Δx.
  • u 고르기: 미분하면 단순해지는 쪽을 u로(다항식, 로그, 역삼각함수), 지수·삼각함수는 dv로.

3. 실험 모형과 실제의 차이

· 정적분 치환에는 g′이 구간에서 연속이라는 조건이 필요합니다.

· 수치 적분은 오차가 있습니다(중점 1000등분의 오차는 대략 (b − a)·h²/24·f″의 평균, 여기서는 10⁻⁴ 정도).

4. 생활 속에서 · 이어지는 개념

  • 부분적분은 물리에서 “미분을 옮기는” 도구입니다. 양자역학의 연산자 옮기기, 고체역학의 약형식에서 경계항이 0이 되는 조건이 물리적 경계 조건이 돼요.
치환: ∫ₐᵇ f(g(x))·g′(x) dx = ∫ f(u) du (u는 g(a)부터 g(b)까지) · 부분적분: ∫ₐᵇ u dv = [uv]ₐᵇ − ∫ₐᵇ v du

웹툰 10화 #2 · 치환과 부분적분 판서

예제

∫₀¹ x²eˣ dx를 부분적분으로 구하시오.

u = x², dv = eˣ dx로 두면 [x²eˣ]₀¹ − 2∫₀¹ xeˣ dx이고, 다시 부분적분하면 ∫₀¹ xeˣ dx = [xeˣ − eˣ]₀¹ = 1입니다. 따라서 e − 2·1 = e − 2, 한꺼번에 쓰면 [(x² − 2x + 2)eˣ]₀¹ = e − 2입니다. e − 2 ≈ 0.7183

∫ eˣ sin x dx를 부분적분 두 번으로 구하시오.

I = ∫ eˣ sin x dx = eˣ sin x − ∫ eˣ cos x dx이고, ∫ eˣ cos x dx = eˣ cos x + I입니다. 대입하면 I = eˣ sin x − eˣ cos x − I이므로 2I = eˣ(sin x − cos x), I = eˣ(sin x − cos x)/2 + C입니다. 원래 적분이 다시 나오면 방정식으로 풀면 됩니다.
