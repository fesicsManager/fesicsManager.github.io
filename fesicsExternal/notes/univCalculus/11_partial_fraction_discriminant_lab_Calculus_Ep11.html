대학 미적분학 · 웹툰 11화 「분모에 x²이 있으면 아크탄젠트?」

부분분수와 판별식 — 분모의 인수가 적분의 꼴을 정한다

분모가 이차식인 다섯 유리함수의 정적분을 ‘arctan b − arctan a’(뭉치), 판별식에 맞춘 분해, 심프슨 수치 적분으로 계산해 비교했습니다. ∫₂³ 1/(x² − 1) dx는 정확한 값 ½·ln(3/2) ≈ 0.20273인데 뭉치 값은 0.14190으로 70%였고, 1/(x² + 2x + 5)에서는 400%로 더 크게 어긋났습니다. 판별식의 부호에 따른 로그·유리함수·아크탄젠트의 세 꼴을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 유리함수의 정적분(∫₂³ 1/(x² − 1), ∫₀¹ 1/(x² + 3x + 2), ∫₀¹ 1/(x² + 2x + 1), ∫₋₁¹ 1/(x² + 2x + 5), ∫₀¹ 1/(x² + 1))과 계산 방법(뭉치 arctan · 판별식대로 분해한 정확한 값 · 수치 적분)을 고르고 적분하기를 누르면 피적분 함수와 분모의 실근이 그려지고 판별식·분해·값·정확한 값 대비 %가 기록표에 쌓입니다. ∫₂³ 1/(x² − 1) dx를 세 방법으로 기록하고 판별식이 0인 경우와 음수인 경우도 기록해 4개 이상 모으면 결과 비교 탭에서 판별식과 답의 꼴을 볼 수 있습니다.

x² − 1은 판별식 4 > 0이라 (x − 1)(x + 1)로 쪼개지고, ½(1/(x − 1) − 1/(x + 1))을 적분하면 로그 두 개가 되어 ½·ln(3/2)가 나옵니다. 판별식이 0인 (x + 1)²은 −1/(x + 1)로 유리함수가 답이 되고, 판별식이 음수인 x² + 2x + 5는 완전제곱 (x + 1)² + 4로 바꿔 ½·arctan((x + 1)/2)가 나옵니다. 뭉치의 arctan b − arctan a는 분모가 정확히 x² + 1일 때만 맞았습니다.

개념 정리

1. 분모의 인수가 답의 꼴을 정한다

  • 판별식 > 0 (서로 다른 일차 인수): 1/(x² − 1) = ½(1/(x − 1) − 1/(x + 1)) → 로그 두 개.
  • 판별식 = 0 (반복 인수): 1/(x + 1)² → −1/(x + 1), 로그도 아크탄젠트도 아닌 유리함수.
  • 판별식 < 0 (기약 이차식): 완전제곱 1/((x + 1)² + 4) → ½·arctan((x + 1)/2).

∫₂³ 1/(x² − 1) dx = ½[ln((x − 1)/(x + 1))]₂³ = ½ ln(3/2) ≈ 0.20273 — ½을 잊으면 ln(3/2) ≈ 0.40547.

2. 이 실험의 계산 방법

정확한 값은 위 규칙으로 구한 식, 수치 적분은 심프슨 공식 1000등분입니다. 부분분수 계수는 x에 값을 넣어 검산합니다(예: 1/(x²(x + 1)) = −1/x + 1/x² + 1/(x + 1), x = 2에서 1/12).

3. 실험 모형과 실제의 차이

· 분모가 5차 이상이면 인수분해를 식으로 못 할 수 있어 근을 수치로 찾습니다.

· 근호 √(a² − x²)는 x = a sin θ 삼각치환으로 유리식으로 바꾼 뒤 같은 방법을 씁니다(θ 범위에서 cos θ ≥ 0 확인).

4. 생활 속에서 · 이어지는 개념

  • 라플라스 역변환에서 전달함수를 부분분수로 쪼개면, 일차 인수는 지수 감쇠, 기약 이차 인수는 진동이 됩니다. 분모의 인수가 곧 시스템의 “극”이에요.
판별식 > 0: 1/((x − α)(x − β)) → 로그 두 개 · 판별식 = 0: 1/(x − α)² → −1/(x − α) · 판별식 < 0: 1/((x + p)² + q²) → (1/q)·arctan((x + p)/q)

예제

∫₀¹ 1/(x² + 3x + 2) dx를 구하시오.

x² + 3x + 2 = (x + 1)(x + 2)이고 1/((x + 1)(x + 2)) = 1/(x + 1) − 1/(x + 2)입니다. [ln((x + 1)/(x + 2))]₀¹ = ln(2/3) − ln(1/2) = ln(4/3)이므로 ln(4/3) ≈ 0.2877입니다. 실험의 분해 값 0.28768과 같아요.

1/(x²(x + 1))을 부분분수로 분해하고 x = 2에서 검산하시오.

A/x + B/x² + C/(x + 1)로 두면 1 = Ax(x + 1) + B(x + 1) + Cx²입니다. x = 0에서 B = 1, x = −1에서 C = 1, x² 계수 비교 A + C = 0에서 A = −1입니다. x = 2를 넣으면 왼쪽 1/12, 오른쪽 −1/2 + 1/4 + 1/3 = 1/12로 맞습니다. −1/x + 1/x² + 1/(x + 1)
