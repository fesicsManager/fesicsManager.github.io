고 독서와 작문 · 웹툰 6화 「정의만 쓰면 과학 설명이 끝나나」

과학 개념을 설명하는 글 — 정의 · 예시 · 단계 · 비유와 한계

‘관성’ 설명 네 판을 중학생 연구 보조원 20명씩에게 읽히고, 식탁보를 빠르게 당겨도 접시가 거의 제자리에 남는 까닭을 설명하게 했습니다. 정의만 쓴 판은 6명, 예시를 더한 판은 12명이 바르게 설명했고, 비유만 더한 판은 9명에 그친 데다 ‘관성은 힘이다’라는 오개념 동의가 12명으로 늘었습니다. 네 부품을 모두 갖추고 비유의 한계를 밝힌 판은 17명이 바르게 설명했고 오개념 동의는 2명이었습니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 관성 설명 판((가) 정의만 / (나) 정의 + 예시 / (다) 정의 + 비유만 / (라) 정의 + 예시 + 단계 + 비유와 한계)을 고르고, 새 상황을 바르게 설명할 사람 수(20명 중)를 예측한 뒤 이 설명 읽히기를 누르면 설명의 네 부품 칸, 식탁보 장면, 바르게 설명한 사람과 ‘관성은 힘이다’에 동의한 사람이 나옵니다. 기록이 4개 이상 쌓이면 결과 비교 탭에서 네 판을 비교할 수 있어요. (응답 수는 제로 랩의 가상 실험입니다)

표 1. 설명 판에 따른 결과 (실험 예시)
설명 판부품 수바르게 설명힘이다 동의
(가) 정의만1/46/207/20
(나) + 예시2/412/206/20
(다) + 비유만2/49/2012/20
(라) 네 부품4/4+한계17/202/20

정의는 맞았지만 정의만 있으면 6명밖에 새 상황을 설명하지 못했습니다. 비유만 넣은 (다)는 ‘고집쟁이’라는 말이 ‘버티는 힘’을 떠올리게 해 오개념 동의가 12명으로 오히려 늘었고, (라)처럼 한계를 한 줄 밝히자 2명으로 줄었어요. 맞는 글과 통하는 글은 다릅니다.

개념 정리

1. 설명하는 글의 네 부품

  • 정의 — 개념의 울타리. 무엇이 들어가고 빠지는지 정한다(관성: 물체가 운동 상태를 유지하려는 성질).
  • 예시 — 독자가 아는 장면으로 울타리 안을 채운다(버스가 갑자기 출발하면 몸이 뒤로 쏠림).
  • 단계 — 원리가 작동하는 과정(버스가 움직임 → 발은 따라감 → 윗몸은 멈춰 있던 상태를 유지).
  • 비유와 한계 — 비유가 어디까지 맞고 어디부터 안 맞는지 밝힌다(‘고집쟁이’는 비유일 뿐, 관성은 힘이 아니라 물체의 성질).

2. 새 상황에 적용하기 — 식탁보와 접시

식탁보를 아주 빠르게 당기면 접시와 식탁보 사이 마찰력이 접시에 작용하는 시간이 매우 짧습니다. 그래서 접시는 멈춰 있던 상태를 거의 그대로 유지해 거의 제자리에 남아요. 관성은 접시를 붙잡는 힘이 아니라 접시가 가진 성질입니다.

3. 읽기 표가 쓰기 개요가 된다

과학·기술 글을 읽을 때 네 칸 표를 만들면 빈칸이 곧 아직 이해하지 못한 곳입니다. 그 빈칸을 다른 자료로 채운 뒤 설명하는 글을 써요. 그리고 예시는 독자를 따라갑니다 — 중학생에게는 버스, 운전하는 어른에게는 급정거와 안전띠.

4. 실험 모형과 실제의 차이

· 응답 수는 제로 랩의 가상 실험값입니다. 관성이 힘이 아니라 물체의 성질이라는 것은 과학적 사실이에요.

· 실제로는 당기는 빠르기와 재질에 따라 접시가 조금 끌려가기도 합니다.

정의(울타리) + 예시(아는 장면) + 단계(작동 과정) + 비유와 한계 → 새 상황에 적용
