고등 공통영어 ② · 웹툰 8화 「발표는 원고를 잘 읽으면 끝인가」

발표의 길 안내 표지 — 되감기 버튼이 없는 청중에게 문단 나눔을 소리로 들려준다

같은 내용의 3분 영어 발표에 예고·순서/전환·정리 표지를 넣거나 빼고, 슬라이드와 말 속도도 바꿔 30명 가상 학급의 기억을 보았습니다. 핵심어 슬라이드·보통 속도에서 표지를 0개 → 3개로 늘리자 세 요점을 모두 적은 청중이 1명 → 15명으로 늘었고, 원고 전체 슬라이드와 빠른 속도는 그 수를 줄였습니다. 귀를 위한 발표 구조를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 예고(Today I'm going to talk about three …), 순서·전환(First, … Now let's move on to …), 정리(To sum up, …)를 각각 넣거나 빼고, 슬라이드(핵심어만 / 원고 전체)와 말 속도(보통 / 빠르게)를 고른 뒤 이 판으로 발표하기를 누릅니다. 발표 흐름 띠에 표지 깃발이, 아래에 청중 30명의 기억 정도가 색으로 나오고, 세 요점을 모두 적은 청중 수가 기록돼요. 기록이 4개 이상이면 결과 비교 탭이 열립니다. 기억 확률 = 0.35 + 표지마다 0.15 − (원고 전체 슬라이드 0.10) − (빠른 속도 0.10)은 경향을 보이려고 정한 가정값이에요.

내용은 한 글자도 바꾸지 않았는데, 표지를 하나씩 더할 때마다 세 요점을 모두 적은 청중이 1 → 4 → 8 → 15명으로 늘었습니다(모형). 표지를 모두 넣어도 원고 전체 슬라이드에 빠른 속도를 더하면 7명으로 줄었어요 — 청중에게 듣기와 읽기를 동시에 시키고 처리할 시간을 빼앗았기 때문입니다. 읽는 사람에게는 문단 나눔과 제목이 보이지만 듣는 사람은 되감기 버튼이 없으므로, 예고·순서·전환·강조·정리 표지가 머릿속에 목차를 그려 줍니다. 글에서는 반복이 흠이지만 발표에서는 핵심을 처음·중간·끝에 되풀이하는 것이 장치예요. 수치는 가정값이고 실제 효과 크기는 내용·청중에 따라 다릅니다.

개념 정리

1. 듣는 사람은 되감기 버튼이 없다

읽는 사람에게는 문단 나눔·제목·굵은 글씨가 보이지만, 듣는 사람에게는 하나도 보이지 않고 되돌아 들을 수도 없습니다. 그래서 발표는 길 안내 표지(signposting)로 문단 나눔을 소리로 들려줘야 해요.

  • 예고: Today I'm going to talk about three ways to save energy.
  • 순서: First, … / Second, … / Finally, …
  • 전환: Now let's move on to the second point.
  • 강조: The most important point is this.
  • 정리: To sum up, … / In short, …
  • 마무리: Thank you for listening. Do you have any questions?

2. 귀를 위한 문장

짧은 문장 · 주어와 동사는 앞쪽 · 숫자는 어림 · 슬라이드에는 핵심어만

글에서는 되풀이가 흠이지만, 발표에서는 핵심을 처음·중간·끝에 되풀이하는 것이 장치입니다. 원고를 다 붙인 슬라이드는 청중에게 듣기와 읽기를 동시에 시켜요.

움직여 보기

길 안내 표지를 켜고 끄며 30명 학급에 발표하기

한 요점 기억 확률 세 요점 모두

표지 버튼을 켜고 끄며 발표해 보세요. 표지가 없으면 띠의 문단 경계도 흐려집니다. 기억 확률 = 0.35 + 0.15 × 표지 수 − 0.10(원고 전체) − 0.10(빠르게)인 가정 모형이고, 30명의 기억은 고정된 난수라 실험 표 1과 같은 수가 나와요(표지 0 → 3개: 1 → 4 → 8 → 15명).

3. 실험 모형과 실제의 차이

· 기억 확률의 덧셈 모형은 경향을 보여 주려고 만든 가정입니다. 실제 효과 크기는 내용·청중·발표자에 따라 달라요.

· 30명의 기억 여부는 고정된 난수로 정해, 조건을 바꿀 때 차이만 보이도록 했습니다.

기억 확률(모형) = 0.35 + 0.15 × 표지 수 − 0.10(원고 전체 슬라이드) − 0.10(빠른 속도)

예제

모형에서 표지 3개, 원고 전체 슬라이드, 빠른 속도일 때 한 요점을 기억할 확률은?

0.35 + 0.15 × 3 − 0.10 − 0.10 = 0.60 → 60%. 실험에서 세 요점을 모두 적은 청중은 30명 중 7명이었다.
