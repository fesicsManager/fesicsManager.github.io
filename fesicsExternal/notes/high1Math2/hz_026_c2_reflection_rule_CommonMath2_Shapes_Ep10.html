대칭이동 — x축 대칭은 y에, y축 대칭은 x에 − 부호

점의 좌표를 정하고 x축, y축, 원점, 직선 y = x에 대한 대칭을 차례로 적용해 옮겨진 점과 식에서 바꾸는 문자를 기록했습니다. x축 대칭에서는 y의 부호가, y축 대칭에서는 x의 부호가 바뀌어 기준 축의 이름과 바뀐 문자가 반대였습니다. 네 가지 대칭이동의 규칙을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 점의 x, y(−5~5)를 정하고 대칭 기준(x축·y축·원점·y = x)을 고른 뒤 ‘거울에 비춰 보기’를 누르면 자동 기록됩니다. 네 기준을 모두 포함해 4개 이상 기록하면 분석이 열립니다.

표 1. 네 가지 대칭이동 (실험 예시)
점 (x, y)대칭 기준옮겨진 점식에서 바꾸는 것바뀐 문자
(3, 2)x축(3, −2)y → −yy
(3, 2)y축(−3, 2)x → −xx
(3, 2)원점(−3, −2)x → −x, y → −yx, y
(3, 2)직선 y = x(2, 3)x와 y를 맞바꿈x ↔ y
(4, 0)x축(4, 0)y → −yy

x축에 대해 접으면 위아래가 뒤집혀 y의 부호가, y축에 대해 접으면 좌우가 뒤집혀 x의 부호가 바뀌었습니다. x축 위의 점 (4, 0)이 x축 대칭에서 제자리에 있는 것으로 확인할 수 있습니다. 원점 대칭은 둘 다, 직선 y = x 대칭은 부호가 아니라 자리를 맞바꿉니다.

개념 정리

1. x축 대칭은 y에 −, y축 대칭은 x에 − — 바뀌는 것은 “넘어가는 축”이 아니다

x축에 대해 접으면 위아래가 뒤집히니 y좌표의 부호가 바뀝니다. y축에 대해 접으면 좌우가 뒤집혀 x좌표가 바뀌고요. 이름에 끌려 “x축 대칭이니 x에 −”라고 하면 정반대가 됩니다.

왜 그럴까

  • x축 대칭: (a, b) → (a, −b), 식에서는 y 대신 −y
  • y축 대칭: (a, b) → (−a, b), 식에서는 x 대신 −x
  • 원점 대칭: 둘 다 부호가 바뀜 / y = x 대칭: x와 y를 서로 바꿈

2. 자주 하는 오해 바로잡기

· “x축 대칭이면 x에 −x를 넣는다” → 바뀌는 것은 y입니다.

3. 생활 속에서 · 이어지는 개념

  • 좌우 반전 사진은 y축 대칭, 물에 비친 모습은 x축 대칭입니다.

예제

직선 y = 2x − 3을 x축에 대하여 대칭이동한 직선과 직선 y = x에 대하여 대칭이동한 직선을 각각 구하시오.

x축 대칭: y 대신 −y → −y = 2x − 3 → y = −2x + 3. y = x 대칭: x와 y를 바꿈 → x = 2y − 3 → y = (x + 3)/2.

원 (x − 2)² + (y + 1)² = 9를 원점에 대하여 대칭이동한 원의 방정식을 구하시오.

x 대신 −x, y 대신 −y: (−x − 2)² + (−y + 1)² = 9 → (x + 2)² + (y − 1)² = 9. 중심 (2, −1)이 (−2, 1)로 옮겨졌습니다.
