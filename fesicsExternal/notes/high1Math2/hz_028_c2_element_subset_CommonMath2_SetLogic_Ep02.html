∈와 ⊂ — 원소와 집합의 관계, 집합과 집합의 관계

왼쪽에 원소 또는 집합을, 오른쪽에 집합을 놓고 ∈와 ⊂가 각각 참인지 기록했습니다. 왼쪽이 원소면 ⊂는 쓸 수조차 없었고, {1}처럼 왼쪽이 집합이면 ∈는 거짓인데 ⊂는 참인 경우가 많았습니다. 두 기호가 서로 다른 관계를 나타냄을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 왼쪽 대상(1~5: 1, {1}, {1, 2}, ∅, 4)과 오른쪽 집합(1~3: {1, 2, 3}, {1, {2}}, ∅)을 고르고 ‘상자 안을 들여다보기’를 누르면 자동 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

여섯 기록 모두에서 ∈와 ⊂의 답이 같지 않았습니다. 왼쪽이 원소면 ∈, 집합이면 ⊂를 씁니다. {1}은 ‘1이 든 상자’라서 {1, 2, 3}의 원소가 아니지만 부분집합입니다. {1, {2}}의 원소는 1과 {2}이므로 2는 원소가 아니고, 그래서 {1, 2} ⊄ {1, {2}}입니다. ∅은 모든 집합의 부분집합이지만 ∅ ∈ ∅은 거짓입니다.

개념 정리

1. ∈는 “원소 ↔ 집합”, ⊂는 “집합 ↔ 집합”의 관계

A = {1, 2, 3}일 때 1 ∈ A는 맞지만 1 ⊂ A는 틀려요. 1은 집합이 아니기 때문입니다. 반대로 {1} ⊂ A는 맞고 {1} ∈ A는 틀립니다 — A의 원소는 1이지 {1}이 아니니까요. 왼쪽이 원소인지 집합인지가 기호를 정합니다.

왜 그럴까

  • ∅ ⊂ A는 모든 A에 대해 참이지만, ∅ ∈ A는 A가 ∅을 원소로 가질 때만 참입니다.
  • A = {1, {2}} 처럼 집합을 원소로 가질 수도 있어 구분이 더 중요해집니다.
  • A ⊂ A는 항상 참(자기 자신도 부분집합)입니다.

∈ 인가 ⊂ 인가 왜?

집합을 ‘상자’로 생각하세요. ∈는 왼쪽이 오른쪽 상자 안에 그대로 하나의 물건으로 들어 있는지, ⊂는 왼쪽 상자에 든 물건이 하나도 빠짐없이 오른쪽 상자에도 있는지를 묻습니다. {1}은 ‘1이 든 상자’라서 {1, 2, 3}의 원소는 아니지만 부분집합입니다.

2. 자주 하는 오해 바로잡기

· “∈와 ⊂는 같은 뜻이다” → 왼쪽에 무엇이 오느냐가 다릅니다.

3. 생활 속에서 · 이어지는 개념

  • 폴더 안의 “파일”과 “하위 폴더”를 구분하는 것과 같은 감각입니다.
여러 왼쪽 대상과 집합에 대해 ∈·⊂를 각각 판정하고, 왜 그런지 설명을 함께 표시

예제

A = {1, {2}, 3}일 때 다음의 참·거짓을 판정하시오. ㉠ 2 ∈ A ㉡ {2} ∈ A ㉢ {2} ⊂ A ㉣ {{2}} ⊂ A

A의 원소는 1, {2}, 3입니다. ㉠ 2는 원소가 아니므로 거짓. ㉡ {2}는 원소이므로 참. ㉢ {2}의 원소 2가 A에 없으므로 거짓. ㉣ {{2}}의 원소 {2}가 A에 있으므로 참.

∅ ∈ ∅과 ∅ ⊂ ∅의 참·거짓을 판정하시오.

∅에는 원소가 없으므로 ∅ ∈ ∅은 거짓. 모든 집합은 자기 자신의 부분집합이고 ∅은 모든 집합의 부분집합이므로 ∅ ⊂ ∅은 참.
