역함수의 그래프 — y = x에 대하여 대칭

일차함수 f(x) = ax + b와 확인할 x를 정해 f 위의 점, f⁻¹ 위의 점, x축에 대칭인 점을 기록했습니다. f 위의 점 (a, b)는 f⁻¹ 위에서 언제나 좌표가 뒤바뀐 (b, a)였고, x축 대칭인 (a, −b)는 한 번도 맞지 않았습니다. 역함수의 그래프가 직선 y = x에 대한 대칭인 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 f의 a(1~4), b(−4~4)와 확인할 x(−3~4)를 정하고 ‘y = x에 비춰 보기’를 누르면 자동 기록됩니다. 직선 y = x 위에 놓이는 점도 포함해 4개 이상 기록하면 분석이 열립니다.

표 1. f 위의 점과 f⁻¹ 위의 점 (실험 예시)
f(x)f 위의 점f⁻¹ 위의 점x축 대칭이면맞는 쪽
2x + 1(1, 3)(3, 1)(1, −3) ×y = x 대칭
2x + 1(2, 5)(5, 2)(2, −5) ×y = x 대칭
2x + 1(−1, −1)(−1, −1)(−1, 1) ×y = x 위 — 제자리
x + 2(0, 2)(2, 0)(0, −2) ×y = x 대칭
3x − 2(1, 1)(1, 1)(1, −1) ×y = x 위 — 제자리

f(a) = b이면 f⁻¹(b) = a이므로 점 (a, b)가 (b, a)로 자리를 바꿉니다. 좌표를 맞바꾸는 것은 직선 y = x에 대한 대칭이고, x축 대칭 (a, −b)와는 다릅니다. (−1, −1), (1, 1)처럼 y = x 위의 점은 움직이지 않아서 f와 f⁻¹의 그래프가 여기서 만났습니다.

개념 정리

1. 역함수의 그래프는 원래 그래프를 y = x 에 대해 접은 것

f 위의 점 (a, b)는 f⁻¹ 위에서 (b, a)가 돼요. x좌표와 y좌표가 자리를 바꾸는 것이고, 그것이 바로 y = x 에 대한 대칭입니다. x축 대칭은 (a, −b)라 전혀 다른 점입니다.

왜 그럴까

  • f(a) = b ⟺ f⁻¹(b) = a — 정의 자체가 자리 바꾸기입니다.
  • 그래서 f의 정의역과 치역이 f⁻¹에서는 서로 뒤바뀝니다.
  • y = x 위의 점은 제자리 — f와 f⁻¹의 교점이 이 위에 생기는 이유입니다.

움직여 보기

점 (a, b)를 y = x 에 대해 접으면 (b, a)

f 위의 점 f⁻¹ 위의 점 x축 대칭 점

f(x) = ax + b 의 a, b와 확인할 x를 바꿔 보세요. f 위의 점 (x, f(x))는 y = x 를 건너 좌표가 뒤바뀐 점이 되고, 그 점은 언제나 파란 f⁻¹ 그래프 위에 있습니다. 회색 x축 대칭 점은 f⁻¹ 위에 오지 않습니다. f = 2x + 1, x = −1 처럼 y = x 위의 점은 제자리입니다. (한 칸 = 1, 화면은 −6 ~ 6)

2. 자주 하는 오해 바로잡기

· “역함수의 그래프는 x축에 대칭이다” → y = x 에 대한 대칭입니다.

📋 데이터 확인 탭의 결론

“○개”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = 2x + 1의 역함수를 구하고 f⁻¹(3)을 구하시오.

y = 2x + 1을 x에 대해 풀면 x = (y − 1)/2. x와 y를 바꾸면 f⁻¹(x) = (x − 1)/2. f⁻¹(3) = 1로, 표의 점 (1, 3) ↔ (3, 1)과 일치합니다.

f(x) = 3x − 2의 그래프와 그 역함수의 그래프의 교점을 구하시오.

f는 증가함수이므로 두 그래프의 교점은 직선 y = x 위에 있습니다. 3x − 2 = x → x = 1. 교점 (1, 1).
