평행이동 — 오른쪽으로 a만큼 옮기면 식에서는 x − a

포물선 y = 0.4x² − 1을 x축 방향으로 a, y축 방향으로 b만큼 옮기고, x 대신 x − a를 넣은 식과 x + a를 넣은 식 중 어느 쪽이 실제로 옮긴 그래프와 겹치는지 기록했습니다. a ≠ 0인 모든 기록에서 x − a를 넣은 식만 겹쳤습니다. 옮긴 점을 원래 자리로 되돌려 대입하기 때문에 부호가 반대로 보인다는 것을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 이동량 a, b(−4~4)를 정하고 ‘옮겨서 겹쳐 보기’를 누르면 실제로 옮긴 그래프, x − a 대입 그래프, x + a 대입 그래프가 함께 그려지고 자동 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

꼭짓점 (0, −1)이 (a, −1 + b)로 옮겨 갔고, 그 그래프와 겹친 것은 언제나 x 대신 x − a를 넣은 식이었습니다. 옮긴 그래프 위의 점 (x, y)는 원래 그래프의 점 (x − a, y − b)에서 왔으므로 원래 식에 되돌린 좌표를 넣어 y − b = f(x − a)가 됩니다. a = −3이면 x − (−3) = x + 3이 되는 것도 같은 규칙입니다.

개념 정리

1. 오른쪽으로 a만큼 옮기면 식에서는 x를 x − a 로 바꾼다

옮긴 그래프 위의 점 (x, y)는 원래 그래프의 (x−a, y−b)에서 온 점이에요. 그래서 원래 식에 x−a, y−b를 넣어야 합니다. “오른쪽으로 갔는데 왜 −인가”가 아니라, 거꾸로 되돌려 대입하기 때문입니다.

왜 그럴까

  • 점 (p, q)가 (p+a, q+b)로 가므로, 새 좌표 X=p+a에서 p=X−a.
  • y = f(x) → y − b = f(x − a), 즉 y = f(x−a) + b.
  • 원 (x−p)²+(y−q)²=r²도 같은 이유로 중심이 (p, q)입니다.

움직여 보기

포물선을 옮기면 어느 식과 겹칠까?

━ 처음 y = 0.4x² − 1 · ━ 실제로 옮긴 그래프 · ╌ x − a 대입 · ┈ x + a 대입

꼭짓점 (0, −1) → 옮긴 식 x − a 대입 x + a 대입

a, b를 정하고 ‘실제로 옮겨 보기’를 누르세요. 보라 그래프는 언제나 초록 점선(x − a 대입)에 가서 겹칩니다. 옮긴 그래프 위의 점 (x, y)는 처음 그래프의 점 (x − a, y − b)에서 왔기 때문에, 원래 식에 되돌린 좌표를 넣는 것입니다.

2. 자주 하는 오해 바로잡기

· “x축으로 a만큼 옮기면 x를 x+a로 바꾼다” → 방향이 반대로 갑니다.

3. 생활 속에서 · 이어지는 개념

  • 이미지 편집에서 레이어를 옮길 때도 좌표계 기준으로는 반대로 계산합니다.
포물선을 실제로 옮긴 그래프와, x−a·x+a를 대입한 두 식의 그래프를 함께 그려 겹치는 쪽을 확인

예제

y = x² + 2x의 그래프를 x축 방향으로 3, y축 방향으로 −1만큼 평행이동한 그래프의 식을 구하시오.

x 대신 x − 3, y 대신 y + 1을 넣습니다. y + 1 = (x − 3)² + 2(x − 3) → y = x² − 4x + 2. 꼭짓점도 (−1, −1) → (2, −2)로 옮겨져 y = (x − 2)² − 2와 일치합니다. y = x² − 4x + 2.

원 (x − 1)² + (y + 2)² = 4를 x축 방향으로 −3, y축 방향으로 5만큼 평행이동한 원의 방정식과 중심을 구하시오.

x 대신 x + 3, y 대신 y − 5를 넣으면 (x + 3 − 1)² + (y − 5 + 2)² = 4 → (x + 2)² + (y − 3)² = 4, 중심 (−2, 3). 중심 (1, −2)를 (−3, 5)만큼 옮긴 점과 같습니다.
