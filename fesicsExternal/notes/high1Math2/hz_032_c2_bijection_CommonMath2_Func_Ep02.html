일대일대응 — 일대일함수이면서 치역과 공역이 같아야 한다

정의역과 공역의 원소 수(2~4)와 대응 방식(1~4)을 바꿔 화살표를 긋고 함수, 일대일, 치역 = 공역, 일대일대응을 각각 판정했습니다. 일대일인데도 공역에 화살표를 받지 못한 원소가 남아 일대일대응이 아닌 기록이 있었고, 일대일대응은 두 집합의 원소 수가 같을 때만 나왔습니다. 두 조건이 모두 필요함을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 정의역 원소 수, 공역 원소 수, 대응 방식을 정하고 ‘화살표를 그어 보기’를 누르면 네 가지 판정이 자동 기록됩니다. 원소 수가 같은 경우와 다른 경우를 섞어 4개 이상 기록하면 분석이 열립니다.

표 1. 대응 방식에 따른 판정 (실험 예시)
정의역 → 공역대응 방식함수일대일치역 = 공역일대일대응
3 → 31○○○○
3 → 41○○××
4 → 31○×○×
3 → 32 (모두 한 원소로)○×××
3 → 34○○○○
2 → 44○○××

3 → 4, 2 → 4 기록은 일대일인데 일대일대응이 아니었습니다. 서로 다른 원소는 서로 다른 곳으로 갔지만 공역에 화살표를 받지 못한 원소가 남았기 때문입니다. 반대로 4 → 3은 공역을 다 채웠지만 두 원소가 한 곳으로 모여 일대일이 아니었습니다. 일대일대응은 일대일 + 치역 = 공역이고, 유한집합에서는 두 집합의 원소 수가 같아야 합니다.

개념 정리

1. 일대일함수 + 치역 = 공역 이어야 일대일대응

일대일함수는 서로 다른 것은 서로 다른 곳으로 간다는 뜻이에요. 하지만 공역에 도착하지 않은 원소가 남아 있으면 일대일대응이 아닙니다. 두 조건이 모두 맞아야 하고, 그러려면 두 집합의 원소 개수가 같아야 합니다.

왜 그럴까

  • 함수: 정의역의 모든 원소가 정확히 하나씩 대응돼야 합니다.
  • 일대일: f(a)=f(b)이면 a=b.
  • 일대일대응이면 역함수를 만들 수 있습니다 — 되돌릴 길이 하나로 정해지기 때문입니다.

2. 자주 하는 오해 바로잡기

· “일대일함수면 일대일대응이다” → 공역에 남는 원소가 있으면 아닙니다.

3. 생활 속에서 · 이어지는 개념

  • 좌석 배정에서 “한 사람에 한 자리”가 일대일, “빈자리가 없다”까지 더해야 일대일대응입니다.
정의역·공역의 크기와 대응 방식을 바꿔 화살표를 그리고, 세 가지 조건을 각각 판정

예제

X = {1, 2, 3}, Y = {4, 5, 6, 7}일 때 f(x) = x + 3은 일대일대응인가?

f(1) = 4, f(2) = 5, f(3) = 6으로 서로 다른 원소가 서로 다른 값에 대응하므로 일대일함수입니다. 그러나 치역 {4, 5, 6} ≠ 공역 Y(7이 남음)이므로 일대일대응이 아닙니다.

X = {1, 2, 3}에서 Y = {a, b, c}로의 일대일대응의 개수를 구하시오.

1의 짝 3가지, 2의 짝 남은 2가지, 3의 짝 1가지이므로 3 × 2 × 1 = 6개.
