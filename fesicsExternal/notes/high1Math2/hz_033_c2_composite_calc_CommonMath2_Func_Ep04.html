합성함수 — (f∘g)(x) = f(g(x))는 안쪽 g부터 계산한다

두 일차함수 f(x) = ax + b, g(x) = cx + d와 넣을 값 x를 정해 g(x), f(g(x)), f(x), g(f(x))를 나란히 기록했습니다. f(x) = 2x + 1, g(x) = 3x − 2에서는 모든 x에서 두 값이 4만큼 달랐고, 특별한 경우에만 같았습니다. 합성의 계산 순서와 교환법칙이 성립하지 않음을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 x(−4~5)와 f의 a, b, g의 c, d를 정하고 ‘안쪽부터 흘려보내기’를 누르면 두 순서의 계산 결과가 자동 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

f(x) = 2x + 1, g(x) = 3x − 2에서는 (f∘g)(x) = 6x − 3, (g∘f)(x) = 6x + 1이라 모든 x에서 4만큼 달랐습니다. (f∘g)(x)는 기호에서 f가 앞에 있지만 계산은 안쪽 g가 먼저입니다. 두 값이 같았던 것은 둘 다 평행이동이거나 f = g인 특별한 경우뿐이라, 합성은 일반적으로 f∘g ≠ g∘f입니다.

개념 정리

1. (f∘g)(x) = f(g(x)) — 안쪽 g 를 먼저 계산한다

기호는 f∘g 지만 계산은 g 부터예요. x를 g에 넣어 나온 값을 다시 f에 넣습니다. 순서를 바꾼 g∘f 는 대개 전혀 다른 값이 나옵니다. 기호의 생김새가 계산 순서와 반대라 헷갈리는 자리입니다.

왜 그럴까

  • f∘g 는 “g 다음에 f”를 뜻합니다 — 함수는 오른쪽부터 작용합니다.
  • (f∘g)(x) = f(g(x)) 이고 (g∘f)(x) = g(f(x)) — 두 식의 정의역·치역도 다를 수 있습니다.
  • h∘(f∘g) = (h∘f)∘g — 결합법칙은 성립합니다.

2. 자주 하는 오해 바로잡기

· “f∘g는 f를 먼저 계산한다” → 안쪽의 g 가 먼저입니다.

3. 생활 속에서 · 이어지는 개념

  • “번역한 뒤 요약”과 “요약한 뒤 번역”이 다른 것과 같습니다.
두 일차함수를 정하고 x를 넣어 g→f 순서와 f→g 순서의 결과를 나란히 계산

예제

f(x) = x², g(x) = x + 1일 때 (f∘g)(2)와 (g∘f)(2)를 구하시오.

(f∘g)(2) = f(g(2)) = f(3) = 9. (g∘f)(2) = g(f(2)) = g(4) = 5. 순서가 바뀌면 값이 다릅니다.

f(x) = 2x + 1, g(x) = 3x − 2일 때 (f∘g)(x)와 (g∘f)(x)를 구하시오.

(f∘g)(x) = f(3x − 2) = 2(3x − 2) + 1 = 6x − 3. (g∘f)(x) = g(2x + 1) = 3(2x + 1) − 2 = 6x + 1. 실험 표의 값과 일치합니다(x = 2에서 9와 13).
