두 직선의 위치 관계 — a : b까지 같으면 평행, c까지 같아야 일치

직선 ① x + 2y − 2 = 0을 고정하고 직선 ②의 계수 a, b, c를 바꿔 두 직선의 위치 관계와 교점의 개수를 기록했습니다. a : b의 비가 다르면 한 점에서 만났고, a : b가 같을 때 c까지 같은 비면 일치, c만 어긋나면 평행이었습니다. 이 세 경우가 연립방정식의 해의 개수와 그대로 대응함을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 직선 ②의 a, b(−6~6), c(−8~8)를 정하고 ‘두 직선을 겹쳐 보기’를 누르면 자동 기록됩니다. 한 점에서 만남·평행·일치가 모두 나오도록 4개 이상 기록하면 분석이 열립니다.

표 1. ① x + 2y − 2 = 0과 직선 ②의 위치 관계 (실험 예시)
직선 ②a : b 비c까지 비례위치 관계교점 수
2x + 4y − 6 = 0같음×평행0
2x + 4y − 4 = 0같음○일치무수히 많음
x − y + 1 = 0다름×한 점에서 만남 (0, 1)1
−x − 2y + 2 = 0같음○일치무수히 많음
3x + 6y + 0 = 0같음×평행0
2x + y − 4 = 0다름×한 점에서 만남 (2, 0)1

a : b가 1 : 2로 같은 네 기록은 모두 기울기가 −1/2로 같았지만, c까지 같은 비인 두 기록만 일치했고 c가 어긋난 두 기록은 만나지 않는 평행선이었습니다. a : b가 다르면 반드시 한 점에서 만났습니다. 연립방정식으로 읽으면 한 점에서 만남 = 해 1개, 평행 = 해 없음, 일치 = 해가 무수히 많음입니다.

개념 정리

1. a : b 까지만 같으면 평행, c까지 같아야 일치

두 직선 a₁x+b₁y+c₁=0, a₂x+b₂y+c₂=0에서 a : b가 같으면 기울기가 같아 평행해요. 여기서 c까지 같은 비면 사실 같은 직선(일치)이고, c만 어긋나면 만나지 않는 평행선입니다. 비가 다르면 한 점에서 만납니다.

왜 그럴까

  • a₁/a₂ = b₁/b₂ ≠ c₁/c₂ → 평행 (교점 없음)
  • a₁/a₂ = b₁/b₂ = c₁/c₂ → 일치 (교점 무수히 많음)
  • 비가 다르면 → 한 점에서 만남

2. 자주 하는 오해 바로잡기

· “계수가 비례하면 언제나 일치다” → c까지 비례해야 일치이고, c만 어긋나면 평행입니다.

3. 생활 속에서 · 이어지는 개념

  • 연립방정식의 해가 하나·없음·무수히 많음으로 갈리는 것이 그대로 이 세 경우입니다.
①을 x + 2y − 2 = 0으로 고정하고 ②의 계수를 바꿔 가며 두 직선을 그려 교점 개수를 판정

예제

두 직선 x + 2y − 2 = 0과 kx + 6y + 3 = 0이 평행할 때 상수 k의 값을 구하시오.

평행하려면 1/k = 2/6 ≠ −2/3이어야 합니다. 1/k = 1/3에서 k = 3이고, 이때 c의 비는 −2/3으로 1/3과 다르므로 일치가 아닌 평행입니다. k = 3.

연립방정식 x + 2y = 2, 3x + 6y = k의 해가 무수히 많을 조건과 해가 없을 조건을 구하시오.

두 식을 x + 2y − 2 = 0, 3x + 6y − k = 0으로 보면 a : b = 1 : 3으로 같습니다. c의 비 −2 : −k도 1 : 3이면 일치이므로 k = 6이면 해가 무수히 많고, k ≠ 6이면 평행이라 해가 없습니다.
