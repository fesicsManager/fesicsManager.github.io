공집합과 부분집합의 개수 — 원소가 n개면 부분집합은 2ⁿ개

∅, {0}, {∅}, {1, 2}, {a, b, c}의 부분집합을 모두 나열해 개수를 세고 2ⁿ과 비교했습니다. 모든 집합에서 나열한 개수와 2ⁿ이 같았고, ∅은 원소 0개, {0}과 {∅}은 원소가 1개였습니다. 부분집합의 개수 공식과 공집합에 관한 헷갈리는 점을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 집합(1~5)을 고르고 ‘부분집합을 모두 나열하기’를 누르면 나열 결과와 개수가 자동 기록됩니다. ∅과 {0}을 포함해 4개 이상 기록하면 분석이 열립니다.

표 1. 원소의 개수와 부분집합의 개수 (실험 예시)
집합원소 개수 n부분집합 개수2ⁿ진부분집합일치
∅0110○
{0}1221○

{1, 2}2443○
{a, b, c}3887○

나열한 부분집합의 개수는 언제나 2ⁿ과 같았습니다. 원소마다 ‘넣는다/뺀다’ 두 가지를 곱하기 때문입니다. ∅의 원소는 0개이지만 부분집합은 ∅ 하나(2⁰ = 1)이고, {0}과 {∅}은 원소가 1개라 ∅과 다른 집합입니다. 자기 자신을 뺀 진부분집합은 2ⁿ − 1개입니다.

개념 정리

1. ∅ 은 원소가 0개, {0}과 {∅}은 원소가 1개 — 빈 상자와 “빈 상자가 든 상자”는 다르다

∅ 은 아무것도 없는 모임이라 n(∅) = 0이에요. {0}은 0이라는 원소가 하나 든 집합이라 n = 1, {∅}도 ∅ 이라는 원소가 하나 든 집합이라 n = 1입니다. 원소가 n개면 부분집합은 2ⁿ개, 자기 자신을 뺀 진부분집합은 2ⁿ − 1개입니다.

왜 그럴까

  • 각 원소마다 “넣는다/안 넣는다” 두 가지 → 2×2×… = 2ⁿ.
  • ∅의 부분집합은 ∅ 하나뿐 — 2⁰ = 1.
  • 특정 원소를 반드시 포함하는 부분집합은 2ⁿ⁻¹개입니다.

2. 자주 하는 오해 바로잡기

· “{0}과 ∅ 은 같다” → {0}은 원소가 하나 있는 집합입니다.

3. 생활 속에서 · 이어지는 개념

  • 빈 폴더와 빈 폴더가 하나 들어 있는 폴더는 분명히 다릅니다.
집합을 골라 부분집합을 모두 나열해 세고, 2ⁿ 및 진부분집합 개수와 대조
📋 데이터 확인 탭의 결론

“모든 기록에서 나열한 개수와 2ⁿ이 같았습니다. 원소마다 “넣는다/뺀다” 두 가지를 곱한 것입니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

A = {1, 2, 3, 4}의 부분집합의 개수, 진부분집합의 개수, 1은 반드시 포함하고 4는 포함하지 않는 부분집합의 개수를 구하시오.

부분집합 2⁴ = 16개, 진부분집합 16 − 1 = 15개. 1과 4의 포함 여부가 정해졌으므로 2, 3만 고르면 되어 2² = 4개.

집합 B = {∅, 0, {0}}의 원소의 개수와 부분집합의 개수를 구하시오.

원소는 ∅, 0, {0} 세 개로 모두 다릅니다. n(B) = 3, 부분집합은 2³ = 8개.
