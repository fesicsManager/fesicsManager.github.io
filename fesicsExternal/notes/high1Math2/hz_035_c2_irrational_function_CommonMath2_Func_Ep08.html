무리함수 — 근호 안이 0 이상인 x만 정의역

y = √(ax + b) + q에서 a, b, q와 확인할 x를 바꿔 근호 안이 0이 되는 x, 정의역, 그래프의 시작점, 그 x에서 값이 있는지를 기록했습니다. 근호 안이 음수가 되는 x에서는 값이 없었고, a > 0이면 오른쪽, a < 0이면 왼쪽으로만 그래프가 뻗었습니다. 무리함수에서 정의역을 먼저 정해야 하는 까닭을 정리합니다.

실험 안내: 자유 탐구 탭에서 a(−3~3), b(−6~6), q(−3~3)와 확인할 x(−7~7)를 정하고 ‘넣을 수 있는 x 찾기’를 누르면 자동 기록됩니다. 정의역 안과 밖의 x, a의 부호가 다른 경우를 섞어 4개 이상 기록하면 분석이 열립니다.

근호 안이 음수가 된 기록에서는 실수 값이 존재하지 않았습니다. 근호 안이 0이 되는 x가 그래프의 시작점이고, a > 0이면 x ≥ −b/a, a < 0이면 x ≤ −b/a입니다. q를 더하면 시작점이 (−b/a, q)로 올라가거나 내려가 치역은 y ≥ q가 되므로 q < 0이면 음수 값도 나옵니다. a = 0, b < 0이면 정의역이 아예 없습니다.

개념 정리

1. 근호 안 ≥ 0 인 x 만 정의역 — 그 밖에서는 그래프가 아예 없다

y = √(ax + b) + q 는 ax + b ≥ 0 인 x에서만 값을 가져요. a > 0이면 x ≥ −b/a 로 오른쪽 반쪽, a < 0이면 x ≤ −b/a 로 왼쪽 반쪽입니다. 정의역을 정하지 않고 그래프를 그리면 있지도 않은 부분을 그리게 됩니다.

왜 그럴까

  • 실수 범위에서 음수의 제곱근은 없습니다.
  • 근호 안이 0이 되는 점이 그래프의 시작점(끝점)입니다.
  • √(ax + b) 자체는 0 이상이지만, 이 실험처럼 q 만큼 올리고 내리면 y ≥ q 가 됩니다 — q 가 음수면 y 도 음수가 될 수 있습니다.
  • a = 0 이면 무리함수가 아닙니다. b ≥ 0 이면 y = √b + q 인 상수함수이고, b < 0 이면 정의역이 아예 없습니다.

2. 자주 하는 오해 바로잡기

· “정의역은 신경 쓰지 않아도 된다” → 무리함수는 정의역이 그래프의 모양을 정합니다.

3. 생활 속에서 · 이어지는 개념

  • 제곱근이 들어간 공식(속력, 거리)에서 음수가 나오면 계산이 아니라 조건을 다시 봐야 합니다.
a, b를 바꿔 근호 안의 부호를 확인하고, 정의역 안팎에서 값이 있는지 표시

예제

함수 y = √(6 − 2x) + 1의 정의역과 치역을 구하시오.

6 − 2x ≥ 0 → x ≤ 3(정의역). 근호 부분은 0 이상이므로 y ≥ 1(치역 {y | y ≥ 1}). 그래프는 (3, 1)에서 시작해 왼쪽으로 뻗습니다.

y = √(ax + b)의 그래프가 점 (2, 0)에서 시작하여 왼쪽으로 뻗고 점 (−2, 2)를 지날 때 상수 a, b를 구하시오.

왼쪽으로 뻗으므로 a < 0이고, 시작점에서 2a + b = 0 → b = −2a. (−2, 2)를 대입하면 √(−2a + b) = √(−4a) = 2 → −4a = 4 → a = −1, b = 2. 즉 y = √(−x + 2).
