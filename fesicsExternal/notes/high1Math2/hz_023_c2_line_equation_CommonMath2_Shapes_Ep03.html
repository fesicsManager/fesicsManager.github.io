직선의 방정식 — 세로선은 y = mx + n으로 쓸 수 없다

두 점 A, B를 옮겨 가며 Δx, Δy, 기울기, 직선의 식을 기록했습니다. Δx = 0인 세로선에서만 기울기를 계산할 수 없었고 식도 x = k 꼴로만 쓸 수 있었으며, 가로선은 기울기 0으로 정상이었습니다. 모든 직선을 담는 일반형 ax + by + c = 0이 왜 필요한지 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 A, B의 좌표(−5~5)를 정하고 ‘기울기를 재어 보기’를 누르면 자동 기록됩니다. 두 점의 x좌표를 같게 한 경우(세로선)와 y좌표를 같게 한 경우(가로선)를 포함해 4개 이상 기록하면 분석이 열립니다.

표 1. 두 점으로 구한 기울기와 직선의 식 (실험 예시)

(−2, −1)(3, 4)551○y = x + 1

다섯 기록 중 Δx = 0인 하나만 기울기를 구할 수 없었습니다. 기울기 Δy/Δx에서 분모 Δx가 0이면 나눗셈 자체가 불가능하므로 기울기는 ‘무한대’가 아니라 정의되지 않습니다. 반면 가로선의 기울기 0은 정상적인 값입니다. 그래서 모든 직선을 한 식으로 나타내려면 ax + by + c = 0을 쓰고, b = 0일 때가 세로선입니다.

개념 정리

1. 세로선 x = k는 기울기가 정의되지 않아 y = mx + n 꼴로 쓸 수 없다

기울기는 Δy / Δx 인데, 세로선은 Δx = 0이라 나눌 수 없습니다. 기울기가 “무한대”인 것이 아니라 아예 정해지지 않습니다. 그래서 모든 직선을 담으려면 ax + by + c = 0 이라는 일반형이 필요합니다.

왜 그럴까

  • y = mx + n 꼴은 세로선만 빼고 모든 직선을 나타냅니다.
  • 일반형 ax+by+c=0에서 b=0이면 세로선 x = −c/a가 됩니다.
  • 가로선은 기울기 0 — 이건 정상적인 값이라 y = n으로 쓸 수 있습니다.

2. 자주 하는 오해 바로잡기

· “모든 직선은 y = mx + n으로 쓸 수 있다” → 세로선 하나가 빠집니다.

3. 생활 속에서 · 이어지는 개념

  • 그래프 프로그램이 세로선을 그릴 때 따로 처리하는 이유가 바로 이것입니다.
두 점의 좌표로 Δx, Δy를 구해 기울기를 계산하고, Δx = 0일 때 어떤 일이 생기는지 표시

예제

두 점 (2, −1), (2, 5)를 지나는 직선의 방정식을 구하시오.

Δx = 2 − 2 = 0이므로 기울기가 정의되지 않는 세로선입니다. 두 점의 x좌표가 모두 2이므로 x = 2.

직선 3x − 2y + 6 = 0의 기울기와 y절편을 구하시오.

b = −2 ≠ 0이므로 y에 대해 풀 수 있습니다. 2y = 3x + 6 → y = (3/2)x + 3. 기울기 3/2, y절편 3.
