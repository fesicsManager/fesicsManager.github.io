반례 — 예시 40개는 증명이 아니고 반례 하나면 거짓

n² + n + 41에 n = 0부터 N까지 넣어 소수였던 개수와 처음 깨진 n을 기록했습니다. N = 39까지는 40개 모두 소수라 ‘항상 소수’처럼 보였지만, n = 40에서 1681 = 41 × 41로 깨졌습니다. ‘모든 ~’ 꼴의 명제를 증명하는 일과 반박하는 일의 차이를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 확인할 범위 N(5~60)을 정하고 ‘n까지 모두 확인하기’를 누르면 소수였던 개수와 처음 깨진 n이 자동 기록됩니다. N을 40 전후로 바꿔 4개 이상 기록하면 분석이 열립니다.

n = 0부터 39까지 40번 연속으로 소수였지만 n = 40 하나로 ‘모든 n에 대하여 소수’는 거짓이 되었습니다. 범위를 넓히면 n = 41(1763 = 41 × 43), 44, 49, 56에서도 깨져 N = 60에서는 61개 중 56개만 소수였습니다. ‘모든 x에 대하여 p’는 반례 하나로 거짓이 되지만, 참임을 보이려면 모든 경우를 덮는 논증이 필요합니다.

개념 정리

1. 예시가 아무리 많아도 증명이 아니다 — 반례 하나면 거짓

n² + n + 41 은 n = 0부터 39까지 40번 연속으로 소수예요. 그래서 “항상 소수”처럼 보이지만, n = 40에서 40² + 40 + 41 = 1681 = 41²로 깨집니다. “모든 ~이다” 형태의 명제는 반례 하나로 무너집니다.

왜 그럴까

  • “모든 x에서 참”을 보이려면 모든 경우를 덮는 논증이 필요합니다.
  • 반대로 거짓임을 보이는 데는 반례 하나면 충분합니다.
  • “어떤 x에서 참”이라면 예시 하나로 증명이 됩니다 — 형태에 따라 다릅니다.

2. 자주 하는 오해 바로잡기

· “예를 들어 보이면 증명이 된다” → 40개가 맞아도 41번째에서 깨질 수 있습니다.

3. 생활 속에서 · 이어지는 개념

  • 실험을 여러 번 해 잘 된 것과 “항상 안전하다”를 보이는 것은 전혀 다른 일입니다.
n을 0부터 지정한 값까지 넣어 실제로 소수인지 판정하고, 처음 깨지는 n을 찾아 표시

예제

n = 41일 때 n² + n + 41의 값을 인수분해하여 합성수임을 보이시오.

41² + 41 + 41 = 41 × (41 + 1 + 1) = 41 × 43 = 1763. 1과 자기 자신 외에 41, 43을 약수로 가지므로 합성수입니다.

명제 ‘모든 자연수 n에 대하여 2ⁿ > n²이다’가 거짓임을 보이시오.

반례 하나면 됩니다. n = 3이면 2³ = 8, 3² = 9로 8 > 9가 아니므로 거짓(n = 2, 4에서도 같은 값이 되어 성립하지 않습니다).

확인 문제

1번· 관찰 확인

실험에서 n² + n + 41이 처음으로 소수가 아니게 된 n과 그 값은?

40² + 40 + 41 = 1681 = 41².
🔬 실험으로 다시 확인

2번· 핵심 개념

‘모든 x에 대하여 p(x)이다’가 거짓임을 보이는 방법으로 옳은 것은?

반례 하나가 ‘모든’을 무너뜨립니다.
🔬 실험으로 다시 확인

3번· 적용

명제 ‘어떤 자연수 n에 대하여 n² + n + 41은 합성수이다’를 증명하는 방법은?

‘어떤 ~’ 꼴은 예시 하나로 참이 증명됩니다.
🔬 실험으로 다시 확인

4번· 오해 바로잡기

‘n = 0부터 39까지 모두 소수였으니 n² + n + 41은 항상 소수이다’가 잘못된 까닭은?

실제로 n = 40에서 깨졌습니다.
