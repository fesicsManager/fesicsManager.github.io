중학교 3학년 수학 · 웹툰 21화 「양쪽에 똑같이」

완전제곱식 만들기 — (b/2)²은 양변에 똑같이 더한다

x² + bx = c의 b, c와 모서리 조각 (b/2)²을 더하는 곳을 바꾸며 정리한 식과 검산 값을 기록했습니다. 양쪽에 더하면 검산 값이 언제나 c와 같았고, 왼쪽에만 더하면 검산 값이 정확히 (b/2)²만큼 작았습니다. 완전제곱식을 만들어 이차방정식을 푸는 방법을 정리합니다.

실험 안내: 🔬 자유 탐구 탭에서 b(2, 4, 6, 8, 10), c(3, 5, 7, 12), 모서리 조각 (b/2)²을 더하는 곳(양쪽 / 왼쪽만)을 고르고 완전제곱식 만들기를 누르면 타일 그림과 저울, 정리한 식, 큰 근의 검산 값이 기록됩니다. 기록이 4개 이상이면 ✅ 결과 비교 탭에서 ‘(b/2)² 대 c − 검산 값’ 그래프를 볼 수 있습니다.

x² + 6x = 7의 양쪽에 9를 더하면 (x + 3)² = 16 → x = 1 또는 −7로 검산 값이 7이 됩니다. 왼쪽에만 더하면 (x + 3)² = 7이 되어 검산 값이 −2, 곧 c보다 (b/2)² = 9만큼 작아집니다. x² 정사각형 옆에 bx를 반씩 붙이면 모서리에 (b/2) × (b/2) 빈칸이 생기고, 이 칸을 채운 만큼 우변에도 더해야 저울이 수평을 유지합니다.

개념 정리

1. 등식의 성질

등식의 양변에 같은 수를 더해도 등식은 성립합니다. 한쪽에만 더하면 저울이 기울어요.

x² + bx = c → x² + bx + (b/2)² = c + (b/2)² → (x + b/2)² = c + (b/2)²

  • x² + 6x = 7 → x² + 6x + 9 = 16 → (x + 3)² = 16 → x = 1 또는 −7
  • 왼쪽에만 9를 더하면 (x + 3)² = 7 → x = −3 ± √7 → 대입하면 x² + 6x = −2 ≠ 7

2. 타일 그림

x² 정사각형 옆에 bx를 반씩 나눠 두 변에 붙이면 모서리에 (b/2) × (b/2) 만큼 빈 칸이 생깁니다. 이 칸을 채우는 수가 (b/2)² 이에요.

더할 수 완성한 식 해 검산 x² + bx

x² 옆에 bx를 반씩 나눠 붙이면 모서리에 (b/2) × (b/2) 칸이 빕니다. 그 칸을 채운 만큼 오른쪽에도 더해야 저울이 평형이에요. '왼쪽에만 더하기'를 눌러 x² + 6x = 7의 해가 어떻게 틀어지는지 비교해 보세요.

x² + bx = c → x² + bx + (b/2)² = c + (b/2)² → (x + b/2)² = c + (b/2)²

예제

x² + 8x = 9를 완전제곱식을 이용해 푸시오.

(8/2)² = 16을 양변에 더하면 (x + 4)² = 25 → x + 4 = ±5. x = 1 또는 x = −9. 검산: 1 + 8 = 9, 81 − 72 = 9.

x² + 4x = 1을 완전제곱식을 이용해 푸시오.

(4/2)² = 4를 양변에 더하면 (x + 2)² = 5 → x + 2 = ±√5. x = −2 ± √5
