중학교 3학년 수학 · 웹툰 30화 「묶을 때 나누는 것을 잊지 마라」

표준형으로 고치기 — x² 계수로 묶을 땐 x항도 나눈다

여섯 개의 이차함수를 ‘a로 묶고 x항도 a로 나누는 방법’과 ‘x항은 그대로 두고 묶는 방법’으로 표준형으로 고쳐 원래 그래프와 겹쳐 보았습니다. 나누어 묶은 표준형만 원래 곡선과 겹쳤고, 나누지 않으면 꼭짓점과 x = 1에서의 값이 모두 어긋났습니다. 표준형으로 고치는 바른 순서를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 식(6개 중 하나)과 묶는 방법을 고르고 표준형으로 고치기를 누르면, 내가 만든 표준형이 점선으로 겹쳐지고 꼭짓점 비교와 x = 1 대입 검산이 기록됩니다. 같은 식을 두 방법으로 고쳐 4개 이상 기록하면 결과 비교 탭에서 방법별 일치 비율을 볼 수 있어요.

표 1. 묶는 방법에 따른 표준형 (실험 예시)
원래 식방법내 표준형꼭짓점일치
2x² − 8x + 5나눔2(x − 2)² − 3(2, −3)예
2x² − 8x + 5안 나눔2(x − 4)² − 27(4, −27)아니오
3x² + 6x − 1나눔3(x + 1)² − 4(−1, −4)예
3x² + 6x − 1안 나눔3(x + 3)² − 28(−3, −28)아니오
−x² + 4x + 1나눔−(x − 2)² + 5(2, 5)예
−x² + 4x + 1안 나눔−(x + 2)² + 5(−2, 5)아니오

x항을 나누지 않고 묶으면 2(x² − 8x)처럼 다시 전개했을 때 x항이 −16x로 a배가 되어 원래 식과 다른 함수가 됩니다. 그래서 꼭짓점의 x좌표도 원래의 a배(2 → 4, −1 → −3, 2 → −2)로 어긋났어요. a로 묶을 때는 x항의 계수도 a로 나누고, 괄호 안에서 더하고 뺀 수를 밖으로 꺼낼 때는 a를 곱해야 합니다. 끝나면 x = 1처럼 0이 아닌 수를 넣어 두 식의 값이 같은지 검산하세요(x = 0은 x항을 나누지 않은 틀린 식도 c로 같게 나와 오류를 못 잡아요).

개념 정리

1. x² 계수로 묶을 땐 x항도 나눈다

ax² + bx + c = a(x² + (b/a)x) + c = a(x + b/2a)² − b²/4a + c

  • 2x² − 8x + 5 = 2(x² − 4x) + 5 = 2(x − 2)² − 8 + 5 = 2(x − 2)² − 3
  • 나누지 않으면: 2(x² − 8x) + 5 → 전개하면 2x² − 16x + 5 로 원래 식과 다름

또 괄호 안에서 더하고 뺀 (b/2a)² 을 밖으로 꺼낼 때 a를 곱해 빼야 합니다.

2. 검산

표준형을 다시 전개해서 원래 식이 나오는지, 또는 x = 1 처럼 0이 아닌 수를 넣어 두 식의 값이 같은지 확인하세요. x = 0 을 넣으면 x항을 나누지 않은 틀린 식도 값이 c로 같게 나와 이 오류를 잡지 못해요.

ax² + bx + c = a(x² + (b/a)x) + c = a(x + b/2a)² − b²/4a + c
📋 결과 카드의 검산

“x = 1 대입 검산 — 원래 −1, 내 식 −9 ✘”

실험 「자유 탐구」 · y = 2x² − 8x + 5를 x항을 나누지 않고 묶었을 때

예제

y = 3x² − 12x + 7을 y = a(x − p)² + q 꼴로 고치세요.

3(x² − 4x) + 7 = 3(x² − 4x + 4 − 4) + 7 = 3(x − 2)² − 12 + 7 = 3(x − 2)² − 5. 검산: 3(x² − 4x + 4) − 5 = 3x² − 12x + 7 ✔

y = −2x² + 8x − 3의 꼭짓점과 최댓값을 구하세요.

−2(x² − 4x) − 3 = −2(x − 2)² + 8 − 3 = −2(x − 2)² + 5. 꼭짓점 (2, 5), a < 0이므로 최댓값 5.
