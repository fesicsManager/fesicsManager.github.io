중학교 3학년 수학 · 웹툰 28화 「위아래로 움직이는 값」

y = ax² + q — +q는 오른쪽이 아니라 위로 옮긴다

a와 q를 바꾸고 ‘오른쪽 이동’과 ‘위로 이동’ 중 예상을 골라 평행이동한 그래프를 기록했습니다. 같은 x에서 y값이 모두 q만큼 커져 꼭짓점이 (0, 0)에서 (0, q)로 옮겨졌고, ‘오른쪽 이동’ 예상은 x = 0에서 값이 맞지 않았습니다. y축 방향 평행이동을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 a(1, 2, −1), q(−4 ~ 4), 나의 예상을 고르고 평행이동하기를 누르면 원래 그래프의 점 다섯 개가 화살표로 움직이고 꼭짓점과 예상의 맞고 틀림이 기록됩니다. 기록 4개 이상이면 결과 비교 탭에서 q와 꼭짓점 좌표, 예상 정확도를 볼 수 있어요.

모든 기록에서 꼭짓점의 x좌표는 0 그대로였고 y좌표만 q와 똑같이 변했습니다. 오른쪽으로 q만큼 옮긴 그래프 y = a(x − q)²이라면 x = 0에서 y = aq²(예: 9, 18)이 나와야 하지만 실제 값은 q였어요. +q는 같은 x에서 y값을 q만큼 키우므로 그래프 전체가 위(q < 0이면 아래)로 움직입니다. x축 방향 이동은 y = a(x − p)² 꼴로 따로 배웁니다.

개념 정리

1. 핵심 원리

같은 x에서 y = ax² + q 의 y값은 y = ax² 의 y값보다 정확히 q만큼 큽니다. 모든 점이 세로로 q만큼 움직이므로 그래프는 y축 방향으로 q만큼 평행이동.

  • 꼭짓점: (0, 0) → (0, q)
  • 축의 방정식: x = 0 그대로
  • q < 0 이면 아래로 이동

2. 오른쪽으로 옮기려면?

x축 방향 이동은 y = a(x − p)² 꼴입니다(29화). "+q가 붙으면 오른쪽"은 이 둘을 섞은 착각이에요.

3. 확인 방법

x = 0 을 넣어 보면 됩니다. y = x² + 3 → y = 3 (꼭짓점이 y축 위에서 3). 오른쪽으로 옮긴 그래프라면 x = 0 에서 y = 9 가 나와야 해요.

회색 점선은 y = ax², 보라 실선은 y = ax² + q 입니다. q를 바꾸면 주황 화살표가 모두 같은 길이 q로 위(q < 0이면 아래)를 향해요. '착각' 단추를 누르면 오른쪽으로 옮긴 그래프 y = a(x − q)²(빨강 점선)와 비교할 수 있어요. a = 1, q = 3이면 x = 0에서 실제는 3, 착각한 그래프는 9입니다.

예제

y = −2x² − 5의 꼭짓점과 축을 쓰고, y = −2x²을 어떻게 옮긴 그래프인지 말하세요.

꼭짓점 (0, −5), 축 x = 0. y = −2x²을 y축 방향으로 −5만큼(아래로 5) 평행이동한 그래프입니다.

y = 3x²을 y축 방향으로 4만큼 평행이동했습니다. 점 (1, 3)은 어디로 옮겨지나요?

y = 3x² + 4가 되고, x는 그대로 y만 4 커지므로 (1, 3) → (1, 7). 검산: 3 × 1² + 4 = 7.
