중학교 3학년 수학 · 웹툰 27화 「아래로가 아니라 뒤집힌 것」

a의 부호 — a < 0은 ‘아래쪽’이 아니라 ‘뒤집힘’이다

y = ax² + q에서 a의 부호와 꼭짓점 높이 q를 바꾸며 볼록한 방향과 x축 위에 있는 부분을 기록했습니다. a < 0이어도 q > 0이면 그래프의 일부가 x축 위에 걸쳐 있었고, a의 부호를 바꾸면 그래프가 뒤집히기만 했습니다. a의 부호가 정하는 것은 위치가 아니라 볼록한 방향임을 정리합니다.

실험 안내: 자유 탐구 탭에서 a(−2, −1, −½, ½, 1, 2)와 꼭짓점 높이 q(0, 3, 6)를 고르고 그래프 그리기를 누르면 볼록 방향과 x축 위 부분이 기록표에 자동으로 쌓입니다. 기록이 4개 이상이면 결과 비교 탭에서 a < 0인 기록 중 x축 위에 걸친 경우를 셀 수 있어요.

표 1. a의 부호와 q에 따른 그래프의 위치 (실험 예시)
aq볼록 방향x축 위 부분
−10위로 ∩원점 빼고 x축 아래
−13위로 ∩−1.73 < x < 1.73 에서 x축 위
−16위로 ∩−2.45 < x < 2.45 에서 x축 위
−26위로 ∩−1.73 < x < 1.73 에서 x축 위
13아래로 ∪전체가 x축 위
½0아래로 ∪원점 빼고 x축 위

a < 0인 기록은 모두 위로 볼록(∩)이었지만, x축 아래에만 있었던 것은 q = 0일 때뿐입니다. q = 3, 6처럼 꼭짓점을 올리면 꼭짓점 근처가 x축 위로 올라와 −√(q/−a) < x < √(q/−a) 구간이 x축 위에 있었어요. y = ax²과 y = −ax²은 x축에 대하여 대칭이므로 a의 부호는 그래프를 뒤집을 뿐, 그래프가 x축의 위인지 아래인지는 q 등에 따라 정해집니다.

개념 정리

1. 핵심 원리

  • a > 0 : 아래로 볼록 (∪, 꼭짓점이 최저점)
  • a < 0 : 위로 볼록 (∩, 꼭짓점이 최고점)

y = ax² 과 y = −ax² 은 x축에 대하여 대칭입니다. 즉 a의 부호를 바꾸면 그래프가 뒤집힙니다. 그래프가 x축의 위쪽인지 아래쪽인지는 꼭짓점의 y좌표 q 등에 따라 달라져요.

y = ax² + q (a < 0, q > 0) 은 −√(q/−a) < x < √(q/−a) 에서 x축 위

2. 착각의 까닭

y = −x² 만 보면 원점을 빼고 모두 x축 아래라서 "아래쪽"으로 기억하기 쉽습니다. 꼭짓점을 위로 옮기면 바로 깨지는 규칙이에요.

a > 0 → 아래로 볼록(∪)  ·  a < 0 → 위로 볼록(∩)  ·  y = ax² + q (a < 0, q > 0)는 −√(q/−a) < x < √(q/−a)에서 x축 위
📋 결과 카드의 판정

“아니요! a < 0 인데 x축 위에 있는 부분이 있어요”

실험 「자유 탐구」 · a < 0, q > 0으로 그렸을 때

예제

y = −2x² + 8의 그래프가 x축 위에 있는 x의 범위를 구하세요.

−2x² + 8 > 0 → x² < 4 → −2 < x < 2. 식으로 쓰면 √(q/−a) = √(8/2) = 2. a < 0이지만 −2 < x < 2에서 x축 위에 있습니다.

y = ½x² − 2는 a > 0입니다. 이 그래프는 전부 x축 위에 있을까요?

꼭짓점이 (0, −2)로 x축 아래에 있으므로 ½x² − 2 < 0, 즉 x² < 4인 −2 < x < 2에서는 x축 아래에 있습니다. a > 0도 ‘위쪽’을 뜻하지 않아요.
