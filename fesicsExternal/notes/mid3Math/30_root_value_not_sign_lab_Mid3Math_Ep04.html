무리수와 실수 — 근호가 아니라 값으로 판단한다

근호 안에 자연수·소수·분수를 넣고 유리수인지 무리수인지 먼저 예측한 뒤 값을 확인했습니다. √4, √0.04, √(8/18)처럼 근호가 붙어 있어도 유리수인 수가 있었고, √0.4는 0.2가 아닌 무리수였습니다. 유리수·무리수·실수의 뜻과 근호가 붙은 수를 판정하는 방법을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 근호 안의 수 종류(자연수, 소수, 분수)와 수, 내 예측(유리수, 무리수)을 고르고 값 확인하기를 누르면 기약분수로 고친 모습, 값, 분류, 예측이 맞았는지가 기록됩니다. 기록이 4개 이상이면 결과 비교 탭에서 근호가 있어도 유리수였던 수를 모아 볼 수 있어요.

표 1. 근호가 붙은 수의 분류 (실험 예시)
수기약분수로값분류
√442유리수
√20204.4721359…무리수
√0.041/251/5 = 0.2유리수
√0.42/50.6324555…무리수
√2.259/43/2 = 1.5유리수
√(8/18)4/92/3유리수

근호가 붙은 일곱 수 가운데 네 수가 유리수였습니다. √4 = 2, √0.04 = 0.2, √2.25 = 1.5, √(8/18) = √(4/9) = 2/3처럼 근호 안의 수를 기약분수로 고쳤을 때 분자와 분모가 모두 제곱수이면 근호가 벗겨져 유리수가 되었어요. √20, √0.4, √(2/9)는 그렇지 않아 순환하지 않는 무한소수, 곧 무리수였습니다. 특히 0.2² = 0.04이므로 √0.4는 0.2가 아니에요. “근호가 있으면 무리수”가 아니라 값을 보고 판단해야 합니다.

개념 정리

1. 유리수와 무리수

  • 유리수: (정수)/(0이 아닌 정수) 꼴의 분수로 나타낼 수 있는 수. 예) 3, −2, 1/2, 0.75, 0.333…
  • 무리수: 유리수가 아닌 수, 곧 순환하지 않는 무한소수. 예) √2, √5, π
  • 실수 = 유리수 + 무리수

2. 근호가 붙은 수 판정하기

  1. 근호 안의 수를 기약분수로 고친다. (0.04 = 1/25, 8/18 = 4/9, 0.4 = 2/5)
  2. 분자와 분모가 모두 제곱수인지 본다.
  3. 모두 제곱수이면 근호가 벗겨져 유리수, 아니면 무리수.
√(a²/b²) = a/b (a, b는 자연수)  ·  실수 = 유리수 + 무리수

“표기가 아니라 값으로 판단한다”

3. 자주 하는 실수

√0.4 = 0.2라고 쓰기 쉽지만 0.2² = 0.04입니다. √0.04 = 0.2이고, √0.4 = √(2/5) ≈ 0.632…는 무리수예요. 소수의 근호는 분수로 바꾸어 확인하세요.

📋 결과 카드의 판정

“내 예측 무리수 → 틀렸어요 ✘”

실험 「자유 탐구」 · √(8/18)을 무리수로 예측했을 때 (8/18 = 4/9 → 2/3)

예제

다음 중 무리수를 모두 고르세요. √16, √0.09, √12, −√(1/9), √0.9, π

√16 = 4, √0.09 = 0.3, −√(1/9) = −1/3은 유리수. √12, √0.9 = √(9/10), π는 무리수입니다.

√(18/50)은 유리수인지 무리수인지 판정하세요.

18/50 = 9/25로 약분되고 9 = 3², 25 = 5²이므로 √(18/50) = 3/5, 유리수입니다.

“순환소수는 무리수이다.” 이 말을 바르게 고치세요.

순환소수는 분수로 나타낼 수 있으므로 유리수입니다. 무리수는 순환하지 않는 무한소수예요.
