중학교 3학년 수학 · 웹툰 15화 「합과 곱을 동시에」

x² + px + q의 인수분해 — 합과 곱을 동시에 맞춘다

인수분해할 식을 고르고 두 수 m, n을 정해 (x + m)(x + n)으로 전개한 결과를 기록했습니다. 곱만 맞으면 x의 계수가, 합만 맞으면 상수항이 틀렸고, 합과 곱을 동시에 만족하는 쌍만 정답이었습니다. 합과 곱으로 인수분해하는 방법을 정리합니다.

실험 데이터 되짚기

실험 안내: 🔬 자유 탐구 탭에서 인수분해할 식(x² + 5x + 6 등 6개)을 고르고 첫째 수 m, 둘째 수 n(각각 −6 ~ 6)을 정한 뒤 두 수로 전개해 보기를 누르면 합, 곱, 판정(정답 / 곱만 / 합만 / 둘 다 ✘)이 기록됩니다. 기록이 4개 이상이면 ✅ 결과 비교 탭에서 판정별 기록 수와 식별 정답 쌍을 볼 수 있습니다.

표 1. 고른 두 수의 합·곱과 판정 (실험 예시)

x² + 5x + 61676곱만
x² + 5x + 61454합만

x² + 5x + 6에서 (1, 6)은 곱만 맞아 x² + 7x + 6, (1, 4)는 합만 맞아 x² + 5x + 4가 되었고, 합 5와 곱 6을 동시에 만족하는 (2, 3)만 정답이었습니다. (m, n) 평면에서 곱 조건 mn = q는 곡선, 합 조건 m + n = p는 직선이고 두 그래프가 만나는 격자점이 답입니다. 상수항이 음수이면 두 수의 부호가 다릅니다.

개념 정리

1. 합과 곱을 동시에 맞추기

(x + m)(x + n) = x² + (m + n)x + mn 이므로 x² + px + q 를 인수분해하려면 합이 p, 곱이 q인 두 정수를 동시에 찾아야 합니다.

  • 곱만 맞추면: 6 = 1 × 6 → (x + 1)(x + 6) = x² + 7x + 6 (x의 계수가 틀림)
  • 합만 맞추면: 5 = 1 + 4 → (x + 1)(x + 4) = x² + 5x + 4 (상수항이 틀림)

2. 찾는 순서

곱이 q인 정수 쌍을 먼저 모두 적고(부호 포함), 그중 합이 p인 쌍을 고르면 빠르고 확실합니다. q가 음수면 두 수의 부호가 달라요.

3. 그림 읽기

mn = q 는 반비례 그래프(쌍곡선), m + n = p 는 기울기 −1인 직선입니다. 두 그래프의 교점이 곧 인수분해의 답이에요.

(x + m)(x + n) = x² + (m + n)x + mn  ·  x² + px + q → m + n = p 이고 mn = q

예제

x² − 2x − 15를 인수분해하시오.

곱이 −15인 정수 쌍: (1, −15), (−1, 15), (3, −5), (−3, 5). 이 중 합이 −2인 쌍은 (3, −5)입니다. (x + 3)(x − 5)

x² + 9x + 20을 인수분해하시오.

곱이 20이고 합이 9인 두 수는 4와 5입니다. (x + 4)(x + 5)
