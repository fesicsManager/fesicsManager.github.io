중학교 3학년 수학 · 웹툰 18화 「0일 때만 특별하다」

AB = 0의 성질 — 곱이 0일 때만 각 인수를 0으로 놓는다

(x − 2)(x − 3) = k의 k와 풀이 방법을 바꾸며 구한 x를 대입한 값을 기록했습니다. ‘각 인수 = k’ 방법은 k = 0일 때만 모두 통과했고, 전개해서 한쪽을 0으로 만든 방법은 언제나 통과했습니다. AB = 0의 성질과 올바른 풀이 순서를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 🔬 자유 탐구 탭에서 (x − 2)(x − 3) = k의 k(0, 2, 6, 12, 20)와 풀이 방법(A = k 또는 B = k로 풀기 / 전개해서 한쪽을 0으로)을 고르고 풀고 대입하기를 누르면 구한 x, 대입 값, 통과 수가 기록됩니다. 기록이 4개 이상이면 ✅ 결과 비교 탭에서 방법별 대입 통과율을 볼 수 있습니다.

표 1. k와 방법에 따른 해와 대입 결과 (실험 예시)
k방법구한 x대입 값통과
0인수 = k2, 30, 02/2
2인수 = k4, 52, 61/2
2= 0 정리1, 42, 22/2
6인수 = k8, 930, 420/2
6= 0 정리0, 56, 62/2
12= 0 정리−1, 612, 122/2

k = 6에서 ‘인수 = k’로 구한 x = 8, 9를 넣으면 30, 42가 나와 하나도 통과하지 못했습니다. 곱이 6이 되는 조합은 1 × 6, 2 × 3, (−2) × (−3) …처럼 무수히 많아 각 인수를 정할 수 없기 때문입니다. 곱해서 0이 되려면 적어도 하나가 0이어야 하므로 반드시 한쪽을 0으로 만든 뒤 인수분해합니다. k = 2에서 x = 4가 통과한 것은 다른 인수 x − 3이 우연히 1이었기 때문입니다.

개념 정리

1. 곱이 0인 경우만 특별

AB = 0 ⇔ A = 0 또는 B = 0. 0은 곱해서 0을 만드는 유일한 수이기 때문이에요.

하지만 AB = 6 은 1 × 6, 2 × 3, 0.5 × 12, (−2) × (−3) … 처럼 무수히 많은 조합이 가능해서 A나 B의 값을 정할 수 없습니다.

2. 올바른 풀이

(x − 2)(x − 3) = 6 → x² − 5x + 6 = 6 → x² − 5x = 0 → x(x − 5) = 0 → x = 0 또는 5. 한쪽을 반드시 0으로 만든 뒤 인수분해해요.

3. 우연히 맞는 경우

k = 2 에서 "x − 3 = 2 → x = 5" 는 틀리지만 "x − 2 = 2 → x = 4" 는 (4 − 2)(4 − 3) = 2 로 우연히 맞습니다. 방법이 옳아서가 아니라 다른 인수가 1이 되었기 때문이에요.

AB = 0 ⇔ A = 0 또는 B = 0  ·  (x − 2)(x − 3) = k → x² − 5x + (6 − k) = 0

예제

(x − 2)(x − 3) = 12를 푸시오.

x² − 5x + 6 = 12 → x² − 5x − 6 = 0 → (x + 1)(x − 6) = 0. 대입하면 (−3)(−4) = 12, 4 × 3 = 12. x = −1 또는 x = 6

(x + 1)(x − 4) = 6을 푸시오.

x² − 3x − 4 = 6 → x² − 3x − 10 = 0 → (x − 5)(x + 2) = 0. 대입하면 6 × 1 = 6, (−1)(−6) = 6. x = 5 또는 x = −2
