이차방정식의 뜻 — 정리한 뒤 x²이 남아야 이차방정식

방정식을 고르고 이차방정식인지 예측한 뒤, 모든 항을 좌변으로 옮겨 정리한 결과를 기록했습니다. 양변에 x²이 똑같이 있는 식은 x²이 사라져 일차방정식이나 거짓 등식이 되었고, x²이 안 보이던 x(x + 1) = 5는 이차방정식이었습니다. 이차방정식을 판단하는 순서를 정리합니다.

표 1. 정리한 식과 판정 (실험 예시)
방정식정리한 식판정예측맞음
x² + 3x = x² − 23x + 2 = 0일차방정식이차아니오
x(x + 1) = 5x² + x − 5 = 0이차방정식아님아니오
(x + 2)² = x² + 4x4 = 0해가 없는 식 (거짓 등식)이차아니오
2x² = (x + 1)²x² − 2x − 1 = 0이차방정식이차예
(x − 1)(x + 1) = x²−1 = 0해가 없는 식 (거짓 등식)아님예
x² = 2x²−x² = 0이차방정식아님아니오

x² + 3x = x² − 2는 정리하면 3x + 2 = 0으로 일차방정식, (x + 2)² = x² + 4x는 4 = 0인 거짓 등식이었습니다. 반대로 x² = 2x²은 −x² = 0으로 x²의 계수가 −1이라 이차방정식입니다. 겉모양이 아니라 정리한 뒤 x²의 계수가 0이 아닌지로 판단해야 합니다. 그래프 y = (좌변) − (우변)이 포물선이면 이차, 직선이면 아닙니다.

개념 정리

1. 정리한 뒤 x²의 계수로 판단

모든 항을 좌변으로 옮겨 정리했을 때 ax² + bx + c = 0 (a ≠ 0) 꼴이 되어야 이차방정식입니다.

  • x² + 3x = x² − 2 → 3x + 2 = 0 : x²이 사라져 일차방정식
  • (x + 2)² = x² + 4x → 4 = 0 : x가 모두 사라지고 거짓인 등식 → 해가 없음
  • x(x + 1) = 5 → x² + x − 5 = 0 : 처음엔 x²이 안 보여도 이차방정식

2. 판단 순서

① 괄호를 전개한다 → ② 모든 항을 한쪽으로 옮긴다 → ③ 동류항을 정리한다 → ④ x² 계수가 0이 아닌지 본다.

3. 그래프로 보기

y = ax² + bx + c 는 a ≠ 0일 때 포물선, a = 0이면 직선입니다. 그래프 모양으로도 차수를 확인할 수 있어요.

처음 모양만 보고 판단하지 말고 ① 전개 → ② 한쪽으로 옮기기 → ③ 동류항 정리 → ④ x² 계수 확인 순서로 정리해 보세요. 오른쪽 그래프는 y = (좌변) − (우변)입니다. 포물선이면 이차방정식, 직선이면 일차방정식이고, x축과 만나는 점(빨간 점)의 x좌표가 해예요. (x + 2)² = x² + 4x는 x축과 만나지 않는 수평선 y = 4 → 해가 없습니다.

(좌변) − (우변) = 0으로 정리 → ax² + bx + c = 0 (a ≠ 0)이면 이차방정식

예제

2x² + x = 2x² − 3x + 1은 이차방정식인가?

모든 항을 좌변으로 옮기면 2x² − 2x² + x + 3x − 1 = 4x − 1 = 0으로 x²이 사라집니다. 이차방정식이 아니다(일차방정식)

(x − 3)² = 2x는 이차방정식인가?

전개하면 x² − 6x + 9 = 2x → x² − 8x + 9 = 0이고 x²의 계수가 1 ≠ 0입니다. 이차방정식이다
