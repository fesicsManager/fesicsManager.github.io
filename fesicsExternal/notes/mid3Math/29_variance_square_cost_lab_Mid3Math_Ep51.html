중학교 3학년 수학 · 웹툰 51화 「제곱에는 대가가 있다」

분산 — 편차를 제곱하면 극단값에 민감해지고 단위가 바뀐다

공부 시간 자료 다섯 개 중 마지막 값에 k시간을 더해 극단값을 만들며 편차 절댓값의 평균, 분산, 표준편차를 기록했습니다. k가 커질수록 분산은 절댓값 평균보다 훨씬 가파르게 커졌고, 가장 큰 편차가 차지하는 몫도 제곱하면 더 커졌습니다. 분산이 편차를 제곱하는 까닭과 그 대가를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 자료(A: 2, 3, 3, 4, 3 / B: 1, 5, 2, 4, 3), 마지막 값에 더할 시간 k(0 ~ 6), 강조해서 볼 값을 고르고 흩어짐 재기를 누르면 절댓값 평균, 분산, 표준편차가 기록됩니다. k를 0, 2, 4, 6처럼 바꿔 4개 이상 기록하면 결과 비교 탭에서 k에 따른 세 값의 그래프를 볼 수 있어요. (자료는 계산을 위한 가상 자료입니다.)

자료k절댓값 평균분산표준편차가장 큰 편차의 몫 (|편차| → 편차²)

자료 A에서 k를 0에서 6으로 키우자 절댓값 평균은 0.400 → 1.920으로 약 5배, 분산은 0.400 → 6.160으로 약 15배가 되었습니다. 편차가 2배이면 절댓값의 기여는 2배지만 제곱의 기여는 4배이므로 분산은 평균에서 멀리 떨어진 극단값에 훨씬 민감해요. 또 분산의 단위는 시간²이라 원래 단위로 되돌리려고 제곱근을 씌운 표준편차를 씁니다. 제곱은 계산과 증명이 편한 대신 이런 대가를 치릅니다.

개념 정리

1. 핵심 원리

편차 = 자료 − 평균, 편차의 합 = 0 (항상)

  • 편차 절댓값의 평균: 부호만 없앱니다. 편차가 2배면 기여도 2배.
  • 분산 = (편차²의 평균): 편차가 2배면 기여는 4배. 평균에서 멀리 떨어진 값(극단값)에 훨씬 민감해요.
  • 표준편차 = √분산: 분산의 단위는 시간²이라 원래 단위(시간)로 되돌리기 위해 제곱근을 씌웁니다.

평균 절댓값 평균 분산 표준편차 가장 큰 편차의 몫

주황 막대가 편차(자료 − 평균)입니다. 아래 두 띠는 전체 가운데 각 값이 차지하는 몫인데, 빨간 칸(가장 큰 편차)은 제곱하면 몫이 더 커져요. k를 0, 2, 4, 6으로 바꿔 표 1과 맞춰 보세요(가상 자료).

2. 그래도 제곱을 쓰는 까닭

제곱은 계산·증명이 편하고(절댓값처럼 꺾이는 곳이 없음), 평균이 편차 제곱의 합을 가장 작게 만드는 값이 되는 등 좋은 성질이 많습니다. 대신 극단값에 민감하고 단위가 바뀌는 대가를 치러요.

3. 실험 모형

자료는 5개, 마지막 값에 k시간을 더해 극단값을 만듭니다. 분산은 (편차²의 합) ÷ 자료 수 로 계산해요.

편차 = 자료 − 평균, 편차의 합 = 0  ·  분산 = (편차²의 합) ÷ (자료 수)  ·  표준편차 = √분산

분산: 시간², 표준편차·편차 절댓값의 평균: 시간

예제

자료 1, 2, 3, 4, 5의 편차 절댓값의 평균, 분산, 표준편차를 구하세요.

평균 3, 편차 −2, −1, 0, 1, 2. 절댓값 평균 = (2 + 1 + 0 + 1 + 2) ÷ 5 = 1.2, 분산 = (4 + 1 + 0 + 1 + 4) ÷ 5 = 2, 표준편차 = √2 ≈ 1.41.

편차가 1인 자료와 3인 자료가 있습니다. 절댓값 기준과 제곱 기준에서 두 자료의 기여는 각각 몇 배 차이가 나나요?

절댓값 기준 1 : 3으로 3배, 제곱 기준 1 : 9로 9배. 제곱하면 큰 편차의 몫이 훨씬 커집니다.
