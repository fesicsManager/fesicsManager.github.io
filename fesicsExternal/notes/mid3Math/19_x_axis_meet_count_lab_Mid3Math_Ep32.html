중학교 3학년 수학 · 웹툰 32화 「만나지 않을 수도 있다」

그래프와 x축의 교점 — 0개, 1개, 2개 모두 가능하다

a와 꼭짓점 (p, q)를 바꾸며 포물선이 x축과 만나는 점의 개수와 판별식 b² − 4ac를 기록했습니다. 교점은 2개뿐 아니라 1개(접함), 0개인 경우도 있었고, 그 개수는 a와 q의 부호로 정해졌습니다. 교점의 개수를 꼭짓점과 판별식으로 판단하는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 a(1, −1, 2, ½), 꼭짓점의 x좌표 p(−1, 0, 2), y좌표 q(−4 ~ 4), 나의 예상을 고르고 그래프 그리기를 누르면 교점과 판별식 D가 기록됩니다. 기록 4개 이상이면 결과 비교 탭에서 교점 개수별 기록과 a × q의 부호를 비교할 수 있어요.

표 1. 꼭짓점과 교점의 개수 (실험 예시)
a꼭짓점일반형D교점 수
1(0, −3)y = x² − 3122개
1(2, 0)y = x² − 4x + 401개
1(2, 3)y = x² − 4x + 7−120개
−1(−1, 3)y = −x² − 2x + 2122개
−1(0, −3)y = −x² − 3−120개

아래로 볼록(a > 0)인데 꼭짓점이 x축 위(q > 0)에 있거나, 위로 볼록(a < 0)인데 꼭짓점이 x축 아래(q < 0)에 있으면 그래프는 x축과 만나지 않았습니다. 판별식은 D = −4aq이므로 a와 q의 부호가 다르면 2개, q = 0이면 1개, 부호가 같으면 0개예요. 이것은 이차방정식 ax² + bx + c = 0의 실근의 개수와 같은 이야기입니다.

개념 정리

1. 핵심 원리

y = a(x − p)² + q 의 그래프가 x축과 만나는 점의 개수는 꼭짓점의 높이 q와 볼록한 방향 a로 결정됩니다.

  • a > 0 (∪): q < 0 → 2개, q = 0 → 1개(접함), q > 0 → 0개
  • a < 0 (∩): q > 0 → 2개, q = 0 → 1개, q < 0 → 0개

일반형 y = ax² + bx + c 로 전개하면 D = b² − 4ac = −4aq 가 되어, D > 0 → 2개, D = 0 → 1개, D < 0 → 0개와 같은 결론이에요.

2. 착각의 까닭

교과서 예제가 주로 x축과 두 점에서 만나는 그래프라 생기는 오해입니다. 이차방정식 ax² + bx + c = 0 이 해가 없을 수 있는 것과 같은 이야기예요.

y = a(x − p)² + q → 일반형의 D = b² − 4ac = −4aq  ·  D > 0 → 2개, D = 0 → 1개, D < 0 → 0개

예제

y = x² − 4x + 5의 그래프가 x축과 만나는지 판별식과 표준형으로 확인하세요.

D = (−4)² − 4 × 1 × 5 = −4 < 0. 표준형 y = (x − 2)² + 1은 아래로 볼록이고 꼭짓점 (2, 1)이 x축 위에 있습니다. 두 방법 모두 만나지 않는다(0개).

y = −2(x − 1)² + 8과 x축의 교점의 x좌표를 구하세요.

a < 0, q > 0이므로 2개. −2(x − 1)² + 8 = 0 → (x − 1)² = 4 → x − 1 = ±2 → x = −1, 3.
