이차함수의 뜻 — 방정식은 점 몇 개, 함수는 곡선 전체

같은 식을 방정식 모드와 함수 모드로 계산하며 기록했습니다. 방정식 모드는 x² − 2x − 3 = 0을 만드는 x = −1, 3 두 수만 주었고, 함수 모드는 x를 넣을 때마다 y를 하나씩 만들어 점들이 포물선을 이루었습니다. 이차방정식과 이차함수의 차이와 관계를 정리합니다.

실험 안내: 🔬 자유 탐구 탭에서 식(x² − 2x − 3, x² − 4, −x² + 2x + 3)과 모드(방정식: 0이 되는 x 찾기 / 함수: x를 넣어 y 구하기)를 고르고, 함수 모드에서는 넣을 x(−3 ~ 5, 0.5 간격)를 정해 계산하기를 누릅니다. x를 여러 번 바꿔 4개 이상 기록하면 ✅ 결과 비교 탭에서 모은 점과 방정식의 해를 한 그래프로 볼 수 있습니다.

함수 모드에서 x = −2, −1, 0, 1, 3을 넣으니 y = 5, 0, −3, −4, 0으로 점이 하나씩 생겨 포물선을 이루었습니다. 그중 y = 0이 된 점(x = −1, 3)이 바로 방정식의 해입니다. 이차방정식은 등식을 참으로 만드는 x를 찾는 ‘질문’이고, 이차함수는 모든 x에 y를 하나씩 대응시키는 ‘규칙’입니다. 식은 같아도 묻는 것이 다릅니다.

개념 정리

1. 이차방정식과 이차함수

  • 이차방정식 ax² + bx + c = 0 : 등식을 참으로 만드는 x의 값(해)을 찾는 문제. 답은 수 0~2개.
  • 이차함수 y = ax² + bx + c : x의 값 하나하나에 y의 값을 하나씩 대응시키는 규칙. 그래프는 곡선(포물선) 전체.

방정식 ax² + bx + c = 0 의 해 = 함수 y = ax² + bx + c 의 그래프가 x축과 만나는 점의 x좌표

2. 비유

함수는 "자판기"(넣으면 나온다), 방정식은 "질문"(무엇을 넣으면 0이 나오나?)입니다. 같은 식을 쓰지만 묻는 것이 달라요.

이차함수 y = ax² + bx + c (a ≠ 0)  ·  ax² + bx + c = 0의 해 = 그래프와 x축이 만나는 점의 x좌표

예제

y = x² − 4에서 x = 3일 때 y의 값과, 이차방정식 x² − 4 = 0의 해를 구하시오.

함수: y = 9 − 4 = 5이므로 점 (3, 5). 방정식: x² = 4 → x = ±2. y = 5, 해 x = ±2 (그래프가 x축과 만나는 점의 x좌표)

y = 2x + 1, y = x² − x, x² − x = 0, y = 3 중 이차함수를 고르시오.

y = 2x + 1은 일차함수, x² − x = 0은 이차방정식, y = 3은 상수함수입니다. y가 x의 이차식으로 나타나는 것은 y = x² − x
