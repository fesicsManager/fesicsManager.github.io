제곱근을 이용한 풀이 — (x − p)² = q이면 x = p ± √q

p, q와 풀이 방법(+√q만 / ±√q)을 바꾸며 구한 해를 포물선 y = (x − p)²과 수평선 y = q의 교점과 비교해 기록했습니다. q > 0이면 ‘+√q만’ 방법은 해를 하나 놓쳤고, q = 0이면 해가 하나, q < 0이면 해가 없었습니다. 제곱근을 이용해 이차방정식을 푸는 방법을 정리합니다.

(x − 1)² = 4를 x − 1 = 2로만 풀면 x = 3 하나뿐이지만, 그래프는 x = −1에서도 만납니다. x − 1은 제곱해서 4가 되는 수, 곧 ±2이기 때문입니다. q = 0이면 꼭짓점에서 접해 중근 x = p 하나, q < 0이면 제곱이 음수가 될 수 없어 해가 없습니다. q가 제곱수가 아니면 1 ± √2처럼 근호가 남습니다.

개념 정리

1. 제곱해서 q가 되는 수는 ±√q

(x − p)² = q (q > 0) → x − p = ±√q → x = p ± √q

x − p 는 제곱해서 q가 되는 수, 즉 q의 제곱근입니다. 1화에서 본 것처럼 양수의 제곱근은 두 개예요.

  • q > 0 : 해 2개 (포물선과 수평선이 두 점에서 만남)
  • q = 0 : 해 1개, x = p (중근 — 꼭짓점에서 접함)
  • q < 0 : 해 없음 (제곱은 음수가 될 수 없음)

해의 개수 해 근삿값

주황 화살표는 x = p에서 왼쪽·오른쪽으로 똑같이 √q만큼 떨어져 있어요. 그래서 해는 p + √q 와 p − √q 두 개입니다. q = 0이면 꼭짓점에서 한 점(중근), q가 음수면 만나지 않아요. p = 1, q = 2로 두고 1 ± √2 를 확인해 보세요.

2. 무리수 해

q가 제곱수가 아니면 해는 p ± √q 처럼 근호가 남습니다. 예: (x − 1)² = 2 → x = 1 ± √2 (≈ 2.414, −0.414)

(x − p)² = q (q > 0) → x − p = ±√q → x = p ± √q

예제

(x + 1)² = 16을 푸시오.

x + 1 = ±4이므로 x = −1 + 4 = 3 또는 x = −1 − 4 = −5. x = 3 또는 x = −5

(x − 3)² = 5를 푸시오.

x − 3 = ±√5이므로 x = 3 ± √5 (≈ 5.236, 0.764)
