중학교 3학년 수학 · 웹툰 10화 「네 번 곱해야 한다」

다항식의 곱셈 — (x + a)(x + b)는 네 조각을 모두 곱한다

a, b와 전개 방법을 고르고 x에 수를 넣어 직사각형의 실제 넓이와 내 식의 값을 비교해 기록했습니다. 앞끼리·뒤끼리만 곱하면 늘 (a + b)x만큼 모자랐고, 네 번 모두 곱하면 차이가 0이었습니다. 분배법칙으로 전개하는 원리를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 🔬 자유 탐구 탭에서 a(1 ~ 5), b(1 ~ 5), 전개 방법(앞끼리·뒤끼리만 곱하기 / 네 번 모두 곱하기), 확인할 x(1 ~ 10)를 고르고 넓이로 확인하기를 누르면 실제 넓이와 내 식의 값, 차이가 기록됩니다. 기록이 4개 이상이면 ✅ 결과 비교 탭에서 x에 따른 오차 그래프를 볼 수 있습니다.

(x + 2)(x + 3)을 앞끼리·뒤끼리만 곱하면 x = 1, 5, 10에서 차이가 5, 25, 50으로, 언제나 빠진 두 조각 (a + b)x = 5x와 같았습니다. 가로와 세로를 두 토막씩 내면 조각은 x², bx, ax, ab 네 개이므로 곱셈도 2 × 2 = 4번 해야 합니다. 네 번 모두 곱하면 어떤 x에서도 차이가 0입니다.

개념 정리

1. 분배법칙을 두 번

(x + a)(x + b) = x·x + x·b + a·x + a·b = x² + (a + b)x + ab

앞 괄호의 두 항이 뒤 괄호의 두 항과 한 번씩 모두 만나야 하므로 곱은 2 × 2 = 4번입니다. 직사각형 그림에서도 가로를 두 토막, 세로를 두 토막 내면 조각은 네 개예요.

2. 앞끼리·뒤끼리의 대가

x² + ab 만 쓰면 넓이 (a + b)x 만큼이 빠집니다. x가 클수록 빠진 양도 커져요. x = 0 일 때만 우연히 맞습니다.

3. 그림 읽기

그림은 선택한 x 값에 맞춰 실제 비율로 그렸습니다. 음수 a, b에서도 식은 똑같이 성립하지만, 넓이 그림은 양수일 때만 그릴 수 있어요.

(x + a)(x + b) = x² + bx + ax + ab = x² + (a + b)x + ab

예제

(x + 4)(x + 6)을 전개하시오.

x·x + x·6 + 4·x + 4·6 = x² + 10x + 24. x² + 10x + 24

(x + 3)(x + 5)를 x² + 15로 잘못 전개했다. x = 4에서 실제 값과 얼마나 차이 나는가?

실제 값은 7 × 9 = 63, 잘못된 식의 값은 16 + 15 = 31입니다. 차이는 63 − 31 = 32 = (3 + 5) × 4입니다. 32
