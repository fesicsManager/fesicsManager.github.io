제곱근의 뜻 — 양수의 제곱근은 두 개다

제곱근을 찾을 수를 고르고 개수를 예측한 뒤, x를 바꿔 가며 제곱해서 그 수에 도착하는지 기록했습니다. 9에는 3과 −3 두 화살표가 도착했고, 0에는 하나, −4에는 하나도 도착하지 않았습니다. 제곱근의 개수와 √ 기호의 뜻을 정리합니다.

실험 안내: 🔬 자유 탐구 탭에서 제곱근을 찾을 수(4, 9, 16, 25, 2, 0, −4)와 ‘제곱근은 몇 개일까?’ 예측을 고르고, 확인할 수 x(−6 ~ 6, 0.5 간격)를 정한 뒤 제곱해서 확인하기를 누르면 결과가 기록표에 자동으로 쌓입니다. 기록이 4개 이상이면 ✅ 결과 비교 탭에서 수별로 찾은 x와 예측 정확도를 볼 수 있습니다.

9를 고르면 x = 3과 x = −3 두 수가 모두 9에 도착합니다. 제곱은 부호를 지우는 계산이라, 거꾸로 제곱근을 찾을 때는 양수 a마다 √a와 −√a 두 갈래가 생깁니다. 0에 도착하는 수는 0 하나뿐이고, −4에는 어떤 x도 도착하지 않습니다. 2의 제곱근 ±√2(≈ ±1.414)는 0.5 간격 눈금으로 딱 맞출 수는 없지만(1.5² = 2.25) 분명히 두 개 있습니다.

개념 정리

1. 제곱해서 a가 되는 수는 두 개

x² = a 를 만족하는 x 를 a의 제곱근이라고 합니다. 3² = 9 이고 (−3)² = 9 이므로 9의 제곱근은 3과 −3, 두 개예요.

  • 양수 a의 제곱근: 양수 하나(√a), 음수 하나(−√a) → 합쳐서 ±√a
  • 0의 제곱근: 0 하나뿐 (0² = 0)
  • 음수의 제곱근: 없음 (어떤 수를 제곱해도 음수가 되지 않으므로, 실수 범위)

2. ‘9의 제곱근’과 √9는 다르다

√9는 기호로, 9의 양의 제곱근 하나만 가리킵니다. 그래서 √9 = 3 이지만 "9의 제곱근"은 ±3 입니다.

3. 그림 읽기

화살표 두 개가 한 점에 모이는 것은 x와 −x를 제곱하면 같은 값이 되기 때문입니다. 제곱은 부호 정보를 지우는 계산이라, 거꾸로 갈 때는 두 갈래가 생겨요.

x² = a (a > 0) ⇔ x = ±√a  ·  √a는 a의 양의 제곱근 하나

예제

25의 제곱근과 √25를 각각 구하시오.

제곱해서 25가 되는 수는 5와 −5이므로 25의 제곱근은 ±5입니다. √25는 양의 제곱근 하나만 가리키므로 5입니다. 25의 제곱근: ±5, √25 = 5

7, 0, −9, 0.16 중에서 제곱근이 없는 수와 제곱근이 하나뿐인 수를 고르시오.

7의 제곱근은 ±√7, 0.16의 제곱근은 ±0.4로 두 개씩입니다. 0의 제곱근은 0 하나뿐이고, −9는 어떤 수를 제곱해도 될 수 없으므로 제곱근이 없습니다. 없는 수: −9, 하나뿐인 수: 0
