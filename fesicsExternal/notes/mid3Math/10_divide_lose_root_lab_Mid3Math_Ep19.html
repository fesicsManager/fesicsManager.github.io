중학교 3학년 수학 · 웹툰 19화 「나누면 해가 사라진다」

인수분해로 풀기 — 양변을 x로 나누면 해를 잃는다

방정식과 풀이 방법(양변을 공통인수로 나누기 / 한쪽으로 모아 인수분해)을 골라 구한 해의 수를 그래프의 교점 수와 비교해 기록했습니다. 나누기 방법은 언제나 해를 하나 놓쳤고, 놓친 해는 나눈 식이 0이 되는 값이었습니다. 이차방정식을 안전하게 푸는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 🔬 자유 탐구 탭에서 방정식(x² = 3x, 2x² = 6x, x² = −2x, 3x² = x, (x − 2)(x + 1) = 4(x − 2))과 풀이 방법을 고르고 풀어서 비교하기를 누르면 좌변·우변 그래프와 함께 구한 해, 전체 해, 놓친 해의 수가 기록됩니다. 기록이 4개 이상이면 ✅ 결과 비교 탭에서 방법별로 찾은 해의 비율을 볼 수 있습니다.

표 1. 풀이 방법별로 찾은 해의 수 (실험 예시)
방정식방법구한 해전체 해놓침
x² = 3x나누기1개2개1개
x² = 3x인수분해2개2개0개
3x² = x나누기1개2개1개
3x² = x인수분해2개2개0개
(x − 2)(x + 1) = 4(x − 2)나누기1개2개1개
(x − 2)(x + 1) = 4(x − 2)인수분해2개2개0개

x² = 3x를 x로 나누면 x = 3만 남지만 그래프는 x = 0에서도 만납니다. (x − 2)(x + 1) = 4(x − 2)를 x − 2로 나누면 x = 2를 잃습니다. 나누려면 나누는 식이 0이 아니어야 하는데, 바로 그 값이 해일 수 있기 때문입니다. 모든 항을 한쪽으로 모아 x(x − 3) = 0처럼 인수분해하면 해를 모두 찾습니다.

개념 정리

1. 0으로는 나눌 수 없다

양변을 x로 나누려면 x ≠ 0 이어야 합니다. 그런데 x = 0이 해일 수도 있죠. 나누는 순간 그 가능성을 버리게 돼요.

x² = 3x → x² − 3x = 0 → x(x − 3) = 0 → x = 0 또는 x = 3

  • (x − 2)(x + 1) = 4(x − 2) 에서 (x − 2)로 나누면 x = 3 만 남고 x = 2 를 잃습니다.
  • 안전한 방법: 모든 항을 한쪽으로 옮겨 = 0 을 만든 뒤 인수분해

2. 그래프로 보기

좌변 그래프와 우변 그래프가 만나는 점마다 해가 하나씩 있습니다. 이차방정식은 해가 최대 2개예요.

1
좌변 우변 판정

x를 바꾸며 초록 점선 위의 빨간 점(좌변)과 파란 점(우변)이 같은 높이가 되는 곳을 찾아보세요. 만나는 점이 2개이니 해도 2개입니다. '양변을 나누면?'을 누르면 나누는 순간 사라지는 해가 보여요.

x² = 3x → x² − 3x = 0 → x(x − 3) = 0 → x = 0 또는 x = 3

예제

x² = 5x를 푸시오.

x² − 5x = 0 → x(x − 5) = 0이므로 x = 0 또는 x = 5. 양변을 x로 나누면 x = 0을 잃습니다.

(x − 1)(x + 4) = 2(x − 1)을 푸시오.

(x − 1)(x + 4) − 2(x − 1) = 0 → (x − 1)(x + 4 − 2) = (x − 1)(x + 2) = 0. x = 1 또는 x = −2
