일반화 좌표와 제약 — 좌표 하나로 푸는 애트우드 장치

실험에서 두 추의 질량 m₁, m₂(0.5~3 kg)와 도르래(질량 없음·원판·고리), 푸는 방식(뉴턴·라그랑주)을 바꿔 가며 추를 놓고 위치–시간 기록에서 가속도를 맞춤으로 구했습니다. 가속도는 a = (m₁ − m₂)g/(m₁ + m₂ + I/R²)를 따라 도르래 관성이 클수록 줄었고, 뉴턴 방식과 라그랑주 방식은 같은 값을 주었으며 장력은 뉴턴 방식에서만 나왔습니다. 홀로노믹 제약, 일반화 좌표, 구속력이 라그랑주 방정식에 나타나지 않는 까닭을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 m₁(내려가는 쪽)과 m₂(0.5~3 kg, 0.25 kg 간격), 도르래(질량 없음 I/R² = 0/원판 M = 1 kg, I/R² = 0.5 kg/고리 M = 1 kg, I/R² = 1 kg), 푸는 방식(뉴턴/라그랑주)을 정하고 놓아서 측정하기를 누르면 1.2 s 동안의 위치 기록을 q = ½at²로 맞춘 측정 가속도와 이론값이 기록표에 자동으로 쌓입니다(뉴턴 방식이면 결과 칸에 장력 T₁, T₂도 표시). 도르래를 바꿔 가며 질량 차를 서너 가지 기록해 4개 이상이 되면 데이터 검증 탭에서 a–Δm/M유효 그래프와 관성 무시 공식의 오차표가 열립니다. 모형: g = 9.8 m/s², 줄 질량·축 마찰 무시, 위치 측정 오차 ±1 mm.

개념 정리

1. 제약과 일반화 좌표

두 추의 높이 x₁, x₂와 도르래 회전각 φ는 줄이 늘어나지도 미끄러지지도 않는다는 홀로노믹 제약 x₁ + x₂ = ℓ(일정), Rφ = x₁로 묶여 있습니다. 좌표 3개 − 제약 2개 = 자유도 1이므로 일반화 좌표 q = x₁ 하나로 모든 위치를 쓸 수 있습니다(x₂ = ℓ − q, φ = q/R). 일반화 좌표는 길이일 필요도 없어서 각도·넓이·모드 진폭 등 계에 맞는 무엇이든 될 수 있습니다. 제약이 좌표 사이의 등식으로 쓰이면 홀로노믹, 속도나 부등식으로만 쓰이면(굴러가는 바퀴의 방향, 상자 속 기체) 비홀로노믹입니다.

2. 라그랑주 방식과 뉴턴 방식

운동 에너지 T = ½m₁q̇² + ½m₂q̇² + ½I(q̇/R)², 퍼텐셜 V = −m₁gq + m₂gq(+ 상수)이므로 L = ½(m₁ + m₂ + I/R²)q̇² + (m₁ − m₂)gq. 오일러–라그랑주 방정식에서 (m₁ + m₂ + I/R²)q̈ = (m₁ − m₂)g — 방정식 하나로 끝납니다. 뉴턴 방식은 미지수 a, T₁, T₂에 대해 m₁g − T₁ = m₁a, T₂ − m₂g = m₂a, (T₁ − T₂)R = Iα(α = a/R) 세 식을 풀어야 같은 a를 얻습니다. 그 대신 장력 T₁ − T₂ = (I/R²)a 같은 구속력을 알려면 뉴턴 방식이나 라그랑주 승수법이 필요합니다.

3. 구속력은 왜 사라지는가

이상적인 줄의 장력은 제약을 만족하는 가상 변위(q가 조금 변할 때 두 추와 도르래가 함께 움직이는 변위)에 대해 알짜 일을 하지 않습니다 — 한 추에 한 일과 도르래·다른 추에 한 일이 상쇄됩니다(달랑베르 원리). 그래서 제약에 맞는 일반화 좌표를 고르는 순간 구속력은 방정식에서 사라집니다. 실험 모형은 줄 질량과 축 마찰을 무시했고 위치 측정에 ±1 mm 오차를 넣어 a 측정이 이론과 소수 셋째 자리에서 조금 다를 수 있습니다. 실제 장치에서는 축 마찰과 줄의 미끄러짐이 a를 더 줄입니다.

제약: x₁ + x₂ = ℓ, Rφ = x₁  ·  L = ½(m₁ + m₂ + I/R²)q̇² + (m₁ − m₂)gq  ·  a = (m₁ − m₂)g/(m₁ + m₂ + I/R²)  ·  T₁ = m₁(g − a), T₂ = m₂(g + a), T₁ − T₂ = (I/R²)a

g 9.8 m/s² · I/R²: 질량 없음 0, 원판(½MR²) 0.5 kg, 고리(MR²) 1 kg (M = 1 kg) · m₁ 1.5, m₂ 1 kg, 원판: a 1.633 m/s²

예제

m₁ = 2 kg, m₂ = 1 kg, 원판 도르래(I/R² = 0.5 kg)에서 가속도와 두 장력을 구하라.

a = (2 − 1) × 9.8/(2 + 1 + 0.5) = 9.8/3.5 = 2.80 m/s². T₁ = m₁(g − a) = 2 × 7.0 = 14.0 N, T₂ = m₂(g + a) = 1 × 12.6 = 12.6 N. 확인: T₁ − T₂ = 1.4 N = (I/R²)a = 0.5 × 2.8. a = 2.80 m/s², T₁ = 14.0 N, T₂ = 12.6 N

m₁ = 1.5 kg, m₂ = 1 kg, 고리 도르래(I/R² = 1 kg)에서 도르래 관성을 무시한 공식 a = Δm·g/(m₁ + m₂)를 쓰면 몇 % 틀리는가?

관성 무시: a = 0.5 × 9.8/2.5 = 1.960 m/s². 실제: a = 0.5 × 9.8/3.5 = 1.400 m/s². 오차 = (1.960 − 1.400)/1.400 = 0.40. 40 % 크게 나온다 (원판이면 1.960 vs 1.633으로 20 %)
