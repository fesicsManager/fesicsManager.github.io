이중진자 — 정규모드에서 카오스까지

시뮬레이션에서 길이 1 m·질량 1 kg의 막대 두 개를 이은 이중진자를 작은 각과 큰 각에서 놓아 궤적을 보고, 초기 각 차이 10⁻⁶~10⁻⁹인 두 진자가 갈라지는 시각을 재어 리아푸노프 지수를 추정했습니다. 작은 각(10°)에서는 느린 모드(0.765√(g/L) = 2.40 rad/s)와 빠른 모드(1.848√(g/L) = 5.78 rad/s)의 합으로 오래 겹쳤지만, 120°에서는 수 초 안에 갈라졌고 초기 차이를 1 000배 줄여도 갈라지는 시각이 ln 1 000/λ ≈ 6.9/λ만큼만 늦어졌습니다. 라그랑지안에서 운동 방정식 세우기, 선형화와 정규모드, 초기 조건 민감성, 카오스에서 의미 있는 물리량을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

모형: g = 9.8, L₁ = L₂ = 1, m₁ = m₂ = 1, 마찰 없음. 운동 방정식을 RK4(dt 0.0015)로 적분, 두 궤적 거리의 로그 기울기로 λ 추정. 에너지 T + V를 함께 표시.

느린 모드와 빠른 모드의 진동수 비 √[(2 + √2)/(2 − √2)] = 2.414는 무리수라 작은 각의 운동은 닫히지 않는 준주기입니다. 카오스 영역에서는 정밀도를 1 000배 올려도 예측 시간이 λ⁻¹ × 6.9만큼만 늘어나 장기 예측이 불가능하고, 그래도 에너지는 보존되어 궤적이 에너지 곡면 위에 갇혀 있습니다.

개념 정리

1. 라그랑지안에서 정규모드까지

막대 두 개를 이은 이중진자는 자유도 2인 계입니다. 라그랑지안 L = T − V(T = ½m₁L₁²θ̇₁² + ½m₂[L₁²θ̇₁² + L₂²θ̇₂² + 2L₁L₂θ̇₁θ̇₂cosΔ], V = −(m₁ + m₂)gL₁cosθ₁ − m₂gL₂cosθ₂, Δ = θ₁ − θ₂)에서 오일러–라그랑주 방정식을 세우면 두 각도가 비선형으로 결합된 방정식(질량·길이가 같으면 2θ̈₁ + θ̈₂cosΔ + θ̇₂²sinΔ + 2(g/L)sinθ₁ = 0, θ̈₂ + θ̈₁cosΔ − θ̇₁²sinΔ + (g/L)sinθ₂ = 0)이 나옵니다. 작은 각에서는 sin → θ, cos → 1로 선형화되어 고윳값 문제가 되고 두 정규모드 — 같은 방향으로 흔들리는 느린 모드 ω₋ = √[(2 − √2)g/L] = 0.765√(g/L), 반대 방향의 빠른 모드 ω₊ = √[(2 + √2)g/L] = 1.848√(g/L) — 가 나오며, 임의의 작은 운동은 두 모드의 합입니다(시뮬 15의 정규모드 일반론).

2. 카오스 — 결정론적인데 예측 불가능

큰 각에서는 비선형 결합이 지배해 운동이 카오스가 됩니다: 결정론적 방정식인데도 초기 조건의 미세한 차이가 e^(λt)로 지수적으로 벌어져(λ = 리아푸노프 지수) 장기 예측이 불가능합니다. 예측 가능 시간 ≈ ln(허용 오차/초기 오차)/λ이므로 정밀도를 1 000배 올려도 시간은 ln 1 000/λ ≈ 6.9/λ만 늘어납니다 — 시뮬에서 δ₀ 10⁻⁶ → 10⁻⁹로 줄여도 갈라지는 시각이 2 s 정도만 늦어진 이유입니다. 두 궤적 거리의 로그를 시간에 대해 그리면 초기 기울기가 λ입니다. 에너지는 보존되므로 카오스라도 궤적은 3차원 에너지 곡면 위에 갇혀 있고(시뮬 23 푸앵카레 단면), 위상공간 넓이도 보존됩니다(시뮬 19). 날씨 예보가 2주를 넘기 어려운 이유가 대기의 카오스(로렌츠, 나비 효과)이며, 심장 부정맥·소행성 궤도·인구 동역학·난류도 결정론적 카오스로 분석합니다.

3. 모형과 실제

마찰·공기 저항 없는 이상 진자입니다. 실제 이중진자는 감쇠로 결국 멈추지만 그 전까지는 같은 민감성을 보입니다. 수치 적분 자체에도 반올림 오차(10⁻¹⁶)가 있어 컴퓨터 두 대에서 같은 초기 조건으로도 결국 갈라지므로, 카오스에서는 ‘정확한 궤적’보다 통계적 성질(리아푸노프 지수, 위상공간 분포, 뒤집힘 빈도)이 의미 있는 물리량입니다. RK4는 에너지를 조금씩 잃거나 얻으므로 긴 적분에는 심플렉틱 적분기가 낫고, 시뮬의 에너지 표시로 적분 정확도를 확인할 수 있습니다.

L = T − V → 오일러–라그랑주  ·  선형화: ω± = √[(2 ± √2) g/L]  ·  카오스: δ(t) ≈ δ₀ e^(λt)  ·  예측 시간 ≈ ln(δ_허용/δ₀) ÷ λ

g 9.8, L 1: ω₋ 2.40, ω₊ 5.78 rad/s (비 2.414) · 120°: λ ≈ 3~4 /s · δ₀ 10⁻⁶ → 10⁻⁹: +6.9/λ ≈ 2 s

🔬 과학 원리 탭

“초기 차이 10⁻⁹로 줄여도 갈라지는 시각만 늦어져요: 예측 가능 시간 ≈ ln(허용 오차/초기 오차)/λ. 정밀도 1 000배 → 시간은 ln1000/λ ≈ 6.9/λ만 늘어요.”

시뮬 ② 초기 조건 민감성

예제

L = 0.5 m인 이중진자의 두 정규모드 주기는?

√(g/L) = √19.6 = 4.43 rad/s. 느린 모드 ω = 0.765 × 4.43 = 3.39 rad/s → T = 1.85 s, 빠른 모드 1.848 × 4.43 = 8.19 rad/s → T = 0.77 s.

λ = 3.5 /s인 카오스 운동에서 초기 각 오차 10⁻⁴ rad이 0.1 rad까지 커지는 시간은? 센서 정밀도를 10⁻⁷로 올리면?

t = ln(0.1/10⁻⁴)/3.5 = ln 1 000/3.5 = 6.91/3.5 = 2.0 s. 10⁻⁷: ln 10⁶/3.5 = 13.8/3.5 = 3.9 s — 1 000배 정밀해도 2 s만 늘어납니다.
