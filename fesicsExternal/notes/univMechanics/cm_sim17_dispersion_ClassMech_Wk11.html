분산 관계 — 격자가 전달할 수 없는 진동수

시뮬레이션에서 질량 m = 1이 간격 a = 1, 용수철 k = 1로 이어진 사슬(N = 20, 양 끝 고정)의 정규모드를 보고 ω–q 분산 곡선을 그렸으며, 파수가 2π/a만큼 다른 두 파동이 질량 자리에서 같은 값을 가지는 것과 파속(파동 묶음)이 퍼지는 것을 확인했습니다. 모드 1(q = π/21a)은 ω 0.149로 선형 근사와 같았지만 모드 10은 1.36으로 선형값 1.50보다 낮았고, 모드 20(q ≈ π/a)은 차단 진동수 2√(k/m) = 2에 가까운 1.99로 이웃이 정확히 반대로 움직이는 정상파였습니다. 분산 관계의 유도, 선형 영역과 차단 진동수, 브릴루앙 영역, 위상 속도와 군속도를 정리합니다.

긴 파장에서는 ω ≈ a√(k/m)·q로 선형(연속 매질의 음파, 속력 a√(k/m) = 1)이지만, 파장이 격자 간격에 가까워지면 ω가 포화해 차단 진동수 2√(k/m)를 넘지 못합니다. 모드 진동수 간격이 위로 갈수록 좁아져 상태 밀도가 차단 근처에서 큽니다. 위상 속도와 군속도가 달라지는 것이 분산이며 파속이 퍼지는 원인입니다.

개념 정리

1. 분산 관계의 유도와 차단 진동수

질량 m이 간격 a로 용수철 k에 이어진 사슬의 j번째 질량 운동 방정식은 mẍ_j = k(x_{j+1} − 2x_j + x_{j−1}). 진행파 x_j = A e^{i(qja − ωt)}를 넣으면 −mω² = k(e^{iqa} + e^{−iqa} − 2) = −4k sin²(qa/2) → ω(q) = 2√(k/m)|sin(qa/2)| — 분산 관계. 양 끝 고정 N개 사슬은 정상파 조건으로 q_n = nπ/[(N + 1)a]인 N개의 정규모드(시뮬 15)가 됩니다. q가 작을 때(파장 ≫ a) sin ≈ 각도라 ω ≈ (a√(k/m))·q로 선형 — 연속 매질(줄·막대)의 음파이고 속력 a√(k/m)는 매질의 강성/밀도에서 나옵니다. 파장이 a에 가까워지면 ω가 포화해 최대 차단 진동수 2√(k/m)를 넘지 못하고, 격자는 그보다 높은 진동수의 파동을 전달할 수 없습니다(저역 통과 필터). q = π/a에서는 이웃이 정확히 반대로 움직이는 정상파라 군속도 dω/dq = 0입니다.

2. 브릴루앙 영역, 위상 속도와 군속도

파수가 2π/a만큼 다른 두 파동 q와 q + 2π/a는 질량 위치 x = ja에서 e^{i(q + 2π/a)ja} = e^{iqja}로 완전히 같은 값을 가져 물리적으로 구별되지 않습니다(연속 곡선은 다르지만 질량 자리에서는 같음 — 신호 처리의 에일리어싱). 따라서 의미 있는 q는 제1 브릴루앙 영역 −π/a < q ≤ π/a로 충분합니다. 위상 속도 ω/q는 마루가 움직이는 속력, 군속도 dω/dq = a√(k/m) cos(qa/2)는 파속(에너지·정보)이 움직이는 속력이며 둘이 다르면 파속이 퍼집니다 — 시뮬 ③에서 가우스 파속의 성분마다 속도가 달라 폭이 넓어지는 것이 이것입니다. 실제 결정의 포논 분산 곡선은 중성자 비탄성 산란으로 재고, 고체 열용량이 저온에서 T³으로 줄어드는 디바이 법칙이 분산 관계와 차단 진동수에서 나옵니다. 포토닉 결정·메타물질은 원하는 분산(밴드 갭)을 설계해 특정 파동을 차단합니다.

3. 모형과 실제

최근접 이웃만 잇는 선형 용수철 모형입니다. 실제 결정은 먼 이웃 상호작용·비조화성이 있어 분산 곡선 모양이 달라지고, 단위 격자에 원자가 둘 이상이면(NaCl) 광학 가지가 추가되어 q = 0에서도 유한한 진동수(적외선 흡수)를 가집니다. 실제 격자 진동은 양자화된 포논이고 3차원에서는 종파·횡파 가지가 방향에 따라 다르지만, 이 1차원 모형이 열용량·열전도 이해의 출발점입니다. 시뮬의 파속은 유한한 사슬(160개)이라 끝에서 반사되며, 애니메이션은 해석해로 그리므로 수치 오차가 없습니다.

mẍ_j = k(x_{j+1} − 2x_j + x_{j−1})  ·  ω(q) = 2√(k/m) |sin(qa/2)|  ·  선형: ω ≈ a√(k/m) q  ·  차단 ω_max = 2√(k/m)  ·  v_φ = ω/q, v_g = dω/dq = a√(k/m) cos(qa/2)  ·  브릴루앙 영역 |q| ≤ π/a

k = m = a = 1: 음속 1, 차단 2 · N 20: 모드 1 ω 0.149, 모드 10 1.36 (선형 1.50), 모드 20 1.99 · q = π/a에서 v_g = 0

시뮬 ① 사슬의 정규모드 · 분산과 차단

예제

k = 100 N/m, m = 0.01 kg, a = 0.02 m인 사슬에서 파장 0.08 m 파동의 진동수와 군속도는? 차단 진동수는?

q = 2π/0.08 = 78.5 /m, qa/2 = 0.785 rad. ω = 2√(10⁴) × sin 0.785 = 200 × 0.707 = 141 rad/s(선형 근사 157). v_g = 0.02 × 100 × cos 0.785 = 1.41 m/s(긴 파장 음속 2 m/s). 차단 ω_max = 200 rad/s(f = 31.8 Hz) — 그 이상은 전달 불가.

N = 20 사슬의 모드 n과 모드 42 − n(예: 2와 40)이 물리적으로 같은 까닭은?

q_n = nπ/21a에서 q_40 = 40π/21a = 2π/a − 2π/21a → 질량 자리에서 sin(j·40π/21) = −sin(j·2π/21)로 모드 2의 부호만 바뀐 것 → 같은 모드. N개 질량에는 독립 모드가 N개뿐이며 제1 브릴루앙 영역 밖의 q는 안쪽의 어느 q와 등가입니다.
