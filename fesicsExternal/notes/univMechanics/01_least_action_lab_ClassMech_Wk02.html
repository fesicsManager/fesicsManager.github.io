최소 작용의 원리 — 실제 경로는 작용을 정류시킨다

실험에서 양 끝점을 고정한 채 실제 경로 x(t)에 η(t) = ε sin(nπt/T)를 더해 비틀고, 계(자유 낙하·조화 진동자), 걸린 시간 T(0.6·1.5 s), 모드 n(1~3), 비틂 크기 ε(−0.3~0.3 m)를 바꿔 작용 S = ∫L dt의 변화 ΔS를 기록했습니다. 자유 낙하에서는 ΔS가 언제나 양수이고 ε²에 비례했지만, 조화 진동자를 반주기보다 긴 1.5 s 동안 n = 1로 비틀면 ΔS가 음수가 되었습니다. 해밀턴의 원리와 오일러–라그랑주 방정식, 2차 변분으로 본 최소와 정류의 차이를 정리합니다.

실험 안내: 자유 탐구 탭에서 계(자유 낙하 L = ½mẋ² − mgx/조화 진동자 L = ½mẋ² − ½kx²), 걸린 시간 T(0.6 s/1.5 s), 비틂 모드 n(1/2/3), 비틂 크기 ε(−0.3~0.3 m, 0.05 m 간격)를 정하고 작용 계산하기를 누르면 실제 경로의 작용 S₀, 비튼 경로의 작용 S, 수치 ΔS와 2차 변분 이론값이 기록표에 자동으로 쌓입니다. 한 조건에서 ε를 서너 가지 바꾸고 진동자·긴 시간·n = 1도 꼭 기록해 4개 이상이 되면 데이터 검증 탭에서 ΔS–ε² 그래프와 조건별 기울기(측정 vs 이론)가 열립니다. 모형: m = 1 kg, g = 9.8 m/s², 진동자 k = π² N/m(ω = π s⁻¹, 반주기 1 s), 낙하 경로 x(0) = x(T) = 0, 진동자 x(0) = 0, x(T) = 0.2 m, 400칸 심프슨 적분.

ε를 2배로 하면 ΔS가 4배(ε²에 비례)이고 ε의 부호를 바꿔도 같은 부호입니다 — 1차 변분이 0이라는 뜻입니다. 자유 낙하는 어떤 비틂에도 ΔS > 0이라 실제 경로가 작용의 최소이지만, 진동자를 반주기(1 s)보다 긴 1.5 s 동안 보면 n = 1 비틂에서 ΔS < 0, n = 2에서는 ΔS > 0이라 실제 경로는 최소가 아닌 안장점입니다. 수치 ΔS와 2차 변분 이론이 소수 넷째 자리까지 같습니다.

개념 정리

1. 해밀턴의 원리와 오일러–라그랑주 방정식

고정된 끝점 사이의 모든 경로 가운데 실제 경로는 작용 S[x] = ∫₀ᵀ L(x, ẋ, t) dt, L = T − V를 정류시키는(δS = 0) 경로입니다. x → x + εη(η(0) = η(T) = 0)로 바꾸고 ε의 1차 항을 부분 적분하면 δS = ε∫[∂L/∂x − d/dt(∂L/∂ẋ)]η dt — 모든 η에 대해 0이려면 d/dt(∂L/∂ẋ) − ∂L/∂x = 0(오일러–라그랑주 방정식)이어야 합니다. L = ½mẋ² − V에서는 곧 mẍ = −V′(x), 뉴턴 방정식입니다. 힘 대신 스칼라 하나(L)로 운동을 정하므로 좌표를 자유롭게 바꿀 수 있고(3주차 일반화 좌표), 광학의 페르마 원리·양자역학의 경로 적분으로 이어집니다.

2. 2차 변분 — 최소인가 정류인가

1차 항이 사라진 뒤 남는 2차 항이 ΔS의 부호를 정합니다. 두 계 모두 L이 x, ẋ에 대해 2차 이하라 ΔS는 ε²에서 정확히 끝납니다. 자유 낙하(V = mgx): ΔS = ½m∫η̇² dt = mε²n²π²/(4T) > 0 — 언제나 최소. 조화 진동자(V = ½kx²): ΔS = (mε²T/4)[(nπ/T)² − ω²]. T < π/ω(반주기보다 짧음)이면 모든 n에서 양수지만, T > π/ω이면 n = 1에서 (π/T)² < ω²라 음수가 되어 실제 경로는 안장점입니다. T가 길수록 음의 방향이 늘어납니다(T > 2 s면 n = 2도 음수). 그래서 정확한 이름은 '최소 작용'이 아니라 정류 작용이고, 방정식이 요구하는 것도 δS = 0뿐입니다.

3. 모형과 실제

실험은 비틂을 sin(nπt/T) 한 모드씩만 넣었지만, 끝점이 고정된 임의의 비틂은 이 모드들의 푸리에 합이고 2차 계수가 모드마다 따로 더해지므로 한 모드라도 계수가 음수면 최소가 아닙니다. 비선형 퍼텐셜(진자 등)에서는 ΔS에 ε³ 이상 항이 생겨 작은 ε에서만 ε²에 비례합니다. 작용의 수치 적분(400칸 심프슨)은 매끄러운 경로에서 오차가 매우 작아 이론과 소수 넷째 자리까지 일치합니다. 반주기 π/ω에서 n = 1 계수가 0이 되는 지점은 같은 끝점을 잇는 실제 경로가 여럿 생기는 '켤레점'입니다.

S = ∫₀ᵀ L dt, L = T − V  ·  δS = 0 ⇔ d/dt(∂L/∂ẋ) − ∂L/∂x = 0  ·  낙하: ΔS = mε²n²π²/(4T)  ·  진동자: ΔS = (mε²T/4)[(nπ/T)² − ω²]

m 1 kg, g 9.8 m/s², ω = π s⁻¹(반주기 1 s) · 낙하 T 0.6 s, n 1: ΔS/ε² = 4.112 J·s/m² · 진동자 T 1.5 s, n 1: −2.056 J·s/m², n 2: +2.879 J·s/m²

예제

자유 낙하(m = 1 kg, T = 0.6 s)의 실제 경로를 n = 1, ε = 0.1 m로 비틀었을 때 ΔS를 구하라. ε = 0.2 m면?

ΔS = mε²n²π²/(4T) = 1 × 0.01 × 1 × 9.8696/(4 × 0.6) = 0.0411 J·s. ε를 2배로 하면 ε²이 4배라 0.1645 J·s. 0.0411 J·s, 0.1645 J·s (n = 2, ε = 0.1도 n²이 4배라 0.1645 J·s)

조화 진동자(m = 1 kg, ω = π s⁻¹)를 T = 1.5 s 동안 보고 n = 1, ε = 0.2 m로 비틀었다. ΔS를 구하고 실제 경로가 최소인지 판정하라.

계수 (mT/4)[(nπ/T)² − ω²] = 0.375 × [(π/1.5)² − π²] = 0.375 × (4.386 − 9.870) = −2.056 J·s/m². ΔS = −2.056 × 0.04 = −0.0822 J·s. n = 2이면 0.375 × (17.546 − 9.870) = +2.879로 양수. ΔS = −0.0822 J·s — 방향에 따라 S가 줄기도 늘기도 하므로 안장점(정류)이지 최소가 아니다
