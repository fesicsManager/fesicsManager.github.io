중학교 2학년 수학 · 웹툰 8화 「반올림하면 조건이 깨진다」

일차부등식의 활용 — 개수는 반올림이 아니라 조건 쪽 정수로

‘예산 안에서 최대 몇 개’와 ‘모두 태우려면 버스 최소 몇 대’ 두 상황에서 부등식의 경계를 구하고, 반올림·버림·올림으로 개수를 정한 뒤 원래 조건에 넣어 검산했습니다. 최대 개수는 버림, 최소 대수는 올림만 늘 정답이었고, 반올림은 경계의 소수 부분에 따라 조건을 깨기도 했습니다. 부등식의 방향에 맞는 정수를 고르는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 상황(① 배송비 3000원 + 한 개 700원으로 예산 안에서 사기, ② 한 대 45명인 버스로 모두 태우기), 예산 또는 인원, 소수점 처리(반올림·버림·올림)를 고르고 개수 정하고 검산하기를 누르면 경계와 내 답, 검산 결과가 기록됩니다. 같은 수치에서 세 방법을 모두 해 보고 경계의 소수 부분이 0.5 이상일 때와 미만일 때를 비교하며 4개 이상 기록하면 결과 비교 탭에서 처리 방법별 정답 비율과 조건이 깨진 기록을 볼 수 있어요. (가격·좌석 수는 가상 설정입니다.)

표 1. 처리 방법별 개수와 검산 (실험 예시)
상황경계처리내 답검산결과
최대 개수 (예산 12,500원)x ≤ 13.57반올림14개12,800원 > 12,500원조건 위반
최대 개수 (예산 12,500원)x ≤ 13.57버림13개12,100원 ≤ 12,500원정답
최대 개수 (예산 13,000원)x ≤ 14.29반올림14개12,800원 ≤ 13,000원정답
최소 대수 (100명)x ≥ 2.22반올림2대90석 < 100명조건 위반
최소 대수 (100명)x ≥ 2.22올림3대135석 ≥ 100명정답
최소 대수 (250명)x ≥ 5.56반올림6대270석 ≥ 250명정답

반올림은 가까운 정수를 고를 뿐 부등식의 방향을 보지 않습니다. 최대 개수에서 경계 13.57을 반올림하면 14개가 되어 12,800원으로 예산을 넘었고, 최소 대수에서 2.22를 반올림하면 2대라 90석밖에 안 됐어요. 반올림이 맞은 것은 13,000원(14.29)·250명(5.56)처럼 우연히 반올림 방향이 조건 쪽과 같을 때뿐입니다. x ≤ 경계이면 버림, x ≥ 경계이면 올림을 하고, 마지막에 원래 조건에 넣어 검산하세요.

개념 정리

1. 반올림이 아니라 “조건 쪽” 정수

  • 최대 개수(예산 안에서 사기): 3000 + 700x ≤ 예산 → x ≤ 경계 → 경계 이하의 가장 큰 정수 = 버림
  • 최소 개수(모두 태우기): 45x ≥ 인원 → x ≥ 경계 → 경계 이상의 가장 작은 정수 = 올림

x ≤ 12.9 → x = 12, x ≥ 2.2 → x = 3

반올림은 “가까운 수”를 고르는 방법이라, 경계를 넘어 조건 밖으로 나갈 수 있어요(12.9 → 13, 2.2 → 2).

2. 마지막 단계: 검산

· 답을 정한 뒤 원래 조건(예산 이하? 모두 탑승?)에 넣어 보면 실수를 바로 찾을 수 있습니다.

· 경계가 정수(예: 10)로 딱 떨어지면 세 방법이 모두 같은 답을 줘서 오개념이 드러나지 않아요.

최대 개수: 3000 + 700x ≤ 예산 → x ≤ 경계 → 버림  ·  최소 대수: 45x ≥ 인원 → x ≥ 경계 → 올림

예제

한 상자에 12개씩 담을 때 100개를 모두 담으려면 상자가 최소 몇 개 필요한가요?

상자 수를 x라 하면 12x ≥ 100, x ≥ 8.33…입니다. 경계 이상의 가장 작은 정수(올림)는 9. 검산: 12 × 9 = 108 ≥ 100. 반올림한 8개는 96개라 4개가 남습니다. 답 9개.

5000원으로 한 개 1200원짜리 물건을 최대 몇 개 살 수 있나요?

1200x ≤ 5000, x ≤ 4.16…입니다. 경계 이하의 가장 큰 정수(버림)는 4. 검산: 1200 × 4 = 4800 ≤ 5000. 답 4개.
