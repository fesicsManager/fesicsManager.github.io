중학교 2학년 수학 · 웹툰 8화 「가장 긴 변을 찾아라」

피타고라스 정리의 역과 활용 — c는 반드시 가장 긴 변

순서가 뒤섞인 세 변 중 하나를 c로 골라 a² + b²와 c²을 비교해 직각·예각·둔각을 판정하고 실제 판정과 비교했습니다. 가장 긴 변을 c로 고르면 언제나 판정이 맞았지만, 다른 변을 c로 고르면 실제 모양과 상관없이 항상 ‘예각’이 나왔습니다. 피타고라스 정리의 역으로 삼각형을 판정하는 방법을 정리합니다.

가장 긴 변이 아닌 수를 c로 고르면 a² + b² 안에 가장 긴 변의 제곱이 들어가 a² + b²가 c²보다 항상 커져서 무조건 ‘예각’이 나왔습니다. 직각삼각형 5, 3, 4도, 둔각삼각형 4, 2, 3도 예각으로 잘못 판정되었어요. 이 부등식은 그 변과 마주 보는 각(가장 크지 않은 각)이 예각이라는 뜻일 뿐입니다. 삼각형의 종류는 가장 큰 각이 정하므로, 반드시 가장 긴 변을 c로 두어야 해요.

개념 정리

1. c는 반드시 가장 긴 변

세 변 a, b, c에서 c가 가장 긴 변일 때

  • a² + b² = c² → c와 마주 보는 각이 90° → 직각삼각형
  • a² + b² > c² → 가장 큰 각이 90°보다 작음 → 예각삼각형
  • a² + b² < c² → 가장 큰 각이 90°보다 큼 → 둔각삼각형

가장 긴 변이 아닌 변을 c로 두면 a² + b²에 가장 긴 변의 제곱이 들어가 항상 a² + b² > c²이 되어 무조건 “예각”이라는 잘못된 판정이 나옵니다. 그 식은 그 변과 마주 보는(가장 크지 않은) 각이 예각이라는 뜻일 뿐이에요.

예) 5, 3, 4 에서 c = 3 → 5² + 4² = 41 > 9 → “예각”? 실제로는 c = 5 → 9 + 16 = 25 → 직각

움직여 보기

c를 어느 변으로 고르느냐에 따라 판정이 달라진다

a² + b² c² 가장 큰 각

처음에는 5, 3, 4에서 c = 3을 골랐어요(빨간 변). a² + b² = 41 > 9라서 “예각”으로 잘못 판정됩니다. ‘c를 가장 긴 변으로’를 눌러 c = 5로 바꾸면 9 + 16 = 25 = 5²로 직각이 맞게 나와요. 보라색 각이 가장 긴 변과 마주 보는 가장 큰 각입니다(각도는 참고값).

2. 이 실험의 그림

· 삼각형은 세 변의 길이로 좌표를 계산해 그렸고, 가장 큰 각의 크기는 코사인 법칙(고등 과정)으로 계산해 참고로 보여 줍니다.

c가 가장 긴 변일 때: a² + b² = c² → 직각  ·  a² + b² > c² → 예각  ·  a² + b² < c² → 둔각

예제

세 변의 길이가 8, 17, 15인 삼각형은 어떤 삼각형인가요?

가장 긴 변 17을 c로 둡니다. 8² + 15² = 64 + 225 = 289, 17² = 289로 같으므로 직각삼각형 (c = 8로 잘못 두면 17² + 15² = 514 > 64가 되어 ‘예각’으로 틀리게 판정됩니다.)

세 변의 길이가 6, 9, 5인 삼각형은 어떤 삼각형인가요?

가장 긴 변 9를 c로 둡니다. 5² + 6² = 25 + 36 = 61, 9² = 81. 61 < 81이므로 둔각삼각형
