중학교 2학년 수학 · 웹툰 1화 「하나에 하나면 된다」

함수의 뜻 — x 하나에 y가 오직 하나면 함수다

여섯 가지 대응 관계를 화살표 그림으로 그리고, x 하나마다 y가 딱 하나인지로 함수인지 판정했습니다. y = x²와 ‘3으로 나눈 나머지’는 여러 x가 같은 y로 모였지만 함수였고, ‘약수’·‘절댓값이 x인 수’는 x 하나에서 화살표가 여러 개 나가 함수가 아니었습니다. 함수의 조건이 x 쪽에만 있다는 것을 정리합니다.

실험 안내: 대응 관계 여섯 개 중 하나와 ‘함수이다 / 함수가 아니다’ 중 예측을 고르고 화살표 그리기를 누르면 x에서 y로 화살표가 그려지고, y가 없거나 둘 이상인 x는 따로 표시됩니다. 여섯 관계를 해 보며 4개 이상 기록하면 결과 비교 탭에서 관계 분류표(함수 / 일대일)와 예측 적중률을 볼 수 있어요.

표 1. 대응 관계의 판정 (실험 예시)
관계 (x의 값)x 하나에 y 개수y 쪽 겹침함수일대일
y = 2x (1~4)모두 1개없음예예
y = x² (−2~2)모두 1개y = 1, 4예아니오
y는 x를 3으로 나눈 나머지 (1~6)모두 1개y = 0, 1, 2예아니오
y는 x의 약수 (1~4)x = 2, 3, 4에서 2개 이상y = 1, 2아니오아니오
y는 x보다 작은 자연수 (1~3)x = 1에서 0개, x = 3에서 2개y = 1아니오아니오
y는 절댓값이 x인 수 (1~3)모두 2개없음아니오아니오

y = x²에서는 −2와 2가 모두 4로, −1과 1이 모두 1로 갔지만 x 하나마다 y가 하나이므로 함수입니다. 반대로 ‘절댓값이 x인 수’는 y 쪽 겹침이 전혀 없었는데도 x = 1에서 1과 −1 두 개로 갈라져 함수가 아니었어요. 함수 판정은 x 쪽만 보면 됩니다. y 하나에 x도 하나인 것은 ‘일대일 대응’이라는 더 좁은 성질이에요.

개념 정리

1. 함수의 조건은 x 쪽에만 있다

x의 값이 하나 정해지면 y의 값이 오직 하나 정해질 때, y는 x의 함수입니다.

  • x 하나에 y가 없거나 둘 이상 → 함수가 아님
  • 서로 다른 x가 같은 y로 가는 것은 괜찮음 → 예) y = x² 에서 −2와 2가 모두 4로

함수: 모든 x → y 한 개 (y 쪽 겹침 허용)

2. “하나에 하나”의 두 방향

· y 하나에 x도 하나인 관계는 일대일 대응이라는 더 좁은 성질입니다. 함수가 되는 데 필요하지 않아요.

· 자판기: 버튼(x) 하나에 음료(y) 하나면 함수입니다. 두 버튼이 같은 음료를 줘도 고장이 아니에요. 한 버튼에서 음료가 둘 중 아무거나 나온다면 그때는 함수가 아닙니다.

함수: 모든 x → y가 오직 한 개 (y 쪽 겹침 허용)  ·  일대일 대응: 함수이면서 y 쪽 겹침도 없음

예제

우리 반 학생(x)과 생일이 있는 달(y)의 대응, 달(x)과 그 달에 생일인 학생(y)의 대응은 각각 함수인가요?

학생 한 명의 생일 달은 하나뿐이므로 앞의 대응은 함수입니다(같은 달인 학생이 여럿이어도 괜찮아요). 달 하나에는 생일인 학생이 여럿이거나 없을 수 있으므로 뒤의 대응은 함수가 아닙니다.

x가 1, 2, 3, 4이고 y는 x를 2로 나눈 나머지일 때, y는 x의 함수인가요? 일대일 대응인가요?

1 → 1, 2 → 0, 3 → 1, 4 → 0으로 x마다 y가 하나씩이라 함수입니다. y = 0, 1에 x가 둘씩 모이므로 일대일 대응은 아닙니다.
