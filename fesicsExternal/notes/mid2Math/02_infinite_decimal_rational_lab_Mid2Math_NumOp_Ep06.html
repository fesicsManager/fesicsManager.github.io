중학교 2학년 수학 · 웹툰 6화 「무한하다고 다 같은 무한은 아니다」

순환소수와 유리수 — 끝나지 않아도 되풀이되면 분수가 된다

끝없이 이어지는 소수 여덟 개를 하나씩 골라 유리수인지 예측하고, 순환마디가 있는지 확인한 뒤 분수로 바꾸어 다시 나누어 보았습니다. 순환소수 다섯 개는 모두 분수로 바뀌었고 그 분수를 나누면 원래 소수가 그대로 나왔지만, 0.1010010001…·원주율·√2는 되풀이되는 마디가 없었습니다. 유리수를 가르는 기준이 ‘끝나느냐’가 아니라 ‘순환하느냐’임을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 무한소수 하나와 ‘유리수다 / 유리수가 아니다’ 중 예측을 고르고 분수로 바꿔 보기를 누르면 순환마디가 색으로 표시되고, 순환소수는 분수로 바뀐 뒤 그 분수를 다시 나눈 검산 결과가 나옵니다. 순환소수 다섯 개와 순환하지 않는 소수 세 개를 섞어 4개 이상 기록하면 결과 비교 탭에서 분류표와 종류별 예측 적중률을 볼 수 있어요.

표 1. 무한소수를 분수로 바꾸고 다시 나누기 (실험 예시)
소수순환?순환마디분수로검산 (분수를 다시 나누기)
0.121212…순환1212/99 = 4/330.121212121212…
0.1666…순환6 (앞의 1은 한 번만)15/90 = 1/60.166666666666…
0.142857142857…순환142857142857/999999 = 1/70.142857142857…

3.14159265…(원주율)순환 안 함없음나타낼 수 없음해당 없음

여덟 개 모두 ‘무한’하다는 점은 같았습니다. 그러나 같은 마디가 되풀이되는 소수는 10배·100배 한 식에서 빼면 끝없는 꼬리가 지워져 분수(유리수)로 바뀌고, 그 분수를 다시 나누면 원래 소수가 그대로 나왔습니다. 0.1010010001…은 0이 하나씩 늘어나는 규칙은 있지만 같은 길이의 마디가 되풀이되지 않아 분수로 쓸 수 없어요. 유리수를 가르는 기준은 끝나느냐가 아니라 순환하느냐입니다.

개념 정리

1. 무한소수는 두 종류

  • 순환소수: 같은 마디가 끝없이 되풀이됩니다. 예) 0.142857142857… → 분수로 쓸 수 있으므로 유리수
  • 순환하지 않는 무한소수: 되풀이되는 마디가 없습니다. 예) 원주율 3.14159…, √2 = 1.41421… → 유리수가 아님(무리수, 3학년에서 배움)

2. 순환소수를 분수로

x = 0.121212… 이면 100x = 12.121212… 이므로 100x − x = 12 → x = 12/99 = 4/33

소수점 아래 순환하지 않는 자리가 있으면(0.1666…) 10x = 1.666…, 100x = 16.666…에서 90x = 15 → x = 1/6

순환마디 곱한 수 뺀 결과 분수

파란 줄은 순환하지 않는 자리 + 순환마디 한 번만큼, 주황 줄은 순환하지 않는 자리만큼 소수점을 옮긴 것입니다. 두 줄의 소수 부분(점선 상자)이 똑같아지는 순간 빼면 꼬리가 사라져 분수가 됩니다. 0.1666…에서 100x − 10x = 15 가 되는지 확인해 보세요.

3. “규칙이 있다”와 “순환한다”는 다릅니다

· 0.1010010001…은 0이 하나씩 늘어나는 규칙은 있지만, 같은 길이의 마디가 되풀이되지는 않아요. 마디 길이가 L이라면 0이 L개보다 많이 이어지는 구간이 나올 수 없는데, 이 수에는 그런 구간이 계속 나옵니다.

· 원주율·√2가 순환하지 않는다는 것은 증명된 사실이고, 이 실험에서는 앞자리만 보여 줍니다.

x = 0.121212… → 100x − x = 12 → x = 12/99 = 4/33  ·  x = 0.1666… → 100x − 10x = 15 → x = 15/90 = 1/6

“무한소수지만 유리수”

실험 「자유 탐구」 · 순환소수를 분수로 바꾸었을 때의 분류

예제

0.2777…(7이 반복)을 분수로 나타내세요.

x = 0.2777…이라 하면 10x = 2.777…, 100x = 27.777…입니다. 두 식을 빼면 90x = 25이므로 x = 25/90 = 5/18. 검산: 5 ÷ 18 = 0.2777…

0.454545…를 분수로 나타내세요.

x = 0.4545…이면 100x = 45.4545…입니다. 100x − x = 45이므로 99x = 45, x = 45/99 = 5/11. 검산: 5 ÷ 11 = 0.4545…
