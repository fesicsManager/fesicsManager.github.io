중학교 2학년 수학 · 웹툰 5화 「약분은 전체에게만」

다항식의 나눗셈 — (a + b) ÷ a는 각 항에 나누어 준다

a와 b에 1~9의 수를 넣고, (a + b) ÷ a의 답이라고 생각하는 식(b, 1 + b, b ÷ a, 1 + b ÷ a)과 실제 값을 비교했습니다. ‘b’와 ‘1 + b’는 대부분의 수에서 반례가 나왔고 몇몇 쌍에서만 우연히 같았지만, 1 + b ÷ a는 어떤 수를 넣어도 같았습니다. 더해진 항은 혼자 약분할 수 없다는 것을 정리합니다.

  • 웹툰 5화
  • 실험: 다항식 ÷ 단항식
  • 수학 원리
  • 자습 노트
  • 다음: 반올림하면 조건이 깨진다

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: a, b 슬라이더(1~9)와 (a + b) ÷ a의 답이라고 생각하는 식을 고르고 수를 넣어 비교하기를 누르면, 막대 모형으로 a + b를 a 크기씩 나누어 보여 주고 실제 값과 내 답의 값을 비교해 ‘같음 / 우연히 같음 / 반례’로 기록합니다. ‘b’를 골라 a, b를 여러 번 바꾸며 4개 이상 기록하면 결과 비교 탭에서 식별 결과와 반례 모음을 볼 수 있어요.

표 1. (a + b) ÷ a에 수를 넣어 비교 (실험 예시)
ab내 답실제 (a + b) ÷ a내 답의 값결과
36b36반례
22b22우연히 같음
361 + b37반례
151 + b66우연히 같음
42b ÷ a3/21/2반례
361 + b ÷ a33같음

(a + b)에서 a는 곱해진 인수가 아니라 더해진 항이라 혼자 지울 수 없습니다. 나눗셈은 각 항에 나누어 주어 a ÷ a + b ÷ a = 1 + b/a가 돼요. ‘b’는 a = 2, b = 2에서, ‘1 + b’는 a = 1에서만 우연히 맞았고 다른 쌍에서는 반례가 나왔습니다. 한 번이라도 다르면 그 식은 틀린 것이고, 우연히 맞은 한 쌍으로는 식이 맞다고 할 수 없어요.

개념 정리

1. 나눗셈은 각 항에 나누어 준다

(a + b) ÷ a = a ÷ a + b ÷ a = 1 + b/a

  • a를 “지우는” 약분은 분자·분모가 곱셈으로만 이루어져 있을 때 공통인수에만 쓸 수 있어요. 예) ab ÷ a = b
  • (a + b)에서 a는 곱해진 인수가 아니라 더해진 항이라 혼자 지울 수 없습니다.

움직여 보기

(a + b) ÷ a 는 'a 길이 묶음이 몇 개?'

(a + b) ÷ a 1 + b/a 'b'라고 지운 답

파란 a 칸과 주황 b 칸을 a 길이씩 자르면, 파란 부분은 꼭 1묶음이고 주황 부분은 b/a 묶음입니다. 그래서 (a + b) ÷ a = 1 + b/a. a = 3, b = 6이면 3이지 6이 아니에요. a = 2, b = 2처럼 두 점이 우연히 겹치는 수도 있지만, 재생해 보면 거의 모든 b에서 어긋납니다.

2. 수를 넣어 반례 찾기

a = 3, b = 6: (3 + 6) ÷ 3 = 3 인데 “b”는 6 → 틀림. 한 번이라도 다르면 그 식은 항등식이 아닙니다.

3. 우연히 맞는 경우

· a = 2, b = 2이면 (2 + 2) ÷ 2 = 2 = b 로 우연히 같아요. 한 쌍이 맞았다고 식이 맞는 것은 아닙니다.

· 식이 항상 같으려면 모든 a(≠0), b에서 같아야 하고, 그것은 계산 규칙으로 보여야 합니다.

(a + b) ÷ a = a ÷ a + b ÷ a = 1 + b/a  ·  약분은 곱셈으로 된 공통인수에만: ab ÷ a = b
📋 실험 결과 판정

“이 수에서는 우연히 같음 — 식으로는 틀림”

실험 「자유 탐구」 · a = 2, b = 2에서 ‘b’를 골랐을 때

예제

(6x + 3) ÷ 3을 ‘6x’라고 쓴 친구가 있습니다. x = 1을 넣은 반례와 바른 계산을 보이세요.

x = 1이면 (6 + 3) ÷ 3 = 3인데 6x = 6이므로 다릅니다(반례). 바르게는 각 항을 3으로 나누어 6x ÷ 3 + 3 ÷ 3 = 2x + 1이고, x = 1이면 3으로 맞아요.

a = 4, b = 6일 때 (a + b) ÷ a와 1 + b ÷ a의 값을 각각 구해 비교하세요.

(4 + 6) ÷ 4 = 10/4 = 5/2, 1 + 6 ÷ 4 = 1 + 3/2 = 5/2. 두 값이 5/2로 같습니다. 반면 ‘b’로 계산하면 6이라 다릅니다.
