중학교 2학년 수학 · 웹툰 1화 「백 번 맞아도 증명은 아니다」

증명의 뜻 — 확인은 ‘아직 반례를 못 찾았다’일 뿐이다

세 가지 주장을 확인 개수를 5~45개로 늘려 가며 검사했습니다. n² + n + 41은 40번 연속 소수였다가 n = 40에서 깨졌고, 원 위 점을 잇는 영역 수는 1, 2, 4, 8, 16 다음에 32가 아니라 31이었으며, 삼각형 내각의 합만 끝까지 180°였습니다. 반례 하나는 거짓을 확정하지만 확인을 아무리 늘려도 참은 확정되지 않고, 참은 증명으로만 보일 수 있음을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 주장(n² + n + 41은 항상 소수 / 원 위 n개 점을 이으면 영역 2ⁿ⁻¹개 / 삼각형 세 내각의 합은 180°), 확인할 개수(5~45, 영역 주장은 최대 10), 나의 판단을 고르고 차례대로 확인하기를 누르면 하나씩 검사해 연속 성립 개수와 첫 반례를 기록합니다. 첫 번째 주장을 5개·25개·45개로, 두 번째 주장을 5개와 10개로 해 보며 4개 이상 기록하면 결과 비교 탭에서 주장별 연속 성립 개수와 판단 기록을 볼 수 있어요.

표 1. 확인 개수를 늘려 본 결과 (실험 예시)
주장확인 개수연속 성립첫 반례실제로는
n² + n + 41은 항상 소수2525없음거짓
n² + n + 41은 항상 소수4540n = 40: 1681 = 41 × 41거짓
원 위 n개 점 → 영역 2ⁿ⁻¹개55없음거짓
원 위 n개 점 → 영역 2ⁿ⁻¹개105n = 6: 영역 31개 (2ⁿ⁻¹ = 32)거짓
삼각형 세 내각의 합은 180°4545없음참 (증명)

n² + n + 41을 25개만 확인했다면 ‘항상 소수’라고 믿기 쉽지만, 41번째 확인(n = 40)에서 1681 = 41 × 41이 나왔습니다. 영역 주장도 5개까지는 완벽했어요. 확인은 ‘아직 반례를 못 찾았다’는 뜻일 뿐입니다. 삼각형 내각의 합도 45개 확인만으로는 참이 확정되지 않고, 한 꼭짓점을 지나 밑변에 평행한 직선을 그어 엇각이 같음을 이용하는 증명이 있어야 모든 삼각형에서 참이라고 말할 수 있습니다.

개념 정리

1. 확인은 “아직 반례를 못 찾았다”일 뿐

  • n² + n + 41: n = 0부터 39까지 40번 모두 소수지만 n = 40이면 1681 = 41 × 41 로 소수가 아닙니다.
  • 원 위 n개의 점을 모두 이을 때 생기는 영역: 1, 2, 4, 8, 16 … 으로 2배씩 늘다가 n = 6에서 32가 아니라 31입니다(점 셋이 한 점에서 만나지 않게 놓을 때).
  • 삼각형 내각의 합 180°: 수천 개를 재도 “다음 삼각형”이 남습니다. 하지만 한 꼭짓점을 지나 밑변에 평행한 직선을 그으면 엇각이 같아서 모든 삼각형에서 성립함을 보일 수 있어요. 이것이 증명입니다.

반례 하나 → 거짓이 확정, 확인 여러 번 → 참이 확정되지 않음, 증명 → 모든 경우에 참

2. 이 실험의 계산

· 영역 수는 공식 C(n,4) + C(n,2) + 1 로 계산했습니다(일반적인 위치의 점).

· 삼각형은 무작위 좌표로 만들고 각을 계산해 더했습니다. 소수점 계산 오차는 0.001° 아래예요.

반례 하나 → 거짓 확정  ·  확인 여러 번 → 참이 확정되지 않음  ·  증명 → 모든 경우에 참  ·  원 위 n개 점의 영역 수 = C(n, 4) + C(n, 2) + 1

“참 — 확인이 아니라 증명(평행선의 엇각) 덕분”

실험 「자유 탐구」 · 삼각형 내각의 합을 45개 확인했을 때

예제

n² + n + 41에 n = 41을 넣은 값은 소수인가요?

41² + 41 + 41 = 1681 + 82 = 1763 = 41 × (41 + 1 + 1) = 41 × 43이므로 소수가 아닙니다. 반례는 하나만 있어도 ‘항상 소수’가 거짓임을 확정합니다.

원 위의 점 7개를 모두 이을 때(점 셋이 한 점에서 만나지 않게) 생기는 영역 수를 공식 C(n, 4) + C(n, 2) + 1로 구하고 2ⁿ⁻¹과 비교하세요.

C(7, 4) = 35, C(7, 2) = 21이므로 35 + 21 + 1 = 57. 2⁶ = 64와 다르므로 영역은 57개, 2ⁿ⁻¹ 규칙은 n = 7에서도 틀립니다.
