중학교 2학년 수학 · 웹툰 3화 「원점을 지나야 정비례다」

일차함수와 정비례 — b = 0일 때만 정비례다

기울기 a와 y절편 b를 바꾸며 y = ax + b의 표(x = 1, 2, 3, 4)와 그래프를 만들고, y ÷ x가 일정한지, x가 2배일 때 y도 2배인지, 원점을 지나는지 확인했습니다. b = 0인 식만 y ÷ x가 일정하고 원점을 지났으며, b ≠ 0이면 x가 늘 때 y가 늘더라도 정비례가 아니었습니다. 정비례가 일차함수의 특별한 경우임을 정리합니다.

실험 안내: 기울기 a(2, 3, −2, 0.5)와 y절편 b(0, 1, 3, −2), ‘정비례다 / 정비례가 아니다’ 예측을 고르고 표와 그래프 그리기를 누르면 x = 1~4의 표, y ÷ x, 2배 검사, 원점 통과 여부가 나오고 기록됩니다. a는 그대로 두고 b만 0, 1, 3, −2로 바꾸며 4개 이상 기록하면 결과 비교 탭에서 b에 따른 예측 적중률과 기록한 식의 분류를 볼 수 있어요.

네 식 모두 그래프는 직선(일차함수)이었지만 b = 0인 식만 y ÷ x가 일정하고 원점을 지났습니다. y = 2x + 3은 x가 늘면 y도 늘지만 x가 1 → 2로 2배일 때 y는 5 → 7로 2배가 아니에요. y절편 b가 0이 아니면 모든 y에 같은 수가 더해져 비율이 깨집니다. 그래서 정비례 ⊂ 일차함수(a ≠ 0)이고, 그 반대는 성립하지 않습니다.

개념 정리

1. 정비례는 일차함수 중 b = 0 인 경우

  • 정비례 y = ax: x가 2배, 3배 … 되면 y도 2배, 3배 …, y ÷ x = a 로 일정, 그래프가 원점을 지남
  • 일차함수 y = ax + b: 그래프는 직선이지만 b ≠ 0 이면 원점을 지나지 않고, y ÷ x가 변함

x = 1 → y = a + b, x = 2 → y = 2a + b ≠ 2(a + b) (b ≠ 0일 때)

2. “x가 늘면 y도 는다”는 정비례의 뜻이 아님

· y = 2x + 3 도 x가 늘면 y가 늘지만, x가 2배일 때 y는 2배가 아니에요.

· 정비례·일차함수 관계: 정비례 ⊂ 일차함수 (a ≠ 0일 때). 모든 정비례는 일차함수지만 그 반대는 아닙니다.

정비례 y = ax: y ÷ x = a로 일정, 원점을 지남  ·  y = ax + b (b ≠ 0): x = 1 → a + b, x = 2 → 2a + b ≠ 2(a + b)

예제

택시 요금이 기본요금 3000원에 1 km마다 1000원씩 더해진다고 할 때(가상 요금), 거리 x km와 요금 y원의 관계식을 쓰고 정비례인지 판단하세요.

y = 1000x + 3000. x = 2이면 5000원, x = 4이면 7000원으로 거리가 2배여도 요금은 2배가 아니고, x = 0일 때 y = 3000이라 원점을 지나지 않습니다. 따라서 일차함수지만 정비례가 아닙니다. (한 개 800원인 사과 값 y = 800x는 정비례입니다.)

일차함수 y = ax + b의 그래프가 원점과 점 (2, 6)을 지날 때 a, b를 구하고 정비례인지 말하세요.

원점을 지나므로 0 = a × 0 + b, b = 0. (2, 6)을 넣으면 6 = 2a, a = 3. 식은 y = 3x로 a = 3, b = 0, 정비례입니다.
