중학교 2학년 수학 · 웹툰 2화 「f는 곱하는 수가 아니다」

함숫값 — f(x)는 x를 넣었을 때 나오는 값이다

다섯 함수에 x = 1~6을 넣어 실제 함숫값 f(x)와, f가 곱하는 수라고 볼 때의 값 f(1) × x를 나란히 비교했습니다. x = 1에서는 어느 함수든 같았지만 x가 1이 아니면 f(x) = 3x를 빼고 모두 달랐습니다. f가 수가 아니라 규칙의 이름이라는 것을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 함수(3x, 2x + 1, x², 10 − 3x, 12 ÷ x), 넣을 x(1~6), 예측(f(1) × x와 같을지 / 다를지)을 고르고 기계에 넣기를 누르면 함수 기계가 실제 f(x)와 곱셈 해석 값을 계산해 기록합니다. 한 함수에서 x를 1, 3, 6으로 바꾸고 다른 함수도 해 보며 4개 이상 기록하면 결과 비교 탭에서 실제 함숫값과 f(1) × x 직선 그래프, 함수별 곱셈 해석 성공률(x ≠ 1)을 볼 수 있어요.

표 1. 실제 함숫값과 곱셈 해석 비교 (실험 예시)

f(x) = 3x399예

f(x) = x²6366아니오

f가 곱하는 수라면 f = f(1)이고 f(x)는 언제나 f(1) × x여야 합니다. 그러나 f(x) = 2x + 1에서 f(3)은 7인데 f(1) × 3은 9로 달랐어요. 곱셈 해석이 늘 맞은 것은 정비례 f(x) = 3x뿐이었고, x = 1에서는 어느 함수든 f(1) × 1 = f(1)이라 같게 나와 x = 1 한 번의 확인으로는 아무것도 알 수 없습니다. f(3)은 ‘규칙 f에 3을 넣은 결과’입니다.

개념 정리

1. f(x)는 “x를 넣었을 때 나오는 값”

f는 규칙의 이름이고, 괄호 안은 넣는 값입니다. f(3)은 “규칙 f에 3을 넣은 결과”이지 f × 3이 아니에요.

  • f(x) = 2x + 1 → f(3) = 2 × 3 + 1 = 7
  • 만약 f가 수라면 f = f(1) = 3 이고 f × 3 = 9 → 실제 7과 다름 → 곱셈 해석은 모순

f(x) = f(1) × x 가 모든 x에서 맞는 것은 정비례 함수 y = ax 뿐

2. 우연히 맞는 경우

· f(x) = 3x 에서는 f(1) × x 가 항상 맞습니다. 그래서 정비례만 보면 오개념이 드러나지 않아요.

· x = 1을 넣으면 어느 함수든 f(1) × 1 = f(1) 이라 항상 같게 나옵니다. x = 1 한 번만 확인해서는 안 돼요.

f(x) = 2x + 1 → f(3) = 2 × 3 + 1 = 7  ·  f(x) = f(1) × x가 모든 x에서 맞는 것은 y = ax 꼴뿐

“다름 — 곱셈 해석이 틀렸다는 증거”

실험 「자유 탐구」 · f(x) = 2x + 1에 x = 3을 넣었을 때

예제

f(x) = x² − 1에서 f(2), f(3)을 구하고, f(2)를 ‘f × 2’로 계산하면 왜 말이 안 되는지 설명하세요.

f(2) = 4 − 1 = 3, f(3) = 9 − 1 = 8. f가 수라면 f = f(1) = 1 − 1 = 0이라 ‘f × 2’ = 0이 되어 실제 값 3과 다릅니다. 따라서 f(2) = 3, f(3) = 8이고 f는 곱하는 수가 아닙니다.

f(x) = −2x + 5일 때 f(−1) + f(2)의 값을 구하세요.

f(−1) = −2 × (−1) + 5 = 7, f(2) = −2 × 2 + 5 = 1이므로 f(−1) + f(2) = 8입니다.
