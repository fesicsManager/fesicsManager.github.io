중학교 2학년 수학 · 웹툰 46화 「확률은 약속이 아니다」

확률과 실제 결과 — 확률 ½은 ‘정확히 절반’의 약속이 아니다

동전을 n번(2, 10, 100, 1000) 던지는 실험을 200회씩 반복하며 앞면이 정확히 절반 나온 비율과 앞면 비율의 평균·범위를 기록했습니다. n이 커질수록 앞면 비율은 ½ 근처로 모였지만, 정확히 절반이 나온 비율은 50 %에서 약 2.5 %로 오히려 작아졌습니다. 확률의 뜻과 실제 결과의 관계를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 한 번의 실험에서 던지는 횟수 n(2, 10, 100, 1000번)과 예측을 고르고 200회 던지기를 누릅니다. 컴퓨터 난수로 던진 모의 실험이라 누를 때마다 결과가 조금씩 달라요. 정확히 절반인 비율, 이론값, 앞면 비율의 평균과 범위가 기록표에 자동으로 쌓이고, 기록이 4개 이상이면 결과 비교 탭에서 실험값과 이론값을 비교할 수 있어요.

표 1. n에 따른 ‘정확히 절반’ 비율과 앞면 비율 (실험 예시, 200회씩 · 무작위)
n정확히 절반이론비율 평균비율 범위
248.5%50.0%0.5120.00 ~ 1.00
1025.5%24.6%0.5080.10 ~ 0.90
1008.5%8.0%0.5020.35 ~ 0.64
10002.5%2.5%0.4990.46 ~ 0.54

n이 커질수록 앞면 비율의 범위가 0.00 ~ 1.00에서 0.46 ~ 0.54로 좁아지며 ½ 근처로 모였습니다. 그런데 정확히 절반이 나온 비율은 오히려 50 % → 약 2.5 %로 작아졌어요. 확률 ½은 한 번 한 번의 결과나 ‘n번 중 꼭 n/2번’을 약속하지 않고, 많이 반복할 때의 비율이 ½에 가까워진다는 뜻입니다. n = 2에서도 두 번 모두 뒷면이 나오는 경우가 ¼이나 됩니다.

개념 정리

1. 확률은 “많이 했을 때의 비율”

앞면이 나올 확률 ½은 한 번 한 번의 결과를 정해 주지 않습니다. 여러 번 반복하면 앞면의 비율이 ½에 가까워진다는 뜻이에요(큰 수의 법칙, 고등학교에서 자세히 배움).

  • 2번 던져 앞면이 정확히 1번일 확률: 앞뒤, 뒤앞 → 4가지 중 2가지 = ½. 두 번 모두 뒷면일 확률도 ¼이나 됩니다.
  • n이 커질수록 앞면 비율은 ½ 근처로 모이지만, “정확히 절반”일 확률은 오히려 작아져요.

n = 10에서 정확히 5번일 확률 = 252/1024 ≈ 0.246

동전을 많이 던질수록 앞면 비율은 ½ 근처로 모인다

던진 횟수 0앞면 0앞면 비율 —정확히 절반일 확률(이론)

같은 횟수로 여러 번 던져 보세요(회색 선 = 바로 전 결과). 처음 몇 번은 비율이 크게 흔들리지만 많이 던질수록 초록 점선(½) 가까이 모입니다. 그래도 “정확히 절반”이 나올 확률은 n이 클수록 오히려 작아져요(10번 252/1024 ≈ 0.246, 100번 약 0.080, 1000번 약 0.025). 동전은 컴퓨터가 무작위로 던집니다.

2. 이론값 계산

· n번 중 정확히 n/2번 앞면일 확률 = (n번 중 n/2번을 고르는 경우의 수) ÷ 2ⁿ. 고르는 경우의 수는 3학년·고등학교에서 배우는 조합으로 계산했습니다.

· n = 2: 0.5, n = 10: 약 0.246, n = 100: 약 0.080, n = 1000: 약 0.025

확률 ½ = 많이 반복할 때 앞면 비율이 가까워지는 값  ·  정확히 절반일 확률: n = 2 → 0.5, n = 10 → 252/1024 ≈ 0.246, n = 100 → 약 0.080, n = 1000 → 약 0.025

예제

동전을 4번 던질 때 앞면이 정확히 2번 나올 확률을 구하세요.

모든 경우는 2 × 2 × 2 × 2 = 16가지. 앞면 2번인 경우를 빠짐없이 나열하면 앞앞뒤뒤, 앞뒤앞뒤, 앞뒤뒤앞, 뒤앞앞뒤, 뒤앞뒤앞, 뒤뒤앞앞의 6가지. 확률 = 6/16 = 3/8 (절반이 나올 확률도 ½보다 작아요.)

‘앞면이 나올 확률이 ½이니 동전을 2번 던지면 앞면이 반드시 한 번 나온다’는 말이 틀렸음을 보이려 합니다. 2번 모두 뒷면이 나올 확률을 구하세요.

모든 경우는 앞앞, 앞뒤, 뒤앞, 뒤뒤의 4가지이고 뒤뒤는 1가지이므로 확률 = ¼. 앞면이 정확히 한 번일 확률은 2/4 = ½일 뿐입니다.
