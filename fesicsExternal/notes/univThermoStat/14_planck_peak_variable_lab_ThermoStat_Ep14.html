대학 열통계물리 · 웹툰 14화 「태양 빛의 ‘봉우리 색’은 하나로 정해지는가」

플랑크 스펙트럼 — 봉우리는 ‘무엇당’으로 그리느냐에 달렸다

광원(직접 고른 온도, 우주배경복사 2.7255 K, 지구 흑체 255 K)과 그래프 방식을 바꾸며 파장당 스펙트럼 u_λ와 진동수당 스펙트럼 u_ν의 피크를 계산했습니다. 태양 5772 K에서 u_λ 피크는 502 nm, u_ν 피크는 339 THz(c/ν = 883 nm)로 같은 스펙트럼이 두 봉우리를 가졌고, 피크 광자 에너지 비는 4.9651/2.8214 ≈ 1.76이었습니다. 광자 기체(μ = 0)의 플랑크 분포, 슈테판-볼츠만 법칙, 빈 변위 법칙을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 광원(온도 직접 정하기(슬라이더) · 우주배경복사 2.7255 K · 지구 흑체(반사율 0.3) 255 K), 온도(2000~12 000 K, 슬라이더 선택 시), 그래프 방식(파장 스펙트럼 u_λ · 진동수 스펙트럼 u_ν)을 고르고 스펙트럼 그리기를 누르면 두 스펙트럼과 함께 u_λ 피크 파장(x = 4.9651), u_ν 피크 진동수(x = 2.8214)와 그 파장 c/ν, 두 피크 광자 에너지 비, 표면 방출 σT⁴가 기록표에 자동으로 쌓입니다. 온도를 3가지 이상 바꾸고 우주배경복사·지구도 기록해 4개 이상이 되면 데이터 검증 탭에서 log λ_peak–log T 그래프로 빈 변위 법칙(기울기 −1, λT 일정)을 확인할 수 있습니다. 태양 5772 K는 같은 광도를 내는 흑체의 유효 온도이며 실제 태양 스펙트럼에는 흡수선이 있습니다.

모든 줄에서 c/ν 피크가 u_λ 피크의 약 1.76배(= 4.9651/2.8214)입니다. 같은 태양 빛이 파장당으로는 502 nm(청록), 진동수당으로는 883 nm(근적외선)에서 봉우리를 이룹니다. u_ν dν = u_λ dλ이고 |dν/dλ| = c/λ²라 같은 에너지를 다른 폭으로 나눠 담기 때문입니다. 두 피크 모두 T에 반비례해(λ_peak T = 2.898×10⁻³ m·K, c/ν_peak T = 5.100×10⁻³ m·K) 우주배경복사는 mm, 지구는 약 11 μm 적외선입니다. 변하지 않는 것은 적분, 곧 전체 출력 σT⁴입니다.

개념 정리

1. 밀도 함수의 봉우리는 변수 선택에 따라 달라진다

광자는 개수가 보존되지 않아 μ = 0, 평균 광자수 1/(ehν/k_BT − 1). 모드 수를 세면

u_ν = (8πhν³/c³) / (ehν/k_BT − 1), U/V = 8π⁵(k_BT)⁴/15(hc)³, σ = 2π⁵k_B⁴/15h³c² = 5.670×10⁻⁸ W·m⁻²·K⁻⁴

u_ν dν = u_λ dλ이고 |dν/dλ| = c/λ²이므로 두 밀도 함수의 모양이 다릅니다. x = hν/k_BT로 쓰면

  • u_ν 최대: (x − 3)eˣ + 3 = 0 → x = 2.8214
  • u_λ 최대: (x − 5)eˣ + 5 = 0 → x = 4.9651 → 빈 상수 b = hc/(x k_B) = 2.898×10⁻³ m·K

2. 계산값

  • 태양 5772 K: u_λ 피크 502 nm, u_ν 피크 339 THz(c/ν = 883 nm, 근적외선)
  • 우주배경복사 2.7255 K: 1.063 mm / 160.2 GHz(1.87 mm), 광자 약 411개/cm³
  • 지구 흑체(반사율 0.3) 255 K: u_λ 피크 약 11 μm

3. 실험 모형과 실제의 차이

· 변하지 않는 것은 적분(전체 출력 σT⁴)입니다. "눈이 녹색에 맞춰 진화했다"는 설명은 봉우리가 그래프 방식에 따라 달라진다는 점을 조심해야 해요.

· 고전 등분배라면 u_ν ∝ ν²T로 적분이 발산합니다(자외선 파탄).

4. 생활 속에서 · 이어지는 개념

  • 태양 광도 L = 4πR²σT⁴ ≈ 3.83×10²⁶ W. 지구 흑체 온도 278 K(반사율 0) → 255 K(0.3), 실제 288 K와의 차이가 온실 효과의 크기입니다.
광자 μ = 0, n̄ = 1/(e^(hν/k_BT) − 1)  ·  u_ν = (8πhν³/c³)/(e^(hν/k_BT) − 1)  ·  σ = 2π⁵k_B⁴/15h³c² = 5.670×10⁻⁸ W·m⁻²·K⁻⁴  ·  x = hν/k_BT: u_ν 최대 (x − 3)eˣ + 3 = 0 → 2.8214, u_λ 최대 (x − 5)eˣ + 5 = 0 → 4.9651  ·  λ_peak T = 2.898×10⁻³ m·K

예제

반사율 0.3인 지구를 255 K 흑체로 볼 때 u_λ 피크 파장과 표면 방출 세기 σT⁴를 구하시오(b = 2.898×10⁻³ m·K, σ = 5.670×10⁻⁸ W·m⁻²·K⁻⁴).

λ_peak = b/T = 2.898×10⁻³/255 ≈ 1.136×10⁻⁵ m ≈ 11.4 μm(적외선, 온실가스가 흡수하는 영역). σT⁴ = 5.670×10⁻⁸ × 255⁴ = 5.670×10⁻⁸ × 4.228×10⁹ ≈ 240 W/m². 실제 평균 지표 온도 약 288 K와의 차이 33 K가 온실 효과의 크기다. 약 11.4 μm, 약 240 W/m²

우주배경복사 T = 2.7255 K의 광자 수 밀도 n = 16πζ(3)(k_BT/hc)³(ζ(3) = 1.2021)를 1 cm³당 개수로 구하시오.

k_BT/hc = (1.380649×10⁻²³ × 2.7255)/(6.62607×10⁻³⁴ × 2.99792×10⁸) = 3.7629×10⁻²³/1.98645×10⁻²⁵ ≈ 189.43 m⁻¹. (189.43)³ ≈ 6.797×10⁶ m⁻³. n = 16π × 1.2021 × 6.797×10⁶ ≈ 4.11×10⁸ m⁻³ ≈ 411 cm⁻³. 약 411개/cm³
