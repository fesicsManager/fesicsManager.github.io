대학 열통계물리 · 웹툰 6화 「에너지는 똑같이 나눠 갖는 게 가장 흔한가」

다중도와 거시상태 확률 — 공평한 분배가 압도적으로 흔해지는 이유

진동자 N개짜리 아인슈타인 고체 A와 B가 에너지 q단위를 나눠 가질 때, 다중도 Ω(N, q) = C(q + N − 1, q)로 ‘정확히 반반’ 확률, ‘전부 A’ 확률, 분포의 상대 폭을 세었습니다. N = 3, q = 6에서 반반은 21.65%, 전부 A는 6.06%였지만 N = 300, q = 100에서는 반반 7.37%, 전부 A 9.57×10⁻²⁸이고 상대 폭 σ/q는 0.267에서 0.054로 줄었습니다. 등확률 가정과 제2법칙의 통계적 의미를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 각 고체의 진동자 수 N(3 · 30 · 300, A = B)과 전체 에너지 단위 q(6 · 30 · 100)를 고르고 경우의 수 세기를 누르면 P(q_A) 막대(정확한 확률)와 무작위 300번 표본 점(고정 시드), 전체 미시상태 수, 반반 확률, 전부 A 확률, 분배가 모두 같은 확률이라면의 값 1/(q + 1), 분포 폭 σ와 상대 폭 σ/q가 기록표에 자동으로 쌓입니다. N = 3, q = 6에서 시작해 N과 q를 키워 가며 기록하세요. 이 실험은 기록이 3개 이상이면 데이터 검증 탭이 열리며(안내 문구는 4번 이상을 권합니다), 크기별 반반·몰빵 확률 막대와 수치 σ/q 대 공식 √[(q + 2N)/(q(2N + 1))]/2 그래프를 볼 수 있습니다.

N = 3, q = 6에서 반반(q_A = 3)은 100/462 = 21.65%로 가장 흔하지만 ‘반칙’ 같은 6 : 0도 6.06%나 됩니다. 계를 키우면 정확히 반반인 확률은 오히려 작아지지만(7.37%) 분포가 반반 근처로 좁아집니다: σ/q가 0.267 → 0.054, 전부 A 확률은 9.57×10⁻²⁸. 진동자 10²²개인 고체라면 상대 폭이 10⁻¹¹ 수준이라 가장 그럴듯한 거시상태가 사실상 ‘그 상태’가 됩니다. 자연이 공평한 것이 아니라 공평한 쪽 경우의 수가 압도적으로 많은 것입니다.

개념 정리

1. 공평한 쪽의 경우의 수가 압도적으로 많다

아인슈타인 고체: 같은 진동수의 양자 조화진동자 N개, 전체 에너지 U = qε. 에너지 단위 q개(●)와 칸막이 N−1개(│)를 한 줄로 배열하면

Ω(N, q) = C(q + N − 1, q) = (q + N − 1)! / (q! (N − 1)!)

기본 가정: 고립계에서 접근 가능한 모든 미시상태는 동등한 확률. 그러면 P(q_A) = Ω_A(q_A) Ω_B(q − q_A) / Ω_전체

2. N = 3 + 3, q = 6

  • Ω(3, q) = 1, 3, 6, 10, 15, 21, 28 / 전체 Ω(6, 6) = C(11, 6) = 462
  • P(q_A = 3) = 100/462 ≈ 21.6%, P(q_A = 6) = 28/462 ≈ 6.1%
  • N = 300 + 300, q = 100이면 P(50) ≈ 7.4×10⁻², P(0) ≈ 9.6×10⁻²⁸
  • 두 같은 고체에서 분포의 표준편차: σ² = (q/4)(q + 2N)/(2N + 1) — 상대 폭은 대략 1/√N로 줄어 '바늘'이 됩니다.

3. 실험 모형과 실제의 차이

· '모든 미시상태가 동등하다'는 증명된 정리가 아니라 기본 가정입니다(에르고딕성은 특정 계에서만 증명).

· 아인슈타인 고체는 모든 진동자의 진동수가 같다는 근사입니다.

4. 생활 속에서 · 이어지는 개념

  • 동전 100개를 던져 정확히 앞면 50개일 확률은 약 0.080에 불과하지만, 앞면 비율이 0.4~0.6을 벗어나는 일은 드뭅니다.
Ω(N, q) = C(q + N − 1, q) = (q + N − 1)!/(q!(N − 1)!)  ·  등확률 가정 ⇒ P(q_A) = Ω_A(q_A)Ω_B(q − q_A)/Ω_전체  ·  N = 3 + 3, q = 6: Ω_전체 = C(11, 6) = 462  ·  σ² = (q/4)(q + 2N)/(2N + 1), 상대 폭 ∼ 1/√N

웹툰 6화 #4 · 다중도 표 검증

예제

진동자 3개짜리 고체 A, B가 에너지 6단위를 나눠 가진다. Ω(3, q) = 1, 3, 6, 10, 15, 21, 28(q = 0~6)을 써서 A가 5단위 이상을 가질 확률을 구하시오.

P(q_A) = Ω(3, q_A)Ω(3, 6 − q_A)/462. q_A = 5: 21 × 3 = 63, q_A = 6: 28 × 1 = 28. 합 91 → P = 91/462 ≈ 0.197. 전체 Ω(6, 6) = C(11, 6) = 462는 28 + 63 + 90 + 100 + 90 + 63 + 28과 같다. 약 19.7%

N_A = N_B = 300, q = 100일 때 공식 σ² = (q/4)(q + 2N)/(2N + 1)로 q_A 분포의 표준편차와 상대 폭 σ/q를 구하고 실험 기록과 비교하시오.

σ² = (100/4) × (100 + 600)/(601) = 25 × 1.1647 ≈ 29.12, σ ≈ 5.40. σ/q ≈ 0.0540으로 실험의 수치 상대 폭 0.0540과 같다. q_A는 50 ± 5 안팎에 몰려 있고, 0단위(전부 B)나 100단위(전부 A) 쪽은 10⁻²⁷ 수준이다. σ ≈ 5.40, σ/q ≈ 0.054
