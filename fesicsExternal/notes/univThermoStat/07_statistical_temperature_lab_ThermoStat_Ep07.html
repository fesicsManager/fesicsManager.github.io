대학 열통계물리 · 웹툰 7화 「에너지를 더 많이 가진 쪽이 더 뜨거운가」

통계적 온도 1/T = ∂S/∂U — 총에너지가 아니라 진동자당 에너지가 정한다

진동자 100개인 고체 A와 1000개인 고체 B의 에너지 q_A, q_B를 바꾸며 k_BT/ε = 1/ln(1 + N/q)와, 에너지 한 단위가 A에서 B로 옮겨 갈 때의 정확한 ΔS/k_B를 기록했습니다. A(q 300), B(q 1000)에서 총에너지는 B가 많지만 k_BT/ε는 A 3.48, B 1.44로 A가 뜨거웠고, A → B 이동의 ΔS/k_B = +0.407로 에너지는 A에서 B로 흘렀습니다. S = k_B ln Ω와 1/T = (∂S/∂U)_(N,V)을 유도하고 에너지 흐름 방향을 예측합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 고체 A의 에너지 q_A(50~600 단위, 진동자 100개)와 고체 B의 에너지 q_B(200~2000 단위, 진동자 1000개)를 고르고 두 고체 붙이기를 누르면 ln(Ω_AΩ_B) 곡선과 함께 두 고체의 k_BT/ε, A → B 한 단위 이동의 정확한 ΔS/k_B(이항계수), 근사 ε(1/T_B − 1/T_A)/k_B, 처음 흐름 방향, 엔트로피 최대인 평형 q_A가 기록표에 자동으로 쌓입니다. 총에너지는 B가 많지만 진동자당 에너지는 A가 많은 경우와 그 반대인 경우를 섞어 기록이 4개 이상이 되면 데이터 검증 탭에서 정확한 ΔS와 온도 근사식을 비교(기울기 1)할 수 있습니다.

첫 줄은 총에너지가 B(1000)가 많은데도 진동자당 에너지가 큰 A(3단위)가 더 뜨거워 에너지가 A에서 B로 흘렀습니다. 둘째 줄은 총에너지·진동자당 에너지 모두 B가 커서 B → A입니다. 진동자당 에너지가 2.0으로 같은 마지막 줄은 총에너지가 10배 달라도 온도가 같고 흐름이 없습니다. 모든 줄에서 정확한 ΔS와 근사 ε(1/T_B − 1/T_A)/k_B가 0.005 이내로 맞아, 에너지는 받았을 때 엔트로피를 더 많이 얻는 쪽(∂S/∂U가 큰 쪽, T가 낮은 쪽)으로 흐릅니다.

개념 정리

1. 온도는 ∂S/∂U의 역수

계는 Ω_AΩ_B가 최대인 분배로 갑니다. S ≡ k_B ln Ω로 두면 S_전체 = S_A + S_B이고, 최대 조건 ∂S_A/∂U_A = ∂S_B/∂U_B에서 평형에서 같아지는 양을 온도로 정의합니다.

1/T ≡ (∂S/∂U)_(N,V)

에너지는 받았을 때 엔트로피를 더 많이 얻는 쪽(∂S/∂U가 큰 쪽 = T가 낮은 쪽)으로 흐릅니다. 1화의 "에너지를 내놓으려는 경향"이 여기서 증명돼요.

아인슈타인 고체에 스털링 근사 ln n! ≈ n ln n − n을 쓰면 k_BT/ε = 1 / ln(1 + N/q) — 온도는 총량 q가 아니라 진동자당 에너지 q/N이 정합니다.

2. A(N 100, q 300), B(N 1000, q 1000)

  • k_BT_A/ε = 1/ln(4/3) ≈ 3.48, k_BT_B/ε = 1/ln 2 ≈ 1.44 → A가 더 뜨겁다
  • A → B 1단위: ΔS/k = ln(300/399) + ln(2000/1001) = −0.2852 + 0.6921 = +0.407 (근사 +0.405)

3. 실험 모형과 실제의 차이

· 스털링 근사는 q, N이 작으면 오차가 큽니다. N = q = 1000에서 2000 ln 2 ≈ 1386.3 대 정확값 1381.6(오차 0.34%).

· 에너지 상한이 있는 스핀계에서는 S(U)가 감소해 '음의 온도'가 생길 수 있습니다.

4. 생활 속에서 · 이어지는 개념

  • 고온 극한(q ≫ N)에서 U ≈ Nk_BT — 진동자 하나당 k_BT로, 10화 등분배 정리의 예고편입니다.
S ≡ k_B ln Ω  ·  평형: ∂S_A/∂U_A = ∂S_B/∂U_B ⇒ 1/T ≡ (∂S/∂U)_(N,V)  ·  스털링 ln n! ≈ n ln n − n: S/k_B ≈ (q + N)ln(q + N) − q ln q − N ln N ⇒ k_BT/ε = 1/ln(1 + N/q)  ·  A → B 한 단위: ΔS/k_B ≈ ε(1/T_B − 1/T_A)/k_B
뭉치

“고체 A는 진동자 100개에 에너지 300단위, 고체 B는 진동자 1000개에 에너지 1000단위. 붙이면? B가 에너지 부자니까 B에서 A로 흘러간다!”

웹툰 7화 #1 · 뭉치가 두 블록을 비교한다

닥터 이안

“에너지가 많은 쪽이 아니라 에너지를 하나 더 받았을 때 경우의 수가 덜 늘어나는 쪽이 뜨겁다. A는 이미 진동자당 에너지가 많아서 한 단위 더 받아도 상대적으로 별 감흥이 없는 거다.”

웹툰 7화 #4 · 온도와 한 단위 이동의 엔트로피 변화

예제

A(N = 100, q = 50)와 B(N = 1000, q = 1000)를 붙였다. 두 고체의 k_BT/ε를 구하고, 에너지 한 단위가 A에서 B로 갈 때의 정확한 ΔS/k_B를 Ω(N, q − 1)/Ω(N, q) = q/(q + N − 1), Ω(N, q + 1)/Ω(N, q) = (q + N)/(q + 1)로 계산해 흐름 방향을 정하시오.

k_BT_A/ε = 1/ln(1 + 100/50) = 1/ln 3 ≈ 0.91, k_BT_B/ε = 1/ln 2 ≈ 1.44 → B가 더 뜨겁다. ΔS/k_B = ln(50/149) + ln(2000/1001) = −1.092 + 0.692 ≈ −0.400 < 0. A → B는 엔트로피를 줄이므로 일어나지 않고, 반대로 B → A가 +0.400만큼 늘린다. T_A ≈ 0.91ε/k_B, T_B ≈ 1.44ε/k_B, 에너지는 B → A

N = q = 1000인 아인슈타인 고체의 ln Ω를 스털링 근사로 추정하고, 정확한 값 ln C(1999, 1000) ≈ 1381.6과 비교해 상대 오차를 구하시오.

ln Ω ≈ (q + N)ln(q + N) − q ln q − N ln N = 2000 ln 2000 − 2 × 1000 ln 1000 = 2000 ln 2 ≈ 1386.3. 상대 오차 (1386.3 − 1381.6)/1381.6 ≈ 0.34%. 차이는 주로 생략한 ½ln(2πn) 항에서 나오며, N ∼ 10²²이면 무시할 수 있다. 약 1386.3, 오차 약 0.34%
