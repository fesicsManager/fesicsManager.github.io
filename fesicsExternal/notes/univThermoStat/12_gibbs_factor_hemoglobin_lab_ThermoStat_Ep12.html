대학 열통계물리 · 웹툰 12화 「헤모글로빈은 산소를 반만 붙잡는가」

화학 퍼텐셜과 기브스 인자 — 두 상태라도 가중치가 같아야 반반

산소 분압(0.01~0.30 atm)과 모형을 바꾸며 헤모글로빈 결합 자리의 O₂ 점유율을 기브스 인자로 계산했습니다. 폐(0.20 atm, μ = −0.600 eV)에서 97.7%, 근육(0.05 atm)에서 91.3%였고, CO가 경쟁하는 세 상태 모형에서는 O₂ 24.4%, CO 75.0%로 뒤집혔습니다. 화학 퍼텐셜 μ ≡ −T(∂S/∂N)_(U,V)와 기브스 합으로 점유율을 계산하는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 산소 분압(0.01~0.30 atm, 0.20 = 폐, 0.05 = 근육)과 모형(O₂만 (빈 자리 · O₂ 두 상태) · O₂ + CO 경쟁 (세 상태))을 고르고 점유율 계산을 누르면 결합 자리 100개 그림과 점유율 곡선, k_BT(310 K), 산소의 화학 퍼텐셜 μ, −(ε − μ)/k_BT, 기브스 인자, 기브스 합 𝒵, O₂·CO 점유율, 빈 자리 비율이 기록표에 자동으로 쌓입니다. O₂만 모형으로 분압을 4가지 이상 바꿔 기록하면 데이터 검증 탭에서 ln[θ/(1 − θ)]–ln P 기울기가 1인지 확인할 수 있습니다. ε(O₂) = −0.7 eV, ε(CO) = −0.85 eV, 폐의 μ = −0.60 eV, μ_CO = −0.72 eV는 Schroeder 교재의 근사값이며 독립 자리 단순 모형입니다.

결합 자리는 두 상태뿐인데도 폐에서 점유율은 97.7%입니다. ε − μ = −0.1 eV가 k_BT(0.0267 eV)의 약 3.7배라 결합 상태의 가중치 e^3.744 ≈ 42.2가 빈 상태의 1을 압도하기 때문입니다. 분압이 4배 줄어도(폐 → 근육) μ는 k_BT ln(1/4) ≈ −0.037 eV만 내려가 점유율은 91.3%로 조금만 떨어집니다 — 독립 자리 모형으로는 산소를 많이 내놓지 못합니다. CO는 결합 에너지가 0.15 eV 깊어 가중치 129.9로 자리의 75%를 빼앗습니다.

개념 정리

1. 두 상태라도 가중치가 같아야 반반

입자 교환의 평형 조건에서 μ ≡ −T(∂S/∂N)_(U,V). 입자는 μ가 높은 쪽에서 낮은 쪽으로 갑니다. 9화의 유도를 입자 교환까지 넓히면

P(s) = e−(E_s − μN_s)/k_BT / 𝒵, 𝒵 = Σ e−(E_s − μN_s)/k_BT (기브스 합)

결합 자리: 𝒵 = 1 + e−(ε−μ)/k_BT. 이상기체에서 μ = −k_BT ln(VZ_int/Nv_Q)이고 N/V ∝ P이므로 Δμ = k_BT ln(P₂/P₁).

2. 체온 310 K (k_BT = 0.0267 eV)

  • 폐: −(ε − μ)/k_BT = 0.1/0.02671 ≈ 3.744, e3.744 ≈ 42.2, 점유율 ≈ 97.7%
  • 근육(0.05 atm): Δμ ≈ −0.037 eV → μ ≈ −0.637 eV, 점유율 ≈ 91.3%
  • CO 경쟁: 𝒵 = 1 + 42.2 + 129.9 = 173.1 → O₂ 24.4%, CO 75.0%

빨강 = O₂가 붙은 자리, 검정 = CO, 흰 칸 = 빈 자리. 자리마다 계속 붙었다 떨어지지만 붙어 있는 비율은 기브스 인자 비로 정해집니다. 분압을 폐(0.20) → 근육(0.05)으로 4배 줄여도 μ는 k_BT ln(1/4) ≈ −0.037 eV만 내려가 점유율이 조금만 떨어집니다. (310 K, 독립 자리 단순 모형, ε·μ는 Schroeder 교재 근사값)

3. 실험 모형과 실제의 차이

· 실제 헤모글로빈은 결합 자리 4개가 서로 영향을 주는 협동 결합이라 점유율 곡선이 S자이고, 근육에서 훨씬 많은 산소를 내놓습니다.

· ε, μ 값은 교재용 근사값입니다. 이상기체 식으로 직접 계산하면 폐의 μ ≈ −0.58 eV(점유율 98.8%)로 비슷합니다.

예제

근육 쪽 산소 분압이 폐(0.20 atm, μ = −0.60 eV)의 1/4인 0.05 atm이다. 이상기체에서 μ의 변화와 독립 자리 모형의 점유율을 구하시오(ε = −0.70 eV, k_BT = 0.02671 eV).

N/V ∝ P이므로 Δμ = k_BT ln(0.05/0.20) = 0.02671 × (−1.386) ≈ −0.037 eV → μ ≈ −0.637 eV. −(ε − μ)/k_BT = 0.063/0.02671 ≈ 2.357, e^2.357 ≈ 10.56. θ = 10.56/11.56 ≈ 0.913. 분압이 4배 줄어도 점유율은 97.7%에서 91.3%로만 떨어진다. 실제 헤모글로빈은 협동 결합으로 S자 곡선을 만들어 훨씬 많이 내놓는다. μ ≈ −0.637 eV, 점유율 약 91.3%

결합 자리가 비었음(1), O₂ 결합(ε − μ = −0.10 eV), CO 결합(ε_CO − μ_CO = −0.85 − (−0.72) = −0.13 eV) 세 상태일 때 310 K에서 기브스 합과 O₂, CO 점유율을 구하시오.

𝒵 = 1 + e^(0.10/0.02671) + e^(0.13/0.02671) = 1 + 42.2 + 129.9 = 173.1. P(O₂) = 42.2/173.1 ≈ 0.244, P(CO) = 129.9/173.1 ≈ 0.750, 빈 자리 ≈ 0.006. 결합 에너지 0.15 eV 차이가 e^(0.15/0.0267) ≈ 270배의 가중치 차이가 된다. 𝒵 ≈ 173.1, O₂ 약 24.4%, CO 약 75.0%
