대학 열통계물리 · 웹툰 8화 「엔트로피가 늘면 무조건 일어나는가」

기브스 자유에너지 — 일정한 T, P에서는 ΔG ≤ 0인 쪽으로

얼음 1 mol이 물로 변하는 과정을 온도(−20~+20 °C)와 압력(1~400 atm)을 바꿔 ΔG = ΔH − TΔS + ΔV·ΔP로 판정했습니다. 1 atm에서 −10 °C는 ΔG = +221 J/mol(녹지 않음), +10 °C는 −219 J/mol(녹음)이었고, 압력을 200 atm으로 올리자 녹는점이 −1.46 °C로 내려갔습니다. 르장드르 변환으로 H, F, G를 정의하고 ΔG ≤ 0 조건과 클라우지우스-클라페이롱 식을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 온도(−20~+20 °C), 압력(1~400 atm), 판정 방식(계 + 환경(ΔG로 판정) · 계의 엔트로피만(ΔS > 0이면 녹는다))을 고르고 판정하기를 누르면 TΔS, ΔG, 환경·우주의 엔트로피 변화, 그 압력의 녹는점, 판정이 기록표에 자동으로 쌓입니다. 1 atm에서 온도를 −10, 0, +10 °C 등 3가지 이상, 그리고 압력을 높여 몇 번 더 기록해 4개 이상이 되면 데이터 검증 탭에서 ΔG–T 직선의 기울기(−ΔS), 절편(ΔH), 녹는점과 압력–녹는점 직선(dP/dT)을 구할 수 있습니다. 모형: ΔH = 6010 J/mol, ΔS = 22.0 J/(mol·K)를 온도와 무관하다고 둔 근사, ΔV = −1.63 cm³/mol(대표값).

얼음의 엔트로피는 언제나 +22.0 J/K 늘지만 −10 °C에서는 ΔG = 6010 − 263.15 × 22.0 ≈ +221 J/mol로 녹지 않습니다. 환경이 6010/263.15 ≈ 22.84 J/K를 잃어 우주 전체의 엔트로피가 줄어들기 때문입니다. 이 모형의 녹는점은 6010/22.0 = 273.18 K(0.03 °C)라 0 °C 줄은 ΔG = +0.7 J/mol(표시 +1)로 |ΔG| < 1 J/mol이라 기록표와 결과 판정 모두 ‘공존’으로 나옵니다. ΔV < 0이라 압력을 높이면 녹는점이 내려가지만 100 atm에 약 0.74 K, 곧 1 K에 약 133 atm이 필요합니다.

개념 정리

1. 일정한 T, P에서는 G가 줄어드는 쪽으로

dU = T dS − P dV + μ dN을 르장드르 변환하면 H = U + PV, F = U − TS, G = U − TS + PV. 계가 온도 T 환경에서 열 Q = ΔH(등압)를 받으면 환경 엔트로피는 −ΔH/T이므로

ΔS_계 − ΔH/T ≥ 0 ⇔ ΔG = ΔH − TΔS ≤ 0

G가 줄어드는 쪽이 우주의 엔트로피가 늘어나는 쪽입니다. 늘어나야 하는 것은 얼음의 엔트로피가 아니라 우주의 엔트로피예요.

2. 1 atm 부호표

  • −10 °C: ΔG = 6010 − 263.15×22.0 ≈ +221 J/mol (얼음 안정)
  • +10 °C: ΔG ≈ −219 J/mol (물 안정), ΔG = 0 → T = 6010/22.0 ≈ 273.2 K
  • −10 °C 환경은 6010/263.15 ≈ 22.84 J/K를 잃어 우주 전체는 손해

압력: dG/dP = ΔV이므로 ΔG(P) = ΔG(1 atm) + ΔV·ΔP. 클라우지우스-클라페이롱 dP/dT = L/(TΔV) ≈ −1.35×10⁷ Pa/K ≈ −133 atm/K.

TΔS ΔG 우주 ΔS 이 압력의 녹는점 판정

얼음의 엔트로피(파랑)는 언제나 +22.0 J/K 늘지만, 녹으려면 환경에서 열 ΔH를 빼앗아 환경 엔트로피(주황)가 줄어듭니다. 늘어나야 하는 것은 보라(우주) 막대 = −ΔG/T입니다. 압력을 높이면 보라 선이 아래로 내려가 녹는점이 낮아집니다. (ΔH = 6010 J/mol, ΔS = 22.0 J/(mol·K) 일정, ΔV = −1.63 cm³/mol)

3. 실험 모형과 실제의 차이

· ΔH, ΔS가 온도에 무관하다는 것은 좁은 범위의 근사입니다.

· ΔG < 0은 '일어날 수 있다'이지 '빨리 일어난다'가 아닙니다(다이아몬드, 과냉각된 물).

· 스케이트가 미끄러운 이유는 압력 녹음보다 표면 준액체층과 마찰열이 더 큰 몫이라는 것이 현재 주류 설명입니다.

4. 생활 속에서 · 이어지는 개념

  • 맥스웰 관계 (∂S/∂P)_T = −(∂V/∂T)_P처럼 재기 어려운 양을 쉬운 양(열팽창)으로 바꿀 수 있습니다.
H = U + PV, F = U − TS, G = U − TS + PV  ·  dG = −S dT + V dP + μ dN  ·  일정 T, P: ΔS_계 − ΔH/T ≥ 0 ⇔ ΔG = ΔH − TΔS ≤ 0  ·  ΔG(P) ≈ ΔG(1 atm) + ΔV·ΔP  ·  dP/dT = L/(TΔV) ≈ −1.35×10⁷ Pa/K ≈ −133 atm/K

웹툰 8화 #4 · 온도별 ΔG 부호표

예제

1 atm, −5 °C(268.15 K)에서 얼음 1 mol이 물로 변하는 과정의 ΔG와 우주의 엔트로피 변화를 구하시오(ΔH = 6010 J/mol, ΔS = 22.0 J/(mol·K)).

ΔG = ΔH − TΔS = 6010 − 268.15 × 22.0 = 6010 − 5899.3 ≈ +110.7 J/mol > 0. 환경은 −ΔH/T = −6010/268.15 ≈ −22.41 J/K, 계는 +22.0 J/K라 ΔS_우주 = −ΔG/T ≈ −0.413 J/K < 0. 우주 엔트로피를 줄이므로 저절로 녹지 않는다. ΔG ≈ +111 J/mol, ΔS_우주 ≈ −0.41 J/K, 녹지 않음

0 °C에서 물의 몰부피 18.02 cm³, 얼음 19.65 cm³이다. 클라우지우스-클라페이롱 식으로 융해 곡선의 기울기 dP/dT를 atm/K로 구하고, 압력을 1 atm에서 100 atm으로 올릴 때 녹는점 변화를 어림하시오.

ΔV = 18.02 − 19.65 = −1.63 cm³/mol = −1.63×10⁻⁶ m³/mol. dP/dT = L/(TΔV) = 6010/(273.15 × (−1.63×10⁻⁶)) ≈ −1.35×10⁷ Pa/K ≈ −133 atm/K. 99 atm을 올리면 ΔT ≈ −99/133 ≈ −0.74 K(실험 기록 0.03 → −0.71 °C). 스케이트 날 압력만으로 얼음이 녹는다는 설명은 부족하다. dP/dT ≈ −133 atm/K, 녹는점 약 0.74 K 하강
