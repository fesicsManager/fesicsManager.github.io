c와 g의 두 가지 소리 — 바로 뒤 글자를 봐요

c나 g가 들어간 단어 카드를 골라 바로 뒤 글자와 실제 소리를 기록했습니다. 뒤에 a·o·u가 오면 딱딱한 소리(ㅋ·ㄱ), e·i·y가 오면 부드러운 소리(ㅅ·ㅈ에 가까움)가 났고, c는 모든 카드가 규칙대로였지만 g에는 get, girl, give 같은 예외가 있었습니다. 뒤 글자로 소리를 맞히는 규칙과 예외를 다루는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 단어 카드(c 단어 10장, g 단어 9장 중 하나)를 고르고 c(g)의 소리를 딱딱한 소리와 부드러운 소리 중에서 예측한 뒤 소리 확인하기를 누르면 뒤 글자, 실제 소리, 규칙과 맞는지가 기록됩니다. c 단어와 g 단어, 뒤 글자가 a·o·u인 것과 e·i·y인 것을 골고루 4개 이상 기록하면 결과 비교 탭이 열립니다.

표 1. c·g 바로 뒤 글자와 소리 (실험 예시)
단어뒤 글자소리규칙과
cataㅋ맞음
cityiㅅ맞음
penciliㅅ맞음
gameaㄱ맞음
pageeㅈ맞음
girliㄱ예외

c는 바로 뒤에 a·o·u가 오면 ‘ㅋ’, e·i·y가 오면 ‘ㅅ’ 소리였고, 실험의 c 카드는 모두 규칙과 맞았어요. g도 대부분 같은 규칙(ㄱ / ㅈ에 가까운 소리)을 따랐지만, girl처럼 i 앞인데도 ‘ㄱ’인 예외가 있었어요. 규칙으로 대부분을 맞히고, 맞지 않는 단어는 예외로 적어 두면 돼요.

개념 정리

1. c와 g는 뒤를 보고 소리를 정한다

뒤에 a · o · u → 딱딱한 소리 (c = ㅋ, g = ㄱ)
뒤에 e · i · y → 부드러운 소리 (c = ㅅ, g = ㅈ에 가까움)

  • cat, cup, coat → 'ㅋ' / city, ice, pencil → 'ㅅ'
  • game, go, gum → 'ㄱ' / giraffe, orange, page → 'ㅈ'에 가까운 소리

2. 예외도 있어요

g는 예외가 있어요. get, girl, give는 e·i 앞인데도 'ㄱ' 소리예요. c 규칙은 거의 잘 맞아요.

3. 실험 모형과 실제의 차이

· 이 실험은 c·g가 한 번 나오는 쉬운 단어만 골랐어요.

· 규칙은 처음 보는 단어를 맞히라고 있어요. 맞으면 규칙, 안 맞으면 예외로 적어 두면 돼요.

4. 생활 속에서 · 이어지는 개념

  • rice는 c 뒤에 e → 'ㅅ', cold는 o → 'ㅋ'. 처음 보는 단어에 써 보세요.
c·g 바로 뒤에 a·o·u → 딱딱한 소리(c = ㅋ, g = ㄱ) · 뒤에 e·i·y → 부드러운 소리(c = ㅅ, g = ㅈ에 가까움)

예제

face와 coat에서 c는 각각 어떤 소리가 나나요?

face는 c 바로 뒤에 e가 있으니 부드러운 ‘ㅅ’, coat는 c 바로 뒤에 o가 있으니 딱딱한 ‘ㅋ’ 소리예요. face — ㅅ, coat — ㅋ

giraffe와 gum에서 g는 각각 어떤 소리가 나나요?

giraffe는 g 뒤에 i가 있어 ‘ㅈ’에 가까운 부드러운 소리, gum은 g 뒤에 u가 있어 딱딱한 ‘ㄱ’ 소리예요. 다만 g는 get, girl, give처럼 예외가 있으니 소리를 들어 확인해요. giraffe — ㅈ에 가까운 소리, gum — ㄱ
