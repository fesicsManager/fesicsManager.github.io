글자 이름과 글자 소리 — 읽을 때는 소리를 이어 붙여요

단어 카드를 골라 글자 이름(비, 이, 디)으로 한 번, 글자 소리(ㅂ, ㅔ, ㄷ)로 한 번 이어 읽고, 진짜 단어와 같은지 기록했습니다. 이름으로 읽으면 ‘비이디’처럼 모든 카드가 진짜 단어와 달랐고, 소리로 읽으면 모든 카드가 진짜 단어가 되었습니다. 글자의 이름과 소리가 어떻게 다른지, 파닉스가 무엇인지 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 단어 카드(bed, cat, dog, sun, hat, map, cup, pen, pig 중 하나)와 읽는 방법(글자 이름으로 / 글자 소리로)을 고르고 이어 읽기를 누르면 카드가 뒤집히며 이어 붙인 결과와 진짜 단어와 같은지가 기록됩니다. 같은 단어를 이름으로 한 번, 소리로 한 번 읽고 카드도 바꿔 가며 4개 이상 기록하면 결과 비교 탭이 열립니다.

표 1. 읽는 방법에 따른 이어 읽기 결과 (실험 예시)
단어읽는 방법이어 붙인 결과진짜 단어와
bed글자 이름으로비이디다름 ✗
bed글자 소리로베드같음 ✓
hat글자 이름으로에이치에이티다름 ✗
hat글자 소리로햇같음 ✓
map글자 이름으로엠에이피다름 ✗
cat글자 소리로캣같음 ✓

글자 이름으로 이어 읽은 기록은 하나도 진짜 단어가 되지 않았고, 글자 소리로 이어 읽은 기록은 모두 진짜 단어가 되었습니다. 알파벳 노래는 글자의 이름을 부르는 노래이고, 단어를 읽을 때는 글자 소리를 이어 붙여요. h처럼 이름(에이치)과 소리(짧은 ㅎ)가 아주 다른 글자도 있어요.

개념 정리

1. 글자에는 이름과 소리가 따로 있다

알파벳 노래는 글자의 이름을 부르는 노래예요. 단어를 읽을 때는 이름이 아니라 소리를 이어 붙여요.

  • b — 이름 '비', 소리 'ㅂ'
  • h — 이름 '에이치', 소리 짧은 'ㅎ'
  • c — 이름 '씨', cat에서 소리 'ㅋ'

읽기 = 글자 소리 + 글자 소리 + 글자 소리

글자 소리를 알면 처음 보는 단어도 읽을 수 있어요. hat의 h를 c로 바꾸면 cat! 이렇게 읽는 방법을 파닉스라고 해요.

2. 실험 모형과 실제의 차이

· 영어 소리를 한글로 적으면 비슷할 뿐 똑같지 않아요. 진짜 소리는 음성으로 들어 보세요.

· 기기 음성은 낱소리(ㅂ)만 따로 내기 어려워서, 소리로 읽기를 고르면 이어 붙인 단어를 들려줘요.

3. 생활 속에서 · 이어지는 개념

  • 이름은 부를 때, 소리는 읽을 때! 글자를 셀 때나 철자를 말할 때(b-e-d)는 이름을 써요.
읽기 = 글자 소리 + 글자 소리 + 글자 소리 (이름은 부를 때, 소리는 읽을 때)

예제

pen을 글자 이름으로 이어 읽으면 어떻게 되고, 글자 소리로 이어 읽으면 어떻게 되나요?

이름으로 읽으면 피 + 이 + 엔 → ‘피이엔’이 되어 진짜 단어와 달라요. 소리로 읽으면 ㅍ + ㅔ + ㄴ → ‘펜’이 돼요. 소리로 이어 읽어야 pen(펜)이 됩니다

친구에게 bed의 철자를 하나씩 불러 줄 때(b-e-d)는 글자 이름과 글자 소리 중 무엇을 쓰나요?

철자를 말하거나 글자를 셀 때는 글자를 ‘부르는’ 것이므로 이름을 써요. ‘비, 이, 디’라고 불러 줍니다. 단어를 ‘읽을’ 때만 소리를 이어 붙여요. 글자 이름
