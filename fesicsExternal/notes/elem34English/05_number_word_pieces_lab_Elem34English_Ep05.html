숫자 단어 조각 — 27개면 99까지 말할 수 있어요

1부터 99까지 숫자를 골라 영어 이름을 만들고, 새로 익혀야 하는 단어인지 조각을 붙여 만든 단어인지, 1부터 그 숫자까지 새 단어가 몇 개 필요한지 기록했습니다. 21은 twenty + one으로 붙여 만들었고, 99까지 필요한 새 단어는 27개뿐이었습니다. 숫자 단어를 만드는 규칙과 헷갈리는 철자·소리를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 숫자 막대(1~99)로 숫자를 정하고, 1~99를 말하는 데 꼭 필요한 단어 수를 예측한 뒤 숫자 만들기를 누르면 영어 이름, 만드는 법(새 단어 / 조각 붙이기), 1부터 그 숫자까지 필요한 새 단어 수가 기록됩니다. 19, 20, 21, 99 같은 경계 숫자와 13·30 같은 헷갈리는 짝을 골라 4개 이상 기록하면 결과 비교 탭이 열립니다.

표 1. 숫자별 영어 이름과 필요한 새 단어 수 (실험 예시)
숫자영어만드는 법1~n 새 단어
13thirteen새 단어13개
20twenty새 단어20개
21twenty-onetwenty + one20개
30thirty새 단어21개
45forty-fiveforty + five22개
99ninety-nineninety + nine27개

21부터는 새 단어가 늘지 않고 십의 자리 단어 + 일의 자리 단어를 붙였어요. 새 단어 수가 늘어나는 곳은 30, 40, …, 90처럼 십의 자리 단어가 처음 나올 때뿐이라서, 99까지 필요한 새 단어는 1~19의 19개와 twenty~ninety 8개를 더한 27개였어요. 철자는 forty(four가 아님), thirteen, fifteen을 조심해요.

개념 정리

1. 99개를 다 외우지 않는다

1~19 (19개) + 십의 자리 twenty~ninety (8개) = 27개

21부터는 십의 자리 단어 + 일의 자리 단어를 붙이면 돼요. twenty + one = twenty-one. 그래서 1부터 99까지 말하려면 27개면 충분해요.

  • 13~19는 대부분 숫자 + teen: sixteen, seventeen, nineteen
  • 철자 조심: thirteen(three가 아니라 thir), fifteen(five가 아니라 fif), eighteen(t가 하나), forty(four가 아니라 for)

2. thirteen과 thirty 구별하기

thir-TEEN은 뒤 칸을 길고 세게, THIR-ty는 앞 칸을 세게 말해요. 끝을 길게 끌면 teen, 짧게 끊으면 ty!

3. 실험 모형과 실제의 차이

· 21~99 사이 숫자는 twenty-one처럼 가운데에 붙임표(-)를 넣어 써요.

· 100은 one hundred로, 새 단어 hundred가 하나 더 필요해요.

1~99에 필요한 단어 = 1~19(19개) + twenty~ninety(8개) = 27개 · 21부터 = 십의 자리 단어 + 일의 자리 단어
제로 · 뭉치

웹툰 5화 #5 · thirteen과 thirty 구별하기

예제

1부터 50까지 영어로 말하려면 새 단어가 몇 개 필요한가요?

1~19는 모두 새 단어라 19개, 20부터 50까지는 십의 자리 단어 twenty, thirty, forty, fifty 4개만 새로 필요해요. 19 + 4 = 23. 실험에서 50을 고르면 ‘1~50 새 단어 23개’로 나와요. 23개

thirteen(13)과 thirty(30)는 말할 때 어떻게 구별하나요?

thirteen은 뒤 칸 teen을 길고 세게(thir-TEEN), thirty는 앞 칸을 세게 하고 ty는 짧게(THIR-ty) 말해요. 끝을 길게 끌면 13, 짧게 끊으면 30
