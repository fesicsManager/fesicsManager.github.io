비가역 현상과 엔트로피 — 되돌아갈 수는 있지만 확률이 너무 작다

실험에서 칸막이 구멍이 난 상자 왼쪽에 입자 N개를 모아 두고, 매 순간 무작위로 입자 하나가 반대쪽으로 넘어가게 하며 왼쪽 비율과 엔트로피 S/k = ln W를 관찰했습니다. 입자는 곧 반반 근처에 머물렀고, N이 클수록 흔들림이 작아졌으며, 모두 왼쪽으로 돌아오는 일은 N = 4에서는 자주, N = 40 이상에서는 한 번도 일어나지 않았습니다. 비가역 현상과 열역학 제2법칙의 통계적 의미를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 입자 수 N(4 · 10 · 40 · 100 · 400개)과 관찰 시간(입자 이동 200~4000번)을 정하고 칸막이 열기를 누르면 왼쪽 비율과 엔트로피 그래프가 그려지고, 뒤쪽 절반의 평균 비율, 흔들림 σ(측정과 이론), 엔트로피, 모두 왼쪽으로 돌아온 횟수(측정과 기대값)가 나옵니다. 무작위라 실행마다 조금씩 다르며, 4개 이상 기록하면 σ와 1/√N 그래프, N별 되돌아옴 표를 볼 수 있습니다.

반반 배치는 가짓수 W가 가장 많아 엔트로피가 최대이므로, 무작위로 움직이는 입자는 가짓수가 많은 상태로 가서 거기 머뭅니다. 처음 상태(모두 왼쪽, W = 1)로 돌아오는 것이 금지된 것은 아니지만 확률이 (1/2)ᴺ이라 N = 4에서는 2000번 중 100번 넘게 일어나도 N = 40만 되어도 사실상 0입니다. 흔들림도 1/√N에 비례해 줄어 거시계(N ≈ 10²³)에서는 엔트로피가 줄어드는 변화가 사실상 일어나지 않습니다.

개념 정리

1. 되돌아갈 수는 있지만, 확률이 너무 작다

입자 하나하나의 운동 법칙은 시간을 거꾸로 돌려도 성립합니다. 그런데 N개 입자가 왼쪽에 n개 있는 배치의 가짓수는 W = NCn이고, 반반(n = N/2)일 때 가장 많습니다. 무작위로 움직이면 계는 가짓수가 많은 상태로 갈 확률이 압도적이라 반반 근처에 머뭅니다.

  • 볼츠만 엔트로피: S = kB ln W — 가짓수가 많을수록 크다.
  • 평형 상태에서 입자가 모두 왼쪽에 있을 확률은 (1/2)N. N = 10이면 약 1/1000, N = 100이면 약 10−30.
  • 왼쪽 비율의 흔들림(표준편차)은 σ = 0.5 / √N — 입자가 많을수록 요동이 작아집니다.

그래서 거시적인 계에서는 엔트로피가 줄어드는 방향의 변화가 사실상 일어나지 않습니다. 이것이 열역학 제2법칙과 비가역 현상(잉크 퍼짐, 열이 뜨거운 곳 → 찬 곳, 마찰열)의 통계적 의미예요.

2. 실험 모형과 실제의 차이

· 실제 기체는 입자가 동시에 움직이고 위치·속도의 가짓수도 셉니다. 이 모형은 칸만 세는 단순화입니다.

· 무작위 추출을 쓰므로 같은 조건도 실행마다 결과가 조금씩 다릅니다.

3. 생활 속에서 · 이어지는 개념

  • 섞인 소금물이 저절로 소금과 물로 나뉘지 않고, 깨진 컵이 저절로 붙지 않는 것도 같은 까닭입니다.
W = C(N, n) (N개 중 왼쪽 n개의 배치 수)  ·  S = k_B ln W  ·  모두 왼쪽일 확률 = (1/2)ᴺ  ·  되돌아옴 기대값 = 이동 횟수 × (1/2)ᴺ  ·  σ = 0.5 ÷ √N

에렌페스트 상자 모형 · 처음 S/k = ln 1 = 0 · N = 10: S최대/k = ln 252 ≈ 5.53 · 실제 기체 분자 수 약 10²³개

예제

N = 10일 때 왼쪽 5개·오른쪽 5개인 배치의 가짓수와 S/k는? 모두 왼쪽인 배치와 비교해 보자.

W = C(10, 5) = 252, S/k = ln 252 ≈ 5.53. 모두 왼쪽은 W = 1, S/k = 0입니다. 반반 상태가 될 수 있는 방법이 252배 많으므로 무작위 이동은 반반 쪽으로 갑니다.

관찰 시간을 4000번으로 늘리면 N = 10과 N = 40에서 모두 왼쪽으로 돌아오는 횟수의 기대값은?

N = 10: 4000 × (1/2)¹⁰ = 4000 ÷ 1024 ≈ 3.9번. N = 40: 4000 × (1/2)⁴⁰ ≈ 3.6×10⁻⁹번 — 입자 수를 4배로 늘렸을 뿐인데 사실상 일어나지 않습니다.
