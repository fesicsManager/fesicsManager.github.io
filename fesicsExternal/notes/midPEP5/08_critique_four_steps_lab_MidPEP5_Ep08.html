중학교 체육 ⑤ · 웹툰 8화 「감상평은 좋다 싫다면 되나」

표현 활동의 비평 — 묘사·분석·해석·평가로 근거 있는 감상평 쓰기

세 모둠이 서로 다른 감상평을 받고 작품을 고친 뒤 다시 공연했습니다. “좋아” “별로” 한 줄을 받은 A는 6.1 → 6.3점, 근거 없이 단점만 받은 B는 6.0 → 6.6점, 묘사·분석·해석·평가 네 단계를 받은 C는 6.2 → 7.8점이었고 C만 다섯 명 모두 다시 고치고 싶어 했습니다. 비평의 네 단계와 ‘낯선 것과 틀린 것은 다르다’는 개방적 태도를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 감상 카드의 ‘묘사’·‘분석’·‘해석’ 칸을 넣을지 뺄지, ‘평가’ 칸을 한 줄 / 단점만 나열 / 근거·제안 가운데 무엇으로 쓸지 고른 뒤 감상 카드 건네기를 누르면, 받은 모둠이 무엇을 고칠지 알았는지, 다시 고치고 싶은 모둠원 수, 고치기 전·후 관객 점수가 기록표에 남아요. 웹툰의 A·B·C를 먼저 건네고, 칸을 하나씩 넣고 빼 보세요. (모둠과 점수는 가상 조사예요.)

표 1. 감상 카드 구성에 따른 결과 (관객 20명 평균, 10점 만점, A·B·C는 제로 랩의 가상 조사, 나머지는 가상 모형)
묘사분석해석평가고칠 곳 앎고치고 싶다점수 변화
———한 줄모름2/56.1 → 6.3
———단점만 나열조금 앎1/56.0 → 6.6
○○○근거·제안알았음5/56.2 → 7.8
———근거·제안조금 앎3/56.2 → 7.2
○○○한 줄조금 앎4/56.1 → 6.9

한 줄 감상평(A)은 솔직했지만 받은 모둠이 무엇을 고칠지 몰랐고 점수는 0.2점만 올랐어요. 단점만 늘어놓은 B는 문제를 조금 알았지만 고치고 싶은 사람이 5명 중 1명뿐이었습니다. 네 단계를 모두 쓴 C는 무엇을 고칠지 알았고 다섯 명 모두 고치고 싶어 해 1.6점이 올랐어요. 무엇을 보았고 왜 그렇게 느꼈는지(근거)가 있을 때 감상평이 다음 작품으로 가는 길이 됩니다.

개념 정리

1. 비평의 네 단계

  • 묘사: 본 것을 판단 없이 그대로 말하기 — “처음엔 원 대형이었고, 가운데 한 명이 멈춰 있었다”
  • 분석: 표현 요소가 어떻게 쓰였는지 짚기 — “멈춘 한 명 둘레로 나머지가 차례로 빨라졌다”
  • 해석: 무엇을 전하려 했는지 읽기 — “혼자 남겨진 마음을 보여 주려는 것 같았다”
  • 평가: 근거를 들어 좋은 점과 제안 말하기 — “멈춤과 빠름의 대비가 분명해 좋았다. 끝부분은 앞사람에게 가려져, 두 줄 엇갈림으로 서 보면 어떨까”

‘좋다, 싫다’는 평가의 끝에 오는 말이다. 그 앞에 무엇을 보았고 왜 그렇게 느꼈는지가 있어야 비평이 된다.

2. 쓸모 있는 비평과 개방적 태도

좋은 점을 근거와 함께 말해 주면 그 부분은 지키고, 아쉬운 점을 제안으로 말하면 고칠 마음이 생긴다. 좋은 비평은 상대를 깎는 것이 아니라 다음 작품으로 가는 길을 보여 준다.

나와 전혀 다른 방식의 작품을 보면 ‘틀리다’ 대신 ‘낯설다’고 말하고, 만든 사람에게 무엇을 보여 주려 했는지 먼저 물어본다. 사람의 외모나 실수를 놀리지 말고 작품만 말한다. 내 작품에 대한 감상평을 들을 때도 같은 마음으로 듣는다.

감상 카드에 무엇을 담으면 점수가 오를까

넣은 칸 평가의 구체성 오른 점수 고친 뒤

칸을 켜고 평가의 수준을 바꿔 보세요. 노트의 가상 모형은 오른 점수 = 0.2 + 0.4 × 구체성 + 0.2 × 넣은 칸 수(구체성: 한 줄 0, 단점 나열 1, 근거·제안 2)입니다. 묘사·분석·해석 세 칸을 모두 채우고 근거와 제안까지 적은 카드가 6.2 → 7.8로 가장 많이 올랐습니다. 여기서는 시작 점수를 6.1로 두었습니다.

3. 실험 모형과 실제의 차이

· A·B·C 세 결과는 제로 랩의 가상 조사입니다. 나머지 조합은 넣은 칸 수와 평가의 구체성(한 줄 0, 단점 나열 1, 근거·제안 2)으로 정한 가상 모형이에요(오른 점수 = 0.2 + 0.4 × 구체성 + 0.2 × 넣은 칸 수).

· 실제 반응은 작품과 사람, 말하는 태도에 따라 달라집니다.

비평 = 묘사(본 것) → 분석(표현 요소) → 해석(전하려는 뜻) → 평가(근거 + 좋은 점 + 제안)

웹툰 8화 #4 · 세 모둠의 고친 뒤 점수

예제

관객 점수가 A 6.1 → 6.3, B 6.0 → 6.6, C 6.2 → 7.8로 바뀌었다. 각 모둠의 점수는 얼마나 올랐고, C는 B보다 몇 점 더 올랐는가?

A: 6.3 − 6.1 = 0.2점, B: 6.6 − 6.0 = 0.6점, C: 7.8 − 6.2 = 1.6점. C − B = 1.6 − 0.6 = 1.0점 더 올랐다. A 0.2점, B 0.6점, C 1.6점, C가 B보다 1.0점 더

뭉치의 감상 카드: “묘사: 제로가 왼발부터 나왔다. 분석: 왼발이었다. 해석: 왼발을 좋아한다. 평가: 근거를 들어 최고!” 분석·해석·평가 칸을 고쳐 써라.

분석은 표현 요소가 어떻게 쓰였는지 짚어야 한다 — 예: “왼발로 시작한 걸음이 다른 친구들에게 차례로 이어졌다(시차).” 해석은 전하려는 뜻을 읽는다 — 예: “한 사람의 움직임이 모두에게 퍼지는 모습을 보여 주려는 것 같았다.” 평가는 실제 근거를 들어 좋은 점과 제안을 쓴다 — 예: “차례로 이어지는 흐름이 분명해 좋았다. 마지막에 다 같이 멈추면 끝이 더 또렷할 것 같다.” 분석 = 표현 요소, 해석 = 전하려는 뜻, 평가 = 근거 있는 좋은 점 + 제안
