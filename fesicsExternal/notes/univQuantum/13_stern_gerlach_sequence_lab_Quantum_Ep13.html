대학 양자역학 · 웹툰 13화 「회전하지 않는 각운동량」

스핀 ½과 연속 슈테른-게를라흐 측정 — 마지막 확률은 직전 상태가 정한다

은 원자 2000개를 슈테른-게를라흐 장치에 차례로 통과시키며 처음 상태, 가운데 장치, z방향 자기장 구간, 마지막 장치의 축을 바꾸어 마지막 장치에서 −축으로 가는 비율을 기록했습니다. +z만 고른 빔을 다시 z로 재면 0이었지만, 가운데 SG-x에서 +x만 통과시키면 이론 50 %(측정 0.476), 60° 축이면 25 %(0.241)가 −z로 갔고, 두 빔을 다시 합치면 다시 0이었습니다. 스핀 ½의 2차원 상태 공간과 파울리 행렬, 연속 측정, 라머 세차를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 처음 상태(SG-z에서 +z만 골라냄 또는 χ = (2, i)/√5), 가운데 장치(없음 · SG-x +x · SG-60° + · SG-x 두 빔 합침 · SG-y +y), z방향 자기장 구간(B = 0 · 0.50 · 1.00 T, 머무는 시간 17.8 ps), 마지막 장치의 축(z · x · y)을 고르고 원자 빔 보내기를 누르면 마지막 장치에서 −축으로 간 비율(측정)과 이론값이 기록됩니다. z+ → 없음 → z, z+ → x+ → z, z+ → 60° → z, z+ → x 합침 → z를 차례로 기록하고 자기장 1.00 T도 켜 보세요. 기록이 4개 이상이면 데이터 검증 탭에서 −축 비율 대 (1 − n̂·⟨σ⟩)/2 그래프와 배치별 결과표를 볼 수 있습니다.

처음에 +z만 골랐어도 가운데 SG-x에서 +x를 통과시키면 마지막 SG-z에서 절반(이론 0.500, 측정 0.476)이 −z로 갔습니다. x 측정이 상태를 χ₊⁽ˣ⁾로 바꿔 처음 z 정보를 지웠기 때문이에요. 60° 축이면 sin²30° = 0.250, 두 빔을 다시 합쳐 어느 길인지 기록하지 않으면 중첩이 복원되어 0이었습니다. +x로 준비한 스핀이 1.00 T 구간(17.8 ps)에서 반 바퀴 세차하면 SG-x에서 전부 −x로 갔어요. 마지막 확률을 정하는 것은 마지막 장치 직전의 상태뿐입니다.

개념 정리

1. 스핀 ½과 파울리 행렬

Ŝ = (ħ/2)σ, σₓ = [[0,1],[1,0]], σ_y = [[0,−i],[i,0]], σ_z = [[1,0],[0,−1]], [σᵢ, σⱼ] = 2iε_ijk σ_k

상태 공간은 2차원입니다. n̂ = (sin θ cos φ, sin θ sin φ, cos θ) 방향 "위" 상태는

χ₊⁽ⁿ⁾ = (cos(θ/2), e^(iφ) sin(θ/2)), P(+n̂ | +ẑ) = cos²(θ/2)

각도가 θ/2로 들어가므로 2π 회전에 부호가 바뀌고 4π에서 돌아옵니다 — 회전하는 공으로는 설명할 수 없는 내재적 각운동량이에요.

2. 자기장 속 세차

Ĥ = g_s μ_B B Ŝ_z/ħ, ΔE = g_s μ_B B (g_s = 2.00232, μ_B = 5.78838×10⁻⁵ eV/T). B = 1.00 T에서 ΔE = 1.159×10⁻⁴ eV, f_L = 28.0 GHz. +x로 준비한 스핀은 ⟨Sₓ⟩ = (ħ/2)cos ω_L t로 돕니다. 자기장 구간에 머무는 시간은 1.00 T에서 정확히 반 바퀴(17.8 ps)가 되도록 잡았어요.

3. 연속 측정

  • z+ → z: 아래 0
  • z+ → x+ → z: x 통과 확률 ½, 마지막 장치에 들어온 빔의 50 %가 −z (처음 빔 대비 ¼)
  • z+ → 60° 축 + → z: sin²30° = 25 %
  • z+ → SG-x 두 빔을 결맞게 다시 합침 → z: 0 — "어느 길"을 기록하지 않으면 중첩이 그대로

4. 실험 모형과 실제의 차이

· 실제로 두 빔을 결맞게 다시 합치기는 매우 어렵습니다(파인만 강의의 "수정된 SG 장치" 사고실험).

· 세차의 회전 방향은 자기 모멘트의 부호에 따릅니다. 은 원자의 두 점은 최외각 전자 하나의 스핀 때문이에요.

· g_s = 2.00232는 실험값으로 씁니다(2는 디랙 방정식, 0.00232는 양자 전기역학 보정).

Ŝ = (ħ/2)σ, σₓ = [[0,1],[1,0]], σ_y = [[0,−i],[i,0]], σ_z = [[1,0],[0,−1]] · χ₊⁽ⁿ⁾ = (cos(θ/2), e^(iφ)sin(θ/2)), P(+n̂ | +ẑ) = cos²(θ/2) · ΔE = g_sμ_B B, ω_L = g_sμ_B B/ħ

“그럼 두 방향만 있는 거네. 위, 아래. 그리고 z로 위를 골라낸 다음 x로 재고, 다시 z로 재면 당연히 전부 위!”

제로

“마지막 줄이 핵심이네요. 두 빔을 다시 합치면 χ₊ = (χ₊⁽ˣ⁾ + χ₋⁽ˣ⁾)/√2이 복원돼요. ‘어느 길로 갔는지’ 기록이 남을 때만 상태가 바뀌어요.”

웹툰 13화 #4 · 연속 측정 검증

예제

스핀 상태 χ = (2, i)/√5에서 S_z, S_y를 측정할 때 +ħ/2가 나올 확률을 각각 구하시오(χ₊⁽ʸ⁾ = (1, i)/√2).

S_z: |2/√5|² = 0.8. S_y: ⟨χ₊⁽ʸ⁾|χ⟩ = (1/√10)(1·2 + (−i)(i)) = (1/√10)(2 + 1) = 3/√10 → 확률 0.9. 검산: ⟨σ_y⟩ = 2(0.9) − 1 = 0.8이고, 직접 χ†σ_yχ = (1/5)(2·1 + (−i)(2i)) = 4/5 = 0.8로 일치한다. 실험에서도 −z 0.199(이론 0.200), −y 0.096(이론 0.100)이었다. P(+z) = 0.8, P(+y) = 0.9

전자 스핀(g_s = 2.00232, μ_B = 5.788×10⁻⁵ eV/T)이 B = 1.00 T 자기장에 있을 때 두 준위의 에너지 차와 라머 진동수를 구하고, 반 바퀴 세차하는 데 걸리는 시간을 구하시오.

ΔE = g_sμ_B B = 2.00232 × 5.788×10⁻⁵ × 1.00 = 1.159×10⁻⁴ eV. f_L = ΔE/h = 1.159×10⁻⁴ / 4.1357×10⁻¹⁵ = 2.80×10¹⁰ Hz = 28.0 GHz. 반 바퀴는 1/(2f_L) = 17.8 ps이다. 실험의 자기장 구간이 바로 이 시간이라, +x로 준비한 스핀이 −x로 뒤집혀 SG-x에서 −x 비율이 1.000이었다. ΔE ≈ 1.16×10⁻⁴ eV, 28.0 GHz, 17.8 ps
