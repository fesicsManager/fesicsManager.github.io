비축퇴 섭동 이론 — 1차는 가중 평균, 2차는 준위 반발

무한 우물 왼쪽 절반에 턱 V₀를 깔거나 조화 진동자 용수철을 ε만큼 세게 하고, 1차·2차 섭동 보정과 고유함수 기저 행렬의 수치 대각화(수렴값 N = 60)를 비교했습니다. 턱 모형 바닥 준위의 1차 보정은 정확히 V₀/2였고, V₀ = 0.5E₁에서 2차까지 0.23438E₁이 수렴값 0.23445E₁과 0.03 % 이내로 맞았으며, 진동자는 √(1+ε)의 테일러 급수를 그대로 재현했습니다. 섭동 급수의 유도와 적용 범위를 정리합니다.

턱 모형에서 1차 보정은 세기와 관계없이 정확히 V₀/2였습니다. |ψₙ|²가 x = a/2에 대칭이라 절반이 턱 위에 있기 때문으로, 1차 보정은 교란을 비섭동 상태로 평균한 가중 평균이에요. 2차 보정은 바닥 준위에서 −0.0625V₀²/E₁(내려감), 둘째 준위에서 +0.0469V₀²/E₁(올라감)로 이웃 준위끼리 서로 밀어내는 준위 반발입니다. 2차까지의 오차는 V₀ = 0.5E₁에서 0.03 %였지만 1.0E₁에서는 0.25 %로 커졌어요. 진동자는 1 + ε/2 − ε²/8로 √(1+ε)에 다가갔고(ε = 0.5: 1.21875 대 1.22474), 세기가 클수록 고차 항이 중요해집니다.

개념 정리

1. 비축퇴 섭동 이론

Ĥ = Ĥ⁰ + λĤ′를 λ로 전개하면

Eₙ⁽¹⁾ = ⟨n⁰|Ĥ′|n⁰⟩, Eₙ⁽²⁾ = Σ_(m≠n) |⟨m⁰|Ĥ′|n⁰⟩|² / (Eₙ⁰ − Eₘ⁰)

1차 보정은 교란을 비섭동 상태로 평균한 것(가중 평균)이고, 바닥 상태의 2차 보정은 분모가 모두 음수라 항상 내려갑니다. 축퇴가 있으면 이 공식이 깨져요.

2. 조화 진동자 + (ε/2)mω²x²

정확해 ω → ω√(1+ε) → E/E⁰ = √(1+ε). 1차 1 + ε/2, 2차 1 + ε/2 − ε²/8 — √(1+ε)의 테일러 급수 그대로입니다. ε = 0.01 · 0.1 · 0.5 → 정확 1.004988 · 1.048809 · 1.224745.

수치 대각화는 비섭동 고유함수 N개로 Ĥ 행렬을 만들어 야코비 회전으로 대각화합니다. N을 늘리면 정확값으로 수렴해요.

3. 무한 우물 + 왼쪽 절반 턱

  • Eₙ⁽¹⁾ = V₀/2 (모든 n) — |ψₙ|²가 x = a/2에 대칭이라 정확히 절반이 턱 위
  • H′₂₁ = 4V₀/(3π) = 0.4244V₀, H′₃₁ = 0, H′₄₁ = −0.1698V₀, H′₆₁ = 0.1091V₀ (짝수 m만 남음)
  • E₁⁽²⁾ = −0.0625V₀²/E₁ (m = 2 항이 96 %), E₂⁽²⁾ = +0.0469V₀²/E₁ — 준위 반발
  • V₀ = 0.1E₁: 2차까지 0.04938E₁ / V₀ = 0.5E₁: 2차까지 0.23438, 수치 0.23445

4. 실험 모형과 실제의 차이

· 섭동 급수가 아예 발산하는 경우(점근 급수)도 많습니다. 변분법은 섭동이 작지 않아도 쓸 수 있는 보완 도구예요.

· "수렴값"은 N = 60 기저 대각화 결과입니다(넷째 자리 이내로 수렴).

예제

조화 진동자에 Ĥ′ = λx̂를 더할 때 바닥 에너지의 1차·2차 보정을 사다리 연산자로 구하고, 완전제곱으로 얻은 정확해와 비교하시오.

x̂ = √(ħ/2mω)(â₊ + â₋). 1차: ⟨0|x̂|0⟩ = 0. 2차: 0이 아닌 행렬 요소는 ⟨1|x̂|0⟩ = √(ħ/2mω)뿐이므로 E⁽²⁾ = λ²(ħ/2mω)/(E₀ − E₁) = λ²(ħ/2mω)/(−ħω) = −λ²/(2mω²). 정확해: ½mω²x² + λx = ½mω²(x + λ/mω²)² − λ²/(2mω²)로 평형점만 이동하고 에너지는 정확히 −λ²/(2mω²) 내려간다. 급수가 2차에서 끝나고 정확하다. E⁽¹⁾ = 0, E⁽²⁾ = −λ²/(2mω²) = 정확해

왼쪽 절반 턱 모형에서 V₀ = 0.2E₁일 때 바닥 준위의 ΔE를 1차와 2차까지 구하고, H′₂₁ = 4V₀/(3π)인 m = 2 항이 2차 보정에서 차지하는 비율을 구하시오.

1차: E₁⁽¹⁾ = V₀/2 = 0.1000E₁. m = 2 항: |H′₂₁|²/(E₁ − E₂) = (0.4244 × 0.2E₁)²/(−3E₁) = −0.00240E₁. 전체 2차 계수 −0.0625를 쓰면 E₁⁽²⁾ = −0.0625 × 0.2²E₁ = −0.00250E₁이므로 m = 2 항이 약 96 %를 차지한다(홀수 m 항은 대칭성 때문에 0). 2차까지 ΔE = 0.1000 − 0.0025 = 0.0975E₁로 실험 수렴값 0.09750E₁과 같다. 1차 0.1000E₁, 2차까지 0.0975E₁, m = 2 항 약 96 %
