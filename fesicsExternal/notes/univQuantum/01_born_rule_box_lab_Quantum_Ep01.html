대학 양자역학 · 웹툰 1화 「전자는 어디에 ‘있는가’」

보른 규칙 — 확률은 상자가 아니라 상태가 정한다

폭 a 상자 속 입자의 상태(포물선 x(a−x), 바닥 ψ₁, 들뜬 ψ₂, 균일)와 구간을 고르고, 같은 상태를 매번 새로 준비해 위치를 100~10000번 측정했습니다. 포물선 상태에서 0 ~ a/4 구간의 적분 확률은 0.1035로 뭉치가 말한 25 %보다 훨씬 작았고, 측정 빈도는 횟수가 늘수록 이 값 근처로 모였습니다. |Ψ|²를 확률 밀도로 읽는 보른 규칙, 규격화, 확률 보존을 정리합니다.

포물선 상태의 네 구간 확률은 0.1035 · 0.3965 · 0.3965 · 0.1035(합 1)로, |ψ|²가 벽에서 0으로 가고 가운데에서 커서 벽 쪽 4분의 1 구간은 25 %가 아니라 약 10 %입니다. 측정 빈도와 적분 확률의 차이는 100회에서 +0.047, 10000회에서 −0.005로 줄었는데, 통계적 흔들림 √(P(1−P)/N)이 1/√N로 줄기 때문이에요. ψ₂와 균일 상태는 0.25가 나왔지만 이유가 다릅니다. ψ₂는 대칭 덕분이고, 균일 ψ = 1/√a는 벽에서 0이 아니어서 무한 우물에서 허용되지 않는 상태예요. 확률은 상자가 아니라 상태가 정합니다.

개념 정리

1. 보른 규칙

입자의 상태는 파동함수 Ψ(x, t) 하나로 기술되고, |Ψ|²가 확률 밀도입니다.

P(a ≤ x ≤ b) = ∫ₐᵇ |Ψ(x, t)|² dx, ∫ |Ψ|² dx = 1 (규격화)

구간 확률은 구간 길이가 아니라 보라색 곡선 아래 초록 넓이입니다. 포물선 상태의 0~a/4는 0.1035(25 %가 아님), ψ₂와 균일은 0.25 — 같은 값이지만 이유가 다르죠. 균일 상태는 벽에서 0이 아니라 무한 우물에서는 허용되지 않아요. 측정은 매번 새로 준비한 상태를 재는 모의 측정이라 빈도는 표와 조금 다를 수 있고, 횟수가 많을수록 넓이에 가까워집니다.

2. 확률은 상자가 아니라 상태가 정한다

25 %는 |ψ|²가 상수일 때만 맞는데, ψ = 1/√a는 벽에서 0이 아니어서 무한 우물의 허용된 상태가 아닙니다. 경계 조건이 상태의 모양을, 모양이 확률을 정해요. 반면 ψ₂ = √(2/a)·sin(2πx/a)는 가운데에서 0인데도 각 4분의 1 구간 확률이 우연히 정확히 0.25입니다 — 균일해서가 아니라 대칭 때문이에요.

3. 확률 보존

V가 실수이면 연속 방정식 ∂ρ/∂t + ∂J/∂x = 0이 성립하고 J = (iħ/2m)(Ψ ∂Ψ*/∂x − Ψ* ∂Ψ/∂x)가 확률 흐름입니다. 퍼텐셜에 허수부 V₀ − iΓ를 넣으면 P(t) = e^(−2Γt/ħ)로 확률이 새어 나가요(광학 퍼텐셜).

4. 이 실험의 계산

  • ψ = A·x(a−x): ∫₀ᵃ A²x²(a−x)² dx = A²a⁵/30 = 1 → A = √(30/a⁵)
  • u = x/a로 치환하면 P(0 ≤ x ≤ a/4) = 30∫₀^¼ u²(1−u)² du = 53/512 = 0.1035
  • 네 구간: 0.1035 · 0.3965 · 0.3965 · 0.1035 (합 1)

실험 안에서는 심프슨 수치 적분으로 같은 값을 계산하고, 누적 분포(CDF)를 거꾸로 풀어 모의 측정값을 뽑습니다.

5. 실험 모형과 실제의 차이

· 측정 직후 같은 입자를 다시 재면 같은 값이 나옵니다(붕괴). 여기서는 매번 새로 준비한 상태를 재는 앙상블 측정이에요.

· "측정 전에 어디 있었나"는 실재론·코펜하겐·불가지론 등 해석이 갈리는 질문입니다. 이 실험은 해석을 채점하지 않습니다.

P(a ≤ x ≤ b) = ∫ₐᵇ |Ψ(x,t)|² dx, ∫|Ψ|² dx = 1 · ψ = √(30/a⁵)·x(a−x) → P(0 ≤ x ≤ a/4) = 53/512 = 0.1035

웹툰 1화 #4 · 규격화와 구간 확률 검증

예제

ψ(x) = A·e^(−|x|/a) (−∞ < x < ∞)를 규격화하고, |x| < a에서 입자를 발견할 확률을 구하시오.

∫|ψ|²dx = 2A²∫₀^∞ e^(−2x/a)dx = A²a = 1 → A = 1/√a. P(|x| < a) = 2·(1/a)∫₀ᵃ e^(−2x/a)dx = 1 − e⁻² ≈ 0.865. 전체 길이가 무한이라 ‘구간 길이 비율’로는 어림조차 할 수 없고, 상태의 모양이 확률을 정한다. A = 1/√a, 약 86.5 %

포물선 상태 ψ = √(30/a⁵)·x(a−x)에서 위치를 1000번 측정할 때, 0 ~ a/4 구간에서 발견되는 횟수의 기댓값과 통계적 흔들림(표준편차)을 구하시오.

P = 30∫₀^¼ u²(1−u)²du = 30(1/192 − 1/512 + 1/5120) = 53/512 = 0.1035. 기댓값 NP = 1000 × 0.1035 ≈ 104회. 이항 분포의 표준편차 √(NP(1−P)) = √(1000 × 0.1035 × 0.8965) ≈ 9.6회(빈도로 ±0.0096). 실험의 1000회 기록 0.0900(90회)은 약 1.4σ 아래로 통계적 흔들림 범위 안이다. 약 104회 ± 10회
