대학 양자역학 · 웹툰 12화 「궤도가 아니라 구름」

수소 원자의 지름 분포 — 보어 반지름은 경계가 아니라 최빈값

수소 원자의 상태(1s ~ 3d)와 반지름 R, 핵의 종류를 바꾸며 지름 확률 밀도 P(r) = r²|R_nl|²를 수치 적분했습니다. 1s 전자가 r < a₀ 안에 있을 확률은 0.3233, r < 2a₀는 0.7619였고, ⟨r⟩은 1.5a₀로 최빈 거리 a₀보다 컸습니다. 환산 질량을 넣으면 발머 α가 ¹H 656.47 nm, ²H 656.29 nm로 갈렸습니다. 수소 원자의 에너지와 축퇴, 지름 분포, 비리얼 관계를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 상태(1s · 2s · 2p · 3s · 3p · 3d), 반지름 R(0.5 ~ 12 a₀ 슬라이더), 핵(무한 질량 · ¹H · ²H)을 고르고 전자 구름 적분하기를 누르면 P(r < R), ⟨r⟩, 발머 α 파장이 기록됩니다. 1s로 R = 1.0과 2.0을 기록하고 2s·2p·3d의 ⟨r⟩도 기록해 일반식과 비교하세요. 기록이 4개 이상이면 데이터 검증 탭에서 ⟨r⟩ 대 ½[3n² − l(l+1)] 그래프와 핵 질량별 발머 α 표를 볼 수 있습니다.

1s 전자가 r < a₀ 안에 있을 확률은 0.3233으로 뭉치가 말한 반반이 아니었습니다. P(r)은 a₀에서 최대지만 바깥으로 긴 꼬리가 있어 ⟨r⟩ = 1.5a₀이고, 보어 반지름은 경계가 아니라 가장 있을 법한 거리예요. ⟨r⟩은 2s 6, 2p 5, 3d 10.5(a₀)로 ½[3n² − l(l+1)]과 같았고, 2s는 r = 2a₀에 지름 마디가 있어 그 안쪽 확률이 0.0527뿐이었습니다. 무한 질량 핵에서 656.11 nm였던 발머 α는 환산 질량을 넣으면 ¹H 656.47 nm, ²H 656.29 nm로 약 0.18 nm 갈립니다(1931년 중수소 발견).

개념 정리

1. 수소 원자의 해

Eₙ = −13.606 eV / n², l = 0, …, n−1, 축퇴도 Σ(2l+1) = n², a₀ = 4πε₀ħ²/(mₑe²) = 0.0529177 nm

지름 확률 밀도는 부피 요소 4πr²dr 때문에 P(r) = r²|R_nl|²입니다. 바닥 상태 ψ₁₀₀ = e^(−r/a₀)/√(πa₀³).

2. 환산 질량과 중수소 발견

μ = mₑm_p/(mₑ + m_p)를 쓰면 바닥 에너지 −13.598 eV, 발머 α(3→2) 진공 파장 656.47 nm. 중수소는 656.29 nm(차 0.179 nm) — 1931년 유리(Urey)가 이 동위원소 이동으로 중수소를 발견했습니다.

3. 1s 지름 분포

  • P(r) = (4r²/a₀³) e^(−2r/a₀), 최빈 거리 = a₀
  • P(r < a₀) = 1 − 5e⁻² = 0.3233, P(r < 2a₀) = 1 − 13e⁻⁴ = 0.7619
  • ⟨r⟩ = 1.5a₀ = 0.0794 nm, 일반식 ⟨r⟩ = ½[3n² − l(l+1)] a₀
  • ⟨1/r⟩ = 1/a₀ → ⟨V⟩ = −27.21 eV = 2E₁, ⟨T⟩ = +13.61 eV (비리얼 2⟨T⟩ = −⟨V⟩)

보어 반지름은 "가장 있을 법한 거리"일 뿐 경계가 아닙니다. l = 0이라 각운동량은 0이지만 σₚ ≠ 0 — 전자는 돌지 않고 운동량 분포를 가진 구름이에요. 2s는 r = 2a₀ = 0.106 nm에 마디가 있고, 2p의 최빈 거리는 4a₀ = 0.212 nm입니다.

4. 실험 모형과 실제의 차이

· 비상대론·스핀 없는 해입니다. 실제 스펙트럼에는 미세 구조(약 10⁻⁴ eV), 램 이동, 초미세 구조(21 cm선)가 더해집니다.

· ⟨V⟩, ⟨T⟩, 지름 분포는 무한 질량 핵 기준(a₀)으로 계산하고, 에너지·파장만 환산 질량을 반영합니다.

Eₙ = −13.606 eV/n², 축퇴도 n², a₀ = 4πε₀ħ²/(mₑe²) = 0.0529177 nm · 1s: P(r) = (4r²/a₀³)e^(−2r/a₀), P(r < a₀) = 1 − 5e⁻² = 0.3233, ⟨r⟩ = ½[3n² − l(l+1)]a₀
제로

“안쪽 32.3%, 바깥 67.7%. 최빈값 a₀, 평균 1.5a₀. 보어 반지름은 ‘가장 있을 법한 거리’일 뿐 경계가 아니에요.”

예제

수소 1s 상태에서 ⟨1/r⟩ = 1/a₀임을 이용해 ⟨V⟩와 ⟨T⟩를 eV로 구하고 비리얼 관계를 확인하시오(e²/(4πε₀a₀) = 2 × 13.606 eV).

⟨V⟩ = −(e²/4πε₀)⟨1/r⟩ = −e²/(4πε₀a₀) = −27.21 eV. E₁ = ⟨T⟩ + ⟨V⟩ = −13.61 eV이므로 ⟨T⟩ = −13.61 − (−27.21) = +13.61 eV. 2⟨T⟩ = 27.21 eV = −⟨V⟩로 쿨롱 퍼텐셜의 비리얼 정리가 성립한다. l = 0이라 각운동량은 0이지만 운동 에너지는 0이 아니다. ⟨V⟩ = −27.21 eV, ⟨T⟩ = +13.61 eV

ψ₂₁₀ ∝ r e^(−r/2a₀) cos θ의 지름 확률 밀도 최빈 거리를 구하고 보어 모형의 n = 2 반지름과 비교하시오.

R₂₁ ∝ r e^(−r/2a₀)이므로 P(r) ∝ r²R² = r⁴e^(−r/a₀). d/dr(r⁴e^(−r/a₀)) = 0 → 4/r = 1/a₀ → r = 4a₀ = 0.212 nm. 보어 모형의 n²a₀ = 4a₀와 같지만 이 일치는 l = n − 1 상태에서만 성립하고, 평균 ⟨r⟩ = ½[3·4 − 2]a₀ = 5a₀는 다르다(실험의 2p 기록 ⟨r⟩ = 5.000). 최빈 거리 4a₀ ≈ 0.212 nm
