대학 양자역학 · 웹툰 11화 「화살표는 z축을 가리킬 수 없다」

각운동량 양자화 — 최대 정렬에서도 각도가 남는다

각운동량 상태 |l, m⟩을 고르고 |L| = ħ√(l(l+1)), L_z = mħ로 z축과의 각을 구한 뒤, L_x 행렬을 야코비 회전으로 대각화해 ⟨L_x²⟩를 기록했습니다. m = l로 최대 정렬해도 l = 1, 2, 3, 10, 100에서 45.0°, 35.3°, 30.0°, 17.5°, 5.7°가 남았고, ⟨L_x²⟩는 언제나 ½[l(l+1) − m²]ħ²였습니다. 각운동량 대수, 고윳값 ħ²l(l+1)·mħ, 고전 극한을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 각운동량 양자수 l(1 · 2 · 3 · 10 · 100)과 자기 양자수 m(m = l · l − 1 · 0)을 고르고 상태 만들기를 누르면 z축과의 각 θ, l(l+1) − m², ⟨L_x²⟩/ħ²가 기록되고 L_x 측정 가능 값과 확률이 표시됩니다. m = l로 l = 1, 2, 3, 10, 100을 모두 기록하고, l = 1, m = 0도 기록해 보세요. 기록이 4개 이상이면 데이터 검증 탭에서 ⟨L_x²⟩ 대 l(l+1) − m² 직선(기울기 ½)과 최소 각도 표를 볼 수 있습니다.

m = l로 최대 정렬해도 cos θ = l/√(l(l+1))이라 θ = 45.00°(l = 1), 35.26°(l = 2)…로 0이 되지 않았고, l = 100에서야 5.71°까지 줄었습니다. l이 커질수록 각이 0으로 가는 것이 고전 극한이에요. ⟨L_x²⟩는 모든 기록에서 ½[l(l+1) − m²]과 같았습니다. |l, l⟩에서는 ⟨L_x²⟩ = ⟨L_y²⟩ = lħ²/2라 σ_Lxσ_Ly = (ħ/2)|⟨L_z⟩|로 불확정성 하한을 정확히 채웁니다. 세 성분이 서로 교환하지 않으니 동시에 정할 수 없어요.

개념 정리

1. 각운동량 대수

[L̂_x, L̂_y] = iħL̂_z (순환), [L̂², L̂_i] = 0

그래서 L̂²와 L̂_z 하나만 동시에 정할 수 있습니다. 사다리 연산자 L̂± = L̂_x ± iL̂_y로

L̂²|l,m⟩ = ħ²l(l+1)|l,m⟩, L̂_z|l,m⟩ = mħ|l,m⟩, m = −l, …, l

2. 반정수와 3차원

Y_l^m ∝ e^(imφ)가 한 값이어야 해서 궤도 각운동량은 정수 l. 교환 관계만 쓰면 l = ½, 3/2, …도 허용되는데, 이것이 13화의 스핀입니다. 중심력 문제의 유효 퍼텐셜에는 L²/2mr² 대신 ħ²l(l+1)/2mr²가 들어가요.

3. 최대 정렬에서도 남는 각도

  • cos θ_min = l/√(l(l+1)) = √(l/(l+1))
  • l = 1, 2, 3, 10, 100 → θ_min = 45.0°, 35.3°, 30.0°, 17.5°, 5.7° (고전 극한에서 0으로)
  • |l, l⟩에서 ⟨L_x²⟩ = ⟨L_y²⟩ = ħ²l/2 → σ_Lx σ_Ly = ħ²l/2 = (ħ/2)|⟨L_z⟩| (불확정성 하한과 같음)
  • 일반식 ⟨L_x²⟩ = (ħ²/2)[l(l+1) − m²]

L_x 행렬은 ⟨m±1|L̂_x|m⟩ = (ħ/2)√(l(l+1) − m(m±1))인 (2l+1)×(2l+1) 실대칭 행렬이고, 실험은 이것을 야코비 회전으로 대각화합니다(l ≤ 10).

4. 실험 모형과 실제의 차이

· "기울어진 화살표"도 비유입니다. L_x, L_y는 값이 정해지지 않은 채 분포를 가질 뿐이에요.

· 화학의 p_x, p_y 아령은 Y₁¹과 Y₁⁻¹을 섞은 실수 조합이라 L_z 고유상태가 아닙니다.

[L̂_x, L̂_y] = iħL̂_z, [L̂², L̂ᵢ] = 0, L̂²|l,m⟩ = ħ²l(l+1)|l,m⟩, L̂_z|l,m⟩ = mħ|l,m⟩ · cos θ_min = l/√(l(l+1)), ⟨L_x²⟩ = (ħ²/2)[l(l+1) − m²]
뭉치

“각운동량은 화살표야. z축으로 똑바로 세우면 L_z = |L|, 끝. 원자 속 전자도 각운동량을 z축에 딱 맞출 수 있어.”

웹툰 11화 #4 · 최대 정렬에서도 남는 각도

예제

|l = 1, m = 0⟩ 상태에서 L_x를 측정할 때 가능한 결과와 각 확률을 구하시오. (L_x 고유상태: |±⟩ₓ = ½|1,1⟩ ± (1/√2)|1,0⟩ + ½|1,−1⟩, |0⟩ₓ = (|1,1⟩ − |1,−1⟩)/√2)

가능한 값은 +ħ, 0, −ħ. |⟨±ₓ|1,0⟩|² = (1/√2)² = ½, |⟨0ₓ|1,0⟩|² = 0. 따라서 ±ħ가 각 50 %이고 0은 절대 나오지 않는다. 검산: ⟨L_x²⟩ = ½ħ² + ½ħ² = ħ²이고, 일반식 (ħ²/2)[l(l+1) − m²] = (ħ²/2)(2 − 0) = ħ² 및 실험 기록 1.000과 같다. +ħ 50 %, −ħ 50 %, 0은 0 %

|l = 2, m = 2⟩ 상태에서 반고전적 각 θ와 σ_Lxσ_Ly를 구하고 불확정성 하한과 비교하시오.

|L| = ħ√6 = 2.449ħ, L_z = 2ħ → cos θ = 2/√6 = 0.8165, θ = 35.26°. ⟨L_x²⟩ = ⟨L_y²⟩ = (ħ²/2)(6 − 4) = ħ²이고 ⟨L_x⟩ = ⟨L_y⟩ = 0이므로 σ_Lxσ_Ly = ħ². 하한 (ħ/2)|⟨L_z⟩| = (ħ/2)(2ħ) = ħ²로 등호가 성립한다. θ ≈ 35.3°, σ_Lxσ_Ly = ħ² = 하한
