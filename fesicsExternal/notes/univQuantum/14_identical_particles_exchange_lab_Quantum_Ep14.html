대학 양자역학 · 웹툰 14화 「구별할 수 없는 둘」

동일 입자의 교환 대칭 — 이름표 없는 두 입자의 거리

폭 a 무한 우물에 상호작용 없는 두 입자를 ψₐ, ψ_b에 하나씩 넣고, 두 입자 파동함수를 구별 가능·공간 대칭(보손형)·공간 반대칭(페르미온형)으로 만들어 2차원 수치 적분으로 거리 √⟨(x₁ − x₂)²⟩를 구했습니다. 같은 ψ₁, ψ₂ 쌍인데 거리는 0.196a(보손형), 0.321a(구별 가능), 0.410a(페르미온형)로 달랐고, ψ₁, ψ₃ 쌍은 대칭과 관계없이 0.332a였습니다. 교환 대칭, 교환 항, 파울리 배타 원리를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 두 입자의 상태(ψ₁, ψ₂ · ψ₁, ψ₃ · ψ₂, ψ₃)와 두 입자 파동함수(구별 가능 · 공간 대칭 보손형 · 공간 반대칭 페르미온형)를 고르고 거리 계산하기를 누르면 ⟨(x₁−x₂)²⟩/a², 거리/a, x₁ = x₂ 대각선의 밀도비가 기록됩니다. ψ₁, ψ₂ 쌍으로 세 가지 대칭을 모두 기록하고 ψ₁, ψ₃ 쌍도 비교하세요. 기록이 4개 이상이면 데이터 검증 탭에서 대칭별 거리 막대와 수치 적분 대 교환 항 식 비교표를 볼 수 있습니다.

ψ₁, ψ₂ 쌍의 ⟨(x₁ − x₂)²⟩는 구별 가능 0.1033a², 보손형 0.0384a², 페르미온형 0.1682a²로, 차이는 정확히 ∓2|⟨x⟩₁₂|² = ∓0.0649a²였습니다. 페르미온형은 x₁ = x₂에서 밀도가 0, 보손형은 2배라 힘을 넣지 않았는데도 밀어내거나 끌어당기는 것처럼 보여요(교환 힘). ψ₁, ψ₃ 쌍은 ⟨x⟩₁₃ = 0이라 보손형·페르미온형 모두 0.1104a²로 같았고, 대각선 밀도비(2.00 대 0.00)만 달랐습니다. 교환 효과는 겹침 적분 ⟨x⟩ₐ_b가 0이 아닐 때만 거리에 나타납니다.

개념 정리

1. 교환 대칭

교환 연산자 P̂ψ(x₁, x₂) = ψ(x₂, x₁). 동일 입자는 P̂ψ = ±ψ여야 합니다.

ψ±(x₁, x₂) = [ψₐ(x₁)ψ_b(x₂) ± ψ_b(x₁)ψₐ(x₂)]/√2

+는 보손(정수 스핀), −는 페르미온(반정수 스핀). 페르미온에서 a = b이면 ψ₋ = 0 — 파울리 배타 원리.

⟨(x₁ − x₂)²⟩± = ⟨x²⟩ₐ + ⟨x²⟩_b − 2⟨x⟩ₐ⟨x⟩_b ∓ 2|⟨x⟩ₐ_b|²

2. 스핀과 함께

전자는 스핀까지 포함한 전체가 반대칭이어야 합니다. 스핀 단일항이면 공간 부분은 대칭(보손형), 삼중항이면 반대칭(페르미온형). 공유 결합, 헬륨 오르토/파라 준위, 강자성체의 교환 상호작용이 여기서 나와요.

3. ψ₁, ψ₂ 쌍

  • ⟨x²⟩ₙ = a²(1/3 − 1/(2n²π²)): 0.28267a², 0.32067a², ⟨x⟩ = a/2
  • ⟨x⟩₁₂ = −16a/(9π²) = −0.18013a (3화 중첩의 진동 진폭과 같은 겹침 적분)
  • 구별 가능 0.1033a² (0.321a), 보손형 0.0384a² (0.196a), 페르미온형 0.1682a² (0.410a)
  • ψ₁, ψ₃ 쌍은 대칭성 때문에 ⟨x⟩₁₃ = 0이라 1차원 거리에서 교환 효과가 사라짐

힘을 넣지 않았는데 끌리거나 밀리는 것처럼 보이는 교환 힘은 실제 힘이 아니라 대칭화 요구의 기하학적 결과입니다.

4. 실험 모형과 실제의 차이

· 1차원·상호작용 없는 모형입니다. 실제 다전자 계산은 하트리-포크 같은 근사법이 필요해요.

· 거리는 160×160 칸 중점 적분, 표의 이론값은 위 식으로 계산합니다.

ψ±(x₁, x₂) = [ψₐ(x₁)ψ_b(x₂) ± ψ_b(x₁)ψₐ(x₂)]/√2 · ⟨(x₁ − x₂)²⟩± = ⟨x²⟩ₐ + ⟨x²⟩_b − 2⟨x⟩ₐ⟨x⟩_b ∓ 2|⟨x⟩ₐ_b|², ⟨x⟩₁₂ = −16a/(9π²) = −0.180a
뭉치

“전자 두 개를 상자에 넣으면 전자 A는 ψ₁, 전자 B는 ψ₂. 이름표만 붙이면 끝이지. 둘 사이 거리 평균은 이름표랑 상관없어.”

예제

폭 a 무한 우물에 상호작용 없는 전자 3개(스핀 ½)를 넣을 때 바닥 상태 총에너지를 E₁ 단위로 구하시오. 구별 가능한 스핀 없는 입자 3개라면?

전자는 페르미온이라 한 상태(n, 스핀)에 하나뿐이다. n = 1에 스핀 위·아래로 2개(2E₁), 세 번째는 n = 2(E₂ = 4E₁) → 6E₁. 구별 가능한 입자는 셋 다 n = 1에 들어가 3E₁. 배타 원리가 에너지를 두 배로 올렸고, 고체의 페르미 에너지와 백색왜성의 축퇴압이 이 효과의 확대판이다. 전자 6E₁, 구별 가능 3E₁

ψ₁, ψ₂ 쌍(폭 a 무한 우물)에서 ⟨x²⟩ₙ = a²(1/3 − 1/(2n²π²)), ⟨x⟩₁₂ = −16a/(9π²)를 이용해 세 경우의 √⟨(x₁ − x₂)²⟩를 구하시오.

⟨x²⟩₁ = 0.28267a², ⟨x²⟩₂ = 0.32067a², ⟨x⟩₁ = ⟨x⟩₂ = a/2. 구별 가능: 0.28267 + 0.32067 − 2(0.25) = 0.10334a² → 0.321a. 2|⟨x⟩₁₂|² = 2(0.18013)² = 0.06489a². 보손형 0.10334 − 0.06489 = 0.03845a² → 0.196a, 페르미온형 0.10334 + 0.06489 = 0.16823a² → 0.410a. 실험의 2차원 수치 적분과 넷째 자리까지 같다. 0.321a, 0.196a, 0.410a
