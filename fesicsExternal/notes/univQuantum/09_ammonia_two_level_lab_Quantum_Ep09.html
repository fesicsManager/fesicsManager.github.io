대학 양자역학 · 웹툰 9화 「상태는 벡터, 관측량은 행렬」

2준위계와 유니터리 시간 변화 — 확률은 새지 않고 진동한다

암모니아의 질소 위치를 |U⟩, |D⟩ 두 상태로 근사한 2×2 해밀토니안을 수치로 대각화해 시간을 돌리고, 시각 t에 |D⟩에서 발견될 확률 P_D를 기록했습니다. |U⟩에서 출발한 고립계는 P_D = sin²(At/ħ)를 따라 10.47 ps에 0.50을 지나 20.95 ps에 1.00, 41.89 ps에 다시 0이 되었고, 결어긋남(T₂ = 10 ps)을 켜야 0.5 근처에 머물렀습니다. 디랙 표기, 에르미트 연산자, 2준위계의 대각화와 유니터리 시간 변화를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 처음 상태(|U⟩ · |D⟩ · 에너지 고유상태 |+⟩), 환경(고립 · T₂ = 50 ps · T₂ = 10 ps), 시각 t(0 ~ 60 ps 슬라이더)를 고르고 시간 진행을 누르면 sin²(At/ħ)와 P_D가 기록됩니다. |U⟩·고립으로 0, 5.24, 10.5, 15.7, 20.9, 41.9 ps 근처를 기록한 뒤 T₂ = 10 ps로 바꿔 긴 시각을 기록하세요. 기록이 4개 이상이면 데이터 검증 탭에서 P_D 대 sin²(At/ħ) 그래프(고립계 기울기 1)와 시각별 기록표를 볼 수 있습니다.

|U⟩에서 출발한 고립계의 P_D는 모든 시각에서 sin²(At/ħ)와 일치했고, 10.47 ps에 0.50을 지난 뒤 멈추지 않고 20.95 ps에 1.00까지 완전히 넘어갔다가 41.89 ps에 0으로 돌아왔습니다. 확률이 새는 것이 아니라 상대 위상이 돌며 진동하는 거예요. 같은 41.89 ps에서 T₂ = 10 ps 결어긋남을 넣으면 P_D = 0.4924로, 0.5 근처에 머무는 것은 환경과의 상호작용이 있을 때뿐입니다. 에너지 고유상태 |+⟩는 정상상태라 P_D = 0.5000에서 변하지 않았어요(표의 sin² 열은 |U⟩ 출발 기준 값).

개념 정리

1. 디랙 표기와 에르미트 연산자

상태는 힐베르트 공간의 벡터 |ψ⟩, 내적은 ⟨φ|ψ⟩ = ∫φ*ψ dx. 관측량은 에르미트 연산자(Q̂† = Q̂)라서 고유값이 실수이고 서로 다른 고유값의 고유벡터는 직교합니다. Q̂를 재면 결과는 고유값 qₙ, 확률은 |⟨eₙ|ψ⟩|²예요.

2. 암모니아 메이저 (1954)

이 23.87 GHz 전이를 썼습니다. 불균일 전기장으로 위 준위 분자만 골라 공진기에 넣는 원리예요.

3. 암모니아 2준위계

Ĥ = [[E₀, −A], [−A, E₀]], |±⟩ = (|U⟩ ± |D⟩)/√2, E± = E₀ ∓ A

  • |U⟩ = (|+⟩ + |−⟩)/√2 → P_D(t) = sin²(At/ħ)
  • 2A = hf, f = 23.87 GHz → 2A = 9.87×10⁻⁵ eV
  • 처음 1이 되는 시각 t₁ = πħ/(2A) = 1/(2f) = 20.9 ps, 41.9 ps에 다시 |U⟩
  • t = 0 · 5.24 · 10.5 · 15.7 · 20.9 · 41.9 ps → P_D = 0 · 0.146 · 0.500 · 0.854 · 1.000 · 0

고립된 계의 시간 변화는 유니터리 Û = e^(−iĤt/ħ)라 정보가 새지 않습니다. 확률이 "새는" 것이 아니라 진동해요. 반반에서 멈추는 것은 환경과의 상호작용(결어긋남, 시간 상수 T₂)이 있을 때의 이야기입니다.

4. 실험 모형과 실제의 차이

· 실제 암모니아에는 다른 진동 준위도 있지만 간격이 2A보다 훨씬 커서 저온에서는 두 상태만 남습니다.

· 결어긋남은 에너지 기저의 비대각 밀도 행렬 원소가 e^(−t/T₂)로 줄어드는 가장 단순한 모형으로 넣었습니다(가상 T₂ 값).

· E₀ = 1 eV로 두었지만 전체 위상만 바뀌므로 어떤 측정값에도 영향이 없습니다.

Ĥ = [[E₀, −A], [−A, E₀]], |±⟩ = (|U⟩ ± |D⟩)/√2, E± = E₀ ∓ A · |U⟩에서 P_D(t) = sin²(At/ħ) · 2A = hf (f = 23.87 GHz) = 9.87×10⁻⁵ eV, t₁ = 1/(2f) = 20.9 ps

닥터 이안

“고립된 계의 시간 변화는 유니터리, Û = e^(−iĤt/ħ)다. 정보가 새지 않으니 ‘평형으로 풀어지는’ 일이 없다. 반반으로 섞여 끝나는 것은 환경과의 상호작용(결어긋남)이 있을 때의 이야기다.”

웹툰 9화 #4 · 2준위계 시간 변화 검증

예제

Q̂ = [[0, −i], [i, 0]]이 에르미트임을 보이고 고윳값과 규격화된 고유벡터를 구해 직교함을 확인하시오.

전치 켤레를 취하면 Q̂† = [[0, (i)*], [(−i)*, 0]] = [[0, −i], [i, 0]] = Q̂이므로 에르미트다. 특성방정식 λ² − 1 = 0 → λ = ±1(실수). 고유벡터 (1, i)/√2(+1), (1, −i)/√2(−1). 첫 벡터에 켤레를 취한 내적은 ½(1·1 + (−i)(−i)) = ½(1 − 1) = 0으로 직교한다. 13화에서 만날 파울리 행렬 σ_y다. λ = ±1, (1, ±i)/√2, 서로 직교

암모니아 반전 진동수 f = 23.87 GHz로 2A(eV)와 P_D가 처음 1이 되는 시각을 구하고, t = 5.24 ps에서의 P_D를 구하시오(h = 4.1357×10⁻¹⁵ eV·s).

2A = hf = 4.1357×10⁻¹⁵ × 23.87×10⁹ = 9.87×10⁻⁵ eV. P_D = sin²(At/ħ)가 처음 1이 되는 것은 At/ħ = π/2일 때, t₁ = πħ/(2A) = 1/(2f) = 2.09×10⁻¹¹ s ≈ 20.9 ps. t = 5.24 ps는 t₁의 약 1/4이라 At/ħ ≈ π/8 → P_D = sin²(π/8) = 0.146. 실험 기록도 0.1466이었다. 2A ≈ 9.87×10⁻⁵ eV, t₁ ≈ 20.9 ps, P_D ≈ 0.146
