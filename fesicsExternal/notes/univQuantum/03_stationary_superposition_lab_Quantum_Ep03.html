대학 양자역학 · 웹툰 3화 「변하지 않는 상태, 움직이는 중첩」

정상상태와 중첩 — 출렁임은 상대 위상에서 나온다

폭 a 무한 우물의 전자를 정상상태 Ψ₁, Ψ₂ 또는 중첩 (ψ₁+ψ₂)/√2, (ψ₁+ψ₃)/√2로 준비하고 시각 t를 바꾸며 ⟨x⟩와 ⟨H⟩를 기록했습니다. 정상상태의 ⟨x⟩는 언제나 0.5000a였지만, ψ₁+ψ₂ 중첩은 0.3199a ↔ 0.6801a를 주기 3.67 fs로 오갔고 ⟨H⟩ = 0.940 eV는 시간에 무관했습니다. 변수분리, 정상상태의 성질, 상대 위상이 만드는 운동을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 상태(정상상태 Ψ₁ · Ψ₂, 중첩 ψ₁+ψ₂ · ψ₁+ψ₃), 우물 폭 a(0.80 · 1.00 · 1.20 nm), 시각 t(0 ~ 8 fs 슬라이더)를 고르고 시간 진행을 누르면 cos ωt, ⟨x⟩/a, ⟨H⟩가 기록됩니다. 정상상태 Ψ₁을 여러 시각에 기록한 뒤, 중첩 ψ₁+ψ₂로 0 ~ 4 fs 사이 시각을 4개 이상 기록하세요. 기록이 4개 이상이면 데이터 검증 탭에서 ⟨x⟩/a − ½ 대 cos ωt 직선과 상태별 ⟨x⟩ 범위·주기 표를 볼 수 있습니다.

Ψ₁은 t = 0과 1.84 fs에서 ⟨x⟩ = 0.5000a로 같아 정상상태는 |Ψ|²와 기댓값이 시간에 무관합니다. ψ₁+ψ₂ 중첩은 ⟨x⟩/a − 0.5 = −0.1801·cos ωt를 따라 0.3199a(t = 0)에서 0.6801a(t = 1.84 fs, 반주기)로 움직였고, 주기는 T = h/(E₂ − E₁) = 3.67 fs였어요. 움직임은 서로 다른 에너지 사이의 상대 위상에서 나옵니다. ψ₁+ψ₃는 |Ψ|²가 출렁여도 ⟨x⟩₁₃ = 0이라 ⟨x⟩가 0.5a에 머물렀고, 어느 중첩이든 ⟨H⟩ = Σ|cₙ|²Eₙ은 일정했습니다.

개념 정리

1. 변수분리와 정상상태

V가 시간에 무관하면 Ψ = ψ(x)·e^(−iEt/ħ), Ĥψ = Eψ. 위상 인자의 크기는 |e^(−iEt/ħ)|² = 1이라 |Ψ|²와 모든 기댓값이 시간에 무관합니다.

2. 중첩에서 생기는 움직임

Ψ = (ψ₁e^(−iE₁t/ħ) + ψ₂e^(−iE₂t/ħ))/√2 이면

|Ψ|² = ½(ψ₁² + ψ₂²) + ψ₁ψ₂ cos ωt, ω = (E₂ − E₁)/ħ

  • ⟨x⟩₁₂ = (2/a)∫ x sin(πx/a) sin(2πx/a) dx = −16a/(9π²) = −0.1801a
  • ⟨x⟩(t) = a/2 − 0.180a·cos ωt
  • 전자, a = 1.00 nm: E₁ = π²ħ²/(2ma²) = 0.376 eV, E₂ = 1.504 eV, 주기 T = h/ΔE = 3.67 fs

움직임은 서로 다른 에너지 사이의 상대 위상에서 나옵니다. 전체 위상(에너지 기준점)은 관측되지 않아요.

3. 에너지 보존

중첩이 출렁여도 ⟨H⟩ = Σ|cₙ|²Eₙ은 시간에 무관합니다. ψ₁ + ψ₃ 중첩은 |Ψ|²가 출렁여도 대칭 때문에 ⟨x⟩₁₃ = 0이라 ⟨x⟩가 a/2에 머물러요.

4. 실험 모형과 실제의 차이

· 실제 원자·양자점의 중첩은 자발 방출로 결국 바닥 상태로 떨어집니다(전자기장 양자화가 필요해 이 실험 범위 밖).

· ⟨x⟩는 매 시각 |Ψ|²를 심프슨 적분(400칸)해 구합니다.

Ψ = (ψ₁e^(−iE₁t/ħ) + ψ₂e^(−iE₂t/ħ))/√2 → |Ψ|² = ½(ψ₁² + ψ₂²) + ψ₁ψ₂ cos ωt, ω = (E₂ − E₁)/ħ, ⟨x⟩(t) = a/2 − 0.180a·cos ωt

웹툰 3화 #4 · 무한 우물 두 상태 중첩 검증

예제

폭 a = 1.00 nm 무한 우물의 전자가 (ψ₁ + ψ₂)/√2 상태에 있다. E₁, E₂, ⟨x⟩가 진동하는 주기, 같은 에너지 차의 광자 파장을 구하시오.

E₁ = π²ħ²/(2mₑa²) = π² × (1.0546×10⁻³⁴)² / (2 × 9.109×10⁻³¹ × 10⁻¹⁸) J = 6.02×10⁻²⁰ J = 0.376 eV, E₂ = 4E₁ = 1.504 eV. ΔE = 1.128 eV → T = h/ΔE = 4.136×10⁻¹⁵ eV·s / 1.128 eV = 3.67 fs(ω = 1.71×10¹⁵ rad/s). λ = hc/ΔE = 1239.8 eV·nm / 1.128 eV = 1099 nm(근적외선). E₁ = 0.376 eV, E₂ = 1.504 eV, T ≈ 3.67 fs, λ ≈ 1099 nm

중첩 상태 Ψ = (ψ₁e^(−iE₁t/ħ) + ψ₂e^(−iE₂t/ħ))/√2에서 ⟨H⟩가 시간에 무관함을 보이고, a = 1.00 nm 전자에 대해 eV로 구하시오.

cₙ(t) = cₙ(0)e^(−iEₙt/ħ)이므로 |cₙ(t)|² = |cₙ(0)|²는 상수다. 교차항 ⟨ψ₁|Ĥ|ψ₂⟩ = E₂⟨ψ₁|ψ₂⟩ = 0(직교)이라 시간 의존이 남지 않고 ⟨H⟩ = Σ|cₙ|²Eₙ = ½(0.376 + 1.504) = 0.940 eV. 실험 기록의 ⟨H⟩ 열도 모든 시각에서 0.940이었다. 에너지 보존의 양자 버전이다. ⟨H⟩ = 0.940 eV(시간 불변)
