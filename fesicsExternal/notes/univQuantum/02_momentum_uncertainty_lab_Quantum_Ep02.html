대학 양자역학 · 웹툰 2화 「운동량은 ‘미분’이다」

운동량 연산자와 불확정성 — σₓσₚ는 ħ/2 아래로 내려가지 않는다

파동함수(포물선, 무한 우물 바닥 ψ₁, 가우스, ψ₂)와 길이 척도 a, 위상 기울기 k₀를 바꾸며 ⟨x⟩, σₓ와 p̂ = −iħ d/dx로 구한 ⟨p⟩, σₚ를 기록했습니다. σₓσₚ는 가우스 0.500ħ, ψ₁ 0.568ħ, 포물선 0.598ħ, ψ₂ 1.670ħ로 어느 상태도 하한 ħ/2 아래로 내려가지 않았고, a를 바꾸거나 e^(ik₀x)를 곱해도 곱은 변하지 않았습니다. 기댓값을 연산자로 계산하는 법과 불확정성의 의미를 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 파동함수(포물선 x(a−x), 무한 우물 바닥 sin(πx/a), 가우스 σₓ = 0.2a, 들뜬 sin(2πx/a)), 길이 척도 a(0.50 · 1.00 · 2.00 nm), 위상 기울기(k₀ = 0 또는 5.0 nm⁻¹)를 고르고 기댓값 계산하기를 누르면 σₓ, σₚ, σₓσₚ/ħ가 기록됩니다. 네 상태를 모두 기록하고, 한 상태로 a와 k₀를 바꿔 보세요. 기록이 4개 이상이면 데이터 검증 탭에서 σₚ–1/σₓ 그래프(기울기 = σₓσₚ/ħ)와 상태별 표를 볼 수 있습니다.

폭을 1.00 → 0.50 nm로 줄이면 σₓ는 절반(0.1890 → 0.0945 nm), σₚ는 두 배(3.162 → 6.325 ħ/nm)가 되어 σₓσₚ는 상태의 모양만으로 정해집니다. e^(ik₀x)를 곱하면 ⟨p⟩만 ħk₀ = 5.000 ħ/nm로 바뀌고 σₚ는 그대로였어요. 하한 0.500ħ에 정확히 닿은 것은 가우스뿐이고, 포물선은 1.20배, ψ₁은 1.14배, 마디가 하나 있는 ψ₂는 3.34배였습니다. σ는 측정 오차가 아니라 상태 고유의 퍼짐입니다.

개념 정리

1. 연산자로 구하는 기댓값

⟨x⟩ = ∫ ψ* x ψ dx, ⟨p⟩ = ∫ ψ* (−iħ ∂/∂x) ψ dx, σ_Q² = ⟨Q²⟩ − ⟨Q⟩²

실수 ψ에서는 ⟨p⟩ = −(iħ/2)[ψ²] = 0이고, ⟨p²⟩ = ħ² ∫ |ψ′|² dx (경계에서 ψ = 0이라 부분적분 항이 사라짐).

2. 길이 척도와 위상 기울기

폭 a를 바꾸면 σₓ ∝ a, σₚ ∝ 1/a라서 곱은 그대로입니다. ψ에 e^(ik₀x)를 곱하면 ⟨p⟩ = ħk₀가 되지만 σₚ는 변하지 않아요 — 위상의 기울기가 평균 운동량입니다.

3. 포물선 상태 ψ = √(30/a⁵)·x(a−x)

  • ⟨x²⟩ = 2a²/7, σₓ² = a²/28 → σₓ = 0.189a (균일 분포라면 a/√12 = 0.289a)
  • ⟨p²⟩ = 10ħ²/a² → σₚ = √10 ħ/a = 3.162 ħ/a
  • σₓσₚ = √(5/14) ħ = 0.598 ħ — 하한 0.5ħ의 1.20배

무한 우물 바닥 sin(πx/a)는 0.568ħ, 가우스 함수는 정확히 0.500ħ(최소)입니다. 가우스 파속은 σₓ = 0.2a로 잡았고 상자 밖까지 퍼진 자유 공간 상태예요.

4. 실험 모형과 실제의 차이

· σ는 측정 오차가 아니라 상태 고유의 퍼짐입니다. 완벽한 장비로 같은 상태를 재도 흩어져요.

· 도함수는 중심 차분, 적분은 심프슨 공식(800칸)으로 계산해 이론값과 넷째 자리 이하에서 다를 수 있습니다.

⟨x⟩ = ∫ψ*xψ dx, ⟨p⟩ = ∫ψ*(−iħ ∂/∂x)ψ dx, σ_Q² = ⟨Q²⟩ − ⟨Q⟩², σₓσₚ ≥ ħ/2 · 포물선: σₓ = a/√28 = 0.189a, σₚ = √10 ħ/a → σₓσₚ = √(5/14) ħ = 0.598ħ

예제

무한 우물 바닥 상태 ψ₁ = √(2/a)·sin(πx/a)의 σₓ, σₚ와 σₓσₚ를 구하시오.

⟨x⟩ = a/2, ⟨x²⟩ = a²(1/3 − 1/(2π²)) = 0.28267a² → σₓ² = 0.28267a² − 0.25a² = 0.03267a², σₓ = 0.1808a. 실수 ψ라 ⟨p⟩ = 0, ⟨p²⟩ = ħ²∫|ψ′|²dx = π²ħ²/a² → σₚ = πħ/a = 3.142ħ/a. σₓσₚ = 0.1808π ħ = 0.568ħ로 하한 ħ/2의 1.14배다. σₓ ≈ 0.181a, σₚ = πħ/a, σₓσₚ ≈ 0.568ħ

실수 규격화 함수 φ(x)에 대해 ψ(x) = φ(x)e^(ik₀x)의 ⟨p⟩를 구하고, k₀ = 5.0 nm⁻¹일 때 평균 운동량을 SI 단위로 구하시오(ħ = 1.0546×10⁻³⁴ J·s).

ψ′ = (φ′ + ik₀φ)e^(ik₀x)이므로 ⟨p⟩ = −iħ∫φ(φ′ + ik₀φ)dx = −iħ[φ²/2]₋∞^∞ + ħk₀∫φ²dx = ħk₀. 수치: 1.0546×10⁻³⁴ × 5.0×10⁹ = 5.27×10⁻²⁵ kg·m/s. 실험의 k₀ = 5.0 nm⁻¹ 기록에서도 ⟨p⟩ = 5.000 ħ/nm, σₚ는 3.162 ħ/nm 그대로였다. 위상의 기울기가 평균 운동량이다. ⟨p⟩ = ħk₀ ≈ 5.27×10⁻²⁵ kg·m/s
