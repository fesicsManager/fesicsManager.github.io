대학 양자역학 · 웹툰 10화 「교환하지 않는 것들」

에렌페스트 정리 — d⟨p⟩/dt는 ⟨F(x)⟩이지 F(⟨x⟩)가 아니다

가우스 파속(중심 μ, 폭 σ)을 자유·균일장·조화·4차 퍼텐셜에 놓고 힘의 평균 ⟨F⟩와 평균 위치에서의 힘 F(⟨x⟩)를 수치 적분으로 비교했습니다. 조화 퍼텐셜에서는 둘이 정확히 같았지만, 4차 퍼텐셜(μ = 1.00, σ = 0.50)에서는 ⟨F⟩ = −1.75로 F(⟨x⟩) = −1.00과 75 % 달랐습니다. 일반화된 불확정성 원리, 기댓값의 시간 변화식과 에렌페스트 정리, 고전 극한의 조건을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 퍼텐셜(자유 · 균일장 V = x · 조화 V = ½x² · 4차 V = ¼x⁴), 파속 중심 μ(0.50 · 1.00 · 1.50), 파속 폭 σₓ(0 ~ 1 슬라이더)를 고르고 힘 평균 내기를 누르면 ⟨F⟩, F(⟨x⟩)와 차이가 기록됩니다(무차원 단위). 4차 퍼텐셜, μ = 1.00으로 σ를 0, 0.25, 0.5, 0.75, 1.0으로 바꿔 기록하고 조화 퍼텐셜과도 비교하세요. 기록이 4개 이상이면 데이터 검증 탭에서 −⟨F⟩ − μ³ 대 σ² 직선(기울기 3μ)과 퍼텐셜별 비교표를 볼 수 있습니다.

표 1. 힘의 평균과 평균 위치에서의 힘 (실험 예시, 무차원 단위 λ = k = 1)

4차 퍼텐셜에서 차이 ⟨F⟩ − F(⟨x⟩)는 σ = 0, 0.25, 0.5, 1.0일 때 0, −0.1875, −0.75, −3.0으로 정확히 −3μσ²였습니다. ⟨x³⟩ = μ³ + 3μσ²이기 때문에 파속의 퍼짐이 보정항을 만들어 중심이 고전 궤적을 따르지 않아요. μ = 1.50에서는 −3 × 1.5 × 0.25 = −1.125로 보정이 더 컸습니다. 조화 퍼텐셜은 σ와 관계없이 차이가 0이었어요. 힘이 x의 1차 이하일 때만 ⟨F⟩ = F(⟨x⟩)가 정확히 성립하고, σ → 0이면 고전 극한이 회복됩니다.

개념 정리

1. 일반화된 불확정성과 시간 변화

σ_Aσ_B ≥ |⟨[Â, B̂]⟩ / 2i|, d⟨Q⟩/dt = (i/ħ)⟨[Ĥ, Q̂]⟩ + ⟨∂Q̂/∂t⟩

[x̂, p̂] = iħ를 넣으면 σₓσₚ ≥ ħ/2. 교환하는 연산자는 동시 고유상태를 가질 수 있고, 교환하지 않으면 불확정성이 생깁니다. Q̂ = x̂, p̂를 넣으면 에렌페스트 정리:

d⟨x⟩/dt = ⟨p⟩/m, d⟨p⟩/dt = ⟨−∂V/∂x⟩ = ⟨F(x)⟩

2. 보존량과 에너지-시간

[Ĥ, Q̂] = 0이면 ⟨Q⟩ 보존(뇌터 정리의 양자판). Δt·ΔE ≥ ħ/2에서 Δt는 "관측량이 눈에 띄게 변하는 시간"입니다. 수소 2p 수명 1.596 ns → ΔE ≈ ħ/τ = 4.12×10⁻⁷ eV, 자연 선폭 99.7 MHz.

3. 4차 퍼텐셜 V = (λ/4)x⁴

  • x = μ + u, u ~ N(0, σ²): ⟨x³⟩ = μ³ + 3μσ²
  • μ = 1.00, σ = 0.50: ⟨x³⟩ = 1 + 0.75 = 1.75 → d⟨p⟩/dt = −1.75λ (F(⟨x⟩) = −1.00λ와 75 % 차이)
  • 힘이 x의 1차 이하(자유·균일장·조화)일 때만 ⟨F⟩ = F(⟨x⟩)가 정확히 성립 — 결맞음 상태가 고전 궤적을 정확히 따르는 이유

4. 실험 모형과 실제의 차이

· 한 순간의 ⟨F⟩만 비교합니다. 시간이 흐르면 비조화 퍼텐셜 속 파속은 모양도 바뀌어요.

· 고전 극한은 σ가 힘이 변하는 길이 척도보다 훨씬 작을 때 근사적으로 회복됩니다(σ → 0을 넣어 보세요).

d⟨Q⟩/dt = (i/ħ)⟨[Ĥ, Q̂]⟩ + ⟨∂Q̂/∂t⟩ → d⟨x⟩/dt = ⟨p⟩/m, d⟨p⟩/dt = ⟨−∂V/∂x⟩ · σ_Aσ_B ≥ |⟨[Â, B̂]⟩/2i| · V = (λ/4)x⁴: ⟨x³⟩ = μ³ + 3μσ²
제로

“식을 정확히 쓰면 d⟨p⟩/dt = ⟨F(x)⟩이야. 힘의 평균이지, 평균 위치에서의 힘이 아니고.”

웹툰 10화 #4 · 비선형 힘의 평균 검증

예제

[x̂, p̂²]를 계산하고, 이를 이용해 자유 입자에서 d⟨x²⟩/dt를 구하시오.

[x̂, p̂²] = p̂[x̂, p̂] + [x̂, p̂]p̂ = 2iħp̂. 자유 입자 Ĥ = p̂²/2m에서 [x̂², p̂²] = x̂[x̂, p̂²] + [x̂, p̂²]x̂ = 2iħ(x̂p̂ + p̂x̂)이므로 [Ĥ, x̂²] = −(iħ/m)(x̂p̂ + p̂x̂). 따라서 d⟨x²⟩/dt = (i/ħ)⟨[Ĥ, x̂²]⟩ = (1/m)⟨x̂p̂ + p̂x̂⟩. 6화에서 파속이 퍼지는 속도가 이 위치–운동량 상관에서 나온다. [x̂, p̂²] = 2iħp̂, d⟨x²⟩/dt = ⟨x̂p̂ + p̂x̂⟩/m

수소 2p 상태의 수명이 τ = 1.596 ns이다. 에너지–시간 관계로 자연 선폭 ΔE와 진동수 폭을 구하시오(ħ = 6.582×10⁻¹⁶ eV·s).

ΔE ≈ ħ/τ = 6.582×10⁻¹⁶ eV·s / 1.596×10⁻⁹ s = 4.12×10⁻⁷ eV. 진동수 폭 Δν = 1/(2πτ) = 1/(2π × 1.596×10⁻⁹ s) = 9.97×10⁷ Hz ≈ 99.7 MHz. 시간은 연산자가 아닌 매개변수라, 여기서 Δt는 ‘관측량이 눈에 띄게 변하는 시간’(수명)으로 읽는다. ΔE ≈ 4.12×10⁻⁷ eV, 약 99.7 MHz
