대학 양자역학 · 웹툰 16화 「미리 정해진 답은 없었다」

CHSH 벨 검정 — 미리 정해진 답안지로는 |S| > 2를 만들 수 없다

스핀 단일항 쌍을 앨리스와 밥에게 보내 축 간격 θ(a = 0, b = θ, a′ = 2θ, b′ = 3θ)로 재고, 양자역학과 뭉치의 답안지 모형(국소 숨은 변수)을 같은 방법으로 시뮬레이션해 CHSH 값 S를 기록했습니다. θ = 45°에서 양자역학은 S = −2.857(이론 −2√2 = −2.828)로 |S| ≤ 2를 넘었고, 답안지 모형은 −2.021(이론 −2)에 머물렀습니다. 얽힘과 상관 함수 E(a, b) = −cos θ_ab, CHSH 부등식, 실험이 배제한 것과 남은 해석 문제를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 축 간격 θ(0 ~ 90° 슬라이더), 모형(양자역학 단일항 또는 답안지 모형), 설정마다 측정하는 쌍의 수(100 · 1000 · 10000쌍)를 고르고 쌍 측정하기를 누르면 측정한 S와 이론 S가 기록됩니다. θ = 45°에서 두 모형을 비교하고, θ = 0°, 15°, 30°, 60°, 90°도 기록해 보세요. 기록이 4개 이상이면 데이터 검증 탭에서 상관 E 대 cos(축 사이 각) 그래프와 θ별 |S| 표를 볼 수 있습니다. 측정 문제의 해석은 채점하지 않습니다.

θ = 45°에서 양자역학의 S는 −2.857(이론 −2√2 = −2.828)로 국소 숨은 변수 한계 |S| ≤ 2를 넘었고, 답안지 모형은 −2.021(통계적 흔들림 안에서 −2)에 머물렀습니다. 답안지 모형의 상관은 각도에 직선으로 비례(−(1 − 2θ_ab/π))해 θ = 30°에서도 −2였지만, 양자역학의 E = −cos θ_ab는 θ = 30°에서 −2.598, 60°에서 −2.500으로 2를 넘었어요. 앨리스가 어느 축을 고르든 밥 혼자 본 + 비율은 약 0.5라 얽힘으로 신호를 보낼 수는 없습니다. 벨 실험이 배제하는 것은 ‘국소적이고 결과가 미리 정해진’ 숨은 변수 이론이며, 그다음 무엇을 버릴지는 해석마다 다르고 합의는 없습니다.

개념 정리

1. 얽힘과 CHSH 부등식

단일항 |Ψ⁻⟩ = (|↑↓⟩ − |↓↑⟩)/√2는 |φ⟩_A ⊗ |χ⟩_B 꼴로 쓸 수 없습니다(얽힘). 두 결과 곱의 기댓값은

E(a, b) = ⟨Ψ⁻|(σ_A·a)(σ_B·b)|Ψ⁻⟩ = −a·b = −cos θ_ab

결과가 각자 자기 축과 숨은 변수 λ에만 의존(국소성)하고 미리 정해져 있다면

S = E(a,b) − E(a,b′) + E(a′,b) + E(a′,b′), |S| ≤ 2

각 λ에서 A(B − B′) + A′(B + B′) = ±2이기 때문입니다(CHSH, 1969).

2. 신호 불가

밥 혼자 보는 결과는 앨리스가 무슨 축을 고르든 항상 50:50입니다. 상관은 두 기록을 고전 통신으로 맞춰 볼 때만 드러나요.

3. 해석은 열려 있다

벨 실험이 배제한 것은 "국소적이고 결과가 미리 정해진" 숨은 변수 이론입니다. 코펜하겐 계열·다세계·드브로이-봄·객관적 붕괴·큐비즘 등은 무엇을 버릴지 다르게 답하며, 물리학계의 합의는 없습니다.

4. a = 0°, a′ = 90°, b = 45°, b′ = 135°

  • E = −0.7071, +0.7071, −0.7071, −0.7071 → S = −2.8284, |S| = 2√2 > 2 (치렐슨 한계)
  • 뭉치의 답안지 모형(A = sgn cos(a − λ), B = −sgn cos(b − λ))은 E가 각도에 직선으로 비례해 같은 설정에서 |S| = 2
  • 1982년 아스페 등, 2015년 델프트·빈·NIST 그룹이 허점을 막은 실험으로 위반을 확인 — 2022년 노벨 물리학상(아스페, 클라우저, 차일링거)

a = 0, b = θ, a′ = 2θ, b′ = 3θ로 두면 S = 3E(θ) − E(3θ)입니다(θ = 45°가 표 4번 설정). 답안지 모형은 상관이 각도에 직선이라 어떤 θ에서도 |S| ≤ 2를 넘지 못하지만, 양자역학의 −cos θ는 곡선이라 θ = 45°에서 2√2까지 올라가요. 노란 선은 모의 측정값입니다. 밥 혼자 보면 언제나 반반이라 얽힘으로 신호를 보낼 수는 없어요.

5. 실험 모형과 실제의 차이

· 실제 실험은 검출 효율·측정 축 선택의 독립성·빛보다 빠른 축 교체 같은 허점을 막아야 합니다. 여기서는 이상적인 검출을 가정했어요.

· 답안지 모형은 대표적인 국소 숨은 변수 모형 하나입니다. 어떤 국소 모형도 |S| ≤ 2를 넘지 못한다는 것이 부등식의 내용이에요.

E(a, b) = ⟨Ψ⁻|(σ_A·a)(σ_B·b)|Ψ⁻⟩ = −cos θ_ab · S = E(a,b) − E(a,b′) + E(a′,b) + E(a′,b′), 국소 숨은 변수: |S| ≤ 2 · a = 0°, a′ = 90°, b = 45°, b′ = 135°: |S| = 2√2 ≈ 2.828

예제

스핀 단일항에서 앨리스는 z축, 밥은 z축에서 60° 기운 축으로 잰다. 두 결과가 같을 확률을 구하시오.

E = −cos 60° = −0.5. 같을 확률 P₌, 다를 확률 P≠에서 E = P₌ − P≠, P₌ + P≠ = 1 → P₌ = (1 + E)/2 = 0.25. 직접 계산: 앨리스가 +를 얻으면 밥 쪽은 −z 상태가 되고, 60° 축으로 +가 나올 확률은 sin²(60°/2) = 0.25로 일치한다. 밥 혼자 보면 여전히 +, −가 반반이다. 0.25

a = 0°, a′ = 90°, b = 45°, b′ = 135°에서 양자역학의 S를 구하고, 각 λ에서 A(B − B′) + A′(B + B′) = ±2임을 이용해 국소 숨은 변수 이론의 한계와 비교하시오.

E(a,b) = −cos 45° = −0.7071, E(a,b′) = −cos 135° = +0.7071, E(a′,b) = −cos 45° = −0.7071, E(a′,b′) = −cos 45° = −0.7071. S = −0.7071 − 0.7071 − 0.7071 − 0.7071 = −2.828, |S| = 2√2. 결과가 ±1로 미리 정해져 있으면 B − B′와 B + B′ 중 하나는 0, 다른 하나는 ±2라 각 λ에서 ±2이고, 평균하면 |S| ≤ 2다. 2√2는 양자역학이 허용하는 최대값(치렐슨 한계)이다. |S| = 2√2 ≈ 2.83 > 2
