에너지 고유상태 전개 — 측정 확률은 |cₙ|²

무한 우물 속 상태(포물선, 삼각형, (ψ₁+2ψ₃)/√5, 치우친 x²(a−x))를 고유함수 ψₙ = √(2/a)sin(nπx/a)로 전개해 cₙ을 구하고, 부분합 항 수 N을 바꿔 확률 합과 ⟨H⟩를 기록했습니다. 포물선의 |c₁|²은 0.99856으로 100 %가 아니었고 짝수 n 계수는 0이었으며, ⟨H⟩ = 1.0132E₁은 E₁보다 컸습니다. 일반화된 통계적 해석, 직교성·완비성, 변분 원리를 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 상자 속 상태(자동 규격화)와 부분합에 쓸 항 수 N(1 · 3 · 5 · 9 · 25)을 고르고 전개 계수 구하기를 누르면 |c₁|², 처음 N항의 확률 합, ⟨H⟩/E₁, log|cₙ|²–log n 기울기가 기록됩니다. 포물선으로 N = 1, 3, 9를 기록하고, 삼각형과 (ψ₁+2ψ₃)/√5도 한 번씩 기록하세요. 기록이 4개 이상이면 데이터 검증 탭에서 log|cₙ|² 대 log n 그래프와 상태별 에너지 측정 예측표를 볼 수 있습니다.

포물선은 |c₁|² = 0.99856, |c₃|² = 0.00137, |c₅|² = 6.39×10⁻⁵이고 짝수 n은 0입니다. 상태가 x = a/2에 대칭인데 짝수 n 고유함수는 반대칭이라 대칭성만으로 절반의 계수가 사라집니다. N을 1 → 9로 늘리면 확률 합이 0.998555 → 0.999999로 1에 다가가 완비성을 보여 줘요. ⟨H⟩는 포물선 1.0132E₁, 삼각형 1.2159E₁, x²(a−x) 1.4185E₁로 모두 E₁보다 커서 어떤 시험 함수의 ⟨H⟩도 바닥 에너지의 상한(변분 원리)이 됩니다. 계수가 줄어드는 기울기는 매끄러운 포물선 −6, 가운데가 꺾인 삼각형 −4였어요.

개념 정리

1. 일반화된 통계적 해석

Eₙ = n²π²ħ²/(2ma²), ψ = Σ cₙψₙ, cₙ = ∫₀ᵃ ψₙ*ψ dx, P(Eₙ) = |cₙ|²

에너지 측정값은 반드시 Eₙ 중 하나이고, 그 확률이 |cₙ|²입니다. 직교성(∫ψₘψₙ = δₘₙ)과 완비성이 이 전개를 보장해요.

2. 계수가 줄어드는 빠르기

log|cₙ|²를 log n에 대해 그리면 직선이 됩니다. 매끄러운 포물선은 기울기 −6, 꺾인 점이 있는 삼각형은 −4 — 모서리가 날카로울수록 높은 에너지 성분이 많이 섞여요.

N을 늘리면 보라색 합이 회색 원래 상태에 겹쳐 가고 확률 합이 1에 다가갑니다(완비성). 오른쪽에서 포물선의 점은 기울기 −6 직선, 꺾인 점이 있는 삼각형은 −4 직선을 따라 줄어요. 대칭인 상태는 짝수 n이 모두 0(빈 점)입니다. ⟨H⟩/E₁은 어떤 시험 함수든 1보다 큽니다(변분 원리).

3. 양자 부활

모든 Eₙ이 E₁의 정수배(n²)이므로 t = h/E₁마다 Ψ가 처음 모양으로 정확히 돌아옵니다. a = 1.00 nm 전자는 E₁ = 0.376 eV, h/E₁ = 11.0 fs.

4. 포물선 상태 √(30/a⁵)·x(a−x)

  • n 홀수: cₙ = 8√15/(nπ)³, n 짝수: 0 (상태는 x = a/2에 대칭, 짝수 n 고유함수는 반대칭)
  • |c₁|² = 960/π⁶ = 0.99856, |c₃|² = 0.00137, |c₅|² = 6.39×10⁻⁵
  • ⟨H⟩ = (ħ²/2m)∫|ψ′|² = 10E₁/π² = 1.0132E₁ — 변분 원리: 어떤 시험 함수도 E₁보다 작을 수 없음

5. 실험 모형과 실제의 차이

· 실제 양자점은 유효 질량·유한 장벽·3차원 구조 때문에 이 수치와 다릅니다. 무한 우물은 가둠 에너지의 크기 감각을 주는 모형이에요.

· cₙ은 심프슨 적분(1000칸), ⟨H⟩는 수치 미분 후 중점 적분으로 계산합니다.

Eₙ = n²π²ħ²/(2ma²), ψ = Σcₙψₙ, cₙ = ∫₀ᵃ ψₙ*ψ dx, P(Eₙ) = |cₙ|² · 포물선: cₙ = 8√15/(nπ)³ (n 홀수), |c₁|² = 960/π⁶ = 0.99856, ⟨H⟩ = 10E₁/π² = 1.0132E₁

예제

무한 우물에서 Ψ(x,0) = (ψ₁ + 2ψ₃)/√5일 때 에너지 측정 가능한 값과 확률, ⟨H⟩를 E₁ 단위로 구하시오.

규격화: (1 + 4)/5 = 1. 측정값은 E₁(확률 1/5 = 0.2)과 E₃ = 9E₁(확률 4/5 = 0.8)뿐이다. ⟨H⟩ = 0.2 × E₁ + 0.8 × 9E₁ = 7.4E₁. 실험 기록도 |c₁|² = 0.20000, ⟨H⟩ = 7.4000E₁이었다. 7.4E₁은 기댓값일 뿐 한 번의 측정에서는 절대 나오지 않는다. E₁(20 %), 9E₁(80 %), ⟨H⟩ = 7.4E₁

포물선 상태 √(30/a⁵)·x(a−x)의 c₁을 구하고, |c₁|²과 ⟨H⟩/E₁을 계산하시오.

∫₀ᵃ x(a−x)sin(πx/a)dx = 4a³/π³이므로 c₁ = √(2/a)·√(30/a⁵)·4a³/π³ = 8√15/π³, |c₁|² = 960/π⁶ = 0.99856. ⟨H⟩ = (ħ²/2m)∫|ψ′|²dx = (ħ²/2m)(10/a²) = (10/π²)E₁ = 1.0132E₁로 E₁보다 1.3 % 크다(변분 원리). |c₁|² ≈ 0.9986, ⟨H⟩ ≈ 1.013E₁
