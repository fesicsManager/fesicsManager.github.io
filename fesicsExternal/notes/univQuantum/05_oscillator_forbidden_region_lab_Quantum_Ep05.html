조화 진동자와 고전 금지 영역 — 바닥 상태의 15.7 %는 전환점 밖에

사다리 연산자 점화식으로 만든 조화 진동자 준위 ψₙ(n = 0 ~ 5)에서 위치를 500 · 5000번 측정해, 고전 전환점 |ξ| = √(2n+1) 바깥에서 발견되는 빈도를 셌습니다. 바닥 상태의 금지 영역 확률은 erfc(1) = 0.1573이었고 n이 커질수록 0.112, 0.095, 0.085로 줄었으며, σₓσₚ는 (n + ½)ħ였습니다. 사다리 연산자로 얻는 Eₙ = (n + ½)ħω, 영점 에너지, 금지 영역 확률을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 준위 n(0 ~ 5), 위치 측정 횟수(500 · 5000회), 눈금(무차원 ξ = x/x₀ 또는 HCl 분자 pm)을 고르고 위치 측정하기를 누르면 전환점 ξₜ, 금지 영역 확률(적분)과 측정 빈도, σₓσₚ/ħ가 기록됩니다. n = 0, 1, 2, 3을 차례로 기록해 보세요. 기록이 4개 이상이면 데이터 검증 탭에서 준위별 금지 영역 확률 그래프와 기록 요약표를 볼 수 있습니다.

바닥 상태(n = 0)에서 전환점 |x| = x₀ 바깥의 확률은 0.1573으로, 뭉치가 말한 0이 아니라 여섯 번 중 한 번꼴입니다. 측정 빈도는 500회 0.1360, 5000회 0.1532로 적분값 근처에 흩어졌어요. n이 커질수록 0.1116, 0.0951, 0.0855, (n = 5) 0.0740으로 줄어 고전 극한에 다가가지만 0이 되지는 않습니다. σₓσₚ/ħ = n + ½(0.5, 1.5, 2.5, 3.5, 5.5)로 바닥 상태만 하한 ħ/2를 채웠어요.

개념 정리

1. 사다리 연산자

â± = (∓ip̂ + mωx̂)/√(2ħmω), [â₋, â₊] = 1, Ĥ = ħω(â₊â₋ + ½)

â₋ψ₀ = 0이라는 1차 미분방정식 하나에서 ψ₀ = (mω/πħ)^¼ e^(−mωx²/2ħ), E₀ = ½ħω가 나오고, â₊를 반복해 Eₙ = (n + ½)ħω를 얻습니다. 실험 안에서는 같은 관계를 점화식 ψₙ₊₁ = √(2/(n+1)) ξψₙ − √(n/(n+1)) ψₙ₋₁ (ξ = x/x₀)로 계산해요.

2. 실제 분자 — HCl

진동 파수 2886 cm⁻¹ → ħω = hcν̃ = 0.358 eV, 환산 질량 μ = 1.627×10⁻²⁷ kg, k = μω² = 481 N/m, x₀ = 10.9 pm, 바닥 상태 σₓ = x₀/√2 = 7.72 pm. 결합 길이 127 pm에 비하면 작지만, 절대영도에서도 분자는 멈추지 않습니다(영점 에너지).

3. 비리얼 정리와 불확정성

모든 정상상태에서 ⟨V⟩ = ½⟨H⟩, σₓσₚ = (n + ½)ħ입니다.

4. 고전 금지 영역의 확률

  • 전환점: ½mω²xₜ² = (n + ½)ħω → ξₜ = √(2n+1), x₀ = √(ħ/mω)
  • n = 0: P(|ξ| > 1) = erfc(1) = 0.1573
  • n = 0, 1, 2, 3 → 0.157, 0.112, 0.095, 0.085 — 준위가 높을수록 고전 극한에 다가감

5. 실험 모형과 실제의 차이

· 실제 분자 퍼텐셜은 비조화적이라 높은 준위로 갈수록 간격이 좁아지고 결국 해리됩니다. 조화 근사는 바닥 근처에서만 좋아요.

· 정상상태는 ⟨x⟩ = 0으로 고정입니다. 고전적으로 흔들리는 상태는 결맞음 상태(â₋의 고유상태)예요.

â± = (∓ip̂ + mωx̂)/√(2ħmω), [â₋, â₊] = 1, Ĥ = ħω(â₊â₋ + ½), Eₙ = (n + ½)ħω · ψ₀ = (mω/πħ)^¼ e^(−mωx²/2ħ), P(|x| > x₀) = erfc(1) = 0.1573 (x₀ = √(ħ/mω))

예제

HCl 분자의 진동 파수는 2886 cm⁻¹, 환산 질량은 μ = 1.627×10⁻²⁷ kg이다. ħω, 용수철 상수 k, 바닥 상태 σₓ를 구하시오.

ħω = hcν̃ = 1.2398×10⁻⁶ eV·m × 2.886×10⁵ m⁻¹ = 0.358 eV, ω = 0.358 × 1.602×10⁻¹⁹ J / 1.0546×10⁻³⁴ J·s = 5.44×10¹⁴ s⁻¹. k = μω² = 1.627×10⁻²⁷ × (5.44×10¹⁴)² = 481 N/m. x₀ = √(ħ/μω) = 1.09×10⁻¹¹ m = 10.9 pm, σₓ = x₀/√2 = 7.72 pm. 결합 길이 127 pm에 비해 작지만 절대영도에서도 0이 아니다(영점 에너지 ½ħω = 0.179 eV). ħω ≈ 0.358 eV, k ≈ 481 N/m, σₓ ≈ 7.7 pm

상태 ψ₁에서 ⟨x²⟩, ⟨p²⟩를 사다리 연산자로 구하고 σₓσₚ를 계산하시오.

x̂ = √(ħ/2mω)(â₊ + â₋)이므로 x̂² = (ħ/2mω)(â₊² + â₊â₋ + â₋â₊ + â₋²). ψ₁에서 â₊â₋ → 1, â₋â₊ → 2, 제곱 항은 직교라 0 → ⟨x²⟩ = 3ħ/(2mω). 같은 방법으로 ⟨p²⟩ = 3mħω/2. ⟨x⟩ = ⟨p⟩ = 0이므로 σₓσₚ = √(9ħ²/4) = 1.5ħ. 일반식은 (n + ½)ħ이고 실험의 n = 1 기록도 1.500이었다. ⟨x²⟩ = 3ħ/(2mω), ⟨p²⟩ = 3mħω/2, σₓσₚ = 3ħ/2
