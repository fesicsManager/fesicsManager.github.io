대학 양자역학 · 웹툰 7화 「붙잡히는 상태, 튕겨 나가는 상태」

유한 우물과 델타 우물 — 속박 상태의 개수는 z₀가 정한다

폭 2a, 깊이 V₀ 유한 우물에 전자를 넣고 경계 조건에서 나온 초월방정식을 수치로 풀어 속박 상태를 세었습니다. 폭 1.00 nm에서 깊이 0.100 · 1.00 · 5.00 eV는 각각 1 · 2 · 4개였고, 같은 넓이 α = 0.500 eV·nm의 델타 우물은 속박 상태 1개(E_b = −1.64 eV)와 반사율 R = 1/(1 + E/|E_b|)를 보였습니다. 속박과 산란, 짝·홀 초월방정식, 우물에서의 반사를 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 모형(유한 우물 또는 델타 우물 α = 2aV₀), 깊이 V₀(0.100 · 1.00 · 5.00 · 20.0 eV), 폭 2a(0.50 · 1.00 · 2.00 nm), 입사 에너지 E/|E_b|(0.1 · 1 · 10, 델타 우물에서만)를 고르고 준위 구하기를 누르면 z₀와 준위 수(또는 R), 바닥 준위(또는 E_b)가 기록됩니다. 폭 1.00 nm로 깊이 0.100·1.00·5.00 eV를 기록하고, 델타 우물로 E/|E_b| = 0.1·1·10을 기록하세요. 기록이 4개 이상이면 데이터 검증 탭에서 준위 수 대 2z₀/π 계단 그래프와 1/R − 1 대 E/|E_b| 직선을 볼 수 있습니다.

폭 1.00 nm에서 깊이를 0.100 → 1.00 → 5.00 eV로 바꾸면 z₀ = 0.810 → 2.562 → 5.728이고 속박 상태는 1 → 2 → 4개로, N = ⌈2z₀/π⌉와 같았습니다. 무한 우물과 달리 개수가 유한하고, 얕을수록 준위가 바닥 쪽으로 눌려요(1.00 eV 우물의 1번 준위는 바닥 기준 0.191 eV, 무한 우물은 0.376 eV). 아무리 얕아도 짝 상태 하나는 남습니다. 델타 우물(α = 0.500 eV·nm)은 속박 상태가 E_b = −1.640 eV 하나뿐이고, 입사 전자의 반사율은 E/|E_b| = 0.1 · 1 · 10에서 0.909 · 0.500 · 0.091이었어요. 고전 입자는 우물을 무조건 통과하지만 파동은 우물에서도 반사됩니다.

개념 정리

1. 속박과 산란

V(±∞) = 0일 때 E < 0이면 무한대에서 e^(−κ|x|)로 감쇠하는 속박 상태(에너지 불연속), E > 0이면 e^(±ikx)로 진동하는 산란 상태(에너지 연속)입니다.

2. 델타 우물 V = −αδ(x)

κ = mα/ħ², E_b = −mα²/(2ħ²) (속박 상태 단 1개), R = 1/(1 + E/|E_b|)

α = 0.500 eV·nm: κ = 6.56 nm⁻¹, E_b = −1.64 eV, E/|E_b| = 0.1·1·10 → R = 0.909·0.500·0.091. 고전 입자는 우물을 무조건 통과하지만, 파동은 우물에서도 반사돼요.

3. 유한 우물 (V = −V₀, |x| < a)

z = a√(2m(E+V₀))/ħ, z₀ = a√(2mV₀)/ħ로 두면

짝: tan z = √((z₀/z)² − 1), 홀: −cot z = √((z₀/z)² − 1), 속박 상태 수 N = ⌈2z₀/π⌉

  • V₀ = 1.00 eV, 2a = 1.00 nm: z₀ = 2.562, N = 2 — 짝 z = 1.119 (E = −0.809 eV), 홀 z = 2.147 (E = −0.297 eV)
  • V₀ = 5.00 eV는 4개(바닥 기준 0.272·1.077 eV …), V₀ = 0.100 eV는 1개(0.064 eV)
  • 1차원에서는 아무리 얕아도 짝 상태가 최소 하나 있습니다.
  • 바닥 상태 꼬리 길이 1/κ: V₀ = 1.00 eV에서 κ = 4.61 nm⁻¹, 1/κ = 0.217 nm — 생각보다 많이 샘

4. 실험 모형과 실제의 차이

· 짝·홀 방정식은 z·sin z = w·cos z, z·cos z + w·sin z = 0 (w = √(z₀² − z²)) 꼴로 바꿔 부호 변화를 찾고 이분법으로 풉니다.

· 3차원 얕은 구형 우물에는 속박 상태가 없을 수 있습니다. "항상 하나"는 1차원의 결과예요.

z₀ = a√(2mV₀)/ħ, 짝: tan z = √((z₀/z)² − 1), 홀: −cot z = √((z₀/z)² − 1), N = ⌈2z₀/π⌉ · 델타 V = −αδ(x): κ = mα/ħ², E_b = −mα²/(2ħ²), R = 1/(1 + E/|E_b|)

예제

깊이 V₀ = 1.00 eV, 폭 2a = 2.00 nm 유한 우물에 갇힌 전자의 z₀와 속박 상태 수를 구하시오(ħ²/2mₑ = 0.0381 eV·nm²).

a = 1.00 nm이므로 z₀ = a√(V₀/(ħ²/2m)) = 1.00 × √(1.00/0.0381) = 5.12. N = ⌈2z₀/π⌉ = ⌈3.26⌉ = 4. 실험에서도 이 우물은 짝·홀 준위 4개(바닥 −0.934 eV)였다. 폭 1.00 nm(z₀ = 2.56, 2개)와 비교하면 깊이가 같아도 폭이 2배면 z₀도 2배다. 개수를 정하는 것은 깊이와 폭의 조합 z₀ ∝ a√V₀이다. z₀ ≈ 5.12, 속박 상태 4개

α = 0.500 eV·nm 델타 우물에 대해 κ, 속박 에너지 E_b, 그리고 |x| > 1/κ에서 입자를 발견할 확률을 구하시오(ħ²/2mₑ = 0.0381 eV·nm²).

κ = mα/ħ² = α/(2 × 0.0381 eV·nm²) = 6.56 nm⁻¹(1/κ = 0.152 nm), E_b = −mα²/(2ħ²) = −α²/(4 × 0.0381) = −1.64 eV. ψ = √κ e^(−κ|x|)이므로 P(|x| > 1/κ) = 2κ∫_(1/κ)^∞ e^(−2κx)dx = e⁻² = 0.135. E < 0이라 x ≠ 0은 전부 고전 금지 영역인데도 13.5 %가 이 꼬리 바깥에 있다. κ ≈ 6.56 nm⁻¹, E_b ≈ −1.64 eV, 약 13.5 %
