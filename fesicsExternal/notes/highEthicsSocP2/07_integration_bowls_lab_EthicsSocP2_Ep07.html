고등 현대사회와 윤리 ② · 웹툰 7화 「함께 살려면 같아져야 하나」

다문화 사회의 통합 모델 — 공통 기반 위에 다름을 얼마나 남기는가

같은 가상 학교에서 급식·언어 교육·반 편성 정책 카드만 바꾸며 소수 문화가 유지되는 정도, 공통 기반(한국어·법·인권), 가까운 통합 모델을 기록했습니다. 급식과 언어 카드의 단계를 올리면 유지 정도가 낮음 → 중간 → 높음으로 오르며 용광로 → 국수 대접 → 샐러드 볼에 가까워졌고, 세 모델 모두 공통 기반은 유지되었습니다. 반을 출신별로 나누면 유지 정도는 높아도 공통 기반이 약해져 어느 통합 모델도 아닌 분리가 되었습니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 급식(기존 메뉴만·대체 메뉴 추가·여러 나라 메뉴 순환), 언어 교육(한국어 몰입만·문화 행사 연 1회·모어 유지 지원), 반 편성(함께·출신별로 나눔) 카드를 고르고 이 정책으로 운영하기를 누르면 네 그릇 가운데 가장 가까운 모델이 밝아지고, 기록표에 급식·언어·반·유지·공통 기반·가까운 모델이 쌓입니다. 기록이 4개 이상이면 결과 비교 탭에서 정책 조합별 모델과 모델별 기록 수를 볼 수 있어요. 반은 ‘함께 편성’으로 두고 급식과 언어 카드를 같은 단계로 맞춰 세 번 바꾼 뒤, 반을 나눠 보세요. 제로 랩의 가상 사례를 옮긴 단순 모형이며 어느 모델이 옳은지는 채점하지 않습니다.

표 1. 정책 카드 조합별 가까운 모델 (실험 예시 — 단순 모형)

대체 메뉴모어 지원함께높음유지샐러드 볼 (다문화)
기존만몰입만분리높음약해짐분리 (통합 모델 아님)

반을 ‘함께 편성’으로 둔 다섯 줄은 모두 공통 기반이 ‘유지’였습니다. 세 통합 모델의 차이는 공통 기반이 아니라 그 위에 다름을 얼마나 남기느냐예요. 급식(0~2)과 언어(0~2) 점수의 합이 1 이하이면 용광로, 2이면 국수 대접, 3 이상이면 샐러드 볼에 가깝게 나왔습니다. 마지막 줄처럼 출신별로 반을 나누면 다름은 많이 남지만 공통 기반이 약해져 다름을 지키는 것과 떼어 놓는 것은 다르다는 점이 드러나요. 또 어느 모델이든 인권을 침해하는 관습까지 존중하지는 않는다는 선은 공통입니다.

개념 정리

1. '같음'과 '다름'을 어디에 두는가

  • 용광로(동화주의): 여러 문화가 녹아 주류 문화 하나로 합쳐진다.
  • 샐러드 볼(다문화주의): 각 재료가 제 맛을 유지하면서 한 그릇을 이룬다.
  • 국수 대접: 주류 문화가 국수와 국물처럼 바탕을 이루고, 다른 문화는 고명처럼 얹혀 맛을 더한다.

세 모델 모두 공통 기반을 유지합니다. 차이는 그 위에 다름을 얼마나 남기느냐예요. 출신별로 따로 떼어 놓는 것은 다름은 남지만 어느 통합 모델도 아닌 분리입니다.

유지 점수 공통 기반 가까운 모델

반을 '함께 편성'으로 두면 그릇(공통 기반)은 그대로이고, 그 위에 다름이 얼마나 남는지만 바뀝니다. 반을 나누면 다름은 남아도 그릇이 갈라져 어느 통합 모델도 아닌 '분리'가 돼요. 유지 점수 = 급식(0~2) + 언어(0~2)인 단순 모형입니다.

2. 각 모델의 논거

  • 동화주의: 공통의 언어와 문화가 있어야 소통 비용이 줄고 소속감이 생긴다.
  • 다문화주의: 정체성을 버리게 하는 것이 그 자체로 불평등이며, 다양성이 사회를 풍부하게 한다.
  • 국수 대접: 그 사이에서 현실적 균형을 찾으려 한다.

3. 모든 모델에 공통인 선

관습의 차이는 존중하되, 인권을 침해하는 관습까지 존중 대상이 되지는 않습니다. 정책마다 모델이 다를 수도 있어요. 언어는 공통을, 음식과 명절은 다양성을 넓게 두는 식으로.

4. 실험 모형과 실제의 차이

· 유지 정도는 급식(0~2)과 언어 교육(0~2)을 더한 단순 점수입니다. 실제 정책 효과는 학생·지역·운영 방식에 따라 다릅니다.

· 우리나라에 사는 외국인은 이미 200만 명을 넘었습니다. 다문화 정책은 이미 현실의 선택이에요.

유지 점수 = 급식 단계(0~2) + 언어 단계(0~2) → 1 이하 용광로 · 2 국수 대접 · 3 이상 샐러드 볼 · 반을 나누면 분리(공통 기반 약해짐)

단계: 급식 기존만 0 · 대체 메뉴 1 · 순환+대체 2 / 언어 몰입만 0 · 행사 연 1회 1 · 모어 지원 2 (단순 모형)

예제

급식 ‘여러 나라 메뉴 순환 + 대체 메뉴’, 언어 ‘한국어 몰입 교육만’, 반 ‘함께 편성’이면 유지 점수와 가까운 모델은?

2 + 0 = 2이므로 유지 ‘중간’, 국수 대접에 가깝습니다. 공통 기반은 유지돼요.

급식과 언어를 모두 가장 높은 단계(2 + 2)로 두고 반만 ‘출신별로 나눔’으로 바꾸면 무엇이 달라지나요?

유지는 ‘높음’으로 같지만 공통 기반이 ‘유지’ → ‘약해짐’이 되고, 모델이 샐러드 볼에서 분리(통합 모델 아님)로 바뀝니다.
