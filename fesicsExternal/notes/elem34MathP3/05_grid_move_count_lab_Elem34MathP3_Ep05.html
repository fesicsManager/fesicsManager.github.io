평면에서 점의 이동 — 건너간 칸을 세요

점 ㄱ의 말을 오른쪽으로 3칸 옮길 때 출발 칸부터 "하나"라고 세면 실제로는 2칸만 움직여 점 ㄷ에 섰어요. 건너갈 때마다 하나씩 세니 점 ㄹ에 닿았어요. 이동을 방향과 칸 수로 말하는 방법을 정리해요.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 이동(오른쪽 3칸, 왼쪽 2칸, 위쪽 1칸, 두 방향 이동 둘)과 칸을 세는 방법(출발 칸부터 / 건너가며)을 고르고 말 옮기기를 누르면, 실제로 움직인 칸과 도착한 곳이 기록돼요.

표 1. 두 가지로 센 칸 (실험 결과)
하라는 이동출발 칸까지 세면 실제로 움직인 칸한 칸씩 건너가며 세면
오른쪽으로 3칸2칸3칸
왼쪽으로 2칸1칸2칸
위쪽으로 1칸0칸 (제자리)1칸

출발 칸을 세면 언제나 한 칸씩 모자라요. 1칸 옮기라고 하면 제자리에 그대로 있어요.

개념 정리

1. 점의 이동

점의 이동은 '어느 쪽으로 몇 칸'으로 말해요. 몇 칸은 점이 실제로 건너간 칸의 수예요. 출발한 자리는 0칸이에요.

2. 두 방향으로 옮기기

오른쪽 3칸 → 위쪽 2칸, 위쪽 2칸 → 오른쪽 3칸은 순서가 달라도 같은 곳에 도착해요.

3. 도형 옮기기

삼각형을 오른쪽으로 5칸 옮기려면 세 꼭짓점을 모두 오른쪽으로 5칸씩 옮겨 다시 이어요. 모양과 크기는 그대로, 자리만 바뀌어요.

움직여 보기

모눈 위에서 점과 삼각형 옮기기 — 건너간 칸 세기

지금까지 오른쪽 위쪽 도착

출발한 자리는 0, 한 칸 건너갈 때마다 1, 2, 3… 으로 셉니다. 순서를 ‘위쪽 먼저’로 바꿔도 같은 곳(회색 점선 길 끝)에 도착하는지 보세요. 삼각형은 세 꼭짓점을 모두 같은 만큼 옮기므로 모양과 크기는 그대로예요.

옮긴 칸 수 = 건너간 칸의 수 (출발 칸은 0)

예제

점 ㄱ에서 오른쪽으로 4칸, 아래쪽으로 1칸 옮긴 점을 찾는 방법을 말해 보세요.

출발 칸은 세지 않고, 오른쪽으로 건너갈 때마다 1, 2, 3, 4를 센 뒤, 아래쪽으로 한 번 건너가요.

점이 (오른쪽 3칸, 위쪽 2칸) 옮겨졌어요. 원래 자리로 돌아가려면?

왼쪽으로 3칸, 아래쪽으로 2칸 옮기면 돼요(순서는 바꾸어도 같아요).
