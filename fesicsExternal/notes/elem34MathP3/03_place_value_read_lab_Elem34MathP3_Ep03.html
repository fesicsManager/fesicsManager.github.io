소수 세 자리 수 — 자리마다 하나씩 읽어요

0.305, 0.35, 1.024를 자릿값 판에 넣어 봤어요. 0.305는 0.1이 3개, 0.001이 5개이고, 0.35는 0.1이 3개, 0.01이 5개라 0.35가 더 컸어요. 소수점 아래를 덩어리로 읽으면 크기가 거꾸로 들리는 까닭과 바른 읽기를 정리해요.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 수(0.305kg, 0.35kg, 0.035kg, 1.024kg, 2.045kg, 1.07m)와 읽는 방법(한 덩어리로 / 자리마다 하나씩)을 고르고 자릿값 판에 넣기를 누르면, 자릿값과 읽기, 0.001의 개수가 기록돼요.

0.305는 0.001이 305개, 0.35는 350개예요. 0.35가 더 커요. 덩어리로 읽으면 0.35와 0.035가 둘 다 "영 점 삼십오"가 되어 버려요.

개념 정리

1. 소수 세 자리 수

1/1000 = 0.001(영 점 영영일). 소수 첫째 자리는 0.1, 둘째 자리는 0.01, 셋째 자리는 0.001이 몇 개인지 나타내요.

2. 소수 읽기

소수점 아래는 숫자를 하나씩 읽고, 0도 '영'이라고 읽어요. 0.305 → 영 점 삼영오, 1.024 → 일 점 영이사.

수 읽기 자릿값

예를 고르거나 판의 숫자 칸을 눌러 바꿔 보세요. 소수점 아래는 숫자를 하나씩 읽고 0도 ‘영’이라고 읽습니다. 끝자리의 0(흐린 칸)은 쓰지 않아도 같은 수예요.

3. 단위 바꾸기와 빈자리 0

  • 1g = 0.001kg → 2kg 45g = 2.045kg
  • 1cm = 0.01m → 1m 7cm = 1.07m
  • 빈자리에 0을 안 쓰면 2.45kg, 1.7m처럼 다른 수가 돼요.
0.305 = 0.1 × 3 + 0.001 × 5 = 0.001이 305개
