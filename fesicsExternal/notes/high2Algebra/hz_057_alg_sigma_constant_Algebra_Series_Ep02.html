상수의 합 — Σc는 n번 더한 nc

상수 c와 항의 개수 n을 바꾸며 c를 n개 쌓아 직접 더한 값을 nc, c와 비교해 기록했습니다. 직접 더한 값은 모든 기록에서 nc였고, c와 같은 것은 n = 1이거나 c = 0일 때뿐이었습니다. Σ 안에 k가 없어도 n번 더한다는 뜻을 정리합니다.

Σ는 ‘k = 1부터 n까지 각 k마다 하나씩 만들어 더하라’는 뜻이라 안에 k가 없어도 n번 더합니다. 그래서 Σ(k=1~n) c = nc입니다. n = 1이거나 c = 0이면 nc와 c가 우연히 같아 보이지만, 그 밖에는 달랐습니다. Σ(aₖ + c) = Σaₖ + nc처럼 상수항은 n배로 들어옵니다.

개념 정리

1. Σ(k=1~n) c = nc — k가 보이지 않아도 n번 더한다

시그마 안에 k 가 없어도 k = 1부터 n까지 n번 더하라는 뜻은 그대로예요. 그래서 c 를 n번 더한 nc 가 됩니다. “c 가 하나만 있으니 c”라고 하면 항의 개수를 통째로 빼먹는 것입니다.

왜 그럴까

  • Σ는 “각 k마다 하나씩 만들어 더하라”는 명령입니다.
  • Σ(aₖ + c) = Σaₖ + nc — 상수항이 n배로 들어옵니다.
  • 합의 공식에서 자주 틀리는 자리입니다.

2. 자주 하는 오해 바로잡기

· “Σc 는 c 다” → 항의 개수 n 이 곱해집니다.

3. 생활 속에서 · 이어지는 개념

  • 매달 같은 금액을 n개월 저축하면 총액이 n배가 되는 것과 같습니다.

예제

Σ(k=1~10) 4를 구하시오.

4를 10번 더하므로 10 × 4 = 40

Σ(k=1~5) (2k + 3)을 구하시오.

2 × (1 + 2 + 3 + 4 + 5) + 5 × 3 = 30 + 15 = 45
