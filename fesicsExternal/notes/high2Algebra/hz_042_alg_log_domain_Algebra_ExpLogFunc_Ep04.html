로그함수의 정의역 — 진수는 반드시 양수

로그함수 y = log_a(x − p)에서 x를 바꿔 진수 x − p의 값과 로그값을 기록했습니다. 진수가 양수일 때만 값이 나왔고, 0이나 음수이면 정의되지 않았습니다. 정의역이 x > p이고 x = p가 점근선인 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 밑 a(0.2~4, 0.1 단위), 평행이동 p(−4~4), 확인할 x(−5~6, 0.5 단위)를 정하고 ‘넣을 수 있는 x 찾기’를 누르면 진수 값, 로그값, 정의 여부, 정의역이 기록됩니다. 밑을 1로 두면 ‘밑 1은 로그의 밑이 될 수 없다’는 안내가 뜨고 기록되지 않습니다. 4개 이상 기록하면 분석이 열립니다.

표 1. y = log₂(x − p)에서 x에 따른 정의 여부 (실험 예시, 밑 a = 2)
x진수 값log 값정의되나정의역
421✅x > 2
20—❌x > 2
1−1—❌x > 2
010✅x > −1
−1−1—❌x > 0

진수가 0 이하인 행은 모두 정의되지 않았습니다. a > 0이면 aˣ은 항상 양수이므로 ‘a를 몇 번 곱해 M이 되나’에서 M이 0 이하일 수 없습니다. 지수함수의 치역 (0, ∞)이 로그함수의 정의역이 되어 log_a(x − p)의 정의역은 x > p이고, x가 p에 가까워지면 값이 −∞로 내려가 x = p가 점근선입니다. 같은 x = 0이라도 p = −1이면 정의되고 p = 0이면 정의되지 않습니다.

개념 정리

1. 진수는 반드시 양수 — 0이나 음수는 넣을 수 없다

log_a M 은 “a를 몇 번 곱하면 M이 되나”인데, a > 0 이면 aˣ 은 항상 양수라 M이 0이나 음수가 될 수 없어요. 그래서 진수 조건 M > 0 이 붙고, log_a(x − p) 의 정의역은 x > p 입니다.

왜 그럴까

  • 지수함수의 치역이 (0, ∞)이므로, 역함수인 로그함수의 정의역도 (0, ∞).
  • x가 p에 가까워지면 log 값이 −∞로 내려갑니다 — x = p 가 점근선입니다.
  • 로그방정식을 풀고 검산해야 하는 이유도 이 조건 때문입니다.

움직여 보기

넣을 수 있는 x 찾기 — 진수가 양수인 곳만

진수 x − p = 로그값 정의되나 정의역

초록 띠가 정의역 x > p, 빨간 점선이 점근선 x = p입니다. x를 p 쪽으로 옮기면 로그값이 끝없이 내려가고, p를 넘어가면 진수가 0 이하가 되어 값이 없어요(빨간 ✕). 같은 x = 0도 p = −1이면 정의되고 p = 0이면 정의되지 않습니다.

2. 자주 하는 오해 바로잡기

· “로그함수의 정의역은 모든 실수다” → 진수가 양수인 곳뿐입니다.

3. 생활 속에서 · 이어지는 개념

  • pH 계산에서 농도가 0이 될 수 없는 것과 같은 이유입니다.
평행이동한 로그함수에서 x를 바꿔 진수의 부호를 확인하고, 정의되는 구간을 표시

예제

y = log₂(x − 3)의 정의역과 점근선을 구하시오.

진수 조건 x − 3 > 0에서 정의역 x > 3, 점근선 x = 3

y = log₃(5 − x)의 정의역을 구하시오.

5 − x > 0이므로 x < 5
