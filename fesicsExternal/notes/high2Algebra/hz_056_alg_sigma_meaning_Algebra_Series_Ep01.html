고등학교 대수 · 실험 「시그마 실험실」

Σ의 성질 — 합에는 나뉘고 곱에는 나뉘지 않는다

aₖ = k, bₖ = k + 1로 두고 n을 바꾸며 Σ(aₖ + bₖ), Σaₖ + Σbₖ, Σ(aₖbₖ), (Σaₖ)(Σbₖ)를 직접 더해 기록했습니다. 합은 모든 n에서 같았지만 곱은 n = 2에서도 8과 15로 달랐습니다. Σ가 덧셈의 성질만 물려받는 까닭을 정리합니다.

Σ(aₖ + bₖ) = Σaₖ + Σbₖ는 더하는 순서만 바꾼 것이라 항상 성립했습니다. 그러나 (Σaₖ)(Σbₖ)를 전개하면 a₁b₂, a₂b₁처럼 번호가 다른 항끼리의 곱(교차항)이 들어가 Σ(aₖbₖ)보다 커졌습니다. 상수배 Σcaₖ = cΣaₖ는 성립하지만 곱과 몫에는 나뉘지 않습니다.

개념 정리

1. 시그마는 덧셈·뺄셈에만 나뉘고, 곱셈에는 나뉘지 않는다

Σ(aₖ + bₖ) = Σaₖ + Σbₖ 는 성립해요 — 더하는 순서를 바꾼 것뿐이니까요. 하지만 Σ(aₖbₖ) 와 (Σaₖ)(Σbₖ) 는 다릅니다. 뒤엣것을 전개하면 서로 다른 번호끼리 곱한 항까지 들어가기 때문입니다.

왜 그럴까

  • (a₁+a₂)(b₁+b₂) = a₁b₁ + a₁b₂ + a₂b₁ + a₂b₂ — 교차항이 생깁니다.
  • Σ(caₖ) = cΣaₖ 는 성립합니다 — 상수는 밖으로 뺄 수 있습니다.
  • Σ는 “더하기의 줄임말”이라, 덧셈의 성질만 물려받습니다.

움직여 보기

(Σaₖ)(Σbₖ)를 넓이로 — 교차항이 숨어 있다

보라 Σ(aₖbₖ) 주황 교차항 전체 (Σaₖ)(Σbₖ) Σ(aₖ+bₖ) = Σaₖ+Σbₖ

aₖ = k, bₖ = k + 1입니다. 직사각형 전체 넓이가 (Σaₖ)(Σbₖ)인데, Σ(aₖbₖ)는 대각선의 보라 칸만 더한 것입니다. 주황 칸(번호가 다른 곱, 교차항)만큼 차이가 나므로 시그마는 곱에 나뉘지 않습니다. n = 3이면 20과 54입니다.

2. 자주 하는 오해 바로잡기

· “Σ 는 괄호처럼 분배된다” → 곱에는 분배되지 않습니다.

3. 생활 속에서 · 이어지는 개념

  • 평균의 곱과 곱의 평균이 다른 것과 같은 구조입니다.
aₖ = k, bₖ = k+1 로 두고 n까지 네 가지 합을 모두 직접 계산해 비교
📋 데이터 확인 탭의 결론

“모든 기록에서 Σ(a+b) = Σa + Σb 였습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

Σ(k=1~3) k(k + 1)과 (Σ(k=1~3) k)(Σ(k=1~3) (k + 1))을 각각 구하시오.

2 + 6 + 12 = 20, (1 + 2 + 3)(2 + 3 + 4) = 6 × 9 = 54. 20과 54 (다르다)

Σ(k=1~n) aₖ = 10, Σ(k=1~n) bₖ = 4일 때 Σ(k=1~n) (2aₖ + 3bₖ)를 구하시오.

2 × 10 + 3 × 4 = 32
