등비중항 — b² = ac에서 b는 두 개

첫째항 a와 셋째항 c를 바꾸며 b² = ac를 계산하고 b = +√(ac), −√(ac)로 수열을 만들어 기록했습니다. 모든 기록에서 두 값 모두 등비수열을 이뤘습니다. 등비중항이 둘인 까닭과 등차중항과의 차이를 정리합니다.

a, b, c가 등비수열이면 b/a = c/b에서 b² = ac입니다. 제곱해서 ac가 되는 수는 ±√(ac) 두 개라서 2, 4, 8(공비 2)과 2, −4, 8(공비 −2)이 모두 등비수열입니다. 공비가 음수이면 항의 부호가 번갈아 바뀝니다. 평균인 등차중항 b = (a + c)/2가 하나뿐인 것과 다릅니다. ac < 0이면 실수인 등비중항이 없습니다.

개념 정리

1. b² = ac 에서 b 는 ±√(ac) — 등비중항은 둘이다

a, b, c 가 등비수열이면 b/a = c/b 에서 b² = ac 예요. 제곱해서 ac 가 되는 수는 두 개이므로 등비중항도 둘입니다. 공비가 양수인 수열과 음수인 수열이 각각 하나씩 생깁니다. (등차중항은 b = (a+c)/2 로 하나뿐입니다.)

왜 그럴까

  • 공비 r 이 음수면 항의 부호가 번갈아 바뀝니다.
  • ac < 0 이면 실수 범위에서 등비중항이 없습니다.
  • 등차중항은 평균이라 하나, 등비중항은 제곱근이라 둘 — 이 차이가 핵심입니다.

2. 자주 하는 오해 바로잡기

· “등비중항은 하나뿐이다” → 부호가 다른 두 개가 모두 성립합니다.

3. 생활 속에서 · 이어지는 개념

  • 성장률을 역산할 때 부호까지 따져야 실제 의미가 맞는 답을 고를 수 있습니다.
