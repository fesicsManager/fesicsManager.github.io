고등학교 대수 · 실험 「지수방정식 실험실」

지수방정식 — 밑을 맞춘 다음 지수를 비교한다

2ˣ = 2^k 꼴의 방정식을 만들고, 우변을 밑 2로 맞춘 식에서 지수를 비교해 구한 x를 대입해 검산했습니다. 밑을 맞추면 모든 기록에서 검산이 맞았습니다. aᵐ = aⁿ ⟺ m = n이 밑이 같을 때만 쓸 수 있는 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 k(−3~6)와 우변을 다른 밑으로 쓸 수(2~8)를 정하고 ‘밑을 맞춰 풀기’를 누르면 방정식, 밑을 맞춘 식, 구한 x, 검산값이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 밑을 맞춰 푼 지수방정식 (실험 예시)
방정식밑이 같나밑을 맞춘 식지수 비교로 구한 x검산맞나
2ˣ = 8×2ˣ = 2³38✅
2ˣ = 16×2ˣ = 2⁴416✅
2ˣ = 0.25○2ˣ = 2⁻²−20.25✅
2ˣ = 64×2ˣ = 2⁶664✅
2ˣ = 1×2ˣ = 2⁰01✅

우변을 다른 밑(4, 8 등)으로 쓴 경우에도 2의 거듭제곱으로 고쳐 밑을 맞춘 뒤 지수를 비교하면 검산이 모두 맞았습니다. 지수함수는 일대일이라 aˣ = a^k ⟺ x = k (a > 0, a ≠ 1)입니다. 8 = 4^1.5처럼 밑이 다른 채로 지수만 비교하면 엉뚱한 답이 나오고, a = 1이면 1ˣ = 1이 모든 x에서 성립해 이 논법을 쓸 수 없습니다. 밑을 맞출 수 없으면 양변에 로그를 취합니다.

개념 정리

1. a^m = a^n ⟺ m = n — 단, 밑이 같을 때만

밑이 같아야 지수를 비교할 수 있어요. 2ˣ = 8 은 8을 2³으로 고쳐 밑을 맞춘 뒤 x = 3 을 얻습니다. 밑이 다른 채로 지수만 비교하면 전혀 다른 답이 나옵니다. (a = 1 일 때는 지수가 달라도 양변이 같아져 예외입니다.)

왜 그럴까

  • 지수함수가 일대일이라 aˣ = a^k ⟺ x = k.
  • a = 1 이면 1ˣ = 1 로 모든 x가 해가 되어 이 논법을 쓸 수 없습니다.
  • 밑을 맞출 수 없으면 양변에 로그를 취합니다.

2. 자주 하는 오해 바로잡기

· “지수만 같으면 된다” → 밑을 먼저 맞춰야 지수를 비교할 수 있습니다.

3. 생활 속에서 · 이어지는 개념

  • 복리·감가상각 계산에서 기간을 구할 때 이 절차를 그대로 씁니다.
같은 수를 서로 다른 밑으로 표현해 방정식을 만들고, 밑을 맞춘 풀이와 맞추지 않은 풀이를 검산
📋 데이터 확인 탭의 결론

“밑을 맞춰 구한 답은 모두 검산을 통과했습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

4ˣ = 32를 푸시오.

2^(2x) = 2⁵이므로 2x = 5, x = 5/2

9^(x+1) = 27을 푸시오.

3^(2x+2) = 3³이므로 2x + 2 = 3, x = 1/2

확인 문제

1번· 관찰 확인

실험에서 2ˣ = 16을 기록했을 때 구한 x는?

16 = 2⁴이므로 x = 4입니다.
🔬 실험으로 다시 확인

2번· 핵심 개념

지수방정식에서 지수를 비교할 수 있는 조건은?

지수함수가 일대일일 때만 지수를 비교할 수 있습니다.
🔬 실험으로 다시 확인

3번· 적용

8ˣ = 4의 해는?

2^(3x) = 2²에서 3x = 2, x = 2/3입니다.
🔬 실험으로 다시 확인

4번· 오해 바로잡기

4ˣ = 8에서 ‘지수를 보면 x = 3’이라고 답했다. 바르게 고친 것은?

밑을 같게 만든 다음에야 지수를 비교합니다.
