고등학교 대수 · 실험 「쪼개기 실험실」

부분분수와 망원합 — 가운데가 지워진다

Σ(k=1~n) 1/{k(k + 1)}을 직접 더한 값과 부분분수로 쪼개 남은 두 항 1 − 1/(n + 1)을 비교해 기록했습니다. 모든 n에서 두 값이 같았고 지워진 조각은 2(n − 1)개였습니다. 쪼개면 이웃끼리 지워져 양 끝만 남는 원리를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 n(2~12)을 정하고 ‘쪼개서 지워 보기’를 누르면 직접 더한 합, 1 − 1/(n + 1), 지워진 항 수가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. Σ 1/{k(k+1)}의 합 (실험 예시)
n직접 더한 합1 − 1/(n+1)남은 두 항지워진 항 수같나
20.6666670.6666671 − 1/32✅
30.750.751 − 1/44✅
50.8333330.8333331 − 1/68✅
90.90.91 − 1/1016✅
120.9230770.9230771 − 1/1322✅

1/{k(k + 1)} = 1/k − 1/(k + 1)로 쪼개 늘어놓으면 (1 − 1/2) + (1/2 − 1/3) + … + (1/n − 1/(n + 1))에서 이웃한 조각이 부호가 반대라 지워지고 맨 앞 1과 맨 뒤 −1/(n + 1)만 남습니다. 그래서 합은 n/(n + 1)이고, n이 커지면 1에 가까워질 뿐 1을 넘지 않습니다.

개념 정리

1. 1/{k(k+1)} = 1/k − 1/(k+1) — 쪼개면 이웃끼리 지워진다

각 항을 두 조각으로 쪼개 늘어놓으면 앞 항의 뒤 조각과 뒤 항의 앞 조각이 서로 지워져요. 결국 맨 앞과 맨 뒤 조각만 남아 합이 1 − 1/(n+1) 이 됩니다. 망원경이 접히는 모습과 닮아 망원급수라고 부릅니다.

왜 그럴까

  • 1/k − 1/(k+1) = 1/{k(k+1)} — 통분하면 확인됩니다.
  • 이웃끼리 부호가 반대라 상쇄됩니다.
  • n이 커지면 1/(n+1) → 0 이라 합이 1에 다가갑니다.

움직여 보기

쪼개서 이어 붙이면 — 앞뒤만 남는다

직접 더한 합 1 − 1/(n+1) 지워진 조각 수

k번째 조각 1/{k(k+1)}은 수직선에서 1 − 1/k부터 1 − 1/(k+1)까지의 길이와 같습니다. 이어 붙이면 사이 눈금이 모두 지워지고, 식에서도 이웃 조각이 줄로 지워져 1과 −1/(n+1)만 남습니다. n = 20이면 20/21입니다.

2. 자주 하는 오해 바로잡기

· “분수 수열은 더할 수 없다” → 쪼개면 대부분 지워집니다.

3. 생활 속에서 · 이어지는 개념

  • 복잡한 합을 “앞뒤만 남기는” 이 기법은 대학 수학에서도 계속 쓰입니다.
n까지의 항을 직접 더한 값과, 쪼개서 남은 두 항으로 구한 값을 비교
📋 데이터 확인 탭의 결론

“모든 기록에서 두 값이 정확히 같았습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

Σ(k=1~20) 1/{k(k + 1)}을 구하시오.

1 − 1/21 = 20/21

Σ(k=1~4) 1/{(2k − 1)(2k + 1)}을 구하시오.

1/{(2k − 1)(2k + 1)} = (1/2){1/(2k − 1) − 1/(2k + 1)}이므로 (1/2)(1 − 1/9) = 4/9
