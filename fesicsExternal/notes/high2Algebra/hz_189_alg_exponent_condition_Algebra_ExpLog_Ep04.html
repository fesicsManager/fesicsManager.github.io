지수법칙의 조건 — 밑이 양수일 때만 안전하다

밑 a와 두 지수 m, n을 0.5 단위로 바꾸며 (a^m)^n과 a^(mn)을 각각 계산해 기록했습니다. 밑이 양수인 기록은 모두 같았지만, 밑이 음수이거나 0이면 값이 갈리거나 정의되지 않는 경우가 나왔습니다. 지수함수·로그함수의 밑에 a > 0이 붙는 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 밑 a(−4~4), 지수 m(−2~4), n(−2~4)을 0.5 단위로 정하고 ‘밑을 바꿔 확인하기’를 누르면 (a^m)^n, a^(mn), 같은지 여부와 밑의 조건이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 밑에 따른 (a^m)^n과 a^(mn) (실험 예시)
밑 a지수 (m, n)(a^m)^na^(mn)같나밑의 조건
42, 0.544✅a > 0 — 안전
23, −10.1250.125✅a > 0 — 안전
−42, 0.54−4❌a < 0 — 분수 지수에서 깨짐
−21, 1−2−2✅a < 0 — 분수 지수에서 깨짐
01, −1정의 안 됨정의 안 됨❌a = 0 — 음수 지수 불가

밑이 양수인 행은 지수가 음수든 분수든 두 값이 같았습니다. 밑이 −4이고 n = 0.5이면 ((−4)²)^0.5 = √16 = 4인데 (−4)¹ = −4라 계산 순서에 따라 값이 갈렸습니다. 밑이 음수여도 정수 지수만 쓰면(−2, m = n = 1) 우연히 맞지만, 분수 지수가 끼면 깨질 수 있습니다. 밑이 0이면 0⁻¹ = 1/0이 정의되지 않습니다. 그래서 지수를 실수 전체로 넓힐 때 밑은 a > 0으로 제한합니다.

개념 정리

1. 지수법칙은 밑이 양수일 때 안전하다 — 음수나 0 에서는 깨진다

(a^m)^n = a^(mn) 은 a > 0 일 때 언제나 성립해요. 밑이 음수면 깨집니다 — a = −4, m = 2, n = 0.5 를 직접 넣어 보세요. 왼쪽은 ((−4)²)^0.5 = √16 = 4 인데 오른쪽은 (−4)¹ = −4 입니다. 밑이 0 이면 0의 음수 제곱이 정의되지 않습니다.

왜 그럴까

  • 음수의 분수 제곱은 실수 범위에서 정의되지 않는 경우가 많습니다. 이 실험도 그런 경우를 “정의 안 됨”으로 표시합니다.
  • (−8)^(1/3) = −2 처럼 홀수 제곱근만 따로 정의하는 관례도 있지만, 그렇게 해도 위의 a = −4 예처럼 지수법칙은 여전히 깨집니다.
  • 0⁰ 과 0의 음수 제곱은 정의되지 않습니다.
  • 그래서 지수함수·로그함수의 밑에 a > 0 조건이 붙습니다.

움직여 보기

(a^m)^n 과 a^(mn) — 두 길로 계산해 비교

(a^m)^n a^(mn) 같나 밑의 조건

밑 a를 양수에서 음수로 바꿔 보세요. a > 0이면 지수가 음수든 분수든 두 길의 결과가 같지만, a = −4, m = 2, n = 0.5이면 위 길은 4, 아래 길은 −4로 갈립니다. 실험과 같이, 음수의 분수 제곱과 0의 0 이하 제곱은 '정의 안 됨'으로 표시합니다.

📋 데이터 확인 탭의 결론

“밑이 양수인 기록은 모두 성립했습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

((−8)²)^(1/2)과 (−8)^(2 × 1/2)을 각각 계산하고 지수법칙이 성립하는지 판단하시오.

((−8)²)^(1/2) = 64^(1/2) = 8, (−8)^1 = −8. 두 값이 달라 성립하지 않는다(밑이 음수)

(0²)^(−1)과 0^(2 × (−1))은 정의되는지 판단하시오.

(0²)^(−1) = 0^(−1) = 1/0, 0^(−2) = 1/0². 둘 다 0으로 나누게 되어 모두 정의되지 않는다
