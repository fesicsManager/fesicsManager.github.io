밑변환 공식 — 어떤 밑으로 바꿔도 값은 같다

진수 a, 밑 b, 바꿀 밑 c를 정해 log_b a를 직접 구하고, 상용로그·자연로그·밑 c로 환산한 값을 함께 기록했습니다. 어떤 밑으로 바꿔도 값이 소수 다섯째 자리까지 같았습니다. log_b a = log_c a / log_c b가 성립하는 까닭을 정리합니다.

실험 안내: 자유 탐구 탭에서 진수 a(2~100), 밑 b(2~20), 바꿀 밑 c(2~20)를 정하고 ‘밑을 바꿔 계산하기’를 누르면 직접 계산, log a / log b, ln a / ln b 값이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

밑이 10이든 e든 c든 결과가 같았습니다. b^x = a의 양변에 log_c를 씌우면 x·log_c b = log_c a이므로 log_b a = log_c a / log_c b입니다. 분자와 분모에 같은 자를 대는 셈이라 비가 변하지 않습니다. 그래서 계산기에 log와 ln만 있어도 log₂ 10 ≈ 3.32193 같은 값을 구할 수 있고, log_b a × log_a b = 1도 여기서 나옵니다.

개념 정리

1. log_b a = log_c a / log_c b — 어떤 밑으로 바꿔도 값은 같다

밑이 달라도 “몇 번 곱했나”라는 뜻은 같아요. 밑을 c로 바꾸면 분자와 분모에 같은 자가 들어가 단위만 환산되는 셈이라 값이 변하지 않습니다. 그래서 계산기에 log(상용)나 ln만 있어도 어떤 밑의 로그든 구할 수 있습니다.

왜 그럴까

  • b^x = a 에 log_c 를 씌우면 x·log_c b = log_c a → x = log_c a / log_c b.
  • log_b a · log_a b = 1 — 분자와 분모를 뒤집은 관계입니다.
  • 밑을 무엇으로 고르든 비가 같아 결과가 같습니다.

2. 자주 하는 오해 바로잡기

· “밑이 다르면 계산할 수 없다” → 어떤 밑으로든 환산할 수 있습니다.

3. 생활 속에서 · 이어지는 개념

  • 계산기에 log₂ 버튼이 없어도 log/ln 두 개로 모두 해결됩니다.
밑 b의 로그를 직접 구하고, 상용로그와 자연로그로 각각 환산해 세 값을 비교

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

log 2 = 0.3010일 때 log₂ 10의 값을 소수 둘째 자리까지 구하시오.

log₂ 10 = log 10 / log 2 = 1 / 0.3010 ≈ 3.32

log₂ 3 × log₃ 8의 값을 구하시오.

(log 3 / log 2) × (log 8 / log 3) = log 8 / log 2 = log₂ 8 = 3
