고등학교 대수 · 실험 「위상 실험실」

삼각함수의 평행이동 — sin(x − p)는 오른쪽으로 p

p를 π/6 단위로 바꾸며 y = sin(x − p)의 그래프를 그리고 마루의 x좌표를 재어 기록했습니다. p > 0이면 마루가 π/2에서 오른쪽으로, p < 0이면 왼쪽으로 옮겨졌고 위치는 늘 π/2 + p였습니다. 괄호 안의 빼기가 오른쪽 이동이 되는 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 p(π/6 단위, −π~π)와 진폭 a(1~3)를 정하고 ‘마루의 위치 재기’를 누르면 원래 마루와 옮긴 마루의 위치, 이동 방향이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. p에 따른 마루의 이동 (실험 예시)
p원래 마루 위치옮긴 마루 위치이동 방향x−p 대입맞는 쪽
π/2π/2π오른쪽 →x = π/2 + p오른쪽 ✅
π/3π/25π/6오른쪽 →x = π/2 + p오른쪽 ✅
ππ/23π/2오른쪽 →x = π/2 + p오른쪽 ✅
−π/6π/2π/3← 왼쪽x = π/2 + p—
−π/2π/20← 왼쪽x = π/2 + p—

sin x의 마루는 x = π/2입니다. sin(x − p)의 마루는 x − p = π/2, 곧 x = π/2 + p에 생기므로 p > 0이면 오른쪽으로 갑니다. 새 그래프의 점 (x, y)는 원래 그래프의 (x − p, y)에서 왔기 때문에 괄호 안의 부호와 이동 방향이 반대로 보입니다. 진폭 a를 바꿔도 마루의 x좌표와 주기 2π는 그대로였습니다.

개념 정리

1. sin(x − p) 는 오른쪽으로 p 만큼 — 괄호 안의 빼기가 오른쪽 이동

sin x 의 마루는 x = π/2 에 있어요. sin(x − p) 의 마루는 x − p = π/2, 즉 x = π/2 + p 에 생깁니다. p 가 양수면 마루가 오른쪽으로 갑니다. 평행이동에서 x를 x−p로 바꾸는 것과 똑같은 규칙입니다.

왜 그럴까

  • 새 그래프의 점 (x, y)는 원래 그래프의 (x−p, y)에서 왔습니다.
  • 그래서 괄호 안의 부호와 실제 이동 방향이 반대로 보입니다.
  • 주기 2π는 그대로 — 좌우로 밀어도 폭은 변하지 않습니다.

움직여 보기

y = sin(x − p) — 마루가 어디로 가나

마루 x = π/2 + p 이동

p를 양수로 하면 괄호 안이 빼기(x − p)인데도 보라 그래프의 마루가 오른쪽으로 갑니다. 마루는 x − p = π/2 인 곳, 곧 x = π/2 + p 에 생기기 때문입니다. 표의 p = π/2, π/3, π, −π/6, −π/2 를 맞춰 보세요.

2. 자주 하는 오해 바로잡기

· “sin(x − π/2)는 왼쪽으로 옮긴 것이다” → 오른쪽입니다.

3. 생활 속에서 · 이어지는 개념

  • 두 파동의 위상차, 신호의 지연 시간을 나타낼 때 이 이동을 씁니다.
p를 바꿔 그래프를 그리고 마루의 x좌표를 직접 읽어, π/2 + p 와 대조

예제

y = sin(x − π/3)의 마루의 x좌표를 0 ≤ x < 2π에서 구하시오.

x − π/3 = π/2이므로 x = 5π/6

y = 2 sin(x + π/4)의 최댓값과 그때의 x (0 ≤ x < 2π)를 구하시오.

x + π/4 = π/2에서 x = π/4, 최댓값은 진폭 2. x = π/4일 때 최댓값 2
