수학적 귀납법 — 가정에서 다음을 이끌어낸다

세 가지 증명 방식(가정을 써서 연결, 가정을 안 씀, n = 1 확인 생략)으로 도미노를 밀어 몇 번째까지 성립하는지 기록했습니다. 두 단계를 모두 갖춘 방식만 끝까지 넘어갔고, 가정을 쓰지 않으면 1개, n = 1을 빼면 0개에서 멈췄습니다. 귀납 가정이 증명의 대상이 아니라 출발점임을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 확인할 n(1~10)과 증명 방식을 고르고 ‘도미노를 밀어 보기’를 누르면 n = 1 확인, 가정 사용, k → k+1 연결, 몇 번째까지 성립하는지가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 증명 방식에 따른 도미노 (실험 예시)
증명 방식 (n)n=1 확인가정 사용k→k+1 연결몇 번째까지 성립증명 완성
가정을 써서 연결 (6)✅✅✅6개✅
가정을 써서 연결 (10)✅✅✅10개✅
가정을 안 씀 (6)✅❌❌1개❌
n=1 확인 생략 (6)❌✅✅0개❌

수학적 귀납법은 ① n = 1에서 성립, ② n = k에서 성립한다고 가정하면 n = k + 1에서도 성립의 두 단계입니다. ①은 첫 도미노를 넘어뜨리고 ②는 모든 이웃 도미노를 잇습니다. ②가 없으면 첫 도미노에서 멈추고(1개), ①이 없으면 아무것도 넘어가지 않았습니다(0개). ②에서 가정은 증명할 대상이 아니라 실제로 대입해 쓰는 출발점입니다.

개념 정리

1. 귀납법은 “가정을 증명”하는 것이 아니라 “가정에서 다음을 이끌어내는” 것

수학적 귀납법은 두 단계예요. ① n = 1 에서 성립 ② n = k 에서 성립한다고 가정하면 n = k+1 에서도 성립. ②에서 가정은 증명 대상이 아니라 출발점입니다. 가정을 쓰지 않고 k+1을 직접 보이려 하면 연결 고리가 끊겨 도미노가 넘어가지 않습니다.

왜 그럴까

  • ①은 첫 도미노를 넘어뜨리는 것, ②는 도미노 사이의 간격을 맞추는 것입니다.
  • ②만 있고 ①이 없으면 아무 도미노도 넘어가지 않습니다.
  • 가정을 실제로 대입해 쓰는 것이 ② 단계의 핵심 작업입니다.

2. 자주 하는 오해 바로잡기

· “가정도 증명해야 한다” → 가정은 출발점입니다. 증명할 것은 “가정 → 다음”입니다.

📋 데이터 확인 탭의 결론

“세 가지를 모두 확인했습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

1 + 3 + … + (2n − 1) = n²의 ② 단계를 보이시오.

n = k에서 1 + 3 + … + (2k − 1) = k²이라 가정하면, 양변에 2k + 1을 더해 k² + 2k + 1 = (k + 1)². n = k + 1에서도 성립

모든 자연수 n에 대하여 2ⁿ > n임을 귀납법으로 보이시오.

① n = 1: 2 > 1. ② 2ᵏ > k라 가정하면 2ᵏ⁺¹ = 2 × 2ᵏ > 2k ≥ k + 1 (k ≥ 1). 모든 자연수 n에서 성립
