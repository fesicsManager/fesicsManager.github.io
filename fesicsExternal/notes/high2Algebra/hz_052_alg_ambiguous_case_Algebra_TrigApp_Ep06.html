SSA의 애매한 경우 — 삼각형이 0, 1, 2개

각 A, 알고 있는 변 b, 마주 보는 변 a를 바꾸며 높이 h = b sin A를 계산하고 만들 수 있는 삼각형의 개수를 기록했습니다. a < h이면 0개, a = h이면 1개, h < a < b이면 2개, a ≥ b이면 1개였습니다. 두 변과 끼인각이 아닌 각이 삼각형을 하나로 정하지 못하는 까닭을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 각 A(15°~80°), 변 b(4~12), 변 a(2~14)를 정하고 ‘만들 수 있는 삼각형 세기’를 누르면 h, a와 h·b의 대소, 삼각형 개수가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

꼭짓점 C에서 반지름 a인 원을 그려 밑변과 몇 번 만나는지 세는 것과 같습니다. 거리 h = b sin A보다 a가 짧으면 닿지 않고, 같으면 접해 직각삼각형 하나, h < a < b이면 두 점에서 만나 삼각형이 두 개입니다. a ≥ b이면 한 교점이 A의 반대쪽으로 넘어가 하나만 남습니다. 그래서 SSA는 합동조건이 아닙니다.

개념 정리

1. 두 변과 끼이지 않은 각(SSA)은 삼각형을 하나로 정하지 못한다

각 A와 변 b를 고정하면 높이 h = b sin A 가 정해져요. 마주 보는 변 a 가 h < a < b 이면 삼각형이 두 개 생기고, a = h 면 하나(직각), a < h 면 하나도 없습니다. a ≥ b 면 하나입니다.

왜 그럴까

  • 원과 직선의 교점 개수 문제와 같은 구조입니다 — 반지름 a인 원이 밑변을 몇 번 만나나.
  • SSS, SAS, ASA는 삼각형을 하나로 정하지만 SSA는 정하지 못합니다.
  • 그래서 합동조건에 SSA가 없습니다.

2. 자주 하는 오해 바로잡기

· “조건이 세 개면 삼각형이 하나로 정해진다” → SSA는 두 개가 나올 수 있습니다.

3. 생활 속에서 · 이어지는 개념

  • 측량에서 각 하나와 변 두 개만 재면 답이 둘일 수 있어 조건을 더 확인합니다.
각 A와 두 변을 바꿔 높이 h를 계산하고, a와 h·b의 대소로 삼각형의 개수를 판정해 그림으로 표시

예제

A = 30°, b = 10, a = 6일 때 삼각형 ABC는 몇 개인가?

h = 10 sin 30° = 5이고 5 < 6 < 10이므로 2개

A = 45°, b = 8, a = 4일 때 삼각형 ABC는 몇 개인가?

h = 8 sin 45° = 4√2 ≈ 5.66 > 4이므로 0개
