고등학교 대수 · 실험 「첫째항 실험실」

합과 일반항 — a₁은 S₁로 따로 구한다

Sₙ = n² + pn + q에서 p, q를 바꾸며 aₙ = Sₙ − Sₙ₋₁로 구한 식에 n = 1을 넣은 값과 실제 a₁ = S₁을 비교해 기록했습니다. 상수항 q = 0일 때만 두 값이 같았고, q ≠ 0이면 q만큼 어긋났습니다. aₙ = Sₙ − Sₙ₋₁이 n ≥ 2에서만 성립하는 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 p(−4~5)와 상수항 q(−4~5)를 정하고 ‘n=1을 확인하기’를 누르면 공식으로 구한 aₙ, n = 1 대입값, 실제 a₁, 한 식으로 쓸 수 있는지가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. aₙ 공식의 n = 1 대입값과 S₁ (실험 예시)
Sₙ공식으로 구한 aₙn=1 대입실제 a₁ = S₁같나답
n² + 2n + 32n + 136❌a₁ 따로
n² + 2n2n + 133✅한 식으로
n² − n − 22n − 20−2❌a₁ 따로
n²2n − 111✅한 식으로
n² + 4n + 52n + 3510❌a₁ 따로

Sₙ − Sₙ₋₁은 n번째 항 하나만 남기는 계산이라 n ≥ 2에서만 쓸 수 있고, a₁ = S₁은 따로 구합니다. 공식에 n = 1을 넣은 값은 1 + p, 실제 a₁은 1 + p + q라 두 값의 차가 정확히 q였습니다. 그래서 q = 0일 때만 aₙ을 한 식으로 쓸 수 있고, q ≠ 0이면 a₁ 따로, n ≥ 2에서 공식으로 나누어 씁니다.

개념 정리

1. aₙ = Sₙ − Sₙ₋₁ 은 n ≥ 2 에서만 — a₁ 은 S₁ 로 따로 구한다

이 문제의 Sₙ 식은 n ≥ 1 에서만 주어진 것이라, aₙ = Sₙ − Sₙ₋₁ 은 n ≥ 2 에서만 쓸 수 있어요. (합 기호의 관례로 S₀ = 0 으로 두기도 하지만, 주어진 식에 n = 0 을 넣은 값 q 가 그 0 과 같다는 보장이 없습니다.) a₁ 은 S₁ 그 자체입니다. Sₙ 에 상수항이 있으면 공식에 n = 1 을 넣은 값과 실제 a₁ 이 어긋납니다.

왜 그럴까

  • Sₙ = a₁ + a₂ + … + aₙ 이므로 S₁ = a₁.
  • Sₙ − Sₙ₋₁ 은 “n번째 항 하나만 남기는” 계산이라 n ≥ 2 에서 뜻이 있습니다.
  • Sₙ 의 상수항 q 가 0이면 두 값이 우연히 맞아떨어집니다.

2. 자주 하는 오해 바로잡기

· “aₙ = Sₙ − Sₙ₋₁ 을 모든 n 에 쓴다” → n = 1 은 따로 확인해야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 누적값에서 그날의 값을 빼낼 때 첫날은 따로 처리해야 하는 것과 같습니다.
Sₙ = n² + pn + q 로 두고 aₙ 공식을 구한 뒤, n=1 대입값과 S₁ 을 비교

예제

Sₙ = n² + 3n + 1일 때 일반항 aₙ을 구하시오.

a₁ = S₁ = 5, n ≥ 2에서 aₙ = Sₙ − Sₙ₋₁ = 2n + 2 (n = 1 대입값 4 ≠ 5). a₁ = 5, aₙ = 2n + 2 (n ≥ 2)

Sₙ = 2ⁿ − 1일 때 일반항 aₙ을 구하시오.

n ≥ 2에서 aₙ = 2ⁿ − 2ⁿ⁻¹ = 2ⁿ⁻¹, a₁ = S₁ = 1 = 2⁰으로 맞으므로 aₙ = 2ⁿ⁻¹ (n ≥ 1)
