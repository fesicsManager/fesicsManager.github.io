삼각방정식 — 해의 개수는 k와 구간이 정한다

k와 구간의 끝을 바꾸며 y = sin x와 가로선 y = k의 교점을 세어 기록했습니다. |k| < 1이면 한 주기에 두 개씩, |k| = 1이면 하나씩 해가 생겼고 구간을 넓히면 해가 계속 늘었으며, |k| > 1이면 해가 없었습니다. sin x = k의 해를 구간과 함께 정하는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 k(×0.1, −1.2~1.2)와 구간 끝(π 단위, π~6π)을 정하고 ‘가로선과의 교점 세기’를 누르면 교점 수와 해, 0~2π에서의 개수가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

sin x의 치역이 [−1, 1]이므로 |k| > 1이면 해가 없고, |k| < 1이면 한 주기(2π)에 두 개, |k| = 1이면 가로선이 스치듯 만나 한 개입니다. sin의 주기가 2π라서 구간을 넓힐수록 해가 계속 늘어납니다(0.5는 0~4π에서 4개). 그래서 삼각방정식의 답은 구간을 정해 쓰거나 일반해로 씁니다. 구간 끝을 포함하면 k = 0에서 0, π, 2π처럼 끝점도 해로 셉니다.

개념 정리

1. sin x = k 는 구간을 넓힐수록 해가 계속 늘어난다

|k| < 1 이면 한 주기(2π)마다 해가 두 개씩 생겨요. 구간을 넓히면 해가 끝없이 늘어나므로, 답은 보통 구간을 정해 쓰거나 일반각 2nπ ± … 꼴로 씁니다. |k| > 1 이면 해가 하나도 없습니다.

왜 그럴까

  • sin의 치역이 [−1, 1] 이라 |k| > 1 이면 가로선이 그래프에 닿지 않습니다.
  • k = ±1 일 때는 한 주기에 해가 하나(접하듯 만남).
  • 문제에 “0 ≤ x < 2π” 같은 구간이 붙는 이유가 이것입니다.
  • k = 1 이나 k = −1 이면 가로선이 스치듯 한 점에서만 만나 한 주기에 해가 하나뿐입니다.

2. 자주 하는 오해 바로잡기

· “해는 하나뿐이다” → 주기함수라서 구간을 넓히면 계속 늘어납니다.

3. 생활 속에서 · 이어지는 개념

  • 진동하는 값이 특정 크기가 되는 시각이 주기적으로 반복되는 것과 같습니다.
k와 구간의 끝을 바꿔 가며 y = k 와 y = sin x 의 교점을 실제로 세어 표시

예제

0 ≤ x < 2π에서 sin x = 1/2을 푸시오.

기준각 π/6과 π − π/6에서 x = π/6, 5π/6

0 ≤ x < 4π에서 sin x = −1/2의 해의 개수를 구하시오.

한 주기에 7π/6, 11π/6 두 개씩, 두 주기이므로 7π/6, 11π/6, 19π/6, 23π/6. 4개
