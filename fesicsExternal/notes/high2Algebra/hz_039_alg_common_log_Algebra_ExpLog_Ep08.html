상용로그 — 정수 부분은 자릿수, 소수 부분은 숫자 배열

가수(1.0~9.9)와 10의 거듭제곱 자리를 바꿔 N을 만들고, log N을 정수 부분과 소수 부분으로 나눠 자릿수와 함께 기록했습니다. 모든 기록에서 정수 부분 + 1이 자릿수였고, 가수가 같으면 소수 부분이 같았습니다. 큰 수의 자릿수와 첫 숫자를 로그로 읽는 방법을 정리합니다.

실험 안내: 자유 탐구 탭에서 가수(×0.1, 1.0~9.9)와 10의 거듭제곱 자리(0~6)를 정하고 ‘자릿수와 맞춰 보기’를 누르면 log N, 정수 부분, 소수 부분, 자릿수가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

N = a × 10ⁿ (1 ≤ a < 10)이면 log N = n + log a이고 0 ≤ log a < 1입니다. 그래서 정수 부분 n + 1 = 자릿수(정수 N일 때)이고, 35와 3500처럼 숫자 배열이 같으면 소수 부분이 같습니다(0.5441). 소수 부분이 클수록 첫 숫자가 커서(990은 0.9956) 소수 부분으로 맨 앞 숫자를 알 수 있습니다.

개념 정리

1. log N 의 정수 부분은 자릿수−1, 소수 부분은 “첫 숫자”를 담는다

N = a × 10ⁿ (1 ≤ a < 10) 이면 log N = n + log a 예요. 정수 부분 n은 10의 몇 제곱 자리인지를, 소수 부분 log a는 맨 앞 숫자들이 무엇인지를 담습니다. 그래서 정수 부분에 1을 더하면 자릿수가 됩니다.

왜 그럴까

  • 0 ≤ log a < 1 이므로 소수 부분은 언제나 a에서 옵니다.
  • 같은 숫자 배열이면 자릿수가 달라도 소수 부분이 같습니다 (35와 3500).
  • 소수 부분이 클수록 첫 숫자가 큽니다 — 순서가 보존됩니다.

움직여 보기

log N을 정수 부분과 소수 부분으로 나눠 보기

log N = 정수 부분 소수 부분 자릿수

위 수직선은 log N, 아래 주황 상자는 보라 점이 들어 있는 한 칸(소수 부분)을 크게 늘린 것입니다. 상자의 눈금 1~9는 log 1, log 2, …, log 9 자리라서 점이 어느 눈금 사이에 있는지로 맨 앞 숫자를 알 수 있어요. 10의 거듭제곱만 바꾸면 소수 부분은 그대로입니다(35와 3500).

2. 자주 하는 오해 바로잡기

· “로그값의 소수 부분은 의미가 없다” → 맨 앞 숫자를 그대로 담고 있습니다.

3. 생활 속에서 · 이어지는 개념

  • 큰 수의 자릿수를 세지 않고 알아내거나, 2¹⁰⁰의 첫 숫자를 구할 때 씁니다.

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

log 2 = 0.3010일 때 2¹⁰⁰은 몇 자리 수인가?

log 2¹⁰⁰ = 100 × 0.3010 = 30.10, 정수 부분 30이므로 31자리

log N = 4.5441일 때 N을 구하시오. (log 3.5 = 0.5441)

N = 10^4 × 10^0.5441 = 3.5 × 10⁴ = 35000
