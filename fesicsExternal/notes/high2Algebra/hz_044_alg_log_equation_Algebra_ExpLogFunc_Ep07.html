고등학교 대수 · 실험 「로그방정식 실험실」

로그방정식 — 구한 근은 진수 조건으로 거른다

log x + log(x − k) = c를 x(x − k) = 10^c로 바꿔 두 근을 구하고, 각 근이 진수 조건을 통과하는지 기록했습니다. 모든 기록에서 두 근 중 음수 근이 걸러져 답은 하나였습니다. 로그를 합치는 과정에서 가짜 근이 생기는 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 k(1~6)와 우변 c(0~3)를 정하고 ‘두 근을 원래 식에 넣기’를 누르면 형식적인 두 근, 진수 조건, 통과한 근, 답의 개수가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 형식적인 근과 진수 조건 (실험 예시)
방정식형식적인 두 근진수 조건통과한 근답의 개수
log x + log(x−3) = 15, −2x > 351
log x + log(x−1) = 01.62, −0.62x > 11.621
log x + log(x−5) = 212.81, −7.81x > 512.811
log x + log(x−4) = 15.74, −1.74x > 45.741
log x + log(x−6) = 06.16, −0.16x > 66.161

이차방정식 x² − kx − 10^c = 0의 두 근은 곱이 −10^c < 0이라 하나는 음수이고, 이 근은 x > 0, x − k > 0을 통과하지 못했습니다. log A + log B = log AB는 A > 0, B > 0일 때만 성립하는데, 합친 식 x(x − k) = 10^c는 두 인수가 모두 음수여도 성립하므로 정의역이 넓어져 가짜 근이 생깁니다. 그래서 로그방정식은 풀고 난 뒤 반드시 진수 조건으로 거릅니다.

개념 정리

1. 로그방정식은 푼 뒤 진수 조건으로 반드시 걸러야 한다

log x + log(x−k) = c 를 합치면 x(x−k) = 10^c 라는 이차방정식이 나와요. 두 근이 나오지만 x > 0 이고 x − k > 0 을 모두 만족해야 원래 식에 넣을 수 있습니다. 음수 근이나 작은 근은 진수 조건에 걸려 답이 아닙니다.

왜 그럴까

  • 로그를 합치는 과정에서 정의역이 넓어져 원래 없던 근이 생깁니다.
  • log A + log B = log(AB) 는 A > 0, B > 0 일 때만 성립합니다.
  • 그래서 “구한 값은 모두 해”가 아니라, 대입해 봐야 합니다.

2. 자주 하는 오해 바로잡기

· “구한 값은 모두 해다” → 진수 조건을 통과한 것만 해입니다.

3. 생활 속에서 · 이어지는 개념

  • 식을 변형하는 과정에서 조건이 넓어지면 가짜 답이 생긴다는 일반 원리의 대표 사례입니다.
k와 c를 바꿔 이차방정식의 두 근을 구하고, 각 근이 진수 조건을 통과하는지 표시

예제

log₂ x + log₂(x − 2) = 3을 푸시오.

x(x − 2) = 8, x² − 2x − 8 = 0, x = 4 또는 −2. 진수 조건 x > 2에서 x = 4

log₃(x + 1) + log₃(x − 1) = 1을 푸시오.

(x + 1)(x − 1) = 3, x² = 4, x = ±2. 진수 조건 x > 1에서 x = 2
