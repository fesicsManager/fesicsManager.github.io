지수함수의 그래프 — 밑이 1보다 작으면 내려간다

밑을 0.1~4.0으로 바꾸며 x = 0, 1, 2, 3에서 y = aˣ의 값을 재어 기록했습니다. a > 1이면 값이 커지고 0 < a < 1이면 작아졌지만, 어느 경우든 f(0) = 1이고 값은 항상 양수였습니다. 밑에 따른 증가·감소와 그래프의 공통점을 정리합니다.

실험 안내: 자유 탐구 탭에서 밑 a(×0.1, 0.1~4.0)를 정하고 ‘x를 키우며 값 재기’를 누르면 f(0)~f(3)과 증가·감소가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

a > 1이면 증가, 0 < a < 1이면 감소했습니다. 모든 행에서 f(0) = 1이었고 값은 0보다 컸습니다. 그래프는 (0, 1)을 지나고 x축이 점근선입니다. (1/2)ˣ = 2^(−x)이므로 y = (1/a)ˣ의 그래프는 y = aˣ를 y축에 대칭시킨 것입니다.

개념 정리

1. 0 < a < 1 이면 감소 — 지수함수가 언제나 늘어나는 것은 아니다

a > 1 이면 곱할수록 커져 오른쪽 위로 가지만, 0 < a < 1 이면 곱할수록 작아져 오른쪽 아래로 내려갑니다. 두 경우 모두 (0, 1)을 지나고 x축을 점근선으로 가진다는 점은 같습니다.

왜 그럴까

  • (1/2)ˣ = 2^(−x) — 밑이 1보다 작은 것은 지수의 부호를 뒤집은 것과 같습니다.
  • 그래서 y = (1/a)ˣ 의 그래프는 y = aˣ 를 y축에 대칭시킨 것입니다.
  • 어느 쪽이든 값은 항상 양수 — 그래프가 x축 아래로 내려가지 않습니다.

2. 자주 하는 오해 바로잡기

· “지수함수는 언제나 증가한다” → 밑이 1보다 작으면 감소합니다.

3. 생활 속에서 · 이어지는 개념

  • 방사성 물질의 감소, 약물 농도의 감소가 모두 0 < a < 1 인 지수함수입니다.
밑을 바꿔 가며 x = 0, 1, 2, 3 에서의 값을 재어 늘어나는지 줄어드는지 판정

예제

y = (1/3)ˣ와 y = 3ˣ의 그래프는 어떤 관계인가?

(1/3)ˣ = 3^(−x)이므로 x 대신 −x를 넣은 것, 곧 y축에 대하여 대칭

부등식 (1/2)ˣ > 1/8을 푸시오.

1/8 = (1/2)³이고 밑 1/2 < 1이라 감소함수이므로 부등호 방향이 바뀌어 x < 3
