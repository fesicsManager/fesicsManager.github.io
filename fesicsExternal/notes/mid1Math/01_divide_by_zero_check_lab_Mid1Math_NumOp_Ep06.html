중학교 1학년 수학 · 웹툰 6화 「0으로는 나눌 수 없다」

0으로 나누기 — 나눗셈은 곱셈으로 거꾸로 확인한다

나누어지는 수 a(6, −3, 0)를 고르고 나누는 수 b를 2에서 0 쪽으로 줄여 가며 몫을 구한 뒤 곱셈으로 확인했습니다. b가 0에 가까워질수록 몫의 크기는 한없이 커졌고, b = 0에서는 □ × 0 = a를 만족하는 수가 없거나(a ≠ 0) 모든 수가 만족해(a = 0) 몫을 정할 수 없었습니다. 나눗셈과 역수, 0으로 나누지 않는 약속을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 나누어지는 수 a(6, −3, 0)를 고르고 나누는 수 b를 −2~2에서 0.5씩 움직인 뒤 나눗셈 확인하기를 누르면 몫과 곱셈 확인이 기록표에 자동으로 쌓입니다. b를 2 → 1 → 0.5 → 0으로 줄여 가며 기록하고, a = 0일 때도 b = 0을 해 보세요. 기록이 4개 이상이면 ✅ 결과 비교 탭에서 b와 몫의 그래프, b = 0일 때의 기록을 볼 수 있습니다.

b를 2 → 1 → 0.5로 줄이자 6 ÷ b는 3 → 6 → 12로 커졌습니다. 0.5로 나누는 것은 역수 2를 곱하는 것과 같기 때문이에요. 그런데 b = 0이 되면 □ × 0 = 6을 만족하는 □가 없어 몫이 없고, 0 ÷ 0은 □ × 0 = 0을 모든 수가 만족해 몫을 하나로 정할 수 없습니다. 그래서 0으로 나누는 것은 생각하지 않기로 약속하고, 0 ÷ b = 0(b ≠ 0)은 그대로 계산합니다.

개념 정리

1. 나눗셈은 곱셈의 거꾸로

a ÷ b = q ⇔ q × b = a. 몫 q는 “b를 곱해서 a가 되는 수”예요. 그리고 a ÷ b = a × (1/b) 처럼 역수를 곱하는 것과 같아요.

  • a ≠ 0, b = 0: q × 0 = a 인 q를 찾아야 하는데, 어떤 수에 0을 곱해도 0이라서 그런 수가 없어요.
  • a = 0, b = 0: q × 0 = 0 은 모든 수가 만족해서 몫을 하나로 정할 수 없어요.
  • 0은 역수도 없어요(0 × □ = 1 인 □가 없음).

그래서 수학에서는 0으로 나누는 것을 생각하지 않기로 약속해요. 반면 0 ÷ b = 0 (b ≠ 0)은 문제없이 계산됩니다.

2. 이 실험의 계산 방법

b를 0.5씩 바꾸며 몫을 기약분수로 구하고, b가 0에 가까워질수록 몫의 절댓값이 한없이 커지는 모습을 그래프로 봐요.

3. 실험 모형과 실제의 차이

· 계산기에서 6 ÷ 0 을 누르면 “Error” 또는 “정의되지 않음”이 나와요. 계산기가 고장 난 것이 아니라 답이 없는 계산이기 때문입니다.

4. 생활 속에서 · 이어지는 개념

  • “6개를 0명에게 똑같이 나누면 한 명이 몇 개?”는 뜻이 없는 질문이에요. 스프레드시트의 #DIV/0! 오류도 같은 까닭입니다.
a ÷ b = q ⇔ q × b = a  ·  a ÷ b = a × (1/b) (b ≠ 0)  ·  0 ÷ b = 0 (b ≠ 0)
🔬 자유 탐구 화면의 판정

“그래서 0으로 나누는 것은 생각하지 않기로 약속해요”

실험 「자유 탐구」 · b = 0으로 확인했을 때

예제

12 ÷ 0.5의 몫을 구하고 곱셈으로 확인하세요.

0.5의 역수는 2이므로 12 ÷ 0.5 = 12 × 2 = 24. 확인: 24 × 0.5 = 12 ✓.

0 ÷ 7과 7 ÷ 0을 각각 곱셈으로 확인하면?

0 ÷ 7: □ × 7 = 0을 만족하는 수는 0 하나 → 0 ÷ 7 = 0. 7 ÷ 0: □ × 0 = 7을 만족하는 수가 없음 → 계산할 수 없다(생각하지 않는다).
