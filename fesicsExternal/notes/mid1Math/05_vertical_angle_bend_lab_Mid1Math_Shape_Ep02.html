맞꼭지각 — 두 직선이 만날 때만 마주 보는 각이 같다

첫 직선의 기울기 t와 두 번째 선이 꺾인 정도 k를 바꾸며 마주 보는 두 각 ∠a, ∠c를 재었습니다. 꺾임이 0°(두 직선)일 때는 언제나 ∠a = ∠c였지만, 선이 꺾이면 ∠a − ∠c가 정확히 k만큼 생겼고 네 각의 합은 늘 360°였습니다. 맞꼭지각의 성질과 그 성질이 성립하는 조건을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 첫 직선의 기울기 t(20°~70°)와 두 번째 선이 꺾인 정도 k(0°~16°)를 정하고 예상을 고른 뒤 각도 재기를 누르면 네 각과 ∠a, ∠c가 기록표에 쌓입니다. 꺾임 0°일 때와 꺾였을 때를 모두 재고 기울기도 바꿔 보세요. 기록이 4개 이상이면 ✅ 결과 비교 탭에서 꺾인 정도와 ∠a − ∠c의 그래프를 볼 수 있습니다.

표 1. 꺾인 정도와 마주 보는 두 각 (실험 예시)
기울기 t꺾임 k∠a∠c∠a − ∠c같음
50°0°50°50°0°예
50°8°50°42°8°아니오
30°4°30°26°4°아니오
70°16°70°54°16°아니오
40°0°40°40°0°예

꺾임이 0°이면 ∠a + ∠b = 180°, ∠b + ∠c = 180°라서 ∠a = ∠c입니다. 두 번째 선이 k° 꺾이면 ∠b = 180° + k° − t°, ∠c = t° − k°가 되어 ∠a − ∠c가 기울기와 관계없이 꺾인 정도 k와 같았습니다. 네 각의 합은 꺾여도 360°이므로, 합이 360°라는 사실만으로는 맞꼭지각이 같다고 할 수 없습니다. ‘마주 보는 모양’이 아니라 ‘두 직선’이라는 조건이 필요합니다.

개념 정리

1. 맞꼭지각은 “두 직선”이 만날 때만 같다

두 직선이 한 점에서 만나면 마주 보는 각을 맞꼭지각이라 하고, 그 크기는 서로 같아요. 까닭은 한 직선이 이루는 각이 180°이기 때문이에요.

∠a + ∠b = 180°, ∠b + ∠c = 180° ⇒ ∠a = ∠c

두 번째 선이 꺾여 직선이 아니면 ∠a + ∠b 가 180°가 아니게 되고, 마주 보는 두 각의 크기는 꺾인 각만큼 차이가 나요. “마주 보는 각”이라는 모양만으로는 같다고 할 수 없어요.

50°0°
∠a ∠b ∠c ∠d ∠a − ∠c 네 각의 합

빨간 선은 곧은 직선, 파란 선은 점 O에서 k°만큼 꺾인 선이에요(회색 점선이 꺾이기 전 직선). k = 0°이면 ∠a = ∠c이지만, 꺾이면 ∠a − ∠c가 정확히 k가 됩니다. 네 각의 합은 언제나 360°예요. 표 1의 t = 50°, k = 8°도 맞춰 보세요.

2. 이 실험의 계산 방법

첫 직선의 기울기를 t°, 꺾인 정도를 k°라 하면 ∠a = t°, ∠b = 180° + k° − t°, ∠c = t° − k°, ∠d = 180° − t° (네 각의 합은 항상 360°).

3. 실험 모형과 실제의 차이

· 그림에서는 꺾임이 작으면 눈으로 구별하기 어려워요. 그래서 “직선인지”는 눈이 아니라 조건(주어진 두 직선)으로 판단해야 해요.

4. 생활 속에서 · 이어지는 개념

  • 가위의 두 날은 곧은 막대라서 벌린 각과 손잡이 쪽 각이 같아요. 날이 휘어 있으면 이 관계가 깨집니다.
∠a + ∠b = 180°, ∠b + ∠c = 180° ⇒ ∠a = ∠c  ·  (실험 모형) ∠a = t, ∠b = 180° + k − t, ∠c = t − k, ∠d = 180° − t

예제

두 직선이 만나 생긴 각 중 하나가 65°일 때 나머지 세 각은?

맞꼭지각은 65°, 이웃한 두 각은 180° − 65° = 115° → 115°, 65°, 115° (맞꼭지각의 성질과 평각 180°를 씀).

실험 모형에서 t = 60°, k = 10°일 때 ∠a, ∠b, ∠c, ∠d는?

∠a = 60°, ∠b = 180° + 10° − 60° = 130°, ∠c = 60° − 10° = 50°, ∠d = 180° − 60° = 120°. 합은 360°이지만 ∠a − ∠c = 10°로 같지 않아요.
