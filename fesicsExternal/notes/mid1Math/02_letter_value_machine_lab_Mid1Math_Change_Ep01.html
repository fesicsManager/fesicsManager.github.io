중학교 1학년 수학 · 웹툰 1화 「문자는 자리를 지킨다」

문자의 사용 — 2a는 2 × a, 생략된 곱셈을 살려 대입한다

식(2a, 3a + 1, ab, 10a + b, 4(a + 1))에 a = 3, 4, 7을 넣고 ‘곱셈으로 읽기’와 ‘숫자를 나란히 붙여 읽기’로 계산해 그림에서 센 개수와 비교했습니다. 곱셈으로 읽은 값은 언제나 그림과 같았고, 나란히 붙여 읽은 값(예: 2a → 23)은 한 번도 맞지 않았습니다. 문자식에서 곱셈 기호를 생략하는 약속과 대입하는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 식, a의 값(3, 4, 7), 읽는 방법(곱셈으로 읽기 / 숫자를 나란히 붙여 읽기)을 고른 뒤 대입하기를 누르면 그림에서 센 개수와 내 값이 기록표에 쌓입니다(b는 5로 고정). 같은 식을 두 방법으로 읽어 보고, 기록이 4개 이상이면 ✅ 결과 비교 탭에서 식별·방법별로 그림과 맞은 횟수를 볼 수 있습니다.

표 1. 두 방법으로 읽은 값과 그림에서 센 개수 (실험 예시, b = 5)
식a방법내 값그림같음
2a3곱셈66O
2a3나란히236X

ab3나란히3515X
10a + b4곱셈4545O
4(a + 1)7나란히4832X

그림에서 센 개수는 언제나 곱셈으로 읽은 값과 같았습니다. 2a는 ‘a개씩 든 봉지 2개’이므로 2a = 2 × a이고, a = 3을 넣으면 23이 아니라 6입니다. ab도 a × b라서 a = 3, b = 5이면 15입니다. 숫자를 나란히 써서 35가 되는 것은 자릿값 때문이므로, ‘십의 자리 숫자 a, 일의 자리 숫자 b인 수’는 10a + b로 써야 합니다.

개념 정리

1. 문자 앞의 수는 “곱하기”가 생략된 것

  • 2a = 2 × a, ab = a × b, 4(a + 1) = 4 × (a + 1)
  • 수와 문자, 문자와 문자 사이의 곱셈 기호 ×는 생략하고, 수를 문자 앞에 써요.
  • 문자에 수를 넣을(대입할) 때는 생략된 × 를 다시 살려야 해요: a = 3이면 2a = 2 × 3 = 6

“십의 자리 숫자가 a, 일의 자리 숫자가 b인 두 자리 수”는 ab가 아니라 10a + b예요. a = 3, b = 5이면 35인데, ab는 3 × 5 = 15가 되니까요. 숫자를 나란히 쓰는 것은 자릿값 때문에 생기는 일이고, 문자를 나란히 쓰는 것은 곱셈이에요.

2. 이 실험의 계산 방법

“곱셈으로 읽기”는 생략된 ×를 살려 계산하고, “나란히 붙여 읽기”는 문자 자리에 숫자를 그대로 붙여 쓴 수로 계산해요. 둘 다 그림에서 센 개수와 비교합니다.

3. 실험 모형과 실제의 차이

· 그림은 식의 뜻 하나를 보여 줄 뿐이에요. 같은 식이 다른 상황(넓이, 가격 등)을 나타낼 수도 있어요.

4. 생활 속에서 · 이어지는 개념

  • “한 개에 a원인 공책 3권의 값”은 3a원이에요. 공책값이 1000원이면 3 × 1000 = 3000원이지, 31000원이 아니지요.
2a = 2 × a  ·  ab = a × b  ·  4(a + 1) = 4 × (a + 1)  ·  두 자리 수(십의 자리 a, 일의 자리 b) = 10a + b

예제

a = 4, b = 5일 때 3a + 2b의 값은?

생략된 ×를 살려 3 × 4 + 2 × 5 = 12 + 10 = 22.

a = −2일 때 5a − 1과 4(a + 1)의 값은?

5 × (−2) − 1 = −11, 4 × (−2 + 1) = 4 × (−1) = −4. 음수를 대입할 때는 괄호를 씌워요.
