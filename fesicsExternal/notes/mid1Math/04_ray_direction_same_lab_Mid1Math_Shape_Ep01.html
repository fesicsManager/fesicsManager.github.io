직선·반직선·선분 — 반직선은 시작점과 방향이 모두 같아야 같다

직선 위의 두 점 A, B로 만든 도형(직선 AB·BA, 반직선 AB·BA, 선분 AB·BA) 두 개를 골라 같은 도형인지 예상하고, 세 점 P₁(A 왼쪽), P₂(A와 B 사이), P₃(B 오른쪽)이 포함되는지 비교했습니다. 직선 AB와 직선 BA, 선분 AB와 선분 BA는 포함하는 점이 모두 같았지만, 반직선 AB와 반직선 BA는 P₁, P₃에서 달랐습니다. 점·선의 종류와 같은 도형의 뜻을 정리합니다.

실험 안내: 도형 1, 도형 2와 나의 예상(같은 도형 / 다른 도형)을 고른 뒤 그려서 비교하기를 누르면 두 도형이 그려지고 P₁, P₂, P₃의 포함 여부와 판정이 기록표에 쌓입니다. 반직선 AB와 반직선 BA, 직선 AB와 직선 BA, 선분 AB와 선분 BA를 모두 비교해 보고, 기록이 4개 이상이면 ✅ 결과 비교 탭에서 비교한 쌍과 예상이 빗나간 쌍을 볼 수 있습니다.

두 도형이 같다는 것은 포함하는 점이 모두 같다는 뜻입니다. 직선과 선분은 이름의 두 글자 순서를 바꿔도 같은 도형이지만, 반직선 AB는 A에서 시작해 B 쪽으로 뻗고 반직선 BA는 B에서 시작해 A 쪽으로 뻗어서 P₃은 반직선 AB에만, P₁은 반직선 BA에만 있습니다. A = 0, B = 1인 수직선으로 보면 반직선 AB는 0 이상, 반직선 BA는 1 이하의 모든 수입니다.

개념 정리

1. 반직선은 “시작점”과 “방향”이 모두 정해진다

  • 직선 AB: 두 점을 지나 양쪽으로 한없이 뻗은 선. 직선 AB = 직선 BA
  • 선분 AB: A에서 B까지의 부분. 선분 AB = 선분 BA
  • 반직선 AB: A에서 시작해 B 쪽으로 한없이 뻗은 선. 반직선 BA는 B에서 시작해 A 쪽으로 뻗어요. 그래서 반직선 AB ≠ 반직선 BA

두 도형이 같다는 것은 포함하는 점이 모두 같다는 뜻이에요. 반직선 AB는 P₃을 포함하지만 반직선 BA는 포함하지 않아요.

A = 0, B = 1인 수직선이에요. 화살표 끝은 한없이 뻗는다는 뜻입니다. 위(파랑)·아래(빨강) 도형이 P₁, P₂, P₃을 똑같이 포함해야 같은 도형이에요. 반직선은 어디서 시작해 어느 쪽으로 뻗는지 재생해서 보세요.

2. 이 실험의 계산 방법

A를 0, B를 1인 수직선 위에 두고, 각 도형을 “어디서부터 어디까지”로 나타내 비교해요. 반직선 AB는 0 이상의 모든 수, 반직선 BA는 1 이하의 모든 수입니다.

3. 실험 모형과 실제의 차이

· 화면에는 끝이 있지만 직선과 반직선은 실제로는 한없이 뻗어요. 그래서 길이를 잴 수 있는 것은 선분뿐이에요.

4. 생활 속에서 · 이어지는 개념

  • 손전등 빛은 반직선처럼 한쪽 끝에서 한 방향으로 뻗어요. 빛을 켠 위치와 방향이 모두 같아야 같은 빛줄기입니다.
직선 AB = 직선 BA  ·  선분 AB = 선분 BA  ·  반직선 AB ≠ 반직선 BA  ·  (A = 0, B = 1) 반직선 AB: x ≥ 0, 반직선 BA: x ≤ 1

예제

한 직선 위에 A, B, C가 차례로 있을 때 반직선 AB와 반직선 AC는 같은가? 반직선 BA와 반직선 BC는?

반직선 AB와 AC는 시작점 A와 방향(오른쪽)이 같으므로 같다. 반직선 BA는 B에서 왼쪽, BC는 B에서 오른쪽으로 뻗어 방향이 반대이므로 다르다.

수직선에서 A = 0, B = 1일 때 반직선 AB와 반직선 BA에 모두 포함되는 점들은 어떤 도형을 이루는가?

x ≥ 0이면서 x ≤ 1인 점, 곧 0 ≤ x ≤ 1 → 선분 AB.
