중1 기술 · 웹툰 4화 「문제를 잘못 잡으면 답도 틀린다」

문제 확인과 정보 수집 — 직접 잰 숫자 하나가 검색 백 번보다 낫다

온도계로 직접 잰 값을 가로(1 = 창가)·세로(1 = 앞) 위치, 시간대, 직사광선 여부와 함께 지도에 찍어 자리별 온도 분포를 기록했습니다. 창가(가로 1~2)와 복도 쪽(가로 5~6)의 차이가 컸고 원인은 오후 직사광선이어서, 문제를 ‘교실이 덥다’가 아니라 ‘5~6교시 창가 자리가 직사광선으로 3 ℃ 더 덥다’로 좁히면 해결책은 선풍기가 아니라 차광이었습니다. 문제 해결 4단계와 확산·수렴 사고를 정리합니다.

‘덥다’는 증상이지 문제가 아닙니다. 문제 확인 → 정보 수집 → 해결 방안 탐색 → 대안 선정의 4단계에서 1단계를 건너뛰면 엉뚱한 답(선풍기)이 나옵니다. 문제를 좁힐수록 답이 선명해지고, 우리 교실 온도는 인터넷에 없으므로 직접 측정이 정보 수집의 핵심입니다.

개념 정리

1. 문제 해결 4단계 — 문제 확인이 먼저

문제 확인 → 정보 수집 → 해결 방안 탐색 → 대안 선정. 뭉치는 ‘더우니까 선풍기’로 1단계를 건너뛰었습니다. ‘어디가 왜 더운가’를 먼저 봐야 하며, 온도계 6개를 곳곳에 놓고 재 보니 창가와 복도 쪽의 차이가 컸고 원인은 오후 직사광선이었습니다. 그럼 답은 선풍기가 아니라 차광입니다.

정보 수집에서 가장 중요한 것

많이·빨리 모으기나 인터넷 검색이 아니라 직접 측정입니다. 우리 교실 온도는 인터넷에 없습니다.

2. 확산적 사고 vs 수렴적 사고

아이디어를 낼 때는 넓게(확산), 고를 때는 좁게(수렴). 두 개를 동시에 하면 아무것도 안 나옵니다 — 내면서 동시에 비판하면 안 됩니다. 브레인스토밍의 첫 규칙: 비판은 나중에. 실습은 3분 안에 아이디어 10개, 그다음 기준 세 개(비용·설치 난이도·효과)로 하나 고르기.

3. 생활 속에서 · 이어지는 개념

‘성적이 안 나온다’도 증상입니다. 어느 과목·어느 단원·어느 시간대인지 재어 보면 문제가 좁혀집니다. 5화에서는 좁힌 문제에 맞는 대안을 기준으로 고르는 법을 봅니다.

문제 확인 → 정보 수집(직접 측정) → 해결 방안 탐색(확산) → 대안 선정(수렴)
