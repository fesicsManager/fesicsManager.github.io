초등 5~6학년 도덕 · 웹툰 7화 「단톡방 말은 우리끼리만 아나」

전달 나무 계산 — 글은 더하기가 아니라 곱하기로 퍼져요

한 사람이 1시간마다 전하는 수, 받은 사람 중 다시 전하는 비율, 지난 시간을 바꿔 글을 받은 사람 수를 계산했습니다. 3명씩 모두 전달하면 5시간 뒤 363명으로, ‘더하기’로 생각한 15명의 20배가 넘었고 8시간이면 약 1만 명이었습니다. 받은 사람이 다시 전할 때 퍼지는 모양을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 한 사람이 1시간마다 전하는 수(2·3·4명), 받은 사람 중 다시 전하는 비율(모두 / 절반 / 열에 하나), 지난 시간(1~8시간)을 고르고 퍼지는 수 계산하기를 누르면 모두 합친 사람 수가 기록표에 자동으로 쌓입니다. 3명 · 모두 전달 · 5시간을 먼저 해 보는 식으로 4개 이상 기록하면 결과 비교 탭이 열립니다.

표 1. 전달 규칙에 따른 퍼짐 (실험 예시, 계산 모형)
전하는 수전달 비율시간모두더하기 생각
3명모두 전달5시간363명15명
2명모두 전달5시간62명10명
4명모두 전달5시간1,364명20명
3명절반만 전달5시간40명15명
3명열에 하나만 전달5시간4명15명
3명모두 전달8시간9,840명24명

3명씩 모두 전달하면 새로 받는 사람이 3 → 9 → 27 → 81 → 243으로 3배씩 늘어, 5시간 뒤 모두 363명이 되었습니다. ‘3명씩 5번’이라는 더하기 생각(15명)과 큰 차이가 나요. 8시간이면 9,840명으로 약 1만 명이고, 전교생 600명(예시)은 약 6시간 뒤에 넘었어요. 전달 비율이 절반이면 40명, 열에 하나면 4명으로 줄었으니 실제로는 더 느릴 수 있지만, 모두가 다시 전하면 퍼지는 모양은 곱하기입니다.

개념 정리

1. 더하기가 아니라 곱하기

한 사람이 1시간마다 3명에게 전하고, 받은 사람도 똑같이 하면:

시간12345
새로 받은 사람392781243

5시간 뒤 모두 = 3 + 9 + 27 + 81 + 243 = 363명 · 8시간이면 약 1만 명

처음 몇 시간은 별것 아닌 것 같다가 갑자기 커져요. 6화 연못과 반대 모양이에요.

2. 지우기는 퍼지기를 못 따라간다

원래 글을 지워도 이미 퍼진 화면 저장본은 지울 수 없어요. 2018년 미국 연구진이 트위터 자료를 분석했더니, 거짓 소식이 사실보다 더 빨리, 더 멀리 퍼지는 경향이 있었어요.

그래서 보내기 전 3초가 지운 뒤 3시간보다 힘이 세요.

3. 실험 모형과 실제의 차이

· "절반만 전달"은 받은 사람 중 절반이 전한다고 둔 평균 계산이에요(소수점은 반올림).

· 실제로는 같은 사람이 여러 번 받기도 해서 정확한 숫자는 달라져요. 퍼지는 모양을 보는 실험이에요.

새로 받은 사람: 3 → 9 → 27 → 81 → 243 (시간마다 3배) · 5시간 뒤 모두 = 3 + 9 + 27 + 81 + 243 = 363명

예제

한 사람이 1시간마다 2명에게 전하고 받은 사람도 모두 똑같이 하면, 4시간 뒤 받은 사람은 모두 몇 명인가요?

새로 받은 사람: 2 → 4 → 8 → 16. 모두 2 + 4 + 8 + 16 = 30명이에요. 30명

3명씩 모두 전달할 때 전교생 600명을 처음 넘는 것은 몇 시간 뒤인가요?

5시간 뒤 363명으로 아직 600명이 안 돼요. 6시간째 새로 받는 사람 729명을 더하면 363 + 729 = 1,092명. 약 6시간 뒤
