고등 한문 ② · 웹툰 5화 「과학은 한문으로 기록할 수 없었나」

과학 기록의 형식 — 항목 하나가 빠지면 비교가 무너진다

가상의 빗물 기록 카드에서 날짜·장소·깊이 단위·같은 규격 그릇을 하나씩 가리고, 해마다·계절 변화, 고을 사이 비교, 비 온 날 세기가 가능한지 확인했습니다. 숫자가 그대로 남아 있어도 그릇 규격이 다르면 고을 사이 비교가 무너졌습니다. 오래 쓰이는 기록이 갖춰야 할 형식을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 가릴 항목(없음·날짜·장소·깊이 단위·같은 규격 그릇)과 하고 싶은 비교(해마다·계절 변화 / 고을 사이 비교 / 비 온 날 세기)를 고른 뒤 ‘이 기록으로 비교하기’를 누릅니다. 비교가 가능하면 막대그래프가, 불가능하면 물음표가 그려지고 까닭이 나옵니다. 카드의 고을·날짜·깊이 값은 설명용 가상 자료입니다. 기록 4개 이상이면 결과 비교 탭에서 가린 항목 × 비교 표를 채워 봅니다.

표 1. 가린 항목과 비교 가능 여부 (실험 예시)
가린 항목비교결과
없음고을 사이 비교○ 가능
날짜고을 사이 비교△ 일부만
장소고을 사이 비교✕ 불가능
깊이 단위고을 사이 비교✕ 불가능
같은 규격 그릇고을 사이 비교✕ 불가능
날짜해마다·계절 변화✕ 불가능

고을 사이 비교는 장소·단위·같은 규격 그릇 가운데 하나만 빠져도 불가능했고, 날짜가 빠지면 해마다·계절 변화를 볼 수 없었습니다. 깊이 단위를 가려도 비 온 날은 셀 수 있었습니다. 표준화된 도구, 고정된 기록 항목(날짜·장소·양·단위), 공용 글말이 갖춰져야 기록이 비교·검증 자료가 됩니다. 측우기로 잰 빗물을 자·치·푼으로 적은 조선의 기록이 지금도 기후 연구 자료로 검토되는 까닭입니다.

개념 정리

1. 형식을 갖춘 기록은 오래 쓰이는 자료가 된다

조선 전기의 공식 기록은 한문이었고, 한문에도 단위와 숫자가 있었습니다. 측우기로 잰 빗물의 깊이는 자(尺)·치(寸)·푼(分)으로 적었고(1자 = 10치, 1치 = 10푼), 날짜는 간지로 정확히 표시했어요.

  • 『농사직설』 세종 11년(1429) — 우리 땅에 맞는 농사법을 농민의 경험에서 모아 정리
  • 측우기 제도 세종 23~24년(1441~1442) — 같은 규격의 그릇으로 빗물을 재어 보고
  • 『동의보감』 1610년 완성, 1613년 간행 — 허준이 편찬, 인용한 책의 이름(출전)을 밝힘. 2009년 유네스코 세계기록유산

2. 비교가 성립하는 조건

표준화된 도구 + 고정된 기록 항목(날짜·장소·양·단위) + 공용 글말 하나라도 빠지면 특정 비교가 무너집니다. 출전 표시는 오늘날 논문의 참고문헌처럼 원래 책과 대조할 수 있게 해 줘요.

3. 실험 모형과 실제의 차이

· 카드의 수치는 가상입니다. 실제 옛 강우 기록은 지금도 기후 연구 자료로 검토됩니다.

· 옛 기록의 해석과 오늘날 과학의 결론은 구분해야 합니다. 옛 의학서의 처방은 그 시대의 지식이고, 지금의 의학적 판단은 의료인과 현대 연구에 따릅니다.

4. 생활 속에서 · 이어지는 개념

  • 실험 보고서에 날짜·조건·단위를 빠뜨리면 다른 사람이 결과를 비교할 수 없습니다. 측우기 기록과 같은 이유예요.
비교가 성립하는 조건 = 표준화된 도구 + 고정된 기록 항목(날짜·장소·양·단위) + 공용 글말 (1자 = 10치, 1치 = 10푼)
닥터 이안 · 제로

“측우기로 잰 빗물은 자(尺)·치(寸)·푼(分)이라는 길이 단위로 깊이를 적었다. 한문에도 단위와 숫자가 있고, 날짜는 간지로 정확히 표시됐다.” “형식만 정해 두면 한문으로도 측정값을 적을 수 있네요.”

웹툰 5화 #2 · 조선 전기의 과학·기술 기록

제로 · 닥터 이안

“같은 규격의 그릇을 나눠 준 게 핵심이네요. 그릇이 다르면 숫자가 있어도 비교가 안 되니까요.” “그렇다. 측정 도구를 표준화하고, 기록 항목을 고정하고, 한문이라는 공용 글말로 적었다.”

웹툰 5화 #4 · 기록 항목 빼기 실험 — 제로 5 : 뭉치 0

예제

어느 고을의 빗물 기록이 ‘5치 4푼’이다. 이를 치 단위의 소수로 나타내면? 이 값을 다른 고을과 비교하려면 무엇이 더 필요한가?

1치 = 10푼이므로 4푼 = 0.4치, 5치 4푼 = 5.4치이다. 다른 고을과 비교하려면 장소와 날짜가 적혀 있고, 두 고을이 같은 규격의 그릇으로 재었어야 한다. 5.4치 · 장소·날짜·같은 규격의 측정 도구가 필요

『동의보감』이 인용한 책의 이름(출전)을 밝혀 둔 것은 오늘날의 무엇과 같은 일을 하는가?
