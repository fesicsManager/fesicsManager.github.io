대학 일반물리 실험 2 · 7주차 · 전류가 만드는 자기장

도선 아래 나침반 — tanθ–I/r 기울기로 지구 자기장 재기

실험에서 남북 방향 직선 도선 아래 r(1~10 cm)에 나침반을 두고 전류 I(0~10 A)를 흘려 바늘이 돌아간 각 θ를 기록했습니다. r = 3 cm에서 1 A는 12.6°, 3 A는 33.9°, 6 A는 53.1°였고, 3 A·6 cm와 1.5 cm·3 A처럼 I/r이 같으면 θ도 같았습니다. tanθ–I/r의 기울기 μ₀/(2πB_E) ≈ 6.67×10⁻³ m/A에서 B_E = 3.0×10⁻⁵ T를 되찾았습니다. 직선 전류의 자기장과 자기장의 합성을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 전류 I(0~10 A)와 도선–나침반 거리 r(1~10 cm) 슬라이더, 전류 방향(남 → 북 / 북 → 남)을 고른 뒤 「전류 흘리기」를 누르면 바늘 각도 θ와 tanθ가 기록표에 자동으로 쌓입니다. 기록이 4개 이상이면 「데이터 검증」 탭에서 tanθ–I/r 그래프(θ ≥ 80°는 맞춤에서 제외)와 B_E 추정값이 열립니다.

θ는 I에 비례하지 않지만(3 A → 33.9°, 6 A → 53.1°) tanθ는 I/r에 정확히 비례합니다. 나침반은 도선의 자기장(서쪽)과 지구 자기장 수평 성분(북쪽)의 합성 방향을 가리키기 때문입니다. 도선 자기장이 B_E와 같아지는 4.5 A·3 cm에서 θ = 45°입니다. θ가 80°를 넘으면 작은 각도 오차에도 tanθ가 크게 변해 맞춤에서 뺍니다.

개념 정리

1. 전류는 자기장을 만든다

비오-사바르 법칙 dB = (μ₀/4π) I dl × r̂ / r²을 무한 직선 도선에 적분하거나, 앙페르 법칙 ∮B·dl = μ₀I을 원형 고리에 쓰면 B = μ₀I / (2πr) (μ₀ = 4π×10⁻⁷ T·m/A)

  • 방향: 오른손 엄지를 전류 방향으로 하면 네 손가락이 감는 방향. 남→북 전류 아래에서는 서쪽.
  • 나침반은 합성 자기장 방향을 가리킴: tanθ = B도선 / BE = (μ₀/2πBE)·(I/r)

2. 두 도선 사이의 힘

나란한 두 도선은 서로의 자기장 속에서 힘을 받습니다: F/L = μ₀I₁I₂/(2πd). 같은 방향 전류는 끌어당기고 반대 방향은 밀어내요. 1 m 떨어진 두 도선에 1 A씩 흐를 때 2×10⁻⁷ N/m — 옛 암페어 정의의 바탕입니다.

3. 실험 모형과 실제의 차이

· 도선이 무한히 길다고 가정했습니다. 실제로는 도선 길이가 r보다 충분히 길어야 하고, 돌아오는 도선은 멀리 둬야 해요.

· θ가 90°에 가까우면 tanθ가 작은 각도 오차에도 크게 변합니다 → 그래프에는 θ < 80°인 점만 씁니다.

· 물질의 자성: 철 같은 강자성체를 가까이 두면 자기장이 크게 왜곡됩니다.

4. 생활 속에서 · 이어지는 개념

  • 외르스테드의 발견(1820), 고압선 아래 자기장 크기 어림, 전류 집게 측정기(클램프 미터)
B = μ₀I/(2πr)  ·  ∮B·dl = μ₀I  ·  dB = (μ₀/4π) I dl × r̂/r²  ·  tanθ = B_도선/B_E = (μ₀/2πB_E)·(I/r)  ·  F/L = μ₀I₁I₂/(2πd)

μ₀ = 4π×10⁻⁷ T·m/A (μ₀/2π = 2×10⁻⁷) · B_E ≈ 3.0×10⁻⁵ T(우리나라 부근 수평 성분) · 기울기 이론값 6.67×10⁻³ m/A

예제

도선에서 3 cm 아래 나침반이 정확히 45° 돌아가려면 전류가 얼마여야 하는가? (B_E = 3.0×10⁻⁵ T)

tan45° = 1 → μ₀I/(2πr) = B_E. I = B_E × 2πr/μ₀ = 3.0×10⁻⁵ × 0.03 ÷ (2×10⁻⁷) = 4.5 A.

어느 학생의 tanθ–I/r 맞춤 기울기가 6.0×10⁻³ m/A였다. 이 학생이 구한 B_E는?

기울기 = μ₀/(2πB_E) → B_E = 2×10⁻⁷ ÷ 6.0×10⁻³ = 3.3×10⁻⁵ T. 가정값 3.0×10⁻⁵ T보다 약 11 % 큽니다 — 근처 철제 물체, 돌아오는 도선, 짧은 도선 등이 원인일 수 있습니다.
