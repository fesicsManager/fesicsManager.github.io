얇은 렌즈의 상 — 1/s_i–1/s_o 직선의 절편이 1/f

실험에서 볼록(f = +10, +20 cm)·오목(f = −15 cm) 렌즈 앞에 물체를 놓고 물체 거리 s_o(4~60 cm)를 바꿔 상 거리 s_i와 배율을 기록했습니다. f = 10 cm 볼록 렌즈에서 s_o = 30, 20, 15 cm는 상 15, 20, 30 cm의 도립 실상이었고, s_o = 5 cm(초점 안)는 s_i = −10 cm인 2배 정립 허상이었습니다. 오목 렌즈는 늘 축소 정립 허상이었습니다. 1/s_i–1/s_o 그래프는 기울기 −1, 절편 1/f인 직선이었습니다. 렌즈 공식과 상의 성질을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 렌즈(볼록 10 cm·볼록 20 cm·오목 −15 cm)를 고르고 물체 거리 s_o 슬라이더(4~60 cm)를 맞춘 뒤 「상 맺기」를 누르면 상 거리 s_i와 상의 성질이 기록표에 자동으로 쌓입니다(물체가 초점 위면 상이 무한히 멀어 측정되지 않음). 한 렌즈에서 초점 바깥 3곳, 안쪽 1곳 이상을 재고, 기록이 4개 이상이면 「데이터 검증」 탭에서 1/s_i–1/s_o 그래프와 맞춤으로 구한 f가 열립니다.

볼록 렌즈는 물체가 2f 밖이면 축소 실상, f와 2f 사이면 확대 실상, f 안쪽이면 확대 정립 허상(돋보기)입니다. 실상·허상 모든 점이 1/s_o + 1/s_i = 1/f 한 식을 따라, 1/s_i = −(1/s_o) + 1/f — 기울기 −1, y절편 1/f인 직선에 놓입니다. 오목 렌즈는 f < 0이라 s_i가 늘 음수인 축소 정립 허상입니다.

개념 정리

1. 얇은 렌즈 공식

1/so + 1/si = 1/f, 배율 m = −si/so (m < 0이면 도립)

  • 볼록 렌즈(f > 0): so > 2f 축소 실상 · f < so < 2f 확대 실상 · so < f 확대 정립 허상(돋보기)
  • 오목 렌즈(f < 0): 언제나 축소 정립 허상
  • 그래프: 1/si = −1·(1/so) + 1/f → 기울기 −1, y절편 1/f

2. 반사와 굴절

렌즈는 굴절(스넬 법칙 n₁sinθ₁ = n₂sinθ₂)로, 구면 거울은 반사로 같은 공식(1/so + 1/si = 1/f, f = R/2)을 따릅니다. 렌즈 제작자 공식 1/f = (n−1)(1/R₁ − 1/R₂).

3. 실험 모형과 실제의 차이

· 실제 렌즈는 구면 수차(가장자리 광선이 더 짧은 곳에 모임)와 색수차(파장마다 n이 다름)가 있습니다.

· 허상은 스크린에 맺히지 않아 실제로는 시차법 등으로 위치를 찾아요.

4. 생활 속에서 · 이어지는 개념

  • 카메라·눈(수정체), 돋보기, 근시 안경(오목), 원시 안경(볼록), 현미경과 망원경(렌즈 두 개의 조합)
1/s_o + 1/s_i = 1/f  ·  m = −s_i/s_o  ·  1/s_i = −(1/s_o) + 1/f  ·  n₁sinθ₁ = n₂sinθ₂  ·  1/f = (n − 1)(1/R₁ − 1/R₂)  ·  구면 거울 f = R/2

부호: 실상 s_i > 0, 허상 s_i < 0, 볼록 f > 0, 오목 f < 0, m < 0이면 도립 · 물체 높이 3 cm

🔬 실험 피드백

“물체가 초점 위에 있으면 렌즈를 지난 광선이 나란하게 나가 상이 무한히 먼 곳에 생겨요.”

실험 자유 탐구 탭 · s_o를 초점 거리와 같게 두었을 때

예제

f = 10 cm 볼록 렌즈로 2배 확대 실상과 2배 확대 허상을 만들려면 물체를 각각 어디에 두어야 하는가?

실상: m = −2 → s_i = 2s_o, 1/s_o + 1/(2s_o) = 1/10 → s_o = 15 cm(s_i = 30 cm). 허상: m = +2 → s_i = −2s_o, 1/s_o − 1/(2s_o) = 1/10 → s_o = 5 cm(s_i = −10 cm). 둘 다 표 1에서 확인됩니다.

어느 렌즈의 1/s_i–1/s_o 맞춤 직선이 기울기 −1.00, y절편 0.050 cm⁻¹이었다. 초점 거리와 렌즈 종류는?

절편 = 1/f → f = 1 ÷ 0.050 = 20 cm, 볼록 렌즈. 오목 렌즈라면 절편이 음수(f = −15 cm이면 −0.0667 cm⁻¹)입니다.
