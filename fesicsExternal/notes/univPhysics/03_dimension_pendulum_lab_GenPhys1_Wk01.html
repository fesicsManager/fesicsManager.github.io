차원 해석으로 찾은 진자 주기 — 지수는 맞히고 상수는 못 맞힌다

실험에서 줄 길이 L(0.1~2.0 m), 추의 질량(50 g·200 g·1 kg), 장소(지구·달·화성)를 바꿔 10회 왕복 시간을 재고 C = T·√(g/L)을 계산했습니다. 길이를 4배로 하면 주기가 2배가 되었고(ln T − ln L 기울기 0.500), 질량을 바꿔도 주기는 그대로였으며, C는 어느 조건에서도 6.28 근처였습니다. 차원 해석이 주는 것(지수 ½·−½·0)과 주지 못하는 것(상수 2π)을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 줄 길이 L 슬라이더, 추의 질량·장소(g) 버튼과 함께 ‘나의 차원 해석 예측’(T ∝ L½, L1, L2)을 고르고 10회 왕복 시간 재기를 누르면 L·질량·장소·T·C가 기록표에 자동으로 쌓입니다. 같은 행성에서 길이를 3가지 이상, 같은 길이에서 질량을 2가지 이상 바꿔 4개 이상 기록하면 ✅ 데이터 검증 탭에 ln T − ln L 그래프와 평균 C가 나옵니다. 측정값은 이론 주기를 0.01 s 단위(10회 시간)로 끊은 값입니다.

L이 0.25 → 1.00 → 2.00 m로 4배·2배가 될 때 T는 2배·√2배가 되어 T ∝ L½이고, 질량을 50 g에서 1 kg으로 바꿔도 T는 2.007 s 그대로였습니다(c = 0). 달에서는 g가 1/6이라 T가 √(9.80/1.62) ≈ 2.46배 길어졌습니다. 그러나 모든 줄에서 C는 약 6.283 = 2π — 이 숫자는 차원 해석이 아니라 운동 방정식이 줍니다. C의 작은 흔들림(6.282~6.286)은 시간을 0.01 s로 끊은 반올림 때문입니다.

개념 정리

1. 식의 양변은 같은 차원이어야 한다

T = C·La·gb·mc 라고 두면 차원은 s = ma·(m/s²)b·kgc 입니다. 길이: a + b = 0, 시간: −2b = 1, 질량: c = 0 → a = ½, b = −½, c = 0.

T = C·√(L/g) — 차원 해석은 C를 알려 주지 못합니다. 운동 방정식을 풀면 작은 진폭에서 C = 2π.

움직여 보기

진자의 주기 — 길이·질량·장소를 바꾸면?

10회 시간 T C = T·√(g/L)

길이를 4배로 하면 주기는 2배(그래프 기울기 ½), 추를 1 kg으로 바꿔도 주기는 그대로, 달에서는 √(9.80/1.62) ≈ 2.46배 길어집니다. 어느 경우든 C는 2π ≈ 6.283 근처 — 표 1과 같은 값입니다. (진폭 10°, 공기 저항 무시)

2. 이 실험의 확인 방법

  • ln T = ½·ln L + 상수 → 로그-로그 그래프의 기울기 = 지수 a.
  • C = T·√(g/L) 을 기록마다 계산해 2π ≈ 6.283 과 비교합니다.
  • 질량을 바꿔도 T가 같으면 c = 0 이 확인됩니다.

3. 벡터와 단위

추에 작용하는 힘(중력, 장력)은 벡터입니다. 복원력은 중력의 접선 성분 mg·sinθ 뿐이고, 이 분해가 운동 방정식에서 C = 2π를 만듭니다.

4. 실험 모형과 실제의 차이

· 진폭이 커지면 주기가 조금 길어집니다(20°에서 약 0.8 %).

· 실제 추는 크기가 있어 물리 진자에 가깝고, 공기 저항도 있습니다.

· g 값: 지구 9.80, 달 1.62, 화성 3.71 m/s² (대략값).

T = C·La·gb·mc → s = ma(m/s²)bkgc → a = ½, b = −½, c = 0  ·  T = C√(L/g), C = 2π (작은 진폭)  ·  ln T = ½ ln L + 상수

[L] = m, [g] = m/s², [m] = kg, [T] = s · g: 지구 9.80, 달 1.62, 화성 3.71 m/s² · L = 1 m 지구에서 T ≈ 2.007 s

예제

지구에서 L = 0.50 m일 때 T = 1.419 s, L = 2.00 m일 때 T = 2.838 s였다. ln T − ln L 그래프의 기울기(지수 a)는?

a = ln(2.838/1.419) ÷ ln(2.00/0.50) = ln 2 ÷ ln 4 = 0.500. 길이 4배에 주기 2배이므로 T ∝ L½, 차원 해석의 예측과 같습니다.

지구에서 L = 1.00 m 진자의 주기가 2.007 s였다. 같은 진자를 달(g = 1.62 m/s²)로 가져가면 주기는? 실험값 4.937 s와 비교하라.

T ∝ g−½이므로 T달 = 2.007 × √(9.80/1.62) = 2.007 × 2.460 ≈ 4.94 s. 실험값 4.937 s와 반올림 범위에서 일치합니다. 상수 C를 몰라도 비율은 차원 해석만으로 구해집니다.
