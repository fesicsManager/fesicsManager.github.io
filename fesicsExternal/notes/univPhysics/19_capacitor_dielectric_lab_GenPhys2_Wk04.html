축전기와 유전체 — 무엇이 고정되었느냐가 에너지를 정한다

실험에서 넓이 100 cm²인 평행판 축전기를 12 V로 충전하고 공기·테플론·종이·유리 유전체를 전지에 연결한 채, 또는 전지를 떼고 끼우며 판 간격 d(0.5~5 mm)를 바꿔 C와 U/U₀를 기록했습니다. 1 mm 공기는 88.5 pF, 종이(κ ≈ 3.7)는 327.6 pF였고 C는 1/d에 비례했습니다. 저장 에너지는 연결 상태에서 κ배(3.7), 분리 상태에서 1/κ배(0.27)로 정반대였습니다. 전기 용량과 두 가지 끼우는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 유전체(공기·테플론·종이·유리)와 끼우는 방법(전지에 연결한 채 / 충전 후 떼고)을 고르고 판 간격 d 슬라이더(0.5~5 mm)를 맞춘 뒤 「유전체 끼우기」를 누르면 C와 U/U₀가 기록표에 자동으로 쌓입니다. 기록이 4개 이상이면 「데이터 검증」 탭에서 재료별 C–1/d 그래프, 기울기로 구한 κ, 방법별 U/U₀ 비교표가 열립니다.

간격을 절반으로 하면 C는 2배 — C–1/d 그래프는 원점을 지나는 직선이고 기울기 = κε₀A(공기 88.5 pF·mm)이므로 기울기의 비가 곧 κ입니다. 전지에 연결한 채 끼우면 V가 고정되어 Q와 U가 κ배로 늘고(전지가 일을 함), 떼고 끼우면 Q가 고정되어 V와 U가 1/κ로 줄어듭니다(줄어든 에너지는 유전체를 끌어당기는 일).

개념 정리

1. 전기 용량은 모양과 사이 물질로만 정해진다

C = κ ε₀ A / d (ε₀ = 8.854×10⁻¹² F/m). 유전체는 편극으로 판 사이 전기장을 1/κ로 줄여, 같은 전하에 필요한 전압을 낮춥니다 → 용량 κ배.

움직여 보기

유전체를 밀어 넣으면 — 전지에 연결했을 때와 떼었을 때

C Q V U/U₀

판 위 +, −는 판의 자유 전하, 유전체 표면의 작은 기호는 편극 전하, 주황 화살표는 전기장입니다. 연결한 채면 V가 12 V로 묶여 전하가 더 들어오고(U 증가), 떼고 넣으면 Q가 묶여 V와 U가 1/κ로 줄어듭니다. (A = 100 cm², 판 가장자리 전기장 번짐 무시, 판 간격은 그림에서 늘려 그림)

2. 두 가지 끼우는 방법

  • 전지 연결 유지(V 고정): Q → κQ₀, U = ½CV² → κU₀. 전지가 추가 전하를 밀어 넣으며 일을 합니다.
  • 전지 분리 후(Q 고정): V → V₀/κ, U = Q²/2C → U₀/κ. 줄어든 에너지는 유전체를 판 사이로 끌어당기는 일이 됩니다.

3. 실험 모형과 실제의 차이

· 실제 판 가장자리에서는 전기장이 휘어 C가 식보다 조금 큽니다(간격이 넓을수록 더).

· 유전체마다 견딜 수 있는 전기장(절연 파괴 세기)이 있어 너무 얇게 만들면 방전됩니다.

· 직렬 연결은 1/C = Σ1/Cᵢ, 병렬 연결은 C = ΣCᵢ — 유전체를 판의 절반만 채우는 경우는 병렬 두 개로 볼 수 있어요.

4. 생활 속에서 · 이어지는 개념

  • 키보드·터치스크린의 정전 용량 센서, 카메라 플래시, 전자 회로의 적층 세라믹 축전기(유전 상수가 큰 세라믹)
C = κε₀A/d  ·  Q = CV, U = ½CV² = Q²/(2C)  ·  V 고정: Q → κQ₀, U → κU₀  ·  Q 고정: V → V₀/κ, U → U₀/κ  ·  병렬 C = ΣCᵢ, 직렬 1/C = Σ1/Cᵢ

ε₀ = 8.854×10⁻¹² F/m · A = 100 cm², d = 1 mm → C₀ = 88.5 pF, Q₀ = 1.06×10⁻⁹ C, U₀ = 6.38×10⁻⁹ J · κ: 테플론 2.1, 종이 3.7, 유리 4.7

예제

1 mm 간격 축전기(C₀ = 88.5 pF)를 12 V로 충전하고 전지를 뗀 뒤 유리(κ = 4.7)를 끼웠다. 전압과 에너지 변화는?

Q 고정 → V = 12 ÷ 4.7 = 2.55 V. U₀ = ½ × 88.5×10⁻¹² × 12² = 6.38×10⁻⁹ J, U = U₀/4.7 = 1.36×10⁻⁹ J. 줄어든 약 5.0×10⁻⁹ J는 유전체를 판 사이로 끌어당기는 일이 되었습니다.

판 사이의 절반(넓이 기준)만 종이(κ = 3.7)로 채우면 C는 C₀의 몇 배인가?

넓이 A/2인 축전기 두 개의 병렬: C = κε₀(A/2)/d + ε₀(A/2)/d = C₀(3.7 + 1)/2 = 2.35배. 1 mm라면 88.5 × 2.35 ≈ 208 pF입니다.
