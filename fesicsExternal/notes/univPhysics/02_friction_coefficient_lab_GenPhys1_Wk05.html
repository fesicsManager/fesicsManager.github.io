마찰계수 측정 — 임계각과 회귀 절편

실험에서 나무–나무, 강철–강철, 얼음–얼음 빗면의 각도를 서서히 올려 물체가 미끄러지기 시작하는 임계각으로 정지 마찰계수 μ_s = tan θ_s를 구하고, 여러 각도에서 0.8 m를 미끄러지는 시간으로 가속도 a = 2L/t²를 재어 a/cosθ = g·tanθ − gμ_k 회귀의 기울기(≈ g)와 절편에서 운동 마찰계수 μ_k = −B/A를 구했습니다. 나무는 θ_s 26.6° → μ_s 0.50, 회귀 절편 −2.94 → μ_k 0.30이었고, 얼음은 5.7° → 0.10, 0.03이었습니다. 각도 읽기 오차 ±0.5°는 μ_s에 ±0.011의 불확도를 주었습니다. 정지·운동 마찰, 선형화 회귀, 상관된 불확도를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

모형: 건조한 깨끗한 표면·상온의 시뮬레이션 기준값(보편적 물성값이 아님). g = 9.80665, L = 0.800 m. a = g(sinθ − μ_k cosθ), t = √(2L/a). 회귀 y = a/cosθ, x = tanθ → y = Ax + B, A ≈ g, B = −gμ_k.

μ_s는 질량과 무관하게 임계각만으로 정해지고, 회귀 기울기 A가 g(9.8)와 맞는지가 측정 타당성의 검사입니다. 어느 재료든 μ_k < μ_s — 정지한 접촉면은 미세 요철이 맞물릴 시간이 있지만 미끄러지는 동안에는 그 결합이 계속 끊어지기 때문입니다.

개념 정리

1. 빗면 위의 힘과 두 마찰계수

경사각 θ의 빗면 위 물체에는 중력의 빗면 성분 mg sinθ와 수직 항력 N = mg cosθ가 작용합니다. 정지 마찰: 미끄러지기 직전(임계각 θ_s)에 최대 정지 마찰력 μ_s N = mg sinθ_s → μ_s = tanθ_s, 질량이 소거되어 각도만으로 정해집니다(물리학 실험의 빗면·마찰과 같은 논리). 운동 마찰: 미끄러지는 동안 a = g(sinθ − μ_k cosθ)이므로 한 각도에서 t를 재면 μ_k = tanθ − 2L/(g t² cosθ)로 바로 나오지만, 여러 각도의 자료를 선형화해 a/cosθ = g tanθ − gμ_k로 놓고 회귀하면 기울기 A = g, 절편 B = −gμ_k → μ_k = −B/A를 얻으며 기울기가 g와 맞는지로 시간 측정·모형의 타당성을 함께 검사할 수 있습니다. 나무 30°에서 μ_k 0.30이면 a = 9.8(0.5 − 0.26) = 2.36 m/s², t = 0.82 s. 얼음은 μ_k 0.03이라 10°에서도 1.4 m/s²로 미끄러집니다.

2. 불확도 — 각도 오차와 상관된 회귀 계수

μ_s = tanθ_s의 불확도는 δμ_s = sec²θ_s · δθ(라디안): 나무 26.6°, ±0.5° → 1.25 × 0.0087 = ±0.011(2 %). 임계각이 클수록(강철 36.5°, sec² 1.55) 같은 각도 오차가 더 큰 μ_s 오차가 됩니다. 회귀 절편으로 구한 μ_k = −B/A의 불확도는 A와 B가 같은 자료에서 나와 상관되어 있으므로 (δμ/μ)² = (σ_B/B)² + (σ_A/A)² − 2cov(A,B)/(AB)처럼 공분산 항을 포함해야 정확합니다 — 각도 범위가 좁거나 점이 적으면 A와 B가 서로 보상하며 크게 흔들려 실험 피드백처럼 ‘각도를 넓게 흩어 더 재세요’가 됩니다. 기울기 A가 9.8에서 몇 % 이상 벗어나면 시간 측정이나 모형(구르기, 기울어짐)에 문제가 있다는 뜻입니다. 실험 01의 무작위·계통 오차 구분이 여기서도 그대로 적용됩니다.

3. 모형과 실제

재료별 계수는 시뮬레이션 기준값이며, 실제 마찰계수는 표면 거칠기·오염·습도·온도·윤활·속도에 따라 크게 달라 같은 ‘나무–나무’도 0.25~0.5로 보고됩니다 — 보편적 문헌값이 아니라 조건이 붙은 값입니다. 쿨롱 마찰 모형(마찰력 ∝ N, 속력 무관)은 근사로, 실제로는 속력·접촉 시간에 따라 조금 변하고 얼음은 표면의 얇은 물막 때문에 온도에 매우 민감합니다. 물체가 구르거나 기울면 식이 달라집니다. 도로의 안전 경사, 타이어–노면 마찰(젖으면 절반 이하), 등산화 고무 배합이 이런 측정에서 나오며, 회귀 절편으로 물리량을 구하는 선형화 기법은 아레니우스 플롯(활성화 에너지)·라인위버–버크(효소 K_m) 등에 두루 쓰입니다.

μ_s = tan θ_s  ·  a = g(sinθ − μ_k cosθ), a = 2L ÷ t²  ·  선형화: a/cosθ = g tanθ − gμ_k → μ_k = −B ÷ A  ·  δμ_s = sec²θ δθ  ·  (δμ_k/μ_k)² = (σ_B/B)² + (σ_A/A)² − 2cov(A,B)/(AB)

나무 μ_s 0.50 (26.6°), μ_k 0.30 · 강철 0.74 (36.5°), 0.57 · 얼음 0.10 (5.7°), 0.03 · L 0.8 m · 나무 30°: a 2.36 m/s², t 0.82 s · ±0.5° → δμ_s ±0.011

실험 데이터 확인 탭 · μ_s vs μ_k, 회귀 기울기 검사

예제

강철 블록이 45° 빗면에서 0.8 m를 0.73 s에 미끄러졌다. μ_k는?

a = 2 × 0.8 ÷ 0.73² = 3.00 m/s². μ_k = tanθ − a/(g cosθ) = 1 − 3.00/(9.807 × 0.707) = 1 − 0.433 = 0.57. 기준값과 일치. 한 점으로도 구할 수 있지만 회귀는 g 검사까지 해 줍니다.

회귀에서 A = 9.5 ± 0.4, B = −3.1 ± 0.3이 나왔다. μ_k와 (공분산을 무시한) 대략의 불확도는? A가 9.8과 맞는가?

μ_k = 3.1/9.5 = 0.33. (δμ/μ)² ≈ (0.3/3.1)² + (0.4/9.5)² = 0.0094 + 0.0018 → δμ/μ = 10.6 % → ±0.03(공분산 항이 음수면 조금 작아짐). A = 9.5 ± 0.4는 9.8과 0.75σ 차이로 타당합니다.
