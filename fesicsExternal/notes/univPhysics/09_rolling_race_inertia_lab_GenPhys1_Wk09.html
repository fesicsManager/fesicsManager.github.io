빗면 구르기 경주 — 가속도는 질량이 아니라 모양 c = I/(mR²)가 정한다

실험에서 고리·속 빈 구·원판·속찬 구를 길이 2 m 빗면에서 미끄러짐 없이 굴리며 빗면 각도(5~30°)와 질량(0.5·2.0 kg)을 바꿔 도달 시간과 가속도 a = 2L/t²를 기록했습니다. 15°에서 속찬 구 1.49 s, 원판 1.54 s, 속 빈 구 1.62 s, 고리 1.78 s 순이었고 질량을 바꿔도 시간은 같았습니다. a − sinθ 기울기 g/(1 + c)로 관성 모멘트 계수를 역산하며 회전의 제2법칙과 회전 운동 에너지를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 구르는 물체 버튼(고리·속 빈 구·원판·속찬 구), 빗면 각도 θ 슬라이더(5~30°, 5° 간격), 질량 버튼(0.5·2.0 kg)을 정하고 굴리기를 누르면 물체·θ·질량·t·a가 자동 기록됩니다(시간은 0.01 s 단위). 결과 칸에는 마찰 없이 미끄러지는 블록의 시간도 비교로 나옵니다. 두 가지 이상의 물체로 각도를 바꿔 4개 이상 기록하면 ✅ 데이터 검증 탭에 물체별 a − sinθ 그래프와 역산 c, 같은 각도의 순위가 나옵니다.

질량을 4배로 바꾼 고리도 같은 1.78 s — 질량·반지름이 아니라 모양 c만 가속도를 정합니다. c가 작을수록(속찬 구) 에너지를 회전에 덜 나눠 주어 빠르고, 미끄러지는 블록(c = 0, 15°에서 1.26 s)이 가장 빠릅니다. 역산 c가 이론값보다 0.004~0.009 큰 것은 시간을 0.01 s로 끊은 반올림 때문입니다.

개념 정리

1. 회전에 대한 뉴턴 제2법칙

τ = Iα, 미끄러짐 없는 구름: v = Rω, a = Rα. 병진: mg sinθ − f = ma, 회전: fR = Iα.

a = g sinθ / (1 + c), c = I/(mR²) — 질량·반지름이 아니라 모양(c)만 가속도를 정합니다.

회전 운동 에너지

K = ½mv² + ½Iω² = ½mv²(1 + c). 같은 높이를 내려오면 c가 클수록 회전에 에너지를 더 나눠 주고 병진 속력이 느립니다. 관성 모멘트는 I = ∫r²dm, 평행축 정리 I = Icm + Md².

2. 구름에서 마찰의 역할

정지 마찰 f = mg sinθ·c/(1+c) 가 돌림힘을 줍니다. 미끄러지지 않으려면 μs ≥ tanθ·c/(1+c). 이 마찰은 일을 하지 않아요(접촉점이 순간 정지).

3. 실험 모형과 실제의 차이

· 구름 저항(변형)과 공기 저항은 무시했습니다. 각도가 크면 실제로는 미끄러질 수 있어요.

mg sinθ − f = ma, fR = Iα, a = Rα  ·  a = g sinθ/(1 + c), c = I/(mR²)  ·  K = ½mv²(1 + c)  ·  미끄러지지 않을 조건 μs ≥ tanθ·c/(1 + c)

c: 고리 1, 속 빈 구 2/3, 원판 1/2, 속찬 구 2/5 · L = 2 m, g = 9.8 m/s² · 병진 에너지 비율 1/(1 + c)

예제

원판(c = ½)을 30° 빗면 2 m에서 굴렸다. 가속도와 도달 시간은?

a = 9.8 × 0.5 ÷ 1.5 ≈ 3.27 m/s², t = √(2 × 2 ÷ 3.267) ≈ 1.11 s. 실험값 1.11 s와 같습니다. 병진 에너지는 전체의 1/1.5 ≈ 67 %입니다.

15° 빗면에서 정체를 모르는 물체의 측정 가속도가 1.802 m/s²였다. c를 구하고 물체를 판정하라.

c = g sinθ/a − 1 = 9.8 × 0.2588 ÷ 1.802 − 1 = 2.536 ÷ 1.802 − 1 ≈ 0.41 → c = 2/5인 속찬 구.
