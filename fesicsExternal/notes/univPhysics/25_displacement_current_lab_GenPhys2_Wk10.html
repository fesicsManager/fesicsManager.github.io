충전 중인 축전기의 자기장 — 변위 전류가 앙페르 법칙을 완성한다

실험에서 반지름 5.0 cm 원판 축전기를 전류 I(0.5~5 A)로 충전하며, 두 판 사이와 도선 옆에서 반지름 r(1~15 cm)인 원을 따라 자기장 B를 기록했습니다. I = 2 A에서 판 사이 B는 r = 1, 2.5, 4 cm에서 1.6, 4.0, 6.4 μT로 r에 비례했고, r ≥ 5 cm에서는 도선 옆과 같이 1/r로 줄었습니다(r = 10 cm에서 둘 다 4.0 μT). 전하가 흐르지 않는 곳의 자기장을 변위 전류 I_d = ε₀dΦ_E/dt로 정리합니다.

실험 데이터 되짚기

실험 안내: 측정 위치(두 판 사이 / 도선 옆)를 고르고 충전 전류 I(0.5~5 A)와 경로 반지름 r(1~15 cm) 슬라이더를 맞춘 뒤 「충전하며 B 재기」를 누르면 B와 B/I가 기록표에 자동으로 쌓입니다. 기록이 4개 이상이면 「데이터 검증」 탭에서 두 위치의 B/I–r 그래프와 같은 r에서의 비교표가 열립니다.

판 사이에는 전하가 흐르지 않는데도 자기장이 있습니다. 판 사이의 전기장이 변하며 생기는 변위 전류 I_d = ε₀dΦ_E/dt가 충전 전류 I와 같기 때문입니다. r < R인 원은 변위 전류의 r²/R²만 감싸 B가 r에 비례하고(B/I = 0.8r μT/A), r ≥ R이면 전부를 감싸 도선 옆과 똑같이 B = μ₀I/(2πr)입니다. r = 2.5 cm에서 두 위치의 B가 4배 다른 까닭도 이것입니다.

개념 정리

1. 맥스웰의 빠진 조각

앙페르 법칙 ∮B·dl = μ₀I만 쓰면, 같은 원을 경계로 하는 곡면을 도선을 뚫게 잡느냐 판 사이를 지나게 잡느냐에 따라 답이 달라지는 모순이 생깁니다. 맥스웰은 변하는 전기장이 전류처럼 작용한다고 보고 항을 더했어요.

∮B·dl = μ₀(I + ε₀ dΦE/dt), 판 사이에서 Id = ε₀ dΦE/dt = I

  • 판 사이, r < R: 원 안의 변위 전류는 I·r²/R² → B = μ₀Ir/(2πR²)
  • r ≥ R: 변위 전류 전부 I → B = μ₀I/(2πr), 도선 옆과 똑같음

2. 맥스웰 방정식과 전자기파

변하는 B가 E를 만들고(패러데이), 변하는 E가 B를 만듭니다(맥스웰-앙페르). 둘이 서로를 만들며 빈 공간을 c = 1/√(μ₀ε₀) ≈ 3.00×10⁸ m/s로 나아가는 것이 전자기파예요.

3. 실험 모형과 실제의 차이

· 실제 실험에서 판 사이 자기장은 마이크로테슬라 수준이라 교류 충전과 민감한 탐지 코일로 잽니다.

· 가장자리에서 전기장이 휘어 r ≈ R 근처 값은 식과 조금 달라요.

4. 생활 속에서 · 이어지는 개념

  • 안테나의 전파 발생, 빛·전파·X선이 모두 같은 방정식의 해라는 통일
∮B·dl = μ₀(I + ε₀dΦ_E/dt)  ·  I_d = ε₀dΦ_E/dt = I  ·  r < R: B = μ₀Ir/(2πR²)  ·  r ≥ R: B = μ₀I/(2πr)  ·  c = 1/√(μ₀ε₀)

μ₀ = 4π×10⁻⁷ T·m/A, ε₀ = 8.854×10⁻¹² F/m · R = 5 cm, I = 2 A → 판 사이 dE/dt = I/(ε₀πR²) = 2.88×10¹³ V/(m·s) · c ≈ 3.00×10⁸ m/s

예제

I = 4 A로 충전할 때 판 사이 r = 2.5 cm에서 B는? 같은 r을 도선 옆에서 재면?

판 사이: B = μ₀Ir/(2πR²) = 2×10⁻⁷ × 4 × 0.025 ÷ 0.05² = 8.0 μT. 도선 옆: B = 2×10⁻⁷ × 4 ÷ 0.025 = 32 μT. 판 사이 원은 변위 전류의 (2.5/5)² = 1/4만 감쌉니다.

I = 2 A일 때 판 사이 전기장의 변화율 dE/dt는? 이것이 만드는 자기장이 일상에서 잘 느껴지지 않는 까닭은?

I = ε₀ (dE/dt) πR² → dE/dt = 2 ÷ (8.854×10⁻¹² × π × 0.05²) = 2.9×10¹³ V/(m·s). 1초에 수십조 V/m씩 변해야 겨우 μT 수준의 자기장이 생깁니다 — μ₀ε₀ = 1/c²이 매우 작기 때문입니다.
