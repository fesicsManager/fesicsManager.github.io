인수정리 — f(k) = 0이면 (x − k)가 인수

두 정수근과 −1을 근으로 갖는 삼차식에 여러 k를 대입하며 f(k)와 조립제법의 나머지를 기록했습니다. 두 값은 언제나 같았고, 나머지가 0이 된 k는 모두 상수항의 약수였습니다. 인수정리와 정수근 후보를 고르는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 근 1, 근 2(−4~4의 정수)로 삼차식 f(x) = (x − 근 1)(x − 근 2)(x + 1)을 만들고, 대입할 k(−6~6)를 정해 ‘후보를 하나씩 대입하기’를 누릅니다. 4개 이상 기록하면 분석이 열립니다.

모든 기록에서 f(k) = 조립제법의 나머지였습니다(나머지정리). 나머지가 0인 k = 1, −2, −1에서만 (x − k)가 인수였고, 이 수들은 모두 상수항 −2의 약수입니다. 정수 계수이고 최고차항 계수가 1인 다항식의 정수근은 상수항의 약수 중에서만 찾으면 됩니다.

개념 정리

1. f(k) = 0 ⟺ f(x)가 (x−k)로 나누어떨어진다

나머지정리에서 (x−k)로 나눈 나머지는 f(k)예요. 나머지가 0이면 나누어떨어지므로 (x−k)가 인수입니다. 정수 계수 다항식에서 정수인 근은 상수항의 약수뿐이라, 아무 수나 넣는 대신 약수만 시험하면 됩니다.

왜 그럴까

  • f(x)=(x−k)Q(x)+R에 x=k를 넣으면 R=f(k).
  • f(x)=(x−a)(x−b)(x−c)를 전개하면 상수항은 −abc — 그래서 정수근은 상수항의 약수.
  • 조립제법은 이 나눗셈을 계수만으로 빠르게 하는 방법입니다.

움직여 보기

k를 대입한 값 f(k) = 조립제법의 나머지

f(k) 조립제법 나머지 (x − k)는

f(x) = (x − 근 1)(x − 근 2)(x + 1)입니다. 빨간 점의 높이 f(k)와 조립제법 맨 끝 칸(나머지)이 늘 같습니다. 그래프가 x축과 만나는 k(초록 점)에서만 나머지가 0이 되어 (x − k)가 인수가 됩니다. 그래프는 높이 −15~45 범위만 보여 줍니다.

2. 자주 하는 오해 바로잡기

· “근은 아무 수나 대입해 찾는다” → 상수항의 약수 몇 개만 시험하면 충분해요.

3. 생활 속에서 · 이어지는 개념

  • 방정식을 풀 때 한 근만 찾으면 차수가 하나 내려가 나머지는 이차방정식으로 풀립니다.
두 정수근으로 삼차식을 만들고, 임의의 k를 대입한 f(k)와 조립제법의 나머지를 나란히 표시
📋 데이터 확인 탭의 결론

“모든 기록에서 f(k) = 조립제법의 나머지입니다. 나눠 보지 않아도 대입만으로 나머지를 알 수 있습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = x³ − 3x² − x + 3을 인수분해하시오.

상수항 3의 약수 ±1, ±3을 시험: f(1) = 1 − 3 − 1 + 3 = 0 → (x − 1)이 인수. 조립제법 몫 x² − 2x − 3 = (x − 3)(x + 1) → (x − 1)(x − 3)(x + 1).

f(x) = x³ + ax² − 4x + 4가 x − 2로 나누어떨어질 때 a의 값은?

f(2) = 8 + 4a − 8 + 4 = 4a + 4 = 0 → a = −1.
