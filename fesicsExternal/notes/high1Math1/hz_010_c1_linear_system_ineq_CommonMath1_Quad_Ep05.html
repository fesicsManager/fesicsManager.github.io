연립일차부등식 — 해는 두 구간의 교집합

① x > p와 ② x < q의 p, q를 바꾸며 수직선에서 겹치는 범위, 합친 범위, 정수해 개수를 기록했습니다. 연립의 해는 두 구간이 겹친 부분뿐이었고, p ≥ q이면 겹치는 곳이 없어 해가 없었습니다. 연립부등식의 해가 교집합인 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 p, q(−8~8)를 정하고 ‘수직선에서 직접 세어 보기’를 누르면 두 부등식, 겹치는 범위, 정수해 개수가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. x > p, x < q의 해 (실험 예시)
부등식 ①부등식 ②겹치는 범위합친 범위정수해 개수
x > −2x < 5−2 < x < 5모든 실수6
x > 0x < 30 < x < 3모든 실수2
x > −5x < −1−5 < x < −1모든 실수3
x > 4x < 4없음x ≠ 40
x > 6x < 2없음x < 2 또는 x > 60

연립은 두 조건을 동시에 만족하라는 뜻이라 해는 겹친 부분(교집합)입니다. p < q이면 두 구간을 합치면 모든 실수가 되어 버려, 한쪽만 만족하는 수까지 들어옵니다. p ≥ q이면 겹치는 곳이 없어 ‘해가 없다’가 정상적인 답입니다(x > 4, x < 4는 x = 4에서도 겹치지 않음).

개념 정리

1. 연립부등식의 해는 두 해집합의 “교집합”

연립은 두 조건을 동시에 만족하라는 뜻이에요. 그래서 수직선에서 두 구간이 겹치는 부분만 해가 됩니다. 각각의 해를 다 합치면(합집합) 한쪽만 만족하는 수까지 들어가 버립니다.

왜 그럴까

  • x가 실제로 두 식에 모두 들어가야 하므로 “그리고” 조건 — 교집합입니다.
  • p ≥ q이면 겹치는 곳이 없어 해가 없습니다.
  • “또는”으로 묶인 문제라면 그때는 합집합이 답입니다 — 문장을 먼저 봐야 합니다.

움직여 보기

x > p 그리고 x < q — 두 구간이 겹치는 곳만 해

연립의 해(겹친 부분) 정수해 합친 부분의 정수(−10~10에서)

파랑 ①과 주황 ②가 둘 다 칠해진 곳(보라)만 연립부등식의 해예요. q를 p보다 작게 만들면 겹치는 곳이 사라져 ‘해가 없다’가 됩니다(예제 2와 같은 상황). 합친 부분은 한쪽만 만족하는 수까지 들어가 훨씬 많아지는 것도 비교해 보세요.

2. 자주 하는 오해 바로잡기

· “각각의 해를 모두 합치면 된다” → 그러면 한쪽만 만족하는 수까지 답이 됩니다.

3. 생활 속에서 · 이어지는 개념

  • “키 160 이상이고 몸무게 50 이하”처럼 조건이 둘 이상 붙는 기준은 모두 교집합입니다.
p와 q를 바꿔 두 구간을 수직선에 칠하고, 겹친 구간과 합친 구간의 정수해를 각각 세어 비교

예제

연립부등식 2x − 1 > 3, x + 4 < 10의 정수해의 개수는?

x > 2, x < 6 → 2 < x < 6 → 정수 3, 4, 5 → 3개.

연립부등식 x + 3 ≤ 1, 3x > 6을 푸시오.

x ≤ −2, x > 2 → 겹치는 부분이 없음 → 해가 없다.
