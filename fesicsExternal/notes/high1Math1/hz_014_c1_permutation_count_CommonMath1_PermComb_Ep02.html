순열 ₙPᵣ — 자리마다 선택지가 하나씩 줄어든다

n명 중 r명을 뽑아 한 줄로 세울 때 자리별 선택 수를 곱한 값, ₙPᵣ, 중복을 허용한 nʳ을 기록했습니다. 자리별 곱은 언제나 ₙPᵣ와 같았고, nʳ은 r이 커질수록 훨씬 컸습니다. 순열의 공식이 ‘하나씩 줄어드는 곱’임을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 전체 n(2~8)과 뽑아 세울 r(1~5, n보다 크면 n으로 맞춤)을 정하고 ‘자리를 하나씩 채우기’를 누르면 자리별 선택 수와 ₙPᵣ, nʳ이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 자리별 곱과 ₙPᵣ, nʳ (실험 예시)
nr자리별 선택 수곱ₙPᵣn^r (중복 허용)

첫 자리는 n가지, 둘째 자리는 이미 쓴 사람을 빼고 n − 1가지…라서 ₙPᵣ = n(n − 1)⋯(n − r + 1) = n!/(n − r)!입니다. r = n이면 n!입니다. 같은 사람을 다시 쓸 수 있으면 자리마다 n가지로 그대로라 nʳ이 되고, 5명 중 5자리이면 120과 3125로 크게 벌어집니다.

개념 정리

1. ₍ₙ₎Pᵣ = n(n−1)(n−2)… — 자리를 채울 때마다 선택지가 하나씩 줄어든다

첫 자리는 n가지, 두 번째는 이미 쓴 하나를 빼고 n−1가지… 이렇게 r개의 자리를 채우면 n(n−1)…(n−r+1)이에요. 같은 사람을 다시 쓸 수 있다면 줄어들지 않아 nʳ이 됩니다. 줄어드는가가 두 식을 가릅니다.

왜 그럴까

  • ₍ₙ₎Pᵣ = n!/(n−r)! — 전체 줄 세우기에서 나머지 자리의 순서를 나눠 없앤 것입니다.
  • r = n이면 n! — 모두 줄 세우기.
  • 조합은 여기서 다시 r!로 나눈 것 — 순서를 따지지 않기 때문입니다.

2. 자주 하는 오해 바로잡기

· “n개에서 r개를 고르는 것은 한 가지 계산이다” → 순서를 따지는지, 중복을 허용하는지에 따라 값이 다릅니다.

3. 생활 속에서 · 이어지는 개념

  • 비밀번호는 중복 허용(nʳ), 달리기 1·2·3등은 순열(ₙPᵣ)입니다.
자리마다 남은 선택지 개수를 표시하며 곱해 가고, ₙPᵣ·nʳ과 나란히 비교
📋 데이터 확인 탭의 결론

“모든 기록에서 두 값이 같았습니다. 공식은 “자리마다 하나씩 줄어든다”를 줄여 쓴 것뿐입니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

7명 중에서 회장, 부회장, 총무를 한 명씩 뽑는 방법의 수는?

자리가 구별되므로 순열: ₇P₃ = 7 × 6 × 5 = 210.

숫자 1~5로 세 자리 비밀번호를 만들 때, 중복을 허용하는 경우와 허용하지 않는 경우의 수는?

중복 허용 5³ = 125, 중복 불허 ₅P₃ = 60 → 125, 60.
