행렬의 상등 — 꼴과 같은 자리의 성분이 모두 같아야

A = (1 2; 3 4)를 고정하고 B의 성분 자리를 바꾸거나 꼴을 바꾸며 ‘꼴이 같나’, ‘대응 성분이 같나’, ‘A = B’를 기록했습니다. 같은 1, 2, 3, 4를 썼어도 자리가 하나만 바뀌면 A ≠ B였고, 꼴이 다르면 비교조차 할 수 없었습니다. 두 행렬이 같을 조건을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 B에서 바꿀 자리(0~3, 0이면 그대로)와 B의 행 수·열 수(1~3)를 정하고 ‘자리를 바꿔 보기’를 누르면 꼴과 성분의 판정이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. A = (1 2; 3 4)와 B의 비교 (실험 예시)
A의 꼴B의 꼴B에 쓰인 수(행별)꼴이 같나대응 성분이 같나A = B
2×22×21,2 / 3,4 (그대로)○○✅
2×22×22,1 / 3,4 (1행 교환)○×❌
2×22×21,2 / 4,3 (2행 교환)○×❌
2×22×24,3 / 2,1 (역순)○×❌
2×23×21,2 / 3,4 / 1,2××❌

행렬은 수를 자리까지 포함해 늘어놓은 것이라, 같은 수를 써도 배치가 다르면 다른 행렬입니다. A = B이려면 ① 꼴(행 수·열 수)이 같고 ② 모든 i, j에서 aᵢⱼ = bᵢⱼ여야 합니다. 그래서 상등 문제는 성분마다 방정식을 하나씩 세워 풉니다.

개념 정리

1. 행렬이 같다 = 꼴이 같고, 같은 자리의 성분이 모두 같다

행렬은 수를 자리까지 포함해 늘어놓은 것이에요. 같은 수 1, 2, 3, 4를 썼더라도 배치가 다르면 다른 행렬입니다. 2×2와 4×1은 성분이 같아도 꼴이 달라 애초에 비교 대상이 아닙니다.

왜 그럴까

  • aᵢⱼ = bᵢⱼ가 모든 i, j에서 성립해야 A = B입니다.
  • 집합과 달리 행렬은 순서와 위치가 의미를 가집니다.
  • 상등을 이용해 미지수를 구하는 문제는 성분별로 방정식을 세우는 것입니다.

2. 자주 하는 오해 바로잡기

· “성분이 같으면 같은 행렬이다” → 자리가 다르면 다른 행렬입니다.

3. 생활 속에서 · 이어지는 개념

  • 이미지의 픽셀 배열도 행렬 — 같은 색을 써도 배치가 다르면 전혀 다른 그림입니다.
A는 고정하고 B의 꼴과 성분 배치를 바꿔 가며, 꼴·성분을 각각 판정해 표시

예제

(x + 1, 2; 3, y) = (4, 2; 3, 2x)일 때 x, y의 값은?

(1, 1) 성분: x + 1 = 4 → x = 3, (2, 2) 성분: y = 2x = 6 → x = 3, y = 6.

1×2 행렬 (a b)와 2×1 행렬 (a; b)는 같은 행렬인가?

성분은 같지만 꼴이 1×2와 2×1로 다르므로 같지 않다.
