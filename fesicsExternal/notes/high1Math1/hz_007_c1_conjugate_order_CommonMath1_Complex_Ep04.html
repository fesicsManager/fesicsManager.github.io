켤레복소수와 절댓값 — 복소수에는 대소가 없다

z = a + bi의 실수부와 허수부를 바꾸며 켤레 z̄, z + z̄, z·z̄, |z|를 기록하고, i > 0과 i < 0을 각각 가정해 보았습니다. z + z̄와 z·z̄는 늘 실수였고 z·z̄ = |z|²이었으며, i의 부호를 어느 쪽으로 가정해도 −1 > 0이라는 모순이 나왔습니다. 켤레의 성질과 복소수의 ‘크기’를 재는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 실수부 a와 허수부 b(−5~5, 0.5 간격)를 정하고 i의 부호 가정(i > 0 또는 i < 0)을 고른 뒤 ‘대소를 가정해 보기’를 누릅니다. 4개 이상 기록하면 분석이 열립니다.

표 1. z와 켤레의 합·곱·절댓값 (실험 예시)
z켤레 z̄z+z̄z·z̄|z|대소 비교
3 + 2i3 − 2i6133.606불가능(−1>0 모순)
1 + 5i1 − 5i2265.099불가능(−1>0 모순)
−2 + 1.5i−2 − 1.5i−46.252.5불가능(−1>0 모순)
4i−4i0164불가능(−1>0 모순)
4 − 3i4 + 3i8255불가능(−1>0 모순)

켤레는 허수부의 부호만 바꾼 수라 z + z̄ = 2a, z·z̄ = a² + b² = |z|²으로 둘 다 실수입니다. 한편 i > 0이면 양변에 i를 곱해 i² > 0, i < 0이면 음수끼리 곱해 i² > 0 — 어느 쪽이든 −1 > 0이 되어 복소수에는 대소 관계를 줄 수 없습니다. 비교는 실수인 절댓값 |z|로 합니다.

개념 정리

1. 복소수에는 크기 순서를 줄 수 없다 — 대신 절댓값(거리)을 쓴다

i>0을 가정하면 양변에 i를 곱해 i²>0, 즉 −1>0이 되어 모순이에요. i<0을 가정해도 음수끼리 곱하면 i²>0이라 또 −1>0. 어느 쪽도 안 되므로 복소수에는 대소 관계가 없습니다. 대신 원점까지의 거리 |z| = √(a²+b²)로 “크기”를 잽니다.

왜 그럴까

  • z+z̄ = 2a (실수), z·z̄ = a²+b² = |z|² (0 이상의 실수) — 켤레와 짝을 지으면 실수가 됩니다.
  • |z|는 실수라서 비교할 수 있지만, |z₁|=|z₂|여도 z₁=z₂는 아닙니다.
  • 실수 계수 방정식의 허근이 항상 켤레로 나오는 것도 이 성질과 이어집니다.

2. 자주 하는 오해 바로잡기

· “복소수도 크기를 비교할 수 있다” → 순서를 주면 반드시 모순이 생깁니다.

3. 생활 속에서 · 이어지는 개념

  • 신호의 세기를 다룰 때 복소수 자체가 아니라 절댓값(진폭)을 비교합니다.
a, b를 바꿔 z와 켤레의 합·곱·절댓값을 계산하고, i의 부호를 가정했을 때 유도되는 결론을 표시
📋 데이터 확인 탭의 결론

“모든 기록에서 z·z̄ = |z|² 이고, z+z̄는 허수부가 사라진 실수였습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

z = 2 − 5i일 때 z + z̄, z·z̄, |z|를 구하시오.

z̄ = 2 + 5i → z + z̄ = 4, z·z̄ = 4 + 25 = 29, |z| = √29 → 4, 29, √29.

3 + 4i와 5i 중 원점에서 더 먼 수는?

|3 + 4i| = √(9 + 16) = 5, |5i| = 5 → 거리는 5로 같다. 절댓값이 같아도 두 수는 서로 다른 수입니다.
