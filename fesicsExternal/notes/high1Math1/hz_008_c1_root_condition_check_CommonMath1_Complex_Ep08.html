근과 답의 구별 — 상황의 조건을 통과해야 답

가로 + 세로 = S, 넓이 = A인 직사각형에서 가로 x가 만족하는 x² − Sx + A = 0의 두 근을 구하고, 조건(길이 > 0, 가로 > 세로, 조건 없음)을 걸어 통과한 근을 기록했습니다. ‘가로 > 세로’ 조건에서는 두 근 중 하나만 남았고, 판별식이 음수면 근이 아예 없었습니다. 방정식의 근을 문제 상황으로 되돌려 검산하는 습관을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 둘레의 절반 S(6~20)와 넓이 A(5~99), 문제의 조건을 고르고 ‘두 근을 조건에 넣어 보기’를 누르면 두 근, 통과한 근, 답의 개수가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. x² − Sx + A = 0의 근과 답 (실험 예시)
상황두 근조건통과한 근답의 개수
둘레/2=12, 넓이=328, 4길이>08, 42
둘레/2=12, 넓이=328, 4가로>세로81
둘레/2=10, 넓이=255, 5가로>세로—0
둘레/2=10, 넓이=30없음길이>0—0
둘레/2=20, 넓이=9911, 9가로>세로111

같은 방정식이라도 조건에 따라 답의 개수가 2, 1, 0으로 달라졌습니다. 이 상황에서는 두 근의 합이 S > 0, 곱이 A > 0이라 두 근이 늘 양수여서 ‘길이 > 0’은 거르지 못하고, ‘가로 > 세로’가 하나를 걸러 냅니다. 정사각형(5, 5)은 가로 > 세로를 만족하지 못하고, D = 100 − 120 < 0이면 그런 직사각형이 없습니다. 근을 구한 뒤 문제 문장으로 되돌아가 확인해야 합니다.

개념 정리

1. 방정식의 해와 문제의 답은 다르다 — 상황의 조건을 통과해야 답

가로+세로 = S, 넓이 = A인 직사각형에서 가로 x는 x² − Sx + A = 0을 만족해요. 두 근이 모두 나오지만, 길이는 양수여야 하고 “가로가 더 길다” 같은 조건이 붙으면 하나만 남습니다. 근을 구한 뒤 반드시 상황에 되돌려 검산해야 합니다.

왜 그럴까

  • 판별식 D = S²−4A < 0이면 그런 직사각형은 아예 없습니다.
  • 두 근의 합은 S, 곱은 A — 근과 계수의 관계로 검산할 수 있습니다.
  • 물건의 개수, 시간, 길이는 모두 “양수”·“정수” 같은 숨은 조건을 가집니다.

움직여 보기

방정식의 근 → 문제의 조건 통과 → 답

두 근 통과한 근 답의 개수

가로 + 세로 = S이면 넓이는 x(S − x)이고, 넓이가 A인 곳(빨간 선과 만나는 점)이 x² − Sx + A = 0의 근입니다. 초록 점은 조건을 통과한 근, 회색 ✕는 걸러진 근입니다. 빨간 선이 곡선 꼭대기보다 높으면(D < 0) 근이 없습니다.

2. 자주 하는 오해 바로잡기

· “조건을 만족하는 근이면 다 답이다” → 방정식의 조건이 아니라 문제 상황의 조건까지 봐야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 시간·속력·인원처럼 음수가 될 수 없는 양을 구할 때마다 이 검산이 필요합니다.
S와 A로 이차방정식을 세워 두 근을 구하고, 선택한 조건을 통과하는 근만 남겨 개수를 표시

예제

둘레가 30, 넓이가 56인 직사각형에서 가로가 세로보다 길 때 가로의 길이는?

x + y = 15, xy = 56 → x² − 15x + 56 = 0 → x = 8 또는 7. 가로 > 세로이면 가로 8 (세로 7).

연속하는 두 자연수의 곱이 12일 때 작은 수는?

x(x + 1) = 12 → x² + x − 12 = 0 → x = 3 또는 −4. 자연수 조건으로 −4를 버림 → 3.
