이차부등식이 항상 성립할 조건 — a > 0이고 D < 0

a, b, c를 바꾸며 y = ax² + bx + c를 모든 x에서 확인하고, 판별식 D와 최솟값, ‘모든 x에서 > 0’ 여부를 기록했습니다. a > 0이고 D < 0일 때만 최솟값이 양수라 항상 성립했고, D = 0이면 최솟값이 0이라 실패했습니다. 같은 D < 0이 ‘항상 성립’과 ‘해가 없다’로 읽히는 까닭을 정리합니다.

최솟값은 꼭짓점의 y좌표 −D/(4a)입니다. a > 0, D < 0이면 이 값이 양수라 모든 실수 x에서 ax² + bx + c > 0입니다. D = 0이면 최솟값이 0이라 ‘> 0’은 깨지고, a < 0이면 위로 볼록이라 최솟값이 없습니다. 같은 조건 a > 0, D < 0에서 ax² + bx + c < 0은 해가 없습니다 — 어느 부등식을 보느냐의 차이입니다.

개념 정리

1. “항상 성립”은 D < 0, “해가 없다”도 D < 0 — 어느 부등식인지가 다르다

ax²+bx+c > 0이 모든 실수에서 성립하려면 a > 0이고 D < 0이어야 해요. 같은 D < 0이지만, ax²+bx+c < 0의 해가 없는 조건이기도 합니다. 같은 식을 어느 쪽에서 보느냐의 차이입니다.

왜 그럴까

  • a>0, D<0이면 그래프가 x축 위에 통째로 떠 있어 어떤 x를 넣어도 양수입니다.
  • 꼭짓점의 y좌표 −D/(4a)가 최솟값이고, 이것이 0보다 크면 항상 양수.
  • a=0이면 이차식이 아니므로 일차식으로 따로 판단해야 합니다.

움직여 보기

y = x² − 2kx + 9 — k에 따라 최솟값과 해가 어떻게 바뀔까

식 D/4 = k² − 9 최솟값 9 − k²

초록으로 칠한 x가 부등식의 해예요. 꼭짓점(최솟값)이 x축 위에 있으면(D/4 < 0) ‘> 0’은 모든 실수에서 성립하고, 같은 때 ‘< 0’은 해가 없습니다. k가 −3과 3 사이일 때만 그렇다는 것을 아래 띠에서 확인하세요(예제 1: −3 < k < 3).

2. 자주 하는 오해 바로잡기

· “D < 0이면 해가 없다” → 어떤 부등식인지에 따라 “항상 성립”이 되기도 합니다.

예제

모든 실수 x에 대해 x² − 2kx + 9 > 0이 성립하도록 하는 k의 범위는?

a = 1 > 0이므로 D/4 = k² − 9 < 0 → −3 < k < 3.

x² + 4x + 5 < 0의 해는?

D = 16 − 20 = −4 < 0, a > 0 → x² + 4x + 5는 항상 양수(최솟값 1) → 해가 없다.
