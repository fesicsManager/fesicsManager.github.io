영인자 — AB = O여도 A, B가 O가 아닐 수 있다

A = (a b; a b), B = (c d; −c −d)의 성분을 바꾸며 AB를 계산하고, A = O, B = O, AB = O인지를 기록했습니다. a = b이면 c, d와 관계없이 AB = O였고, A와 B가 모두 영행렬이 아닌데도 곱이 영행렬인 경우가 여러 번 나왔습니다. 실수와 다른 행렬 곱셈의 성질과 주의할 점을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 A의 (1,1)·(1,2) 성분 a, b와 B의 (1,1)·(1,2) 성분 c, d(−3~3)를 정하고 ‘곱이 O가 되는 짝 찾기’를 누릅니다. A의 두 행은 같고, B의 2행은 1행의 부호를 바꾼 것입니다. 4개 이상 기록하면 분석이 열립니다.

AB의 성분은 (a − b)c, (a − b)d뿐이라 a = b이면 c, d가 무엇이든 AB = O입니다. 첫째·셋째 줄은 A ≠ O, B ≠ O인데 AB = O — 실수에서는 불가능한 영인자입니다. 그래서 AB = O에서 ‘A = O 또는 B = O’를 결론지을 수 없고, AB = AC에서 B = C도 바로 말할 수 없습니다. A가 역행렬을 가지면 이런 일이 생기지 않습니다.

개념 정리

1. 행렬에서는 AB = O 여도 A, B가 O일 필요가 없다

실수에서는 ab = 0이면 a = 0이거나 b = 0이에요(영인자가 없음). 행렬에서는 다릅니다 — 영이 아닌 두 행렬의 곱이 영행렬이 될 수 있습니다. 그래서 행렬 방정식에서 양변을 “나누는” 소거가 안 됩니다.

왜 그럴까

  • A의 행벡터와 B의 열벡터가 수직이면 그 성분이 0이 됩니다.
  • 이 실험의 A, B 에서는 AB 의 네 성분이 모두 (a − b)c, (a − b)d 이므로 a = b 이면 c, d 가 무엇이든 AB = O 입니다.
  • AB=O이고 A가 역행렬을 가지면 B=O — 역행렬이 없을 때만 이런 일이 생깁니다.
  • A²=O인데 A≠O인 행렬도 있습니다(멱영행렬).

움직여 보기

A ≠ O, B ≠ O인데 AB = O — 행과 열이 수직이면

a − b AB 판정

A = (a b; a b), B = (c d; −c −d)로 실험과 같은 꼴입니다(시작 값은 예제의 A = (1 1; 1 1), B = (1 −1; −1 1)). AB의 성분은 A의 행 (a, b)와 B의 열 (c, −c), (d, −d)를 곱해 더한 (a − b)c, (a − b)d예요. B의 열은 늘 회색 점선 위에 있으니, b = a가 되어 빨간 화살표가 점선과 수직이 되는 순간 AB = O가 되는지 확인해 보세요.

2. 자주 하는 오해 바로잡기

· “AB = O이면 A = O이거나 B = O이다” → 실수의 성질을 그대로 옮긴 오해입니다.

3. 생활 속에서 · 이어지는 개념

  • 연립방정식이 “해가 무수히 많다”가 되는 상황이 바로 이런 행렬에서 일어납니다.
A, B의 성분을 바꿔 곱을 계산하고, 영행렬이 되는 순간 A와 B가 영행렬인지 함께 판정

예제

A = (1 1; 1 1), B = (1 −1; −1 1)일 때 AB를 구하시오.

(1,1) 1 − 1 = 0, (1,2) −1 + 1 = 0, 2행도 같음 → AB = O. A ≠ O, B ≠ O입니다.

A = (0 1; 0 0)일 때 A²을 구하시오.

(1,1) 0·0 + 1·0 = 0, (1,2) 0·1 + 1·0 = 0, 2행은 모두 0 → A² = O (A ≠ O).
