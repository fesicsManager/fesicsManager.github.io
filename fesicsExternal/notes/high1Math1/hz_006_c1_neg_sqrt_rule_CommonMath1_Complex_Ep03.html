음수의 제곱근 — 먼저 i로 바꾼 뒤 곱한다

a, b의 부호를 바꾸며 √a × √b를 ‘i로 바꿔 곱하기’와 ‘근호 안을 먼저 곱하기’로 각각 계산해 기록했습니다. a와 b가 모두 음수일 때만 두 값의 부호가 반대였고, 나머지 경우에는 같았습니다. √a√b = √(ab)가 성립하는 조건과 안전한 계산 순서를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 a, b(−9~9, 음수 가능)를 정하고 ‘두 방법으로 계산하기’를 누르면 두 계산 결과와 일치 여부가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

√(−2)·√(−3) = (√2 i)(√3 i) = √6·i² = −√6 ≈ −2.449입니다. 근호 안을 먼저 곱하면 i × i = −1이 사라져 부호가 뒤집힙니다. √a√b = √(ab)는 a, b가 둘 다 음수일 때만 깨지므로, 음수의 제곱근은 먼저 i로 바꾼다는 순서를 지키면 됩니다.

개념 정리

1. √a·√b = √(ab)는 a, b가 모두 0 이상일 때만 성립

√(−2)·√(−3) = (√2 i)(√3 i) = √6 i² = −√6 이에요. 근호 안을 먼저 곱해 √6이라고 하면 부호가 반대가 됩니다. 음수의 제곱근은 반드시 i로 바꾼 다음 계산해야 합니다.

왜 그럴까

  • √a·√b=√(ab)는 실수 범위에서 증명된 성질이라, 근호 안이 음수로 넘어가면 보장되지 않습니다.
  • 두 수가 모두 음수일 때만 어긋납니다 — 하나만 음수면 결과가 같아요.
  • √(a/b) = √a/√b 도 같은 조건이 붙습니다(b<0일 때 주의).

움직여 보기

√a·√b와 √(ab) — 둘 다 음수이면 왜 부호가 뒤집힐까

방법 1 방법 2 같나?

화살표의 방향만 보세요(길이는 그림에 맞춰 줄였습니다). 양수의 제곱근은 오른쪽(0°), 음수의 제곱근은 위쪽(90°, i 방향)입니다. 곱하면 방향이 더해져 90° + 90° = 180°, 즉 음수가 됩니다. 근호 안을 먼저 곱하면 이 회전이 사라져 부호가 반대로 나옵니다.

2. 자주 하는 오해 바로잡기

· “√(−2)×√(−3) = √6” → 둘 다 음수일 때는 부호가 뒤집혀 −√6입니다.

3. 생활 속에서 · 이어지는 개념

  • 부호 하나 때문에 답이 정반대가 되는 대표적인 자리라, 시험에서 자주 함정으로 나옵니다.
a, b의 부호를 바꿔 가며 i로 바꿔 곱한 값과 근호 안을 곱한 값을 각각 계산해 표시
📋 데이터 확인 탭의 결론

“a와 b가 모두 음수일 때만 두 값이 달라졌습니다. 나머지 경우에는 규칙이 그대로 성립합니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

√(−4) × √(−9)의 값은?

2i × 3i = 6i² = −6. (√36 = 6으로 하면 틀림)

√12 ÷ √(−3)의 값은?

√(−3) = √3 i → √12 / (√3 i) = 2/i = 2·(−i) = −2i. 근호 안을 먼저 나누면 √(−4) = 2i가 되어 부호가 반대입니다.
