(a + b + c)² — 제곱항 셋과 교차항 2(ab + bc + ca)

a, b, c를 바꾸며 한 변이 a + b + c인 정사각형을 9조각으로 잘라 넓이를 더하고, a² + b² + c²와 비교해 기록했습니다. 두 값의 차이는 언제나 주황색 6조각의 넓이 2(ab + bc + ca)였습니다. 세 항의 합의 제곱 공식이 조각 수로 어떻게 설명되는지 정리합니다.

모든 기록에서 (a + b + c)² − (a² + b² + c²) = 2(ab + bc + ca)였습니다. 대각선 3조각이 제곱항, 나머지 6조각이 ab, bc, ca가 두 개씩인 교차항입니다. a = b = c = 6이면 교차항이 216으로 전체 324의 3분의 2나 되어, 교차항을 빼먹으면 크게 틀립니다.

개념 정리

1. (a+b+c)² = a²+b²+c² + 2(ab+bc+ca) — 교차항이 세 쌍, 각각 두 번

한 변이 a+b+c인 정사각형을 가로·세로로 각각 a, b, c로 자르면 9조각이 생겨요. 대각선의 3조각이 a², b², c²이고 나머지 6조각이 ab, bc, ca가 각각 2개씩입니다. 그래서 2(ab+bc+ca)가 붙습니다.

왜 그럴까

  • 항이 2개면 조각은 4개(2×2), 3개면 9개(3×3), n개면 n²개입니다.
  • 대각선 위 n개가 제곱항, 나머지 n²−n개가 교차항이고 대칭이라 2씩 묶입니다.
  • a+b+c=0이면 a²+b²+c² = −2(ab+bc+ca)라는 자주 쓰는 관계가 여기서 나옵니다.

2. 자주 하는 오해 바로잡기

· “(a+b+c)² = a²+b²+c²” → 6조각을 통째로 빼먹은 값이에요.

3. 생활 속에서 · 이어지는 개념

  • 세 사람의 몫을 합쳐 제곱하는 계산, 분산 공식의 전개 등 교차항이 실제로 값을 좌우합니다.
a, b, c를 바꿔 (a+b+c)²를 직접 계산하고, 9조각의 넓이를 하나씩 더해 어느 항이 빠졌는지 확인
📋 데이터 확인 탭의 결론

“모든 기록에서 차이 = 2(ab+bc+ca) 였습니다. 빠진 것은 주황색 6조각입니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

a + b + c = 7, ab + bc + ca = 12일 때 a² + b² + c²의 값은?

a² + b² + c² = (a + b + c)² − 2(ab + bc + ca) = 49 − 24 = 25.

(x + 2y − 1)²을 전개하시오.

제곱항 x² + 4y² + 1, 교차항 2(x·2y + 2y·(−1) + (−1)·x) = 4xy − 4y − 2x → x² + 4y² + 4xy − 2x − 4y + 1.
