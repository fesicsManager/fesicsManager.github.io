연립이차방정식의 해 — 해는 두 식을 모두 만족하는 짝

x + y = s, xy = s + 1에서 t² − st + (s + 1) = 0의 두 근 r₁, r₂로 네 가지 짝 (r₁, r₂), (r₂, r₁), (r₁, r₁), (r₂, r₂)를 만들어 두 식에 대입해 기록했습니다. 순서만 바꾼 두 짝은 모두 해였고, 같은 근을 두 번 쓴 짝은 두 식이 함께 어긋났습니다. 연립방정식의 해가 순서쌍이며 반드시 두 식에 모두 넣어 검산해야 함을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 x + y의 값 s(2~8, xy = s + 1로 정해짐)와 살펴볼 짝(1~4)을 정하고 ‘짝을 지어 검산하기’를 누릅니다. s가 4 이하이면 판별식이 음수라 실수해가 없어 기록되지 않습니다. 4개 이상 기록하면 분석이 열립니다.

표 1. x + y = s, xy = s + 1의 후보 짝 검산 (실험 예시)
후보 (x, y)식 ① 만족식 ② 만족해인가짝이 맞나
(3, 2)✅✅✅맞음
(2, 3)✅✅✅맞음
(3, 3)❌❌❌어긋남
(2, 2)❌❌❌어긋남
(4.41, 1.59)✅✅✅맞음

s = 5이면 xy = 6이고 두 근은 3, 2입니다. x + y와 xy는 x, y를 바꿔도 같은 대칭식이라 (3, 2)와 (2, 3)이 모두 해입니다. 반면 (3, 3)은 합 6, 곱 9로 두 식이 함께 어긋났습니다. s = 6이면 두 근은 3 ± √2(약 4.41, 1.59)입니다. 해는 x와 y가 따로 있는 것이 아니라 순서쌍이므로 두 식 모두에 넣어 확인합니다.

개념 정리

1. 연립방정식의 해는 “짝”이다 — 두 식 모두에 넣어 검산해야 한다

x+y = s, xy = p 는 x 와 y 를 서로 바꿔도 똑같은 식(대칭식)이라, 두 근 r₁, r₂ 에 대해 (r₁, r₂) 와 (r₂, r₁) 이 둘 다 해입니다. 하지만 근 하나를 두 번 쓴 (r₁, r₁) 처럼 아무렇게나 짝지으면 두 식이 모두 어긋나지요. 짝을 지었으면 반드시 두 식에 모두 넣어 확인해야 합니다.

왜 그럴까

  • 해는 순서쌍 (x, y) 이지 x 와 y 가 따로 있는 것이 아닙니다.
  • 대입법에서 한 문자를 없앤 뒤 나머지를 구할 때 짝이 자동으로 정해집니다.
  • 합·곱은 대칭식이라 (r₁, r₂) 와 (r₂, r₁) 이 모두 해입니다. 해가 되는 짝은 이 두 가지뿐이고, 나머지 짝은 두 식이 함께 어긋납니다.

움직여 보기

해는 짝 (x, y) — 두 그래프가 만나는 점

후보 짝
두 근 r₁, r₂ 후보 해인가

r₁, r₂는 t² − st + p = 0의 두 근이에요. 실험처럼 p = s + 1로 두면 s = 5일 때 (3, 2)·(2, 3), s = 6일 때 (4.41, 1.59)가 해입니다. 보라 점(후보)이 초록 점(직선과 곡선이 만나는 곳)에 올라야 두 식을 모두 만족하는 해예요. 같은 근을 두 번 쓴 (r₁, r₁)은 두 식이 함께 어긋나는지 확인하세요.

2. 자주 하는 오해 바로잡기

· “구한 값을 아무렇게나 짝지어도 된다” → 같은 근을 두 번 쓰면 두 식이 함께 깨집니다.

· “순서를 바꾸면 틀린다” → 합·곱처럼 대칭인 식에서는 순서를 바꾼 짝도 해입니다.

3. 생활 속에서 · 이어지는 개념

  • 두 조건을 동시에 만족해야 하는 답은 언제나 짝으로 확인합니다.
네 가지 (x, y) 후보를 두 식에 각각 대입해, 둘 다 만족하는 짝만 골라냄

예제

연립방정식 x + y = 7, xy = 12를 푸시오.

x, y는 t² − 7t + 12 = 0의 두 근 3, 4 → (x, y) = (3, 4), (4, 3).

연립방정식 x − y = 1, x² + y² = 13을 푸시오.

y = x − 1을 대입: x² + (x − 1)² = 13 → x² − x − 6 = 0 → x = 3 또는 −2, 이때 y = 2 또는 −3 → (3, 2), (−2, −3). 대입법은 짝이 자동으로 정해집니다.
