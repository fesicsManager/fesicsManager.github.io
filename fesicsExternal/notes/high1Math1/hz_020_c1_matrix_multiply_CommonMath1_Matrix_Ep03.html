고등학교 공통수학1 · 실험 「곱셈 실험실」

행렬의 곱셈 — i행과 j열을 맞물려 곱해 더한다

A = (a b; 2 1), B = (c 3; d 1)의 성분과 계산할 자리를 바꾸며 AB의 한 성분이 어느 행과 어느 열로 계산되는지 따라가고, 같은 자리끼리 곱한 행렬과 비교해 기록했습니다. 행 × 열로 구한 AB는 같은 자리끼리 곱한 행렬과 매번 달랐습니다. 행렬의 곱의 정의와 곱할 수 있는 조건을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 A의 (1,1)·(1,2) 성분, B의 (1,1)·(2,1) 성분(−3~5)과 계산할 성분(1~4)을 정하고 ‘행과 열을 맞춰 곱하기’를 누르면 고른 성분의 계산식, AB, 같은 자리끼리 곱한 행렬이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 행 × 열의 곱과 같은 자리끼리의 곱 (행은 / 로 구분, 실험 예시)
AB고른 성분 계산올바른 AB같은 자리끼리 곱같나
1,2 / 2,13,3 / 4,1(1,1): 1×3+2×4 = 1111,5 / 10,73,6 / 8,1❌
1,2 / 2,13,3 / 4,1(1,2): 1×3+2×1 = 511,5 / 10,73,6 / 8,1❌
2,−1 / 2,10,3 / 3,1(2,1): 2×0+1×3 = 3−3,5 / 3,70,−3 / 6,1❌
3,1 / 2,12,3 / 5,1(2,2): 2×3+1×1 = 711,10 / 9,76,3 / 10,1❌
0,0 / 2,11,3 / 1,1(1,1): 0×1+0×1 = 00,0 / 3,70,0 / 2,1❌

AB의 (i, j) 성분은 A의 i행과 B의 j열의 성분을 차례로 곱해 더한 값 aᵢ₁b₁ⱼ + aᵢ₂b₂ⱼ입니다. 같은 자리끼리 곱한 행렬은 더하는 단계가 없어 전혀 다른 행렬이었습니다. 가로줄과 세로줄이 맞물려야 하므로 A의 열 수 = B의 행 수일 때만 곱할 수 있습니다.

개념 정리

1. AB의 (i, j) 성분 = A의 i행과 B의 j열을 “맞물려” 곱해 더한 값

행렬의 곱은 같은 자리끼리 곱하는 것이 아니라, A의 가로줄과 B의 세로줄을 하나씩 짝지어 곱해 모두 더해요. 그래서 A의 열 수와 B의 행 수가 맞아야 계산이 됩니다.

왜 그럴까

  • (AB)ᵢⱼ = Σₖ aᵢₖ bₖⱼ — k가 A의 열이자 B의 행입니다.
  • 같은 자리끼리 곱하는 연산도 있지만(아다마르 곱) 그것은 행렬의 곱이 아닙니다.
  • 이 정의 때문에 AB와 BA가 달라지고, 결합법칙은 성립합니다.

움직여 보기

AB의 한 성분 = A의 가로줄 × B의 세로줄

성분 고르기
고른 성분 AB (4 6; 10 12)같은 자리끼리 곱 (2 0; 3 12) → 다름

예제의 A = (1 2; 3 4), B = (2 0; 1 3)입니다. 성분을 바꿔 가며 빨강(A의 i행)과 파랑(B의 j열)이 한 칸씩 짝지어 곱해진 뒤 더해지는 것을 확인하세요. 같은 자리끼리 곱한 (2 0; 3 12)는 행렬의 곱이 아닙니다.

2. 자주 하는 오해 바로잡기

· “같은 자리 성분끼리 곱한다” → 그러면 연립방정식·변환을 나타내는 행렬의 뜻이 사라집니다.

3. 생활 속에서 · 이어지는 개념

  • 좌표 변환, 회전, 그래프의 연결 관계 계산이 모두 이 “행 × 열” 규칙 위에 서 있습니다.
2×2 행렬에서 고른 성분 하나를 골라 어느 행과 어느 열이 쓰이는지 강조하며 계산 과정을 표시

예제

A = (1 2; 3 4), B = (2 0; 1 3)일 때 AB를 구하시오.

(1,1) 1·2 + 2·1 = 4, (1,2) 1·0 + 2·3 = 6, (2,1) 3·2 + 4·1 = 10, (2,2) 3·0 + 4·3 = 12 → (4 6; 10 12).

A가 2×3, B가 3×1 행렬일 때 AB와 BA는 정의되는가?

AB: A의 열 3 = B의 행 3 → 2×1 행렬. BA: B의 열 1 ≠ A의 행 2 → 정의되지 않음.
