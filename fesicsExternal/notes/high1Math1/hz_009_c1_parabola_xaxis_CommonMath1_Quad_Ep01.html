이차함수와 x축 — D는 몇 번, a는 어느 쪽

y = ax² + bx + c의 a, b, c를 바꾸며 판별식 D, x축과의 교점 수, 그래프의 위치를 기록했습니다. D의 부호가 교점 수(2, 1, 0)를 정했고, 만나지 않을 때 x축 위인지 아래인지는 a의 부호가 정했습니다. a와 D의 부호 조합으로 위치 관계를 네 가지로 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 a(−3~3), b(−6~6), c(−6~8)를 정하고 ‘x축과 만나는 곳 찾기’를 누르면 D, 교점 수, 그래프의 위치가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

D > 0이면 두 점, D = 0이면 한 점에서 접하고, D < 0이면 만나지 않습니다. 같은 D = −8이라도 a = 1이면 x축 위, a = −1이면 x축 아래였습니다. 꼭짓점의 y좌표 −D/(4a)의 부호를 a와 D가 함께 정하기 때문입니다(첫 줄 꼭짓점 y = 2, 넷째 줄 −2).

개념 정리

1. D의 부호는 “몇 번 만나나”, a의 부호는 “어느 쪽에 있나”

D > 0이면 두 점, D = 0이면 한 점, D < 0이면 만나지 않아요. 만나지 않을 때 그래프가 x축 아래에 있는지 위에 있는지는 D가 아니라 a의 부호가 정합니다. a > 0이고 D < 0이면 그래프는 x축 위에 통째로 있습니다.

왜 그럴까

  • a>0이면 아래로 볼록이라 꼭짓점이 최저점 — 최저점이 x축 위면 전체가 위.
  • 꼭짓점의 y좌표는 −D/(4a)이므로, a>0·D<0이면 −D/(4a)>0.
  • “모든 실수 x에서 ax²+bx+c>0” 조건이 바로 a>0, D<0입니다.

움직여 보기

a, b, c를 바꾸며 포물선과 x축의 위치 관계 보기

식 D = b² − 4ac 교점 꼭짓점 y = −D/(4a) 위치

c를 바꾸면 그래프가 위아래로만 움직여요. D가 0을 지나는 순간 교점이 2개 → 1개 → 0개로 바뀝니다. D < 0일 때 그래프가 x축 위인지 아래인지는 a의 부호(위로/아래로 볼록)를 보세요. 빨간 점 = x축과 만나는 점, 보라 점 = 꼭짓점.

2. 자주 하는 오해 바로잡기

· “D < 0이면 그래프가 x축 아래에 있다” → a > 0이면 오히려 x축 위에 있어요.

3. 생활 속에서 · 이어지는 개념

  • 이차부등식이 항상 성립하는지 판정할 때 이 네 가지 분류를 그대로 씁니다.
a, b, c를 바꿔 D를 계산하고 실제 교점 개수를 세어, a와 D의 부호 조합별로 위치를 분류
📋 데이터 확인 탭의 결론

“D > 0인 기록에서 그래프는 x축 위에 있었습니다. D가 음수라고 아래에 있는 게 아닙니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

y = −x² + 4x − 5의 그래프와 x축의 위치 관계는?

D = 16 − 20 = −4 < 0, a < 0 → 꼭짓점 y = −D/(4a) = 4/(−4) = −1 → 교점 0개, x축 아래 전체.

y = x² − 6x + k의 그래프가 x축에 접할 때 k의 값은?

D = 36 − 4k = 0 → k = 9.
