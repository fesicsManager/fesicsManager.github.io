절댓값 부등식 — |x − c|는 c까지의 거리

중심 c, 기준 k, 부등호 방향을 바꾸며 −12부터 12까지의 정수를 대입해 |x − c| < k 또는 |x − c| > k를 만족하는 수를 찾고, 절댓값을 그냥 뗀 답과 비교해 기록했습니다. ‘<’이면 c를 가운데 둔 한 구간, ‘>’이면 바깥 두 구간이 답이었고, 그냥 뗀 답은 매번 여러 개를 틀렸습니다. 절댓값을 거리로 읽는 풀이를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 중심 c(−5~5), k(1~8), 부등호 방향(< 또는 >)을 정하고 ‘만족하는 수를 모두 찾기’를 누르면 만족하는 정수, 올바른 구간, 한쪽만 본 답이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 절댓값 부등식의 해 (−12~12 정수 대입, 실험 예시)

|x − c|는 c까지의 거리이고 거리는 좌우 양쪽에 있습니다. 그래서 |x − c| < k는 c − k < x < c + k(가운데 한 구간), |x − c| > k는 x < c − k 또는 x > c + k(바깥 두 구간)입니다. 절댓값을 그냥 떼면 반대쪽 경계가 사라져 ‘<’에서는 작은 수를 잘못 넣고, ‘>’에서는 왼쪽 구간을 통째로 빠뜨립니다(표의 개수는 −12~12 안에서 센 값).

개념 정리

1. |x − c|는 “c까지의 거리” — 거리는 좌우 양쪽에 있다

|x − c| < k는 c에서 거리가 k보다 가까운 점이라 c−k < x < c+k 한 구간이 돼요. |x − c| > k는 반대로 멀리 떨어진 점이라 x < c−k 또는 x > c+k, 두 조각으로 갈립니다.

왜 그럴까

  • |x| < 3을 x < 3으로만 쓰면 x = −100도 답이 되어 버립니다.
  • 거리는 음수가 없으므로 |x−c| < 0은 해가 없고, |x−c| > −1은 모든 실수가 해입니다.
  • 절댓값이 둘 이상이면 부호가 바뀌는 점에서 구간을 나눠 풀어야 합니다.

부등식 해 만족하는 정수(−12~12) P

주황 화살표가 c에서 양쪽으로 거리 k예요. ‘< k’는 가까운 점이라 가운데 한 구간, ‘> k’는 먼 점이라 바깥 두 구간으로 갈립니다. P를 움직이며 거리 |x − c|와 만족 여부를 보세요. 초록 점 = 만족하는 정수, 속이 빈 원 = 끝점 미포함.

2. 자주 하는 오해 바로잡기

· “|x| < 3이면 x < 3이다” → 왼쪽 끝이 없어 −3보다 작은 수까지 들어옵니다.

3. 생활 속에서 · 이어지는 개념

  • 오차 범위 “±0.5mm 이내”가 바로 |측정값 − 기준| ≤ 0.5 입니다.
−10부터 10까지 모든 정수를 대입해 실제로 만족하는 수를 찾고, 한쪽만 본 답과 비교

예제

|x − 1| ≤ 4를 만족하는 정수의 개수는?

−4 ≤ x − 1 ≤ 4 → −3 ≤ x ≤ 5 → 정수 −3, −2, …, 5 → 9개.

|2x + 1| > 5를 푸시오.

2x + 1 > 5 또는 2x + 1 < −5 → x > 2 또는 x < −3 → x < −3 또는 x > 2.
