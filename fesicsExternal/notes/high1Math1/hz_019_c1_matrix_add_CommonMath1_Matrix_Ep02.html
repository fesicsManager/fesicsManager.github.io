행렬의 덧셈과 실수배 — 덧셈은 같은 꼴끼리, 실수배는 언제나

A와 B의 행·열 수와 실수 k를 바꾸며 A + B가 정의되는지, kA의 꼴이 어떻게 되는지 기록했습니다. 덧셈은 꼴이 같을 때만 되었고 2×3과 3×2처럼 성분 개수가 같아도 안 되었으며, 실수배는 어떤 꼴에서도 가능하고 꼴이 그대로였습니다. 덧셈과 실수배의 정의와 조건을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 A의 행·열, B의 행·열(1~3), 실수배 k(−3~3)를 정하고 ‘더해 보기’를 누르면 덧셈 가능 여부와 kA의 꼴이 기록됩니다. A, B의 성분은 1부터 차례로 채워집니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 꼴에 따른 덧셈과 실수배 (실험 예시)
A의 꼴B의 꼴덧셈 가능실수배 kkA의 꼴결과
2×22×2✅22×2합 계산됨
2×33×2❌−12×3정의 안 됨
1×31×3✅31×3합 계산됨
3×11×3❌03×1정의 안 됨
2×32×2❌−22×3정의 안 됨

(A + B)ᵢⱼ = aᵢⱼ + bᵢⱼ는 같은 자리끼리 더하는 것이라 꼴이 같아야 합니다. 2×3과 3×2는 성분이 6개씩이지만 자리가 대응되지 않아 더할 수 없습니다. 실수배 kA는 모든 성분에 k를 곱하므로 어떤 꼴이든 가능하고 꼴도 그대로입니다. 꼴이 같으면 A + B = B + A, k(A + B) = kA + kB가 성립합니다.

개념 정리

1. 덧셈은 꼴이 같을 때만, 실수배는 꼴에 상관없이 언제나

행렬의 덧셈은 같은 자리끼리 더하는 것이라, 자리가 하나하나 맞아떨어져야 해요. 2×3과 3×2는 성분 개수가 6개로 같아도 자리가 대응되지 않아 더할 수 없습니다. 반면 실수배는 모든 성분에 k를 곱하는 것이라 꼴이 그대로 유지되고 언제나 가능합니다.

왜 그럴까

  • (A+B)ᵢⱼ = aᵢⱼ + bᵢⱼ — 이 식 자체가 같은 자리를 전제합니다.
  • A + B = B + A, (A+B)+C = A+(B+C) — 꼴이 같기만 하면 실수처럼 다룰 수 있습니다.
  • k(A+B) = kA + kB도 성립합니다.

움직여 보기

A + B는 같은 자리끼리, kA는 모든 성분에 k배

A + B kA의 꼴

성분은 실험처럼 1부터 차례로 채웠어요. A를 2×3, B를 3×2로 바꾸면 성분이 6개씩으로 같아도 짝 없는 자리(빨강)가 생겨 A + B가 정의되지 않는지, k를 바꿔도 kA의 꼴은 A와 같은지 확인해 보세요.

2. 자주 하는 오해 바로잡기

· “꼴이 달라도 더할 수 있다” → 자리가 대응되지 않으면 정의되지 않습니다.

3. 생활 속에서 · 이어지는 개념

  • 같은 형식의 표(같은 행·열 이름)끼리만 합산할 수 있는 것과 같은 이치입니다.
A, B의 꼴을 바꿔 가며 덧셈 가능 여부를 판정하고, kA는 꼴이 그대로인지 확인

예제

A = (1 2; 3 4), B = (0 −1; 2 5)일 때 2A − B를 구하시오.

2A = (2 4; 6 8) → 2A − B = (2 − 0, 4 + 1; 6 − 2, 8 − 5) = (2 5; 4 3).

A가 2×3 행렬, B가 3×2 행렬일 때 A + B와 3A는 정의되는가?

꼴이 달라 A + B는 정의되지 않고, 3A는 2×3 행렬로 정의됩니다.
