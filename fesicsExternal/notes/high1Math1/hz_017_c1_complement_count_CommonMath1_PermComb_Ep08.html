고등학교 공통수학1 · 실험 「반대편 실험실」

여사건으로 세기 — ‘적어도 하나’는 전체 − ‘하나도 없음’

0~9를 중복 허용해 만든 n자리 숫자열 중 특정 숫자가 적어도 하나 들어간 것의 개수를, 정확히 k개씩 나눠 더하는 방법과 전체에서 ‘하나도 없음’을 빼는 방법으로 기록했습니다. 두 방법의 답은 언제나 같았지만, 정면으로 세면 항이 자리 수만큼 늘어났고 여사건은 늘 한 줄이었습니다. 여사건을 이용해 세는 요령을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 자리 수 n(1~5)과 조건의 숫자 m(0~9)을 정하고 ‘두 방향으로 세어 보기’를 누르면 정면으로 센 수, 전체, 반대 경우, 전체 − 반대가 기록됩니다. 첫 자리 0도 허용한 숫자열을 셉니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 숫자 7이 적어도 하나 들어간 n자리 숫자열 (실험 예시)
n자리조건정면으로 센 수전체반대 경우전체 − 반대
1숫자 7 적어도 하나11091
2숫자 7 적어도 하나191008119
3숫자 7 적어도 하나2711000729271
4숫자 7 적어도 하나34391000065613439
5숫자 7 적어도 하나409511000005904940951

정면으로 세면 정확히 1개, 2개, …, n개인 경우 ₙCₖ × 9ⁿ⁻ᵏ를 모두 더해야 합니다(3자리: 243 + 27 + 1 = 271). 반대로 ‘하나도 없음’은 자리마다 9가지라 9ⁿ 한 가지뿐이므로 10ⁿ − 9ⁿ 한 줄로 끝납니다. n(A) = 전체 − n(Aᶜ)이며, ‘적어도’, ‘모두 ~는 아니다’가 보이면 여사건을 먼저 떠올립니다.

개념 정리

1. “적어도 하나”는 전체에서 “하나도 없음”을 빼는 게 훨씬 짧다

“적어도 하나 포함”을 정면으로 세면 1개·2개·3개… 경우를 모두 나눠 더해야 해요. 반대인 “하나도 없음”은 한 가지 경우뿐이라 계산이 한 줄로 끝납니다. 10ⁿ − 9ⁿ 이 그것입니다.

왜 그럴까

  • 여사건 A^c는 A와 배반이고 합치면 전체이므로 n(A) = 전체 − n(A^c).
  • “적어도”, “아닌 것이 없다”, “모두는 아니다” 같은 말이 나오면 여사건을 먼저 의심합니다.
  • 확률에서도 같은 구조 — P(적어도 하나) = 1 − P(하나도 없음).

2. 자주 하는 오해 바로잡기

· “적어도은 정면으로 세는 게 정확하다” → 정확하지만 훨씬 길고, 나눠 세다 빠뜨리기 쉽습니다.

3. 생활 속에서 · 이어지는 개념

  • “적어도 한 번 당첨될 확률”처럼 반대편이 하나뿐인 문제에서 늘 쓰입니다.
모든 n자리 수를 실제로 만들어 조건을 만족하는 개수를 직접 세고, 10ⁿ − 9ⁿ과 대조
📋 데이터 확인 탭의 결론

“모든 기록에서 두 방법의 답이 같았습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

0~9를 중복 허용해 만든 네 자리 숫자열(첫 자리 0 허용) 중 5가 적어도 하나 들어간 것의 개수는?

전체 10⁴ = 10000, 5가 하나도 없음 9⁴ = 6561 → 3439.

동전 4개를 던질 때 앞면이 적어도 한 개 나오는 경우의 수는?

전체 2⁴ = 16, 모두 뒷면 1 → 16 − 1 = 15.
