중학교 역사② 한국사 · 2부 · 웹툰 7화 「우리말 사전은 학자 몇이 만들었나」

조선어학회와 우리말 사전 — 규칙을 먼저 정하고 여럿이 28년

사전을 누가 만드는지와 맞춤법·표준어 규칙을 먼저 정할지를 바꿔 가상의 사전 만들기 기간을 계산하고, 실제 원고 연표(1929~1957)에서 고른 연도의 원고 위치를 기록했습니다. 천재 학자 한 명이 규칙 없이 모으면 약 163년이 걸렸지만, 회원과 전국 참여로 규칙을 먼저 정하면 약 16년으로 줄었습니다. 맞춤법이 정해진 때와 사전 원고가 걸어온 길을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 누가 만드는지(천재 학자 1명 · 학회 회원 수십 명 · 회원과 전국 교사·독자), 규칙(맞춤법·표준어를 먼저 정함 / 규칙 없이 낱말부터 모음), 실제 연표에서 볼 연도(1929~1957)를 고른 뒤 사전 만들기 계산을 누르면 규칙 정하기·낱말 모으기 기간, 가상 소요 기간, 모인 지역 말 범위, 그해 실제 원고의 위치가 나옵니다. 같은 사람 수로 두 규칙을 비교하고 연도를 1943년과 1945년으로 옮겨 보는 식으로 4번 이상 기록하면 결과 비교 탭이 열립니다. 낱말 수 목표, 한 사람이 1년에 모으는 낱말 수, 중복 비율은 가상 모형 값이고 아래 연표는 실제 기록이에요.

표 1. 만드는 사람과 규칙에 따른 가상 기간 (실험 예시, 가상 모형)
만든 사람규칙가상 기간지역 말연도
1명규칙 없이163년10%1933
1명규칙 먼저107년10%1933
회원 수십 명규칙 없이30년45%1943
회원 수십 명규칙 먼저24년45%1945
회원+전국 참여규칙 없이18년90%1947
회원+전국 참여규칙 먼저16년90%1957

한 사람이 혼자 모으면 규칙을 먼저 정해도 100년이 넘게 걸렸고, 모인 지역 말도 10%로 서울 말 위주였습니다. 사람이 늘수록 기간이 줄고 지역 말 범위가 넓어졌어요. 같은 사람 수라면 규칙을 먼저 정하는 쪽이 늘 빨랐습니다. 규칙 정하기에 4년이 들어도, 규칙 없이 모으면 같은 말이 여러 표기로 들어와 다시 정리해야 하기 때문이에요. 맞춤법은 원래 있던 것이 아니라 1933년 「한글 마춤법 통일안」으로 여러 해 회의를 거쳐 정한 규칙입니다. 실제 원고는 1942년 조선어학회 사건으로 빼앗기고 이윤재·한징이 감옥에서 숨졌으며, 1945년 9월 서울역 창고에서 다시 찾았어요. 1929년 시작부터 1957년 완간까지 28년, 수많은 사람의 손이 사전을 만들었습니다.

개념 정리

1. 맞춤법은 "원래 있던 것"이 아니라 정한 것

사전을 만들려면 먼저 어떻게 적을지를 정해야 합니다. 그때까지는 같은 말을 사람마다, 신문마다 다르게 적었어요. 1933년 「한글 마춤법 통일안」은 여러 해 회의를 거듭해 정한 규칙이고, 1936년에는 표준어 모음이 발표되었습니다. 지금 우리 맞춤법의 뿌리가 여기 있어요.

2. 연표

  • 1910년대 주시경과 제자들의 사전 원고 「말모이」(책으로 나오지 못함) → 1921년 조선어연구회 → 1929년 조선어사전편찬회 → 1931년 조선어학회로 이름을 바꿈
  • 1933년 맞춤법 통일안 → 학회 잡지 『한글』 등을 통해 각 지방의 말을 모음
  • 1942년 조선어학회 사건: 회원들이 붙잡혀 가고 원고를 빼앗김. 이윤재·한징이 감옥에서 숨짐
  • 1945년 9월 서울역 창고에서 원고를 다시 찾음 → 1947년 『조선말 큰사전』 첫 권 → 1957년 여섯 권 완간

3. 이 실험의 계산 방법 (가상)

걸리는 해 = 규칙 정하기 + 목표 낱말 수 ÷ (1년에 모으는 낱말 수) × 중복 보정 + 다듬기 규칙 없이 모으면 같은 말이 여러 표기로 들어와 다시 정리해야 하므로 모으는 시간에 1.6배를 곱했습니다.

4. 말을 지킨 다른 길

· 1926년 "가갸날"(뒤에 한글날), 한글 강습회, 신문사의 문자 보급 운동(학생들이 방학 때 농촌에 가 글을 가르침). 일제 말에는 학교에서 조선어 수업이 사실상 사라졌습니다.

· 실제 사전은 규칙 정하기 · 낱말 모으기 · 원고 지키기 · 펴내기가 28년 동안 많은 사람의 손으로 이어진 결과예요.

가상 기간 = 규칙 정하기(먼저 정하면 4년) + 목표 150,000낱말 ÷ 1년에 모으는 낱말 수 × (규칙 없이 모으면 1.6) + 다듬기 3년
닥터 이안 · 제로

“사전을 만들려면 먼저 ‘어떻게 적을지’를 정해야 한다. 그때까지는 같은 말을 사람마다, 신문마다 다르게 적었어. 맞춤법은 원래 있던 게 아니라 1933년에 여러 해 회의를 거듭해서 정한 규칙이야.” “표제어로 올릴 ‘표준말’도 정해야 하고요.”

예제

학회 회원 수십 명(1년에 9,000낱말)이 규칙을 먼저 정할 때와 규칙 없이 모을 때 가상 기간은 각각 얼마인가?

규칙 먼저: 4 + 150,000 ÷ 9,000(약 16.7) + 3 ≈ 23.7 → 약 24년. 규칙 없이: 0 + 16.7 × 1.6(약 26.7) + 3 ≈ 29.7 → 약 30년. 약 24년 / 약 30년

실제 연표에서 1943년과 1945년을 고르면 사전 원고는 각각 어디에 있었나?

1943년: 1942년 조선어학회 사건으로 원고를 빼앗겨 재판 증거물로 옮겨 다니던 때입니다(이윤재·한징 옥사). 1945년: 9월 서울역 창고에서 원고를 다시 찾았어요. 빼앗김 → 서울역 창고에서 되찾음
