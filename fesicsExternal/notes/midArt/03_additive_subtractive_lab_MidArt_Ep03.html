중학교 미술 · 웹툰 3화 「색을 섞으면 어두워지는가」

가산 혼합과 감산 혼합 — 빛은 더할수록 밝고, 물감은 섞을수록 어둡다

혼합 방식(빛 RGB·이상적인 잉크 CMY·실제 물감)과 섞을 조합을 바꾸며 결과색과 밝기(모형)를 섞기 전 평균과 비교했습니다. 빨강 + 초록은 빛에서 노랑(밝기 93%, 섞기 전 평균 46%)이 되었지만 물감에서는 탁한 갈색(29%, 평균 36%)이 되었고, 셋 다 섞으면 빛은 흰색 100%, 잉크는 검정 0%였습니다. 더하는 섞기와 빼는 섞기의 원리를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 혼합 방식(빛·이상적인 잉크·실제 물감)을 고르고 1·2·3번 기본색 가운데 섞을 조합(한 색·두 색·셋 다)을 골라 ‘섞어 보기’를 누릅니다. 빛·물감은 1 빨강·2 초록·3 파랑, 잉크는 1 청록·2 자홍·3 노랑이에요. 같은 조합을 세 방식에서 모두 섞어 보면 결과 비교 탭에 조합 × 방식 표와 밝기 비교 막대가 채워집니다. 물감 반사율은 설명용 가정치예요.

표 1. 같은 조합, 다른 혼합 방식 (실험 계산)
방식섞은 색결과밝기섞기 전 평균
빛빨강 + 초록노랑93%46%
물감빨강 + 초록탁한 갈색29%36%
빛초록 + 파랑청록79%39%
물감초록 + 파랑탁한 청록29%32%
빛빨강 + 초록 + 파랑흰색100%33%
잉크청록 + 자홍 + 노랑검정0%67%

빛은 섞은 뒤가 섞기 전 평균보다 늘 밝았고, 잉크·물감은 늘 어두웠습니다. 빛을 겹치면 눈에 들어오는 빛이 늘고(가산 혼합), 물감을 섞으면 흡수가 늘어 반사되는 빛이 줄어듭니다(감산 혼합). 화면은 RGB, 인쇄는 CMYK라서 같은 파일도 색이 달라 보여요.

개념 정리

1. 더하는 섞기와 빼는 섞기

  • 가산 혼합(빛): 빨강·초록·파랑(RGB) 빛을 겹치면 눈에 들어오는 빛이 늘어나 밝아집니다. 셋을 같은 세기로 겹치면 흰색.
  • 감산 혼합(물감·잉크): 물감은 빛의 일부를 흡수하고 나머지를 반사합니다. 섞을수록 흡수가 늘어 반사되는 빛이 줄고 어두워져요. 기본색은 청록·자홍·노랑(CMY).

2. 이 실험의 계산 방법

빛: 결과 = 각 색의 합 (최대 1) · 잉크: 결과 = 각 잉크 투과율의 곱 · 물감: 결과 = 반사율의 기하평균(같은 양 섞기)

밝기는 0.2126 R + 0.7152 G + 0.0722 B로 계산합니다(사람 눈이 초록에 가장 민감하다는 가중치).

3. 실험 모형과 실제의 차이

· 실제 물감은 수많은 파장을 조금씩 흡수·반사하고, 입자 크기와 매체에 따라 섞인 색이 달라집니다. 여기서는 세 파장대만 다뤄요.

· 실제 인쇄는 CMY에 검정(K)을 더한 CMYK를 씁니다. CMY만으로는 깨끗한 검정이 잘 안 나오고 잉크도 많이 들기 때문이에요.

4. 생활 속에서 · 이어지는 개념

  • 화면은 RGB, 인쇄는 CMYK라서 같은 파일을 인쇄하면 색이 달라 보입니다.
  • 빨간 사과는 빨간 빛을 주로 반사하고 나머지를 흡수합니다. 조명이 바뀌면 보이는 색도 달라져요.

웹툰 3화 #2 · 두 가지 혼합을 나란히

예제

빛 모드에서 빨강 (1, 0, 0)과 초록 (0, 1, 0)을 겹친 결과와 밝기를 계산하면?

성분별로 더하면 (1, 1, 0) = 노랑. 밝기 = 0.2126 × 1 + 0.7152 × 1 + 0.0722 × 0 = 0.9278 ≈ 93%.

이상적인 잉크에서 청록 (0, 1, 1)과 자홍 (1, 0, 1)을 겹치면? (투과율의 곱)

(0 × 1, 1 × 0, 1 × 1) = (0, 0, 1) → 파랑, 밝기 0.0722 ≈ 7%. 섞기 전 평균 54%보다 크게 어두워졌습니다.
