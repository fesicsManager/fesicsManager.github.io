방위표 — 위쪽이 북쪽인 것은 법칙이 아니라 약속

방위표의 N이 가리키는 쪽을 위·오른쪽·아래·왼쪽으로 바꾸고, 찾을 방위와 나의 답을 골라 지도를 돌려 확인했습니다. N이 위쪽일 때만 ‘위쪽 = 북쪽’이 맞았고, N이 오른쪽이면 북쪽은 오른쪽 도서관, 위쪽 문구점은 서쪽이었습니다. 방향은 종이의 위쪽이 아니라 방위표가 정한다는 것을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 방위표의 N이 가리키는 쪽(위쪽·오른쪽·아래쪽·왼쪽), 찾을 방위(북·동·남·서), 나의 답(학교 둘레 네 곳 중 하나)을 고르고 지도 돌려 확인하기를 누르세요. 지도가 돌아가 N이 위로 오고, 정답과 맞았는지가 자동으로 기록됩니다. N 방향을 바꿔 가며 4개 이상 기록하면 결과 비교 탭이 열립니다.

표 1. N 방향과 찾을 방위를 바꾼 기록 (실험 예시)
N 방향찾을 방위정답나의 답맞음
오른쪽북도서관문구점✕
오른쪽북도서관도서관○
위쪽북문구점문구점○
아래쪽북우체국문구점✕
왼쪽북놀이터놀이터○
오른쪽서문구점문구점○

같은 ‘북쪽’을 찾아도 N 방향에 따라 정답이 문구점·도서관·우체국·놀이터로 계속 바뀌었습니다. ‘위쪽 = 북쪽’이 맞은 것은 N이 위쪽을 가리킬 때뿐이었어요. 지도를 돌려도 고장은 그대로이고 종이 방향만 바뀝니다. 그래서 처음 보는 지도는 먼저 방위표를 찾고, N을 위로 맞춘 뒤 위 = 북, 오른쪽 = 동, 아래 = 남, 왼쪽 = 서로 읽습니다.

개념 정리

1. 방향은 방위표가 정해요

지도의 방위표에서 N이 가리키는 쪽이 북쪽입니다. 방위표가 없을 때만 "위쪽을 북쪽"으로 보기로 약속했어요. 위쪽이 북쪽인 것은 법칙이 아니라 약속입니다.

2. 4방위와 8방위

  • 북쪽을 보고 서면 오른쪽이 동, 왼쪽이 서, 뒤쪽이 남이에요.
  • 북과 동 사이는 북동, 남과 서 사이는 남서처럼 나누면 8방위가 됩니다.
  • "오른쪽"은 보는 사람마다 다르지만 "북동쪽"은 모두에게 같은 곳이에요.

3. 이 실험의 방법

N이 위로 오도록 지도를 돌린다 → 위 = 북, 오른쪽 = 동, 아래 = 남, 왼쪽 = 서

4. 실험과 실제의 차이

· 실제 나침반 바늘은 북쪽(정확히는 자기 북쪽)을 가리켜요. 지도의 북쪽과 아주 조금 다를 수 있지만 고장 안에서 길을 찾을 때는 거의 같습니다.

5. 생활 속에서 · 이어지는 개념

  • 안내도나 등산 지도는 보기 편하게 돌려 그린 것도 있어요. 처음 보는 지도는 먼저 방위표를 찾으세요.

웹툰 1화 #4 · 지도를 돌려 N을 위로 맞추기

예제

방위표의 N이 아래쪽을 가리키는 지도에서, 학교 오른쪽에 그려진 도서관은 학교의 어느 쪽에 있나요?

지도를 반 바퀴 돌려 N을 위로 맞추면, 오른쪽에 있던 도서관이 왼쪽으로 갑니다. N이 위일 때 왼쪽은 서쪽이에요. 실험에서 N을 아래쪽으로 두고 ‘서쪽’을 찾아도 도서관이 나옵니다. 서쪽

친구에게 가게 위치를 알려 줄 때 ‘학교 오른쪽’보다 ‘학교 북동쪽’이라고 말하면 좋은 까닭은 무엇인가요?

오른쪽·왼쪽은 보는 사람이 어느 쪽을 보고 서 있는지에 따라 달라져요. 방위는 방위표로 정해져서 누구에게나 같은 곳을 가리킵니다. 북과 동 사이가 북동이에요. 누가 보아도 같은 곳을 가리키기 때문입니다.
