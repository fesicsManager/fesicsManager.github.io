실험에서 입사각을 바꿔 반사각을 재고, 오목·볼록거울 앞의 물체 거리를 바꿔 상의 종류를 관찰했습니다. 입사각 = 반사각이었고, 볼록거울은 어디에 두어도 작고 똑바로 선 허상만 만들었습니다. 반사 법칙과 세 거울의 쓰임을 정리합니다.

반사 실험에서는 입사각 30°·45°·60° 모두 반사각이 같았습니다. 오목거울은 물체가 초점(30 cm) 밖이면 거꾸로 실상, 안이면 큰 허상. 볼록거울은 거리와 관계없이 항상 작고 똑바로 선 허상입니다.

개념 정리

1. 반사 법칙

빛이 거울에 부딪히면 튕겨 나오는데, 법선(거울면에 수직인 선)을 기준으로 입사각 = 반사각입니다(반사 법칙). 매끈한 면에서는 규칙적으로(정반사), 거친 면에서는 사방으로(난반사) 반사됩니다. 우리가 물체를 보는 것은 난반사된 빛이 눈에 들어오기 때문입니다.

2. 세 거울의 상

거울빛상쓰임
평면거울그대로같은 크기, 좌우가 바뀐 똑바로 선 허상이 거울 뒤 같은 거리에거울, 잠망경, 만화경
오목거울모음초점 밖: 거꾸로 선 실상 / 초점 안: 크게 보이는 똑바로 선 허상화장 확대 거울, 치과 거울, 손전등 반사갓, 천체 망원경, 태양열 조리기
볼록거울퍼뜨림항상 작고 똑바로 선 허상, 넓은 시야자동차 사이드미러, 도로 반사경

거울 공식 1/a + 1/b = 1/f (f = 곡률 반지름 ÷ 2, 오목 +, 볼록 −). b > 0이면 실상(반사광이 실제로 만남), b < 0이면 허상. 배율 = |b| ÷ a. 사이드미러에 “사물이 보이는 것보다 가까이 있음”이라 적힌 것은 볼록거울이 상을 작게 만들기 때문입니다.

3. 모형과 실제

거울 공식은 빛이 광축 가까이로 들어오는 근축 근사입니다. 구면거울의 가장자리 빛은 정확히 초점에 모이지 않아 상이 흐려지므로(구면 수차) 정밀 망원경은 포물면 거울을 씁니다. 실제 거울은 빛을 조금 흡수해 상이 어두워지고, 유리 앞면 반사로 이중상이 생기기도 합니다.

입사각 = 반사각   ·   1/a + 1/b = 1/f

오목 f = +30 cm, 볼록 f = −30 cm · b > 0 실상, b < 0 허상 · 배율 = |b| ÷ a

피지

“빛이 거울에 들어오는 각도(입사각)와 튕겨 나가는 각도(반사각)는 항상 같아. 이걸 반사 법칙이라고 해.”

웹툰 2화 · 지유: “거울에 내 모습이 그대로 비치는 건 왜 그래?” 민재: “그래서 거울 속 글씨가 반대로 보이는 거구나!”

민재

“평면거울-같은 크기, 볼록거울-작고 넓은 시야, 오목거울-크게 확대! 각각 쓰임새가 다르네.”

웹툰 2화 · 지유: “화장할 때 쓰는 확대 거울도 오목거울이었구나!”

예제

초점 거리 30 cm인 오목거울에서 45 cm 앞에 물체를 두면 상은 어디에, 어떤 모양으로, 몇 배로 생길까?

1/45 + 1/b = 1/30 → 1/b = 1/30 − 1/45 = 1/90 → b = +90 cm. b > 0이므로 거울 앞 90 cm에 거꾸로 선 실상, 배율 90 ÷ 45 = 2배.

같은 오목거울 앞 20 cm(초점 안)에 물체를 두면?

1/b = 1/30 − 1/20 = −1/60 → b = −60 cm. 거울 뒤 60 cm에 똑바로 선 허상, 배율 60 ÷ 20 = 3배. 화장 확대 거울이 이 원리입니다.

확인 문제

1번· 관찰 확인

실험에서 볼록거울 앞 물체 거리를 바꿔 보았을 때 상은?

볼록거울은 빛을 퍼뜨려 어떤 거리에서도 정립·축소된 허상만 만듭니다. 넓은 시야를 확보하는 자동차 사이드미러에 쓰는 이유입니다.

2번· 핵심 개념

반사 법칙으로 옳은 것은?

법선을 기준으로 빛이 들어오는 각과 나가는 각은 항상 같습니다. 실험에서 30°·45°·60° 모두 확인했습니다.

3번· 적용

치과에서 쓰는 작은 거울과 손전등 반사갓에 쓰이는 거울은?

오목거울은 빛을 한 곳으로 모아 상을 크게 만들거나(치과 거울, 화장 거울) 빛을 한 방향으로 보냅니다(손전등 반사갓, 태양열 조리기).

4번· 웹툰 연결

볼록거울은 빛을 퍼뜨려 상이 작고 넓은 범위가 보입니다. 그래서 사이드미러·도로 반사경에 쓰이고, ‘사물이 보이는 것보다 가까이 있음’이라는 경고가 붙습니다.
