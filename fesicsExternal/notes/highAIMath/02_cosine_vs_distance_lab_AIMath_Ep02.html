유클리드 거리와 코사인 유사도 — 거리는 길이까지, 코사인은 방향만

기준 문장 A ‘나는 수학이 좋다’를 B(A를 두 번 이어 붙인 문장), C, D, E와 비교해 유클리드 거리와 코사인 유사도를 계산했습니다. 거리로는 C가 1.414로 B(1.732)보다 가까웠지만, 코사인으로는 B가 1로 완전히 같은 방향이었습니다. 재는 자에 따라 ‘가장 비슷한 문장’이 바뀌는 이유를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 기준 문장(A 또는 B)과 비교할 문장(A~E)을 고르고 거리와 코사인 계산하기를 누르면 두 벡터, 차이 벡터, 유클리드 거리, 내적, 길이 곱, 코사인 유사도, 사이 각이 나오고, 두 벡터를 같은 길이·각도로 옮긴 평면 그림이 그려집니다. 4개 이상 기록하면 결과 비교 탭에서 거리 순위와 코사인 순위를 나란히 볼 수 있습니다.

표 1. 두 문장 벡터의 거리와 코사인 유사도 (실험 예시, 단어장 [나, 수학, 과학, 좋다, 싫다])
비교유클리드 거리코사인 유사도사이 각
A–B1.7321.0000.0°
A–C1.4140.66748.2°
A–D1.4140.66748.2°
A–E1.7320.91324.1°
B–C2.6460.66748.2°

기준 A에서 거리로는 C(1.414)가 B(1.732)보다 가깝지만, 코사인으로는 B가 1로 가장 가깝습니다. B = 2A라 방향은 같고 길이만 두 배여서, 거리는 길이 차이까지 벌점으로 세고 코사인은 방향만 봅니다. 한편 뜻이 정반대인 D ‘나는 수학이 싫다’도 A와의 코사인이 C와 같은 0.667이라, 재는 자를 바꿔도 벡터가 담지 못한 뜻은 되살아나지 않습니다.

개념 정리

1. 거리는 길이까지, 코사인은 방향만

  • 유클리드 거리: |a − b| = √( Σ(aᵢ − bᵢ)² ) — 두 점 사이의 직선 거리. 한 벡터의 길이만 늘어나도 거리가 커집니다.
  • 코사인 유사도: cos θ = (a · b) ÷ (|a| × |b|) — 두 화살표 사이 각의 코사인. 1이면 같은 방향, 0이면 직각입니다. 단어 빈도는 음수가 없어서 0과 1 사이에 있어요.

B는 A를 두 번 이어 붙여 B = 2A입니다. 방향은 똑같고 길이만 두 배라 코사인은 1이지만, 거리는 √3 ≈ 1.732로 C(√2 ≈ 1.414)보다 멀게 나옵니다. 길이가 제각각인 문서를 비교할 때 코사인 유사도를 많이 쓰는 이유예요.

2. 이 실험의 계산 방법

내적 a · b = a₁b₁ + a₂b₂ + … + a₅b₅ (곱해서 더하기) · |a| = √(a · a)

평면 그림에서 두 화살표 끝 사이 거리는 코사인 법칙 |a − b|² = |a|² + |b|² − 2|a||b| cos θ로 실제 유클리드 거리와 정확히 같습니다.

3. 실험 모형과 실제의 차이

· 대본의 단어장은 [나, 수학, 과학, 좋다] 4칸이고, 여기서는 D를 넣으려고 ‘싫다’를 더해 5칸입니다. 0인 칸이 하나 늘 뿐 A·B·C 사이의 거리와 코사인은 같아요.

· D ‘나는 수학이 싫다’는 A와 뜻이 정반대인데 코사인이 C와 똑같은 2/3입니다. 재는 자를 바꿔도 벡터가 담지 못한 정보(뜻)는 되살아나지 않아요.

4. 생활 속에서 · 이어지는 개념

  • 검색 엔진·추천 시스템은 질문과 문서를 벡터로 바꾼 뒤 코사인 유사도가 큰 순서로 보여 주는 경우가 많습니다. 내적은 퍼셉트론의 가중합과 같은 ‘곱해서 더하기’예요.
코사인 유사도 cos θ = (a · b) ÷ (|a| × |b|), 유클리드 거리 = √(Σ(aᵢ − bᵢ)²)

예제

a = (1, 2, 0), b = (2, 4, 0)의 유클리드 거리와 코사인 유사도를 구하시오.

차이 (−1, −2, 0)이므로 거리 = √5 ≈ 2.236. 내적 = 2 + 8 = 10, |a| = √5, |b| = √20, 길이 곱 = √100 = 10이므로 코사인 = 10 ÷ 10 = 1. 거리는 약 2.236이지만 방향은 완전히 같습니다.

A = (1, 1, 0, 1, 0)과 E = (2, 1, 1, 2, 0)의 내적과 코사인 유사도를 구하시오.

내적 = 2 + 1 + 0 + 2 + 0 = 5, |A| = √3, |E| = √10이므로 코사인 = 5 ÷ √30 ≈ 0.913입니다.
