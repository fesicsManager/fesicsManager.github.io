회전·대칭 행렬 — 값은 그대로, 자리만 옮긴다

5 × 5 그림의 가운데 칸을 원점으로 하는 수학 좌표에서 반시계 90° 회전, x·y 맞바꾸기, 전치, 180° 회전, y축 대칭, 화면 좌표의 R을 적용해 점 (2, 1)을 추적했습니다. 회전 행렬은 (2, 1)을 (−1, 2)로, x·y 맞바꾸기는 (1, 2)로 보냈고, 어느 변환에서도 25칸 값의 합 2,280은 그대로였습니다. 회전과 뒤집기를 행렬식으로 구별하는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 변환 행렬(반시계 90° 회전 · x와 y 맞바꾸기 · 행렬 전치 · 180° 회전 · y축 대칭 · 같은 R을 화면 좌표에 적용)과 추적할 점(네 점)을 고르고 행렬 적용하기를 누르면 결과 그림, 옮겨 간 점과 칸, 회전/대칭 판정, 값의 합, 3 × 3 숫자 그림 M의 결과가 나옵니다. 4개 이상 기록하면 결과 비교 탭에서 추적 기록과 M의 변환 결과를 비교할 수 있습니다.

회전 행렬 R = [[0, −1], [1, 0]]은 (x, y)를 (−y, x)로 보내 (2, 1)이 (−1, 2)가 됩니다. 뭉치의 답 (1, 2)는 x와 y를 맞바꾼 직선 y = x 대칭이고, 행렬식이 −1인 뒤집기입니다. 같은 R을 화면 좌표(y 아래쪽)에 쓰면 (1, −2)로 가서 화면에서는 시계 방향으로 돈 것처럼 보입니다. 모든 변환에서 값의 합이 2,280 그대로라, 회전·대칭은 값이 아니라 자리를 바꿉니다.

개념 정리

1. 회전·대칭은 값이 아니라 자리를 바꾼다

4화의 밝기 연산은 자리는 그대로 두고 값을 바꿨습니다. 회전과 대칭은 반대로 값은 그대로 두고 자리만 옮겨요. 그래서 픽셀 25개의 값을 모두 더한 합은 변환 전후가 같습니다.

  • 반시계 90° 회전 R = [[0, −1], [1, 0]] : (x, y) → (−y, x) — (2, 1)은 (−1, 2)로 갑니다.
  • x와 y 맞바꾸기 [[0, 1], [1, 0]] : (x, y) → (y, x) — 직선 y = x에 대한 대칭(뒤집기)이지 회전이 아닙니다.
  • 전치(행 ↔ 열): 행렬의 왼쪽 위–오른쪽 아래 대각선을 기준으로 뒤집기. 위쪽이 y+인 이 좌표에서는 직선 y = −x에 대한 대칭 [[0, −1], [−1, 0]]과 같아요.

행렬식(ad − bc)이 +1이면 회전, −1이면 뒤집기입니다. 회전 결과는 전치한 뒤 행 순서를 위아래로 뒤집어도 얻어져요. 3 × 3 숫자 그림 M = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]을 반시계로 돌리면 [[3, 6, 9], [2, 5, 8], [1, 4, 7]]입니다.

움직여 보기

행렬을 곱하면 칸이 자리를 옮긴다 — 값은 그대로

점 (2, 1) → 행렬식

가운데 칸이 원점 (0, 0), 위쪽이 y+인 좌표입니다. 행렬을 고르고 ▶ 옮기기를 누르면 25칸이 (x, y) → (ax + by, cx + dy)로 움직입니다. 행렬식이 +1이면 돌기만 하고(회전), −1이면 그림이 납작해졌다가 뒤집혀 나옵니다(대칭). ‘R을 화면 좌표에’는 y가 아래로 커지는 화면에서 R을 쓴 결과를 이 좌표로 다시 그린 것이라 시계 방향으로 돕니다.

2. 이 실험의 계산 방법

(x′, y′) = (a·x + b·y, c·x + d·y) → 새 열 = x′ + 3, 새 행 = 3 − y′

화면 좌표는 보통 y가 아래쪽으로 커집니다. 같은 R을 화면 좌표에 그대로 쓰면 화면에서는 시계 방향으로 돌아 보여요. 마지막 선택지가 그 경우입니다.

3. 실험 모형과 실제의 차이

· 90° 단위 회전은 칸이 칸으로 정확히 옮겨 갑니다. 45°처럼 다른 각도는 cos·sin이 약 0.707이라 새 좌표가 칸 사이에 떨어지므로, 가장 가까운 칸 값을 쓰거나 주변 칸 값을 섞습니다. 그래서 45° 회전을 여러 번 하면 그림이 조금씩 흐려져요.

4. 생활 속에서 · 이어지는 개념

  • 휴대전화 사진의 자동 회전, 게임 캐릭터의 방향 전환, 데이터 증강(사진을 돌리고 뒤집어 학습 자료 늘리기)이 모두 이 행렬 계산입니다.

예제

수학 좌표 (0, 2)에 있는 점(칸 (1, 3))을 반시계 90° 회전하면 어느 점, 어느 칸으로 가는가?

(x, y) → (−y, x)이므로 (0, 2) → (−2, 0). 열 = −2 + 3 = 1, 행 = 3 − 0 = 3이라 점 (−2, 0), 칸 (3, 1)입니다.

M = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]을 전치한 뒤 행 순서를 위아래로 뒤집은 결과를 구하시오.

Mᵀ = [[1, 4, 7], [2, 5, 8], [3, 6, 9]], 행을 거꾸로 쌓으면 [[3, 6, 9], [2, 5, 8], [1, 4, 7]]로 반시계 90° 회전 결과와 같습니다.
