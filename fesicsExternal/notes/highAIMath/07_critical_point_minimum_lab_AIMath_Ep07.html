미분 0과 최솟값 — 필요조건일 뿐, 후보는 구간 끝까지

x², −x², x³, g(x) = x³ − 3x에서 미분이 0인 점을 부호표로 판정하고, 구간 양 끝까지 포함해 최솟값 후보를 비교했으며, 출발점을 바꿔 가며 기울기를 따라 내려갔습니다. g(x)는 출발점 0에서 x = 1(값 −2)에 멈췄지만 최솟값은 구간 끝 x = −3의 −18이었고, −x²는 출발점 0에서 기울기 0이라 바로 멈췄지만 그곳은 극대였습니다. f′(a) = 0이 무엇을 보장하고 무엇은 보장하지 않는지 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 함수와 구간(x² · −x² · x³ · x³ − 3x)을 고르고 내려가기 출발점 x 슬라이더를 정한 뒤 판정하고 내려가 보기를 누르면 미분이 0인 점의 부호표와 이계도함수 판정, 최솟값 후보 비교, 기울기를 따라 내려가 멈춘 곳과 판정이 나옵니다. 4개 이상 기록하면 결과 비교 탭에서 멈춘 곳과 최솟값, 함수별 미분 0인 점의 정체를 비교할 수 있습니다.

기울기가 0인 곳에서 멈췄어도 그곳이 최솟값이라는 보장은 없습니다. −x²의 x = 0은 극대, x³의 x = 0은 부호가 + → +로 극값이 아닌 평평한 점이며, x³은 그 근처에서 400걸음 동안 거의 움직이지 못했습니다. g(x)의 극소 x = 1(−2)도 동네에서 가장 낮을 뿐, 닫힌 구간의 최솟값은 구간 끝 x = −3의 −18이었습니다. 최솟값은 미분 0인 점과 양 끝을 모두 후보로 놓고 비교해야 합니다.

개념 정리

1. f′(a) = 0은 필요조건일 뿐

미분 가능한 함수가 구간 안쪽의 점 a에서 극값을 가지면 f′(a) = 0입니다. 하지만 거꾸로 f′(a) = 0이라고 극값인 것은 아니에요. f(x) = x³은 f′(0) = 0이지만 f(−0.1) = −0.001 < f(0) = 0 < f(0.1) = 0.001이라 극값이 아닙니다.

  • 부호표: f′의 부호가 − → + 이면 극소, + → − 이면 극대, 바뀌지 않으면 극값 아님.
  • 이계도함수 판정: f″(a) > 0이면 극소, f″(a) < 0이면 극대, f″(a) = 0이면 판정 불가 → 부호표로 돌아갑니다(x³의 경우).
  • 극소 ≠ 최솟값: 극소는 ‘동네에서’ 가장 낮은 곳, 최솟값은 ‘전체에서’ 가장 낮은 곳입니다.

2. 이 실험의 계산 방법

닫힌 구간의 최솟값 후보 = f′(x) = 0인 점 + 구간의 양 끝 — 후보를 전부 계산해 비교합니다.

g(x) = x³ − 3x, −3 ≤ x ≤ 2: g′(x) = 3(x − 1)(x + 1). g(−3) = −18, g(−1) = 2, g(1) = −2, g(2) = 2 → 최솟값은 미분이 0이 아닌 끝점 x = −3에서 −18, 최댓값은 x = −1과 x = 2에서 2입니다.

점을 움직이면 접선 색이 바뀝니다: 빨강 = 내려감(f′ < 0), 파랑 = 올라감(f′ > 0), 보라 = 평평(f′ = 0). 큰 점은 후보(구간 양 끝 + f′ = 0인 점)이고, 초록 점은 지금까지 지나온 곳에서 가장 낮은 곳입니다. x³ − 3x에서는 극소 x = 1(−2)보다 끝점 x = −3(−18)이 더 낮고, x³은 x = 0에서 평평해도 극값이 아닙니다.

3. 실험 모형과 실제의 차이

· 실제 인공지능 학습 함수는 변수가 수백만 개라 기울기가 0인 점이 아주 많고, 그중 상당수는 어떤 방향으로는 올라가고 어떤 방향으로는 내려가는 말안장 모양입니다. 그래서 ‘기울기가 0이 됐다’만으로 학습이 성공했다고 하지 않아요.

· 최소제곱(회귀)처럼 바닥이 하나뿐인 아래로 볼록한 함수는 미분 0이 곧 최솟값이 되는 예외적인 경우입니다.

웹툰 7화 #5 · 인공지능에서 이게 왜 문제인가

예제

f(x) = x³ − 12x, 구간 −5 ≤ x ≤ 3에서 최솟값과 최댓값을 구하시오.

f′(x) = 3x² − 12 = 3(x − 2)(x + 2) = 0 → x = ±2. 후보: f(−5) = −65, f(−2) = 16, f(2) = −16, f(3) = −9. 최솟값 −65 (x = −5, 구간 끝), 최댓값 16 (x = −2)입니다.

f(x) = x⁴에서 x = 0을 이계도함수로 판정할 수 있는가? 판정할 수 없다면 부호표로 판정하시오.

f′(x) = 4x³, f″(x) = 12x²이라 f″(0) = 0으로 이계도함수 판정은 아무 말도 해 주지 않습니다. f′의 부호가 x < 0에서 −, x > 0에서 +이므로 x = 0은 극소입니다.
