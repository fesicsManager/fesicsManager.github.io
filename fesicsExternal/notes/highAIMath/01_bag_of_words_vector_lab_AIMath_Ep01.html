고등 인공지능 수학 · 웹툰 1화 「컴퓨터는 글의 뜻을 읽는가」

단어 빈도 벡터 — 세는 것만 남고 어순은 사라진다

다섯 문장을 단어장 [고양이, 개, 쫓는다, 공]으로 세어 벡터로 바꾸고, 단어 하나씩 세기와 두 단어 묶음 세기를 비교했습니다. 쫓는 쪽이 반대인 S1과 S2는 단어 하나씩 세면 둘 다 (1, 1, 1, 0)이었지만, 두 단어 묶음으로 세면 갈라졌고 대신 16칸 중 14칸이 0이 되었습니다. 단어 주머니 표현이 무엇을 남기고 무엇을 버리는지 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 문장(S1~S5)과 세는 방법(단어 하나씩 세기 4칸 · 두 단어 묶음 세기 16칸)을 고르고 벡터로 바꾸기를 누르면 조사 뗀 단어, 벡터, 0인 칸 수, 같은 벡터인 다른 문장이 나옵니다. 4개 이상 기록하면 결과 비교 탭에서 문장별로 두 방법의 구별 결과와 0인 칸 비율을 비교할 수 있습니다.

표 1. 문장과 세는 방법에 따른 벡터 (실험 예시)
문장세는 방법벡터0인 칸같은 벡터 문장
S1단어 하나(1, 1, 1, 0)1 / 4S2
S2단어 하나(1, 1, 1, 0)1 / 4S1
S1두 단어 묶음0 아닌 칸 2개14 / 16없음
S2두 단어 묶음0 아닌 칸 2개14 / 16없음
S3단어 하나(0, 1, 1, 1)1 / 4S4
S4두 단어 묶음0 아닌 칸 2개14 / 16없음

단어 하나씩 세면 S1과 S2, S3과 S4가 각각 같은 벡터가 되어 숫자만으로는 누가 누구를 쫓는지 알 수 없습니다. 두 단어 묶음으로 세면 S1(고양이→개, 개→쫓는다)과 S2(개→고양이, 고양이→쫓는다)가 갈라지지만 16칸 중 14칸이 0인 희소 벡터가 됩니다. 또 S3과 S4는 뜻이 같은데도 두 단어 묶음이 달라지니, 묶음 세기도 뜻을 아는 것은 아닙니다.

개념 정리

1. 세는 것만 남고 순서는 사라진다

단어장을 정하고 문장마다 각 단어가 몇 번 나왔는지 세어 한 줄로 적은 것이 단어 빈도 벡터입니다. 세기만 하므로 어떤 단어가 몇 번 나왔는지는 남지만 어순은 남을 자리가 없어요. 그래서 ‘고양이가 개를 쫓는다’와 ‘개가 고양이를 쫓는다’는 둘 다 (1, 1, 1, 0)입니다. 단어를 자루에 쏟아 넣고 세는 것과 같아서 단어 주머니(bag of words)라고 불러요.

2. 문서–단어 행렬

문장 하나를 행 하나, 단어 하나를 열 하나로 쌓은 표가 문서–단어 행렬입니다. 문장 3개 × 단어 4개면 3 × 4 행렬이고, 문장이 늘면 행이, 단어장이 늘면 열이 늘어요.

3. 이 실험의 계산 방법

단어 하나: 칸 = 단어장 단어 수 (4칸) · 두 단어 묶음: 칸 = 4 × 4 = 16칸, 앞 단어 → 뒤 단어 쌍마다 1씩

세 단어 문장에는 이웃한 쌍이 2개뿐이라 16칸 중 많아야 2칸만 0이 아닙니다. 이렇게 대부분이 0인 행렬을 희소 행렬이라고 해요.

4. 실험 모형과 실제의 차이

· 실제 단어장은 수만 개 단어라 두 단어 묶음은 수억 칸이 될 수 있어, 0인 칸은 저장하지 않는 방법을 씁니다.

· 두 단어 묶음은 어순을 일부 살리지만 뜻을 아는 것은 아닙니다. ‘공을 개가 쫓는다’처럼 뜻이 같아도 순서가 다르면 다른 벡터가 돼요.

5. 생활 속에서 · 이어지는 개념

  • 스팸 메일 거르기, 문서 분류의 가장 기본적인 입력이 단어 빈도 벡터입니다. 번역기·챗봇은 순서와 문맥까지 담는 더 복잡한 벡터를 쓰지만, 출발점은 ‘글을 숫자로 바꾼다’는 같은 생각이에요.
단어 빈도 벡터 = (단어장 각 단어가 나온 횟수), 두 단어 묶음의 칸 수 = (단어장 크기)²

제로 · 닥터 이안

“대신 열이 엄청 늘겠네요. 단어가 4개면 두 단어 묶음은 4 × 4 = 16가지예요.” “그렇다. 정보를 더 담으려면 차원이 커진다.”

웹툰 1화 #5 · 순서를 되살리는 방법

예제

단어장 [고양이, 개, 쫓는다, 공]으로 ‘고양이가 공을 쫓는다’를 조사를 떼고 단어 하나씩 센 벡터와, 두 단어 묶음으로 셀 때 0이 아닌 칸을 구하시오.

단어는 고양이 · 공 · 쫓는다이므로 벡터는 (1, 0, 1, 1)입니다. 이웃한 쌍은 고양이→공, 공→쫓는다 두 개라 0이 아닌 칸은 고양이→공 1, 공→쫓는다 1(나머지 14칸 0)입니다.

문장 3개를 단어장 4개 단어로 센 문서–단어 행렬의 크기를 구하고, 단어장을 10개 단어로 늘리면 두 단어 묶음의 칸이 몇 개가 되는지 구하시오.

행 = 문장 3개, 열 = 단어 4개이므로 3 × 4 행렬입니다. 단어장이 10개면 두 단어 묶음은 10 × 10 = 100칸입니다.
