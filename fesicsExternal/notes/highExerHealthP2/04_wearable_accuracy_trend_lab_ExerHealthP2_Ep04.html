고등 운동과 건강 ② · 웹툰 4화 「스마트워치 숫자는 정확한가」

측정값과 추정값 — 기기 숫자는 종류를 알고 추세로 쓴다

손목 기기의 측정 항목을 바꾸며 2주 동안(둘째 주는 실제로 10% 늘림) 실제 값과 기기 값을 비교해 하루 값의 오차와 두 주 변화(추세)의 오차를 기록했습니다. 보통 걸음 수는 하루 오차 2.0%, 추세 오차 0.7%p로 정확했지만, 소모 열량은 하루 오차 42.5%, 수면 단계는 추세마저 실제 +10%를 −11.5%로 보여 오차가 21.6%p였습니다. 직접 잰 값과 추정한 값을 구분해 쓰는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: ‘측정 항목’(걸음 수 세 조건·심박수 두 조건·소모 열량·수면 총시간·수면 단계)과 ‘보는 방식’(하루 값 그대로·지난주 대비 변화)을 고른 뒤 2주 기록 비교를 누르면 날마다의 실제 값(회색 막대)과 기기 값(파란 점)이 그려지고, 하루 값 오차와 추세 오차가 기록됩니다. 같은 항목에서 보는 방식을 번갈아 보고, 여러 항목을 비교해 보세요. 기록이 4개 이상이면 결과 비교 탭이 열립니다. (항목별 오차 크기는 비교 연구의 일반적 경향을 흉내 낸 가상 값이에요. 기기가 이상 신호를 보여도 스스로 판정하지 말고 의료인에게 확인하세요)

표 1. 항목별 하루 값 오차와 추세 오차 (실제 변화 +10%, 가상 모형)
항목하루 값 오차기기의 두 주 변화추세 오차
걸음·보통2.0%+10.7%0.7%p
걸음·느림33.1%+16.2%6.2%p
심박·안정1.6%+10.2%0.1%p
심박·급변9.0%+14.2%4.2%p
소모 열량42.5%+19.8%9.7%p
수면 단계31.7%−11.5%21.6%p

움직임 센서로 직접 재는 보통 걸음 수와 안정 시 심박수는 하루 값 오차가 2% 안팎으로 작았습니다. 반면 여러 값을 섞어 추정하는 소모 열량은 하루 값 오차가 42.5%였어요. 단계를 여러 번 거쳐 추정할수록 오차가 쌓이므로, 기기 숫자는 절대값보다 같은 기기·같은 조건에서의 변화 추세로 쓰는 것이 낫습니다. 소모 열량도 추세로 보면 오차가 9.7%p로 줄었어요. 다만 잡음이 매우 큰 수면 단계는 실제로 10% 늘었는데 기기는 −11.5%로 보여, 추세마저 믿기 어려웠습니다. 기록은 민감한 개인정보이니 저장·공유 범위를 확인하고, 숫자가 목적이 되어 손을 흔들어 걸음 수를 채우는 식으로 행동이 비뚤어지지 않게 합니다.

개념 정리

1. 직접 잰 값과 추정한 값은 다르다

손목 기기는 움직임 센서로 흔들림을 재서 걸음 수로 바꾸고, 빛을 비춰 혈류 변화를 읽어 심박수를 내고, 그걸 다시 키·몸무게·나이와 섞어 소모 열량을 추정합니다. 단계를 여러 번 거칠수록 오차가 쌓여요.

항목기준 장비와 비교한 경향
걸음 수 (보통 걷기)비교적 정확
걸음 수 (아주 느린 걸음·카트 밀기)적게 세는 경향
심박수 (안정 시)비교적 정확
심박수 (강도 급변·손목 많이 쓰는 운동)오차 커짐
소모 열량오차가 큼 (연구에 따라 수십 % 차이)
수면 총시간 / 수면 단계대체로 근접 / 정확도 낮음

기기 값 = 실제 값 × (1 + 치우침) + 날마다 다른 잡음 — 치우침이 일정하면 같은 기기·같은 조건의 변화 추세는 비교적 믿을 만합니다.

  • 숫자가 목적이 되면 손을 흔들어 걸음 수를 채우는 식으로 행동이 비뚤어집니다. 기록이 불안을 키우기도 해요. 그리고 이 기록은 민감한 개인정보이니 저장·공유 범위를 확인합니다.

2. 실험 모형과 실제의 차이

· 항목별 치우침·잡음(예: 소모 열량 +30% ± 25%)은 가상 값입니다. 실제 오차는 기기 모델·착용 위치·사람에 따라 달라요. "손을 주머니에 넣고 걷기"는 대본 과제 조건을 흉내 낸 가상 항목이에요.

예제

직접 센 100걸음을 기기가 아주 느린 걸음에서 72걸음으로 셌다. 오차는 몇 %이며, 표의 어떤 경향과 맞는가?

(100 − 72) ÷ 100 = 28% 적게 셌다. 아주 느린 걸음은 움직임 센서가 흔들림을 덜 잡아 ‘적게 세는 경향’이 있다(실험의 하루 값 오차 33.1%). 28% — 느린 걸음은 적게 셈

기기가 지난주 하루 평균 소모 열량을 500kcal, 이번 주를 550kcal로 보여 주었다. 기기의 치우침이 일정하다면 무엇을 믿을 수 있고 무엇은 어림값으로 봐야 하는가?

변화율 = (550 − 500) ÷ 500 = 10% 늘었다는 추세는 비교적 믿을 만하다. 그러나 500·550이라는 절대값은 수십 % 오차가 있을 수 있어 식사량 계산에 그대로 쓰지 않고 어림값으로 본다. 추세(+10%)는 참고, 절대값은 어림값
