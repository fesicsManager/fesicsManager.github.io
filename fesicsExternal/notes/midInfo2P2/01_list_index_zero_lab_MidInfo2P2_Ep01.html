리스트와 인덱스 — 첫 칸은 0칸 떨어진 0번

파이썬 리스트 과일 = ['사과', '배', '귤', '감']에서 인덱스를 바꿔 가며 print(과일[i])를 실행하고, append로 늘리거나 0번 칸을 바꾼 뒤에도 출력을 기록했습니다. 과일[2]는 ‘귤’, 과일[4]는 IndexError였지만 append('밤') 뒤에는 과일[4]가 ‘밤’이 되었어요. 인덱스가 0부터인 까닭, len과 마지막 칸 번호, 리스트 다루기를 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 리스트 상태(처음 네 칸 · 과일.append('밤') 실행 후 · 과일[0] = '포도' 실행 후)와 print(과일[ i ])의 i(0 · 1 · 2 · 3 · 4 · −1)를 고르고 실행하면 리스트 칸과 번호가 그려지고 출력 또는 오류가 표시됩니다. 처음 네 칸에서 인덱스 0~4를 모두 실행해 보고, append 뒤에 4번이 어떻게 되는지 기록해 보세요.

인덱스는 ‘맨 앞에서 몇 칸 떨어져 있나’라서 맨 앞 칸은 0번, 과일[2]는 세 번째 칸인 ‘귤’입니다. 네 칸짜리 리스트의 마지막 칸은 len(과일) − 1 = 3번이라 과일[4]를 부르면 IndexError가 나요. append('밤')로 한 칸 늘면 새 칸 번호가 4가 되고, −1은 뒤에서부터 세어 언제나 마지막 칸입니다.

개념 정리

1. 인덱스는 "맨 앞에서 몇 칸 떨어져 있나"

리스트는 여러 값을 한 이름 아래 줄 세워 담는 자료 구조예요. 맨 앞 칸은 0칸 떨어져 있으니 0번입니다.

칸 수 = len(리스트) · 마지막 칸 번호 = len(리스트) − 1

  • 과일[4]처럼 없는 칸을 부르면 IndexError: list index out of range 실행 오류가 나요.
  • range(4)는 0, 1, 2, 3을 만들어서 for i in range(len(과일))로 모든 칸을 빠짐없이 돕니다.
  • 파이썬에서는 과일[-1]처럼 음수를 쓰면 뒤에서부터 셉니다(−1 = 마지막 칸).

2. 리스트 다루기

과일.append('밤') → 맨 뒤에 한 칸 늘어 5칸, 새 칸 번호는 4. 과일[0] = '포도' → 0번 칸의 값이 바뀌어요. 변수 100개 대신 리스트 하나에 100칸이면 됩니다.

칸 수 = len(리스트) · 마지막 칸 번호 = len(리스트) − 1 · range(len(리스트)) = 0, 1, …, len − 1

예제

색 = ['빨강', '주황', '노랑', '초록', '파랑']일 때 print(색[3])의 출력과, 이 리스트의 마지막 칸 번호는?

0번 빨강, 1번 주황, 2번 노랑, 3번 초록이므로 출력은 ‘초록’입니다. 칸 수는 5이므로 마지막 칸 번호는 5 − 1 = 4예요. 초록, 4번

월요일 시간표 6교시를 리스트 시간표에 담았다. ‘3교시’ 과목은 몇 번 칸이고, for i in range(len(시간표))에서 i는 어떤 값들을 차례로 갖는가?

1교시가 0번이므로 3교시는 2번 칸입니다. len(시간표) = 6이고 range(6)은 0, 1, 2, 3, 4, 5를 만들어 모든 칸을 빠짐없이 돌아요.
