중학교 2학년 정보 ② · 웹툰 8화 「되돌리기는 마지막부터」

스택과 큐 — 넣는 순서는 같아도 꺼내는 순서가 반대

선 A·B·C(또는 낱말 다섯 개)를 차례로 넣은 뒤 스택(되돌리기, pop())과 큐(인쇄 대기열, pop(0))로 꺼내는 횟수를 바꾸며 꺼낸 순서와 남은 것을 기록했습니다. 스택은 C → B → A, 큐는 A → B → C 순서로 나왔고, 낱말 다섯 개에서 세 번 꺼내자 스택은 [‘사과’, ‘배’], 큐는 [‘감’, ‘밤’]이 남았어요. 후입선출·선입선출과 파이썬 리스트로 흉내 내는 방법, 목적에 맞는 자료 구조 고르기를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 자료 구조(스택 — 되돌리기(pop()) · 큐 — 인쇄 대기열(pop(0))), 넣은 것(선 A·B·C(그림판) · 낱말 다섯 개(과제)), 꺼내는 횟수(0~4번)를 고르고 실행하면 넣고 꺼내는 과정이 그려지고 꺼낸 순서, 남은 리스트, 비어 있을 때 꺼내기 오류가 표시됩니다. 선 A·B·C로 스택과 큐를 각각 1번, 3번 꺼내 비교하고, 낱말 다섯 개로 과제 결과도 기록해 보세요.

표 1. 자료 구조와 꺼낸 횟수에 따른 결과 (실험 예시, 낱말 다섯 개 = 사과·배·귤·감·밤)
구조넣은 것꺼낸 횟수꺼낸 순서남은 것
스택선 A·B·C1CA, B
큐선 A·B·C1AB, C
스택선 A·B·C3C → B → A(빈 리스트)
큐선 A·B·C3A → B → C(빈 리스트)
스택낱말 5개3밤 → 감 → 귤사과, 배
큐낱말 5개3사과 → 배 → 귤감, 밤
스택선 A·B·C4C → B → A, 4번째는 오류(빈 리스트)

스택은 마지막에 넣은 것을 먼저 꺼내고(후입선출), 큐는 먼저 넣은 것을 먼저 꺼냅니다(선입선출). 그래서 되돌리기를 한 번 누르면 방금 그린 C가 사라지고, 인쇄 대기열은 먼저 보낸 A부터 나와요. 같은 파이썬 리스트도 append로 넣고 pop()으로 맨 뒤를 꺼내면 스택, pop(0)으로 맨 앞을 꺼내면 큐입니다. 빈 리스트에서 더 꺼내면 IndexError가 났어요.

개념 정리

1. 넣는 순서는 같아도 꺼내는 순서가 반대

  • 스택: 마지막에 넣은 것을 먼저 꺼낸다 (접시 쌓기, 후입선출). 되돌리기, 브라우저 "뒤로 가기"
  • 큐: 먼저 넣은 것을 먼저 꺼낸다 (줄 서기, 선입선출). 인쇄 대기열, 메시지 차례대로 보내기, 대기 번호표

파이썬 리스트: append로 넣기 · pop()으로 맨 뒤 꺼내기 = 스택 · pop(0)으로 맨 앞 꺼내기 = 큐

같은 리스트도 꺼내는 규칙이 자료 구조의 이름을 정해요.

2. 목적이 자료 구조를 고른다

목적이 "방금 것 취소"면 스택, "온 순서대로 처리"면 큐. 되돌리기가 큐였다면 방금 한 실수를 고치려다 맨 처음 그린 것을 지웠을 거예요.

스택: append + pop() — 마지막에 넣은 것부터 · 큐: append + pop(0) — 먼저 넣은 것부터

웹툰 8화 #4 · 되돌리기 한 번에 C가 사라짐 — 제로 8 : 뭉치 0

예제

브라우저에서 학교 누리집 → 공지사항 → 급식표 순서로 이동했다. ‘뒤로 가기’를 한 번, 두 번 누르면 각각 어느 화면이 보이는가?

‘뒤로 가기’는 스택이라 가장 최근 페이지부터 거꾸로 돌아갑니다. 한 번 누르면 공지사항, 두 번 누르면 학교 누리집이 보여요.

리스트에 낱말 ‘가’, ‘나’, ‘다’, ‘라’를 차례로 append한 뒤 pop()을 두 번 하면 남은 리스트는? pop(0)을 두 번 하면?

pop()은 맨 뒤부터 꺼내므로 ‘라’, ‘다’가 나오고 [‘가’, ‘나’]가 남습니다. pop(0)은 맨 앞부터 꺼내므로 ‘가’, ‘나’가 나오고 [‘다’, ‘라’]가 남아요.
