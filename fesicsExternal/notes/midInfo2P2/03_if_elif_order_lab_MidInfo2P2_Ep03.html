조건 순서 — 가장 알맞은 것이 아니라 처음 맞는 것

성적 등급 프로그램의 조건을 if–elif 60 → 80 → 90, if–elif 90 → 80 → 60, if 세 개로 바꾸며 점수를 넣어 검사 수와 결과 등급을 기록했습니다. 60 → 80 → 90 순서에서는 65·85·95점이 모두 C였지만, 순서만 90 → 80 → 60으로 뒤집자 A·B·C가 바르게 나왔어요. if–elif가 위에서부터 검사하다 처음 참에서 멈춘다는 것과 죽은 코드, if 세 개와의 차이를 정리합니다.

if–elif는 위에서부터 검사하다 처음 참이 된 곳에서 멈춥니다. 60 → 80 → 90 순서면 60 이상인 점수는 모두 첫 줄에 걸려 B·A 줄은 실행되지 않는 죽은 코드가 돼요. 조건 내용은 그대로 두고 범위가 좁은 조건(90 이상)부터 쓰자 바르게 동작했습니다. if를 세 번 쓰면 세 줄을 모두 검사해 마지막 값이 남으므로, 어떤 점수에서도 맞는 등급이 나오지만, 순서에 기대는 코드라 순서를 뒤집으면 95점이 C가 돼요.

개념 정리

1. "가장 알맞은 것"이 아니라 "처음 맞는 것"

if와 elif는 위에서부터 차례로 검사하다가 처음 참이 된 곳에서 멈춥니다. 그 아래는 보지도 않아요.

60 → 80 → 90 순서면 60 이상인 점수는 모두 첫 줄에 걸려 B·A 줄은 절대 실행되지 않는 죽은 코드가 됩니다.

하나만 골라야 할 때: elif로 묶고, 범위가 좁은 조건(90 이상)부터

2. if 세 개 vs if–elif

  • if를 따로 세 번 쓰면 세 줄을 모두 검사해서, 참인 줄마다 값을 덮어씁니다. 마지막에 넣은 값이 남아요.
  • 60 → 80 → 90 순서의 if 세 개는 뒤 줄이 앞 값을 덮어써서 어떤 점수에서도 맞는 등급이 나와요. 하지만 순서에 기대는 코드라 순서를 뒤집으면 95점이 C가 되고, 필요 없는 검사와 대입도 늘어납니다. 하나만 고를 때는 elif가 읽기 쉽고 효율적이에요.

3. 이 실험의 코드

if–elif: 위에서부터 검사 → 처음 참인 줄만 실행하고 멈춤 · 하나만 고를 땐 범위가 좁은 조건부터

예제

다음 코드에 기온 30을 넣으면 옷에 들어가는 값은? if 기온 >= 10: 옷 = ‘얇은 겉옷’ / elif 기온 >= 25: 옷 = ‘반팔’ / else: 옷 = ‘두꺼운 외투’

30은 첫 조건 기온 ≥ 10에서 이미 참이라 거기서 멈추고 아래 줄은 검사하지 않습니다. ‘얇은 겉옷’

나이에 따라 요금을 어린이(12세 이하)·청소년(13~18세)·어른(19세 이상)으로 정한다. 하나만 바르게 고르도록 if–elif 조건 순서를 쓰시오.

범위가 좁은 쪽부터 쓰면 됩니다. if 나이 >= 19: 어른 / elif 나이 >= 13: 청소년 / else: 어린이. 나이 5 → 어린이, 15 → 청소년, 30 → 어른이 나와요.
