초등 5~6학년 미술 · 웹툰 6화 「화면 속 노랑엔 노랑 점이 있을까」

빛의 혼합 — 화면은 빨강·초록·파랑 빛 점으로 모든 색을 만들어요

화면의 빨강·초록·파랑 빛 점을 하나씩 켜고 끄며 멀리서 보이는 색을 기록했습니다. 빨강과 초록 빛 점만 켜자 노랑으로 보였고, 셋 다 켜면 흰색, 모두 끄면 검정이었습니다. 화면에는 노랑 빛 점이 없었어요. 빛은 섞을수록 밝아지고 물감은 섞을수록 어두워진다는 차이를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 빨강·초록·파랑 빛 점을 각각 켜기 또는 끄기로 고르고 빛 켜기를 누르세요. 세 빛 점의 상태(● 켜짐, ○ 꺼짐)와 우리 눈에 보이는 색이 기록됩니다. 4개 이상 기록하면 결과 비교 탭에 빛 점 관찰표가 열려요.

표 1. 빛 점을 켜고 끈 기록 (실험 예시)
빨강초록파랑보이는 색
●●○노랑
●●●흰색
○●●하늘색(청록)
●○●자주
○○○검정
●○○빨강

화면에는 빨강·초록·파랑 빛 점만 있는데 빨강 + 초록을 함께 켜자 노랑으로 보였어요. 초록 + 파랑은 하늘색, 빨강 + 파랑은 자주, 셋 다 켜면 흰색이 되었어요. 켜진 빛이 많을수록 밝아졌고, 모두 끄면 검정이었어요. 물감은 섞을수록 어두워졌는데 빛은 섞을수록 밝아져요. 정반대예요.

개념 정리

1. 빛은 더할수록 밝아진다

화면에는 노랑 빛 점이 없어요. 빨강 + 초록 빛을 함께 켜면 우리 눈에는 노랑으로 보여요.

  • 빨강 + 초록 = 노랑
  • 초록 + 파랑 = 하늘색(청록)
  • 빨강 + 파랑 = 자주
  • 셋 다 켜면 흰색, 모두 끄면 검정

2. 물감과 정반대

물감은 섞을수록 어두워지고(노랑 + 파랑 = 초록), 빛은 섞을수록 밝아져요(빨강 + 초록 = 노랑). 그래서 화면에서 고른 아주 밝은 색이 종이에 인쇄하면 덜 밝게 나오기도 해요. 왜 다르게 섞이는지는 중학교에서 더 자세히 배워요.

3. 실험 모형과 실제의 차이

· 화면마다 빛 점 모양(줄, 점, 세모 배열)이 달라요. 돋보기로 볼 때는 짧게 보고, 눈이 피곤하면 바로 쉬세요.

빨강 + 초록 = 노랑 · 초록 + 파랑 = 하늘색(청록) · 빨강 + 파랑 = 자주 · 셋 다 = 흰색 · 모두 끔 = 검정 (빛은 더할수록 밝아진다)
닥터 이안
