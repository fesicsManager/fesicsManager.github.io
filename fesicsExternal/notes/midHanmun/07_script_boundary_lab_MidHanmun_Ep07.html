문자 선택 — 문자 정책은 언어의 조건과 맞물린다

같은 뜻의 문장(貴社の記者が汽車で帰社した)을 한국어와 일본어로, 소리 글자만 붙여 쓰기·소리 글자만 띄어 쓰기·한자 섞어 쓰기의 세 방식으로 적고 같은 소리 단어 수와 읽기 막힘 지수를 기록했습니다. 일본어는 ‘きしゃ’로 적힌 단어가 넷이라 가나로 붙여 쓰면 지수 6이었지만, 한자를 섞으면 0이 되었습니다. 한국과 일본이 다른 문자 선택을 한 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 언어(한국어·일본어)와 적는 방식(소리 글자만 붙여 쓰기 / 소리 글자만 띄어 쓰기 / 한자 섞어 쓰기)을 고르고 이 방식으로 적어 보기를 누르세요. 같은 소리로 적힌 서로 다른 단어에 같은 색 밑줄이 그어지고, 같은 소리 단어 수·단어 경계 표시·읽기 막힘 지수가 나옵니다. 두 언어를 세 방식으로 모두 적어 보세요(6가지). 지수는 이 실험용 단순 모형입니다.

한국어로 적으면 ‘귀사’(貴社·歸社) 두 단어만 소리가 같지만, 일본어는 貴社·記者·汽車·帰社가 모두 ‘きしゃ’라 소리 글자만으로는 구별이 어렵습니다. 한국어는 띄어쓰기로 단어 경계를 표시하고, 일본어는 띄어쓰기를 하지 않는 대신 한자가 뜻과 단어 경계를 함께 표시합니다. 문자 정책은 ‘한자가 어렵다’로만 설명되지 않고, 각 언어의 동음이의어 양·표기 체계·띄어쓰기 여부와 역사·정책 선택이 함께 작용한 결과입니다. 실제 읽기에서는 문장 전체의 맥락이 많은 모호함을 풀어 줍니다.

개념 정리

1. 문자 정책은 언어의 조건과 맞물린다

한자를 쓰지 않게 된 까닭을 "어려워서"로만 설명하면, 동아시아 다섯 곳이 서로 다른 선택을 한 이유를 설명하지 못합니다. 각 언어의 동음이의어 양, 표기 체계, 띄어쓰기 여부가 함께 작용했어요.

  • 한국어: 한글은 음소 문자라 소리를 세밀하게 구별하고, 띄어쓰기로 단어 경계를 표시 → 한글 전용이 잘 작동
  • 일본어: 같은 소리의 한자어가 매우 많고 띄어쓰기를 하지 않음 → 한자가 뜻과 단어 경계를 함께 표시

2. 이 실험의 계산 방법

읽기 막힘 지수 = 같은 소리로 적힌 단어 수 + (경계 표시가 없으면 2) 한자로 적힌 단어는 모양이 달라 소리가 같아도 구별됩니다.

움직여 보기

읽기 막힘 지수 = 같은 소리 단어 + 경계 없음 2

사례 같은 소리 단어 경계 없음 막힘 지수

사례를 고르면 막대가 쌓입니다. 주황은 같은 소리로 적힌 단어 수, 보라는 단어 경계 표시가 없을 때 더하는 2예요. 띄어쓰기는 보라를, 한자 섞어 쓰기는 주황까지 없앱니다. 맥락을 뺀 단순 비교 모형입니다.

3. 실험 모형과 실제의 차이

· 실제 읽기에서는 문장 전체의 맥락이 많은 모호함을 풀어 줍니다. 지수는 비교를 위한 단순 모형이에요.

· 일본 어린이 책처럼 가나만으로 쓸 때 띄어 쓰는 경우도 있습니다.

4. 생활 속에서 · 이어지는 개념

  • 한자 병기 논쟁의 실제 쟁점은 "한자가 좋은가"가 아니라 "어디에 얼마나 쓸 때 이해에 도움이 되는가"입니다. 전문 용어나 동음이의어가 헷갈리는 자리에 보조로 쓰는 방식이 대표적인 절충점이에요.

예제

한국어 문장을 소리 글자만 붙여 쓰기 → 띄어 쓰기 → 한자 섞어 쓰기로 바꿀 때 막힘 지수는 각각 얼마이고, 무엇이 지수를 줄였는가?

4 → 2 → 0. 띄어쓰기가 경계 표시가 없을 때의 2점을 없앴고, 한자가 같은 소리 단어 2개(貴社·歸社)를 모양으로 구별했습니다.

동아시아 문자 정책 표에서 대만·홍콩과 중국 본토, 베트남은 각각 어떤 선택을 했는가?

대만·홍콩은 번체자(전통 자형 유지), 중국 본토는 간화자(획을 줄인 글자), 베트남은 로마자 표기(한자 사용 중단)입니다. 같은 한자 문화권에서도 선택이 모두 달랐어요.
