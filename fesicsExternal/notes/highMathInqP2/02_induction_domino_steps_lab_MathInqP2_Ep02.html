고등 수학과제 탐구 ② · 웹툰 2화 「끝없는 경우는 증명할 수 없는가」

수학적 귀납법 — 시작 단계와 이어짐 단계가 모두 있어야 끝없이 쓰러진다

명제, 보고서에 쓴 단계(시작만 / 이어짐만 / 두 단계 모두), 검산할 k를 바꾸며 도미노가 몇 개 쓰러지는지 기록했습니다. 홀수의 합 명제는 두 단계를 모두 썼을 때만 끝없이 모두 쓰러졌고, ‘n² + n은 홀수’는 이어짐 단계가 성립해도 시작 단계가 거짓이라 하나도 쓰러지지 않았습니다. 확인과 증명의 차이, 수학적 귀납법의 두 단계를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: ‘명제’(홀수의 합 = n² / 자연수의 합 / n² + n은 홀수), ‘보고서에 쓴 단계’(시작 단계만 / 이어짐 단계만 / 두 단계 모두), ‘이어짐 단계를 검산할 k’(1~10)를 고른 뒤 단계 확인하고 도미노 밀기를 누르면 k에 해당하는 점 그림(파랑 = 가정한 부분, 주황 = 더하는 부분)과 검산식이 나오고, 도미노 10개 중 몇 개가 쓰러지는지 보여 줍니다. 홀수의 합에서 세 가지 단계를 차례로 기록하고 n² + n 명제도 기록해, 기록이 4개 이상이면 결과 비교 탭에서 명제 · 단계별 증명 완성 여부와 k별 검산표를 볼 수 있습니다.

홀수의 합에서 시작 단계만 쓰면 첫 도미노 1개만, 이어짐 단계만 쓰면 하나도 쓰러지지 않았고, 두 단계를 모두 썼을 때만 끝없이 모두 쓰러졌습니다. k = 3 검산은 9 + 7 = 16 = 4²이지만, 이 숫자 검산이 아니라 k² + (2k + 1) = (k + 1)²이라는 일반식이 모든 k를 한 번에 해결합니다. ‘n² + n은 홀수’는 k = 3에서 12 + 8 = 20으로 이어짐 계산이 맞아도 n = 1에서 2(짝수)라 첫 도미노가 서 있지 않아 0개였습니다.

도미노와 수학적 귀납법 — 두 단계가 모두 있어야 끝까지 간다

쓰러진 도미노

버튼으로 두 단계를 하나씩 꺼 보세요. 시작 단계를 끄면 하나도 쓰러지지 않고, 이어짐 단계를 끄면(여기서는 5번과 6번 사이가 끊긴 경우) 중간에서 멈춥니다. 도미노 10개는 '끝없이'를 나타낸 그림입니다.

2. 한 단계라도 빠지면

'n² + n은 홀수다': k² + k가 홀수라면 (k + 1)² + (k + 1) = (k² + k) + 2(k + 1)이므로 홀수 + 짝수 = 홀수 — 이어짐 단계는 성립합니다. 그런데 n = 1이면 1 + 1 = 2, 짝수라 시작 단계가 무너집니다. 실제로 n² + n = n(n + 1)은 연속한 두 수의 곱이라 항상 짝수예요.

3. 1 + 3 + ⋯ + (2n − 1) = n²

시작: n = 1이면 왼쪽 1, 오른쪽 1² = 1 ✔

이어짐: k² + (2k + 1) = (k + 1)² ✔ — k × k 점 정사각형에 2k + 1개의 점을 'ㄱ'자를 뒤집은 모양으로 붙이면 (k + 1) × (k + 1) 정사각형이 됩니다.

n을 하나씩 늘려 보세요. k × k 정사각형(회색)에 주황색 2k + 1개를 붙이면 언제나 (k + 1) × (k + 1) 정사각형이 됩니다. 그림은 n = 8까지만 보여 주지만, 식 k² + (2k + 1) = (k + 1)²은 모든 k에서 성립합니다.

4. 실험 모형과 실제의 차이

· 실험은 k = 1~10에서 이어짐 단계를 숫자로 검산합니다. 검산은 증명이 아니고, 증명은 위의 식처럼 모든 k에서 한 번에 성립하는 계산이에요.

· 도미노 10개는 "끝없이"를 나타낸 그림입니다.

5. 생활 속에서 · 이어지는 개념

  • 보고서에는 시작 단계와 이어짐 단계를 따로 적고, n = 1~5의 표는 '추측을 만든 자료'로 구분해 붙이세요.
시작: n = 1에서 성립 + 이어짐: n = k에서 성립 ⇒ n = k + 1에서 성립 → 모든 자연수 n에서 성립 · k² + (2k + 1) = (k + 1)²

웹툰 2화 #2 · 도미노 세우기

예제

1 + 2 + ⋯ + n = n(n + 1) ÷ 2를 수학적 귀납법으로 증명하라.

시작: n = 1이면 왼쪽 1, 오른쪽 1 × 2 ÷ 2 = 1 ✔. 이어짐: 1 + ⋯ + k = k(k + 1) ÷ 2라고 하면, 양변에 k + 1을 더해 k(k + 1) ÷ 2 + (k + 1) = (k + 1)(k + 2) ÷ 2 ✔ (실험의 k = 4 검산: 10 + 5 = 15 = 5 × 6 ÷ 2). 두 단계가 모두 성립하므로 모든 자연수 n에서 성립

2 + 4 + ⋯ + 2n = n(n + 1)의 이어짐 단계에서 더해야 할 항과 정리한 식을 쓰고, k = 3으로 검산하라.

n = k에서 성립한다고 하면 다음 항 2(k + 1)을 더해 k(k + 1) + 2(k + 1) = (k + 1)(k + 2)가 됩니다. k = 3: 3 × 4 + 8 = 20 = 4 × 5 ✔. 시작 단계(n = 1: 2 = 1 × 2)도 따로 써야 증명이 완성됩니다. 더할 항 2(k + 1), (k + 1)(k + 2)
