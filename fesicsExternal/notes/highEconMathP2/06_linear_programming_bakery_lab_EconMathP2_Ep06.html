선형 계획 — 이윤이 가장 큰 계획은 영역의 꼭짓점에 있다

빵 x개, 케이크 y개를 만들 때 밀가루와 오븐 시간이 만드는 영역에서 생산 계획을 고르고 이윤 P = 3x + c·y를 기록했습니다. 케이크만 20개는 100천 원, 빵만 30개는 90천 원이었지만 빵 20 · 케이크 10이 110천 원으로 가장 컸고, 케이크 이윤이 7천 원이 되자 최적이 (0, 20)으로 옮겨 갔습니다. 부등식의 영역과 꼭짓점 비교로 최적 계획을 찾는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 케이크 1개 이윤(2천 원 · 5천 원 · 7천 원), 하루 밀가루(40kg · 50kg), 생산 계획(케이크만 최대로, 빵만 최대로, 빵 20 · 케이크 10, 빵 15 · 케이크 15, 이윤 직선 밀어 올리기)을 고르고 이윤 계산하기를 누르면 영역 위에 계획 점과 이윤 직선이 그려지고 자원 사용량과 이윤이 나옵니다. 대본 조건에서 다섯 계획을 모두 계산하고 케이크 이윤을 바꿔 기록하면 결과 비교 탭에서 조건별 최적 꼭짓점을 볼 수 있습니다.

케이크만 20개 만들면 밀가루는 다 쓰지만 오븐이 10시간 놀아 이윤이 100천 원에 그쳤고, 남는 오븐을 빵으로 채운 (20, 10)이 110천 원으로 가장 컸습니다. (15, 15)는 밀가루 45kg이 필요해 만들 수 없었어요. 이윤 직선 3x + 5y = k를 밀어 올리면 영역에서 마지막으로 닿는 점은 언제나 꼭짓점이고, 케이크 이윤이 7천 원이 되자 이윤 직선의 기울기가 바뀌어 최적 꼭짓점이 (0, 20)으로 옮겨 갔습니다.

개념 정리

1. 최댓값은 영역의 꼭짓점에서

제약 x + 2y ≤ 밀가루, x + y ≤ 30, x ≥ 0, y ≥ 0이 만드는 영역 안에서 이윤 P = 3x + 5y가 가장 큰 점을 찾습니다. 이윤 직선 3x + 5y = k를 k를 키우며 밀어 올리면, 영역에서 마지막으로 닿는 점은 언제나 꼭짓점이에요.

  • 밀가루 40kg: 꼭짓점 (0, 0), (30, 0), (0, 20), (20, 10) → 이윤 0, 90, 100, 110.
  • 케이크만 20개면 오븐이 10시간 놉니다. 모자란 자원(밀가루) 1kg당 이윤은 빵 3천 원, 케이크 2.5천 원이에요.
  • 케이크 이윤이 6천 원을 넘으면 케이크만, 3천 원보다 작으면 빵만 만드는 것이 최선이 됩니다.

2. 이 실험의 계산 방법

x + 2y = F와 x + y = 30의 교점: y = F − 30, x = 60 − F 각 꼭짓점에서 P = 3x + c·y를 비교

3. 실험 모형과 실제의 차이

· 실제 공장은 제품·자원이 많아 같은 원리를 컴퓨터로 풉니다.

· 판매량 한계, 재고, 개수가 정수여야 하는 조건이 붙으면 답이 달라질 수 있어요.

뭉치 · 제로

“케이크는 하나에 5천 원 남고 빵은 3천 원 남아! 그럼 케이크만 잔뜩 만들면 이윤이 최대지!” “밀가루가 정해져 있으면 케이크는 몇 개까지 만들 수 있는데?”

웹툰 6화 #1 · 뭉치가 케이크만 굽는다

닥터 이안

“3x + 5y = k인 직선을 k를 키우며 밀어 올리면, 영역에서 마지막으로 닿는 점이 꼭짓점 (20, 10)이다. 선형 계획에서 최댓값은 영역의 꼭짓점에서 나온다.”

웹툰 6화 #4 · 꼭짓점 표와 이윤 직선

예제

밀가루를 50kg으로 늘렸을 때(오븐 30시간, 빵 3천 원 · 케이크 5천 원) 영역의 꼭짓점을 모두 구하고, 이윤이 가장 큰 계획과 그 이윤을 찾으시오.

x + 2y = 50과 x + y = 30의 교점은 y = 20, x = 10. 꼭짓점 (0, 0), (30, 0), (10, 20), (0, 25)의 이윤은 0, 90, 30 + 100 = 130, 125(천 원)입니다. 따라서 빵 10개 · 케이크 20개, 130천 원이 최대예요.

밀가루 40kg, 오븐 30시간에서 케이크 이윤이 2천 원으로 떨어지면 최적 계획은 무엇인가?

꼭짓점 (30, 0), (20, 10), (0, 20)의 이윤은 90, 60 + 20 = 80, 40(천 원)입니다. 케이크 이윤이 3천 원보다 작아 빵만 30개(90천 원)가 최선이에요.
