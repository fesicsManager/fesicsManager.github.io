초등 5~6학년 사회 ③ · 웹툰 8화 「조회 수가 많으면 사실인가」

미디어 바르게 읽기 — 조회 수는 본 사람 수, 사실은 출처로 확인

가상 게시물 카드 10장을 다 믿기, 조회 수로 믿기, 느낌표로 믿기, 출처로 믿기의 네 기준으로 골라 뒷면의 사실 여부를 세었습니다. 조회 수로 믿으면 6장 중 3장만 사실이었지만, 출처가 분명한 4장은 모두 사실이었습니다. 미디어가 하는 일과 소식을 확인하는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 무엇을 보고 믿을까(다 믿는다 / 조회 수 1만 이상만 / 제목에 느낌표가 많은 것만 / 출처가 분명한 것만)와 믿은 소식은(친구 5명에게 전한다 / 전하지 않고 확인만 한다)을 고르고 뒷면 뒤집기를 누르면, 믿은 카드 수와 그중 사실인 카드, 친구에게 전한 틀린 소식 수가 기록됩니다. 네 기준을 모두 해 보아 기록이 4개 이상이면 결과 비교 탭이 열립니다. 게시물 카드는 제로 랩의 가상 자료예요.

표 1. 믿는 기준에 따른 결과 (실험 예시, 가상 자료)
기준믿은 카드그중 사실사실 아님틀린 소식 전함
다 믿음10장5장5장25번
조회 수6장3장3장15번
느낌표4장0장4장20번
출처4장4장0장0번
조회 수6장3장3장0번

조회 수 1만 이상만 믿으면 6장 중 3장(50%)만 사실이었고, 친구 5명에게 전하면 틀린 소식을 15번 나른 셈이었어요. 느낌표가 많은 제목 4장은 하나도 사실이 아니었어요. 출처가 분명한 카드는 조회 수와 상관없이 4장 모두 사실이었어요. 마지막 줄처럼 전하지 않고 확인만 하면 틀린 소식을 퍼뜨리지 않아요.

개념 정리

1. 조회 수는 본 사람 수, 사실은 출처로 확인

묶음 (가상)카드 수사실로 확인
조회 수 많음 + 출처 없음4장1장
조회 수 많음 + 출처 분명2장2장
조회 수 적음 + 출처 없음2장0장
조회 수 적음 + 출처 분명2장2장

조회 수 = 많이 봤다 ≠ 사실이다 · 사실 확인 = 처음 알린 곳(출처) + 다른 믿을 만한 곳

움직여 보기

무엇을 보고 믿을까 — 조회 수와 출처

믿는 기준
믿은 카드 그중 사실 사실 아님 친구 5명에게 전하면 틀린 소식

기준을 바꿔 누르면 믿은 카드가 진하게 바뀌고, 하나씩 뒤집어 사실(초록 ○)인지 아닌지(빨강 ✕) 보여 줘요. 조회 수 많은 6장 중 사실은 3장뿐이지만, 출처가 분명한 4장은 조회 수와 상관없이 모두 사실이에요. 카드는 가상 자료예요.

2. 미디어가 하는 일과 우리가 할 일

  • 신문, 방송, 인터넷 같은 미디어는 사회 소식을 알리고, 사람들이 생각을 나누게 해 줘요. 민주주의에서 무언가를 판단하려면 정확한 정보가 필요해요.
  • 휴교처럼 학교가 정하는 일은 학교 누리집이나 학교 안내 문자처럼 처음 알린 곳을 확인해요.
  • 퍼뜨리기 전에 출처부터 확인하고, 같은 소식을 두 곳 이상에서 확인하고, 사실과 의견을 나눠 읽어요.

3. 실험과 실제의 차이

· 카드 10장은 가상 자료예요. 실제로는 출처가 있어도 틀릴 때가 있고, 출처가 없어도 사실일 때가 있어요(카드 ‘분수대 공사’처럼).

· 그래서 출처를 보고, 다른 믿을 만한 곳에서도 같은 말을 하는지 한 번 더 확인해요.

조회 수 많음 ≠ 사실 · 출처 확인 + 두 곳 이상에서 확인 → 사실인지 판단

예제

조회 수 1만 이상인 카드 6장 가운데 사실은 3장이었어요. 믿은 카드 중 사실인 비율은 몇 %인가요?

3 ÷ 6 = 0.5, 곧 50%예요. 조회 수로 믿으면 절반은 틀린 소식이에요. 50%

사실이 아닌 카드 3장을 믿고 친구 5명에게 모두 전했어요. 틀린 소식을 모두 몇 번 전했나요?

3장 × 5명 = 15번이에요. 퍼뜨리기 전에 출처부터 확인해야 하는 까닭이에요. 15번
