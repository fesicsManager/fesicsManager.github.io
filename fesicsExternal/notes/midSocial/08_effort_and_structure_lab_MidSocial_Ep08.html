노력과 조건 — 결과를 몫으로 나누어 재기

나의 노력, 출발 조건(부모 소득), 졸업하는 해의 경기, 사회 정책을 바꾸며 결과 점수와 가상 동기 200명 중 위치를 기록했습니다. 노력 70점이 같아도 출발 조건에 따라 점수가 48.0, 28.0, 8.0으로 갈렸고, 출발 조건 지원 정책은 ‘어려움’의 몫을 −20에서 −10으로 줄였습니다. 개인 요인과 구조 요인을 함께, 크기로 재는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 나의 노력(0~100점), 출발 조건(넉넉함·보통·어려움), 졸업하는 해의 경기(호황·보통·불황), 사회 정책(없음 / 출발 조건 지원)을 고르고 졸업하기를 누르면 결과 점수와 같은 해 졸업한 가상 동기 200명 중 위치(상위 %)가 기록됩니다. 공식과 가중치는 가상 자료로 만든 단순 모형입니다. 4개 이상 기록하면 결과 비교 탭이 열립니다.

노력은 분명히 작동했습니다. 다른 조건이 같으면 노력 10점마다 점수가 4점 올랐습니다. 그런데 노력이 같아도 출발 조건(±20)과 졸업하는 해의 경기(±12)가 점수를 크게 옮겼고, 노력 30점·넉넉함·호황(44.0)이 노력 100점·어려움·불황(8.0)보다 높게 나오기도 했습니다. 그래서 ‘개인이냐 사회냐’를 고르는 것은 함정이고, 둘 다 작동하므로 각각 얼마나인지를 자료로 재야 합니다. 가중치는 설명용 가상 값이라 실제 크기는 통계로 따로 확인해야 합니다.

개념 정리

1. 둘 다 작동한다, 얼마나인지를 잰다

사회 문제를 볼 때 "개인의 노력"과 "개인을 둘러싼 조건" 중 하나만 고르는 것은 함정입니다. 둘 다 작동하고, 중요한 것은 어느 쪽이 얼마나 작동하는지를 자료로 재는 것이에요.

2. 조건이 결과에 남기는 흔적

  • 부모 소득과 자녀 학업 성취의 상관 → 출발 조건의 영향
  • 세대 간 소득 이동성 → 노력으로 계층을 넘는 정도
  • 청년 실업률의 경기 변동 → 개인 능력과 무관한 변동(같은 사람도 졸업 연도에 따라 결과가 달라짐)

3. 이 실험의 계산 방법

결과 점수 = 0.4 × 노력 + 출발 조건 몫 + 경기 몫 + 우연
출발 조건 몫: 상 +20, 중 0, 하 −20 (출발 지원 정책이 있으면 절반), 경기 몫: 호황 +12, 보통 0, 불황 −12

4. 실험 모형과 실제의 차이

· 실제 요인은 서로 얽혀 있습니다(출발 조건이 노력할 기회 자체에 영향을 주기도 함).

· 가중치는 설명을 위한 가상 값이에요. 실제 크기는 통계청 등의 자료로 확인해야 합니다.

5. 생활 속에서 · 이어지는 개념

  • 개인은 통제할 수 있는 것에 집중하고, 사회는 통제할 수 없는 것 때문에 생기는 격차를 줄입니다. 이 둘은 대립하지 않아요.
결과 점수 = 0.4 × 노력 + 출발 조건 몫(+20 / 0 / −20, 지원 정책이면 절반) + 경기 몫(+12 / 0 / −12)

닥터 이안

“이렇게 나눠 보면 된다. 개인은 자기가 통제할 수 있는 것에 집중하고, 사회는 통제할 수 없는 것 때문에 생기는 격차를 줄인다. 이 둘은 대립하지 않아.”

웹툰 8화 #4 · 조건이 결과에 남기는 흔적

예제

노력 70점·출발 조건 어려움·경기 보통에서 정책이 없을 때와 출발 조건 지원 정책이 있을 때 점수는 각각 얼마인가요?

정책 없음: 0.4 × 70 + (−20) + 0 = 8.0. 지원 정책: 출발 조건 몫이 절반이 되어 28 + (−10) + 0 = 18.0. 8.0점 → 18.0점

노력 30점·넉넉함·호황인 사람과 노력 100점·어려움·불황인 사람의 점수를 각각 몫으로 나누어 계산하세요.

앞사람: 노력 12 + 출발 20 + 경기 12 = 44.0. 뒷사람: 노력 40 + 출발 −20 + 경기 −12 = 8.0. 노력 몫은 뒷사람이 28점 더 크지만 조건 몫의 차이(64점)가 더 컸습니다(모형의 가상 가중치 기준). 44.0점과 8.0점
