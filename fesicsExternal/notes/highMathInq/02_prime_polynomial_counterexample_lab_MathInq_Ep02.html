고등 수학과제 탐구 · 웹툰 2화 「예를 많이 확인하면 증명이 되는가」

사례 검증의 한계와 반례 — 40개가 맞아도 41번째는 모른다

소수를 줄줄이 내놓는 식 네 개와 확인 범위를 바꾸며, 범위 안의 소수 개수와 첫 반례를 기록했습니다. n² + n + 41은 n = 0~39에서 모두 소수였지만 n = 40에서 41²이 되었고, 다른 식들도 상수항으로 묶이는 곳에서 깨졌습니다. 전칭 주장과 반례, ‘확인한 범위’를 정직하게 쓰는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: ‘소수 기계(식)’과 ‘확인할 마지막 n’(0~60)을 고른 뒤 계산하고 판정하기를 누르면 n마다 칸이 소수(초록)·합성수(빨강)로 칠해지고, 확인 범위 안 첫 반례와 ‘이 범위에서 말할 수 있는 것’이 기록됩니다. 같은 식의 범위를 넓혀 가며, 또 식을 바꿔 가며 4개 이상 기록하면 결과 비교 탭에서 식별로 버틴 길이를 비교할 수 있습니다.

표 1. 식과 확인 범위별 판정 (실험 예시)
식확인 범위소수 개수첫 반례판정
n² + n + 410~3940없음범위 안에서만 확인
n² + n + 410~4040n = 40전칭 주장 거짓
n² − n + 410~4041없음범위 안에서만 확인
n² − n + 410~6056n = 41전칭 주장 거짓
n² + n + 170~2018n = 16전칭 주장 거짓

n² + n + 41을 n = 39까지만 보면 반례가 없어 ‘n = 0~39에서 확인함’까지만 말할 수 있었고, 범위를 40으로 넓히자 1,681 = 41 × 41이 나와 ‘모든 n에서 소수다’는 거짓이 되었습니다. 반례는 운이 아니라 식의 구조(상수항 41로 묶임)를 보고 겨냥할 수 있었습니다. n² − n + 41은 n = 41, n² + n + 17은 n = 16, 2n² + 29는 n = 29에서 깨졌습니다.

개념 정리

1. 전칭 주장은 반례 하나로 무너진다

"모든 자연수 n에 대해 n² + n + 41은 소수다"는 전칭 주장입니다. n = 0~39의 40개 사례가 모두 맞아도 41번째는 모릅니다. 반대로 반례 하나면 주장 전체가 거짓이 돼요.

2. 구조를 보고 반례를 겨냥하기

n = 40: 40² + 40 + 41 = 40 × 41 + 41 = 41 × 41 = 1,681

n = 41: 41² + 41 + 41 = 41 × 43 = 1,763

상수항이 41이므로, n² + n이 41의 배수가 되는 n에서는 값 전체가 41로 묶입니다. 반례를 "운 좋게" 찾는 것이 아니라 식의 구조를 보고 겨냥하는 거예요.

  • n² − n + 41: n = 0~40에서 소수, n = 41에서 41².
  • n² + n + 17: n = 0~15에서 소수, n = 16에서 17² = 289.
  • 2n² + 29: n = 0~28에서 소수, n = 29에서 29 × 59 = 1,711.

상수가 아닌 정수 계수 다항식은 모든 자연수에서 소수만 내놓을 수 없다는 것이 알려져 있습니다. 이런 식에는 반례가 반드시 있어요.

3. 실험 모형과 실제의 차이

· 소수 판정은 √값 이하의 모든 수로 나눠 보는 방법(시행 나눗셈)입니다. 이 실험의 값 범위에서는 정확해요.

· 컴퓨터로 1억 개를 확인해도 "확인한 범위"가 넓어질 뿐 증명은 되지 않습니다.

4. 생활 속에서 · 이어지는 개념

예제

n² − n + 41이 소수가 아닌 첫 n을 식을 묶어 예측하라.

n = 41이면 41² − 41 + 41 = 41²이 되어 41로 묶인다(n = 0~40에서는 모두 소수). 실험에서도 n = 41에서 1,681 = 41 × 41이 첫 반례로 나온다. n = 41

2n² + 29에서 n = 29를 넣은 값을 인수분해하라.

2 × 29² + 29 = 29 × (2 × 29 + 1) = 29 × 59 = 1,711. 상수항 29와 n이 같아지면 식 전체가 29로 묶인다. 1,711 = 29 × 59
