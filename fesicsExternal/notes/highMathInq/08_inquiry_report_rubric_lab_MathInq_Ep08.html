고등 수학과제 탐구 · 웹툰 8화 「결론이 같으면 같은 탐구인가」

과제 탐구의 평가 — 결론이 같아도 점수는 3점과 17점

결론이 똑같은 탐구 보고서를 여섯 요소로 구성해 평가 기준표(각 3점, 18점 만점)로 채점하고 기록했습니다. 뭉치의 보고서 A는 3점, 제로의 보고서 B는 17점으로, 점수를 가른 것은 결론이 아니라 조건·과정 기록·근거·재현 가능성·한계 서술이었습니다. 탐구 보고서를 평가하는 기준과 스스로 채점해 보완하는 법을 정리합니다.

결론 칸은 모두 ‘C(n, 4) + C(n, 2) + 1’로 같았지만 보고서 A는 3점, 보고서 B는 17점이었습니다. A에 과정 기록만 보태도 6점이 되었고, B는 표·식을 깔끔하게 정리하면 18점이 되었습니다. B의 ‘틀린 추측 2n−1’은 감점이 아니라 탐구의 증거였습니다.

개념 정리

1. 결론이 아니라 과정이 근거다

결론이 맞아도 과정이 없으면 다른 사람은 그 결론을 믿을 이유가 없습니다. 탐구 보고서는 결론과 함께 아래 여섯 기준으로 평가해요.

기준묻는 것
문제 정의무엇을, 어떤 조건에서 탐구했는가
과정 기록시도·실패·수정이 남아 있는가
근거의 타당성결론을 증명이나 충분한 검증으로 뒷받침했는가
재현 가능성다른 사람이 같은 절차로 같은 결과를 얻을 수 있는가
한계 서술성립하지 않는 조건, 남은 질문을 적었는가
의사소통표·그림·식을 읽기 쉽게 제시했는가

2. 이 실험의 채점 규칙 (각 3점)

  • 문제 정의: 조건(일반적인 위치) 없음 1 · 있음 3
  • 과정 기록: 결론만 0 · 성공한 과정만 2 · 틀린 추측·반례·수정까지 3
  • 근거: 없음(출처 불명) 0 · 사례 몇 개 확인 1 · 1 + 선분 수 + 교점 수로 이유를 보임 3
  • 재현 가능성: 출처·방법 없음 0 · 있음 3 / 한계 서술: 없음 0 · 있음 3
  • 의사소통: 글만 1 · 그림은 있으나 정리 부족 2 · 그림·표·식 정리 3

뭉치의 보고서 A는 1 + 0 + 0 + 0 + 0 + 2 = 3점, 제로의 보고서 B는 3 + 3 + 3 + 3 + 3 + 2 = 17점. 결론 칸은 같아요. B의 "틀린 추측 2n−1"은 감점이 아니라 가점 요소입니다.

3. 실험 모형과 실제의 차이

· 점수 배분은 웹툰 8화의 기준표를 단순화한 예시입니다. 실제 수업의 평가 기준과 배점은 학교·교사마다 다를 수 있어요.

· 분량이 길거나 먼저 냈다는 것은 이 기준표 어디에도 점수로 들어가지 않습니다.

4. 생활 속에서 · 이어지는 개념

  • 이 기준표는 다른 세트의 과제를 보고서로 정리할 때도 공통 채점표로 쓸 수 있습니다. 스스로 채점해 가장 낮은 칸부터 보완하세요.

예제

보고서 A(3점)에 ‘일반적인 위치’ 조건과 ‘세 선분이 한 점에서 만나면 줄어듦’이라는 한계 서술을 보탰다. 합계는 몇 점이 되는가?

문제 정의가 1점 → 3점(+2), 한계 서술이 0점 → 3점(+3)이 되므로 3 + 2 + 3 = 8점. 8점

보고서 B(17점)를 18점으로 만들려면 어느 칸을 어떻게 보완해야 하는가?

B에서 3점이 아닌 칸은 의사소통(2점)뿐이다. 그림·표·식을 읽기 쉽게 정리하면 3점이 되어 18점이 된다. 의사소통 — 표를 정리한다
