중학교 3학년 정보 ② · 웹툰 4화 「확신 90%면 맡겨도 될까」

임곗값 — 오류와 일손을 맞바꾸는 기준은 사람이 정한다

과자 봉지 1000개를 확신도 기준(50~99%)과 일의 종류를 바꾸며 판정하고 자동 처리·자동 오판·사람 검토 수와 가상 비용을 기록했습니다. 기준을 70%에서 95%로 높이자 자동 오판은 23개 → 3개로 줄었지만 사람 검토는 80개 → 390개로 늘었고, 비용이 가장 적은 기준은 과자 봉지 70%, 수행평가 90%, 진료 영상 95%로 일마다 달랐습니다. 확신도의 뜻과 결정·책임을 누가 지는지 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자동 처리 기준(확신도 50·70·80·90·95·99% 이상)과 일의 종류(과자 봉지·수행평가·진료 영상)를 고르고 봉지 1000개 판정하기를 누르면 기준선 오른쪽은 자동 처리, 왼쪽은 사람 검토로 나뉘고 빨간 부분(자동 오판)이 표시됩니다. 4개 이상 기록하면 결과 비교 탭에 기준별 오판·검토 표와 일의 종류별 가장 알맞은 기준이 채워집니다. 70%·95%의 수는 대본 가상 자료, 나머지와 비용 점수는 같은 경향의 가상 값입니다.

기준을 올릴수록 자동 오판은 60 → 1개로 줄지만 사람 검토는 0 → 680개로 늘어납니다. 공짜로 둘 다 좋아지는 기준은 없고, 오류와 일손을 맞바꿀 뿐입니다. 오판 1건의 무게가 작은 과자 봉지는 70%에서 비용이 가장 적었지만, 오판 무게를 크게 둔 수행평가는 90%, 진료 영상은 95%가 가장 알맞았습니다. 확신도는 ‘얼마나 확실해 보이느냐’일 뿐 정답 보장이 아니므로, 사람에게 영향이 큰 일일수록 기준을 높이고 마지막 결정과 책임은 사람이 맡습니다.

개념 정리

1. 확신도는 정답 보장이 아니다

확신도는 "얼마나 확실해 보이느냐"의 점수입니다. 처음 보는 모양 앞에서는 틀리면서도 높은 점수를 낼 수 있어요. 그래서 몇 점부터 기계에 맡길지(임곗값)를 사람이 정합니다.

2. 맞바꾸기

  • 기준을 높이면: 자동 오판은 줄지만, 사람이 검토할 양이 늘어납니다.
  • 기준을 낮추면: 사람 일은 줄지만, 자동 오판이 늘어납니다.
  • 공짜로 둘 다 좋아지는 기준은 없어요. 오류와 일손을 맞바꾸는 것입니다.

3. 이 실험의 계산 방법

가상 비용 = 자동 오판 수 × 오판 1건의 무게 + 사람 검토 수 × 검토 1건의 수고

4. 실험 모형과 실제의 차이

· 봉지 수와 오판 수는 가상 자료입니다. 비용 점수는 일의 종류에 따른 무게 차이를 보여 주려는 가상 가정이에요.

· 사람의 진료·입학·채용처럼 한 번의 오판이 삶을 바꾸는 일은 숫자 비용만으로 정하지 않습니다. 마지막 결정은 사람이 하고, 결정한 사람이 책임지며, 설명과 이의 제기 통로를 함께 갖춰야 해요.

5. 생활 속에서 · 이어지는 개념

  • 인공지능이 사진의 어느 부분을 보고 판정했는지 보여 주면, 사람이 근거를 확인할 수 있습니다. 근거를 볼 수 있어야 믿을지 말지 정할 수 있어요.

예제

기준 90%일 때 자동 처리 730개 중 오판 6개였다. 자동 처리 중 오판 비율과 사람 검토 수는?

오판 비율 = 6 ÷ 730 × 100 ≈ 0.8%, 사람 검토 = 1000 − 730 = 270개입니다. 약 0.8%, 270개.

진료 영상 판독(오판 1건 50점, 검토 1건 0.5점)에서 기준 70%와 95%의 가상 비용을 비교하라.

70%: 23 × 50 + 80 × 0.5 = 1150 + 40 = 1190점. 95%: 3 × 50 + 390 × 0.5 = 150 + 195 = 345점. 95%가 훨씬 적다 — 오판의 무게가 큰 일은 기준을 높여야 합니다. 실제로는 숫자 비용만으로 정하지 않고 사람이 최종 결정합니다.
