중학교 3학년 정보 ② · 웹툰 8화 「알림은 내 시간을 노린다」

주의를 끄는 설계 — 의지를 쓰기 전에 설정부터 바꾼다

알림·영상 자동 재생·잠잘 때 휴대폰 위치를 하나씩 바꾸며 하루 화면 켬 횟수와 사용 시간을 기록했습니다. 모두 켠 상태(머리맡)는 96회·265분이었고, 알림 하나만 끄자 41회·128분으로 줄었으며, 자동 재생까지 끄면 87분, 휴대폰을 다른 방에 두면 35회·53분이었습니다. 앱이 오래 머물게 설계되는 까닭과 조건을 하나만 바꾸는 공정한 비교를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 알림(켬/끔), 영상 자동 재생(켬/끔), 잠잘 때 휴대폰 위치(머리맡/다른 방)를 정하고 하루 기록 보기를 누르면 아침 7시부터 밤 1시까지 화면을 켠 순간이 막대(빨강: 알림이 부름, 파랑: 스스로 켬)로 찍히고 하루 사용 시간이 나옵니다. 조건을 한 번에 하나만 바꿔 4개 이상 기록하면 결과 비교 탭에 ‘조건을 하나만 바꾼 비교’ 표가 채워집니다. 96회·41회는 대본의 가상 기록이고 나머지는 단순 모형의 가상 값입니다.

의지는 그대로인데 알림 하나만 껐더니 화면 켬이 96회에서 41회로 절반 아래가 되었습니다. 줄어든 55회는 모두 알림이 불러서 켠 것이었으니, 부른 쪽은 앱이었습니다. 자동 재생은 켜는 횟수가 아니라 한 번 켤 때 머무는 시간(2.5분 → 1.5분)을 바꾸고, 휴대폰을 다른 방에 두면 잠들기 전 사용 25분이 사라집니다. 많은 무료 앱은 머문 시간이 곧 수익이라 ‘멈출 곳’을 없애는 장치를 설계합니다. 그래서 의지를 쓰기 전에 환경과 설정부터 바꾸고, 조건은 한 번에 하나만 바꿔 비교합니다.

개념 정리

1. 오래 쓰는 것은 의지 반, 설계 반

많은 무료 앱은 이용자가 오래 머물수록 광고 수익이 늘어납니다. 그래서 '멈출 곳'을 없애는 장치가 설계되어 있어요.

  • 끝없는 스크롤: 책의 장 끝 같은 멈출 곳이 없습니다.
  • 자동 재생: 다음 영상이 저절로 시작되어 한 번 켤 때 머무는 시간이 늘어납니다.
  • 빨간 숫자 배지·알림: 내가 켜기 전에 앱이 먼저 부릅니다.
  • 연속 접속 보상: 하루라도 빠지면 손해처럼 느끼게 합니다.

2. 이 실험의 계산 방법 (단순 모형)

하루 사용 시간 = 화면 켬 횟수 × 한 번 켤 때 평균 사용 시간 + 잠들기 전 사용

3. 실험 모형과 실제의 차이

· 알림 켬/끔 횟수는 대본의 가상 기록이고, 자동 재생과 잠자리 효과는 경향을 보여 주려는 가상 값입니다.

· 사람마다, 앱마다 효과의 크기는 다릅니다. 직접 기록할 때는 조건을 한 가지만 바꾸고 며칠씩 재야 공정한 비교가 돼요.

4. 생활 속에서 · 이어지는 개념

  • 의지를 쓰기 전에 환경부터 바꿉니다. 알림 끄기, 자동 재생 끄기, 사용 시간 알림, 잠자리에선 다른 방에 두기. 그리고 언젠가 앱을 만들 때 '오래 붙잡는 앱'과 '필요한 만큼 쓰고 놓아 주는 앱' 중 무엇을 만들지 고르게 될 거예요.
하루 사용 시간 = 화면 켬 횟수 × 한 번 켤 때 평균 사용 시간 + 잠들기 전 사용 (예: 96 × 2.5 + 25 = 265분)

예제

알림 끔·자동 재생 켬·머리맡 조건에서 화면 켬 41회, 한 번 평균 2.5분, 잠들기 전 25분이다. 하루 사용 시간은?

41 × 2.5 + 25 = 102.5 + 25 = 127.5 ≈ 128분(약 2.1시간). 알림을 켠 경우의 265분과 비교하면 절반 아래입니다.

기록 ‘알림 켬·재생 켬·머리맡 96회’와 ‘알림 끔·재생 끔·다른 방 35회’를 비교해 ‘알림을 끄면 61회 준다’고 말해도 되는가?

두 기록은 조건이 세 가지나 달라 무엇 때문에 줄었는지 알 수 없습니다. 말할 수 없다 — 알림만 다른 한 쌍(96회 ↔ 41회)으로 비교해야 공정합니다.
