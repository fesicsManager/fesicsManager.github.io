헤스 법칙 — 경로가 달라도 총 반응열은 같다

실험에서 NaOH 경로(고체 → 수용액 → 중화 vs 고체를 산에 바로)와 탄소 연소 경로(C → CO₂, CO → CO₂로 C → CO 구하기)의 단계별 ΔH를 더하고 빼어 전체 ΔH와 비교했습니다. 두 경로의 합이 같았고, 반응식을 거꾸로 쓰면 부호가, 계수를 곱하면 배율이 바뀌었습니다. 헤스 법칙과 결합 에너지 어림을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

표준 반응 엔탈피(25 ℃) 자료값. 에너지 준위 도식에서 각 단계 화살표를 이어 붙이면 출발점과 도착점의 높이 차 = 전체 ΔH.

표 1. 두 경로의 단계별 ΔH와 합 (실험 계산식: ΔH_전체 = Σ ΔH_단계, 식의 덧셈·뺄셈·배수에 맞춰 조정)

식을 거꾸로 쓰면 ΔH 부호가 바뀌고 계수를 n배 하면 ΔH도 n배. 엔탈피는 상태 함수라 처음과 나중 상태만 정하면 값이 정해지고 중간 경로는 상관없습니다.

개념 정리

1. 헤스 법칙 (웹툰 9화)

예측 게임 — 탄소가 곧바로 CO₂가 되는 경로와 CO를 거쳐 CO₂가 되는 경로의 전체 ΔH는? 제로 ‘단계를 더 거치면 열이 더 새니 다르다’, 뭉치 ‘같다’: 처음과 나중 상태가 같으면 어떤 경로를 거치든 전체 반응 엔탈피는 같습니다(헤스 법칙, 1840) — 산을 곧장 넘든 돌아가든 높이 차이는 같은 것처럼. 그래서 직접 재기 어려운 반응(탄소의 불완전 연소처럼 CO와 CO₂가 함께 생기는 반응)의 ΔH를 잴 수 있는 반응들을 더하고 빼서 구합니다: ① C + O₂ → CO₂(−394), ② CO + ½O₂ → CO₂(−283) → ① − ②: C + ½O₂ → CO, ΔH = −394 − (−283) = −111 kJ. 반응식을 더하고 빼는 대로 ΔH도 더하고 빼며 역반응은 부호를 바꿉니다. 스티로폼 컵 실험: 고체 NaOH 용해 ΔH₁ ≈ −44, 수용액 중화 ΔH₂ ≈ −57 → 합 −101 ≈ 고체를 산에 바로 넣은 ΔH₃ — 실험 오차 안에서 같습니다.

2. 결합 에너지로 어림하기, 헤스 법칙의 쓸모

결합을 끊을 때는 에너지를 흡수하고 새 결합이 생길 때는 방출하므로 그 차이로 ΔH를 어림합니다: H₂ + Cl₂ → 2HCl, 결합 에너지 H–H 436, Cl–Cl 243, H–Cl 432 kJ/mol → ΔH ≈ (436 + 243) − 2 × 432 = −185 kJ — 끊는 에너지보다 새로 이을 때 나오는 에너지가 크면 발열. 표준 생성 엔탈피 표(ΔH_f°)는 헤스 법칙 덕분에 어떤 반응의 ΔH든 ‘생성물 − 반응물’로 계산하게 해 주고, 연료의 발열량·폭약의 에너지·생체 대사 에너지·신소재 합성 공정 설계가 모두 헤스 법칙에 기댑니다. 위험하거나 너무 느리거나 다른 반응이 섞여 직접 재기 어려운 반응도 계산할 수 있습니다.

3. 모형과 실제, 생활 속에서

여기서는 표준 자료값이라 정확히 맞지만, 실제 열량계 실험에서는 각 단계 측정에 열 손실·농도 차이 오차가 있어 합이 1~5 % 어긋납니다. 그 차이가 헤스 법칙의 위반이 아니라 실험 오차임을 확인하는 것이 실제 실험의 목표입니다. 모든 단계가 같은 온도·압력·농도 조건이어야 더할 수 있고, 조건이 다르면 값을 보정해야 합니다. 촉매는 경로를 바꾸지만 처음과 나중이 같으므로 ΔH는 그대로입니다(14화).

ΔH_전체 = Σ ΔH_단계  ·  역반응 → −ΔH · 계수 × n → ΔH × n  ·  ΔH ≈ Σ(끊는 결합 E) − Σ(생기는 결합 E)  ·  ΔH° = Σ ΔH_f°(생성물) − Σ ΔH_f°(반응물)

C → CO₂ −393.5 · CO → CO₂ −283.0 · C → CO −110.5 kJ/mol · NaOH 용해 −44.5 + 중화 −56.1 = −100.6 · H₂ + Cl₂ ≈ −185 kJ

예제

C(s) + O₂ → CO₂ (−393.5), H₂ + ½O₂ → H₂O(l) (−285.8), CH₄ + 2O₂ → CO₂ + 2H₂O(l) (−890.3)에서 메테인의 생성 반응 C + 2H₂ → CH₄의 ΔH는?

① + 2 × ② − ③: −393.5 + 2 × (−285.8) − (−890.3) = −393.5 − 571.6 + 890.3 = −74.8 kJ/mol. 탄소와 수소를 직접 반응시켜 메테인만 만들 수 없으므로 연소열로 돌아서 구합니다.

결합 에너지(C–H 413, O=O 498, C=O 799, O–H 463 kJ/mol)로 CH₄ + 2O₂ → CO₂ + 2H₂O(g)의 ΔH를 어림하면?

끊음: 4 × 413 + 2 × 498 = 2 648. 생김: 2 × 799 + 4 × 463 = 3 450. ΔH ≈ 2 648 − 3 450 = −802 kJ(실측 −802, 물이 기체일 때). 결합 에너지는 평균값이라 보통 몇 % 오차가 납니다.
