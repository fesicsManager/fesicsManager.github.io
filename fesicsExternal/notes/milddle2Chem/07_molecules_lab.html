분자와 분자식 — 원자의 종류·개수·배열

개념 정리

1. 분자와 분자식

분자는 원자 몇 개가 전자를 공유하며 단단히 결합해 하나의 독립된 입자를 이룬 것으로, 그 물질의 성질을 지니는 가장 작은 입자입니다. 분자식은 원자의 종류(원소 기호)와 개수(아래첨자)를 나타냅니다 — 물 H₂O는 수소 2개 + 산소 1개. 산소·수소는 원자 하나만으로는 불안정해 자연에서는 항상 2개가 짝을 이룬 분자(O₂, H₂)로 존재합니다. 결합한 원자의 종류·개수·배열이 다르면 전혀 다른 물질이 됩니다: O₂(숨 쉬는 산소)와 O₃(독성 있는 오존), H₂O(물)와 H₂O₂(과산화 수소).

2. 분자의 모양은 어떻게 정해질까

중심 원자 주위의 전자쌍들은 서로 밀어내며 가장 멀리 떨어지려는 배치를 합니다. 결합에 참여하지 않은 전자쌍(비공유 전자쌍)도 자리를 차지합니다.

  • 이산화 탄소: 탄소에 결합 2개만 → 정반대 방향, 직선(180°).
  • 메테인: 탄소에 결합 4개 → 정사면체, 109.5°.
  • 암모니아: 질소에 결합 3개 + 비공유 전자쌍 1개 → 삼각뿔, 107°.
  • 물: 산소에 결합 2개 + 비공유 전자쌍 2개 → 굽은 모양(104.5°). 비공유 전자쌍이 결합을 더 세게 밀어 각이 좁아집니다.

물의 굽은 모양은 물이 극성을 띠게 하고, 이것이 물의 높은 끓는점·용해 능력·표면 장력의 원인입니다.

3. 모형과 실제

공 막대 모형은 결합각과 원자 수를 보여 주는 단순화입니다. 실제 분자에서 원자들은 서로 겹쳐 있고 결합은 막대가 아니라 전자 구름입니다. 화면의 원 크기는 실제 공유 반지름 비율(H 31 < O 66 < N 71 < C 76 < Cl 99 pm)이고, 결합선 두 줄은 2중 결합, 세 줄은 3중 결합입니다.

총 원자 수 = 아래첨자의 합  ·  앞의 계수 = 분자 수 (2H₂O = 물 분자 2개, 원자 6개)

결합각: H₂O 104.5° · NH₃ 107° · CH₄ 109.5° · CO₂ 180°

아토

“물은 원자 여러 개가 결합한 ‘분자’로 이루어져 있어. 분자는 물질의 성질을 그대로 지니는 가장 작은 입자야. 물 분자는 수소 원자 2개와 산소 원자 1개가 결합해서 만들어져. 그래서 화학식으로 H₂O라고 써!”

웹툰 7화 · 민재: “그럼 우리가 마시는 물은 원자 하나짜리야?”

지유

“산소 기체는 O₂, 이산화탄소는 CO₂, 암모니아는 NH₃구나! 숫자는 원자의 개수를 나타내는 거지?”

웹툰 7화 · 아토: “산소나 수소는 원자 하나만으로는 불안정해서, 자연에서는 항상 원자 2개가 짝을 이룬 분자(O₂, H₂) 형태로 존재해.”

예제

3CO₂는 무엇을 나타내고, 탄소 원자와 산소 원자는 각각 몇 개일까?

이산화 탄소 분자 3개. 분자 하나에 C 1개·O 2개이므로 탄소 3개, 산소 6개, 총 원자 9개. 앞의 계수는 분자 수, 아래첨자는 분자 속 원자 수입니다.

물(H₂O)과 과산화 수소(H₂O₂)는 산소 원자 하나 차이인데 왜 성질이 전혀 다를까?

분자는 원자의 종류·개수·배열이 정해져야 하나의 물질이 됩니다. 산소가 하나 더 붙으면 결합 구조와 전자 배치가 달라져 다른 분자, 다른 물질(과산화 수소는 살균·표백에 쓰이는 반응성 큰 물질)이 됩니다.

확인 문제

1번· 관찰 확인

실험에서 만든 분자 가운데 한 종류의 원소로만 이루어진 것은?

O₂·N₂처럼 한 종류의 원소로 된 분자는 홑원소 물질, 두 종류 이상은 화합물입니다.

2번· 핵심 개념

분자식 NH₃가 나타내는 것은?

원소 기호 오른쪽 아래 숫자가 그 원자의 개수. N 1개(생략) + H 3개 = 원자 4개인 암모니아 분자.

3번· 적용

물 분자가 직선이 아니라 굽은 모양(104.5°)인 이유는?

전자쌍들이 서로 가장 멀리 떨어지려 하는데 비공유 전자쌍이 결합을 더 세게 밀어 정사면체 각(109.5°)보다 좁은 104.5°가 됩니다.

4번· 웹툰 연결

7화에서 아토가 말한 것처럼 산소가 자연에서 O가 아니라 O₂로 존재하는 이유는?

산소·수소·질소 원자는 전자를 공유해 짝을 이루어야 바깥 껍질이 안정해지므로 2원자 분자로 존재합니다.
