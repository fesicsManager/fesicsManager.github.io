중학교 한문 ② · 웹툰 8화 「한자는 처음부터 지금 모양이었나」

서체의 변천 — 재료와 도구, 쓰는 사정이 바뀔 때마다 획의 모양이 바뀌었다

다섯 가지 재료와 도구(뼈 + 칼 · 진흙 틀 + 청동 · 나라의 자형 정리 · 좁은 죽간 + 붓 · 종이 + 붓)로 같은 획을 그어 보았습니다. 칼로 새긴 곡선은 끊어진 가는 선(갑골문), 청동을 부은 선은 굵고 둥근 선(금문), 죽간에 붓으로 빨리 쓴 획은 납작하고 파임이 두드러진 획(예서)이 되었습니다. 갑골문에서 해서까지의 흐름과 모양이 바뀐 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 재료와 도구(거북 배딱지·짐승 뼈 + 칼 / 진흙 틀에 새겨 청동을 부음 / 나라가 자형을 정리 / 좁은 죽간 + 붓 / 종이 + 붓)와 그을 획(곡선 획 / 긴 세로획 / 가로획 끝 파임 자리)을 고르고 이 도구로 긋기를 누릅니다. 배경에 재료가, 가운데에 그 도구로 그은 획이 나타나고, 아래 띠에 이어지는 서체(갑골문 → 금문 → 전서 → 예서 → 해서)와 시기·특징이 표시돼요. 기록이 4개 이상이면 서체의 흐름 표를 보는 결과 비교 탭이 열립니다. 획은 도구의 성질을 보여 주는 개략 도형이며 실제 옛 자형을 재현한 것이 아니에요.

표 1. 재료·도구에 따른 획과 서체 (실험 출력)
재료·도구그은 획서체 (시기)이 도구로 그으면모양의 특징
거북 배딱지·짐승 뼈 + 칼곡선 획갑골문 (상(은)나라)곡선이 어렵고 끊어짐, 곧고 가는 선가늘고 곧은 선, 그림에 가까움
진흙 틀에 새겨 청동을 부음곡선 획금문 (주나라 무렵)굵고 둥근 선이 잘 남음굵고 둥근 선
나라가 자형을 정리 (표준)곡선 획전서·소전 (진나라 통일)자형을 하나로 정리, 굵기가 고르고 길쭉함고른 굵기, 둥글고 긴 모양
좁은 죽간 + 붓 (빨리)가로획 끝 (파임 자리)예서 (진~한나라)납작해지고 붓을 눌렀다 뗀 파임납작하고 곧은 획, 파임이 두드러짐
종이 + 붓 (또박또박)긴 세로획해서 (한나라 말 이후)획마다 시작·끝을 분명히또박또박, 오늘날 인쇄체의 바탕

같은 획이라도 새기는 재료와 쓰는 도구가 바뀌자 모양이 바뀌었습니다. 단단한 뼈에 칼로 새기면 곡선이 어려워 곧고 가는 선이 되고, 틀에 새겨 쇳물을 부으면 굵고 둥근 선이 남아요. 관청 일이 많아져 빨리 많이 써야 하자 둥글게 돌리던 획이 꺾이고 곧아졌고, 예서가 납작한 까닭으로 흔히 좁은 죽간 폭을 들지만 붓을 빠르게 옆으로 끄는 운필 등 여러 요인이 함께 작용했다고 봅니다. 진시황의 소전 정리는 나라마다 달랐던 자형을 통일한 흐름의 한 단계였지, 하루아침에 모든 글자를 바꾼 것이 아니에요. 서체가 바뀐 시기도 칼로 자르듯 나뉘지 않고 겹치며, 지금도 간화자나 컴퓨터 글꼴처럼 ‘쓰는 사정’이 모양을 바꿉니다.

개념 정리

1. 재료와 도구, 그리고 쓰임이 모양을 바꾼다

  • 갑골문 (상·은나라): 거북 배딱지·짐승 뼈에 칼로 새김 → 가늘고 곧은 선, 그림에 가까움
  • 금문 (주나라 무렵): 청동기에 새기거나 부어 만듦 → 굵고 둥근 선
  • 전서(소전) (진나라 통일): 나라가 자형을 정리 → 고른 굵기, 둥글고 긴 모양
  • 예서 (진~한나라): 죽간에 붓으로 빠르게 → 납작하고 곧은 획, 파임이 두드러짐
  • 해서 (한나라 말 이후 자리 잡음): 붓·종이 → 또박또박, 오늘날 인쇄체의 바탕

모양이 바뀐 까닭 = 새기는 재료 + 쓰는 도구 + 빠르게·많이·통일되게 써야 하는 쓰임

관청 일이 많아져 빨리 많이 써야 하니 둥글게 돌리던 획이 꺾이고 곧아졌습니다. 진시황의 소전 정리는 나라마다 달랐던 자형을 통일한 한 단계였지, 한 번에 모든 것을 바꾼 것이 아니에요. 지금도 간화자, 컴퓨터 글꼴처럼 "쓰는 사정"이 모양을 바꿉니다.

2. 실험 모형과 실제의 차이

· 예서가 납작한 까닭으로 "좁은 죽간 폭"이 흔히 드는 설명이지만, 붓을 빠르게 옆으로 끄는 운필 등 여러 요인이 함께 작용했다고 봅니다.

· 서체가 바뀌는 시기는 칼로 자르듯 나뉘지 않고 겹칩니다.

모양이 바뀐 까닭 = 새기는 재료 + 쓰는 도구 + 빠르게·많이·통일되게 써야 하는 쓰임 (갑골문 → 금문 → 전서 → 예서 → 해서)
