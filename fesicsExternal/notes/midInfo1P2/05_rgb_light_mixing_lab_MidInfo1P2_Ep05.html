RGB 색 표현 — 빛은 더할수록 밝아진다

화면 픽셀의 R·G·B 값(각 0~255)을 바꾸며 빛을 더하는 화면과 같은 비율의 물감 섞기(단순 모형)를 비교하고 결과 색을 기록했습니다. (255, 255, 0)은 화면에서 노랑, 물감에서는 탁한 갈색 계열이었고, 세 값이 모두 255면 흰색, 모두 0이면 검정, 모두 128이면 회색이었어요. 빛의 가산 혼합과 물감의 감산 혼합, 픽셀 하나에 드는 24비트를 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 R(빨강 빛) · G(초록 빛) · B(파랑 빛) 값을 0~255로 정하고 섞는 방식(화면 빛(더하기) · 같은 비율의 물감(빼기))을 고른 뒤 실행하면 결과 색과 색 이름, 밝기, 이 픽셀을 담는 데 필요한 비트가 표시됩니다. (255, 255, 0)을 화면 빛과 물감으로 각각 만들어 비교하고, 세 값을 모두 같게 해서 무슨 색이 되는지 기록해 보세요. 화면 밝기를 적당히 낮추고 오래 응시하지 마세요.

화면은 빛을 내는 장치라 빨강 + 초록 빛 = 노랑, 세 빛을 다 켜면 흰색, 다 끄면 검정입니다. 같은 비율의 물감은 빛을 흡수해 (84, 68, 31) 같은 탁한 갈색이 되어 규칙이 반대예요. 비율을 그대로 두고 세기만 줄이면 (128, 128, 0) 올리브색처럼 같은 계열에서 어두워지고, 세 값이 같으면 회색 계열입니다. 픽셀 하나는 8 + 8 + 8 = 24비트(3바이트)로 약 1,678만 가지 색을 나타내요.

개념 정리

1. 빛은 더할수록 밝아진다

화면은 빛을 내는 장치라 R·G·B 빛을 더해서 색을 만듭니다(가산 혼합). 빨강 + 초록 = 노랑, 세 빛을 모두 켜면 흰색, 모두 끄면 검정이에요.

색 하나 = (R, G, B) · 각각 8비트(0~255) → 256 × 256 × 256 = 16,777,216가지 (약 1,678만)

2. 물감은 섞을수록 어두워진다

물감과 잉크는 빛을 흡수해서 남은 빛을 반사합니다. 섞을수록 흡수하는 빛이 늘어 어두워져요(감산 혼합). 그래서 인쇄기는 빨강·초록·파랑이 아니라 청록(C)·자홍(M)·노랑(Y)에 검정(K)을 더해 씁니다.

  • 세 값이 모두 같으면 회색 계열 (0 검정 → 128 회색 → 255 흰색)
  • 비율은 그대로 두고 세기만 줄이면 같은 색 계열에서 어두워져요. (255, 255, 0) 노랑 → (128, 128, 0) 올리브색

3. 실험 모형과 실제의 차이

· 물감 모드는 각 물감이 반사하는 빛의 비율을 섞은 양만큼 곱하는 단순 모형입니다. 실제 물감 색은 안료 종류에 따라 달라요.

· 화면마다 색 표현 범위가 달라 같은 숫자도 조금 다르게 보일 수 있습니다.

색 하나 = (R, G, B), 각 8비트(0~255) → 256 × 256 × 256 = 16,777,216가지

예제

화면 픽셀을 (0, 255, 255)로 정하면 어떤 색으로 보이는가? (255, 0, 255)는?

초록과 파랑 빛을 최대로 더하면 밝은 청록, 빨강과 파랑을 더하면 자홍입니다. 빛은 더할수록 밝아지므로 탁한 색이 되지 않아요.

가로 100픽셀, 세로 100픽셀 그림의 모든 픽셀을 (R, G, B) 각 8비트로 저장하면 압축 전 몇 바이트가 필요한가?

픽셀 하나는 24비트 = 3바이트이고 픽셀 수는 100 × 100 = 10,000개이므로 10,000 × 3 = 30,000바이트입니다. 30,000바이트
