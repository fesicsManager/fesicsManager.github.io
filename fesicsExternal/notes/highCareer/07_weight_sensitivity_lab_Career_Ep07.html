고등 진로와 직업 · 웹툰 7화 「점수표에서 1위가 나온 선택지가 곧 정답인가」

민감도 확인 — 가중치를 흔들어도 1위가 유지되는가

세 가상 대안(가 · 나 · 다)의 가중치 의사결정 표에서 가중치 조합 다섯 가지와 가의 흥미 점수(5점 / 4점)를 바꿔 가중 합계와 1위를 기록했습니다. 처음 가중치로는 가 3.7, 나 3.6, 다 3.5로 가가 0.1점 차 1위였지만, 흥미 가중치 0.1을 비용으로 옮기자 가 3.4, 나 3.5, 다 3.8로 다가 1위가 됐고, 가의 흥미 점수만 4점으로 낮춰도 나가 1위였습니다. 가중 합계 계산과 결과를 읽는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: ‘가중치 조합’(처음 0.4/0.3/0.2/0.1 · 흥미 0.1 → 비용 · 흥미 0.2 → 비용 · 비용 0.1 → 흥미 · 모두 같게 0.25씩)과 ‘가의 흥미 점수’(5점 · 4점)를 고른 뒤 다시 계산하기를 누르면 세 대안의 가중 합계 막대와 순위, 1위와 2위의 차이가 기록됩니다. 다섯 가지 조합을 모두 계산하고 가의 흥미 점수를 4로 낮춘 경우도 포함해 4개 이상 기록하면 결과 비교 탭이 열립니다. (대안·점수·가중치는 수업용 가상 자료)

처음 가중치(흥미 0.4 · 역량 0.3 · 비용 0.2 · 거리 0.1)로는 가 = 5×0.4 + 3×0.3 + 2×0.2 + 4×0.1 = 3.7로 1위였지만 2위와 0.1점 차이였습니다. 흥미 가중치 0.1을 비용으로 옮기기만 해도 꼴찌였던 다가 3.8로 1위가 됐고, 가중치는 그대로 두고 가의 흥미 점수를 5에서 4로 낮춰도 가는 3.3으로 내려가 나(3.6)가 1위였습니다. 반대로 비용 0.1을 흥미로 옮기면 가가 4.0으로 앞섰습니다. 그러므로 이 표의 결론은 ‘가가 정답’이 아니라 ‘흥미와 비용 중 무엇을 더 무겁게 보느냐가 결정을 가른다’는 것이고, 할 일은 흥미 점수를 체험으로 확인하고 비용 점수를 실제 금액으로 고치는 것입니다. ‘모두 같게’도 하나의 선택일 뿐이라 다가 4.0으로 1위였습니다.

개념 정리

1. 표는 결정을 대신하지 않고, 고민의 핵심을 찾아 준다

가중치 의사결정 표는 기준을 빠짐없이 꺼내 놓고 무엇을 더 중요하게 보는지 숫자로 드러내는 좋은 도구입니다. 하지만 가중치와 점수는 내가 정한 값이에요. 그래서 가중치를 조금 흔들어도 순위가 유지되는지 확인해야 합니다.

2. 표를 쓸 때의 주의

  • 처음 매긴 점수에 끌려 다음 점수를 맞추기 쉽습니다(기준점 효과). 기준마다 세 대안을 한 줄씩 비교해 매기면 덜 흔들려요.
  • “모두 같은 가중치”도 하나의 선택일 뿐이고, 결과가 또 달라집니다.
  • 표가 끝났는데 마음이 반대쪽으로 끌린다면, 표에 빠진 기준이 있다는 신호일 수 있어요.

3. 이 실험의 계산 방법

가중 합계 = Σ (기준 점수 × 가중치)
가 = 5×0.4 + 3×0.3 + 2×0.2 + 4×0.1 = 3.7, 나 = 3.6, 다 = 3.5
흥미 0.1을 비용으로 옮기면(0.3/0.3/0.3/0.1) 가 3.4, 나 3.5, 다 3.8 — 1위가 뒤집힙니다.

4. 실험 모형과 실제의 차이

· 점수 1 ~ 5는 측정값이 아니라 판단값입니다. 1화처럼 체험으로 흥미 점수를 확인하고, 비용 점수는 실제 금액을 찾아 고치세요.

5. 생활 속에서 · 이어지는 개념

  • 지금 고민 중인 선택 하나에 대해 대안 2 ~ 3개, 기준 4개로 가중치 표를 만들고, 가중치 하나를 0.1 옮겼을 때 1위가 바뀌는지 확인해 보세요.
가중 합계 = Σ (기준 점수 × 가중치) · 가 = 5×0.4 + 3×0.3 + 2×0.2 + 4×0.1 = 3.7

예제

가중치를 흥미 0.2 · 역량 0.3 · 비용 0.4 · 거리 0.1로 바꿨다. 가(5, 3, 2, 4), 나(4, 4, 3, 2), 다(2, 4, 5, 5)의 가중 합계와 1위를 구하라.

가 = 5×0.2 + 3×0.3 + 2×0.4 + 4×0.1 = 1.0 + 0.9 + 0.8 + 0.4 = 3.1. 나 = 0.8 + 1.2 + 1.2 + 0.2 = 3.4. 다 = 0.4 + 1.2 + 2.0 + 0.5 = 4.1. 가 3.1, 나 3.4, 다 4.1 → 다 1위

가중치 0.5 · 0.3 · 0.1 · 0.1(비용 0.1을 흥미로 옮김)에서 가의 흥미 점수를 4점으로 낮췄다. 세 대안의 가중 합계와 1위를 구하라.

가 = 4×0.5 + 3×0.3 + 2×0.1 + 4×0.1 = 2.0 + 0.9 + 0.2 + 0.4 = 3.5. 나 = 4×0.5 + 4×0.3 + 3×0.1 + 2×0.1 = 2.0 + 1.2 + 0.3 + 0.2 = 3.7. 다 = 2×0.5 + 4×0.3 + 5×0.1 + 5×0.1 = 1.0 + 1.2 + 0.5 + 0.5 = 3.2. 흥미 점수 1점이 1위를 가에서 나로 바꿨습니다. 가 3.5, 나 3.7, 다 3.2 → 나 1위
