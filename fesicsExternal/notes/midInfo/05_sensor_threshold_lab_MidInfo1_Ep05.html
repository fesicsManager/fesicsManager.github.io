센서와 기준값 — 센서는 판단하지 않는다

하루 밝기 곡선(아침 700·점심 950·해 질 무렵 250·밤 30)에 기준값을 바꾸며 LED가 켜진 시간과 낭비(밝기 ≥ 400인데 켜짐)를 기록했습니다. 기준 300이면 18시 30분~6시 30분 12시간, 800이면 17시~8시 15시간으로 대낮 흐림에도 켜졌고, 100이면 9시간이지만 해 질 무렵 어두운데 안 켜졌습니다. 판단은 센서가 아니라 조건에 있음을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 밝기(t) = 최대 × sin 곡선(낮) + 야간 값, 10분마다 LED = 밝기 < 기준, 켜진 시간 = 켜진 칸 × 10분, 낭비 = 밝기 ≥ 400인데 켜진 시간입니다.

조도 센서는 ‘어둡다’고 말하지 않고 0~1023 숫자만 줍니다. ‘어두우면 켜라’는 사람이 기준값으로 정해 조건문에 써 넣는 것이며, 너무 낮으면 캄캄해질 때까지 안 켜지고 너무 높으면 낭비합니다. 좋은 기준값은 실제로 여러 번 재 보고 정하며, 실제 센서는 값이 흔들려 켜는 기준과 끄는 기준을 다르게 둡니다(히스테리시스).

개념 정리

1. 센서는 판단하지 않는다

조도 센서는 "어둡다"고 말하지 않아요. 0(캄캄)부터 1023(눈부심)까지 숫자만 줘요. "어두우면 켜라"는 사람이 기준값으로 정해요. 값 < 300이면 해 질 무렵부터 켜지고, 값 < 800으로 바꾸면 대낮에도 켜져요. 기준값이 너무 낮으면 캄캄해질 때까지 안 켜지고, 너무 높으면 전기를 낭비해요. 좋은 기준값은 실제로 여러 번 재 보고 정해요.

계산해 보기

  • 맑은 날: 아침 7시 700, 점심 950, 해 질 무렵 18시 250, 밤 30.
  • 기준 300: 약 18시 30분~6시 30분 켜짐 = 12시간. 기준 800: 약 17시~8시 = 15시간(대낮 흐림에도 켜짐).
  • 기준 100: 20시~5시 = 9시간, 하지만 해 질 무렵엔 어두운데 안 켜져요.

2. 실험 모형과 실제의 차이

· 실제 센서는 값이 흔들려서 기준 근처에서 켜졌다 꺼졌다를 반복해요. 그래서 켜는 기준과 끄는 기준을 다르게 두거나(히스테리시스) 평균을 써요.

· 조도 센서 값을 교실 아침·점심·해 질 무렵 세 번 재서 표로 만들고, 불을 켤 기준값을 정해 이유를 써 보세요.

3. 생활 속에서 · 이어지는 개념

  • 스마트폰 자동 밝기, 자동차 오토라이트, 화장실 센서등 — 모두 기준값이 있어요.

예제

교실에서 아침 650, 점심 900, 해 질 무렵 220을 쟀다면 불을 켤 기준값으로 알맞은 것은?

해 질 무렵(220)엔 켜지고 아침(650)엔 안 켜지는 300~400쯤. 이유를 데이터로 설명하는 것이 설계.

화분 자동 물주기와 창문 자동 닫기에 필요한 센서·구동기는?

화분: 습도 센서 + 펌프. 창문: 빗물 센서 + 모터. 목적 → 부품 → 조건 → 프로그램 → 테스트 순.
