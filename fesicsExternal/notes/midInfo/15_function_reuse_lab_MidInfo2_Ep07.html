함수 — 한 번 정의하고, 여러 번 부른다

별 그리기(20줄)를 부르는 횟수를 바꾸며 복붙 방식과 함수 방식의 줄 수·고칠 곳을 기록하고, 세 변의 길이를 받아 삼각형 여부를 참/거짓으로 돌려주는 함수를 여러 입력으로 시험했습니다. 복붙은 줄 수 20 × 횟수·고칠 곳 = 횟수였고, 함수는 20 + 횟수·고칠 곳 1이었으며, 삼각형 판정은 가장 긴 변 < 나머지 두 변의 합일 때 참이었습니다. 매개변수와 반환값을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 복붙 줄 수 = 20 × n, 함수 줄 수 = 20 + n, 고칠 곳 = n / 1. 삼각형 = 가장 긴 변 < 나머지 두 변의 합.

함수는 ‘별 그리기’라는 이름을 붙인 요리법 — 한 번 정의하고 별(100), 별(200)처럼 부르기만 하며 고칠 때는 한 곳입니다. 괄호 안이 재료(매개변수), return 뒤가 요리(반환값). 반복문은 ‘같은 자리에서 여러 번’, 함수는 ‘여러 자리에서 이름으로’. print()·len()도 남이 만든 함수이고, 한 함수는 한 가지 일을 하는 것이 좋습니다.

개념 정리

1. 한 번 정의하고, 여러 번 부른다

별 하나를 그리는 데 20줄이 든다면, 별 세 개는 복붙으로 60줄이에요. 별을 조금 크게 바꾸려면 세 곳을 고쳐야 하고, 하나를 빠뜨리면 별 크기가 제각각이 돼요. 함수는 "별 그리기"라는 이름을 붙인 요리법이에요. 한 번 정의(20줄)하고 별(100), 별(200)처럼 부르기만 하면 돼요. 고칠 때는 한 곳. 입력(매개변수)을 받아 결과(반환값)를 돌려주는 함수는 계산기처럼 쓸 수 있어요 — 세 변으로 삼각형이 되는지 참/거짓을 돌려주는 함수처럼요.

계산해 보기

  • 복붙: 줄 수 = 20 × 횟수, 고칠 곳 = 횟수. 함수: 줄 수 = 20 + 횟수, 고칠 곳 = 1.
  • 삼각형 판정: 가장 긴 변 < 나머지 두 변의 합이면 참. (3, 4, 5) 참, (1, 2, 5) 거짓.

2. 실험 모형과 실제의 차이

· 함수가 너무 많은 일을 하면 오히려 이해하기 어려워요. 한 함수는 한 가지 일을 하는 것이 좋아요.

· 세 변의 길이를 받아 삼각형이 될 수 있는지 참/거짓을 돌려주는 함수를 만들고 5가지 입력으로 시험해 보세요.

3. 생활 속에서 · 이어지는 개념

  • print(), len()처럼 우리가 쓰는 명령 대부분이 남이 만든 함수예요.
  • 요리법에 "소스 만들기(3쪽 참조)"라고 쓰는 것이 함수 호출이에요.
