중2 정보 · 웹툰 3화 「변수는 상자가 아니라 이름표다」

변수 — = 는 ‘같다’가 아니라 ‘넣어라’

코드 x = 3; y = x × 2; x = x + y; y = y − 1을 한 줄씩 실행하며 모든 변수 값을 표에 기록하고, a = 5; b = a; a = 7과 두 값 바꾸기(t = a; a = b; b = t)도 추적했습니다. x는 3, 3, 9, 9 · y는 −, 6, 6, 5였고, b = a 뒤 a를 7로 바꿔도 b는 5였으며, 임시 이름표 t가 없으면 한 값이 사라졌습니다. 대입의 원리를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 각 줄을 ‘오른쪽 계산 → 왼쪽 변수에 저장’ 규칙으로 실행하고, 줄마다 모든 변수 값을 표에 기록합니다.

표 1. 한 줄씩 추적 (실험 모형)
줄실행 내용xy
x = 3x에 3 넣기3—
y = x × 23 × 2 = 6을 y에36
x = x + y3 + 6 = 9를 x에96
y = y − 16 − 1 = 5를 y에95
(별도) a = 5; b = a; a = 7b는 복사한 순간의 5a = 7b = 5

a = 5는 ‘a와 5가 같다’가 아니라 ‘a라는 이름표가 붙은 자리에 5를 넣어라’입니다. b = a는 그 순간 값을 복사하므로 이후 a가 바뀌어도 b는 모릅니다. x = x + y는 오른쪽을 먼저 계산해 왼쪽에 넣으라는 뜻이라 자연스럽고, 숫자 5와 문자 "5"는 다릅니다(5 + 5 = 10, "5" + "5" = "55").

개념 정리

1. = 는 "같다"가 아니라 "넣어라"

a = 5는 "a와 5가 같다"가 아니라 "a라는 이름표가 붙은 자리에 5를 넣어라"예요. b = a는 a의 값 5를 복사해서 b에 넣어요. 그다음 a = 7을 해도 b는 여전히 5예요 — b는 a를 따라다니는 게 아니라 그때 값을 복사했으니까요. x = x + y는 수학에서는 이상하지만 프로그램에서는 "오른쪽을 계산해 왼쪽에 넣어라"라 자연스러워요. 한 줄씩 표로 추적하면 절대 헷갈리지 않아요.

계산해 보기

  • x = 3; y = x * 2; x = x + y; y = y − 1 → x: 3, 3, 9, 9 / y: −, 6, 6, 5.
  • 두 값 바꾸기: t = a; a = b; b = t — 임시 이름표 t가 없으면 한 값이 사라져요.

2. 실험 모형과 실제의 차이

· 리스트·객체는 값이 아니라 "가리키는 곳"을 복사해서, 하나를 바꾸면 다른 이름으로도 바뀐 것이 보여요. 그건 다음 단계예요.

· x = 3, y = x * 2, x = x + y, y = y − 1을 한 줄씩 실행하며 x, y 값을 표로 추적해 보세요.

3. 생활 속에서 · 이어지는 개념

  • 게임 점수 score = score + 10이 바로 이 규칙이에요.
  • 스프레드시트에서 값을 복사해 붙이면 원본을 바꿔도 안 바뀌는 것과 같아요(수식 참조는 다름).
각 줄을 "오른쪽 계산 → 왼쪽 변수에 저장" 규칙으로 실행하고, 줄마다 모든 변수 값을 표에 기록
뭉치 · 제로 · 닥터 이안

“a = 5, b = a, a = 7. 그러니까 b도 7! a와 b는 연결됐으니까!” “b = a는 ‘연결’이 아니라 ‘복사’ 아니야?” “변수는 값에 붙이는 이름이다. b = a는 그 순간 a의 값을 b에 옮겨 적는 것. 이후 a가 바뀌어도 b는 모른다. 수학의 등호와 다르다. 그래서 a = a + 1이 성립한다.”

웹툰 3화 #1~#2 · 종이컵 두 개와 구슬

닥터 이안 · 제로 · 뭉치

“b는 5다. 컴퓨터는 명령을 위에서 아래로, 한 줄씩, 그 순간의 값으로만 처리한다. 오른쪽을 먼저 계산하고 왼쪽에 넣는다. 순서를 기억해.” “…등호를 수학으로 읽어서 틀렸어.”

웹툰 3화 #4 · a=5 → b에 5 복사 → a에 7 — 제로 3 : 뭉치 0

예제

a = 2; b = a + 3; a = b × 2; b = a − b를 추적하면 최종 a, b는?

a: 2, 2, 10, 10 / b: −, 5, 5, 5 → a = 10, b = 5.

t 없이 a = b; b = a로 두 값을 바꾸면 어떻게 되나?

a = b에서 a의 원래 값이 사라져 둘 다 b의 값이 된다. 임시 이름표 t가 필요.
