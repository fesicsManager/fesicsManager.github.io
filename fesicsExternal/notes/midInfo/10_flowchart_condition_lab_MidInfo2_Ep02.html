순서도와 조건 — 마름모에는 질문이, 화살표에는 답이

횡단보도 건너기 순서도를 조건 없음·조건 1개(신호만)·조건 2개 + 되돌아가기로 바꾸고 신호·차 상황을 대입해 안전하게 건넘·기다림·사고를 기록했습니다. 조건이 없으면 빨간불에도 건너 사고가 났고, 신호만 보면 초록불에 우회전 차가 올 때 위험했으며, 조건 2개에 되돌아가기가 있으면 빨간불이면 기다렸다 다시 확인해 항상 안전했습니다. 순차·선택·반복을 정리합니다.

실험 안내: 순서도를 상황(신호·차)에 대입해 화살표를 따라갑니다. 결과 = 안전하게 건넘 / 기다림 / 사고. 되돌아가기가 있으면 신호가 바뀔 때까지 반복합니다.

순서도에서 네모는 일, 마름모는 예/아니오로 답할 수 있는 질문입니다. 세상의 모든 프로그램은 순차·선택·반복의 조합이며, 좋은 순서도는 필요한 질문을 모두 갖고 ‘아니오’일 때 되돌아가 다시 확인하는 화살표(반복)가 있습니다. ‘90 이상이면 A’ 뒤에 ‘아니면?’이 없으면 89점은 갈 곳이 없습니다.

개념 정리

1. 마름모에는 질문이, 화살표에는 답이

순서도에서 네모는 일(건넌다), 마름모는 질문(신호가 초록인가?)이에요. 마름모 안에 "길을 건넌다"를 넣으면 예/아니오 화살표가 갈 곳이 없어요. 질문이 없으면 빨간불에도 건너고, 질문이 하나면 초록불에 차가 와도 건너요. 좋은 순서도는 필요한 질문을 모두 갖고, 조건이 안 맞으면 되돌아가서 기다리는 화살표가 있어요. 그래야 "아니오"일 때 멈추지 않고 다시 확인해요.

계산해 보기

  • 조건 없음: 신호·차와 상관없이 건넘 → 빨간불·차 있음이면 사고.
  • 조건 1개(신호만): 초록불에 차가 오면(우회전 차) 위험.
  • 조건 2개 + 되돌아가기: 빨간불이면 기다렸다 다시 확인 → 항상 안전.

결과 질문 기다림

순서도와 상황을 바꿔 가며 주황 점이 화살표를 따라가게 해 보세요. 되돌아가는 화살표가 없으면 "아니오"에서 그대로 끝나 버리고, 되돌아가기가 있으면 기다렸다가 다시 묻습니다. (기다리는 동안 신호가 초록으로 바뀌고 차가 지나간다고 가정했어요.)

2. 실험 모형과 실제의 차이

· 실제 판단에는 "차가 멈출 것 같은가"처럼 확률적인 것이 많아요. 프로그램은 그것도 숫자 조건으로 바꿔야 해요.

· 자판기에서 음료 사기를 순서도로 그려 보세요. 마름모 최소 2개, 되돌아가는 화살표 최소 1개.

3. 생활 속에서 · 이어지는 개념

  • 엘리베이터(문에 사람 있나? → 다시 열기), 세탁기(물이 찼나? → 기다림) — 모두 마름모와 되돌아가기예요.
  • 게임의 "체력이 0인가?"도 마름모예요.

예제

자판기에서 음료 사기 순서도의 마름모 두 개와 되돌아가는 화살표 하나를 설계하면?

마름모 ① 돈이 충분한가?(아니오 → 돈 더 넣기 → 되돌아감) ② 재고가 있는가?(아니오 → 다른 음료 고르기). 예/예 → 버튼 → 음료 → 끝.

엘리베이터 문의 ‘사람이 있나? → 다시 열기’는 세 구조 중 무엇인가?

선택(마름모) + 반복(되돌아가기) — 사람이 없을 때까지 반복.
