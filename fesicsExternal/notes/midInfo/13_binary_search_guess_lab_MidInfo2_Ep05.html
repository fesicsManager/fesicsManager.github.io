이진 탐색 — 반씩 자르면 열 번이면 천 개

자료 수 N을 바꾸며 하나씩 묻기(평균 N/2·최악 N)와 반씩 자르기(≈ log₂N)의 질문 수를 기록했습니다. 1~1000은 1000 → 500 → 250 → … → 1로 열 번, 100은 7번, 100만은 20번이었고, 하나씩 묻기는 평균 500번이었습니다. 정렬되어 있어야 쓸 수 있는 이진 탐색의 원리를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 반씩 자르기는 가운데 = ⌊(왼쪽 + 오른쪽) ÷ 2⌋, 크면 왼쪽 = 가운데 + 1, 작으면 오른쪽 = 가운데 − 1, 같으면 끝. 하나씩은 1부터 차례로 묻습니다.

‘1이야? 2야?’는 평균 N/2번이지만 가운데를 묻고 크다/작다만 들으면 절반이 사라져 열 번이면 천 개입니다. 정렬되어 있어야 쓸 수 있으므로 컴퓨터는 찾기 전에 정렬부터 합니다 — 정렬은 비용이지만 한 번 내면 계속 이득. 사전·전화번호부·업다운 게임 필승 전략이 모두 이진 탐색입니다.

개념 정리

1. 반씩 자르면 열 번이면 천 개

1~1000 중 숨은 숫자를 "1이야? 2야?" 하고 물으면 평균 500번이 걸려요. 대신 가운데(500)를 묻고 "크다/작다"만 들으면 절반이 사라져요. 1000 → 500 → 250 → 125 → 63 → 32 → 16 → 8 → 4 → 2 → 1 — 열 번이에요. 이것이 이진 탐색이고, 정렬되어 있어야(순서가 있어야) 쓸 수 있어요. N이 2배가 되어도 질문은 한 번만 늘어요. 100만 개면 20번, 10억 개면 30번.

계산해 보기

  • 필요한 질문 수 ≈ log₂N: 100 → 7번, 1,000 → 10번, 1만 → 14번, 100만 → 20번.
  • 하나씩 묻기: 평균 N/2번, 최악 N번.

2. 실험 모형과 실제의 차이

· 순서가 없는 목록에서는 반씩 자르기를 쓸 수 없어요. 그래서 먼저 정렬(6화)해 두거나 딕셔너리(고등)를 써요.

· 짝이 1~100 사이 숫자를 정하면 이진 탐색으로 7번 안에 맞혀 보세요. 질문한 숫자를 모두 기록하세요.

3. 생활 속에서 · 이어지는 개념

  • 사전에서 단어 찾기, 전화번호부 — 우리는 이미 반씩 자르기를 써요.
  • "업다운 게임"의 필승 전략이 이진 탐색이에요.

뭉치 · 제로 · 닥터 이안

“‘홍길동’ 찾기! 첫 장부터 한 명씩! 이게 제일 확실해!” “ㅎ은 맨 뒤인데?” “가운데를 편다. ‘ㅅ’이면 홍길동은 뒤쪽. 뒤쪽의 가운데를 편다. 반씩 버린다. 순차 탐색은 아무 데나 되지만 느리고, 이진 탐색은 정렬된 곳에서만 되지만 빠르다.”

예제

1~100에서 숨은 수 73을 이진 탐색으로 찾을 때 질문 순서는?

50(크다) → 75(작다) → 62(크다) → 68(크다) → 71(크다) → 73(정답) — 6번(최대 7번).

정렬 안 된 책상 서랍에서 물건 찾기는 어떤 탐색인가?

순차 탐색 — 순서가 없어 반씩 자르기를 쓸 수 없다. 그래서 느리다.
