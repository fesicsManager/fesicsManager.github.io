임계 경로 — 경로는 더하고 합류점은 최댓값, 가장 긴 경로가 완공일

카페 리모델링 작업 6개(철거 2 · 전기 3 · 배관 5 · 바닥 2 · 도장 3 · 가구 1일)의 완공일을 모두 더하기 · 모두 동시에 · 선후 관계의 세 방법으로 구하고, 지연 · 단축 · 추가 조건을 바꿔 기록했습니다. 모두 더하면 16일, 모두 동시에 하면 5일이었지만 선후 관계로 구한 최소 기간은 가장 긴 경로 A-C-D-F의 10일이었습니다. 임계 경로와 작업별 여유, 일정을 줄이려면 어디를 줄여야 하는지를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 완공일 계산 방법(① 모두 더하기 · ② 모두 동시에 · ③ 선후 관계로), B 전기 배선 지연(없음 · 1일 · 2일), 인원 투입으로 하루 단축(없음 · C 배관 · E 도장 · A 철거), 추가 선후 관계(없음 · D 바닥은 E 도장이 끝난 뒤)를 고르고 일정 계산하기를 누르면, 날짜별 작업표에 막대가 그려지고 경로별 길이 · 최소 기간 · 임계 경로 · 작업별 빠른 시작과 여유가 나오며 기록표에 쌓입니다. 세 가지 계산 방법을 모두 해 보고, B 지연 · C 단축 · E 단축 · ‘D는 E 뒤’ 조건도 기록해 보세요. 기록이 4개 이상이면 결과 비교 탭에서 조건별 최소 기간 막대와 계산 방법 비교표를 볼 수 있습니다.

표 1. 계산 방법과 조건에 따른 완공일 (실험 예시, 작업 기간은 수업용 가상 자료)
방법B 지연단축추가 조건답실제 최소임계 경로
더하기0일없음없음16일10일A-C-D-F
동시0일없음없음5일10일A-C-D-F
선후 관계0일없음없음10일10일A-C-D-F
선후 관계2일없음없음11일11일A-B-E-F
선후 관계0일C−1없음9일9일A-B-E-F, A-C-D-F
선후 관계0일없음D는 E 뒤11일11일A-B-E-D-F

경로 A → B → E → F는 9일, A → B → D → F는 8일, A → C → D → F는 10일이므로 가장 긴 경로 10일이 최소 기간이고, 여유가 0인 A · C · D · F가 임계 경로입니다. 모두 더하기(16일)는 한 사람이 혼자 할 때, 모두 동시에(5일)는 선후 관계를 어긴 계산입니다. B와 E는 여유가 1일이라 B가 하루 늦어도 10일 그대로지만 이틀 늦으면 11일이 되고, ‘D는 E 뒤’ 조건 하나만 더해도 임계 경로가 A-B-E-D-F로 바뀌며 11일이 됩니다. C를 하루 줄이면 9일이 되지만 E를 하루 줄이면 10일 그대로라, 일정을 줄이려면 임계 경로 위 작업을 줄여야 합니다.

개념 정리

1. 경로는 더하고, 합류점은 최댓값

작업마다 '무엇이 끝나야 시작할 수 있는가'를 적고, 시작에서 끝까지 이어지는 경로의 길이를 구합니다. 가장 긴 경로가 전체 기간이고 그 경로가 임계 경로예요.

  • A → B → E → F = 2 + 3 + 3 + 1 = 9일
  • A → B → D → F = 2 + 3 + 2 + 1 = 8일
  • A → C → D → F = 2 + 5 + 2 + 1 = 10일 ← 임계 경로

가장 빠른 시작 = 앞 작업 끝나는 날의 최댓값 · 가장 늦은 시작 = 뒤 작업 늦은 시작의 최솟값 − 기간 · 여유 = 늦은 시작 − 빠른 시작

B·E는 여유 1일 — B가 하루 늦어도 완공 10일, 이틀 늦으면 11일. 'D는 E가 끝난 뒤' 조건을 더하면 임계 경로가 A-B-E-D-F로 바뀌고 11일이 됩니다.

2. 줄이려면 임계 경로를

C를 4일로 줄이면 9일(임계 경로가 둘이 됨). 임계 경로가 아닌 E만 줄이면 하루도 안 줄어요.

3. 실험 모형과 실제의 차이

· 기간을 확정값으로 봤지만 실제로는 날씨·자재 입고로 흔들립니다.

· '동시에 가능'이 '동시에 할 사람이 있음'을 뜻하지는 않아요. 같은 기사가 B와 C를 다 맡으면 동시 진행은 불가능합니다.

가장 빠른 시작 = 앞 작업들이 끝나는 날의 최댓값 · 여유 = 가장 늦은 시작 − 가장 빠른 시작 · 최소 기간 = 가장 긴 경로 = 2 + 5 + 2 + 1 = 10일
닥터 이안

“모든 작업을 더하는 것도, 모두 동시에 하는 것도 틀렸다. 답은 그 사이 어딘가에 있고, 그걸 정하는 게 선후 관계다.”

제로

“여유가 0인 A, C, D, F가 임계 경로예요. 이 중 하나라도 하루 늦으면 오픈도 하루 늦어져요.”

웹툰 7화 #4 · 경로 길이와 작업별 여유

예제

카페 리모델링에서 A 철거를 인원 투입으로 하루 줄이면 완공일과 임계 경로는 어떻게 되는가?

A는 모든 경로가 지나는 작업이므로 세 경로가 모두 하루씩 줄어 A → B → D → F = 7일, A → B → E → F = 8일, A → C → D → F = 9일이 됩니다. 최소 기간은 9일이고 임계 경로는 그대로 A-C-D-F입니다. 9일, A-C-D-F

작업 P(3일), Q(4일, P 뒤), R(2일, P 뒤), S(3일, Q·R 뒤)가 있다. 각 작업의 가장 빠른 시작일, 최소 기간, R의 여유를 구하시오.

P 0일 → Q, R 3일 → S는 합류점이므로 max(3 + 4, 3 + 2) = 7일 → 완공 7 + 3 = 10일. R의 가장 늦은 시작 = 7 − 2 = 5일이므로 여유 = 5 − 3 = 2일. 임계 경로는 P-Q-S입니다. P 0일 · Q 3일 · R 3일 · S 7일, 최소 기간 10일, R 여유 2일
