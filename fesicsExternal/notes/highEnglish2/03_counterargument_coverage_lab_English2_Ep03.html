고등 영어Ⅱ · 웹툰 3화 「반론을 소개하면 내 주장이 약해지는가」

반론과 재반박 — 독자의 반론을 공정하게 꺼내 답하는 논설

등교 시간을 8시 30분으로 늦추자는 영어 논설 네 판본(A 반론 없음 · B 허수아비 반론 · C 양보와 재반박 · C + 남은 과제)을 학부모 독자의 걱정 ⓐ아침 등교 · ⓑ동아리 · ⓒ버스에 맞대 보았습니다. A와 B는 반론 대응 수가 0 / 3이었고, C는 ⓐⓑ에 양보와 재반박으로 답해 2 / 3, C+는 ⓒ를 남은 과제로 정직하게 밝혔습니다. 논설에서 반론을 다루는 방법과 연결어를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 논설 판본(A · B · C · C+)과 이 학부모 독자의 가장 큰 걱정(ⓐ 아침 등교 · ⓑ 동아리 · ⓒ 버스)을 고르고 이 독자에게 읽히기를 누르면 ⓐⓑⓒ 중 답한 반론 수, 이 독자의 걱정에 대한 대응(답 없음 / 남은 과제로 밝힘 / 양보 + 재반박), 찾은 연결어, 허수아비 반론 여부가 기록됩니다. 네 판본을 모두 읽혀 보고 특히 걱정 ⓒ(버스)를 가진 독자로도 해 보세요. 기록이 4개 이상이면 결과 비교 탭에서 판본별 반론 대응률과 독자 걱정 × 판본 표를 볼 수 있습니다.

표 1. 판본과 독자 걱정에 따른 반론 대응 (실험 예시, 반론 세 개는 가상 설문 상위 3개)
판본독자 걱정이 걱정에답한 반론
Aⓐ 아침 등교답 없음0/3
Bⓐ 아침 등교답 없음0/3
Cⓐ 아침 등교양보 + 재반박으로 답함2/3
Cⓒ 버스답 없음2/3
C+ⓑ 동아리양보 + 재반박으로 답함2/3
C+ⓒ 버스남은 과제로 정직하게 밝힘2/3

B는 반론 문장을 넣었지만 아무도 하지 않은 주장(정오 등교)을 반박한 허수아비 논증이라 대응 수가 0이었습니다. C는 Some parents worry that …(반론) → This concern is understandable.(양보) → However, …(재반박)의 순서로 학부모의 실제 걱정 ⓐⓑ에 답해 2 / 3이 되었습니다. 해결책이 없는 ⓒ는 The bus schedule would need to be reviewed …처럼 남은 과제로 정직하게 밝히는 편이 믿음을 얻습니다. 양보는 항복이 아니라, 약점을 인정하면서 주장을 유지하는 방법입니다.

개념 정리

1. 논설의 독자는 아직 설득되지 않은 사람

그 사람 머릿속에는 이미 반론이 있습니다. 글이 그 반론을 모른 척하면 독자는 "이 사람은 내 걱정을 모르는구나" 하고 읽기를 멈춰요. 반론을 공정하게 꺼내 답하면 독자의 질문을 먼저 받아 주는 셈입니다.

주장(claim) ← 이유(reason) ← 근거(evidence)　·　반론(counterargument) → 양보(concession) → 재반박(rebuttal)

  • 허수아비 논증: 아무도 하지 않은 약한 주장(정오 등교)을 세워 놓고 이기는 척 — 대응 수 0
  • 양보는 항복이 아니다: Admittedly, this is a real cost; still, … — 약점을 인정하면서 주장은 유지
  • 모르는 건 정직하게: The bus schedule would need to be reviewed … — 남은 과제를 밝히는 글이 더 믿음을 얻음

2. 연결어 지도

  • 반론 소개: Some may argue that…, Critics point out that…, Some parents worry that…
  • 양보: Admittedly, It is true that…, This concern is understandable.
  • 재반박: However, Even so, Nevertheless, still

3. 실험 모형과 실제의 차이

· "계속 읽을 가능성"은 대본의 논리를 단계로 나타낸 것이지 실제 설문 결과가 아닙니다.

· 실제 독자의 걱정은 이 세 개보다 많을 수 있어요. 쓰기 전에 독자의 반론 목록부터 만드는 것이 핵심입니다.

주장(claim) ← 이유(reason) ← 근거(evidence) · 반론(counterargument) → 양보(concession) → 재반박(rebuttal)

예제

C 판본에서 Some parents worry that, This concern is understandable, However, Others point out that, Admittedly, still의 역할을 반론 소개 · 양보 · 재반박으로 나누시오.

반론 소개: Some parents worry that, Others point out that. 양보: This concern is understandable, Admittedly. 재반박: However, still. 이 표지를 따라가면 남의 논설도 뼈대가 보인다. 반론 소개 2개 · 양보 2개 · 재반박 2개

‘수업 중 휴대전화를 걷자’는 논설에서 학생 독자의 반론 ‘급한 연락을 받을 수 없다’에 양보와 재반박으로 답하는 두 문장을 영어로 쓰시오.

예: Some students worry that they will miss urgent calls from their families. This concern is understandable; however, families could call the school office, which can pass on urgent messages right away. 반론을 공정하게 소개하고, 인정한 뒤, 해결책으로 재반박했다.
