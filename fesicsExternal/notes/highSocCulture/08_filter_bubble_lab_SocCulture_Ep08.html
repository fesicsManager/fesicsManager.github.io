추천 알고리즘과 필터 버블 — 접근이 같아도 화면은 다르다

관점 X와 Y의 글이 반반 섞인 가상 플랫폼에서 30일 동안 추천 방식, 처음 성향, 이용 습관을 바꾸며 30일째 반대 관점 비율과 나중 성향을 기록했습니다. 처음 성향 X 60%일 때 시간순은 반대 관점 50%를 유지했지만, 개인화 추천은 14%까지 줄고 성향이 X 80%로 기울었으며, 다른 출처를 찾아보면 53%로 되돌아갔습니다. 추천 알고리즘이 정보 환경을 바꾸는 고리와 정보 격차를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 추천 방식(시간순 / 참여도 기반 개인화 / 개인화 + 다양성 보정), 나의 처음 성향(중립 X 50% / 약간 X 쪽 60%), 이용 습관(추천 화면만 봄 / 다른 출처도 하루 2개)을 고르고 30일 사용하기를 누르면 30일째 반대 관점 비율과 나중 성향이 기록됩니다. 클릭 확률과 추천 규칙은 가상 모형이며 실제 플랫폼의 알고리즘은 공개되지 않은 부분이 많습니다. 4개 이상 기록하면 결과 비교 탭이 열립니다.

표 1. 추천 방식·성향·습관별 30일 결과 (실험 모형)
추천 방식처음 성향습관30일째 반대 관점나중 성향
시간순X 60%추천만50%X 60%
개인화X 60%추천만14%X 80%
개인화+보정X 60%추천만30%X 76%
개인화X 60%다른 출처53%X 58%
개인화중립추천만50%X 50%
시간순X 60%다른 출처50%X 60%

같은 플랫폼에 접근했는데도 추천 방식에 따라 화면이 달라졌습니다. 개인화 추천에서는 내 성향 쪽 글을 더 누르고(확증 편향) → 추천이 그 클릭 비율을 따라가고 → 성향도 클릭 쪽으로 움직이는 고리가 돌아, 반대 관점이 50%에서 14%로 줄고 성향이 X 60%에서 80%로 기울었습니다(필터 버블). 다양성 보정은 반대 관점을 30% 아래로 내려가지 않게 막았고, 다른 출처를 찾아보는 습관(그날 화면에 덜 나온 관점으로 2개를 채움, 반반이면 X 1개 + Y 1개)은 고리를 밖에서 끊었습니다. 처음 성향이 중립이면 고리가 돌지 않았습니다. 실제 필터 버블의 강도는 연구마다 결과가 엇갈리며, 접근(1차) 외에도 활용 역량(2차)과 성과(3차)의 정보 격차가 남습니다.

개념 정리

1. 접근이 같아도 화면은 다르다

추천 알고리즘은 이용자의 과거 반응(클릭, 체류 시간)을 근거로 보여 줄 정보를 고릅니다. 그래서 같은 서비스를 써도 사람마다 다른 정보 환경이 만들어져요. 비슷한 관점만 반복해 보게 되는 현상을 필터 버블이라고 부릅니다.

2. 정보 격차의 세 층

  • 1차 접근: 기기·통신망이 있는가
  • 2차 활용 역량: 검색·판별·생산 능력
  • 3차 성과: 정보를 실제 이익(취업·행정·의료 등)으로 바꾸는 정도

3. 이 실험의 계산 방법

클릭 확률 = 45% ± 0.9 × (성향 − 50%) — 내 성향 쪽 글을 더 누름 (확증 편향)
개인화 추천: 내일 같은 관점 비율 = 지금까지 클릭 중 같은 관점 비율 (다양성 보정이 있으면 최대 70%)
다른 출처 2개: 그날 화면에 덜 나온 관점으로 채움 (반반이면 X 1개 + Y 1개)
성향은 매일 클릭한 글 쪽으로 조금씩 움직입니다.

4. 실험 모형과 실제의 차이

· 필터 버블이 실제로 얼마나 강한지는 연구마다 결과가 엇갈립니다. 사람들은 추천 밖의 경로로도 정보를 얻어요.

· 감정을 자극하는 글이 참여를 더 끌어 확산에 유리하다는 문제, 플랫폼은 알고 이용자는 모르는 데이터 비대칭도 함께 논의됩니다.

5. 생활 속에서 · 이어지는 개념

  • 개인 차원에서는 출처를 다양화하고 추천 밖 경로로 찾아보기, 사회 차원에서는 알고리즘 투명성, 데이터 권리, 디지털 리터러시 교육이 논의됩니다.

예제

성향이 X 60%인 사람의 클릭 확률은 X 글 45% + 0.9 × 10%, Y 글 45% − 0.9 × 10%입니다. 첫날 X 5개·Y 5개를 보면 클릭 중 X 비율은?

X 클릭 확률 54%, Y 36%. 기대 클릭 X 5 × 0.54 = 2.7, Y 5 × 0.36 = 1.8. X 비율 = 2.7 ÷ 4.5 = 60%. 개인화 추천은 이 비율을 따라가 둘째 날 반대 관점이 약 43%로 줄었습니다. 60%

같은 조건에서 ‘개인화 + 다양성 보정’을 고르면 30일째 반대 관점 비율이 30%였습니다. 왜 14%까지 내려가지 않았나요?

다양성 보정은 같은 관점 비율을 최대 70%로 제한하므로, 반대 관점이 30% 아래로 내려가지 않습니다. 다만 성향은 X 76%까지 기울었습니다. 같은 관점 비율 상한 70% 때문
