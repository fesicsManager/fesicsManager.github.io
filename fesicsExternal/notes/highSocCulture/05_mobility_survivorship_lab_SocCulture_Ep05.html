고등 사회와 문화 · 웹툰 5화 「계층은 노력으로 넘을 수 있는가」

사회 이동의 측정 — 성공 수기와 전체 통계

가상 사회 2,000가구의 부모·자녀 소득 5분위 이동 표를 만들며 부모-자녀 소득의 연관 정도(β), 보는 자료(성공 수기 / 전체 통계), 출발 조건 지원 정책을 바꿔 하위 20% 출신의 상위 20% 진입률을 기록했습니다. β가 0.2 → 0.4 → 0.6으로 커지자 진입률은 14.5% → 6.3% → 2.0%로 줄었고, 성공 수기만 보면 언제나 100%처럼 보였습니다. 생존 편향과 이동성 지표를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 부모-자녀 소득의 연관 정도(β 0.2 / 0.4 / 0.6), 보는 자료, 사회 정책(없음 / 출발 조건 지원: 모형에서 β −0.1)을 고르고 통계 만들기를 누르면 보이는 성공률과 실제 하위 → 상위 진입률이 기록됩니다. β와 가구 자료는 가상 모형이며, 실제 나라별 값은 연구마다 측정 방법이 다릅니다. 4개 이상 기록하면 결과 비교 탭이 열립니다.

표 1. 연관 정도·자료·정책별 하위 → 상위 진입률 (하위 20% 출신 400가구, 실험 모형)
β자료정책보이는 성공률실제 상위 진입
0.2전체 통계없음14%14.5%
0.4전체 통계없음6%6.3%
0.6전체 통계없음2%2.0%
0.3전체 통계지원11%11.0%
0.5전체 통계지원4%4.3%
0.4성공 수기없음100%6.3%

성공 수기 10편만 읽으면 성공률이 언제나 100%로 보였지만, 같은 사회(β 0.4)의 전체 통계에서 하위 20% 출신 400가구 중 상위 20%에 든 가구는 25가구(6.3%)였습니다. 같은 방식으로 시도했다가 실패한 사람은 책을 쓰지 않아 분모가 보이지 않는 것, 이것이 생존 편향입니다. β(세대 간 소득 탄력성에 해당)가 클수록 부모 소득이 자녀 소득을 많이 설명해 이동성이 낮았고, 기회가 완전히 평등하다면 각 칸은 20%(80가구)여야 합니다. 이동성을 볼 때는 실제 지표와 사람들의 인식을 둘 다 재야 합니다. 모형의 β는 점수 상관이라 실제 로그 소득 탄력성과는 조금 다릅니다.

개념 정리

1. 분모가 보이지 않는 자료

성공한 사람의 이야기만 모으면 성공 확률을 알 수 없습니다. 같은 방식으로 시도했다가 실패한 사람은 책을 쓰지 않으니까요. 이것이 생존 편향입니다. 그래서 개인 사례가 아니라 부모와 자녀를 짝지어 추적한 대규모 통계를 봐야 해요.

2. 이동성을 재는 지표

  • 세대 간 소득 탄력성: 부모 소득이 자녀 소득을 얼마나 설명하나 → 값이 클수록 이동성 낮음
  • 계층 이동 인식 조사: 사람들이 이동 가능하다고 믿는 정도 → 실제와 다를 수 있음
  • 상위 소득 진입률: 하위 출신이 상위로 가는 비율 → 절대 수치로 비교 가능
  • 국제 비교: 나라별 차이 → 제도 효과 추정

3. 이 실험의 계산 방법

자녀 소득 점수 = β × 부모 소득 점수 + √(1 − β²) × 우연 (점수는 평균 0, 표준편차 1로 맞춤)
출발 조건 지원 정책은 모형에서 β를 0.1 낮추는 것으로 나타냈습니다.

4. 실험 모형과 실제의 차이

· 이 모형의 β는 부모-자녀 소득 점수의 상관이며, 실제 "소득 탄력성"은 로그 소득의 기울기로 계산해 조금 다릅니다.

· 국제 비교 연구에서는 공교육의 지역 간 격차가 작고, 초기 아동기 지원이 크고, 의료·주거 불안이 낮은 나라에서 이동성이 높은 경향이 보고됩니다.

5. 생활 속에서 · 이어지는 개념

  • 이동성이 낮은데 높다고 믿으면 실패가 전부 개인 탓이 되고, 실제보다 낮게 믿으면 아무도 시도하지 않습니다. "사실"과 "인식"을 둘 다 재야 하는 이유예요.
자녀 소득 점수 = β × 부모 소득 점수 + √(1 − β²) × 우연 · 하위 → 상위 진입률 = (하위 20% 출신 중 상위 20% 가구) ÷ 400

닥터 이안

“그렇다. 이동성이 낮은데 높다고 믿는 사회에서는 실패가 전부 개인 탓이 된다. 반대로 실제보다 낮게 믿으면 아무도 시도하지 않고.”

웹툰 5화 #4 · 이동성을 재는 지표들

예제

β 0.4일 때 하위 20% 출신 400가구 중 25가구가 상위 20%에 들었습니다. 진입률은 얼마이고, 기회가 완전히 평등할 때와 비교하면?

25 ÷ 400 = 6.25% ≈ 6.3%. 완전히 평등하면 각 칸 20%, 즉 80가구여야 하므로 그 약 3분의 1 수준입니다. 약 6.3% (평등 기준 20%)

같은 사회에서 성공 수기 10편만 읽으면 성공률이 몇 %로 보이고, 왜 그런가요?

수기는 성공한 사람만 쓰므로 10명 모두 성공한 사례입니다. 시도했다가 실패한 가구(분모 400가구 중 375가구)는 자료에 나타나지 않습니다. 100% — 생존 편향
