극한 실험실 — 함숫값이 없어도 극한은 있다

(x² − 1)/(x − 1), |x|/x, 계단함수 세 함수에서 문제의 x에 ±0.001 등으로 다가가며 왼쪽 값·오른쪽 값을 재고 함숫값과 비교했습니다. 첫 함수는 x = 1에서 값이 없어도 극한 2가 있었고, 나머지 둘은 함숫값이 있거나 없거나 좌우 값이 달라 극한이 없었습니다. 극한의 뜻을 정리합니다.

극한은 ‘도착했을 때의 값’이 아니라 다가가는 값이라 함숫값과 무관합니다. (x² − 1)/(x − 1)은 x ≠ 1에서 x + 1과 같아 2로 다가갑니다. 극한이 존재하려면 좌극한과 우극한이 모두 있고 서로 같아야 합니다.

개념 정리

1. 극한은 '도착했을 때의 값'이 아니라 '다가가는 값'이에요

(x² − 1)/(x − 1)은 x = 1에서 값이 없지만(0/0), x가 1에 가까이 갈 때 값은 x + 1 → 2로 다가가요. 극한은 함숫값과 무관해요. 반대로 |x|/x나 계단함수처럼 왼쪽에서 다가간 값과 오른쪽에서 다가간 값이 다르면 극한이 없어요. 극한이 존재하려면 좌극한과 우극한이 모두 있고 서로 같아야 해요.

세 함수로 확인

  • (x² − 1)/(x − 1): x → 1일 때 0.999 → 1.999, 1.001 → 2.001 → 극한 2, 함숫값 없음.
  • |x|/x: x → 0⁻ → −1, 0⁺ → 1 → 극한 없음.
  • 계단함수: 좌우 극한이 달라 극한 없음, 함숫값은 정의됨.

왼쪽과 오른쪽에서 다가가 보기

왼쪽 오른쪽 극한 함숫값

주황 점은 왼쪽(a − d), 초록 점은 오른쪽(a + d)에서 다가가요. 두 값이 같은 수로 모이면 그것이 극한이고, 그 점의 함숫값(빈 원 = 값 없음)과는 상관없어요. 계단함수는 y = [x](x를 넘지 않는 가장 큰 정수)로 그렸어요.

2. 자주 하는 오해 바로잡기

· "극한 = 대입" → 대입이 가능하고 연속이면 같지만, 그렇지 않은 경우가 극한의 핵심이에요.

3. 생활 속에서 · 이어지는 개념

  • 0.999… = 1, 순간 속도, 원의 넓이(정다각형의 극한)가 모두 극한 개념이에요.
x = a ± 0.001 등에서 함숫값 계산 → 좌·우 값 비교, f(a) 정의 여부 별도 표시

예제

lim_{x→2} (x² − 4)/(x − 2)는?

x ≠ 2에서 x + 2 → 4. x = 2 대입은 0/0이지만 극한은 있습니다.

lim_{x→0} |x|/x가 존재하지 않는 까닭은?

좌극한 −1, 우극한 1로 다르기 때문.
