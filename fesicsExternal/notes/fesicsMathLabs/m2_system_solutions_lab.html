연립방정식 실험실 — 해는 1개·없음·무수히 많음

2x + y = 4를 고정하고 두 번째 식 ax + by = c의 계수를 바꿔 두 직선을 그리며 해의 개수를 기록했습니다. x·y 계수의 비가 다르면 한 점에서 만나 해 1개, 계수비는 같은데 상수비가 다르면 평행이라 해 없음, 상수까지 비례하면 같은 직선이라 무수히 많았습니다. 계수로 해의 개수를 판정하는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 두 번째 식의 계수를 정해 보자. 첫 번째 식은 2x + y = 4로 고정이다.

표 1. 두 번째 식과 해의 개수 (실험 예시, 첫 식 2x + y = 4)
두 번째 식계수비 같은가 (a/2 = b/1)?상수까지 비례 (= c/4)?해교점
4x + 2y = 8예예무수히 많음같은 직선
4x + 2y = 9예아니오없음평행
x − y = 1아니오—1개(5/3, 2/3)
−2x − y = −4예예무수히 많음같은 직선
3x + 2y = 6아니오—1개(2, 0)

4x + 2y = 8은 2x + y = 4의 2배 → 같은 직선; 4x + 2y = 9는 기울기 같고 절편 다름 → 평행. 계수만 보고 그래프를 그리기 전에 알 수 있으며, 해가 없는 것은 문제가 틀린 것이 아니라 조건이 모순(평행)인 것입니다.

개념 정리

1. 해의 개수는 두 직선의 위치 관계: 1개·없음·무수히 많음

2x + y = 4와 ax + by = c에서 x·y 계수의 비가 다르면 두 직선이 한 점에서 만나 해 1개, 계수비는 같은데 상수비가 다르면 평행이라 해 없음, 상수까지 비례하면 같은 직선이라 해가 무수히 많아요. 계수만 보고 그래프를 그리기 전에 알 수 있어요.

왜 그럴까

  • 4x + 2y = 8: 2x + y = 4의 2배 → 같은 직선 → 무수히.
  • 4x + 2y = 9: 기울기 같고 절편 다름 → 평행 → 없음.
  • x − y = 1: 기울기 다름 → 교점 하나.

2. 자주 하는 오해 바로잡기

· "해가 없으면 문제가 틀렸다" → 조건이 모순인 것(평행)일 뿐이에요.

3. 생활 속에서 · 이어지는 개념

  • 두 요금제가 같아지는 사용량(교점), 절대 같아지지 않는 경우(평행)가 이 판정이에요.
a/2 = b/1 인지, = c/4 인지로 판정 → 그래프의 교점 수와 대조

예제

x + 2y = 3, 2x + 4y = k가 해를 갖지 않는 k는?

계수비 2 → 상수도 6이면 무수히, 아니면 없음 → k ≠ 6.

두 요금제 y = 2x + 10, y = 2x + 5가 같아지는 사용량은?

평행 → 없다(항상 두 번째가 5 싸다).
