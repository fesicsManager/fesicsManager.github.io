분모가 같은 분수 실험실 — 분모끼리 더하면 생기는 일

분모가 같은 두 분수를 막대와 원 조각으로 모으거나 덜어 내며 답을 세었습니다. 답은 언제나 분자(조각의 개수)끼리만 계산한 값이었고, 분모끼리도 더한 답은 띠 길이가 실제 합의 절반밖에 되지 않았습니다. 분모가 같은 분수의 덧셈과 뺄셈 방법을 정리합니다.

실험 안내: 분모(전체를 몇 조각으로 나눌지)와 두 분자를 정하고 계산해 보자.

표 1. 조각을 세어 구한 답과 분모끼리도 계산한 답 (실험 예시)
식조각 세기실제 답분모끼리도 계산하면
2/7 + 3/71/7 조각 2개 + 3개 = 5개5/75/14 (절반 길이)
1/4 + 2/41/4 조각 1개 + 2개 = 3개3/43/8 (절반 길이)
5/7 + 4/71/7 조각 9개9/7 = 1과 2/79/14
6/8 − 2/81/8 조각 6개 − 2개 = 4개4/8분모 0 (말이 안 됨)
1 − 3/55/5에서 1/5 조각 3개를 덜어 냄2/5—

조각의 크기(분모)가 같으니 조각의 개수(분자)만 세면 답이 나왔습니다. 분모끼리도 더한 답은 늘 실제 합보다 작았습니다.

개념 정리

1. 분모는 조각의 크기, 분자는 조각의 개수

2/7은 전체(1)를 똑같이 7조각으로 나눈 것 가운데 2조각이에요. 분모 7은 조각의 크기(1/7)를, 분자 2는 조각의 개수를 말해요. 분모가 같은 두 분수는 조각의 크기가 같으니, 조각을 그대로 모으거나 덜어 낼 수 있어요.

2. 분모가 같은 분수의 덧셈과 뺄셈

분모가 같으면 분자끼리만 더하거나 빼고, 분모는 그대로 써요.

  • 2/7 + 3/7 → 1/7 조각 2개와 3개를 모으면 5개 → 5/7.
  • 6/8 − 2/8 → 1/8 조각 6개에서 2개를 덜어 내면 4개 → 4/8.
  • 1 − 3/5 → 1을 5/5로 바꾸면 5/5 − 3/5 = 2/5.
  • 5/7 + 4/7 = 9/7 → 7조각이 모이면 1이 되므로 1과 2/7.

처음 값은 1/5 + 1/5예요. 5등분 띠에 두 칸이 색칠되어 2/5가 되고, 아래 빨간 띠(분모끼리도 더한 2/10)는 그 절반 길이예요. 분모와 분자를 바꾸고 ‘뺄셈’도 눌러 보세요. 분자는 분모보다 클 수 없고, 뺄셈에서는 둘째 분자가 첫째보다 클 수 없어 자동으로 맞춰져요.

3. 분모끼리도 더하면 왜 틀릴까

1/5 + 1/5를 ‘분자끼리, 분모끼리’ 더해 2/10이라고 하면, 분모 10은 전체를 10조각으로 더 잘게 나눈다는 뜻이 돼요. 조각이 절반 크기로 작아졌는데 개수는 2개 그대로라, 띠 길이가 실제 답 2/5의 절반밖에 안 돼요. 무언가를 더했는데 1/5 하나와 같은 길이가 된 셈이니 말이 안 되지요. 조각의 크기(분모)는 더하는 것이 아니라 그대로 두는 것이에요.

4. 자주 하는 오해 바로잡기

· "분자는 분자끼리, 분모는 분모끼리 더한다" → 분모를 더하면 조각이 작아져 답이 실제의 절반이 돼요.

· "1 − 3/5는 분모가 달라서 못 뺀다" → 1을 5/5로 바꾸면 분모가 같은 뺄셈이에요.

5. 생활 속에서 · 이어지는 개념

  • 피자 8조각 중 내가 3조각, 동생이 2조각을 먹으면 3/8 + 2/8 = 5/8판, 남은 것은 1 − 5/8 = 3/8판이에요.
