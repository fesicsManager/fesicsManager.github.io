부등식 해 실험실 — 경계는 같아도 방향은 a의 부호가 정한다

ax + b > 0의 a, b를 바꾸며 −10부터 10까지 하나씩 대입해 만족하는 정수를 찾고 a의 부호와 해의 방향을 대조했습니다. 경계값 −b/a는 같지만 a > 0이면 x > 경계, a < 0이면 x < 경계였고, a = 0이면 b의 부호에 따라 모든 수 또는 해 없음이었습니다. 해의 방향 규칙을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: ax + b > 0 의 계수를 정하고, 어떤 x가 만족하는지 보자.

표 1. a의 부호와 해의 방향 (실험 예시)
부등식a의 부호경계 −b/a만족한 정수 (−10~10)해부호 그대로 풀면
2x − 6 > 0+34, 5, …, 10x > 3x > 3 (같음)
−2x + 6 > 0−3−10, …, 2x < 3x > 3 (틀림)
3x + 9 > 0+−3−2, …, 10x > −3—
0x + 5 > 00—모두모든 실수—
0x − 5 > 00—없음해 없음—

a로 나눌 때 a가 음수면 부등호가 뒤집혀 방향이 반대. 그래프로는 y = ax + b가 x축 위에 있는 구간 — a > 0이면 경계 오른쪽, a < 0이면 왼쪽. a가 음수면 양변에 −1을 곱해 a를 양수로 만든 뒤 푸는 방법도 있으며, 경계값만이 아니라 방향까지가 답입니다.

개념 정리

1. ax + b > 0의 경계는 x = −b/a로 같지만, 해의 방향은 a의 부호가 정해요

a > 0이면 x > −b/a, a < 0이면 x < −b/a예요. 경계값은 같은데 방향이 반대인 이유는 a로 나눌 때 a가 음수면 부등호가 뒤집히기 때문이에요. a = 0이면 b > 0일 때 모든 수가 해, 아니면 해가 없어요. −10~10을 하나씩 넣어 보면 규칙이 그대로 보여요.

왜 그럴까

  • 2x − 6 > 0 → x > 3. −2x + 6 > 0 → −2x > −6 → x < 3.
  • 그래프로: y = ax + b가 x축 위에 있는 구간. a > 0이면 경계 오른쪽, a < 0이면 왼쪽.
  • a가 음수면 양변에 −1을 곱해 a를 양수로 만든 뒤 푸는 방법도 있어요(이때 부등호 뒤집기).

2. 자주 하는 오해 바로잡기

· "경계값이 같으면 답도 같다" → 방향까지가 답이에요.

3. 생활 속에서 · 이어지는 개념

  • "예산 안에서 최대 몇 개?", "몇 km부터 택시가 더 싼가?" 같은 문제가 일차부등식이에요.
x = −10…10 대입해 만족하는 정수 찾기 → a 부호별 해의 방향 기록
📋 데이터 확인 탭의 결론

“실제로 수를 하나씩 넣어 보니, a가 양수면 해가 x > 경계, 음수면 x 였다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

−4x + 12 ≥ 0을 푸시오.

−4x ≥ −12 → x ≤ 3 (또는 4x − 12 ≤ 0 → x ≤ 3). x ≤ 3.

한 개 1 500원인 물건을 10 000원으로 최대 몇 개?

1500x ≤ 10000 → x ≤ 6.67 → 6개.
