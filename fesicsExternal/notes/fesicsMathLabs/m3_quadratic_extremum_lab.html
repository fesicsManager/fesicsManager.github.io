최댓값 실험실 — 최솟값은 c가 아니다

y = ax² + bx + c의 계수를 바꾸며 그래프에서 가장 낮은(높은) 점을 직접 찾아 x = −b/2a, 그 값과 c를 비교했습니다. 최댓값·최솟값이 나오는 x는 언제나 −b/2a였고 그 값은 c − b²/4a로 b = 0일 때만 c와 같았으며, a > 0이면 최솟값, a < 0이면 최댓값이었습니다. 이차함수의 최적값을 정리합니다.

표 1. 최적값의 위치와 값 (실험 예시)
식최댓값/최솟값그때의 x−b/2a같나?c최적값 = c?
x² − 4x + 1최솟값 −322예1아니오
x² − 4x + 7최솟값 322예7아니오
−2x² + 8x − 3최댓값 522예−3아니오
x² + 0x + 4최솟값 400예4예 (b = 0)

완전제곱으로 고치면 y = a(x + b/2a)² + (c − b²/4a)라 꼭짓점 x = −b/2a, 최적값 = c − b²/4a. c는 x = 0일 때의 값(y절편)일 뿐이며, 꼭짓점은 두 근의 정중앙(대칭축). a > 0 아래로 볼록 → 최솟값, a < 0 위로 볼록 → 최댓값.

개념 정리

1. 최댓값·최솟값은 x = −b/2a에서, 그 값은 c가 아니에요

y = ax² + bx + c의 꼭짓점 x좌표는 −b/2a이고 최솟값(a > 0) 또는 최댓값(a < 0)은 그 x를 대입한 값이에요. c는 x = 0일 때의 값, 즉 y절편일 뿐이고, b = 0일 때만 꼭짓점과 겹쳐요. 완전제곱으로 고치면 y = a(x + b/2a)² + (c − b²/4a)라 최적값 = c − b²/4a예요.

왜 그럴까

  • y = x² − 4x + 7: x = 2에서 최솟값 3 (c = 7이 아님).
  • a > 0 아래로 볼록 → 최솟값, a < 0 위로 볼록 → 최댓값.
  • 꼭짓점은 두 근의 정중앙(대칭축).

2. 자주 하는 오해 바로잡기

· "상수항 c가 최솟값" → 그래프가 x = 0에서 꼭짓점일 때만.

3. 생활 속에서 · 이어지는 개념

  • 던진 공의 최고 높이, 이익이 최대가 되는 가격, 울타리로 만드는 최대 넓이가 이차함수 최적화예요.
그래프에서 가장 낮은(높은) 점 탐색 → x = −b/2a, y와 c 비교

예제

y = −x² + 6x − 5의 최댓값은?

x = 3에서 −9 + 18 − 5 = 4.

둘레 20 m 울타리로 만드는 직사각형의 최대 넓이는?

S = x(10 − x) = −x² + 10x → x = 5에서 25 m²(정사각형).
