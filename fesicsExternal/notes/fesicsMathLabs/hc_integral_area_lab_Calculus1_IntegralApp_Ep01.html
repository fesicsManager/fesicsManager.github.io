정적분 실험실 — 정적분값은 부호 있는 넓이

f(x) = x² − 4의 적분 구간을 바꾸며 정적분값과 실제 넓이를 따로 구해 비교했습니다. 구간이 x축 아래(−2 < x < 2)를 포함하면 정적분값이 넓이보다 작거나 음수였고, x축 위에서만 적분할 때만 두 값이 같았습니다. 정적분과 넓이의 차이를 정리합니다.

실험 데이터 되짚기

실험 안내: 구간의 양 끝을 정해 보자. f(x) = x² − 4 는 x = ±2 에서 x축을 지난다.

∫ f dx는 x축 위를 양수, 아래를 음수로 셉니다. 넓이를 구하려면 x축과 만나는 점(±2)에서 구간을 나눠 각 조각의 절댓값을 더해야 하며, F(q) − F(p)는 언제나 정적분값이지 넓이가 아닙니다. 홀함수의 대칭 구간 정적분은 0이지만 넓이는 0이 아닙니다.

개념 정리

1. 정적분값은 '부호 있는 넓이'예요

∫ f(x)dx는 x축 위 부분을 양수, 아래 부분을 음수로 세요. 그래서 f(x) = x² − 4를 −2~2를 포함한 구간에서 적분하면 값이 실제 넓이보다 작거나 음수예요. 넓이를 구하려면 x축과 만나는 점(±2)에서 구간을 나눠 각 조각의 절댓값을 더해야 해요. F(q) − F(p)는 언제나 정적분값이지 넓이가 아니에요.

계산해 보기

  • ∫₋₂² (x² − 4)dx = [x³/3 − 4x] = −32/3 ≈ −10.67 (전부 x축 아래).
  • 구간 [0, 3]: ∫₀² = −16/3, ∫₂³ = 7/3 → 정적분 −3, 넓이 16/3 + 7/3 = 23/3.
  • 대칭 구간에서 홀함수의 정적분은 0이지만 넓이는 0이 아니에요.

움직여 보기

정적분값과 넓이가 달라지는 순간

정적분 F(q) − F(p) 넓이 x축 위(+) x축 아래(−)

y = x² − 4에서 x축 위 부분(파랑)은 +, 아래 부분(빨강)은 −로 더해져 정적분이 됩니다. 넓이는 x = ±2에서 나눠 각 조각의 절댓값을 더해요. [0, 3]이면 정적분 −3, 넓이 16/3 + 7/3 = 23/3 ≈ 7.67.

2. 자주 하는 오해 바로잡기

· "정적분 = 넓이" → 그래프가 x축 위에 있을 때만 같아요.

3. 생활 속에서 · 이어지는 개념

  • 속도가 음수(후진)인 구간을 포함하면 정적분은 변위, 절댓값 적분은 총 이동 거리예요.
정적분 = F(q) − F(p); 넓이 = Σ |각 구간 정적분| (x축 교점 ±2에서 분할)

예제

y = x² − 4와 x축, x = 0, x = 3으로 둘러싸인 넓이는?

∫₀² = −16/3, ∫₂³ = 7/3 → 넓이 16/3 + 7/3 = 23/3. 정적분 −3과 다름.

∫₋₁¹ x³ dx와 y = x³, x축, x = ±1 사이 넓이는?

정적분 0(홀함수). 넓이 = 2 × ∫₀¹ x³ = 1/2.
