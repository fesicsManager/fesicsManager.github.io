함수 판정 실험실 — 세로선 한 번, 가로선 한 번

다섯 가지 그래프에 세로선을 옮겨 가며 만나는 점의 최대 개수를 세어 함수인지 판정하고, 가로선으로 일대일인지 확인했습니다. 원과 옆으로 누운 포물선은 세로선과 두 점에서 만나 함수가 아니었고, y = x²은 함수이지만 가로선과 두 점에서 만나 일대일이 아니었습니다. 함수의 정의와 역함수 존재 조건을 정리합니다.

함수는 정의역의 각 x에 y가 하나씩 대응해야 하므로 세로선과 두 점에서 만나면 ‘정해진 값’이 없어 함수가 아닙니다. 함수 중 가로선과도 한 번만 만나면 일대일이고 그때만 역함수가 있습니다. 그릴 수 있다고 다 함수는 아닙니다(원은 관계).

개념 정리

1. 함수: 세로선 판정, 일대일: 가로선 판정

그래프가 함수이려면 어떤 세로선을 그어도 그래프와 많아야 한 점에서 만나야 해요(한 x에 y가 하나). 원이나 옆으로 누운 포물선은 세로선과 두 점에서 만나 함수가 아니에요. 함수 중에서도 어떤 가로선과도 한 번만 만나면 일대일 함수이고, 그때만 역함수가 있어요.

왜 그럴까

  • 함수의 정의: 정의역의 각 원소에 치역의 원소가 하나씩 대응. 두 개 대응하면 '정해진 값'이 없어요.
  • y = x²: 함수이지만 가로선 y = 4가 x = ±2에서 만나 일대일이 아님 → 역함수 없음(정의역을 x ≥ 0으로 제한하면 가능).
  • y = x³, y = 2x + 1: 일대일 → 역함수 있음.

2. 자주 하는 오해 바로잡기

· "그릴 수 있으면 함수" → 원은 관계이지 함수가 아니에요.

· "역함수는 항상 있다" → 일대일 대응일 때만.

3. 생활 속에서 · 이어지는 개념

  • 주민번호 → 사람(함수, 일대일), 사람 → 좋아하는 음식(여러 개면 함수 아님)처럼 대응 규칙을 따져요.
세로선 x = t를 옮기며 교점 수 세기(최대 2 이상이면 함수 아님); 가로선 y = t로 일대일 판정

예제

y = |x|는 함수인가? 일대일인가?

세로선 판정 통과 → 함수. 가로선 y = 3이 x = ±3에서 만남 → 일대일 아님, 역함수 없음.

y = x²의 역함수가 존재하도록 정의역을 제한하면?

x ≥ 0(또는 x ≤ 0)으로 제한 → 역함수 y = √x.
