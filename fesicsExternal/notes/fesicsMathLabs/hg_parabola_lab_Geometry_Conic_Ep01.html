포물선 실험실 — 초점까지 거리 = 준선까지 거리

포물선 y² = 4px의 p와 점의 y좌표를 바꾸며 초점 (p, 0)까지의 거리와 준선 x = −p까지의 거리를 재어 비교했습니다. 어느 점에서 재도 두 거리는 같았고, 거리 자체는 점마다 달랐지만 그 관계는 변하지 않았습니다. 포물선의 정의와 반사 성질을 정리합니다.

√((x − p)² + y²) = x + p를 제곱해 정리하면 y² = 4px. 점 (p, 2p)에서 초점까지 2p, 준선까지 p + p = 2p. 초점에서 나온 빛은 포물선에 반사되어 축과 평행하게 나가고, 이차함수 y = x²도 초점 (0, 1/4)·준선 y = −1/4인 같은 곡선입니다.

개념 정리

1. 포물선: 초점까지 거리 = 준선까지 거리

포물선은 한 점(초점)과 한 직선(준선)에서 같은 거리에 있는 점들의 자취예요. y² = 4px는 초점 (p, 0), 준선 x = −p에 대해 이 조건을 좌표로 옮겨 쓴 식이에요. 거리 자체는 점마다 달라도 두 거리의 관계(같음)는 변하지 않아요.

왜 그럴까

  • √((x − p)² + y²) = x + p를 제곱해 정리하면 y² = 4px.
  • 점 (p, 2p): 초점까지 2p, 준선까지 p + p = 2p ✓.
  • 초점에서 나온 빛이 포물선에 반사되면 축과 평행하게 나가요(반사 성질).

2. 자주 하는 오해 바로잡기

· "이차함수 y = x²과 포물선은 다른 것" → 같은 곡선이에요. y = x²은 초점 (0, 1/4), 준선 y = −1/4.

예제

y² = 8x의 초점과 준선은?

4p = 8 → p = 2 → 초점 (2, 0), 준선 x = −2.

초점 (0, 3), 준선 y = −3인 포물선의 방정식은?

x² = 4·3·y → x² = 12y.
