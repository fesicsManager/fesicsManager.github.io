정수 뺄셈 실험실 — 빼는 수의 부호를 바꿔 더한다

두 정수를 바꾸며 직접 뺀 값과 빼는 수의 부호를 바꿔 더한 값을 비교하고 순서를 바꾼 값도 확인했습니다. 뺄셈은 언제나 부호 바꿔 더하기와 같았고((−4) − (−7) = (−4) + 7 = 3), 순서를 바꾸면 부호가 반대인 값이 나왔습니다. 뺄셈 규칙과 순서의 중요성을 정리합니다.

a − b = a + (−b). 수직선에서 ‘왼쪽으로 7 가는 것을 되돌리기’는 ‘오른쪽으로 7 가기’와 같습니다. 음수를 빼면 커집니다. a − b와 b − a는 부호가 반대(합 0)이고, 뺄셈을 모두 덧셈으로 바꾸면 순서를 자유롭게 바꿔 계산할 수 있습니다.

개념 정리

1. 빼기는 '빼는 수의 부호를 바꿔 더하기'예요

a − b = a + (−b). (−4) − (−7) = (−4) + 7 = 3이에요. 수직선에서 '왼쪽으로 7 가는 것을 되돌리기'는 '오른쪽으로 7 가기'와 같기 때문이에요. 덧셈과 달리 뺄셈은 순서를 바꾸면 값이 달라져요(a − b ≠ b − a, 두 수가 같을 때만 우연히 같음).

왜 그럴까

  • 5 − 8 = 5 + (−8) = −3. 5 − (−2) = 5 + 2 = 7.
  • a − b와 b − a는 부호가 반대(합이 0).
  • 뺄셈을 모두 덧셈으로 바꾸면 순서를 자유롭게 바꿀 수 있어 계산이 편해요.

2. 자주 하는 오해 바로잡기

· "음수를 빼면 더 작아진다" → 음수를 빼는 것은 양수를 더하는 것이라 커져요.

3. 생활 속에서 · 이어지는 개념

  • 빚(−)을 없애 주는 것(빼기)은 돈이 늘어나는 것과 같아요.
직접 뺀 값과 부호 바꿔 더한 값 비교; 순서 바꾼 값과도 비교
📋 데이터 확인 탭의 결론

“뺄셈은 언제나 빼는 수의 부호를 바꿔 더하는 것과 같았다. (−4) − (−7)은 (−4) + 7이 되어 3이다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

(−2) − (+9)와 (−2) − (−9)는?

(−2) + (−9) = −11; (−2) + 9 = 7.

3 − 7 + 5 − 2를 덧셈으로 바꿔 계산하시오.

3 + (−7) + 5 + (−2) = (3 + 5) + (−9) = −1.
