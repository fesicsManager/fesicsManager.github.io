합성함수 실험실 — 넣는 순서를 바꾸면 결과가 달라진다

두 일차함수 f(x) = ax + b, g(x) = cx + d의 계수를 바꾸며 f∘g와 g∘f의 식과 값을 비교했습니다. x의 계수 ac는 항상 같았지만 상수항(ad + b와 bc + d)이 달라 대부분 f∘g ≠ g∘f였고, 같아지는 것은 ad + b = bc + d인 특별한 경우뿐이었습니다. 합성의 순서와 기호를 정리합니다.

실험 안내: 두 일차함수를 정하고, 넣는 순서를 바꿔 보자.

표 1. f∘g와 g∘f (실험 예시)
fgf∘g = f(g(x))g∘f = g(f(x))x 계수 같음같은가?
2x + 13x − 26x − 36x + 1예다름
2x + 0x + 32x + 62x + 3예다름
2x + 13x + 06x + 16x + 3예다름
2x + 13x + 26x + 56x + 5예같음 (ad + b = bc + d)

f∘g는 오른쪽 g를 먼저 적용한 뒤 f에 넣는 것입니다. ‘3 더하고 2배’(2x + 6)와 ‘2배 하고 3 더하기’(2x + 3)가 다른 것과 같으며, 합성은 곱 f(x)·g(x)와 전혀 다릅니다.

개념 정리

1. 합성함수는 순서에 따라 달라요: f∘g ≠ g∘f

(f∘g)(x) = f(g(x))는 g를 먼저 통과시킨 뒤 f에 넣는 것이고, (g∘f)(x)는 그 반대예요. f(x) = ax + b, g(x) = cx + d면 f∘g = acx + (ad + b), g∘f = acx + (bc + d)로 x의 계수는 같지만 상수항이 달라요. f∘g = g∘f가 되는 것은 ad + b = bc + d인 특별한 경우뿐이에요.

왜 그럴까

  • f: 2배, g: +3. f(g(x)) = 2(x + 3) = 2x + 6, g(f(x)) = 2x + 3. '3 더하고 2배'와 '2배 하고 3 더하기'는 달라요.
  • 합성 기호는 오른쪽 함수부터 적용해요(f∘g에서 g가 먼저).
  • 정의역·치역이 맞아야 합성이 가능해요: g의 치역이 f의 정의역 안에 있어야 해요.

2. 자주 하는 오해 바로잡기

· "f∘g는 f 먼저" → 안쪽(오른쪽)부터예요.

· "합성 = 곱셈" → f(x)·g(x)와는 전혀 달라요.

3. 생활 속에서 · 이어지는 개념

  • 할인 후 세금 vs 세금 후 할인, 환율 변환 뒤 수수료 계산 순서가 합성 순서예요.
f∘g = a(cx + d) + b, g∘f = c(ax + b) + d; 식과 특정 x에서의 값 비교

예제

f(x) = x², g(x) = x + 1일 때 (f∘g)(2)와 (g∘f)(2)는?

f(g(2)) = f(3) = 9, g(f(2)) = g(4) = 5.

f(x) = 2x + 1, (f∘g)(x) = 4x + 3일 때 g(x)는?

2g(x) + 1 = 4x + 3 → g(x) = 2x + 1.
