대응 관계 실험실 — 한 칸 차이만으로는 식이 안 된다

연필 값(× 100), 나이(− 3), 성냥개비(× 3 + 1) 세 관계의 표를 채우고 두 양의 차와 몫을 기록해 어떤 규칙이 항상 성립하는지 판정했습니다. 관계마다 차가 일정한 것, 몫이 일정한 것, 둘 다 아닌 것이 있었고, 성냥개비는 한 칸에 3씩 늘지만 식은 × 3 + 1이었습니다. 대응 관계를 식으로 세우는 법을 정리합니다.

표에서 한 칸 늘 때 얼마나 늘었는지만 보면 규칙을 잘못 잡습니다. 성냥개비는 ‘+3 규칙’이라고만 하면 사각형 10개일 때 30으로 틀리고, 시작값(+1)을 확인해야 합니다. 왼쪽 값으로 오른쪽 값을 바로 구하는 식을 세우고 첫 줄에 대입해 검산합니다.

개념 정리

1. 대응 관계는 '왼쪽에서 오른쪽을 바로 구하는 식'이에요

표에서 한 칸 늘 때 얼마나 늘었는지(차)만 보면 규칙을 잘못 잡을 수 있어요. 사각형 개수와 성냥개비 수는 1개씩 늘 때 3씩 늘지만, 성냥개비 = 사각형 × 3 + 1이에요. "+3 규칙"이라고만 하면 사각형 10개일 때 30이라고 틀리게 돼요. 관계마다 차가 일정한 것, 몫이 일정한 것, 둘 다 아닌 것이 있으니 왼쪽 값으로 오른쪽 값을 직접 구하는 식을 세워야 해요.

관계의 종류

  • 몫이 일정: 연필 수 × 100원 = 값(비례). 표에서 오른쪽 ÷ 왼쪽이 항상 같아요.
  • 차가 일정: 나이 관계(동생 = 형 − 3). 오른쪽 − 왼쪽이 항상 같아요.
  • 둘 다 아님: 성냥개비 3 × n + 1, 이 경우 "한 칸 차이 3"은 맞지만 n에서 바로 구하려면 +1이 필요해요.

2. 자주 하는 오해 바로잡기

· "한 칸에 3씩 늘면 식은 ×3" → 시작값(+1)을 확인해야 해요. 표의 첫 줄에 대입해 검산하세요.

3. 생활 속에서 · 이어지는 개념

  • 택시 요금(기본요금 + 거리 × 요금), 휴대폰 요금제가 '× 하고 +' 관계예요.
표의 각 줄에서 차 = 오른쪽 − 왼쪽, 몫 = 오른쪽 ÷ 왼쪽을 계산해 일정한지 판정
📋 데이터 확인 탭의 결론

“관계마다 규칙의 종류가 달랐다. 차가 일정한 것, 몫이 일정한 것, 그리고 차도 몫도 일정하지 않은 것까지 있었다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

택시 요금이 기본 4 800원에 1 km마다 1 000원씩 오른다. 거리 n km와 요금의 대응식은? 7 km면?

요금 = 1 000 × n + 4 800 (‘× 하고 +’ 관계). 7 km: 11 800원. ‘1 km에 1 000원’만 보고 7 000원이라 하면 틀립니다.

표에서 (1, 5), (2, 8), (3, 11)이 주어졌다. 식은?

한 칸 차 3 → 3n + □; n = 1일 때 5 → □ = 2 → 3n + 2. 검산 n = 3: 11 ✓.
