등비급수 실험실 — |r| < 1일 때만 합이 멈춘다

첫째항 a, 공비 r(−1.5~1.5), 항의 개수 n(1~40)을 바꾸며 부분합이 a/(1 − r)에 다가가는지 기록했습니다. |r| < 1일 때만 부분합이 한 값에 다가갔고, r = −0.5는 위아래로 진동하며 수렴했으며 r = 1.2는 발산, r = −1은 진동 발산했습니다. 등비급수의 수렴 조건을 정리합니다.

Sₙ = a(1 − rⁿ)/(1 − r)에서 |r| < 1이면 rⁿ → 0이 되어 S = a/(1 − r). |r| ≥ 1이면 항이 줄지 않아 계속 커지거나 튑니다. r이 음수여도 판단 기준은 절댓값. ‘항이 줄면 수렴’은 등비수열에는 맞지만 1/n 같은 일반 급수에는 아닙니다.

개념 정리

1. 등비급수는 |r| < 1일 때만 수렴, 합은 a/(1 − r)

항이 계속 줄어들어야(|r| < 1) 무한히 더해도 합이 한 값에 멈춰요. 부분합 Sₙ = a(1 − rⁿ)/(1 − r)에서 rⁿ → 0이 되어 S = a/(1 − r). |r| ≥ 1이면 항이 줄지 않아 합이 계속 커지거나(r ≥ 1) 튀어요(r ≤ −1). r이 음수여도 판단 기준은 절댓값이에요.

왜 그럴까

  • a = 1, r = 0.5: 1 + 0.5 + 0.25 + … → 2. n = 10에서 1.998.
  • r = −0.5: 1 − 0.5 + 0.25 − … → 2/3, 부분합이 위아래로 진동하며 수렴.
  • r = 1.2: 항이 커져 발산. r = −1: 1, 0, 1, 0… 진동 발산.

움직여 보기

부분합 막대 — 한 값에 멈출까, 끝없이 갈까

S₁₀ 마지막 막대 판정

막대 하나가 부분합 Sₙ = a(1 − rⁿ)/(1 − r)입니다. |r| < 1이면 막대 끝이 보라 점선 a/(1 − r)에 붙어 멈추고(r이 음수면 위아래로 번갈아 다가감), |r| ≥ 1이면 커지거나 튀어서 한 값에 멈추지 않아요. 세로 눈금은 값에 맞춰 바뀝니다.

2. 자주 하는 오해 바로잡기

· "항이 줄면 무조건 수렴" → 등비수열은 맞지만 일반 급수(1/n)는 아니에요.

· "r = 1도 공식 사용" → 분모 0.

3. 생활 속에서 · 이어지는 개념

  • 0.999… = 1(0.9 + 0.09 + …), 공이 튀는 총 거리, 경제의 승수 효과가 등비급수예요.

“등비급수는 |r| 부분합이 한 값 a/(1−r) 에 다가갔다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

0.999… = 1을 등비급수로 보이시오.

0.9 + 0.09 + … = 0.9/(1 − 0.1) = 1.

높이 10 m에서 떨어뜨린 공이 매번 60 % 높이로 튈 때 총 이동 거리는?

10 + 2 × (6 + 3.6 + …) = 10 + 2 × 6/(1 − 0.6) = 10 + 30 = 40 m.
