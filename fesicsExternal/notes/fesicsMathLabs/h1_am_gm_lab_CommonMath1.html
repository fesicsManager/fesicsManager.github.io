평균 부등식 실험실 — 산술평균은 기하평균보다 작지 않다

두 양수 a, b(1~20)를 정해 지름 a + b인 반원에서 반지름(산술평균)과 수선(기하평균)의 길이를 비교했습니다. 산술평균이 기하평균보다 작았던 적은 한 번도 없었고, 두 값이 같아진 것은 a = b일 때뿐이었습니다. 부등식의 기하적·대수적 까닭과 최대·최소 문제 활용을 정리합니다.

개념 정리

1. 산술평균 ≥ 기하평균 (등호는 a = b일 때)

두 양수 a, b의 산술평균 (a + b)/2와 기하평균 √(ab)는 (a + b)/2 ≥ √(ab)이고, 같아지는 것은 a = b일 때뿐이에요. 지름이 a + b인 반원에서 반지름이 산술평균, 지름을 a : b로 나눈 점에서 세운 수선의 길이가 기하평균이에요(직각삼각형 닮음 h² = ab). 수선은 반지름을 넘을 수 없고 정중앙에서만 반지름과 같아져요.

대수적 증명

  • (a + b)/2 − √(ab) = (√a − √b)²/2 ≥ 0. 제곱이 0이 되는 것은 √a = √b, 즉 a = b.
  • a = 1, b = 9: 산술평균 5, 기하평균 3. a = b = 4: 둘 다 4.
  • 합이 일정하면 곱은 a = b에서 최대, 곱이 일정하면 합은 a = b에서 최소 — 최대·최소 문제의 도구.

2. 자주 하는 오해 바로잡기

· "등호가 성립하는 조건을 빠뜨림" → 최솟값 문제에서 등호 조건(a = b)이 실제로 가능한지 반드시 확인해야 해요. 또 a, b가 양수일 때만 성립해요.

3. 생활 속에서 · 이어지는 개념

“산술평균이 기하평균보다 작았던 적은 한 번도 없었고, 두 값이 같아진 것은 a = b일 때뿐이었다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

x > 0일 때 x + 4/x의 최솟값은?

x + 4/x ≥ 2√(x · 4/x) = 2 · 2 = 4. 등호는 x = 4/x, 즉 x = 2에서 성립(양수이므로 가능).

둘레가 40인 직사각형의 넓이 최댓값은?

가로 + 세로 = 20 → 넓이 = ab ≤ ((a + b)/2)² = 100. 100(a = b = 10, 정사각형).
