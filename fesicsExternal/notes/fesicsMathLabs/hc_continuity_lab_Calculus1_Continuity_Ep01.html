연속 실험실 — 세 가지가 모두 맞아야 이어진다

x < 1에서 x + k, x > 1에서 2x인 조각함수의 k와 f(1) 값을 바꾸며 좌극한·우극한·함숫값을 비교했습니다. k = 1이어야 극한이 존재했고, 거기에 f(1) = 2까지 맞아야 연속이었으며, 극한이 있어도 함숫값이 다르면 점 하나가 떠 있는 불연속이었습니다. 연속의 세 조건을 정리합니다.

연속의 세 조건: ① f(a) 정의 ② 좌극한 = 우극한 ③ 극한값 = f(a). 하나만 어긋나도 끊깁니다. 극한은 있는데 함숫값이 다르면 제거 가능 불연속(점 하나 재정의로 고침), 좌우 극한이 다르면 계단 불연속입니다.

개념 정리

1. 연속의 세 조건

함수가 x = a에서 연속이려면 ① f(a)가 정의되고 ② 좌극한 = 우극한(극한 존재) ③ 그 극한값 = f(a)여야 해요. 셋 중 하나만 어긋나도 그래프가 끊겨요. 극한이 있어도 함숫값이 따로 놀면 점 하나가 떨어져 나가고(제거 가능 불연속), 좌우 극한이 다르면 계단처럼 뛰어요.

조각함수로 확인

  • x < 1에서 x + k, x > 1에서 2x: 좌극한 1 + k, 우극한 2 → k = 1이어야 극한 존재. 여기에 f(1) = 2여야 연속.
  • k = 1, f(1) = 5: 극한 2는 있지만 f(1) ≠ 2 → 불연속(점이 떠 있음).
  • k = 0: 좌극한 1 ≠ 우극한 2 → 극한 없음.

x < 1에서 x + k, x > 1에서 2x인 함수예요. 주황·초록 점이 x = 1로 다가가는 값(극한)과 보라 점 f(1)을 비교하세요. k = 1, f(1) = 2일 때만 세 조건이 모두 맞아 끊김 없이 이어집니다.

2. 자주 하는 오해 바로잡기

· "극한이 있으면 연속" → 함숫값까지 같아야 해요.

· "f(a)가 있으면 연속" → 좌우 극한이 달라도 f(a)는 있을 수 있어요.

3. 생활 속에서 · 이어지는 개념

  • 택시 요금(거리에 따라 계단식)은 불연속, 온도 변화는 연속 — 연속이어야 중간값 정리·미분을 쓸 수 있어요.

예제

f(x) = (x² − 4)/(x − 2) (x ≠ 2), f(2) = k가 x = 2에서 연속이 되는 k는?

극한 = lim (x + 2) = 4 → k = 4. k ≠ 4면 극한은 있으나 불연속.

f(x) = ax + 1 (x < 2), x² (x ≥ 2)가 모든 실수에서 연속일 a는?

좌극한 2a + 1 = 우극한 = f(2) = 4 → a = 3/2.
