평행선 실험실 — AD : AB = DE : BC, AD : DB ≠ DE : BC

삼각형 ABC의 꼭짓점 A와 밑변 BC에 평행한 선 DE의 위치를 바꾸며 AD : AB, AE : AC, DE : BC, AD : DB, AE : EC를 재어 서로 같은 비와 다른 비를 구별했습니다. DE ∥ BC일 때 AD : AB = AE : AC = DE : BC와 AD : DB = AE : EC는 항상 성립했지만 AD : DB = DE : BC는 성립하지 않았습니다. 평행선과 선분의 비를 정리합니다.

△ADE ∽ △ABC라 전체 변에 대한 비가 같고(AD : AB = DE : BC), 조각끼리의 비 AD : DB = AE : EC도 성립. 하지만 DE가 정확히 중간이면 AD : DB = 1 : 1인데 DE : BC = 1 : 2. DE를 구할 때는 잘린 조각의 비가 아니라 AB 전체에 대한 비를 씁니다. 역도 성립: AD : AB = AE : AC이면 DE ∥ BC.

개념 정리

1. DE ∥ BC이면 AD : AB = AE : AC = DE : BC, AD : DB = AE : EC

삼각형 밑변 BC에 평행한 선 DE를 그으면 △ADE ∽ △ABC라 전체 변에 대한 비가 같아요(AD : AB = DE : BC). 조각끼리의 비 AD : DB = AE : EC도 성립해요. 하지만 AD : DB와 DE : BC는 다른 비예요. DE가 정확히 중간이면 AD : DB = 1 : 1인데 DE : BC = 1 : 2예요. DE를 구할 때는 잘린 조각의 비가 아니라 AB 전체에 대한 비를 써야 해요.

왜 그럴까

  • AD = 2, DB = 3(AB = 5), BC = 10: DE = 10 × 2/5 = 4. AD : DB = 2 : 3으로 계산하면 6.7(틀림).
  • 닮음비는 대응하는 '변 전체'의 비예요.
  • 역도 성립: AD : AB = AE : AC이면 DE ∥ BC.

2. 자주 하는 오해 바로잡기

· "AD : DB = DE : BC" → 잘린 조각 비를 그대로 쓰면 틀려요.

3. 생활 속에서 · 이어지는 개념

  • 그림자로 나무 높이 재기, 지도 축척, 사진 확대·축소가 닮음비 계산이에요.

“DE ∥ BC일 때 AD:AB = AE:AC = DE:BC가 언제나 성립했고, AD:DB = AE:EC도 항상 성립했다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

AD = 2, DB = 3, BC = 10일 때 DE는? (DE ∥ BC)

AB = 5 → DE = 10 × 2/5 = 4. 2 : 3으로 하면 6.7(틀림).

AD = 4, DB = 6, AE = 6일 때 EC는?

4 : 6 = 6 : EC → EC = 9.
