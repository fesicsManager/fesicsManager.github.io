원의 방정식 실험실 — 항상 원이 되는 것은 아니다

x² + y² + Ax + By + C = 0의 계수를 바꿔 완전제곱으로 정리하고 반지름²의 부호로 원·점·그래프 없음을 판정했습니다. 중심 (−A/2, −B/2)는 언제나 계산되었지만 우변이 양수일 때만 원이었고, 0이면 한 점, 음수면 그래프가 없었습니다. 원이 되는 조건을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: x² + y² + Ax + By + C = 0 의 계수를 정해 보자.

표 1. 계수와 판정 (실험 예시)
방정식중심반지름² = (A² + B²)/4 − C반지름나타내는 것
x² + y² − 4x + 2y − 4 = 0(2, −1)4 + 1 + 4 = 93원
x² + y² − 4x + 0y + 8 = 0(2, 0)4 − 8 = −4—그래프 없음
x² + y² − 4x + 0y + 4 = 0(2, 0)4 − 4 = 00점 (2, 0)
x² + y² + 6x − 8y + 0 = 0(−3, 4)9 + 16 = 255원 (원점 지남)

(x + A/2)² + (y + B/2)² = A²/4 + B²/4 − C에서 좌변은 두 제곱의 합이라 0 이상이므로 우변이 음수면 만족하는 점이 없습니다. 중심을 구했다고 원이라 단정하면 안 되며, 원의 조건은 A² + B² − 4C > 0입니다.

개념 정리

1. x² + y² + Ax + By + C = 0이 항상 원은 아니에요

완전제곱으로 정리하면 (x + A/2)² + (y + B/2)² = A²/4 + B²/4 − C예요. 우변이 양수면 원(반지름 = √우변), 0이면 점 하나, 음수면 그래프 없음이에요. 중심 (−A/2, −B/2)는 어느 경우에나 계산되어 나오므로, 중심을 구했다고 원이라고 단정하면 안 돼요.

왜 그럴까

  • (x − a)² + (y − b)²은 두 제곱의 합이라 0 이상. 우변이 음수면 만족하는 점이 없어요.
  • x² + y² − 4x + 8 = 0: (x − 2)² + y² = −4 → 그래프 없음. C = 4면 점 (2, 0), C = 0이면 반지름 2인 원.
  • 원이 되는 조건: A² + B² − 4C > 0.

2. 자주 하는 오해 바로잡기

· "x², y² 계수가 같고 xy항이 없으면 원" → 필요조건일 뿐, 우변 부호까지 봐야 해요.

3. 생활 속에서 · 이어지는 개념

  • GPS 위치 결정(원의 교점), 레이더 탐지 범위 계산이 원의 방정식이에요.
r² = (A² + B²)/4 − C → r² > 0 원, = 0 점, < 0 없음

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

x² + y² − 2x + 4y + k = 0이 원이 되는 k의 범위는?

(x − 1)² + (y + 2)² = 5 − k > 0 → k < 5. k = 5면 점 (1, −2).

x² + y² + 6x − 8y = 0의 중심과 반지름은?

(x + 3)² + (y − 4)² = 25 → 중심 (−3, 4), 반지름 5.
