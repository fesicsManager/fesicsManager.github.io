집합 실험실 — 여집합을 씌우면 ∪와 ∩이 바뀐다

전체집합 {1, …, 12}에서 A = p의 배수, B = q의 배수를 만들어 (A ∪ B)ᶜ, Aᶜ ∩ Bᶜ, (A ∩ B)ᶜ, Aᶜ ∪ Bᶜ를 원소 단위로 대조했습니다. (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ, (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ는 모든 조합에서 성립했고, 기호를 그대로 둔 (A ∪ B)ᶜ = Aᶜ ∪ Bᶜ는 성립하지 않았습니다. 드모르간 법칙을 정리합니다.

‘A 또는 B에 속하지 않는다’는 ‘A에 속하지 않고 그리고 B에도 속하지 않는다’와 같은 말입니다. 벤 다이어그램에서 (A ∪ B)ᶜ는 두 원 바깥 = 두 여집합의 겹치는 부분. 부정은 ∪↔∩, ‘모든’↔‘어떤’을 바꿉니다.

개념 정리

1. 드모르간 법칙: 여집합을 취하면 ∪와 ∩이 바뀌어요

(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ, (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ. "A 또는 B에 속하지 않는다"는 "A에 속하지 않고 그리고 B에도 속하지 않는다"와 같은 말이기 때문이에요. 기호만 그대로 두고 여집합을 씌우면((A ∪ B)ᶜ = Aᶜ ∪ Bᶜ) 틀려요.

원소로 확인

  • U = {1…12}, A = 2의 배수, B = 3의 배수. A ∪ B = {2,3,4,6,8,9,10,12}, 여집합 {1,5,7,11}. Aᶜ ∩ Bᶜ = 홀수 ∩ 3의 배수 아님 = {1,5,7,11} ✓.
  • Aᶜ ∪ Bᶜ = {1,3,5,7,9,11} ∪ {1,2,4,5,7,8,10,11}은 훨씬 커서 다름.
  • 벤 다이어그램에서 (A ∪ B)ᶜ는 두 원 바깥 = 두 여집합의 겹치는 부분.

2. 자주 하는 오해 바로잡기

· "부정은 기호 그대로 분배" → 부정은 ∪↔∩, '모든'↔'어떤'을 바꿔요.

3. 생활 속에서 · 이어지는 개념

  • 검색 조건 "NOT (A OR B)" = "NOT A AND NOT B", 프로그래밍 조건문·회로 설계(NAND/NOR)에 드모르간 법칙을 써요.
각 원소가 A, B에 속하는지 판정 → 양변 집합을 원소 단위로 비교
📋 데이터 확인 탭의 결론

“여집합을 취하면 ∪와 ∩이 서로 바뀌었다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

U = {1…10}, A = {1, 2, 3}, B = {3, 4}일 때 (A ∩ B)ᶜ는?

A ∩ B = {3} → 여집합 {1, 2, 4, 5, 6, 7, 8, 9, 10}. Aᶜ ∪ Bᶜ = {4…10} ∪ {1, 2, 5…10}로 같음 ✓.

‘수학과 영어를 모두 좋아하는 것은 아니다’를 바꿔 말하면?

‘수학을 안 좋아하거나 또는 영어를 안 좋아한다’ — (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ.
