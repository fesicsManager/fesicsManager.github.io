변곡점 실험실 — f″ = 0은 후보일 뿐, 볼록성이 바뀌어야 한다

x³, x⁴, sin x, x³ − 3x에서 f″를 재고 f″ = 0인 점의 좌우에서 볼록함이 실제로 바뀌는지 확인했습니다. x³의 x = 0은 f″ 부호가 − → +로 바뀌어 변곡점이었지만 x⁴의 x = 0은 f″ = 0인데도 좌우 모두 아래로 볼록이라 변곡점이 아니었습니다. 변곡점의 판정 기준을 정리합니다.

변곡점은 휘는 방향이 바뀌는 점. f″가 존재하고 연속이면 변곡점에서 f″ = 0이지만, f″ = 0이라고 항상 변곡점은 아니며(x⁴), x^(1/3)의 x = 0처럼 f″가 없어도 변곡점일 수 있습니다. 극값에서 f′ = 0이 충분조건이 아닌 것과 같은 구조이고, 변곡점에서 f′은 0이 아닐 수 있습니다.

개념 정리

1. 변곡점의 판정 기준은 좌우의 볼록성 변화, f″(a) = 0은 후보를 찾는 단서예요

변곡점은 그래프가 휘는 방향(볼록성)이 바뀌는 점이에요. f″가 a 근방에서 존재하고 a에서 연속인 전형적인 예에서는 변곡점에서 f″ = 0이 되지만, f″ = 0이라고 항상 변곡점은 아니에요. 반대로 f(x) = x^(1/3)처럼 x = 0에서 f″가 존재하지 않아도 볼록성이 바뀌어 변곡점이 되는 경우도 있어서, f″ = 0을 일반적인 필요조건이라고 할 수는 없어요. x⁴은 x = 0에서 f″ = 0인데 좌우 모두 아래로 볼록이라 방향이 안 바뀌어요. 극값에서 f′ = 0이 충분조건이 아니었던 것과 같은 구조로, 앞뒤에서 f″의 부호가 실제로 바뀌어야 변곡점이에요.

확인해 보기

  • x³: f″ = 6x, x = 0에서 − → + 부호 바뀜 → 변곡점.
  • x⁴: f″ = 12x² ≥ 0, x = 0에서 0이지만 부호 그대로 → 변곡점 아님.
  • sin x: f″ = −sin x, x = 0, π에서 부호 바뀜 → 변곡점.

2. 자주 하는 오해 바로잡기

· "f″ = 0 풀면 변곡점" → 부호 변화 확인 필수.

· "변곡점이면 반드시 f″ = 0" → f″가 존재하고 연속인 경우에만. x^(1/3)의 x = 0처럼 f″가 없어도 변곡점일 수 있어요.

· 변곡점에서 f′은 0이 아닐 수 있어요(x³ − 3x의 x = 0에서 f′ = −3).

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = x³ − 6x² + 9x의 변곡점은?

f″ = 6x − 12 = 0 → x = 2, 부호 − → + 바뀜 → 변곡점 (2, 2).

f(x) = x⁴ − 4x³의 변곡점은?

f″ = 12x² − 24x = 12x(x − 2) → x = 0, 2에서 부호 바뀜 → (0, 0), (2, −16).
