근호 실험실 — √(a²) = |a|

수 a(−10~10)를 제곱했다가 다시 근호를 씌우며 수직선에서 위치가 어떻게 되는지 기록했습니다. √(a²)은 a가 0 이상일 때만 a와 같았고 음수일 때는 −a가 되어 항상 |a|였으며, 근호는 언제나 0 이상을 내놓았습니다. 근호의 정의와 절댓값의 관계를 정리합니다.

근호 √는 ‘제곱해서 그 수가 되는 음이 아닌 수’로 정의되어 √((−3)²) = √9 = 3 = −(−3). 문자를 다룰 때 부호를 모르면 함부로 벗길 수 없고 √(a²) = |a|로 써야 언제나 맞습니다(√(x² − 2x + 1) = |x − 1|). 제곱근이 두 개(±)라는 것과 근호 기호(양의 제곱근만)는 다른 이야기.

개념 정리

1. √(a²) = |a|: 근호는 항상 0 이상을 내놓아요

√(a²)은 a ≥ 0이면 a, a < 0이면 −a예요. √((−3)²) = √9 = 3 = −(−3). 근호 √는 '제곱해서 그 수가 되는 음이 아닌 수'로 정의되어 있기 때문이에요. 그래서 문자를 다룰 때는 부호를 모르면 근호를 함부로 벗길 수 없고, √(a²) = |a|로 써야 언제나 맞아요.

왜 그럴까

  • a = 5: √25 = 5 = a. a = −5: √25 = 5 = −a. a = 0: 0.
  • √(x² − 2x + 1) = √((x − 1)²) = |x − 1|: x < 1이면 1 − x.
  • 제곱근이 두 개(±)라는 것과 근호 기호(√, 양의 제곱근만)는 다른 이야기예요.

2. 자주 하는 오해 바로잡기

· "제곱했다 근호 씌우면 원래 수" → 음수는 부호가 사라져 돌아오지 않아요.

3. 생활 속에서 · 이어지는 개념

  • 거리·크기 계산(√(Δx²) = |Δx|), 표준편차가 항상 0 이상인 이유가 이 정의예요.

예제

a < 0일 때 √(a²) + √((−a)²)을 간단히 하시오.

|a| + |−a| = (−a) + (−a) = −2a.

x < 1일 때 √(x² − 2x + 1)은?

|x − 1| = 1 − x.
