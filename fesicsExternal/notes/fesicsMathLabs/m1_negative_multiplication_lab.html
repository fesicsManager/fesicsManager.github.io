음수 곱셈 실험실 — 음수 × 음수 = 양수

두 정수(−5~5)를 바꾸며 곱셈표를 채우고 결과의 부호와 절댓값을 나누어 기록했습니다. 절댓값은 언제나 그냥 곱한 값이었고 부호만 규칙(같으면 +, 다르면 −)을 따랐으며, 곱셈표의 흐름을 음수 줄로 이으면 (−3) × (−4) = +12가 자연스럽게 나왔습니다. 부호 규칙의 근거를 정리합니다.

3 × 1 = 3, 3 × 0 = 0, 3 × (−1) = −3, 3 × (−2) = −6처럼 3씩 줄어드는 흐름을 음수 줄로 이으면 (−3) × 1 = −3, (−3) × 0 = 0, (−3) × (−1) = +3으로 3씩 늘어납니다. 분배법칙으로도 (−3) × [(−4) + 4] = 0 → (−3)(−4) = 12. 음수를 짝수 개 곱하면 +, 홀수 개면 −.

개념 정리

1. 음수 × 음수 = 양수: 곱셈표의 규칙을 이어 가면 나와요

곱셈에서 절댓값은 그냥 곱하고 부호만 규칙을 따라요: 같으면 +, 다르면 −. 3 × 1 = 3, 3 × 0 = 0, 3 × (−1) = −3, 3 × (−2) = −6처럼 한 줄에서 3씩 줄어드는 흐름을 음수 줄로 이으면 (−3) × 1 = −3, (−3) × 0 = 0, (−3) × (−1) = +3으로 3씩 늘어나 (−3) × (−4) = +12가 자연스럽게 나와요.

왜 그럴까

  • 분배법칙으로도: (−3) × [(−4) + 4] = 0 → (−3)(−4) + (−12) = 0 → (−3)(−4) = 12.
  • '반대의 반대는 원래 방향' — 뒤로 걷는 영상을 거꾸로 재생하면 앞으로 가요.
  • 음수를 짝수 개 곱하면 +, 홀수 개면 −.

움직여 보기

곱셈표 한 줄을 음수 쪽으로 이어 가면

a × b 절댓값의 곱 부호 n이 1 줄 때마다

막대 하나가 a × n의 값이에요(위는 양수, 아래는 음수). a = −3이면 n이 1씩 줄 때마다 곱이 3씩 늘어나요. 이 흐름을 0을 지나 이어 가면 (−3) × (−1) = +3, (−3) × (−4) = +12가 저절로 나와요. 보라 테두리가 b에 해당하는 칸이에요.

2. 자주 하는 오해 바로잡기

· "음수 × 음수는 더 큰 음수" → 부호가 같으면 양수예요.

3. 생활 속에서 · 이어지는 개념
