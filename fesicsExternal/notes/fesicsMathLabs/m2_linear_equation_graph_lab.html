일차방정식 그래프 실험실 — 직선이지만 함수가 아닐 수 있다

ax + by + c = 0의 계수를 바꿔 그래프를 그리고 y = 꼴로 고쳐 쓸 수 있는지 확인했습니다. 그래프는 언제나 직선이었지만 b = 0이면 x = −c/a라는 세로선이 되어 한 x에 y가 무수히 대응해 함수가 아니었고, a = 0이면 가로선으로 함수이지만 일차함수는 아니었습니다. 직선의 방정식과 일차함수의 관계를 정리합니다.

b ≠ 0이면 y = (−a/b)x + (−c/b)로 일차함수. b = 0이면 세로선이라 ‘하나의 x에 하나의 y’라는 함수 조건을 어깁니다. 그래서 직선의 방정식 ⊋ 일차함수이며, 예산 제약 2x + 3y = 60 같은 조건이 직선의 방정식입니다.

개념 정리

1. ax + by + c = 0은 언제나 직선이지만, b = 0이면 함수가 아니에요

b ≠ 0이면 y = (−a/b)x + (−c/b)로 고쳐 쓸 수 있어 일차함수예요. 하지만 b = 0이면 x = −c/a라는 세로선이 되어 한 x에 y가 무수히 대응해요 — '하나의 x에 하나의 y'라는 함수 조건을 어겨요. 그래서 직선의 방정식 ⊋ 일차함수예요. a = 0이면 가로선 y = −c/b로 함수이긴 하지만 일차함수는 아니에요(상수함수).

왜 그럴까

  • 2x + 3y − 6 = 0 → y = −(2/3)x + 2: 일차함수.
  • 2x − 6 = 0 → x = 3: 세로선, 함수 아님.
  • 3y − 6 = 0 → y = 2: 가로선, 함수(기울기 0).

움직여 보기

세로선 검사 — 한 x에 점이 몇 개 만날까?

그래프 y = 꼴 판정

주황 세로선이 지나갈 때 그래프와 만나는 점이 언제나 1개면 함수입니다. b를 0으로 바꿔 2x − 6 = 0(세로선 x = 3)을 만들면, 세로선이 x = 3에 닿는 순간 무수히 많은 점과 겹쳐 함수가 아니에요. a = 0이면 가로선(기울기 0)으로 함수이지만 일차함수는 아니에요.

2. 자주 하는 오해 바로잡기

· "직선이면 다 일차함수" → 세로선은 함수가 아니에요.

3. 생활 속에서 · 이어지는 개념

  • 지도의 경계선, 예산 제약(2x + 3y = 60 같은 조건)이 직선의 방정식이에요.

예제

4x − 2y + 6 = 0을 일차함수 꼴로 고치시오.

2y = 4x + 6 → y = 2x + 3.

점 (3, −1)을 지나고 y축에 평행한 직선의 방정식은? 함수인가?

x = 3; 세로선이라 함수 아님.
