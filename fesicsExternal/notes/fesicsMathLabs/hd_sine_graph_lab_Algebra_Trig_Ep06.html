삼각함수 실험실 — b가 크면 주기는 짧아진다

y = a sin(bx)의 a(−4~4), b(1~4)를 바꾸며 그래프에서 최댓값·최솟값과 되풀이되는 길이를 직접 재어 |a|, 2π/b와 대조했습니다. (최대 − 최소)/2는 언제나 |a|였고 주기는 2π/b로 b가 클수록 짧아졌으며, a가 음수면 위아래가 뒤집혔지만 진폭은 |a|였습니다. 진폭과 주기를 정리합니다.

sin의 한 주기는 안의 값이 0에서 2π까지 갈 때이므로 bx = 2π → x = 2π/b. sin(2x)는 x가 π만 가도 한 바퀴라 주기 π, sin(x/2)는 4π. b는 단위 길이에 몇 번 진동하는가에 비례하며 주기가 아닙니다. cos도 같고 tan은 기본 주기 π라 π/b.

개념 정리

1. y = a sin(bx): a는 진폭, 주기는 2π/b

a는 그래프의 세로 크기(진폭 |a|)를 정하고, b는 가로로 얼마나 촘촘한지를 정해요. sin의 한 주기는 안의 값이 0에서 2π까지 갈 때이므로 bx = 2π → x = 2π/b가 주기예요. b가 클수록 주기는 짧아져요. b를 주기로 착각하기 쉽지만 반대예요. a가 음수면 위아래가 뒤집히지만 최댓값·최솟값의 크기는 |a|예요.

왜 그럴까

  • sin(2x)는 x가 π만 가도 안이 2π가 되어 한 바퀴 → 주기 π. sin(x/2)는 주기 4π.
  • y = 3 sin(2x): 최대 3, 최소 −3, 주기 π.
  • cos, tan도 같은 규칙(tan은 기본 주기 π라 π/b).

움직여 보기

y = a sin(bx) — a는 세로 크기, b는 촘촘함

진폭 |a| 최대 / 최소 주기 2π/b 점의 안쪽 값 bx

b를 2로 하면 주황 막대(한 주기)가 π로 짧아져요 — b가 커질수록 주기는 짧아집니다. 점을 따라가 보면 안쪽 값 bx가 2π가 되는 순간 그래프가 한 번 되풀이돼요. a를 음수로 하면 위아래가 뒤집히지만 진폭은 |a|입니다.

2. 자주 하는 오해 바로잡기

· "b = 2면 주기가 2배" → 절반이에요. b는 '1단위 길이에 몇 번 진동'에 비례해요.

3. 생활 속에서 · 이어지는 개념

  • 소리의 진동수(b)와 크기(a), 교류 전압 220 sin(120πt)의 주기 1/60초가 이 식이에요.

예제

y = −4 sin(3x)의 진폭·최댓값·주기는?

진폭 4, 최댓값 4(뒤집혀도 크기 같음), 주기 2π/3.

교류 전압 v = 220 sin(120πt)의 주기와 진동수는?

주기 2π/120π = 1/60 s, 진동수 60 Hz.
