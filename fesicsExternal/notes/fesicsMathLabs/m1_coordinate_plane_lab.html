좌표평면 실험실 — (a, b)와 (b, a)는 다른 점

두 수 a, b(−6~6)를 바꾸며 (a, b)와 (b, a)를 함께 찍고 위치와 사분면을 비교했습니다. a ≠ b이면 두 점은 언제나 달랐고 부호가 다르면 사분면까지 달라졌으며, a = b일 때만 같은 자리(직선 y = x 위)였습니다. 순서쌍과 사분면을 정리합니다.

첫 수가 x(가로), 둘째 수가 y(세로)로 역할이 정해진 순서쌍. (a, b)와 (b, a)는 y = x에 대칭. 사분면: (+, +) 1, (−, +) 2, (−, −) 3, (+, −) 4이며 축 위의 점은 어느 사분면에도 속하지 않습니다. (2, 5)의 x축 대칭 (2, −5), y축 대칭 (−2, 5), 원점 대칭 (−2, −5).

개념 정리

1. 좌표는 순서가 있는 짝이에요

(a, b)와 (b, a)는 a ≠ b이면 다른 점이에요. 첫 수가 x(가로), 둘째 수가 y(세로)로 역할이 정해져 있기 때문이에요. 같은 자리에 오는 것은 a = b일 때뿐이고, 그때 점은 직선 y = x 위에 있어요. 부호가 다르면 사분면까지 달라져요: (3, −2)는 제4사분면, (−2, 3)은 제2사분면.

왜 그럴까

  • (a, b)와 (b, a)는 직선 y = x에 대해 서로 대칭이에요.
  • 사분면: (+, +) 1, (−, +) 2, (−, −) 3, (+, −) 4. 축 위의 점은 어느 사분면에도 속하지 않아요.
  • (2, 5)에서 x축 대칭은 (2, −5), y축 대칭은 (−2, 5), 원점 대칭은 (−2, −5).

2. 자주 하는 오해 바로잡기

· "좌표는 두 수의 모음" → 순서쌍이에요. 지도의 (위도, 경도)를 바꾸면 전혀 다른 곳이에요.

3. 생활 속에서 · 이어지는 개념

  • 바둑판·엑셀 셀(열, 행), 체스 칸, 스크린 픽셀이 모두 순서쌍이에요.
두 점을 찍어 위치·사분면 비교; a = b이면 일치
📋 데이터 확인 탭의 결론

“a와 b가 다르면 (a, b)와 (b, a)는 언제나 다른 점이었다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

점 (−4, 7)이 속한 사분면과 x축 대칭점은?

제2사분면; x축 대칭 (−4, −7).

(a, b)가 제3사분면일 때 (b, −a)는 어느 사분면?

a < 0, b < 0 → (음, 양) → 제2사분면.
