행렬 실험실 — AB와 BA는 대체로 다르다

두 행렬의 성분을 바꿔 가며 AB와 BA를 각각 계산해 같은지 기록했습니다. 대부분의 조합에서 AB ≠ BA였고 같아지는 경우는 단위행렬처럼 특별할 때뿐이어서 행렬 곱셈에 교환법칙이 성립하지 않음을 확인했습니다. 곱셈 규칙과 전개 시 주의점을 정리합니다.

실험 안내: 두 행렬의 성분을 정하고, 곱하는 순서를 바꿔 보자.

표 1. AB와 BA 비교 (실험 예시, 2 × 2 행렬)
ABABBA같은가?
[1 2; 0 1][0 1; 1 0][2 1; 1 0][0 1; 1 2]다름
[1 2; 3 4][1 0; 0 1] (단위행렬)[1 2; 3 4][1 2; 3 4]같음
[1 1; 0 1][1 0; 1 1][2 1; 1 1][1 1; 1 2]다름
[2 0; 0 2][1 3; 2 1][2 6; 4 2][2 6; 4 2]같음 (스칼라 행렬)

(AB)₁₁ = a₁₁b₁₁ + a₁₂b₂₁이지만 (BA)₁₁ = b₁₁a₁₁ + b₁₂a₂₁로 둘째 항의 조합이 다릅니다. 행렬은 변환이라 ‘회전 뒤 대칭’과 ‘대칭 뒤 회전’이 다른 것과 같습니다. 그래서 (A + B)² = A² + AB + BA + B²이며 2AB로 묶을 수 없습니다.

개념 정리

1. 행렬 곱셈은 교환법칙이 성립하지 않아요

수는 2 × 3 = 3 × 2이지만 행렬은 일반적으로 AB ≠ BA예요. 행렬 곱은 '앞 행렬의 행 × 뒤 행렬의 열'을 더하는 규칙이라 순서를 바꾸면 조합이 달라지기 때문이에요. 가끔 AB = BA가 되는 경우(단위행렬, 같은 행렬의 거듭제곱 등)가 있지만 특별한 조합일 뿐이에요. 그래서 (A + B)² = A² + AB + BA + B²이지 A² + 2AB + B²이 아니에요.

왜 그럴까

  • 행렬은 '변환'이에요. 90° 회전 뒤 x축 대칭과, x축 대칭 뒤 90° 회전은 결과가 달라요 — 순서가 중요.
  • 2 × 2에서 (AB)₁₁ = a₁₁b₁₁ + a₁₂b₂₁, (BA)₁₁ = b₁₁a₁₁ + b₁₂a₂₁ — 둘째 항이 달라요.
  • 결합법칙 (AB)C = A(BC)와 분배법칙은 성립해요.

📋 데이터 확인 탭의 결론

“AB와 BA가 다른 경우가”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

A = [1 2; 0 1], B = [0 1; 1 0]일 때 AB와 BA를 구하시오.

AB = [1·0 + 2·1, 1·1 + 2·0; 0 + 1, 0 + 0] = [2 1; 1 0], BA = [0 + 0, 0 + 1; 1 + 0, 2 + 0] = [0 1; 1 2]. 다릅니다.

(A − B)(A + B) = A² − B²이 성립하는 조건은?

전개하면 A² + AB − BA − B²이므로 AB = BA일 때만 성립합니다.
