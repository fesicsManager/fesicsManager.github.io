기본정리 실험실 — 잘게 더한 값 = F(q) − F(p)

f(x) = ax + b의 계수와 구간 [p, q]를 바꾸며 구간을 2만 개로 나눠 더한 리만 합과 원시함수의 끝값 차 F(q) − F(p)를 비교했습니다. 두 값은 언제나 같았고(차이 10⁻⁶ 수준의 수치 오차), 그래프가 x축 아래에 있는 부분이 크면 적분값이 음수였습니다. 미적분의 기본정리를 정리합니다.

넓이 함수 A(x) = ∫ₚˣ f를 x로 미분하면 폭 dx인 띠의 넓이 f(x)dx에서 f(x) — 즉 A는 f의 원시함수입니다. 그래서 ‘잘게 더하기’와 ‘미분 거꾸로’가 같은 답으로 이어지고, 무한히 더하는 대신 원시함수를 찾아 빼기만 하면 됩니다.

개념 정리

1. 미적분의 기본정리: ∫ₚ^q f(x)dx = F(q) − F(p)

곡선 아래 넓이를 구하려고 구간을 2만 개로 잘게 나눠 더한 값과, f의 원시함수 F(F′ = f)의 두 끝값 차 F(q) − F(p)가 항상 같아요. '잘게 더하기'(적분)와 '미분을 거꾸로 하기'(원시함수)가 같은 답으로 이어진다는 것이 기본정리이고, 덕분에 무한히 더하는 대신 원시함수를 찾아 빼기만 하면 돼요.

왜 그럴까

  • 넓이 함수 A(x) = ∫ₚ^x f를 x로 미분하면 f(x)예요(폭 dx인 띠의 넓이 f(x)dx). 즉 A는 f의 원시함수.
  • f = ax + b: F = ax²/2 + bx. 구간 [1, 3], a = 2, b = 1: F(3) − F(1) = 12 − 2 = 10.
  • 적분값이 음수면 그래프가 x축 아래에 있는 부분이 더 크다는 뜻이에요.

2. 자주 하는 오해 바로잡기

· "적분은 넓이, 미분은 기울기라 관련 없다" → 서로 역연산이에요.

· 정적분값 ≠ 넓이(x축 아래는 음수)라는 점은 다른 실험에서 확인해요.

3. 생활 속에서 · 이어지는 개념

  • 속도를 적분하면 이동 거리, 거리를 미분하면 속도 — 주행 기록계와 속도계의 관계예요.

“구간을 2만 개로 잘게 나눠 더한 값과 F(q) − F(p) 가 언제나 같았다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

∫₁³ (2x + 1)dx를 구하시오.

F = x² + x → F(3) − F(1) = 12 − 2 = 10.

∫₀² (3x² − 2x)dx는?

F = x³ − x² → 8 − 4 − 0 = 4.
