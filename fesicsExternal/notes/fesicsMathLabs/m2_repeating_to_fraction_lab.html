순환소수 실험실 — 0.999… = 1

순환하지 않는 부분과 순환마디를 정해 10ⁿ을 곱해 꼬리를 겹치고 빼서 분수로 바꾼 뒤 다시 나누어 원래 값과 같은지 확인했습니다. 모든 순환소수는 분수로 바뀌었고 되돌려도 값이 같았으며, 순환마디가 9뿐이면 정수가 되어 0.999… = 1이었습니다. 순환소수를 분수로 바꾸는 법을 정리합니다.

실험 안내: 순환하지 않는 부분과 순환마디를 정해 보자.

표 1. 순환소수의 분수 변환 (실험 예시)
순환소수분모 만들기분수기약분수다시 소수로일치?정수?
0.9̇10x − x = 99/911예예
0.2̇10x − x = 22/92/90.222…예아니오
0.1̇2̇100x − x = 1212/994/330.1212…예아니오
0.12̇100x − 10x = 1111/9011/900.1222…예아니오
1.9̇10x − x = 1818/922예예

x = 0.999…, 10x = 9.999…, 빼면 9x = 9 → x = 1. 0.999…는 1에 ‘가까운 수’가 아니라 1을 다르게 쓴 것(차이가 0보다 크다면 얼마인지 말할 수 없음). 공식: 분자 = 전체 숫자 − 비순환 부분, 분모 = 9를 마디 길이만큼, 0을 비순환 자릿수만큼. 모든 순환소수는 유리수.

개념 정리

1. 10ⁿ을 곱해 꼬리를 겹치고 빼면 분수가 돼요: 0.999… = 1

x = 0.999…에서 10x = 9.999…, 빼면 9x = 9, x = 1. 0.999…는 1에 '가까운 수'가 아니라 1을 다르게 쓴 것이에요. 순환하지 않는 부분이 있으면 그만큼 10을 더 곱해 맞춰요: 0.12̇ → 100x − 10x = 12.2̇ − 1.2̇ = 11 → x = 11/90. 모든 순환소수는 분수로 쓸 수 있으니 유리수예요.

왜 그럴까

  • 공식: 분자 = (전체 숫자) − (순환하지 않는 부분), 분모 = 9를 마디 길이만큼, 0을 비순환 자릿수만큼.
  • 0.2̇ = 2/9, 0.1̇2̇ = 12/99 = 4/33, 0.12̇ = 11/90.
  • 되돌려 나누면 원래 순환소수가 나와요.

2. 자주 하는 오해 바로잡기

· "0.999…는 1보다 아주 조금 작다" → 차이가 0보다 큰 수라면 얼마인지 말할 수 없어요. 차이는 0.

3. 생활 속에서 · 이어지는 개념

  • 계산기에 1/3 × 3을 넣어 0.999…가 보여도 정확히 1인 이유예요.
순환 구조로 분수 구성 → 다시 나누어 일치 확인, 마디 9만 있는 경우 정수 판정
