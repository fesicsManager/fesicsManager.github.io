지수 실험실 — a⁰ = 1은 지수법칙을 이어 붙인 결과

밑 a(2~5)를 정하고 지수를 1씩 내리며 값의 변화를 따라가 a⁰과 a⁻ⁿ의 정의가 어디서 오는지 확인했습니다. 지수를 1 내릴 때마다 값이 a로 나누어졌고, 그 흐름을 그대로 이으면 a⁰ = 1, a⁻ⁿ = 1/aⁿ이 되었으며 aⁿ × a⁻ⁿ = 1이 항상 성립했습니다. 지수 확장의 원리를 정리합니다.

2³ = 8 → 2² = 4 → 2¹ = 2 → 2⁰ = 1 → 2⁻¹ = 0.5 → 2⁻² = 0.25, 매번 ÷2. aᵐ ÷ aⁿ = aᵐ⁻ⁿ에 m = n을 넣으면 a⁰ = 1, m = 0을 넣으면 a⁻ⁿ = 1/aⁿ — 억지 약속이 아니라 지수법칙이 계속 성립하도록 이어 붙인 정의입니다. 0⁰은 정의하지 않습니다.

개념 정리

1. a⁰ = 1, a⁻ⁿ = 1/aⁿ은 지수법칙을 이어 붙인 결과예요

지수를 1씩 내릴 때마다 값은 a로 나누어져요: a³ → a² → a¹ → 그다음은 a¹ ÷ a = 1 = a⁰, 다시 ÷a → 1/a = a⁻¹. 0제곱·음수 제곱은 억지로 정한 약속이 아니라 aᵐ × aⁿ = aᵐ⁺ⁿ이 계속 성립하도록 자연스럽게 이어 붙인 정의예요. 실제로 aⁿ × a⁻ⁿ = a⁰ = 1이 항상 성립해요.

왜 그럴까

  • 2³ = 8, 2² = 4, 2¹ = 2, 2⁰ = 1, 2⁻¹ = 0.5, 2⁻² = 0.25 — 매번 ÷2.
  • aᵐ ÷ aⁿ = aᵐ⁻ⁿ에 m = n을 넣으면 a⁰ = 1, m = 0을 넣으면 a⁻ⁿ = 1/aⁿ.
  • 0⁰은 정의하지 않아요(0으로 나누는 셈).

움직여 보기

지수를 1씩 내리면 값은 a로 나누어진다

aⁿ aⁿ × a⁻ⁿ

▶을 누르면 a³에서 시작해 지수를 하나씩 내립니다. 매번 ÷a를 하니 a¹ 다음은 a ÷ a = 1(= a⁰), 그다음은 1/a(= a⁻¹)입니다. 지수 n을 골라 aⁿ × a⁻ⁿ = a⁰ = 1이 되는지도 확인하세요. 처음 값 a = 2: 8, 4, 2, 1, 1/2, 1/4, 1/8.

2. 자주 하는 오해 바로잡기

· "a⁰ = 0" → 아무것도 안 곱한 상태는 1(곱셈의 항등원)이에요.

· "a⁻ⁿ은 음수" → 역수예요. (−2)⁻² = 1/4 > 0.

3. 생활 속에서 · 이어지는 개념

  • 10⁻³ = 0.001(밀리), 10⁻⁶(마이크로) 같은 단위 접두어가 음의 지수예요.

예제

(−2)⁻³과 (1/3)⁻²의 값은?

1/(−8) = −1/8; 1/(1/9) = 9. 음의 지수는 역수이지 음수가 아닙니다.

2⁵ × 2⁻⁵과 10⁻³을 소수로 나타내면?

2⁰ = 1; 10⁻³ = 0.001(밀리).
