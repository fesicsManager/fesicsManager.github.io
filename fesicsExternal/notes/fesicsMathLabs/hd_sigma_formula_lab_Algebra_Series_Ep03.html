시그마 실험실 — 제곱의 합 ≠ 합의 제곱

n(1~30)을 바꾸며 1부터 n까지의 합·제곱합·세제곱합을 직접 더해 세 공식과 대조했습니다. Σk = n(n+1)/2, Σk² = n(n+1)(2n+1)/6, Σk³ = (Σk)²이 모두 정확히 일치했고, Σk²은 (Σk)²과 n = 1에서만 같았습니다. 세 공식과 흔한 혼동을 정리합니다.

Σk³ = (Σk)²은 신기하게 성립하지만 Σk²은 n의 3차식, (Σk)²은 4차식이라 차수부터 다릅니다. 공식은 수학적 귀납법이나 (k + 1)³ − k³의 망원합으로 증명하며, Σ(k + 1)² 같은 식은 전개해 Σk², Σk, Σ1로 나눕니다.

개념 정리

1. 제곱의 합 ≠ 합의 제곱

Σk = n(n+1)/2, Σk² = n(n+1)(2n+1)/6, Σk³ = [n(n+1)/2]²예요. 신기하게 Σk³ = (Σk)²이지만, Σk²은 (Σk)²과 전혀 달라요. '제곱의 합'과 '합의 제곱'을 섞어 쓰면 안 되고, n이 커질수록 차이가 급격히 벌어져요.

왜 그럴까

  • n = 3: Σk = 6, (Σk)² = 36, Σk² = 14, Σk³ = 36.
  • Σk²은 n의 3차식, (Σk)²은 4차식 — 차수부터 달라요.
  • 공식은 수학적 귀납법이나 (k+1)³ − k³의 망원합으로 증명해요.

움직여 보기

합의 제곱 (Σk)²와 제곱의 합 Σk² — n을 늘리며 비교

Σk (Σk)² Σk³ Σk² 차이

보라 막대 (Σk)²와 주황 동그라미 Σk³는 늘 같은 높이에 있지만, 파란 막대 Σk²은 훨씬 낮아요. n = 3이면 36과 14, n = 10이면 3025와 385 — n이 커질수록 차이가 빠르게 벌어지는 것을 확인해 보세요. 세로 눈금은 지금 n에 맞춰 바뀌어요.

2. 자주 하는 오해 바로잡기

· "Σk² = (Σk)²" → 3차식과 4차식이라 n = 1에서만 같아요.

· Σ(k + 1)² 같은 식은 전개해서 Σk², Σk, Σ1로 나눠요.
