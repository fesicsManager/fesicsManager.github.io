평행선 실험실 — 동위각이 같은 것은 평행할 때뿐

아래 직선의 기울기와 가로지르는 선의 각을 바꾸며 위·아래 동위각을 재고 같아지는 조건을 찾았습니다. 두 직선이 평행(기울기 0°)일 때만 동위각이 같았고 평행하지 않으면 기울기만큼 달랐으며, 맞꼭지각은 평행과 상관없이 언제나 같았습니다. 동위각·엇각·맞꼭지각을 정리합니다.

평행선은 방향이 같으므로 가로지르는 선과 이루는 각도 같습니다. 엇각 = 동위각의 맞꼭지각이라 평행일 때 같고, 맞꼭지각은 같은 두 직선이 만드는 각이라 180° − 공통각으로 항상 같습니다. 거꾸로 동위각이 같으면 평행(평행선의 판정).

개념 정리

1. 동위각·엇각이 같은 것은 두 직선이 평행할 때뿐

한 직선이 두 직선을 가로지를 때 같은 위치의 각(동위각)과 엇갈린 위치의 각(엇각)은 두 직선이 평행할 때만 같아요. 평행하지 않으면 달라요. 반면 맞꼭지각은 평행과 상관없이 언제나 같아요. 거꾸로 동위각이 같으면 두 직선은 평행이에요(평행선의 판정).

왜 그럴까

  • 평행선은 방향이 같으므로 가로지르는 선과 이루는 각도 같아요. 기울기가 다르면 각도 달라요.
  • 맞꼭지각은 같은 두 직선이 만드는 각이라 180° − 공통각으로 항상 같아요.
  • 엇각 = 동위각의 맞꼭지각이라 평행일 때 같아요.

2. 자주 하는 오해 바로잡기

· "가로지르는 선이 있으면 동위각은 같다" → 평행 조건이 빠지면 틀려요.

예제

평행한 두 직선을 가로지르는 선이 한 직선과 65°를 이룰 때 다른 직선과 이루는 동위각과 엇각은?

동위각 65°, 엇각 65°, 이웃한 각 115°.

동위각이 각각 70°와 75°로 재어졌다면 두 직선은?

평행이 아니다(5° 차이만큼 기울어짐).
