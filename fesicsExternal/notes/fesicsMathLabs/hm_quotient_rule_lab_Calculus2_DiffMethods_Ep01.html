몫의 미분 실험실 — (f/g)′ = (f′g − fg′)/g²

분자 ax + b, 분모 cx + 1의 계수와 확인할 x를 바꾸며 f/g를 수치 미분한 값을 몫의 법칙과 f′/g′과 비교했습니다. 몫의 법칙은 항상 맞았고 f′/g′은 한 번도 맞지 않았으며, 분자의 빼는 순서를 바꾸면 부호가 반대가 되었습니다. 몫의 미분법을 정리합니다.

곱의 법칙을 f = (f/g)·g에 적용해 정리하면 몫의 법칙이 나옵니다. (2x + 1)/(x + 1)의 도함수 [2(x + 1) − (2x + 1)]/(x + 1)² = 1/(x + 1)². ‘f′g − fg′’ 순서가 중요하고, (1/g)′ = −g′/g²이 특수한 경우. 분모가 0인 점에서는 미분 불가.

개념 정리

1. 몫의 미분법: (f/g)′ = (f′g − fg′)/g²

미분은 나눗셈과도 그대로 어울리지 않아요. (f/g)′ = f′/g′이 아니라 (f′g − fg′)/g²이고, 분자의 빼는 순서도 중요해요. 곱의 법칙을 f = (f/g)·g에 적용해 정리하면 이 식이 나와요.

왜 그럴까

  • f = 2x + 1, g = x + 1: (f/g)′ = [2(x+1) − (2x+1)·1]/(x+1)² = 1/(x+1)². f′/g′ = 2/1 = 2(틀림).
  • (1/g)′ = −g′/g²가 특수한 경우(f = 1).
  • 순서를 바꾸면 부호가 반대가 돼요 — 'f′g − fg′'로 외우세요.

2. 자주 하는 오해 바로잡기

· "분자·분모 따로 미분" → 차수만 봐도 틀려요. 분모가 0인 점에서는 미분 불가.

3. 생활 속에서 · 이어지는 개념

  • 평균 비용(총비용 ÷ 생산량)의 변화율, 농도(용질 ÷ 용액)의 변화율이 몫의 미분이에요.

예제

y = x/(x² + 1)의 도함수는?

[1 · (x² + 1) − x · 2x]/(x² + 1)² = (1 − x²)/(x² + 1)².

y = 1/(3x − 2)의 도함수는?

−3/(3x − 2)².
