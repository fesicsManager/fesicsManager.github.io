인수분해 실험실 — x² − b²은 (x − b)(x + b)

x² − b², x² − 2bx + b², x² + b² 세 식에 여러 x를 대입해 (x − b)(x + b)와 (x − b)² 두 후보를 검산했습니다. x² − b²에는 합·차 공식이, x² − 2bx + b²에는 완전제곱이 맞았고 x² + b²은 두 후보 모두 틀렸으며, 한 값에서 우연히 맞아도 다른 값에서 어긋났습니다. 인수분해의 검산법을 정리합니다.

(x − b)² = x² − 2bx + b²이라 가운데 항 −2bx가 있어야 하고, x² + b²은 유리수 범위에서 인수분해되지 않습니다. 인수분해는 모든 x에서 값이 같아야 하므로 전개하거나 두세 값 이상 대입해 검산합니다. 암산 19 × 21 = 20² − 1 = 399가 합·차 공식.

개념 정리

1. x² − b² = (x − b)(x + b), x² − 2bx + b² = (x − b)²

x² − b²을 (x − b)²로 쓰면 틀려요. (x − b)² = x² − 2bx + b²이라 가운데 항 −2bx가 있어야 해요. x² + b²은 유리수 범위에서 인수분해되지 않아요. 인수분해는 모든 x에서 값이 같아야 하므로 전개하거나 여러 값을 대입하면 바로 검산돼요.

왜 그럴까

  • x = 3, b = 2: x² − b² = 5, (x − b)(x + b) = 1 × 5 = 5 ✓, (x − b)² = 1 ✗.
  • x² − 4x + 4 = (x − 2)²: x = 3 → 1 = 1 ✓.
  • x² + 4: x = 0 → 4, (x − 2)(x + 2) = −4, (x − 2)² = 4(우연). x = 1 → 5 vs −3 vs 1 → 둘 다 ✗.

2. 자주 하는 오해 바로잡기

· "한 값에서 맞으면 인수분해가 맞다" → 우연히 맞을 수 있어요. 두세 값 이상 확인.
