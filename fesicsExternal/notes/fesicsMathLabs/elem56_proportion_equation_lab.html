비례식 실험실 — 외항의 곱 = 내항의 곱

네 수(1~12)로 비례식을 만들어 바깥끼리·안끼리 곱하고 비례식 성립 여부와 비교했습니다. 두 비율이 같을 때는 언제나 외항의 곱 = 내항의 곱이었고, 비율이 다를 때는 두 곱도 달랐습니다. 성질의 까닭과 모르는 항 구하기를 정리합니다.

실험 안내: 네 수를 정해 비례식을 만들고, 바깥끼리·안끼리 곱해 보자.

표 1. 비례식과 두 곱 (실험 예시)
식외항의 곱내항의 곱두 곱이 같나?두 비율비례식인가?
2 : 3 = 4 : 62 × 6 = 123 × 4 = 12같음0.67 / 0.67예
3 : 4 = 9 : 123636같음0.75 / 0.75예
2 : 3 = 4 : 51012다름0.67 / 0.8아니오
5 : 2 = 10 : 42020같음2.5 / 2.5예

‘두 곱이 같다’와 ‘비례식이다’가 모든 기록에서 일치했습니다. a : b = c : d는 a/b = c/d이고 양변에 b × d를 곱하면 a × d = b × c가 되기 때문이며, 옆끼리(a × b = c × d)가 아니라 바깥끼리·안쪽끼리입니다.

개념 정리

1. 비례식에서는 외항의 곱 = 내항의 곱이에요

2 : 3 = 4 : 6처럼 두 비의 비율이 같으면 바깥 두 수의 곱(2 × 6)과 안쪽 두 수의 곱(3 × 4)이 같아요. 비율이 다르면 두 곱도 달라요. 그래서 2 : 3 = 4 : □처럼 모르는 항이 있어도 2 × □ = 3 × 4로 바꿔 □ = 6을 구할 수 있어요.

왜 그럴까

  • a : b = c : d는 a/b = c/d. 양변에 b × d를 곱하면 a × d = b × c.
  • 비율이 같다는 건 한쪽을 몇 배 하면 다른 쪽이 된다는 뜻이라, 곱셈으로 연결돼요.
  • 곱이 같은지 확인하면 비례식이 맞는지 검산할 수 있어요.

2. 자주 하는 오해 바로잡기

· "옆끼리 곱한다(a × b = c × d)" → 바깥끼리·안쪽끼리예요.

3. 생활 속에서 · 이어지는 개념

  • 지도 축척(1 : 50 000), 요리 재료 늘리기, 사진 비율 맞추기가 비례식이에요.
a : b = c : d ⇔ a × d = b × c; 비례식 판정 = a ÷ b와 c ÷ d가 같은지
📋 데이터 확인 탭의 결론

“비례식이 성립할 때는 언제나 외항의 곱 = 내항의 곱이었고, 성립하지 않을 때는 두 곱도 달랐다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

2 : 3 = 4 : □에서 □는?

외항 곱 = 내항 곱: 2 × □ = 3 × 4 = 12 → □ = 6.

축척 1 : 50 000 지도에서 4 cm는 실제 몇 km인가?

1 : 50 000 = 4 : □ → □ = 200 000 cm = 2 km.
