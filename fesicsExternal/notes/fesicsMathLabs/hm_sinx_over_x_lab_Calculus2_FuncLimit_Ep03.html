삼각함수 극한 실험실 — sin x/x → 1은 라디안에서만

x를 1.5, 0.5, 0.1, 0.01로 줄여 가며 sin x/x, (1 − cos x)/x, tan x/x를 재고 도 단위로 잰 값과 비교했습니다. sin x/x는 1로, 같은 0/0 꼴인 (1 − cos x)/x는 0으로 갔고, 도 단위로 재면 sin x°/x → π/180 ≈ 0.01745였습니다. 두 극한과 라디안의 필요성을 정리합니다.

단위원에서 작은 각 x의 호 길이 = x(라디안), 현의 반 = sin x → 둘이 거의 같고, 넓이 비교로 cos x < sin x/x < 1을 얻어 조임 정리. (1 − cos x)/x = sin²x/[x(1 + cos x)] → 1 × 0/2 = 0이고 (1 − cos x)/x² → 1/2. 0/0이라고 다 같은 값이 아니며, 계산기 DEG 모드에서는 1로 가지 않습니다.

개념 정리

1. lim sin x/x = 1 (라디안), lim (1 − cos x)/x = 0

x → 0에서 sin x/x는 1로, 같은 0/0 꼴인 (1 − cos x)/x는 0으로 가요 — 꼴이 같아도 극한은 달라요. sin x/x → 1은 라디안일 때만 성립해요. 도 단위로 재면 sin x°/x → π/180 ≈ 0.01745예요. 미적분에서 라디안을 쓰는 이유이고, (sin x)′ = cos x도 여기서 나와요.

왜 그럴까

  • 단위원에서 작은 각 x의 호 길이 = x(라디안), 현의 반 = sin x → 둘이 거의 같아요. 부채꼴 넓이 비교로 cos x < sin x/x < 1을 얻어 조임 정리.
  • x = 0.5 → 0.9589, 0.1 → 0.9983, 0.01 → 0.99998.
  • (1 − cos x)/x = sin²x/[x(1 + cos x)] → 1 × 0/2 = 0. (1 − cos x)/x² → 1/2.

2. 자주 하는 오해 바로잡기

· "0/0이면 다 1" 또는 "다 0" → 부정형은 경우마다 달라요.

· 계산기를 DEG 모드로 두면 sin x/x가 1로 안 가요.

3. 생활 속에서 · 이어지는 개념

  • 작은 각에서 sin θ ≈ θ 근사가 진자 주기 공식, 광학의 근축 근사에 쓰여요.
x를 0에 가깝게 줄이며 두 비 계산; 도 단위 버전은 sin(x·π/180)/x
📋 데이터 확인 탭의 결론

“x → 0 일 때 sin x / x 는 1에 다가갔지만, 같은 0/0 꼴인 (1 − cos x)/x 는 0으로 갔다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

lim sin 3x/x (x → 0)는?

3 · sin 3x/(3x) → 3.

lim (1 − cos x)/x²은?

sin²x/[x²(1 + cos x)] → 1 × 1/2 = 1/2.
