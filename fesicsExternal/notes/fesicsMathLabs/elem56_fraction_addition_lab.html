초등 5~6학년 수학 · 실험 「분수 덧셈 실험실」

분수 덧셈 실험실 — 분모는 더할 수 없다

두 단위분수(분모 2~10)를 같은 크기 조각으로 다시 잘라 더하고 분모끼리 더한 답과 비교했습니다. 분모끼리 더한 답은 한 번도 맞지 않았고 오히려 더한 두 분수보다 작아졌으며, 통분해 분자만 더한 값이 실제 합이었습니다. 분모의 뜻과 통분을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 두 단위분수를 정하고, 같은 크기 조각으로 다시 잘라 더해 보자.

표 1. 단위분수의 덧셈 (실험 예시)
식분모끼리 더한 답그 값실제 합그 값같은가?
1/2 + 1/32/50.403/6 + 2/6 = 5/60.83다름 (1/2보다도 작음)
1/2 + 1/42/60.332/4 + 1/4 = 3/40.75다름
1/3 + 1/62/90.222/6 + 1/6 = 3/6 = 1/20.50다름
1/5 + 1/52/100.202/50.40다름

분모끼리 더한 답은 항상 실제 합보다 작고 두 분수 중 큰 쪽보다도 작았습니다. 분모는 조각의 크기, 분자는 조각의 개수이므로 크기가 다른 조각은 같은 크기(공통분모 = 공배수)로 다시 잘라야 셀 수 있습니다.

개념 정리

1. 분모는 조각의 크기라서 더할 수 없어요

1/2 + 1/3을 분모끼리 더해 2/5라고 하면, 1/2보다도 작은 답이 나와 말이 안 돼요. 분모는 '몇 조각으로 나눴나'(조각 크기)이고 분자는 '조각 몇 개'예요. 크기가 다른 조각은 바로 셀 수 없으니 같은 크기로 다시 잘라(통분) 3/6 + 2/6 = 5/6처럼 분자만 더해요.

왜 그럴까

  • 1/2 띠와 1/3 띠를 6등분하면 각각 3칸과 2칸 → 합 5칸 = 5/6.
  • 공통분모는 두 분모의 공배수(최소공배수가 편함).
  • 분모끼리 더한 답은 항상 실제 합보다 작고, 두 분수 중 큰 쪽보다도 작아요(두 분수 사이 값이 나와요).

2. 자주 하는 오해 바로잡기

· "분자끼리, 분모끼리 더한다" → 분모를 더하면 조각을 더 잘게 나눈 셈이 되어 값이 줄어요.

3. 생활 속에서 · 이어지는 개념

  • 반 컵(1/2)과 1/4컵의 밀가루는 합쳐 3/4컵이지 2/6컵이 아니에요.
1/a + 1/b = (b + a) ÷ (a × b) → 통분 후 분자 합; 잘못된 방법 2/(a + b)와 비교
📋 데이터 확인 탭의 결론

“분모끼리 더한 답은 한 번도 맞지 않았고, 오히려 더한 두 분수보다 작아졌다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

1/4 + 1/6을 통분해 구하시오.

최소공배수 12: 3/12 + 2/12 = 5/12. 분모끼리 더하면 2/10 = 1/5로 1/4보다 작아 말이 안 됩니다.

밀가루 반 컵(1/2)과 1/4컵을 합치면?

2/4 + 1/4 = 3/4컵. 2/6컵이 아닙니다.
