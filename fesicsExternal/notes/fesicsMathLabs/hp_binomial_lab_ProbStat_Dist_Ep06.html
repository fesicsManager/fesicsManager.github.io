이항분포 실험실 — 평균 np, 분산 np(1 − p)

시행 횟수 n(1~30)과 성공 확률 p를 바꾸며 모든 경우의 확률 nCk·pᵏ(1 − p)ⁿ⁻ᵏ를 직접 더해 평균과 분산을 구하고 np, np(1 − p)와 대조했습니다. 두 값은 정확히 일치했고 확률의 합은 항상 1이었으며, 평균이 정수가 아니면 최빈값과 평균이 다른 자리에 있었습니다. 이항분포의 성질을 정리합니다.

한 번의 시행(베르누이)에서 평균 p, 분산 p(1 − p)인 것이 독립적으로 n번 더해진 결과 — 독립 시행의 분산은 더해지므로 n배. 분산에는 (1 − p)가 붙어 p = 0.5에서 최대. 모든 k의 확률 합 = (p + 1 − p)ⁿ = 1(이항정리). 시행이 독립이 아니면(비복원) 초기하분포.

개념 정리

1. 이항분포 B(n, p)의 평균 np, 분산 np(1 − p)

성공 확률 p인 시행을 n번 독립적으로 반복할 때 성공 횟수 X의 확률은 P(X = k) = nCk·pᵏ(1 − p)ⁿ⁻ᵏ예요. 모든 경우의 확률을 직접 더해 구한 평균과 분산은 정확히 np, np(1 − p)예요. 한 번의 시행(베르누이)에서 평균 p, 분산 p(1 − p)인 것이 독립적으로 n번 더해진 결과예요.

왜 그럴까

  • n = 10, p = 0.3: 평균 3, 분산 2.1. p = 0.5면 분포가 좌우 대칭, 0이나 1에 가까우면 한쪽으로 치우쳐요.
  • 독립 시행의 분산은 더해지므로 n배. 평균이 정수가 아니면 최빈값(가장 높은 막대)과 평균이 다른 자리에 있어요.
  • 모든 k의 확률 합 = (p + 1 − p)ⁿ = 1(이항정리).

움직여 보기

이항분포 B(n, p) — 막대 전체의 무게중심과 퍼짐

Σk·P(k) np Σ(k−평균)²P(k) np(1−p) 최빈값

막대 높이가 P(X = k) = nCk·pᵏ(1 − p)ⁿ⁻ᵏ예요(그래프 높이는 가장 큰 막대에 맞춰 늘렸어요). 보라 점선이 평균, 주황 띠가 평균 ± 표준편차입니다. n = 10, p = 0.3이면 평균 3, 분산 2.1 — p를 움직이며 분산이 p = 0.5에서 가장 커지는지 보세요.

2. 자주 하는 오해 바로잡기

· "분산도 np" → 분산에는 (1 − p)가 붙어 p = 0.5에서 최대예요.

· 시행이 독립이 아니면(비복원 추출) 초기하분포로 달라요.

3. 생활 속에서 · 이어지는 개념

  • 불량품 개수, 설문 응답 수, 자유투 성공 수 예측이 이항분포이고, n이 크면 정규분포로 근사해요.
Σ k·P(k) = 평균, Σ (k − 평균)²·P(k) = 분산; np, np(1 − p)와 대조

예제

자유투 성공률 0.6인 선수가 15번 던질 때 성공 횟수의 평균과 표준편차는?

평균 9, 분산 15 × 0.6 × 0.4 = 3.6 → 표준편차 ≈ 1.9.

B(n, p)의 평균 8, 분산 6.4일 때 n, p는?

np = 8, np(1 − p) = 6.4 → 1 − p = 0.8 → p = 0.2, n = 40.
