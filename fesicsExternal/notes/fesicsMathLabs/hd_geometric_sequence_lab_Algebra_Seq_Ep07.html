등비수열 실험실 — 합 공식은 r ≠ 1일 때만

첫째항 a, 공비 r(−3~3, 0.5 단위), 항의 개수 n을 바꾸며 항을 만들어 더하고 aₙ = a·rⁿ⁻¹, Sₙ = a(rⁿ − 1)/(r − 1)과 대조했습니다. 두 공식은 r이 음수여도 맞았지만 r = 1이면 분모가 0이라 합 공식을 쓸 수 없었고 그때는 Sₙ = na였습니다. 공식의 유도와 예외를 정리합니다.

Sₙ − rSₙ = a − arⁿ에서 (1 − r)Sₙ = a(1 − rⁿ). r = 1이면 양변이 0 = 0이라 정보가 없고 모든 항이 같으니 Sₙ = na. 공비가 미지수인 문제는 r = 1인 경우를 나눠 풉니다. r < 0이면 항의 부호가 번갈지만 공식은 그대로입니다.

개념 정리

1. aₙ = a·rⁿ⁻¹, 합 공식은 r ≠ 1일 때만

공비 r을 (n − 1)번 곱한 것이 n번째 항이고, 합은 Sₙ = a(rⁿ − 1)/(r − 1)이에요. 그런데 r = 1이면 분모가 0이라 이 식을 쓸 수 없고, 모든 항이 같으니 Sₙ = n·a예요. r이 음수면 항의 부호가 번갈아 바뀌지만 공식은 그대로 성립해요.

왜 그럴까

  • Sₙ − rSₙ = a − arⁿ에서 (1 − r)Sₙ = a(1 − rⁿ). r = 1이면 양변 0 = 0으로 정보가 없어요.
  • a = 2, r = 3, n = 4: 2, 6, 18, 54 → 합 80 = 2(81 − 1)/2 ✓.
  • r = −2: 2, −4, 8, −16 → 합 −10 = 2(16 − 1)/(−3) ✓.

2. 자주 하는 오해 바로잡기

· "공식은 항상 쓸 수 있다" → r = 1은 예외. 문제에서 공비가 미지수면 r = 1인 경우를 나눠 풀어야 해요.

3. 생활 속에서 · 이어지는 개념

예제

등비수열 3, 6, 12, …의 제8항과 첫 8항의 합은?

a₈ = 3 × 2⁷ = 384; S₈ = 3(2⁸ − 1)/(2 − 1) = 765.

첫째항 5, 공비 r인 등비수열의 첫 3항의 합이 15일 때 r은?

r ≠ 1: 5(1 + r + r²) = 15 → r² + r − 2 = 0 → r = 1(제외) 또는 r = −2. r = 1이면 S₃ = 15 ✓ → r = 1 또는 −2.
