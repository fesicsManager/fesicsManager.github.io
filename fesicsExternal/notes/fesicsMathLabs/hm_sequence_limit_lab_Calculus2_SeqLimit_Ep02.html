수열의 극한 실험실 — ∞ − ∞는 정해진 값이 없다

1/n, (2n + 1)/(n + 3), √(n+1) − √n, (−1)ⁿ, n² − n 다섯 수열의 항을 큰 n까지 따라가며 수렴 여부를 판정했습니다. 같은 ∞ − ∞ 꼴이라도 √(n+1) − √n은 0으로, n² − n은 ∞로 갔고, (−1)ⁿ은 진동해 수렴하지 않았습니다. 수렴의 뜻과 부정형 처리를 정리합니다.

√(n+1) − √n은 유리화하면 1/(√(n+1) + √n) → 0, n² − n = n(n − 1) → ∞ — 꼴만 보고 판단할 수 없습니다. (2n + 1)/(n + 3)은 최고차항 n으로 나누어 2. 수렴은 ‘한 값에 한없이 가까워지는 것’이며 (−1)ⁿ/n처럼 진동하며 수렴할 수도 있습니다.

개념 정리

1. 수렴은 '한 값에 한없이 가까워지는 것', 꼴만 보고 판단하지 마세요

√(n+1) − √n은 ∞ − ∞ 꼴이라 얼핏 알 수 없어 보이지만, 유리화하면 1/(√(n+1) + √n)이라 0으로 수렴해요. 반면 (−1)ⁿ처럼 값이 계속 튀거나, n처럼 끝없이 커지면 수렴하지 않아요. 부정형(∞ − ∞, ∞/∞, 0/0)은 식을 변형하거나 실제로 큰 n을 넣어 봐야 해요.

대표 수열

  • 1/n → 0, (2n + 1)/(n + 3) → 2(분모·분자 최고차로 나눔), √(n+1) − √n → 0.
  • (−1)ⁿ: −1, 1, −1… 진동 발산. n² − n: ∞ − ∞ 꼴이지만 n(n − 1) → ∞.
  • 같은 ∞ − ∞ 꼴이라도 극한은 0, 상수, ∞ 모두 가능해요.

움직여 보기

수열의 항을 하나씩 찍어 보면 — 다가가나, 튀나, 커지나?

a₁₀ a₁₀₀ a₁₀₀₀ 판정

수열을 골라 n = 1~40의 항을 찍어 보세요. 초록 점선이 극한값입니다. √(n+1) − √n과 n² − n은 둘 다 ∞ − ∞ 꼴인데 하나는 0으로, 하나는 끝없이 커져요.

2. 자주 하는 오해 바로잡기

· "∞ − ∞ = 0" → 부정형이라 정해진 값이 없어요.

· "항이 커졌다 작아지면 발산" → 진동하며 수렴할 수도 있어요((−1)ⁿ/n → 0).

3. 생활 속에서 · 이어지는 개념

  • 반복 계산(뉴턴법)이 답에 수렴하는지, 알고리즘이 멈추는지 판단이 수열의 극한이에요.
n = 10, 100, 1000…에서 항 계산 → 한 값으로 다가가는지, 튀는지, 커지는지 판정

예제

lim (3n² − n)/(n² + 2)는?

n²으로 나눔: (3 − 1/n)/(1 + 2/n²) → 3.

lim (√(n² + n) − n)은?

유리화: n/(√(n² + n) + n) = 1/(√(1 + 1/n) + 1) → 1/2.
