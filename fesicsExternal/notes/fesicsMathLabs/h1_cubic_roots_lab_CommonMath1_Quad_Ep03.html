삼차식 실험실 — 근과 계수의 관계는 차수를 올려도 이어진다

세 근(−4~4)을 정해 (x − α)(x − β)(x − γ)를 전개하고 근의 합·두 개씩 곱의 합·세 근의 곱을 계수 b, c, d와 대조했습니다. 모든 기록에서 합 = −b, 두 개씩 곱의 합 = c, 곱 = −d였고 부호는 근을 홀수 개 곱한 항에서 음수였습니다. 비에트 정리의 구조와 부호 규칙을 정리합니다.

세 관계가 모든 기록에서 성립했습니다. x² 계수는 x 두 개와 근 하나(−부호)를 고른 항의 합이라 −(α + β + γ), x 계수는 근 두 개(부호 +), 상수항은 근 세 개(부호 −)입니다. 최고차 계수가 a면 모두 a로 나눕니다.

개념 정리

1. 삼차방정식의 근과 계수의 관계

세 근 α, β, γ를 가진 삼차식 (x − α)(x − β)(x − γ)를 전개하면 x³ − (α+β+γ)x² + (αβ+βγ+γα)x − αβγ예요. 따라서 x³ + bx² + cx + d = 0에서 세 근의 합 = −b, 두 개씩 곱의 합 = c, 세 근의 곱 = −d예요. 이차방정식의 관계(합 −b/a, 곱 c/a)가 차수를 올려도 같은 규칙으로 이어져요(비에트 정리).

왜 그럴까

  • x² 계수: 세 인수에서 x를 두 개 고르고 근 하나를 −부호로 고른 항의 합 → −(α+β+γ).
  • x 계수: x 하나, 근 두 개 → +(αβ+βγ+γα). 상수항: 근 셋 → −αβγ.
  • 근 1, 2, 3: x³ − 6x² + 11x − 6. 합 6, 두 개씩 곱 합 11, 곱 6.

움직여 보기

세 근을 고르면 삼차식이 정해진다

식 α+β+γ αβ+βγ+γα αβγ

근을 −1, 2, 3으로 두면 x³ − 4x² + x + 6이 나오고, 근의 합 4 = −b, 두 개씩 곱의 합 1 = c, 세 근의 곱 −6 = −d예요(표 1과 같음). 근을 바꿔 가며 세 관계가 늘 맞는지 확인해 보세요. 그래프는 정확히 세 근에서 x축을 지나요(y 값이 큰 곳은 잘려 보여요).

2. 자주 하는 오해 바로잡기

· "부호를 헷갈림" → 홀수 개 근을 곱한 항(x², 상수)은 음수, 짝수 개는 양수. 최고차 계수가 a면 모두 a로 나눠요.

3. 생활 속에서 · 이어지는 개념

  • 근을 직접 구하지 않고 근의 합·곱 같은 대칭식 값을 구할 때, 제어공학의 특성방정식 분석에 쓰여요.
세 근으로 전개해 계수 b, c, d를 얻고 −b, c, −d와 대조
📋 데이터 확인 탭의 결론

“세 근을 전개해 만든 삼차식에서 근의 합은 −b, 두 개씩 곱한 것의 합은 c, 세 근의 곱은 −d였다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

x³ − 2x² − 5x + 6 = 0의 세 근이 α, β, γ일 때 α² + β² + γ²은?

합 2, 두 개씩 곱의 합 −5 → (α + β + γ)² − 2(αβ + βγ + γα) = 4 + 10 = 14. 근을 구하지 않아도 됩니다(실제 근 1, 3, −2: 1 + 9 + 4 = 14 ✓).

2x³ + 4x² − 3x + 1 = 0의 세 근의 합과 곱은?

a = 2로 나눔: 합 = −4/2 = −2, 곱 = −1/2 = −1/2.
