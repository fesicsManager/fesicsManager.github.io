여사건 실험실 — «적어도 한 번»은 1에서 뺀다

주사위를 던지는 횟수 n(1~12)을 바꾸며 1의 눈이 한 번도 안 나올 확률 (5/6)ⁿ과 적어도 한 번 나올 확률 1 − (5/6)ⁿ을 구하고 n/6과 비교했습니다. 두 확률의 합은 항상 1이었고, n/6은 n = 1일 때만 맞았으며 n = 7이면 1을 넘어 확률이 될 수 없었습니다. 여사건 활용법을 정리합니다.

‘한 번, 두 번, …, n번 나올 확률’을 모두 더하는 대신 반대 사건(한 번도 안 나옴) 하나만 구해 1에서 뺍니다. 매번 안 나올 확률 5/6이 독립이라 n번 모두 안 나올 확률은 곱 (5/6)ⁿ. 6번 던져도 1이 나올 확률은 66.5 %뿐 — 확률은 더해지지 않고 곱으로 쌓입니다.

개념 정리

1. "적어도 한 번"은 여사건으로: 1 − (한 번도 안 나올 확률)

주사위를 n번 던져 1이 적어도 한 번 나올 확률은 1 − (5/6)ⁿ이에요. '한 번, 두 번, …, n번 나올 확률'을 모두 더하는 대신 반대 사건(한 번도 안 나옴) 하나만 구해 1에서 빼요. n/6은 n = 1일 때만 맞고, n = 7이면 7/6 > 1이 되어 확률이 될 수 없어요.

왜 그럴까

  • 매번 안 나올 확률 5/6, 독립이므로 n번 모두 안 나올 확률 (5/6)ⁿ.
  • n = 1: 1/6 = 0.167(n/6과 일치). n = 2: 11/36 = 0.306(n/6 = 0.333). n = 6: 0.665(n/6 = 1 아님).
  • n이 커질수록 1에 가까워지지만 1이 되지는 않아요.

n을 바꿔 보세요. 보라 막대(1 − (5/6)ⁿ)는 1에 가까워지지만 1을 넘지 않아요. 주황 막대(n/6)는 n = 7부터 1을 넘어 확률이 될 수 없어요. 오른쪽 띠는 '한 번도 안 나옴'과 '적어도 한 번'을 합치면 언제나 1임을 보여 줘요.

2. 자주 하는 오해 바로잡기

· "6번 던지면 1이 꼭 한 번 나온다" → 66.5 %뿐이에요. 확률은 더해지지 않고 곱으로 쌓여요.

3. 생활 속에서 · 이어지는 개념

  • "n명 중 생일이 같은 사람이 적어도 두 명" 같은 문제도 여사건으로 풀어요(23명이면 50 %).

“«적어도 한 번»은 1 − (한 번도 안 나올 확률) 로 구했다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

동전을 4번 던져 앞면이 적어도 한 번 나올 확률은?

1 − (1/2)⁴ = 1 − 1/16 = 15/16.

명중률 0.3인 사수가 3발 쏴서 적어도 한 발 맞힐 확률은?

1 − 0.7³ = 1 − 0.343 = 0.657.
