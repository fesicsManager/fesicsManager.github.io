로그 실험실 — 곱은 합으로, 덧셈은 안 된다

밑 a와 두 진수 x, y를 바꾸며 log(xy), log(x + y), log(x/y)를 log x ± log y와 비교했습니다. log(xy) = log x + log y, log(x/y) = log x − log y는 예외 없이 성립했지만 log(x + y) = log x + log y는 진수가 1인 특수한 경우 외에는 틀렸습니다. 로그 성질의 근거를 정리합니다.

x = aᵐ, y = aⁿ이면 xy = aᵐ⁺ⁿ → log(xy) = m + n — 지수법칙 aᵐ·aⁿ = aᵐ⁺ⁿ을 뒤집은 성질입니다. 덧셈에 대응하는 지수법칙은 없으므로 log(x + y)는 쪼갤 수 없습니다. log(xⁿ) = n·log x도 같은 원리.

개념 정리

1. 로그는 곱을 합으로, 나눗셈을 차로 바꿔요. 덧셈은 안 돼요

log(xy) = log x + log y, log(x/y) = log x − log y는 지수법칙 aᵐ·aⁿ = aᵐ⁺ⁿ을 뒤집은 성질이에요. 원래 자리에 곱셈이 있어야 로그 밖에서 덧셈이 돼요. 덧셈에 대응하는 지수법칙은 없으므로 log(x + y) ≠ log x + log y예요.

왜 그럴까

  • x = aᵐ, y = aⁿ이면 xy = aᵐ⁺ⁿ → log(xy) = m + n = log x + log y.
  • log₂(4 × 8) = log₂32 = 5 = 2 + 3 ✓. log₂(4 + 8) = log₂12 ≈ 3.58 ≠ 5.
  • log(xⁿ) = n·log x도 같은 원리(거듭제곱 → 곱셈).

2. 자주 하는 오해 바로잡기

· "로그를 분배한다" → log(x + y)를 log x + log y로 쪼개는 것은 가장 흔한 오류예요.

3. 생활 속에서 · 이어지는 개념

  • 계산자·로그표는 곱셈을 덧셈으로 바꿔 계산했고, 데시벨 합산도 로그 성질을 써요.
