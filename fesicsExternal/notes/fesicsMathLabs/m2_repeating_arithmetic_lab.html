순환소수 계산 실험실 — 0.3̇ + 0.6̇ = 1

순환마디 한 자리인 두 순환소수 0.ṗ, 0.q̇를 정해 분수 p/9 + q/9로 더하고 소수 자리끼리 더한 결과와 비교했습니다. p + q = 9면 합이 정확히 1이었고(0.9̇ = 1), p + q ≥ 10이면 받아올림이 끝없이 생겨 자리끼리 더하는 방법이 통하지 않았습니다. 순환소수 계산법을 정리합니다.

x = 0.ṗ → 10x = p.ṗ → 9x = p → x = p/9. 두 자리 마디는 /99, 세 자리는 /999. 0.9̇ = 9/9 = 1은 정확한 등식이며, 계산기에 0.333… + 0.666…을 넣어 0.999…로 보여도 1/3 + 2/3 = 1입니다. 순환소수는 분수로 바꾼 뒤 계산합니다.

개념 정리

1. 순환소수 계산은 분수로 바꿔서: 0.ṗ = p/9

0.3̇ + 0.6̇ = 3/9 + 6/9 = 9/9 = 1이에요. 자리끼리 더하면 0.9̇가 되는데 이 값이 바로 1이에요. p + q ≥ 10이면 받아올림이 끝없이 생겨 자리끼리 더하는 방법은 아예 통하지 않아요(0.7̇ + 0.8̇ = 15/9 = 1.6̇). 순환소수는 분수로 바꾼 뒤 계산하는 것이 정확해요.

왜 그럴까

  • x = 0.ṗ → 10x = p.ṗ → 9x = p → x = p/9.
  • 두 자리 순환마디는 /99, 세 자리는 /999.
  • 0.9̇ = 9/9 = 1은 정확한 등식이에요.

분수 합 값 정수? 자리 합

수직선의 작은 눈금 하나가 1/9이에요. 파랑(p칸)과 빨강(q칸)을 이어 붙이면 (p + q)/9가 돼요. p = 3, q = 6이면 정확히 1에 닿아요 — 0.999… = 1이에요. p + q가 10 이상(예: 7과 8)이면 자리마다 받아올림이 끝없이 생겨 ①의 방법은 통하지 않아요.

2. 자주 하는 오해 바로잡기

· "0.3̇ + 0.6̇ = 0.9̇이고 이는 1보다 조금 작다" → 0.9̇ = 1이에요.

3. 생활 속에서 · 이어지는 개념

  • 1/3 + 2/3 = 1인데 계산기에 0.333… + 0.666…을 넣으면 0.999…로 보이는 이유예요.
p/9 + q/9 = (p + q)/9 계산 → 정수 여부, 자리 합이 10 이상인 경우 기록
📋 데이터 확인 탭의 결론

“순환소수는 분수로 바꿔 계산해야 정확했다. 0.ṗ = p/9 이므로 두 수의 합은 (p+q)/9 다.”
