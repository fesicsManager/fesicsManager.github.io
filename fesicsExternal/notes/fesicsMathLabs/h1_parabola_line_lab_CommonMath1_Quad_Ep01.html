접선 실험실 — 접한다는 것은 중근을 갖는다는 뜻

포물선 y = x²과 직선 y = mx + n의 m, n을 바꾸며 연립한 이차방정식 x² − mx − n = 0의 판별식과 실제 교점 개수를 대조했습니다. D > 0이면 두 점, D = 0이면 한 점(접함), D < 0이면 만나지 않아 판별식 예측이 모두 맞았습니다. 교점 = 실근의 원리를 정리합니다.

실험 데이터 되짚기

실험 안내: 포물선 y = x² 과 직선 y = mx + n 의 직선 계수를 정해 보자.

표 1. 직선과 포물선의 교점 (실험 예시)
직선판별식 D = m² + 4n교점 개수교점의 x접하는가?
y = 2x − 1011 (접점 (1, 1))예
y = 2x + 3162−1, 3아니오
y = 2x − 3−80—아니오
y = −4x − 401−2 (접점 (−2, 4))예
y = 0x + 0010 (접점 원점)예

같은 기울기 2에서 n만 바꾸면 D = 4 + 4n의 부호가 바뀌어 두 점 → 접함 → 떨어짐으로 옮겨 갔습니다. 접선의 기울기 m은 접점 x = m/2에서의 미분계수 2x와 같습니다(m = 2 → x = 1). ‘접하면 근이 없다’가 아니라 중근 하나가 있는 것입니다.

개념 정리

1. 교점의 개수 = 연립한 이차방정식의 실근 개수

포물선 y = x²과 직선 y = mx + n의 교점은 x² = mx + n, 즉 x² − mx − n = 0의 실근이에요. 판별식 D = m² + 4n이 양수면 두 점, 0이면 한 점(접함), 음수면 만나지 않아요. "접한다"는 이 방정식이 중근을 갖는다는 뜻이라, 그래프를 안 그려도 판별식으로 알 수 있어요.

왜 그럴까

  • m = 2, n = −1: D = 4 − 4 = 0 → x = 1에서 접함(접점 (1, 1)).
  • n을 조금 키우면 D > 0으로 두 점, 줄이면 D < 0으로 떨어짐.
  • 접선의 기울기는 접점에서의 미분계수(2x)와 같아요 — 미적분과 이어져요.

2. 자주 하는 오해 바로잡기

· "접하면 한 번 스친 것뿐 근은 없다" → 근이 하나(중근)로 있는 거예요.

· 원과 직선도 같은 방법이지만 '중심에서의 거리'로 판정하는 게 더 편해요.

3. 생활 속에서 · 이어지는 개념

  • 포물선 궤도(공)와 직선 경사면의 충돌 지점, 렌즈 설계에서 접선 조건이 이 계산이에요.
D = m² + 4n → 부호로 판정; 실제 교점은 근을 구해 좌표로 표시

예제

y = x²에 접하고 기울기가 4인 직선의 방정식은?

x² − 4x − n = 0의 D = 16 + 4n = 0 → n = −4 → y = 4x − 4. 접점 x = 2, (2, 4).

y = x²과 y = 3x + k가 서로 다른 두 점에서 만나는 k의 범위는?

D = 9 + 4k > 0 → k > −9/4.
