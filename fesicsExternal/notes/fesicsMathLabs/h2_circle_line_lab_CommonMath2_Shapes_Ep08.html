원과 직선 실험실 — 거리 d와 반지름 r만 비교하면 된다

원의 반지름 r과 직선 y = mx + n을 바꾸며 중심에서 직선까지의 거리 d를 구해 교점 개수를 예측하고 연립 결과와 대조했습니다. d < r이면 두 점, d = r이면 접함, d > r이면 만나지 않아 예측이 항상 맞았고, 기울기 크기와는 무관했습니다. 거리 판정법을 정리합니다.

실험 안내: 원의 반지름과 직선을 정하고, 중심에서 직선까지의 거리와 비교해 보자.

표 1. 거리와 교점 개수 (실험 예시, 중심 원점)
원직선거리 d = |n|/√(m² + 1)반지름 rd와 r교점 개수
x² + y² = 4y = x + 22/√2 = 1.412d < r2
x² + y² = 4y = x + 2√22√2/√2 = 22d = r1 (접함)
x² + y² = 4y = x + 44/√2 = 2.832d > r0
x² + y² = 9y = 5 (수평)53d > r0
x² + y² = 9y = 3x + 003d < r2 (중심 지남)

직선 위 점 중 중심에 가장 가까운 점까지의 거리가 d이므로 그 점이 원 안(d < r)이면 직선이 원을 뚫고 지나갑니다. 접점은 중심에서 직선에 내린 수선의 발이고, 현의 길이는 2√(r² − d²)로 같은 d에서 나옵니다. 연립해 판별식으로 푼 결과와 항상 일치합니다.

개념 정리

1. 중심에서 직선까지의 거리 d와 반지름 r을 비교해요

원과 직선의 교점 개수는 연립하지 않아도 원의 중심에서 직선까지의 거리 d로 알 수 있어요: d < r 두 점, d = r 접함, d > r 만나지 않음. 점과 직선 사이 거리 공식 d = |ax₀ + by₀ + c|/√(a² + b²)로 계산하고, 연립해서 판별식으로 푼 결과와 항상 일치해요.

왜 그럴까

  • 직선 위의 점 중 중심에 가장 가까운 점까지의 거리가 d예요. 그 점이 원 안(d < r)이면 직선이 원을 뚫고 지나가요.
  • x² + y² = 4, y = x + 2: 중심 (0, 0)에서 거리 2/√2 = √2 < 2 → 두 점.
  • 접할 때 접점은 중심에서 직선에 내린 수선의 발이에요.

2. 자주 하는 오해 바로잡기

· "기울기가 크면 원을 못 만난다" → 기울기가 아니라 거리가 정해요.

· 현의 길이 = 2√(r² − d²)도 같은 거리로 구해요.

3. 생활 속에서 · 이어지는 개념

  • 도로(직선)가 통신탑 범위(원) 안을 지나는지, 위성이 지구 그림자를 지나는지 판정이 이 원리예요.
d = |c|/√(m² + 1) (직선 y = mx + c, 중심 원점); d와 r 비교 → 연립 판별식과 대조

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

x² + y² = 9와 y = 2x + k가 접하는 k는?

d = |k|/√5 = 3 → k = ±3√5.

x² + y² = 25와 직선 3x + 4y = 15가 만나 생기는 현의 길이는?

d = 15/5 = 3, r = 5 → 2√(25 − 9) = 8.
