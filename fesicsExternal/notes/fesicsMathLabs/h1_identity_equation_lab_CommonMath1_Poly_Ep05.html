항등식 실험실 — 몇 개 맞아도 증명이 아니다, 계수를 비교한다

ax + b = cx + d의 네 계수를 바꾸며 x에 여러 값을 대입해 성립하는 x의 개수를 세고 판정했습니다. 양변의 계수와 상수가 모두 같을 때만 모든 x에서 성립했고(항등식), 계수만 같으면 해가 없었으며, 계수가 다르면 해가 하나였습니다. 항등식·방정식의 구별과 계수 비교법을 정리합니다.

실험 안내: 양변의 계수를 정하고, x에 여러 값을 넣어 성립하는지 보자.

표 1. 세 경우의 판정 (실험 예시)

2x + 3 = 2x + 3예예모든 x항등식모든 실수
2x + 3 = 2x − 1예아니오0개불능없음
2x + 3 = −x + 6아니오—1개방정식x = 1
3x − 4 = 3x − 4예예모든 x항등식모든 실수

(a − c)x = d − b로 옮기면 세 경우가 보입니다: a ≠ c면 x 하나, a = c·b ≠ d면 0 = (0 아닌 수)로 불능, a = c·b = d면 0 = 0. x를 몇 개 넣어 맞는다고 항등식이 되는 게 아니라 계수 비교로 판정합니다(단, n차식은 서로 다른 n + 1개에서 성립하면 항등식).

개념 정리

1. 항등식은 '모든 x에서' 성립하고, 계수 비교로 판정해요

ax + b = cx + d가 모든 x에서 성립하려면 a = c이고 b = d여야 해요(항등식). 계수만 같고 상수가 다르면 성립하는 x가 하나도 없고, 계수가 다르면 딱 한 x에서만 성립해요(방정식). "x에 몇 개 넣어 봤더니 맞더라"는 항등식의 근거가 못 돼요 — 무한히 많은 x를 다 확인할 수 없으니 계수 비교로 판정해요.

왜 그럴까

  • (a − c)x = d − b. a ≠ c면 x = (d − b)/(a − c) 하나뿐. a = c, b ≠ d면 0 = (0 아닌 수)로 불능. a = c, b = d면 0 = 0으로 항상 참.
  • n차 항등식은 서로 다른 (n + 1)개의 x에서 성립하면 항등식이에요 — 일차식은 2개면 충분.
  • 항등식은 x에 어떤 값을 대입해도 되므로 계수를 구할 때 편한 값(0, 1, −1)을 넣는 수치 대입법을 써요.

2. 자주 하는 오해 바로잡기

· "등식이면 다 방정식" → 항등식은 '풀 것'이 아니라 '항상 참'인 식이에요.

3. 생활 속에서 · 이어지는 개념

  • 부분분수 분해, 다항식의 나눗셈 검산, 물리 공식의 단위 맞추기가 항등식의 계수 비교예요.
여러 x에 대입해 양변 값 비교; 판정: a = c ∧ b = d → 항등식, a = c ∧ b ≠ d → 해 없음, a ≠ c → 해 하나
📋 데이터 확인 탭의 결론

“양변의 계수와 상수가 모두 같을 때만 모든 x에서 성립했다. 이것이 항등식이고,”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

a(x − 1) + b(x + 2) = 4x + 5가 x에 대한 항등식일 때 a, b는?

계수 비교: (a + b)x + (−a + 2b) → a + b = 4, −a + 2b = 5 → b = 3, a = 1. 또는 수치 대입 x = 1: 3b = 9 → b = 3; x = −2: −3a = −3 → a = 1, b = 3.

kx + 2 = 3x + k가 모든 x에서 성립하려면?

k = 3이고 2 = k여야 하는데 모순 → 그런 k는 없다. k = 3이면 해 없음, k ≠ 3이면 해 하나.
