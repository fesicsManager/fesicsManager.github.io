등식 실험실 — 양변에 똑같이 해야 유지된다

저울 양쪽 값을 같게 맞춘 뒤 더하기·빼기·곱하기·나누기를 양변에 똑같이 할 때와 한쪽에만 할 때 등식이 유지되는지 기록했습니다. 양변에 같은 조작을 하면 언제나 유지되었고 한쪽만 하면 깨졌으며, 0으로 나누기는 할 수 없었습니다. 등식의 성질을 정리합니다.

양팔저울 양쪽에 같은 무게를 올리면 평형이 유지되는 것과 같으며, 이 성질이 방정식을 푸는 근거입니다. x + 3 = 7 → 양변 −3 → x = 4. 양변에 0을 곱하면 0 = 0이 되어 정보가 사라지고 0으로 나눌 수는 없습니다. 이항은 새 규칙이 아니라 양변에서 같은 수를 빼는 것의 줄임.

개념 정리

1. 등식은 양변에 똑같이 해야 유지돼요

등식의 양변에 같은 수를 더하거나 빼거나 곱하거나 (0이 아닌 수로) 나누어도 등식은 그대로예요. 양팔저울 양쪽에 같은 무게를 올리면 평형이 유지되는 것과 같아요. 한쪽에만 하면 저울이 기울어 등식이 깨져요. 이 성질이 방정식을 푸는 근거예요.

왜 그럴까

  • 8 = 8에서 양변 +3 → 11 = 11 ✓. 왼쪽만 +3 → 11 ≠ 8.
  • x + 3 = 7 → 양변 −3 → x = 4. 2x = 10 → 양변 ÷2 → x = 5.
  • 양변에 0을 곱하면 0 = 0이 되어 정보가 사라지고, 0으로 나눌 수는 없어요.

2. 자주 하는 오해 바로잡기

· "이항은 새로운 규칙" → 양변에서 같은 수를 빼는 것을 줄여 쓴 것뿐이에요.

3. 생활 속에서 · 이어지는 개념

  • 저울로 물건 무게 재기, 요리 비율 늘리기(양쪽 재료 모두 2배)가 등식의 성질이에요.

예제

2x − 5 = 9를 등식의 성질로 푸시오.

양변 +5: 2x = 14 → 양변 ÷2: x = 7.

x/3 + 1 = 4를 푸시오.

양변 −1: x/3 = 3 → 양변 ×3: x = 9.
