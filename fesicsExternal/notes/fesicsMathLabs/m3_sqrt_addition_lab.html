제곱근 덧셈 실험실 — 근호 안이 같을 때만 계수를 더한다

두 항 p√q, r√s를 정해 길이로 이어 붙여 실제 합을 재고 계수끼리 더한 값·근호 안끼리 더한 값과 비교했습니다. 근호 안이 같을 때만 계수끼리 더할 수 있었고(2√3 + 3√3 = 5√3), 근호 안이 다르면 합쳐지지 않았으며 근호 안을 더한 값은 한 번도 맞지 않았습니다. 제곱근의 덧셈 규칙을 정리합니다.

√3을 하나의 덩어리로 보면 2√3 + 3√3은 2a + 3a = 5a와 같은 동류항 계산. √2 막대와 √3 막대는 단위가 달라 개수로 못 합칩니다. 근호 안을 간단히 하면(√8 = 2√2) 동류항이 드러나며, 곱셈은 근호 안끼리 곱해도 됩니다(√2 × √3 = √6).

개념 정리

1. 근호 안이 같을 때만 계수끼리 더해요: 2√3 + 3√3 = 5√3

√3을 하나의 '덩어리'로 보면 2√3 + 3√3은 2a + 3a = 5a와 같은 동류항 계산이에요. 근호 안이 다르면(√2 + √3) 하나로 합쳐지지 않고 그대로 두어야 해요. 근호 안끼리 더하는 것(√2 + √3 = √5?)은 한 번도 맞지 않아요: 1.414 + 1.732 = 3.146 ≠ 2.236. 근호 안을 간단히 하면(√12 = 2√3) 동류항이 드러나기도 해요.

왜 그럴까

  • 길이로: √3 막대 2개 + 3개 = 5개. √2 막대와 √3 막대는 단위가 달라 개수로 못 합쳐요.
  • √8 + √2 = 2√2 + √2 = 3√2 — 먼저 간단히.
  • 곱셈은 근호 안끼리 곱해도 돼요(√2 × √3 = √6).

2. 자주 하는 오해 바로잡기

· "√a + √b = √(a + b)" → 제곱하면 a + b + 2√(ab)로 2√(ab)만큼 더 커요.

3. 생활 속에서 · 이어지는 개념

  • 정사각형 대각선 여러 개 이어 붙이기(n√2), 벡터 크기 합산에서 단위 맞추기.
두 항 길이 이어 붙여 실측 → 계수 합, 근호 안 합과 비교

3√2 + 2√2 = 5√2 = √50 → 같다.
