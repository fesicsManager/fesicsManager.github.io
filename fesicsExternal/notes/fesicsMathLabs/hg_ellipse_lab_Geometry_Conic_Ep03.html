타원 실험실 — 두 초점까지 거리의 합은 항상 2a

긴반지름 a, 짧은반지름 b를 고정하고 타원 위 점의 위치를 바꿔 가며 두 초점까지의 거리를 재고 합을 2a와 비교했습니다. 각 거리는 점마다 크게 달랐지만 합은 언제나 2a였고, 초점 거리는 c² = a² − b²을 만족했습니다. 타원의 정의와 초점을 정리합니다.

x²/a² + y²/b² = 1은 √((x−c)²+y²) + √((x+c)²+y²) = 2a를 정리한 식. 긴 축 끝에서 (a − c) + (a + c) = 2a, 짧은 축 끝에서 2√(b² + c²) = 2a → b² + c² = a²(타원은 빼기, 쌍곡선은 더하기). 끈의 양 끝을 두 초점에 고정해 그리면 타원이 되는 까닭이고, c = 0이면 원입니다.

개념 정리

1. 타원: 두 초점까지 거리의 합이 일정(= 2a)

타원 위 어느 점에서 재도 두 초점 F, F′까지 거리의 합은 2a(긴반지름의 2배)로 같아요. 각 거리는 점마다 크게 달라도 합은 움직이지 않아요. 끈의 양 끝을 두 초점에 고정하고 팽팽히 당겨 그리면 타원이 되는 이유예요. 초점은 c² = a² − b²로 정해지고, c/a(이심률)가 클수록 납작해요.

왜 그럴까

  • x²/a² + y²/b² = 1은 √((x−c)²+y²) + √((x+c)²+y²) = 2a를 정리한 식이에요.
  • 긴 축 끝점: (a − c) + (a + c) = 2a. 짧은 축 끝점: √(b² + c²) × 2 = 2a → b² + c² = a².
  • c = 0이면 두 초점이 겹쳐 원(a = b).

2. 자주 하는 오해 바로잡기

· "초점은 타원의 중심" → 중심에서 c만큼 떨어진 두 점이에요.

· "c² = a² + b²" → 그건 쌍곡선. 타원은 빼기.

3. 생활 속에서 · 이어지는 개념

  • 행성 궤도(태양이 한 초점), 속삭이는 회랑(한 초점의 소리가 다른 초점에 모임), 신장 결석 쇄석기가 타원 초점을 써요.
점 위치를 바꾸며 두 초점까지 거리 계산 → 합 = 2a 확인, a² − b² = c² 검산

예제

x²/25 + y²/9 = 1의 초점과 이심률은?

c² = 25 − 9 = 16 → 초점 (±4, 0), 이심률 c/a = 0.8.

두 초점 (±3, 0)까지 거리의 합이 10인 타원의 방정식은?

a = 5, c = 3 → b² = 16 → x²/25 + y²/16 = 1.
