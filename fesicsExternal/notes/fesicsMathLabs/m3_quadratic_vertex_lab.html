이차함수 실험실 — (x − p)면 오른쪽으로 p

y = a(x − p)² + q의 a, p, q를 바꾸며 그래프에서 꼭짓점을 직접 찾아 p, −p, q와 대조했습니다. 꼭짓점은 언제나 (p, q)였고 괄호 안이 (x − 3)이면 오른쪽으로 3 옮겨졌으며, 식의 부호와 이동 방향이 반대였습니다. 표준형의 뜻과 평행이동을 정리합니다.

x = 3을 넣어야 괄호가 0이 되어 그 자리가 꼭짓점 — ‘괄호를 0으로 만드는 x’를 찾으면 틀리지 않습니다. x 대신 x − p를 넣으면 같은 y값이 p만큼 늦게(오른쪽에서) 나오고, q는 그대로 위아래 이동, a의 부호가 볼록 방향. 일반형은 완전제곱으로 고쳐 p = −b/2a.

개념 정리

1. y = a(x − p)² + q의 꼭짓점은 (p, q): 부호와 이동 방향이 반대

괄호 안이 (x − 3)이면 그래프는 오른쪽으로 3 옮겨져요. x = 3을 넣어야 괄호가 0이 되어 그 자리가 꼭짓점이 되기 때문이에요. 식에 보이는 −3과 이동 방향 +3이 반대라 헷갈리지만, "괄호를 0으로 만드는 x"를 찾으면 틀리지 않아요. q는 그대로 위아래 이동, a의 부호가 볼록 방향이에요.

왜 그럴까

  • y = (x − 3)² + 1: 꼭짓점 (3, 1). y = (x + 2)² − 4: 꼭짓점 (−2, −4).
  • x 대신 x − p를 넣으면 같은 y값이 p만큼 늦게(오른쪽에서) 나와요.
  • 일반형 ax² + bx + c는 완전제곱으로 고쳐 p = −b/2a.

2. 자주 하는 오해 바로잡기

· "(x − 3)이니 왼쪽으로 3" → 오른쪽. (x + 3)이 왼쪽이에요.

3. 생활 속에서 · 이어지는 개념

  • 분수대 물줄기 위치 조정, 위성 안테나(포물면) 초점 맞추기가 포물선 평행이동이에요.

“꼭짓점은 언제나 (p, q)였다. y = a(x − p)² + q에서 괄호 안이 (x − p)면 그래프는 오른쪽으로 p만큼 옮겨진다.”

예제

y = 2x²을 x축 방향 −4, y축 방향 3만큼 평행이동한 식은?

y = 2(x + 4)² + 3, 꼭짓점 (−4, 3).

y = x² − 6x + 11의 꼭짓점은?

(x − 3)² + 2 → (3, 2).
