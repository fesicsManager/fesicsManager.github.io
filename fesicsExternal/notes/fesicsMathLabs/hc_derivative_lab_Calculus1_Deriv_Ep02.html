미분계수 실험실 — 할선의 기울기가 2a로 다가간다

y = x² 위의 기준점 a와 거리 h(0.01~2)를 바꾸며 두 점을 잇는 할선의 기울기를 재고 2a + h, 2a와 비교했습니다. 할선의 기울기는 언제나 2a + h였고 h를 줄일수록 2a에 가까워졌으며, h = 0에서는 잴 수 없지만 다가가는 값은 분명했습니다. 미분계수의 정의를 정리합니다.

[(a + h)² − a²]/h = (2ah + h²)/h = 2a + h — h로 나눈 뒤에는 h = 0을 넣어도 문제없이 2a. 극한은 대입이 아니라 다가가는 값이며, h를 음수로 잡아도 같은 2a로 가야(좌우 일치) 미분가능합니다. 이 값이 f′(a)이고 그 기울기의 직선이 접선입니다.

개념 정리

1. 미분계수는 할선 기울기의 극한이에요

y = x² 위의 두 점 (a, a²)와 (a + h, (a + h)²)를 잇는 할선의 기울기는 [(a + h)² − a²]/h = 2a + h예요. h를 줄일수록 2a에 가까워지고, h = 0이면 두 점이 겹쳐 기울기를 못 재지만 다가가는 값 2a는 분명해요. 이 극한값이 미분계수 f′(a)이고, 그 기울기의 직선이 접선이에요.

왜 그럴까

  • a = 1: h = 2 → 4, h = 1 → 3, h = 0.1 → 2.1, h = 0.01 → 2.01 → 2로 수렴.
  • h를 음수로 잡아도 2a + h → 2a로 같은 값 — 좌우가 같아야 미분가능.
  • f′(a) = lim (f(a + h) − f(a))/h가 미분의 정의예요.

할선 기울기 2a + h f′(a) = 2a 차이

y = x² 위의 두 점 A(a, a²), B(a + h, (a + h)²)를 잇는 빨간 할선과 보라 점선 접선을 비교하세요. a = 1이면 h = 2 → 4, h = 1 → 3, h = 0.1 → 2.1처럼 2에 다가가요. h를 음수로 해도 같은 값으로 다가갑니다.

2. 자주 하는 오해 바로잡기

· "h = 0을 넣으면 0/0이니 미분은 불가능" → 극한은 '대입'이 아니라 '다가가는 값'이에요.

예제

f(x) = x²의 x = 3에서의 미분계수를 정의로 구하시오.

lim [(3 + h)² − 9]/h = lim (6 + h) = 6.

f(x) = x³의 x = a에서 할선의 기울기와 f′(a)는?

[(a + h)³ − a³]/h = 3a² + 3ah + h² → h → 0에서 3a².
