극값 실험실 — 기울기가 0이라고 다 극값은 아니다

f(x) = x³ + ax의 a(−6~6)를 바꾸며 f′(x) = 0인 점의 개수와 실제 극값의 개수를 비교했습니다. a < 0이면 f′ = 0인 두 점이 모두 극대·극소였지만 a = 0이면 f′(0) = 0인데도 극값이 아니었고, a > 0이면 f′ = 0인 점 자체가 없었습니다. 극값의 필요조건과 판정법을 정리합니다.

극값에서는 f′ = 0이지만(필요조건) 역은 성립하지 않습니다. x³은 f′(0) = 0인데 양쪽 다 f′ > 0이라 부호가 바뀌지 않아 극값이 아닙니다. 극값은 f′의 부호가 + → −(극대), − → +(극소)로 바뀌는 점이며 증감표나 f″ ≠ 0으로 확인합니다.

개념 정리

1. f′(a) = 0은 극값의 필요조건일 뿐이에요

극값에서는 접선이 수평(f′ = 0)이지만, f′ = 0이라고 항상 극값은 아니에요. f(x) = x³은 f′(0) = 0인데 기울기가 잠깐 0이 되었다가 다시 같은 방향(증가)으로 올라가 극값이 아니에요. 극값이려면 그 점 앞뒤에서 f′의 부호가 바뀌어야 해요(+ → − 극대, − → + 극소).

f(x) = x³ + ax로 확인

  • a < 0: f′ = 3x² + a = 0인 두 점 x = ±√(−a/3)에서 부호가 바뀜 → 극대·극소.
  • a = 0: f′ = 3x² ≥ 0, x = 0에서 0이지만 양쪽 다 양수 → 극값 아님(변곡점).
  • a > 0: f′ > 0 항상 → 극값 없음, 단조 증가.

2. 자주 하는 오해 바로잡기

· "f′ = 0 풀면 극값 끝" → 증감표로 부호 변화를 확인해야 해요. 이계도함수 판정(f″ ≠ 0)도 쓸 수 있어요.

3. 생활 속에서 · 이어지는 개념

  • 이익 최대·비용 최소 문제에서 f′ = 0인 점이 정말 최대인지 확인하지 않으면 잘못된 결정을 해요.
f′(x) = 0의 근을 구하고 근의 좌우에서 f′ 부호(또는 f 값 비교) 확인
📋 데이터 확인 탭의 결론

“a가 음수면 f′ = 0 인 두 점이 모두 극대·극소였지만, a = 0 일 때는 f′(0) = 0 인데도 극값이 아니었다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = x³ − 3x의 극값을 구하시오.

f′ = 3x² − 3 = 0 → x = ±1. x = −1: + → − 극대 f(−1) = 2; x = 1: − → + 극소 f(1) = −2.

f(x) = x⁴는 x = 0에서 극값인가?

f′ = 4x³, x = 0 좌우에서 − → + → 극소. f″(0) = 0이라 이계도함수 판정은 결론을 못 내지만 부호 변화로 판정됩니다.
