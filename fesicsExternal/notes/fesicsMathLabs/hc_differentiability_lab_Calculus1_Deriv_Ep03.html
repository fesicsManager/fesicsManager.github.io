미분가능성 실험실 — 이어져 있어도 뾰족하면 미분할 수 없다

x², x³, |x|, x^(2/3) 네 함수의 x = 0에서 h = ±0.001 등으로 좌우 기울기를 재어 연속과 미분가능을 구별했습니다. 네 함수 모두 x = 0에서 연속이었지만 |x|는 좌우 기울기가 −1과 1로 달랐고 x^(2/3)은 기울기가 무한대로 가서 미분할 수 없었습니다. 연속과 미분가능의 관계를 정리합니다.

미분가능 → 연속은 f(a + h) − f(a) = [차분비] × h → f′(a) × 0 = 0으로 증명되지만, 역은 성립하지 않습니다. 뾰족점(좌·우 미분계수 다름)과 수직 접선(기울기 ∞)이 연속이지만 미분 불가능한 대표 예이며, 미분가능성은 점마다 따집니다.

개념 정리

1. 연속은 미분가능의 필요조건일 뿐이에요

미분가능하면 반드시 연속이지만, 연속이라고 미분가능한 건 아니에요. x = 0에서 |x|는 왼쪽 기울기 −1, 오른쪽 +1로 달라 뾰족해서 접선이 하나로 정해지지 않고, x^(2/3)은 기울기가 무한대로 가서 접선이 세로로 서요. 둘 다 이어져 있지만 미분할 수 없어요.

판정 방법

  • 좌미분계수 lim_{h→0⁻} [f(h) − f(0)]/h 와 우미분계수가 같아야 미분가능.
  • x², x³: 좌우 모두 0 → 미분가능. |x|: −1 vs 1. x^(2/3): h^(−1/3) → ±∞.
  • 미분가능 → 연속 증명: f(a + h) − f(a) = [차분비] × h → f′(a) × 0 = 0.

움직여 보기

왼쪽·오른쪽 기울기를 x = 0에서 비교하기

h 좌 기울기 [f(−h) − f(0)]/(−h) 우 기울기 [f(h) − f(0)]/h h → 0이면

빨간 선은 왼쪽 점(−h), 파란 선은 오른쪽 점(h)과 원점을 잇는 할선이에요. h를 줄였을 때 두 선이 한 직선으로 모이면 미분가능, |x|처럼 서로 다른 선으로 남거나 x2/3처럼 세로로 서면 미분할 수 없어요. 네 함수 모두 x = 0에서 이어져(연속) 있어요.

2. 자주 하는 오해 바로잡기

· "그래프가 이어지면 미분된다" → 뾰족점·수직 접선에서는 안 돼요.

· 미분가능성은 점마다 따지는 성질이에요.

3. 생활 속에서 · 이어지는 개념

  • 속도가 갑자기 꺾이는 순간(공이 벽에 튕김)은 위치가 연속이어도 미분(속도)이 불연속이에요.
h = ±0.001 등에서 [f(h) − f(0)]/h 계산 → 좌·우 값 비교
📋 데이터 확인 탭의 결론

“네 함수 모두 x = 0 에서 끊기지 않았지만, |x|, x^(2/3)는 왼쪽과 오른쪽 기울기가 달라(또는 무한대로 가서) 미분할 수 없었다. |x|는 뾰족하고, x^(2/3)은 접선이 세로로 서 버린다. 즉 연속은 미분가능의 필요조건일 뿐 충분조건이 아니다. 반대로 미분가능하면 반드시 연속이다.”

예제

f(x) = |x − 2|는 x = 2에서 연속인가? 미분가능한가?

연속 예(극한 = f(2) = 0). 좌미분계수 −1, 우미분계수 1 → 미분 불가능.

f(x) = x² (x ≤ 1), 2x − 1 (x > 1)은 x = 1에서 미분가능한가?

연속: 1 = 1 ✓. 좌미분계수 2·1 = 2, 우미분계수 2 → 미분가능(매끄럽게 이어짐).
