분배법칙 실험실 — 괄호 앞의 수는 모든 항에

k(ax + b)의 k, a, b와 x 값을 바꾸며 괄호를 먼저 계산한 값, 바르게 전개한 kax + kb, 상수항을 그대로 둔 kax + b를 비교했습니다. 바른 전개는 언제나 괄호 먼저 계산한 값과 같았고, 상수항을 그대로 둔 값은 k = 1이거나 b = 0일 때만 우연히 맞았습니다. 분배법칙을 정리합니다.

k(ax + b) = 가로 k, 세로 (ax + b)인 직사각형 넓이 = 두 조각 kax + kb의 합. 3(2x + 5) = (2x + 5) + (2x + 5) + (2x + 5) = 6x + 15. 괄호는 묶음 전체이므로 상수항에도 곱하며, k가 음수면 상수항 부호까지 바뀝니다(−2(x − 3) = −2x + 6).

개념 정리

1. 괄호 앞의 수는 괄호 안의 모든 항에 곱해요

k(ax + b) = kax + kb. 상수항 b에도 k를 곱해야 해요. 3(2x + 5)를 6x + 5로 쓰면 틀려요(맞는 것은 6x + 15). k가 1이거나 b가 0일 때만 우연히 같아요. 특히 k가 음수면 상수항 부호까지 바뀌어요: −2(x − 3) = −2x + 6.

왜 그럴까

  • k(ax + b) = 가로 k, 세로 (ax + b)인 직사각형 넓이 = 두 조각 kax + kb의 합.
  • 3(2x + 5) = (2x + 5) + (2x + 5) + (2x + 5) = 6x + 15.
  • x = 1: 3 × 7 = 21 = 6 + 15 ✓, 6 + 5 = 11 ✗.

움직여 보기

k(ax + b)는 묶음 (ax + b)를 k번 — 상수항도 k번

2
괄호 먼저 바른 전개 상수항 그대로

식을 고르고 x 값을 바꿔 보세요. 긴 막대는 x, 작은 네모는 1이에요. 파란색은 +, 빨간색은 −예요. 묶음을 k번 쌓으면 x 막대도 1 네모도 모두 k배가 되고, k가 음수면 색(부호)이 모두 뒤집혀요. 상수항을 빼먹은 값은 괄호 먼저 계산한 값과 달라요.

2. 자주 하는 오해 바로잡기

· "문자 항에만 곱한다" → 항마다 모두. 괄호는 '묶음 전체'예요.

3. 생활 속에서 · 이어지는 개념

  • 세트 3개 사기: (물건 2개 + 덤 5개) × 3 = 물건 6개 + 덤 15개 — 덤도 3배예요.

예제

세트(물건 2개 + 덤 5개)를 3세트 사면?

3 × (2 + 5) = 물건 6개 + 덤 15개(덤도 3배).
