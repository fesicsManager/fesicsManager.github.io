증가·감소 실험실 — 기울기의 부호가 오르내림을 말한다

삼차함수 f(x) = x³ + ax² + bx의 계수와 확인할 x를 바꾸며 f′(x)의 부호와 x ± 0.1에서의 실제 변화를 대조했습니다. f′ > 0인 곳에서는 예외 없이 증가, f′ < 0인 곳에서는 감소했고, f′ = 0의 두 근 사이가 감소 구간이었습니다. 증감표의 원리를 정리합니다.

f′(x)는 접선의 기울기이므로 양수면 오른쪽으로 올라가고 음수면 내려갑니다. f′ = 0의 두 근 사이에서 f′ < 0(감소), 바깥에서 > 0(증가). f′ ≥ 0이고 = 0인 점이 떨어져 있으면 여전히 증가(x³). f′은 변화의 방향과 빠르기이지 f의 크기가 아닙니다.

개념 정리

1. f′ > 0이면 증가, f′ < 0이면 감소

도함수 f′(x)는 그 점에서 접선의 기울기예요. 기울기가 양수면 그래프가 오른쪽으로 올라가고(증가), 음수면 내려가요(감소). 그래서 f′의 부호만 조사하면 함수 전체의 오르내림을 알 수 있고, 이것이 증감표를 만드는 이유예요. f′ = 0인 점에서 부호가 바뀌면 극값이에요.

삼차함수로 확인

  • f = x³ + ax² + bx: f′ = 3x² + 2ax + b. f′ = 0의 두 근 사이에서 f′ < 0(감소), 바깥에서 > 0(증가).
  • 어떤 x에서 f′(x) > 0이면 x 바로 옆 f(x + h) > f(x) — 실제 값으로 확인.
  • f′ ≥ 0이고 = 0인 점이 떨어져 있으면 여전히 증가(x³).

2. 자주 하는 오해 바로잡기

· "f′이 크면 f도 크다" → f′은 f의 '변화 방향과 빠르기'이지 f의 크기가 아니에요.

3. 생활 속에서 · 이어지는 개념

  • 기업 매출의 성장률(도함수)이 양수인 동안 매출은 늘고, 성장률이 줄어도 양수면 여전히 늘어요.

예제

f(x) = x³ − 6x² + 9x의 증가·감소 구간은?

f′ = 3x² − 12x + 9 = 3(x − 1)(x − 3). 증가: x ≤ 1, x ≥ 3; 감소: 1 ≤ x ≤ 3.

f(x) = x³ + ax가 모든 실수에서 증가할 a의 범위는?

f′ = 3x² + a ≥ 0 항상 → a ≥ 0(a = 0이면 x = 0에서만 0이라 여전히 증가).
