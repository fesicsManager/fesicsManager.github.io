이차부등식 실험실 — 부등호만으로는 안·바깥이 정해지지 않는다

ax² + bx + c의 a 부호와 부등호 방향(>, <)을 조합해 그래프에서 조건을 만족하는 구간을 기록했습니다. 해가 두 근 사이인지 바깥인지는 부등호 방향만으로 정해지지 않았고 a의 부호와 함께 봐야 했으며, D ≤ 0이면 모든 실수·한 점 제외·없음 같은 해가 나왔습니다. 그래프로 푸는 원리를 정리합니다.

같은 ‘> 0’이라도 a > 0(아래로 볼록)이면 바깥, a < 0(위로 볼록)이면 사이였습니다. 해는 그래프가 x축 위/아래에 있는 x 구간이므로 a < 0이면 양변에 −1을 곱해 a > 0으로 바꾸고 부등호를 뒤집어 푸는 것이 안전합니다.

개념 정리

1. 이차부등식의 해는 그래프가 x축 위/아래에 있는 구간이에요

ax² + bx + c > 0의 해는 y = ax² + bx + c의 그래프가 x축보다 위에 있는 x의 범위예요. a > 0(아래로 볼록)이면 두 근 바깥, a < 0(위로 볼록)이면 두 근 사이가 답이에요. 부등호 방향을 바꾸면 반대가 돼요. 판별식이 0 이하면 해가 모든 실수, 한 점을 뺀 모든 실수, 한 점, 없음 중 하나예요.

네 가지 조합 (D > 0, 근 α < β)

  • a > 0, > 0: x < α 또는 x > β. a > 0, < 0: α < x < β.
  • a < 0, > 0: α < x < β. a < 0, < 0: x < α 또는 x > β.
  • a < 0이면 양변에 −1을 곱해 a > 0으로 바꾸고 부등호를 뒤집어 푸는 것이 안전해요.
  • D < 0, a > 0: 그래프가 항상 x축 위 → > 0의 해는 모든 실수, < 0의 해는 없음.

예제

−x² + 5x − 6 ≥ 0을 푸시오.

−1 곱: x² − 5x + 6 ≤ 0 → (x − 2)(x − 3) ≤ 0 → 2 ≤ x ≤ 3.

모든 실수 x에서 x² + kx + 4 > 0이 성립하는 k의 범위는?

a > 0이고 D = k² − 16 < 0 → −4 < k < 4.
