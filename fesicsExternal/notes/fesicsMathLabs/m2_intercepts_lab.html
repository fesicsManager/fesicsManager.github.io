절편 실험실 — x절편은 −b ÷ a

y = ax + b의 a, b를 바꾸며 그래프가 두 축과 만나는 점을 찾아 대입으로 검산하고 부호를 바꾸지 않은 b ÷ a와 비교했습니다. x절편은 y = 0을 넣어 푼 −b/a였고 대입하면 언제나 y = 0이 되었으며, b/a는 b = 0일 때만 우연히 맞았습니다. 절편의 뜻과 구하는 법을 정리합니다.

y축과 만나는 점은 (0, b), x축과 만나는 점은 0 = ax + b를 풀어 (−b/a, 0). 이항하면 부호가 바뀌므로 항상 대입 검산. a, b가 같은 부호면 x절편은 음수, 다르면 양수. a = 0이면 수평선이라 x절편이 없고(b ≠ 0), 두 절편을 알면 직선을 바로 그릴 수 있습니다.

개념 정리

1. y절편은 x = 0의 y값 b, x절편은 y = 0을 풀어 −b/a

y = ax + b에서 y축과 만나는 점은 (0, b), x축과 만나는 점은 0 = ax + b를 풀어 x = −b/a, 즉 (−b/a, 0)이에요. 부호를 빠뜨린 b/a는 b = 0일 때만 우연히 맞아요. 절편은 '축과 만나는 점의 좌표 하나'라는 것을 기억하세요. a = 0이면 수평선이라 x절편이 없어요(b ≠ 0).

왜 그럴까

  • y = 2x + 6: y절편 6, x절편 −3. 검산 2(−3) + 6 = 0 ✓. b/a = 3이면 2·3 + 6 = 12 ≠ 0.
  • x절편의 부호: a, b가 같은 부호면 음수, 다르면 양수.
  • 두 절편을 알면 직선을 바로 그릴 수 있어요.

움직여 보기

직선을 따라가다 y = 0이 되는 곳이 x절편

y절편 x절편 −b/a 검산 b/a를 넣으면

주황 점이 y절편(초록)에서 출발해 직선을 따라 내려가며 y값이 0이 되는 곳(빨강)에서 멈춥니다. 회색 × 는 부호를 빠뜨린 b/a 자리로, 넣어 보면 y가 0이 아니에요(y = 2x + 6이면 x = 3에서 y = 12). a, b의 부호를 바꿔 x절편이 어느 쪽에 생기는지 보세요.

2. 자주 하는 오해 바로잡기

· "x절편은 b/a" → 이항하면 부호가 바뀌어요. 항상 대입 검산.

3. 생활 속에서 · 이어지는 개념

  • 손익분기점(이익 = 0이 되는 판매량), 연료가 바닥나는 시각이 x절편이에요.
y = 0 대입해 x 구하기 → 원식에 대입해 검산, b/a와 비교
📋 데이터 확인 탭의 결론

“x절편은 y = 0을 넣어 푼 값, 즉 −b ÷ a였고, 넣어 보면 언제나 y가 0이 되었다.”

예제

y = −2x + 8의 두 절편과 두 절편·원점이 만드는 삼각형의 넓이는?

y절편 8, x절편 4 → 넓이 ½ × 4 × 8 = 16.

x절편 3, y절편 −6인 직선의 식은?

기울기 = (0 − (−6))/(3 − 0) = 2 → y = 2x − 6.
