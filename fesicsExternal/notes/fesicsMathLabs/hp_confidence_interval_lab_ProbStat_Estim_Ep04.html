신뢰구간 실험실 — 95 %는 방법의 성공률

모평균 50(σ = 10)인 모집단에서 크기 n인 표본을 100개 뽑아 신뢰구간 x̄ ± zσ/√n을 100개 만들고 그중 몇 개가 50을 품는지 세었습니다. 품은 개수는 신뢰도와 비슷했고(95 % → 약 95개), 신뢰도를 높이면 구간이 넓어지고 n을 키우면 좁아졌습니다. 신뢰도의 올바른 해석을 정리합니다.

모평균은 고정된 값이고 움직이는 것은 구간 쪽. 같은 방법으로 100번 만들면 약 95개가 품고 5개는 놓친다는 뜻이지 ‘모평균이 이 구간에 있을 확률 95 %’가 아닙니다 — 특정 구간이 품었는지는 사실상 정해져 있습니다(0 또는 1). 폭 ∝ σ/√n이라 n을 4배 해야 폭이 절반.

개념 정리

1. 신뢰도 95 %는 '구간 만드는 방법'의 성공률이에요

표본으로 만든 95 % 신뢰구간은 "모평균이 이 구간에 있을 확률이 95 %"가 아니에요. 모평균은 고정된 값이고 움직이는 것은 구간 쪽이에요. 같은 방법으로 표본을 100번 뽑아 구간을 100개 만들면 그중 약 95개가 모평균을 품고 5개는 놓쳐요. 신뢰도를 높이면 구간이 넓어지고, 표본 크기 n을 키우면 구간이 좁아져요(폭 ∝ σ/√n).

왜 그럴까

  • 구간 = x̄ ± z·σ/√n (95 %: z = 1.96, 99 %: 2.58). x̄가 표본마다 달라 구간이 이동해요.
  • n = 25, σ = 10: 95 % 구간 폭 ±3.9. n = 100이면 ±1.96(절반).
  • 어떤 특정 구간이 모평균을 품었는지 아닌지는 사실상 정해져 있어요(확률 0 또는 1).

2. 자주 하는 오해 바로잡기

· "95 % 확률로 모평균이 여기 있다" → 빈도주의 해석과 다른 뜻이에요. "이 방법은 95 % 신뢰할 만하다"가 맞아요.

3. 생활 속에서 · 이어지는 개념

  • 여론조사의 "±3.1 %p(95 % 신뢰수준)"가 바로 이 구간이에요.
모평균 50인 모집단에서 표본 100개 추출 → 각각 x̄ ± zσ/√n → 50을 품은 구간 수 세기
📋 데이터 확인 탭의 결론

“100개의 표본에서 만든 신뢰구간 중 신뢰도에 해당하는 개수만큼이 모평균을 품었고, 나머지는 놓쳤다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

σ = 12, n = 36, x̄ = 70일 때 95 % 신뢰구간은?

70 ± 1.96 × 12/6 = 70 ± 3.92 → [66.08, 73.92].

95 % 신뢰구간의 폭을 ±1로 줄이려면 표본 크기는?(σ = 10)

1.96 × 10/√n ≤ 1 → √n ≥ 19.6 → n ≥ 385.
