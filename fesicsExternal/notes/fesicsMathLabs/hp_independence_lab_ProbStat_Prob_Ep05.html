독립·배반 실험실 — 배반은 오히려 강한 종속

2 × 2 표의 네 칸 인원을 바꾸며 독립 조건 P(A∩B) = P(A)P(B)와 배반 조건 P(A∩B) = 0이 각각 언제 성립하는지 기록했습니다. 6/6/9/9는 독립이었고 겹치는 칸을 0으로 하면 배반이었지만 그때 P(A|B) = 0 ≠ P(A)로 종속이었으며, 둘 다 성립하는 것은 한쪽 확률이 0일 때뿐이었습니다. 두 개념의 차이를 정리합니다.

배반은 ‘동시에 일어날 수 없다’, 독립은 ‘한쪽이 일어나도 다른 쪽 확률이 그대로’. 배반이면 한쪽이 일어난 순간 다른 쪽은 불가능해지므로 강하게 종속. 벤 다이어그램의 ‘겹침 없음’과 확률의 ‘독립’은 다른 그림이며, 독립이면 P(A∪B) = P(A) + P(B) − P(A)P(B), 배반이면 P(A) + P(B).

개념 정리

1. 배반과 독립은 전혀 다른 개념이에요

배반은 "동시에 일어날 수 없다"(P(A∩B) = 0), 독립은 "한쪽이 일어나도 다른 쪽 확률이 그대로다"(P(A∩B) = P(A)P(B))예요. 오히려 배반이면 한쪽이 일어난 순간 다른 쪽은 불가능해지므로 강하게 종속이에요. 둘 다 성립하는 것은 한쪽 확률이 0인 경우뿐이에요.

2 × 2 표로 확인

  • 6/6/9/9(A∩B/A만/B만/없음): P(A) = 0.4, P(B) = 0.5, P(A∩B) = 0.2 = 0.4 × 0.5 → 독립.
  • A∩B 칸을 0으로: 배반. 이때 P(A|B) = 0 ≠ P(A) → 종속.
  • 독립이면 P(A∪B) = P(A) + P(B) − P(A)P(B), 배반이면 P(A) + P(B).

2. 자주 하는 오해 바로잡기

· "겹치지 않으면 서로 상관없다(독립)" → 겹치지 않는 것이야말로 강한 상관이에요. 벤 다이어그램의 '겹침 없음'과 확률의 '독립'은 다른 그림이에요.

3. 생활 속에서 · 이어지는 개념

  • 동전 두 번(독립) vs 카드 한 장이 하트이면서 스페이드(배반) — 확률 계산 방법이 달라요.
P(A∩B)가 0인지(배반), P(A)P(B)와 같은지(독립) 각각 판정

예제

동전 두 번 던지기에서 첫 번째 앞면(A), 두 번째 앞면(B)은 독립인가 배반인가?

P(A∩B) = 1/4 = P(A)P(B) → 독립, 배반 아님(둘 다 앞면 가능).

카드 한 장이 하트(A)와 스페이드(B)는?

P(A∩B) = 0 → 배반; P(A|B) = 0 ≠ 1/4 → 종속.
