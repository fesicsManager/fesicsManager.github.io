내적 실험실 — 내적 0은 수직

두 벡터의 성분을 바꾸며 성분곱의 합 a₁b₁ + a₂b₂와 |a||b|cosθ를 비교하고 내적의 부호와 각의 관계를 확인했습니다. 두 계산은 언제나 같았고, 내적 0은 정확히 각 90°와 일치했으며 예각이면 양수, 둔각이면 음수였습니다. 내적의 뜻과 활용을 정리합니다.

내적은 ‘b 방향으로 본 a의 그림자 길이 × |b|’이므로 내적 0 ⇔ 그림자 없음 ⇔ 수직. 둔각이면 그림자가 반대쪽이라 음수. 코사인법칙 |a − b|² = |a|² + |b|² − 2|a||b|cosθ를 성분으로 전개하면 두 식이 같음이 나오고, cosθ = a·b/(|a||b|)로 각을 구합니다. 내적은 벡터가 아니라 스칼라입니다.

개념 정리

1. 내적 = |a||b|cosθ = 성분곱의 합

두 벡터의 내적은 a·b = a₁b₁ + a₂b₂ = |a||b|cosθ예요. "b 방향으로 본 a의 그림자 길이 × |b|"이므로, 내적 0 ⇔ 그림자 없음 ⇔ 수직이에요. 각이 예각이면 양수, 둔각이면 그림자가 반대쪽으로 생겨 음수예요. 내적의 부호만으로 각의 종류를 판정할 수 있어요.

왜 그럴까

  • (4, 2)·(−1, 2) = −4 + 4 = 0 → 수직. (3, 0)·(1, 1) = 3 > 0 → 예각 45°.
  • 코사인법칙에서 |a − b|² = |a|² + |b|² − 2|a||b|cosθ를 성분으로 전개하면 두 식이 같음이 나와요.
  • cosθ = a·b/(|a||b|)로 각을 구해요.

움직여 보기

내적 = a의 그림자 길이 × |b| — 그림자가 없으면 수직

|a| |b| 그림자 길이 그림자 × |b|

처음 모습은 표 1의 (4, 2)·(−1, 2) = 0 — 그림자가 점 하나로 줄어 수직이에요. b를 (−3, 1)로 바꾸면 −10(둔각 135°), a = (3, 0), b = (1, 1)이면 3(예각 45°). b를 한 바퀴 돌리며 그림자 색과 내적의 부호가 함께 바뀌는 것을 보세요.

2. 자주 하는 오해 바로잡기

· "내적은 벡터" → 스칼라(수)예요.

· "내적 0이면 영벡터" → 수직일 뿐이에요.

3. 생활 속에서 · 이어지는 개념

예제

a = (1, 2), b = (3, −1)이 이루는 각의 코사인은?

a·b = 3 − 2 = 1, |a| = √5, |b| = √10 → cosθ = 1/√50 ≈ 0.141(예각).

a = (2, k)와 b = (3, −1)이 수직일 k는?

6 − k = 0 → k = 6.
