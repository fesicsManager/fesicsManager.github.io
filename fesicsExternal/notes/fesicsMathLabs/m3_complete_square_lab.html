완전제곱 실험실 — 모퉁이에 (b/2)²을 채운다

x² + bx의 b와 검산할 x를 바꾸며 넓이 그림의 모퉁이 빈 칸을 채워 무엇을 더해야 정사각형이 되는지 찾고 대입해 검산했습니다. 더할 수는 언제나 (b/2)²이었고 어떤 x를 넣어도 x² + bx + (b/2)² = (x + b/2)²이 맞았으며, b/2나 b²을 더하면 맞지 않았습니다. 완전제곱식 만들기를 정리합니다.

개념 정리

1. x² + bx를 정사각형으로 만들려면 (b/2)²을 더해요

x² 정사각형 옆에 bx 직사각형을 반으로 갈라 (b/2)x 두 개를 위와 옆에 붙이면, 한 변이 x + b/2인 정사각형에서 모퉁이 (b/2)²만 비어 있어요. 그것을 채우면 x² + bx + (b/2)² = (x + b/2)². b/2나 b²을 더하는 것은 맞지 않아요. 이 '모퉁이 채우기'가 근의 공식을 만드는 첫 단계예요.

왜 그럴까

  • x² + 6x + 9 = (x + 3)². x = 2: 4 + 12 + 9 = 25 = 5² ✓.
  • x² + 6x + 3 = (x + 3)² − 6처럼 남는 상수는 밖으로 빼요.
  • ax²이면 먼저 a로 묶고 진행해요.

2. 자주 하는 오해 바로잡기

· "b²을 더한다" → b의 절반의 제곱이에요. 6x면 9(3²), 36이 아님.

3. 생활 속에서 · 이어지는 개념

  • 이차함수 꼭짓점 찾기, 포물선 운동의 최고점, 원의 방정식 중심 구하기가 모두 완전제곱이에요.
b에서 (b/2)² 계산 → x 대입해 좌변과 (x + b/2)² 비교
📋 데이터 확인 탭의 결론

“x² + bx 를 정사각형으로 만들려면 (b/2)² 을 더해야 했다. 어떤 x를 넣어 검산해도 맞았다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

x² + 8x + 5를 완전제곱 꼴로 고치시오.

x² + 8x + 16 − 16 + 5 = (x + 4)² − 11.

2x² − 12x + 7을 완전제곱 꼴로 고치시오.

2(x² − 6x) + 7 = 2[(x − 3)² − 9] + 7 = 2(x − 3)² − 11.
