편차 실험실 — 편차의 합은 항상 0

다섯 사람의 점수(하나는 10으로 고정)를 바꾸며 각 값의 편차를 구해 더하고 절댓값의 합·제곱의 합과 비교했습니다. 편차의 합은 자료를 아무리 바꿔도 언제나 0이었고, 흩어진 정도를 재려면 절댓값이나 제곱을 써야 했으며 편차 제곱의 평균이 분산, 그 제곱근이 표준편차였습니다. 분산이 필요한 까닭을 정리합니다.

Σ(xᵢ − x̄) = Σxᵢ − n·x̄ = n·x̄ − n·x̄ = 0 — 평균은 위로 넘친 만큼과 아래로 모자란 만큼이 딱 맞는 자리. 편차의 합이 0인 것은 흩어짐과 무관하며, 부호를 없애기 위해 제곱을 써서 분산을 만듭니다. 모든 값이 같으면 절댓값 합도 0.

개념 정리

1. 편차의 합은 항상 0, 그래서 제곱해서 분산을 만들어요

편차 = 값 − 평균. 평균은 '위로 넘친 만큼과 아래로 모자란 만큼이 딱 맞아떨어지는 자리'라 편차를 그냥 더하면 언제나 0이에요. 흩어진 정도를 재려면 부호를 없애야 해서 절댓값이나 제곱을 써요. 편차 제곱의 평균이 분산, 그 제곱근이 표준편차예요.

왜 그럴까

  • Σ(xᵢ − x̄) = Σxᵢ − n·x̄ = n·x̄ − n·x̄ = 0.
  • 2, 4, 9 (평균 5): 편차 −3, −1, +4 → 합 0. 제곱합 26 → 분산 26/3.
  • 모든 값이 같으면 편차가 모두 0이라 절댓값 합도 0.

2. 자주 하는 오해 바로잡기

· "편차 합이 0이면 자료가 안 흩어진 것" → 흩어짐과 무관하게 항상 0이에요.

3. 생활 속에서 · 이어지는 개념

  • 측정 오차 분석, 주가 변동성, 품질 검사의 산포 계산에 분산·표준편차를 써요.
다섯 값의 평균 → 편차 합, |편차| 합, 편차² 합 비교

예제

2, 4, 9의 편차·분산·표준편차는?

평균 5, 편차 −3, −1, +4 (합 0), 제곱합 26 → 분산 26/3 ≈ 8.67, 표준편차 ≈ 2.94.

편차가 −2, 1, x, 3일 때 x는?

합 0 → x = −2.
