역함수 실험실 — f⁻¹은 되돌리는 함수, 1/f가 아니다

일차함수 f(x) = ax + b와 값 x를 바꿔 역함수 f⁻¹(x) = (x − b)/a와 역수 1/f(x)를 나란히 계산하고 f(f⁻¹(x))가 x로 돌아오는지 확인했습니다. f(f⁻¹(x))는 언제나 x였고, 역함수와 역수가 같았던 기록은 없었습니다. 역함수의 뜻·표기·존재 조건을 정리합니다.

f⁻¹의 −1은 지수가 아니라 ‘거꾸로’ 표시입니다(sin⁻¹x도 1/sin x가 아님). y = ax + b에서 x, y를 바꿔 풀면 f⁻¹(x) = (x − b)/a이고 그래프는 y = x 대칭, 정의역과 치역이 서로 바뀝니다. a ≠ 0이어야(일대일) 역함수가 있습니다.

개념 정리

1. f⁻¹은 '되돌리는 함수'이지 1/f가 아니에요

역함수 f⁻¹는 f(x) = y일 때 f⁻¹(y) = x가 되도록 x와 y의 역할을 맞바꾼 함수예요. 그래서 f(f⁻¹(x)) = f⁻¹(f(x)) = x이고 그래프는 y = x에 대칭이에요. f⁻¹의 −1은 지수가 아니라 '거꾸로'라는 표시이며, 1/f(x)(역수)와는 전혀 달라요.

왜 그럴까

  • f(x) = 2x + 1: y = 2x + 1 → x = (y − 1)/2 → f⁻¹(x) = (x − 1)/2. 1/f(x) = 1/(2x + 1)과 비교하면 값이 완전히 달라요.
  • f⁻¹가 있으려면 f가 일대일 대응이어야 해요(a ≠ 0인 일차함수는 항상 OK).
  • 정의역과 치역이 서로 바뀌어요.

움직여 보기

역함수는 y = x에 비춘 그래프, 1/f와는 다르다

f(x) f⁻¹(f(x)) 1/f(x)

파란 점 (x, f(x))를 y = x(회색 점선)에 비추면 빨간 점 (f(x), x)가 되고, 그 점들이 모여 역함수 그래프가 됩니다. 처음 값 f(x) = 2x + 1에서 f(1) = 3, f⁻¹(3) = 1이지만 1/f(1) = 1/3(주황 점선 곡선)로 전혀 달라요. a = 0이면 일대일이 아니라 역함수가 없어요(눈금 1칸 = 1).

2. 자주 하는 오해 바로잡기

· "f⁻¹ = 1/f" → 지수 −1과 표기가 같아 생기는 혼동이에요. sin⁻¹x도 1/sin x가 아니에요.

3. 생활 속에서 · 이어지는 개념

  • 섭씨 ↔ 화씨 변환, 암호화 ↔ 복호화, 로그 ↔ 지수가 역함수 쌍이에요.
f⁻¹(x) = (x − b)/a; f(f⁻¹(x)) = x 확인, 1/f(x)와 비교
📋 데이터 확인 탭의 결론

“f⁻¹은 f를 되돌리는 함수였다. f(f⁻¹(x))는 언제나 x로 돌아왔다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = 3x − 6의 역함수와 f⁻¹(9)는?

x = 3y − 6 → y = (x + 6)/3 → f⁻¹(x) = (x + 6)/3, f⁻¹(9) = 5(f(5) = 9 ✓).

섭씨→화씨 F = 1.8C + 32의 역함수는?

C = (F − 32)/1.8. 화씨 86°F → 30 ℃.
