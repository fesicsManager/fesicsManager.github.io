복소수 실험실 — i를 곱하면 90° 돈다

i의 지수 n(1~20)과 복소수 a + bi를 바꿔 가며 iⁿ의 값, 켤레복소수의 곱, 제곱을 기록했습니다. iⁿ은 i, −1, −i, 1이 4개 주기로 되풀이되어 n을 4로 나눈 나머지만으로 결정되었고, 켤레끼리의 곱은 항상 실수였지만 (a + bi)²은 허수부가 남았습니다. 회전으로 보는 i와 켤레복소수의 성질을 정리합니다.

나머지가 같은 n은 iⁿ도 같았습니다(7과 13은 다르지만 8과 20은 같음). 켤레곱 a² + b²은 언제나 실수, 제곱 (a² − b²) + 2abi는 a나 b가 0일 때만 실수였습니다.

개념 정리

1. i를 곱하면 90° 회전, 켤레를 곱하면 실수

i² = −1이므로 i의 거듭제곱은 i, −1, −i, 1이 4개 주기로 되풀이돼요. 복소평면에서 i를 곱하는 것이 원점 중심 90° 회전이라 네 번이면 제자리예요. 그래서 iⁿ은 n을 4로 나눈 나머지만 보면 돼요. 켤레복소수 (a + bi)(a − bi) = a² + b²은 항상 실수이지만 그냥 제곱 (a + bi)² = a² − b² + 2abi는 허수부가 남아요.

왜 그럴까

  • i¹ = i, i² = −1, i³ = −i, i⁴ = 1, i⁵ = i… 나머지 1·2·3·0에 대응.
  • (a + bi)(a − bi) = a² − (bi)² = a² + b² — 허수부가 부호 반대라 상쇄.
  • 분모의 허수를 없앨 때(분모의 실수화) 켤레를 분모·분자에 곱하는 이유예요.

2. 자주 하는 오해 바로잡기

· "i의 거듭제곱은 계속 커진다" → 크기 1인 채로 돌기만 해요.

· "(a + bi)²도 실수" → b ≠ 0, a ≠ 0이면 허수부 2ab가 남아요.

3. 생활 속에서 · 이어지는 개념

  • 교류 회로·신호 처리에서 복소수 곱셈은 위상(각도) 회전을 나타내요.
iⁿ = i^(n mod 4); 켤레 곱 = a² + b², 제곱 = (a² − b²) + 2ab·i
📋 데이터 확인 탭의 결론

“i의 거듭제곱은 1, i, −1, −i 가 4개 주기로 되풀이되었고, n을 4로 나눈 나머지만 보면 바로 알 수 있었다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

i¹⁰⁰ + i¹⁰¹ + i¹⁰² + i¹⁰³의 값은?

100 mod 4 = 0 → 1 + i + (−1) + (−i) = 0. 연속 4개의 합은 항상 0.

(2 + i)/(1 − i)를 a + bi 꼴로 나타내시오.

분모의 켤레 (1 + i)를 곱함: (2 + i)(1 + i)/(1 + 1) = (2 + 2i + i − 1)/2 = 1/2 + 3/2 i.
