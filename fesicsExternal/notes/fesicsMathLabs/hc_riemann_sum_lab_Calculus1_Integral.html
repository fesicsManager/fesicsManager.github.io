구분구적 실험실 — 직사각형 합이 좁혀 들어가는 값

y = x² 아래 0~b의 넓이를 직사각형 n개(1~60)로 채워 왼쪽 높이의 작은 쪽 합과 오른쪽 높이의 큰 쪽 합을 구하고 b³/3과 비교했습니다. 참값은 언제나 두 합 사이에 있었고, n을 키울수록 두 합의 차가 n에 반비례해 줄어 같은 값으로 좁혀졌습니다. 구분구적법의 원리를 정리합니다.

두 합의 차 = (f(b) − f(0)) × b/n으로 n에 반비례해 0으로 갑니다. 직사각형이 아무리 많아도 정확히 맞지는 않지만 다가가는 값은 하나(b³/3)로 정해지고, 그 극한이 정적분입니다. Σk² = n(n+1)(2n+1)/6으로 극한을 계산하면 정확히 b³/3.

개념 정리

1. 정적분은 직사각형 합이 좁혀 들어가는 값이에요

곡선 y = x² 아래 넓이(0~b)를 직사각형 n개로 채우면, 왼쪽 높이로 만든 작은 쪽 합과 오른쪽 높이로 만든 큰 쪽 합 사이에 참값이 있어요. n을 키울수록 두 합이 같은 값 b³/3으로 좁혀지고, 그 극한이 정적분이에요(구분구적법). 직사각형이 아무리 많아도 정확히 맞지는 않지만 다가가는 값은 하나로 정해져요.

왜 그럴까

  • b = 1: n = 2 → 0.125 ~ 0.625, n = 20 → 0.309 ~ 0.359, n = 200 → 0.331 ~ 0.336 → 1/3.
  • 두 합의 차 = (f(b) − f(0)) × b/n → n에 반비례해 0으로.
  • Σ k² = n(n+1)(2n+1)/6 공식으로 극한을 계산하면 정확히 b³/3.

움직여 보기

작은 쪽 합과 큰 쪽 합이 b³/3으로 좁혀진다

L U 참값 b³/3 U − L

b = 1, n = 2이면 L = 0.125, U = 0.625이고, n = 20이면 0.309 ~ 0.359입니다. ▶을 눌러 n을 200까지 늘리며 빨간 부분(U − L = b³/n)이 줄어 두 합이 참값 b³/3 사이에서 좁혀지는 것을 확인하세요.

2. 자주 하는 오해 바로잡기

· "직사각형으로는 곡선을 정확히 못 채우니 넓이를 구할 수 없다" → 오차가 0으로 수렴하므로 극한값이 넓이예요.

3. 생활 속에서 · 이어지는 개념

  • 컴퓨터의 수치 적분, 속도 기록으로 거리 계산, 불규칙한 땅 넓이 측정이 모두 구분구적법이에요.
L = Σ f(xᵢ₋₁)Δx, U = Σ f(xᵢ)Δx, Δx = b/n; L ≤ b³/3 ≤ U 확인

예제

b = 1, n = 4일 때 큰 쪽 합 U는?

Δx = 1/4, 높이 (1/4)², (2/4)², (3/4)², 1 → U = (1 + 4 + 9 + 16)/64 = 30/64 = 0.469. L = (0 + 1 + 4 + 9)/64 = 0.219.

n → ∞에서 Σ(k/n)² · (1/n)의 극한을 공식으로 구하시오.

(1/n³) · n(n+1)(2n+1)/6 → (2n³ + …)/(6n³) → 1/3.
