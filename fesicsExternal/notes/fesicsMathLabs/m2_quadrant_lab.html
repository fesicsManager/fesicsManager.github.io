사분면 실험실 — 지나는 사분면은 부호만이 정한다

y = ax + b의 기울기와 y절편의 부호 조합 네 가지를 만들어 직선이 지나는 사분면을 기록했습니다. 지나는 사분면은 a와 b의 부호만으로 정해졌고 크기를 바꿔도 결과가 같았으며, 어떤 직선이든 세 사분면을 지나고 한 곳을 지나지 않았습니다. 부호와 사분면의 관계를 정리합니다.

표 1. 부호 조합과 사분면 (실험 결과)
식a 부호b 부호지나는 사분면지나지 않는 곳
y = 2x + 3++1, 2, 34
y = 2x − 3+−1, 3, 42
y = −2x + 3−+1, 2, 43
y = −2x − 3−−2, 3, 41
y = 4x + 1 (크기만 다름)++1, 2, 34 (같음)

b의 부호가 y축 어디서 출발하는지, a의 부호가 오른쪽으로 오르는지 내리는지를 정합니다. 외우지 말고 y절편 위치 + 방향으로 그려 보면 바로 보입니다. b = 0이면 원점을 지나 두 사분면만(1·3 또는 2·4). 지나지 않는 사분면: a, b 같은 부호면 4(양)/1(음), 다른 부호면 2 또는 3.

개념 정리

1. 직선이 지나는 사분면은 기울기와 y절편의 부호가 정해요

y = ax + b(a ≠ 0)는 세 사분면을 지나고 한 곳을 지나지 않아요. b의 부호가 y축 어디서 출발하는지, a의 부호가 오른쪽으로 오르는지 내리는지를 정해요. a > 0, b > 0 → 1·2·3, a > 0, b < 0 → 1·3·4, a < 0, b > 0 → 1·2·4, a < 0, b < 0 → 2·3·4. 크기는 상관없어요.

왜 그럴까

  • 외우지 말고: y절편 위치 + 방향으로 그려 보면 바로 보여요.
  • b = 0이면 원점을 지나 두 사분면만(1·3 또는 2·4).
  • 지나지 않는 사분면: a, b 같은 부호면 4(양)/1(음), 다른 부호면 2 또는 3.

2. 자주 하는 오해 바로잡기

· "기울기가 가파르면 사분면이 달라진다" → 부호만 중요해요.

3. 생활 속에서 · 이어지는 개념

  • 이익(y)–판매량(x) 그래프에서 초기 비용(b < 0)과 마진(a > 0)의 부호로 그래프 위치를 읽어요.
부호 조합별 직선 그리기 → 지나는 사분면 기록, 같은 조합끼리 결과 일치 확인
📋 데이터 확인 탭의 결론

“지나는 사분면은 a와 b의 부호만으로 정해졌다. 크기를 바꿔도 결과가 같았다.”

예제

y = −5x + 2가 지나지 않는 사분면은?

a < 0, b > 0 → 1·2·4 지남 → 제3사분면.

y = ax + b가 제2사분면을 지나지 않으면 a, b의 부호는?

a > 0, b < 0.
