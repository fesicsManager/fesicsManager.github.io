접선 실험실 — 두 접선의 길이는 같다

원의 반지름과 원 밖 점 P까지의 거리 d를 바꾸며 P에서 그은 두 접선의 길이와 접점에서의 각을 재었습니다. 두 접선의 길이는 언제나 같았고 접점에서 반지름과 수직이었으며 길이는 √(d² − r²)이었습니다. 접선의 길이 성질을 정리합니다.

접선은 접점에서 반지름과 수직이므로 △OAP, △OBP는 빗변 OP를 공유하고 OA = OB인 직각삼각형 → RHS 합동이라 PA = PB. OP는 ∠APB를 이등분하고 사각형 OAPB는 ∠AOB + ∠APB = 180°. 삼각형 내접원에서 각 꼭짓점의 두 접선 길이가 같은 것이 이 성질이며, ‘접선의 길이’는 P에서 접점까지.

개념 정리

1. 원 밖 한 점에서 그은 두 접선의 길이는 같아요

점 P에서 원에 접선 두 개를 그으면 PA = PB예요. 접선은 접점에서 반지름과 수직이므로 △OAP, △OBP는 빗변 OP를 공유하고 OA = OB인 직각삼각형 → RHS 합동이라 접선 길이가 같아요. 길이는 √(d² − r²)(d = OP). OP는 ∠APB를 이등분해요.

왜 그럴까

  • r = 3, d = 5: 접선 길이 4. d = 3(원 위)이면 0, d < r이면 접선 없음.
  • 사각형 OAPB는 두 각이 직각이라 ∠AOB + ∠APB = 180°.
  • 삼각형의 내접원에서 각 꼭짓점의 두 접선 길이가 같은 것이 이 성질이에요.

2. 자주 하는 오해 바로잡기

· "접선의 길이 = 접선 전체 길이" → P에서 접점까지의 선분 길이를 말해요.

3. 생활 속에서 · 이어지는 개념

  • 벨트가 도르래에 감기는 길이 계산, 인공위성에서 보이는 지구 범위가 접선 길이 문제예요.
접점 계산 → PA, PB 길이, ∠OAP = 90° 확인, √(d² − r²) 대조

예제

반지름 6인 원의 중심에서 10 떨어진 점에서 그은 접선의 길이는?

√(100 − 36) = 8.

삼각형 ABC의 내접원이 변과 접하는 점을 D(BC), E(CA), F(AB)라 할 때 AF = 3, BD = 4, CE = 5이면 둘레는?

AE = 3, BF = 4, CD = 5 → 둘레 = 2(3 + 4 + 5) = 24.
