제곱근 실험실 — √a + √b ≠ √(a + b), √a × √b = √(ab)

두 수 a, b를 바꾸며 √a + √b와 √(a + b), √a × √b와 √(ab)를 길이로 나란히 재어 비교했습니다. 덧셈에서는 √a + √b가 √(a + b)보다 언제나 컸고 한 번도 같지 않았지만, 곱셈에서는 √a × √b = √(ab)가 항상 성립했습니다. 근호와 연산의 관계를 정리합니다.

(√a + √b)² = a + b + 2√(ab)라서 2√(ab)만큼 더 큽니다. 길이로: 3과 4를 이어 붙이면 7, 넓이 25인 정사각형 한 변은 5. 근호는 곱셈·나눗셈과는 자유롭게 오가지만 덧셈·뺄셈과는 안 되며, (a + b)² ≠ a² + b², 1/(a + b) ≠ 1/a + 1/b도 같은 오류 패턴입니다.

개념 정리

1. √a + √b ≠ √(a + b), 하지만 √a × √b = √(ab)

덧셈에서는 √a + √b가 √(a + b)보다 항상 커요(a, b > 0). (√a + √b)² = a + b + 2√(ab)라서 2√(ab)만큼 더 크기 때문이에요. 반면 곱셈에서는 √a × √b = √(ab)가 언제나 성립해요. 근호는 곱셈·나눗셈과는 자유롭게 오가지만 덧셈·뺄셈과는 그렇지 않아요.

왜 그럴까

  • √9 + √16 = 7, √25 = 5. √9 × √16 = 12 = √144 ✓.
  • 길이로: 3과 4를 이어 붙이면 7, 넓이 25인 정사각형 한 변은 5.
  • 같은 오류 패턴: (a + b)² ≠ a² + b², 1/(a + b) ≠ 1/a + 1/b.

움직여 보기

√a + √b와 √(a + b) — 직각삼각형으로 보면

√a + √b √(a + b) (√a + √b)² − (a + b) √a × √b

두 변이 √a, √b인 직각삼각형의 빗변은 피타고라스 정리로 √(a + b)예요. 두 변을 이어 붙인 길이(√a + √b)는 언제나 빗변보다 길어요. 처음 값 a = 9, b = 16이면 3 + 4 = 7과 √25 = 5. 차이를 제곱으로 보면 정확히 2√(ab)이고, 곱셈 √a × √b = √(ab)는 언제나 맞아요.

2. 자주 하는 오해 바로잡기

· "근호는 안으로 나눠 줄 수 있다" → 곱·나눗셈만. 덧셈은 안 돼요.

3. 생활 속에서 · 이어지는 개념

  • 두 진동의 합성 진폭, 오차 합산(√(σ₁² + σ₂²) ≠ σ₁ + σ₂)에서 이 차이가 중요해요.
