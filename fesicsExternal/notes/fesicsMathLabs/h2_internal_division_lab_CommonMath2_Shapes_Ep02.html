내분점 실험실 — m 쪽에 B가 곱해진다

두 점 A, B와 비 m : n을 바꿔 (mB + nA)/(m + n)으로 내분점을 찍고 실제 거리 비 AP : PB를 재어 확인했습니다. 올바른 식은 언제나 m : n을 맞췄고, 순서를 바꾼 (mA + nB)/(m + n)은 m = n(중점)일 때만 우연히 맞았습니다. 가중치가 반대로 붙는 까닭을 정리합니다.

P가 A에 가까울수록(m 작음) A의 영향이 커야 하므로 A에는 큰 가중치 n이 붙습니다. P = A + (m/(m + n))(B − A), 즉 A에서 전체의 m/(m + n)만큼 간 점으로 기억하면 헷갈리지 않습니다. 외분점은 (mB − nA)/(m − n).

개념 정리

1. 내분점 P = (mB + nA)/(m + n)

선분 AB를 m : n으로 내분하는 점은 P = (m·B + n·A)/(m + n)이에요. m 쪽 비율에 B의 좌표가 곱해진다는 점이 헷갈리기 쉬워요. P가 A에 가까울수록 AP(m)이 작으니, A의 영향이 커지려면 A에 큰 가중치 n이 붙어야 하기 때문이에요. 순서를 바꾼 식은 m = n(중점)일 때만 우연히 같아요.

왜 그럴까

  • A = 0, B = 10을 1 : 4로 내분: P = (1 × 10 + 4 × 0)/5 = 2. A에서 2, B에서 8 → 2 : 8 = 1 : 4 ✓. 순서를 바꾸면 8로 틀려요.
  • P = A + (m/(m + n))(B − A): A에서 전체의 m/(m + n)만큼 간 점.
  • 외분점은 (mB − nA)/(m − n).

움직여 보기

내분점은 ‘무게 n을 A에, m을 B에 올린 저울’의 받침점

P = (m·B + n·A)/(m+n) AP : PB 바꾼 식 (mA+nB)/(m+n)

A(0)에 무게 n개, B(10)에 무게 m개를 올리면 저울이 수평을 이루는 받침점(보라 삼각형)이 바로 m : n 내분점입니다. 무거운 쪽에 가까워지니 P가 A에 가까울수록 A에 큰 가중치 n이 붙어요. 처음 값 1 : 4이면 P = 2, 회색 ✗는 가중치를 바꾼 틀린 점 8이에요.

2. 자주 하는 오해 바로잡기

· "(mA + nB)/(m + n)" → 가중치가 반대예요. 헷갈리면 거리 비를 직접 재어 확인하세요.

3. 생활 속에서 · 이어지는 개념

  • 두 색을 m : n으로 섞은 색, 두 도시 사이 비율 지점, 컴퓨터 그래픽의 선형 보간(lerp)이 내분점이에요.
공식으로 P 계산 → 실제 거리 AP : PB를 재어 m : n과 대조

“A와 B를 m : n으로 나누는 점은 (mB + nA)/(m + n)이었다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

A(1, 2), B(7, −4)를 2 : 1로 내분하는 점은?

((2·7 + 1·1)/3, (2·(−4) + 1·2)/3) = (5, −2). A에서 전체의 2/3만큼 간 점.

A(0, 0), B(6, 3)을 1 : 2로 외분하는 점은?

(1·B − 2·A)/(1 − 2) = (6, 3)/(−1) = (−6, −3).
