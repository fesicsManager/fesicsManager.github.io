접선 실험실 — 중근은 삼차에서 인수가 겹치는 것

포물선 y = x²과 직선 y = mx + n을 연립해 접할 때 D = 0, 즉 중근이 하나 생기는 것을 눈으로 확인했습니다. 3화에서는 이 '겹친 근'을 차수를 올려 삼차식에서 다시 봅니다. 이차에서 (x − p)²이던 것이 삼차에서는 (x − p)²(x − q)가 되어, 그래프가 x축에 닿았다 돌아서는 자리로 나타납니다. 중근과 인수분해를 잇습니다.

표 1. 접함(중근)이 식에 남는 꼴 — 이차에서 삼차로
상황연립·인수분해한 식겹친 근x축과 만나는 자리
y = x²과 y = 2x − 1 (접함)(x − 1)² = 0x = 1 (중근)1곳 (닿음)
y = x²과 y = 2x + 3(x + 1)(x − 3) = 0없음2곳 (뚫음)
삼차: (x − 1)²(x − 3)x³ − 5x² + 7x − 3x = 1 (중근)x = 1 닿음, x = 3 뚫음
삼차: (x − 1)³x³ − 3x² + 3x − 1x = 1 (삼중근)1곳 (스치며 뚫음)
삼차: (x − 1)(x − 2)(x − 3)x³ − 6x² + 11x − 6없음3곳 모두 뚫음

접선 실험에서 D = 0일 때 나온 것은 ‘근이 없음’이 아니라 겹친 인수 (x − 1)²이었습니다. 이 겹침은 차수를 올려도 사라지지 않아서, 삼차식에서도 (x − p)² 꼴이 들어 있으면 그 자리에서 그래프가 x축에 닿았다 돌아섭니다. 그래서 삼차방정식의 근 개수를 셀 때는 중근을 몇 겹인지까지 세어 모두 3개로 맞춥니다.

개념 정리

1. 접함 = 중근 = 겹친 인수

포물선 y = x²과 직선 y = mx + n이 접하는 것은 x² − mx − n = (x − p)² = 0이 되는 때예요. 판별식 D = m² + 4n이 0이면 두 근이 한곳으로 모여 인수가 겹칩니다. 중요한 건 이 '겹침'이 이차만의 일이 아니라는 거예요. 삼차식도 (x − p)²(x − q)처럼 겹친 인수를 가질 수 있고, 그때 x = p는 중근이에요.

왜 그럴까

  • m = 2, n = −1: x² − 2x + 1 = (x − 1)² → 근 x = 1 하나지만 두 겹이에요.
  • 삼차 (x − 1)²(x − 3) = 0의 근은 1(두 겹), 3 → 겹침까지 세면 모두 3개.
  • 겹친 근의 자리에서는 그래프가 x축을 뚫지 않고 닿았다 돌아서요. 접선이 포물선에 닿는 모습과 같은 사정이에요.

움직여 보기

직선을 내려 보자 — 두 점, 접함(중근), 떨어짐

직선 D = m² + 4n 교점

기울기 m = 2로 두고 재생하면 직선이 내려가며 두 점 → 접함 → 떨어짐으로 바뀌다가, n = −1(D = 0)에서 멈춰요. 이때 접점은 (1, 1)로 노트의 예와 같아요. 접할 때도 교점(중근)이 하나 있다는 것을 확인하세요.

2. 삼차방정식은 인수분해로 근을 찾는다

삼차에는 판별식 공식을 쓰지 않아요. 대신 x에 정수를 넣어 0이 되는 값 하나를 찾고(상수항의 약수부터 넣어 봐요), 그것으로 나눠 이차식으로 낮춘 뒤 익숙한 이차 방법을 씁니다. x³ − 5x² + 7x − 3이면 x = 1에서 0 → (x − 1)(x² − 4x + 3) = (x − 1)²(x − 3)이고, 남은 이차식에서 또 1이 나와 중근임을 알게 돼요.

3. 자주 하는 오해 바로잡기

· "접하면 한 번 스친 것뿐 근은 없다" → 근이 하나(중근)로 있는 거예요.

· "삼차방정식의 근은 세 개" → 겹침까지 세면 세 개예요. 서로 다른 근은 3개, 2개, 1개일 수 있어요.

· 중근이라고 다 '닿았다 돌아섬'은 아니에요. (x − 1)³처럼 세 겹이면 스치면서도 뚫고 지나가요.

4. 이어지는 개념

  • 겹친 근은 미분과 바로 이어져요 — f(p) = 0이면서 f′(p) = 0인 자리가 중근이에요. 접선의 기울기가 그 자리에서 0이 되는 것과 같은 조건이에요.
D = 0 ⇔ (x − p)² ⇔ 겹친 근 — 차수가 올라도 같은 꼴로 이어진다

예제

x³ − 5x² + 7x − 3 = 0의 근을 모두 구하고, 중근이 있는지 말하세요.힌트 — 상수항 3의 약수인 ±1, ±3을 넣어 0이 되는 값을 먼저 찾고, 그것으로 나눠 이차식으로 낮추세요.

x = 1을 넣으면 1 − 5 + 7 − 3 = 0 → (x − 1)로 나누면 x² − 4x + 3 = (x − 1)(x − 3). 따라서 (x − 1)²(x − 3) = 0 → x = 1(중근), x = 3. 겹침까지 세면 근은 3개이고, 그래프는 x = 1에서 x축에 닿았다 돌아서고 x = 3에서 뚫고 지나갑니다.

x³ − 7x + k = 0이 x = 2를 근으로 가질 때 k와 나머지 두 근은?힌트 — 근이라는 말은 넣으면 0이라는 뜻입니다. 먼저 k를 구한 뒤 (x − 2)로 나누세요.

8 − 14 + k = 0 → k = 6. x³ − 7x + 6 = (x − 2)(x² + 2x − 3) = (x − 2)(x + 3)(x − 1) → 나머지 두 근은 x = 1, x = −3. 세 근이 모두 달라 중근은 없습니다.
