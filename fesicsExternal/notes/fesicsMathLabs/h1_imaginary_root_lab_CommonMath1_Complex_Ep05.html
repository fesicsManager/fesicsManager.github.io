허근 실험실 — 판별식이 음수여도 근은 있다

ax² + bx + c = 0의 계수를 바꾸며 판별식과 두 근을 구해 복소평면에 찍고, 근의 합과 곱이 실수인지 확인했습니다. D < 0이면 그래프가 x축과 만나지 않았지만 근은 켤레 허근 쌍으로 존재했고, 합(−b/a)과 곱(c/a)은 언제나 실수였습니다. 허근의 존재와 켤레 성질을 정리합니다.

실험 안내: 계수를 정하고 두 근을 구해 보자. 판별식이 음수여도 근은 존재한다.

표 1. 판별식과 근 (실험 예시)
식b² − 4ac근의 종류두 근합곱x축과 만남
x² − 4x + 8 = 0−16허근 (켤레)2 ± 2i48안 만남
x² − 4x + 3 = 04서로 다른 실근1, 343두 점
x² − 4x + 4 = 00중근2, 244한 점 (접함)
x² + 2x + 5 = 0−16허근 (켤레)−1 ± 2i−25안 만남

D < 0인 기록에서 두 근은 언제나 실수축에 대칭인 켤레쌍이었고 허수부가 상쇄되어 합·곱이 실수였습니다. 그래프가 x축과 안 만나는 것은 ‘실근이 없다’이지 ‘해가 없다’가 아닙니다 — 복소수 범위에서 이차방정식은 항상 근이 2개(중근 포함)입니다.

개념 정리

1. 판별식이 음수여도 근은 있어요(허근, 켤레쌍)

ax² + bx + c = 0의 근 x = [−b ± √(b² − 4ac)]/2a에서 판별식 D = b² − 4ac < 0이면 √D가 허수가 되어 두 근은 복소수예요. 그래프가 x축과 안 만나는 것은 실근이 없다는 뜻이지 해가 없다는 뜻이 아니에요. 실수 계수 방정식의 허근은 항상 a + bi와 a − bi 켤레쌍이라 근의 합(−b/a)과 곱(c/a)은 실수예요.

왜 그럴까

  • x² − 4x + 8 = 0: D = −16 → x = 2 ± 2i. 합 4, 곱 8.
  • 켤레의 합은 2a(실수), 곱은 a² + b²(실수) — 허수부가 상쇄.
  • 복소평면에서 켤레 두 근은 실수축에 대칭인 두 점이에요.

2. 자주 하는 오해 바로잡기

· "D < 0이면 근이 없다" → 실수 범위에서만 없어요. 복소수 범위에서 이차방정식은 항상 근이 2개(중근 포함)예요(대수학의 기본정리).

3. 생활 속에서 · 이어지는 개념

  • 진동·회로의 감쇠 진동 해가 켤레 허근에서 나오고, 허수부가 진동수를 뜻해요.
D = b² − 4ac; D ≥ 0 실근, D < 0 허근 (−b ± i√(−D))/2a; 합·곱의 허수부 = 0 확인

예제

x² + 2x + 5 = 0의 두 근과 그 합·곱은?

D = 4 − 20 = −16 → x = (−2 ± 4i)/2 = −1 ± 2i. 합 −2, 곱 (−1)² + 2² = 5 ✓(계수 −b/a, c/a).

실수 계수 이차방정식의 한 근이 3 + i일 때 방정식은?

다른 근은 켤레 3 − i. 합 6, 곱 10 → x² − 6x + 10 = 0.
