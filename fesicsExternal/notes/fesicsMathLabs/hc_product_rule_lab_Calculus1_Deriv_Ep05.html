곱의 미분 실험실 — (fg)′ = f′g + fg′

f = xᵐ, g = xⁿ의 m, n과 확인할 x를 바꾸며 곱 fg를 수치 미분한 값을 f′g + fg′, f′g′, 그리고 x^(m+n)을 직접 미분한 (m + n)x^(m+n−1)과 비교했습니다. 곱의 법칙은 항상 맞았고 f′g′은 한 번도 맞지 않았으며, 지수법칙으로 구한 값과도 일치했습니다. 곱의 미분법을 정리합니다.

직사각형 넓이 f × g가 변할 때 가로가 변한 몫(f′g)과 세로가 변한 몫(fg′)이 따로 더해집니다. 차수로 검산: x⁵의 도함수는 4차인데 f′g′ = 2x · 3x² = 6x³은 3차라 바로 틀림. 몫의 미분 (f/g)′ = (f′g − fg′)/g²도 같은 논리입니다.

개념 정리

1. 곱의 미분법: (fg)′ = f′g + fg′

미분은 덧셈·상수배와는 잘 어울리지만(선형), 곱셈과는 그렇지 않아요. (fg)′ = f′g′이 아니라 f′g + fg′예요. 직사각형 넓이 f × g가 변할 때 가로가 변한 몫(f′g)과 세로가 변한 몫(fg′)이 따로 더해지기 때문이에요. x^m · x^n = x^(m+n)으로 먼저 정리해 미분한 결과와도 일치해요.

왜 그럴까

  • f = x², g = x³: (fg)′ = (x⁵)′ = 5x⁴. f′g + fg′ = 2x·x³ + x²·3x² = 5x⁴ ✓. f′g′ = 2x·3x² = 6x³ ✗.
  • 증명: f(x+h)g(x+h) − f(x)g(x)를 [f(x+h) − f(x)]g(x+h) + f(x)[g(x+h) − g(x)]로 쪼갬.
  • 몫의 미분 (f/g)′ = (f′g − fg′)/g²도 같은 논리에서 나와요.

움직여 보기

직사각형 넓이 f × g가 늘어나는 세 조각

주황 ÷ h 파랑 ÷ h 보라 ÷ h f′g + fg′ = 5x⁴ f′g′ = 6x³

x가 h만큼 늘면 넓이는 주황(Δf × g) + 파랑(f × Δg) + 보라(Δf × Δg)만큼 늘어납니다. ▶으로 h를 줄이면 주황 ÷ h → f′g, 파랑 ÷ h → fg′이 되고 보라 ÷ h는 0으로 사라져, 넓이의 변화율이 f′g + fg′(x = 1이면 5)에 모입니다. f′g′(x = 1이면 6)과는 맞지 않아요. 가로와 세로의 눈금 크기는 다릅니다.

2. 자주 하는 오해 바로잡기

· "각각 미분해서 곱한다" → 차수를 세어 보면 바로 틀린 게 보여요(5차의 도함수는 4차인데 f′g′은 3차).

3. 생활 속에서 · 이어지는 개념

예제

y = (x² + 1)(x³ − 2x)의 도함수는?

2x(x³ − 2x) + (x² + 1)(3x² − 2) = 2x⁴ − 4x² + 3x⁴ − 2x² + 3x² − 2 = 5x⁴ − 3x² − 2. 전개 후 미분해도 같음.

f(1) = 2, f′(1) = 3, g(1) = −1, g′(1) = 4일 때 (fg)′(1)은?

3 × (−1) + 2 × 4 = 5.
