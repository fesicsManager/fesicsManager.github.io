동류항 실험실 — 3a + 2b는 5ab가 아니다

a, b의 계수와 대입할 값을 바꾸며 3a + 2b를 바르게 계산한 값과 5ab로 계산한 값을 비교하고 타일 모델로 확인했습니다. 두 값은 거의 항상 달랐고 우연히 같아지는 값이 있어도 모든 값에서 같지 않아 식이 같지 않았습니다. 동류항의 조건을 정리합니다.

3a는 a 타일 3개, 2b는 b 타일 2개 — 길이가 달라 한 종류로 셀 수 없어 더 줄일 수 없습니다. 5ab는 a × b 타일 5개로 전혀 다른 양. 계수를 더할 수 있는 것은 문자와 차수가 완전히 같은 동류항뿐(3a + 2a = 5a). 3a² + 2a도 동류항이 아닙니다. 사과 3개 + 배 2개 = 과일 5개이지 ‘사과배 5개’가 아닙니다.

개념 정리

1. 동류항끼리만 더할 수 있어요: 3a + 2b ≠ 5ab

3a는 a 타일 3개, 2b는 b 타일 2개예요. 두 타일은 길이가 달라 한 종류로 셀 수 없으니 3a + 2b는 더 줄일 수 없어요. 5ab는 a × b 타일 5개로 전혀 다른 양이에요. 계수를 더할 수 있는 것은 문자 부분이 완전히 같은 동류항뿐이에요(3a + 2a = 5a).

왜 그럴까

  • a = 2, b = 3: 3a + 2b = 12, 5ab = 30. 값이 같아지는 경우가 있어도 모든 값에서 같아야 식이 같은 거예요.
  • 3a² + 2a도 동류항이 아니에요(차수가 다름).
  • 사과 3개 + 배 2개 = 과일 5개이지 '사과배 5개'가 아니에요.

움직여 보기

타일로 보는 3a + 2b와 5ab

3a + 2b 5ab 같은가? 3a + 2a = 5a

파란 a 막대와 초록 b 막대는 길이가 달라 '같은 막대 5개'로 셀 수 없어요. 5ab는 길이가 아니라 넓이(직사각형)라 아예 다른 양이에요. a = 2, b = 3이면 12와 30. a = b = 1일 때만 우연히 같아지는지 확인해 보세요. 맨 아래처럼 같은 a 막대끼리는 3개 + 2개 = 5개로 합칠 수 있어요.

2. 자주 하는 오해 바로잡기

· "문자가 있으면 다 합친다" → 문자와 차수가 똑같아야 해요.

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

4x + 3y − x + 5y를 간단히 하면?

(4 − 1)x + (3 + 5)y = 3x + 8y. 더는 못 줄임.

2a² + 3a + a² − a를 간단히 하면?

3a² + 2a(a²과 a는 다른 동류항).
