이차방정식 실험실 — 판별식의 부호가 실근의 개수

ax² + bx + c의 계수를 바꿔 포물선을 그리고 x축과 만나는 횟수를 b² − 4ac의 부호와 대조했습니다. 판별식이 양수면 2번, 0이면 1번(접함), 음수면 만나지 않아 예외가 없었고, 근이 없는 경우는 그래프가 x축 위(또는 아래)에만 있는 것이었습니다. 판별식과 그래프의 관계를 정리합니다.

x² + x + 1−3−0실근 없음
−x² + 4x − 5−4−0실근 없음 (x축 아래)

근의 공식 x = (−b ± √(b² − 4ac))/2a에서 √ 안이 양수면 서로 다른 두 실근, 0이면 중근, 음수면 실근 없음. D = 0이면 완전제곱식이라 x축에 접하고, a > 0·D < 0이면 포물선이 x축 위에 떠 있습니다(y > 0 항상). 실수 범위에서는 0·1·2개, 복소수까지 넓히면 항상 2개.

개념 정리

1. 판별식 b² − 4ac의 부호가 실근의 개수를 정해요

근의 공식 x = (−b ± √(b² − 4ac))/2a에서 √ 안이 양수면 서로 다른 두 실근, 0이면 중근(1개), 음수면 실근 없음이에요. 그래프로는 포물선이 x축과 2번, 1번(접함), 0번 만나는 것이에요. 근이 없다고 방정식이 틀린 게 아니라 그래프가 x축 위(또는 아래)에만 있는 거예요.

왜 그럴까

  • x² − 5x + 6: D = 25 − 24 = 1 > 0 → 2, 3. x² − 2x + 1: D = 0 → 1(중근). x² + x + 1: D = −3 → 없음.
  • a > 0이고 D < 0이면 포물선이 x축 위에 떠 있어요(y > 0 항상).
  • D = 0이면 완전제곱식이라 x축에 접해요.

2. 자주 하는 오해 바로잡기

· "이차방정식은 항상 근이 두 개" → 실수 범위에서는 0·1·2개. 복소수까지 넓히면 항상 2개.

3. 생활 속에서 · 이어지는 개념

  • 공이 특정 높이에 도달하는지(근 있음/없음), 두 곡선이 만나는지 판정에 판별식을 써요.
D = b² − 4ac 부호 → 예측한 교점 수와 실제 그래프 교점 수 대조
📋 데이터 확인 탭의 결론

“b² − 4ac가 양수면 2번, 0이면 1번, 음수면 만나지 않았다. 예외는 없었다.”

예제

x² + kx + 9 = 0이 중근을 가질 k는?

k² − 36 = 0 → k = ±6.

2x² − 3x + 5 = 0의 실근의 개수는?

D = 9 − 40 = −31 < 0 → 0개.
