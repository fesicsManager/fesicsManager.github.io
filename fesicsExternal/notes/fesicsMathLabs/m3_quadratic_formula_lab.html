근의 공식 실험실 — 공식으로 구한 값은 정말 해

ax² + bx + c = 0의 계수를 바꾸며 근의 공식으로 두 근을 구해 원래 식에 대입하고 √ 안(판별식)이 완전제곱수인지, 인수분해로 풀리는지 확인했습니다. 공식으로 구한 값을 넣으면 언제나 0이 되었고, 판별식이 완전제곱수면 근이 유리수라 인수분해로도 풀렸지만 아니면 무리수 근이었습니다. 근의 공식의 뜻을 정리합니다.

공식은 ax² + bx + c = 0을 완전제곱으로 고쳐 x를 푼 결과라 모든 이차방정식에 통합니다. 인수분해가 안 되면 근이 없는 것이 아니라 무리수 근이 있으며 그때 공식이 유일한 길. 2a로 나누는 것을 잊거나 −b의 부호를 놓치는 실수가 흔합니다.

개념 정리

1. 근의 공식 x = (−b ± √(b² − 4ac)) / 2a

공식으로 구한 두 값을 원식에 대입하면 정확히 0이 돼요. 공식은 ax² + bx + c = 0을 완전제곱으로 고쳐 x를 푼 결과라 모든 이차방정식에 통해요. √ 안(판별식)이 완전제곱수면 근이 유리수라 인수분해로도 풀리고, 아니면 무리수 근이라 인수분해가 안 돼요 — 그때 공식이 유일한 길이에요. D < 0이면 실근이 없어요.

왜 그럴까

  • x² − 5x + 6: D = 1 → x = (5 ± 1)/2 = 3, 2. 인수분해 (x − 2)(x − 3) ✓.
  • x² − 2x − 1: D = 8 → x = 1 ± √2. 인수분해 불가.
  • 2a로 나누는 것을 잊거나 −b의 부호를 놓치는 실수가 흔해요.

판별식 b² − 4ac 두 근 대입한 값 √ 안이 완전제곱수?

a, b, c를 바꿔 보세요. 공식으로 구한 근(빨간 점)은 언제나 그래프가 x축과 만나는 곳이라 대입하면 0이 돼요. 판별식이 1, 25처럼 완전제곱수면 근이 유리수(인수분해 가능), 17, 8처럼 아니면 무리수예요. 판별식이 음수면 x축과 만나지 않아 실근이 없어요.

2. 자주 하는 오해 바로잡기

· "인수분해가 안 되면 근이 없다" → 무리수 근이 있어요. 공식으로 구해요.

예제

x² − 4x + 1 = 0을 풀고 검산하시오.

x = (4 ± √12)/2 = 2 ± √3. 검산: (2 + √3)² − 4(2 + √3) + 1 = 7 + 4√3 − 8 − 4√3 + 1 = 0 ✓.

황금비 x² − x − 1 = 0의 양의 근은?

(1 + √5)/2 ≈ 1.618.
