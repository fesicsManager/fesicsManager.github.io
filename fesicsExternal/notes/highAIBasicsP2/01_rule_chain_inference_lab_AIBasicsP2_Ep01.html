고등 인공지능 기초 ② · 웹툰 1화 「규칙만 많으면 전문가가 되는가」

지식 표현과 추론 — 규칙을 잇는 힘은 틀린 결론도 잇는다

동물 박사 규칙 12개에 동물 사실을 넣고 추론 방향(전향 · 후향)과 규칙 목록(기본 · 예외를 붙인 목록)을 바꾸며 결론 수, 틀린 결론, 살펴본 규칙 수를 기록했습니다. 펭귄의 사실 3개에서 전향 추론은 목록에 직접 없는 ‘펭귄 후보’를 끌어냈지만 ‘날 수 있음’, ‘높은 나무에 둥지’라는 틀린 결론도 함께 냈고, 예외 조건을 붙이자 틀린 결론이 사라졌습니다. 지식 표현·추론 엔진과 지식 획득의 병목을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 입력할 동물 사실(펭귄 · 참새 · 오리너구리 · 개), 추론 방향(전향 추론: 사실 → 결론 · 후향 추론: 목표 ‘날 수 있음?’ → 사실), 규칙 목록(기본 규칙 12개 · 예외 조건 2개를 붙인 규칙)을 고른 뒤 추론 엔진 돌리기를 누르면 사실에서 결론까지의 사슬이 단계별로 그려지고, 기록표에 결론 수·틀린 결론 수·살펴본 규칙 수가 남습니다. 펭귄을 기본 규칙과 예외 규칙으로 각각 돌리고 오리너구리도 같은 비교를 한 뒤, 후향 추론으로 ‘날 수 있음?’을 물어 살펴본 규칙 수를 확인해 보세요. 규칙과 사실은 학습용 가상 예시입니다.

지식을 사실(‘깃털이 있다’)과 규칙(‘깃털이 있으면 새다’)으로 적는 것이 지식 표현이고, 규칙을 차례로 적용해 결론을 끌어내는 부분이 추론 엔진입니다. 펭귄의 사실 3개에서 엔진은 새 → 물새 → 펭귄 후보로 사슬을 이어 목록에 직접 적히지 않은 결론을 냈어요. 규칙 하나하나는 사람이 썼지만 잇는 건 기계입니다. 그런데 같은 힘으로 ‘새이면 난다’가 발동해 ‘날 수 있음’, ‘높은 나무에 둥지’라는 틀린 결론도 이어졌습니다. ‘단, 펭귄 후보는 제외’ 같은 예외를 붙이자 틀린 결론은 사라졌지만, 타조·키위·박쥐까지 다루려면 예외의 예외가 끝없이 늘어납니다. 이것이 지식 획득의 병목이에요. 후향 추론은 목표에 필요한 규칙만 살펴봐(2~4개) 전향(3~6개 발동)보다 적은 규칙으로 답했습니다.

개념 정리

1. 지식 표현과 추론

지식을 기계가 다룰 수 있게 사실("깃털이 있다")과 규칙("깃털이 있으면 새다")으로 적는 것을 지식 표현이라 합니다. 규칙을 차례로 적용해 결론을 끌어내는 부분이 추론 엔진이에요.

  • 전향 추론: 사실에서 출발해, 조건이 맞는 규칙을 모두 발동하고 새로 생긴 결론으로 또 발동합니다.
  • 후향 추론: "이 동물은 날 수 있는가?" 같은 목표에서 출발해, 그 결론을 내는 규칙의 조건을 거꾸로 확인해 갑니다. 필요한 규칙만 살펴봐요.
  • 규칙 하나하나는 사람이 썼지만 잇는 건 기계가 합니다. 그래서 목록에 직접 없는 결론("펭귄 후보")이 나와요. 같은 힘 때문에 틀린 결론("펭귄은 난다")도 함께 이어집니다.

2. 예외와 지식 획득의 병목

"새이면 난다"에 "단, 펭귄 후보는 제외"를 붙이면 틀린 결론은 사라지지만, 타조·키위… 예외의 예외까지 적다 보면 규칙이 끝없이 늘어납니다. 자전거 타는 법처럼 말로 다 꺼낼 수 없는 지식도 많아요. 이 병목 때문에 데이터에서 규칙을 찾는 학습 기반 방법이 커졌습니다.

3. 실험 모형과 실제의 차이

· 1970년대에는 이런 방식으로 수백 개 규칙을 담은 의료 상담용 전문가 시스템이 만들어지기도 했습니다.

· 규칙 기반은 결론이 어떤 규칙을 거쳤는지 그대로 보여 줄 수 있어, 세금 계산·법규 확인처럼 근거를 밝혀야 하는 곳에서 지금도 쓰입니다.

전향 추론: 사실 → 조건이 맞는 규칙을 모두 발동 → 새 결론으로 다시 발동 · 후향 추론: 목표 ← 그 결론을 내는 규칙의 조건을 거꾸로 확인 · 예외 규칙: 조건 ∧ (예외가 아님) → 결론

모형: 규칙 R1~R12 · 예외 = R6 ‘새 → 날 수 있음’에 ‘단, 펭귄 후보 제외’, R8 ‘포유류 → 새끼를 낳음’에 ‘단, 오리너구리 후보 제외’

예제

펭귄의 사실(깃털 있음 · 알을 낳음 · 헤엄침)에 기본 규칙으로 전향 추론을 하면 단계마다 어떤 결론이 나오나요?

1단계: R1(깃털 → 새)로 ‘새’. 2단계: R4(새 ∧ 헤엄 → 물새), R6(새 → 날 수 있음), R12(새 ∧ 알 → 알을 품음). 3단계: R5(물새 ∧ 알 → 펭귄 후보), R7(날 수 있음 → 높은 나무에 둥지). 모두 6개 규칙이 3단계에 걸쳐 발동했어요. 새 → 물새·날 수 있음·알을 품음 → 펭귄 후보·높은 나무에 둥지

예외를 붙인 규칙(R6: 새 ∧ 펭귄 후보가 아님 → 날 수 있음)으로 펭귄에게 후향 추론 ‘날 수 있음?’을 물으면 어떤 순서로 확인하나요?

‘날 수 있음’을 내는 R6에서 출발해 조건 ‘새’를 R1로 확인(깃털 있음 → 예)하고, 예외 ‘펭귄 후보’를 R5 → R4로 거꾸로 확인합니다(물새 ← 새 ∧ 헤엄 → 예, 알을 낳음 → 예). 펭귄 후보가 참이므로 R6은 발동하지 않아요. 살펴본 규칙은 R6·R1·R5·R4 4개입니다. 아니오 (규칙 4개 확인)
