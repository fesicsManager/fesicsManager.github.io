유전자 발현 조절: 젖당 오페론 — 필요할 때만 켜지는 스위치

실험에서 대장균을 젖당·포도당 있음/없음 네 가지 배지에서 배양하며 젖당 분해 효소의 양을 쟀습니다. 야생형은 젖당만 있을 때 100, 젖당과 포도당이 모두 있으면 5, 젖당이 없으면 2 이하였습니다. 조절 유전자나 작동 부위가 고장 난 돌연변이는 젖당이 없어도 100(포도당 있으면 5)을 만들었고, 구조 유전자가 고장 나면 어떤 조건에서도 0이었습니다. 오페론의 구성, 억제 단백질과 포도당 효과, 진핵생물과의 차이를 정리합니다.

두 스위치가 함께 작동합니다. 젖당은 억제 단백질을 떼어 내 길을 열고(2 → 100), 포도당은 있으면 활성화를 막아 발현을 1/20로 낮춥니다(100 → 5). 조절 유전자·작동 부위 돌연변이는 젖당 스위치만 고장 낸 것이라 포도당 효과는 그대로 남습니다.

개념 정리

1. 젖당 오페론 (웹툰 10화)

대장균은 젖당 분해 효소를 늘 만들지 않고 젖당이 있을 때만 관련 유전자를 켜 에너지 낭비를 막습니다. 오페론은 프로모터(RNA 중합 효소가 붙는 자리), 작동 부위(억제 단백질이 붙는 자리), 젖당 분해에 필요한 구조 유전자 3개가 나란히 있고, 따로 떨어진 조절 유전자가 억제 단백질을 만듭니다. 젖당이 없을 때: 억제 단백질이 작동 부위에 붙어 RNA 중합 효소의 길을 막음 → 전사 안 됨. 젖당이 있을 때: 젖당(에서 바뀐 물질)이 억제 단백질에 붙어 모양을 바꾸면 작동 부위에서 떨어짐 → 효소 유전자 세 개를 한꺼번에 전사. 예측 게임 ⑩ ‘포도당은 없고 젖당만 있으면 전사될까?’ 뭉치 ‘안 된다’, 제로 ‘젖당이 억제 단백질을 떼어 내니 된다’ — 효소 양이 늘어 제로 승 5 : 5. 포도당이 있을 때는 가장 쉬운 먹이인 포도당을 먼저 쓰느라 오페론이 거의 켜지지 않습니다.

2. 돌연변이로 읽는 조절 논리

조절 유전자가 고장 나 억제 단백질을 못 만들거나, 작동 부위가 고장 나 억제 단백질이 못 붙으면 젖당이 없어도 효소가 계속 만들어집니다(실험 100) — 스위치가 ‘켜짐’에 고정된 셈이라 젖당이 없을 때는 에너지를 낭비합니다. 구조 유전자가 고장 나면 전사가 되어도 효소가 없어 젖당 배지에서 천천히 자랍니다. 자코브와 모노는 바로 이런 돌연변이 대장균들을 비교해 1961년 오페론 모델을 세웠습니다. 실험에서 ‘젖당 +, 포도당 +’일 때 5로 낮은 것은 포도당이 있으면 활성화 단백질(cAMP–CAP)이 프로모터를 돕지 못하기 때문이며, 대장균은 포도당을 다 쓴 뒤에야 젖당으로 갈아타 성장 곡선에 잠시 멈칫하는 구간(2단 성장)이 생깁니다.

3. 진핵생물은 무엇이 다를까

원핵생물은 관련 유전자 여러 개를 한 스위치(오페론)로 함께 조절하지만, 진핵생물은 유전자마다 따로 조절하고 여러 전사 인자가 조절 부위에 붙어야 전사가 시작되며 멀리 떨어진 조절 부위와 염색질이 풀리고 감긴 정도도 영향을 줍니다(전등 스위치 하나 vs 여러 사람이 동시에 눌러야 열리는 금고). 이 정교한 조절이 같은 유전체로 근육·신경·간 세포를 만들어 내는 세포 분화의 바탕입니다(11화). 실험 모형의 0.02·0.05 계수는 실제 대장균의 기저 발현(약 1/1 000)과 포도당 억제 정도를 단순화한 값입니다.

효소량 ∝ (억제 단백질 결합 여부: 붙음 0.02 / 떨어짐 1) × (포도당: 없음 1 / 있음 0.05)  ·  젖당 → 억제 단백질 떨어짐  ·  포도당 없음 → 활성화 단백질 작동

야생형: 2 / 0 / 100 / 5 · 조절 유전자·작동 부위 고장: 100 / 5 / 100 / 5 · 구조 유전자 고장: 0

예제

어떤 대장균이 젖당이 없는 배지에서도 효소를 100 만들었지만 포도당을 넣자 5로 줄었다. 어디가 고장 났는가?

젖당 스위치가 고장 나 항상 켜져 있으므로 조절 유전자(억제 단백질 못 만듦) 또는 작동 부위(억제 단백질이 못 붙음) 돌연변이. 포도당 효과는 남아 있으므로 프로모터·활성화 체계는 정상입니다. 둘을 구별하려면 정상 조절 유전자를 플라스미드로 넣어 보면 됩니다 — 조절 유전자 고장은 회복되고, 작동 부위 고장은 회복되지 않습니다.

젖당 + 포도당 배지에서 대장균의 성장 곡선이 두 단으로 나타나는 까닭을 실험 결과로 설명하시오.

포도당이 있는 동안은 효소량 5로 낮아 포도당만 쓰고, 포도당이 떨어지면 억제가 풀려 효소량 100으로 올라가기까지 잠시 성장이 멈췄다가 젖당으로 다시 자랍니다.
