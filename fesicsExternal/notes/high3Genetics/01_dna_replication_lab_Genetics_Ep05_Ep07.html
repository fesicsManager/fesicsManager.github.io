DNA 구조와 반보존적 복제 — 샤가프와 메셀슨·스탈

실험에서 사람·소·밀·대장균·효모·파지 φX174의 염기 조성을 비교해 이중 나선 DNA에서는 A ≈ T, G ≈ C(사람 A 30.9·T 29.4, G 19.9·C 19.8 %)이지만 단일 가닥 파지에서는 A 24.6·T 32.7 %로 규칙이 깨지는 것을 확인했습니다. 이어 ¹⁵N 대장균을 ¹⁴N 배지로 옮겨 0~3세대의 DNA 띠를 추적하니 1세대 중간 띠 100 %, 2세대 중간 : 가벼움 = 1 : 1, 3세대 1 : 3이었습니다. 유전물질 규명의 과학사, 이중 나선, 반보존적 복제를 정리합니다.

실험 데이터 되짚기

모형: 반보존적 복제에서 g세대 DNA 분자 2^g개 중 ¹⁵N–¹⁴N 혼성(중간 띠)은 항상 2개, 나머지는 ¹⁴N–¹⁴N(가벼운 띠). 염기 조성은 실제 측정값(%).

개념 정리

1. 유전물질을 찾아서 (웹툰 5화)

1928년 그리피스는 열로 죽인 병원성 세균이 살아 있는 비병원성 세균을 병원성으로 바꾸는 형질 전환을 발견했고, 1944년 에이버리는 추출물을 단백질·RNA·DNA 분해 효소로 각각 처리해 DNA 분해 효소로 처리했을 때만 형질 전환이 안 일어남을 보였습니다. 1952년 허시와 체이스는 파지의 단백질 껍질을 ³⁵S, DNA를 ³²P로 표지해 감염시킨 뒤 원심 분리하니 세균 침전물에서 ³²P가 검출되어 DNA만 세균 안으로 들어가 새 바이러스를 만들었음을 확인했습니다(예측 게임 ⑤, 뭉치 승 2 : 3). 샤가프는 여러 생물에서 A = T, G = C임을 발견했고(실험 표 1), 프랭클린의 X선 회절 사진을 바탕으로 1953년 왓슨·크릭이 이중 나선 모형을 제안했습니다. 상보적 염기쌍(A–T 2개, G–C 3개의 수소 결합)은 복제 방식까지 암시했습니다. 단일 가닥 파지 φX174는 짝이 없으므로 샤가프 규칙이 성립하지 않습니다.

2. 반은 새것, 반은 헌것 (웹툰 7화)

보존적(원래 두 가닥 그대로 + 완전히 새 이중 나선), 반보존적(각 가닥이 주형, 새 분자마다 헌 가닥 하나 + 새 가닥 하나), 분산적(조각이 섞임) 세 가설 중 1958년 메셀슨과 스탈은 ¹⁵N 배지에서 기른 대장균을 ¹⁴N 배지로 옮겨 세대별 DNA를 밀도 기울기 원심 분리했습니다. 예측 게임 ⑦ ‘2세대의 띠는?’ 뭉치 ‘중간 : 가벼움 = 1 : 1’, 제로 ‘조금 더 가벼워진 중간 띠 하나(분산적)’ — 두 띠가 같은 양으로 나타나 뭉치 승 3 : 4. 원래 가닥을 주형으로 상보적 염기를 맞춰 붙이니 어미와 똑같은 DNA가 만들어져 유전 정보가 정확히 전달되고, DNA 중합 효소는 잘못 붙은 염기를 확인해 고치기도 합니다. 복제에는 두 가닥을 푸는 효소, 출발점이 되는 짧은 RNA 프라이머, DNA 중합 효소, 조각을 잇는 연결 효소가 관여합니다(용어 수준).

3. 모형과 실제

염기 조성의 A/T·G/C가 정확히 1이 아닌 것은 측정 오차이며, 생물마다 A + T 비율은 달라도(효모 64 %, 대장균 48 %) 쌍의 규칙은 같습니다. 실제 메셀슨·스탈 실험은 세슘 염화물 밀도 기울기에서 자외선으로 띠를 찍었고, 밀도 차는 0.014 g/cm³ 정도로 매우 작습니다. 사람 세포는 30억 염기쌍을 S기 몇 시간 안에 복제하기 위해 수천 곳의 복제 원점에서 동시에 시작합니다(세포 주기 실험). 브로콜리를 갈아 세제·소금·차가운 에탄올로 DNA를 눈으로 뽑아낼 수도 있습니다.

샤가프: A = T, G = C, (A + G) = (T + C)  ·  반보존적 복제 g세대: 총 2^g 분자, 혼성 2개, 가벼움 2^g − 2  ·  중간 띠 비율 = 2 ÷ 2^g

사람 A 30.9 T 29.4 G 19.9 C 19.8 % · φX174 A/T 0.75 (단일 가닥) · 1세대 중간 100 % · 2세대 1 : 1 · 3세대 1 : 3

예제

어떤 이중 나선 DNA에서 G가 22 %다. A, T, C의 비율은?

G = C = 22 % → G + C = 44 % → A + T = 56 % → A = T = 28 %, C = 22 %. 실험의 밀(G 22.7, A 27.3)과 비슷합니다.

¹⁵N 대장균을 ¹⁴N 배지로 옮겨 4세대 뒤 원심 분리하면 중간 띠와 가벼운 띠의 비는? 보존적 복제였다면?

총 16분자, 혼성 2개 → 중간 : 가벼움 = 2 : 14 = 1 : 7. 보존적이었다면 무거운 1 : 가벼운 15로 중간 띠가 전혀 없고, 분산적이면 점점 가벼워지는 띠 하나뿐입니다.
