고등학교 미적분Ⅰ · 실험 「구멍 실험실」

불연속의 종류 — 메울 수 있는 구멍과 없는 구멍

구멍형 (x² − 1)/(x − 1), 점프형(x < 1에서 x, x ≥ 1에서 x + 2), 무한형 1/(x − 1)에서 f(1)의 값을 바꾸며 좌·우극한과 함께 기록했습니다. 극한이 2로 존재하는 구멍형만 f(1) = 2로 고치면 이어졌고, 점프형과 무한형은 어떤 값을 넣어도 이을 수 없었습니다. 불연속의 종류와 제거 가능성을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 불연속의 종류(구멍형·점프형·무한형)를 고르고 f(1)의 값(−3~6)을 정해 ‘구멍을 메워 보기’를 누르면 좌극한, 우극한, f(1), 극한 존재, 메울 수 있는지가 기록됩니다. 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

구멍형은 좌·우극한이 모두 2라 극한이 존재하므로 f(1)을 극한값 2로 바꾸면 연속이 됩니다(제거 가능 불연속). 점프형은 좌극한 1, 우극한 3이 달라 f(1)에 1을 넣든 3을 넣든 한쪽이 어긋나고, 무한형은 극한 자체가 없습니다. 연속의 세 조건 중 ‘극한 존재’가 깨지면 함숫값만 고쳐서는 이을 수 없습니다.

개념 정리

1. 좌극한 = 우극한 일 때만 함숫값을 고쳐 연속으로 만들 수 있다

구멍형은 극한이 존재하는데 함숫값만 어긋난 경우라, f(1)을 극한값으로 고치면 연속이 됩니다. 점프형은 좌·우극한이 달라 어떤 값을 넣어도 이을 수 없고, 무한형은 극한 자체가 없습니다.

왜 그럴까

  • 연속의 세 조건: ①f(a)가 존재 ②극한이 존재 ③둘이 같다.
  • 구멍형은 ①③만 어긋나 고칠 수 있습니다(제거 가능 불연속).
  • 점프·무한형은 ②가 깨져 고칠 수 없습니다.

움직여 보기

구멍은 메울 수 있고, 점프·무한은 못 메운다

좌극한 우극한 f(1) 판정

빨간 점이 f(1)입니다. 구멍형에서 f(1)을 2로 옮기면 구멍이 메워져 연속이 됩니다. 점프형은 좌극한 1, 우극한 3이라 빨간 점을 어디에 두어도 한쪽이 끊기고, 무한형은 값이 위아래로 치솟아 극한이 없습니다. (보기 함수: 구멍형 x + 1, 점프형 x / x + 2, 무한형 1/(x − 1))

2. 자주 하는 오해 바로잡기

· “구멍이 하나뿐이면 연속으로 봐도 된다” → 종류에 따라 다릅니다.

3. 생활 속에서 · 이어지는 개념

  • 데이터의 결측값을 채워도 되는 경우와 채우면 안 되는 경우를 가르는 기준과 같습니다.
세 가지 불연속 함수에서 좌·우극한과 함숫값을 재고, f(1)을 바꿔 연속이 되는지 확인

예제

f(x) = (x² + x − 6)/(x − 2) (x ≠ 2), f(2) = k가 x = 2에서 연속이 되는 k를 구하시오.

x² + x − 6 = (x − 2)(x + 3)이므로 극한은 lim(x + 3) = 5입니다. 극한이 존재하므로 f(2) = 5로 정하면 연속입니다. k = 5

f(x) = x² (x < 1), 2x + a (x ≥ 1)가 x = 1에서 연속이 되는 a를 구하고, a = 1일 때 불연속의 종류를 말하시오.

좌극한 1, 우극한 = f(1) = 2 + a이므로 a = −1. a = 1이면 좌극한 1, 우극한 3으로 달라 점프형이며 함숫값을 고쳐서는 연속이 될 수 없습니다. a = −1, a = 1이면 점프형 불연속
