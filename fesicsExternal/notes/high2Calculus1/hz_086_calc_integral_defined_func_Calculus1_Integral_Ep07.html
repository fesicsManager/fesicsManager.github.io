고등학교 미적분Ⅰ · 실험 「적분 변수 실험실」

정적분으로 정의된 함수 — F(x) = ∫₀ˣ f(t)dt이면 F′(x) = f(x)

f(t) = 0.5t² − t + 1.5를 0부터 x까지 적분한 F(x)를 만들고, 위끝 x를 움직이며 F(x)와 수치 미분값 F′(x), f(x)를 기록했습니다. 모든 x에서 F′(x)와 f(x)가 일치했습니다. 적분 변수 t가 사라지고 결과가 x의 함수가 되는 까닭과 미적분의 기본정리를 정리합니다.

F(x) = x³/6 − x²/2 + 1.5x로 x만의 함수이고, 적분 변수 t는 결과에 남지 않습니다(더미 변수). x를 h만큼 늘리면 폭 h인 띠의 넓이 ≈ f(x)·h가 더해지므로 h로 나눠 h → 0이면 F′(x) = f(x)가 됩니다. 표의 F′(x) 수치값이 모두 f(x)와 같았던 이유입니다. 또 F(0) = 0처럼 위끝과 아래끝이 같으면 적분값은 0입니다.

개념 정리

1. ∫ₐˣ f(t)dt 에서 t 는 계산되며 사라지고, 결과는 x 의 함수

적분 변수 t 는 더해 나가는 과정에서 쓰이고 결과에는 남지 않아요. 위끝 x 만 남아 F(x) 가 x 의 함수가 됩니다. 그리고 이 F 를 미분하면 F′(x) = f(x) — 미적분의 기본정리입니다.

왜 그럴까

  • t는 “더미 변수”라 u로 바꿔 써도 결과가 같습니다.
  • F(x+h) − F(x) 는 폭 h 인 얇은 띠의 넓이 ≈ f(x)·h.
  • 양변을 h로 나눠 h→0 하면 F′(x) = f(x).

2. 자주 하는 오해 바로잡기

· “적분 변수와 바깥 변수는 같다” → t 는 사라지고 x 만 남습니다.

📋 데이터 확인 탭의 결론

“모든 기록에서 두 값이 일치했습니다. 이것이 미적분의 기본정리입니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

d/dx ∫₁ˣ (t³ − 2t) dt를 구하시오.

기본정리에 따라 t를 x로 바꾸면 됩니다. x³ − 2x

∫ₐˣ f(t) dt = x² − 3x + 2일 때, f(x)와 상수 a의 값을 구하시오.

양변을 미분하면 f(x) = 2x − 3. x = a를 넣으면 좌변 0이므로 a² − 3a + 2 = 0 → a = 1 또는 2. f(x) = 2x − 3, a = 1 또는 a = 2
