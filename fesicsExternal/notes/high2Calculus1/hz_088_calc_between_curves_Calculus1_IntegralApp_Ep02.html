고등학교 미적분Ⅰ · 실험 「위−아래 실험실」

두 곡선 사이의 넓이 — 반드시 (위 − 아래)로 적분한다

y = x + 2와 y = x²/2 사이를 구간을 바꾸며 (위 − 아래)와 (아래 − 위) 두 순서로 적분하고 실제 넓이와 비교했습니다. 순서를 바꾸면 부호만 반대가 되었고, 교점 x = 1 − √5가 구간에 들어오면 한 번에 적분한 값이 넓이보다 작아졌습니다. 두 곡선 사이 넓이의 공식을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 구간의 왼쪽 끝(−2 ~ 0.5)과 오른쪽 끝(0.75 ~ 3)을 0.25 단위로 바꾸고 ‘두 곡선 사이 재기’를 누르면 위 곡선, ∫(위 − 아래), ∫(아래 − 위), 넓이, 부호가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

두 곡선은 x²/2 = x + 2, 즉 x = 1 ± √5(≈ −1.24, 3.24)에서 만납니다. 그 사이에서는 y = x + 2가 위이므로 [−1, 3]처럼 교점이 없는 구간에서 ∫(위 − 아래)가 곧 넓이이고, 순서를 바꾸면 부호만 반대입니다. [−2, 3]에는 교점 x ≈ −1.24가 있어 위아래가 뒤바뀐 조각이 빼지므로 6.67 < 8.12가 되었습니다. 그래서 넓이는 교점에서 구간을 나눠 구간마다 ∫(위 − 아래)로 구합니다.

개념 정리

1. 두 곡선 사이의 넓이는 반드시 (위 − 아래) 로 적분한다

순서를 바꿔 (아래 − 위) 로 적분하면 값의 부호만 반대가 돼요. 넓이는 음수가 될 수 없으므로 위아래를 먼저 확인해야 합니다. 어느 쪽이 위인지는 구간에 따라 바뀔 수도 있습니다.

왜 그럴까

  • 넓이 = ∫(위 − 아래) dx — 높이가 항상 0 이상이어야 합니다.
  • 부호가 반대로 나왔다면 위아래를 바꿔 쓴 것입니다.
  • 두 곡선이 교차하면 구간을 나눠 각각 위아래를 다시 판단합니다.

보라색은 직선이 위인 조각, 주황색은 포물선이 위인 조각입니다. 왼쪽 끝이 교점 x = 1 − √5 ≈ −1.24보다 왼쪽으로 가면 주황 조각이 생겨 ∫(x+2 − x²/2)가 넓이보다 작아집니다. 표 1의 [−1, 3], [−2, 3], [−2, 0.75]를 맞춰 보세요.

2. 자주 하는 오해 바로잡기

· “순서 상관없이 빼면 된다” → 부호가 뒤집혀 넓이가 음수가 됩니다.

3. 생활 속에서 · 이어지는 개념

  • 두 값의 차이를 볼 때 기준을 정하지 않으면 부호가 뒤집힙니다.
구간을 바꿔 가며 두 곡선의 위아래를 확인하고, 두 순서로 각각 적분해 비교

예제

y = x²과 y = x + 2로 둘러싸인 부분의 넓이를 구하시오.

교점: x² = x + 2 → x = −1, 2. 그 사이에서 x + 2가 위. ∫₋₁² (x + 2 − x²) dx = [x²/2 + 2x − x³/3]₋₁² = 10/3 − (−7/6). 9/2

y = x²과 y = 2x로 둘러싸인 넓이를 구하시오. ∫₀² (x² − 2x) dx로 계산했다면 무엇이 잘못인가?

0 < x < 2에서 2x가 위이므로 ∫₀² (2x − x²) dx = 4 − 8/3 = 4/3. 순서를 바꾸면 −4/3으로 부호만 반대가 됩니다. 넓이 4/3
