미정계수 — 분모 → 0이면 분자도 → 0

분자 x² + ax + b의 계수 a, b를 바꾸며 x → 2일 때 (x² + ax + b)/(x − 2)의 극한이 존재하는지 기록했습니다. 분모가 0이 되는 x = 2에서 분자도 0인 경우(4 + 2a + b = 0)에만 극한이 존재했고, 그때 극한값은 4 + a였습니다. 미정계수를 정하는 원리를 정리합니다.

x = 2에서 분자가 0인 기록(4 + 2a + b = 0)만 극한이 존재했고, 분자가 2나 11처럼 0이 아니면 값이 무한대로 발산했습니다. 극한이 유한하고 분모 → 0이면 분자 = (분자/분모)×분모 → (유한)×0 = 0이어야 하므로 분자에 (x − 2)가 인수로 들어 있습니다. 약분하면 x² + ax + b = (x − 2)(x + 2 + a)이므로 극한값은 4 + a입니다.

개념 정리

1. 분모 → 0 인데 극한이 존재하면, 분자도 반드시 → 0 이어야 한다

분모가 0으로 가는데 분자가 0이 아닌 수로 가면 값이 무한대로 발산해요. 극한이 유한한 값으로 존재하려면 분자도 함께 0이 되어야 합니다. 그래야 공통인수가 생겨 약분되고, 남은 식에서 극한값이 나옵니다.

왜 그럴까

  • lim f/g 가 유한하고 g→0 이면 f = (f/g)·g → (유한)×0 = 0.
  • 그래서 분자에 (x−2) 가 인수로 들어 있어야 합니다.
  • 조건을 쓰면 a, b 에 대한 방정식이 생겨 미정계수를 정할 수 있습니다.

움직여 보기

분자도 0이 되어야 구멍 하나로 끝난다

x = 2에서 분자 4 + 2a + b 분모 0극한 왼쪽·오른쪽 값

a = 1, b = −6 이면 분자가 (x − 2)(x + 3)으로 약분되어 그래프는 직선 y = x + 3 에 구멍 하나 — 극한 5. b를 −5로 바꾸면 분자가 1이 되어 x = 2 근처에서 값이 위아래로 치솟습니다(발산). 분자가 0인 순간에만 극한이 4 + a 로 존재합니다.

2. 자주 하는 오해 바로잡기

· “분모가 0이 되면 극한은 없다” → 분자도 0이면 약분되어 존재할 수 있습니다.

3. 생활 속에서 · 이어지는 개념

  • 측정식에서 0/0 이 나오는 자리는 보통 정의를 다시 살펴야 하는 지점입니다.
분자의 계수 a, b를 바꿔 x=2 에서 분자·분모의 값을 확인하고, 극한이 존재하는지 판정

예제

lim(x→2) (x² + ax + b)/(x − 2) = 5일 때 상수 a, b를 구하시오.

분모 → 0이므로 분자 → 0: 4 + 2a + b = 0. 이때 분자 = (x − 2)(x + 2 + a)이므로 극한값 4 + a = 5 → a = 1, b = −6. a = 1, b = −6

lim(x→1) (x − 1)/(x² + ax + b) = 1/3일 때 상수 a, b를 구하시오.

분자 → 0이고 극한값이 0이 아니므로 분모도 → 0: 1 + a + b = 0. 분모 = (x − 1)(x + 1 + a)이므로 극한값 1/(2 + a) = 1/3 → a = 1, b = −2. a = 1, b = −2
