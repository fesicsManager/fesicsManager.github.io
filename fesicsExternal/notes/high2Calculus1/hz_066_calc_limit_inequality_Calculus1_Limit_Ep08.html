고등학교 미적분Ⅰ · 실험 「등호 실험실」

극한의 대소 관계 — <가 극한에서는 ≤가 된다

모든 양수 x에서 f(x) < g(x)인 두 함수 쌍을 골라 x를 키우며 f, g의 값과 극한을 기록했습니다. f = −1/x, g = 1/x 쌍은 늘 f < g였지만 두 극한이 모두 0으로 같아졌고, f = 1/x, g = 1 + 1/x 쌍은 극한에서도 0 < 1이 유지되었습니다. 극한의 대소 관계에서 등호가 붙는 까닭을 정리합니다.

실험 안내: 자유 탐구 탭에서 두 함수 쌍 중 하나를 고르고 x(1~200)를 정해 ‘두 함수를 따라가기’를 누르면 f(x), g(x), 대소 관계, 두 극한과 그 비교가 기록됩니다. 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

f = −1/x, g = 1/x에서는 x = 1, 10, 100, 200에서 늘 f < g였지만 간격 2/x가 2 → 0.2 → 0.02 → 0.01로 줄어 두 극한이 모두 0으로 같아졌습니다. 반면 g = 1 + 1/x이면 간격이 늘 1이라 lim f = 0 < 1 = lim g입니다. 그래서 정리는 ‘f(x) < g(x)이면 lim f ≤ lim g’로 등호를 포함해 씁니다. 샌드위치 정리도 이 성질에서 나옵니다.

개념 정리

1. f < g 라도 극한에서는 lim f ≤ lim g — 등호가 붙을 수 있다

모든 x 에서 f(x) < g(x) 여도 극한을 취하면 lim f ≤ lim g 까지만 보장돼요. −1/x < 1/x 는 모든 양수 x 에서 참이지만 둘 다 0으로 가서 극한은 같아집니다. 부등호가 “좁혀지며” 등호가 되는 것입니다.

왜 그럴까

  • 극한은 값이 아니라 “가까워지는 목표”라, 가까워지는 동안의 차이가 사라질 수 있습니다.
  • 그래서 정리에는 언제나 ≤ 로 적혀 있습니다.
  • 샌드위치 정리도 이 성질 위에서 작동합니다.

움직여 보기

늘 f < g 인데, 극한에서는 같아질 수 있다

f(x) g(x) 간격 g − f lim f, lim g

보라색 띠가 두 함수의 간격입니다. 첫 쌍은 간격 2/x 가 0으로 줄어들어 두 극한이 모두 0으로 같아지고, 둘째 쌍은 간격이 1 아래로 줄지 않아 0 < 1 로 남습니다. 그래서 극한에서는 lim f ≤ lim g 로 등호를 붙여 씁니다.

2. 자주 하는 오해 바로잡기

· “부등호가 < 이면 극한도 < 다” → 등호가 될 수 있습니다.

3. 생활 속에서 · 이어지는 개념

  • 두 측정값의 차이가 정밀도를 높일수록 사라지는 상황과 같습니다.
두 함수의 값을 x를 키우며 재고, 항상 f < g 인지와 극한이 같아지는지를 함께 확인
📋 데이터 확인 탭의 결론

“모든 기록에서 f < g 가 성립했습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

모든 양수 x에 대해 (2x − 1)/x < f(x) < (2x + 3)/x일 때 lim(x→∞) f(x)를 구하시오.

(2x − 1)/x = 2 − 1/x → 2, (2x + 3)/x = 2 + 3/x → 2이므로 샌드위치 정리에 의해 lim f(x) = 2. 2

모든 실수 x에서 3x² − 1 ≤ f(x)(x² + 1) ≤ 3x² + 5일 때 lim(x→∞) f(x)를 구하시오.

x² + 1 > 0으로 나누면 (3x² − 1)/(x² + 1) ≤ f(x) ≤ (3x² + 5)/(x² + 1)이고, 양 끝의 극한이 모두 3이므로 lim f(x) = 3. 3
