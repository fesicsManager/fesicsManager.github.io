고등학교 미적분Ⅰ · 실험 「y축 실험실」

y축 방향으로 적분하기 — 같은 영역이면 넓이도 같다

y = x²과 y = k로 둘러싸인 영역의 높이 k를 바꾸며 x로 적분한 값과 y로 적분한 값을 기록했습니다. 모든 k에서 두 값이 같았고, 넓이는 4k√k/3으로 커졌습니다. 곡선을 x = (y의 식)으로 바꿔 y로 적분하는 방법을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 자를 높이 k를 1 ~ 8 사이에서 0.5 단위로 바꾸고 ‘축을 바꿔 재기’를 누르면 영역, x로 적분한 값, y로 적분한 값, 일치 여부가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

x로 적분하면 세로 막대를 쌓아 ∫₋√ₖ^√ₖ (k − x²) dx, y로 적분하면 x = ±√y로 고쳐 가로 막대를 쌓아 ∫₀ᵏ 2√y dy입니다. 같은 영역을 다른 방향으로 자른 것이라 값이 같고, k = 4이면 둘 다 32/3 ≈ 10.67이었습니다. 곡선이 x = g(y)의 꼴로 주어지거나 영역이 y축 쪽으로 단순할 때는 y 적분이 훨씬 간단합니다.

개념 정리

1. 같은 영역이면 어느 축으로 적분해도 넓이는 같다

y = x² 과 y = k 로 둘러싸인 영역은 x 로 적분해도 되고 y 로 적분해도 돼요. y로 적분하려면 x = √y 로 고쳐 가로 방향의 길이를 더합니다. 문제에 따라 한쪽이 훨씬 간단해집니다.

왜 그럴까

  • x로 적분: 세로 막대를 가로로 쌓기. y로 적분: 가로 막대를 세로로 쌓기.
  • x = f(y) 로 고칠 수 있으면 y 적분이 가능합니다.
  • 역함수의 넓이 관계도 같은 아이디어에서 나옵니다.

2. 자주 하는 오해 바로잡기

· “y축 방향으로는 적분할 수 없다” → 식을 x = 로 고치면 됩니다.

3. 생활 속에서 · 이어지는 개념

  • 같은 부피를 가로로 자르든 세로로 자르든 결과가 같은 것과 같습니다.

예제

곡선 x = y²과 y축, 직선 y = 2로 둘러싸인 부분의 넓이를 구하시오.

가로 길이는 y² − 0이므로 y로 적분합니다. ∫₀² y² dy = [y³/3]₀². 8/3

곡선 x = y² − 2y와 y축으로 둘러싸인 부분의 넓이를 구하시오.

y축과의 교점: y² − 2y = 0 → y = 0, 2. 0 < y < 2에서 x < 0이므로 오른쪽(y축) − 왼쪽(곡선): ∫₀² (2y − y²) dy = 4 − 8/3. 4/3
