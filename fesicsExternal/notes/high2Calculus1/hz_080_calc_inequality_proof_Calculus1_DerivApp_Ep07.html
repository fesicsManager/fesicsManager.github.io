부등식의 증명 — 최솟값이 0 이상임을 보이면 끝

−2 ≤ x ≤ 2에서 f(x) = x³ − 3x + k ≥ 0이 참인지, 상수 k와 찍어 볼 점의 개수를 바꾸며 찍은 값들과 실제 최솟값을 기록했습니다. 최솟값은 언제나 k − 2였고, k ≥ 2일 때만 부등식이 성립했습니다. k = 1에서 점을 3개만 찍으면 찍은 값은 모두 0 이상인데도 부등식은 거짓이었습니다. 값 몇 개를 넣어 보는 것과 최솟값으로 증명하는 것의 차이를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 우변의 상수 k(−6 ~ 8)와 찍어 볼 점의 개수(2 ~ 10, x = −1.8 ~ 1.8에 고르게)를 바꾸고 ‘최솟값을 찾아보기’를 누르면 찍은 값이 모두 0 이상인지, 실제 최솟값과 부등식 성립 여부가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

f′(x) = 3x² − 3 = 0 → x = ±1. 구간 [−2, 2]에서 후보는 f(−2) = k − 2, f(−1) = k + 2, f(1) = k − 2, f(2) = k + 2이므로 최솟값은 k − 2(x = 1과 x = −2)이고, k ≥ 2일 때만 부등식이 성립합니다. k = 1, 점 3개(x = −1.8, 0, 1.8)에서는 찍은 값이 0.57, 1, 1.43으로 모두 0 이상이었지만 실제 최솟값은 −1이었습니다 — 음수 구간이 점 사이(x = 1 근처)에 숨어 있었던 것입니다. 점을 6개로 늘리자 x = 0.36에서 −0.03이 나와 반례가 잡혔습니다. 찍어 본 점은 반례를 찾는 데는 유효하지만, 점 사이를 보장하지 못하므로 증명은 최솟값 ≥ 0으로 해야 합니다. 정의역을 모든 실수로 넓히면 x → −∞에서 f → −∞라 어떤 k에서도 성립하지 않으므로, 정의역을 먼저 정해야 합니다.

개념 정리

1. “항상 성립”은 최솟값이 0 이상임을 보여야 증명된다

이 실험은 −2 ≤ x ≤ 2 에서 x³ − 3x + k ≥ 0 이 참인지 봅니다. 그러려면 그 구간에서 f(x) = x³ − 3x + k 의 최솟값을 구해 0 이상인지 확인해요. 값을 몇 개 넣어 보는 것은 반례를 찾는 데는 쓸 수 있어도 증명이 되지는 않습니다.

정의역을 모든 실수로 넓히면 삼차함수는 x → −∞ 에서 −∞ 로 가므로 어떤 k 에서도 성립하지 않습니다. 부등식 증명에서 정의역을 먼저 못 박는 이유입니다.

왜 그럴까

  • 정해진 구간에서 최솟값이 0 이상이면 그 구간의 모든 x 에서 f(x) ≥ 0 입니다.
  • 최솟값은 f′ = 0 인 점과 구간의 끝에서 찾습니다.
  • 값을 넣어 보다가 음수가 나오면 그 하나가 반례가 되어 즉시 반박됩니다.

2. 자주 하는 오해 바로잡기

· “몇 개 넣어 보면 확인된다” → 반례를 못 찾았을 뿐일 수 있습니다.

3. 생활 속에서 · 이어지는 개념

  • 테스트 몇 번 통과했다고 버그가 없다고 할 수 없는 것과 같습니다.
상수 k를 바꿔 여러 점을 찍어 보고, 실제 최솟값과 비교해 판정이 갈리는지 확인

예제

x ≥ 0일 때 부등식 x³ − 3x + 2 ≥ 0이 성립함을 보이시오.

f(x) = x³ − 3x + 2, f′(x) = 3(x − 1)(x + 1). x ≥ 0에서 x = 1에서 극소이자 최소, f(1) = 0. 끝값 f(0) = 2. 최솟값이 0이므로 f(x) ≥ 0 (등호는 x = 1)

0 ≤ x ≤ 3에서 x³ − 3x² + k ≥ 0이 항상 성립하도록 하는 k의 최솟값을 구하시오.

f′(x) = 3x(x − 2). 후보 f(0) = k, f(2) = k − 4, f(3) = k. 최솟값 k − 4 ≥ 0 → k ≥ 4. k의 최솟값 4
