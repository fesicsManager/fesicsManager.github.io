극값의 판정 — f′ = 0에 부호 변화까지

y = x³, x², x⁴는 모두 x = 0에서 f′ = 0입니다. 원점에서 좌우로 h만큼 떨어진 곳의 기울기를 재어 기록했더니 x²과 x⁴는 − → +로 부호가 바뀌어 극소였지만, x³은 양쪽 모두 +여서 극값이 아니었습니다. f′의 부호 변화로 극값을 판정하는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 함수(x³·x²·x⁴)와 좌우로 떨어진 거리 h(×0.01)를 정하고 ‘좌우 기울기 재기’를 누르면 x = 0 좌우의 f′ 값, 부호 변화, 극값 판정이 기록됩니다. 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

x³의 기울기는 좌우 모두 3h²(h = 0.2에서 0.12)로 부호가 바뀌지 않아 원점을 지나며 계속 증가하므로 극값이 아닙니다. x²(∓2h)과 x⁴(∓4h³)는 왼쪽 −, 오른쪽 +로 바뀌어 극소입니다. 따라서 f′(a) = 0은 필요조건일 뿐이며 + → −이면 극대, − → +이면 극소, 부호 변화가 없으면 극값이 아닙니다. x⁴는 f″(0) = 0이라 이계도함수로 판정할 수 없어 부호 변화를 봐야 합니다.

개념 정리

1. f′(a) = 0 은 극값의 필요조건일 뿐 — 좌우에서 부호가 바뀌어야 극값

y = x³ 은 원점에서 f′ = 0 이지만 좌우 모두 f′ > 0 이라 계속 증가해요. 극값이 아닙니다. 극값이 되려면 f′ 의 부호가 +에서 −로(극대) 또는 −에서 +로(극소) 바뀌어야 합니다.

왜 그럴까

  • f′ > 0 이면 증가, f′ < 0 이면 감소 — 부호가 바뀌는 곳에서 방향이 꺾입니다.
  • x³ 처럼 부호가 안 바뀌면 잠깐 평평해질 뿐 계속 같은 방향으로 갑니다.
  • f″ 의 부호로도 판정할 수 있지만 f″ = 0 이면 다시 부호 변화를 봐야 합니다.

2. 자주 하는 오해 바로잡기

· “f′(a) = 0 인 점만 확인하면 된다” → 좌우 부호까지 봐야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 속도가 순간적으로 0 이어도 방향이 바뀌지 않으면 계속 같은 쪽으로 갑니다.
세 함수에서 f′ = 0 인 점의 좌우 기울기를 수치로 재어 부호 변화를 확인

예제

f(x) = x³ − 3x의 극값을 구하시오.

f′(x) = 3(x + 1)(x − 1). x = −1에서 + → −이므로 극댓값 f(−1) = 2, x = 1에서 − → +이므로 극솟값 f(1) = −2. 극댓값 2 (x = −1), 극솟값 −2 (x = 1)

f(x) = x⁴ − 4x³의 극값을 조사하시오.

f′(x) = 4x²(x − 3). x = 0의 좌우에서 f′는 모두 −라 극값이 아니고, x = 3에서 − → +이므로 극솟값 f(3) = 81 − 108 = −27. x = 0은 극값 아님, 극솟값 −27 (x = 3)
