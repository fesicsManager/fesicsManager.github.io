불연속 함수의 합과 곱 — 상쇄되면 이어진다

x = 1에서 끊긴 조각함수 f, g를 세 가지로 짝지어 1의 좌우 값을 재고 f + g, f·g의 연속 여부를 기록했습니다. 점프가 서로 반대인 쌍은 합과 곱이 모두 이어졌지만, 같은 방향으로 점프하거나 연속함수에 불연속함수를 더한 경우는 끊긴 채였습니다. 불연속 함수의 합·곱에 대한 규칙을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 두 함수의 조합(서로 반대로 점프·같은 방향 점프·하나만 불연속)과 1에서 떨어진 거리(×0.01)를 정하고 ‘더하고 곱해 보기’를 누르면 f, g, f + g, f·g의 연속 여부가 기록됩니다. 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

표 1. x = 1 − h / 1 + h에서의 값과 연속 판정 (실험 예시)
조합hf (좌 / 우)g (좌 / 우)f + g (좌 / 우)f·g (좌 / 우)f + g 연속f·g 연속
반대 점프 (f: 0 → 2, g: 2 → 0)0.20 / 22 / 02 / 20 / 0○○
같은 방향 점프 (f: 0 → 2, g: 0 → 1)0.20 / 20 / 10 / 30 / 2××
하나만 불연속 (f = x, g: 0 → 2)0.20.8 / 1.20 / 20.8 / 3.20 / 2.4××
하나만 불연속 (f = x, g: 0 → 2)0.010.99 / 1.010 / 20.99 / 3.010 / 2.02××

반대 점프 쌍은 f가 0 → 2로 오르고 g가 2 → 0으로 내려가 f + g = 2, f·g = 0으로 상수가 되어 이어졌습니다. 같은 방향 점프는 합이 0 → 3으로 더 크게 뛰었습니다. f = x처럼 연속인 함수에 불연속인 g를 더하면 h를 0.01로 줄여도 f의 간격은 0으로 줄지만 합의 간격은 약 2로 남아 연속 + 불연속 = 항상 불연속입니다. f + g가 연속이면 g = (f + g) − f도 연속이 되어 모순이기 때문입니다.

개념 정리

1. 불연속 + 불연속이 연속이 될 수 있다 — 하지만 연속 + 불연속은 반드시 불연속

두 함수가 각각 1에서 끊겨 있어도, 점프의 크기가 서로 반대면 합에서 상쇄되어 연속이 될 수 있어요. 반대로 연속인 함수 + 불연속인 함수는 언제나 불연속입니다 — 상쇄해 줄 상대가 없기 때문입니다.

왜 그럴까

  • 연속의 성질은 “연속 + 연속 = 연속”만 보증합니다.
  • 불연속끼리는 결과가 어떻게 될지 정해져 있지 않아 직접 확인해야 합니다.
  • f 연속, g 불연속인데 f+g 가 연속이면 g = (f+g) − f 가 연속이 되어 모순입니다.

2. 자주 하는 오해 바로잡기

· “두 함수가 불연속이면 합도 불연속이다” → 상쇄되면 연속이 됩니다.

3. 생활 속에서 · 이어지는 개념

  • 두 오차가 서로 반대 방향이면 합쳤을 때 사라지는 것과 같습니다.
세 가지 조합에서 1의 좌우 값을 재어 f, g, f+g, f·g 의 연속 여부를 각각 판정

예제

f(x) = x + 1 (x < 1), x − 1 (x ≥ 1), g(x) = x + a (x < 1), 2x (x ≥ 1)일 때 f + g가 x = 1에서 연속이 되는 a를 구하시오.

x < 1에서 f + g = 2x + 1 + a → 3 + a, x ≥ 1에서 f + g = 3x − 1 → 2이고 (f + g)(1) = 2. 3 + a = 2이므로 a = −1. 이때 f(좌 2, 우 0), g(좌 0, 우 2)는 각각 불연속입니다. a = −1

f(x) = 1 (x ≥ 0), −1 (x < 0)일 때 {f(x)}²은 x = 0에서 연속인가?

f는 좌 −1, 우 1로 불연속이지만 {f(x)}² = 1은 모든 x에서 상수이므로 연속입니다. 연속이다
