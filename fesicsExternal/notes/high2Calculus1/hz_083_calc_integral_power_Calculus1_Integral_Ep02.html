고등학교 미적분Ⅰ · 실험 「지수 실험실」

xⁿ의 부정적분 — 지수를 올리고 그 수로 나눈다

f(x) = xⁿ의 n을 0부터 바꾸며 지수를 하나 올리고 그 수로 나눈 F(x)를 만들고, x = 2에서 다시 미분해 원래 값과 비교했습니다. 모든 n에서 F′(2) = 2ⁿ으로 돌아왔습니다. ∫xⁿ dx = xⁿ⁺¹/(n + 1) + C와 미분으로 검산하는 습관을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 지수 n(0 ~ 6)과 검산할 x(0.5 ~ 4)를 바꾸고 ‘적분하고 다시 미분하기’를 누르면 지수 올리기·나누기·F(x)·F′(x)·원래와 같은지가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. n에 따른 적분과 검산 (검산할 x = 2, 실험 예시)
f(x)지수 올리기나누기F(x)F′(2)원래와 같나
x⁰ (= 1)x¹÷ 1x¹/11✅
x¹x²÷ 2x²/22✅
x²x³÷ 3x³/34✅
x³x⁴÷ 4x⁴/48✅
x⁴x⁵÷ 5x⁵/516✅

(xⁿ⁺¹)′ = (n + 1)xⁿ이므로 n + 1로 나눠야 xⁿ이 됩니다. 그래서 ∫xⁿ dx = xⁿ⁺¹/(n + 1) + C이고, 표의 F′(2)는 모두 f(2) = 2ⁿ과 같았습니다. 미분이 ‘내리고 곱한다’면 적분은 ‘올리고 나눈다’입니다. n = −1이면 분모가 0이 되어 이 공식을 쓸 수 없습니다. 헷갈리면 미분해서 원래로 돌아오는지 검산하면 됩니다.

개념 정리

1. ∫xⁿ dx = x^(n+1)/(n+1) + C — 지수를 올리고 그 수로 나눈다

미분이 “지수를 내리고 곱한다”면, 적분은 그 반대로 지수를 올리고 그 수로 나눕니다. x³ 을 적분하면 x⁴/4 예요. 다시 미분하면 4x³/4 = x³ 으로 돌아옵니다. 헷갈리면 미분해서 검산하면 됩니다.

왜 그럴까

  • (x^(n+1))′ = (n+1)x^n 이므로 n+1 로 나눠야 x^n 이 됩니다.
  • n = −1 이면 분모가 0 이 되어 이 공식을 쓸 수 없습니다(로그가 됩니다).
  • 적분 결과를 미분해 보는 것이 가장 확실한 검산입니다.

2. 자주 하는 오해 바로잡기

· “미분의 반대이니 지수를 내린다” → 올리고 나눕니다.

3. 생활 속에서 · 이어지는 개념

  • 속도에서 위치를 구할 때 차수가 하나씩 올라가는 것과 같습니다.

📋 데이터 확인 탭의 결론

“모든 기록에서 F 를 미분하니 원래 f 로 돌아왔습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

∫(3x² − 4x + 5) dx를 구하시오.

항별로 올리고 나눕니다: 3·x³/3 − 4·x²/2 + 5x. 검산: (x³ − 2x² + 5x)′ = 3x² − 4x + 5. x³ − 2x² + 5x + C

∫(x + 1)² dx를 구하시오.

먼저 전개: x² + 2x + 1. 적분하면 x³/3 + x² + x. x³/3 + x² + x + C
