교점으로 구간 나누기 — 교점을 모두 찾아야 넓이가 맞는다

y = x³/3 − x와 가로선 y = k의 높이를 바꾸며 교점을 모두 찾고, 교점마다 나눠 구한 넓이와 양 끝 교점 사이를 한 번에 적분한 값을 비교했습니다. 교점이 2개일 때는 두 값이 같았지만 3개가 되면 한 번에 적분한 값이 작아졌고, k = 0에서는 0까지 떨어졌습니다. 교점으로 구간을 나누는 절차를 정리합니다.

f′(x) = x² − 1이라 극댓값 2/3(x = −1), 극솟값 −2/3(x = 1)입니다. k = ±2/3이면 가로선이 접해 교점이 2개, 구간이 하나라 두 값이 같습니다. k = 0이면 교점 −√3, 0, √3에서 위아래가 번갈아 바뀌어 한 번에 적분하면 양쪽이 상쇄되어 0이지만, 나누면 3/4 + 3/4 = 1.5입니다. 절차: ① 연립해 교점을 모두 구하고 ② 구간을 나누고 ③ 구간마다 위아래를 확인해 ④ (위 − 아래)를 더한다.

개념 정리

1. 교점을 모두 찾아야 구간을 바르게 나눌 수 있다

두 곡선이 여러 번 만나면 위아래가 번갈아 바뀝니다. 교점을 하나만 찾고 적분하면 한 조각이 음수로 더해져 넓이가 줄어들어요. 교점을 모두 찾아 구간을 나눈 뒤, 구간마다 위아래를 다시 정해야 합니다.

왜 그럴까

  • 교점 = 두 식을 연립해 얻은 방정식의 실근.
  • 실근의 개수만큼 구간이 나뉩니다.
  • 각 구간에서 아무 점이나 하나 넣어 보면 위아래를 알 수 있습니다.

교점 구간 수 나눠 구한 넓이 한 번에 적분(절댓값) 차이

파란 조각은 곡선이 위, 주황 조각은 가로선이 위인 부분입니다. k = 0이면 조각이 2개라 한 번에 적분하면 서로 지워져 0이지만, 나누면 3/4 + 3/4 = 1.5입니다. k = ±2/3이면 가로선이 곡선에 접해 구간이 하나가 됩니다(표 1과 같은 k).

2. 자주 하는 오해 바로잡기

· “교점 하나만 찾으면 된다” → 모두 찾아야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 두 그래프가 여러 번 교차하는 데이터에서 차이의 총량을 구할 때 같은 문제가 생깁니다.
곡선의 높이를 바꿔 교점의 개수를 달리하고, 나눠 적분한 값과 한 번에 적분한 값을 비교

예제

곡선 y = x³ − 4x와 x축으로 둘러싸인 부분의 넓이를 구하시오.

교점: x(x − 2)(x + 2) = 0 → x = −2, 0, 2. 기함수라 두 조각의 넓이가 같습니다. ∫₀² (4x − x³) dx = 8 − 4 = 4, 따라서 넓이 = 4 + 4. 8 (한 번에 ∫₋₂²하면 0이 됩니다)

곡선 y = x³ − x² − 2x와 x축으로 둘러싸인 부분의 넓이를 구하시오.

교점 x = −1, 0, 2. [−1, 0]에서는 곡선이 위: ∫₋₁⁰ (x³ − x² − 2x) dx = 5/12. [0, 2]에서는 아래: ∫₀² −(x³ − x² − 2x) dx = 8/3. 5/12 + 8/3 = 37/12
