평균변화율 — 양 끝만 보는 할선의 기울기

f(x) = x + k·sin(πwx/4)·x(4 − x)/8에서 흔들림 크기 k와 위치 w를 바꿔 가운데 모양만 다른 곡선을 만들고, 구간 [0, 4]의 평균변화율을 기록했습니다. 곡선이 가운데에서 아무리 오르내려도 f(0) = 0, f(4) = 4는 그대로여서 평균변화율은 모두 1이었습니다. 평균변화율의 뜻과 한계를 정리합니다.

개념 정리

1. 평균변화율은 양 끝만 보고 계산한다 — 가운데가 어떻든 상관없다

평균변화율 = {f(b) − f(a)} / (b − a) 는 두 점을 잇는 할선의 기울기예요. 양 끝값이 같으면 가운데에서 아무리 크게 오르내려도 평균변화율은 똑같습니다. 그래서 평균만으로는 곡선의 모양을 알 수 없습니다.

왜 그럴까

  • 할선은 두 점만 지나므로 중간 정보를 담지 않습니다.
  • 순간변화율(미분계수)은 그 점 근처만 보므로 중간의 변화를 잡아냅니다.
  • 평균값 정리는 “평균변화율과 같은 순간변화율을 갖는 점이 있다”고 말합니다.

움직여 보기

가운데를 흔들어도 평균변화율은 그대로

f(a) f(b) 평균변화율

회색 점선은 f(x) = x² − 3x, 초록 곡선은 a와 b 사이만 흔든 곡선입니다. 흔들림을 바꿔도 양 끝 점과 보라색 할선은 움직이지 않습니다. a = 1, b = 4이면 평균변화율 2(예제 1)입니다.

예제

f(x) = x² − 3x에서 x의 값이 1에서 4까지 변할 때의 평균변화율을 구하시오.

f(4) = 4, f(1) = −2이므로 {4 − (−2)}/(4 − 1) = 6/3 = 2. 2

f(x) = x³과 g(x) = 3x + 2의 구간 [−1, 2]에서의 평균변화율을 비교하시오.

f(−1) = −1, f(2) = 8이고 g(−1) = −1, g(2) = 8로 양 끝값이 같습니다. 둘 다 {8 − (−1)}/3 = 3으로, 곡선과 직선이지만 평균변화율은 같습니다. 둘 다 3
