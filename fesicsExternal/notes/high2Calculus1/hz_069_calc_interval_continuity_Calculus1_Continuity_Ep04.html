구간에서의 연속 — 끝점은 안쪽 한쪽만 본다

f(x) = x²/2 − 1을 닫힌구간 [a, b]에서만 정의하고, 구간을 바꿔 가며 왼쪽 끝점 x = a에서 왼쪽·오른쪽으로 다가갈 때의 값을 기록했습니다. 끝점의 바깥쪽에는 함숫값이 아예 없었고, 안쪽(오른쪽)에서만 보면 f(a)로 다가가 연속이었지만 양쪽을 고집하면 불연속으로 판정되었습니다. 구간에서의 연속을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 구간의 왼쪽 끝 a(−3~1)와 오른쪽 끝 b(2~5)를 정하고 ‘끝점에서 다가가기’를 누르면 끝점 x = a의 왼쪽·오른쪽 값과 ‘한쪽만 보면’·‘양쪽을 보면’ 판정이 기록됩니다. 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

표 1. f(x) = x²/2 − 1의 왼쪽 끝점 판정 (실험 예시)
구간끝점왼쪽에서오른쪽에서한쪽만 보면양쪽을 보면
[0, 3]x = 0값 없음−1연속불연속
[−3, 5]x = −3값 없음3.5연속불연속
[1, 2]x = 1값 없음−0.5연속불연속
[−2, 4]x = −2값 없음1연속불연속

어느 구간을 골라도 끝점 a의 왼쪽에는 함숫값이 없어 좌극한을 따질 수 없었습니다. 오른쪽에서 다가가면 f(x) → f(a)(예: [0, 3]에서 −1)이므로 a에서 우연속입니다. [a, b]에서 연속이란 (a, b)에서 연속이고 a에서 우연속, b에서 좌연속이라는 뜻이며, 양쪽을 요구하면 모든 닫힌구간의 끝점이 불연속이 되어 최대·최소 정리나 사잇값 정리를 쓸 수 없게 됩니다.

개념 정리

1. 닫힌구간의 끝점에서는 안쪽 방향의 한쪽 극한만 본다

[a, b] 에서 정의된 함수는 a 의 왼쪽에는 아예 값이 없어요. 그러니 좌극한을 따질 수 없고, 오른쪽에서만 다가가 f(a) 와 같은지 봅니다. 양쪽을 다 봐야 한다고 고집하면 모든 닫힌구간의 끝점이 불연속이 되어 버립니다.

왜 그럴까

  • 연속은 정의역 안에서 따집니다 — 정의역 밖에서 다가갈 수는 없습니다.
  • a 에서 우연속, b 에서 좌연속이면 “구간에서 연속”이라 합니다.
  • 최대·최소 정리, 사잇값 정리가 닫힌구간을 요구하는 이유이기도 합니다.

움직여 보기

끝점에서는 구간 안쪽에서만 다가간다

x = a 왼쪽 값 없음x = a 오른쪽 f(a) x = b 왼쪽 f(b) 판정 a에서 우연속, b에서 좌연속 → [a, b]에서 연속

회색 칸은 구간 밖이라 함수가 아예 없습니다(빨간 ×). 초록 점은 a의 오른쪽에서, 주황 점은 b의 왼쪽에서 다가가 각각 f(a), f(b)에 도착합니다. [0, 3]이면 오른쪽에서 −1 = f(0)이므로 x = 0에서 우연속입니다.

2. 자주 하는 오해 바로잡기

· “닫힌구간의 끝점에서도 양쪽을 봐야 한다” → 바깥쪽에는 함수가 없습니다.

3. 생활 속에서 · 이어지는 개념

  • 측정 가능한 범위의 경계에서 바깥값을 요구할 수 없는 것과 같습니다.
구간을 바꿔 가며 끝점의 좌우에 값이 있는지 확인하고, 한쪽 극한만으로 판정

예제

f(x) = √(4 − x²)는 구간 [−2, 2]에서 연속인가?

(−2, 2)에서 연속이고, x = −2에서 우극한 0 = f(−2), x = 2에서 좌극한 0 = f(2)입니다. [−2, 2]에서 연속이다

f(x) = x + 1 (0 ≤ x < 2), f(2) = k로 정의된 함수가 [0, 2]에서 연속이 되는 k를 구하시오.

x = 2는 오른쪽 끝점이므로 좌극한만 봅니다. lim(x→2−) (x + 1) = 3 = f(2)이어야 하므로 k = 3. k = 3
