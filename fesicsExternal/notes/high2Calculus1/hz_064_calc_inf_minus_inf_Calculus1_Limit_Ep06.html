∞ − ∞ 꼴 — 0이 아니라 유리화해야 보인다

√(x² + ax) − x에서 a를 정하고 x를 10에서 200까지 키우며 두 항과 그 차를 기록했습니다. 두 항은 모두 한없이 커졌지만 차는 0이 아니라 a/2에 가까워졌고, a를 바꾸면 극한값도 달라졌습니다. ∞ − ∞ 꼴을 유리화로 푸는 방법을 정리합니다.

a = 6일 때 차는 x = 10에서 2.649, 100에서 2.956, 200에서 2.978로 a/2 = 3에 다가갔고, a = −4이면 −2, a = 10이면 5 근처로 갔습니다. 같은 ∞ − ∞ 꼴인데 극한이 a에 따라 다르므로 정해지지 않는 꼴입니다. 분자를 유리화하면 ax/(√(x² + ax) + x)가 되고, 분모·분자를 x로 나누면 a/(√(1 + a/x) + 1) → a/2입니다.

개념 정리

1. ∞ − ∞ 는 정해지지 않는 꼴 — 식을 바꿔 봐야 값이 보인다

√(x²+ax) 와 x 는 둘 다 무한히 커지지만, 그 차이는 a/2 라는 유한한 값에 가까워져요. ∞ − ∞ 를 그냥 0으로 보면 a가 무엇이든 0이 되어 버립니다. 분자를 유리화하면 ax/(√(x²+ax)+x) 가 되어 a/2 가 보입니다.

왜 그럴까

  • √(x²+ax) ≈ x + a/2 (x가 클 때) — 차가 a/2 로 남습니다.
  • 유리화는 ∞−∞ 를 ∞/∞ 로 바꿔 계산할 수 있게 만듭니다.
  • a를 바꾸면 극한값도 함께 바뀝니다 — 그래서 “정해지지 않는 꼴”입니다.

움직여 보기

∞ − ∞ 의 차는 0이 아니라 a/2 로 간다

√(x² + ax) x 차 a/2와의 오차

a = 6 에서 x = 10, 100, 200 으로 키우면 차가 2.649 → 2.956 → 2.978 로 a/2 = 3(주황 점선)에 다가갑니다. a를 바꾸면 도착점도 바뀝니다 — 그래서 ∞ − ∞ 는 '정해지지 않는 꼴'입니다. (x² + ax 가 음수인 곳은 정의되지 않아 그리지 않음)

2. 자주 하는 오해 바로잡기

· “∞ − ∞ = 0 이다” → a에 따라 극한이 달라집니다.

3. 생활 속에서 · 이어지는 개념

  • 두 큰 값의 차이가 의미 있는 정보가 되는 계산(오차, 차액)에서 늘 나타납니다.
a와 x를 바꿔 두 항의 값과 차를 직접 계산하고, a/2 에 가까워지는지 추적

예제

lim(x→∞) {√(x² + 4x) − x}의 값을 구하시오.

유리화하면 4x/(√(x² + 4x) + x) = 4/(√(1 + 4/x) + 1) → 4/2 = 2. 2

lim(x→∞) {√(x² + 3x + 1) − √(x² − x)}의 값을 구하시오.

유리화하면 (4x + 1)/(√(x² + 3x + 1) + √(x² − x))이고, 분모·분자를 x로 나누면 (4 + 1/x)/(√(1 + 3/x + 1/x²) + √(1 − 1/x)) → 4/2 = 2. 2
