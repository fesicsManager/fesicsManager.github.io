변위와 이동 거리 — ∫v dt와 ∫|v| dt는 되돌아오면 갈라진다

속도 v(t) = 3t − t²인 물체의 끝 시각 T를 늘리며 변위 ∫v dt와 이동 거리 ∫|v| dt를 기록했습니다. T ≤ 3에서는 두 값이 같았지만, t = 3 이후 뒤로 가면서 변위는 줄고 거리는 계속 늘었습니다. 변위와 이동 거리의 차이를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 끝 시각 T를 0.5 ~ 6 사이에서 0.5 단위로 바꾸고 ‘시간만큼 움직이기’를 누르면 변위, 이동 거리, 되돌아온 구간 여부, 일치 여부가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

v(t) = t(3 − t)는 0 < t < 3에서 양수, t > 3에서 음수입니다. 그래서 T ≤ 3이면 변위 = 거리이고, T > 3이면 음수가 더해져 변위는 줄지만 거리는 계속 늘어납니다. T = 4.5에서는 앞으로 4.5, 뒤로 4.5를 가서 제자리(변위 0)지만 거리는 9였습니다. 계산할 때는 v = 0인 시각에서 구간을 나눠 부호에 맞춰 더합니다. 거리는 언제나 변위의 절댓값 이상입니다.

개념 정리

1. 변위는 위치의 변화량, 거리는 실제로 움직인 길이

∫v dt 는 변위 — 출발 위치에 대한 최종 위치의 변화량(부호 포함)이에요. 되돌아온 구간에서는 음수가 더해져 값이 줄어듭니다. 실제 이동 거리는 ∫|v| dt 로, 방향에 상관없이 모두 더합니다. 제자리로 돌아오면 변위는 0 이지만 거리는 0 이 아닙니다.

왜 그럴까

  • v > 0 이면 앞으로, v < 0 이면 뒤로 — 변위는 이 부호를 그대로 반영합니다.
  • 거리는 부호를 없애고 더하므로 항상 변위 이상입니다.
  • v 가 0 이 되는 시각에서 구간을 나눠 계산합니다.

파란 넓이는 앞으로 간 만큼(+), 빨간 넓이는 되돌아온 만큼(−)입니다. 아래 수직선에서 t = 3에 점이 4.5까지 갔다가 돌아오므로, T > 3부터 변위는 줄고 거리는 계속 늘어납니다. T = 4.5에서 변위 0, 거리 9 — 표 1과 같습니다.

2. 자주 하는 오해 바로잡기

· “정적분 값이 움직인 거리다” → 되돌아오면 줄어듭니다.

3. 생활 속에서 · 이어지는 개념

  • 왕복한 뒤 제자리로 오면 변위는 0 이지만 주행거리계는 늘어나 있습니다.
끝 시각을 늘리며 변위와 이동 거리를 각각 계산하고, 되돌아오는 구간에서 갈라지는지 확인

예제

속도 v(t) = 2t − 4로 움직이는 점의 0 ≤ t ≤ 3에서 변위와 이동 거리를 구하시오.

변위: ∫₀³ (2t − 4) dt = 9 − 12 = −3. 거리: t = 2에서 나눠 ∫₀² (4 − 2t) dt = 4, ∫₂³ (2t − 4) dt = 1. 변위 −3, 이동 거리 5

속도 v(t) = t² − 4t + 3일 때 0 ≤ t ≤ 3에서 변위와 이동 거리를 구하시오.

변위: [t³/3 − 2t² + 3t]₀³ = 9 − 18 + 9 = 0. 거리: t = 1에서 나눠 ∫₀¹ v dt = 4/3, ∫₁³ v dt = −4/3 → 4/3. 변위 0, 이동 거리 8/3
