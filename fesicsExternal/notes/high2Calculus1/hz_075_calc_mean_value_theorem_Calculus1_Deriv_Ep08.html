평균값 정리 — c는 있지만 중점이라는 보장은 없다

삼차함수 f(x) = 0.15x³ − 0.5x² + 1의 구간 [a, b]를 바꿔 가며 평균변화율과, 그와 같은 기울기 f′(c)를 갖는 점 c를 찾아 구간의 중점과 비교했습니다. 모든 구간에서 c가 적어도 하나 존재했지만 중점과 일치한 적은 없었고, 두 개가 나온 구간도 있었습니다. 평균값 정리가 말하는 것과 말하지 않는 것을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 구간의 왼쪽 a(×0.5, 즉 −3~1)와 오른쪽 b(×0.5, 즉 1.5~5)를 정하고 ‘같은 기울기 찾기’를 누르면 평균변화율, 찾은 c, 구간의 중점, 둘의 차이가 기록됩니다. 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

표 1. f(x) = 0.15x³ − 0.5x² + 1의 평균값 정리 c (실험 예시)
구간평균변화율찾은 c구간의 중점중점과의 차이
[−1, 3]0.05−0.049, 2.27111.049
[−3, 3]1.35−0.94700.947
[0, 3]−0.150.162, 2.061.50.56
[0, 2]−0.40.523, 1.69910.477
[1, 5]1.653.32530.325

[1, 5]에서 평균변화율 1.65와 같은 기울기의 점은 c = 3.325로 중점 3에서 0.325 벗어났고, [−1, 3]·[0, 3]·[0, 2]에서는 c가 두 개였습니다(차이는 중점에 더 가까운 c 기준). 평균값 정리는 f가 [a, b]에서 연속, (a, b)에서 미분가능하면 f′(c) = {f(b) − f(a)}/(b − a)인 c가 적어도 하나 있다는 것만 보장합니다. c가 늘 중점이 되는 것은 이차함수일 때뿐입니다.

개념 정리

1. 평균값 정리는 “그런 c 가 있다”만 말한다 — 어디인지는 말해 주지 않는다

연속이고 미분가능하면 구간 안에 평균변화율과 같은 순간변화율을 갖는 점 c 가 적어도 하나 있어요. 하지만 c 가 중점이라는 보장은 없습니다. 이차함수에서는 우연히 중점이 되지만, 삼차 이상에서는 달라집니다.

왜 그럴까

  • 할선과 평행한 접선이 반드시 생긴다는 것이 정리의 내용입니다.
  • c는 여러 개일 수도 있습니다.
  • 롤의 정리는 f(a)=f(b)인 특별한 경우입니다.

움직여 보기

할선과 평행한 접선 — 그 점 c 는 중점일까?

평균변화율 c 중점

보라색 할선과 초록 접선이 평행해지는 점이 c 입니다. x² − 2x 에서는 c 가 언제나 중점이지만, x³ 의 [0, 3]에서는 c = √3 ≈ 1.73 으로 중점 1.5 와 다릅니다(예제 2). a 를 음수로 하면 c 가 두 개 나오기도 합니다.

📋 데이터 확인 탭의 결론

“○개 / 전체”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = x² − 2x에 대해 구간 [0, 3]에서 평균값 정리를 만족하는 c를 구하시오.

평균변화율 {f(3) − f(0)}/3 = (3 − 0)/3 = 1, f′(c) = 2c − 2 = 1에서 c = 3/2로 중점입니다(이차함수). c = 3/2

f(x) = x³에 대해 구간 [0, 3]에서 평균값 정리를 만족하는 c를 구하시오.

평균변화율 27/3 = 9, f′(c) = 3c² = 9에서 c = √3 (0 < c < 3). 중점 1.5와 다릅니다. c = √3
