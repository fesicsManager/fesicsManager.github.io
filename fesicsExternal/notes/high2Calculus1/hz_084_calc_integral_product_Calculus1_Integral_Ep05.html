고등학교 미적분Ⅰ · 실험 「곱 실험실」

정적분의 성질 — 합에는 나뉘지만 곱에는 나뉘지 않는다

f(x) = x, g(x) = x + 1로 두고 구간을 바꾸며 ∫fg와 ∫f × ∫g를 비교했습니다. 모든 구간에서 두 값이 달랐고, 반대로 ∫(f + g)와 ∫f + ∫g는 항상 같았습니다. 정적분이 어떤 연산에 나뉘는지 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 구간의 왼쪽 끝(0 ~ 2)과 오른쪽 끝(0.5 ~ 4)을 0.5 단위로 바꾸고 ‘두 방법으로 적분하기’를 누르면 ∫fg, ∫f, ∫g, ∫f × ∫g와 일치 여부가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 곱의 적분과 적분의 곱 (f = x, g = x + 1, 실험 예시)
구간∫fg∫f∫g∫f × ∫g같나
[0, 1]0.83330.51.50.75❌
[0, 2]4.6667248❌
[1, 3]12.66674624❌
[2, 4]24.66676848❌
[0, 4]29.333381296❌

∫fg = ∫(x² + x)dx이므로 [0, 2]에서 8/3 + 2 = 14/3 ≈ 4.67인데 ∫f × ∫g = 2 × 4 = 8입니다. 반면 ∫(f + g) = ∫(2x + 1)dx는 [0, 2]에서 6 = 2 + 4로 같았습니다. 적분은 잘게 잘라 더하는 것이라 합과 상수배에는 나뉘지만, 곱은 (Σ)(Σ)로 전개하면 교차항이 생겨 ∫fg ≠ ∫f × ∫g입니다. 곱의 적분은 전개해서 구합니다.

개념 정리

1. 적분은 덧셈에는 나뉘지만 곱셈에는 나뉘지 않는다

∫(f + g) = ∫f + ∫g 는 성립하지만 ∫(f·g) ≠ ∫f · ∫g 예요. 적분은 “잘게 잘라 더하기”라서 합에는 그대로 적용되지만, 곱은 잘게 자른 조각끼리 곱해 더해야 해서 전혀 다른 값이 됩니다.

왜 그럴까

  • 합의 적분은 각 조각의 합을 더한 것이라 순서를 바꿔도 같습니다.
  • 곱의 적분은 (Σ)(Σ) 형태로 교차항이 생겨 달라집니다.
  • 곱의 적분을 다루려면 부분적분이나 치환적분이 필요합니다.

2. 자주 하는 오해 바로잡기

· “∫fg = ∫f × ∫g” → 곱에는 성립하지 않습니다.

3. 생활 속에서 · 이어지는 개념

  • 평균의 곱과 곱의 평균이 다른 것과 같은 구조입니다.
f = x, g = x+1 로 두고 구간을 바꿔 ∫fg 와 ∫f·∫g, ∫(f+g) 와 ∫f+∫g 를 각각 계산
📋 데이터 확인 탭의 결론

“모든 기록에서 ∫(f+g) = ∫f + ∫g 였습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

∫₀¹ x·x dx와 (∫₀¹ x dx)²을 각각 구해 비교하시오.

∫₀¹ x² dx = 1/3, (∫₀¹ x dx)² = (1/2)² = 1/4. 1/3 ≠ 1/4

∫₀² x(x + 1) dx를 구하시오.

전개: x² + x. [x³/3 + x²/2]₀² = 8/3 + 2. 14/3
