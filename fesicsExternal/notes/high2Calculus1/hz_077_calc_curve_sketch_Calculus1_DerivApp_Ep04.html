함수의 그래프 개형 — 증감표에 끝값까지 더해야 그려진다

f(x) = x³/3 − x² − 3x + 4의 구간 양 끝을 바꾸며 극대·극소와 양 끝의 함숫값, 최댓값을 기록했습니다. 극댓값은 늘 5.67이었지만 구간에 따라 최댓값이 끝점에서 나오기도 했고, 극점이 구간 밖으로 빠지기도 했습니다. 개형을 그리는 순서와 끝값을 확인해야 하는 이유를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 구간의 왼쪽 끝(−4 ~ 0)과 오른쪽 끝(0.5 ~ 5)을 0.5 단위로 바꾸고 ‘끝까지 그려 보기’를 누르면 극대·극소·양 끝값·최댓값이 표에 기록됩니다. 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

표 1. 구간에 따른 극값·끝값·최댓값 (f(x) = x³/3 − x² − 3x + 4, 실험 예시)
구간극대극소왼쪽 끝값오른쪽 끝값최대
[−2, 3]5.67—3.33−55.67 (극대)
[−1.5, 4]5.67−55.13−2.675.67 (극대)
[−4, 2]5.67—−21.33−3.335.67 (극대)
[0, 5]—−545.675.67 (끝)
[−0.5, 2.5]——5.21−4.545.21 (끝)

f′(x) = x² − 2x − 3 = (x + 1)(x − 3)이므로 극대는 x = −1(값 17/3 ≈ 5.67), 극소는 x = 3(값 −5)입니다. 극점이 구간 안쪽에 있을 때만 후보가 되고, [0, 5]나 [−0.5, 2.5]처럼 극대점이 빠지면 최댓값은 구간의 끝에서 나옵니다. [−4, 2]에서는 최솟값도 극소가 아닌 왼쪽 끝 −21.33이었습니다. 그래서 개형은 ① f′로 증감 ② 극대·극소 ③ 양 끝값 ④ x → ±∞의 방향을 모두 확인해야 정해집니다.

개념 정리

1. 증감표는 “어디서 꺾이나”만 알려 준다 — 끝값은 따로 확인해야 한다

극대·극소는 주변에서만 가장 큰(작은) 값이에요. 구간의 양 끝에서 더 큰 값이 나올 수 있습니다. 그래서 그래프를 그릴 때는 극값과 함께 양 끝의 함숫값, 그리고 x가 커질 때의 방향까지 확인해야 합니다.

왜 그럴까

  • 극값은 국소적 정보, 끝값은 경계의 정보입니다.
  • 삼차함수는 x→∞ 에서 한없이 커지므로 열린구간에서는 최댓값이 없습니다.
  • 닫힌구간에서 최댓값은 극값과 끝값 중에서 나옵니다.

2. 자주 하는 오해 바로잡기

· “극값만 알면 그래프가 그려진다” → 끝을 봐야 전체 모양이 정해집니다.

3. 생활 속에서 · 이어지는 개념

  • 부분 최적만 보고 전체를 판단하면 더 좋은 선택을 놓칩니다.
구간을 바꿔 가며 극대·극소와 양 끝의 값을 함께 계산해 최댓값이 어디서 나오는지 확인

예제

f(x) = x³ − 3x의 닫힌구간 [−2, 3]에서 최댓값과 최솟값을 구하시오.

f′(x) = 3x² − 3 = 0 → x = ±1. 후보: f(−2) = −2, f(−1) = 2, f(1) = −2, f(3) = 18. 극댓값 2보다 오른쪽 끝값이 큽니다. 최댓값 18 (x = 3), 최솟값 −2 (x = −2, 1)

y = x³ − 3x² + 2의 극댓값과 극솟값을 구하고, x → −∞, x → ∞일 때 그래프의 방향을 말하시오.

y′ = 3x² − 6x = 3x(x − 2). x = 0에서 극대 2, x = 2에서 극소 8 − 12 + 2 = −2. 최고차항 계수가 양수이므로 x → −∞에서 −∞, x → ∞에서 ∞. 극댓값 2, 극솟값 −2, 왼쪽 아래에서 오른쪽 위로
