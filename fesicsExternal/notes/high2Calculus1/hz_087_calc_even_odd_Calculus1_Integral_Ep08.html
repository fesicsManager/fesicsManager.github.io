고등학교 미적분Ⅰ · 실험 「대칭 실험실」

우함수·기함수의 정적분 — 두 배일까, 0일까

x²(우함수), x³(기함수), x² + x(어느 쪽도 아님)를 [−a, a]에서 왼쪽과 오른쪽으로 나눠 적분했습니다. 우함수는 전체가 오른쪽의 2배, 기함수는 전체가 0이었고, x² + x는 둘 다 아니었습니다. 대칭을 이용해 정적분을 간단히 하는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 함수(x², x³, x² + x)를 고르고 구간 반폭 a(0.5 ~ 4)를 바꾼 뒤 ‘좌우를 비교하기’를 누르면 대칭, 왼쪽 적분, 오른쪽 적분, 전체, 2 × 오른쪽이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

우함수 f(−x) = f(x)는 y축 대칭이라 왼쪽과 오른쪽 적분이 같아 ∫₋ₐᵃ f = 2∫₀ᵃ f, 기함수 f(−x) = −f(x)는 원점 대칭이라 왼쪽이 정확히 상쇄되어 ∫₋ₐᵃ f = 0입니다. x² + x는 대칭이 없어 2 × 오른쪽(9.333)과 전체(5.333)가 달랐지만, x²(우) 부분과 x(기) 부분으로 나누면 전체 = 2∫₀² x² dx + 0 = 16/3으로 바로 구해집니다.

개념 정리

1. 우함수는 2∫₀ᵃ, 기함수는 0 — 대칭의 종류가 결과를 가른다

우함수 f(−x) = f(x) 는 y축 대칭이라 왼쪽과 오른쪽 넓이가 같아 2배가 돼요. 기함수 f(−x) = −f(x) 는 원점 대칭이라 왼쪽이 음수로 정확히 상쇄되어 0이 됩니다. 대칭이 아니면 어느 쪽도 쓸 수 없습니다.

왜 그럴까

  • 우함수: 왼쪽 적분 = 오른쪽 적분.
  • 기함수: 왼쪽 적분 = −(오른쪽 적분).
  • 일반 함수는 우함수 부분과 기함수 부분으로 나눠 볼 수 있습니다.

2. 자주 하는 오해 바로잡기

· “대칭이면 두 배 하면 된다” → 기함수는 0 이 됩니다.

3. 생활 속에서 · 이어지는 개념

  • 좌우로 같은 양이 오가면 순 변화가 0 인 상황과 같습니다.
세 함수를 [−a, a] 에서 좌우로 나눠 적분해, 합이 2배인지 0인지 확인

예제

∫₋₁¹ (x³ + 3x² − x + 2) dx를 구하시오.

x³, −x는 기함수라 0. 3x² + 2는 우함수라 2∫₀¹ (3x² + 2) dx = 2(1 + 2) = 6. 6

∫₋₂² (x⁵ − 4x³ + x) dx를 구하시오.

모든 항이 홀수 차수인 기함수이므로 대칭 구간에서 상쇄됩니다. 0
