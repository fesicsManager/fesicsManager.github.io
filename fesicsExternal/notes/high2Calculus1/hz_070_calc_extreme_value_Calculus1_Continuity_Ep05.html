고등학교 미적분Ⅰ · 실험 「닫힌구간 실험실」

최대·최소 정리 — 닫힌구간과 연속이 함께 있어야 보장된다

연속함수 f(x) = −0.6x² + 1.5x + 2와 x = 0.5에서 1.4만큼 아래로 끊기는 함수를 두고, 구간의 끝을 열고 닫으며 최댓값·최솟값이 있는지 기록했습니다. 닫힌구간과 연속이 함께 갖춰진 경우에만 둘 다 반드시 있었고, 하나라도 빠지면 최댓값이나 최솟값이 사라지는 경우가 나왔습니다. 최대·최소 정리를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 구간의 a(−3~0)와 b(1~4), 끝의 열림·닫힘, 함수의 연속·끊김을 정하고 ‘끝을 열고 닫기’를 누르면 최댓값·최솟값의 존재와 정리를 쓸 수 있는지가 기록됩니다. 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

표 1. 구간의 개폐·연속 여부와 최댓값·최솟값 (실험 예시)
구간연속최댓값최솟값정리를 쓸 수 있나
[−2, 2]○2.94−3.4○
(−2, 2)○2.94없음×
(−2, 1)○없음없음×
[−2, 2]×없음−3.4×
[0, 1]×없음1.2×

[−2, 2]에서 연속이면 꼭짓점 x = 1.25의 2.94가 최댓값, 끝점의 −3.4가 최솟값이었습니다. 같은 구간을 열면 −3.4에 다가갈 뿐 도달하지 못해 최솟값이 없고, (−2, 1)처럼 꼭짓점이 구간 밖이면 최댓값도 사라졌습니다. 끊긴 함수는 닫힌구간에서도 점프 직전의 2.6에 다가가기만 해 최댓값이 없었습니다. 닫힌구간 + 연속이면 반드시 있고, 조건이 빠지면 (−2, 2)의 최댓값처럼 있을 수도, 없을 수도 있습니다.

개념 정리

1. 닫힌구간 + 연속 — 두 조건이 모두 있어야 최댓값·최솟값이 보장된다

열린구간에서는 끝에 가까워질 뿐 도달하지 못해 최댓값이 없을 수 있어요. 중간에 끊긴 함수도 마찬가지입니다. 최대·최소 정리는 “닫힌구간에서 연속이면 반드시 최댓값과 최솟값을 갖는다”고 말합니다 — 두 조건이 함께 필요합니다.

왜 그럴까

  • (0, 1)에서 f(x) = x 는 1에 한없이 가까워지지만 1이 되지 못합니다.
  • 끊긴 함수는 점프하는 자리에서 값을 건너뛰어 버립니다.
  • 정리는 “있다”만 보장하고, 어디인지는 말해 주지 않습니다.

움직여 보기

닫힌구간과 열린구간 — 최댓값·최솟값이 정말 있을까?

f(a) f(b) 최댓값 최솟값

f(x) = x² − 4x + 1 입니다. [0, 3]에서 최댓값 1, 최솟값 −3(예제 1)을 확인한 뒤 열린구간으로 바꿔 보세요. 끝점이 빈 동그라미가 되면 그 값에 다가가기만 할 뿐 닿지 못해 최댓값이 사라집니다.

2. 자주 하는 오해 바로잡기

· “연속함수는 언제나 최댓값을 갖는다” → 구간이 닫혀 있어야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 가능한 범위가 열려 있으면 “가장 좋은 선택”이 존재하지 않을 수 있습니다.
구간의 개폐와 연속 여부를 바꿔 가며 최댓값·최솟값이 실제로 존재하는지 확인

예제

f(x) = x² − 4x + 1의 닫힌구간 [0, 3]에서의 최댓값과 최솟값을 구하시오.

f(x) = (x − 2)² − 3이므로 꼭짓점에서 f(2) = −3, 끝값은 f(0) = 1, f(3) = −2입니다. 최댓값 1, 최솟값 −3

f(x) = 2x + 1은 열린구간 (0, 2)에서 최댓값·최솟값을 갖는가?

f는 증가함수이고 함숫값은 1과 5 사이에서 두 수에 한없이 가까워지지만 도달하지 못합니다. 최댓값·최솟값 모두 없다
