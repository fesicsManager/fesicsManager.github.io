절댓값 함수의 정적분 — 부호가 바뀌는 곳에서 자른다

f(x) = x² − 2x − 3의 구간을 바꾸며, 그냥 적분한 값과 f = 0인 점에서 나눠 절댓값으로 더한 값을 비교했습니다. f가 음수인 부분이 늘 들어 있어 두 값은 항상 달랐고, 차이는 음수 부분 넓이의 2배였습니다. ∫|f|를 구하는 절차를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 구간의 왼쪽 끝(−4 ~ 0)과 오른쪽 끝(0.5 ~ 4)을 0.5 단위로 바꾸고 ‘잘라서 적분하기’를 누르면 부호 바뀌는 점, 그냥 적분, 나눠 적분, 실제 넓이가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 나누지 않은 적분과 나눈 적분 (f(x) = x² − 2x − 3, 실험 예시)
구간부호 바뀌는 점그냥 적분나눠 적분실제 넓이같나
[−2, 4]−1, 3−615.333315.3333❌
[−1, 3]없음−10.666710.666710.6667❌
[0, 4]3−6.666711.333311.3333❌
[−4, 0.5]−123.62530.37530.375❌
[0, 2]없음−7.33337.33337.3333❌

f(x) = (x + 1)(x − 3)은 −1 < x < 3에서 음수입니다. [0, 4]에서는 [0, 3]의 −9와 [3, 4]의 7/3을 나눠 |−9| + 7/3 = 34/3 ≈ 11.33이 되지만, 그냥 적분하면 −9 + 7/3 = −6.67입니다. 차이는 정확히 음수 부분 넓이의 2배입니다. 절차: ① f = 0인 점을 모두 찾고 ② 구간을 나누고 ③ 음수 구간은 −f로 바꿔 ④ 더한다.

개념 정리

1. |f| 를 적분하려면 f 가 0 이 되는 점에서 구간을 나눠야 한다

∫|f| 는 f 가 음수인 구간에서 부호를 뒤집어 더해야 해요. 절댓값을 그대로 둔 채 적분하면 음수 부분이 빠져 버립니다. 먼저 f = 0 인 점을 찾아 구간을 나누고, 각 구간에서 f 의 부호에 맞춰 ±를 붙입니다.

왜 그럴까

  • |f| = f (f ≥ 0), −f (f < 0) — 구간마다 식이 다릅니다.
  • 그래서 “구간을 나누는 적분”이 필요합니다.
  • 넓이를 구하는 문제는 사실상 모두 이 형태입니다.

움직여 보기

음수 부분을 뒤집어 더하면 ∫|f|

부호 바뀌는 점 그냥 적분 ∫f 나눠 적분 ∫|f| 차이 = 음수 넓이 × 2

초록 동그라미(f = 0 인 x = −1, 3)에서 구간을 자릅니다. 빨간 음수 부분을 x축 위로 뒤집으면(−f) 모든 넓이가 더해져 ∫|f| 가 됩니다. 그냥 적분하면 빨간 부분이 빼지므로 두 값의 차이가 음수 부분 넓이의 2배인지 확인해 보세요.

2. 자주 하는 오해 바로잡기

· “절댓값도 그냥 적분하면 된다” → 부호가 바뀌는 점에서 나눠야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 수익과 손실이 섞인 구간에서 총 변동폭을 구하는 계산과 같습니다.
구간을 바꿔 가며 f = 0 인 점을 찾아 나눠 적분하고, 나누지 않은 값과 비교

예제

∫₀⁴ |x − 1| dx를 구하시오.

x = 1에서 나눕니다. ∫₀¹ (1 − x) dx = 1/2, ∫₁⁴ (x − 1) dx = 9/2. 5

∫₋₂² |x² − 1| dx를 구하시오.

x = ±1에서 나눕니다. [−2, −1]: ∫(x² − 1) = 4/3, [−1, 1]: ∫(1 − x²) = 4/3, [1, 2]: ∫(x² − 1) = 4/3. 4
