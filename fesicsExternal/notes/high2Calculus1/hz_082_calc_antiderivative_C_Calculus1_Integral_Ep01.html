부정적분과 적분상수 — 되돌리면 답은 하나가 아니다

F(x) = x³/3 − x + C에서 적분상수 C를 바꾸며 F(1)과 F′(1)을 기록했습니다. C가 바뀌면 F(1)은 C만큼 달라졌지만 F′(1)은 언제나 0으로 같았고, 그래프는 세로로 평행이동했을 뿐이었습니다. 부정적분에 + C를 붙이는 이유를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 적분상수 C(−5 ~ 5)와 기울기를 확인할 x(−2 ~ 3)를 바꾸고 ‘여러 개를 겹쳐 그리기’를 누르면 C, F(x), F(1), F′(1), 도함수 일치 여부가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 적분상수 C에 따른 원시함수 (f(x) = x² − 1, 실험 예시)
CF(x)F(1)F′(1)도함수가 같나

F(1) = 1/3 − 1 + C = C − 2/3이라 C에 따라 값이 달라지지만, F′(x) = x² − 1이므로 같은 x에서 기울기는 모두 같습니다(F′(1) = 0, F′(2) = 3). 미분하면 상수항이 사라지므로 x² − 1을 적분할 때 원래 상수를 알 수 없고, 그래서 답을 함수들의 모임 x³/3 − x + C로 씁니다. F(1) = 5 같은 조건이 하나 주어지면 C가 정해집니다.

개념 정리

1. 미분하면 상수가 사라지므로, 되돌릴 때는 상수를 알 수 없다

F(x) = x² 과 x² + 3 은 미분하면 둘 다 2x 예요. 그래서 2x 를 적분할 때 원래 상수가 무엇이었는지 알 방법이 없습니다. 가능한 모든 답을 한꺼번에 나타내려고 + C 를 붙입니다.

왜 그럴까

  • 두 함수의 도함수가 같으면 차이가 상수입니다.
  • 그래서 부정적분은 하나의 함수가 아니라 함수의 모임입니다.
  • 한 점을 지난다는 조건이 주어지면 C가 정해집니다.

움직여 보기

C 만 다른 원시함수들 — 같은 x 에서 기울기는?

F(x) F(1) = C − 2/3 이 x 에서 F(x) F′(x) = x² − 1

회색 곡선은 표 1의 C = −2, 0, 1, 3, 5 이고, 보라 곡선이 지금 고른 C 입니다. C 를 바꾸면 그래프가 위아래로만 평행이동하고, 같은 x 에 그은 주황 접선들은 모두 나란해요(기울기가 같음). 그래서 x² − 1 을 적분하면 C 를 하나로 정할 수 없습니다.

2. 자주 하는 오해 바로잡기

· “적분상수는 안 써도 된다” → 답이 하나가 아니므로 반드시 붙여야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 속도만 알면 출발 위치를 알 수 없는 것과 같습니다.
C 를 바꿔 여러 원시함수를 겹쳐 그리고, 같은 x 에서 기울기가 모두 같은지 확인
📋 데이터 확인 탭의 결론

“서로 다른 C 를 써도 도함수가 모두 같았습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

F′(x) = 3x² + 2x이고 F(1) = 5일 때 F(x)를 구하시오.

F(x) = x³ + x² + C. F(1) = 1 + 1 + C = 5 → C = 3. F(x) = x³ + x² + 3

F′(x) = 2x − 4이고 F(0) = 1일 때 F(2)의 값을 구하시오.

F(x) = x² − 4x + C, F(0) = C = 1. F(2) = 4 − 8 + 1. F(2) = −3
