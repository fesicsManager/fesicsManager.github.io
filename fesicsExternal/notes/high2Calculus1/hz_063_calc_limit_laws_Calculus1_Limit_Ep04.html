고등학교 미적분Ⅰ · 실험 「성질 실험실」

극한의 성질 — 각각 존재할 때만 쓸 수 있다

f = |x|/x, g = −|x|/x 쌍에서 x를 0의 좌우로 다가가며 f, g, f + g의 좌·우 값을 기록했습니다. f와 g는 각각 좌극한과 우극한이 달라 극한이 없었지만, 합 f + g는 어느 쪽에서나 0이라 극한이 존재했습니다. 극한의 성질을 쓸 수 있는 조건을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 0에서 떨어진 거리(×0.01)와 함수 쌍을 고르고 ‘양쪽에서 다가가기’를 누르면 f, g의 좌·우 값과 f + g의 극한 여부가 기록됩니다. 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

표 1. f = |x|/x, g = −|x|/x 쌍에서 x → 0 (실험 예시)
x → 0f의 좌·우 값g의 좌·우 값f + g의 극한따로 존재합은 존재
±0.5−1 / 11 / −10×○
±0.2−1 / 11 / −10×○
±0.1−1 / 11 / −10×○
±0.01−1 / 11 / −10×○

거리를 0.5에서 0.01까지 줄여도 f는 왼쪽 −1, 오른쪽 1, g는 왼쪽 1, 오른쪽 −1로 좌우가 달라 각각은 극한이 없습니다. 그러나 두 점프가 정확히 반대라 f + g = 0이 되어 합의 극한은 0입니다. 따라서 lim(f + g) = lim f + lim g는 두 극한이 각각 존재할 때만 쓸 수 있는 규칙이며, 합의 극한이 있다고 각각의 극한이 있는 것은 아닙니다.

개념 정리

1. 극한의 사칙 성질은 두 극한이 “각각 존재할 때” 쓸 수 있다

lim(f+g) = lim f + lim g 는 두 극한이 각각 존재할 때 성립하는 규칙이에요. f와 g가 따로는 극한이 없는데 합의 극한은 있을 수 있습니다. 이때 규칙을 거꾸로 쓰면 “존재하지 않는 것끼리 더했다”는 이상한 계산이 됩니다.

왜 그럴까

  • f = |x|/x 는 x→0 에서 좌극한 −1, 우극한 1 로 극한이 없습니다.
  • 그런데 f + g = 0 이라 합의 극한은 0 으로 존재합니다.
  • 성질은 “있으면 이렇게 계산해도 된다”는 보증이지, 존재를 보장하지 않습니다.

2. 자주 하는 오해 바로잡기

· “각각 극한을 구해 계산하면 된다” → 각각 존재하는지 먼저 확인해야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 각 부품의 오차가 제멋대로여도 합이 안정적일 수 있는 것과 비슷합니다.
0에 좌우에서 다가가며 f, g, f+g 의 값을 각각 재어 극한의 존재 여부를 판정

예제

lim(x→0) f(x) = 3, lim(x→0) g(x) = −2일 때 lim(x→0) {2f(x) − f(x)g(x)}의 값을 구하시오.

두 극한이 각각 존재하므로 성질을 쓸 수 있습니다. 2·3 − 3·(−2) = 6 + 6 = 12. 12

lim(x→1) f(x) = 2이고 lim(x→1) {f(x) + g(x)} = 5일 때 lim(x→1) g(x)를 구하시오.

g = (f + g) − f이고, f와 f + g의 극한이 모두 존재하므로 성질을 쓸 수 있습니다. lim g = 5 − 2 = 3. 3

확인 문제

1번· 관찰 확인

f = |x|/x, g = −|x|/x 쌍에서 기록한 결과로 옳은 것은?

두 점프가 반대라 합에서 상쇄됩니다.
🔬 실험으로 다시 확인

2번· 핵심 개념

lim(f + g) = lim f + lim g 를 쓸 수 있는 조건은?

성질은 ‘각각 있으면 이렇게 계산해도 된다’는 보증입니다.
🔬 실험으로 다시 확인

3번· 적용

lim(x→a) f(x) = 4, lim(x→a) {f(x) − g(x)} = 1일 때 lim(x→a) g(x)는?

g = f − (f − g)이고 두 극한이 존재하므로 4 − 1 = 3입니다.
🔬 실험으로 다시 확인

4번· 오해 바로잡기

‘lim(f + g)가 존재하므로 lim f와 lim g도 존재한다’는 주장에 대한 설명으로 옳은 것은?

성질을 거꾸로 쓰면 안 됩니다.
