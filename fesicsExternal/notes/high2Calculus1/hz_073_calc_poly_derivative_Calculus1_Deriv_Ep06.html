상수항의 미분 — 위아래로 옮겨도 기울기는 같다

f(x) = x² − x + c에서 상수항 c만 −4에서 6까지 바꾸며 x = 1, 2에서의 기울기를 수치로 재어 기록했습니다. 그래프가 위아래로 옮겨져 f(1)은 c와 함께 달라졌지만, f′(1) = 1, f′(2) = 3은 c와 상관없이 같았습니다. 상수함수의 도함수가 0인 이유를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 상수항 c(−4~6)와 미분할 점 x(×0.5)를 정하고 ‘세로로 밀어 보기’를 누르면 f(1), f′(1), f′(2)와 도함수가 기록됩니다. 같은 x에서 c만 바꾸며 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

c를 바꾸면 f(1) = c로 함숫값은 달라졌지만 f′(1) = 1, f′(2) = 3은 모든 c에서 같았고 도함수 2x − 1과 일치했습니다. c는 그래프를 통째로 위아래로 옮길 뿐 모양을 바꾸지 않기 때문입니다. 식으로는 (c)′ = lim(c − c)/h = 0이므로 (f + c)′ = f′이고, 거꾸로 적분할 때는 사라진 c를 알 수 없어 적분상수 C를 붙입니다.

개념 정리

1. 상수항은 그래프를 위아래로 옮길 뿐 — 기울기를 바꾸지 않는다

f(x) = x² + c 에서 c 를 바꾸면 그래프가 통째로 위아래로 움직여요. 모양은 그대로라 어느 점에서든 접선의 기울기가 같습니다. 그래서 상수항을 미분하면 0 이 되고, 도함수에는 c 가 남지 않습니다.

왜 그럴까

  • 상수함수의 변화율은 0 — 아무리 시간이 지나도 값이 변하지 않습니다.
  • (f + c)′ = f′ + 0 = f′.
  • 거꾸로 적분할 때 적분상수 C 가 되살아나는 이유이기도 합니다.

2. 자주 하는 오해 바로잡기

· “상수항도 미분하면 남는다” → 변화가 없으므로 0 입니다.

3. 생활 속에서 · 이어지는 개념

  • 출발 위치가 달라도 속도 그래프는 같은 것과 같습니다.
상수항 c 를 바꿔 여러 그래프를 겹쳐 그리고, 같은 x 에서 기울기를 수치로 재어 비교
📋 데이터 확인 탭의 결론

“같은 x 에서 c 만 바꾼 기록들의 기울기가 모두 같았습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = 3x³ − 2x² + 5x − 7의 도함수와 f′(1)을 구하시오.

f′(x) = 9x² − 4x + 5 (상수 −7의 도함수는 0), f′(1) = 9 − 4 + 5 = 10. f′(x) = 9x² − 4x + 5, f′(1) = 10

f′(x) = 2x − 1이고 f(0) = 3인 다항함수 f(x)를 구하시오.

도함수가 2x − 1인 함수는 x² − x + C 꼴이고, f(0) = C = 3. f(x) = x² − x + 3
