중3 기술 · 웹툰 6화 「스스로 판단하게 만들기」

제어와 자동화 — 자동과 자동화의 차이는 판단(되먹임)의 유무

닫힌 제어(센서로 판단)와 열린 제어(계속 켜 둠)에서 설정 온도·히스테리시스·히터 세기·바깥 온도를 바꾸며 30분간 실내 온도 곡선과 히터 켜짐 횟수를 기록했습니다. 열린 제어는 설정값 24 ℃를 넘어서도 멈추지 않고 계속 올랐지만 닫힌 제어는 24 ± 1 ℃ 범위를 지켰고, 히스테리시스를 0.2 ℃로 좁히면 정밀해지지만 히터가 훨씬 자주 켜졌으며, 바깥이 추울수록 켜져 있는 시간이 늘었습니다. 로봇의 3요소와 피드백 제어를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 뉴턴 냉각 법칙 dT/dt = −k(T − 바깥온도) + 히터. 닫힌 제어는 설정값 ± 히스테리시스 범위에서 히터를 껐다 켭니다. 히터 세기가 0.035 × (설정 − 바깥)보다 작으면 계속 켜 두어도 설정 온도에 닿지 못합니다.

로봇의 조건은 생김새가 아니라 센서(감지) → 제어부(판단) → 액추에이터(동작)의 순환입니다. 선풍기는 켜면 그냥 돌고(열린 제어), 에어컨은 온도를 재서 스스로 껐다 켭니다(피드백 제어). 자동과 자동화의 차이는 판단(되먹임)의 유무이며, 히스테리시스 범위를 좁히면 정밀해지지만 기기가 더 자주 켜집니다.

개념 정리

1. 열린 제어 vs 닫힌(피드백) 제어

열린 제어는 결과를 보지 않고 정해진 대로만 하므로 설정값을 넘어서도 멈추지 않습니다. 닫힌 제어는 되먹임으로 설정 범위를 지킵니다. 로봇이 똑똑해 보이는 것은 이 되먹임 덕분입니다. 3화의 입력–제어–출력과 같은 구조가 계속 나오는 것이 융합의 까닭입니다.

히스테리시스

켜는 기준과 끄는 기준 사이의 여유. 0에 가깝게 하면 기준 근처에서 켜졌다 꺼졌다를 반복해 기기 수명이 줄어듭니다.

2. 로봇 제작과 고장 진단 순서

선을 따라가는 로봇 — 적외선 센서 두 개, 모터 두 개, 조건문 네 줄. 실제로 돌리면 조명 때문에 값이 흔들리므로 여러 번 읽어 평균을 냅니다. 코드가 맞았는데 안 될 때 의심할 순서: ① 배선 ② 센서 값 ③ 임계값 ④ 코드 — 대부분 코드 앞에서 끝납니다.

3. 생활 속에서 · 이어지는 개념

보일러·냉장고·자동 밝기 화면이 모두 피드백 제어입니다. 8화에서는 이 구조에 통신을 붙여 교실 크기로 키웁니다(IoT).

dT/dt = −k(T − T바깥) + 히터; 닫힌 제어: T < 설정 − h → 켜기, T > 설정 + h → 끄기 (h = 히스테리시스)

예제

설정 24 ℃·바깥 0 ℃일 때 히터 세기가 얼마 이상이어야 설정에 닿나?

0.035 × (24 − 0) = 0.84 ℃/분 이상. 그보다 약하면 계속 켜 두어도 못 닿아 열린·닫힌 곡선이 같아진다.

선 따라가기 로봇의 코드가 맞는데 움직이지 않을 때 먼저 볼 것은?

배선 → 센서 값 → 임계값 → 코드 순. 대부분 코드 앞에서 끝난다.
