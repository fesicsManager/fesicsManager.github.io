고등 소프트웨어와 생활 · 웹툰 6화 「테스트를 많이 통과하면 버그가 없는 프로그램인가」

경계값 테스트 — 버그는 경계에 살고, 테스트는 버그가 없음을 증명하지 못한다

‘4명 이상 12명 이하’를 받아야 하는 동아리 신청 프로그램에 경계 버그 네 가지를 숨기고, 테스트 묶음마다 올바른 코드와 결과가 다른지 확인했습니다. 뭉치 코드(4 < n ≤ 12)는 ③ 4명·12명 묶음만 잡았고 평범한 값 6·8명이나 범위 밖 1·20명은 모두 통과했으며, 경계값 세트 3·4·12·13은 네 버그를 모두 잡았습니다. 경계값을 고르는 법과 테스트의 한계를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 테스트 묶음(① 6명, 8명 ~ ④ 3명, 13명, ⑤ 무작위 10개, ⑥ 경계값 세트)과 코드에 숨은 버그 네 가지 중 하나를 고르고 테스트 실행을 누르면 0~30 수직선에 테스트 값이 떨어지며 기대 결과와 실제 결과, 버그 발견 여부가 기록됩니다. 뭉치 코드 버그에 ①~④를 모두 넣어 보고, ⑤ 무작위 10개를 여러 번 눌러 몇 번 놓치는지 세어 보세요. 기록이 4개 이상이면 결과 비교 탭에서 묶음 × 버그 표와 무작위 테스트의 놓친 비율을 볼 수 있습니다.

표 1. 테스트 묶음과 숨은 버그에 따른 발견 여부 (실험 예시, 의도한 조건 4 ≤ n ≤ 12)

뭉치 코드 4 < n ≤ 12는 0~30명 31개 값 가운데 4 하나에서만 올바른 코드와 결과가 다릅니다. 그래서 평범한 값(6, 8)이나 멀리 떨어진 값(1, 20)은 몇 번을 넣어도 통과하고, 경계 바깥쪽(3, 13)도 이 버그는 못 잡습니다. 그러나 ④(3, 13)는 ‘n ≤ 13’처럼 위 경계를 넘친 버그를 잡으므로 쓸모없는 테스트가 아닙니다. 무작위 10개는 4를 한 번도 안 뽑을 확률이 (30/31)^10 ≈ 0.72라 열 번 넣어도 약 72%는 놓칩니다. 경계 바로 안쪽과 바깥쪽 3·4·12·13을 한 세트로 넣고, 정상 값·잘못된 입력도 함께 넣습니다.

개념 정리

1. 버그는 경계에 산다

조건문 버그는 대개 경계에서 생깁니다. <와 <=를 헷갈리는 식이에요. 뭉치 코드 return 4 < n <= 12　(의도: 4 <= n <= 12)는 4명일 때만 틀립니다.

  • 0~30명 31개 값을 모두 넣으면 결과가 다른 값은 4 하나뿐 → 6~8 같은 평범한 값으로 100번 테스트해도 잡을 확률 0
  • 0~30에서 무작위로 10개를 뽑아 4를 한 번도 안 뽑을 확률 = (30/31)^10 ≈ 0.72 → 열 번 넣어도 약 72%는 놓침
  • 경계값 하나(4)를 넣으면 한 번에 잡힘

2. 경계값 세트 3 · 4 · 12 · 13

4 < n은 4가, 3 <= n은 3이, n < 12는 12가, n <= 13은 13이 잡습니다. 그래서 경계 바로 안쪽과 바깥쪽 네 개를 한 세트로 넣어요. ④(3, 13)는 이번 버그는 못 잡지만 다른 버그를 잡는 쓸모 있는 테스트입니다.

3. 테스트의 한계

· 테스트는 "찾은 버그가 있다"는 말할 수 있지만 "버그가 없다"는 증명하지 못합니다. 잘 고를수록 놓칠 가능성을 줄일 뿐이에요.

· 실제 사용자는 빈칸, "열두명", −5 같은 잘못된 입력도 넣습니다. 정상 값·경계값·잘못된 입력을 모두 넣으세요.

· 만든 사람은 자기가 생각한 값만 넣기 쉬워서, 다른 사람이 테스트를 짜 주면 좋습니다.

예제

실험에서 숨은 버그를 ‘3 <= n <= 12’(아래 경계 넘침)로 두었다. ① 6명·8명, ③ 4명·12명, ④ 3명·13명 묶음 중 이 버그를 잡는 묶음을 고르고 까닭을 쓰시오.

올바른 코드와 버그 코드의 결과가 다른 값은 3 하나뿐입니다(올바른 코드는 3을 거부, 버그 코드는 허용). ①과 ③에는 3이 없어 모두 통과하고, ④의 3명에서 기대 거부 / 실제 허용으로 결과가 갈립니다. ④ 3명, 13명

0~30에서 같은 값이 다시 뽑힐 수 있게 무작위로 값 5개를 골라 뭉치 코드를 테스트할 때, 버그를 놓칠 확률을 소수 둘째 자리까지 구하시오.

한 번 뽑을 때 4가 아닐 확률은 30/31입니다. 5번 모두 4가 아닐 확률 = (30/31)^5 ≈ 0.849 → 약 0.85. 10개일 때(약 0.72)보다 더 자주 놓칩니다. 약 0.85
