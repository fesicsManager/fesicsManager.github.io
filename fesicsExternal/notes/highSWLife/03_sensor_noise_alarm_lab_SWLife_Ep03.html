센서 노이즈 처리 — 이동평균과 히스테리시스로 흔들리는 판단을 잡는다

교실 이산화탄소 센서의 20분 기록에 단순 기준 · 이동평균 · 히스테리시스를 차례로 적용해 ‘환기하세요’ 불이 새로 켜진 횟수와 처음 켜진 시각을 비교했습니다. 단순 기준은 4번 켜졌지만 3분 이동평균과 히스테리시스(끄기 950)는 1번이었고, 대신 이동평균은 2분 늦게 켜졌습니다. 노이즈를 다루는 두 방법과 그 대가를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 판단 방법(단순 기준 · 이동평균 · 히스테리시스)을 고르고, 이동평균이면 평균에 쓰는 값의 개수(2~10개), 히스테리시스면 끄는 기준(900~1000 ppm)을 정한 뒤 20분 따라가기를 누르면 측정값 그래프 아래 불이 켜지고 새로 켜짐·꺼짐·전환 횟수와 처음 켜진 시각이 기록됩니다. 세 방법을 기본 설정으로 모두 해 보고 평균 개수를 10개로, 끄기 기준을 1000으로도 바꿔 보세요. 기록이 4개 이상이면 결과 비교 탭에서 방법별 켜짐 횟수와 대가 비교표를 볼 수 있습니다.

측정값이 985~1020 ppm 사이를 오가는 4~10분 구간에서 단순 기준은 4·6·8·11분에 새로 켜지고 5·7·10분에 꺼져 전환이 7번이나 됐습니다. 3분 이동평균은 6분째 평균 1005.0에서 한 번 켜진 뒤 평균이 1000.0 아래로 내려가지 않아 계속 켜져 있었고, 히스테리시스는 4분째 켜진 뒤 측정값 최솟값 985가 끄기 기준 950 이상이라 꺼지지 않았습니다. 그러나 이동평균은 개수를 늘릴수록 매끄럽지만 늦어지고(3개 6분, 10개 12분), 히스테리시스는 끄는 기준을 켜는 기준에 가깝게 잡으면 다시 깜빡인다(990이면 2번, 1000이면 단순 기준과 같은 4번). 알림의 목적에 따라 방법을 고릅니다.

개념 정리

1. 노이즈 위에서 판단이 뒤집힌다

센서 값에는 실제 변화에 노이즈(측정할 때마다 생기는 작은 흔들림)가 섞입니다. 값이 기준 근처를 오가면 공기는 거의 그대로인데 판단은 계속 뒤집혀요.

  • 단순 기준: 켜짐 = (값 ≥ 1000) → 4·6·8·11분에 새로 켜짐 4번, 꺼짐 3번, 전환 7번
  • 3분 이동평균: 평균 = (v[i−2] + v[i−1] + v[i]) ÷ 3 → 6분째 (1010 + 990 + 1015) ÷ 3 = 1005.0에서 1번, 이후 최솟값 1000.0
  • 히스테리시스(켜기 1000, 끄기 950): 4분째 켜진 뒤 최솟값 985 ≥ 950이라 계속 켜짐 → 1번

회색 점이 1분마다 잰 값, 아래 칸이 ‘환기하세요’ 불(주황 = 켜짐)입니다. 단순 기준은 1000 근처에서 불이 깜빡이고, 이동평균(보라 선)은 차분하지만 늦게 켜지며, 히스테리시스는 끄기 기준(주황 점선)을 1000에 가깝게 올릴수록 다시 깜빡입니다(측정값은 수업용 가상 자료).

2. 공짜는 없다

이동평균은 차분하지만 늦고(3개 평균이면 2분 늦게 알림), 평균 낼 개수를 늘릴수록 더 매끄럽고 더 늦어집니다. 히스테리시스는 빠르지만 끄는 기준을 잘못 잡으면 오래 켜져 있어요. 끄는 기준을 1000으로 올리면 단순 기준과 똑같아집니다.

그래서 알림의 목적부터 정합니다. 늦으면 위험한 알림은 빠른 쪽을, 몇 분 늦어도 괜찮은 환기 안내는 차분한 쪽을 고르고, 둘을 함께 쓰기도 해요.

3. 실험 모형과 실제의 차이

· 20분짜리 한 가지 기록만 썼습니다. 다른 기록에서는 횟수가 달라질 수 있어요.

· 센서를 문 옆에 다는지, 사람 숨이 닿는 책상 위에 다는지에 따라 값이 달라집니다. 설치 위치도 설계입니다.

예제

실험의 측정값 중 4~6분 값은 1010, 990, 1015 ppm이고 5~7분 값은 990, 1015, 995 ppm이다. 6분째와 7분째의 3분 이동평균을 구하고, 기준 1000으로 판단한 결과를 쓰시오.

6분째 = (1010 + 990 + 1015) ÷ 3 = 3015 ÷ 3 = 1005.0 → 1000 이상이라 켜짐. 7분째 = (990 + 1015 + 995) ÷ 3 = 3000 ÷ 3 = 1000.0 → 1000 이상이라 계속 켜짐. 단순 기준이었다면 7분째 값 995가 1000 미만이라 꺼졌을 것입니다. 6분 1005.0 켜짐, 7분 1000.0 켜짐 유지

실험의 처음 10분 측정값은 930, 960, 985, 1010, 990, 1015, 995, 1020, 1005, 985이다. 켜기 1000, 끄기 990인 히스테리시스로 판단할 때 처음 10분 동안 꺼지는 시각을 구하시오.

4분째 1010 ≥ 1000에서 켜집니다. 켜진 뒤에는 값이 990 미만일 때만 꺼지는데 5분 990, 6분 1015, 7분 995, 8분 1020, 9분 1005는 모두 990 이상이라 유지되고, 10분째 985 < 990에서 꺼집니다. 실험에서도 끄기 990은 4·11분에 2번 켜지고 10분에 1번 꺼졌습니다. 10분째
