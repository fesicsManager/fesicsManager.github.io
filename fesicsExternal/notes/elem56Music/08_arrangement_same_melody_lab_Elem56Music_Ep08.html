초등 5~6학년 음악 · 웹툰 8화 「반주를 바꾸면 가락도 바뀔까」

편곡 — 반주를 바꿔도 가락은 그대로

직접 만든 9음 가락에 반주 없음, 피아노 쿵짝짝, 장구 3박, 기타 펼침화음을 입히고 가락 진동수와 바뀐 층을 기록했습니다. 네 반주 모두 가락 진동수는 262·330·392·440·392·330·294·247·262 Hz로 똑같았고, 바뀐 것은 화음·리듬·악기 층이었습니다. 노래의 층과 편곡을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 반주(반주 없음·피아노 쿵짝짝·장구 3박·기타 펼침화음)와 가락(켜기·끄기)을 고르고 들어 보기를 누르면 가락 진동수와 바뀐 층이 기록됩니다. 기록이 4개 이상이면 결과 비교 탭이 열려요. 반주 네 가지를 모두 들어 보고, 반주를 켠 채 가락만 꺼서도 들어 보세요.

반주를 네 가지로 바꿔도 가락 9음(도 미 솔 라 솔 미 레 낮은 시 도)의 진동수는 한 숫자도 바뀌지 않았어요. 반주 없음과 비교해 바뀐 것은 피아노와 기타에서는 화음·리듬·악기 층, 장구에서는 리듬·악기 층이었어요. 노래는 가락(맨 위층), 화음(가운데층), 리듬과 악기(바닥층)로 되어 있고, 편곡은 위층은 그대로 두고 아래층을 바꾸는 일이에요. 느낌이 바뀌었다고 가락이 바뀐 것은 아니에요.

개념 정리

1. 노래는 층으로 되어 있어요

  • 맨 위층: 가락 (계이름·길이·높이)
  • 가운데층: 화음 (함께 울리는 음들)
  • 바닥층: 리듬과 악기 (쿵짝짝, 장단, 펼침화음…)

편곡은 위층(가락)은 그대로 두고 아래층을 바꾸는 일이에요. 그래도 노래 전체의 느낌은 확 바뀌어요.

2. 이 실험의 확인 방법

반주마다 가락 9음의 계이름 · 진동수(Hz)를 적어 비교해요. 모두 같으면 "가락은 그대로"예요.

3. 실험 모형과 실제의 차이

· 실제 편곡에서는 가락의 빠르기나 꾸밈음을 조금 바꾸기도 해요. 이 실험은 반주만 바꾼 경우예요.

4. 생활 속에서 · 이어지는 개념

  • 옥타브는 2 대 1, 어울림은 간단한 비율, 단조는 반음 하나, 형식은 반복과 대비, 장단은 박 나누기, 소리 크기는 10배 눈금. 전부 재고 셀 수 있었어요.
편곡 = 가락(맨 위층)은 그대로 + 화음·리듬·악기(아래층)를 바꿈 → 느낌이 달라진다
닥터 이안

“노래는 층으로 되어 있어. 맨 위가 가락, 그 아래가 화음, 바닥이 리듬과 악기. 편곡은 아래층을 바꾸는 거야.”

예제

가락의 첫 음 도는 262 Hz, 넷째 음 라는 440 Hz예요. 라는 도의 약 몇 배인가요? 반주를 바꾸면 이 값은 달라지나요?

440 ÷ 262 ≈ 1.68배예요(약 3 : 5). 반주를 바꿔도 가락의 진동수는 그대로라서 이 값도 그대로예요. 약 1.68배, 달라지지 않는다

피아노 쿵짝짝 반주를 기타 펼침화음으로 바꾸면, 실험 기록으로 볼 때 무엇이 그대로이고 무엇이 바뀌나요?

두 반주의 화음은 모두 ‘도미솔 · 도미솔 · 솔시레’로 같고, 가락도 그대로예요. 리듬(쿵짝짝 → 한 음씩 펼침)과 악기(피아노 → 기타)가 바뀌어요. 가락·화음은 그대로, 리듬·악기가 바뀜
