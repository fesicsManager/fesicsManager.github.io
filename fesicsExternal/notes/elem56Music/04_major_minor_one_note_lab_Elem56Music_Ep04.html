초등 5~6학년 음악 · 웹툰 4화 「장조와 단조는 다른 음일까」

장3화음과 단3화음 — 가운데 음 반음 하나

도–미–솔에서 한 음씩 움직여 세 음의 간격(반음 수)과 화음 판정을 기록했습니다. 미만 반음 내리자 3 + 4가 되어 도–미♭–솔 단3화음이 되었고, 도를 내리거나 솔을 올리면 기본 모양이 아니었으며, 세 음을 모두 올리면 다시 장3화음(레–파♯–라)이었습니다. 장조와 단조의 차이가 반음 하나라는 것을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 도–미–솔을 바꾸는 방법(그대로·도를 반음 내리기·미를 반음 내리기·솔을 온음 올리기·세 음 모두 온음 올리기)과 듣기(화음·짧은 가락)를 고르고 들어 보기를 누르면 세 음, 쌓은 간격(반음 수), 화음 판정, 바뀐 음 수가 기록됩니다. 기록이 4개 이상이면 결과 비교 탭이 열려요. 다섯 가지 방법을 모두 기록하고, ‘미를 반음 내리기’는 가락으로도 들어 보세요.

표 1. 도–미–솔을 바꾼 결과 (실험 예시)
바꾼 방법세 음간격판정바뀐 음 수
그대로도–미–솔4 + 3장3화음0개
도 ↓반음시–미–솔5 + 3장·단3화음 기본 모양 아님1개
미 ↓반음도–미♭–솔3 + 4단3화음1개
솔 ↑온음도–미–라4 + 5장·단3화음 기본 모양 아님1개
모두 ↑온음레–파♯–라4 + 3장3화음3개

음 하나만 바꾼 세 기록 가운데 미를 반음 내린 것만 3 + 4가 되어 단3화음이 되었어요. 세 음을 모두 바꾼 레–파♯–라는 간격이 4 + 3 그대로라서 오히려 장3화음이었어요. 장3화음과 단3화음은 다른 세계가 아니라 가운데 음 반음 하나의 차이예요. 다만 ‘장조는 밝고 단조는 슬프다’는 흔한 경향일 뿐 공식은 아니에요. 빠르기·셈여림·악기도 느낌을 함께 만들어요.

개념 정리

1. 가운데 음 반음 하나

  • 장3화음(도–미–솔): 아래에서 가운데까지 반음 4개, 가운데에서 위까지 반음 3개 (4 + 3)
  • 단3화음(도–미♭–솔): 가운데 음만 반음 내려 3 + 4

세 음 중 가운데 하나, 그것도 반음 하나만 바꾸면 장3화음이 단3화음이 돼요. 장조와 단조는 다른 세계가 아니라 계단 한 칸의 차이예요.

2. 이 실험의 판정 방법

4 + 3 → 장3화음 · 3 + 4 → 단3화음 · 그 밖 → 기본 모양이 아님

3. 실험 모형과 실제의 차이

· 도를 내린 "시–미–솔"이나 솔을 올린 "도–미–라"는 도 단3화음은 아니지만, 다른 화음(미 단3화음, 라 단3화음)의 음 순서를 바꾼 모양이에요. 이것은 중학교에서 배워요.

· 단조라도 빠르고 크게 연주하면 신나게 들리기도 해요. 느낌은 빠르기·셈여림·악기가 함께 만들어요.

장3화음 = 반음 4 + 3 · 단3화음 = 반음 3 + 4 (가운데 음만 반음 내림)
닥터 이안

“세 음 중 가운데 하나, 그것도 반음 하나. 그것만으로 장3화음이 단3화음이 된다.”

웹툰 4화 #4 · 한 음씩 바꿔 치기

닥터 이안

“단조라도 빠르고 크게 연주하면 신나게 들리기도 해. 느낌은 조성만이 아니라 빠르기·셈여림·악기가 함께 만든다.”

웹툰 4화 #5 · 단조는 꼭 슬플까

예제

도–미–솔과 도–미♭–솔의 간격을 반음 수로 각각 구해 보세요. (도 = 0, 미♭ = 3, 미 = 4, 솔 = 7)

도–미–솔: 4 − 0 = 4, 7 − 4 = 3 → 4 + 3. 도–미♭–솔: 3 − 0 = 3, 7 − 3 = 4 → 3 + 4. 순서가 뒤바뀌었어요. 장3화음 4 + 3, 단3화음 3 + 4

파–라–도는 장3화음이에요(파 = 5, 라 = 9, 높은 도 = 12). 단3화음으로 바꾸려면 어떻게 하나요?

파–라–도는 4 + 3이에요. 가운데 음 라를 반음 내려 라♭(8)으로 하면 3 + 4가 돼요. 파–라♭–도 (가운데 라를 반음 내림)
