빙판 위에서 서로 밀기 — 운동량 보존

실험에서 두 사람의 질량(30~150 kg), 미는 힘(100~400 N), 미는 시간(0.2~1 s)을 바꿔 가며 밀려나는 속도를 기록했습니다. 두 사람의 운동량은 크기가 같고 방향이 반대라 합이 항상 0이었고, 속력 비는 질량의 역비였습니다. 작용·반작용과 운동량 보존을 정리합니다.

빙판 마찰 무시. 왼쪽으로 움직이는 속도는 음(−)입니다.

속력비–질량비 그래프는 기울기 1인 직선입니다. 두 사람의 운동량은 크기가 같고 방향이 반대라 합이 0 — 밀기 전에 둘 다 멈춰 있었으니 밀어낸 뒤에도 합이 0입니다. 이것이 운동량 보존입니다.

개념 정리

1. 작용·반작용에서 운동량 보존으로

두 사람이 서로 밀면 작용·반작용으로 크기가 같고 방향이 반대인 힘을 같은 시간 동안 받습니다. 그래서 두 사람이 받는 충격량(F·Δt)의 크기는 같고 방향은 반대이며, 처음 정지해 있었다면 밀린 뒤에도 두 운동량의 합은 0입니다: m_A·v_A + m_B·v_B = 0. 외부 힘(마찰)이 없으면 계의 총 운동량은 보존됩니다. 가벼운 사람이 더 빠르게 밀려나는 이유는 같은 운동량을 작은 질량이 나눠 갖기 때문입니다.

움직여 보기

빙판에서 서로 밀기 — 운동량의 합은 0 그대로

충격량 J = F·Δt v_A v_B m_A·v_A + m_B·v_B

질량을 바꿔 보세요. 두 사람은 같은 크기의 힘을 같은 시간 받아 운동량 화살표 길이가 늘 같고 방향만 반대입니다. 그래서 가벼운 쪽이 더 빨리 밀려납니다(속력 비 = 질량의 역비). 빙판 마찰 무시, 미는 힘은 일정하다고 가정했고 화면은 실제의 절반 빠르기입니다.

2. 계산해 보기

충격량 J = F × Δt. 100 N × 0.5 s = 50 N·s → 두 사람 모두 운동량 크기 50 kg·m/s. 속도: v_A = −J ÷ m_A, v_B = J ÷ m_B. 50 kg·80 kg이면 −1.0 m/s, +0.63 m/s. 속력 비 = 질량의 역비: v_A : v_B = m_B : m_A. 질량이 같으면 같은 속력으로 반대 방향. 운동 에너지는 보존되지 않습니다(0 → 양수) — 근육이 한 일이 운동 에너지로 바뀐 것이고 가벼운 쪽이 더 많은 에너지를 가져갑니다.

3. 모형과 실제, 생활 속에서

빙판 마찰과 공기 저항을 0으로, 미는 힘을 일정하다고 가정했습니다. 실제로는 미는 동안 힘이 변하고 마찰 때문에 밀린 뒤 서서히 멈춥니다. 사람은 강체가 아니라 팔을 펴는 동안 몸의 일부만 먼저 움직이지만 질량 중심의 운동량 합은 보존됩니다. 총의 반동, 로켓 추진(가스를 뒤로 밀어 앞으로 나아감), 우주 유영 중 공구를 던지면 반대로 밀려나는 것 모두 운동량 보존이고, 당구·컬링에서 충돌 후 속도를 예측할 때도 같은 법칙을 씁니다.

J = F·Δt  ·  v_A = −J ÷ m_A, v_B = +J ÷ m_B  ·  m_A·v_A + m_B·v_B = 0

속력 비 = 질량의 역비 · 운동량 보존 (외력 0) · 운동 에너지는 보존 안 됨(근육의 일)

예제

40 kg인 A와 120 kg인 B가 서로 밀어 A가 −3.0 m/s로 밀려났다. B의 속도는?

40 × (−3.0) + 120 × v_B = 0 → v_B = +1.0 m/s. 질량이 3배이므로 속력은 1/3.

우주 유영 중인 우주인(80 kg)이 2 kg 공구를 4 m/s로 던졌다. 우주인은 어떻게 될까?

운동량 보존: 80 × v = −2 × 4 → v = −0.1 m/s(반대 방향). 느리지만 멈출 방법이 없어 위험합니다 — 실제로는 안전줄을 씁니다.
