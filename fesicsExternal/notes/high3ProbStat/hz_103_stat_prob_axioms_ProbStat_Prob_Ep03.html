확률 0과 1 — 연속에서는 불가능·반드시와 다르다

0~1 구간에서 점을 여러 번 뽑아 ‘정확히 0.5’, ‘0.5가 아닌 수’, ‘0.4~0.6 사이’가 실제로 몇 번 일어나는지 기록했습니다. 정확히 0.5는 한 번도 나오지 않았고, 0.4~0.6은 약 20%였습니다. 확률 0·1과 ‘불가능·반드시’의 차이를 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 뽑을 점의 개수(10~2000)와 살펴볼 사건(라디오 단추 3개)을 고른 뒤 ‘구간에서 점 뽑기’를 누르면 한 행씩 기록됩니다. 세 사건을 모두 포함해 4개 이상 기록하면 분석이 열립니다.

표 1. 구간 [0, 1]에서 점을 뽑을 때 (실험 예시, 무작위)
상황확률실제로 일어나나해석
정확히 0.500 / 100확률 0 인데 불가능은 아님
0.5 가 아님1100 / 100확률 1 인데 반드시는 아님
0.4~0.60.221 / 100길이의 비
0.4~0.60.2398 / 2000길이의 비
정확히 0.500 / 2000확률 0 인데 불가능은 아님

연속인 구간에서 확률은 길이의 비라 0.4~0.6은 0.2, 한 점은 길이가 0이라 확률 0입니다. 그래도 0.5가 뽑히는 것이 배제되지는 않으므로 P(A) = 0이어도 A가 공사건이 아닐 수 있습니다. 유한 표본공간(근원사건 확률이 모두 양수)에서만 P(A) = 0 ⟺ A = ∅이 성립합니다. 확률 1은 ‘거의 확실’일 뿐 ‘반드시’와는 다릅니다.

개념 정리

1. 확률 1 은 “거의 확실”, 확률 0 은 “거의 일어나지 않음” — “반드시”와는 다르다

0 과 1 사이에서 점을 하나 뽑을 때 정확히 0.5 가 나올 확률은 0 이에요. 그래도 불가능하지는 않습니다. 반대로 “0.5 가 아닌 수가 나올 확률”은 1 이지만, 0.5 가 나올 가능성이 아주 없지는 않습니다. 유한한 경우에서는 P = 0 이 곧 불가능이지만, 연속인 경우에는 다릅니다.

왜 그럴까

  • 한 점의 길이는 0 이라 전체 길이에 대한 비가 0 입니다.
  • P(A) = 0 이어도 A 가 공집합이 아닐 수 있습니다.
  • 유한 표본공간에서 근원사건의 확률이 모두 0 보다 크면 P(A) = 0 ⟺ A = ∅ 이 성립합니다.

2. 자주 하는 오해 바로잡기

· “확률이 1이면 반드시 일어난다” → 연속 확률에서는 예외가 있을 수 있습니다.

예제

주사위를 한 번 던질 때 7의 눈이 나오는 사건의 확률은? 이 사건은 공사건인가?

유한 표본공간 {1, …, 6}에 7이 없으므로 P = 0이고 공사건(불가능)입니다.

[0, 1]에서 임의로 뽑은 수가 0.2 이상 0.45 이하일 확률은?

길이의 비 (0.45 − 0.2) ÷ 1 = 0.25
