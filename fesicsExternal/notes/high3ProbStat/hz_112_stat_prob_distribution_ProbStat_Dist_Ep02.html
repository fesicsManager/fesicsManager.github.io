확률분포의 조건 — 0 이상, 합은 정확히 1

X = 1, 2, 3, 4의 확률을 0.05 단위로 자유롭게 넣어 합과 분포 여부를 기록했습니다. 합이 정확히 1일 때만 분포로 인정되었고, 0.8이나 1.2이면 분포가 아니었습니다. 확률분포의 두 조건과 미정계수 구하기를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 P(X=1)~P(X=4)를 슬라이더(0.05 단위)로 조절하고 버튼을 누르면 한 행씩 기록됩니다. 합이 1인 경우와 아닌 경우를 섞어 4개 이상 기록하면 분석이 열립니다.

확률분포가 되려면 ① 각 확률 ≥ 0, ② 합 = 1이어야 합니다. X가 가질 수 있는 값들이 표본공간 전체를 빠짐없이, 겹치지 않게 나누기 때문입니다. 합이 1보다 작으면 값을 빠뜨렸거나, 크면 겹쳐 셌거나, 단순히 잘못 넣은 것일 수 있습니다. 합이 1이 아니면 기댓값 계산도 의미를 잃으며, 미지수가 있는 분포표는 ‘합 = 1’로 풉니다.

개념 정리

1. 확률분포의 두 조건 — 각 확률이 0 이상, 모두 더하면 정확히 1

확률분포가 되려면 ① 모든 값이 0 이상이고 ② 합이 정확히 1 이어야 해요. 합이 1보다 작으면 “어딘가 빠진 경우”가 있을 수 있고, 크면 겹쳐 센 것일 수 있습니다 — 단순히 값을 잘못 넣은 것일 수도 있으니 무엇이 잘못됐는지는 따로 따져 봐야 합니다. 이 조건은 기댓값·분산 계산의 전제이기도 합니다.

왜 그럴까

  • 표본공간 전체의 확률이 1 이기 때문입니다.
  • 합이 1 이 아니면 기댓값 계산도 의미를 잃습니다.
  • 미지수가 있는 분포표는 “합 = 1”로 값을 구합니다.

2. 자주 하는 오해 바로잡기

· “확률의 합이 1 이 아닐 수도 있다” → 그러면 분포가 아닙니다.

3. 생활 속에서 · 이어지는 개념

  • 설문 응답 비율의 합이 100%가 안 되면 무응답이 빠진 것입니다.
네 확률을 자유롭게 넣어 합을 확인하고, 1 에 맞췄을 때와 아닐 때의 기댓값을 비교

예제

P(X=1) = a, P(X=2) = 2a, P(X=3) = 3a, P(X=4) = 4a일 때 a는?

a + 2a + 3a + 4a = 10a = 1 → a = 0.1

P(X = x) = kx (x = 1, 2, 3)일 때 P(X ≥ 2)는?

k(1 + 2 + 3) = 1 → k = 1/6, P(X ≥ 2) = (2 + 3)/6 = 5/6
