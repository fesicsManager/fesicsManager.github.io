함수의 개수 — 정의역이 지수, 공역이 밑

정의역의 원소 수 m과 공역의 원소 수 n을 바꾸며 함수의 수 nᵐ, 일대일함수의 수 ₙPₘ, 두 집합을 바꾼 mⁿ을 기록했습니다. 대부분 nᵐ과 mⁿ이 달랐고, m > n이면 일대일함수는 0개였습니다. 곱의 법칙으로 함수를 세는 방법을 정리합니다.

정의역의 원소 하나하나가 공역의 n개 중 하나를 독립적으로 고르므로 함수의 수 = nᵐ입니다. 지수는 정의역, 밑은 공역이라 자리를 바꾸면 값이 달라집니다(m = 2, n = 4에서만 우연히 16으로 같음). 일대일함수는 고른 것을 다시 쓸 수 없어 ₙPₘ이고, m > n이면 0개 — 비둘기집 원리입니다.

개념 정리

1. 함수의 개수는 nᵐ — 정의역이 지수, 공역이 밑

정의역의 원소 하나하나가 공역의 n개 중 하나를 고릅니다. 그래서 n × n × … (m번) = nᵐ 이에요. m과 n을 바꾸면 값이 완전히 달라집니다. 일대일함수는 겹치면 안 되므로 ₙPₘ 입니다.

왜 그럴까

  • 각 원소가 독립적으로 선택하므로 곱의 법칙이 적용됩니다.
  • 일대일이려면 고른 것을 다시 쓸 수 없어 선택지가 하나씩 줄어듭니다.
  • m > n 이면 일대일함수는 0개 — 비둘기집 원리입니다.

움직여 보기

정의역의 원소마다 공역에서 하나씩 고른다

함수 nᵐ 일대일 ₙPₘ 바꾸면 mⁿ 보는 중

m, n을 정하고 ▶를 눌러 함수를 하나씩 넘겨 보세요. 화살표 m개가 저마다 n곳 중 하나를 고르니 n × n × … = nᵐ개입니다. '일대일함수만'을 누르면 화살표 끝이 겹치는 함수가 빠지고(ₙPₘ), m > n이면 하나도 남지 않습니다. 예제: m = 3, n = 5 → 125개, 60개.

2. 자주 하는 오해 바로잡기

· “정의역과 공역은 바꿔도 된다” → nᵐ 과 mⁿ 은 전혀 다릅니다.

예제

X = {1, 2, 3}에서 Y = {a, b, c, d, e}로의 함수의 수와 일대일함수의 수는?

함수: 5³ = 125, 일대일함수: ₅P₃ = 5 × 4 × 3 = 60 → 125개, 60개

X = {1, 2, 3, 4}에서 Y = {1, 2}로의 함수 중 치역이 Y 전체인 함수의 수는?

전체 2⁴ = 16개에서 모두 1로 가는 것, 모두 2로 가는 것 2개를 빼면 14개
