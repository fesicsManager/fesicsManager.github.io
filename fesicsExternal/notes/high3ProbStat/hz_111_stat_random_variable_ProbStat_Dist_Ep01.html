확률변수 — 미지수가 아니라 결과에 수를 붙이는 함수

동전 세 개의 8가지 결과에 ‘앞면의 개수’, ‘첫 동전이 앞이면 1’, ‘앞면 − 뒷면’으로 X를 정해 보고, 같은 값의 결과 수와 P(X = 값)을 기록했습니다. 표본공간은 그대로인데 X의 정의에 따라 가질 수 있는 값과 확률이 달랐고, 확률의 합은 늘 1이었습니다. 확률변수의 뜻을 정리합니다.

실험 안내: 자유 탐구 탭에서 X의 정의(라디오 단추 3개)와 확인할 값 k(정의에 따라 앞면 개수 0~3, 첫 동전 0~1, 앞면−뒷면 −3·−1·1·3)를 고른 뒤 버튼을 누르면 한 행씩 기록됩니다. 세 정의를 모두 포함해 4개 이상 기록하면 분석이 열립니다.

확률변수 X는 표본공간의 각 결과에 실수를 하나씩 대응시키는 함수입니다. 같은 8가지 결과라도 X를 앞면 개수로 정하면 값이 0~3, 앞 − 뒤로 정하면 −3, −1, 1, 3이 됩니다. P(X = k)는 X 값이 k가 되는 결과들의 확률을 모은 것이고, 모든 값의 확률을 더하면 1입니다.

개념 정리

1. 확률변수는 “표본공간의 각 결과에 수를 대응시키는 함수”

X 는 풀어서 구하는 미지수가 아니라, 결과 하나하나에 수를 붙이는 함수예요. 같은 시행이라도 X 를 어떻게 정하느냐에 따라 전혀 다른 확률변수가 됩니다. P(X = k) 는 X 값이 k 가 되는 결과들의 확률을 모은 것입니다.

왜 그럴까

  • X : Ω → ℝ — 정의역은 표본공간 Ω, 즉 개별 결과 ω 하나하나의 모임입니다. 사건(결과들의 집합)이 아닙니다.
  • 같은 값을 갖는 결과들을 묶어 확률을 더한 것이 확률분포입니다.
  • 모든 값의 확률을 더하면 1 이 됩니다.

2. 자주 하는 오해 바로잡기

· “확률변수는 미지수다” → 값을 구하는 대상이 아니라 대응 규칙입니다.

3. 생활 속에서 · 이어지는 개념

  • 설문의 각 응답에 점수를 매기는 채점 규칙이 바로 확률변수입니다.

예제

동전 3개를 던질 때 X = 앞면의 개수이면 P(X = 2)는?

앞앞뒤, 앞뒤앞, 뒤앞앞 3가지 → 3/8

주사위 두 개를 던져 X = (큰 눈 − 작은 눈)이라 할 때, X가 가질 수 있는 값과 P(X = 0)은?

값은 0, 1, 2, 3, 4, 5. X = 0은 같은 눈 6가지 → P(X = 0) = 6/36 = 1/6
