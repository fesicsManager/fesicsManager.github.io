방정식의 정수해 — 자연수 조건은 1씩 미리 배정

x + y + z = n의 n을 3~12로 바꾸며 해를 모두 나열해 음이 아닌 정수해와 자연수해의 개수를 세었습니다. 나열한 개수는 ₍ₙ₊₂₎C₂, ₍ₙ₋₁₎C₂와 정확히 일치했고, 두 개수의 차이는 n이 커질수록 벌어졌습니다. 중복조합으로 정수해를 세는 방법을 정리합니다.

음이 아닌 정수해는 ₃Hₙ = ₍ₙ₊₂₎C₂(칸막이 방법)입니다. 자연수해는 각 변수에 1씩 미리 배정하면 x′ + y′ + z′ = n − 3의 음이 아닌 정수해가 되어 ₍ₙ₋₁₎C₂입니다. 표에서 두 개수의 차이는 9, 12, 18, … 로 n이 커질수록 벌어졌습니다 — ‘자연수’인지 ‘음이 아닌 정수’인지 한 단어에 답이 달라집니다.

개념 정리

1. 자연수 해는 각 변수에서 1씩 빼서 음이 아닌 정수 문제로 바꾼다

x+y+z = n 의 음이 아닌 정수해는 ₃H_n = ₍n+2₎C₂ 예요. 자연수해(1 이상)는 각 변수에서 1씩 미리 빼 두면 x′+y′+z′ = n−3 의 음이 아닌 정수해와 같아져 ₍n−1₎C₂ 가 됩니다. 조건 한 줄에 답이 완전히 달라집니다.

왜 그럴까

  • 중복조합 ₙHᵣ = ₍n+r−1₎Cᵣ — 칸막이 방법으로 셉니다.
  • 자연수 조건은 “각 변수에 최소 1개씩 미리 배정”으로 처리합니다.
  • 일반적으로 xᵢ ≥ aᵢ 조건은 모두 이 방법으로 바꿉니다.

움직여 보기

사탕 n개와 칸막이 2개 — 해를 하나씩 넘겨 보기

음이 아닌 정수해 ₃Hₙ = ₍ₙ₊₂₎C₂ 자연수해 ₍ₙ₋₁₎C₂ 보는 중

x + y + z = n 의 해 하나는 사탕(●) n개와 칸막이(|) 2개를 한 줄로 놓는 방법 하나와 같습니다. 칸막이 왼쪽이 x, 가운데가 y, 오른쪽이 z. '자연수해'를 누르면 회색 사탕을 한 개씩 미리 나눠 주고 남은 n − 3개만 나누므로 개수가 확 줄어듭니다(표: n = 6 → 28개, 10개).

2. 자주 하는 오해 바로잡기

· “음이 아닌 정수와 자연수는 같은 조건이다” → 개수가 크게 다릅니다.

3. 생활 속에서 · 이어지는 개념

  • 사탕을 나눠 줄 때 “한 개도 못 받을 수 있다”와 “최소 한 개씩”이 전혀 다른 문제입니다.

예제

x + y + z + w = 8의 음이 아닌 정수해의 개수는?

₄H₈ = ₁₁C₈ = ₁₁C₃ = 165개

x + y + z = 10에서 x ≥ 2, y ≥ 1, z ≥ 0인 정수해의 개수는?

x′ = x − 2, y′ = y − 1로 두면 x′ + y′ + z = 7 → ₃H₇ = ₉C₂ = 36개
