뽑는 순서 — 중간 확률은 달라도 최종은 같다

빨간 공과 파란 공의 개수를 바꾸며 비복원으로 ‘빨강 다음 파랑’과 ‘파랑 다음 빨강’의 확률을 각각 곱셈정리로 계산했습니다. 중간의 조건부확률은 매번 달랐지만 곱한 최종 확률은 항상 같았습니다. 뽑는 순서와 확률의 관계를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 빨간 공·파란 공 개수(각 2~8)를 정하고 버튼을 누르면 한 행씩 기록됩니다. 개수를 바꿔 가며 4개 이상 기록하면 분석이 열립니다.

표 1. 비복원으로 두 번 뽑을 때 두 순서의 확률 (실험 예시)
순서첫 번째두 번째(조건부)곱반대 순서같나
빨→파 (빨 3·파 5)0.3750.71430.2678570.267857✅
빨→파 (빨 4·파 6)0.40.66670.2666670.266667✅
빨→파 (빨 2·파 2)0.50.66670.3333330.333333✅
빨→파 (빨 5·파 3)0.6250.42860.2678570.267857✅
빨→파 (빨 6·파 8)0.42860.61540.2637360.263736✅

빨→파는 (r/n)·(b/(n−1)), 파→빨은 (b/n)·(r/(n−1))로 둘 다 rb / (n(n−1))로 정리되어 같습니다. 하지만 중간의 조건부확률 P(파|빨) = b/(n−1)과 P(빨|파) = r/(n−1)은 다릅니다. 같은 이유로 두 번째 공이 빨강일 확률도 r/n으로 첫 번째와 같습니다 — 제비뽑기에서 순서가 공평한 까닭입니다.

개념 정리

1. 조건부확률은 순서에 따라 다르지만, 곱한 최종 확률은 같다

“빨강 다음 파랑”의 확률은 P(빨강)·P(파랑|빨강) 이고, “파랑 다음 빨강”은 P(파랑)·P(빨강|파랑) 이에요. 중간 값은 다르지만 곱한 결과는 같습니다. 분모와 분자가 자리만 바꿔 곱해지기 때문입니다.

왜 그럴까

  • 두 확률 모두 (빨강 수 × 파랑 수) / (n × (n−1)) 로 정리됩니다.
  • 조건부확률 자체는 달라도 곱셈정리의 결과는 대칭입니다.
  • 두 번째로 뽑는 공의 확률이 첫 번째와 같은 것도 같은 이유입니다.

2. 자주 하는 오해 바로잡기

· “순서를 바꿔도 결과는 같다” → 중간 확률은 달라지고 최종만 같습니다.

3. 생활 속에서 · 이어지는 개념

  • 제비뽑기에서 먼저 뽑든 나중에 뽑든 당첨 확률이 같은 이유입니다.
두 순서로 각각 조건부확률을 계산하고 곱한 값을 비교
📋 데이터 확인 탭의 결론

“모든 기록에서 두 순서의 최종 확률이 같았습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

당첨 2개가 포함된 제비 10개에서 A가 먼저, B가 나중에 1개씩 뽑는다. B가 당첨될 확률은?

A 당첨 후: 2/10 × 1/9 = 2/90, A 꽝 후: 8/10 × 2/9 = 16/90 → 합 18/90 = 1/5 (A와 같음)

빨간 공 4개, 파란 공 2개에서 비복원으로 두 번 뽑을 때, 빨→파와 파→빨의 확률은?

4/6 × 2/5 = 8/30, 2/6 × 4/5 = 8/30 → 둘 다 4/15
