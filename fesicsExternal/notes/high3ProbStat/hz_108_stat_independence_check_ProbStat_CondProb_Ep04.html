사건의 독립 — 조건을 붙여도 확률이 그대로

2×2 표의 네 칸 인원을 조절하며 P(B), P(B|A), P(B|Aᶜ), P(A)P(B)를 기록했습니다. 두 행의 비율이 같을 때(ad = bc) 세 확률이 모두 같아 독립이었고, 그렇지 않으면 A가 B의 확률을 바꾸었습니다. 독립의 세 가지 동치 조건을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 A∩B, A∩Bᶜ, Aᶜ∩B, Aᶜ∩Bᶜ 네 칸의 인원(각 1~30)을 조절하고 버튼을 누르면 한 행씩 기록됩니다. 독립인 배치와 아닌 배치를 섞어 4개 이상 기록하면 분석이 열립니다.

표 1. 네 칸(a / b / c / d)에 따른 독립 판정 (실험 예시)
표P(B)P(B|A)P(B|Aᶜ)P(A)P(B)독립
12/8/18/120.60.60.60.24✅
10/10/10/100.50.50.50.25✅
15/5/10/200.50.750.33330.2❌
6/4/9/60.60.60.60.24✅
20/10/5/150.50.66670.250.3❌

독립 ⟺ P(B|A) = P(B) ⟺ P(A∩B) = P(A)P(B) ⟺ P(B|Aᶜ) = P(B). 표에서는 A 행과 Aᶜ 행의 B 비율이 같을 때, 곧 ad = bc일 때입니다. 12/8/18/12에서 P(A∩B) = 12/50 = 0.24 = P(A)P(B)였고, 15/5/10/20에서는 0.3 ≠ 0.2였습니다. 독립과 배반은 다릅니다 — 배반이면 P(B|A) = 0이라 오히려 강하게 종속입니다.

개념 정리

1. 독립 ⟺ P(B|A) = P(B) ⟺ P(A∩B) = P(A)P(B)

독립이라는 말은 A 가 일어났다는 정보가 B 의 확률을 바꾸지 않는다는 뜻이에요. 조건을 붙여도 확률이 그대로면 독립입니다. 표에서는 두 행의 비율이 같아질 때 성립합니다.

왜 그럴까

  • P(B|A) = P(A∩B)/P(A) 이므로, 이것이 P(B) 와 같으면 P(A∩B) = P(A)P(B).
  • 독립이면 P(B|Aᶜ) = P(B) 도 성립합니다.
  • 독립과 배반은 다릅니다 — 배반이면 오히려 강하게 종속입니다.

2. 자주 하는 오해 바로잡기

· “독립이면 조건부확률도 달라진다” → 달라지지 않는 것이 독립입니다.

3. 생활 속에서 · 이어지는 개념

  • 광고를 본 것과 구매가 독립이면 광고 효과가 없다는 뜻입니다.

예제

P(A) = 0.4, P(B) = 0.5, P(A∩B) = 0.2일 때 A와 B는 독립인가?

P(A)P(B) = 0.4 × 0.5 = 0.2 = P(A∩B) → 독립

두 집단의 안경 비율이 같아야 하므로 12/30 = x/20 → x = 8
