경우의 수 분류 — 순서와 중복, 두 질문

n = 4, r = 2로 두고 ‘순서를 따지나’, ‘중복을 허용하나’의 답을 바꾸며 공식과 값을 기록했습니다. 같은 n, r인데도 6, 10, 12, 16으로 값이 모두 달랐습니다. 두 질문으로 네 가지 공식을 고르는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 n, r을 정하고 ‘순서’와 ‘중복’ 라디오 단추를 고른 뒤 ‘갈래를 따라가기’를 누르면 한 행씩 기록됩니다. 네 가지 조합을 모두 4개 이상 기록하면 분석이 열립니다.

표 1. n = 4, r = 2일 때 네 갈래 (실험 예시)
순서중복상황공식값
따짐안 함회장·부회장 뽑기ₙPᵣ12
따짐허용비밀번호 만들기nʳ16
안 따짐안 함대표 2명 뽑기ₙCᵣ6
안 따짐허용같은 사탕 나눠 주기ₙ₊ᵣ₋₁Cᵣ (ₙHᵣ)10

① 순서를 따지나 ② 중복을 허용하나, 두 질문에 답하면 공식이 정해집니다. 순서를 따지지 않으면 r!가지 배열이 하나로 묶여 ₙPᵣ = 12가 ₙCᵣ = 6이 되고, 중복을 허용하면 고를 때마다 선택지가 줄지 않아 nʳ = 16이 됩니다. 중복조합 ₙHᵣ = ₙ₊ᵣ₋₁Cᵣ은 칸막이 방법으로 셉니다.

개념 정리

1. 순서 × 중복 두 질문이 네 가지 공식을 가른다

순서를 따지고 중복 없으면 ₙPᵣ, 중복 허용이면 nʳ. 순서를 안 따지고 중복 없으면 ₙCᵣ, 중복 허용이면 ₙ₊ᵣ₋₁Cᵣ 예요. 문제를 보고 공식을 “느낌으로” 고르는 대신, 두 질문에 먼저 답하면 됩니다.

왜 그럴까

  • 순서를 따지지 않으면 r! 가지 배열이 한 가지로 묶입니다.
  • 중복을 허용하면 고를 때마다 선택지가 줄지 않습니다.
  • 중복조합은 칸막이 방법으로 n+r−1 자리에서 r개를 고르는 것과 같습니다.

2. 자주 하는 오해 바로잡기

· “문제를 보면 공식이 바로 정해진다” → 두 질문을 거쳐야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 비밀번호, 대표 선출, 사탕 나눠 주기가 각각 다른 칸에 들어갑니다.
두 질문의 답을 바꿔 가며 네 가지 공식의 값을 계산하고, 같은 n·r 에서 얼마나 다른지 확인

예제

서로 다른 과일 5종류에서 3개를 사는데 같은 종류를 여러 개 사도 되는 경우의 수는?

순서 ×, 중복 ○ → ₅H₃ = ₇C₃ = 35가지

1, 2, 3, 4, 5로 세 자리 자연수를 만들 때, 숫자 중복을 허용하는 경우와 허용하지 않는 경우의 수는?

순서 ○이므로 중복 허용 5³ = 125, 중복 금지 ₅P₃ = 60 → 125개, 60개

₄H₂ = ₅C₂ = 10.
