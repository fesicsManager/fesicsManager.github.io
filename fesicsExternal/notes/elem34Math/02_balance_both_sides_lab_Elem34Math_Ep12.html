초등 3~4학년 수학 · 웹툰 12화 「저울을 기울이지 않는 법」

등식의 성질 — 양쪽에 똑같이 해야 평평하다

평평한 저울 위의 등식(4 + 2 = 6 등)에 ‘양쪽에 2 더하기’, ‘왼쪽에만 2 더하기’ 같은 일을 하고 저울이 평평하게 남는지 기록했습니다. 양쪽에 똑같은 일을 했을 때만 평평했고, 한쪽만 바꾸거나 양쪽에 다른 수를 더하면 기울었어요. 등호(=)를 지키는 규칙을 정리합니다.

실험 안내: 🔬 자유 탐구 탭에서 처음 등식, 저울에 할 일, 나의 예상(평평하다·기울어진다)을 고르고 저울에 적용하기를 누르면 양쪽 값과 저울 모습이 나오고 기록표에 저절로 쌓여요. 기록이 4개 이상이면 ✅ 결과 비교 탭에서 ‘양쪽에 똑같이·한쪽만·양쪽에 다르게’별 결과를 볼 수 있어요.

평평하게 남은 경우는 모두 양쪽에 똑같은 일을 한 경우였어요(더하기·빼기·곱하기 모두). 양쪽에 무언가를 했어도 2와 3처럼 다른 수를 더하면 9와 10이 되어 기울었어요.

개념 정리

1. 등호는 “양쪽의 값이 같다”는 약속

등식 4 + 2 = 6은 저울이 평평한 상태와 같아요. 이 평평함을 지키려면 양쪽에 똑같은 일을 해야 합니다.

  • 양쪽에 같은 수를 더해도, 양쪽에서 같은 수를 빼도, 양쪽에 같은 수를 곱해도 등호는 지켜져요.
  • 한쪽만 바꾸면 그쪽만 무거워지거나 가벼워져 저울이 기울어요.
  • 양쪽에 다른 수를 더해도 기울어요. “양쪽에 뭔가 했다”가 아니라 “똑같은 일을 했다”가 중요해요.

움직여 보기

양쪽에 똑같은 일을 하면 저울은 평평하게 남을까?

왼쪽 값 오른쪽 값 상태

처음은 4 + 2 = 6이에요. 양쪽에 같은 수를 더하거나 빼거나 곱하면 저울은 평평한 채로 남고, 한쪽만 바꾸면 기울어요. 기운 저울은 반대쪽에도 똑같이 해 주면 다시 평평해져요.

2. 이 실험의 계산 방법

왼쪽 값 = 오른쪽 값 이면 평평, 다르면 큰 쪽으로 기울어요.

3. 실험 모형과 실제의 차이

· 실제 저울은 접시 무게, 받침점 위치에 따라 조금씩 달라질 수 있지만, 수학의 저울은 값만 비교하는 약속이에요.

4. 생활 속에서 · 이어지는 개념

  • □ + 3 = 8 에서 양쪽에서 3을 빼면 □ = 5 가 돼요. 5·6학년과 중학교에서 방정식을 푸는 방법이 바로 이 저울 지키기입니다.

📋 실험 화면의 판정

“평평해요 — 등호(=)가 지켜졌어요”

실험 「자유 탐구」 · 양쪽에 똑같은 일을 했을 때

예제

□ + 3 = 8 에서 □를 구하려면 저울 양쪽에 어떤 똑같은 일을 하면 될까요?

양쪽에서 똑같이 3을 빼요. 왼쪽은 □ + 3 − 3 = □, 오른쪽은 8 − 3 = 5. 저울이 평평하므로 □ = 5예요.

4 + 2 = 6 저울의 왼쪽에만 2를 더했어요. 다시 평평하게 하려면?

왼쪽은 8, 오른쪽은 6이라 왼쪽이 2만큼 무거워요. 오른쪽에도 2를 더하면 8 = 8로 평평해져요. 결국 양쪽에 똑같이 2를 더한 것과 같아요.
