고등 정보 ② · 웹툰 7화 「추천 알고리즘은 취향을 읽는가, 만드는가」

필터 버블 — 클릭이 추천을 만들고 추천이 클릭을 만든다

주제 5개가 각 20 %인 추천 화면에서 하루 20개 노출·5개 클릭 모형으로 클릭 위주·인기 위주·다양성 보정 추천 방식을 바꿔 가며 날짜별 상위 주제 비율과 다양성(엔트로피 비)을 기록했습니다. 게임만 클릭하면 게임 비율이 20 → 33 → 50 → 67 %로 5일 만에 80 %를 넘었고, 각 주제 최소 10 %를 보장하면 60 % 근처에서 멈췄습니다. 되먹임과 알고리즘의 책임을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 하루에 추천 20개를 보고 5개를 클릭합니다. 클릭 확률은 노출 비율 × 관심도입니다. 다양성 1 = 완전히 고름, 0 = 한 주제뿐.

추천 알고리즘은 내일 노출 ∝ 오늘 노출 × (1 + 2 × 클릭 점유율)처럼 클릭한 것과 비슷한 것을 더 보여 주고, 뜬 것 중에서 또 클릭하니 며칠 만에 화면이 한 주제로 채워집니다 — 필터 버블. 알고리즘은 취향을 읽는 동시에 만들며, 목표 함수(시청 시간 최대화)가 무엇인지 묻는 것이 디지털 시민의 첫 질문입니다.

개념 정리

1. 클릭이 추천을 만들고 추천이 클릭을 만든다

추천 알고리즘은 "당신이 클릭한 것과 비슷한 것"을 더 보여 줘요. 게임 영상 3개를 클릭하면 다음 날 게임이 더 많이 뜨고, 뜬 것 중에서 또 클릭하니 그다음 날은 더 많이 떠요. 이 되먹임이 며칠 만에 화면을 한 주제로 채워요 — 필터 버블. 알고리즘은 취향을 읽는 동시에 만들어요. 계정 A와 B가 처음 클릭 3개만 달라도 하루 뒤 화면이 완전히 달라져요. 그래서 설명 가능성·감사·선택권(다양성 보정, 추천 끄기)이 알고리즘의 책임으로 논의돼요.

계산해 보기

  • 주제 5개, 처음엔 각 20 %. 클릭 위주 추천: 내일 비율 ∝ 오늘 비율 × (1 + 2 × 클릭 점유율). 게임만 클릭하면 게임 비율 20 → 33 → 50 → 67 % … 5일이면 80 % 이상.
  • 다양성 보정(각 주제 최소 10 % 보장)을 넣으면 상위 주제가 60 % 근처에서 멈춰요.

2. 실험 모형과 실제의 차이

· 실제 서비스는 시청 시간·좋아요·친구·시간대 등 수천 개 신호를 쓰고 사람이 직접 튜닝해요. 하지만 "많이 본 것을 더 보여 준다"는 되먹임은 같아요.

· 자주 쓰는 앱의 추천 20개를 주제별로 분류해 상위 주제 비율을 재고, 일주일간 의식적으로 다른 주제를 클릭한 뒤 다시 재 보세요.

3. 생활 속에서 · 이어지는 개념

  • 같은 뉴스 앱이 사람마다 다른 세상을 보여 줘요. 이견을 만나기 어려워지는 것이 사회적 문제예요.
  • "관심 없음" 버튼과 시청 기록 삭제는 되먹임 고리를 끊는 사용자의 선택권이에요.
클릭 확률 ∝ 노출 비율 × 관심도, 내일 노출 ∝ 오늘 노출 × (1 + 2 × 클릭 점유율) (클릭 위주) / 인기 위주는 전체 인기도로 / 다양성 보정은 최소 10 % 보장, 다양성 = 엔트로피 ÷ 최대 엔트로피

예제

게임 비율 40 %, 오늘 클릭 5개 중 5개가 게임이면 내일 게임 비율(정규화 전 가중치)은?

0.4 × (1 + 2 × 1) = 1.2, 나머지 4개 주제 각 0.15 × 1 = 0.6 → 정규화하면 1.2 ÷ 1.8 ≈ 67 %.

되먹임 고리를 끊는 사용자의 선택권 두 가지는?
