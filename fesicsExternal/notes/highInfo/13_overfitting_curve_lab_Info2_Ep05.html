과적합 — 데이터를 외우면 규칙을 못 배운다

y = sin(x) + 잡음 자료에서 학습 데이터 수·잡음 크기·다항식 차수를 바꾸며 학습 오차와 검증 오차(RMSE)를 기록했습니다. 학습 10개·잡음 큼일 때 9차 곡선은 학습 오차 0.00이지만 검증 오차가 폭발했고 검증 오차는 3차에서 최소였으며, 학습 100개면 9차도 검증 오차가 크게 늘지 않았습니다. 과적합·과소적합과 검증 데이터의 원리를 정리합니다.

모델이 복잡할수록 학습 데이터는 더 잘 맞추지만 잡음까지 외워 새 데이터에서 오차가 커집니다(과적합). 너무 단순하면 둘 다 못 맞춥니다(과소적합). 학습 오차는 계속 줄고 검증 오차는 줄다가 꺾여 오르는 그 지점이 적당한 복잡도이며, 데이터를 늘리는 것이 과적합의 첫째 해법입니다.

개념 정리

1. 데이터를 외우면 규칙을 못 배운다

모델이 복잡할수록(다항식 차수가 높을수록) 학습 데이터는 더 잘 맞출 수 있어요. 9차 곡선은 점 10개를 정확히 지나요. 하지만 그 곡선은 잡음까지 외운 것이라, 처음 보는 검증 데이터에서는 오차가 오히려 커져요. 이것이 과적합이에요. 반대로 너무 단순한 모델(1차 직선)은 학습·검증 모두 못 맞춰요(과소적합). 학습 오차는 계속 줄고 검증 오차는 줄다가 꺾여 오르는 그래프 — 그 꺾이는 점이 적당한 복잡도예요.

계산해 보기

  • 학습 10개·잡음 큼: 1차 오차 0.5, 3차 0.15, 9차 0.00 (학습) / 검증은 3차에서 최소, 9차에서 폭발.
  • 학습 100개: 9차도 검증 오차가 크게 안 늘어요 — 데이터를 늘리는 것이 과적합의 첫째 해법이에요.

2. 실험 모형과 실제의 차이

· 실제 모델은 차수 대신 층 수·학습 횟수·특성 수가 복잡도예요. 데이터를 학습 7 : 검증 2 : 시험 1로 나눠 검증 오차가 꺾이는 지점에서 멈춰요(조기 종료).

· 과적합을 줄이는 법 — 데이터 늘리기, 모델 단순화, 규제(가중치 억제), 일부러 노이즈·드롭아웃 주기.

3. 생활 속에서 · 이어지는 개념

  • 기출문제 답만 외운 학생과 원리를 이해한 학생 — 새 문제에서 갈려요.
  • 공개 데이터셋 하나를 7:2:1로 나눠 간단한 분류 모델을 학습시키고 학습·검증 정확도 그래프를 그려 과적합 시작점을 표시해 보세요.

예제

데이터 1 000개를 7 : 2 : 1로 나누면 각각 몇 개이고 무엇에 쓰나?

학습 700(다이얼 맞추기), 검증 200(멈출 때 정하기·모델 고르기), 테스트 100(최종 점수, 딱 한 번).

학습 오차 0.02, 검증 오차 0.6인 모델의 상태와 해법 두 가지는?

과적합. 해법: 데이터 늘리기, 모델 단순화(또는 규제·드롭아웃·조기 종료).
