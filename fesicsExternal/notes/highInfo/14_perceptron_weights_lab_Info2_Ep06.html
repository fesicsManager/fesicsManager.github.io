퍼셉트론 학습 — 학습 = 다이얼(가중치) 돌리기

입력 2개·가중치 2개·편향 1개인 뉴런 하나로 AND·OR·XOR를 학습률과 에포크 수를 바꿔 학습시키고, 정답률과 경계선 w₁x₁ + w₂x₂ + b = 0을 기록했습니다. AND·OR는 몇 에포크 만에 100 %가 되었지만 XOR는 에포크를 아무리 늘려도 직선 하나로 나눌 수 없어 75 %를 넘지 못했습니다. 가중치 갱신 규칙과 다층 신경망의 원리를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 퍼셉트론 학습 규칙을 에포크 수만큼 반복합니다(예제 순서 (0,0)(0,1)(1,0)(1,1)). 빨강 = 정답 1, 파랑 = 정답 0.

뉴런 하나는 출력 = (w₁x₁ + w₂x₂ + b > 0) ? 1 : 0이고, 학습은 틀린 예제마다 w ← w + 학습률 × (정답 − 출력) × x로 다이얼을 조금 돌리는 일입니다. XOR처럼 직선 하나로 못 나누는 문제는 층을 쌓아 곡선 경계를 만듭니다 — 첫 층은 선, 다음 층은 모양, 그다음은 얼굴.

개념 정리

1. 학습 = 다이얼(가중치) 돌리기

뉴런 하나는 출력 = (w₁x₁ + w₂x₂ + b > 0) ? 1 : 0이에요. w₁·w₂·b가 다이얼이고, 학습은 틀린 예제마다 w ← w + 학습률 × (정답 − 출력) × x로 다이얼을 조금 돌리는 일이에요. 몇 바퀴(에포크) 돌면 AND·OR는 100 %가 돼요. 그런데 XOR는 직선 하나로 나눌 수 없어 뉴런 하나로는 영원히 못 맞춰요(1969년 민스키). 층을 쌓으면(다층 신경망) 곡선 경계가 생겨 XOR도 풀려요. 첫 층은 선, 다음 층은 모양, 그다음은 얼굴 — 깊은 신경망은 다이얼이 백만 개예요.

계산해 보기 (AND, 학습률 0.5)

  • 시작 w = (0.2, −0.3), b = 0.1. 첫 예제 (0,0) 정답 0인데 출력 1(0.1 > 0) → 입력이 0이라 w는 그대로, b ← −0.4. (0,1)·(1,0)은 맞히고, (1,1) 정답 1인데 출력 0(−0.5) → w ← (0.7, 0.2), b ← 0.1.
  • 2바퀴째: (0,0) 또 틀려 b ← −0.4, (1,0) 정답 0인데 출력 1 → w₁ ← 0.2, b ← −0.9, (1,1) 틀려 w ← (0.7, 0.7), b ← −0.4 … 이렇게 고쳐 가면 3바퀴 뒤엔 w = (1.2, 0.7), b = −0.4로 2/4이고, 모두 13번 고친 6바퀴째에 w = (1.2, 0.7), b = −1.4가 되어 네 점 모두 정답.

움직여 보기

다이얼(가중치)을 돌리며 경계선을 찾는 뉴런 하나

문제

바퀴 수를 0부터 올려 보세요. 틀린 점(빨간 고리)이 있을 때마다 w와 b가 바뀌고 경계선이 움직여요. 색칠된 쪽이 출력 1이에요. AND는 6바퀴째에 4/4가 되지만, XOR는 아무리 돌려도 직선 하나로 나눌 수 없어요(시작 w = (0.2, −0.3), b = 0.1, 학습률 0.5).

2. 실험 모형과 실제의 차이

· 실제 신경망은 0/1 계단 대신 부드러운 함수(시그모이드·ReLU)를 쓰고, 오차를 뒤로 전파해(역전파) 모든 층의 다이얼을 한꺼번에 조정해요.

· 표계산 프로그램으로 뉴런 하나를 만들어 가중치를 손으로 바꿔 가며 AND를 맞혀 보세요. 몇 번 만에 됐나요?

3. 생활 속에서 · 이어지는 개념

  • 사진 속 고양이를 알아보는 신경망도 원리는 같아요. 다이얼이 수억 개이고 예제가 수백만 장일 뿐이에요.
  • "학습한 AI"는 규칙을 사람이 적은 게 아니라 다이얼이 데이터로 맞춰진 거예요. 그래서 왜 그렇게 답했는지 설명이 어려워요.

닥터 이안 · 제로 · 뭉치

“예측이 틀리면 ‘얼마나 틀렸나’(손실)를 재고, 손실이 줄어드는 방향으로 다이얼을 조금 돌린다. 이걸 수백만 번.” “산에서 내려갈 때 가장 가파른 쪽으로 한 걸음씩 가는 것 같네요.” “정확히 그 이름이다. 경사 하강법.” “…생각이 아니라 다이얼 조정이었어.”

웹툰 ② 6화 #4 · 공부 시간·수면 시간 → 합격 예측 — 제로 6 : 뭉치 0

예제

w = (0.2, −0.3), b = 0.1, 학습률 0.5에서 입력 (1,1) 정답 1인데 출력 0이면 갱신 후 w, b는?

w ← w + 0.5 × (1 − 0) × (1,1) = (0.7, 0.2), b ← 0.1 + 0.5 = 0.6.

신경망이 ‘학습’할 때 실제로 변하는 것은?

가중치 값만. 뉴런 개수·구조·코드는 그대로고 다이얼만 돌아간다. 그래서 왜 그렇게 답했는지 설명이 어렵다.
