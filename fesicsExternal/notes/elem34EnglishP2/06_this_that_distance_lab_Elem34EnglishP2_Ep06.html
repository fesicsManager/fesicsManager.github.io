초등 3~4학년 영어 ② · 웹툰 6화 「this와 that은 아무거나 쓰나」

this와 that — 거리가 낱말을 정한다

공을 손 안, 한 걸음 앞, 교실 끝에 두고 this나 that으로 가리키며 판정과 원어민 선생님 10명(가상)이 쓴 말을 기록했습니다. 손 안에서는 10명 모두 this, 교실 끝에서는 10명 모두 that이었고, 한 걸음 앞에서는 this 7명, that 3명으로 갈렸습니다. 공이 여럿이면 these, those로 바뀌었습니다. 가리키는 말을 고르는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 공의 자리(내 손 안 · 한 걸음 앞 · 교실 끝), 공의 수(공 하나 · 공 여럿), 가리키는 말(this / these · that / those)을 고르고 가리키며 말하기를 누르면 내가 한 영어 문장과 ○·✕ 판정, 같은 자리에서 원어민 선생님 10명(가상, 공 하나)이 쓴 말이 나오고 기록표에 쌓입니다. 소리를 켜면 영어 음성으로 들려줘요. 4개 이상 기록하면 결과 비교 탭이 열립니다.

표 1. 공의 자리를 바꿔 가리킨 기록 (실험 예시, 선생님 수는 가상 자료)
공의 자리공의 수내 말판정선생님 10명(가상)
내 손 안하나This is a ball.○this 10 · that 0
한 걸음 앞하나This is a ball.○this 7 · that 3
한 걸음 앞하나That is a ball.○this 7 · that 3
교실 끝하나This is a ball.✕this 0 · that 10
교실 끝하나That is a ball.○this 0 · that 10
교실 끝여럿Those are balls.○this 0 · that 10 (공 하나일 때)

공이 내 손 안에 있을 때는 선생님 10명 모두 this, 교실 끝에 있을 때는 10명 모두 that을 썼어요. 그래서 교실 끝의 공을 This로 가리키면 ✕가 나왔지요. 한 걸음 앞처럼 중간 거리에서는 this 7명, that 3명으로 사람마다 조금 달라서 둘 다 ○였어요. 거리라는 변수 하나가 낱말을 바꿔요. 공이 여럿이면 this는 these, that은 those가 되어 개수도 함께 살펴야 해요.

개념 정리

1. 거리라는 변수 하나가 낱말을 바꾼다

  • this — 말하는 사람 가까이 있는 것
  • that — 멀리 있는 것
공의 자리thisthat
내 손 안10명0명
한 걸음 앞7명3명
교실 끝0명10명

중간 거리에서는 사람마다 조금 달라요. 아주 가까우면 모두 this, 아주 멀면 모두 that이에요.

2. 우리말은 셋, 영어는 둘 — 그리고 개수

우리말은 이것·그것·저것 셋, 영어는 주로 this·that 둘로 나눠요. 여럿이면 this → these, that → those로 바뀌어요.

3. 실험과 실제의 차이

· 선생님 수는 대본의 가상 자료이고, 공 하나일 때만 조사했어요.

· 실제로는 거리뿐 아니라 말하는 사람의 마음(가깝게 느끼는지)도 영향을 줘요.

가까운 것: this (여럿이면 these) · 멀리 있는 것: that (여럿이면 those)
닥터 이안 · 제로

“this는 말하는 사람 가까이 있는 것, that은 멀리 있는 것을 가리킨다.” “물건까지의 거리가 낱말을 정하는 거예요?”

웹툰 6화 #2 · 손에 든 연필과 멀리 있는 시계

제로 · 닥터 이안

“가까우면 this, 멀면 that. 중간에서는 사람마다 조금 달라요.” “거리라는 변수 하나가 낱말을 바꾼다. 아주 멀면 모두 that이다.”

웹툰 6화 #4 · 공을 점점 멀리 두기

예제

공이 한 걸음 앞에 있을 때 this를 쓴 선생님(가상)은 that을 쓴 선생님보다 몇 명 많나요?

this 7명, that 3명이에요. 7명 − 3명 = 4명 많아요. 중간 거리에서는 이렇게 답이 갈렸어요. 4명

교실 끝에 공이 여러 개 있어요. 가리키며 소개하는 문장을 쓰세요.

멀리 있으니 that, 여럿이니 that이 those로 바뀌고 is도 are로 바뀌어요. 실험에서도 교실 끝·공 여럿·that / those를 고르면 ○가 나와요. Those are balls.
