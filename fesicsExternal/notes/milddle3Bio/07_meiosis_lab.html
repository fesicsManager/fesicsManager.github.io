감수 분열 — 절반이 되어야 하는 까닭

실험에서 여러 생물의 생식세포를 만들어 체세포와 염색체 수를 비교했습니다. 생물이 무엇이든 생식세포는 정확히 절반이었습니다. 두 번 연속 나뉘는 과정과, 왜 절반이어야 수정 후 원래 수로 돌아오는지 정리합니다.

기울기가 정확히 0.5 — 생물이 무엇이든 생식세포의 염색체 수는 체세포의 정확히 절반입니다. DNA 복제는 딱 한 번, 분열은 두 번이라 딸세포 4개가 생깁니다.

개념 정리

1. 왜 절반이어야 할까

감수 분열은 생식세포(정자·난자)를 만드는 특별한 분열입니다. 수정할 때 정자 23 + 난자 23 = 46이 되어 세대가 바뀌어도 염색체 수가 유지됩니다. 절반으로 줄이지 않으면 합쳐질 때마다 유전 정보가 두 배씩 계속 늘어날 것입니다. 자손이 부모 양쪽의 유전 정보를 반반씩 물려받는 이유이기도 합니다.

2. 두 번의 분열

  • 제1 분열: 모양과 크기가 같은 상동 염색체(하나는 아버지, 하나는 어머니에게서 온 것)가 짝을 지어 나란히 섰다가 서로 갈라져 다른 세포로 갑니다. 이때 염색체 수가 절반이 되고(2n → n), 짝지은 동안 일부를 교환해(교차) 유전자가 새로 섞입니다.
  • 제2 분열: 체세포 분열처럼 각 염색체의 두 염색분체가 갈라집니다. 염색체 수는 그대로 n.

결과: 유전적으로 서로 다른 생식세포 4개. 상동 염색체가 어느 쪽으로 갈지 무작위라 223 ≈ 800만 가지 조합이 가능합니다. 형제자매가 서로 다르게 생긴 이유입니다.

‘정확히 절반’은 이배체(2n) 생물이 정상적으로 분열할 때입니다. 분열 중 염색체가 제대로 나뉘지 않으면 수가 어긋나고(다운 증후군은 21번 염색체가 3개), 씨 없는 수박(3n)은 짝을 지을 수 없어 감수 분열이 안 되므로 씨가 없습니다. 사람의 난자는 4개 중 1개만 완성되고 나머지는 극체로 퇴화합니다.

생식세포 염색체 수 = 체세포 염색체 수 ÷ 2

복제 1번 + 분열 2번 → 딸세포 4개 (n) · 수정: n + n = 2n

제로

“어... 합쳐질 때마다 유전 정보가 두 배씩 계속 늘어나겠네요?”

웹툰 7화 · 닥터 이안: “바로 그거야! 절반으로 줄여야 수정될 때 다시 원래 양으로 맞춰지는 거지.” 제로: “그래서 자식이 엄마 아빠를 반반씩 닮는 거군요!”

뭉치

“(삐빅) 비교 표시. 체세포 분열은 염색체 수 유지. 생식세포 분열은 염색체 수 절반으로 감소.”

웹툰 7화 · 제로: “왜 절반씩이나 줄이는 거예요?” — 정자와 난자는 원래 세포의 딱 절반만큼의 유전 정보를 가진다.

예제

체세포 염색체가 24개인 벼의 생식세포에는 염색체가 몇 개 있을까? 수정란은?

생식세포 = 24 ÷ 2 = 12개. 수정란 = 12 + 12 = 24개로 부모의 체세포와 같아집니다.

감수 분열이 없이 염색체 46개짜리 생식세포가 수정된다면 자손, 손자의 염색체 수는 어떻게 될까?

자손 46 + 46 = 92, 손자 92 + 92 = 184 … 세대마다 두 배로 늘어납니다. 감수 분열로 절반(23)을 만들어야 46이 유지됩니다. 제로가 추리해 낸 바로 그 이유입니다.

확인 문제

1번· 관찰 확인

실험에서 서로 다른 생물의 생식세포를 만들었을 때 체세포 대비 염색체 수의 비율은?

생물이 무엇이든 생식세포의 염색체 수는 체세포의 정확히 절반입니다. 그래프의 기울기가 0.5, 절편이 0이었습니다.

2번· 핵심 개념

생식세포를 만들 때 염색체 수가 절반이 되어야 하는 이유는?

정자 23 + 난자 23 = 46. 절반으로 줄여야 수정 후 자손의 염색체 수가 부모의 체세포와 같아지고, 세대가 바뀌어도 유지됩니다.

3번· 적용

체세포 분열과 감수 분열에서 염색체 수의 변화로 옳은 것은?

체세포 분열은 복제 1번 + 분열 1번으로 46 → 46, 감수 분열은 복제 1번 + 분열 2번으로 46 → 23입니다.
