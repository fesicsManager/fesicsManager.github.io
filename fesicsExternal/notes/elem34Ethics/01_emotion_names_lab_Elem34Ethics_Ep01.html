초등 3~4학년 도덕 · 웹툰 1화 「기분은 좋다·나쁘다 둘뿐인가」

마음에 이름 붙이기 — 이름을 알면 필요한 것이 보여요

상황 카드를 고르고, 두 칸 표시판(좋다·나쁘다)과 여러 칸 표시판(이름 6개)에 마음 카드를 넣어 기록했습니다. 두 칸에서는 소풍 취소도 그림 찢김도 모두 ‘나쁘다’로 같아졌지만, 여러 칸에서는 실망·화남처럼 서로 다른 이름과 필요한 것이 나왔습니다. 상황의 단서로 마음 이름을 찾는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 상황 카드(6개), 내가 붙인 마음 이름(6개), 표시판(두 칸 / 여러 칸)을 고르고 이 칸에 카드 넣기를 누르면 단서와 필요한 것이 나오고 기록표에 자동으로 쌓입니다. 같은 상황을 두 칸과 여러 칸에 한 번씩 넣는 식으로 4개 이상 기록하면 결과 비교 탭이 열립니다.

표 1. 상황 카드를 표시판에 넣은 기록 (실험 예시)
상황표시판붙인 이름단서와 같음
소풍 취소두 칸나쁘다—
소풍 취소여러 칸실망예
소풍 취소여러 칸화남다시 보기
그림 찢김여러 칸화남예
첫 수영여러 칸걱정예
단짝여러 칸서운함예

두 칸 표시판에서는 어떤 이름을 골라도 카드가 ‘나쁘다’ 칸 하나로 들어가고, 필요한 것은 ‘알 수 없어요’로 나왔습니다. 여러 칸에서는 소풍 취소가 ‘기대가 깨졌나’ 단서의 실망, 그림 찢김이 ‘누가 막았나’ 단서의 화남으로 나뉘었습니다. 소풍 취소에 ‘화남’을 붙이면 ‘다시 보기’가 나왔는데, 실제 마음은 섞일 수도 있으니 틀렸다는 뜻이 아니라 단서를 한 번 더 살펴보라는 뜻이에요.

개념 정리

1. 이름을 알면 필요한 것이 보인다

'나쁘다' 안에는 여러 마음이 들어 있어요. 마음마다 생기는 단서가 다르고, 그래서 필요한 것도 달라요.

단서마음 이름필요한 것
누가 막았나화남막힌 것 치우기
기대가 깨졌나실망기대 다시 맞추기
남이 볼까 봐부끄러움괜찮다는 말
앞일이 불안한가걱정준비와 안심
내 마음을 몰라주나서운함마음 알아주기
남이 가진 게 부럽나샘남내 것도 소중히 보기

2. 마음은 신호예요

화도 실망도 틀린 마음이 아니에요. 몸이 보내는 신호예요. "나 실망했어"라고 정확히 말하면 친구가 "왜 화났어?" 하고 오해하지 않아요.

상황 → 단서 찾기 → 마음 이름 → 필요한 것

3. 실험 모형과 실제의 차이

· 실제 마음은 여러 개가 섞일 수 있어요. 소풍이 취소되면 실망하면서 조금 화가 날 수도 있지요.

· 마음에 이름을 붙이면 마음이 조금 가라앉는다는 심리학 연구가 있어요.

상황 → 단서 찾기 → 마음 이름 → 필요한 것

예제

‘내일 처음 수영을 배워요’ 카드의 단서, 마음 이름, 필요한 것은 무엇인가요?

아직 일어나지 않은 일이 불안하니 단서는 ‘앞일이 불안한가’예요. 이 단서의 이름은 걱정이고, 필요한 것은 준비하고 안심하는 것이에요. 걱정 → 준비와 안심

‘소풍 취소’와 ‘그림 찢김’을 두 칸 표시판에 넣을 때와 여러 칸 표시판에 넣을 때, 구별되는 마음은 각각 몇 가지인가요?

두 칸에서는 둘 다 ‘나쁘다’ 칸으로 들어가 1가지예요. 여러 칸에서는 실망(기대가 깨짐)과 화남(누가 막음)으로 나뉘어 2가지예요. 두 칸 1가지 · 여러 칸 2가지
