비음화 — 자리는 그대로, 소리 내는 방식만 바뀐다

받침(ㄱ·ㄷ·ㅂ 계열)과 뒤에 오는 소리(ㄴ·ㅁ·모음)를 바꾸며 실제 낱말과 가상 단어에 표준 발음법 제18항을 적용해 발음을 기록했습니다. 비음 앞에서는 ㄱ→ㅇ, ㄷ→ㄴ, ㅂ→ㅁ 세 방향으로만 바뀌었고, 모음 앞에서는 바뀌지 않고 받침이 넘어가 소리 났으며, 처음 보는 가상 단어도 같은 방향으로 읽혔습니다. [궁물]은 흐트러진 소리가 아니라 규칙이 만든 표준 발음이라는 것을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: ‘받침’(ㄱ 계열 · ㄷ 계열 · ㅂ 계열), ‘뒤에 오는 소리’(ㄴ · ㅁ · 모음), ‘낱말 종류’(실제 낱말 · 가상 단어)를 고르고 규칙 적용하기를 누르면 소리 지도에서 받침이 바로 아래 비음 칸으로 내려가는지 보이고 발음과 변화가 기록됩니다. 4개 이상 기록하면 결과 비교 탭에서 규칙 적용 표와 가상 단어 읽기 시험(가상 결과)을 볼 수 있습니다.

표 1. 받침과 뒤 소리에 따른 발음 (실험 예시)
받침뒤 소리낱말발음변화
ㄱㅁ국물[궁물]ㄱ→ㅇ
ㄷㄴ닫는[단는]ㄷ→ㄴ
ㅂㅁ밥물[밤물]ㅂ→ㅁ
ㄷㅁ꽃망울[꼰망울]ㄷ→ㄴ
ㄱ모음국이[구기]없음
ㄱㅁ뱍몰 (가상)[뱡몰]ㄱ→ㅇ

‘ㄱ’과 ‘ㅇ’은 혀 뒤를 막는 자리가 같고, 코로 숨이 나가느냐만 다릅니다. 받침 뒤에 비음 ‘ㄴ, ㅁ’이 오면 코를 미리 열면서 받침이 같은 자리의 비음으로 바뀌어, 변화는 ㄱ→ㅇ, ㄷ→ㄴ, ㅂ→ㅁ 세 방향으로만 정리되었습니다. ‘꽃망울’의 ‘ㅊ’도 대표음 ‘ㄷ’을 거쳐 [ㄴ]이 되었습니다. 대충 발음했다면 방향이 제멋대로여야 하고, 사전에 없는 가상 단어(뱍몰·슫나·팝메)에서도 같은 방향이 나타난 것은 규칙이 머릿속에 있다는 증거입니다. 모음 앞(국이[구기])에서는 비음화가 일어나지 않습니다.

개념 정리

1. 자리는 그대로, 방식만 바뀐다

‘ㄱ’과 ‘ㅇ’은 혀 뒤를 막는 자리가 같고, 다른 건 코로 숨이 나가느냐뿐입니다. ‘ㄱ’ 받침 뒤에 비음 ‘ㅁ’이 오면, 코를 미리 열면서 ‘ㄱ’이 같은 자리의 비음 ‘ㅇ’으로 바뀌어요. 이것이 비음화입니다.

2. 표준 발음법 제18항

받침 ‘ㄱ(ㄲ, ㅋ, ㄳ, ㄺ), ㄷ(ㅅ, ㅆ, ㅈ, ㅊ, ㅌ, ㅎ), ㅂ(ㅍ, ㄼ, ㄿ, ㅄ)’은 ‘ㄴ, ㅁ’ 앞에서 [ㅇ, ㄴ, ㅁ]으로 발음한다.

ㄱ → ㅇ · ㄷ → ㄴ · ㅂ → ㅁ — 소리 지도에서 바로 아래 칸으로 내려갑니다. 대충 발음했다면 방향이 제멋대로여야 하는데, 표가 한 줄로 정리돼요. 그래서 [궁물]은 흐트러진 소리가 아니라 표준 발음입니다.

3. 다른 변동도 같은 원리

  • 제19항: 받침 ‘ㅁ, ㅇ’ 뒤의 ‘ㄹ’은 [ㄴ] — 담력[담ː녁], 강릉[강능]
  • 제20항: ‘ㄴ’은 ‘ㄹ’의 앞이나 뒤에서 [ㄹ] — 신라[실라], 칼날[칼랄]
  • 음운 변동 네 가지: 교체(국물), 탈락(값[갑]), 첨가(솜이불[솜ː니불]), 축약(좋고[조ː코])

1화와 이어집니다: 소리가 이렇게 규칙적으로 바뀌니까, 표기는 바뀌기 전 모양을 붙잡아 둡니다.

4. 실험 모형과 실제의 차이

· 가상 단어 읽기 결과는 제로 랩의 가상 시험이에요. 실제로도 사람들이 처음 보는 말에 규칙을 적용한다는 연구 방법(가짜 낱말 시험)은 언어학에서 널리 쓰입니다.

· 조항 원문은 국립국어원 『표준 발음법』 기준이며, 개정 여부는 최신 고시로 확인하세요.

표준 발음법 제18항: 받침 ㄱ·ㄷ·ㅂ(계열) + ㄴ·ㅁ → [ㅇ·ㄴ·ㅁ] (같은 자리의 비음)

예제

‘앞마당’, ‘짓는’, ‘깎는’의 표준 발음을 쓰고 받침이 어떻게 바뀌었는지 밝혀라.

앞마당: ㅍ(대표음 ㅂ) + ㅁ → [암마당]. 짓는: ㅅ(대표음 ㄷ) + ㄴ → [진ː는]. 깎는: ㄲ(대표음 ㄱ) + ㄴ → [깡는]. 모두 같은 자리의 비음으로 바뀌었습니다. [암마당] · [진ː는] · [깡는]

‘신라’를 [실라]로, ‘담력’을 [담ː녁]으로 읽는 것은 표준 발음법 몇 항에 해당하며, 비음화와 어떤 점이 같은가?

신라[실라]는 제20항(ㄴ이 ㄹ 앞뒤에서 [ㄹ]), 담력[담ː녁]은 제19항(ㅁ·ㅇ 뒤의 ㄹ은 [ㄴ])입니다. 모두 이웃한 소리에 맞춰 다른 소리로 바뀌는 ‘교체’이며, 일정한 조건에서 일정한 방향으로만 일어나는 규칙입니다. 제20항(유음화)·제19항, 둘 다 규칙적인 교체
