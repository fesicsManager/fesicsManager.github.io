분수와 소수의 크기 비교 — 같은 꼴로 바꾸어 견줘요

3/8 L와 0.4 L 우유를 소수로(0.375 < 0.4), 분모 1000인 분수로(375/1000 < 400/1000), 통분해서(15/40 < 16/40), 수직선에서 견주었더니 모두 0.4 L가 1/40 L 더 많았어요. 분수와 소수를 견주는 여러 방법을 정리해요.

개념 정리

1. 같은 수직선 위의 수

분수와 소수는 겉모습만 다를 뿐 같은 수직선 위에 놓이는 수예요. 한 가지 꼴로 바꾸면 견줄 수 있어요.

2. 분수 → 소수

  • 분모를 10, 100, 1000으로 바꾸기: 3/8 = 375/1000 = 0.375
  • 분자를 분모로 나누기: 3/8 = 3 ÷ 8 = 0.375

3. 딱 떨어지지 않을 때

1/3 = 0.333…처럼 끝없이 이어지면 소수를 분수로 바꾸어 통분해요. 0.3 = 3/10, 1/3 = 10/30 > 9/30 = 3/10이니 1/3이 더 커요.

예제

3/4과 0.7 중 어느 쪽이 큰가요?

3/4 = 0.75 > 0.7이에요. 통분하면 15/20 > 14/20. 3/4이 더 커요.

2/5와 0.45 중 어느 쪽이 큰가요?

2/5 = 0.4 < 0.45예요. 통분하면 8/20 < 9/20. 0.45가 더 커요.
