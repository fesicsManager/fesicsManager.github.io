상태 변화와 열의 출입

개념 정리

1. 상태가 변할 때 온도가 멈추는 이유

물질을 가열하면 보통 온도가 올라가지만, 상태가 변하는 동안에는 열을 흡수해도 온도가 일정합니다. 흡수한 열이 입자의 운동을 빠르게 하는 데 쓰이지 않고 입자 사이의 인력을 끊어 배열을 바꾸는 데 쓰이기 때문입니다. 이 열을 융해열(고체 → 액체), 기화열(액체 → 기체)이라 하고, 반대로 응고·액화할 때는 같은 양의 열을 방출합니다.

열 흡수열 방출
융해 · 기화 · 승화(고체 → 기체)응고 · 액화 · 승화(기체 → 고체)

2. 가열 곡선 읽기

  • 기울어진 구간: 온도가 오르는 구간. 기울기 = 가열 출력 ÷ (질량 × 비열)이라 비열이 작을수록 가파릅니다(얼음 2.1, 물 4.18, 수증기 2.0 J/g·℃).
  • 평평한 구간: 상태 변화 구간. 길이 = 잠열 × 질량 ÷ 출력.

Q = 출력 × 시간, ΔT = Q ÷ (m × c), 융해열 L = 평평한 구간의 Q ÷ m.

3. 생활 속에서, 그리고 실제

땀이 증발하며 기화열을 빼앗아 몸을 식히고, 알코올 솜을 팔에 대면 시원합니다. 음료에 얼음을 넣으면 얼음이 녹으며 융해열을 흡수해 오래 시원합니다 — 0 ℃ 물보다 0 ℃ 얼음이 훨씬 잘 식힙니다. 수증기에 닿으면 뜨거운 물보다 큰 화상을 입는 것은 액화하며 열을 한꺼번에 내놓기 때문입니다. 실제로는 열이 공기로 새고 비커도 데워져 평평한 구간이 더 길고 기울기가 완만하며, 얼음이 고르게 녹지 않아 완벽한 수평이 아닙니다.

Q = 출력 × 시간  ·  ΔT = Q ÷ (m × c)  ·  L = Q(평평한 구간) ÷ m

물: 융해열 334 J/g · 기화열 2260 J/g · 비열 4.18 J/g·℃

몰리

“얼음이 녹을 때(융해) 주변의 열을 흡수하기 때문이야! 그래서 얼음 주변은 시원해지는 거지. 반대로 물이 얼음이 될 때(응고)는 열을 밖으로 방출해.”

웹툰 3화 · 지유: “얼음이 녹으면서 음료수가 시원해지는 것 같아. 왜 그럴까?”

몰리

“수증기에 닿으면 뜨거운 물보다 더 큰 화상을 입을 수 있어. 액화되면서 열을 한꺼번에 내놓기 때문이야.”

웹툰 3화 · 민재: “융해·기화는 열 흡수, 응고·액화는 열 방출! 정리되네.”

예제

0 ℃ 얼음 50 g을 모두 0 ℃ 물로 녹이는 데 필요한 열량은? 1000 W 가열기로 몇 초 걸릴까?

Q = 334 J/g × 50 g = 16 700 J. 시간 = 16 700 ÷ 1000 = 16.7초. 이 동안 온도계는 0 ℃에 멈춰 있습니다.

같은 0 ℃인데 얼음 100 g이 물 100 g보다 음료를 훨씬 잘 식히는 이유는?

0 ℃ 물은 데워지면서만 열을 흡수하지만(1 ℃당 418 J), 0 ℃ 얼음은 먼저 녹으면서 융해열 33 400 J을 흡수한 뒤 다시 물로서 열을 흡수합니다. 융해열 33 400 J은 물 100 g을 80 ℃나 데울 수 있는 양입니다.

확인 문제

1번· 관찰 확인

실험의 가열 곡선에서 100 ℃ 평평한 구간이 0 ℃ 구간보다 훨씬 길었던 이유는?

평평한 구간의 길이 = 잠열 × 질량 ÷ 출력. 기화열 2260 J/g은 융해열 334 J/g의 약 7배라 100 ℃ 구간이 7배 깁니다.

2번· 핵심 개념

물이 끓는 동안 온도가 100 ℃로 일정한 이유는?

상태 변화 중 흡수한 열(기화열)은 입자 사이의 인력을 끊어 배열을 바꾸는 데 쓰이므로 입자의 운동(온도)은 그대로입니다.
🔬 실험으로 다시 확인

3번· 적용

열을 흡수하는 상태 변화끼리 옳게 짝지은 것은?

고체 → 액체(융해), 액체 → 기체(기화)로 갈 때는 인력을 끊어야 하므로 열을 흡수합니다. 반대 방향은 열을 방출합니다.
🔬 실험으로 다시 확인

4번· 웹툰 연결

3화에서 몰리가 설명한 ‘알코올을 손등에 바르면 시원한 이유’는?

알코올은 휘발성이 강해 피부에서 빠르게 기화하며 기화열만큼 피부의 열을 빼앗습니다. 땀이 마를 때 시원한 것과 같은 원리입니다.
