초등 5~6학년 실과 ③ · 웹툰 3화 「만들기 전에 해야 할 일」

만들기 전에 할 일 — 고치기 쉬운 곳에서 먼저 고친다

같은 과제를 ‘그림 먼저 그리고 만들기’와 ‘바로 만들기’ 두 방법으로 해 보고 쓴 재료 개수·다시 만든 횟수·걸린 시간을 더미에 쌓았습니다. 그림 먼저는 재료 6개·다시 만들기 0번·25분(그리기 5분 포함)이었고, 바로 만들기는 재료 18개·다시 만들기 3번·40분이었으며, ‘빨리 시작’과 ‘빨리 끝남’은 같은 말이 아니었습니다. 문제 해결 4단계와 평가를 정리합니다.

실험 안내: 같은 과제를 두 가지 방법으로 각각 해 보고 기록합니다. 종이에 그리는 것은 재료를 쓰지 않습니다.

표 1. 두 방법 비교 (실험 기록 예, 같은 과제)
방법쓴 재료다시 만든 횟수걸린 시간비고
그림 먼저 그리고 만들기6개0번25분 (그리기 5 + 만들기 20)한 번에 완성
바로 만들기18개 (3배)3번40분시작은 빨랐지만 늦게 끝남
그림 먼저, 2회차5개0번22분평가 반영
바로 만들기, 2회차12개2번35분—

‘일단 만들자, 만들면서 생각하면 돼’는 3번부터 시작하는 것입니다. 문제 확인 → 아이디어 찾기 → 만들기 → 평가하기에서 만들기는 제일 재밌지만 제일 늦게 오는 단계이며, 실패를 가장 많이 줄여 주는 것은 좋은 재료가 아니라 그림으로 먼저 그려 보기 — 종이에 그리는 건 공짜라 고치기 쉬운 곳에서 먼저 고치는 것이 설계의 이유입니다.

개념 정리

1. 문제 해결 4단계와 설계

문제 확인 → 아이디어 찾기 → 만들기 → 평가하기. 그림을 먼저 그린 모둠은 재료를 덜 쓰고 한 번에 완성했고, 바로 만든 모둠은 세 번 다시 만들어 재료를 세 배 썼습니다. ‘빨리 시작’과 ‘빨리 끝남’은 다릅니다(중2 기술 4화도 같은 이야기).

2. 만들기와 평가

만들 때는 안전 먼저(가위·글루건·공구는 보호 장구). 완성 뒤 꼭 평가합니다 — 문제를 해결했나, 쓰기 편한가, 안전한가, 고칠 점은. ‘잘 만들었다’로 끝내면 안 되며 평가는 다음 작품의 설계도입니다. 다른 사람이 써 봐야 진짜 평가가 나오므로 친구들과 공유합니다.

3. 생활 속에서 · 이어지는 개념

불편 노트에서 고른 문제로 실제 물건을 만들고 친구들과 공유해 보세요. 4화에서는 만든 아이디어에 이름표(권리)가 있다는 것을 봅니다.

총 비용 = 재료 + 다시 만든 횟수 × 재료 + 시간; 그림(공짜)에서 고치기 → 다시 만들기 ≈ 0
뭉치 · 제로 · 닥터 이안

예제

바로 만들기로 재료 4개씩 4번 만들었다면 쓴 재료는? 그림 먼저로 1번이면?

16개 vs 4개. 그림 5분이 재료 12개와 다시 만들기 시간을 아낀다.

완성 뒤 평가 네 가지 질문은?

문제를 해결했나 · 쓰기 편한가 · 안전한가 · 고칠 점은. 다른 사람이 써 봐야 진짜 평가.
