인공지능의 학습 — 배운 것 안에서만 답한다

귀 길이·꼬리 길이 특징 지도에 고양이·강아지 이름표 예시를 클릭으로 넣고, 새 동물(귀 5·꼬리 5 등)을 판단시켜 ‘가장 가까운 예시와 같다’는 답을 기록했습니다. 고양이 예시만 넣으면 강아지 위치의 동물도 언제나 고양이라고 했고, 두 종류를 넣으면 가까운 쪽으로 판단했으며, 예시를 한쪽에 몰아 넣으면 판단이 그쪽으로 기울었습니다. 학습 과정 네 단계와 인공지능을 쓸 때 생각할 것을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 이 인공지능은 ‘가장 가까운 예시와 같다’고 답합니다. 화면을 클릭하면 고른 이름표로 예시가 추가됩니다. 먼저 예시를 넣고 새 동물을 판단시킵니다.

표 1. 예시와 판단 (실험 기록 예, 특징 = 귀 길이 · 꼬리 길이)
넣은 예시새 동물 (귀, 꼬리)판단해석
고양이 5개만(8, 2) — 강아지 자리고양이한 종류만 배워 다른 답이 없음
고양이 5 + 강아지 5(8, 2)강아지가까운 예시
고양이 5 + 강아지 5(5, 5) — 중간가까운 쪽 (예시 배치에 따라)경계
고양이 20 + 강아지 2(6, 4)고양이한쪽에 몰면 그쪽으로 기움
‘모른다’예시 없음답 없음모른다는 답은 따로 가르쳐야

인공지능은 다 아는 것도 사람보다 똑똑한 것도 아닙니다. 예시 모으기 → 학습하기 → 맞혀 보기 → 틀리면 고치기 — 사람이 규칙을 써 주는 것이 아니라 예시에서 스스로 찾아내며 배운 것 안에서만 답합니다. 고양이만 배운 AI에게 강아지를 보여 주면 ‘모른다’가 아니라 고양이라고 하고, 틀린 것은 AI가 아니라 덜 가르친 우리이며 한쪽으로 치우친 예시는 치우친 판단을 만듭니다.

개념 정리

1. 가장 가까운 예시와 같다

‘모른다’는 답은 따로 가르쳐 줘야 합니다. 어떤 예시를 주느냐가 곧 판단을 결정하고, 예시를 한쪽에만 몰아 넣으면 판단이 그쪽으로 기웁니다(중3 기술 7화의 편향). 인공지능이 배우는 것은 규칙이 아니라 예시입니다.

2. 인공지능과 우리 생활

번역, 추천, 음성 인식, 사진 정리, 자율주행 — 편해진 만큼 생각할 것도 생겼습니다: 개인정보, 틀렸을 때 누가 책임지는지, AI가 만든 걸 내가 만든 것처럼 말하지 않기. 도구를 썼다고 말하는 건 부끄러운 게 아니라 감추는 게 문제입니다.

3. 세트·과정의 한 줄

컴퓨터는 똑똑한 게 아니라 정확한 것이다 — 정확하게 말하는 법을 배우는 것이 우리 몫. 실과 다섯 세트: 나 → 내 주변 → 만들기 → 잇고 기르기 → 컴퓨터. 중학교에서는 기술과 가정, 그리고 정보로 나뉘어 더 깊이 다룹니다.

판단 = 가장 가까운 예시의 이름표 (배운 것 안에서만); 학습 = 예시 모으기 → 학습 → 맞혀 보기 → 틀리면 고치기
뭉치 · 제로 · 닥터 이안

“인공지능은 다 알아! 사람보다 똑똑해!” “그럼 내 이름도 알아?” “예시 모으기 → 학습하기 → 맞혀 보기 → 틀리면 고치기. 사람이 규칙을 써 주는 게 아니라 예시에서 스스로 찾아낸다. 배운 것 안에서만 답한다. 그게 인공지능의 한계이자 특징이야.”
