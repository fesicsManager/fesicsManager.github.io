고등 인공지능 기초 · 웹툰 3화 「선 하나로 나눌 수 있을까」

퍼셉트론 — 배운다는 것은 숫자(가중치)가 바뀌는 것

무게와 색상값으로 사과와 귤을 나누는 선을 사람이 쓴 규칙(‘빨가면 사과’)과 퍼셉트론 학습으로 찾고, 학습률과 반복 횟수를 바꾸며 오답률을 기록했습니다. 풋사과·청귤이 섞이자 규칙은 학습 자료 오답 25 %·새 과일 오답 30 %였지만, 퍼셉트론(학습률 0.1, 10바퀴)은 학습 자료 0 %·새 과일 5 %였고 남은 것은 숫자 세 개(w₁ = 0.598, w₂ = 0.696, b = 0)뿐이었습니다. 크기가 겹치는 자료는 30바퀴를 돌려도 8 %에 머물렀습니다. 가중치·학습률·선 하나의 한계를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 과일 자료(기본 · 풋사과·청귤 포함 · 크기가 겹치는 과일 포함), 방법(규칙 / 퍼셉트론 학습), 학습률(0.01 · 0.1 · 1.0), 반복 횟수(1~30바퀴)를 정한 뒤 학습시키기를 누르면 경계선이 바퀴마다 움직이고, 학습 자료 오답률·새 과일 오답률·저장된 숫자 세 개가 나옵니다. 세 자료에서 규칙과 학습을 비교하고 학습률을 바꿔 4번 이상 기록하면 결과 비교 탭에서 자료별 규칙 vs 학습 막대와 학습률별 기록표가 나옵니다. 과일 자료는 고정 시드로 만든 가상 자료입니다.

경계선은 w₁·무게 + w₂·색상 + b = 0이고, 학습은 틀린 점을 만날 때마다 선을 그 점 쪽으로 조금 미는 일입니다. 학습이 끝나면 사진이나 표는 필요 없고 숫자 세 개(w₁, w₂, b)만 남습니다. 풋사과·청귤 자료에서 시작 선(0, 1, 0: 색상만 봄)은 학습 뒤 (0.598, 0.696, 0)이 되어 무게도 함께 쓰게 되었습니다. 학습률 0.01은 10바퀴로는 부족했고(학습 오답 10 %), 이 자료에서는 1.0도 1바퀴 만에 0 %가 되었지만, 겹침 자료에서는 학습률 1.0이 가중치를 크게 키우기만 하고 오답은 8 %에서 줄지 않았습니다. 점들이 직선 하나로 나뉘지 않으면 퍼셉트론은 0 %에 도달할 수 없고, 이 한계를 넘은 것이 다층 신경망입니다.

개념 정리

1. 배운다 = 숫자(가중치)가 바뀐다

경계선은 w₁·무게 + w₂·색상 + b = 0입니다. 이 식의 값이 0보다 크면 사과, 작으면 귤이라고 판단해요.

  • 퍼셉트론 규칙(1958, 로젠블랫): 틀린 점을 만날 때만 w ← w + 학습률 × 정답(사과 +1, 귤 −1) × 입력. 선이 틀린 점 쪽으로 조금 밀리고, 맞힌 점에서는 그대로예요. ‘학습률 × (정답 − 예측) × 입력’으로 쓰기도 하는데, 틀렸을 때 (정답 − 예측)이 ±2라서 학습률을 두 배로 잡은 것과 같아요.
  • 학습률: 한 번에 미는 크기. 너무 작으면 오래 걸리고, 크면 한 번 틀릴 때마다 크게 흔들려요.
  • 학습이 끝나면 사진이나 표는 필요 없고 w₁, w₂, b 세 숫자만 남습니다. 이것이 모델이에요.

2. 선 하나의 한계

점들이 직선 하나로 나뉘지 않으면(겹치거나 XOR처럼 배치되면) 퍼셉트론은 끝없이 흔들립니다. 1969년 이 한계가 지적된 뒤 연구가 한동안 주춤했고, 층을 쌓은 다층 신경망이 해결책이 되었어요.

3. 실험 모형과 실제의 차이

· 입력은 계산 전에 무게 (g − 150)/50, 색상 2×값 − 1로 크기를 맞췄습니다(정규화).

· 시작 선은 "색상값 0.5 이상이면 사과" 규칙과 같게 두었어요. 학습은 이 규칙에서 출발해 선을 옮깁니다.

· 실제 과일 분류는 사진 수천 장과 훨씬 많은 가중치를 씁니다.

4. 생활 속에서 · 이어지는 개념

  • 스팸 필터, 불량품 선별처럼 "예/아니오"로 나누는 문제는 대부분 경계선(면)을 학습하는 문제입니다.
틀렸을 때만 w ← w + 학습률 × 정답(±1) × 입력, 판단: w₁·무게 + w₂·색상 + b > 0이면 사과

입력 정규화: 무게 (g − 150) ÷ 50, 색상 2 × 값 − 1 (0 초록 ~ 1 빨강)

닥터 이안

“규칙을 쓰지 말고, 점을 나누는 선을 기계가 찾게 한다. 선의 기울기와 위치가 숫자(가중치·편향)다. ‘배운다’는 이 숫자가 바뀐다는 뜻이야.”

닥터 이안 · 제로

“사진 2천 장으로 배웠는데 남은 건 숫자 세 개. 이게 모델이다.” “새 과일도 이 선의 어느 쪽인지만 보면 되고요.”

웹툰 3화 #4 · 학습 과정 검증 — 제로 3 : 뭉치 0

예제

학습 결과 w₁ = 0.598, w₂ = 0.696, b = 0인 모델에 무게 200 g, 색상 0.2(초록빛)인 풋사과를 넣으면 무엇으로 판단하는가?

정규화: 무게 (200 − 150) ÷ 50 = 1, 색상 2 × 0.2 − 1 = −0.6. 0.598 × 1 + 0.696 × (−0.6) + 0 = 0.598 − 0.418 = 0.180 > 0 → 사과. 시작 규칙(색상만, 0 × 1 + 1 × (−0.6) < 0)이었다면 귤로 틀렸을 것입니다.

시작 선 (w₁, w₂, b) = (0, 1, 0)이 정규화 입력 (1, −0.6)인 사과(정답 +1)를 귤로 틀렸다. 이 실험의 코드처럼 틀린 점마다 w ← w + 학습률 × 정답(±1) × 입력, b ← b + 학습률 × 정답으로 고치면, 학습률 0.1일 때 새 숫자는?

w₁ = 0 + 0.1 × 1 = 0.1, w₂ = 1 + 0.1 × (−0.6) = 0.94, b = 0 + 0.1 = 0.1 → (0.1, 0.94, 0.1). 선이 틀린 점 쪽으로 조금 밀렸습니다.
