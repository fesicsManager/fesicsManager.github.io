가상 문장 모음에서 ‘…비율은’ 다음에 온 숫자를 세어 만든 작은 언어 모델로 같은 통계 질문과 참고 문헌 요청을 여러 번 하고, 온도와 확인 방법을 바꿔 답의 흔들림과 원 자료 일치를 기록했습니다. 숫자 후보는 23 %·25 %·27 %·29 %·31 %였는데 가장 흔한 27 %(10번 중 4번)가 원 자료 25 %와 달라서, 온도 0에서는 5번 모두 27 %로 같았지만 하나도 맞지 않았습니다. 참고 문헌을 온도 1.0으로 20번 만들자 17가지가 나왔고 원 자료와 일치한 것은 2개뿐이었습니다. 다음 단어 확률·온도·환각·확인 책임을 정리합니다.

언어 모델은 P(다음 단어 | 앞 문맥)을 배웁니다. 이 실험의 모델은 바로 앞 단어 하나만 보므로 ‘비율은’ 다음 숫자를 세면서 어느 학교 이야기였는지는 잊고 숫자만 남깁니다. 그래서 가장 흔한 27 %가 ‘우리 학교’ 답이 되고, 온도 0에서는 매번 같지만 틀립니다. 일관성과 정확성은 다릅니다. 참고 문헌도 제목 단어를 이어 붙이고 저자·연도를 섞어 만들기 때문에 형식은 완벽한데 존재하지 않는 문헌이 나옵니다(환각). 거짓말이 아니라 진실이라는 개념 자체가 모델 안에 없습니다. 실제 대형 모델은 훨씬 긴 문맥과 검색을 써서 더 정확하지만 확률로 생성한다는 원리는 같으므로, 원 자료로 확인하고 사용 사실과 출처를 밝히는 것은 사람의 몫입니다.

개념 정리

1. 그럴듯한 다음 단어 고르기

언어 모델은 P(다음 단어 | 앞 문맥)을 배웁니다. 이 실험의 모델은 바로 앞 단어 하나만 보는 가장 단순한 모델(바이그램)이에요. "비율은" 다음에 온 숫자를 세어 확률로 바꾸면, 어느 학교 이야기였는지는 잊고 숫자만 남습니다.

  • 온도 T: 확률 ∝ (등장 횟수)^(1/T). T = 0이면 항상 가장 흔한 단어, T가 크면 드문 단어도 자주 뽑혀요.
  • 환각: 참고 문헌도 "제목에 흔히 오는 단어 → 다음 단어"를 이어 붙여 만듭니다. 형식은 완벽한데 존재하지 않는 문헌이 나올 수 있어요. 거짓말이 아니라, 진실이라는 개념 자체가 모델 안에 없습니다.

2. 사용하는 사람의 몫

생성형 인공지능의 답은 원 자료로 사실을 확인하고, 어느 단계에 어떻게 썼는지 밝혀야 합니다. 초안·요약·번역에는 강력하지만 검증은 사람이 해요.

3. 실험 모형과 실제의 차이

· 실제 모델은 신경망으로 수천 단어 이상의 앞 문맥을 보고, 검색 결과를 붙여 쓰기도 해서 이 모형보다 훨씬 정확합니다. 그래도 "확률로 생성한다"는 원리는 같아요.

· 인공지능 프로젝트 순서: 문제 정의 → 데이터(정당한 출처) → 모델 → 평가 → 배포와 영향 점검.

4. 생활 속에서 · 이어지는 개념

  • 챗봇이 알려 준 통계·판례·논문은 반드시 원문을 찾아 확인하세요.
P(다음 단어 | 앞 단어) = 그 단어가 뒤따른 횟수 ÷ 전체 횟수, 온도 T: 확률 ∝ (등장 횟수)^(1/T)

예제

‘비율은’ 다음 숫자 후보가 23 % 2번, 25 % 1번, 27 % 4번, 29 % 1번, 31 % 2번 나왔다. 온도 1.0에서 원 자료 값 25 %가 뽑힐 확률은?

온도 1.0이면 확률 = 등장 횟수 비율이므로 1 ÷ 10 = 10 %. 20번 물어도 맞는 답이 한 번도 안 나올 수 있습니다(실험: 0 / 20).

같은 후보에서 온도 0.5라면 27 %가 뽑힐 확률은? (확률 ∝ 횟수^(1/T))

1/T = 2이므로 가중치는 2² = 4, 1² = 1, 4² = 16, 1² = 1, 2² = 4, 합 26. 27 %의 확률 = 16 ÷ 26 ≈ 0.615 → 약 62 %. 온도를 낮추면 흔한 답에 더 쏠리지만, 흔한 답이 맞는 답은 아닙니다.
