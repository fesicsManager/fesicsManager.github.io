초등 5~6학년 체육 · 웹툰 5화 「규칙을 바꿔도 경기는 똑같을까」

규칙과 전략 — 규칙을 바꾸면 경기의 모양이 바뀐다

규칙(원래 규칙·세 번 패스한 뒤에만 슛)과 팀(잘하는 2명 + 3명·실력이 비슷한 5명)을 바꾸며 10분 경기에서 공 만진 사람 수, 패스 수, 골 수를 세었습니다. 잘하는 2명 + 3명 팀에서 원래 규칙은 공 만진 사람 2~3명·패스 2~8번이었지만, 새 규칙은 5명 모두·패스 28~32번이었습니다. 골 수는 경기마다 흔들렸지만 많이 돌린 평균은 비슷했습니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 규칙에서 ‘원래 규칙’ 또는 ‘세 번 패스한 뒤에만 슛’을, 우리 팀에서 ‘잘하는 2명 + 3명’ 또는 ‘실력이 비슷한 5명’을 고르고 10분 경기하기를 누르면 공 만진 사람 수, 패스 수, 골 수가 기록됩니다. 두 규칙을 두 번 이상씩 경기해 기록이 4개 이상이면 결과 비교 탭이 열립니다. 선수 행동 확률을 정해 놓고 돌린 가상 경기라 할 때마다 결과가 조금씩 달라요.

표 1. 규칙에 따른 관찰표 (잘하는 2명 + 3명 팀, 실험 예시 4경기 + 4000경기 모의 평균)
규칙팀만진 사람패스골
원래2명이 잘함2명8번1골
세 번 패스2명이 잘함5명28번3골
원래2명이 잘함3명2번1골
세 번 패스2명이 잘함5명32번5골
원래 (4000경기 평균)2명이 잘함2.9명6.2번2.7골
세 번 패스 (4000경기 평균)2명이 잘함5.0명27.0번2.3골

규칙 한 줄을 바꾸자 공 만진 사람이 2~3명 → 5명 모두, 패스가 평균 약 6번 → 약 27번(네 배 넘게)으로 늘었어요. 혼자서는 슛할 수 없으니 패스를 받으려고 모두 빈 곳으로 움직였기 때문이에요. 골 수는 몇 경기만 보면 1골·3골·5골처럼 흔들렸지만, 많이 돌린 평균은 2.7골과 2.3골로 비슷했어요. 규칙이 바뀌면 이기는 방법, 곧 전략이 바뀌어요. 경기는 부딪히지 않게 넓은 곳에서 해요.

개념 정리

1. 규칙이 바뀌면 전략이 바뀌어요

"세 번 패스한 뒤에만 슛" 규칙이 생기면 잘하는 친구 혼자서는 골을 넣을 수 없어요. 패스를 받으려고 모두 빈 곳으로 움직이고, 공을 만지는 사람이 늘어요.

실제 스포츠도 그래요. 농구에 먼 곳에서 넣으면 3점을 주는 규칙이 생긴 뒤로 먼 곳에서 던지는 슛이 크게 늘었어요.

2. 안전

  • 부딪히지 않게 넓은 곳에서 해요. 아프거나 어지러우면 바로 멈추고 어른에게 말하기. 몸이 아픈 곳이 있거나 병이 있으면 먼저 어른과 상의하세요.

3. 이 실험의 계산 방법

  • 원래 규칙: 잘하는 친구가 공을 잡으면 자주 혼자 슛하고, 패스도 주로 잘하는 친구끼리 해요.
  • 새 규칙: 세 번 패스하기 전에는 슛할 수 없고, 패스는 빈 곳으로 움직인 친구 누구에게나 가요.
  • 패스 성공 약 87%, 슛 성공은 실력에 따라 달라요.

4. 실험 모형과 실제의 차이

· 실제 경기는 상대 팀, 운동장, 그날 기분에 따라 훨씬 다양해요.

· 규칙은 목적에 맞게 골라요: 목적 정하기 → 규칙 바꾸기 → 다시 기록해 확인하기.

규칙 한 줄 바꾸기 → 움직임(전략)이 바뀜 · 목적 정하기 → 규칙 바꾸기 → 다시 기록해 확인하기

웹툰 5화 #4 · 관찰표 비교

예제

원래 규칙에서 패스는 평균 약 6번, 새 규칙에서는 평균 약 27번이었어요. 새 규칙의 패스는 원래의 몇 배인가요?

27 ÷ 6 = 4.5. 4.5배. 대본의 ‘네 배 넘게 늘었다’와 같아요.

원래 규칙 첫 경기에서 공 만진 사람은 2명, 새 규칙 경기에서는 5명이었어요. 몇 명 늘었고, 몇 배가 되었나요?

5 − 2 = 3명 늘었고, 5 ÷ 2 = 2.5배예요. 3명 늘어 2.5배
