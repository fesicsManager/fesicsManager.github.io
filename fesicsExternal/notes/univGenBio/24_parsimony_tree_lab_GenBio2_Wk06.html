최대 절약법 — 변화가 가장 적은 나무를 고른다

실험에서 상어·개구리·도마뱀·사람을 잇는 뿌리 없는 나무 세 가지를 형질 7개와 가상 DNA 12자리로 평가하고 피치 알고리즘으로 변화 수(나무 길이)를 셌습니다. 형질 자료는 나무1 7단계, 나무2 8단계, 나무3 9단계로, DNA 자료는 12·14·14단계로 두 자료 모두 ((상어, 개구리), (도마뱀, 사람))을 골랐습니다. 털처럼 한 무리만 가진 형질은 정보가 없었고, 성체 꼬리 없음은 수렴이었습니다. 공유 파생 형질, 절약법, 동형 형질을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 자료(형질 7개 · 가상 DNA 12자리)와 계통수 가설 세 가지 중 하나를 고르고 변화 수 세기를 누르면 형질별 필요한 변화 수, 나무 길이, 세 나무의 길이, 최대 절약 여부가 나오고 기록표에 자동으로 쌓입니다. 두 자료에서 세 나무를 모두 기록해 기록이 4개 이상이면 데이터 검증 탭에서 자료 × 계통수 길이 표와 막대가 열립니다.

모든 무리가 같거나 한 무리만 다른 형질은 어느 나무에서도 변화 수가 같아 나무를 가르지 못합니다. 정보 있는 형질은 2 대 2로 나뉘는 양막·각질 피부·성체 꼬리 셋뿐입니다. 양막·각질 피부(공유 파생 형질)는 나무1을, 성체 꼬리 없음은 나무2를 지지하지만 다수가 이겨 나무1이 7단계로 가장 짧습니다. DNA 12자리(정보 있는 자리 5개)도 나무1 12단계, 나머지 14단계로 같은 나무를 골랐습니다.

개념 정리

1. 공유 파생 형질로 묶는다

계통 분류는 조상에서 새로 생긴 형질(파생 형질)을 함께 가진 무리를 한 가지로 묶습니다. 모든 무리가 가진 형질(턱)이나 한 무리만 가진 형질(털)은 어떤 나무에서도 변화 수가 같아 나무를 가르는 정보가 없습니다.

2. 분류 체계와 생명의 역사

  • 세균·고세균·진핵생물의 3역 체계는 rRNA 서열 비교에서 나왔습니다. 분자 시계는 서열 차이로 갈라진 시기를 어림합니다.

3. 계산 방법 — 피치(Fitch) 알고리즘

두 가지의 상태 집합이 겹치면 교집합(변화 0), 겹치지 않으면 합집합(변화 +1)을 위로 올립니다. 모든 형질의 변화를 더한 값이 나무 길이이고, 최대 절약 계통수 = 길이가 가장 짧은 나무

  • 네 무리의 뿌리 없는 나무는 딱 세 가지이고, 정보가 있는 형질은 2 대 2로 나뉘는 형질뿐입니다.
  • 서로 다른 계통에서 따로 생긴 비슷한 형질(수렴, 동형 형질)은 절약법을 헷갈리게 합니다. 여기서는 "성체 꼬리 없음"이 개구리와 사람에서 따로 생긴 예입니다.

4. 실험 모형과 실제의 차이

· 실제 연구는 수천 자리 서열과 진화 모형(최대 가능도·베이즈 방법)을 씁니다.

· 형질 코딩(있음/없음)을 어떻게 정하느냐에 따라 결과가 달라질 수 있습니다.

피치 알고리즘: 두 가지의 상태 집합이 겹치면 교집합(변화 0), 겹치지 않으면 합집합(변화 +1)  ·  나무 길이 = Σ 형질별 변화 수  ·  최대 절약 계통수 = 길이가 가장 짧은 나무

나무1 ((상어, 개구리), (도마뱀, 사람)) · 나무2 ((상어, 도마뱀), (개구리, 사람)) · 나무3 ((상어, 사람), (개구리, 도마뱀))

예제

성체 꼬리(상어 1, 개구리 0, 도마뱀 1, 사람 0)를 나무1과 나무2에서 피치 알고리즘으로 세면 각각 몇 단계인가?

나무1: (상어 1, 개구리 0) → 겹치지 않음 {0,1} +1, (도마뱀 1, 사람 0) → {0,1} +1, 뿌리 {0,1}∩{0,1} → 0 → 2단계. 나무2: (상어 1, 도마뱀 1) → {1}, (개구리 0, 사람 0) → {0}, 뿌리에서 겹치지 않음 +1 → 1단계. 나무1에서 2단계라는 것은 꼬리를 잃는 변화가 두 계통에서 따로 일어났다(수렴)는 뜻입니다.

형질 자료에서 가장 짧은 나무와 두 번째 나무의 길이 차이는? 최소 가능 길이와 비교하면 동형 형질은 몇 번인가?

나무1 7단계, 나무2 8단계 → 차이 1단계. 형질마다 최소 변화 수(상태 수 − 1)를 더하면 0 + 1 × 6 = 6이므로, 나무1에서도 1번의 추가 변화(성체 꼬리의 수렴)가 필요합니다. 차이가 작을수록 결론은 형질 선택에 민감합니다.
