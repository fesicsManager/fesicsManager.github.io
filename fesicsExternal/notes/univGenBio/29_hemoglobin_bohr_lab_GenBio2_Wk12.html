헤모글로빈 산소 해리 곡선 — 협동성의 S자와 보어 효과

실험에서 성인 헤모글로빈·태아 헤모글로빈·미오글로빈을 고르고 pH(7.2·7.4·7.6)와 조직의 산소 분압(10~100 mmHg)을 바꿔 포화도를 쟀습니다. 성인 Hb는 P₅₀ 26.8 mmHg의 S자 곡선으로 40 mmHg에서 74.7%였고, pH 7.2에서는 P₅₀가 33.4로 커져 같은 분압에 더 많이 내려놓았습니다. 태아 Hb(P₅₀ 19)와 미오글로빈(P₅₀ 2.8, n = 1)은 친화력이 컸습니다. 힐 식과 힐 그래프, 보어 효과를 정리합니다.

실험 안내: 자유 탐구 탭에서 산소 결합 단백질(성인 Hb·태아 Hb·미오글로빈), pH(7.2·7.4·7.6), 조직의 산소 분압 슬라이더(10~100 mmHg, 5 간격)를 고르고 포화도 측정을 누르면 P₅₀, 측정 포화도(±0.3% 잡음), 폐 포화도, 조직에 내려놓은 비율, 힐 좌표가 나오고 기록표에 자동으로 쌓입니다. 한 조건에서 분압을 여러 값으로 재어 기록이 4개 이상이면 데이터 검증 탭에서 힐 그래프와 조건별 힐 계수·P₅₀ 표가 열립니다.

성인 Hb는 협동성(n = 2.7) 때문에 20~40 mmHg 사이에서 포화도가 31 → 75%로 가파르게 변해, 조직 분압의 작은 차이에도 산소를 많이 내려놓습니다. pH가 7.2로 낮아지면 곡선이 오른쪽으로 이동(P₅₀ 26.8 → 33.4)해 40 mmHg에서 내려놓는 양이 22.5 → 35.3%p로 늘어납니다. 미오글로빈은 n = 1의 쌍곡선이고 친화력이 매우 커서 산소를 저장합니다.

개념 정리

1. 협동적 결합이 만드는 S자

헤모글로빈은 소단위 4개로 되어 있어, 산소 하나가 붙으면 나머지의 친화력이 커집니다(협동성). 그래서 S = Pⁿ / (P₅₀ⁿ + Pⁿ) 의 S자 곡선이 되고, 조직 분압(약 20~40 mmHg)의 작은 변화에도 많은 산소를 내려놓습니다.

2. 힐 그래프 (선형화)

log(S / (1 − S)) = n · log P − n · log P₅₀ — 기울기가 힐 계수 n, 가로축 절편이 log P₅₀입니다.

  • 보어 효과: 활발한 조직은 CO₂·H⁺가 많아 pH가 낮고, 곡선이 오른쪽으로 이동해 산소를 더 내려놓습니다.
  • 태아 헤모글로빈은 친화력이 커(P₅₀가 작음) 태반에서 어머니 피의 산소를 받아 옵니다.
  • 미오글로빈은 소단위가 하나라 협동성이 없고(n = 1) 친화력이 매우 커서 근육에 산소를 저장합니다.

3. 면역과 연결

  • 호흡 표면은 병원체가 들어오는 통로이기도 합니다. 점액·섬모(선천 면역)와 항체·T세포(적응 면역)가 함께 지킵니다.

4. 실험 모형과 실제의 차이

· 실제 곡선은 2,3-BPG 농도·온도·CO₂에 따라서도 이동하며, 힐 계수는 포화도 전 구간에서 일정하지 않습니다.

S = Pⁿ / (P₅₀ⁿ + Pⁿ)  ·  log(S/(1 − S)) = n·log P − n·log P₅₀  ·  보어 효과: P₅₀(pH) = P₅₀(7.4) × 10^(−0.48(pH − 7.4))  ·  내려놓는 비율 = S(100, pH 7.4) − S(조직)

성인 Hb P₅₀ 26.8 mmHg, n 2.7 · 태아 Hb P₅₀ 19 · 미오글로빈 P₅₀ 2.8, n 1 · 폐 100 mmHg

예제

성인 Hb에서 격렬히 운동하는 근육(pH 7.2, P(O₂) 20 mmHg)과 쉬는 근육(pH 7.4, 40 mmHg)이 받는 산소 비율을 실험 모형으로 비교하라.

운동: S(100) − S(20) = 97.2 − 20.0 = 77.2%p. 휴식: 97.2 − 74.7 = 22.5%p. 약 3.4배입니다. 분압 하강(S자 곡선의 가파른 구간)과 산성화(보어 효과)가 함께 산소 공급을 늘립니다. 폐 포화도는 폐의 pH 7.4로 계산합니다.

성인 Hb(pH 7.4)의 P = 40 mmHg에서 힐 좌표 log(S/(1 − S))를 구하고, n·log(P/P₅₀)와 같은지 확인하라.

S = 0.747 → log(0.747 ÷ 0.253) = 0.470. n·log(P/P₅₀) = 2.7 × (1.602 − 1.428) = 2.7 × 0.174 = 0.470. 두 값이 같으므로 힐 그래프의 점은 기울기 n = 2.7인 직선 위에 놓입니다.
