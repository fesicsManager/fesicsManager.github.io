하디–바인베르크와 진화 요인 — 흔들리는 빈도, 밀리는 빈도

실험에서 집단 크기 N(10~1 000), 초기 빈도 p₀, 선택 계수 s를 정해 50세대 동안 대립유전자 빈도를 추적했습니다. s = 0·N = 100·p₀ = 0.5에서는 50세대 뒤 p가 0.2~0.8 사이 어디든 나와 돌릴 때마다 달랐고(유전적 부동), N = 10은 몇 세대 만에 고정 또는 소실, N = 1 000은 0.5 근처에 머물렀습니다. s = 0.1(aa 불리)이면 p가 10세대 뒤 약 0.61, 50세대 뒤 약 0.78로 한 방향으로 올랐지만 q가 작아질수록 느려져 열성 대립유전자가 잘 사라지지 않았습니다. 평형 조건, 부동과 선택의 수식, 유효 집단 크기, 보인자 빈도 계산을 정리합니다.

개념 정리

1. 하디–바인베르크 평형 — 진화의 기준선

대립유전자 빈도 p·q(p + q = 1)인 집단이 ① 무작위 교배 ② 무한히 큰 집단 ③ 돌연변이·이주·선택 없음 조건을 만족하면 유전자형 빈도는 p² + 2pq + q² = 1로 세대가 지나도 변하지 않습니다. 이는 ‘진화가 일어나지 않는 기준선’이라, 실제 집단이 여기서 벗어나면 어떤 진화 요인이 작용했는지 알 수 있습니다. 응용: 열성 유전병 발생률 q² = 1/10 000 → q = 0.01 → 보인자 2pq ≈ 2 %(보인자가 환자의 200배) — 유전 상담의 기초 계산이며 생물의 유전 실험 04·06(멘델·가계도)의 집단 버전입니다.

2. 유전적 부동과 자연 선택

유전적 부동: 유한 집단에서는 다음 세대를 만드는 2N개 생식세포가 표본 추출이라 빈도가 우연히 흔들리고, 한 세대 변화의 표준편차 √(pq/2N)는 N이 작을수록 큽니다 — 실험에서 N = 10은 몇 세대 만에 고정/소실, N = 1 000은 0.5 근처. 같은 조건으로 3번 이상 돌리면 매번 다른 결과가 나오는 것이 부동의 본질이며, 고정 확률은 처음 빈도, 소요 시간은 약 4N 세대입니다. 자연 선택: 선택 계수 s만큼 적응도가 낮은 유전자형(aa: 1 − s)이 덜 남겨 빈도가 한 방향으로 이동합니다. 완전 열성이면 Δp ≈ s·p·q²/(1 − sq²)라 처음엔 빠르다가(p 0.5 → 0.6에 약 9세대) q가 작아지면 aa가 드물어 매우 느려집니다(0.8 → 0.9에 약 55세대). 큰 N에서는 선택이 결정적이고 작은 N에서는 부동이 선택을 이기기도 하며, s < 1/2N이면 사실상 중립 — 멸종 위기종의 작은 집단이 유리한 대립유전자도 우연히 잃는 이유라 보전 생물학은 유효 집단 크기를 중시합니다.

3. 모형과 실제

라이트–피셔 모형은 세대가 겹치지 않고 N이 일정하며 무작위 교배하는 한 유전자좌·두 대립유전자 집단입니다. 실제 집단은 세대가 겹치고 N이 변하며(유효 집단 크기 N_e는 실제 개체 수보다 작음 — 성비 불균형, 번식 개체 수 변동), 이주·돌연변이·근친 교배가 함께 작용합니다. 선택 계수를 일정하게 뒀지만 실제 적응도는 환경·빈도에 따라 변하고(빈도 의존 선택, 이형 접합 우세 — 낫 모양 적혈구 유전자가 말라리아 지역에서 유지되는 이유), 실험은 유전자형 빈도를 항상 HW 비율로 두어 근친 교배에 의한 이형 접합 감소는 나타내지 않습니다.

p² + 2pq + q² = 1  ·  선택(aa: 1 − s): p′ = p ÷ (1 − s q²), Δp ≈ s p q²  ·  부동: p_next = Binomial(2N, p′)/2N, σ = √(pq/2N)  ·  고정 확률 = p₀, 시간 ~ 4N  ·  중립 조건 s < 1/(2N)

N 100·s 0·50세대: p 0.2~0.8 · N 1 000: 0.42~0.58 · s 0.1: 10세대 0.61, 50세대 0.78 · q² = 10⁻⁴ → 보인자 2 %

실험 데이터 확인 탭 · 부동의 확인 방법

예제

어떤 집단에서 열성 형질(aa)이 16 %다. p, q와 이형 접합 빈도는? 우성 표현형 중 보인자 비율은?

q² = 0.16 → q = 0.4, p = 0.6. 2pq = 0.48. 우성 표현형(p² + 2pq = 0.84) 중 보인자 = 0.48/0.84 = 57 %. HW 평형이 성립한다는 가정이 필요합니다.

N = 50, p = 0.5인 집단에서 한 세대의 부동에 의한 빈도 변화의 표준편차는? s = 0.005인 약한 선택은 이 집단에서 효과가 있는가?

σ = √(0.25/100) = 0.05. 선택의 기대 변화 Δp ≈ 0.005 × 0.5 × 0.25 = 0.0006으로 부동(0.05)보다 훨씬 작고, s = 0.005 < 1/(2N) = 0.01이므로 사실상 중립 — N이 1 000이면 1/2N = 0.0005라 선택이 작용합니다.
