멘델 교배와 카이제곱 검정 — 우연인가, 다른가

실험에서 단성·양성 잡종 교배와 검정 교배의 자손을 N = 20~2 000마리 추출해 이론 비(3 : 1, 9 : 3 : 3 : 1, 1 : 1 : 1 : 1)와 비교하는 카이제곱 검정을 하고, 연관된 유전자의 검정 교배에서 재조합 빈도를 구했습니다. N = 100에서 80 : 20은 χ² = 1.33 < 3.84로 3 : 1과 다르지 않았지만, 같은 비율의 N = 1 000(800 : 200)은 χ² = 13.3으로 기각되었습니다. RF = 0.18로 연관된 두 유전자의 검정 교배(N = 100)는 부모형 41·41, 재조합형 9·9로 χ² ≈ 41 ≫ 7.81이라 독립이 기각되고 거리는 18 cM이었습니다. 검정의 논리, 자유도와 임계값, 표본 크기의 효과, 연관 분석을 정리합니다.

개념 정리

1. 카이제곱 검정의 논리

멘델 교배의 이론 비는 확률이라 실제 자손 수는 늘 조금씩 벗어납니다. 그 차이가 우연으로 볼 수 있는 범위인지(귀무가설 ‘이론 비와 같다’를 기각하지 못함) 진짜 다른지(기각)를 χ² = Σ(O − E)²/E로 판단합니다. 자유도 = 범주 수 − 1이고 χ²가 임계값(df 1: 3.84, df 3: 7.81, α = 0.05)보다 크면 ‘이론 비와 다르다’고 결론합니다 — p값은 귀무가설이 참일 때 이만큼 벗어날 확률입니다. ‘기각하지 못함’은 ‘이론 비가 맞다’의 증명이 아니라 ‘자료가 반박하지 못했다’는 뜻이고, α = 0.05는 관행적 기준입니다. 실험에서 80 : 20(N 100)과 800 : 200(N 1 000)은 비율이 같은데 판정이 다릅니다 — χ²가 N에 비례하기 때문이며, 유의성과 효과 크기(편차 5 %)는 별개입니다. 카이제곱 검정은 여론 조사·임상 시험·품질 관리 등 범주형 자료 분석의 기본 도구입니다.

2. 연관 분석 — 독립이 깨지면 거리가 보인다

두 유전자가 같은 염색체에 연관되어 있으면 검정 교배가 1 : 1 : 1 : 1에서 벗어나 부모형이 많아지고, 재조합형 비율 RF가 유전자 사이 거리(1 % = 1 cM)가 됩니다(생물의 유전 실험 05). 실험의 RF 0.18: 기대 부모형 41 + 41, 재조합형 9 + 9 → 독립 가설 χ² = 2 × (41 − 25)²/25 + 2 × (9 − 25)²/25 = 20.5 + 20.5 = 41 ≫ 7.81. 이 검정은 ‘독립이 아니다’를 말할 뿐 RF 값 자체는 재조합형/N으로 따로 구하며, N이 작으면 RF의 표준 오차 √(RF(1 − RF)/N)(N 100이면 ±0.04)가 큽니다. RF는 50 %를 넘지 않고 먼 거리에서는 이중 교차 때문에 과소평가됩니다. 모건이 초파리 눈 색으로 연관과 X 염색체 유전을 밝힌 것(1910)이 유전자가 염색체 위에 있다는 첫 증거였습니다.

3. 모형과 실제

완전 우성·유전자형별 동일 생존율·독립 표본을 가정했습니다. 실제 초파리 교배에서는 유전자형별 생존율 차이(치사 대립유전자면 2 : 1), 성별 효과(초파리 수컷은 교차 없음 → 수컷 검정 교배는 RF 0), 계수 오류가 편차를 만들고, 이런 요인은 χ² 기각의 원인이 ‘연관’이 아닐 수도 있음을 뜻합니다. 기대 빈도가 5 미만인 범주(예: 9 : 3 : 3 : 1의 마지막 칸, N < 80)에서는 χ² 근사가 나빠 예이츠 보정·정확 검정이 필요합니다. 생물의 유전 실험 04(멘델 χ²)를 표본 크기·검정력·연관까지 확장한 실험입니다.

χ² = Σ (O − E)² ÷ E  ·  df = 범주 수 − 1  ·  χ² > 임계값 → 귀무가설 기각  ·  RF = 재조합형 ÷ N (1 % = 1 cM)  ·  SE(RF) = √[RF(1 − RF)/N]

임계값 α 0.05: df 1 3.84, df 2 5.99, df 3 7.81 · 80 : 20 (N 100) χ² 1.33 / 800 : 200 (N 1 000) 13.3 · RF 0.18 → χ² 41, 18 cM

예제

양성 잡종 자가 교배 자손 160마리가 96 : 30 : 26 : 8이었다. 9 : 3 : 3 : 1과 다른가?

기대 90 : 30 : 30 : 10. χ² = 36/90 + 0 + 16/30 + 4/10 = 0.40 + 0 + 0.53 + 0.40 = 1.33 < 7.81(df 3) → 기각 못 함. 마지막 칸 기대 10 ≥ 5라 근사 유효.

검정 교배 400마리가 AB 165, ab 171, Ab 32, aB 32였다. 독립인가? 연관이라면 거리와 그 표준 오차는?

기대 각 100. χ² = (65² + 71² + 68² + 68²)/100 = (4 225 + 5 041 + 4 624 + 4 624)/100 = 185 ≫ 7.81 → 독립 기각, 연관. RF = 64/400 = 0.16 → 16 cM, SE = √(0.16 × 0.84/400) = 0.018 → 16 ± 1.8 cM.
