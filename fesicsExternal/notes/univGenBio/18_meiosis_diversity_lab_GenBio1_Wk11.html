감수분열 — 쌍마다 동전 던지기, 그리고 비분리

실험에서 상동 염색체 쌍의 수 n(1·2·3·4·10·23)을 바꿔 배우자 종류 2ⁿ과 수정란 조합 4ⁿ을 계산하고 배우자 1,000개를 뽑아 나온 종류를 셌습니다. n ≤ 4에서는 모든 종류가 나왔지만 n = 10(1,024종류)에서는 약 640종류만, n = 23에서는 거의 모두 서로 달랐습니다. 첫 번째 쌍에 1분열 비분리를 넣으면 정상 배우자 0%, 2분열 비분리는 50%였습니다. 독립 분리·교차·무작위 수정과 비분리를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 상동 염색체 쌍의 수 n(1·2·3·4·10·23쌍)과 분열 상태(정상·1분열 비분리·2분열 비분리)를 고르고 감수분열 진행을 누르면 2ⁿ·4ⁿ, 배우자 1,000개에서 나온 종류, 이번 배우자 4개의 염색체 수가 나오고 기록표에 자동으로 쌓입니다. 기록이 4개 이상이면 데이터 검증 탭에서 n–배우자 종류(log₂) 그래프와 비분리 비교표가 열립니다.

n이 하나 늘 때마다 배우자 종류는 2배, log₂(종류) = n이라 그래프의 기울기는 1입니다. n이 작으면 1,000개 안에 모든 종류가 나오지만, n = 10이면 1,024 × (1 − e^(−1000/1024)) ≈ 638종류만 나와 표본보다 가능한 조합이 많아집니다. 비분리는 1분열에서 일어나면 배우자 4개가 모두 비정상, 2분열에서 일어나면 절반만 비정상입니다.

개념 정리

1. 쌍마다 동전 던지기

감수 1분열 중기에 상동 염색체 쌍은 적도판에 서로 독립적으로 배열합니다. 쌍마다 어머니 쪽·아버지 쪽이 어느 극으로 갈지 두 가지이므로 배우자 종류 = 2ⁿ, 두 부모의 배우자가 무작위로 만나면 수정란 조합 = 2ⁿ × 2ⁿ = 4ⁿ. 사람(n = 23)은 약 840만 종류의 배우자, 약 70조 가지 조합입니다.

빨강은 어머니에게서, 파랑은 아버지에게서 받은 염색체입니다. 쌍마다 어느 쪽이 왼쪽 극으로 갈지 동전 던지듯 따로 정해지므로, 재생하면 n쌍에서 2ⁿ가지 배열이 차례로 나타납니다. 사람(n = 23)은 2²³ = 8,388,608가지, 수정란 조합은 약 70.4조 가지입니다. (교차 제외)

2. 유전적 다양성의 세 가지 원천

  • ① 독립 분리 ② 교차(감수 1분열 전기의 재조합) ③ 무작위 수정

3. 비분리

  • 1분열 비분리: 상동 염색체가 갈라지지 않아 배우자 4개가 모두 비정상(n+1 두 개, n−1 두 개).
  • 2분열 비분리: 한쪽 세포에서 자매 염색 분체가 갈라지지 않아 절반만 비정상(n+1, n−1, n, n).
  • n+1 배우자가 정상 배우자와 수정하면 삼염색체(예: 21번 삼염색체 — 다운 증후군)가 됩니다.

그림으로 보기

비분리가 일어난 때에 따라 달라지는 배우자

한 쌍의 상동 염색체(빨강·파랑)만 따라가 봅니다. 1분열에서 상동 염색체가 갈라지지 않으면 배우자 4개가 모두 비정상(n+1, n+1, n−1, n−1), 2분열에서 자매 염색 분체가 갈라지지 않으면 절반만 비정상(n+1, n−1, n, n)입니다.

4. 실험 모형과 실제의 차이

· 교차가 일어나면 한 염색체 안에서도 조합이 섞여 2ⁿ보다 훨씬 많은 배우자가 생깁니다.

· 비분리는 드물게 일어나며, 어머니 나이가 많을수록 빈도가 높아진다고 알려져 있습니다.

배우자 종류 = 2ⁿ  ·  수정란 조합 = 2ⁿ × 2ⁿ = 4ⁿ  ·  1분열 비분리 → n+1, n+1, n−1, n−1  ·  2분열 비분리 → n+1, n−1, n, n

사람 n = 23 → 2²³ = 8,388,608, 4²³ ≈ 70.4조 (교차 제외)

예제

2n = 6인 생물(n = 3)에서 교차 없이 한 개체가 만드는 배우자 종류와, 두 부모가 만드는 수정란 조합 수는?

쌍마다 어느 극으로 갈지 2가지 → 2³ = 8종류. 두 부모의 배우자가 무작위로 만나면 8 × 8 = 64가지(= 4³). 형제 둘이 같은 조합일 확률은 1/64 ≈ 1.56%입니다.

21번 염색체가 감수 1분열에서 비분리된 난자 4개(실제로는 난자 1개와 극체)가 정상 정자와 수정한다면 수정란의 21번 염색체 수는?

1분열 비분리 배우자는 n+1, n+1, n−1, n−1 → 수정하면 21번이 3개(삼염색체) 또는 1개(일염색체)로 정상은 없습니다. 2분열 비분리라면 n+1, n−1, n, n이라 절반은 정상(21번 2개)입니다. 21번 삼염색체가 다운 증후군입니다.
