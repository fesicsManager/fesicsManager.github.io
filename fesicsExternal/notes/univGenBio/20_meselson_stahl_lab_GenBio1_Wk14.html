메셀슨–스탈 실험 — 띠의 수와 위치로 반보존적 복제를 고른다

실험에서 ¹⁵N에서 기른 대장균을 ¹⁴N 배지로 옮긴 뒤 반보존적·보존적·분산적 복제 모형별로 0~4세대의 CsCl 원심분리 띠를 예측해 1958년 실제 결과와 비교했습니다. 1세대 중간 띠 하나로 보존적 모형이, 2세대 중간 + 가벼운 두 띠로 분산적 모형이 탈락했고 반보존적만 끝까지 맞았습니다. 평균 밀도는 세 모형이 언제나 같았습니다. 반보존적 복제와 복제 효소들을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 복제 모형(반보존적·보존적·분산적)과 ¹⁴N 배지에서 지난 세대 수 슬라이더(0~4)를 고르고 원심분리하기를 누르면 예측 띠(위치와 비율), 띠 개수, 평균 밀도, 실제 결과와의 일치 여부가 나오고 기록표에 자동으로 쌓입니다. 기록이 4개 이상이면 데이터 검증 탭에서 모형 × 세대 판정표와 평균 밀도 그래프가 열립니다.

개념 정리

1. 무게로 가닥의 출신을 추적한다

CsCl 용액을 고속 원심분리하면 밀도 기울기가 생기고, DNA는 자기 밀도와 같은 높이에 띠를 이룹니다. ¹⁵N DNA는 ¹⁴N DNA보다 무거워 아래쪽에 모여요.

2. 세 모형의 예측 (¹⁴N 배지 g세대 뒤)

  • 반보존적: 옛 가닥 하나 + 새 가닥 하나. 1세대 중간 띠만, 2세대부터 중간 : 가벼움 = 2 : (2g − 2)
  • 보존적: 원래 이중 나선이 그대로 남음. 무거운 띠 1/2g + 가벼운 띠
  • 분산적: 옛 조각과 새 조각이 섞임. 띠 하나가 세대마다 가벼운 쪽으로 이동

실제로는 1세대에 중간 띠 하나(→ 보존적 탈락), 2세대에 중간 + 가벼운 두 띠(→ 분산적 탈락)가 나와 반보존적 복제가 확인됐습니다.

3. 복제 과정

  • 헬리케이스가 풀고, 프라이메이스가 RNA 프라이머를 놓고, DNA 중합효소가 5′→3′ 방향으로만 합성합니다. 지연 가닥은 오카자키 절편으로 만들어져 연결효소가 잇습니다.
  • 선형 염색체 끝은 매번 조금씩 짧아지며(말단 복제 문제), 텔로머레이스가 텔로미어를 늘여 보완합니다.

4. 실험 모형과 실제의 차이

· 평균 밀도는 세 모형 모두 같습니다. 모형을 가르는 것은 띠의 수와 위치예요.

반보존적: 중간 띠 2/2^g, 가벼운 띠 1 − 2/2^g (g ≥ 1)  ·  보존적: 무거운 띠 1/2^g + 가벼운 띠  ·  분산적: 띠 하나, 밀도 1.710 + 0.014/2^g  ·  평균 밀도 = 1.710 + 0.014/2^g (세 모형 공통)

¹⁵N DNA 1.724, ¹⁴N DNA 1.710, 중간(혼성) 1.717 g/cm³

예제

반보존적 복제로 ¹⁴N 배지에서 3세대가 지났다. DNA 분자 8개 가운데 중간 띠와 가벼운 띠는 각각 몇 개인가?

처음 ¹⁵N 가닥 2개는 끝까지 남아 각각 다른 분자에 들어갑니다 → 중간(¹⁵N/¹⁴N) 2개, 나머지 6개는 가벼움(¹⁴N/¹⁴N). 비율 2/8 = 25% : 75%로 표 1의 3세대와 같습니다.

2세대 DNA를 가열해 단일 가닥으로 풀고 원심분리하면, 반보존적과 분산적 모형은 각각 어떤 띠를 보이는가?

반보존적: 가닥 8개 중 ¹⁵N 가닥 2개(25%)와 ¹⁴N 가닥 6개(75%)가 나뉘어 무거운 단일 가닥 띠와 가벼운 단일 가닥 띠 두 개. 분산적: 모든 가닥에 옛 조각과 새 조각이 섞여 중간 밀도 띠 하나. 가닥 단위로 풀면 두 모형을 1세대에서도 가를 수 있습니다.
