대조 실험과 표본 크기 — 비교 대상이 있어야 원인을 말한다

실험에서 비료의 실제 효과(0·+1·+3 cm)를 숨겨 두고, 대조군 설계와 처리 전후 비교 설계, 화분 수 3·10·30개를 바꿔 가며 t 검정 판정이 맞는지 확인했습니다. 실제 효과가 0인데도 전후 비교는 자연 성장 2 cm가 섞여 거의 매번 ‘효과 있음’이라 했고, 대조군 설계는 우연에 의한 약 5%만 틀렸습니다. 작은 효과(+1 cm)는 화분이 적으면 자주 놓쳤습니다. 대조군·무작위 배정·반복의 역할과 1종·2종 오류를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 실험 설계(대조군 있음/전후 비교), 한 집단의 화분 수(3·10·30개), 비료의 실제 효과(0·+1·+3 cm, 채점용 정답)를 고르고 2주 기르고 측정하기를 누르면 결과가 기록표에 자동으로 쌓입니다. 누를 때마다 새 표본이 뽑히므로 같은 조건을 여러 번 반복하고, 기록이 4개 이상이면 데이터 검증 탭에서 설계·효과별 ‘효과 있음’ 비율과 추정 오차 그래프가 열립니다.

표 1. 설계·화분 수·실제 효과별 ‘효과 있음’ 판정 비율 (실험 모형으로 2만 회 모의)

대조군10+3 cm+3.0 cm0.67 cm약 99%
전후 비교100 cm+2.0 cm (자연 성장)0.47 cm약 96% (혼입)

대조군 설계에서 효과가 0이면 ‘효과 있음’은 화분 수와 관계없이 약 5%로, 95% 기준이 허용한 1종 오류입니다. 전후 비교는 자연 성장 2 cm가 효과에 섞여(혼입) 효과가 없어도 거의 매번 유의하게 나옵니다. 같은 +1 cm 효과라도 SE가 1.5·√(2/n)로 줄어드는 만큼 검출 비율이 29%(n = 10)에서 72%(n = 30)로 올라갑니다 — 작은 효과일수록 반복 수가 필요합니다.

개념 정리

1. 비교할 대상이 있어야 원인을 말할 수 있다

식물은 비료가 없어도 자랍니다. 처리 전후만 비교하면 자연 성장과 비료 효과가 섞여 구별되지 않아요. 무작위로 나눈 대조군은 처리만 빼고 모든 조건을 같게 해서 이 혼입 변수를 지웁니다.

2. 표본 크기와 우연

  • 개체마다 자라는 양이 다르므로 평균 차이에는 우연 오차가 섞입니다. 오차의 크기는 표준오차 SE ≈ s / √n 로 줄어듭니다.
  • t = 추정 효과 / SE 가 임계값(95% 기준)보다 크면 "우연만으로는 설명하기 어렵다"고 판정합니다.
  • 효과가 없는데 있다고 하는 것을 1종 오류, 효과가 있는데 놓치는 것을 2종 오류라 합니다. 작은 효과는 n이 작으면 자주 놓칩니다.

3. 이 실험의 계산 방법

대조군 설계: 효과 = 처리군 평균 성장 − 대조군 평균 성장 (자유도 2n−2)
전후 비교: 효과 = 처리군 평균 성장 (자유도 n−1)

4. 실험 모형과 실제의 차이

· 성장량을 정규분포로 뽑은 가상 자료입니다. 실제 식물은 빛·물·화분 위치 같은 변수가 더 많아 무작위 배정과 반복이 더 중요합니다.

· 과학적 방법은 관찰 → 가설 → 검증 가능한 예측 → 대조 실험 → 결론(가설 수정)의 순환입니다.

5. 생활 속에서 · 이어지는 개념

  • 신약 임상 시험의 위약 대조군, 이중 맹검은 모두 같은 원리입니다.
대조군 설계: 효과 = 처리군 평균 − 대조군 평균, SE = √(s₁²/n + s₂²/n), 자유도 2n − 2  ·  전후 비교: 효과 = 처리군 평균 성장, SE = s/√n, 자유도 n − 1  ·  t = 추정 효과 / SE, |t| > 임계값(95%)이면 ‘효과 있음’

자연 성장 평균 2 cm, 개체 표준편차 1.5 cm · 임계 t: 자유도 4 → 2.776, 18 → 2.101, 58 → 2.002, 9 → 2.262

🔬 실험 피드백

“없는 효과를 주장(1종 오류·혼입)”

실험 결과 · 실제 효과 0 cm인데 ‘효과 있음’으로 판정됐을 때

예제

대조군 설계, 화분 10개씩. 처리군 평균 성장 4.4 cm, 대조군 2.1 cm, 두 집단의 표준편차가 모두 1.5 cm였다. 추정 효과, t, 95% 신뢰구간과 판정은?

효과 = 4.4 − 2.1 = 2.3 cm. SE = √(1.5²/10 + 1.5²/10) = 0.671 cm, t = 2.3 ÷ 0.671 = 3.43 > 2.101(자유도 18) → 효과 있음. 신뢰구간 = 2.3 ± 2.101 × 0.671 = 2.3 ± 1.41 → 0.89 ~ 3.71 cm. 구간이 0을 포함하지 않는 것과 t > 임계값은 같은 판정입니다.

비료 효과가 실제로 없는데 전후 비교 설계(화분 10개)로 평균 성장 2.0 cm, 표준편차 1.5 cm를 얻었다. 판정과 문제점은?

SE = 1.5 ÷ √10 = 0.474, t = 2.0 ÷ 0.474 = 4.22 > 2.262(자유도 9) → ‘효과 있음’. 그러나 2 cm는 비료 없이도 자라는 자연 성장입니다. 비교 대상이 없어 처리 효과와 시간 효과가 섞인 것이므로 혼입 변수 때문에 생긴 잘못된 결론입니다. 같은 조건의 대조군을 두면 사라집니다.
