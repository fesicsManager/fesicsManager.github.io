접두사·어근·접미사 — 긴 단어는 조각의 합

접두사(in·ex·trans·re·pre·sub), 어근(port·spect·dict), 접미사(-able·-er·-ion)를 조립해 조각 뜻과 실제 뜻을 비교했습니다. port 하나로 import·export·transport·report·support·portable 같은 단어 가족이 나왔고, ex + spect → expect, sub + spect → suspect처럼 붙을 때 철자가 바뀌기도 했습니다. portion 같은 가짜 친구와 indict처럼 조각 뜻과 먼 단어도 확인하고, 단어 종류별 학습 전략을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 접두사·어근·접미사를 하나씩 고르고 조립하기를 누릅니다. 조립된 단어, 조각 뜻의 합, 실제 뜻, 철자 변화 같은 주의 사항이 나오고, 목록에 없는 조합은 ‘없거나 거의 쓰이지 않는 조합’으로 표시됩니다. 한 어근을 정해 접두사와 접미사를 바꿔 가며 단어 가족을 넓히고, 결과 비교 탭에서 어근별로 찾은 단어 수를 확인하세요.

표 1. 조각을 조립한 단어 (실험 결과)

어근 하나에 접두사·접미사를 바꿔 붙이자 단어 여러 개가 한 가족으로 묶였습니다. 영어 어휘의 상당수는 라틴어·그리스어에서 왔고 학술 용어일수록 그래서, 어려운 단어일수록 오히려 조각내기가 쉽습니다. 다만 붙을 때 소리 때문에 철자가 바뀌고(in + port → import, sub + port → support), portion처럼 철자만 같고 뿌리가 다른 가짜 친구도 있어 조각 뜻은 짐작의 출발점일 뿐입니다.

개념 정리

1. 긴 단어는 조각의 합

영어 어휘의 상당수는 라틴어·그리스어에서 왔고, 학술 용어일수록 그렇습니다. 그래서 어려운 단어일수록 오히려 조각내기가 쉬워요.

  • port(나르다): import(안으로), export(밖으로), transport(가로질러), portable(나를 수 있는), 항구 port도 같은 뿌리
  • spect(보다): inspect(안을 보다), respect(다시 보다), suspect(아래에서 보다), spectator(보는 사람)
  • dict(말하다): predict(미리 말하다), dictionary(말 모음), dictate(말해 주다)
  • tele(멀리): telephone, television, telescope

붙을 때 소리 때문에 철자가 바뀐다: in+port → import, ex+spect → expect, sub+port → support, sub+spect → suspect

2. 단어마다 전략이 다르다

  • 길고 학술적인 말(international, biodegradable) → 조각내기
  • 짧고 흔한 말(get, run, take) → 덩어리 표현으로(get up, get along)
  • 짝으로 다니는 말(make a decision) → 통째로

3. 실험 모형과 실제의 차이

· 조각 뜻이 늘 실제 뜻과 딱 맞지는 않아요(indict = 기소하다, c는 소리 나지 않음).

· portion처럼 철자가 같아 보여도 뿌리가 다른 "가짜 친구"도 있습니다.

단어 = 접두사(방향·때) + 어근(핵심 뜻) + 접미사(품사·역할)
뭉치 · 제로

“import, export, transport, portable, porter… 왜 이렇게 비슷하게 생겼는데 뜻은 다 달라! 따로 외워야 해!” “비슷하게 생긴 게 힌트 아닐까?”

닥터 이안 · 제로

“port는 ‘나르다’라는 뜻의 뿌리다. 항구(port)도 같은 뿌리야. 물건을 나르는 곳이니까.” “다섯 단어가 아니라 뿌리 하나와 접두사 몇 개였네요.”

웹툰 8화 #2 · 단어를 조각으로 자르기

예제

inspector를 조각으로 나누고 뜻을 짐작하면?

in(안으로) + spect(보다) + -or(하는 사람) → 안을 들여다보는 사람 = 검사관.

get, take처럼 짧고 흔한 단어는 어떤 전략으로 익히는 것이 좋은가?

조각이 나지 않고 뜻이 많으므로 덩어리 표현(get up, get along)과 예문으로 익힌다. 조각내기는 international처럼 길고 학술적인 단어에 쓴다.
