고등 정치와 법 ④ · 웹툰 4화 「국제 갈등은 원인이 하나인가」

국제 갈등의 원인과 해결 — 원인이 여러 겹이면 처방도 여러 겹

상류 갑국의 댐과 하류 을국의 농업용수를 둘러싼 가상 공유 하천에서 정보 공유, 공동 하천 위원회, 가뭄 해 조항을 켜고 끄며 10년간 외교 충돌 건수와 합의 수준을 기록했습니다. 어느 나라를 혼내는 조건 없이 충돌이 14건 → 8건 → 3건 → 1건으로 줄었어요. 국제 갈등의 원인, 국제사법재판소의 관할, 세계시민의 역할을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 정보 실시간 공유, 공동 하천 위원회, 가뭄 해 조항을 각각 있음·없음으로 고르고 국제사법재판소로 가져가는 방법(가져가지 않음 / 을국 혼자 제소 / 두 나라가 동의)을 정한 뒤 10년 흘려 보내기를 누르면 해마다 충돌 막대가 자라고 10년간 충돌 건수, 합의 수준, 재판소 관할 결과가 나와 기록표에 쌓입니다. 국가와 건수는 제로 랩의 가상 실험이에요.

표 1. 조건별 10년간 외교 충돌 (실험 가상 값)

웹툰 표의 네 줄처럼 조건을 하나씩 켜면 충돌이 14건 → 8건 → 3건 → 1건으로 줄고 합의는 장기 협정까지 나아갔어요. 혼내는 조건은 하나도 없었습니다. 가뭄 조항이 없으면 3·7년째 가뭄 해에 충돌이 몰렸고, 조항을 켜면 그 몰림이 사라졌어요. 자원 문제엔 정보와 협의체가, 가뭄 불안에는 예외 조항이 맞는 처방이었습니다.

개념 정리

1. 국제 갈등의 다섯 원인

원인내용
영토·국경경계선을 둘러싼 서로 다른 주장
자원물·에너지·광물처럼 모자란 자원의 분배
민족·종교·문화정체성의 차이와 차별, 소수 집단 문제
역사 인식과거 사건에 대한 서로 다른 해석
경제적 이해무역, 관세, 산업 경쟁

실제 갈등은 대개 여러 칸이 겹쳐 있어, 하나의 원인만 찾아 ‘나쁜 쪽’을 지목하면 다른 칸의 원인이 그대로 남아요.

2. 국제사법재판소와 동의

국제사법재판소는 원칙적으로 분쟁 당사국들이 재판받기로 동의해야 사건을 다룰 수 있어요. 한쪽 나라 혼자 원한다고 다른 나라를 재판에 세울 수 없으니, 동의를 끌어내는 외교가 먼저입니다.

3. 세계시민이 할 수 있는 일

국제기구는 중재하고, 비정부 기구는 난민과 피해 지역을 돕고, 개인은 정확한 정보를 찾고 혐오 표현에 맞서며 기부나 캠페인에 참여할 수 있어요. 세계시민은 어느 나라 편을 드는 사람이 아니라 갈등을 여러 원인으로 이해하고 사람의 존엄을 먼저 보는 사람입니다.

원인 칸마다 맞는 처방: 자원 분배 → 정보 공유 + 공동 위원회 · 위기 때의 불안 → 예외(가뭄) 조항 · 국제사법재판소 = 당사국의 동의가 있어야 재판

10년간 충돌 건수·합의 수준은 제로 랩의 가상 값(웹툰 표에 없는 조합도 같은 방식의 가상 값)

예제

아무 조건도 없을 때와 정보 공유 + 공동 위원회일 때, 10년간 충돌 건수는 몇 건 줄었나요? 줄어든 비율은?

14건 → 3건으로 11건 줄었어요. 11 ÷ 14 ≈ 0.79이므로 11건, 약 79% 감소입니다.

을국이 갑국의 동의 없이 혼자 국제사법재판소에 제소하면 실험은 어떤 결과를 보여 주나요?

국제사법재판소는 원칙적으로 당사국의 동의가 있어야 사건을 다루므로 원칙적으로 재판이 열리기 어렵다는 결과가 나와요. 동의를 끌어내는 외교가 먼저입니다.
