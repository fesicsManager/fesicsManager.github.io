확산적 사고와 수렴적 사고 — 넓게 모은 뒤 기준으로 좁힌다

같은 문제(방학 동안 화분에 물 주기)를 A 모둠은 나오는 즉시 따지고, B 모둠은 15분 모은 뒤 5분 기준표로 골랐습니다. A는 아이디어 4개·2갈래, B는 19개·6갈래가 나왔고, B는 서로 다른 두 갈래를 합친 답이 기준 점수 8점 만점이었어요. 기술적 문제 해결 과정과 확산적·수렴적 사고를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: ‘모으는 방식’(A 모둠 · B 모둠)과 ‘좁히는 방법’(기준표 · 목소리 큰 사람)을 고른 뒤 20분 동안 풀어 보기를 누르면 아이디어가 갈래별로 쌓이고, 최종 아이디어와 기준 점수(8점 만점)가 나와요. 네 가지 조합을 해 보면 결과 비교 탭에서 두 모둠과 좁히는 방법을 견줄 수 있어요. (결과는 제로 랩의 가상 실험이에요.)

표 1. 모으는 방식과 좁히는 방법에 따른 결과 (제로 랩 가상 실험)
방식좁히기아이디어갈래망설인 사람최종 (점수)
A 모둠기준표4개2갈래4/5명페트병 거꾸로 꽂기 (6점)
A 모둠목소리 큰 사람4개2갈래4/5명자동 물 주기 장치 (3점)
B 모둠기준표19개6갈래1/5명심지 장치 + 그늘 쪽 바닥으로 옮기기 (8점)
B 모둠목소리 큰 사람19개6갈래1/5명자동 물 주기 장치 (3점)

나오자마자 따지면 사람들이 말하기를 망설여 아이디어와 갈래가 줄어요. 먼저 넓게 모은 B 모둠은 ‘자리 옮기기’처럼 장치가 아닌 생각까지 나와 두 갈래를 합친 답(8점)을 얻었어요. 하지만 많이 모아도 기준 없이 고르면 3점짜리가 뽑혔어요. 넓게 모으기와 기준으로 좁히기, 둘 다 필요합니다.

개념 정리

1. 기술적 문제 해결 과정

문제 확인 → 정보 수집 → 해결 방안 탐색 → 해결 방안 선정 → 만들기 → 평가. 확인한 문제, 모은 정보, 넓힌 아이디어, 좁힌 결정이 모두 기록에 남아야 다음에 고칠 수 있어요.

2. 확산적 사고와 수렴적 사고

  • 확산적 사고: 판단을 미루고, 많이, 여러 갈래로 아이디어를 낸다 (넓게 벌리는 깔때기)
  • 수렴적 사고: 기준을 세워 따지고 하나를 고른다, 필요하면 합친다 (좁게 모으는 깔때기)

3. 기준표로 좁히기

기준 예: 방학 내내 물이 가나 · 비용 · 우리 손으로 만들 수 있나 · 교실을 적시지 않나. 아이디어마다 기준별 점수를 매겨 더해요. 기준을 정하려면 방학 일수, 화분이 하루에 먹는 물의 양 같은 정보가 필요해요.

4. 실험 모형과 실제의 차이

· 아이디어 수와 점수는 제로 랩의 가상 실험이에요. 판단을 미루고 양을 늘리는 브레인스토밍 규칙은 실제로 쓰이는 방법입니다.
