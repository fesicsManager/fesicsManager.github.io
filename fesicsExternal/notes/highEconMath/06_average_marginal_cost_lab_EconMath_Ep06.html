평균 비용과 한계 비용 — 평균이 가장 작은 곳에서 둘은 같다

총비용 함수 C(q) = q² + 100에서 생산량을 바꿔 평균 비용 AC = C ÷ q와 한계 비용 MC = C′(q)를 계산했습니다. 평균 비용은 q = 10에서 20만 원으로 가장 작았고 그때 한계 비용도 정확히 20이었으며, 50개를 만들면 개당 52만 원으로 커졌습니다. 고정비가 나눠지는 효과와 늘어나는 비용의 경쟁, 미분으로 최솟값 찾기를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 총비용 함수(C = q² + 100 · C = 2q² + 200 · C = 10q + 100)와 생산량 q 슬라이더(1~60개)를 고르고 이만큼 만들어 보기를 누르면 평균 비용 곡선(파랑)과 한계 비용 선(빨강) 위에 현재 생산량이 표시되고, 결과 창에 MC와 AC의 관계가 나옵니다. 대본 함수에서 q = 5, 8, 10, 20, 50을 기록하면 결과 비교 탭에서 (생산량, 평균 비용) 점 그래프와 대본의 평균 비용표를 볼 수 있습니다. 비용 함수는 가상 모형입니다.

평균 비용 AC = q + 100/q에서 고정비 몫 100/q은 줄지만 q는 커지므로, 평균 비용은 q = 10까지 줄다가 다시 커집니다. MC < AC일 때는 새로 만든 하나가 평균을 끌어내리고, MC > AC일 때는 끌어올려서 평균이 가장 작은 q = 10에서 MC = AC = 20이 됩니다. 설비에 여유가 있는 C = 10q + 100에서는 평균 비용이 계속 줄어 10에 다가가므로, ‘계속 싸진다’는 비용 함수 모양에 달린 문제예요.

개념 정리

1. 고정비는 나눠지지만 늘어나는 비용은 더 빨리 커질 수 있다

평균 비용 AC(q) = q + 100/q 에서 100/q(고정비 나눔)은 q가 커질수록 작아지고, q(만드는 양에 따라 빨리 커지는 비용)는 커집니다. 둘이 겨루므로 평균 비용은 줄다가 다시 커져요.

  • 평균 비용 = 한 개당 비용 = C ÷ q
  • 한계 비용 = 한 개 더 만들 때 늘어나는 비용 = C′(q)
  • MC < AC이면 새로 만든 하나가 평균을 끌어내리고, MC > AC이면 끌어올립니다. 그래서 평균 비용이 가장 작은 곳에서 MC = AC예요.

2. 이 실험의 계산 방법

AC′(q) = 1 − 100/q² = 0 → q = 10, AC(10) = 10 + 10 = 20 = MC(10) = 2 × 10
C = 2q² + 200: AC = 2q + 200/q, AC′ = 2 − 200/q² = 0 → q = 10, AC = MC = 40.
C = 10q + 100: AC = 10 + 100/q 는 계속 줄어들어 10에 다가가고, MC = 10으로 늘 AC보다 작습니다.

3. 실험 모형과 실제의 차이

· q² 비용은 공장 크기가 정해진 짧은 기간을 본 모형입니다. 설비를 늘리면 비용 함수 자체가 바뀌어, 넓은 범위에서 ‘많이 만들수록 싸지는’ 규모의 경제가 나타나기도 해요.

· 그래서 ‘계속 줄어든다’도 ‘계속 늘어난다’도 비용 함수 모양을 보기 전에는 말할 수 없습니다.

· 생산량은 1개 단위로만 바꿀 수 있게 했습니다.

4. 생활 속에서 · 이어지는 개념

  • 5화의 매출 R과 6화의 비용 C를 합치면 이윤 = R − C가 됩니다. 이윤이 최대인 곳에서는 한계 수입과 한계 비용이 같아져요.
AC(q) = C(q) ÷ q = q + 100/q, MC(q) = C′(q) = 2q, AC′(q) = 1 − 100/q² = 0 → q = 10

C: 만 원, q: 개

닥터 이안

“우연이 아니다. 한계 비용이 평균보다 작으면 새로 만든 한 개가 평균을 끌어내리고, 크면 끌어올린다. 평균이 내려가다 올라가기 시작하는 지점은 둘이 같은 곳이야.”

웹툰 6화 #4 · 평균 비용표와 도함수

예제

C(q) = 2q² + 200일 때 평균 비용이 최소가 되는 생산량과 그때의 평균 비용·한계 비용을 구하시오.

AC = 2q + 200/q, AC′ = 2 − 200/q² = 0 → q² = 100 → q = 10. AC(10) = 20 + 20 = 40, MC = 4q = 40이므로 q = 10에서 AC = MC = 40입니다.

C(q) = q² + 100에서 q = 20일 때 하나를 더 만들면 평균 비용은 올라가는가, 내려가는가?

AC(20) = 20 + 5 = 25, MC(20) = 40. MC > AC이므로 새로 만든 하나가 평균보다 비싸 평균 비용은 올라갑니다(AC(21) ≈ 25.76).
