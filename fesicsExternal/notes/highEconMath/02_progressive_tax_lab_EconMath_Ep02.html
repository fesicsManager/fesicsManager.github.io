누진세와 구간별 일차함수 — 높은 세율은 넘친 부분에만

수업용 예시 세율표(0~2,000만 원 10%, 2,000만~5,000만 원 20%, 5,000만 원 초과 30%)로 소득을 바꿔 가며 세금·실수령액·실효세율을 계산하고, 초과분에만 세율을 매기는 방식과 전체에 세율을 매기는 뭉치의 방식을 비교했습니다. 5,000만 원에서 5,100만 원으로 늘면 실제로는 세금이 30만 원만 늘고 실수령액은 70만 원 늘었지만, 뭉치의 방식에서는 실수령액이 430만 원 줄었습니다. 구간별 일차함수, 한계세율과 실효세율을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 과세 소득 x 슬라이더(0~10,000만 원)와 세금 계산 방식(구간별 초과분에만 · 전체 소득에 그 구간 세율)을 고르고 세금 계산하기를 누르면 소득이 세 구간 컵에 채워지고 실수령액 그래프 위에 점이 찍힙니다. 결과 창의 ‘100만 원 더 벌면’을 보며 5,000과 5,100을 두 방식으로 모두 기록하면 결과 비교 탭에서 실수령액이 줄어든 구간이 있는지 판정해 줍니다. 세율표는 실제 세법 수치가 아닌 예시 구간입니다.

표 1. 소득과 계산 방식에 따른 세금 (실험 예시, 예시 세율표, 단위 만 원)
소득방식세금실수령액실효세율
2,000초과분2001,80010.0%
4,900초과분7804,12015.9%
5,000초과분8004,20016.0%
5,100초과분8304,27016.3%
5,000전체에1,0004,00020.0%

초과분 방식에서는 5,000 → 5,100으로 100만 원 더 벌 때 넘친 100만 원에만 30%가 붙어 세금은 30만 원, 실수령액은 70만 원 늘어납니다. 전체에 세율을 매기면 5,100만 원 전체에 30%가 붙어 실수령액이 4,000 → 3,570으로 떨어지는 절벽이 생기지만, 누진세는 그렇게 설계하지 않아요. 실수령액 x − T(x)의 기울기가 0.9 → 0.8 → 0.7로 늘 양수이기 때문입니다.

개념 정리

1. 구간 세율은 그 구간에 들어간 부분에만

소득을 컵 세 개에 차례로 붓는다고 생각하세요. 첫 컵(0~2,000만 원)이 차야 둘째 컵으로 넘치고, 넘친 부분에만 다음 세율이 붙습니다. 그래서 구간이 올라가도 이미 앞 컵에 담긴 소득의 세금은 그대로예요.

  • 세금 T(x)는 구간 경계(2,000, 5,000)에서 끊기지 않고 꺾이기만 합니다. 기울기가 0.1 → 0.2 → 0.3으로 바뀔 뿐이에요.
  • 실수령액 x − T(x)의 기울기는 0.9 → 0.8 → 0.7로 늘 양수 → 소득이 늘면 실수령액도 반드시 늘어납니다.

2. 한계세율과 실효세율

한계세율 = 마지막 1만 원에 붙는 세율(구간 세율). 실효세율 = 세금 ÷ 전체 소득. 소득 5,100만 원이면 한계세율 30%, 실효세율 약 16.3%로 서로 다릅니다.

3. 이 실험의 계산 방법

0 ≤ x ≤ 2,000: T = 0.1x 2,000 < x ≤ 5,000: T = 200 + 0.2(x − 2,000) x > 5,000: T = 800 + 0.3(x − 5,000) (단위 만 원)

4. 실험 모형과 실제의 차이

· 세 구간 세율표는 수업용 예시 구간이며 실제 소득세율표가 아닙니다.

· 실제 세금에는 공제·감면·지방세 등이 더해져 계산이 더 복잡합니다. 그래도 ‘구간 세율은 초과분에만’이라는 뼈대는 같아요.

· ‘전체에 세율’ 방식은 오개념을 보여 주기 위한 비교용 계산입니다.

5. 생활 속에서 · 이어지는 개념

  • “구간이 올라가서 손해”라는 말은 대부분 전체에 세율을 매기는 오해에서 나옵니다. 누진 구조의 전기 요금 등도 구간별로 나눠 계산해요.
T(x) = 0.1x (x ≤ 2,000) · 200 + 0.2(x − 2,000) (2,000 < x ≤ 5,000) · 800 + 0.3(x − 5,000) (x > 5,000)

x, T: 만 원 · 예시 세율표(실제 세법 수치 아님)

뭉치 · 제로

“이번 달 일을 더 하면 소득이 5,000만 원을 넘어서 세율 구간이 올라가! 그럼 번 돈 전체에 높은 세율이 붙어서 손해야! 일 안 할래!” “그 표는 누가 만든 건데?” “…내 머릿속.”

웹툰 2화 #1 · 뭉치가 일을 거절한다

제로

“5,000에서 5,100으로 100만 원 더 벌면 세금은 30만 원만 늘어요. 실수령액은 70만 원 늘고요.”

웹툰 2화 #4 · 구간별 계산과 그래프

예제

예시 세율표에서 과세 소득이 6,000만 원일 때 세금, 실수령액, 실효세율을 구하시오.

T = 800 + 0.3 × (6,000 − 5,000) = 800 + 300 = 1,100만 원, 실수령액 = 6,000 − 1,100 = 4,900만 원, 실효세율 = 1,100 ÷ 6,000 ≈ 18.3% (한계세율은 30%).

예시 세율표에서 과세 소득이 2,500만 원일 때 세금과 실효세율을 구하시오.

T = 200 + 0.2 × (2,500 − 2,000) = 200 + 100 = 300만 원, 실효세율 = 300 ÷ 2,500 = 12%입니다.
