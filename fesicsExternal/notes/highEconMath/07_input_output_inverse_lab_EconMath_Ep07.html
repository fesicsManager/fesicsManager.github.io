고등 경제 수학 · 웹툰 7화 「한 산업의 수요가 100 늘면 생산도 100만 늘어나는가」

투입 계수 행렬과 역행렬 — 수요 100이 생산 217로 번지다

두 산업의 투입 계수표 A = [[0.2, 0.3], [0.4, 0.1]]로 최종 수요가 늘 때의 생산 증가를 단계별로 쌓고 역행렬 (I − A)⁻¹로 한 번에 구해 비교했습니다. 1번 산업 수요가 100 늘면 누적 합은 100 → 160 → 188 → 202.4 → … 로 커져 역행렬 값 (150, 66.67), 합 약 216.7에 다가갔습니다. 산업 연관 효과와 행렬의 등비급수를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 투입 계수표(대본 계수표 · 재료를 더 쓰는 산업), 늘어난 최종 수요(1번 +100 · 2번 +100 · 두 산업 +50씩), 어디까지 계산할까(0단계 ~ 5단계 · 끝까지(역행렬))를 고르고 파급 계산하기를 누르면 두 산업의 생산 증가가 단계별 막대로 쌓이고 점선(역행렬 값)과 비교됩니다. 대본 계수표에서 1번 산업 +100을 0단계부터 끝까지 기록하면 결과 비교 탭에서 기록별 누적 합과 대본의 파급 단계표를 볼 수 있습니다. 투입 계수는 가상값입니다.

1번 산업이 100을 더 만들려면 재료로 1번 제품 20과 2번 제품 40이 필요하고, 그 재료를 만들려면 또 재료가 필요합니다. 단계마다 새로 필요한 양은 (20, 40) → (16, 12) → (6.8, 7.6)처럼 줄어들어 누적 합이 무한히 커지지 않고 약 216.7에 수렴해요. 이것이 (I − A)⁻¹ = I + A + A² + ⋯ 이고, 수요 100이 생산 약 217을 움직이는 산업 연관 효과입니다. 재료를 더 쓰는 계수표에서는 같은 수요 100이 약 361로 번졌습니다.

개념 정리

1. 생산된 것의 일부는 다시 다른 생산의 재료가 된다

1번 산업 제품 1을 만들려면 1번 제품 0.2와 2번 제품 0.4가 필요합니다. 그 재료를 만들려면 또 재료가 필요하고… 그래서 최종 수요만큼만 만들면 모자랍니다.

  • 총생산 x = 중간재 Ax + 최종 수요 d → (I − A)x = d → x = (I − A)⁻¹d
  • 단계별 파급: d, Ad, A²d, A³d, ⋯ 를 차례로 더하면 (I − A)⁻¹ = I + A + A² + A³ + ⋯ (행렬의 등비급수)
  • 투입 계수가 충분히 작으면 단계마다 필요한 양이 줄어 일정한 값으로 수렴합니다. 무한히 늘어나지 않아요.

2. 이 실험의 계산 방법

A = [[0.2, 0.3], [0.4, 0.1]] → I − A = [[0.8, −0.3], [−0.4, 0.9]], 행렬식 = 0.8 × 0.9 − (−0.3)(−0.4) = 0.6
(I − A)⁻¹ = (1/0.6)[[0.9, 0.3], [0.4, 0.8]] = [[1.5, 0.5], [0.667, 1.333]]
d = (100, 0) → x = (150, 66.7), 합 약 216.7

3. 실험 모형과 실제의 차이

· 투입 계수가 고정돼 있다고 가정합니다. 실제로는 가격이 오르면 재료를 바꾸기도 해요.

· 공장이 꽉 차 있으면 생산을 바로 늘릴 수 없습니다. 그래서 이 계산은 ‘파급의 크기를 어림하는 도구’로 씁니다.

· ‘재료를 더 쓰는 산업’ 계수표는 비교용 가상값입니다.

4. 생활 속에서 · 이어지는 개념

  • 정부·연구 기관은 산업 연관표로 어떤 산업의 수요 변화가 전체 생산·고용에 미치는 효과(생산 유발 계수)를 어림합니다. 나라 사이의 부가가치 사슬도 같은 원리로 추적해요.
x = Ax + d → (I − A)x = d → x = (I − A)⁻¹d, (I − A)⁻¹ = I + A + A² + A³ + ⋯

A = [[0.2, 0.3], [0.4, 0.1]], (I − A)⁻¹ = [[1.5, 0.5], [0.667, 1.333]]

예제

대본 계수표에서 2번 산업의 최종 수요가 100 늘 때 두 산업의 생산 증가량을 역행렬로 구하시오.

x = (I − A)⁻¹(0, 100) = (0.5 × 100, 1.333 × 100) ≈ (50, 133.3), 합 약 183.3. 1번 산업 수요가 늘 때(합 약 216.7)보다 파급이 작습니다.

대본 계수표에서 최종 수요 d = (100, 0)일 때 1단계(재료)로 새로 필요한 양 Ad를 구하시오.

Ad = (0.2 × 100 + 0.3 × 0, 0.4 × 100 + 0.1 × 0) = (20, 40). 누적은 (120, 40), 합 160입니다.
