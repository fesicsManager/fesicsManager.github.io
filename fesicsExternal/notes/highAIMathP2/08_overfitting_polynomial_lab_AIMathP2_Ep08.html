과적합 — 학습 오차 0인 모델이 새 자료에서 가장 크게 틀렸다

학습 자료 네 점에 0차부터 3차까지 다항식을 최소제곱으로 맞추고 학습 MSE와 새 자료 x = 4(y = 5)의 예측을 기록했습니다. 3차 모델은 학습 MSE가 0이었지만 ŷ(4) = 15로 10이나 틀렸고, 학습 MSE 0.45인 직선은 4.50으로 0.5만 틀렸습니다. 학습 오차와 새 자료 오차를 함께 봐야 하는 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 다항식 차수(0차 평균 · 1차 직선 · 2차 · 3차 네 점 통과)를 고르고 모델 맞추기를 누르면 학습 자료 (0, 1), (1, 3), (2, 2), (3, 4)에 맞춘 곡선이 x = 5까지 그려지고, 학습 MSE와 새 자료 x = 4의 예측·오차가 나옵니다. 0차부터 3차까지 차례로 기록하면 결과 비교 탭에서 차수별 학습 오차와 새 자료 오차를 막대로 비교할 수 있습니다.

표 1. 차수별 학습 오차와 새 자료 오차 (실험 예시, 새 자료 x = 4일 때 실제 y = 5)

0차 (평균)1.2502.50+2.502.50

차수를 올릴수록 학습 MSE는 1.250 → 0.450 → 0.000으로 줄었지만, 새 자료 오차는 직선이 0.5로 가장 작았고 학습 오차 0인 3차 모델이 10으로 가장 크게 틀렸습니다. 3차 모델은 3에서 2로 내려갔다 4로 오르는 작은 흔들림까지 따라가려 휘었고, 그 휨이 자료 바깥에서 x = 5에 41까지 번졌어요. 이렇게 학습 자료에만 지나치게 맞춘 상태가 과적합입니다. 이 네 점에서는 최소제곱 2차식의 x² 계수가 0이라 직선과 같게 나왔어요.

개념 정리

1. 흔들림까지 외우면 바깥에서 크게 틀린다

점 네 개는 3차 함수 하나로 정확히 지나갈 수 있습니다: ŷ = x³ − 4.5x² + 5.5x + 1. 학습 오차는 0이지만, 3에서 2로 내려갔다 4로 오르는 작은 흔들림까지 따라가려고 휘어서 자료 바깥(x = 4)에서 15로 치솟아요. 학습 자료에만 지나치게 맞춘 상태를 과적합이라고 합니다.

  • 직선(최소제곱) ŷ = 0.8x + 1.3: 학습 MSE 0.45, x = 4에서 4.5 (0.5만 틀림).
  • 3차: 학습 MSE 0, x = 4에서 15 (10 틀림), x = 5면 41 (직선은 5.3).

2. 이 실험의 계산 방법

최소제곱: Σ(yᵢ − ŷᵢ)²이 가장 작은 계수 학습 MSE = Σ(yᵢ − ŷᵢ)² ÷ 4 새 자료 오차 = 5 − ŷ(4)

3. 실험 모형과 실제의 차이

· 실제로는 자료 일부를 학습에 쓰지 않고 떼어 두었다가 학습이 끝난 뒤 그 자료로 시험합니다.

· 직선이 항상 정답은 아닙니다. 너무 단순하면 학습 자료도 못 맞히고, 너무 복잡하면 흔들림까지 외워요. 그 사이를 새 자료의 오차로 찾습니다.

4. 생활 속에서 · 이어지는 개념

  • 연습 문제 답을 통째로 외우면 연습에서는 100점이지만 처음 보는 시험 문제에서는 무너집니다. 인공지능도 같아요.

웹툰 8화 #4 · 학습 오차와 새 자료 오차

예제

3차 모델 ŷ = x³ − 4.5x² + 5.5x + 1과 직선 ŷ = 0.8x + 1.3의 x = 5에서의 예측을 각각 구하시오.

3차: 125 − 4.5 × 25 + 5.5 × 5 + 1 = 125 − 112.5 + 27.5 + 1 = 41. 직선: 0.8 × 5 + 1.3 = 5.3. 따라서 3차 41, 직선 5.3으로 자료에서 멀어질수록 차이가 커집니다.

직선 ŷ = 0.8x + 1.3의 학습 MSE를 구하시오.

예측 1.3, 2.1, 2.9, 3.7이므로 오차는 −0.3, 0.9, −0.9, 0.3입니다. MSE = (0.09 + 0.81 + 0.81 + 0.09) ÷ 4 = 1.8 ÷ 4 = 0.45예요.
