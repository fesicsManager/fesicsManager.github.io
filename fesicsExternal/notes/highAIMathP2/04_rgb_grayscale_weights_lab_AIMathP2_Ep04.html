고등 인공지능 수학 ② · 웹툰 4화 「흑백 사진은 세 색의 평균인가」

RGB 가중합 — 흑백 변환은 세 값을 하나로 줄이는 선택이다

색 하나를 골라 단순 평균, BT.601 가중합, BT.709 가중합으로 흑백 값을 계산하고 기록했습니다. 단순 평균으로는 빨강·초록·파랑이 모두 85였지만 BT.601로는 76.24, 149.69, 29.07로 갈라졌고, BT.709에서도 초록 182 · 파랑 18로 초록이 가장 밝았습니다. 가중합으로 차원을 줄이는 계산과 가중치가 정하는 것을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 색 (R, G, B)(빨강, 초록, 파랑, 노랑, 흰색, 주황빛)과 흑백 변환 방법(단순 평균 · BT.601 가중합 · BT.709 가중합)을 고르고 흑백으로 바꾸기를 누르면 채널별 기여 막대와 바뀐 회색, 흑백 값이 나옵니다. 초록과 파랑을 단순 평균과 BT.601로 각각 바꿔 기록하면 결과 비교 탭에서 색별 흑백 값을 막대로 비교할 수 있습니다.

표 1. 색·방법별 흑백 값 (실험 예시)
색방법흑백 값정수
빨강 (255, 0, 0)평균85.0085
빨강 (255, 0, 0)BT.60176.2476
초록 (0, 255, 0)BT.601149.69150
파랑 (0, 0, 255)BT.60129.0729
초록 (0, 255, 0)BT.709182.38182
주황빛 (200, 100, 50)BT.601124.20124

단순 평균은 세 채널에 1/3씩 같은 무게를 주므로 빨강·초록·파랑이 모두 85, 같은 회색이 되었습니다. BT.601은 사람 눈이 가장 밝게 느끼는 초록에 0.587, 가장 어둡게 느끼는 파랑에 0.114를 주어 초록 약 150, 파랑 약 29로 갈랐어요. BT.709는 숫자가 다르지만 초록 > 빨강 > 파랑의 순서는 같았습니다. 가중치의 합이 1이라 흰색은 어느 방법이든 255 그대로예요.

개념 정리

1. 세 값을 하나로 줄이는 가중합

컬러 픽셀 (R, G, B)를 회색 하나로 줄이는 것은 가중합 w₁R + w₂G + w₃B입니다. 사람 눈은 같은 세기라도 초록을 가장 밝게, 파랑을 가장 어둡게 느끼기 때문에 영상 표준은 초록에 큰 가중치를 줘요.

  • 가중치의 합 = 1 → 흰색 (255, 255, 255)은 그대로 255로 남습니다.
  • BT.601: 초록 0.587 × 255 = 149.685 ≈ 150, 파랑 0.114 × 255 = 29.07 ≈ 29.
  • 단순 평균으로는 빨강·초록·파랑이 모두 85, 같은 회색이 됩니다.

2. 이 실험의 계산 방법

단순 평균 = (R + G + B) ÷ 3 BT.601 = 0.299R + 0.587G + 0.114B BT.709 = 0.2126R + 0.7152G + 0.0722B

3. 실험 모형과 실제의 차이

· 실제 영상 처리에서는 감마 보정 같은 단계가 더해져 숫자가 조금 다를 수 있습니다.

· 어느 방법이든 값 세 개를 하나로 줄이므로 정보가 사라지고, 다른 색이 같은 회색이 되는 일이 생깁니다.

4. 생활 속에서 · 이어지는 개념

  • 파란 하늘이 흑백 사진에서 어둡게 나오는 까닭, 초록 글씨와 파란 글씨가 흑백 인쇄에서 다르게 보이는 까닭이 이 가중치입니다. 색이 핵심 단서인 문제(익은 과일 고르기)라면 흑백으로 바꾸기 전에 무엇이 사라지는지 따져야 해요.
흑백 값 = w₁R + w₂G + w₃B, BT.601: 0.299R + 0.587G + 0.114B, BT.709: 0.2126R + 0.7152G + 0.0722B

R, G, B: 0~255, 가중치 합 = 1 · 가중치는 영상 표준 값, 색은 계산 연습용 예시

웹툰 4화 #4 · 두 방법의 흑백 값 표

예제

노랑 (255, 255, 0)을 단순 평균과 BT.601 가중합으로 각각 흑백 변환하시오.

단순 평균: (255 + 255 + 0) ÷ 3 = 170. BT.601: 0.299 × 255 + 0.587 × 255 = 76.245 + 149.685 = 225.93 ≈ 226. 따라서 평균 170, BT.601 약 226으로 가중합이 더 밝아요.

단순 평균으로는 같은 회색이지만 BT.601로는 30 이상 차이 나는 두 색의 예를 실험의 색에서 찾고 차이를 구하시오.

빨강 (255, 0, 0)과 파랑 (0, 0, 255)은 평균이 모두 85이지만, BT.601로는 76.245와 29.07입니다. 차이는 약 47로 30 이상이에요(초록과 파랑이면 약 121).
