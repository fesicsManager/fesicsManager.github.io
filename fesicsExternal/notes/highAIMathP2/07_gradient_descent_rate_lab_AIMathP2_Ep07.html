경사 하강법과 학습률 — 한 걸음마다 (1 − 2η)가 곱해진다

손실 골짜기 f(x) = x²에서 x = 4로 출발해 학습률 η를 바꾸며 다섯 걸음씩 경사 하강을 하고 x₅와 결과를 기록했습니다. η = 0.1은 1.3107로 천천히, 0.4는 0.00128로 빠르게 다가갔고, 0.5는 한 걸음 만에 바닥에 닿았지만 0.9는 좌우로 튀었고 1.1은 −9.9533까지 멀어졌습니다. 학습률이 수렴과 발산을 가르는 원리를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 손실 골짜기(f(x) = x², 출발 x = 4 · f(x) = 3x², 출발 x = 2)와 학습률 η(0.1, 0.3, 0.4, 0.5, 0.9, 1.0, 1.1)를 고르고 다섯 걸음 걷기를 누르면 곡선 위에서 공이 걸음마다 움직이고 x₀ → x₅와 한 걸음에 곱해지는 수, 결과가 나옵니다. 웹툰 골짜기에서 여러 학습률을 기록하면 결과 비교 탭에서 학습률별 |x₅|를 막대로 비교할 수 있습니다.

f′(x) = 2x이므로 새 x = x − η × 2x = (1 − 2η) × x, 곧 걸음마다 같은 수 (1 − 2η)가 곱해지는 등비수열입니다. η를 0.1에서 0.4, 0.5로 키우면 빨라졌지만, 0.5를 넘으면 곱하는 수가 음수가 되어 바닥을 건너뛰기 시작했고 η = 0.9는 0.1과 같은 크기로 튀며 겨우 다가갔어요. |1 − 2η| < 1, 곧 0 < η < 1일 때만 수렴하고, η = 1.1이면 4 → −4.8 → 5.76 → −6.912 → 8.2944 → −9.9533으로 발산했습니다.

개념 정리

1. 한 걸음마다 곱해지는 수 (1 − 2η)

경사 하강: 새 x = x − η × f′(x). f(x) = x²이면 f′(x) = 2x이므로 새 x = (1 − 2η) × x. 걸음마다 같은 수가 곱해지는 등비수열이에요.

  • |1 − 2η| < 1, 즉 0 < η < 1이면 x → 0으로 수렴. η = 0.5면 한 걸음 만에 0.
  • 0.5 < η < 1이면 1 − 2η가 음수 → 바닥을 넘어 좌우로 튀며 다가갑니다.
  • η = 1이면 영원히 왕복, η > 1이면 튀며 멀어집니다(발산). η = 1.1: 4 → −4.8 → 5.76 → −6.912 → 8.294.

골짜기

2. 이 실험의 계산 방법

f(x) = a·x², f′(x) = 2a·x → xn+1 = (1 − 2aη)·xn (웹툰 a = 1, 과제 a = 3)

3. 실험 모형과 실제의 차이

· 실제 손실 함수는 방향마다 골짜기 폭이 달라 알맞은 학습률을 미리 정확히 알 수 없습니다. 여러 값을 시험하거나, 처음엔 크게 걷다가 점점 줄이는 방법을 써요.

· 학습률처럼 사람이 미리 정해 주는 수를 하이퍼파라미터라고 합니다.

4. 생활 속에서 · 이어지는 개념

  • 너무 작으면 느리고, 너무 크면 튀고 — 샤워기 온도를 맞출 때 손잡이를 너무 크게 돌리면 뜨거움과 차가움을 오가는 것과 같아요.
x_(n+1) = x_n − η f′(x_n), f(x) = a·x²이면 x_(n+1) = (1 − 2aη) x_n

η: 학습률(하이퍼파라미터), 웹툰 골짜기 a = 1, 과제 골짜기 a = 3 · 손실 함수는 계산 연습용 단순 모형

예제

손실 함수 f(x) = 3x²에서 x = 2로 출발해 η = 0.1, 0.3, 0.4로 다섯 걸음씩 계산하고, 이 골짜기에서 수렴하는 학습률의 범위를 구하시오.

f′(x) = 6x이므로 곱하는 수는 1 − 6η입니다. η = 0.1(×0.4): 2 → 0.8 → 0.32 → 0.128 → 0.0512 → 0.02048로 수렴, η = 0.3(×(−0.8)): 2 → −1.6 → 1.28 → −1.024 → 0.8192 → −0.65536으로 튀며 수렴, η = 0.4(×(−1.4)): 2 → −2.8 → 3.92 → −5.488 → 7.6832 → −10.75648로 발산. |1 − 6η| < 1에서 0 < η < 1/3입니다.

f(x) = x², x₀ = 4, η = 0.3일 때 다섯 걸음 뒤 x₅를 구하시오.

곱하는 수 1 − 2 × 0.3 = 0.4이므로 4 → 1.6 → 0.64 → 0.256 → 0.1024 → 0.04096입니다. 실험 값 0.041과 같아요.
