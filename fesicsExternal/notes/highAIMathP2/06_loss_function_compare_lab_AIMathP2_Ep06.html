손실 함수 — 오차 합은 상쇄되고 제곱 평균은 가려낸다

자료 (1, 2), (2, 4), (3, 6)에 모델 직선을 골라 오차 합, 절댓값 평균, 제곱 평균(MSE)을 기록했습니다. 모델 A(ŷ = 4)는 오차 합이 0인데 MSE가 2.67로, 오차 합이 −3인 C(MSE 1)보다 나빴고, 평균점 직선은 기울기 m을 0~4로 바꿔도 오차 합이 늘 0이었습니다. 손실을 재는 방법이 모델의 좋고 나쁨을 정한다는 점을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 모델(A: ŷ = 4 · B: ŷ = 2x · C: ŷ = 2x + 1 · 평균점 직선 ŷ = 4 + m(x − 2)), 평균점 직선의 기울기 m(0~4, 0.5씩), 강조할 손실(오차 합 · 절댓값 평균 · 제곱 평균)을 고르고 손실 재기를 누르면 자료와 직선 사이의 오차 막대와 세 손실 값이 나옵니다. A, B, C를 재고 평균점 직선의 m을 바꿔 기록하면 결과 비교 탭에서 m에 따른 오차 합과 MSE를 그래프로 볼 수 있습니다.

A는 양 끝에서 2씩 틀렸는데도 +2와 −2가 서로 지워 오차 합이 0이었습니다. 평균점 (2, 4)를 지나는 직선은 m이 무엇이든 오차 합이 0이라 오차 합으로는 좋은 직선과 나쁜 직선을 가려낼 수 없었어요. 제곱하면 부호가 사라져 상쇄가 일어나지 않고 큰 오차가 더 큰 벌점을 받으므로, MSE = 2(m − 2)²/3은 m = 2일 때만 0이 되었습니다.

개념 정리

1. 부호가 있는 오차는 서로 지운다

오차 합에서는 +2와 −2가 상쇄됩니다. 그래서 모델 A(ŷ = 4)는 두 점에서 2씩 틀렸는데도 오차 합이 0이에요. 제곱하면 부호가 사라져 상쇄가 일어나지 않고, 큰 오차는 더 크게 벌점을 받습니다.

  • A: 오차 −2, 0, +2 → 합 0, MSE 8/3 ≈ 2.67 / C: −1, −1, −1 → 합 −3, MSE 1.
  • 평균점 (2, 4)를 지나는 ŷ = 4 + m(x − 2)는 m이 무엇이든 오차 합이 0입니다. MSE = 2(m − 2)²/3은 m = 2일 때만 0이에요.

2. 이 실험의 계산 방법

오차 eᵢ = yᵢ − ŷᵢ 오차 합 = Σeᵢ 절댓값 평균 = Σ|eᵢ| ÷ n MSE = Σeᵢ² ÷ n

3. 실험 모형과 실제의 차이

· 제곱 오차는 튀는 자료 하나에 크게 끌려가므로, 그럴 땐 절댓값 오차를 쓰기도 합니다. 손실 함수도 선택이에요.

· 이 실험은 자료 세 개의 연습용 예시입니다.

4. 생활 속에서 · 이어지는 개념

  • 인공지능은 손실을 줄이는 쪽으로 학습합니다. 손실을 어떻게 재느냐가 ‘무엇을 잘하는 모델’이 될지를 정해요.

웹툰 6화 #4 · 오차 합과 제곱 오차

예제

자료 (1, 3), (2, 5), (3, 4)의 평균점 (2, 4)를 지나는 직선 ŷ = 4 + m(x − 2)에서 m = 0, 0.5, 1일 때 오차 합과 MSE를 구하고, 오차 합만으로 직선을 고를 수 있는지 판단하시오.

오차는 (m − 1), 1, −m이라 합은 늘 0입니다. MSE는 m = 0이면 (1 + 1 + 0) ÷ 3 ≈ 0.67, m = 0.5이면 (0.25 + 1 + 0.25) ÷ 3 = 0.5, m = 1이면 (0 + 1 + 1) ÷ 3 ≈ 0.67. 오차 합은 모두 0이라 고를 수 없고, MSE로는 m = 0.5가 가장 좋습니다.

실험 자료 (1, 2), (2, 4), (3, 6)에서 평균점 직선의 기울기가 m = 1일 때 MSE를 구하고 공식 2(m − 2)²/3과 비교하시오.

ŷ = 4 + (x − 2) = x + 2이므로 예측 3, 4, 5, 오차 −1, 0, +1. MSE = (1 + 0 + 1) ÷ 3 ≈ 0.67이고, 2(1 − 2)²/3 = 2/3과 같습니다.
