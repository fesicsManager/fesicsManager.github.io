이차부등식 — 사이인지 바깥인지는 a와 부등호가 정한다

a, b, c와 부등호 방향을 바꾸며 그래프에서 조건을 만족하는 구간을 수직선에 표시하고 해의 모양을 기록했습니다. a > 0에서 < 0은 두 근 사이, > 0은 바깥이었고 a < 0이면 반대였으며, D = 0·D < 0에서는 해가 없거나 모든 실수가 되었습니다. 그래프로 푸는 원리를 정리합니다.

포물선이 x축 아래에 있는 구간이 < 0의 해. a < 0이면 양변에 −1을 곱해 같은 문제로 바꿉니다. (x − 1)(x − 2) < 0 → 곱이 음수려면 부호가 달라야 1 < x < 2 (x < 1, x < 2가 아님). 그래프를 그리면 외울 필요가 없습니다.

개념 정리

1. a > 0, 두 근 α < β: ax² + bx + c < 0은 "사이", > 0은 "바깥"

포물선이 x축 아래에 있는 구간이 < 0의 해예요. a > 0(아래로 볼록)이면 두 근 사이에서 음수, 바깥에서 양수. a < 0이면 반대예요. D = 0이면 < 0의 해가 없고 ≤ 0은 x = α 하나, D < 0이면 a > 0일 때 > 0이 모든 실수·< 0은 해 없음. 그래프를 그리면 외울 필요가 없어요.

왜 그럴까

  • x² − 3x + 2 < 0 → (x − 1)(x − 2) < 0 → 1 < x < 2. > 0 → x < 1 또는 x > 2.
  • −x² + 3x − 2 > 0은 양변 −1 곱해 위와 같은 문제.
  • x² + 1 > 0: 모든 실수. x² + 1 < 0: 해 없음.

2. 자주 하는 오해 바로잡기

· "(x − 1)(x − 2) < 0 → x < 1, x < 2" → 곱이 음수려면 부호가 달라야 해요.

3. 생활 속에서 · 이어지는 개념

  • 이익이 양수인 가격 범위, 공이 특정 높이 이상인 시간 구간이 이차부등식이에요.
그래프에서 조건 만족 구간을 수직선에 표시 → a·D 부호별 해의 모양 기록

예제

−x² + 5x − 4 ≥ 0을 푸시오.

x² − 5x + 4 ≤ 0 → (x − 1)(x − 4) ≤ 0 → 1 ≤ x ≤ 4.

모든 실수 x에서 x² + kx + 1 > 0이 성립할 k의 범위는?

D = k² − 4 < 0 → −2 < k < 2.
