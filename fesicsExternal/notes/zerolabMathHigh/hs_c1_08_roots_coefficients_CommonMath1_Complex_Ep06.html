근과 계수의 관계 — 합 −b/a, 곱 c/a

a, b, c를 바꾸며 두 근을 직접 구해 합·곱을 계산하고 −b/a, c/a와 비교했습니다. 실근이든 허근이든 합 = −b/a, 곱 = c/a가 항상 성립했고, a ≠ 1일 때도 a로 나누면 맞았습니다. 근과 계수의 관계와 활용을 정리합니다.

실험 안내: 근을 직접 계산해 합·곱을 −b/a, c/a와 비교합니다(허근 포함).

ax² + bx + c = a(x − α)(x − β) = ax² − a(α + β)x + aαβ에서 계수 비교. 근의 공식에서 ±√D가 합에서 상쇄, 곱에서 (b² − D)/4a² = c/a. α² + β² = (α + β)² − 2αβ, |α − β| = √D/|a|. 거꾸로 x² − (합)x + (곱) = 0. 삼차식: α + β + γ = −b/a, αβ + βγ + γα = c/a, αβγ = −d/a. a로 나누는 것을 잊지 않습니다.

개념 정리

1. α + β = −b/a, αβ = c/a

ax² + bx + c = a(x − α)(x − β) = ax² − a(α + β)x + aαβ이므로 계수를 비교하면 나와요. 근을 구하지 않아도 합·곱을 알 수 있고, 허근이어도 성립해요. 거꾸로 두 수를 근으로 하는 방정식은 x² − (합)x + (곱) = 0. 삼차식은 α + β + γ = −b/a, αβ + βγ + γα = c/a, αβγ = −d/a.

왜 그럴까

  • 2x² + 3x − 5 = 0: 근 1, −5/2. 합 −3/2 = −b/a ✓, 곱 −5/2 = c/a ✓.
  • α² + β² = (α + β)² − 2αβ, |α − β| = √D/|a|.
  • 근의 공식에서 ±√D 부분이 합에서는 상쇄, 곱에서는 (b² − D)/4a² = c/a.

2. 자주 하는 오해 바로잡기

· "합 = −b" → a로 나눠야 해요.

📋 데이터 확인 탭의 결론

“모든 기록에서 합 = −b/a, 곱 = c/a. ax² + bx + c = a(x − α)(x − β)를 전개해 계수를 비교하면 b = −a(α+β), c = aαβ 가 나옵니다. 근을 구하지 않아도 계수만 보면 됩니다.”

예제

2x² − 4x + 1 = 0의 두 근 α, β에 대해 α² + β²과 |α − β|는?

합 2, 곱 ½ → α² + β² = 4 − 1 = 3; |α − β| = √(16 − 8)/2 = √2.

두 근이 3 + √2, 3 − √2인 이차방정식(최고차 1)은?

합 6, 곱 7 → x² − 6x + 7 = 0.
