AB와 BA — 순서를 바꾸면 답이 달라진다

A의 성분을 바꾸며 같은 두 행렬을 AB, BA로 계산해 성분을 비교했습니다. 대부분 AB ≠ BA였고 같아지는 경우는 단위행렬·스칼라 행렬·같은 행렬의 거듭제곱 같은 특별한 예외뿐이었으며, 결합법칙과 분배법칙은 성립했습니다. 행렬 곱셈의 비가환성을 정리합니다.

실험 안내: 같은 두 행렬을 AB, BA로 계산해 성분별로 비교합니다.

표 1. AB와 BA (실험 예시)
ABABBAAB = BA?
[1 2; 0 3][1 0; 1 1][3 2; 3 3][1 2; 1 5]아니오
[1 1; 0 1][1 0; 1 1][2 1; 1 1][1 1; 1 2]아니오
[1 2; 0 3][1 0; 0 1] (E)[1 2; 0 3][1 2; 0 3]예
[2 0; 0 2][1 3; 2 1][2 6; 4 2][2 6; 4 2]예 (스칼라)

AB의 성분은 A의 행 · B의 열, BA는 B의 행 · A의 열로 계산 자체가 다릅니다. 기하적으로 ‘회전 후 반사’와 ‘반사 후 회전’은 다른 변환. AB = O이어도 A = O 또는 B = O가 아닐 수 있으며(영인자), 곱셈이니까 순서 무관은 행렬·함수 합성·회전에서 틀립니다.

개념 정리

1. 행렬 곱셈은 교환법칙이 성립하지 않아요: AB ≠ BA

수의 곱셈과 달리 행렬은 순서를 바꾸면 결과가 달라지는 것이 보통이에요. AB의 성분은 A의 행 · B의 열, BA는 B의 행 · A의 열로 계산 자체가 달라요. AB = BA가 되는 경우(단위행렬, 같은 행렬의 거듭제곱, 스칼라 행렬)는 특별한 예외예요. 결합법칙 (AB)C = A(BC)와 분배법칙은 성립해요.

왜 그럴까

  • A = [[1, 1], [0, 1]], B = [[1, 0], [1, 1]]: AB = [[2, 1], [1, 1]], BA = [[1, 1], [1, 2]].
  • 기하적으로: "회전 후 반사"와 "반사 후 회전"은 다른 변환.
  • AB = O이어도 A = O 또는 B = O가 아닐 수 있어요.

움직여 보기

AB와 BA를 나란히 계산해 보기

AB BA AB = BA ?

같은 두 행렬이라도 곱하는 순서를 바꾸면 결과가 달라져요. AB는 A의 행과 B의 열을, BA는 B의 행과 A의 열을 짝지으니 계산 자체가 다릅니다. B가 단위행렬 E나 2E처럼 스칼라행렬일 때만 AB = BA가 됩니다.

2. 자주 하는 오해 바로잡기

· "곱셈이니까 순서 무관" → 행렬·함수 합성·회전은 순서가 중요해요.

3. 생활 속에서 · 이어지는 개념

  • 옷을 입고 벗는 순서, 3D 그래픽에서 회전·이동 순서를 바꾸면 결과가 달라지는 것과 같아요.
같은 두 행렬을 AB, BA로 계산 → 성분 비교

예제

A = [1 1; 0 1], B = [1 0; 1 1]일 때 AB, BA를 구하시오.

AB = [2 1; 1 1], BA = [1 1; 1 2].

A = [1 1; 1 1], B = [1 −1; −1 1]일 때 AB는?

[0 0; 0 0] — 둘 다 영행렬이 아닌데 곱이 O(영인자).
