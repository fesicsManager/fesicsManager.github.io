유리함수의 평행이동 — 점근선은 x = p, y = q

k, p, q를 바꾸며 y = k/(x − p) + q의 세로·가로 점근선과 x = p + 1에서의 값을 기록했습니다. 점근선은 언제나 x = p, y = q였고, x − p인데 오른쪽으로 가는 까닭은 x = p에서 분모가 0이 되어 그래프가 터지기 때문이었습니다. 유리함수의 평행이동과 점근선을 정리합니다.

y = k/x의 점근선 x = 0, y = 0이 (p, q)만큼 함께 이동. y = (ax + b)/(cx + d)는 c ≠ 0, ad − bc ≠ 0이면 나눗셈으로 이 꼴로 고칠 수 있고 점근선은 x = −d/c, y = a/c; ad − bc = 0이면 약분되어 상수함수(구멍). 두 점근선의 교점 (p, q)가 대칭 중심이며 분모를 0으로 만드는 x가 p라 오른쪽.

개념 정리

1. y = k/(x − p) + q의 점근선은 x = p, y = q

y = k/x의 점근선 x = 0, y = 0이 (p, q)만큼 함께 이동해요. x − p인데 오른쪽으로 가는 이유는 x = p일 때 분모가 0이 되어 그래프가 터지는 자리(세로 점근선)가 되기 때문이에요. y = (ax + b)/(cx + d)는 c ≠ 0이고 ad − bc ≠ 0이면 나눗셈으로 이 꼴로 고칠 수 있고, 점근선은 x = −d/c, y = a/c예요. ad − bc = 0이면 분자와 분모가 비례해 약분되어 상수함수가 되고, x = −d/c는 세로 점근선이 아니라 그래프에 뚫린 구멍이에요.

왜 그럴까

  • y = 2/(x − 1) + 3: 점근선 x = 1, y = 3. 두 점근선 교점 (1, 3)이 대칭 중심.
  • y = (3x + 1)/(x − 1) = 3 + 4/(x − 1): 점근선 x = 1, y = 3.
  • k > 0이면 1·3사분면 방향, k < 0이면 2·4사분면 방향.
