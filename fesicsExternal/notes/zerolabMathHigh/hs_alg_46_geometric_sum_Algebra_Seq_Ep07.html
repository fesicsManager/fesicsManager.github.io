등비수열의 합 — r = 1은 따로 계산한다

첫째항 a, 공비 r, 항의 개수 n을 바꾸며 직접 더한 합과 공식 a(rⁿ − 1)/(r − 1), a·n을 비교했습니다. r ≠ 1이면 공식이 항상 맞았지만 r = 1이면 분모가 0이라 공식을 쓸 수 없었고 그때는 모든 항이 a라 na였습니다. 합 공식의 유도와 예외를 정리합니다.

S = a + ar + … + arⁿ⁻¹에 r을 곱해 빼면 rS − S = arⁿ − a → S(r − 1) = a(rⁿ − 1). r = 1이면 r − 1 = 0으로 나눌 수 없어 따로 na. |r| < 1이면 a(1 − rⁿ)/(1 − r)로 쓰면 부호가 편하고 n → ∞에서 a/(1 − r)로 수렴. 문제에서 r이 미지수면 경우를 나눕니다.

개념 정리

1. Sₙ = a(rⁿ − 1)/(r − 1) (r ≠ 1), r = 1이면 Sₙ = na

S = a + ar + … + arⁿ⁻¹에 r을 곱해 빼면 rS − S = arⁿ − a → S(r − 1) = a(rⁿ − 1). r = 1이면 r − 1 = 0으로 나눌 수 없어서 따로 계산해요 — 이때는 모든 항이 a라 na예요. |r| < 1이면 n → ∞일 때 합이 a/(1 − r)로 수렴해요.

왜 그럴까

  • a = 1, r = 2, n = 5: 1 + 2 + 4 + 8 + 16 = 31 = (32 − 1)/1.
  • a = 3, r = 1, n = 4: 12 = 4 × 3.
  • |r| < 1: a(1 − rⁿ)/(1 − r)로 쓰면 부호가 편해요.

2. 자주 하는 오해 바로잡기

· "공식은 항상 쓸 수 있다" → r = 1은 0/0 꼴. 문제에서 r이 미지수면 경우를 나눠요.
