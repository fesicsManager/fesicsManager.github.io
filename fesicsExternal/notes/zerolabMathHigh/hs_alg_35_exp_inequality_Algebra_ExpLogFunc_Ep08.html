지수·로그 부등식 — 밑이 1보다 작으면 뒤집힌다

밑 a와 x₁ < x₂를 바꾸며 a^x₁과 a^x₂의 대소를 비교했습니다. a > 1이면 a^x₁ < a^x₂로 부등호가 유지되었지만 0 < a < 1이면 a^x₁ > a^x₂로 뒤집혔습니다. 지수·로그 부등식에서 밑의 범위를 확인해야 하는 까닭을 정리합니다.

a > 1이면 증가함수, 0 < a < 1이면 감소함수. 밑을 맞춘 뒤 지수끼리 비교하되 밑이 1보다 작으면 부등호를 뒤집습니다. (½)ˣ < ⅛ → (½)ˣ < (½)³ → x > 3. 로그 부등식은 진수 > 0 조건도 함께: log_{0.5} x > 2 → x < 0.25이고 x > 0.

개념 정리

1. 밑이 1보다 크면 부등호 유지, 0과 1 사이면 뒤집힘

x₁ < x₂일 때 a > 1이면 a^(x₁) < a^(x₂)(증가함수), 0 < a < 1이면 a^(x₁) > a^(x₂)(감소함수)예요. 지수·로그 부등식을 풀 때 밑을 맞춘 뒤 지수끼리 비교하는데, 밑이 1보다 작으면 부등호를 뒤집어야 해요. 로그 부등식은 진수 > 0 조건도 함께 챙겨야 해요.

왜 그럴까

  • 2¹ < 2³ (2 < 8). (½)¹ > (½)³ (0.5 > 0.125).
  • (½)ˣ < ⅛ → (½)ˣ < (½)³ → x > 3.
  • log_{0.5} x > 2 → x < 0.25, 그리고 x > 0.

2. 자주 하는 오해 바로잡기

· "지수가 크면 값도 크다" → 밑이 1보다 작으면 반대예요.

3. 생활 속에서 · 이어지는 개념

  • 감가상각(0.8ⁿ)은 n이 클수록 작고, 복리(1.05ⁿ)는 클수록 커요 — 밑에 따라 방향이 달라요.

예제

(1/3)^(x−1) ≥ 1/27을 푸시오.

(1/3)^(x−1) ≥ (1/3)³ → 밑 < 1이라 x − 1 ≤ 3 → x ≤ 4.

log₂(x − 1) < 3을 푸시오.

진수 x > 1; x − 1 < 8 → 1 < x < 9.
