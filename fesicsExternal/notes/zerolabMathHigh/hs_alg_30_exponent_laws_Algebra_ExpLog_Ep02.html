지수의 확장 — 법칙을 지키려고 그렇게 정했다

밑 a와 지수 m, n에 0·음수·분수를 넣어 aᵐ·aⁿ과 aᵐ⁺ⁿ, (aᵐ)ⁿ과 aᵐⁿ을 수치로 비교했습니다. 어떤 지수를 넣어도 두 법칙이 그대로 성립했고, a⁰ = 1, a⁻ⁿ = 1/aⁿ, a^(1/n) = ⁿ√a는 법칙을 유지하기 위해 정할 수밖에 없는 값이었습니다. 지수 확장의 논리를 정리합니다.

개념 정리

1. a⁰ = 1, a⁻ⁿ = 1/aⁿ, a^(1/n) = ⁿ√a는 지수법칙을 유지하기 위한 정의

지수를 0·음수·분수로 넓힐 때 새 규칙을 만든 게 아니라, aᵐ·aⁿ = aᵐ⁺ⁿ, (aᵐ)ⁿ = aᵐⁿ이 그대로 성립하도록 값을 정한 거예요. aⁿ·a⁰ = aⁿ⁺⁰ = aⁿ이려면 a⁰ = 1, aⁿ·a⁻ⁿ = a⁰ = 1이려면 a⁻ⁿ = 1/aⁿ, (a^(1/n))ⁿ = a¹ = a이려면 a^(1/n) = ⁿ√a여야 해요. 이렇게 정하면 밑 a > 0인 실수 지수 범위에서는 m, n에 어떤 실수를 넣어도 좌변과 우변이 일치해요. 밑이 음수이거나 0이면 유리수 지수가 정의되지 않거나 (aᵐ)ⁿ = aᵐⁿ이 깨질 수 있어서, 이 실험도 a > 0만 다뤄요.

확인

  • 2³ · 2⁻¹ = 8 × ½ = 4 = 2². (8^(1/3))² = 2² = 4 = 8^(2/3).
  • 2², 2¹, 2⁰, 2⁻¹: 4, 2, 1, ½ — 절반씩 줄어드는 흐름이 자연스럽게 이어져요.
  • 밑 a > 0이어야 분수 지수가 잘 정의돼요((−8)^(1/3)은 주의).

예제

8^(2/3)과 (1/4)^(−1/2)의 값은?

(³√8)² = 4; (1/4)^(−1/2) = (4)^(1/2) = 2.

연 5 % 이자를 월 단위로 나눌 때 월 이율은?

1.05^(1/12) − 1 ≈ 0.407 %(5/12 = 0.417 %가 아님).
