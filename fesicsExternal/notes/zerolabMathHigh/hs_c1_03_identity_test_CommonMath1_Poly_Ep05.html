항등식 — n차식은 n + 1개의 x에서 일치하면 항등식

이차식 g(x) = px² + qx + r의 계수를 바꾸며 f(x) = x² + 3x + 2와 7개의 x에서 값을 비교해 일치한 점의 개수와 항등식 여부를 기록했습니다. 계수가 모두 같을 때만 7개 모두 일치했고, 계수가 다르면 일치한 점이 최대 2개(교점)였으며 3개 이상 일치하면 항등식이었습니다. 항등식의 판정 기준을 정리합니다.

f − g가 n차 이하인데 n + 1개의 근을 가지면 영다항식(n차식의 근은 최대 n개). 이차식끼리는 서로 다른 3개의 x에서 같으면 모든 x에서 같고, 1~2개 일치는 우연(교점)일 수 있습니다. 계수비교법과 수치대입법이 같은 결론. 항등식은 모든 x, 방정식은 특정 x.

개념 정리

1. n차 이하 다항식은 서로 다른 n + 1개의 x에서 일치하면 항등식

f − g가 n차 이하인데 n + 1개의 근을 가지면 영다항식이에요(n차식은 근이 최대 n개). 그래서 x² + 3x + 2와 이차식 g(x)가 서로 다른 3개의 x에서 같으면 모든 x에서 같아요. 반대로 1개나 2개만 맞는 것은 우연(교점)일 수 있어요. 계수비교법과 수치대입법이 같은 결론을 줘요.

왜 그럴까

  • g = x² + 3x + 2와 다른 이차식은 교점이 최대 2개 → 3개 일치 불가.
  • 7개 중 2개만 일치: 항등식 아님. 3개 이상 일치: 항등식(이차식끼리).
  • 항등식은 '모든 x에서' 성립, 방정식은 '특정 x에서' 성립.

정수 x = −3 … 3 일곱 곳에서 두 값을 비교합니다. 이차식끼리는 서로 다른 3개(= 차수 + 1)에서 같으면 모든 x에서 같아요. 1~2개만 맞는 것은 그냥 교점입니다. (▶는 x² 계수 1, 상수항 2에서 시작합니다)

2. 자주 하는 오해 바로잡기

· "두세 개 맞으면 같은 식" → 차수 + 1개 이상이어야 해요.

3. 생활 속에서 · 이어지는 개념

  • n + 1개 점으로 n차 곡선이 유일하게 정해지는 것(보간법), 부분분수 분해의 계수 결정이 이 원리예요.
g 계수 조정 → 7개 x에서 f, g 값 비교 → 일치 개수와 항등식 판정

예제

ax² + bx + c = 2(x − 1)² + 3이 항등식일 때 a, b, c는?

전개 2x² − 4x + 5 → a = 2, b = −4, c = 5.

3개의 점 (0, 1), (1, 2), (2, 5)를 지나는 이차함수가 유일한 까닭은?

이차식은 3개의 x에서 값이 정해지면 유일(n + 1개 조건).
