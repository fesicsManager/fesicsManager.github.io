역함수 — 입력·출력을 바꾼 함수, 1/f가 아니다

f(x) = ax + b의 계수와 t를 바꾸며 f⁻¹(f(t)), f⁻¹(t), 1/f(t)를 계산하고 두 그래프의 y = x 대칭을 확인했습니다. f⁻¹(f(t))는 언제나 t로 돌아왔고 f⁻¹(t)와 1/f(t)는 달랐으며, 그래프는 y = x에 대칭이었습니다. 역함수의 뜻과 존재 조건을 정리합니다.

f(a) = b이면 f⁻¹(b) = a, 그래프는 (a, b) ↔ (b, a)로 y = x 대칭. 기호 f⁻¹의 −1은 지수가 아니라 ‘역’(sin⁻¹x = arcsin ≠ 1/sin x). f∘f⁻¹ = f⁻¹∘f = 항등함수이고 f × (1/f) = 1과 다른 개념. 역함수는 f가 일대일 대응일 때만 존재하며, f와 f⁻¹의 교점은 대개 y = x 위(감소함수는 예외 있음).

개념 정리

1. 역함수 f⁻¹는 입력·출력을 바꾼 함수, 1/f(x)와 전혀 달라요

f(a) = b이면 f⁻¹(b) = a예요. 그래프는 (a, b) ↔ (b, a)로 y = x에 대칭이에요. 기호 f⁻¹의 −1은 지수가 아니라 '역'을 뜻해요. f(x) = 2x + 1이면 f⁻¹(x) = (x − 1)/2인데 1/f(x) = 1/(2x + 1)로 완전히 다른 함수예요. 역함수는 f가 일대일 대응일 때만 존재해요.

왜 그럴까

  • x = 3: f(3) = 7, f⁻¹(3) = 1, 1/f(3) = 1/7.
  • f∘f⁻¹ = f⁻¹∘f = 항등함수(x). f × (1/f) = 1과 다른 개념.
  • f와 f⁻¹의 교점은 y = x 위에 있어요(감소함수는 예외 있음).

2. 자주 하는 오해 바로잡기

· "f⁻¹ = 1/f" → sin⁻¹x(arcsin)가 1/sin x가 아닌 것과 같아요.

3. 생활 속에서 · 이어지는 개념

  • 섭씨→화씨와 화씨→섭씨, 암호화와 복호화, 환율 변환의 역방향이 역함수예요.
f와 f⁻¹ 그래프 함께 → y = x 대칭 확인, 같은 x에서 f⁻¹(x)와 1/f(x) 비교
📋 데이터 확인 탭의 결론

“모든 기록에서 f⁻¹(f(t)) = t. 역함수는 f가 보낸 값을”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = 3x − 6의 역함수와 f⁻¹(9), 1/f(9)는?

f⁻¹(x) = (x + 6)/3; f⁻¹(9) = 5; 1/f(9) = 1/21.

f(x) = x²(x ≥ 0)의 역함수는?

f⁻¹(x) = √x (x ≥ 0) — 정의역 제한으로 일대일.
