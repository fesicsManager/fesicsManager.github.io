수학적 귀납법 — 두 조건 중 하나만 빠져도 무너진다

① n = 1 성립(첫 도미노)과 ② k → k + 1 전이(연쇄) 두 조건을 켜고 끄며 몇 번째 도미노까지 넘어가는지 기록했습니다. 둘 다 성립하면 모든 도미노가 넘어졌지만 ①만 있으면 첫 개만, ②만 있으면 하나도 넘어지지 않았고, ②가 k = 5부터 끊기면 5개까지만 넘어졌습니다. 귀납법의 두 조건을 정리합니다.

①은 첫 도미노 넘어뜨리기, ②는 앞 것이 넘어지면 다음 것도 넘어지기. ②에서 k에서의 성립을 가정하는 것은 순환논법이 아니라 다음 단계로 넘어가는 규칙을 증명하는 것. ②가 k ≥ 5부터만 성립하면 ①을 n = 5로 잡습니다(2ⁿ > n² 등). 재귀 함수(기저 조건 + 재귀 단계)가 같은 구조.

개념 정리

1. 귀납법 = 첫 도미노 넘어뜨리기 + 앞 것이 넘어지면 다음 것도 넘어지기

모든 자연수 n에서 명제가 성립함을 보이려면 ① n = 1에서 성립(첫 도미노), ② n = k에서 성립하면 n = k + 1에서도 성립(연쇄) 두 가지가 모두 필요해요. ①만 있으면 첫 개만 넘어지고, ②만 있으면 시작이 없어 하나도 안 넘어져요. ②를 확인할 때 k에서의 성립을 가정하는 것이 핵심이에요.

왜 그럴까

  • 1 + 2 + … + n = n(n + 1)/2: n = 1 ✓; k에서 성립 가정 → k + 1 더하면 (k + 1)(k + 2)/2 ✓.
  • ②가 k ≥ 5부터만 성립하면 ①을 n = 5로 잡아요(2ⁿ > n² 같은 경우).
  • ①이 틀리면 n = 1에서 거짓인 명제라 아무리 ②가 성립해도 의미 없어요.

2. 자주 하는 오해 바로잡기

· "k에서 성립한다고 가정하는 건 순환논법" → 가정에서 다음 단계로 넘어가는 규칙을 증명하는 거예요.

예제

1 + 2 + … + n = n(n + 1)/2를 귀납법으로 증명하시오.

① n = 1: 1 = 1 ✓. ② k에서 성립 가정 → 양변에 k + 1 더하면 k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2 ✓. 따라서 모든 n.

2ⁿ > n²이 n ≥ 5에서 성립함을 보일 때 ①은?

n = 5: 32 > 25 ✓ (n = 2, 3, 4에서는 거짓이므로 시작점을 5로).
