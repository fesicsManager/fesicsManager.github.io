고등학교 대수 · 실험 「1 + 2 + … + n」

1 + 2 + … + n — 계단 두 개로 직사각형

n을 바꾸며 1부터 n까지 직접 더한 합과 n(n + 1)/2, 계단 블록 두 개를 붙인 직사각형 칸 수, n²/2를 비교했습니다. 직접 더한 합은 언제나 n(n + 1)/2 = 직사각형 칸 수의 절반이었고 n²/2와는 n/2만큼 차이가 났습니다. 가우스의 아이디어를 정리합니다.

S + S(거꾸로) = (n + 1) × n → S = n(n + 1)/2. 가우스가 1 + 100 = 101이 50쌍으로 5050을 구한 것과 같은 아이디어이며 등차수열 합 n(a₁ + aₙ)/2의 특별한 경우. n²/2는 대각선 절반만큼(n/2) 모자랍니다.

개념 정리

1. 1 + 2 + … + n = n(n + 1)/2: 계단 두 개를 붙이면 직사각형

높이 1, 2, …, n인 계단 블록을 하나 더 뒤집어 붙이면 n × (n + 1) 직사각형이 돼요. 그 넓이의 절반이 합이에요. 가우스가 1~100을 첫 항과 끝 항끼리 짝지어(1 + 100 = 101이 50쌍) 5050을 구한 것과 같은 아이디어예요.

왜 그럴까

  • n = 4: 1 + 2 + 3 + 4 = 10 = 4 × 5/2.
  • S + S(거꾸로) = (n + 1) × n → S = n(n + 1)/2.
  • 등차수열 합 공식 n(a₁ + aₙ)/2의 특별한 경우.

2. 자주 하는 오해 바로잡기

· "n²/2" → n(n + 1)/2. n/2만큼 차이가 나요(대각선 절반).

3. 생활 속에서 · 이어지는 개념

  • n명이 서로 악수하는 횟수 n(n − 1)/2, 볼링 핀 배열(삼각수)이 이 합이에요.

예제

1 + 2 + … + 50과 51 + 52 + … + 100은?

50 × 51/2 = 1275; 5050 − 1275 = 3775.

n명이 서로 한 번씩 악수하는 횟수는?

1 + 2 + … + (n − 1) = n(n − 1)/2.
