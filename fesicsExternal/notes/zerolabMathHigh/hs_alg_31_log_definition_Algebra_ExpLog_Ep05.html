로그 — a를 몇 제곱해야 x가 되는가

밑 a와 진수 x를 바꾸며 log_a x를 구하고 a^(log_a x)가 x로 되돌아오는지 확인했습니다. 모든 기록에서 되돌아왔고, 진수 1이면 밑과 상관없이 로그값 0, 진수가 1보다 작거나 밑이 1보다 작으면 로그값이 음수였습니다. 로그의 정의와 조건을 정리합니다.

실험 데이터 되짚기

실험 안내: 밑 a(a > 0, a ≠ 1)와 진수 x > 0를 바꾸며 y = aˣ 그래프에서 높이 x가 되는 지점의 x좌표를 읽습니다.

log_a N = x ⟺ aˣ = N. y = aˣ 그래프에서 높이 N이 되는 지점의 x가 log_a N. 밑 a > 0, a ≠ 1, 진수 N > 0이어야 하며(aˣ는 항상 양수라 음수의 로그는 없음), a^(log_a N) = N으로 되돌아옵니다. log 8 ÷ log 2 = log 4가 아니라 log₂ 8 = log 8/log 2 = 3(밑 변환).

개념 정리

1. log_a N = x ⟺ aˣ = N: "a를 몇 제곱해야 N이 되나"

로그는 지수를 거꾸로 묻는 방법이에요. 2ˣ = 8에서 x = 3이므로 log₂ 8 = 3. y = aˣ 그래프에서 높이가 N이 되는 지점의 x가 log_a N이에요. 밑 a > 0, a ≠ 1, 진수 N > 0이어야 해요(aˣ는 항상 양수라 음수의 로그는 없음).

왜 그럴까

  • log₂ 1 = 0(2⁰ = 1), log₂ 2 = 1, log₂ ½ = −1, log₂ √2 = ½.
  • log₁₀ 1000 = 3, log₁₀ 0.01 = −2.
  • a^(log_a N) = N — 로그를 지수에 넣으면 되돌아와요.

2. 자주 하는 오해 바로잡기

· "log 8 ÷ log 2 = log 4" → 로그의 나눗셈은 그런 규칙이 없어요. log₂ 8 = log 8/log 2 = 3(밑 변환).

3. 생활 속에서 · 이어지는 개념

  • pH(−log[H⁺]), 지진 규모, 데시벨, 별의 등급이 모두 로그 눈금이에요.
aˣ 그래프에서 y = N인 x 탐색 → 로그값과 일치 확인
📋 데이터 확인 탭의 결론

“모든 기록에서 a^(log_a x) = x. log_a x 는 “a를 몇 제곱해야 x가 되는가”에 대한 답이므로, 그 답을 다시 지수에 넣으면 x로 돌아옵니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

log₃ 81, log₅ (1/25), log₇ 1의 값은?

4, −2, 0.

log_x 16 = 4인 x는?

x⁴ = 16, x > 0 → x = 2.
