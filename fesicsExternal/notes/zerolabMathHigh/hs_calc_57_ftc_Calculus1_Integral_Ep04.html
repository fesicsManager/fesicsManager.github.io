정적분의 기본정리 — F(b) − F(a)

아래끝 a, 위끝 b, 적분상수 C를 바꾸며 잘게 쪼개 더한 넓이와 F(b) − F(a)를 비교했습니다. 두 값은 항상 같았고 C를 바꿔도 결과가 변하지 않았으며, ∫ₐᵃ = 0, ∫ₐᵇ = −∫ᵦᵃ도 확인되었습니다. 미적분의 기본정리를 정리합니다.

넓이 함수 S(x) = ∫ₐˣ f(t)dt를 미분하면 f(x)(폭 dx인 띠의 넓이 f(x)dx) → S는 f의 부정적분 F와 상수 차이뿐이라 S(b) = F(b) − F(a). 잘게 쪼개 더하는 대신 역미분 한 번. 적분상수 C는 빼기에서 사라지며 정적분은 수라 + C가 붙지 않습니다.

개념 정리

1. ∫ₐᵇ f(x)dx = F(b) − F(a): 넓이는 부정적분의 차

미적분의 기본정리: 넓이 함수 S(x) = ∫ₐˣ f(t)dt를 미분하면 f(x)예요(폭 dx인 띠의 넓이 f(x)dx). 그래서 S는 f의 부정적분 F와 상수 차이뿐이고 S(b) = F(b) − F(a). 잘게 쪼개 더하는 대신 역미분 한 번으로 넓이를 구해요. 적분상수 C는 빼기에서 사라지므로 어떤 C를 써도 결과가 같아요.

왜 그럴까

  • ∫₀¹ x²dx = [x³/3]₀¹ = 1/3 — 구분구적법 극한과 일치.
  • F = x³/3 + 7을 써도 (1/3 + 7) − (0 + 7) = 1/3.
  • ∫ₐᵃ = 0, ∫ₐᵇ = −∫ᵦᵃ.

2. 자주 하는 오해 바로잡기

· "정적분에도 + C가 붙는다" → 정적분은 수예요. C는 부정적분에만.

F = x³ − x² → (27 − 9) − (1 − 1) = 18.

속도 v(t) = 6t − t²(0 ≤ t ≤ 6)로 움직인 총 거리는?

∫₀⁶ (6t − t²)dt = [3t² − t³/3]₀⁶ = 108 − 72 = 36.
