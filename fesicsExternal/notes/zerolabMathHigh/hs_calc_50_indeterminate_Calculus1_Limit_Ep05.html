0/0 꼴 — 값이 없는 게 아니라 이대로는 알 수 없다

분모·분자가 함께 0이 되는 식에서 x = a ± h로 다가가며 값을 기록하고 약분한 식에 대입한 값과 비교했습니다. (x² − 4)/(x − 2)는 x → 2에서 4로 다가갔고 약분 후 대입값과 일치했으며, 같은 0/0 꼴이라도 식마다 값이 달랐습니다. 부정형의 처리법을 정리합니다.

극한은 그 점 주변을 보는 것이므로 인수분해·유리화로 공통 인수를 약분한 뒤 대입. 0/0 꼴은 식마다 값이 달라(0, 1, ∞ 모두 가능) ‘부정형’이며 ∞/∞, ∞ − ∞, 0·∞도 부정형. 순간 속도(Δs/Δt, Δt → 0)가 바로 0/0 꼴의 극한 — 미분의 출발점.

개념 정리

1. 0/0은 "값이 없다"가 아니라 "이대로는 알 수 없다"

분모·분자가 함께 0이 되면 대입이 막히지만, 극한은 그 점 주변을 보는 것이므로 인수분해·유리화로 공통 인수를 약분한 뒤 대입하면 값이 나와요. (x² − 4)/(x − 2)는 x → 2에서 (x + 2) → 4. 0/0 꼴은 식마다 값이 달라서(0, 1, ∞ 모두 가능) '부정형'이라 불러요.

왜 그럴까

  • (√(x + 1) − 1)/x, x → 0: 유리화 → 1/(√(x + 1) + 1) → ½.
  • sin x / x → 1, (1 − cos x)/x → 0, x/x² → ∞: 모두 0/0 꼴이지만 답이 달라요.
  • ∞/∞, ∞ − ∞, 0·∞도 부정형.

2. 자주 하는 오해 바로잡기

· "0/0 = 1" 또는 "= 0" → 정해진 값이 없어요. 반드시 식을 변형해요.

3. 생활 속에서 · 이어지는 개념

  • 순간 속도(Δs/Δt에서 Δt → 0)가 바로 0/0 꼴의 극한 — 미분의 출발점이에요.

📋 데이터 확인 탭의 결론

“h가 작아질수록 양쪽 값이 한 수로 모입니다. 그 수가 극한값이고, 약분해서 얻은 식에 대입한 값과 같습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

lim_{x→3} (x² − 9)/(x − 3)은?

(x + 3) → 6.

lim_{x→0} (√(x + 4) − 2)/x는?

유리화: x/[x(√(x+4) + 2)] = 1/(√(x+4) + 2) → 1/4.
