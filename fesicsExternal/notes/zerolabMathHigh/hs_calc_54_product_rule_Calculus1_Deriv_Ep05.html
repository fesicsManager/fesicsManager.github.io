고등학교 미적분Ⅰ · 실험 「곱의 미분」

곱의 미분 — f′g + fg′, 모퉁이 조각은 사라진다

f(x) = x² + a, g(x) = x + b의 a, b와 확인할 x를 바꾸며 fg를 전개해 미분한 실측값을 f′g + fg′, f′g′과 비교했습니다. f′g + fg′은 항상 맞았고 f′g′은 맞지 않았으며, 직사각형 넓이 모델에서 f′g′은 극한에서 사라지는 모퉁이 조각이었습니다. 곱의 미분법을 정리합니다.

실험 안내: fg를 전개해 미분한 값과 f′g + fg′, f′g′을 각각 비교합니다.

표 1. 곱의 도함수 비교 (실험 예시)
fgx(fg)′ 실측f′g + fg′f′g′어느 쪽이 맞나
x² + 1x + 212·3 + 2·1 = 82x(x + 2) + (x² + 1) = 82x = 2f′g + fg′
x² + 1x + 224·4 + 5 = 21214f′g + fg′
x² − 3x − 100·(−1) + (−3)·1 = −3−30f′g + fg′

가로 f, 세로 g인 직사각형에서 f가 Δf, g가 Δg 늘면 넓이 증가는 Δf·g + f·Δg + Δf·Δg이고 마지막 항은 2차 소량이라 극한에서 사라짐. 몫의 법칙 (f/g)′ = (f′g − fg′)/g², 세 함수 (fgh)′ = f′gh + fg′h + fgh′. 미분은 합·상수배와만 순서를 바꿀 수 있습니다.

개념 정리

1. (fg)′ = f′g + fg′, f′g′이 아니에요

곱의 변화량은 f가 변한 몫 + g가 변한 몫이에요. 가로 f, 세로 g인 직사각형에서 f가 Δf, g가 Δg 늘면 넓이 증가는 Δf·g + f·Δg + Δf·Δg이고, 마지막 항은 2차 소량이라 극한에서 사라져요. 그래서 f′g + fg′. f′g′은 사라지는 그 모퉁이 조각에 해당해 답이 아니에요.

왜 그럴까

  • f = x², g = x³: (x⁵)′ = 5x⁴. f′g + fg′ = 2x·x³ + x²·3x² = 5x⁴ ✓. f′g′ = 6x³ ✗.
  • 몫의 법칙 (f/g)′ = (f′g − fg′)/g²도 같은 원리.
  • 세 함수: (fgh)′ = f′gh + fg′h + fgh′.

2. 자주 하는 오해 바로잡기

· "미분은 곱과 순서를 바꿔도 된다" → 합·상수배만 그래요.

3. 생활 속에서 · 이어지는 개념

  • 매출 = 가격 × 판매량의 변화율(가격 변화 효과 + 수량 변화 효과)이 곱의 미분이에요.
fg를 전개해 미분 → f′g + fg′, f′g′과 각각 비교
📋 데이터 확인 탭의 결론

“모든 기록에서 (fg)′ = f′g + fg′. 그래프에 그린 접선도 초록 직선과 겹칩니다. 반면 f′g′ 는 대부분 엉뚱한 방향입니다”

예제

y = (x² + 1)(x³ − x)의 도함수는?

2x(x³ − x) + (x² + 1)(3x² − 1) = 5x⁴ − 1.

매출 = 가격 × 판매량에서 가격이 오르고 판매량이 줄 때 매출 변화율은?

(가격 변화율 × 판매량) + (가격 × 판매량 변화율) — 두 효과의 합(곱이 아님).
