(A + B)² — 2AB로 합칠 수 없다

A의 성분을 바꾸며 (A + B)²을 직접 계산해 A² + 2AB + B²과 A² + AB + BA + B²에 각각 비교했습니다. A² + AB + BA + B²은 항상 일치했지만 A² + 2AB + B²은 AB = BA일 때만 일치했습니다. 행렬에서 곱셈공식이 통하지 않는 까닭을 정리합니다.

(A + B)(A + B) = A·A + A·B + B·A + B·B. 수에서는 AB = BA라 2AB로 합치지만 행렬은 AB ≠ BA라서 합칠 수 없고, (A + B)(A − B) ≠ A² − B²도 마찬가지. (A + E)² = A² + 2A + E는 성립(E는 어떤 행렬과도 교환 가능). 곱셈공식은 교환법칙이 있을 때만.

개념 정리

1. (A + B)² = A² + AB + BA + B², 2AB로 합칠 수 없어요

(A + B)(A + B)를 분배법칙으로 전개하면 A·A + A·B + B·A + B·B예요. 수에서는 AB = BA라 2AB로 합치지만 행렬은 AB ≠ BA라서 합칠 수 없어요. A² + 2AB + B²이 되는 것은 AB = BA일 때뿐이에요. 마찬가지로 (A + B)(A − B) ≠ A² − B²예요.

왜 그럴까

  • A = [[1, 1], [0, 1]], B = [[1, 0], [1, 1]]: (A + B)² = [[5, 4], [4, 5]], A² + 2AB + B² = [[6, 4], [4, 4]].
  • A² + AB + BA + B²으로 계산하면 정확히 일치.
  • (A + E)² = A² + 2A + E는 성립(E는 어떤 행렬과도 교환 가능).
