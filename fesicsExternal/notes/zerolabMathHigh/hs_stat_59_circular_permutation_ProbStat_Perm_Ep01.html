원순열 — 회전해서 같은 n가지를 하나로

사람 수 n을 바꾸며 일렬 배열 n!을 모두 생성해 회전으로 겹치는 배열을 묶고 서로 다른 원형 배열의 수를 (n − 1)!, n!/n과 비교했습니다. 회전으로 겹치는 묶음의 크기는 n이었고 직접 센 원형 배열은 언제나 (n − 1)!이었습니다. 원순열의 원리와 변형을 정리합니다.

회전해서 겹치는 배열 n개가 같은 것이라 n!/n = (n − 1)! — 한 사람을 고정하고 나머지를 배열해도 같음. 목걸이처럼 뒤집어도 같으면 (n − 1)!/2(n ≥ 3, 서로 다른 구슬). 자리에 번호가 있으면 원순열이 아니라 n!. 정사각형 탁자 4명은 회전 대칭 4개라 3!, 직사각형(2 + 2)은 대칭 2개라 4!/2 = 12.

개념 정리

1. 원순열 = (n − 1)!: 회전해서 같은 n가지를 하나로 묶어요

n명을 일렬로 세우면 n!이지만, 원탁에서는 회전해서 겹치는 배열 n개가 같은 것이라 n!/n = (n − 1)!이에요. 한 사람을 고정하고 나머지를 배열한다고 생각해도 같아요. 서로 다른 구슬 n개(n ≥ 3)로 만든 목걸이처럼 뒤집어도 같은 것으로 보면 (n − 1)!/2. (같은 색 구슬이 있거나 다른 대칭이 더 있으면 단순히 2로 나눌 수 없어요.) 자리에 번호가 있으면 원순열이 아니라 그냥 n!이에요.

왜 그럴까

  • 4명: 24가지 배열 중 회전 4개씩 묶어 6가지.
  • ABCD, BCDA, CDAB, DABC는 같은 원순열.
  • 정사각형 탁자 4명은 회전 대칭이 4개라 역시 3! = 6, 직사각형(2 + 2)은 대칭 2개라 4!/2 = 12.

2. 자주 하는 오해 바로잡기

· "원탁도 n!" → 회전이 같은 배열이라 n으로 나눠요.

3. 생활 속에서 · 이어지는 개념

  • 원탁 회의 자리, 캠프파이어 둘러앉기, 구슬 팔찌 배열이 원순열이에요.
원탁 배열 모두 생성 → 회전 동치 묶기 → 남은 가짓수와 (n − 1)! 비교
📋 데이터 확인 탭의 결론

“모든 기록에서 직접 센 개수 = (n−1)!. 컴퓨터가 n!가지를 전부 만든 뒤 회전해서 같아지는 것끼리 묶어 센 결과입니다 — 공식을 믿고 쓴 값이 아닙니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

7명이 원탁에 앉는 방법의 수와, 특정 두 명이 이웃하는 방법의 수는?

6! = 720; 두 명을 묶어 6명 원순열 5! × 2 = 240.

서로 다른 구슬 5개로 만드는 목걸이의 수는?

(5 − 1)!/2 = 12.
