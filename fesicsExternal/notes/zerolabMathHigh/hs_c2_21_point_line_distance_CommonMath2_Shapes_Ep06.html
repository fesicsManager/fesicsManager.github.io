점과 직선 사이의 거리 — 수선의 발까지

직선 ax + by + c = 0과 점 P를 바꾸며 직선 위 점을 훑어 최단 거리를 찾고 공식 |ax₀ + by₀ + c|/√(a² + b²)과 비교했습니다. 훑어 찾은 최소는 언제나 공식값과 같았고 최소가 되는 지점은 수선의 발이었으며, 세로 차보다 항상 짧거나 같았습니다. 거리 공식의 뜻을 정리합니다.

공식은 법선벡터 (a, b) 방향으로 잰 길이라 √(a² + b²)로 나눠 정규화하고, 절댓값은 어느 쪽에 있든 양수로. y = mx + k 꼴이면 mx − y + k = 0으로 고쳐 씁니다. 세로 방향(y 차)은 거리가 아니며 수직 거리보다 항상 길거나 같습니다. 평행한 두 직선 사이 거리는 한쪽 위의 점에서 다른 직선까지.

개념 정리

1. 점과 직선 사이의 거리 = 수선의 발까지의 거리 = |ax₀ + by₀ + c|/√(a² + b²)

점에서 직선 위 여러 점까지의 거리 중 가장 짧은 것이 거리이고, 그것은 수선의 발까지의 길이예요. 공식은 법선벡터 (a, b) 방향으로 잰 길이라 √(a² + b²)로 나눠 정규화해요. 절댓값은 직선의 어느 쪽에 있든 양수로 만들기 위해서예요. 직선 위 점이면 0.

왜 그럴까

  • (1, 2)와 3x + 4y − 1 = 0: |3 + 8 − 1|/5 = 2.
  • y = mx + k 꼴이면 mx − y + k = 0으로 고쳐 써요.
  • 평행한 두 직선 사이 거리는 한쪽 위의 점에서 다른 직선까지.

2. 자주 하는 오해 바로잡기

· "세로 방향(y 차)이 거리" → 수직 방향이 거리이고, 세로 차보다 항상 짧거나 같아요.

3. 생활 속에서 · 이어지는 개념

  • 도로에서 집까지의 거리, 회귀직선의 오차, 로봇의 벽 감지가 점–직선 거리예요.

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

점 (1, −2)와 직선 4x − 3y + 5 = 0 사이의 거리는?

|4 + 6 + 5|/5 = 3.

평행한 두 직선 2x − y + 1 = 0과 2x − y − 4 = 0 사이의 거리는?

(0, 1)에서 둘째 직선까지: |0 − 1 − 4|/√5 = √5.
