등차중항과 등비중항 — 가운데를 정하는 두 방법

두 수 a, c를 바꾸며 등차중항 (a + c)/2와 등비중항 √(ac)를 구해 차와 비를 확인하고 두 값의 차이를 기록했습니다. 등차중항은 m − a = c − m, 등비중항은 g/a = c/g를 만족했고, 양수에서 등차중항 ≥ 등비중항이며 a = c일 때만 같았습니다. 두 중항과 산술–기하 평균 부등식을 정리합니다.

차가 같게 하면 b = (a + c)/2(산술평균), 비가 같게 하면 b² = ac → b = ±√(ac)(기하평균, a·c가 같은 부호일 때 실수). (a + c)/2 − √(ac) = (√a − √c)²/2 ≥ 0으로 등차중항 ≥ 등비중항. 평균 성장률은 기하평균(10 %, 40 %의 평균 ≈ 24.1 %, 25 % 아님).

개념 정리

1. 등차중항 (a + c)/2, 등비중항 ±√(ac)

a와 c 사이에 수 b를 넣을 때 차가 같게 하면 b − a = c − b → b = (a + c)/2(산술평균), 비가 같게 하면 b/a = c/b → b² = ac → b = ±√(ac)(기하평균). 양수 a, c에서 등차중항 ≥ 등비중항이고 a = c일 때만 같아요(산술–기하 평균 부등식).

왜 그럴까

  • 2와 8: 등차중항 5, 등비중항 4(2, 4, 8).
  • (a + c)/2 − √(ac) = (√a − √c)²/2 ≥ 0.
  • 등비중항은 a, c가 같은 부호일 때만 실수예요.

예제

2와 32 사이에 등차중항과 등비중항을 각각 넣으면?

등차 17 (2, 17, 32); 등비 ±8 (2, 8, 32 또는 2, −8, 32).

x, 6, y가 등차수열이고 6, y, 24가 등비수열일 때 (x, y)는?

x + y = 12, y² = 144 → y = 12일 때 (0, 12), y = −12일 때 (24, −12).
