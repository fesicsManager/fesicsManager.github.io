코사인법칙 — 피타고라스는 A = 90°인 특별한 경우

두 변 b, c와 끼인각 A를 바꾸며 나머지 변 a를 재고 a² − (b² + c²)와 −2bc cos A를 비교했습니다. 두 값은 항상 같았고, A = 90°에서 보정항이 0이 되어 피타고라스 정리가 되었으며, 예각이면 a² < b² + c², 둔각이면 a² > b² + c²이었습니다. 코사인법칙을 정리합니다.

a² = b² + c² − 2bc cos A. 좌표로 증명: B(c, 0), C(b cos A, b sin A) 사이 거리 제곱. 거꾸로 cos A = (b² + c² − a²)/2bc로 세 변에서 각을 구하며(3, 5, 7 → cos = −½ → 120°), 모든 삼각형에서 a² = b² + c²이 아니라 보정항이 필요합니다.

개념 정리

1. a² = b² + c² − 2bc cos A: 피타고라스는 A = 90°인 특별한 경우

두 변 b, c와 끼인각 A로 나머지 변 a를 구하는 식이에요. A = 90°면 cos A = 0이라 a² = b² + c²(피타고라스). A가 예각이면 −2bc cos A < 0이라 a² < b² + c², 둔각이면 a² > b² + c²예요. 거꾸로 세 변으로 각을 구할 수도 있어요: cos A = (b² + c² − a²)/2bc.

왜 그럴까

  • b = c = 1, A = 60° → a² = 2 − 1 = 1(정삼각형). A = 120° → a² = 3.
  • 좌표로 증명: B(c, 0), C(b cos A, b sin A) 사이 거리 제곱.
  • 세 변이 3, 5, 7이면 cos = (9 + 25 − 49)/30 = −½ → 120°.

2. 자주 하는 오해 바로잡기

· "모든 삼각형에서 a² = b² + c²" → 보정항 −2bc cos A가 필요해요.

예제

b = c = 1, A = 120°인 삼각형의 a는?

a² = 1 + 1 − 2 cos 120° = 2 + 1 = 3 → a = √3.

두 배가 항구에서 60°로 갈라져 각각 30 km, 40 km 갔을 때 두 배 사이 거리는?

√(900 + 1600 − 2400 × 0.5) = √1300 ≈ 36 km.
