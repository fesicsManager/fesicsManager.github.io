정적분과 넓이 — 축 아래는 빼진다

구간 [p, q]를 바꾸며 x축 아래를 지나는 구간에서 정적분값과 위쪽 넓이·아래쪽 넓이·실제 넓이 합을 각각 계산해 비교했습니다. 정적분은 아래쪽을 음수로 더해 넓이보다 작았고, 넓이는 x축 교점에서 나눠 절댓값을 더해야 했으며 차이는 아래쪽 넓이의 2배였습니다. 부호 있는 넓이를 정리합니다.

f < 0인 구간은 f(x)dx가 음수라 빼짐(sin x를 0~2π 적분하면 0, 넓이는 4). 넓이는 x축과 만나는 점에서 구간을 나눠 ∫|f(x)|dx. 두 곡선 사이 넓이는 ∫(위 − 아래)dx로 부호 걱정 없이. 속도가 음수인 구간: 정적분은 변위, 절댓값 적분은 총 이동 거리.

개념 정리

1. 정적분은 부호 있는 넓이: x축 아래는 음수로 더해져요

∫ₐᵇ f(x)dx에서 f < 0인 구간은 f(x)dx가 음수라 빼져요. 그래서 sin x를 0에서 2π까지 적분하면 0이지만 실제 넓이는 4예요. 넓이를 구하려면 그래프가 x축과 만나는 점에서 구간을 나눠 각각 절댓값을 취해 더해요: ∫|f(x)|dx.

왜 그럴까

  • ∫₋₁¹ x dx = 0 (왼쪽 −½, 오른쪽 +½). 넓이는 1.
  • ∫₀² (x² − 1)dx = 2/3 (0~1은 −2/3, 1~2는 +4/3). 넓이 = 2/3 + 4/3 = 2.
  • 두 곡선 사이 넓이는 ∫(위 − 아래)dx로 부호 걱정 없이.

예제

∫₀² (x² − 1)dx와 y = x² − 1, x축, x = 0, x = 2로 둘러싸인 넓이는?

정적분 2/3; 넓이 2/3 + 4/3 = 2.

y = x와 y = x² 사이의 넓이(0 ≤ x ≤ 1)는?

∫₀¹ (x − x²)dx = 1/2 − 1/3 = 1/6.
