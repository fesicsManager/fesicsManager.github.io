등차수열 — d를 n − 1번 더한다

첫째항 a, 공차 d, n을 바꾸며 첫째항부터 하나씩 세어 n번째 항을 확인하고 a + (n − 1)d, a + nd 중 어느 쪽과 일치하는지 기록했습니다. 더한 횟수는 언제나 n − 1이었고 a + (n − 1)d가 맞았으며, a + nd는 (n + 1)번째 항이었습니다. 일반항의 까닭을 정리합니다.

둘째 항까지 한 번, 셋째 항까지 두 번 … n번째 항까지는 n − 1번 — 울타리 기둥 n개 사이의 간격이 n − 1개인 것과 같습니다. 첫째항은 이미 있으니 n − 1번. 합은 Sₙ = n(a + aₙ)/2 = n(2a + (n − 1)d)/2, aₙ은 n의 일차식이라 점들이 일직선.

개념 정리

1. aₙ = a + (n − 1)d: 첫째항에서 n번째까지 d를 n − 1번 더해요

첫째항 a에서 둘째 항까지 한 번, 셋째 항까지 두 번 … n번째 항까지는 n − 1번 공차를 더해요. 그래서 a + nd가 아니라 a + (n − 1)d예요. 울타리 기둥 n개 사이의 간격이 n − 1개인 것과 같아요. 합은 Sₙ = n(a + aₙ)/2 = n(2a + (n − 1)d)/2.

왜 그럴까

  • a = 3, d = 4: 3, 7, 11, 15 → a₄ = 3 + 3 × 4 = 15 (3 + 4 × 4 = 19는 a₅).
  • aₙ은 n의 일차식 → 그래프가 점들이 일직선.
  • a₀ = a − d로 놓으면 aₙ = a₀ + nd로 쓸 수도 있어요.

2. 자주 하는 오해 바로잡기

· "n번째니까 d를 n번" → 첫째항은 이미 있으니 n − 1번.

3. 생활 속에서 · 이어지는 개념

예제

등차수열 7, 11, 15, …의 제15항과 첫 15항의 합은?

a₁₅ = 7 + 14 × 4 = 63; S₁₅ = 15 × (7 + 63)/2 = 525.

a₅ = 12, a₁₀ = 27인 등차수열의 첫째항과 공차는?

5d = 15 → d = 3; a = 12 − 4 × 3 = 0.
