등비수열 — r을 n − 1번 곱한다

첫째항 a, 공비 r, n을 바꾸며 공비를 하나씩 곱해 n번째 항을 확인하고 a·rⁿ⁻¹, a·rⁿ 중 어느 쪽과 일치하는지 기록했습니다. 곱한 횟수는 언제나 n − 1이었고 a·rⁿ⁻¹이 맞았으며 a·rⁿ은 (n + 1)번째 항이었습니다. 등비수열의 일반항과 성질을 정리합니다.

등차수열이 d를 n − 1번 더하듯 등비수열은 r을 n − 1번 곱합니다. a·rⁿ이라 쓰면 첫째항이 a·r이 되어 버립니다. |r| > 1이면 급격히 커지고 |r| < 1이면 0으로, r < 0이면 부호가 번갈며, 등비중항 b² = ac, aₙ은 n의 지수함수.

개념 정리

1. aₙ = a·rⁿ⁻¹: 공비를 n − 1번 곱해요

등차수열이 d를 n − 1번 더하듯, 등비수열은 첫째항 a에 공비 r을 n − 1번 곱해요. a·rⁿ은 (n + 1)번째 항이에요. 곱한 횟수를 세면 지수가 보여요. |r| > 1이면 급격히 커지고, |r| < 1이면 0으로 가요.

왜 그럴까

  • a = 2, r = 3: 2, 6, 18, 54 → a₄ = 2·3³ = 54 (2·3⁴ = 162는 a₅).
  • r < 0이면 부호가 번갈아요.
  • 등비중항: b² = ac. aₙ은 n의 지수함수.

2. 자주 하는 오해 바로잡기

· "aₙ = a·rⁿ" → 첫째항이 a·r이 되어 버려요.

3. 생활 속에서 · 이어지는 개념

  • 복리 원리합계(a(1 + i)ⁿ⁻¹), 세균 분열, 종이 접기 두께가 등비수열이에요.
공비를 하나씩 곱하며 n번째 항 확인 → a·rⁿ⁻¹, a·rⁿ 중 일치하는 쪽 기록
📋 데이터 확인 탭의 결론

“모든 기록에서 aₙ = a·rⁿ⁻¹. 첫째항은 아직 한 번도 곱하지 않았으니 r⁰ = 1, n번째 항까지는 n − 1번 곱합니다. 등차수열의 (n − 1)d 와”
