이항분포와 정규분포 — 68 · 95 · 99.7

시행 횟수 n과 성공 확률 p를 바꾸며 이항분포의 평균 np, 표준편차 √(np(1−p))를 구하고 ±1σ, ±2σ, ±3σ 안의 확률을 실제로 더해 68·95·99.7 %와 비교했습니다. n이 클수록, p가 0.5에 가까울수록 정규분포 값에 가까워졌고 작은 n이나 치우친 p에서는 근사가 나빴습니다. 이항분포의 정규근사를 정리합니다.

이항분포 = 베르누이 n개의 합 → 중심극한정리로 N(np, np(1−p)) 근사(대략 np ≥ 5, n(1−p) ≥ 5). 정규분포는 ±1σ 68.3 %, ±2σ 95.4 %, ±3σ 99.7 %. 이산을 연속으로 근사할 때 경계를 a − 0.5, b + 0.5로 넓히는 연속성 수정을 쓰면 더 잘 맞습니다. n = 10이어도 정규분포는 아닙니다.

개념 정리

1. B(n, p)는 평균 np, 표준편차 √(np(1−p)); n이 크면 정규분포로 근사

이항분포를 그리면 n이 커질수록 종 모양이 되어 N(np, np(1−p))로 근사할 수 있어요. 정규분포에서는 μ ± 1σ에 68.3 %, ± 2σ에 95.4 %, ± 3σ에 99.7 %가 들어가요. 이항분포에서 ±1σ, ±2σ 안의 확률을 실제로 더해 보면 이 값에 가까워요(n이 클수록, p가 0.5에 가까울수록 더).

왜 그럴까

  • n = 100, p = 0.5: 평균 50, σ = 5. 45~55 사이 확률 ≈ 0.73(이산이라 68 %보다 약간 큼), 40~60 ≈ 0.96.
  • 근사 조건 대략 np ≥ 5, n(1−p) ≥ 5.
  • 이산인 이항확률 P(a ≤ X ≤ b)를 연속인 정규분포로 근사할 때는 경계를 a − 0.5, b + 0.5로 넓히는 연속성 수정을 쓰면 수치가 더 잘 맞아요.
  • 이항분포 = 베르누이 n개의 합 → 중심극한정리로 정규분포.

2. 자주 하는 오해 바로잡기

· "n = 10이어도 정규분포" → 작은 n이나 치우친 p에서는 근사가 나빠요.

3. 생활 속에서 · 이어지는 개념

  • 불량품 수 관리 한계(±3σ), 선거 출구조사 오차, 동전 100번 던지기 결과 범위 예측.
n, p로 이항분포 계산 → 평균·σ → ±1σ·±2σ 안 확률 합산, 68/95와 비교

예제

동전 100번 던져 앞면 수가 40~60일 확률은 대략?

μ = 50, σ = 5 → ±2σ → 약 95 %(연속성 수정 39.5~60.5로 ≈ 96 %).

불량률 2 %인 제품 1 000개 중 불량 수의 관리 한계(±3σ)는?

μ = 20, σ = √19.6 ≈ 4.43 → 약 7 ~ 33개.
