나머지정리 — 나머지는 f(a)

삼차식의 계수와 나누는 식 x − a의 a를 바꾸며 직접 나눈 나머지 R과 그래프에서 읽은 f(a)를 비교했습니다. R = f(a)는 언제나 성립했고, f(a) = 0이면 x − a가 인수였습니다. 나머지정리·인수정리를 정리합니다.

f(x) = (x − a)Q(x) + R에 x = a를 넣으면 (x − a)가 0이 되어 f(a) = R. 그래프에서는 x = a에서의 높이가 나머지. (2x − 1)로 나눈 나머지는 f(½), (x + a)로 나누면 f(−a). (x − a)(x − b)로 나눈 나머지(일차식)는 f(a), f(b) 두 조건으로 정하며, 호너 방법(조립제법)이 응용.

개념 정리

1. f(x)를 (x − a)로 나눈 나머지 = f(a)

f(x) = (x − a)Q(x) + R(R은 상수)에 x = a를 넣으면 (x − a)가 0이 되어 f(a) = R이에요. 실제로 나눠 보지 않아도 대입 한 번으로 나머지를 알 수 있어요. 그래프에서는 x = a에서의 높이가 나머지예요. f(a) = 0이면 (x − a)가 인수(인수정리).

왜 그럴까

  • f(x) = x³ − 2x + 1을 (x − 2)로: f(2) = 8 − 4 + 1 = 5 = 나머지.
  • (2x − 1)로 나눈 나머지는 f(½).
  • (x − a)(x − b)로 나눈 나머지(일차식)는 f(a), f(b) 두 조건으로 정해요.

2. 자주 하는 오해 바로잡기

· "(x + a)로 나누면 f(a)" → x + a = x − (−a)이므로 f(−a).

3. 생활 속에서 · 이어지는 개념

  • 다항식 값을 빠르게 계산하는 호너 방법(조립제법)이 나머지정리의 응용이에요.

예제

f(x) = x³ − 2x + 1을 x − 2로 나눈 나머지는?

f(2) = 8 − 4 + 1 = 5.

f(x)를 x − 1로 나눈 나머지 3, x − 2로 나눈 나머지 5일 때 (x − 1)(x − 2)로 나눈 나머지는?

R = ax + b: a + b = 3, 2a + b = 5 → a = 2, b = 1 → 2x + 1.
