f′의 부호와 극값 — f′ = 0만으로는 부족하다

f(x) = x³ + ax² + bx의 a, b를 바꾸며 f′ = 0인 x와 그 앞뒤의 부호 변화, 극댓값·극솟값을 기록했습니다. 극값은 f′의 부호가 바뀌는 곳이었고, x³처럼 f′(0) = 0인데 부호가 안 바뀌면 극값이 아니었으며, 판별식이 음수면 f′ = 0인 점이 없어 극값이 없었습니다. 극값의 판정 기준을 정리합니다.

f′ > 0 증가, f′ < 0 감소. 극댓값은 + → −, 극솟값은 − → +로 바뀌는 지점. f′(a) = 0이어도 부호가 안 바뀌면(x³의 0) 극값이 아니고, f″로도 판정(f′(a) = 0, f″(a) < 0이면 극대). 미분가능한 내부점에서 극값이면 f′ = 0(페르마)이지만 역은 불성립이며, |x|의 0처럼 미분 불가능한 점에서도 극값일 수 있습니다.

개념 정리

1. 극값은 f′의 부호가 바뀌는 곳, f′ = 0만으로는 부족해요

f′ > 0이면 증가, f′ < 0이면 감소예요. 극댓값은 증가 → 감소(f′가 + → −), 극솟값은 감소 → 증가로 바뀌는 지점이에요. f′(a) = 0이어도 부호가 안 바뀌면(x³의 x = 0) 극값이 아니에요. 반대로 f′가 없는 뾰족점(|x|의 0)에서도 극값일 수 있어요.

왜 그럴까

  • f = x³ − 3x: f′ = 3(x − 1)(x + 1). x = −1에서 + → −: 극대 2. x = 1에서 − → +: 극소 −2.
  • f = x³: f′ = 3x² ≥ 0, x = 0에서 부호 유지 → 극값 아님(변곡점).
  • f″로도 판정: f′(a) = 0, f″(a) < 0이면 극대.

2. 자주 하는 오해 바로잡기

· "f′ = 0이면 극값" → 아니에요. 함수가 a에서 미분 가능하고 a가 정의역의 내부점이면 극값일 때 f′(a) = 0이지만(페르마 정리), 그 역은 성립하지 않아요. 또한 |x|의 x = 0처럼 미분 불가능한 점에서는 f′(a) = 0이 아니어도 극값일 수 있으므로, 조건 없이 "f′ = 0은 극값의 필요조건"이라고 말할 수는 없어요.

3. 생활 속에서 · 이어지는 개념

  • 이익이 최대가 되는 생산량, 약물 농도가 최고인 시각은 변화율이 +에서 −로 바뀌는 순간이에요.

예제

f(x) = x³ − 6x² + 9x + 1의 극값은?

f′ = 3(x − 1)(x − 3). x = 1: + → − 극대 5; x = 3: − → + 극소 1.

f(x) = x³ + kx가 극값을 갖지 않을 k의 범위는?

f′ = 3x² + k ≥ 0 항상 → k ≥ 0.
