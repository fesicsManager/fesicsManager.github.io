연속의 세 조건 — 함숫값·극한·일치

x < 1에서 x + 1, x ≥ 1에서 ax + b인 함수의 a, b를 바꾸며 경계에서 좌극한·우극한·함숫값을 비교해 이어지는지 판정했습니다. 좌극한 2 = 우극한 = f(1) = a + b일 때만 연속이었고, 하나라도 빠지면 구멍·점프·튐이 생겼습니다. 연속의 세 조건을 정리합니다.

x = a에서 연속 ⟺ ① f(a) 존재 ② lim f(x) 존재 ③ 둘이 같음. 하나라도 빠지면 구멍(②만), 점프(좌우 다름), 튐(①②는 되지만 ③ 불일치). 계수를 조절해 이어지는 조건을 찾으면 미지수 방정식. 연속함수의 합·차·곱·합성은 연속, 극한이 있어도 함숫값과 같아야 연속.

개념 정리

1. x = a에서 연속 ⟺ ① f(a) 존재 ② lim f(x) 존재 ③ 둘이 같음

구간별로 정의된 함수가 이어지려면 경계에서 좌극한 = 우극한 = 함숫값이어야 해요. 하나라도 빠지면 그래프에 구멍(②만 성립), 점프(좌우 다름), 튐(①②는 되지만 ③ 불일치)이 생겨요. 계수를 조절해 이어지는 조건을 찾으면 미지수 방정식이 나와요.

왜 그럴까

  • f(x) = x + 1 (x < 1), ax (x ≥ 1): 연속 조건 2 = a → a = 2.
  • 연속함수의 합·차·곱·합성은 연속. 나눗셈은 분모 0인 곳 제외.
  • 구간에서 연속이면 최대·최소 정리, 사잇값 정리를 쓸 수 있어요.

2. 자주 하는 오해 바로잡기

· "극한이 있으면 연속" → 함숫값과 같아야 해요.

3. 생활 속에서 · 이어지는 개념

  • 누진 요금제의 경계 설계, 애니메이션에서 장면 전환이 끊기지 않게 하는 조건이 연속이에요.

📋 데이터 확인 탭의 결론

“a + b = 2 일 때만 연속입니다”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = (x² − 1)/(x − 1) (x ≠ 1), f(1) = k가 연속이 되는 k는?

극한 2 → k = 2.

f(x) = x² (x < 2), ax − 1 (x ≥ 2)가 연속이 되는 a는?

4 = 2a − 1 → a = 5/2.
