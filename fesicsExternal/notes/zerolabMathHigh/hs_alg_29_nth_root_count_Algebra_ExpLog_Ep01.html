n제곱근 — 실수 범위에서는 0, 1, 2개뿐

거듭제곱 n과 높이 a를 바꾸며 y = xⁿ과 y = a의 교점을 세어 실수인 n제곱근의 개수를 기록했습니다. n이 홀수면 a가 무엇이든 1개, n이 짝수면 a > 0에서 2개, a = 0에서 1개, a < 0에서 0개였습니다. n의 홀짝과 a의 부호만으로 개수가 정해지는 까닭을 정리합니다.

n이 홀수면 xⁿ은 증가함수라 모든 높이를 정확히 한 번씩 지나고, 짝수면 xⁿ ≥ 0이고 좌우 대칭이라 a > 0인 높이는 두 곳, a < 0에는 닿지 못합니다. 기호 ⁿ√a는 n이 짝수일 때 양의 것 하나만 가리킵니다(16의 네제곱근은 ±2, ⁴√16은 2). 복소수까지 넓히면 항상 n개.

개념 정리

1. 실수인 n제곱근의 개수는 n의 홀짝과 a의 부호가 정해요

a의 n제곱근은 xⁿ = a의 해이고, 실수 범위에서는 y = xⁿ과 y = a의 교점 개수예요. n이 홀수면 xⁿ은 증가함수라 어떤 a에도 교점이 정확히 1개(ⁿ√a 하나). n이 짝수면 xⁿ ≥ 0이고 좌우 대칭이라 a > 0이면 ±ⁿ√a 2개, a = 0이면 1개, a < 0이면 0개예요. 복소수까지 넓히면 항상 n개예요.

왜 그럴까

  • x³ = −8 → x = −2 하나. x⁴ = 16 → x = ±2. x² = −4 → 실근 없음.
  • 기호 ⁿ√a는 n이 짝수일 때 양의 것 하나만 가리켜요. "16의 네제곱근"은 ±2, "⁴√16"은 2.
  • n 홀수: ⁿ√(−a) = −ⁿ√a.

2. 자주 하는 오해 바로잡기

· "n제곱근은 항상 n개" → 실수 범위에서는 0, 1, 2개뿐이에요.

3. 생활 속에서 · 이어지는 개념

  • 부피에서 한 변 길이(세제곱근)는 항상 하나, 넓이에서 변(제곱근)은 양수만 뜻이 있어요.
y = xⁿ과 y = a 교점 수 세기 → n 홀짝 × a 부호 표로 정리
📋 데이터 확인 탭의 결론

“n의 홀짝과 a의 부호만으로 개수가 정해집니다 — 짝수 n은 a > 0일 때 2개, a = 0일 때 1개, a < 0이면 없음. 홀수 n은 a가 무엇이든 언제나 1개.”

예제

−27의 세제곱근과 81의 네제곱근을 실수 범위에서 모두 구하시오.

x³ = −27 → −3 (1개); x⁴ = 81 → ±3 (2개).

⁶√64와 ‘64의 여섯제곱근’의 차이는?

⁶√64 = 2 (기호는 양수 하나); 64의 여섯제곱근은 ±2.
