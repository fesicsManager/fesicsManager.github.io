파스칼 삼각형 — 대칭과 윗줄 합으로 nCr 만들기

행 n과 칸 r을 바꾸며 nCr, 대칭 칸 nC(n−r), 윗줄 두 칸 (n−1)C(r−1)과 (n−1)Cr의 합을 비교했습니다. nCr = nC(n−r)과 nCr = 윗줄 두 칸의 합이 항상 성립해 계승 계산 없이 삼각형을 채워 nCr을 구할 수 있었습니다. 파스칼 삼각형의 두 성질을 정리합니다.

특정 원소 하나를 ‘뽑는 경우 (n−1)C(r−1) + 안 뽑는 경우 (n−1)Cr’로 나눈 것이 윗줄 합, r개 뽑기 = n − r개 남기기가 대칭. 줄 합 2ⁿ, (a + b)ⁿ의 계수, 대각선의 삼각수·피보나치, 하키스틱 규칙. 줄과 칸은 0부터 세야 nCr과 맞습니다.

개념 정리

1. nCr = nC(n−r) (대칭), nCr = (n−1)C(r−1) + (n−1)Cr (윗줄 합)

파스칼 삼각형에서 각 칸은 바로 위 두 칸의 합이고 좌우 대칭이에요. 특정 원소 하나를 "뽑는 경우 (n−1)C(r−1) + 안 뽑는 경우 (n−1)Cr"로 나눈 것이 윗줄 합이고, r개 뽑기 = n − r개 남기기가 대칭이에요. 계승 계산 없이 삼각형을 채워 nCr을 구할 수 있어요.

왜 그럴까

  • 5C2 = 4C1 + 4C2 = 4 + 6 = 10 = 5C3.
  • 줄 합 2ⁿ, (a + b)ⁿ의 계수, 대각선의 삼각수·피보나치.
  • 하키스틱 규칙: 대각선을 따라 더한 합이 그 아래 꺾인 칸.

2. 자주 하는 오해 바로잡기

· "줄과 칸을 1부터 셈" → 0부터 세야 nCr과 맞아요.
