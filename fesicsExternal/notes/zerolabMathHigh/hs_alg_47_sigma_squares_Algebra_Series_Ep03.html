고등학교 대수 · 실험 「Σk² 와 (Σk)²」

Σk²과 (Σk)² — 제곱을 먼저 하느냐 나중에 하느냐

n을 바꾸며 Σk, Σk², n(n+1)(2n+1)/6, (Σk)², Σk³을 나란히 기록했습니다. Σk²은 공식과 정확히 같았고 (Σk)²과는 전혀 달랐으며(n ≥ 2에서 항상 (Σk)²이 큼), Σk³ = (Σk)²은 성립했습니다. Σ와 제곱의 순서를 정리합니다.

111111예 (n = 1)

(Σk)² = Σk² + 2Σ(k < l인 kl)이라 항상 (Σk)²이 큽니다. Σk²은 n의 3차식, (Σk)²은 4차식. Σ는 선형 연산(덧셈·상수배)만 통과하며 Σ(aₖbₖ) ≠ ΣaₖΣbₖ. 분산 계산에서 (평균의 제곱)과 (제곱의 평균)을 구분하는 것이 같은 원리.

개념 정리

1. Σk² = n(n + 1)(2n + 1)/6 ≠ (Σk)²

제곱을 먼저 하고 더하는 Σk²과 더한 뒤 제곱하는 (Σk)² = [n(n + 1)/2]²은 전혀 달라요. n = 3: 1 + 4 + 9 = 14 vs (1 + 2 + 3)² = 36. (Σk)² = Σk² + 2Σ(k < l인 kl)이라 항상 (Σk)²이 커요(n ≥ 2). 참고로 Σk³ = (Σk)²은 성립하는 신기한 등식이에요.

왜 그럴까

  • n = 4: Σk² = 30 = 4·5·9/6, (Σk)² = 100, Σk³ = 100.
  • Σk²은 n의 3차식, (Σk)²은 4차식.
  • Σ(aₖ + bₖ) = Σaₖ + Σbₖ는 되지만 Σ(aₖbₖ) ≠ ΣaₖΣbₖ.
