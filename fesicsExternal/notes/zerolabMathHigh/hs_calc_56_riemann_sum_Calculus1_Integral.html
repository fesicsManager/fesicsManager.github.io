고등학교 미적분Ⅰ · 실험 「구분구적법」

구분구적법 — 직사각형을 무한히 잘게 하면 오차가 0

구간 [0, b]와 직사각형 개수 n을 바꾸며 왼쪽 끝 높이(하합)·오른쪽 끝 높이(상합)로 곡선 아래 넓이를 근사하고 참값과의 오차를 기록했습니다. n을 늘릴수록 오차가 대략 1/n에 비례해 줄었고 상합·하합이 참값을 사이에 끼고 좁혀졌습니다. 정적분의 정의를 정리합니다.

실험 안내: n을 늘리며 직사각형 합을 기록하고 참값과의 차이를 추적합니다.

1000오른쪽합0.33380.3330.0005

폭 Δx인 직사각형 n개의 합으로 근사하면 n을 늘릴수록 삐져나오거나 빠지는 부분이 줄어 수렴. Σ(k/n)²·(1/n) = (n + 1)(2n + 1)/6n² → 1/3. 이 극한이 정적분 ∫f(x)dx의 정의이며 극한은 근사값이 아니라 정확한 값. 속도 그래프 아래 넓이 = 이동 거리, 수치 적분이 같은 원리.

개념 정리

1. 직사각형을 무한히 잘게 하면 오차가 0으로: 구분구적법

곡선 아래 넓이를 폭 Δx인 직사각형 n개의 합으로 근사하면, n을 늘릴수록 삐져나오거나 빠지는 부분이 줄어 참값에 수렴해요. 왼쪽 끝 높이(하합)와 오른쪽 끝 높이(상합)가 참값을 사이에 끼고 함께 좁혀져요. 이 극한이 정적분 ∫f(x)dx의 정의예요.

왜 그럴까

  • y = x², [0, 1]: n = 4 오른쪽합 0.469, n = 100 0.338, 참값 1/3.
  • 오차는 대략 1/n에 비례해 줄어요.
  • Σ(k/n)²·(1/n) = (n + 1)(2n + 1)/6n² → 1/3.

2. 자주 하는 오해 바로잡기

· "근사값은 영원히 근사값" → 극한은 정확한 값이에요.

3. 생활 속에서 · 이어지는 개념

  • 속도 그래프 아래 넓이 = 이동 거리, 불규칙한 땅 넓이 측정, 컴퓨터의 수치 적분이 구분구적법이에요.
n 증가 → 직사각형 합 기록, 참값과의 차이 추적
📋 데이터 확인 탭의 결론

“직사각형이 많아질수록 오차가 줄어듭니다. 폭이 b/n 이라 n을 2배로 하면 계단의 삐져나온 부분이 절반이 됩니다. 이 극한값을 넓이로”

예제

y = x², [0, 1]을 n = 2로 나눈 오른쪽합과 왼쪽합은?

오른쪽 (0.25 + 1)/2 = 0.625; 왼쪽 (0 + 0.25)/2 = 0.125. 참값 1/3이 사이.

lim Σ_{k=1}^{n} (k/n)³ · (1/n)의 값은?

∫₀¹ x³ dx = 1/4.
