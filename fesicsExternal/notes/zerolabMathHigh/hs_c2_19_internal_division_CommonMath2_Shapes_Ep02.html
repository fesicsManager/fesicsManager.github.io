내분점 — 좌표가 엇갈려 곱해지는 까닭

A, B의 좌표와 비 m : n을 바꾸며 P = (nA + mB)/(m + n)을 계산하고 AP : PB를 실측해 m : n과 비교했습니다. 엇갈려 곱한 식은 언제나 비를 맞췄고 그대로 곱한 (mA + nB)/(m + n)은 비가 뒤집혔으며, m = n이면 중점이었습니다. 내분점 공식의 구조를 정리합니다.

실험 데이터 되짚기

실험 안내: P 좌표를 계산하고 AP, PB를 실측해 m : n과 비교합니다.

표 1. 내분점과 실측 비 (실험 예시)
ABm : nP (엇갈려 곱)AP : PB그대로 곱했을 때그때 AP : PB
(−4, −2)(4, 3)1 : 3(−2, −0.75)1 : 3 ✓(2, 1.75)3 : 1 ✗
(0, 0)(10, 0)3 : 2(6, 0)3 : 2 ✓(4, 0)2 : 3 ✗
(1, 1)(5, 5)1 : 1(3, 3)1 : 1 ✓(3, 3)1 : 1 (중점)

AP : PB = m : n이면 P는 A에서 전체의 m/(m + n)만큼 간 곳 → P = A + (m/(m + n))(B − A) = (nA + mB)/(m + n). m이 크면 P는 B에 가까워야 하니 B의 비중이 커지는 것이 맞습니다. 외분점은 (mB − nA)/(m − n), 무게중심은 세 점의 평균.

개념 정리

1. m : n 내분점 = (mx₂ + nx₁)/(m + n): 가까운 쪽 좌표에 먼 쪽 비를 곱해요

AP : PB = m : n이면 P는 A에서 전체의 m/(m + n)만큼 간 곳이라 P = A + (m/(m + n))(B − A) = (nA + mB)/(m + n)이에요. 즉 A의 좌표에는 n, B의 좌표에는 m이 곱해져 엇갈려요. m이 크면 P는 B에 가까워야 하니 B의 좌표 비중이 커지는 게 맞아요. 중점은 m = n인 경우.

왜 그럴까

  • A(0), B(10)를 3 : 2로: (2·0 + 3·10)/5 = 6. AP = 6, PB = 4 → 3 : 2 ✓.
  • 외분점은 (mx₂ − nx₁)/(m − n).
  • 무게중심은 세 점 좌표의 평균 — 내분의 확장.

2. 자주 하는 오해 바로잡기

· "(mx₁ + nx₂)/(m + n)" → 순서가 반대. 검산하면 비가 뒤집혀요.

3. 생활 속에서 · 이어지는 개념

  • 두 색을 3 : 2로 섞은 색, 두 지점 사이 특정 비율 위치(급수 시설 배치)가 내분이에요.
P 좌표 계산 → AP, PB 실측 비와 m : n 비교
📋 데이터 확인 탭의 결론

“모든 기록에서 AP × n = PB × m, 즉 AP : PB = m : n 입니다. P는 A에서 출발해 전체의 m/(m+n)만큼 간 지점이니까요.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

A(2, −1), B(8, 5)를 2 : 1로 내분하는 점은?

((1·2 + 2·8)/3, (1·(−1) + 2·5)/3) = (6, 3).

A(0, 0), B(6, 3)을 3 : 1로 외분하는 점은?

(3·B − 1·A)/(3 − 1) = (9, 4.5).
