중복조합 — 공 r개와 칸막이 n − 1개

종류 수 n과 고르는 개수 r을 바꾸며 중복을 허용한 선택을 모두 생성해 개수를 세고 C(n + r − 1, r), 중복 없는 nCr과 비교했습니다. 직접 센 가짓수는 언제나 C(n + r − 1, r)이었고 nCr보다 컸으며, 공 r개와 칸막이 n − 1개를 한 줄로 놓는 방법과 같았습니다. 중복조합을 정리합니다.

표 1. 중복조합 (실험 결과)
종류 n고르는 개수 r직접 센 가짓수C(n + r − 1, r)nCr (중복 없이)
33105C3 = 101
34156C4 = 150 (불가)
2344C3 = 40
42105C2 = 106

n종류에서 중복 허용 r개 = 공 r개를 n개 칸에 나눠 넣기 = 공 r개와 칸막이 n − 1개의 배열(같은 것이 있는 순열) (n + r − 1)!/(r!(n − 1)!) = ₙ₊ᵣ₋₁Cᵣ. x₁ + … + xₙ = r의 음이 아닌 정수해 개수도 같고, 각 종류 최소 1개면 먼저 하나씩 주고 나머지를 중복조합. 중복조합 = nʳ이 아니라 그건 순서 있는 중복순열.

개념 정리

1. 중복조합 ₙHᵣ = ₙ₊ᵣ₋₁Cᵣ: 공 r개와 칸막이 n − 1개 늘어놓기

n종류에서 중복을 허용해 r개를 고르는 것은 공 r개를 n개 칸에 나눠 넣기와 같아요. 공 r개와 칸막이 n − 1개를 한 줄로 놓는 방법(같은 것이 있는 순열)이 (n + r − 1)!/(r!(n − 1)!) = ₙ₊ᵣ₋₁Cᵣ이에요. x₁ + x₂ + … + xₙ = r의 음이 아닌 정수해 개수도 같아요.

왜 그럴까

  • 3종류 과일 4개: ₃H₄ = ₆C₄ = 15. ○○|○|○ = (2, 1, 1).
  • 각 종류 최소 1개면 먼저 하나씩 주고 나머지를 중복조합.
  • 순열·조합·중복순열·중복조합 네 가지를 "순서? 중복?"으로 구분.

2. 자주 하는 오해 바로잡기

· "중복조합 = nʳ" → 그건 순서가 있는 중복순열이에요.
