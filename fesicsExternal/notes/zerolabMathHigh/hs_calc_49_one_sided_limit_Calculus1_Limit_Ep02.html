좌극한과 우극한 — 극한값과 함숫값은 다른 질문

세 유형의 함수에서 x = 1 좌우로 다가가는 거리를 줄이며 좌극한·우극한·f(1)을 비교했습니다. 좌우 극한이 같을 때만 극한이 존재했고 그 값은 f(1)과 별개였으며(f(1)이 없거나 달라도 극한은 있을 수 있고, 좌우가 다르면 f(1)이 있어도 극한 없음), 극한은 그 점을 제외한 주변만 봤습니다. 극한의 뜻을 정리합니다.

극한값은 ‘다가갈 때’의 값, 함숫값은 ‘그 점에서’의 값. x → 1⁻와 x → 1⁺가 같을 때만 lim f(x)가 존재하며 f(1)과 별개. 극한값 = 대입한 값은 연속함수에서만. 구간 요금제(1 kg 직전 요금과 1 kg 요금이 다름)가 계단 불연속의 예.

개념 정리

1. 극한값은 "다가갈 때"의 값, 함숫값은 "그 점에서"의 값

x → 1⁻(왼쪽)와 x → 1⁺(오른쪽)에서 다가가는 값이 같을 때만 극한값 lim f(x)가 존재해요. 이는 f(1)과 별개예요 — f(1)이 정의되지 않았거나 다른 값이어도 극한은 있을 수 있고, 좌우가 다르면 f(1)이 있어도 극한이 없어요. 극한은 그 점을 제외한 주변만 봐요.

왜 그럴까

  • f(x) = (x² − 1)/(x − 1): f(1)은 없지만 lim = 2.
  • f(x) = x (x ≠ 1), f(1) = 5: lim = 1 ≠ f(1) = 5.
  • 계단 함수: 좌극한 0, 우극한 1 → 극한 없음.

2. 자주 하는 오해 바로잡기

· "극한값 = 대입한 값" → 연속함수에서만 그래요.

3. 생활 속에서 · 이어지는 개념

  • 구간 요금제(1 kg 직전 요금과 1 kg 요금이 다름), 순간 속도 정의가 극한이에요.
x = 1 좌우에서 값 읽기 → 좌극한, 우극한, f(1) 세 값 비교

예제

f(x) = |x|/x의 x → 0에서 좌극한·우극한·극한은?

좌 −1, 우 1 → 극한 없음.

f(x) = (x² − 4)/(x − 2) (x ≠ 2)의 x → 2 극한은? f(2)는?

극한 4; f(2)는 정의되지 않음.
