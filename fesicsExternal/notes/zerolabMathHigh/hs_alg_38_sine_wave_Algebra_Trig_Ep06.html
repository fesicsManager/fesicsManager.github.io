고등학교 대수 · 실험 「y = a sin bx + c」

y = a sin bx + c — 주기는 b만이 정한다

진폭 a, b, 세로 이동 c를 바꾸며 그래프에서 마루 간격(주기)과 최댓값·최솟값을 재어 2π/b, 2a와 비교했습니다. 잰 주기는 언제나 2π/b였고 a, c를 바꿔도 주기는 변하지 않았으며, 최대 − 최소 = 2a, 중심선은 y = c였습니다. 삼각함수 그래프의 세 요소를 정리합니다.

sin의 한 주기는 bx가 0에서 2π까지 갈 때이므로 x로는 2π/b(일반적으로 2π/|b|). b가 클수록 촘촘, a는 위아래 폭(진폭 |a|), c는 중심선 높이라 주기와 무관. a가 커도 주기는 길어지지 않습니다. tan bx의 주기는 π/b.

개념 정리

1. y = a sin bx + c의 주기는 2π/|b| (이 실험에서는 b > 0이라 2π/b), 진폭은 |a|, 중심선은 y = c

sin의 한 주기는 bx가 0에서 2π까지 갈 때이므로 x로는 2π/b예요. b가 클수록 촘촘해져요. a는 위아래 폭(진폭), c는 중심선 높이라 주기와는 무관해요. 마루와 마루 사이 거리를 재면 정확히 2π/b가 나와요. 일반적으로는 b ≠ 0일 때 주기가 2π/|b|이고(b가 음수여도 주기는 양수), b = 0이면 상수함수라 기본 주기가 정해지지 않아요.

왜 그럴까

  • y = 3 sin 2x + 1: 주기 π, 최대 4, 최소 −2.
  • y = sin(x/2): 주기 4π.
  • tan bx의 주기는 π/b.

2. 자주 하는 오해 바로잡기

· "a가 크면 주기도 길다" → 진폭만 커져요. 주기는 b만이 정해요.

3. 생활 속에서 · 이어지는 개념

  • 음의 높낮이(진동수 = 1/주기), 조수 간만, 계절 기온 변화가 사인파예요.
그래프에서 마루 간격 측정 → 2π/b와 비교; a, c 변경 시 주기 불변 확인

예제

y = 3 sin 2x + 1의 주기·최댓값·최솟값은?

주기 π, 최대 4, 최소 −2.

주기가 4π이고 최댓값 5, 최솟값 −1인 사인함수는?

b = 1/2, a = 3, c = 2 → y = 3 sin(x/2) + 2.
