로그의 성질 — 곱은 합, 덧셈은 안 된다

밑 a와 진수 x, y, 지수 k를 바꾸며 log(xy), log x + log y, log(x + y), k·log x를 비교했습니다. log(xy) = log x + log y와 log xᵏ = k log x는 항상 성립했지만 log(x + y)는 어떤 간단한 식으로도 나뉘지 않았습니다. 지수법칙에서 나오는 로그의 성질을 정리합니다.

x = aᵖ, y = a^q → xy = a^(p+q) → log(xy) = p + q. log(x/y) = log x − log y, log xⁿ = n log x도 같은 원리. 덧셈은 로그 안으로 못 들어가며 log x · log y도 log(xy)가 아닙니다. 계산자·로그표가 곱셈을 덧셈으로 바꿔 계산하던 원리.

개념 정리

1. log(xy) = log x + log y, 하지만 log(x + y)는 따로 계산할 수 없어요

지수에서 aᵐ·aⁿ = aᵐ⁺ⁿ이므로 로그에서는 곱이 합으로 바뀌어요: log(xy) = log x + log y, log(x/y) = log x − log y, log xⁿ = n log x. 반면 log(x + y)는 어떤 간단한 식으로도 나눠지지 않아요. log 2 + log 3 = log 6 = 0.778, log 5 = 0.699 — 다른 값이에요.

왜 그럴까

  • x = aᵖ, y = a^q → xy = a^(p+q) → log(xy) = p + q.
  • log 8 = 3 log 2, log √2 = ½ log 2.
  • log x · log y도 log(xy)가 아니에요.

2. 자주 하는 오해 바로잡기

· "log(x + y) = log x + log y" → 덧셈은 로그 안으로 못 들어가요.

3. 생활 속에서 · 이어지는 개념

  • 계산자·로그표로 곱셈을 덧셈으로 바꿔 계산하던 것, 복리 기간 계산(log로 지수 풀기)이 로그 법칙이에요.

📋 데이터 확인 탭의 결론

“log(xy) = log x + log y 는 모든 기록에서 성립합니다. 지수법칙 aᵐ·aⁿ = aᵐ⁺ⁿ 을 거꾸로 읽은 것이기 때문입니다 — 곱셈이 지수의 덧셈이었으니, 로그를 취하면 곱이 합이 됩니다.”
