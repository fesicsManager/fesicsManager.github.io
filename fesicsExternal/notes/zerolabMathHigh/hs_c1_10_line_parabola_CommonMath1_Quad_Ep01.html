포물선과 직선 — 교점 수 = 연립 방정식의 D

포물선 y = x² + bx + c와 직선 y = mx + k의 계수를 바꾸며 그래프의 교점 수를 세고 연립한 x² + (b − m)x + (c − k) = 0의 판별식과 대조했습니다. D > 0이면 두 점, D = 0이면 접함, D < 0이면 만나지 않아 항상 일치했습니다. 접선 조건 D = 0을 정리합니다.

교점의 x좌표 = 연립 방정식의 실근. 접선 문제는 D = 0 조건으로 기울기나 절편을 구합니다. 세로선 x = k는 항상 한 점에서 만나지만 연립 판별식으로는 다루지 않으며, 직선이 포물선 안쪽을 지나도 기울기·절편에 따라 접하거나 빗나갈 수 있습니다.

개념 정리

1. 교점 개수 = 연립한 이차방정식의 판별식 부호

y = x² + bx + c와 y = mx + k를 연립하면 x² + (b − m)x + (c − k) = 0. 이 방정식의 D > 0이면 두 점, D = 0이면 접함(한 점), D < 0이면 만나지 않음이에요. 교점의 x좌표가 이 방정식의 실근이니까요. 접선 문제는 D = 0 조건으로 기울기나 절편을 구해요.

왜 그럴까

  • y = x²과 y = 2x − 1: x² − 2x + 1 = 0, D = 0 → (1, 1)에서 접함.
  • y = 2x − 2: D = 4 − 8 < 0 → 안 만남. y = 2x: D = 4 → 두 점.
  • 세로선 x = k는 항상 한 점에서 만나지만 연립 판별식으로는 다루지 않아요.

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

y = x² − 2x + 3에 접하고 기울기 2인 직선은?

x² − 4x + 3 − k = 0, D/4 = 4 − 3 + k = 0 → k = −1 → y = 2x − 1.

y = x²과 y = x + k가 서로 다른 두 점에서 만날 k의 범위는?

D = 1 + 4k > 0 → k > −1/4.
