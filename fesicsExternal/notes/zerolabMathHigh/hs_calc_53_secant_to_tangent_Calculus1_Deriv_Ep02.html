미분계수 — 할선의 극한이 접선

접점 a와 거리 h를 바꾸며 두 점을 잇는 할선의 기울기를 재고 접선의 기울기 f′(a)와의 차이를 기록했습니다. h를 0.1, 0.01, 0.001로 줄일수록 할선 기울기가 f′(a)에 다가갔고, h = 0을 직접 넣으면 0/0이라 극한이 필요했으며 |x|의 x = 0에서는 좌우가 달라 미분 불가였습니다. 미분계수의 정의를 정리합니다.

할선의 기울기 [f(a + h) − f(a)]/h는 평균변화율. h → 0이면 두 점이 하나로 모이고 할선은 접선이 되며 기울기의 극한이 f′(a). h가 음수여도 같은 값으로 수렴해야 미분가능(|x|는 뾰족점). 접선의 정의는 할선의 극한이지 ‘한 점에서만 만나는 직선’이 아닙니다.

개념 정리

1. f′(a) = lim_{h→0} [f(a + h) − f(a)]/h: 할선의 극한이 접선

두 점 (a, f(a)), (a + h, f(a + h))를 잇는 할선의 기울기는 평균변화율이에요. h를 0으로 보내면 두 점이 하나로 모이고 할선은 접선이 되며, 기울기의 극한이 미분계수 f′(a)예요. h = 0을 직접 넣으면 0/0이라 극한이 필요해요. h를 0.1, 0.01, 0.001로 줄이면 값이 f′(a)에 다가가요.

왜 그럴까

  • f(x) = x², a = 1: [(1 + h)² − 1]/h = 2 + h → 2. h = 0.1이면 2.1, 0.01이면 2.01.
  • h가 음수여도(왼쪽 할선) 같은 값으로 수렴해야 미분 가능.
  • |x|는 x = 0에서 좌 −1, 우 +1로 달라 미분 불가(뾰족점).

2. 자주 하는 오해 바로잡기

· "접선은 곡선과 한 점에서만 만나는 직선" → 정의는 할선의 극한이에요. 다른 곳에서 또 만날 수도 있어요.

“h가 작아질수록 차이가 0에 가까워집니다. 미분계수는 이 “가까워지는 값”, 곧”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = x³의 x = 2에서의 미분계수를 정의로 구하시오.

[(2 + h)³ − 8]/h = 12 + 6h + h² → 12.

f(x) = 1/x의 x = 1에서 미분계수는?

[1/(1 + h) − 1]/h = −1/(1 + h) → −1.
