고등학교 대수 · 실험 「지수함수와 로그함수」

지수함수와 로그함수 — y = x에 대칭인 역함수

밑 a와 t를 바꾸며 aᵗ와 log_a(aᵗ)를 구하고 두 그래프 위 점 (t, aᵗ)와 (aᵗ, t)의 대응을 확인했습니다. log_a(aᵗ)는 언제나 t로 되돌아왔고 두 그래프는 y = x에 대칭이었으며, a > 1이면 둘 다 증가, 0 < a < 1이면 둘 다 감소했습니다. 두 함수의 역함수 관계를 정리합니다.

실험 데이터 되짚기

실험 안내: 같은 밑의 두 그래프를 함께 그려 (p, q)와 (q, p)의 대응, 점근선의 교환을 확인합니다.

표 1. 역함수 대응 (실험 예시)
밑 ataᵗlog_a(aᵗ)증가/감소대칭점
2121증가(1, 2) ↔ (2, 1)
2383증가(3, 8) ↔ (8, 3)
2010증가(0, 1) ↔ (1, 0)
0.520.252감소(2, 0.25) ↔ (0.25, 2)

q = aᵖ ⟺ p = log_a q이므로 (p, q)를 뒤집은 (q, p)가 로그 그래프 위에 있어 y = x 대칭. aˣ의 점근선 y = 0(x축)은 로그의 점근선 x = 0(y축)으로, 정의역 ℝ ↔ 치역 (0, ∞)도 서로 바뀝니다. 역함수는 1/f(x)가 아니며 1/aˣ = a⁻ˣ는 전혀 다른 함수.

개념 정리

1. y = aˣ와 y = log_a x는 서로 역함수, 그래프는 y = x 대칭

aˣ의 그래프 위 점 (p, q)를 뒤집은 (q, p)는 log_a x 위에 있어요(q = aᵖ ⟺ p = log_a q). 그래서 두 그래프는 직선 y = x에 대해 대칭이에요. aˣ의 점근선 y = 0(x축)은 log의 점근선 x = 0(y축)으로, 정의역 ℝ ↔ 치역 (0, ∞)도 서로 바뀌어요. (0, 1) ↔ (1, 0).

왜 그럴까

  • 2ˣ: (0, 1), (1, 2), (3, 8). log₂ x: (1, 0), (2, 1), (8, 3).
  • a > 1이면 둘 다 증가, 0 < a < 1이면 둘 다 감소.
  • log_a(aˣ) = x, a^(log_a x) = x — 합성하면 원래대로.

2. 자주 하는 오해 바로잡기

· "역함수 = 1/f(x)" → 역함수는 입력·출력을 바꾼 함수이고 1/aˣ = a⁻ˣ는 전혀 다른 함수예요.

3. 생활 속에서 · 이어지는 개념

  • "몇 년 뒤 2배가 되나"(로그)와 "n년 뒤 얼마인가"(지수)는 같은 관계를 반대로 묻는 것이에요.
같은 밑 두 그래프 함께 그리기 → (p, q)와 (q, p) 대응 확인
📋 데이터 확인 탭의 결론

“모든 기록에서 log_a(aᵗ) = t. 두 함수는 서로 역함수이고, 그래서 그래프가 y = x에 대해 대칭입니다. 지수함수의 점 (t, aᵗ)가 로그함수에서는 (aᵗ, t)로”
