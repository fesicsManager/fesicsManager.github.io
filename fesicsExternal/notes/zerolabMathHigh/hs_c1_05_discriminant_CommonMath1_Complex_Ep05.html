판별식 — D의 부호 = x축 교점의 개수

계수 a, b, c를 바꾸며 D = b² − 4ac와 포물선의 x축 교점 수, 근의 종류를 대조했습니다. D > 0이면 교점 2, D = 0이면 접함(1), D < 0이면 0으로 예측이 항상 맞았고, 실근이 없어도 허근 2개는 있었습니다. 판별식의 뜻을 정리합니다.

근의 공식의 √ 안 값. 그래프로는 꼭짓점의 y좌표 −D/4a의 부호가 a의 부호와 같은지로도 판단. a > 0, D < 0이면 모든 x에서 y > 0(항상 양수 조건). 짝수 판별식 D/4 = b′² − ac가 편하며, D < 0은 실근이 없을 뿐 허근이 있습니다.

개념 정리

1. D = b² − 4ac의 부호 = 포물선과 x축의 교점 개수

근의 공식의 √ 안 값 D가 양수면 서로 다른 두 실근(교점 2), 0이면 중근(접함, 1), 음수면 실근 없음(교점 0)이에요. 그래프로는 꼭짓점의 y좌표 −D/4a의 부호가 a의 부호와 같은지로 판단할 수 있어요. 실근이 없어도 허근 2개는 있어요.

왜 그럴까

  • x² − 2x − 3: D = 16 → 2개. x² − 2x + 1: D = 0 → 접점 (1, 0). x² − 2x + 5: D = −16 → 없음.
  • a > 0, D < 0이면 모든 x에서 y > 0(항상 양수 조건).
  • 짝수 판별식 D/4 = b′² − ac로 계산이 편해요.

2. 자주 하는 오해 바로잡기

· "D < 0이면 근이 없다" → 실근이 없을 뿐 허근이 있어요.

3. 생활 속에서 · 이어지는 개념

  • 공이 특정 높이에 닿는지, 두 물체가 충돌하는지(만나는 시각의 존재) 판정에 판별식을 써요.
계수 변경 → 교점 개수 세기, D 값과 대조

예제

x² + 2kx + k + 2 = 0이 서로 다른 두 실근을 가질 k의 범위는?

D/4 = k² − k − 2 > 0 → (k − 2)(k + 1) > 0 → k < −1 또는 k > 2.

모든 x에서 x² − 4x + m > 0이려면?

D/4 = 4 − m < 0 → m > 4.
