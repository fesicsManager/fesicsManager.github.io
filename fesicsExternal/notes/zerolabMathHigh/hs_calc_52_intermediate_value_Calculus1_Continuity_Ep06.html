사잇값 정리 — 부호가 바뀌면 근이 있다

f(x) = x³ − 3x + c의 c와 구간 [p, q]를 바꾸며 f(p), f(q)의 부호가 다를 때 중점 부호로 구간을 반씩 좁혀 근을 찾았습니다. 양 끝 부호가 다르면 항상 근을 찾았고, 부호가 같아도 근이 있을 수 있었으며 정리는 존재만 보장했습니다. 사잇값 정리와 이분법을 정리합니다.

[a, b]에서 연속인 f가 f(a)와 f(b) 사이의 어떤 값 k에 대해 f(c) = k인 c가 존재. f(a)f(b) < 0이면 근이 있고 이분법으로 원하는 정밀도까지. 연속이 아니면 성립하지 않으며(1/x), 부호가 같아도 근이 있을 수 있고(x² − 1은 −2, 2에서 둘 다 양수) 근의 개수가 아니라 존재만 보장.

개념 정리

1. 연속함수가 구간 양 끝에서 부호가 다르면 그 사이에 근이 있어요

사잇값 정리: [a, b]에서 연속인 f가 f(a)와 f(b) 사이의 어떤 값 k에 대해 f(c) = k인 c가 (a, b)에 존재해요. 특히 f(a)f(b) < 0이면 근이 있어요. 구간을 반으로 나눠 부호가 바뀌는 쪽을 택하는 것을 반복하면(이분법) 근을 원하는 정밀도로 찾아요. 연속이 아니면 성립하지 않아요(1/x는 −1과 1에서 부호가 다르지만 근 없음).

왜 그럴까

  • f(x) = x³ − x − 1: f(1) = −1, f(2) = 5 → (1, 2)에 근. 반복하면 1.3247….
  • 부호가 같아도 근이 있을 수 있어요(x² − 1은 −2, 2에서 둘 다 양수지만 근 2개).
  • 근의 개수가 아니라 존재만 보장해요.

2. 자주 하는 오해 바로잡기

· "부호가 같으면 근이 없다" → 짝수 개 있을 수 있어요.

3. 생활 속에서 · 이어지는 개념

  • 공학 계산기의 방정식 풀이(이분법), "어느 순간 정확히 이 온도였던 때가 있다"는 논증이 사잇값 정리예요.
양 끝 부호 확인 → 중점 부호로 구간 반씩 좁히기 → 근 근사
📋 데이터 확인 탭의 결론

“부호가 달랐던 기록 '+op.length+'개에서 모두 근을 찾았습니다(f(근)이 0에 가깝습니다). 다항함수는 끊긴 곳 없이 이어지므로, 음수에서 양수로 가려면 반드시 0을 지나야 합니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = x³ − x − 1이 (1, 2)에 근을 가짐을 보이고 이분법 두 번으로 좁히시오.

f(1) = −1, f(2) = 5 → 근 존재. f(1.5) = 0.875 > 0 → (1, 1.5); f(1.25) = −0.297 < 0 → (1.25, 1.5).

1/x가 [−1, 1]에서 부호가 다른데 근이 없는 까닭은?

x = 0에서 불연속이라 사잇값 정리를 쓸 수 없음.
