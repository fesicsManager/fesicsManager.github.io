다항식의 나눗셈 — 나머지의 차수는 나누는 식보다 작다

A(x)의 계수와 나누는 식을 바꾸며 몫 Q(x), 나머지 R(x)를 구하고 R의 차수와 B의 차수를 비교했습니다. 나머지의 차수는 언제나 나누는 식의 차수보다 작았고(이차식으로 나누면 일차 이하, 일차식이면 상수), BQ + R = A가 성립했습니다. 나눗셈이 멈추는 기준을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: A ÷ B를 장제법으로 하여 Q, R을 기록하고 deg R < deg B와 BQ + R = A를 확인합니다.

표 1. 몫과 나머지의 차수 (실험 예시)
A(x)B(x)몫 Q(x)나머지 R(x)R의 차수B의 차수R차수 < B차수
x³ − 2x² + 3x − 4x − 2x² + 3201예
x³ + 2x + 1x² + 1xx + 112예
2x³ + x² − 5x + 2x + 22x² − 3x + 10— (나누어떨어짐)1예
x⁴ + 1x² − xx² + x + 1x + 112예

최고차항을 없애는 과정을 더 이상 없앨 수 없을 때까지 반복 — 남은 식의 차수가 B보다 작아지면 멈춥니다(정수 나눗셈에서 나머지 < 나누는 수). deg A = deg B + deg Q, R = 0이면 B가 A의 인수. 나누는 식이 2차 이상이면 나머지가 1차 이상일 수 있습니다.

개념 정리

1. A = BQ + R, 나머지 R의 차수는 나누는 식 B의 차수보다 작아요

다항식 나눗셈은 최고차항을 없애는 과정을 더 이상 없앨 수 없을 때까지 반복해요. 남은 식의 차수가 B의 차수보다 작아지면 B로 더 나눌 수 없어 거기서 멈춰요. 그래서 이차식으로 나누면 나머지는 일차 이하, 일차식으로 나누면 상수예요. 정수 나눗셈에서 나머지가 나누는 수보다 작은 것과 같은 원리예요.

왜 그럴까

  • (x³ + 2x + 1) ÷ (x² + 1) = x, 나머지 x + 1 (1차 < 2차).
  • 차수: deg A = deg B + deg Q.
  • R = 0이면 B가 A의 인수.

2. 자주 하는 오해 바로잡기

· "나머지는 항상 상수" → 나누는 식이 2차 이상이면 나머지가 1차 이상일 수 있어요.

3. 생활 속에서 · 이어지는 개념

  • 오류 검출 코드(CRC), 신호 처리 필터 설계가 다항식 나눗셈을 써요.
A ÷ B 조립·장제법 → Q, R 기록, deg R < deg B 확인, BQ + R = A 검산
📋 데이터 확인 탭의 결론

“모든 기록에서 (R의 차수) < (B의 차수) 입니다. 나머지의 차수가 나누는 식보다 작아질 때까지 나눗셈이 계속되기 때문입니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

x³ − 1을 x² + x + 1로 나눈 몫과 나머지는?

몫 x − 1, 나머지 0(인수).

f(x)를 (x − 1)(x − 2)로 나눈 나머지의 꼴은?

2차로 나누므로 ax + b (일차 이하).
