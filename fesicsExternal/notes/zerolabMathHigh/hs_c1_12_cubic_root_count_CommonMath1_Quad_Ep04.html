삼차방정식의 근 — 중복 포함 실근은 1개 또는 3개

(x − t)(x² + bx + c) = 0의 t, b, c를 바꾸며 세 근을 복소평면에 표시하고 실근·허근의 개수를 기록했습니다. x = t는 항상 실근이고 나머지 둘은 이차식의 D에 따라 실근 2개(중복 포함 총 3) 또는 켤레 허근 2개(실근 1)였으며, 중복 포함 근의 수는 항상 3이었습니다. 삼차방정식의 근의 개수를 정리합니다.

실수 계수면 허근은 짝으로 나오므로 중복도를 포함해 세면 실근은 1개 또는 3개뿐. 서로 다른 실근을 세면 중근 때문에 1·2·3개 모두 가능((x − 1)²(x + 2) = 0은 중복 포함 3개, 서로 다른 2개). 삼차함수 그래프는 x축과 최소 1번 만나며, 대수학의 기본정리: n차 방정식은 중복 포함 n개의 복소근.

개념 정리

1. 삼차방정식의 근은 복소수 범위에서 중복도를 포함해 항상 3개, 중복도 포함 실근은 1개 또는 3개

(x − t)(x² + bx + c) = 0에서 x = t는 실근이고 나머지 둘은 이차식의 판별식에 따라 실근 2개(중복 포함 총 3) 또는 켤레 허근 2개(실근 총 1)예요. 실수 계수면 허근은 짝으로 나오므로 중복도를 포함해 세면 실근은 1개 또는 3개뿐이에요. 다만 서로 다른 실근을 세면 중근 때문에 1개·2개·3개가 모두 가능해요. 예를 들어 (x − 1)²(x + 2) = 0은 중복 포함 실근 3개이지만 서로 다른 실근은 1, −2의 2개예요. 삼차함수 그래프는 x축과 최소 1번 만나요.

왜 그럴까

  • x³ − 1 = (x − 1)(x² + x + 1): 실근 1, 허근 (−1 ± √3i)/2.
  • x³ − 3x + 2 = (x − 1)²(x + 2): 실근 1(중근), −2. 중복 포함 실근 3개, 서로 다른 실근 2개.
  • 대수학의 기본정리: n차 방정식은 중복 포함 n개의 복소근.

2. 자주 하는 오해 바로잡기

· "삼차니까 실근 3개" → 1개일 수도 있어요. 3개면 모두 실근.

· "실근이 2개인 삼차방정식은 없다" → 중복도를 포함해 세면 없지만, 서로 다른 실근을 세면 중근이 있을 때 2개가 돼요. 어떤 기준으로 세는지 먼저 정해야 해요.

3. 생활 속에서 · 이어지는 개념

  • 기체 상태방정식(반데르발스)의 부피 해, 3차 스플라인 곡선 설계에 삼차방정식이 쓰여요.

예제

x³ − 1 = 0의 근을 모두 구하시오.

(x − 1)(x² + x + 1) = 0 → 1, (−1 ± √3 i)/2 (실근 1개, 허근 2개).

x³ − 3x + 2 = 0의 중복 포함 실근 수와 서로 다른 실근 수는?

(x − 1)²(x + 2) → 중복 포함 3, 서로 다른 2 (1, −2).
