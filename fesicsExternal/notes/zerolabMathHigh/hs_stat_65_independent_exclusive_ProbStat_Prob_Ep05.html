독립과 배반 — 비슷해 보이지만 정반대

두 사건 A, B를 정의해 P(A ∩ B)가 0인지(배반), P(A)P(B)와 같은지(독립)를 각각 판정했습니다. 첫 주사위 6과 둘째 주사위 짝수는 독립, 합 7과 합 8은 배반이었고, 배반이면 P(A ∩ B) = 0 ≠ P(A)P(B)로 강하게 종속이었으며 둘 다 성립하려면 한쪽 확률이 0이어야 했습니다. 두 개념의 차이를 정리합니다.

독립은 한쪽 결과가 다른 쪽 확률에 영향을 주지 않는 것, 배반은 동시에 일어날 수 없는 것. 배반이면 한쪽이 일어난 순간 다른 쪽이 불가능해지므로 강하게 종속. 배반이면 덧셈정리에서 뺄 것이 없고 독립이면 곱셈정리에서 조건부가 필요 없음. 벤 다이어그램의 ‘겹침 없음’과 확률의 ‘독립’은 다른 그림.

개념 정리

1. 독립: P(A ∩ B) = P(A)P(B), 배반: P(A ∩ B) = 0 — 정반대 개념

독립은 한쪽 결과가 다른 쪽 확률에 영향을 주지 않는 것(첫 주사위 6과 둘째 주사위 짝수), 배반은 동시에 일어날 수 없는 것(한 주사위가 1이면서 6). 배반이면 한쪽이 일어난 순간 다른 쪽이 불가능해지므로 강하게 종속이에요. 둘 다 성립하려면 P(A) = 0 또는 P(B) = 0이어야 해요.

왜 그럴까

  • 두 주사위: A = 첫째 6(1/6), B = 둘째 짝수(1/2), P(A ∩ B) = 3/36 = 1/12 = 1/6 × 1/2 → 독립.
  • A = 합 7, B = 합 8: 배반. P(A ∩ B) = 0 ≠ P(A)P(B) → 종속.
  • 배반이면 덧셈정리에서 뺄 것이 없고, 독립이면 곱셈정리에서 조건부가 필요 없어요.

예제

동전 앞면(A)과 주사위 6(B)은 독립인가 배반인가?

P(A ∩ B) = 1/12 = 1/2 × 1/6 → 독립; 동시에 가능하므로 배반 아님.

한 장 뽑기에서 하트(A)와 스페이드(B)는?

P(A ∩ B) = 0 → 배반; 0 ≠ 1/4 × 1/4 → 종속.
