대학 전자기학 랩 02 · 델타 함수

한 점에 갇힌 무한대 — 점전하 역설의 해결

실험에서 사각 펄스·가우스·로런츠 세 가지 델타 근사의 폭 ε을 1 → 0.1 → 0.01로 조이며 높이·넓이·∫f·δ_ε를 재고, 반지름 ε인 균일 대전 구의 전기장 발산을 부피 적분해 면 유량과 비교했습니다. 높이는 0.5 → 5 → 50으로 커지면서 넓이는 항상 1이었고 ∫f·δ_ε는 f(a)에 ε²의 속도로 수렴했으며, 구 안의 발산은 ρ/ε₀로 일정하고 밖은 0이지만 부피 적분은 언제나 q/ε₀였습니다. ε → 0에서 발산이 한 점에 몰려 델타 함수가 되었습니다. 점전하 역설, 델타 함수의 적분 정의와 체 거르기, ∇·(r̂/r²) = 4πδ³, 분포로서의 성격을 정리합니다.

모양은 달라도 ε → 0에서 ∫f·δ_ε → f(a)로 같은 극한 — 델타 함수는 값이 아니라 적분 안에서의 행동으로 정의됩니다. 격자 계산에서는 ε을 격자 간격보다 작게 줄일 수 없어 극한을 직접 보는 대신 수렴 경향(ε²)으로 확인합니다.

개념 정리

1. 점전하 역설과 델타 함수

점전하의 전기장 E = q r̂/(4πε₀r²)은 원점 밖 어디서나 ∇·E = 0인데(랩 01), 원점을 감싼 면의 유량은 q/ε₀로 0이 아닙니다 — 발산 정리와 모순처럼 보이는 역설입니다. 해결은 원점에 모든 발산이 집중되어 있다는 것: ∇·(r̂/r²) = 4πδ³(r). 디랙 델타 함수는 값이 아니라 적분 안에서의 행동으로 정의됩니다: 폭 → 0, 높이 → ∞이면서 넓이 = 1을 유지하고, ∫f(x)δ(x − a)dx = f(a)(체 거르기 성질). 그래서 점전하 밀도를 ρ = qδ³(r)로 쓰면 ∇·E = ρ/ε₀가 원점까지 포함해 성립하고 가우스 법칙이 모든 곳에서 참이 됩니다. 실험의 균일 구 모형이 이를 눈으로 보여 줍니다: 반지름 ε 안에 전하를 고르게 펼치면 구 안 E ∝ r, 발산 = ρ/ε₀ = 3q/(4πε³ε₀)로 일정, 구 밖은 0이고 부피 적분은 ε과 무관하게 q/ε₀ — ε → 0에서 발산이 한 점에 몰리며 델타 함수가 됩니다.

2. 델타의 여러 얼굴

세 근사(사각 펄스·가우스·로런츠)는 모양이 전혀 다르지만 ε → 0에서 같은 극한을 주므로 델타는 특정 함수가 아니라 수열의 극한(분포)입니다. 미분 δ′와 합성 δ(g(x)) = Σδ(x − x_i)/|g′(x_i)|(g의 근 x_i)도 적분으로만 정의되며, 3차원 δ³(r) = δ(x)δ(y)δ(z)는 부피 적분이 1입니다. 신호 처리의 임펄스 응답(망치로 한 번 치기 → 시스템의 특성), 샘플링 정리의 빗살 함수, 확률의 점질량 분포, 양자역학의 위치 고유 상태와 그린 함수(점 원천의 응답)가 모두 델타 함수이고, 정전기의 그린 함수 1/(4πε₀|r − r′|)는 ∇²(1/r) = −4πδ³(r)에서 나옵니다(랩 04·07).

3. 모형과 실제

델타 ‘함수’는 함수가 아니라 분포(일반화 함수)입니다. 격자 계산에서는 ε을 격자 간격보다 작게 줄일 수 없어 극한을 직접 볼 수 없고, 수렴 경향으로 확인합니다 — 실험의 ∫f·δ_ε − f(a)가 ε²으로 줄어드는 것은 f의 2차 미분 항(테일러 전개) 때문입니다. 물리적 점전하(전자)의 실제 크기는 10⁻¹⁸ m 이하로 측정되어 델타 함수 모형이 잘 맞지만, 점전하의 자체 에너지 ∝ ∫E² dV가 발산하는 문제는 양자 전기역학의 재규격화로 다룹니다.

∫f(x)δ(x − a)dx = f(a)  ·  ∫δ = 1, 폭 → 0  ·  ∇·(r̂/r²) = 4πδ³(r)  ·  ρ = qδ³(r) → ∇·E = ρ/ε₀  ·  δ(g(x)) = Σ δ(x − x_i)/|g′(x_i)|

사각 펄스 높이 1/2ε: ε 0.01 → 50 · 가우스 1/(ε√π) · 로런츠 1/(πε) · 수렴 ∝ ε² · 균일 구 부피 적분 항상 q/ε₀

🔬 과학 원리 탭

“델타 함수는 값이 아니라 적분 안에서의 행동으로 정의돼요: 폭 → 0, 높이 → ∞이면서 넓이 = 1을 유지하고, ∫f(x)δ(x − a)dx = f(a)(체 거르기 성질).”

실험 과학 원리 · 디랙 델타 함수와 점전하 역설

예제

∫₋₅⁵ (x² + 1)δ(x − 2)dx와 ∫₀^∞ cos x · δ(2x − π)dx를 구하시오.

첫째: 체 거르기 → f(2) = 4 + 1 = 5. 둘째: δ(2x − π) = δ(x − π/2)/|2| → cos(π/2)/2 = 0. 합성 규칙 |g′| = 2로 나누는 것을 잊지 않도록.

반지름 ε = 0.1인 균일 대전 구(q = 1, ε₀ = 1)의 중심에서 0.05 떨어진 곳의 발산과, 구 전체의 발산 부피 적분은?

ρ = 3q/(4πε³) = 3/(4π × 10⁻³) = 239 → 발산 = ρ/ε₀ = 239 (구 안 어디서나 같음). 부피 적분 = ρ × (4/3)πε³ = q/ε₀ = 1. ε을 0.01로 줄이면 발산은 2.39 × 10⁵이지만 적분은 여전히 1.
