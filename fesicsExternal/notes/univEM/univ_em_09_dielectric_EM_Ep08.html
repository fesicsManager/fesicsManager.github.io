대학 전자기학 랩 09 · 유전체

물질이 끼어들 때 — 편극, 속박 전하, 탈분극장

실험에서 균일하게 편극된 구의 표면 속박 전하 σ_b = P cosθ를 링으로 나눠 쿨롱 합으로 안팎 장을 구하고, 외부 장 E₀ 속 선형 유전체 구의 자기 일관 해 E_in = 3E₀/(ε_r + 2)와 경계에서의 전기력선 굴절을 확인했습니다. 편극 구 안의 장은 위치와 무관하게 균일한 −P/(3ε₀)였고 밖은 순수 쌍극자장이었으며, ε_r = 3에서 내부 장은 E₀의 60 %, ε_r → ∞에서 0(도체 극한)이었습니다. 어긋난 두 구 모형으로도 같은 탈분극장이 나왔습니다. 편극과 속박 전하, 탈분극 인자 1/3, 자기 일관 조건, 보조장 D와 경계 조건을 정리합니다.

개념 정리

1. 편극과 속박 전하, 탈분극장

절연체(유전체)를 전기장에 넣으면 분자가 편극되어 단위 부피당 쌍극자 모멘트 P가 생깁니다(랩 08의 쌍극자를 연속체로). 그 효과는 속박 전하로 나타납니다: 표면에 σ_b = P·n̂, 내부에 ρ_b = −∇·P(균일 P면 0). 균일하게 편극된 구는 한쪽 면이 +, 반대 면이 −로 대전되어(σ_b = P cosθ) 안쪽에 P와 반대 방향의 균일한 장 E_in = −P/(3ε₀)를 만듭니다 — 탈분극장. 실험의 ‘어긋난 두 구’ 모형이 이를 다른 길로 보여 줍니다: +ρ 구와 −ρ 구를 d만큼 어긋나게 겹치면 겹친 영역의 장은 두 균일 구의 내부 장(∝ r) 차이 = −ρd/(3ε₀) = −P/(3ε₀)로 균일하고, 외부는 순수 쌍극자장(p = (4/3)πR³P)입니다. 편극 구 바깥에서는 P가 만든 쌍극자장이 외부 장에 더해집니다.

2. 자기 일관 해와 보조장 D

외부 장 E₀ 속 선형 유전체(P = ε₀χ_e E)는 순환 의존입니다: E가 P를 만들고 P의 탈분극장이 E를 바꿉니다. 그러나 균일 구에서는 안쪽 장이 균일하므로 대수 방정식 하나로 닫힙니다: E_in = E₀ − P/(3ε₀) = E₀ − χ_e E_in/3 → E_in = 3E₀/(ε_r + 2)(ε_r = 1 + χ_e). ε_r = 3이면 0.6E₀, ε_r → ∞면 0 — 도체 극한(랩 05)에 연속적으로 이어집니다. 구가 만드는 쌍극자 모멘트 p = 4πε₀R³E₀(ε_r − 1)/(ε_r + 2)(클라우지우스–모소티 인자). 자유 전하만 원천으로 갖는 보조장 D = ε₀E + P를 쓰면 ∇·D = ρ_free로 속박 전하를 몰라도 되고, 경계 조건은 접선 E 연속·법선 D 연속(자유 전하 없을 때) → 전기력선 굴절 tanθ₂/tanθ₁ = ε_r₂/ε_r₁. 축전기 유전체(세라믹 ε_r 수천), 전자레인지 가열(물의 유전 손실), 터치스크린, 절연 케이블 설계가 편극 이론이고, 탈분극(반자기) 인자는 자성체 모양 효과(랩 11)에도 같은 형태로 나타나 MRI 코일·영구자석 설계에 쓰입니다.

3. 모형과 실제

선형·등방·균일 유전체 가정입니다. 실제 물질은 강한 장에서 비선형(포화·절연 파괴 — 공기 3 MV/m), 결정은 방향에 따라 ε이 다르고(텐서), 강유전체(BaTiO₃)는 외부 장 없이도 자발 편극이 있어 히스테리시스를 보입니다. ε_r은 정전기(저주파) 값이며 주파수가 높아지면 분자가 따라 돌지 못해 ε_r이 떨어지고 손실(허수부)이 생깁니다(물: 정전 80, 마이크로파 손실 최대, 광학 1.8 = n²). 탈분극 인자 1/3은 구에만 해당하고 일반 타원체는 세 인자의 합이 1입니다.

σ_b = P·n̂, ρ_b = −∇·P  ·  균일 편극 구: E_in = −P/(3ε₀)  ·  P = ε₀χ_e E, ε_r = 1 + χ_e  ·  E_in = 3E₀/(ε_r + 2), p = 4πε₀R³E₀(ε_r − 1)/(ε_r + 2)  ·  D = ε₀E + P, ∇·D = ρ_f  ·  tanθ₂/tanθ₁ = ε_r₂/ε_r₁

실험 데이터 확인 탭 · 편극 구의 내부 장

예제

ε_r = 4인 유전체 구(R = 2 cm)를 E₀ = 1 000 V/m에 넣었다. 내부 장, 편극 P, 표면 속박 전하 최댓값은?

E_in = 3 × 1 000/6 = 500 V/m. P = ε₀χ_e E_in = 8.85 × 10⁻¹² × 3 × 500 = 1.33 × 10⁻⁸ C/m². σ_b,max = P(θ = 0) = 1.33 × 10⁻⁸ C/m². 검산: 탈분극장 P/(3ε₀) = 500 V/m = E₀ − E_in ✓.

진공에서 ε_r = 3 유전체로 전기력선이 입사각 30°(법선 기준)로 들어간다. 굴절각과, 법선 성분·접선 성분의 변화는?

tanθ₂ = 3 tan 30° = 1.732 → θ₂ = 60°(표면 쪽으로 눕는다). 접선 E 연속: E_t 같음. 법선 D 연속: E_n₂ = E_n₁/3 → 유전체 안 |E|가 줄어 선이 성겨집니다.
