벡터 퍼텐셜 — B = ∇×A와 자기 쌍극자

실험에서 전류 1 A 고리(원형 a = 1 cm, 넓이가 같은 정사각형)의 벡터 퍼텐셜 A를 720조각 선적분으로 구하고 B = ∇×A를 수치 미분해, 거리 r(2~12 cm)·측정 방향(축 위·적도면)·게이지를 바꿔 기록했습니다. 멀어질수록 B가 쌍극자 근사(1/r³)에 붙어 B/B쌍극자가 1에 가까워졌고, 12 cm에서는 원형과 정사각형의 B가 거의 같았으며, A + ∇λ로 바꾸면 |A|는 크게 달라져도 B는 그대로였습니다. 벡터 퍼텐셜, 게이지 자유도, 자기 다중극 전개를 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 고리 모양(원형/정사각형), 측정 방향(축 위 θ = 0°/적도면 θ = 90°), 거리 r(2~12 cm, 1 cm 간격), 게이지(쿨롱 게이지/A + ∇λ, λ = C(xy + xz), C = 5 × 10⁻⁵ T)를 고르고 A와 B 계산하기를 누르면 결과가 기록표에 자동으로 쌓입니다. 한 방향에서 거리를 네 가지 이상 바꾸고, 같은 점에서 게이지만 바꾼 기록도 남겨 4개 이상이 되면 데이터 검증 탭에서 log B–log r 기울기와 게이지 비교표가 열립니다. 모형: μ₀/4π = 10⁻⁷ T·m/A, m = I·πa² = 3.14 × 10⁻⁴ A·m², B는 간격 10 µm의 중앙 차분으로 계산.

개념 정리

1. 벡터 퍼텐셜 A

∇·B = 0이므로 B는 어떤 벡터장의 회전으로 쓸 수 있습니다: B = ∇×A. 쿨롱 게이지(∇·A = 0)에서 선전류의 퍼텐셜은 A(r) = (μ₀I/4π)∮dl′/|r − r′| — 전위 V = (1/4πε₀)∫ρ/𝓇 dτ′와 같은 꼴이라 전류 조각마다 그 방향으로 1/거리만큼 기여합니다. 그래서 원형 고리의 A는 고리와 같은 둘레 방향을 향하고, 축 위에서는 맞은편 조각들이 상쇄돼 0이 됩니다. A의 값이 0이어도 그 주변의 변화(회전)가 0이 아니면 B는 남습니다.

2. 게이지 자유도

임의의 스칼라 함수 λ에 대해 A′ = A + ∇λ로 바꿔도 ∇×∇λ = 0이라 B는 변하지 않습니다. 실험의 λ = C(xy + xz)는 ∇λ = C(y + z, x, x)를 더해 축 위 점 (0, 0, r)에서 A를 (Cr, 0, 0)만큼 바꾸지만 회전은 (0, 0, 0)입니다. 정전기의 V에 상수를 더해도 E가 같은 것과 같은 자유도이며, 계산이 편하도록 쿨롱 게이지(∇·A = 0)나 시간 변화가 있을 때의 로렌츠 게이지를 골라 씁니다.

3. 자기 다중극 전개

멀리서 1/|r − r′|를 전개하면 홀극 항은 ∮dl′ = 0이라 항상 0(자기 홀극 없음)이고 가장 낮은 항이 쌍극자입니다: m = I × 넓이, A_dip = (μ₀/4π)m × r̂/r², B_dip = (μ₀m/4πr³)(2cosθ r̂ + sinθ θ̂). 축 위는 μ₀m/2πr³, 적도면은 그 절반이고 1/r³로 줄어 log B–log r 기울기가 −3입니다. 모양과 상관없이 넓이(m)만 같으면 먼 곳 장이 같아집니다. 가까운 곳의 어긋남은 더 높은 차수의 다중극 항 때문이며, 원형 축 위 정확한 식 μ₀Ia²/2(a² + z²)^(3/2)으로 수치 계산을 확인할 수 있습니다.

축 위에서는 맞은편 조각의 A가 지워져 |A| = 0인데 B는 0이 아닙니다 — B는 A의 값이 아니라 회전입니다. 게이지를 A + ∇λ(λ = C(xy + xz), C = 5 × 10⁻⁵ T)로 바꾸면 |A|가 크게 변해도 B는 그대로입니다. r = 2 cm에서 축 0.716, 적도 1.379였던 비가 12 cm에서 1에 가까워지고, 두 실선 모두 기울기 −3(1/r³)인 점선에 붙습니다. 정사각형은 넓이(πa²)를 원과 같게 잡았습니다.

B = ∇×A, A(r) = (μ₀I/4π)∮dl′/|r − r′|  ·  A → A + ∇λ, ∇×∇λ = 0  ·  m = I·(넓이), B_dip = (μ₀m/4πr³)(2cosθ r̂ + sinθ θ̂)  ·  축 위 정확: B = μ₀Ia²/2(a² + z²)^(3/2)

a 1 cm, I 1 A, m 3.14 × 10⁻⁴ A·m² · 축 위 r = 3 cm: 1.987 µT(쌍극자 2.327 µT) · 멀리서 축 : 적도 = 2 : 1 · log B–log r 기울기 −3

예제

반지름 a = 1 cm, I = 1 A 원형 고리의 축 위 z = 3 cm에서 정확한 B와 쌍극자 근사 B를 구하고 비를 구하라.

정확한 식: B = μ₀Ia²/2(a² + z²)^(3/2) = (4π × 10⁻⁷ × 10⁻⁴)/(2 × (10⁻³)^(3/2)) = 1.2566 × 10⁻¹⁰/(6.325 × 10⁻⁵) = 1.987 × 10⁻⁶ T. 쌍극자: m = π × 10⁻⁴ A·m², B = μ₀m/2πz³ = 2 × 10⁻⁷ × 3.1416 × 10⁻⁴/(2.7 × 10⁻⁵) = 2.327 × 10⁻⁶ T. 비 = (z²/(a² + z²))^(3/2) = 0.9^(3/2) = 1.987 µT, 2.327 µT, 비 0.854 (실험 기록과 같음).

λ = C(xy + xz), C = 5 × 10⁻⁵ T로 게이지 변환할 때 축 위 점 (0, 0, 4 cm)에서 A의 변화량과 B의 변화량을 구하라.

∇λ = C(y + z, x, x) → (0, 0, 0.04)에서 (C × 0.04, 0, 0) = (2 × 10⁻⁶, 0, 0) T·m = 2000 × 10⁻⁹ T·m. 회전: (∂(x)/∂y − ∂(x)/∂z, ∂(y + z)/∂z − ∂(x)/∂x, ∂(x)/∂x − ∂(y + z)/∂y) = (0, 1 − 1, 1 − 1) = 0. |A|는 0 → 2000 × 10⁻⁹ T·m로 바뀌고 B 변화는 0 (896.40 nT 그대로).
