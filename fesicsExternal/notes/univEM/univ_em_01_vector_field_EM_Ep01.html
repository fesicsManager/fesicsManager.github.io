발산과 회전을 직접 재기 — 새어 나오는가, 도는가

실험에서 여러 2차원 벡터장 위에 작은 상자를 놓고 네 변의 유량과 순환을 수치 적분해 넓이로 나누어 발산·회전을 재고, 상자를 줄이며 해석값으로 수렴하는지 확인한 뒤 발산 정리와 스토크스 정리를 경계 적분 대 내부 격자 합으로 검증했습니다. F = (x, y)는 발산 2·회전 0, F = (−y, x)는 발산 0·회전 2, 직선 전단 흐름 F = (y, 0)은 회전 −1, 쌍곡선 흐름 F = (x, −y)는 둘 다 0이었고, 수치값의 오차는 상자 크기의 제곱에 비례해 줄었습니다. 두 연산자의 극한 정의, 두 적분 정리, 맥스웰 방정식과의 연결, 수치 계산의 한계를 정리합니다.

‘돈다’는 경로가 아니라 속도 차입니다 — 직선 전단 흐름에 띄운 작은 물레방아가 도는 것이 회전 ≠ 0의 뜻입니다. 특이점(점전하) 위에 상자를 놓으면 극한이 발산해 정리를 그대로 쓸 수 없습니다.

개념 정리

1. 발산과 회전의 극한 정의

벡터장의 발산 ∇·F는 한 점에서 ‘얼마나 새어 나오는가’(샘/싱크의 세기), 회전 ∇×F는 ‘얼마나 소용돌이치는가’를 나타냅니다. 정의는 극한입니다: 작은 상자를 놓고 발산 = (경계를 나가는 유량) ÷ 넓이, 회전 = (경계를 따라 도는 순환) ÷ 넓이, 상자 → 0. 데카르트 성분으로 쓰면 발산 = ∂F_x/∂x + ∂F_y/∂y(+ ∂F_z/∂z), 2차원 회전의 z 성분 = ∂F_y/∂x − ∂F_x/∂y — 실험이 상자를 줄이며 이 값으로 수렴함을 확인한 것입니다. 3차원 회전은 벡터이고, 스토크스 정리에서는 면의 법선 n̂을 정해 (∇×F)·n̂을 적분하며 경계를 도는 방향은 오른손 법칙으로 n̂과 맞춥니다. 기상도의 수렴(저기압, 상승)·발산(고기압)과 소용돌이도(태풍·토네이도)가 대기 벡터장의 발산·회전이고(지구시스템 실험 05), 유체 시뮬레이션은 비압축 조건 ∇·v = 0을 매 프레임 강제합니다(고전역학 시뮬 19의 위상공간 흐름도 발산 0).

∇·F (∇×F)_z 물레방아 각속도

네 장을 차례로 골라 상자를 옮겨 보세요. (y, 0)은 흐름이 곧은데도 위가 빨라 물레방아가 시계 방향으로 돕니다 — 회전 −1. 물레방아의 각속도는 회전의 절반(ω = (∇×F)_z ÷ 2)이고, 선형 장이라 상자를 어디에 두어도 값이 같습니다.

2. 두 적분 정리와 맥스웰 방정식

극한 정의를 유한한 영역으로 확장한 것이 발산 정리 ∮F·dA = ∫∇·F dV(경계 유량 = 내부 발산의 합)와 스토크스 정리 ∮F·dl = ∫(∇×F)·dA(경계 순환 = 내부 회전의 합)입니다 — 안쪽 격자들의 유량·순환을 더하면 이웃끼리 상쇄되고 바깥 경계만 남기 때문이며, 실험의 ‘경계 적분 vs 내부 격자 합’이 바로 이 상쇄를 보여 줍니다. 전자기학의 맥스웰 방정식은 이 두 연산자로 쓰입니다: ∇·E = ρ/ε₀(전하가 전기장의 샘 — 가우스 법칙, 랩 03), ∇·B = 0(자기 홀극 없음), ∇×E = −∂B/∂t(변하는 자기장이 전기장 소용돌이 — 패러데이), ∇×B = μ₀J + μ₀ε₀∂E/∂t(전류·변위 전류가 자기장 소용돌이 — 앙페르–맥스웰, 랩 10). 적분형과 미분형이 두 정리로 서로 바뀝니다.

그림으로 보기

발산 정리 — 안쪽 경계는 서로 지운다

맞닿은 변을 지나는 흐름(주황)은 한 상자에는 나가는 유량(+), 이웃 상자에는 들어오는 유량(−)으로 똑같이 세어져 더하면 0입니다. 그래서 내부 발산의 합 = 바깥 경계의 유량(발산 정리). 순환도 같은 방식으로 안쪽 변이 지워져 스토크스 정리가 됩니다.

3. 모형과 실제 — 수치 계산의 한계

2차원 단면이라 회전은 z 성분 하나만 봅니다. 상자를 무한히 줄일 수 없어 수치 발산·회전은 2차 오차(상자 크기²)를 가지며, 격자 간격 아래로는 줄일 수 없습니다. 특이점(점전하) 위에 상자를 놓으면 극한이 발산해 정리를 그대로 쓸 수 없고 델타 함수가 필요합니다(랩 02) — F = r̂/r²이 원점 밖 어디서나 발산 0인데 원점을 감싼 면의 유량은 4π인 역설이 그 출발점입니다.

∇·F = lim (∮F·n̂ dl) ÷ 넓이 = ∂F_x/∂x + ∂F_y/∂y  ·  (∇×F)_z = lim (∮F·t̂ dl) ÷ 넓이 = ∂F_y/∂x − ∂F_x/∂y  ·  ∮F·dA = ∫∇·F dV  ·  ∮F·dl = ∫(∇×F)·dA

(x, y): 2, 0 · (−y, x): 0, 2 · (y, 0): 0, −1 · (x, −y): 0, 0 · 수치 오차 ∝ h² · r̂/r² 유량 4π

🔬 과학 원리 탭

“F = (y, 0): 직선 흐름(전단)인데 회전 −1 — 위가 빠르고 아래가 느려 물레방아가 돌아요. ‘돈다’는 경로가 아니라 속도 차예요.”

실험 과학 원리 · 직관을 깨는 예

예제

F = (x² − y, xy)의 발산과 회전(z 성분)을 점 (1, 2)에서 구하시오.

∇·F = ∂(x² − y)/∂x + ∂(xy)/∂y = 2x + x = 3x → (1, 2)에서 3. (∇×F)_z = ∂(xy)/∂x − ∂(x² − y)/∂y = y + 1 → 3. 실험에서 (1, 2)에 작은 상자를 놓으면 두 값 모두 3으로 수렴합니다.

F = (−y, x)에 대해 반지름 R 원을 따라 순환을 직접 계산하고 스토크스 정리로 확인하시오.

원 위에서 F는 접선 방향 크기 R → ∮F·dl = R × 2πR = 2πR². 스토크스: 회전 2 × 넓이 πR² = 2πR² ✓. 실험의 회전 2가 넓이당 순환임을 보여 줍니다.
