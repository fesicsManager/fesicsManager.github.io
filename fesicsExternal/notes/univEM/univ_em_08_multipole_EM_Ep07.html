대학 전자기학 랩 08 · 다중극 전개

멀리서 보면 다 점전하 — 홀극·쌍극자·사중극

실험에서 여러 전하 배치의 총전하 Q, 쌍극자 모멘트 p, 사중극 텐서를 계산하고 차수별 전위 합을 정확한 쿨롱 합과 거리별로 비교해 상대 오차를 그렸으며, 원점을 옮길 때 모멘트가 어떻게 변하는지 보았습니다. Q ≠ 0인 배치는 l = 0만 켜도 먼 거리 오차가 1/r로 급감하고 l = 1을 더하면 1/r²으로 줄었지만, +q·−q 쌍은 l = 1을 켜야 비로소 맞았고 +q·−2q·+q 선형 사중극은 l = 2부터 맞았습니다. Q = 0이면 p가 원점과 무관해 그래프가 평평했고, Q ≠ 0이면 p′ = p − QΔ로 변했습니다. 전개의 구조, 각 항의 각 분포, 원점 의존성, 수렴 조건을 정리합니다.

개념 정리

1. 1/r 거듭제곱으로 펼치기

복잡한 전하 덩어리도 멀리서 보면 단순합니다. 전위 V = (1/4πε₀)Σq_i/|r − r_i|를 1/|r − r_i| = Σ_l (r_i^l/r^(l+1))P_l(cosα)로 전개하면 V(r) = (1/4πε₀)[Q/r + p·r̂/r² + (1/2r³)Σ_ij Q_ij r̂_i r̂_j + …]: 홀극(총전하 Q, 1/r), 쌍극자(p = Σq_i r_i, 1/r², 각 분포 cosθ), 사중극(Q_ij = Σq(3x_ix_j − r²δ_ij), 1/r³, 각 분포 3cos²θ − 1)… 차수가 높을수록 빨리 사그라지므로 먼 거리에서는 0이 아닌 가장 낮은 차수 항이 지배합니다. 총전하가 0이 아니면 점전하처럼 보이고, Q = 0이면(쌍극자, 중성 분자) 쌍극자 항이, p도 0이면(선형 사중극) 사중극 항이 주도합니다. 각 항은 르장드르 다항식 P_l(cosθ)의 각 분포를 가지며(랩 07의 구면 급수와 같은 함수), 실험의 상대 오차 그래프에서 l = 0만 켜면 오차가 1/r로, l = 1을 더하면 1/r²으로 줄어드는 것이 다음 항의 크기입니다.

2. 원점 의존성과 물리적 의미

원점을 Δ만큼 옮기면 p′ = Σq(r_i − Δ) = p − QΔ이므로 Q ≠ 0이면 p가 원점에 따라 변하고(p = 0이 되는 원점 = 전하 중심), Q = 0이면 p는 원점과 무관합니다 — 실험에서 +q·−q 쌍의 그래프가 평평한 이유이고, 같은 논리로 Q = p = 0이면 사중극이 원점 무관입니다. 그래서 중성 분자의 쌍극자 모멘트(물 1.85 D = 6.2 × 10⁻³⁰ C·m)는 잘 정의된 물리량이고 수소 결합·용매 성질·전자레인지 가열을 정하며, CO₂는 대칭이라 p = 0·사중극 ≠ 0이어서 적외선 흡수 방식이 다릅니다(고전역학 시뮬 15의 CO₂ 모드). 안테나 복사(쌍극자 안테나), 지구 자기장(주로 쌍극자 + 사중극 보정), 핵의 전기 사중극 모멘트(핵 모양) 분석에 다중극 전개를 쓰고, 랩 09의 편극 구 바깥 장이 순수 쌍극자장인 것도 같은 전개입니다.

3. 모형과 실제 — 수렴 조건

전개는 전하 분포 바깥(r > 분포 크기)에서만 수렴합니다. 분포 안이나 경계 근처에서는 항을 아무리 더해도 맞지 않으며(실험에서 가까운 거리의 오차가 줄지 않는 이유), 분포 안쪽은 r^l 항의 내부 전개를 따로 씁니다. 실제 분자의 쌍극자 모멘트는 전자 구름의 연속 분포로 정의되고(양자 계산), 외부 장에 따라 유도 쌍극자(편극, 랩 09)가 추가되며, 여기서는 고정 점전하만 다뤘습니다. 쌍극자 항이 정확히 1/r²인 것은 이상적 점 쌍극자(d → 0, qd 일정)의 극한이고 유한 d에서는 사중극 이상의 보정이 붙습니다.

V = (1/4πε₀)[Q/r + p·r̂/r² + (1/2r³)Σ Q_ij r̂_i r̂_j + …]  ·  Q = Σq, p = Σq r_i, Q_ij = Σq(3x_ix_j − r²δ_ij)  ·  원점 이동: p′ = p − QΔ  ·  쌍극자 V = p cosθ/(4πε₀r²), 사중극 ∝ (3cos²θ − 1)/r³

Q ≠ 0: l = 0 오차 ∝ 1/r · +q−q: l = 1부터, θ = 0 최대·90° 0 · +q−2q+q: l = 2부터 · 물 p 1.85 D · 수렴: r > 분포 크기

🔬 실험 피드백

“Q = 0이므로 p는 원점 선택과 무관합니다. 그래프가 평평합니다.” “Q ≠ 0이므로 원점을 옮기면 p가 −QΔ만큼 달라집니다. p = 0이 되는 원점도 존재합니다.”

실험 데이터 확인 탭 · 배치와 원점

예제

+2q가 (0, 0, a), −q가 (0, 0, −a)에 있다. Q, p와 먼 거리 z축 위 전위의 처음 두 항은? p가 0이 되는 원점은?

Q = q, p = 2q·a − q·(−a) = 3qa ẑ. z축(θ = 0) 먼 곳: V ≈ (1/4πε₀)[q/z + 3qa/z²]. p = 0인 원점: p′ = p − QΔ = 0 → Δ = 3a → z = 3a(전하 중심, +2q 위쪽).

+q, −2q, +q가 z = a, 0, −a에 있는 선형 사중극의 Q_zz와 z축 먼 곳 전위는?

Q = 0, p = qa − qa = 0. Q_zz = Σq(3z² − r²) = q(2a²) + 0 + q(2a²) = 4qa². z축(θ = 0)에서 V ≈ (1/4πε₀) Q_zz/(2r³) = 2qa²/(4πε₀r³). 직접 계산 q/(r − a) − 2q/r + q/(r + a) ≈ 2qa²/r³ ✓.
