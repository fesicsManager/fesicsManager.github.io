실험에서 얻은 것

실험 데이터 되짚기

분열 주기와 배양 시간을 바꿔 가며 세포 수를 기록하면 이렇습니다 (세포 1개에서 시작, 모두 동시에 분열 가정).

표 1. 주기·시간과 세포 수 (데이터 확인 탭의 표와 같은 값)
주기 / 시간20분 / 60분20분 / 120분40분 / 120분30분 / 180분
분열 횟수 n3636
세포 수 2ⁿ864864

계산은 언제나 두 단계: ① 분열 횟수 = 경과 시간 ÷ 분열 주기, ② 세포 수 = 2횟수. 같은 120분이라도 주기가 40분이면 8개, 절반인 20분이면 64개 — 횟수가 2배면 세포 수는 2배가 아니라 제곱이 됩니다.

개념 정리

1. 세포 주기와 지수적 증가

세포가 한 번 분열하고 다음 분열까지 걸리는 시간이 세포 주기(분열 주기)입니다. 주기마다 1개가 2개가 되므로 세포 수는 2n으로 지수적으로 늘어납니다. 횟수가 1만 늘어도 세포 수는 두 배가 되므로 시간이 지날수록 차이가 걷잡을 수 없이 커집니다. 세포 주기는 간기(G1 → S(DNA 복제) → G2)와 분열기(M)로 이루어지고, 검문 지점에서 이상이 있으면 멈춥니다. 이 조절이 망가진 것이 암입니다.

2. 세포마다 주기가 다르다

세포분열 주기
대장균 (37 ℃, 영양 풍부)약 20분
장 상피·피부 세포하루~며칠
간세포평소엔 거의 안 하다 다치면 분열
신경·심장 근육 세포거의 분열하지 않음

그래서 피부 상처는 며칠이면 아물지만 신경 손상은 회복이 매우 느립니다. 식중독균이 여름철 몇 시간 만에 위험 수준까지 늘어나는 것이 지수적 증가이고, 냉장 보관은 주기를 크게 늘려 증식을 늦춥니다.

3. 2ⁿ은 어디까지 맞을까

20분 주기라면 하루(1440분)에 72번 분열 → 272개는 지구 부피를 넘는 수라 당연히 불가능합니다. 배양 접시에는 영양분과 공간이 정해져 있어, 세포가 많아질수록 영양분이 떨어지고 노폐물이 쌓여 분열이 느려지다 멈춥니다. 실제 세포 수 그래프는 지연기 → 대수기(가파르게 치솟음) → 정지기(평평) → 사멸기의 S자 모양이고, 2ⁿ 계산은 영양분과 공간이 충분한 대수기에서만 맞습니다. 우리 몸에서도 이 제한을 무시하고 계속 분열하는 상태가 암입니다.

n = 시간 ÷ 주기   ·   세포 수 = 2n

예: 30분 주기 3시간 → n = 6 → 2⁶ = 64개 (대수기에서만 성립)

제로

“60 ÷ 20 = 3번이요!” … “1개 → 2개 → 4개 → 8개! 2를 3번 곱한 거니까 2³ = 8개네요!” … “120 ÷ 20 = 6번 분열이니까, 2⁶ = 64개요!”

심화 6화 · 뭉치: “(삐빅) 힌트 제공. 분열할 때마다 세포 수는 2배가 됩니다.”

닥터
이안

“모든 세포가 이렇게 빨리 분열하는 건 아니야. 피부세포처럼 자주 분열하는 세포도 있고, 신경세포처럼 거의 분열하지 않는 세포도 있어.”

심화 6화 · “이 분열 속도의 차이가 바로 왜 어떤 상처는 금방 낫고, 신경 손상은 회복이 느린지를 설명해줘.”

예제

30분마다 분열하는 세포 1개를 3시간(180분) 배양하면 세포는 몇 개가 될까?

① n = 180 ÷ 30 = 6번 ② 26 = 64개. 4시간이면 n = 8, 28 = 256개.

같은 2시간(120분) 동안 주기가 40분인 세포는 8개가 된다. 주기가 절반인 20분짜리 세포는 몇 개가 될까?

40분: n = 3 → 8개. 20분: n = 6 → 26 = 64개. 주기가 절반이면 세포 수는 2배(16개)가 아니라 8의 제곱인 64개입니다. 주기를 조금만 줄여도 결과가 훨씬 크게 달라지는 이유입니다.

확인 문제

1번· 관찰 확인

실험에서 같은 배양 시간에 분열 주기를 절반으로 줄이면 세포 수는?

분열 횟수 n이 2배가 되면 세포 수는 2ⁿ에서 2²ⁿ = (2ⁿ)²으로 제곱이 됩니다. 40분 주기 8개 → 20분 주기 64개.

2번· 핵심 개념

피부에 난 상처는 며칠이면 아무는데, 신경이 손상되면 회복이 아주 느립니다. 가장 큰 이유는?

피부 세포는 하루~며칠 주기로 자주 분열하지만 신경세포는 거의 분열하지 않습니다. 분열 주기의 차이가 회복 속도의 차이입니다.

3번· 적용

20분마다 분열하는 세포 1개를 100분 배양하면 세포는 몇 개가 될까요?

① n = 100 ÷ 20 = 5 ② 2⁵ = 32개.
