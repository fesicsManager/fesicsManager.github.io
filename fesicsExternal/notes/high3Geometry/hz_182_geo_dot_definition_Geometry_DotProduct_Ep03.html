고등학교 기하 · 실험 「내적 실험실」

내적의 정의 — 두 벡터를 곱했더니 수가 나온다

두 벡터 a, b의 성분을 바꾸며 성분 곱의 합 a₁b₁ + a₂b₂와 |a||b|cos θ를 각각 계산하고 각 θ를 기록했습니다. 두 방법은 언제나 같은 수를 주었고, 그 값은 예각이면 양수, 직각이면 0, 둔각이면 음수였습니다. 내적의 두 가지 정의를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 a의 x, y와 b의 x, y(−5~6)를 정하고 ‘두 방법으로 계산’을 누르면 성분 곱의 합, |a||b|cos θ, 각 θ가 기록됩니다. 4개 이상 기록하면 분석이 열리니 예각·직각·둔각이 모두 나오게 바꿔 보세요.

내적 a·b = a₁b₁ + a₂b₂ = |a||b|cos θ는 벡터가 아니라 수(스칼라)입니다. 두 정의는 코사인법칙 |a − b|² = |a|² + |b|² − 2|a||b|cos θ를 성분으로 전개하면 이어집니다. 내적은 두 벡터가 얼마나 같은 방향을 향하는지를 재는 양이며, 영벡터가 있으면 각은 정의되지 않지만 내적은 0입니다.

개념 정리

1. 내적의 결과는 벡터가 아니라 “수” — 두 계산법이 같은 값을 준다

a·b = a₁b₁ + a₂b₂ 는 수입니다. 벡터끼리 곱했는데 벡터가 아니라 수가 나와요. 이 값은 |a||b|cos θ 와 같고, 두 벡터가 얼마나 같은 방향을 향하는지를 재는 양입니다.

왜 그럴까

  • 성분 정의와 기하적 정의가 코사인법칙으로 연결됩니다.
  • 내적이 크면 같은 방향, 0 이면 수직, 음수면 둔각.
  • 결과가 수(스칼라)라서 “스칼라곱”이라고도 합니다.

2. 자주 하는 오해 바로잡기

· “벡터끼리 곱하면 벡터가 나온다” → 내적은 수를 줍니다.

3. 생활 속에서 · 이어지는 개념

  • 힘과 이동의 내적이 “일”이라는 스칼라 양이 됩니다.
두 벡터를 바꿔 성분 곱의 합과 |a||b|cos θ 를 각각 계산해 비교 — θ는 내적을 쓰지 않고 두 벡터의 방향각 차이(좌표로 잰 각)로 따로 구함
📋 데이터 확인 탭의 결론

“모든 기록에서 두 방법의 값이 같았습니다. 성분 정의와 기하적 정의가 코사인법칙으로 연결됩니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

a = (2, −1), b = (3, 4)일 때 a·b는?

2 × 3 + (−1) × 4 = 6 − 4 = 2

|a| = 2, |b| = 3이고 두 벡터가 이루는 각이 60°일 때 a·b와 |a + b|는?

a·b = 2 × 3 × 1/2 = 3. |a + b|² = |a|² + 2a·b + |b|² = 4 + 6 + 9 = 19. a·b = 3, |a + b| = √19

확인 문제

1번· 관찰 확인

실험에서 a = (4, 2), b = (1, 3)일 때 두 방법으로 구한 값은?

4 × 1 + 2 × 3 = 10 = √20 × √10 × cos 45°.
