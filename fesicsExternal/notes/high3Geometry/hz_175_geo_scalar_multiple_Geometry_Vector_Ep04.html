벡터의 실수배 — 크기는 |k|배, 방향은 k의 부호가 정한다

a = (3, 2)에 실수 k(0.25 간격, −3~3)를 곱해 ka의 성분과 크기를 재고 |k| × |a|와 비교했습니다. 크기는 k가 음수여도 언제나 |k| × |a|로 0 이상이었고, k < 0이면 화살표가 정반대로 뒤집혔으며 k = 0이면 영벡터가 되었습니다. 실수배의 크기와 방향을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 실수 k 슬라이더(0.25 간격, −3~3)를 정하고 ‘실수배 해 보기’를 누르면 ka, 크기, |k| × |a|, 방향이 기록됩니다. 4개 이상 기록하면 분석이 열리니 음수 k도 꼭 넣어 보세요.

ka의 크기는 |k| × |a|로, 길이이므로 음수가 될 수 없습니다. k의 부호는 방향만 정해 k > 0이면 같은 방향, k < 0이면 반대 방향입니다. ka는 언제나 a와 같은 직선 위에 있어 평행의 정의로 이어지고, k = 0이면 방향이 정해지지 않는 영벡터가 됩니다.

개념 정리

1. 크기는 |k| 배, 방향은 k 의 부호가 정한다 — 크기는 음수가 되지 않는다

ka 의 크기는 |k| × |a| 예요. k 가 음수여도 크기는 양수이고, 대신 방향이 반대가 됩니다. “크기가 음수가 된다”가 아니라 “반대 방향으로 |k| 배”입니다.

왜 그럴까

  • 크기는 길이라서 0 이상입니다.
  • k < 0 이면 성분의 부호가 모두 바뀌어 화살표가 뒤집힙니다.
  • k = 0 이면 영벡터가 되어 방향이 정해지지 않습니다.

움직여 보기

실수배 ka — 크기는 |k| 배, 방향은 k 의 부호

ka |ka| |k| × |a| 방향

k 를 움직여 보세요. k 가 음수가 되면 보라 화살표 ka 가 반대로 뒤집히지만, 길이(크기)는 언제나 |k| × |a| 로 0 이상입니다. k = 0 이면 영벡터(점)입니다. 처음 값은 표 1 의 a = (3, 2), k = 2.

2. 자주 하는 오해 바로잡기

· “음수배는 크기를 음수로 만든다” → 방향이 뒤집힐 뿐입니다.

3. 생활 속에서 · 이어지는 개념

  • 반대 방향으로 두 배 빠르게 가는 것을 −2배로 표현합니다.

“크기가 언제나 |k| × |a| 와 같았습니다.”

예제

a = (−2, 6)일 때 −(1/2)a의 성분과 크기는?

−(1/2)a = (1, −3), 크기 = √(1 + 9) = √10 (= (1/2) × |a| = (1/2) × 2√10). (1, −3), √10

|a| = 4인 벡터 a와 방향이 반대이고 크기가 6인 벡터를 a로 나타내시오.

크기 6 = |k| × 4 → |k| = 3/2, 반대 방향이므로 k < 0. −(3/2)a
