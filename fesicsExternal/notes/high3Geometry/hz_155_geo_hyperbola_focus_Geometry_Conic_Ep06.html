쌍곡선의 초점 — 이번엔 c² = a² + b²

쌍곡선의 a, b를 바꾸며 a² + b², a² − b², 실제 c²를 기록했습니다. 실제 c²는 언제나 a² + b²였고, a² − b²는 음수가 되기도 했으며, 두 초점까지 거리의 차는 늘 2a였습니다. 타원과 부호가 반대인 쌍곡선의 초점 공식을 정리합니다.

쌍곡선에서는 실제 c²가 늘 a² + b²였습니다. a = 3, b = 4이면 c = 5이고, 곡선 위 점에서 두 초점까지 거리의 차는 6 = 2a였습니다. 그래서 c > a, 곧 초점이 꼭짓점보다 바깥에 있습니다. a² − b²로 구하면 −7처럼 음수가 되어 c를 구할 수조차 없습니다. 정리하면 타원은 합·빼기, 쌍곡선은 차·더하기입니다.

개념 정리

1. 쌍곡선은 c² = a² + b² — 타원과 부호가 반대

쌍곡선 위의 점에서 두 초점까지 거리의 차가 2a 예요. 여기서는 c² = a² + b² 이라 c > a — 초점이 꼭짓점보다 바깥에 있습니다. 타원은 합이고 빼기, 쌍곡선은 차이고 더하기 — 서로 반대입니다.

왜 그럴까

  • 타원: 거리의 합 = 2a, c² = a² − b².
  • 쌍곡선: 거리의 차 = 2a, c² = a² + b².
  • b 는 점근선의 기울기 ±b/a 를 정합니다.

움직여 보기

쌍곡선의 초점 c² = a² + b² — 상자의 대각선

가로 a, 세로 b 인 주황 상자의 대각선 길이가 √(a² + b²) = c 입니다. 그 길이를 반지름으로 원(보라 점선)을 그리면 x 축과 만나는 곳이 초점이라, c > a — 초점이 꼭짓점보다 바깥에 있습니다. 재생하면 P 가 움직여도 PF₁ − PF₂ = 2a 로 일정합니다(P 는 오른쪽 가지 위).

2. 자주 하는 오해 바로잡기

· “타원과 쌍곡선은 초점 공식이 같다” → 부호가 반대입니다.

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

쌍곡선 x²/16 − y²/9 = 1의 초점을 구하시오.

c² = a² + b² = 16 + 9 = 25, c = 5. 초점 (5, 0), (−5, 0)

두 초점이 (±5, 0)이고, 곡선 위 점에서 두 초점까지 거리의 차가 6인 쌍곡선의 방정식을 구하시오.

2a = 6 → a = 3, c = 5이므로 b² = c² − a² = 25 − 9 = 16. x²/9 − y²/16 = 1
