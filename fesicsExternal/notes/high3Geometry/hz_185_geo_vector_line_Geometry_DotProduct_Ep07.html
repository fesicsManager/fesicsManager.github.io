고등학교 기하 · 실험 「방향벡터 실험실」

직선의 벡터방정식 — P = A + t·d

점 A(1, −2)를 지나고 방향벡터가 d = (d₁, d₂)인 직선에서 매개변수 t(0.25 간격)와 d를 바꾸며 점 P = A + t·d를 만들고, 일반형 d₂x − d₁y = d₂ + 2d₁에 대입해 보았습니다. t를 어떻게 바꾸든 P는 모두 직선 위에 있었고, d의 x성분이 0이면 y = mx + n으로 쓸 수 없는 세로선이 되었습니다. 벡터로 직선을 나타내는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 매개변수 t(0.25 간격, −3~3)와 방향벡터의 x(−4~5), y(−4~5)를 정하고 ‘매개변수를 움직이기’를 누르면 t, 점의 좌표, 일반형 대입 결과, 직선 위 여부, 방향벡터가 기록됩니다. 4개 이상 기록하면 분석이 열리니 x성분이 0인 방향벡터도 넣어 보세요.

표 1. A(1, −2)를 지나는 직선 위의 점 (실험 예시)
방향벡터t점의 좌표일반형일반형에 대입직선 위인가
(2, 3)1(3, 1)3x − 2y = 77✅
(2, 3)−1(−1, −5)3x − 2y = 77✅
(0, 2)0.5(1, −1)2x = 2 (세로선)2✅
(0, 2)2(1, 2)2x = 2 (세로선)2✅
(1, −1)−2(−1, 0)−x − y = 11✅

점 A를 지나고 방향벡터가 d인 직선은 p = a + t·d(t는 실수)이며, 성분으로 쓰면 x = x₁ + td₁, y = y₁ + td₂입니다. t를 소거하면 d₂(x − x₁) − d₁(y − y₁) = 0이 되어 (d₂, −d₁)이 법선벡터인 일반형이 나옵니다. d₁ = 0이면 기울기는 없지만 세로선 x = x₁을 문제없이 나타냅니다. 공간의 직선도 좌표 하나만 늘어난 같은 식입니다.

개념 정리

1. 직선 = 한 점 + t × 방향벡터 — 기울기가 없는 직선도 나타낼 수 있다

점 A 를 지나고 방향벡터 d 인 직선은 P = A + t·d 로 씁니다. t 를 움직이면 직선 위의 모든 점이 나와요. 방향벡터의 x성분이 0 이어도 되므로 세로선도 문제없이 나타냅니다.

왜 그럴까

  • y = mx + n 은 세로선을 나타내지 못합니다.
  • 방향벡터 (0, 1) 이면 세로선이 됩니다.
  • 공간의 직선도 같은 방식으로 쓸 수 있습니다 — 좌표만 하나 늘어납니다.

2. 자주 하는 오해 바로잡기

· “직선에 벡터를 쓸 이유가 없다” → 세로선과 공간의 직선에서 꼭 필요합니다.

3. 생활 속에서 · 이어지는 개념

  • 물체가 등속으로 움직일 때의 위치가 정확히 이 식입니다.
t와 방향벡터를 바꿔 점을 만들고, 그 점이 직선의 일반형을 만족하는지 확인

예제

점 (2, −1)을 지나고 방향벡터가 (3, 4)인 직선의 방정식을 일반형으로 쓰시오.

(x − 2)/3 = (y + 1)/4 → 4x − 8 = 3y + 3 → 4x − 3y − 11 = 0

두 점 A(1, 2), B(4, −1)을 지나는 직선의 벡터방정식을 쓰고, t = 2일 때의 점을 구하시오.

방향벡터 AB = (3, −3). p = (1, 2) + t(3, −3). t = 2 → (7, −4). p = (1, 2) + t(3, −3), (7, −4)
