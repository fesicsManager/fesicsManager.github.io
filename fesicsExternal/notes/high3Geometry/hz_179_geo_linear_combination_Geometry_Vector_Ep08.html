벡터의 일차결합 — 평행하지 않은 두 벡터면 평면 전체

a = (2, 1)과 b(평행하지 않은 (1, 2) 또는 평행한 (4, 2))를 고르고 계수 s, t(0.25 간격)를 바꾸며 sa + tb가 도달한 점을 기록했습니다. 평행하지 않은 기준에서는 s, t를 바꿀 때마다 평면 여러 곳에 도달했지만, 평행한 기준에서는 어떤 s, t로도 직선 x = 2y 위를 벗어나지 못했습니다. 평면벡터의 일차결합을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 s, t 슬라이더(0.25 간격, −2~2)와 기준 벡터(평행하지 않음·평행)를 고르고 ‘목표점에 도달하기’를 누르면 sa + tb와 도달 범위가 기록됩니다. 4개 이상 기록하면 분석이 열리니 두 기준을 모두 기록해 비교해 보세요.

표 1. sa + tb가 도달한 점 (실험 예시, a = (2, 1))
기준 벡터 bstsa + tb두 벡터가 평행이면
(1, 2) 평행하지 않음11(3, 3)평면 전체
(1, 2) 평행하지 않음1−1(1, −1)평면 전체
(1, 2) 평행하지 않음0.51.5(2.5, 3.5)평면 전체

(4, 2) 평행−12(6, 3)직선뿐 (x = 2y)

a와 b가 영벡터가 아니고 평행하지 않으면 평면 위 모든 벡터 p를 p = sa + tb 꼴로 단 한 가지 방법으로 나타낼 수 있습니다. 평면은 이차원이라 독립적인 방향이 두 개 필요하기 때문입니다. 반대로 a ∥ b이면 방향이 하나뿐이라 sa + tb는 한 직선 위에만 놓이고, 서로 다른 (s, t)가 같은 점을 만들기도 합니다(표의 (1, 1)과 (−1, 2)).

개념 정리

1. 평행하지 않은 두 벡터의 일차결합으로 평면의 모든 점에 도달할 수 있다

a 와 b 가 평행하지 않으면 sa + tb 로 평면 위 어떤 점이든 만들 수 있어요. 반대로 두 벡터가 평행하면 아무리 조합해도 한 직선 위만 벗어나지 못합니다.

왜 그럴까

  • 평면은 이차원이라 독립적인 방향이 두 개 필요합니다.
  • 평행한 두 벡터는 방향이 하나뿐이라 직선만 만듭니다.
  • 세 점이 일직선 위에 있을 조건도 이 아이디어에서 나옵니다.

움직여 보기

일차결합 sa + tb 로 평면 어디든

sa + tb a, b 평행? 갈 수 있는 곳

s, t 를 바꾸면 보라 점 sa + tb 가 빨강(a 방향)·파랑(b 방향) 격자를 따라 평면 어디든 갑니다. a = (2, 1) 로 고정했습니다. b 를 (4, 2) 처럼 a 와 평행하게 만들면 격자가 한 직선(x = 2y)으로 접혀 그 밖으로는 갈 수 없습니다. 처음 값은 예제 1: (4, 5) = a + 2b.

2. 자주 하는 오해 바로잡기

· “두 벡터로는 평면을 다 만들 수 없다” → 평행만 아니면 충분합니다.

3. 생활 속에서 · 이어지는 개념

  • 두 방향의 이동만으로 격자 위 어디든 갈 수 있는 것과 같습니다.
s, t 를 바꿔 sa + tb 가 어디에 도달하는지 보고, 두 벡터가 평행할 때와 비교

예제

a = (2, 1), b = (1, 2)일 때 p = (4, 5)를 sa + tb로 나타내시오.

2s + t = 4, s + 2t = 5를 풀면 s = 1, t = 2. p = a + 2b

평행하지 않은 두 벡터 a, b(영벡터 아님)에 대해 (x − 1)a + (y + 2)b = 3a − b일 때 x, y는?

표현이 한 가지뿐이므로 계수 비교: x − 1 = 3, y + 2 = −1 → x = 4, y = −3
