좌표공간 — 점은 세 수 (x, y, z)로 정해진다

세 좌표 x, y, z(0.5 간격, −3~3)를 바꿔 가며 점을 찍고 그 점이 원점·좌표축·좌표평면·일반 위치 중 어디에 있는지 기록했습니다. 0인 좌표가 1개면 좌표평면 위, 2개면 좌표축 위, 3개면 원점이었고, z = 0인 점도 빠짐없이 공간의 점이었습니다. 좌표공간의 점과 좌표평면·좌표축의 관계를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 x, y, z 슬라이더(0.5 간격, −3~3)로 점을 정하고 ‘점을 찍어 보기’를 누르면 점의 좌표와 ‘어디에 있나’가 기록표에 한 줄씩 쌓입니다. 4개 이상 기록하면 데이터 검증 탭의 분석이 열리니, 0인 좌표의 개수가 서로 다른 점을 골고루 찍어 보세요.

표 1. 점의 좌표와 위치 (실험 예시)

(2, 1, 0)1개xy평면 위√5 ≈ 2.2361✅
(0, 0, 1.5)2개z축 위1.5✅
(1.5, 0, −1)1개zx평면 위√3.25 ≈ 1.8028✅

0인 좌표의 개수가 위치를 알려 줍니다: 0개 → 일반 위치, 1개 → 좌표평면 위(z = 0이면 xy평면, y = 0이면 zx평면, x = 0이면 yz평면), 2개 → 좌표축 위, 3개 → 원점. z = 0인 점은 xy평면 위에 있는 공간의 점이지 공간 밖의 점이 아닙니다. 좌표평면은 좌표공간 안에 들어 있으므로 원점까지의 거리도 평면의 공식이 √(x² + y² + z²)로 자연스럽게 이어집니다.

개념 정리

1. 좌표공간의 점은 (x, y, z) 세 수로 정해진다 — z = 0 도 공간의 점

z = 0 인 점은 xy평면 위에 있는 공간의 점이에요. 평면에서 y = 0 인 점이 x축 위의 점이지 “평면 밖”이 아닌 것과 같습니다. 세 좌표 중 하나가 0 이면 그 좌표에 해당하는 평면 위에 있다는 뜻입니다.

왜 그럴까

  • 좌표평면 = z = 0 인 점들의 모임, 좌표공간에 포함됩니다.
  • 좌표가 두 개 0 이면 축 위의 점입니다.
  • 세 개 모두 0 이면 원점입니다.

움직여 보기

세 수 (x, y, z) 로 점 찍기 — 0 이 있으면 어디에 놓일까?

P 놓인 곳 OP = xy평면 위 수선의 발 H

x, y, z 를 하나씩 0 으로 만들어 보세요. 0 이 하나면 좌표평면 위, 둘이면 축 위, 셋이면 원점입니다. z = 0 인 점도 공간의 점이에요. 처음 값 (3, 0, −2) 는 예제 1 의 점입니다. 주황 점선 상자의 모서리가 각 좌표의 길이입니다.

2. 자주 하는 오해 바로잡기

· “z좌표가 0 이면 공간의 점이 아니다” → xy평면 위의 공간의 점입니다.

예제

점 P(3, 0, −2)는 어느 좌표평면 위에 있는가? 또 원점까지의 거리는?

y = 0이므로 zx평면 위. OP = √(9 + 0 + 4) = √13.

점 P(2, −1, 4)에서 xy평면에 내린 수선의 발 H와 z축에 내린 수선의 발 K의 좌표를 구하시오.

xy평면으로는 z만 0으로 → H(2, −1, 0). z축으로는 x, y를 0으로 → K(0, 0, 4). H(2, −1, 0), K(0, 0, 4)
