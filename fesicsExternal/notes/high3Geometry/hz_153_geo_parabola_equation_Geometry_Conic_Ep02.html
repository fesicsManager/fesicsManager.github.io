누운 포물선 y² = 4px — 초점과 준선에서 같은 거리

p와 확인할 점의 y 좌표를 바꾸며 초점 (p, 0)과 준선 x = −p까지의 거리를 기록했습니다. 어느 점에서나 두 거리가 똑같았고, p > 0이면 오른쪽, p < 0이면 왼쪽으로 열렸습니다. 옆으로 열린 포물선의 방정식과 초점·준선을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 p(×0.25)와 확인할 점의 y(×0.5) 슬라이더를 정한 뒤 ‘조건을 만족하는 점 찍기’ 버튼을 누르면 그림이 움직인 다음 한 줄이 표에 자동으로 기록됩니다. 조건을 바꿔 가며 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다. p = 0은 포물선이 아니어서 실험이 0.25로 바꿔 씁니다.

표 1. p와 점에 따른 두 거리 (실험 예시)
p초점준선점초점까지준선까지
1(1, 0)x = −1(1, 2)22
1(1, 0)x = −1(4, 4)55
2(2, 0)x = −2(2, 4)44
−1(−1, 0)x = 1(−1, 2)22
0.5(0.5, 0)x = −0.5(4.5, 3)55

모든 행에서 초점까지와 준선까지의 거리가 같습니다. 이것이 포물선의 정의입니다. 점 (x, y)에서 두 거리를 같게 놓으면 (x − p)² + y² = (x + p)²이고, 정리하면 y² = 4px가 됩니다. 제곱이 붙은 문자가 y이므로 x축이 축이 되어 좌우로 열리고, p > 0이면 오른쪽, p < 0이면 왼쪽입니다. |p|가 클수록 초점이 멀어지고 곡선이 넓게 벌어집니다.

개념 정리

1. 포물선은 “초점과 준선에서 같은 거리” — 열리는 방향은 축이 정한다

y² = 4px 는 초점 (p, 0), 준선 x = −p 인 포물선이에요. x 축을 축으로 좌우로 열립니다. p > 0 이면 오른쪽, p < 0 이면 왼쪽입니다. y = ax² 만 포물선이라고 생각하면 절반만 아는 것입니다.

왜 그럴까

  • 제곱이 붙은 문자가 무엇인지가 축을 정합니다.
  • y² = 4px → x축이 축, x² = 4py → y축이 축.
  • |p| 가 클수록 초점이 멀어지고 곡선이 넓게 벌어집니다.

2. 자주 하는 오해 바로잡기

· “포물선은 위아래로만 열린다” → 좌우로 열리는 것도 포물선입니다.

3. 생활 속에서 · 이어지는 개념

  • 자동차 헤드라이트 반사경의 단면이 옆으로 누운 포물선입니다.
p를 바꿔 초점·준선을 옮기고, 곡선 위 점에서 두 거리를 재어 같은지 확인
📋 데이터 확인 탭의 결론

“모든 기록에서 초점까지와 준선까지의 거리가 같았습니다. 이것이 포물선의 정의입니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

포물선 y² = 12x의 초점과 준선을 구하시오.

4p = 12에서 p = 3입니다. 초점은 (p, 0), 준선은 x = −p이므로 초점 (3, 0), 준선 x = −3

초점이 (−2, 0), 준선이 x = 2인 포물선의 방정식을 구하시오.

초점 (p, 0), 준선 x = −p에서 p = −2이므로 y² = 4·(−2)·x, 곧 y² = −8x. 점 (−2, 4)로 검산하면 초점까지 4, 준선까지 |−2 − 2| = 4로 같습니다.
