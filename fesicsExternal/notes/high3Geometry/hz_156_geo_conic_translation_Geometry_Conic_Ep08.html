이차곡선의 평행이동 — 식이 복잡해도 같은 곡선

타원 x²/4 + y²/9 = 1을 (p, q)만큼 옮기며 전개한 식과 완전제곱으로 정리한 식, 중심을 기록했습니다. 옮길수록 x, y의 일차항이 생겨 식은 복잡해졌지만 모양은 언제나 같은 타원이었습니다. 평행이동과 완전제곱 정리로 중심·초점을 찾는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 x 방향 이동 p와 y 방향 이동 q 슬라이더를 정한 뒤 ‘옮기고 정리하기’ 버튼을 누르면 그림이 움직인 다음 한 줄이 표에 자동으로 기록됩니다. 조건을 바꿔 가며 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

표 1. x²/4 + y²/9 = 1의 평행이동 (실험 예시)
이동 (p, q)전개한 식완전제곱 정리중심모양
(0, 0)9x² + 4y² − 36 = 0x²/4 + y²/9 = 1(0, 0)타원 (그대로)
(2, 1)9x² + 4y² − 36x − 8y + 4 = 0(x − 2)²/4 + (y − 1)²/9 = 1(2, 1)타원 (그대로)
(−1, 2)9x² + 4y² + 18x − 16y − 11 = 0(x + 1)²/4 + (y − 2)²/9 = 1(−1, 2)타원 (그대로)
(3, −2)9x² + 4y² − 54x + 16y + 61 = 0(x − 3)²/4 + (y + 2)²/9 = 1(3, −2)타원 (그대로)
(−2, −1)9x² + 4y² + 36x + 8y + 4 = 0(x + 2)²/4 + (y + 1)²/9 = 1(−2, −1)타원 (그대로)

x의 일차항 계수는 −18p, y의 일차항 계수는 −8q로, 이동량이 그대로 일차항에 드러납니다. 식에 일차항이 있으면 중심이 원점이 아니라는 신호이고, 완전제곱으로 묶으면 중심 (p, q)가 보입니다. 평행이동은 합동변환이라 크기와 모양은 그대로이며, 초점도 (0, ±√5)에서 (p, q ± √5)로 같은 만큼 옮겨집니다.

개념 정리

1. 평행이동해도 곡선의 모양은 그대로 — 완전제곱으로 정리하면 보인다

x²/4 + y²/9 = 1 을 (p, q) 만큼 옮기면 (x−p)²/4 + (y−q)²/9 = 1 이에요. 전개하면 일차항이 생겨 복잡해 보이지만, 완전제곱으로 되돌리면 같은 타원임이 드러납니다. 초점도 그대로 따라 옮겨집니다.

왜 그럴까

  • 평행이동은 모양을 바꾸지 않습니다 — 합동입니다.
  • 일차항이 있으면 중심이 원점이 아니라는 신호입니다.
  • 완전제곱 정리가 중심을 찾아 줍니다.

2. 자주 하는 오해 바로잡기

· “식이 복잡해지면 다른 곡선이다” → 정리하면 같은 곡선입니다.

📋 데이터 확인 탭의 결론

“'+moved+'개 — 모두 같은 타원”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

4x² + y² − 8x + 6y + 9 = 0이 나타내는 도형의 중심과 초점을 구하시오.

4(x − 1)² − 4 + (y + 3)² − 9 + 9 = 0 → 4(x − 1)² + (y + 3)² = 4 → (x − 1)²/1 + (y + 3)²/4 = 1. 장축이 y축 방향이고 c² = 4 − 1 = 3입니다. 중심 (1, −3), 초점 (1, −3 ± √3)

포물선 y² = 4x를 x축 방향으로 2, y축 방향으로 −1만큼 평행이동한 곡선의 방정식과 초점, 준선을 구하시오.

x 대신 x − 2, y 대신 y + 1을 넣어 (y + 1)² = 4(x − 2). 초점 (1, 0)과 준선 x = −1도 같은 만큼 옮겨 초점 (3, −1), 준선 x = 1
