내적의 부호와 각 — 부호는 각이, 크기는 길이가 정한다

|a| = 3을 고정하고 두 벡터가 이루는 각 θ(5° 간격)와 |b|(0.5 간격)를 바꾸며 cos θ와 내적 a·b를 기록했습니다. 예각이면 양수, 직각이면 0, 둔각이면 음수였고, 둔각에서 |b|를 키우면 내적은 더 작은 음수가 될 뿐이었습니다. 내적의 부호와 각의 관계를 정리합니다.

a·b = |a||b|cos θ에서 |a|, |b|는 항상 양수라 부호를 정하는 것은 cos θ입니다. 0° ≤ θ < 90°이면 양수, θ = 90°이면 0, 90° < θ ≤ 180°이면 음수입니다. 그래서 θ = 120°에서 |b|를 3에서 8로 키우면 내적이 −4.5에서 −12로 더 작아집니다. 내적이 크려면 크기뿐 아니라 방향이 맞아야 합니다.

개념 정리

1. 내적의 부호가 각을 말한다 — 크기가 커도 둔각이면 음수

a·b = |a||b|cos θ 에서 부호를 정하는 것은 cos θ 예요. θ가 예각이면 양수, 직각이면 0, 둔각이면 음수입니다. |b| 를 아무리 키워도 θ가 둔각이면 내적은 더 작은 음수가 될 뿐입니다.

왜 그럴까

  • cos θ 는 0°~90° 에서 양수, 90° 에서 0, 90°~180° 에서 음수.
  • 크기는 항상 양수라 부호를 바꾸지 못합니다.
  • 내적이 크다고 벡터가 큰 것은 아닙니다 — 방향이 맞아야 합니다.

2. 자주 하는 오해 바로잡기

· “내적이 크면 벡터도 크다” → 방향이 맞아야 커집니다.

3. 생활 속에서 · 이어지는 개념

  • 같은 힘이라도 진행 방향과 어긋나면 일을 적게 합니다.
각과 |b| 를 바꿔 내적을 계산하고, 부호와 크기의 관계를 확인

예제

|a| = 4, |b| = 5이고 두 벡터가 이루는 각이 135°일 때 a·b는?

4 × 5 × cos 135° = 20 × (−√2/2) = −10√2

a = (1, 3), b = (k, −1)이 이루는 각이 둔각(90° < θ < 180°)이 되는 k의 범위는?

a·b = k − 3 < 0 → k < 3. 단, 평행(θ = 180°)인 경우를 빼야 합니다: 1 × (−1) − 3k = 0 → k = −1/3. k < 3, k ≠ −1/3
