벡터의 평행 — 실수배이면 평행, 반대 방향도 포함

a = (3, 2)를 고정하고 b의 성분(0.5 간격)을 바꾸며 b = ka인 실수 k가 있는지를 성분 조건 a₁b₂ − a₂b₁의 값과 함께 기록했습니다. a₁b₂ − a₂b₁ = 0일 때마다 k가 존재해 평행이었고, 그중 k < 0인 경우는 방향이 반대인데도 평행이었습니다. 두 벡터가 평행할 조건을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 b의 x, y 슬라이더(0.5 간격, −6~6)를 정하고 ‘실수배인지 확인’을 누르면 b = ka 여부, k, 방향, 평행 판정이 기록됩니다. 4개 이상 기록하면 분석이 열리니 평행한 경우와 아닌 경우, k < 0인 경우를 모두 넣어 보세요.

영벡터가 아닌 두 벡터가 평행하다는 것은 b = ka인 실수 k가 존재한다는 뜻이며, k > 0이면 같은 방향, k < 0이면 반대 방향이지만 둘 다 평행입니다. 성분으로는 a₁b₂ − a₂b₁ = 0(성분의 비가 같음)으로 빠르게 판정할 수 있습니다. 영벡터는 모든 벡터와 평행하다고 약속합니다.

개념 정리

1. b = ka 인 실수 k 가 있으면 평행 — k 의 부호는 상관없다

두 벡터가 평행하다는 것은 같은 직선 위에 놓인다는 뜻이에요. 방향이 반대여도(k < 0) 평행입니다. 성분으로는 a₁b₂ − a₂b₁ = 0 인지 보면 됩니다.

왜 그럴까

  • b = ka 이면 두 화살표가 같은 직선 방향입니다.
  • k > 0 이면 같은 방향, k < 0 이면 반대 방향 — 둘 다 평행.
  • 성분 조건 a₁b₂ = a₂b₁ 은 비가 같다는 뜻입니다.

움직여 보기

b = ka 이면 평행 — 반대 방향도 평행

a₁b₂ − a₂b₁ b = ka ? 방향 평행

b 의 성분을 바꿔 보세요. b 가 a 를 지나는 회색 점선 위에 놓이면 a₁b₂ − a₂b₁ = 0, b = ka 이고 화살표가 보라색으로 바뀝니다. 방향이 반대(k < 0)여도 평행입니다. 예제 1 은 a = (2, −3), b = (−4, 6) → k = −2.

2. 자주 하는 오해 바로잡기

· “방향이 반대면 평행이 아니다” → 반대 방향도 평행입니다.

3. 생활 속에서 · 이어지는 개념

  • 같은 직선 위를 반대로 달리는 두 차의 방향은 평행합니다.
b 를 바꿔 가며 a 의 실수배인지 확인하고, k 의 부호와 평행 여부를 함께 기록
📋 데이터 확인 탭의 결론

“○개 — 그중 방향이 반대인 것”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

a = (2, −3)과 b = (x, 6)이 평행할 x는?

2 × 6 − (−3) × x = 12 + 3x = 0 → x = −4 (b = −2a, 반대 방향).

a = (1, 2), b = (3, −1)일 때 a + tb가 c = (1, 5)와 평행할 t는?

a + tb = (1 + 3t, 2 − t). (1 + 3t) × 5 − (2 − t) × 1 = 3 + 16t = 0 → t = −3/16.
