이차곡선과 직선의 교점 — 판별식이 개수를 정한다

타원 x²/4 + y²/9 = 1과 직선 y = mx + k의 기울기와 절편을 바꾸며 교점의 수와 연립식의 판별식 D를 기록했습니다. D > 0이면 2개, D = 0이면 1개(접함), D < 0이면 0개로 언제나 맞아떨어졌습니다. 연립과 판별식으로 위치 관계를 판정하는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 기울기 m(×0.25)과 y 절편 k(×0.5) 슬라이더를 정한 뒤 ‘직선을 움직여 보기’ 버튼을 누르면 그림이 움직인 다음 한 줄이 표에 자동으로 기록됩니다. 조건을 바꿔 가며 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

표 1. 타원 x²/4 + y²/9 = 1과 직선의 교점 (실험 예시)
직선교점 수판별식 DD 의 부호일치
y = 2x + 223024+✅
y = 0.5x21440+✅
y = 3100✅
y = −2x − 5100✅
y = 40−1008−✅
y = x + 50−1728−✅

두 식을 연립하면 (9 + 4m²)x² + 8mkx + 4k² − 36 = 0이라는 x의 이차방정식이 됩니다. 실근의 개수가 곧 교점의 개수이므로 D > 0 → 2개, D = 0 → 1개(접함), D < 0 → 0개입니다. 타원은 닫힌 곡선이라 y = 4처럼 절편이 크면 아예 만나지 않습니다. 곡선과 직선이 늘 두 점에서 만나는 것은 아닙니다.

개념 정리

1. 교점의 개수는 연립해서 얻은 이차방정식의 판별식이 정한다

곡선과 직선은 두 점에서만 만나는 것이 아닙니다. 0개, 1개, 2개 모두 가능해요. 두 식을 연립해 x 에 대한 이차방정식을 만들고 판별식의 부호를 보면 개수가 나옵니다.

왜 그럴까

  • D > 0 → 2개, D = 0 → 1개(접함), D < 0 → 0개.
  • 타원처럼 닫힌 곡선은 직선이 아예 만나지 않을 수 있습니다.
  • 포물선에서 축에 평행한 직선은 항상 1개에서 만납니다.

움직여 보기

직선을 움직이며 교점 세기 — 판별식과 대조

곡선을 고르고 직선 y = mx + k 를 움직여 보세요. 실제 교점(보라 점)의 개수와 연립한 이차방정식의 판별식 부호가 늘 맞습니다. 접하게 맞추기를 누르면 D = 0 이 되는 k 로 옮깁니다(타원, m = 1 이면 k = √13). 포물선에서 m = 0 이면 축에 평행해 교점이 항상 1개입니다.

2. 자주 하는 오해 바로잡기

· “곡선과 직선은 두 점에서 만난다” → 0개나 1개도 흔합니다.

3. 생활 속에서 · 이어지는 개념

  • 빛이 렌즈 경계에 닿는지 스치는지 판단하는 계산과 같습니다.
직선의 기울기와 절편을 바꿔 실제 교점을 세고, 판별식과 대조

예제

타원 x²/4 + y²/9 = 1과 직선 y = x + k가 접할 때 k의 값을 구하시오.

연립하면 9x² + 4(x + k)² = 36 → 13x² + 8kx + 4k² − 36 = 0. D/4 = 16k² − 13(4k² − 36) = −36k² + 468 = 0이므로 k² = 13. k = ±√13

포물선 y² = 4x와 직선 y = x − 3의 교점의 개수와 좌표를 구하시오.

(x − 3)² = 4x → x² − 10x + 9 = 0, D = 100 − 36 = 64 > 0. x = 1, 9이므로 2개: (1, −2), (9, 6)
