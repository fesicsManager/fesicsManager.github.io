포물선의 접선 — 접점 공식과 기울기 공식

포물선 y² = 4x 위 접점의 y 좌표를 바꾸며 접점 공식과 기울기 공식으로 각각 접선을 구해 기록했습니다. 두 공식은 모든 기록에서 똑같은 직선을 주었습니다. 주어진 정보에 따라 두 접선 공식을 골라 쓰는 법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 접점의 y 좌표(×0.5) 슬라이더를 정한 뒤 ‘두 공식으로 구하기’ 버튼을 누르면 그림이 움직인 다음 한 줄이 표에 자동으로 기록됩니다. 조건을 바꿔 가며 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다. 접점의 y 좌표가 0이면 접선이 y축(기울기 없음)이라 실험이 0.5로 바꿔 씁니다.

표 1. y² = 4x의 접선을 두 공식으로 구하기 (실험 예시)
접점접점 공식기울기기울기 공식같은 직선인가
(1, 2)y = x + 11y = x + 1✅
(4, 4)y = 0.5x + 20.5y = 0.5x + 2✅
(0.25, 1)y = 2x + 0.52y = 2x + 0.5✅
(1, −2)y = −x − 1−1y = −x − 1✅
(0.25, −1)y = −2x − 0.5−2y = −2x − 0.5✅

포물선 y² = 4px의 접선은 접점 (x₁, y₁)을 알 때 y₁y = 2p(x + x₁), 기울기 m을 알 때 y = mx + p/m입니다. 접점의 y 좌표가 y₁이면 기울기는 m = 2p/y₁이고, 이 m을 기울기 공식에 넣으면 접점 공식과 같은 직선이 나옵니다. 원의 접선 x₁x + y₁y = r²과는 꼴이 다르므로 곡선마다 따로 익혀야 합니다.

개념 정리

1. 접점을 알면 y₁y = 2p(x+x₁), 기울기를 알면 y = mx + p/m

포물선 y² = 4px 의 접선은 두 가지로 구할 수 있어요. 접점 (x₁, y₁) 을 알면 y₁y = 2p(x + x₁), 기울기 m 을 알면 y = mx + p/m 입니다. 같은 접선을 다른 정보로 표현한 것이라 결과가 같습니다.

왜 그럴까

  • 접점 공식은 x² → x·x₁, y² → y·y₁ 로 바꾸는 규칙에서 나옵니다.
  • 기울기 공식은 판별식 D = 0 조건에서 나옵니다.
  • m = 0 이면 기울기 공식을 쓸 수 없습니다(축에 평행).

움직여 보기

두 공식으로 구한 접선이 겹치는지 보기 (y² = 8x)

접점을 옮기면 접점 공식(초록 굵은 선)과 기울기 공식(주황 점선)으로 각각 구한 접선이 언제나 한 직선으로 겹칩니다. y₁ = 4 이면 예제 1의 y = x + 2, y₁ = 2 이면 예제 2의 y = 2x + 1 입니다. y₁ = 0 이면 접선이 y 축(x = 0)이라 기울기 공식은 쓸 수 없습니다.

· “접선 공식은 원과 같은 방식이다” → 포물선은 형태가 다릅니다.

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

포물선 y² = 8x 위의 점 (2, 4)에서의 접선의 방정식을 구하시오.

4p = 8 → p = 2. y₁y = 2p(x + x₁)에 넣으면 4y = 4(x + 2), y = x + 2. 기울기 공식으로도 y = x + 2/1로 같습니다.

포물선 y² = 8x에 접하고 기울기가 2인 접선의 방정식과 접점을 구하시오.

y = mx + p/m = 2x + 2/2이므로 y = 2x + 1. m = 2p/y₁에서 y₁ = 2, x₁ = 4/8 = 1/2이므로 접점 (1/2, 2)
