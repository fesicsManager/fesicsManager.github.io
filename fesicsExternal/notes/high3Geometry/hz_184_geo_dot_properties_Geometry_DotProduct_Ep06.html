고등학교 기하 · 실험 「나눗셈 실험실」

내적의 성질 — a·b = a·c여도 b = c는 아니다

a = (4, 0)을 고정하고 b를 정한 뒤 c를 b에서 a와 수직인 방향(y방향)으로 옮기며 a·b와 a·c를 기록했습니다. c를 얼마나 옮기든 두 내적은 같았지만 c는 b와 다른 벡터였습니다. 내적에서 소거가 성립하지 않는 까닭을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 b의 x, y(−5~6)와 c를 b에서 옮길 거리(0.5 간격, −4~4)를 정하고 ‘같은 내적 찾기’를 누르면 a, b, c, a·b, a·c, b = c 여부가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. a = (4, 0)과의 내적 (실험 예시)
abca·ba·cb = c ?
(4, 0)(2, 3)(2, 5)88❌
(4, 0)(2, 3)(2, 3)88✅
(4, 0)(−1, 4)(−1, 1)−4−4❌
(4, 0)(3, −2)(3, −0.5)1212❌
(4, 0)(0, 5)(0, 1)00❌

a·b = a·c이면 a·(b − c) = 0, 즉 b − c가 영벡터이거나 a와 수직이라는 것만 알 수 있습니다. 내적은 a 방향 성분만 재므로 a에 수직인 방향의 차이는 사라지고, 그래서 a·b = a·c인 서로 다른 b, c가 무수히 많습니다. 실수와 달리 벡터에는 나눗셈이 없어 소거할 수 없습니다. 반면 교환법칙 a·b = b·a, 분배법칙 a·(b + c) = a·b + a·c, a·a = |a|²는 성립합니다.

개념 정리

1. a·b = a·c 여도 b = c 는 아니다 — 내적에는 소거법칙이 없다

a 와 수직인 방향으로 b 를 옮기면 내적이 변하지 않습니다. 그래서 a·b = a·c 인 서로 다른 b, c 가 무수히 많아요. 실수에서 ab = ac ⟹ b = c 가 성립하는 것과 다릅니다 — 벡터에는 나눗셈이 없습니다.

왜 그럴까

  • a·(b − c) = 0 이면 b − c 가 a 와 수직이면 됩니다 — b = c 가 아니어도 됩니다.
  • 내적은 a 방향 성분만 재므로 수직 방향 정보는 사라집니다.
  • a·b = a·c 에서 얻을 수 있는 것은 (b−c) ⊥ a 뿐입니다.

움직여 보기

a와 수직으로 옮기면 내적은 그대로 — 그래서 소거가 안 된다

c(초록)를 b(파랑)에서 a와 수직인 방향(위·아래)으로 옮겨 보세요. 보라 점선 위의 점은 모두 a 방향 그림자가 같아서 a·b = a·c입니다. 그런데 c ≠ b — 알 수 있는 것은 b − c(주황)가 a와 수직이라는 것뿐입니다.

2. 자주 하는 오해 바로잡기

· “벡터도 나눗셈이 된다” → 내적에서 소거할 수 없습니다.

3. 생활 속에서 · 이어지는 개념

  • 한 방향의 정보만 재면 다른 방향의 차이는 알 수 없습니다.
c 를 a 와 수직인 방향으로 옮겨 가며 두 내적이 같은지 확인

예제

a = (1, 2), b = (3, 1)일 때 a·c = a·b를 만족하고 b와 다른 벡터 c를 하나 구하시오.

b − c가 a와 수직이면 되므로 b − c = t(−2, 1)로 두면 c = (3 + 2t, 1 − t). t = 1이면 c = (5, 0): a·c = 5 = a·b. 예: c = (5, 0)

|a| = 3, |b| = 2, a·b = −1일 때 (a + 2b)·(a − b)를 구하시오.

분배법칙으로 |a|² − a·b + 2b·a − 2|b|² = 9 + a·b − 8 = 9 − 1 − 8 = 0 (두 벡터가 수직).
