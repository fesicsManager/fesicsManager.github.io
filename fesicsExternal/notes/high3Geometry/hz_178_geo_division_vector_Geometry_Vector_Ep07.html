내분점의 위치벡터 — OP = (n·OA + m·OB)/(m + n)

A(−3, −1), B(4, 3)을 m : n으로 내분하는 점 P를 벡터식 OA + (m/(m + n))AB와 좌표식 (n·OA + m·OB)/(m + n)으로 각각 구하고 AP : PB를 확인했습니다. 두 식은 언제나 같은 점을 주었고 실제 거리 비도 정확히 m : n이었으며, m이 클수록 P가 B 쪽으로 갔습니다. 내분점의 위치벡터 공식을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 m, n(1~6)을 정하고 ‘벡터로 내분점 찾기’를 누르면 벡터식·좌표식으로 구한 점과 두 식의 일치, AP : PB 확인 결과가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

AP : PB = m : n이면 AP = (m/(m + n))AB이므로 OP = OA + (m/(m + n))(OB − OA) = (n·OA + m·OB)/(m + n). 계수가 엇갈려 붙는 것이 핵심으로, m이 커질수록 P가 B 쪽으로 가므로 OB에 m이 곱해집니다. 좌표로 쓴 내분점 공식과 똑같고, m = n이면 중점 (OA + OB)/2입니다.

개념 정리

1. 내분점의 위치벡터 = (n·OA + m·OB) / (m + n)

P 가 AB 를 m:n 으로 내분하면 OP = (n·OA + m·OB)/(m+n) 이에요. 계수가 엇갈려 붙는 것이 핵심입니다. m 이 커질수록 P 가 B 쪽으로 가므로, B 에 m 이 곱해집니다.

왜 그럴까

  • AP : PB = m : n 이므로 AP = (m/(m+n))AB.
  • OP = OA + AP = OA + (m/(m+n))(OB − OA) 를 정리하면 나옵니다.
  • 좌표로 구한 내분점 공식과 정확히 같습니다.

2. 자주 하는 오해 바로잡기

· “벡터로는 내분점을 못 나타낸다” → 오히려 더 간결합니다.

📋 데이터 확인 탭의 결론

“모든 기록에서 실제 거리 비가 m : n 과 같았습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

OA = a, OB = b일 때 선분 AB를 1 : 3으로 내분하는 점 P의 위치벡터는?

OP = (3a + 1·b)/(1 + 3) = (3a + b)/4

삼각형 ABC의 꼭짓점의 위치벡터가 a, b, c일 때 무게중심 G의 위치벡터를 구하시오.

BC의 중점 M = (b + c)/2, G는 AM을 2 : 1로 내분 → OG = (1·a + 2·(b + c)/2)/3 = (a + b + c)/3
