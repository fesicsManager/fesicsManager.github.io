고등학교 기하 · 실험 「크기 실험실」

성분의 연산과 크기 — 성분은 따로 더하지만 크기는 √로

두 벡터 a, b의 성분을 바꾸며 a + b의 성분, 크기 |a + b|, 성분의 합, |a| + |b|를 기록했습니다. |a + b|는 성분을 더한 값과 대부분 달랐고, 언제나 |a| + |b| 이하였으며 같은 방향일 때만 등호가 성립했습니다. 성분 연산과 크기 계산을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 a의 x, y와 b의 x, y(−5~6)를 정하고 ‘크기를 재어 보기’를 누르면 a + b, |a + b|, 성분의 합, |a| + |b|가 기록됩니다. 4개 이상 기록하면 분석이 열리니 같은 방향인 두 벡터도 한 번 넣어 보세요.

덧셈·뺄셈·실수배는 성분마다 따로 합니다: a + b = (a₁ + b₁, a₂ + b₂). 그러나 크기는 |a + b| = √((a₁ + b₁)² + (a₂ + b₂)²)로 피타고라스로 구해야 하며 성분의 합이 아닙니다. 또 |a + b| ≤ |a| + |b|(삼각부등식)이고, 등호는 두 벡터가 같은 방향일 때(표의 (2, 1) + (4, 2))만 성립합니다.

개념 정리

1. 성분은 따로 더하지만, 크기는 √(x²+y²) 로 따로 구해야 한다

벡터의 덧셈은 성분마다 따로 합니다: (a₁+b₁, a₂+b₂). 하지만 크기는 성분을 더한 값이 아닙니다. |a+b| = √((a₁+b₁)² + (a₂+b₂)²) 로 구해야 해요. 또 |a+b| ≤ |a|+|b| 입니다(삼각부등식).

왜 그럴까

  • 크기는 피타고라스로 계산한 길이입니다.
  • 성분의 합은 좌표축 방향으로만 더한 값이라 길이가 아닙니다.
  • 두 벡터가 같은 방향일 때만 |a+b| = |a|+|b|.

움직여 보기

성분은 따로 더하고, 크기는 피타고라스로

a(빨강) 끝에 b(파랑)를 이어 붙이면 a + b(보라)가 됩니다. 보라 화살표의 길이는 주황 점선 직각삼각형의 빗변이라 √(x² + y²)로 구하고, 성분의 합과는 다릅니다. 재생하면 |b| = 5인 b가 돌아가며, b가 a와 같은 방향(3, 4)일 때만 |a + b| = |a| + |b| = 10이 됩니다.

2. 자주 하는 오해 바로잡기

· “크기는 성분을 더한 값이다” → 제곱해서 더한 뒤 근호를 씌워야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 동서로 3km, 남북으로 4km 가면 직선거리는 7km 가 아니라 5km 입니다.

📋 데이터 확인 탭의 결론

“모든 기록에서 |a+b| ≤ |a| + |b| 였습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

a = (1, −2), b = (3, 4)일 때 2a − b의 성분과 크기는?

2a − b = (2 − 3, −4 − 4) = (−1, −8), 크기 = √(1 + 64) = (−1, −8), √65

a = (3, 4), b = (4, −3)일 때 |a + b|와 |a| + |b|를 비교하시오.

a + b = (7, 1), |a + b| = √50 = 5√2 ≈ 7.07. |a| + |b| = 5 + 5 = 10. |a + b| < |a| + |b| (방향이 달라서).
