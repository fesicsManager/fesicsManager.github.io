고등학교 기하 · 실험 「자취 실험실」

내적과 자취 — 조건을 식으로 바꾸면 도형이 보인다

A(−2, 0), B(2, 0), d = (1, 2), C(0, 0)을 두고 찍을 점의 개수(50~1500)와 조건을 바꾸며, 무작위로 찍은 점 가운데 조건을 거의 만족하는 점만 표시했습니다. (P − A)·(P − B) = 0은 AB를 지름으로 하는 원, (P − A)·d = 0은 A를 지나고 d에 수직인 직선, |P − C| = 3은 중심 C, 반지름 3인 원으로 나타났습니다. 내적 조건을 방정식으로 옮기는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 찍을 점의 개수(50~1500)와 조건((P−A)·(P−B) = 0, (P−A)·d = 0, |P−C| = r)을 고르고 ‘조건을 만족하는 점 찍기’를 누르면 조건, 만족하는 점의 수, 자취의 모양, 정리한 식이 기록됩니다. 4개 이상 기록하면 분석이 열리며, 세 조건을 모두 기록해야 정리표가 완성됩니다.

표 1. 조건별 자취 (실험 예시, 무작위 — 기대 개수 = 점 수 × 허용 띠 넓이 ÷ 전체 넓이 120)
조건찍은 점만족하는 점기대 개수(이론)자취의 모양식으로 정리
(P−A)·(P−B) = 04008개약 7개AB를 지름으로 하는 원x² + y² = 4
(P−A)·d = 040011개약 10개A를 지나고 d에 수직인 직선x + 2y + 2 = 0
|P−C| = 340012개약 11개중심 C, 반지름 3인 원x² + y² = 9
(P−A)·(P−B) = 0150029개약 27개AB를 지름으로 하는 원x² + y² = 4
|P−C| = 3150044개약 42개중심 C, 반지름 3인 원x² + y² = 9

P = (x, y)로 두고 전개하면 (P − A)·(P − B) = (x + 2)(x − 2) + y² = 0 → x² + y² = 4(지름에 대한 원주각이 직각), (P − A)·d = (x + 2) + 2y = 0 → 일차식이라 직선, |P − C| = 3을 제곱하면 x² + y² = 9입니다. 찍힌 점의 개수는 무작위라 매번 다르지만 모양은 언제나 같습니다. 내적은 말로 된 조건을 방정식으로 옮기는 도구입니다.

개념 정리

1. 내적 조건을 좌표로 옮기면 익숙한 도형의 방정식이 된다

(P−A)·(P−B) = 0 은 “AP 와 BP 가 수직”이라는 조건이고, 자취는 AB 를 지름으로 하는 원이에요. (P−A)·d = 0 은 “AP 가 d 와 수직” — A 를 지나고 d 에 수직인 직선입니다. 내적은 조건을 식으로 옮기는 도구입니다.

왜 그럴까

  • 원주각의 성질 — 지름에 대한 원주각은 직각입니다.
  • (P−A)·d = 0 을 전개하면 일차식이 되어 직선입니다.
  • |P−C| = r 을 제곱하면 원(또는 구)의 방정식이 됩니다.

2. 자주 하는 오해 바로잡기

· “내적은 계산 연습일 뿐이다” → 조건을 도형으로 바꾸는 도구입니다.

3. 생활 속에서 · 이어지는 개념

  • 제약 조건을 식으로 옮기는 것이 모델링의 첫 단계입니다.
조건을 골라 평면의 점들을 검사해 만족하는 점만 표시하고, 자취의 모양을 확인

“세 가지 조건을 모두 확인했습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

A(0, 0), B(6, 0)에 대해 (P − A)·(P − B) = 0을 만족하는 점 P의 자취를 구하시오.

x(x − 6) + y² = 0 → (x − 3)² + y² = 9. 중심 (3, 0), 반지름 3인 원 (AB가 지름).

A(1, 1), n = (2, −3)일 때 (P − A)·n = 0을 만족하는 점 P의 자취의 방정식은?

2(x − 1) − 3(y − 1) = 0 → 2x − 3y + 1 = 0 (A를 지나고 n에 수직인 직선).
