한 점에서 만나도 접선이 아니다 — 축에 평행한 직선

포물선 y² = 4x와 직선 y = mx + k의 기울기를 바꾸며 교점의 수, 판별식, 접선 여부를 기록했습니다. 기울기가 0이면 교점이 늘 하나였지만 연립식이 일차라 접선이 아니었고, 진짜 접선은 판별식이 0일 때뿐이었습니다. 교점의 개수와 접함을 구별하는 기준을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 기울기 m(×0.25)과 y 절편 k(×0.5) 슬라이더를 정한 뒤 ‘직선을 기울여 보기’ 버튼을 누르면 그림이 움직인 다음 한 줄이 표에 자동으로 기록됩니다. 조건을 바꿔 가며 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다.

표 1. 포물선 y² = 4x와 직선 y = mx + k (실험 예시)
기울기교점 수판별식접선인가이유
0 (y = 2)1—(일차)❌기울기 0 — 연립하면 일차식이라 근이 하나뿐
0.5 (k = 2)10✅판별식 0 — 중근이라 접합니다
1 (k = 1)10✅판별식 0 — 중근이라 접합니다
0.5 (k = 1)28❌두 점에서 가로지릅니다
1 (k = 2)0−16❌만나지 않습니다

기울기가 0이면 y = k를 대입해 k² = 4x, 곧 일차방정식이 되어 근이 하나뿐입니다. 그래서 교점은 1개지만 직선이 포물선을 가로지르며 지나가므로 접선이 아닙니다. 기울기가 0이 아닐 때는 m²x² + (2mk − 4)x + k² = 0에서 D = 16 − 16mk이므로 mk = 1일 때만 접선입니다. 접함은 교점의 개수가 아니라 중근(D = 0)으로 판정합니다.

개념 정리

1. 교점이 하나여도 접선이 아닐 수 있다 — 축에 평행한 직선

포물선 y² = 4x 에서 x 축에 평행한 직선(기울기 0)은 언제나 한 점에서만 만나지만 접선이 아니에요. 곡선을 가로지르며 지나가기 때문입니다. 접선은 그 점에서 곡선과 스치듯 닿아야 합니다.

왜 그럴까

  • 연립하면 기울기 0 일 때 일차방정식이 되어 근이 하나뿐입니다.
  • 이차방정식이 되는 경우에만 판별식으로 접함을 판정할 수 있습니다.
  • 접선은 중근(D = 0)을 가질 때입니다.

움직여 보기

한 점에서 만나도 접선이 아닐 수 있다

포물선 y² = 4x 위의 점 P(1/4, 1)을 지나는 직선을 돌려 봅니다. m = 0 이면 교점은 1개뿐이지만 직선이 포물선 안쪽(색칠한 곳)을 가로질러 지나가므로 접선이 아닙니다. m = 2 일 때만 연립식이 중근(D = 0)을 갖고 바깥에서 스치듯 닿습니다 — 예제 1의 y = 2x + 1/2 입니다.

2. 자주 하는 오해 바로잡기

· “한 점에서만 만나면 접선이다” → 축에 평행한 경우는 예외입니다.

3. 생활 속에서 · 이어지는 개념

  • 닿는 것과 스치는 것을 구분해야 하는 판정에서 늘 생기는 문제입니다.
기울기를 바꿔 교점의 개수와 연립식의 차수를 확인하고, 접선인지 판정

예제

포물선 y² = 4x와 직선 y = 2x + k가 접할 때 k의 값을 구하시오.

(2x + k)² = 4x → 4x² + (4k − 4)x + k² = 0. D = (4k − 4)² − 16k² = 16 − 32k = 0이므로 k = 1/2

포물선 y² = 4x와 직선 y = −3의 교점을 구하고, 이 직선이 접선인지 판단하시오.

9 = 4x에서 x = 9/4, 교점은 (9/4, −3) 하나입니다. 그러나 연립식이 일차방정식이고 직선이 축에 평행하게 곡선을 가로지르므로 접선이 아니다
