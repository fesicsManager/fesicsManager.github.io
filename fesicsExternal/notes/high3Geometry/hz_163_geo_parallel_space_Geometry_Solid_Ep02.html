고등학교 기하 · 실험 「평행 실험실」

공간에서의 평행 — 같은 평면에 평행해도 서로 평행이 아니다

정육면체 ABCD-EFGH에서 직선 짝을 골라 두 직선의 관계와 각 직선이 밑면 α에 평행한지를 좌표로 판정해 기록했습니다. 두 직선이 모두 밑면에 평행해도 서로 평행한 경우, 한 점에서 만나는 경우, 꼬인 위치인 경우가 모두 나왔습니다. 공간에서 평행 관계가 옮겨지는 경우와 옮겨지지 않는 경우를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 직선 짝 고르기(1~4) 슬라이더를 정한 뒤 ‘정육면체에서 찾기’ 버튼을 누르면 그림이 움직인 다음 한 줄이 표에 자동으로 기록됩니다. 조건을 바꿔 가며 4개 이상 기록하면 데이터 검증 탭의 분석이 열립니다. 짝이 4가지뿐이므로 모든 짝을 한 번씩 기록하면 됩니다.

표 1. 정육면체에서 고른 직선 짝 (실험 예시)
직선 1직선 2밑면에 평행서로 평행꼬인 위치
EFHG✅ 둘 다○×
EFFG✅ 둘 다× (F에서 만남)×
EFMN (AE, DH의 중점)✅ 둘 다×○
EFHB× (HB는 B에서 밑면과 만남)×○

EF와 FG는 둘 다 밑면에 평행하지만 점 F에서 만나고, EF와 MN(M, N은 모서리 AE, DH의 중점)은 둘 다 밑면에 평행하지만 높이가 달라 꼬인 위치에 있습니다. 곧 같은 평면에 평행한 두 직선이 서로 평행할 필요는 없습니다. ‘직선 ∥ 평면’은 만나지 않는다는 뜻일 뿐 방향을 정하지 않기 때문입니다. 반면 같은 직선에 평행한 두 직선은 서로 평행합니다(평행선의 추이성). 넷째 짝의 HB는 꼭짓점 B에서 밑면과 만나므로 밑면에 평행한 직선이 아니고(실험 표에도 ‘×’로 표시), EF와는 꼬인 위치입니다.

개념 정리

1. 같은 평면에 평행한 두 직선이 서로 평행할 필요는 없다

평면 α 에 평행한 직선은 무수히 많고, 그중 두 개를 골라도 서로 평행일 수도, 만날 수도, 꼬인 위치일 수도 있어요. “평행”이라는 관계는 평면을 매개로 옮겨지지 않습니다.

왜 그럴까

  • 직선 // 평면 은 “만나지 않는다”는 뜻일 뿐 방향을 정하지 않습니다.
  • 반면 두 직선이 같은 직선에 평행하면 서로 평행합니다(평행선의 추이성).
  • 평면과 평면이 평행한 경우는 또 다릅니다.

2. 자주 하는 오해 바로잡기

· “같은 평면에 평행한 두 직선은 서로 평행하다” → 꼬인 위치일 수 있습니다.

3. 생활 속에서 · 이어지는 개념

  • 같은 바닥과 나란한 두 막대가 서로 나란하다는 보장은 없습니다.
꼭짓점 좌표로 판정: 방향벡터가 나란하면 평행, 아니면 스칼라 삼중곱 0 → 만남, 0이 아님 → 꼬인 위치. 방향의 높이 성분이 0이고 밑면 밖에 있으면 밑면에 평행

예제

정육면체 ABCD-EFGH에서 모서리 AE, DH의 중점을 각각 M, N이라 할 때(실험의 셋째 짝), 직선 MN과 EF는 모두 밑면 ABCD에 평행한가? 두 직선의 위치 관계는?

MN은 밑면에서 높이가 모서리의 절반인 곳에, EF는 윗면에 있으며 둘 다 밑면과 만나지 않으므로 모두 밑면에 평행합니다. 그런데 MN은 AD 방향, EF는 AB 방향이라 평행하지 않고, 높이가 달라 만나지도 않습니다. 둘 다 밑면에 평행하지만 꼬인 위치

정육면체 ABCD-EFGH에서 AE ∥ BF, BF ∥ CG일 때 AE와 CG의 위치 관계를 말하시오.

두 직선이 같은 직선 BF에 평행하므로 평행선의 추이성에 따라 AE ∥ CG
