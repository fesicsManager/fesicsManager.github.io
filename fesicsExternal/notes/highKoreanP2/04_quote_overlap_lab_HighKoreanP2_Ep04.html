고등 공통국어 ② · 웹툰 4화 「출처만 밝히면 표절이 아닌가」

쓰기 윤리와 인용 — 출처는 ‘어디서’, 따옴표와 재구성은 ‘어디까지’

원문 한 문장과 학생 문장 A~E를 어절 단위로 맞대어 연속으로 똑같은 어절의 최대 길이를 세고, 따옴표·출처와 함께 판정했습니다. 15어절이 겹쳐도 따옴표와 출처가 있는 B는 정당한 직접 인용이었고, 3어절만 겹친 C는 표절 의심, 1어절만 겹친 E는 표절이었습니다. 출처 표시만으로는 정직함이 증명되지 않는 까닭과 바른 인용의 순서를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 학생 문장(A 원문 그대로 · B 따옴표로 원문 그대로 · C 낱말만 바꿈 · D 자기 말로 재구성 + 출처 · E D와 같은 문장, 출처 없음)과 나의 판정(표절 · 표절 의심 · 정당한 인용)을 고르고 원문과 맞대어 보기를 누르면 원문과 같은 어절이 표시되고, 연속 일치 어절 수, 따옴표·출처, 뼈대 대응, 대본의 판정과 나의 판정이 나옵니다. 기록을 4개 이상 쌓으면 결과 비교 탭에서 문장별 판정을 표로 비교할 수 있습니다.

표 1. 학생 문장의 연속 일치와 판정 (실험 예시)
문장연속 일치따옴표출처판정나의 판정
A15어절✕○표절표절
B15어절○○정당한 인용정당한 인용
C3어절✕○표절 의심정당한 인용
C3어절✕○표절 의심표절 의심
D1어절✕○정당한 인용정당한 인용
E1어절✕✕표절정당한 인용

A와 B는 똑같이 15어절이 겹쳤지만 따옴표 하나로 판정이 표절과 정당한 인용으로 갈렸습니다. C는 연속 일치가 ‘온도를 낮추고 빗물이’ 3어절뿐이지만, 원문 15어절 중 13어절이 같은 순서로 비슷한 말에 대응해 뼈대를 그대로 썼습니다. E는 ‘가로수는’ 1어절만 겹쳤는데도 생각을 빌리고 출처를 밝히지 않아 표절입니다. 출처는 ‘어디서’ 가져왔는지를, 따옴표와 재구성은 ‘어디까지’가 남의 것인지를 알려 주며, 둘 다 갖춰야 정직한 인용입니다.

개념 정리

1. 출처는 ‘어디서’, 따옴표와 재구성은 ‘어디까지’

출처 표시는 어디서 가져왔는지를 알려 줍니다. 독자는 하나 더 알아야 해요. 어디까지가 가져온 것이고 어디부터가 글쓴이의 것인가.

  • 직접 인용: 원문 표현을 그대로 가져오면 따옴표 + 출처 (B)
  • 간접 인용: 생각을 자기 말로 재구성 + 출처 (D)
  • 표절: 남의 표현을 따옴표 없이 자기 문장처럼 씀 (A) · 생각을 빌리고 밝히지 않음 (E)
  • 표절 의심: 낱말만 비슷한 말로 바꾸고 원문의 순서·구조(뼈대)는 그대로 (C) — 연속 일치가 짧아도 정직하지 않아요.

2. 표절과 저작권 침해는 다르다

표절은 학업·연구 윤리의 문제(남의 것을 자기 것처럼 보이게 했는가), 저작권 침해는 법의 문제(허락 없이 남의 저작물을 이용했는가)예요. 저작권이 끝난 옛 책을 출처 없이 베껴도 표절입니다.

원문을 읽고 덮기 → 기억나는 생각을 내 말로 쓰기 → 원문과 대조해 남은 표현은 따옴표 또는 다시 쓰기 → 문장마다 출처

3. 실험 모형과 실제의 차이

· 연속 일치는 이 실험이 문장 부호를 떼고 직접 계산합니다.

· ‘뼈대 대응’은 원문 어절이 같은 순서로 비슷한 말에 대응하는지 사람이 맞대어 센 값입니다. 실제 표절 검사 프로그램은 더 복잡한 방법을 쓰고, 최종 판단은 사람이 해요.

직접 인용 = 원문 그대로 + 따옴표 + 출처 · 간접 인용 = 자기 말로 재구성(문장 구조까지) + 출처 · 표절 = 남의 표현이나 생각을 자기 것처럼 보이게 함
닥터 이안 · 제로

“출처 표시는 ‘어디서 가져왔는가’를 알려 준다. 그런데 독자는 또 하나를 알아야 한다. ‘어디까지가 가져온 것이고, 어디부터가 네 것인가.’” “출처가 맨 아래 하나만 있으면 그 경계를 알 수가 없네요.”

닥터 이안 · 뭉치

“그리고 E를 봐라. 똑같은 어절이 ‘가로수는’ 하나뿐인데도 표절이다. 표현이 아니라 생각을 빌렸으니까.” “…출처 표시는 면죄부가 아니라 최소한의 입장권이었어.”

웹툰 4화 #4 · 원문 일치 어절 대조

예제

학생 문장 C(도시 가로수는 여름 인도의 겉면 온도를 낮추고, 빗물이 한 번에 하수도로 몰리는 걸 늦춘다)에서 원문과 연속으로 똑같은 가장 긴 구간은? 판정은?

문장 부호를 떼고 맞대면 ‘온도를 낮추고 빗물이’가 이어서 같습니다. 연속 일치는 짧지만 원문의 순서와 구조를 그대로 두고 낱말만 바꿨습니다. 3어절 — 표절 의심

저작권이 끝난 옛날 책의 문장을 출처 없이 내 보고서에 그대로 옮겼다. 표절인가, 저작권 침해인가?

저작권 침해는 허락 없이 남의 저작물을 이용했느냐를 묻는 법의 문제이고, 표절은 남의 것을 자기 것처럼 보이게 했느냐를 묻는 윤리의 문제입니다. 저작권이 끝나 법적 문제는 없어도 자기 글처럼 보이게 했습니다. 표절이다 (저작권 침해는 아님)
