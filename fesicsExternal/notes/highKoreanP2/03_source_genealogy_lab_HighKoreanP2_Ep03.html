고등 공통국어 ② · 웹툰 3화 「두 글이 같은 말을 하면 사실인가」

주제 통합적 읽기 — 글 개수가 아니라 근거의 뿌리를 센다

‘바나나를 먹으면 집중력 30% 상승’을 말하는 기사 A·B와 ‘효과가 확인되지 않았다’는 기사 C의 출처를 한 단계씩 거슬러 올라가며 찬성 쪽과 반대 쪽 근거를 셌습니다. 글 개수만 세면 2 대 1이었지만 출처를 보자 A·B가 한 줄기라 1 대 1이 되었고, 원자료까지 가자 ‘바나나 30%’를 뒷받침하는 근거는 0이었습니다. 출처의 독립성과 통합적 읽기의 절차를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 추적 깊이(글 개수만 세기 · 직접 밝힌 출처까지 · 출처의 출처까지 · 원자료까지)와 확인할 주장(바나나 집중력 30% 상승 · 아침 간식 뒤 단기 기억 점수 소폭 상승)을 고르고 이 깊이까지 추적하기를 누르면 출처 계보도, 독립적인 뿌리 수, 주장 쪽 : 반대 쪽 근거 수와 결론이 나옵니다. 기록을 4개 이상 쌓으면 결과 비교 탭에서 깊이별 결론의 변화를 볼 수 있습니다.

표 1. 추적 깊이와 주장에 따른 근거 수 (실험 예시)
깊이주장찬 : 반원자료 확인
글 개수만 세기바나나 30%2 : 1아니오
직접 밝힌 출처까지바나나 30%1 : 1아니오
출처의 출처까지바나나 30%1 : 1아니오
원자료까지바나나 30%0 : 1예
글 개수만 세기간식 소폭↑2 : 1아니오
원자료까지간식 소폭↑1 : 0예

B는 A를, A는 건강 블로그를, 블로그는 연구 요약 영상을 따랐으므로 A와 B는 한 줄기입니다. 원자료까지 간 글은 C뿐이었고, 원자료는 ‘성인 24명, 아침 간식 뒤 단기 기억 점수 소폭 상승’이라고만 말했습니다. 근거의 무게는 글의 개수가 아니라 서로 독립적인 근거인지와 원자료에 얼마나 가까운지로 정해집니다. 같은 출처가 되풀이되어 여러 근거처럼 보이는 것을 순환 보도라고도 하며, 전달될 때마다 내용이 커지기도 합니다.

개념 정리

1. 글 개수가 아니라 근거의 뿌리를 센다

두 사람이 같은 말을 했어도 둘 다 같은 소문을 들었다면 증인은 하나예요. 주제 통합적 읽기에서는 글끼리 무엇이 같고 다른지 비교하기 전에, 그 글들이 서로 독립적인 근거인지 확인해야 합니다.

  • B 기사 → A 기사 → 건강 블로그 → 해외 연구 요약 영상: 한 줄기
  • C 기사 → 연구 논문 원문: 원자료까지 간 유일한 글
  • 원자료: 성인 24명, 아침 간식 뒤 단기 기억 과제 점수 소폭 상승. 바나나만 따로 시험하지 않음. ‘30%’라는 수치 없음.

같은 출처가 여러 번 되풀이되어 여러 근거처럼 보이는 것을 순환 보도라고도 해요. 전달될 때마다 내용이 커지기도 합니다.

추적 깊이 찬 : 반 원자료 확인

깊이를 한 단계씩 올려 보세요. 글은 세 편이지만 B가 A를 따른 것이 드러나면 A·B는 한 줄기(빨강)가 됩니다. 원자료까지 가면 ‘바나나 30%’를 뒷받침하는 근거는 0이에요. 주장을 ‘간식 소폭↑’로 바꾸면 결론이 어떻게 달라지는지도 보세요.

2. 통합적 읽기의 절차

주장·근거 정리 → 출처를 거슬러 독립성 확인 → 어긋나는 지점에서 원자료에 가까운 쪽 확인 → 내 관점 세우기 원자료가 ‘소폭 상승, 소규모 표본’이라고 했다면 내 글도 그 조건을 지켜야 해요.

3. 실험 모형과 실제의 차이

· 실제로는 출처가 밝혀져 있지 않거나 원자료에 접근할 수 없는 경우도 많습니다. 그럴 때는 ‘확인하지 못함’이라고 적는 것도 정직한 읽기예요.

통합적 읽기: 주장·근거 정리 → 출처를 거슬러 독립성 확인 → 어긋나는 지점에서 원자료에 가까운 쪽 확인 → 내 관점 세우기

웹툰 3화 #4 · 원자료까지 추적한 계보도

예제

‘직접 밝힌 출처까지’ 추적했을 때 ‘바나나 30%’ 주장의 찬 : 반 근거 수와 그 까닭은?

B 기사가 밝힌 출처는 A 기사입니다. 따라서 A와 B는 같은 줄기 하나로 세고, C는 따로 셉니다. 1 : 1 — A와 B는 한 줄기

원자료까지 추적하면 ‘바나나 30%’와 ‘아침 간식 뒤 단기 기억 점수 소폭 상승(성인 24명)’은 각각 어떻게 판정되는가?

원자료는 바나나만 따로 시험하지 않았고 ‘30%’라는 수치도 없었습니다. 대신 아침 간식 뒤 점수가 소폭 올랐다고 했습니다. 바나나 30%: 0 : 1(뒷받침 0) / 간식 소폭 상승: 1 : 0(단, 소규모 표본·소폭)
