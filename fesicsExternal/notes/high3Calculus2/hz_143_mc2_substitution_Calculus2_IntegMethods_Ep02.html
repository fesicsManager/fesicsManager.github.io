치환적분 — t = ax + b면 1/a가 붙는다

∫(ax + 1)ⁿdx를 t = ax + 1로 치환해 얻은 F(x)를 다시 미분해 원래 함수와 비교했습니다. 1/a를 붙인 결과는 모든 기록에서 원래 함수로 돌아왔고, 1/a를 빠뜨리면 정확히 a배만큼 어긋났습니다. 치환적분과 미분 검산을 정리합니다.

실험 안내: 자유 탐구 탭에서 (ax + b)ⁿ의 a, n과 검산할 x(0.5 간격)를 정하고 ‘적분하고 다시 미분’을 누르면 치환 결과 F(x), F′(x), 원래 함수값이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

t = ax + 1이면 dt = a dx, dx = dt/a라서 ∫(ax + 1)ⁿdx = (ax + 1)ⁿ⁺¹/{a(n + 1)} + C입니다. 1/a를 빠뜨리면 미분 결과가 원래의 a배(실험에서 2배, 3배, 5배)가 되었습니다. 치환적분은 연쇄법칙을 거꾸로 읽은 것이므로 결과를 미분해 원래 함수로 돌아오는지 보면 언제나 검산됩니다.

개념 정리

1. 치환적분은 “속미분이 곱해져 있을 때” 되돌리는 방법

∫(ax+b)ⁿ dx 를 t = ax+b 로 치환하면 dt = a dx 라 1/a 가 앞에 붙어요. 이 계수를 빠뜨리는 것이 가장 흔한 실수입니다. 미분해서 검산하면 바로 드러납니다.

왜 그럴까

  • 연쇄법칙 (F(g(x)))′ = F′(g(x))·g′(x) 를 거꾸로 읽은 것입니다.
  • g′(x) 가 식에 없으면 상수로 보충해야 합니다.
  • 결과를 미분해 원래로 돌아오는지 보면 언제나 확인됩니다.

t = ax + 1 로 두면 dx = dt/a 라서 결과에 1/a 가 붙습니다. 막대를 보면 1/a 를 넣은 F 를 미분한 값(보라)은 원래 함수값(파랑)과 같고, 1/a 를 빠뜨리면(빨강) a 배가 됩니다. a = 1 일 때만 두 경우가 같아요.

2. 자주 하는 오해 바로잡기

· “적분은 공식을 뒤집기만 하면 된다” → 속미분 계수를 나눠 줘야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 단위 환산 계수를 빠뜨리면 답이 배수만큼 틀리는 것과 같습니다.

예제

t = 3x − 2, dt = 3 dx. ∫t⁴(dt/3) = t⁵/15 + C. (3x − 2)⁵/15 + C

t = x² + 1이면 dt = 2x dx. ∫t³ dt = t⁴/4 + C. (x² + 1)⁴/4 + C
