멈춰도 증가 — f′ = 0인 점이 하나 있어도 증가할 수 있다

y = x³, x², x 중 하나를 고르고 원점에서 h만큼 떨어진 두 점의 함숫값 f(−h), f(h)와 f′(0)을 비교해 기록했습니다. x³은 f′(0) = 0인데도 f(−h) < f(h)라 증가였고, x²은 f(−h) = f(h)라 증가가 아니었습니다. 증가의 정확한 뜻과 도함수 조건의 관계를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 함수(x³, x², x)를 고르고 0에서 떨어진 거리 h(0.05 간격)를 정한 뒤 ‘값을 비교하기’를 누르면 f′(0), f(−h) < f(h) 여부, 판정이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. 세 함수의 원점 근처 비교 (실험 예시)
함수 (h)f′(0)f(−h) < f(h)증가 구간판정
x³ (h = 0.5)0✅모든 실수증가
x³ (h = 0.05)0✅모든 실수증가
x² (h = 0.5)0❌x > 0 만증가 아님
x (h = 0.5)1✅모든 실수증가

x³은 f(−0.5) = −0.125 < f(0.5) = 0.125로 h를 아무리 작게 해도 오른쪽이 컸습니다. 증가의 정의는 x₁ < x₂이면 f(x₁) < f(x₂)이고, 도함수는 이를 판정하는 도구입니다. f′ > 0이면 증가지만 그 역은 성립하지 않으며, 미분가능한 함수가 증가할 조건은 f′ ≥ 0이고 f′ = 0인 점이 구간을 이루지 않는 것입니다.

개념 정리

1. 증가는 “x가 커지면 값이 커진다” — f′ = 0 인 점이 하나 있어도 된다

y = x³ 은 원점에서 f′ = 0 이지만 왼쪽보다 오른쪽 값이 항상 큽니다. 한 점에서 잠깐 멈춰도 구간 전체로는 증가예요. 그래서 증가의 조건은 “f′ ≥ 0 이고 f′ = 0 인 점이 구간을 이루지 않는다”입니다.

왜 그럴까

  • f′ > 0 이면 증가하지만, 그 역은 필요조건이 아닙니다.
  • x³ 은 f′(0) = 0 이어도 −h 와 h 의 값을 비교하면 증가.
  • f′ = 0 이 한 구간 전체에서 성립하면 상수라 증가가 아닙니다.

움직여 보기

f′(0) = 0이어도 증가일까? — f(−h)와 f(h) 비교하기

f′(0) f(−h) f(h) f(−h) < f(h) 판정

x³은 원점에서 보라 접선이 수평(f′(0) = 0)인데도, h를 아무리 줄여도 파란 높이 f(h)가 빨간 높이 f(−h)보다 위에 있습니다. 아래 띠를 보면 f′ = 0인 곳이 점 하나뿐이라 증가입니다. x²은 0의 왼쪽에서 f′ < 0(빨강)이라 증가가 아닙니다.

2. 자주 하는 오해 바로잡기

· “도함수가 0 인 점이 있으면 증가가 아니다” → 점 하나라면 괜찮습니다.

3. 생활 속에서 · 이어지는 개념

  • 잠깐 정체해도 전체로는 계속 오르는 추세가 있습니다.
세 함수에서 f′(0) 과 f(−h), f(h) 를 비교해 증가 여부를 판정

예제

f(x) = x³ − 3x² + 3x는 실수 전체에서 증가하는가?

f′(x) = 3x² − 6x + 3 = 3(x − 1)² ≥ 0이고, f′ = 0인 점은 x = 1 하나뿐입니다. 실수 전체에서 증가한다

f(x) = x³ + ax² + 3x가 실수 전체에서 증가하도록 하는 a의 범위를 구하시오.

f′(x) = 3x² + 2ax + 3 ≥ 0이 모든 x에서 성립해야 하므로 D/4 = a² − 9 ≤ 0. a = ±3일 때도 f′ = 0인 점이 하나뿐이라 증가입니다. −3 ≤ a ≤ 3
