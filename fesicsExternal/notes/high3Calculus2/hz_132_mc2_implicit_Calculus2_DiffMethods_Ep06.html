음함수의 미분 — x² + y² = r²을 그대로 미분하면 −x/y

반지름 r인 원 위의 점을 각도로 움직이며 음함수 미분 −x/y, y에 대해 풀어 미분한 값, 수치 미분을 기록했습니다. 세 값은 원의 위쪽·아래쪽 모두에서 일치했고, y = 0인 좌우 끝에서는 접선이 수직이었습니다. y에 대해 풀지 않고 양변을 x로 미분하는 음함수 미분법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 원 위의 각도(5°~355°)와 반지름 r(1~5)을 정하고 ‘원 위에서 기울기 재기’를 누르면 점의 좌표와 세 방법의 기울기가 표에 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. x² + y² = 9 위의 점에서 기울기 (실험 예시)

2x + 2y·y′ = 0에서 y′ = −x/y 하나로 위쪽(y = √(9 − x²))과 아래쪽(y = −√(9 − x²))의 기울기를 모두 구했습니다. y에 대해 풀면 두 식을 나눠 계산해야 합니다. −x/y는 반지름의 기울기 y/x의 음의 역수로, 접선이 반지름과 수직이라는 사실과 같습니다. y = 0인 (−3, 0)에서는 접선이 수직이라 기울기가 정의되지 않습니다.

개념 정리

1. x² + y² = r² 를 그대로 미분하면 dy/dx = −x/y

y 에 대해 풀지 않고 양변을 x 로 미분하면 2x + 2y·(dy/dx) = 0 에서 dy/dx = −x/y 가 나와요. y = ±√(r²−x²) 로 풀면 위·아래를 나눠 두 번 계산해야 하지만, 음함수 미분은 한 번에 끝납니다.

왜 그럴까

  • y 가 x 의 함수라고 보고 연쇄법칙을 적용합니다: (y²)′ = 2y·y′.
  • 원의 접선은 반지름과 수직 — −x/y 가 바로 그 조건입니다.
  • y = 0 인 점(좌우 끝)에서는 접선이 수직이라 미분할 수 없습니다.

움직여 보기

원 위의 접선 기울기 −x/y — 반지름과 늘 수직

P(x, y) 음함수 미분 −x/y y로 풀어 미분 반지름 기울기 y/x

2x + 2y·y′ = 0에서 y′ = −x/y. 이 값은 위쪽(y > 0)이든 아래쪽(y < 0)이든 식 하나로 나오고, 반지름 기울기 y/x의 음의 역수라서 보라 접선은 파란 반지름과 늘 직각(주황 표시)입니다. 각도 180°(y = 0)에서는 접선이 수직이라 기울기가 없습니다. r = 3으로 두면 표 1의 값이 나옵니다.

2. 자주 하는 오해 바로잡기

· “y 에 대해 풀어야 미분할 수 있다” → 그대로 미분하면 됩니다.

3. 생활 속에서 · 이어지는 개념

  • 복잡한 관계식에서 변화율을 구할 때 표준적으로 쓰는 방법입니다.
원 위의 점을 움직이며 −x/y 와 명시적으로 푼 식의 미분, 수치 미분을 모두 비교

예제

원 x² + y² = 25 위의 점 (3, 4)에서의 접선의 방정식을 구하시오.

y′ = −x/y = −3/4. 접선 y − 4 = −(3/4)(x − 3), 정리하면 3x + 4y = 25.

곡선 x² + xy + y² = 7 위의 점 (1, 2)에서 dy/dx를 구하시오.

양변을 x로 미분: 2x + (y + xy′) + 2y·y′ = 0 → y′ = −(2x + y)/(x + 2y). (1, 2)를 넣으면 −4/5, 즉 dy/dx = −4/5.
