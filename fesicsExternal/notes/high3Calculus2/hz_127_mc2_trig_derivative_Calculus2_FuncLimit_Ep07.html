삼각함수의 도함수 — cos 쪽에만 마이너스가 붙는다

x를 π/12 간격으로 움직이며 sin x, cos x의 값과 수치 미분값을 기록했습니다. (sin x)′는 cos x와, (cos x)′는 sin x가 아니라 −sin x와 모든 점에서 일치했습니다. 삼각함수의 미분법과 부호를 그래프로 확인하는 방법을 정리합니다.

(sin x)′ 열은 cos x 열과, (cos x)′ 열은 −sin x 열과 모든 행에서 같았습니다. x = π/2에서 cos x는 내려가는 중이라 기울기가 −1입니다. 부호를 외우기보다 그래프가 오르는지 내리는지를 보면 매번 다시 만들 수 있습니다. 네 번 미분하면 sin → cos → −sin → −cos → sin으로 제자리에 돌아옵니다.

개념 정리

1. (sin x)′ = cos x, (cos x)′ = −sin x — cos 쪽에만 마이너스

sin 의 도함수는 cos 로 깔끔하지만, cos 의 도함수는 −sin 입니다. cos 는 0 근처에서 내려가고 있기 때문에 기울기가 음수예요. 그래프에서 기울기를 직접 재면 부호가 바로 보입니다.

왜 그럴까

  • x = 0 에서 cos 는 최댓값이라 기울기가 0, 그 오른쪽에서 감소하므로 음수.
  • 네 번 미분하면 제자리로 돌아옵니다: sin → cos → −sin → −cos → sin.
  • 부호를 외우기보다 그래프에서 오르내림을 보면 됩니다.

빨강 접선의 기울기를 재어 같은 x 위에 보라 점으로 찍으면 도함수 그래프가 그려집니다. cos x 는 0 에서 π 까지 내려가므로 기울기가 음수, 그래서 (cos x)′ = −sin x 입니다. sin x 로 바꾸면 보라 곡선이 cos x 가 됩니다. x 눈금은 π/12 씩이고, 표 1과 맞춰 보세요.

2. 자주 하는 오해 바로잡기

· “(sin x)′ = cos x 니까 (cos x)′ = sin x 다” → 마이너스가 붙습니다.

예제

f(x) = 2 sin x + cos x일 때 f′(π/2)를 구하시오.

f′(x) = 2 cos x − sin x이므로 f′(π/2) = 2·0 − 1 = −1.

곡선 y = cos x 위의 x = π/6인 점에서 접선의 기울기를 구하시오.

y′ = −sin x이므로 −sin(π/6) = −1/2. cos x가 이 구간에서 감소하므로 기울기가 음수인 것이 맞습니다.
