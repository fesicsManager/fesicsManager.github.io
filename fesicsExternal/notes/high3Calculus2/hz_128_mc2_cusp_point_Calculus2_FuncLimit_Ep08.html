연속과 미분가능 — 이어져도 꺾이면 미분할 수 없다

|x|, x^(2/3), x² 세 함수에서 0으로부터 떨어진 거리 h를 줄이며 x = 0의 왼쪽·오른쪽 기울기를 기록했습니다. 세 함수 모두 연속이었지만 |x|는 좌우 기울기가 −1과 1로 달랐고, x^(2/3)은 h를 줄일수록 기울기가 한없이 커졌으며, x²만 두 기울기가 0으로 모였습니다. 미분가능성과 연속성의 관계를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 함수(|x|, x^(2/3), x²)와 0에서 떨어진 거리 h(×0.005, 0.005~0.3)를 고르고 ‘좌우 기울기 재기’를 누르면 좌·우 기울기와 연속·미분가능 판정이 표에 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

세 함수 모두 x = 0에서 이어져 있지만(연속) 미분가능한 것은 x²뿐이었습니다. |x|는 h와 상관없이 좌미분계수 −1, 우미분계수 1로 달라 꺾인 점이고, x^(2/3)은 h를 줄일수록 기울기가 ±∞로 치솟는 첨점입니다. x²의 좌우 기울기는 h를 줄이면 둘 다 0으로 모입니다. 미분가능하면 연속이지만, 연속이라고 미분가능한 것은 아닙니다.

개념 정리

1. 연속은 “이어짐”, 미분가능은 “매끄러움” — 이어져도 꺾이면 미분할 수 없다

|x| 는 x = 0 에서 이어져 있지만 왼쪽 기울기가 −1, 오른쪽이 +1 로 달라 미분할 수 없어요. x^(2/3) 은 기울기가 양쪽에서 무한대로 치솟는 첨점입니다. 미분가능하면 연속이지만, 그 역은 성립하지 않습니다.

왜 그럴까

  • 미분가능 = 좌미분계수와 우미분계수가 같고 유한.
  • 꺾임(모서리), 첨점, 수직접선이 모두 미분 불가능한 경우입니다.
  • 불연속이면 당연히 미분도 불가능합니다.

움직여 보기

빨간 선은 (−h, f(−h))와 원점을, 파란 선은 원점과 (h, f(h))를 잇습니다. 함수를 바꾸고 h를 줄여 보세요. 두 기울기가 같은 값(0)으로 모이는 것은 x²뿐이고, |x|는 −1과 1 그대로, x^(2/3)은 끝없이 가팔라집니다. h = 0.1, 0.005일 때 숫자를 표 1과 맞춰 보세요.

2. 자주 하는 오해 바로잡기

· “연속이면 미분가능하다” → 꺾인 점에서는 안 됩니다.

3. 생활 속에서 · 이어지는 개념

  • 부드럽게 이어 붙이는 설계에서 “이어짐”만으로는 부족합니다.
세 함수에서 0 에 좌우로 다가가며 기울기를 재어 두 값이 같아지는지 확인

예제

f(x) = |x − 2|가 x = 2에서 연속인지, 미분가능한지 판정하시오.

lim_{x→2} f(x) = 0 = f(2)이므로 연속. 좌미분계수 −1, 우미분계수 1로 달라 연속이지만 미분가능하지 않습니다.

f(x) = x² (x < 1), ax + b (x ≥ 1)가 x = 1에서 미분가능하도록 a, b를 정하시오.

연속: 1 = a + b. 미분계수 일치: 2·1 = a. 따라서 a = 2, b = −1. 미분가능하려면 연속 조건과 좌우 미분계수 조건이 모두 필요합니다.
