역함수의 미분법 — 대응하는 점에서 (f⁻¹)′(b) = 1/f′(a)

f(x) = x³/6 + x 위의 점 (a, b)를 움직이며 f′(a)와 역함수 위 대응점 (b, a)에서의 기울기 (f⁻¹)′(b)를 재어 곱을 기록했습니다. 두 기울기의 곱은 언제나 1이었고, a와 b는 대부분 서로 다른 점이었습니다. 역함수의 미분법과 ‘어느 점에서 재는가’를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 접점의 x좌표 a(×0.25, 0.25~2.5)를 정하고 ‘두 접선 비교하기’를 누르면 b = f(a), f′(a), (f⁻¹)′(b)와 두 값의 곱이 표에 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

모든 기록에서 f′(a) × (f⁻¹)′(b) = 1이었습니다. 이때 f′은 x = a에서, (f⁻¹)′은 x = b = f(a)에서 잽니다. 같은 x에서 재면 틀립니다: a = 2일 때 (f⁻¹)′(3.333) = 1/3이지만 1/f′(3.333) ≈ 0.153입니다. f(f⁻¹(x)) = x를 미분하면 f′(f⁻¹(x))·(f⁻¹)′(x) = 1이 되어 대응점이 식에 그대로 드러납니다.

개념 정리

1. (f⁻¹)′(b) = 1 / f′(a) — 단, b = f(a) 인 “대응하는 점”에서

역함수의 도함수는 원래 도함수의 역수이지만, 어느 점에서 재느냐가 중요해요. f′ 은 x = a 에서, (f⁻¹)′ 은 x = b = f(a) 에서 재야 합니다. 같은 x 에서 재서 역수라고 하면 틀립니다.

왜 그럴까

  • 역함수의 그래프는 y = x 에 대한 대칭이라 접선의 기울기가 뒤집힙니다.
  • f(f⁻¹(x)) = x 를 미분하면 f′(f⁻¹(x))·(f⁻¹)′(x) = 1.
  • f′(a) = 0 이면 역함수의 접선이 수직이 되어 미분할 수 없습니다.

2. 자주 하는 오해 바로잡기

· “역함수의 도함수는 도함수의 역수다” → 대응하는 점에서 재야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 환율을 뒤집을 때 어느 시점의 값인지 맞춰야 하는 것과 같습니다.
a를 움직이며 f 위의 점과 대응하는 f⁻¹ 위의 점에서 기울기를 각각 재어 곱이 1 인지 확인
📋 데이터 확인 탭의 결론

“모든 기록에서 두 기울기의 곱이 1 이었습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = x³ + x의 역함수를 g라 할 때 g′(2)를 구하시오.

f(1) = 2이므로 g(2) = 1. f′(x) = 3x² + 1에서 f′(1) = 4. 따라서 g′(2) = 1/f′(1) = 1/4.

f(x) = eˣ의 역함수 ln x에 대해, 역함수의 미분법으로 x = e²에서의 미분계수를 구하시오.

f(2) = e²이므로 대응점은 a = 2. f′(2) = e²이므로 (ln x)′|_{x=e²} = 1/e². 이는 (ln x)′ = 1/x에 x = e²을 넣은 값과 같습니다.
