고등학교 미적분Ⅱ · 실험 「밑 실험실」

로그함수의 도함수 — (log_a x)′ = 1/(x ln a)

밑 a와 x를 바꾸며 y = log_a x의 수치 미분값을 1/(x ln a), 1/x와 비교해 기록했습니다. 수치 미분은 언제나 1/(x ln a)와 일치했고, ln a를 빠뜨린 1/x와는 달랐으며, 밑이 클수록 기울기가 작았습니다. 로그함수의 미분법과 자연로그가 기본이 되는 이유를 정리합니다.

모든 기록에서 수치 미분 = 1/(x ln a)였고, 1/x와는 달랐습니다. log_a x = ln x/ln a이므로 미분하면 상수 1/ln a가 곱해지기 때문입니다. 같은 x = 2에서 밑이 2 → 4 → 10으로 커지면 기울기가 0.72 → 0.36 → 0.22로 작아집니다. 밑이 e일 때만 ln e = 1이라 (ln x)′ = 1/x로 깔끔해집니다.

개념 정리

1. (log_a x)′ = 1 / (x ln a) — 밑이 다르면 도함수도 다르다

로그함수를 미분하면 1/(x ln a) 예요. 밑이 e 일 때만 ln e = 1 이라 1/x 로 깔끔해집니다. 밑이 다르면 상수 1/ln a 가 곱해져 그래프의 기울기가 전체적으로 달라집니다.

왜 그럴까

  • log_a x = ln x / ln a 이므로 미분하면 (1/ln a)·(1/x).
  • 밑이 클수록 ln a 가 커져 기울기가 작아집니다.
  • 자연로그를 기본으로 쓰는 이유가 여기 있습니다.

📋 데이터 확인 탭의 결론

“모든 기록에서 1/(x ln a) 와 일치했습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

f(x) = log₁₀ x일 때 f′(5)를 구하시오.

f′(x) = 1/(x ln 10)이므로 f′(5) = 1/(5 ln 10) ≈ 0.0869.

f(x) = ln x + log₂ x일 때 f′(1)을 구하시오.

f′(x) = 1/x + 1/(x ln 2)이므로 f′(1) = 1 + 1/ln 2 ≈ 1 + 1.4427 = 약 2.443.
