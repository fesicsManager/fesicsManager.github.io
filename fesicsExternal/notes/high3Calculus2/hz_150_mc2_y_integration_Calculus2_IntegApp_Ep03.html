고등학교 미적분Ⅱ · 실험 「y 적분 실험실」

y로 적분하기 — f의 넓이 + f⁻¹의 넓이 = 직사각형

y = x²에서 b를 바꿔 가며 ∫₀ᵇx²dx와 y로 적분한 ∫₀^(b²)√y dy를 각각 계산해 기록했습니다. 두 넓이의 합은 모든 기록에서 가로 b, 세로 b²인 직사각형의 넓이와 같았습니다. y에 대한 적분과 역함수의 넓이를 정리합니다.

f 아래 넓이(x로 적분)와 f⁻¹ 왼쪽 넓이(y로 적분)는 겹치지 않고 가로 b, 세로 f(b)인 직사각형을 채웁니다. 그래서 ∫₀ᵇf dx + ∫₀^(f(b))f⁻¹ dy = b·f(b)이고, y = x²에서는 y 적분이 항상 x 적분의 2배였습니다. 한쪽을 구하기 어려우면 직사각형에서 다른 쪽을 빼서 구할 수 있습니다.

개념 정리

1. f 의 넓이 + f⁻¹ 의 넓이 = 직사각형의 넓이

0 부터 b 까지 f 아래 넓이와, 0 부터 f(b) 까지 f⁻¹ 아래 넓이를 더하면 가로 b, 세로 f(b) 인 직사각형이 됩니다. 두 영역이 정확히 직사각형을 채우기 때문이에요. y 로 적분하는 것은 그래프를 옆으로 보는 것입니다.

왜 그럴까

  • f 와 f⁻¹ 는 y = x 대칭이라 두 넓이가 직사각형을 나눕니다.
  • ∫₀ᵇ f dx + ∫₀^f(b) f⁻¹ dy = b·f(b).
  • 한쪽이 구하기 어려우면 다른 쪽에서 빼서 구할 수 있습니다.

움직여 보기

세로로 자른 넓이 + 가로로 자른 넓이 = 직사각형

2.0
∫f dx ∫f⁻¹ dy 두 넓이의 합 직사각형 b·f(b)

파랑(곡선 아래)과 주황(곡선 왼쪽)이 빈틈없이 직사각형을 채웁니다. 그래서 x 로 구하기 쉬운 ∫x²dx 를 직사각형에서 빼면 y 로 적분하는 ∫√y dy 가 바로 나와요. b = 2 이면 8 − 8/3 = 16/3 (예제 1).

2. 자주 하는 오해 바로잡기

· “적분은 x 로만 한다” → y 로도 할 수 있고, 그편이 쉬울 때가 있습니다.

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

∫₀⁴√y dy를 ∫₀²x²dx를 이용해 구하시오.

∫₀²x²dx = 8/3이고 직사각형은 2 × 4 = 8. ∫₀⁴√y dy = 8 − 8/3. 16/3

∫₀¹eˣdx = e − 1을 이용해 ∫₁ᵉ ln y dy를 구하시오.

y = eˣ (0 ≤ x ≤ 1)의 역함수는 x = ln y (1 ≤ y ≤ e). 두 넓이의 합은 큰 직사각형 1 × e에서 작은 직사각형 0 × 1을 뺀 e입니다. ∫₁ᵉ ln y dy = e − (e − 1). 1
