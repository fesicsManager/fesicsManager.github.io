고등학교 미적분Ⅱ · 실험 「위−아래 실험실」

두 곡선 사이의 넓이 — 교점에서 나눠 ∫|f − g|dx

y = x와 y = x³/4 사이에서 구간을 바꿔 가며 교점을 찾고, 한 번에 적분한 ∫(f − g)dx와 나눠 구한 넓이 ∫|f − g|dx를 기록했습니다. 구간 안에 교점이 있으면 위아래가 바뀌어 한 번에 적분한 값이 넓이보다 작았습니다. 두 곡선 사이의 넓이를 구하는 절차를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 구간의 왼쪽과 오른쪽(0.25 간격)을 정하고 ‘교점에서 나누기’를 누르면 교점 수, 나눠 구한 넓이, 한 번에 적분한 값, 차이가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. y = x와 y = x³/4 사이 (교점 x = −2, 0, 2, 실험 예시)

x − x³/4 = x(4 − x²)/4이므로 교점은 x = −2, 0, 2이고, 이 점에서 위아래가 바뀝니다. 교점이 없는 [0, 1]에서는 두 값이 같았지만, [−1, 1]에서는 두 조각이 상쇄되어 한 번에 적분한 값이 0이었습니다. 넓이는 ∫|f − g|dx이므로 교점을 모두 찾아 나눈 뒤 구간마다 (위 − 아래)를 적분합니다.

개념 정리

1. 위아래가 바뀌는 구간이 있으면 교점에서 나눠 적분해야 한다

두 곡선이 교차하면 어느 쪽이 위인지 구간마다 달라집니다. 한 번에 (f − g) 로 적분하면 뒤바뀐 구간이 음수로 들어가 넓이가 줄어들어요. 교점을 모두 찾아 나눈 뒤 각 구간에서 위아래를 다시 정해야 합니다.

왜 그럴까

  • 넓이 = ∫|f − g| dx — 절댓값이 필요합니다.
  • f − g = 0 인 점이 위아래가 바뀌는 자리입니다.
  • 각 구간에 값을 하나 넣어 보면 어느 쪽이 위인지 알 수 있습니다.

2. 자주 하는 오해 바로잡기

· “위아래가 바뀌어도 그냥 빼면 된다” → 일부가 상쇄됩니다.

3. 생활 속에서 · 이어지는 개념

  • 두 지표의 대소가 시기마다 바뀌면 단순 차이 합계는 의미를 잃습니다.
구간을 넓혀 교점을 포함시키며, 나눠 적분한 값과 한 번에 적분한 값을 비교

예제

y = x와 y = x³/4 사이, 0 ≤ x ≤ 3 부분의 넓이를 구하시오.

x = 2에서 위아래가 바뀝니다. ∫₀²(x − x³/4)dx = 2 − 1 = 1, ∫₂³(x³/4 − x)dx = (81/16 − 9/2) − (1 − 2) = 25/16. 41/16

y = x³과 y = x로 둘러싸인 부분의 넓이를 구하시오.

교점 x = −1, 0, 1. [−1, 0]에서는 x³ ≥ x, [0, 1]에서는 x ≥ x³입니다. 대칭이므로 2∫₀¹(x − x³)dx = 2 × 1/4. 1/2
