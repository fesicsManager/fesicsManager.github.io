방정식의 실근 — 곡선과 가로선의 교점으로 센다

x³ − 6x² + 9x = k에서 가로선 y = k의 높이를 바꿔 곡선과의 교점을 세어 기록했습니다. k가 극솟값 0과 극댓값 4 사이면 실근 3개, k가 극값과 같으면 2개, 바깥이면 1개였습니다. 실근의 개수를 그래프로 판정하는 방법을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 가로선 y = k(0.1 간격)를 정하고 ‘가로선을 움직이기’를 누르면 교점 수, 극댓값, 극솟값, k의 위치가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. k에 따른 실근의 개수 (x³ − 6x² + 9x = k, 실험 예시)

f′(x) = 3(x − 1)(x − 3)이므로 극댓값 f(1) = 4, 극솟값 f(3) = 0입니다. 실근의 개수는 y = f(x)와 y = k의 교점 수이고, 개수가 바뀌는 경계는 정확히 극값의 높이입니다. k = 0이면 x = 0과 x = 3(중근)으로 서로 다른 실근이 2개입니다. 삼차 이상은 판별식 대신 이렇게 셉니다.

개념 정리

1. 방정식의 실근 개수 = 곡선과 가로선의 교점 개수

f(x) = k 의 실근은 y = f(x) 와 y = k 의 교점이에요. 가로선을 올리고 내리며 세면 되고, 개수가 바뀌는 지점이 바로 극값의 높이입니다. 판별식은 이차방정식 전용이라 여기서는 쓸 수 없습니다.

왜 그럴까

  • 극값 사이에서 가로선이 세 번 만납니다.
  • 극값과 같은 높이에서는 접하는 점이 생겨 중근이 됩니다.
  • f(x) − k = 0 으로 옮기면 “x축과 몇 번 만나나”와 같습니다.

교점 수 = 실근 k 의 위치 교점의 x

빨간 가로선이 주황 점선(극댓값 4, 극솟값 0) 사이에 있으면 교점이 3개, 점선에 닿으면 접하면서 2개, 바깥이면 1개입니다. 실근 개수가 바뀌는 경계가 바로 극값의 높이입니다.

2. 자주 하는 오해 바로잡기

· “실근은 판별식으로 센다” → 삼차 이상은 그래프로 셉니다.

가로선의 높이를 바꿔 실제 교점을 세고, 극값과의 대소로 개수를 분류

예제

방정식 x³ − 3x = k가 서로 다른 세 실근을 가질 k의 범위를 구하시오.

f(x) = x³ − 3x, f′(x) = 3(x − 1)(x + 1). 극댓값 f(−1) = 2, 극솟값 f(1) = −2. 가로선이 두 극값 사이에 있어야 합니다. −2 < k < 2

방정식 2x³ − 3x² − 12x − k = 0이 서로 다른 두 실근을 가질 k를 모두 구하시오.

f(x) = 2x³ − 3x² − 12x, f′(x) = 6(x − 2)(x + 1). 극댓값 f(−1) = 7, 극솟값 f(2) = −20. 서로 다른 두 실근은 가로선이 극값에 접할 때입니다. k = 7 또는 k = −20
