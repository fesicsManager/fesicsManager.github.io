임계점과 극값 — f′ = 0은 후보일 뿐, 부호가 바뀌어야 극값

f(x) = 3x⁵ − 5x³의 임계점 x = −1, 0, 1을 골라 좌우에서 f′의 부호를 재어 기록했습니다. x = −1에서는 + → −로 극대, x = 1에서는 − → +로 극소였지만, x = 0에서는 양쪽 모두 −라 극값이 아니었습니다. 극값 판정 절차를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 살펴볼 임계점(1~3번: x = −1, 0, 1)과 좌우 거리 h(0.05 간격)를 정하고 ‘앞뒤 부호 재기’를 누르면 왼쪽·오른쪽 f′, 부호 변화, 극값 판정이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. f(x) = 3x⁵ − 5x³의 임계점 판정 (실험 예시)
임계점 (h)왼쪽 f′오른쪽 f′부호 변화극값
x = −1 (h = 0.3)17.4915−3.7485✅극대
x = −1 (h = 0.1)3.8115−2.3085✅극대
x = 0 (h = 0.3)−1.2285−1.2285❌극값 아님
x = 0 (h = 0.1)−0.1485−0.1485❌극값 아님
x = 1 (h = 0.3)−3.748517.4915✅극소

f′(x) = 15x²(x² − 1)이므로 x = 0 좌우에서는 15x² > 0, x² − 1 < 0이라 부호가 계속 −입니다. 그래서 f′(0) = 0인데도 극값이 아니었습니다. 판정 절차는 ① f′ = 0인 점을 모두 찾고 ② 좌우의 부호를 보고 ③ + → −이면 극대, − → +이면 극소, 그대로면 극값 아님입니다.

개념 정리

1. f′ = 0 인 점은 극값의 “후보”일 뿐 — 부호가 바뀌어야 극값

임계점(f′ = 0)에는 극대, 극소, 그리고 어느 쪽도 아닌 점이 있어요. 부호가 + → − 면 극대, − → + 면 극소, 바뀌지 않으면 그냥 평평하게 지나갑니다. f(x) = 3x⁵ − 5x³ 처럼 임계점이 여러 개인 함수에서 세 경우가 모두 나옵니다.

왜 그럴까

  • f′ 의 부호가 함수의 오르내림을 정합니다.
  • 부호가 그대로면 잠깐 멈췄다 같은 방향으로 계속 갑니다.
  • f″ 로도 판정할 수 있지만 f″ = 0 이면 다시 부호를 봐야 합니다.

2. 자주 하는 오해 바로잡기

· “f′(a) = 0 이면 극값이다” → 세 가지 중 하나일 뿐입니다.

3. 생활 속에서 · 이어지는 개념

  • 변화가 잠시 멈춘 지점이 반드시 전환점은 아닙니다.
임계점 세 곳을 골라 좌우의 도함수 부호를 재고 극값 여부를 판정

예제

f(x) = x⁴ − 4x³의 임계점을 구하고 각각 극값인지 판정하시오.

f′(x) = 4x³ − 12x² = 4x²(x − 3). x = 0 좌우에서 f′ < 0으로 부호 변화가 없어 극값이 아니고, x = 3에서는 − → +라 극소, f(3) = −27. x = 0: 극값 아님, x = 3: 극솟값 −27

f(x) = 3x⁵ − 5x³의 극댓값과 극솟값을 구하시오.

x = −1에서 + → −이므로 극대, f(−1) = −3 + 5 = 2. x = 1에서 − → +이므로 극소, f(1) = 3 − 5 = −2. 극댓값 2, 극솟값 −2
