곱의 미분법 — (fg)′ = f′g + fg′, 미분끼리 곱하지 않는다

f(x) = x² + a, g(x) = 2x + 3의 곱에서 x와 a를 바꾸며 수치 미분값을 f′g + fg′, f′g′와 비교해 기록했습니다. 수치 미분은 언제나 f′g + fg′와 일치했고 f′g′와는 크게 어긋났습니다. 넓이 모델로 곱의 미분법이 두 조각의 합인 이유를 정리합니다.

모든 기록에서 수치 미분 = f′g + fg′였고, f′g′와의 차이는 x가 커질수록 벌어졌습니다. 가로 f, 세로 g인 직사각형에서 두 변이 동시에 늘면 늘어난 넓이는 f′g·Δx와 fg′·Δx 두 띠의 합이고, 모퉁이 f′g′·Δx²는 Δx → 0에서 다른 항보다 훨씬 빨리 사라집니다. 세 함수의 곱도 (fgh)′ = f′gh + fg′h + fgh′처럼 하나씩 미분해 더합니다.

개념 정리

1. (fg)′ = f′g + fg′ — 미분끼리 곱하는 것이 아니다

곱의 미분은 한쪽씩 번갈아 미분해 더합니다. f′g′ 처럼 미분끼리 곱하면 전혀 다른 값이 나와요. 두 함수가 동시에 변하므로, 각각이 만드는 변화를 모두 더해야 합니다.

왜 그럴까

  • 넓이 모델 — 가로 f, 세로 g 인 직사각형에서 두 변이 동시에 늘어납니다.
  • 늘어난 넓이 ≈ f′g·Δx + fg′·Δx (두 조각).
  • f′g′ 는 모퉁이의 아주 작은 조각이라 극한에서 사라집니다.

예제

f(x) = x² sin x일 때 f′(π)를 구하시오.

f′(x) = 2x sin x + x² cos x이므로 f′(π) = 2π·0 + π²·(−1) = −π².

f(x) = x eˣ일 때 f′(1)을 구하시오.

f′(x) = 1·eˣ + x·eˣ = (x + 1)eˣ이므로 f′(1) = 2e.
