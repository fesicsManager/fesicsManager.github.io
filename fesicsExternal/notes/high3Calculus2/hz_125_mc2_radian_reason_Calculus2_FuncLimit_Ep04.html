고등학교 미적분Ⅱ · 실험 「각 단위 실험실」

라디안과 sin x/x — 1로 가는 것은 라디안일 때뿐

같은 수 x를 라디안과 도로 각각 해석해 sin x/x와 sin x°/x를 계산하며 x를 0 쪽으로 줄여 기록했습니다. 라디안으로 잰 값은 1에 다가갔지만 도로 잰 값은 π/180 ≈ 0.01745에 머물렀습니다. lim_{x→0} sin x/x = 1이 라디안에서만 성립하는 까닭과 미적분에서 라디안을 쓰는 이유를 정리합니다.

실험 안내: 자유 탐구 탭에서 x(×0.01, 0.01~1)를 정하고 ‘두 단위로 재기’를 누르면 라디안과 도로 계산한 두 값이 표에 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

x를 줄일수록 라디안 값은 1에, 도 값은 π/180 ≈ 0.01745에 붙었습니다. x° = xπ/180 라디안이라 sin x°/x = (π/180)·(sin θ/θ)로 계수 π/180이 남기 때문입니다. 라디안은 호의 길이를 반지름으로 잰 값이어서 작은 각에서 호와 sin 값(높이)이 거의 같아지고, 그래서 (sin x)′ = cos x처럼 공식이 깔끔해집니다.

개념 정리

1. sin x / x → 1 은 x 가 라디안일 때만 성립

각을 도로 재면 sin x° / x → π/180 ≈ 0.01745 가 돼요. 1 이 아닙니다. 라디안은 “호의 길이를 반지름으로 잰 값”이라 작은 각에서 호와 현이 같아지고, 그래서 비가 1 로 갑니다. 미분 공식이 깔끔한 것도 이 때문입니다.

왜 그럴까

  • x 라디안일 때 호의 길이가 x, sin x 는 현의 절반에 해당하는 높이입니다.
  • x → 0 이면 호와 직선이 구별되지 않아 비가 1.
  • 도로 재면 x° = xπ/180 라디안이라 계수가 남습니다.

2. 자주 하는 오해 바로잡기

· “각의 단위는 결과를 바꾸지 않는다” → 미분 공식이 통째로 달라집니다.

3. 생활 속에서 · 이어지는 개념

  • 물리·공학에서 각을 언제나 라디안으로 쓰는 이유입니다.
같은 x 를 라디안과 도로 각각 해석해 sin x / x 를 계산하고 비교

예제

lim_{x→0} sin 4x/(2x)의 값을 구하시오. (x는 라디안)

sin 4x/(2x) = 2·(sin 4x/4x) → 2·1 = 2.

각을 도로 잴 때 lim_{x→0} sin x°/x의 값과, 이때 (sin x°)′가 어떻게 되는지 쓰시오.

sin x°/x = (π/180)·sin(πx/180)/(πx/180) → π/180. 같은 이유로 (sin x°)′ = (π/180)cos x°가 되어 모든 공식에 계수가 붙습니다.

x = 0.01일 때 기록된 두 값으로 옳은 것은?

작은 x에서 라디안은 1, 도는 π/180.

lim_{x→0} sin x/x = 1이 성립하는 조건은?

라디안은 호의 길이/반지름이라 작은 각에서 호 ≈ 높이.

3번· 적용

lim_{x→0} sin 5x/x의 값은? (x는 라디안)

sin 5x/x = 5·(sin 5x/5x) → 5.

그래서 미적분에서는 라디안을 씁니다.
