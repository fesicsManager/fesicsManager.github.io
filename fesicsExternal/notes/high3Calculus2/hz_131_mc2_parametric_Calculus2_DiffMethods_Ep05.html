매개변수로 나타낸 함수의 미분 — dy/dx = (dy/dt)/(dx/dt)

x = t² − 1, y = t³ − 3t인 곡선에서 t를 바꾸며 점의 좌표와 dx/dt, dy/dt, dy/dx를 기록했습니다. t를 소거하지 않고도 두 도함수를 나누어 기울기를 구했고, dx/dt = 0인 t = 0에서는 접선이 수직, dy/dt = 0인 t = ±1에서는 수평이었습니다. 매개변수로 나타낸 함수의 미분법을 정리합니다.

dx/dt = 2t, dy/dt = 3t² − 3이므로 dy/dx = (3t² − 3)/(2t)로 t를 소거하지 않고 기울기를 구했습니다. dy/dt = 0인 t = ±1에서는 접선이 수평, dx/dt = 0인 t = 0에서는 접선이 수직입니다. t = −2와 t = 2는 x가 같아도 y와 기울기가 다른 서로 다른 점이고, 이 곡선은 t = ±√3에서 점 (2, 0)을 두 번 지나 그 점에서 접선이 둘입니다.

개념 정리

1. dy/dx = (dy/dt) / (dx/dt) — t 를 없애지 않고도 기울기를 구한다

x 와 y 가 모두 t 의 함수일 때, 접선의 기울기는 각각을 t 로 미분해 나누면 됩니다. t 를 소거해 y = f(x) 로 고칠 필요가 없어요. 소거가 아예 불가능한 곡선에서도 이 방법은 통합니다.

왜 그럴까

  • 연쇄법칙: dy/dt = (dy/dx)(dx/dt) 이므로 나누면 dy/dx.
  • dx/dt = 0 인 점에서는 접선이 수직이 됩니다.
  • 사이클로이드처럼 소거가 어려운 곡선에서 특히 유용합니다.

움직여 보기

dy/dx = (dy/dt) ÷ (dx/dt) — 가로·세로로 움직이는 빠르기의 비

점 (x, y) dx/dt = 2t dy/dt = 3t² − 3 dy/dx

주황 화살표(가로 빠르기 dx/dt)와 초록 화살표(세로 빠르기 dy/dt)를 이으면 보라 화살표, 곧 접선 방향이 됩니다. 기울기 = 세로 ÷ 가로라서 t를 없애지 않아도 됩니다. t = ±1에서는 초록이 0(수평 접선), t = 0에서는 주황이 0(수직 접선)이 되는 것을 확인해 보세요. (화살표 길이는 실제 값의 0.35배)

2. 자주 하는 오해 바로잡기

· “매개변수는 소거해야 미분할 수 있다” → 나누기만 하면 됩니다.

3. 생활 속에서 · 이어지는 개념

  • 시간에 따른 x·y 위치가 주어진 운동의 진행 방향을 구하는 방법입니다.
t를 움직이며 점의 위치와 두 도함수를 재어 기울기를 구하고, 실제 접선과 비교

예제

x = 2t + 1, y = t² − t일 때 t = 2에 대응하는 점에서 dy/dx를 구하시오.

dx/dt = 2, dy/dt = 2t − 1 → dy/dx = (2t − 1)/2. t = 2이면 3/2.

x = cos t, y = sin t (원)에서 t = π/4인 점의 접선 기울기를 구하시오.

dx/dt = −sin t, dy/dt = cos t → dy/dx = −cos t/sin t. t = π/4이면 −1. 점 (√2/2, √2/2)에서 반지름에 수직인 방향과 일치합니다.
