고등학교 미적분Ⅱ · 실험 「xˣ 실험실」

로그미분법 — 밑과 지수에 모두 x가 있을 때

y = xˣ에서 x를 바꾸며 수치 미분값을 xˣ(ln x + 1), 거듭제곱 공식 x·xˣ⁻¹, 지수함수 공식 xˣ ln x와 비교해 기록했습니다. 수치 미분과 맞은 것은 xˣ(ln x + 1)뿐이었고, 틀린 두 공식의 합이 정답과 같았습니다. 양변에 로그를 취해 미분하는 로그미분법을 정리합니다.

xⁿ 공식(지수를 상수로 봄)도, aˣ 공식(밑을 상수로 봄)도 단독으로는 맞지 않았고, 두 값의 합 x·xˣ⁻¹ + xˣ ln x = xˣ(ln x + 1)이 정답이었습니다. 밑과 지수가 모두 변하므로 두 몫을 다 더해야 합니다. 로그미분법: ln y = x ln x → y′/y = ln x + 1 → y′ = xˣ(ln x + 1). x = 0.3에서 기울기가 음수인 것은 x = 1/e에서 최솟값을 갖기 때문입니다.

개념 정리

1. 밑과 지수에 모두 x 가 있으면 거듭제곱 공식도 지수함수 공식도 쓸 수 없다

xⁿ 은 밑만 변수, aˣ 는 지수만 변수예요. xˣ 는 둘 다 변수라 두 공식 모두 통하지 않습니다. 양변에 로그를 씌워 ln y = x ln x 로 만든 뒤 음함수 미분하면 y′ = xˣ(ln x + 1) 이 나옵니다.

왜 그럴까

  • ln y = x ln x 를 x 로 미분하면 y′/y = ln x + 1.
  • 양변에 y = xˣ 를 곱하면 y′ = xˣ(ln x + 1).
  • 로그가 지수를 앞으로 내려 곱셈을 덧셈으로 바꿔 줍니다.

움직여 보기

y = xˣ의 기울기 — 두 공식의 몫을 더해야 맞는다

y = xˣ ln x + 1 ①, ② 단독과 실제의 차이

밑과 지수가 함께 변하므로 ‘지수만 고정’(①)도 ‘밑만 고정’(②)도 혼자서는 실제 기울기와 다릅니다. 두 몫을 이어 붙인 ①+② 막대가 맨 아래 실제 기울기 막대와 길이가 똑같습니다. x < 1/e ≈ 0.37이면 음수인 ②의 크기가 ①보다 커서 합이 음수(왼쪽)가 됩니다. 막대 눈금은 x마다 다시 맞춥니다.

2. 자주 하는 오해 바로잡기

· “xˣ 는 미분할 수 없다” → 로그를 씌우면 됩니다.

📋 데이터 확인 탭의 결론

“xˣ(ln x + 1) 만 수치 미분과 일치했습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

y = x^(sin x) (x > 0)일 때 x = π/2에서 y′을 구하시오.

ln y = sin x·ln x → y′/y = cos x·ln x + sin x/x. x = π/2이면 y = π/2, 괄호 = 0 + 1/(π/2) = 2/π. 따라서 y′ = (π/2)(2/π) = 1.

y = xˣ (x > 0)이 최솟값을 갖는 x를 구하시오.

y′ = xˣ(ln x + 1) = 0 → ln x = −1 → x = 1/e. 이 점의 왼쪽에서 y′ < 0, 오른쪽에서 y′ > 0이므로 최소입니다.
