최댓값과 끝값 — 극값과 양 끝값을 모두 비교한다

f(x) = x·e^(−x/2)에서 닫힌구간을 바꿔 가며 극댓값과 양 끝값을 모두 계산해 최댓값의 위치를 기록했습니다. 구간이 극대점 x = 2를 포함하면 극댓값 2/e ≈ 0.736이 최댓값이었지만, 포함하지 않으면 구간이 x = 2의 왼쪽에 있을 때는 오른쪽 끝, 오른쪽에 있을 때는 왼쪽 끝에서 최댓값이 나왔습니다. 최댓값을 구하는 절차를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 구간의 왼쪽 끝과 오른쪽 끝(0.25 간격)을 정하고 ‘후보를 모두 비교’를 누르면 극댓값, 양 끝값, 최댓값과 그 위치가 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

f′(x) = e^(−x/2)(1 − x/2)이므로 x = 2에서만 극대입니다. 구간 [0, 1.5]처럼 극대점이 구간 밖이면 f가 계속 증가해 오른쪽 끝값이 최댓값이 되고, [2.5, 4]처럼 구간이 x = 2보다 오른쪽이면 f가 계속 감소해 왼쪽 끝값이 최댓값이 됩니다. 닫힌구간에서 연속이면 최대·최소 정리로 최댓값이 반드시 존재하고, 그 위치는 구간 안의 극값과 양 끝값을 모두 비교해 정합니다.

개념 정리

1. 최댓값의 후보는 극값과 양 끝값 — 모두 비교해야 한다

닫힌구간에서 연속이면 최댓값이 반드시 존재하지만, 그 자리가 극대점이라는 보장은 없어요. 구간의 끝에서 더 큰 값이 나올 수 있습니다. 후보를 빠짐없이 모아 비교하는 것이 전부입니다.

왜 그럴까

  • 극값은 국소적 최대, 끝값은 경계의 값입니다.
  • 최대·최소 정리가 존재를 보장하고, 비교가 위치를 정합니다.
  • 구간이 열려 있으면 최댓값이 없을 수도 있습니다.

2. 자주 하는 오해 바로잡기

· “극값 중에 최댓값이 있다” → 끝값이 더 클 수 있습니다.

3. 생활 속에서 · 이어지는 개념

  • 가능한 범위의 경계에서 최선이 나오는 경우가 많습니다.
구간을 옮겨 가며 극값과 두 끝값을 모두 계산해 최댓값의 위치를 확인

예제

f(x) = x³ − 3x의 구간 [−1, 3]에서의 최댓값과 최솟값을 구하시오.

f′(x) = 3(x − 1)(x + 1). 구간 안의 임계점 x = 1에서 f(1) = −2, 끝값 f(−1) = 2, f(3) = 18. 최댓값 18 (x = 3), 최솟값 −2 (x = 1)

f(x) = x·e^(−x/2)의 구간 [0, 1]에서의 최댓값을 구하시오.

[0, 1]에서 f′(x) = e^(−x/2)(1 − x/2) > 0이므로 증가합니다. 최댓값은 오른쪽 끝값 f(1) = e^(−1/2). 1/√e ≈ 0.607
