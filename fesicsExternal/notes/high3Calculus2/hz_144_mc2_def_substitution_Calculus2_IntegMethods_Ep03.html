고등학교 미적분Ⅱ · 실험 「구간 실험실」

정적분의 치환 — 적분 구간도 t의 범위로 바꾼다

∫ₐᵇ(2x + 1)²dx를 t = 2x + 1로 치환하면서 구간을 [2a + 1, 2b + 1]로 바꾼 값, 구간을 그대로 둔 값, 수치 적분값을 비교해 기록했습니다. 구간을 바꾼 값만 수치 적분과 일치했고, 그대로 둔 값은 전혀 다른 영역을 적분한 것이었습니다. 정적분 치환의 두 가지 올바른 방법을 정리합니다.

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 원래 구간의 왼쪽과 오른쪽(0.5 간격)을 정하고 ‘구간을 바꿔 보기’를 누르면 치환 후 구간, 구간을 바꾼 값, 그대로 둔 값, 수치 적분값이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

t = 2x + 1이면 dx = dt/2이므로 ∫ₐᵇ(2x + 1)²dx = ∫(t²/2)dt이고, 이때 구간은 x = a, b일 때의 t 값 2a + 1, 2b + 1입니다. 예를 들어 [0, 2]는 ∫₁⁵(t²/2)dt = (125 − 1)/6 = 20.6667입니다. 구간을 바꾸기 싫다면 부정적분을 구해 x로 되돌린 뒤 원래 구간을 대입해도 같은 값입니다.

개념 정리

1. 정적분을 치환하면 적분 구간도 t 의 값으로 바꿔야 한다

∫ₐᵇ f(2x+1)dx 를 t = 2x+1 로 치환하면, 구간도 t 의 범위 [2a+1, 2b+1] 로 바뀌어요. 원래 구간을 그대로 두면 전혀 다른 영역을 적분하게 됩니다. 아니면 다시 x 로 되돌린 뒤 원래 구간을 쓰면 됩니다.

왜 그럴까

  • x = a 일 때 t = 2a+1, x = b 일 때 t = 2b+1.
  • 치환은 변수를 바꾼 것이므로 구간도 그 변수의 값이어야 합니다.
  • 부정적분으로 구한 뒤 x 로 되돌려 대입해도 같은 결과입니다.

x 구간 [a, b] 가 t 구간 [2a+1, 2b+1] 로 — 넓이는 그대로

02
치환 후 구간 구간 바꾼 값 그대로 둔 값 수치 적분

두 그림은 가로 눈금 간격과 세로 높이 비율이 같습니다. t = 2x + 1 로 바꾸면 그래프 높이는 절반(t²/2), 구간 폭은 두 배가 되어 넓이가 같습니다(파랑 = 보라). 구간을 [a, b] 그대로 두면(빨간 점선) 전혀 다른 작은 값이 나옵니다.

2. 자주 하는 오해 바로잡기

· “치환해도 적분 구간은 그대로다” → 새 변수의 범위로 바꿔야 합니다.

3. 생활 속에서 · 이어지는 개념

  • 단위를 바꾸면 범위도 함께 바뀌어야 하는 것과 같습니다.

예제

∫₀¹(2x + 1)²dx를 치환으로 구하시오.

t = 2x + 1, dx = dt/2, x: 0 → 1이면 t: 1 → 3. ∫₁³(t²/2)dt = (27 − 1)/6. 13/3

∫₀¹ x(x² + 1)³dx를 구하시오.

t = x² + 1, dt = 2x dx, x: 0 → 1이면 t: 1 → 2. ∫₁²(t³/2)dt = (16 − 1)/8. 15/8
