구간 나누기 — 합은 같지만 반으로 나눠도 값은 반이 아니다

f(x) = x²의 [0, b] 구간을 나누는 점 c를 옮겨 가며 두 조각의 적분값과 합을 기록했습니다. 어디서 나눠도 두 조각의 합은 전체와 같았지만, 가운데에서 나눴을 때 왼쪽 조각은 전체의 12.5%뿐이었습니다. 구간의 분할 성질과 그 한계를 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 나눌 지점 c와 구간 오른쪽 b(0.25 간격)를 정하고 ‘구간을 나눠 더하기’를 누르면 왼쪽 적분, 오른쪽 적분, 합, 원래 값이 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

표 1. ∫₀ᵇx²dx를 c에서 나누기 (실험 예시)

∫ₐᵇf dx = ∫ₐᶜf dx + ∫ᶜᵇf dx는 c의 위치와 상관없이 성립했습니다. 그러나 가운데에서 나눈 세 기록 모두 왼쪽 비율은 (1/2)³ = 12.5%였습니다. x²은 오른쪽으로 갈수록 높아지므로 구간 길이가 같아도 적분값은 같지 않습니다. 이 성질은 |x − 1|처럼 식이 바뀌는 함수를 나눠 적분할 때 씁니다.

개념 정리

1. ∫ₐᵇ = ∫ₐᶜ + ∫ᶜᵇ 는 언제나 성립 — 하지만 반으로 나눠도 값이 반은 아니다

구간을 어디서 나누든 두 조각의 합은 전체와 같습니다. 하지만 구간을 반으로 나눈다고 값이 반이 되지는 않아요. 조각마다 함수의 높이가 다르기 때문입니다. 이 실험의 f(x) = x² 에서는 왼쪽 조각이 훨씬 작습니다.

왜 그럴까

  • 적분은 “넓이를 더하기”라 구간을 붙이면 넓이가 더해집니다.
  • 나눈 점의 위치는 합에 영향을 주지 않습니다.
  • c 가 구간 밖에 있어도 부호 규칙으로 성립합니다.

2. 자주 하는 오해 바로잡기

· “구간을 반으로 나누면 값도 반이다” → 함수 모양에 따라 다릅니다.

3. 생활 속에서 · 이어지는 개념

  • 전체 기간을 반으로 나눠도 실적이 반씩 나뉘지는 않습니다.
나누는 지점을 옮겨 가며 두 조각의 적분값과 합을 계산해 원래 값과 비교
📋 데이터 확인 탭의 결론

“어디서 나눠도 두 조각의 합이 전체와 같았습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

∫₀³|x − 1|dx를 구하시오.

x = 1에서 나눕니다. ∫₀¹(1 − x)dx + ∫₁³(x − 1)dx = 1/2 + 2. 5/2

∫₀¹f(x)dx = 2, ∫₀³f(x)dx = 7일 때 ∫₁³f(x)dx와 ∫₃¹f(x)dx를 구하시오.

∫₀³ = ∫₀¹ + ∫₁³이므로 ∫₁³ = 7 − 2 = 5. 위끝과 아래끝을 바꾸면 부호가 바뀝니다. 5, −5
