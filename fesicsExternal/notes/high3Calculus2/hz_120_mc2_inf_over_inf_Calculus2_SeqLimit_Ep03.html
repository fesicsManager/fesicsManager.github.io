고등학교 미적분Ⅱ · 실험 「속도 실험실」

∞/∞ 꼴의 극한 — 최고차항의 급이 결과를 정한다

(3nᵖ + 5nᵖ⁻¹)/(2n^q + 7n^(q−1))에서 분자 차수 p, 분모 차수 q와 n을 바꾸며 값과 극한을 기록했습니다. 차수가 같으면 값은 1이 아니라 최고차항 계수의 비 3/2에 다가갔고, 분자 차수가 크면 ∞, 작으면 0으로 갔습니다. ∞/∞ 꼴 극한을 최고차항으로 나누어 구하는 방법을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 분자의 차수(1~4), 분모의 차수(1~4), n(×10, 10~2000)을 정하고 ‘커지는 속도 겨루기’를 누르면 그 n에서의 값과 극한이 표에 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

분자·분모가 모두 한없이 커져도 비가 1이 되지는 않습니다. 차수가 같을 때 n = 10에서는 1.30이었지만 n이 커질수록 최고차항 계수의 비 3/2에 붙었습니다. 분모의 최고차항 n^q로 분자·분모를 나누면 나머지 항이 0으로 사라져 분자 차수 > 분모 차수 → ∞, 분자 차수 < 분모 차수 → 0, 같으면 계수의 비가 바로 보입니다.

개념 정리

1. ∞/∞ 는 최고차항의 “급”이 정한다 — 1 이 아니다

분자와 분모가 모두 무한히 커져도, 커지는 속도가 다르면 비는 1 이 아니에요. 분자의 차수가 크면 ∞, 작으면 0, 같으면 최고차항 계수의 비가 됩니다. 분모의 최고차항으로 나눠 보면 바로 보입니다.

왜 그럴까

  • 분자·분모를 n의 최고차수로 나누면 나머지 항이 0 으로 사라집니다.
  • 같은 차수면 계수의 비만 남습니다.
  • 지수함수는 어떤 다항식보다도 빠르게 커집니다.

2. 자주 하는 오해 바로잡기

· “무한대끼리 나누면 1 이다” → 속도의 급이 결과를 정합니다.

3. 생활 속에서 · 이어지는 개념

  • 두 양이 모두 늘어날 때 비율이 어디로 가는지가 실제 의미를 갖습니다.
분자·분모의 차수를 바꿔 n을 키우며 값을 추적하고, 최고차항 비와 비교

예제

lim (4n³ − n)/(2n³ + 5n²)의 값을 구하시오.

분자·분모를 n³으로 나누면 (4 − 1/n²)/(2 + 5/n) → 4/2 = 2.

lim √(9n² + 1)/(2n − 1)의 값을 구하시오.

분자·분모를 n으로 나누면 √(9 + 1/n²)/(2 − 1/n) → √9/2 = 3/2. 근호 안의 n²은 근호 밖에서 n 한 번과 같은 급입니다.
