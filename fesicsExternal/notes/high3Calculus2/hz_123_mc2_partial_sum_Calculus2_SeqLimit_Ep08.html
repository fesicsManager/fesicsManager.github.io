부분합과 일반항 — Sₙ은 누적, aₙ은 그 자리의 값

Sₙ = n² + kn에서 n과 k를 바꾸며 Sₙ, Sₙ₋₁, 그 차이 aₙ, 복원한 항의 합을 기록했습니다. n = 1일 때만 S₁ = a₁이었고 그 뒤로는 두 값이 계속 벌어졌으며, 복원한 항을 다 더하면 정확히 Sₙ으로 돌아왔습니다. aₙ = Sₙ − Sₙ₋₁ 관계와 급수 수렴의 정의를 정리합니다.

Sₙ은 3, 8, 15, …로 빠르게 쌓이는 누적값이고, aₙ은 3, 5, 7, …로 그 자리의 값(= 2n + 1)입니다. a₁ = S₁, n ≥ 2에서 aₙ = Sₙ − Sₙ₋₁이며, 복원한 항을 다 더하면 다시 Sₙ이 됩니다. 급수 Σaₙ의 수렴은 부분합 Sₙ의 수렴으로 정의합니다.

개념 정리

1. Sₙ 은 “여기까지의 합”, aₙ 은 “n번째 항 하나” — 다른 수열이다

Sₙ 은 a₁ 부터 aₙ 까지 모두 더한 값이고, aₙ 은 그 자리 하나의 값이에요. 둘의 관계는 aₙ = Sₙ − Sₙ₋₁ (n ≥ 2). 두 수열을 함께 그려 보면 전혀 다른 모양입니다.

왜 그럴까

  • S 는 누적, a 는 증분 — 미분과 적분의 관계와 같습니다.
  • a₁ = S₁ 은 따로 확인해야 합니다.
  • 급수의 수렴은 Sₙ 의 수렴으로 정의됩니다.

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

Sₙ = n² + 2n + 1일 때 일반항 aₙ을 구하시오.

n ≥ 2에서 aₙ = Sₙ − Sₙ₋₁ = 2n + 1. 그런데 a₁ = S₁ = 4이고 2·1 + 1 = 3이라 맞지 않습니다. 따라서 a₁ = 4, aₙ = 2n + 1 (n ≥ 2). a₁은 반드시 따로 확인합니다.

Sₙ = n/(n + 1)인 급수 Σaₙ에서 a₅와 급수의 합을 구하시오.

a₅ = S₅ − S₄ = 5/6 − 4/5 = 1/30. 급수의 합은 lim Sₙ = lim n/(n + 1) = 1.
