몫의 미분법 — 분자의 순서가 바뀌면 부호가 뒤집힌다

f(x) = x² + a, g(x) = x + b의 몫 f/g에서 x, a, b를 바꾸며 수치 미분값을 (f′g − fg′)/g², (fg′ − f′g)/g²와 비교해 기록했습니다. 수치 미분은 언제나 f′g − fg′ 순서와 일치했고, 순서를 바꾼 값은 부호만 반대였습니다. 몫의 미분법과 그 순서를 정리합니다.

수치 미분과 맞은 것은 (f′g − fg′)/g²뿐이고, 순서를 바꾼 값은 언제나 부호만 반대였습니다. g²은 양수라 부호는 분자가 정하므로, 빼기의 순서(f′g가 먼저)가 답을 정합니다. 미분끼리 나눈 f′/g′는 한 번도 맞지 않았습니다. 검산: g = 1로 두면 (f/1)′ = f′이 나와야 합니다.

개념 정리

1. (f/g)′ = (f′g − fg′) / g² — 분자의 순서가 바뀌면 부호가 반대

몫의 미분법은 분자에서 f′g 가 먼저, fg′ 가 나중입니다. 순서를 바꾸면 전체 부호가 반대가 돼요. 곱의 미분법 (fg)′ = f′g + fg′ 는 더하기라 순서가 상관없지만, 몫은 빼기라 순서가 결과를 정합니다.

왜 그럴까

  • f/g = f·g⁻¹ 로 두고 곱의 법칙과 연쇄법칙을 쓰면 유도됩니다.
  • g² 이 분모라 양수이므로 부호는 분자가 정합니다.
  • g = 1 이면 (f)′ 로 돌아옵니다 — 검산에 쓸 수 있습니다.

2. 자주 하는 오해 바로잡기

· “몫의 미분은 미분끼리 나눈 것이다” → 전혀 다른 식입니다.

📋 데이터 확인 탭의 결론

“f′g − fg′ 쪽만 수치 미분과 일치했습니다.”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

y = x/(x² + 1)의 도함수와 x = 0에서의 미분계수를 구하시오.

y′ = (1·(x² + 1) − x·2x)/(x² + 1)² = (1 − x²)/(x² + 1)². x = 0이면 1.

tan x = sin x/cos x를 몫의 미분법으로 미분하시오.

(cos x·cos x − sin x·(−sin x))/cos²x = (cos²x + sin²x)/cos²x = 1/cos²x = sec²x.

순서를 바꾸면 부호만 반대.

2번· 핵심 개념

(f/g)′ (g ≠ 0)로 옳은 것은?

분자는 ‘위를 먼저 미분’ — f′g가 앞.

3번· 적용

y = (x + 1)/(x − 1)의 x = 2에서 미분계수는?

y′ = −2/(x − 1)² → −2.
