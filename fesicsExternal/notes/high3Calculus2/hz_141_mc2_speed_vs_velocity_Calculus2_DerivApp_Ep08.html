속도와 속력 — v와 a의 부호가 같으면 빨라진다

위치 x(t) = t³/3 − 1.5t² + 2t로 움직이는 점의 시각 t를 바꿔 속도 v, 속력 |v|, 가속도 a를 기록했습니다. a < 0이어도 v < 0이면 빨라졌고, a > 0이어도 v < 0이면 느려졌습니다. 속력의 증감을 판정하는 방법을 정리합니다.

t = 1.2에서는 v < 0, a < 0으로 부호가 같아 속력이 커졌고, t = 1.8에서는 v < 0, a > 0이라 느려졌습니다. 속력 |v|는 속도에서 부호만 뗀 값이지만, 속력의 증감은 v·a의 부호로 정해집니다. v = 0인 t = 1, 2에서 점은 방향을 바꾸고 |v|의 그래프는 꺾입니다.

개념 정리

1. 속력은 |v| — 부호를 뗀 값이지만, 미분하면 전혀 다른 함수

속력 = |속도| 는 맞아요. 하지만 속력의 변화는 가속도의 부호만으로 정해지지 않습니다. v 와 a 의 부호가 같으면 빨라지고, 다르면 느려집니다. v = 0 인 순간에 속력 그래프는 꺾입니다.

왜 그럴까

  • v > 0, a > 0 → 빨라짐 / v > 0, a < 0 → 느려짐
  • v = 0 인 순간은 멈췄다가 방향이 바뀌는 자리, a = 0 인 순간은 속력이 늘지도 줄지도 않는 자리라 “빨라짐/느려짐” 어느 쪽도 아닙니다.
  • v < 0, a < 0 → (뒤로) 빨라짐 / v < 0, a > 0 → 느려짐
  • |v| 는 v = 0 에서 미분불가능한 꺾인 점이 생깁니다.

2. 자주 하는 오해 바로잡기

· “속력은 속도에서 부호만 뗀 것이다” → 값은 맞지만 변화의 성질이 다릅니다.

3. 생활 속에서 · 이어지는 개념

  • 후진하며 가속하면 속도는 더 음수가 되지만 속력은 커집니다.

예제

위치가 x(t) = t³/3 − 1.5t² + 2t인 점의 속력이 증가하는 시간 범위를 구하시오 (t > 0).

v = (t − 1)(t − 2), a = 2t − 3. v·a > 0이어야 합니다. 0 < t < 1: v > 0, a < 0 (느려짐). 1 < t < 1.5: v < 0, a < 0 (빨라짐). 1.5 < t < 2: v < 0, a > 0 (느려짐). t > 2: 둘 다 양수 (빨라짐). 1 < t < 1.5, t > 2

속도가 v(t) = −2t + 2인 점은 t = 3에서 빨라지는가, 느려지는가?

v(3) = −4, a = −2로 부호가 같습니다. 속력 |v|는 4이고 커지는 중입니다. 빨라진다
