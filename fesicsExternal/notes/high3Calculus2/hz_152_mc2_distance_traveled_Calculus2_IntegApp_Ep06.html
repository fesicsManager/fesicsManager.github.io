변위와 이동 거리 — ∫v dt와 ∫|v| dt

속도가 v(t) = 2 cos(πt/3)인 점에서 끝 시각 T를 바꿔 가며 변위 ∫v dt와 이동 거리 ∫|v| dt를 기록했습니다. v가 양수인 동안(T ≤ 1.5)은 두 값이 같았지만, 되돌아오는 구간이 생기자 이동 거리가 더 커졌고 T = 3, 6에서는 변위가 0이었습니다. 위치의 변화량과 움직인 거리를 구별해 정리합니다.

v는 t = 1.5, 4.5에서 0이 되며 부호가 바뀝니다. ∫v dt는 위치의 변화량(변위)이라 뒤로 간 부분이 빠지고, ∫|v| dt는 실제 이동 거리라 계속 더해집니다. [0, 3]에서는 앞으로 6/π, 뒤로 6/π를 움직여 변위 0, 이동 거리 12/π ≈ 3.82였습니다. 이동 거리는 v = 0인 시각에서 나눠 계산합니다.

개념 정리

1. 위치의 변화량(변위)과 실제 이동 거리는 다르다

∫v dt 는 위치가 얼마나 변했는가를 말하고, ∫|v| dt 는 실제로 얼마나 움직였는가를 말해요. 되돌아온 구간이 있으면 변위는 줄어들지만 거리는 계속 늘어납니다. 제자리로 오면 변위는 0 이어도 거리는 0 이 아닙니다.

왜 그럴까

  • v > 0 이면 앞으로, v < 0 이면 뒤로 — 변위는 부호를 반영합니다.
  • 거리는 부호를 없애고 더하므로 항상 변위의 절댓값 이상입니다.
  • v = 0 이 되는 시각에서 구간을 나눠 계산합니다.

2. 자주 하는 오해 바로잡기

· “위치의 변화량이 이동 거리다” → 되돌아오면 달라집니다.

3. 생활 속에서 · 이어지는 개념

  • 왕복하면 주행거리계는 늘지만 출발지로부터의 거리는 0 입니다.
끝 시각을 늘리며 두 값을 계산하고, 되돌아오는 구간에서 갈라지는지 확인

예제

속도가 v(t) = t − 2 (0 ≤ t ≤ 4)인 점의 변위와 이동 거리를 구하시오.

변위: ∫₀⁴(t − 2)dt = 8 − 8 = 0. 이동 거리: t = 2에서 나눠 ∫₀²(2 − t)dt + ∫₂⁴(t − 2)dt = 2 + 2. 변위 0, 이동 거리 4

v(t) = 2 cos(πt/3)일 때 0 ≤ t ≤ 3에서의 변위와 이동 거리를 구하시오.

∫₀³v dt = (6/π)[sin(πt/3)]₀³ = 0. t = 1.5에서 나누면 ∫₀^1.5 v dt = 6/π, ∫₁.₅³|v| dt = 6/π. 변위 0, 이동 거리 12/π ≈ 3.82
