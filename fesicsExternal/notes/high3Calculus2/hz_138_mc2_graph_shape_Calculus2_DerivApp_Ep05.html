그래프의 개형 — 증감, 오목·볼록, 점근선, 끝의 극한까지

y = x²/(x² − 1)의 그래프를 그리며 증가·감소, 오목·볼록, 수직점근선, x → ±∞의 극한을 한 단계씩 더해 기록했습니다. 증감표만으로는 x = 0에서의 극대만 알 수 있었고, 점근선 x = ±1과 y = 1을 확인해야 그래프 전체 모양이 정해졌습니다. 그래프를 그릴 때 조사할 항목을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 확인할 단계(1~4)를 정하고 ‘정보를 하나씩 더하기’를 누르면 확인한 것, 알게 된 것, 그래프 완성도가 기록됩니다. 단계를 바꿔 4개 이상 기록하면 분석이 열립니다.

표 1. y = x²/(x² − 1)의 단계별 정보 (실험 예시)
단계확인한 것알게 된 것그래프 완성도
1단계증가·감소 (f′)x = 0에서 극대25%
2단계+ 오목·볼록 (f″)x = ±1 사이는 위로 볼록50%
3단계+ 수직점근선x = 1, x = −175%
4단계+ x → ±∞의 극한y = 1에 수렴100%

f′(x) = −2x/(x² − 1)²이므로 x = 0에서 + → −로 극대 (0, 0)입니다. f″(x) = (6x² + 2)/(x² − 1)³은 |x| < 1에서 음수라 위로 볼록입니다. 그러나 분모가 0이 되는 x = ±1의 수직점근선과 x → ±∞일 때 y → 1인 수평점근선은 증감표에 나타나지 않습니다. 유리함수의 그래프는 네 가지를 모두 확인해야 합니다.

개념 정리

1. 증감표만으로는 그래프가 정해지지 않는다 — 점근선과 끝의 극한까지

유리함수나 지수·로그가 섞인 함수는 점근선과 x → ±∞ 의 거동이 모양을 크게 좌우해요. 증감과 극값만 표시하면 그래프의 뼈대만 있고 전체 모양은 알 수 없습니다.

왜 그럴까

  • 분모가 0 이 되는 점에서 수직점근선이 생깁니다.
  • x → ±∞ 의 극한이 수평점근선을 정합니다.
  • f″ 의 부호가 휘어진 방향을 알려 줍니다.

2. 자주 하는 오해 바로잡기

· “증감표만 있으면 그래프가 그려진다” → 점근선과 끝을 봐야 합니다.

예제

y = x²/(x² − 1)의 점근선을 모두 구하시오.

분모 x² − 1 = 0에서 수직점근선 x = ±1. lim(x→±∞) x²/(x² − 1) = 1이므로 수평점근선 y = 1. x = 1, x = −1, y = 1

f(x) = x/(x² + 1)의 극값과 점근선을 구하시오.

f′(x) = (1 − x²)/(x² + 1)²이므로 x = −1에서 극소 −1/2, x = 1에서 극대 1/2. 분모가 0이 되지 않아 수직점근선은 없고, x → ±∞일 때 f(x) → 0. 극댓값 1/2, 극솟값 −1/2, 점근선 y = 0
