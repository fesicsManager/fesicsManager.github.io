고등학교 미적분Ⅱ · 실험 「공비 실험실」

등비수열의 극한 — −1 < r ≤ 1일 때만 수렴한다

공비 r(−2~2)과 n을 바꾸며 rⁿ의 값과 극한, 수렴 여부를 기록했습니다. |r| < 1이면 0으로, r = 1이면 1로 수렴했지만, r = −1은 −1과 1을 오가며 극한이 없었고 |r| > 1이면 발산했습니다. 등비수열 {rⁿ}의 수렴 조건 −1 < r ≤ 1을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 공비 r(×0.1, −2.0~2.0)과 n(1~40)을 정하고 ‘거듭제곱을 따라가기’를 누르면 rⁿ과 극한, 수렴 여부가 표에 기록됩니다. 4개 이상 기록하면 분석이 열립니다.

|r| < 1이면 곱할수록 작아져 0으로 가지만, r = −0.9처럼 1에 가까우면 n = 20에서도 0.12로 느리게 다가갑니다. r = 1과 r = −1은 절댓값이 같아도 결과가 정반대입니다: r = 1은 모든 항이 1이라 1로 수렴, r = −1은 진동해 극한이 없습니다. 정리하면 {rⁿ}은 −1 < r ≤ 1일 때만 수렴합니다.

개념 정리

1. |r| 1 → 발산

r = −1 이면 rⁿ 이 −1 과 1 을 번갈아 오가 한 값에 정착하지 못합니다. |r| 가 1 이라고 극한이 1 이 되는 것이 아니에요. r = 1 만 1 로 수렴하고, r = −1 은 진동 발산입니다.

왜 그럴까

  • |r| < 1 이면 곱할수록 작아져 0 으로 갑니다.
  • |r| > 1 이면 곱할수록 커져 발산합니다.
  • r = −1 은 크기는 1 로 일정하지만 부호가 바뀌어 수렴하지 않습니다.

2. 자주 하는 오해 바로잡기

· “r 의 절댓값이 1 이면 극한도 1 이다” → r = −1 은 진동합니다.

3. 생활 속에서 · 이어지는 개념

  • 진동하며 줄지 않는 신호는 안정되지 않습니다.
r을 바꿔 rⁿ 의 항을 그래프로 따라가며 네 가지 경우를 구분
📋 데이터 확인 탭의 결론

“'+conv+'개 / 전체”

실험 「데이터 확인」 · 기록 4개 이상일 때 나오는 정리

예제

lim (3ⁿ⁺¹ + 2ⁿ)/(3ⁿ − 1)의 값을 구하시오.

분자·분모를 3ⁿ으로 나누면 (3 + (2/3)ⁿ)/(1 − (1/3)ⁿ). |2/3| < 1, |1/3| < 1이므로 → 3/1 = 3.

수열 {((x − 1)/2)ⁿ}이 수렴하도록 하는 실수 x의 범위를 구하시오.

공비 (x − 1)/2가 −1 < (x − 1)/2 ≤ 1이어야 하므로 −2 < x − 1 ≤ 2, 즉 −1 < x ≤ 3.

1번· 관찰 확인

실험에서 r = −1로 두고 n을 바꿨을 때 rⁿ은 어떻게 되었는가?

크기는 1로 일정하지만 부호가 바뀌어 한 값에 정착하지 않습니다.

2번· 핵심 개념

수열 {rⁿ}이 수렴하기 위한 r의 조건은?

0으로 수렴(|r| < 1) + 1로 수렴(r = 1).

3번· 적용

lim (2ⁿ + 5ⁿ)/5ⁿ⁺¹의 값은?

5ⁿ으로 나누면 ((2/5)ⁿ + 1)/5 → 1/5.
