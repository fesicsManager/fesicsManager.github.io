눈가림 시험 — 관찰자가 장치 상태를 알면 효과가 없어도 다 맞힌다

실제 효과(없음 / 있다고 가정), 관찰자 조건(앎 / 눈가림), 시험 횟수를 바꾸며 맞힌 횟수와 ‘우연만으로 그럴 확률’을 기록했습니다. 효과가 없는데도 관찰자가 장치 상태를 알면 20번 모두 맞혔고, 눈가림에서는 10번 근처에 머물렀으며, 효과가 있다고 가정하면 눈가림에서도 16번, 18번처럼 높게 맞혔습니다. N선 사건의 기록과 눈가림 시험의 확률 계산을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: ‘실제 효과(숨겨진 진실)’(효과 없음 / 효과가 있다고 가정 · 적중 90%), ‘관찰자 조건’(관찰자가 장치 상태를 앎 / 눈가림), ‘시험 횟수’(10 · 20 · 40번)를 고른 뒤 시험 진행하기를 누르면 동전으로 정한 켬 · 끔 칸이 맞힘(초록) · 틀림(빨강)으로 칠해지고, 효과가 없을 때의 확률 분포 위에 이번 결과가 표시됩니다. ‘효과가 있다고 가정’과 ‘앎’은 단순화한 가상 모형입니다. 세 조건을 여러 번씩 기록해, 기록이 4개 이상이면 결과 비교 탭에서 조건별 평균 적중률과 20번 시험의 기준표를 봅니다.

효과가 없는데 관찰자가 장치 상태를 알면 20번 모두 맞혀 ‘우연 확률 0.1% 미만’이 나왔지만, 이는 기대한 대로 보고했기 때문이라 증거가 되지 못합니다. 같은 ‘효과 없음’을 눈가림으로 1,000번 실행해 보니 평균 적중은 약 10.0번이었고, 우연 확률 5% 미만이 나온 경우는 약 2.3%뿐이었습니다. 효과가 있다고 가정하면 눈가림에서도 16번(우연 확률 0.59%)처럼 높게 맞혔습니다. 눈가림 시험에서 나온 높은 적중만이 효과의 근거가 됩니다.

개념 정리

1. 기대는 지각을 흔들고, 눈가림은 그것을 걸러 낸다

연도기록
1903프랑스 낭시의 물리학자 블롱들로 — 새로운 복사선 'N선'을 발견했다고 발표. 작은 불꽃이나 희미한 빛이 조금 밝아지는 것으로 N선을 '본다'고 함
1903~1904여러 연구자가 N선을 확인했다는 논문을 냄
1904미국 물리학자 우드 — 블롱들로의 실험실을 방문, 어두운 방에서 장치의 프리즘을 몰래 빼냈는데도 측정값이 계속 읽혀 나옴. 결과를 『네이처』에 보고

그 뒤 N선은 실재하지 않는다는 결론으로 정리되었습니다.

2. 눈가림 시험의 확률 (20번, 효과가 없으면 맞힐 확률 1/2)

전체 경우의 수 2²⁰ = 1,048,576

  • 정확히 10번: 184,756 ÷ 1,048,576 ≈ 17.6%
  • 15번 이상: (15,504 + 4,845 + 1,140 + 190 + 20 + 1) ÷ 1,048,576 = 21,700 ÷ 1,048,576 ≈ 2.1%
  • 18번 이상: (190 + 20 + 1) ÷ 1,048,576 ≈ 0.02%

3. 실험 모형과 실제의 차이

· "우연만으로 그럴 확률"이 아주 작으면(흔히 약 5% 미만을 기준으로 삼는 관례가 있음) 우연으로 보기 어렵다고 판단합니다. 그래도 한 번의 시험으로 단정하지 않고 반복과 재현이 필요해요.

· 관찰자가 장치 상태를 알면 효과가 없어도 높은 적중이 나올 수 있습니다. 그래서 "앎" 조건의 적중은 증거가 되지 못해요.

4. 생활 속에서 · 이어지는 개념

  • 기대가 지각을 흔드는 것은 사람 모두의 특성입니다. 과학은 사람을 믿는 대신 절차로 그 특성을 막아요. 신약 시험에서는 환자와 의사 모두 모르게 하는 이중 눈가림을 씁니다.
우연만으로 h번 이상 맞힐 확률 = (C(n, h) + ⋯ + C(n, n)) ÷ 2ⁿ · 20번: 15번 이상 21,700 ÷ 1,048,576 ≈ 2.1%

웹툰 7화 #4 · 눈가림 시험의 확률

예제

효과가 없을 때(맞힐 확률 1/2) 20번 중 15번 이상 맞힐 확률을 구하라.

전체 경우의 수 2²⁰ = 1,048,576. 15~20번 맞히는 경우의 수는 15,504 + 4,845 + 1,140 + 190 + 20 + 1 = 21,700이므로 21,700 ÷ 1,048,576 ≈ 2.1%입니다. 약 2.1%

눈가림 시험 20번에서 16번을 맞혔다. 우연만으로 16번 이상 맞힐 확률을 구하고 판단하라.

16~20번의 경우의 수 4,845 + 1,140 + 190 + 20 + 1 = 6,196, 6,196 ÷ 1,048,576 ≈ 0.59%(실험 값과 같음). 우연만으로는 일어나기 어려워 효과를 의심할 근거가 되지만, 한 번으로 단정하지 않고 반복과 다른 연구실의 재현이 필요합니다. 약 0.59%, 우연으로 보기 어려움
