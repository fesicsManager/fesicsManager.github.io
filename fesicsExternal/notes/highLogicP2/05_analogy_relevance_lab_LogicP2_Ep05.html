유비 추론의 평가 — 개수가 아니라 관련성

학교 = 회사, 쥐 → 사람 약, 지난해 사건 → 올해, 지구 → 물 행성, 제로 = 뭉치 다섯 유비에 무관한 공통점을 0·4·10개 더 붙이고 결론의 크기를 바꿔 점검표를 적용했습니다. 학교 = 회사는 공통점이 14개로 늘어도 관련성 점수가 5점 그대로였고, 쥐 실험 유비는 관련 공통점이 있지만 결정적 차이 때문에 ‘단정’하면 과하다고 나왔습니다. 유비 추론의 강도를 정하는 기준을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 유비 추론 다섯 가운데 하나, 무관한 공통점 덧붙이기(0개·4개·10개 더), 결론의 크기(‘B도 x다’ 단정 / ‘B도 x일 가능성이 있다’ 가설)를 고른 뒤 ‘점검표 적용하기’를 누릅니다. 관련 공통점(초록)·무관한 공통점(회색 점)·결정적 차이(빨강)가 나타나고, 공통점 개수 막대와 관련성 점수 막대가 나란히 그려집니다. 점수는 점검표를 숫자로 나타낸 단순 모형입니다. 기록 4개 이상이면 결과 비교 탭에서 공통점 개수와 점수를 비교합니다.

학교 = 회사는 무관한 공통점을 10개 더 붙여 14개가 되어도 5점 그대로였고, 공통점이 1개뿐인 ‘지난해 사건 → 올해’는 규칙의 요건이 같아 85점이었습니다. 유비의 강도는 공통점의 개수가 아니라, 공통점이 결론의 속성 x가 생기는 이유와 이어져 있는지와 결정적 차이가 있는지로 정해집니다. 쥐 실험 유비는 관련 공통점이 있어 ‘시험해 볼 가설’로는 적절하지만, 몸 크기·대사 속도 같은 차이가 있어 ‘사람에게도 효과가 있다’고 단정하면 결론이 근거보다 커집니다.

개념 정리

1. 개수가 아니라 관련성

유비 추론의 모양: A와 B는 a, b, c가 같다 → A는 x다 → 그러므로 B도 x다 강도를 정하는 것은 공통점이 x가 생기는 이유와 이어져 있느냐입니다.

2. 점검표

  • 관련성: 공통점이 x의 이유와 이어져 있는가
  • 결정적 차이: x를 막는 중요한 차이가 있는가
  • 비교 사례의 수와 다양성: 여러 사례에서 같은 연결이 확인되는가
  • 결론의 크기: "같다"인가, "비슷할 가능성이 있다"인가

3. 이 실험의 점수 모형

관련 공통점이 없으면 5점, 있고 결정적 차이가 있으면 45점, 있고 결정적 차이가 없으면 85점입니다. 무관한 공통점은 몇 개를 붙여도 0점이에요. 결정적 차이가 있는데 "같다"고 단정하면 결론이 근거보다 크다고 표시합니다.

4. 실험 모형과 실제의 차이

· 신약은 동물 실험 뒤에도 사람 대상 시험을 단계적으로 거칩니다. 유비가 "시험해 볼 가설"을 만들고, 시험이 결론을 내요.

· 판례의 "같은 것은 같게"도 유비에 기댑니다. 요건과 관련된 사정이 다르면 결론이 달라질 수 있어요.

5. 생활 속에서 · 이어지는 개념

  • 비유가 나오면 "어떤 점에서 같은가?" → "그 공통점이 결론과 이어지는가?" → "이 차이도 괜찮은가?"를 차례로 묻고, 반대 비유도 대 보세요. 결론이 정반대로 뒤집힌다면 그 비유는 근거보다 꾸밈에 가까웠을 수 있어요.
A와 B는 a, b, c가 같다 → A는 x다 → 그러므로 B도 x다 · 강도 = 관련성 + 결정적 차이 + 비교 사례의 수와 다양성 + 결론의 크기 (모형: 관련 없음 5점 / 관련 있고 차이 있음 45점 / 관련 있고 차이 없음 85점)

예제

‘도서관에는 음식 반입이 금지되어 있다. 그러므로 물병 반입도 금지해야 한다.’를 점검표로 평가하라.

먼저 음식을 금지한 이유(책 훼손, 냄새 등)를 찾고, 그 이유와 관련된 점에서 물병이 음식과 비슷한지 본다. 쏟으면 책이 젖는 점은 관련 있는 공통점이지만, 뚜껑이 있어 쏟을 위험이 낮다면 결정적 차이가 될 수 있다. 금지 이유와 관련된 공통점과 결정적 차이를 따진다 — 공통점 개수를 세는 것이 아님

‘지구에는 물과 생명이 있다 → 물의 흔적이 있는 행성에도 생명이 있을 것’의 결론을 근거에 맞는 크기로 고쳐 쓰라.

액체 물은 생명 활동과 관련된 공통점이지만 대기·온도·에너지원의 차이가 있다. 그래서 ‘생명이 있다’는 단정은 근거보다 크다. ‘그 행성은 생명이 있을 가능성을 탐사해 볼 만하다’
