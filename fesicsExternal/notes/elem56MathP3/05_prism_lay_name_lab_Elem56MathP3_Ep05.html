각기둥의 밑면 — 바닥이 아니라 평행하고 합동인 두 면

삼각기둥 상자를 눕혀 직사각형 면이 바닥에 닿게 놓아도, 평행하고 합동인 두 면은 양옆의 삼각형뿐이었고 면은 5개 그대로였어요. 바닥 면으로 이름을 붙이면 사각기둥(면 6개)이 되어 맞지 않아요. 밑면·옆면·높이를 정리해요.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 상자(삼각·사각·오각·육각기둥), 놓는 방법(세워 / 눕혀 / 굴려), 이름 정하는 방법(바닥 면 / 밑면)을 고르고 상자 놓기를 누르면, 바닥 면과 밑면, 면의 수, 이름이 기록돼요.

표 1. 놓을 때마다 센 면 (실험 결과)
입체도형놓은 방법바닥에 닿은 면밑면면의 수이름
삼각기둥세워 놓기삼각형삼각형 2개5삼각기둥
삼각기둥눕혀 놓기직사각형삼각형 2개(양옆)5삼각기둥
오각기둥눕혀 놓기직사각형오각형 2개(양옆)7오각기둥
사각기둥아무렇게나직사각형마주 보는 직사각형 2개6사각기둥

놓는 방향이 바뀌어도 면의 수와 밑면은 그대로예요. 삼각기둥의 직사각형 옆면들은 서로 평행하지 않아 밑면이 될 수 없어요.

개념 정리

1. 밑면과 옆면

각기둥에서 서로 평행하고 합동인 두 면이 밑면, 밑면과 만나는 면이 옆면이에요. 옆면은 모두 직사각형이에요.

2. 이름과 높이

각기둥의 이름은 밑면의 모양으로 정해요. 두 밑면 사이의 거리가 높이예요. 눕혀 놓으면 높이도 옆으로 누워요.

3. 각기둥의 전개도

□각기둥을 펼치면 □각형 2개와 직사각형 □개. 옆면 직사각형의 수 = 밑면의 변의 수. 육각기둥 → 육각형 2개, 직사각형 6개.

□각기둥: 면 □+2개 = 밑면 2 + 옆면 □
