고등 음악 감상과 비평 · 웹툰 8화 「AI가 작곡하면 작곡가는 필요 없는가」

패턴 생성기 — 학습한 패턴으로 그럴듯한 다음 소리를 잇는다

프로그램이 만든 가상 학습 곡에서 ‘두 음 다음에 온 음’의 횟수를 세어 배운 단순 생성기(2차 마르코프 연쇄)로 16음 가락을 만들고, 학습 데이터 크기와 온도를 바꾸며 학습 곡과의 최장 연속 일치·그럴듯함·새 조합 비율을 기록했습니다. 학습 곡 2개·온도 0.3에서는 16음 중 15음이 학습 곡과 그대로 겹쳤고, 학습 곡 12개·온도 1.5에서는 최장 일치 4음·새 조합 57 %였습니다. 생성 모델의 원리와 유사성 쟁점을 정리합니다.

실험에서 얻은 것

실험 데이터 되짚기

실험 안내: 자유 탐구 탭에서 학습 데이터(학습 곡 2개 · 12개), 학습 곡 문체(장음계 동요풍 · 5음계 민요풍), 온도(0.3~2.0, 무작위성), 시도 번호(1~3번)를 고르고 가락 생성하고 듣기를 누르면 새 가락이 재생되고 학습 곡과의 최장 연속 일치, 그럴듯함(학습 통계 기준), 새로운 3음 조합 비율이 나옵니다. 같은 조건이면 같은 가락이 나오고 시도 번호를 바꾸면 다른 가락이 나와요. 작은 데이터와 큰 데이터에서 온도를 낮게·높게 바꿔 기록하면 결과 비교 탭에서 온도와 최장 일치의 관계를 볼 수 있습니다.

학습 데이터가 작고 온도가 낮으면 생성기는 학습 곡을 거의 통째로 베낍니다(16음 중 15음 일치, 새 조합 0 %). 데이터를 늘리고 온도를 높이면 일치가 짧아지고 새 조합이 늘지만, 그럴듯함(학습 문법을 따르는 정도)은 떨어져요. 이 생성기는 평균적으로 그럴듯한 다음 음을 잇는 것일 뿐, 왜 문법을 어기는지 알고 어기지는 않습니다. 학습 데이터의 저작권과 결과물의 유사성이 함께 쟁점이 되는 까닭이에요.

개념 정리

1. 평균적으로 그럴듯한 것을 만드는 데 강하다

음악 생성 모델은 대량의 기존 음악에서 패턴을 학습하고, 요청에 맞게 그럴듯한 다음 소리를 이어 붙입니다. 익숙한 문법을 잘 따르지만, 문법을 의도적으로 어겨서 의미를 만드는 일은 잘 못해요. 왜 어기는지를 알아야 할 수 있는 일이니까요.

2. 무엇이 논쟁 중인가 (대본 표)

  • 학습 데이터: 허락 없이 학습해도 되는가 — 소송·입법 논의 진행 중
  • 결과물의 권리: 누구의 창작물인가 — 국가별로 기준이 다름
  • 유사성: 기존 표절 기준 적용 시도 / 표시 의무: 플랫폼·공모전별 규정 신설 중 / 실연자 영향: 실제 변화 관측

3. 이 실험의 생성기

  • 학습: 학습 곡에서 "두 음 → 다음 음" 횟수를 셉니다(2차 마르코프 연쇄).
  • 생성: 횟수에 비례해 다음 음을 뽑되, 확률 ∝ (횟수 + 0.05)^(1/온도) — 온도가 낮으면 가장 흔한 길만, 높으면 학습 곡에 없던 길도 가끔 고릅니다.
  • 최장 일치 = 새 가락이 어떤 학습 곡과 연속으로 똑같은 음의 수. 그럴듯함 = 학습 통계로 본 평균 확률(기하평균, %).

데이터가 작고 온도가 낮으면 학습 곡을 길게 그대로 베끼는 경향이 생깁니다. 실제 쟁점인 "특정 곡과 비슷하면?"과 연결돼요.

4. 지금 할 수 있는 일

· "괜찮다", "금지해야 한다"로 단정하기엔 근거가 아직 약합니다. 공모전이나 과제라면 규정을 먼저 확인하고, 사용했다면 어디까지 사용했는지 밝히는 것이 현재로서는 가장 안전해요.

웹툰 8화 #2 · 생성 모델의 작동

예제

학습 곡에서 어떤 두 음 다음에 ‘미’가 3번, ‘레’가 1번 나왔고 나머지 6개 음은 0번이었다(음은 모두 8개). 온도 1일 때 다음 음으로 ‘미’를 고를 확률은?

가중치: 미 3.05, 레 1.05, 나머지 0.05 × 6 = 0.30, 합 4.40. 3.05 ÷ 4.40 ≈ 69 %입니다.

위 상황에서 온도를 0.5로 낮추면 ‘미’를 고를 확률은 어떻게 되는가?

가중치가 (횟수 + 0.05)²로 바뀌어 미 9.30, 레 1.10, 나머지 합 약 0.02 → 9.30 ÷ 10.42 ≈ 89 %. 온도가 낮을수록 가장 흔한 길만 따라가 학습 곡을 베끼기 쉬워집니다.
