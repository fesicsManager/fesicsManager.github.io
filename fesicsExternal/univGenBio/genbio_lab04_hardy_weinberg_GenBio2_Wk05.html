📖 과학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 하디–바인베르크 평형과 진화의 요인

대립유전자 빈도 p·q(p + q = 1)인 집단이 ① 무작위 교배 ② 무한히 큰 집단 ③ 돌연변이·이주·선택 없음 조건을 만족하면 유전자형 빈도는 p² + 2pq + q² = 1로 세대가 지나도 변하지 않아요(하디–바인베르크 평형). 이는 '진화가 일어나지 않는 기준선'이고, 실제 집단이 여기서 벗어나면 어떤 진화 요인이 작용했는지 알 수 있어요. 유전적 부동: 유한 집단에서는 생식세포 표본 추출의 우연으로 빈도가 무작위로 흔들리고, 작은 집단일수록 크게 흔들려 결국 한 대립유전자가 고정(1) 또는 소실(0)돼요. 자연 선택: 선택 계수 s만큼 적응도가 낮은 유전자형이 덜 남겨 빈도가 한 방향으로 이동해요.

⚙️ 시뮬레이션 읽기

  • s = 0, N = 100, p₀ = 0.5: 50세대 뒤 p는 0.2~0.8 사이 어디든 — 같은 조건으로 돌릴 때마다 달라요(부동). N = 10이면 몇 세대 만에 고정/소실, N = 1 000이면 거의 0.5 근처.
  • 부동으로 고정될 확률 = 처음 빈도 p₀. 평형 도달 시간 ≈ 4N 세대 규모.
  • s = 0.1(열성 동형 접합 불리): p가 세대마다 증가. 초기에는 빠르다가 q가 작아지면 대부분 이형 접합에 숨어 느려져요(열성 대립유전자는 잘 사라지지 않음).
  • 큰 N에서는 선택이 결정적, 작은 N에서는 부동이 선택을 이기기도 해요(s < 1/2N이면 사실상 중립).

🧮 이 실험의 계산 방법

각 세대: 선택 후 빈도 p′ = [p² + pq(1 − hs)] ÷ (1 − sq² − …)(모형: aa 적응도 1 − s), 그다음 2N개 생식세포를 이항 추출 p_next = Binomial(2N, p′)/2N; 유전자형 = HW 비율

📌 실험 모형과 실제의 차이
· 라이트–피셔 모형(세대 겹침 없음, 일정한 N, 무작위 교배, 한 유전자좌 두 대립유전자)이에요. 실제 집단은 세대가 겹치고 N이 변하며(유효 집단 크기 N_e는 실제 개체 수보다 작음), 이주·돌연변이·근친 교배가 함께 작용해요.
· 선택 계수를 일정하게 뒀지만 실제 적응도는 환경·빈도에 따라 변해요(빈도 의존 선택, 이형 접합 우세 등).

🌍 생활 속에서

  • 보인자 빈도 추정: 열성 유전병 발생률 q² = 1/10 000 → q = 0.01 → 보인자 2pq ≈ 2 % — 유전 상담의 기초 계산.
  • 멸종 위기종의 작은 집단은 부동으로 유전 다양성을 잃어 보전 생물학에서 유효 집단 크기를 중시해요.
