실험 6 · 멘델 교배와 카이제곱 검정

대학 일반생물 1학기 12~13주차 연계  |  초파리 교배 · 표현형 비 검정 · 연관 분석

📖 과학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 교배 결과의 통계 검정과 연관 분석

멘델 교배의 이론 비(3 : 1, 9 : 3 : 3 : 1, 검정 교배 1 : 1 : 1 : 1)는 확률이라 실제 자손 수는 늘 조금씩 벗어나요. 그 차이가 우연인지(가설 채택) 진짜 다른지(가설 기각)를 카이제곱 검정 χ² = Σ(O − E)²/E로 판단해요. 자유도 = 범주 수 − 1이고 χ²가 임계값(df 1: 3.84, df 3: 7.81, α = 0.05)보다 크면 "이론 비와 다르다"고 결론해요. 두 유전자가 같은 염색체에 연관되어 있으면 검정 교배가 1 : 1 : 1 : 1에서 벗어나 부모형이 많아지고, 재조합형 비율(재조합 빈도 RF)이 유전자 사이 거리(cM)가 돼요.

⚙️ 표본 크기가 결론을 바꾼다

  • N = 100, 관찰 80 : 20(기대 75 : 25): χ² = 25/75 + 25/25 = 1.33 < 3.84 → 3 : 1과 다르지 않음.
  • 같은 비율 N = 1 000, 800 : 200(기대 750 : 250): χ² = 13.3 > 3.84 → 기각. 같은 비율이라도 표본이 크면 작은 편차도 유의해져요.
  • 연관(RF = 0.18) 검정 교배 N = 100: 부모형 각 41, 재조합형 각 9 → 1 : 1 : 1 : 1 가설 χ² ≈ 41 ≫ 7.81 → 독립 기각. RF = 18/100 = 0.18 → 18 cM.
  • 기대 빈도 5 미만 범주가 있으면 χ² 근사가 나빠져 범주를 합치거나 정확 검정을 써요.

🧮 이 실험의 계산 방법

자손 = 이론 확률(연관이면 부모형 (1−RF)/2, 재조합형 RF/2)로 다항 추출; χ² = Σ(O−E)²/E, p값 = χ² 분포 우측 꼬리; RF = 재조합형/N

📌 실험 모형과 실제의 차이
· 완전 우성·동일 생존율·독립 표본을 가정했어요. 실제 초파리 교배에서는 유전자형별 생존율 차이, 성별 효과(수컷은 교차 없음), 계수 오류가 편차를 만들어요.
· "기각하지 못함"은 "이론 비가 맞다"의 증명이 아니라 "자료가 반박하지 못했다"는 뜻이고, α = 0.05는 관행적 기준이에요. RF는 50 %를 넘지 않고 먼 거리에서는 이중 교차로 과소평가돼요.

🌍 생활 속에서

  • 카이제곱 검정은 여론 조사·임상 시험·품질 관리 등 범주형 자료 분석의 기본 도구예요.
  • 모건이 초파리 눈 색으로 연관과 X 염색체 유전을 밝힌 것(1910)이 유전자가 염색체 위에 있다는 첫 증거였어요.
