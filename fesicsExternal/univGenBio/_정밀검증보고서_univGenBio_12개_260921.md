## 우선 수정 사항

### 1. 전기영동 — 심각도 A

파일: `genbio_lab08_electrophoresis_GenBio2_Wk03.html`

문제:

- `dist(bp)` 안에서 매 호출마다 새 난수를 발생시킨다.
- 애니메이션의 매 프레임, 완료 후 겔 이탈 판정, 기록표 작성에서 `dist()`를 각각 다시 호출한다.
- 따라서 같은 한 번의 실험에서도 밴드가 프레임마다 미세하게 흔들리고, 최종 화면 위치·“겔 끝까지 내려감” 판정·기록표 이동 거리가 서로 달라질 수 있다.
- 미지 시료와 마커도 서로 독립적인 새 오차를 계속 받으므로 표준곡선으로 추정한 크기가 사용자가 본 겔과 정확히 대응하지 않는다.

근거 코드:

- `dist()`의 `noise(0.012+distort)`
- `draw()`에서 밴드마다 `dist(bp)` 호출
- `run()` 완료부에서 `dist(bp)>=9.15` 재호출
- `record()`에서 마커와 미지 시료 거리를 다시 계산

수정안:

1. 실행 시작 시 마커·미지 시료의 이동 거리를 한 번만 계산해 `currentRun` 객체에 저장한다.
2. `draw()`, 겔 이탈 판정, `record()`가 모두 같은 저장값을 사용하게 한다.
3. “새 겔” 또는 “실험 시작” 때만 새 오차를 생성한다.

판정: **반드시 수정 후 사용**

### 2. 항생제 감수성 — 심각도 A

파일: `genbio_lab11_antibiotic_GenBio2_Wk02.html`

문제:

- 반코마이신에 `S:17, R:17`을 부여하여 화면에서 S/R 판정을 만들지만, 같은 파일의 설명은 “포도상구균에서 반코마이신은 디스크법으로 내성을 검출할 수 없고 MIC 측정이 필수”라고 말한다. 시뮬레이션 결과와 교육 설명이 정면으로 충돌한다.
- 페니실린 G 기준이 `S:29, R:29`로 입력되어 있다. 판정 코드가 `>=S`를 먼저 적용하면 29 mm는 감수성으로 처리되고 중간 구간도 사라진다. 의도한 경계가 `S ≥29`, `R ≤28`인지 확인해야 한다.
- 파일은 여러 균종·항생제에 하나의 단순 회귀식과 고정 기준을 적용하면서 “CLSI 판정”처럼 보이게 한다. 실제 기준은 균종, 약제, 시험법, 판본에 따라 달라지므로 교육용 가상 기준임을 화면에 명확히 밝혀야 한다.

수정안:

1. VAN은 지름을 보여 주더라도 판정 결과를 `판정 불가—MIC 필요`로 고정한다.
2. PEN 경계를 `S ≥29 / R ≤28` 등 의도한 값으로 분리하고 기준 출처·판본을 명시한다.
3. 실제 임상 판정표가 아니라면 제목과 표에 `교육용 모형값`을 표시한다.

판정: **반드시 수정 후 사용**

### 3. 개체군 성장 — 심각도 B

파일: `genbio_lab05_population_growth_GenBio2_Wk15.html`

문제:

- 분석에서 `K = Math.max(...관찰값)`을 환경수용력 추정값으로 사용한다.
- 관찰 시간이 짧아 정체기에 도달하지 않았으면 최대 관찰값은 K보다 훨씬 작다. 그런데 표와 해설은 이를 `K`로 제시해 학생이 “최댓값 = 환경수용력”으로 이해할 수 있다.
- 초기 지수 성장 회귀도 `N < 0.35 × 관찰 최대값`으로 구간을 정하므로, 관찰 최대값이 낮은 자료에서는 초기 구간 선택이 왜곡된다.

수정안:

1. 로지스틱 비선형 회귀로 `r`과 `K`를 함께 추정한다.
2. 정체기 자료가 부족하면 `K 추정 불가(관찰 최대값만 표시)`로 구분한다.
3. 현재 방식 유지 시 열 이름을 `관찰 최대 N`으로 바꾸고 K와 동일시하지 않는다.

판정: **수정 권장**

### 4. 운동 생리 — 심각도 B

파일: `genbio_lab12_exercise_physiology_GenBio2_Wk11.html`

문제:

- 생성 모델은 회복 전 구간을 하나의 단일 지수함수 `exp(-t/tau)`로 만든다.
- 해설은 회복 곡선이 “빠른 단계와 느린 단계의 두 단계로 보인다”고 설명한다. 현재 데이터 생성식에서는 두 단계가 나타날 수 없다.
- 분석에서 세 구간 맥박을 이용해 다시 τ를 회귀 추정하지만, 표의 비교 부분은 추정 τ가 아니라 생성에 사용한 원래 `r.tau`를 표시한다. 사용자가 보는 분석 결과와 비교표의 τ가 서로 다른 정의가 된다.
- 기록표 피험자 열에는 이름 대신 `A/B/C` 코드만 표시된다.

수정안:

1. 해설을 단일 지수 회복 모형으로 제한하거나, 실제로 두 지수 성분을 합친 이중 지수 모형을 사용한다.
2. 모든 결과표에서 `생성 τ`와 `측정값으로 추정한 τ`를 구분하거나 추정 τ 하나로 통일한다.
3. 피험자 열에 `SUBJ[r.subj].n`을 표시한다.

판정: **수정 권장**
