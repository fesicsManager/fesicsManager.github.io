## 5. 공통 기능·UI·접근성 점검

### 통과

- 6개 HTML 모두 JavaScript 구문 검사 통과
- UTF-8, viewport, 한국어 제목 정상
- 외부 CDN 없이 단독 실행 가능
- 실행 중 입력 잠금, 완료 후 자동 기록, 전체 기록 삭제 확인창 구현
- 기록 4개 미만일 때 데이터 검증의 부족 안내 구현
- 화면 폭 640 px 이하에서 단일 열로 바뀌는 반응형 규칙 존재
- `prefers-reduced-motion` 대응 규칙 존재

### 개선 필요

1. `role="tab"`은 있으나 좌우 화살표·Home·End 키 이동이 없다. WAI-ARIA 탭 패턴에 맞는 키보드 처리를 추가한다.
2. 캔버스는 짧은 `aria-label`만 있고 결과 그림의 수치·관계를 읽어 주는 대체 텍스트가 없다. 화면 결과와 동기화되는 숨김 설명 또는 텍스트 요약을 제공한다.
3. 세그먼트 버튼 그룹에 그룹명(`fieldset/legend` 또는 `role="group" aria-labelledby`)을 부여하면 보조기기 사용성이 좋아진다.
4. 애니메이션은 축소 동작 설정에서도 실행 시간 1.8초가 유지된다. 해당 설정에서는 즉시 결과를 표시하도록 권장한다.
5. 모든 수치형 환경 자료에 `기준연도·지역·자료 범위·출처` 표기가 필요하다.

## 7. 최종 결론

파일은 모두 열 수 있는 구조이며 계산 엔진의 기본 뼈대도 안정적이다. 그러나 현재 상태로는 일부 수치와 표현이 서로 충돌하고, 5화의 재활용 판정은 실제 기준보다 지나치게 단순하다. 위 A급 4건을 먼저 고친 뒤 수업·서비스에 사용하는 것이 안전하다.
