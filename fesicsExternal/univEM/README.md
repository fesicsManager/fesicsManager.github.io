## 수치 계산을 실제로 돌리는 실험

수식을 그리기만 하는 게 아니라 그 자리에서 계산하는 것들입니다. 느린 기기에서는 05·07이 다소 무거울 수 있습니다.

- **05** 푸아송 방정식 SOR 완화법 (매 프레임 24회 스윕)
- **07** 완화법 수치해 ↔ 급수해 실시간 비교
- **10** 비오-사바르 선적분, 앙페르 폐곡선 적분
- **11** 프라이자흐 히스테론 256개 모형

## 권장 사용 순서

대본 → 실험 → 해답집 순으로 짝지어 쓰면 좋습니다.
예: 대본 3화 읽기 → 실험 03 탭1에서 대칭 판정 직접 해보기 → 해답집 ① 문제 3-1~3-4 풀기

## 교차 확인 포인트

서로 다른 실험이 같은 결과에 도달하는 지점입니다. 학생에게 던지기 좋은 질문입니다.

- **03 탭2** 균일 대전 구 ↔ **10 탭1** 균일 전류 원통 — 경계에서 도약이 없는 이유
- **09 탭1** 편극 구 ↔ 어긋난 두 구 모델 — 같은 −P/3ε₀
- **05** 도체 극한 ↔ **09 탭2** ε_r → ∞
- **06 탭1** 영상전하 해 ↔ **05 탭1** 접지 평면 수치해 — 같은 유도전하 분포
