물질이 끼어들 때

편극된 구가 스스로 만드는 장을 재고, 유전체를 외부 장에 넣었을 때 장이 얼마나 약해지는지 확인합니다. 순환 의존을 대수방정식 하나로 닫는 과정을 눈으로 봅니다. 대본 8화에 대응합니다.

📖 과학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 유전체: 편극, 속박 전하, 탈분극장

절연체(유전체)를 전기장에 넣으면 분자가 편극되어 단위 부피당 쌍극자 모멘트 P가 생겨요. 그 효과는 속박 전하로 나타나요: 표면에 σ_b = P·n̂, 내부에 ρ_b = −∇·P. 균일하게 편극된 구는 한쪽 면이 +, 반대 면이 −로 대전되어 안쪽에 P와 반대 방향의 균일한 장 E_in = −P/(3ε₀)를 만들어요 — 탈분극장. 외부 장 E₀ 속 선형 유전체(P = ε₀χ_e E)는 순환 의존(E가 P를 만들고 P가 E를 바꿈)이지만, 자기 일관 조건을 대수 방정식 하나로 닫으면 E_in = 3E₀/(ε_r + 2)로 풀려요(ε_r = 1 + χ_e). 자유 전하만 원천으로 갖는 보조장 D = ε₀E + P를 쓰면 ∇·D = ρ_free로 편해요.

⚙️ 관찰 포인트

  • 어긋난 두 구 모형: +ρ 구와 −ρ 구를 d만큼 어긋나게 겹치면 내부 장 = −ρd/(3ε₀) = −P/(3ε₀) — 완전히 다른 방법으로 같은 탈분극장이 나와요. 외부는 순수 쌍극자장.
  • ε_r = 1: 장 그대로. ε_r = 3: E_in = 0.6E₀. ε_r → ∞: E_in → 0 — 도체 극한(내부 장 0, 표면 전하가 완전히 상쇄).
  • 경계 조건: 접선 E 연속, 법선 D 연속(자유 전하 없을 때) → 전기력선 굴절 tanθ₂/tanθ₁ = ε_r₂/ε_r₁. 유전체 안으로 들어갈수록 선이 표면에 나란히 눕고 성겨져요.
  • 구 밖 장 = E₀ + (편극 구가 만드는 쌍극자장), 쌍극자 모멘트 p = 4πε₀R³E₀(ε_r − 1)/(ε_r + 2).

🧮 이 실험의 계산 방법

편극 구: 표면 속박 전하 σ_b = P·cosθ를 링으로 나눠 쿨롱 합 → 내부·외부 장; 외부 장 문제는 해석해 E_in = 3E₀/(ε_r+2) 및 경계 굴절각 수치 비교

📌 실험 모형과 실제의 차이
· 선형·등방·균일 유전체 가정이에요. 실제 물질은 강한 장에서 비선형(포화·절연 파괴), 결정은 방향에 따라 ε이 다르고(텐서), 강유전체는 외부 장 없이도 자발 편극이 있어요.
· ε_r은 정전기(저주파) 값이에요. 주파수가 높아지면 분자가 따라 돌지 못해 ε_r이 떨어지고 손실(허수부)이 생겨요(물: 정전 80, 광학 1.8).

🌍 생활 속에서

  • 축전기 유전체(세라믹 ε_r 수천), 전자레인지 가열(물의 유전 손실), 터치스크린, 절연 케이블 설계가 편극 이론이에요.
  • 탈분극(반자기) 인자는 자성체 모양 효과에도 같은 형태로 나타나 MRI 코일·영구자석 설계에 쓰여요.
