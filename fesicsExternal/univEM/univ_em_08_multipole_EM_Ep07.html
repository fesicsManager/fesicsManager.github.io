멀리서 보면 다 점전하

복잡한 전하 덩어리를 홀극·쌍극자·사중극으로 잘라 보고, 각 항이 거리에 따라 어떻게 사그라지는지 잽니다. 그리고 원점을 옮기면 무엇이 변하고 무엇이 변하지 않는지 확인합니다. 대본 7화 후반에 대응합니다.

📖 과학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 다중극 전개

복잡한 전하 덩어리도 멀리서 보면 단순해요. 전위를 1/r의 거듭제곱으로 전개하면 V(r) = (1/4πε₀)[Q/r + p·r̂/r² + (사중극)/r³ + …]: 홀극(총전하 Q, 1/r), 쌍극자(p = Σq_i r_i, 1/r²), 사중극(1/r³)… 차수가 높을수록 빨리 사그라지므로 먼 거리에서는 0이 아닌 가장 낮은 차수 항이 지배해요. 총전하가 0이 아니면 점전하처럼 보이고, Q = 0이면(쌍극자, 중성 분자) 쌍극자 항이, p도 0이면(선형 사중극) 사중극 항이 주도해요. 각 항은 르장드르 다항식 P_l(cosθ)의 각 분포를 가져요.

⚙️ 관찰 포인트

  • Q ≠ 0 배치: l = 0만 켜도 먼 거리에서 오차가 1/r로 급감. l = 1 추가 시 오차 ∝ 1/r².
  • Q = 0(+q, −q 쌍): l = 0은 0이라 l = 1을 켜야 비로소 맞기 시작. 세로 방향(θ = 0)에서 V ∝ 1/r², 옆(θ = 90°)에서 0.
  • 사중극(+q, −2q, +q 일직선): Q = 0, p = 0 → l = 2부터. V ∝ (3cos²θ − 1)/r³.
  • 원점 의존성: Q ≠ 0이면 원점을 옮길 때 p가 변해요(p′ = p − Qd). Q = 0이면 p는 원점과 무관. 일반 규칙: 0이 아닌 최저 차수 모멘트만 원점 선택에 무관해요.

🧮 이 실험의 계산 방법

전하 배치에서 Q, p, 사중극 텐서 Q_ij = Σq(3x_ix_j − r²δ_ij) 계산; 차수별 전위 합을 정확한 쿨롱 합과 거리별로 비교해 상대 오차 그래프; 원점 이동 시 모멘트 재계산

📌 실험 모형과 실제의 차이
· 전개는 전하 분포 바깥(r > 분포 크기)에서만 수렴해요. 분포 안이나 경계 근처에서는 항을 아무리 더해도 맞지 않아요.
· 실제 분자의 쌍극자 모멘트는 전자 구름의 연속 분포로 정의되고(양자 계산), 유도 쌍극자(편극)가 외부 장에 따라 추가돼요. 여기서는 고정 점전하만 다뤄요.

🌍 생활 속에서

  • 물 분자의 쌍극자 모멘트(1.85 D)가 수소 결합·용매 성질·전자레인지 가열을 정하고, CO₂는 쌍극자 0·사중극 ≠ 0이라 적외선 흡수 방식이 달라요.
  • 안테나 복사(쌍극자 안테나), 지구 자기장(주로 쌍극자 + 사중극 보정), 핵의 전기 사중극 모멘트(핵 모양) 분석에 다중극 전개를 써요.
