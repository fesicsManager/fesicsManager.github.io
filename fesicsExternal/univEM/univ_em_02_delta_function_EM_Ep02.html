폭을 줄여도 면적이 1로 유지되는 함수를 직접 조여 보고, 그 결과가 점전하 장의 발산 역설을 어떻게 해소하는지 수치로 확인합니다. 대본 2화에 대응합니다.

📖 과학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 디랙 델타 함수와 점전하 역설

점전하의 전기장 E = q r̂/(4πε₀r²)은 원점 밖 어디서나 ∇·E = 0인데, 원점을 감싼 면의 유량은 q/ε₀로 0이 아니에요 — 발산 정리와 모순처럼 보이는 역설이에요. 해결은 원점에 모든 발산이 집중되어 있다는 것: ∇·(r̂/r²) = 4πδ³(r). 델타 함수는 값이 아니라 적분 안에서의 행동으로 정의돼요: 폭 → 0, 높이 → ∞이면서 넓이 = 1을 유지하고, ∫f(x)δ(x − a)dx = f(a)(체 거르기 성질). 그래서 점전하 밀도를 ρ = qδ³(r)로 쓰면 ∇·E = ρ/ε₀가 원점까지 포함해 성립하고, 가우스 법칙이 모든 곳에서 참이 돼요.

⚙️ 조여 보기

  • 세 근사: 사각 펄스 (1/2ε)·[|x| < ε], 가우스 e^(−x²/ε²)/(ε√π), 로런츠 (ε/π)/(x² + ε²). 모양은 달라도 ε → 0에서 ∫f·δ_ε → f(a)로 같은 극한.
  • ε = 1 → 0.1 → 0.01: 높이 0.5 → 5 → 50, 넓이 항상 1, ∫f·δ_ε가 f(a)에 2차(ε²) 속도로 수렴.
  • 점전하: 반지름 ε인 구 안에 전하를 고르게 펼치면(ρ = 3q/4πε³) 구 안 E ∝ r, 발산 = ρ/ε₀ 일정, 구 밖은 0. 부피 적분 = q/ε₀. ε → 0에서 발산이 한 점에 몰리며 δ 함수가 돼요.
  • 델타의 미분·합성(δ(g(x)) = Σδ(x − x_i)/|g′(x_i)|)도 적분으로만 정의돼요.

🧮 이 실험의 계산 방법

δ_ε 세 형태를 격자에서 구성 → 넓이(사다리꼴 적분)와 ∫f·δ_ε 계산; 점전하: 반지름 ε 균일 구의 E(r) 해석해 → ∇·E 수치 미분 → 부피 적분 vs 면 유량 비교

📌 실험 모형과 실제의 차이
· 델타 '함수'는 함수가 아니라 분포(일반화 함수)예요. 격자 계산에서는 ε을 격자 간격보다 작게 줄일 수 없어 극한을 직접 볼 수는 없고, 수렴 경향으로 확인해요.
· 물리적 점전하(전자)의 실제 크기는 10⁻¹⁸ m 이하로 측정되어 델타 함수 모형이 잘 맞지만, 자체 에너지가 발산하는 문제는 양자 전기역학의 재규격화로 다뤄요.

🌍 생활 속에서

  • 신호 처리의 임펄스 응답(망치로 한 번 치기), 샘플링 정리(빗살 함수), 확률의 점질량 분포가 모두 델타 함수예요.
  • 양자역학의 위치 고유 상태와 그린 함수(점 원천의 응답)도 델타 함수로 정의돼요.
