## 1. 결론

8개 HTML 모두 JavaScript 문법 오류, 중복 ID, 참조 누락 ID가 없었고 계산 함수도 정상적으로 값을 반환했다. 전체 621개 조건 조합을 계산해 결과·기록 행 생성까지 검사했으며, 같은 전극을 선택했을 때의 의도된 중단 21건을 제외하면 `NaN`, `Infinity`, 계산 예외는 없었다.

다만 과학 내용상 수정 권고가 필요한 항목은 다음과 같다.

1. **중요 — 04 용해도곱:** 같은 부피의 두 용액을 섞는 설정인데 혼합 후 농도 감소를 반영하지 않아 이온곱 Q가 실제보다 크게 계산된다.
2. **보통 — 06 화학 전지:** 전압-전류가 아니라 전압-농도 실험이 중심이지만, 데이터 검증 문구에서 선형 기울기를 내부 저항이라고 표시할 때 부호를 반대로 해석할 여지가 있다. 현재 공통 분석 표현에서는 음의 기울기 자체가 출력될 수 있으므로 `내부 저항 = −기울기`처럼 명확히 해야 한다.
3. **보통 — 07 전기 분해:** NiSO₄ 수용액에서 Ni 석출만 일어나는 것으로 처리하고 전극 재질을 제시하지 않는다. 실제 수용액에서는 수소 발생 경쟁 및 전극 재질 영향이 있으므로 ‘교육용 이상 모형·불활성 전극’ 조건을 명시하는 것이 안전하다.
4. **보통 — 08 연료 전지:** 내부 저항 손실만 반영한 값을 ‘실제 효율’로 표시한다. 활성화·농도 과전압, 연료 이용률, 보조 장치 손실을 제외했으므로 ‘단순 모형 효율’로 바꾸는 것이 정확하다.

## 2. 검사 방법

- HTML/JavaScript 정적 검사: 스크립트 문법, 중복 ID, `$()` 참조 대상, 기본 문서 구조
- 계산 전수 검사: 모든 선택지 조합에 대해 `compute → stats → record → row` 호출
- 과학 검토: 식, 상수, 단위, 반응식, 전자 수, 농도·부피 처리, 그래프 해석
- UI 검토: 반응형 CSS, 버튼/탭/기록/초기화 흐름, 캔버스 크기 처리, 접근성 속성
- 구성 검토: `units.json`에 적힌 8개 파일과 실제 폴더 파일 일치 확인

참고: 이 작업 환경에서는 브라우저 실행 엔진 다운로드가 네트워크 제한으로 완료되지 않아 픽셀 단위 실제 브라우저 렌더링은 수행하지 못했다. 대신 모든 계산 조건 전수 실행과 스크립트 문법·DOM 참조 정적 검사를 수행했다.

## 3. 파일별 결과

### 01_reaction_rate_lab_MatterEnergy_Ep13-14.html

- 판정: **통과(경미한 보완 권고)**
- 검사 조합: 120개, 오류 0개
- 반응 속도 모형 `v = k[S₂O₃²⁻][H⁺]`, 아레니우스 식, 온도(K) 변환, 촉매의 활성화 에너지 감소 계산은 일관된다.
- `1000/T`를 가로축으로 쓰는 아레니우스 그래프에서 `Ea = −기울기×R`을 kJ/mol로 환산하는 계산도 맞다.
- 보완: 이 모형은 전체 2차 반응이므로 속도 상수 `k`의 단위를 `M⁻¹·s⁻¹`로 표시하는 편이 좋다.

### 02_weak_acid_ka_lab_ChemReaction_Ep02.html

- 판정: **통과**
- 검사 조합: 20개, 오류 0개
- 약산의 이차방정식 해, pH, 이온화도, Ka 역산이 일관된다.
- pH를 0.01 단위로 반올림한 뒤 실험 Ka를 역산하므로 참값과 약간 달라지는 것은 pH 미터 읽기 모형으로 타당하다.
- 탄산은 ‘1단계’로 명시되어 있어 단양성자산 근사 범위가 드러난다.

### 03_titration_buffer_lab_ChemReaction_Ep03_Ep05.html

- 판정: **통과(근사식 보완 권고)**
- 검사 조합: 72개, 오류 0개
- 강산 적정, 약산 반중화점 `pH=pKa`, 중화점의 짝염기 가수분해, 완충 용액 계산은 전체적으로 일관된다.
- 약산 적정 초기에 헨더슨–하셀바흐 식이 처음 pH보다 낮아지면 처음 pH로 고정하는 방식이라 곡선 시작 부분이 잠시 평평해진다. ‘각 지점의 평형을 계산’한다는 설명에 맞추려면 초기 구간도 전하 평형 또는 근사 전환식으로 계산하는 것이 더 정확하다.

### 04_solubility_ksp_lab_ChemReaction.html

- 판정: **수정 필요**
- 검사 조합: 150개, 실행 오류 0개
- Ksp 값, 순수한 물에서의 AB형·AB₂형 용해도 식, 공통 이온 근사식은 적절하다.
- 핵심 오류: 화면은 ‘섞는 두 용액의 농도’ 및 결과표에서 ‘섞기 전 두 용액 농도’라고 설명하지만, 계산은 두 용액을 섞은 뒤에도 각 이온 농도를 그대로 `c`로 사용한다.
- 같은 부피를 섞는다면 혼합 직후 각 이온 농도는 `c/2`이다.
  - AB형: 현재 `Q=c²` → 수정 `Q=(c/2)²=c²/4`
  - AB₂형: 현재 `Q=c³` → 수정 `Q=(c/2)³=c³/8`
- 현재 선택 농도에서는 앙금 유무 판정이 우연히 같을 수 있지만, 표시되는 Q와 `Q/Ksp`는 각각 4배 또는 8배 크게 나온다.
- 권장 수정: `mix(S, cc/2, cc/2)`로 호출하거나 UI 문구를 ‘섞은 뒤 이온 농도’로 바꾼다. 실험 맥락상 전자를 권장한다.

### 05_redox_number_lab_ChemReaction_Ep06.html

- 판정: **통과(표현 보완 권고)**
- 검사 조합: 12개, 오류 0개
- 6개 반응의 산화수 변화와 전자 이동량은 반응식 계수 기준으로 맞다.
- `실제로 섞어 보기`에는 연소·부식·광합성처럼 단순히 섞는 실험이 아닌 항목도 포함된다. 탭 이름을 `현상 관찰` 또는 `반응 관찰`로 바꾸면 더 정확하다.

### 06_galvanic_cell_lab_ChemReaction_Ep08.html

- 판정: **통과(표기 수정 권고)**
- 검사 조합: 147개 중 정상 126개, 의도된 중단 21개, 예외 0개
- 동일 전극 선택 시 중단 메시지가 정상적으로 설계되어 있다.
- 표준 환원 전위, 최소공배수 전자 수, 반응 지수 Q, 네른스트 식, `ΔG=−nFE` 계산은 일관된다.
- 보완: 선형 분석에서 전압을 전류에 대해 그렸을 때 기울기는 `−R`이다. 내부 저항을 보여 줄 경우 `R=−기울기`로 표시해야 한다. 음의 기울기 값을 그대로 ‘내부 저항’이라고 부르면 부호가 틀린 설명이 된다.
- Li 전극은 수용액에서 실제 구현하기 어렵다는 제한을 원리 설명에 이미 밝혀 둔 점은 적절하다.

### 07_electrolysis_plating_lab_ChemReaction_Ep09.html

- 판정: **통과(모형 조건 명시 권고)**
- 검사 조합: 64개, 오류 0개
- `Q=It`, 전자 몰수 `Q/F`, 금속 석출량, 물 전기 분해의 H₂:O₂ 부피비 2:1 계산은 맞다.
- 양극에서 O₂가 발생한다는 결과는 불활성 전극을 전제한다. 전극 재질을 UI 또는 원리 설명에 명시해야 한다.
- NiSO₄ 수용액은 실제로 음극에서 Ni 석출과 H₂ 발생이 경쟁할 수 있다. 현재는 전류 효율 100%의 이상 모형이므로 이를 명시하거나 전류 효율 변수를 도입하는 것이 좋다.

### 08_fuel_cell_lab_ChemReaction_Ep10.html

- 판정: **통과(용어 수정 권고)**
- 검사 조합: 36개, 오류 0개
- 연료별 전자 수, `Q=nzF`, 발전 시간, 전기 에너지, `ΔG/ΔH` 이론 효율 계산은 일관된다.
- 내부 저항에 따른 `V=E°−IR` 모형도 계산상 정상이다.
- 다만 이 값은 오직 내부 저항 손실만 반영한다. `실제 효율` 대신 `단순 모형 효율(내부 저항만 반영)`로 표시해야 실제 연료 전지 성능과 혼동하지 않는다.
- 수소의 ‘물만 나옴’도 전지 출구 기준 설명이다. 전체 환경성을 다룰 때는 수소 생산 방식에 따른 탄소 배출 차이를 덧붙이는 것이 좋다.

## 4. UI·구조 공통 점검

- 8개 모두 스크립트 문법 오류 없음
- 중복 HTML ID 없음

- 모바일에서는 640px 이하에서 1열 레이아웃으로 전환됨

- `prefers-reduced-motion` 대응과 키보드 포커스 표시가 있음
- 캔버스 결과는 텍스트 측정 결과와 함께 제공되어 정보 접근성이 보완됨
