## 반드시 수정할 항목

### B-01 — 01화 해수면 +1 m 확률 예시 불일치

- 화면 설명: 제방 5 m, 해수면 +1 m일 때 연 초과 확률 **0.1 %**, 100년 무사 확률 **90 %**
- 실제 구현: 평균 3 m, 표준편차 0.8 m인 정규 분포에서 `P(X > 5)` 계산
- 실제 결과: 연 초과 확률 약 **0.621 %**, 100년 무사 확률 약 **53.7 %**(100년 침수 확률 약 46.3 %)
- 원인: 설명에 적힌 예시값이 코드의 정규 분포 파라미터와 맞지 않음
- 권장 수정: 설명을 구현 결과에 맞춰 `연 약 0.62 % → 100년 무사 약 54 %`로 고치거나, 의도한 0.1 %를 유지하려면 분포 파라미터를 다시 설계

### B-02 — 01화 제방 높이 비용 증가율 오류

- 화면 설명: 비용이 높이 제곱에 비례할 때 4 m → 5 m는 **44 % 증가**
- 실제 계산: `(5² / 4² - 1) × 100 = 56.25 %`
- 권장 수정: **약 56 % 증가**로 변경

### B-03 — 04화 신용 점수 예시 금리 불일치

- 화면 예시: 755점 → 5 %, 515점 → 15 %
- 구현식: `금리 = 3 % + (1000 - 점수) ÷ 30`(퍼센트 단위)
- 구현 결과: 755점 → 약 **11.2 %**, 515점 → 약 **19.2 %**
- 영향: 화면의 예시 총이자(약 79만 원, 248만 원)는 5 %와 15 % 기준이므로 실제 시뮬레이션 결과와 다르게 표시됨
- 권장 수정: 하나의 기준으로 통일. 현재 구현을 유지한다면 예시 금리와 총이자를 구현 결과로 다시 계산하고, 예시 금리를 유지하려면 점수→금리 함수를 구간식으로 변경

### C-02 — 03화 실패 결과의 ‘잃은 편익’ 정의

코드는 설치 실패 시 `총편익 − 비용`을 `lost`로 둡니다. 총편익이 비용보다 작으면 음수가 될 수 있어 ‘잃은 편익’이라는 이름과 직관이 어긋날 수 있습니다.

- 권장: `실현되지 않은 순편익`으로 명칭을 바꾸고 음수의 의미를 설명하거나, 교육 의도에 따라 `max(0, 총편익 − 비용)` 사용

### D-01 — 캔버스 대체 설명 보강

캔버스에는 `aria-label`이 있으나 결과 그래프의 핵심 수치가 캔버스만으로 제시되는 부분이 있습니다. 측정 결과 표가 대부분을 보완하지만, 시각장애 사용자를 위해 그래프별 요약 문장을 함께 제공하면 좋습니다.

### D-02 — 실제 브라우저 회귀 테스트 추가 권장
