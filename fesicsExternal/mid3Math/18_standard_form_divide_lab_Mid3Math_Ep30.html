30화. 묶을 때 나누는 것을 잊지 마라 — 표준형 고치기

y = 2x² − 8x + 5 를 y = a(x − p)² + q 로 고칠 때, 2로 묶으면서 −8x 를 2로 나누지 않으면 어떻게 될까요? 두 방법으로 만든 표준형 그래프를 원래 그래프 위에 겹쳐 보고, 꼭짓점과 값이 맞는지 확인하세요.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — x² 계수로 묶을 땐 x항도 나눈다

ax² + bx + c = a(x² + (b/a)x) + c = a(x + b/2a)² − b²/4a + c

  • 2x² − 8x + 5 = 2(x² − 4x) + 5 = 2(x − 2)² − 8 + 5 = 2(x − 2)² − 3
  • 나누지 않으면: 2(x² − 8x) + 5 → 전개하면 2x² − 16x + 5 로 원래 식과 다름

또 괄호 안에서 더하고 뺀 (b/2a)² 을 밖으로 꺼낼 때 a를 곱해 빼야 합니다.

📌 검산
표준형을 다시 전개해서 원래 식이 나오는지, 또는 x = 0 을 넣어 두 식의 값(= c)이 같은지 확인하세요.

파란 곡선은 원래 식, 초록(또는 빨강) 점선은 내가 만든 표준형입니다. 두 곡선이 겹치면 올바르게 고친 거예요.
