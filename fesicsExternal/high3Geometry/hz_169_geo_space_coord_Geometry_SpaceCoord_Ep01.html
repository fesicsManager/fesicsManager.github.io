좌표공간 실험실 — 축이 하나 늘었다

점의 세 좌표를 바꿔 가며 위치를 보고, z = 0 인 점도 공간의 점인지 확인합니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 좌표공간의 점은 (x, y, z) 세 수로 정해진다 — z = 0 도 공간의 점

z = 0 인 점은 xy평면 위에 있는 공간의 점이에요. 평면에서 y = 0 인 점이 x축 위의 점이지 “평면 밖”이 아닌 것과 같습니다. 세 좌표 중 하나가 0 이면 그 좌표에 해당하는 평면 위에 있다는 뜻입니다.

⚙️ 왜 그럴까

  • 좌표평면 = z = 0 인 점들의 모임, 좌표공간에 포함됩니다.
  • 좌표가 두 개 0 이면 축 위의 점입니다.
  • 세 개 모두 0 이면 원점입니다.

🧮 이 실험의 계산 방법

세 좌표를 바꿔 가며 점의 위치와 소속(축·평면·일반 위치)을 판정

📌 자주 하는 오해
· “z좌표가 0 이면 공간의 점이 아니다” → xy평면 위의 공간의 점입니다.

🌍 생활 속에서

  • 지도에서 고도 0m 인 지점도 3차원 공간의 한 점입니다.
