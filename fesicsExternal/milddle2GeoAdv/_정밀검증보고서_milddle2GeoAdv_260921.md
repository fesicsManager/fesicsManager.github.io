## 반드시 수정할 항목

### 1. `03_earthquake_energy_lab.html` — 지진 에너지 배율의 기준 혼용

- 원리 설명은 `log E = 1.5M + 4.8`을 제시한다. 이 식을 따르면 규모 차이 1은 약 31.6배, 차이 2는 정확히 1,000배, 차이 4는 1,000,000배이다.
- 그러나 실험 코드는 `K=32`, `32^(규모 차)`를 사용한다. 따라서 차이 2를 1,024배, 차이 4를 1,048,576배로 계산하고 문제 정답도 1,024로 판정한다.
- 같은 페이지 첫 설명에는 “2 차이가 1,000배”, 표·문제에는 “1,024배”가 나와 학생 입장에서는 두 정답이 충돌한다.

권장 수정:

- 가장 정확한 방법: `Math.pow(10, 1.5 * diff())`로 통일하고 차이 1은 31.6배, 차이 2는 1,000배, 차이 4는 100만 배로 표시한다.
- 교과서식 32배를 유지하려면 모든 값에 ‘약’을 붙이고, 문제 정답은 1,000과 1,024를 모두 근삿값으로 허용해야 한다.

### 2. `06_star_magnitude_lab.html` — “2.5⁵ = 정확히 100” 표현

- 코드의 실제 상수는 `100^(1/5) = 2.511886...`라서 계산 자체는 정상이다.
- 그러나 분석 문구는 “2.5를 다섯 번 곱해 정확히 100배”라고 설명한다. 실제로 `2.5^5 = 97.65625`이며, 정확히 100배가 되는 것은 `2.511886...^5`이다.

권장 문구:

> 1등급 차이는 약 2.512배이고, 이 값을 다섯 번 곱하면 정확히 100배가 됩니다.

화면 계산식도 `2.5^d` 대신 `2.512^d` 또는 `100^(d/5)`로 표시하면 코드와 설명이 완전히 일치한다.

### 4. `09_hubble_law_lab.html` — 적색 편이 그림의 위치식

- 수치 표시는 `z = v/c`로 올바르게 계산한다.
- 하지만 검은 흡수선의 화면 위치는 `b*(1+z) + z*0.55`를 사용하여 물리적 파장 관계 `λ관측 = λ기준(1+z)`보다 추가로 이동시킨다.
- 정성적 그림이라면 가능하지만, 화면에 z 수치가 함께 제시되므로 정량적 관계로 오해될 수 있다.

권장 수정:

- 실제 파장 축을 두고 `λ관측 = λ기준(1+z)`로 계산하거나,
- 현재 그림을 유지하려면 “이동을 보기 쉽게 확대해 표시”라고 명시한다.

## 파일별 세부 확인

### `02_plate_speed_lab.html`

- 2.5 cm/년 × 100만 년 = 25 km 정상.

- 46억 년 계산 115,000 km 정상.
- 그래프 축의 시간 단위(백만 년)와 거리 단위(km) 일치.

- 중복 기록만 보완 권장.

### `03_earthquake_energy_lab.html`

### `06_star_magnitude_lab.html`

- 5등급 차이 = 100배, 1등급 차이 = 100^(1/5) ≈ 2.512배 정상.

- 프리셋 값이 슬라이더 범위를 벗어날 때 제한값으로 표시하고 실제 값과 다름을 알리는 안내 존재.
- “2.5를 다섯 번 곱해 정확히 100” 문구 수정 필요.
- 동일 등급 조합 중복 기록 가능.

### `07_diurnal_annual_motion_lab.html`

- 일주 운동 15°/시간, 연주 운동 약 30°/월, 하루 약 0.986° 정상.
- 3시간 → 45°, 2개월 → 60°, 2시간 일찍 → 약 1개월 문제 정답 정상.
- 항성일 23시간 56분과 교육용 24시간 근사의 차이를 별도로 안내함.
- 24시 시작 입력은 현재 시각 표시에 `0시`로 정상 환산됨.
- 동일 조건 중복 기록 가능.

### `09_hubble_law_lab.html`

- `v = H0 d`, `H0 = 70 km/s/Mpc`, `d = v/H0` 계산 정상.
- 100 Mpc → 7,000 km/s, 200 Mpc → 14,000 km/s, 3,500 km/s → 50 Mpc 정상.
- 1 Mpc ≈ 326만 광년 변환 정상.
- 가까운 은하의 고유 운동, 허블 긴장, 큰 적색편이에서 `v ≈ cz`의 한계를 안내함.
- 같은 거리의 중복 기록은 차단되어 있음.
- 적색 편이 그림의 흡수선 위치식만 보완 권장.
