항을 많이 쓸수록 근삿값은 정확해진다?

a = 0을 중심으로 한 n차 테일러 다항식 Tₙ(x)로 함수값을 근사하고, 실제 오차와 라그랑주 공식이 보장하는 오차 한계를 나란히 봅니다. 뭉치는 “항을 많이 쓰면 무조건 정확, 반경 안이면 무조건 원래 함수”라고 했어요. e^(−1/x²)도 골라 보세요.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 라그랑주 나머지

f(x) = Tₙ(x) + Rₙ(x), Rₙ(x) = f⁽ⁿ⁺¹⁾(c)/(n + 1)! · xⁿ⁺¹ (c는 0과 x 사이)

|f⁽ⁿ⁺¹⁾| ≤ M이면 |Rₙ| ≤ M·|x|ⁿ⁺¹/(n + 1)! — n = 0이면 5화의 평균값 정리입니다.

  • e = Σ1/k! + Rₙ, e < 3을 쓰면 |Rₙ| ≤ 3/(n + 1)!. 10⁻⁶ 미만을 보장하려면 (n + 1)! > 3×10⁶ → 10! = 3628800 → n = 9.
  • sin의 짝수 차 항, cos의 홀수 차 항은 0이라 Tₙ이 한 차수 위 다항식과 같고, 한계가 한 단계 더 작아집니다.
  • √(1 + x) ≈ 1 + x/2의 오차는 |f″| ≤ ¼에서 ≤ x²/8. f″ < 0이라 나머지가 음수, 근삿값이 참값보다 큽니다.
  • e^(−1/x²)(f(0) = 0)는 0에서 모든 도함수가 0이라 테일러 급수가 0입니다. 급수는 어디서나 수렴하지만 함수와 0에서만 같아요.
📌 실험 모형과 실제의 차이
· 한계는 “최악의 경우” 보증서입니다. 실제 오차는 항상 한계 이하이고, 거의 꽉 찰 때도 넉넉할 때도 있어요.
· eˣ의 한계는 c가 0과 x 사이라 e^c < eˣ < 3ˣ로 잡았습니다(x > 0).

🌍 생활 속에서

  • 진자의 sin θ ≈ θ(오차 ≤ θ³/6), 상대론 운동 에너지의 첫 항 ½mv²처럼 물리 근사는 대부분 테일러 1~2차입니다. 계산기는 sin 3을 sin(π − 3)으로 바꿔 0 근처로 끌어와 계산해요.

파란 곡선은 원래 함수, 주황 곡선은 n차 테일러 다항식입니다. 세로 선 위의 빨간 막대가 x에서의 실제 오차, 연한 초록 띠가 Tₙ(x) ± 오차 한계입니다.
