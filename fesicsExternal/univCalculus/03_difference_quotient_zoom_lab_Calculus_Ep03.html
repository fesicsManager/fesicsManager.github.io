연속이면 미분할 수 있지 않나

다섯 함수 모두 x = 0에서 연속입니다. h를 줄여 가며 오른쪽·왼쪽 차분몫 (f(±h) − f(0))/(±h)를 계산해 한 값으로 모이는지 봅니다. 뭉치는 x²·sin(1/x)이 0 근처에서 미친 듯이 흔들리니 g′(0)이 없다고 했어요. 정의대로 계산해 보세요.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 미분계수는 차분몫의 극한

f′(a) = lim(h→0) [f(a + h) − f(a)] / h (이 극한이 존재할 때만)

  • 미분 가능 ⇒ 연속: f(a + h) − f(a) = (차분몫)·h → f′(a)·0 = 0.
  • 연속 ⇏ 미분 가능: |x|는 좌 −1, 우 +1. x·sin(1/x)의 차분몫은 sin(1/h)로 계속 진동.
  • 미분 가능 ⇏ 도함수 연속: x²·sin(1/x)의 차분몫 h·sin(1/h)는 |h| 이하로 눌려 0으로(조임 정리). 그런데 x ≠ 0에서 g′(x) = 2x·sin(1/x) − cos(1/x)는 0 근처에서 진동합니다.

🧮 이 실험의 계산 방법

h = 0.1, 0.01, 0.001, 0.0001에서 오른쪽 (f(h) − f(0))/h와 왼쪽 (f(−h) − f(0))/(−h)를 그대로 계산합니다. “도함수 공식에 0을 넣을 수 없다”는 것은 극한과 함숫값을 혼동한 거예요.

📌 실험 모형과 실제의 차이
· 유한한 h 몇 개로는 극한을 증명할 수 없습니다. 표는 증명의 방향(|h·sin(1/h)| ≤ |h|)을 보여 줄 뿐이에요.
· u(x) = x + 2x²·sin(1/x)는 u′(0) = 1 > 0인데도 x = 1/(2kπ)에서 u′ = −1이라 0 근처에서 증가함수가 아닙니다.

🌍 생활 속에서

  • 마찰력이 방향을 바꾸는 점, 다이오드가 켜지는 점, |x| 꼴 손실 함수처럼 공학에는 미분 불가능한 점이 흔합니다. 그래서 좌·우 미분계수를 따로 보거나 “C¹ 함수”라는 조건을 붙여요.

x = −1.6h ~ 1.6h를 확대한 그림입니다. 원점에서 (h, f(h))와 (−h, f(−h))로 그은 두 할선의 기울기가 차분몫입니다. 두 기울기가 h를 줄일 때 같은 값으로 모이면 미분 가능합니다.
