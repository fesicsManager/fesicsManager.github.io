적분은 넓이 공식 아닌가

구간을 n등분해 각 조각에서 가장 큰 값으로 높이를 잡으면 상합 Uₙ, 가장 작은 값이면 하합 Lₙ입니다. n을 늘릴 때 Uₙ − Lₙ이 0으로 가면 적분 가능해요. 뭉치는 x²의 U₁₀ − L₁₀을 “상합 0.385”라고 했습니다. 차이만 따로 계산해 보세요. 디리클레 함수도 골라 보세요.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 적분은 직사각형 합의 극한으로 정의한다

Lₙ ≤ ∫f dx ≤ Uₙ, 유계인 f가 적분 가능 ⇔ lim (Uₙ − Lₙ) = 0

  • 증가함수 x²의 [0, 1]: Uₙ − Lₙ = (f(1) − f(0))/n = 1/n. 그래서 U₁₀ − L₁₀ = 0.1.
  • 계단 함수: 상합과 하합이 다른 조각은 ½이 들어 있는 조각 하나뿐 → Uₙ − Lₙ ≤ 1/n → 0, 적분값 ½.
  • 디리클레 함수(유리수 1, 무리수 0): 모든 조각에서 최대 1, 최소 0 → Uₙ − Lₙ = 1로 고정. 리만 적분 불가.

🧮 이 실험의 계산 방법

증가함수는 조각의 오른쪽 끝이 최대, 왼쪽 끝이 최소입니다. 중점 합 Mₙ은 조각 가운데 높이를 씁니다. x²에서 오차는 정확히 1/3 − Mₙ = 1/(12n²), 일반적으로 오차 한계 (b − a)³·max|f″|/(24n²).

📌 실험 모형과 실제의 차이
· 컴퓨터는 무리수를 정확히 표현하지 못하므로 디리클레 함수는 “각 조각에 유리수·무리수가 모두 있다”는 사실로 계산합니다(조각의 끝점·중점은 유리수라 값 1).
· 정적분은 부호 있는 넓이입니다. ∫₋₁¹x³dx = 0이지만 그래프와 x축 사이 넓이는 ½이에요.

🌍 생활 속에서

  • 공학 데이터는 식이 아니라 측정값 표로 옵니다. 가속도 센서 값을 시간 간격마다 더해 속도를 얻는 것이 바로 리만 합이에요.

연한 파랑 직사각형은 상합, 진한 초록은 하합입니다. 둘의 차이(파랑만 보이는 부분)가 Uₙ − Lₙ입니다. 주황 점은 각 조각의 가운데(중점 합)입니다.
