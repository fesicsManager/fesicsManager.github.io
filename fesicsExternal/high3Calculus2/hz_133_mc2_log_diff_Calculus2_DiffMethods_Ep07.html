xˣ 실험실 — 로그를 씌우고 미분한다

밑과 지수를 따로 바꿔 가며, 어떤 꼴에서 어떤 공식이 통하고 로그 미분법만 늘 통하는지 봅니다.

📖 수학 원리 — 어떤 원리로 이렇게 될까?

🔑 핵심 원리 — 밑과 지수에 모두 x 가 있으면 거듭제곱 공식도 지수함수 공식도 쓸 수 없다

xⁿ 은 밑만 변수, aˣ 는 지수만 변수예요. xˣ 는 둘 다 변수라 두 공식 모두 통하지 않습니다. 양변에 로그를 씌워 ln y = x ln x 로 만든 뒤 음함수 미분하면 y′ = xˣ(ln x + 1) 이 나옵니다.

⚙️ 왜 그럴까

  • ln y = x ln x 를 x 로 미분하면 y′/y = ln x + 1.
  • 양변에 y = xˣ 를 곱하면 y′ = xˣ(ln x + 1).
  • 로그가 지수를 앞으로 내려 곱셈을 덧셈으로 바꿔 줍니다.

🧮 이 실험의 계산 방법

식의 꼴(xˣ · x^c · c^x)과 상수 c, 그리고 x 를 바꿔 가며 수치 미분값과 세 후보 식을 나란히 비교합니다. 거듭제곱 공식은 지수가 상수일 때만, 지수함수 공식은 밑이 상수일 때만 맞고, 로그 미분법은 셋 다 맞습니다.

📌 자주 하는 오해
· “xˣ 는 미분할 수 없다” → 로그를 씌우면 됩니다.
