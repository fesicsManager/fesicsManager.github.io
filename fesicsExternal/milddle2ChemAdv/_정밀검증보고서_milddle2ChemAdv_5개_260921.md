## 3. 반드시 수정할 오류

### [중요] `02_density_float_lab.html` — 밀도 1.00의 경계값 판정 오류

#### 재현 조건

- 질량 50 g, 부피 50 cm³처럼 `질량 ÷ 부피 = 1.00 g/cm³`가 되게 설정한다.
- 또는 질량과 부피를 같은 값으로 설정한다.
- `물에 넣어보기`를 누른다.

#### 현재 동작

- 코드: `var floats = d < WATER_D;`
- `d === 1.00`이면 `floats`가 거짓이 되어 결과표에 **가라앉음**으로 기록된다.
- 결과 문구는 **“물(1.00)보다 크므로 가라앉습니다”**라고 표시된다.
- 캔버스 설명도 **“물보다 무거움 → 가라앉는다”**로 표시된다.

#### 문제점

밀도가 물과 정확히 같으면 물체의 무게와 부력이 같아져 이상적인 모형에서는 물속에 **중성 부력 상태로 머문다**. `1.00`은 물보다 큰 값이 아니므로 현재 문구는 수학적으로도 모순이다. 파일의 과학 원리 설명에는 이미 “밀도가 물과 거의 같은 물체는 물속 아무 데나 머물러요”라고 되어 있어, 설명과 실행 결과도 충돌한다.

#### 권장 수정

3상태로 판정한다.

```js
var EPS = 1e-9;
var state = d < WATER_D - EPS ? 'float'
          : d > WATER_D + EPS ? 'sink'
          : 'neutral';
```

- `float`: 뜸
- `sink`: 가라앉음
- `neutral`: 물속에 머묾(중성 부력)

결과표·결과 문구·캔버스 위치·색상·검증 통계도 같은 3상태를 사용해야 한다. 예시 문구는 다음이 적절하다.

> 밀도 = 1.00 g/cm³로 물과 같으므로, 이상적인 조건에서는 물속에 떠 있는 상태로 머뭅니다.

#### 영향 범위

- 결과 박스
- 측정 기록 표
- 캔버스 물체 위치와 상단 설명
- 데이터 확인 탭의 “뜬 경우/가라앉은 경우” 통계
- “모두 떴다/모두 가라앉았다” 분석 문구

현재 슬라이더가 질량과 부피를 각각 5 단위로 선택하게 되어 있어 같은 값을 고르기 쉽기 때문에, 드문 예외가 아니라 실제 사용 중 쉽게 발생하는 오류다.
